# If you can't share to DVD or Blu-ray disc in Final Cut Pro, Motion 5, or Compressor

If you're using an image for the background, logo image, or title image, try converting the image using Preview.

If you're trying to share to DVD or Blu-ray in Final Cut Pro on Mac, Motion or Compressor, and "The share operation DVD has failed” or "The share operation Blu-ray has failed” alert appears, check the format of the file you're using for the background, logo image, or title image.

## Check the format of the image

Select the image in Finder and choose Get Info. In necessary, click the disclosure arrow next to General. If "High Efficiency Image File Format" (HEIF) appears next to Kind, convert the file to another format with Preview.

[Image: the disclosure arrow]

## Convert the HEIF file

- Locate the file in the Finder, then double-click the file to open it in Preview.

- Choose File > Export.

- Enter a name and choose a location for your file.

- Hold the Option key, click the Format pop-up menu, then choose one of the following file types:

- JPEG

- PNG

- TIFF

- PDF

- PSD

- BMP

- GIF

- Click Save.

- Update your Menu Graphics with the new converted file, then share to DVD or Blu-ray again.
