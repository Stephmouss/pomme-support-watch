# Get missing Sound Library patches in Logic Pro for Mac

To reinstall patches in the Sound Library that were missing after updating to Logic Pro 12.0, update to Logic Pro 12.2, then download the Logic Pro Legacy patches, instruments, and loops sound packs.

## Get missing Sound Library patches

- [Update to Logic Pro 12.2](https://support.apple.com/en-us/122606) , then open Logic Pro.

- Click Logic Pro in the menu bar, then choose Sound Library.

- Enter "Logic Pro Legacy" into the search field at the top of the Sound Library window.

- Select any of these legacy sound packs that you want to install, then click Install next to each sound pack:

- Logic Pro Legacy Patches

- Logic Pro Legacy instruments

- Logic Pro Legacy Loops

[About the updated sound library for Logic Pro 12 and later and MainStage 4 and later on Mac](https://support.apple.com/en-us/125036)
