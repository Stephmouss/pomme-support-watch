# iOS and iPadOS 15.0 and 15.0.1 are unavailable for delayed software updates

Apple recommends that you update to iOS 15.0.2 and iPadOS 15.0.2 or later.

This article is intended for network administrators.

iOS and iPadOS 15.0 and 15.0.1 are unavailable for delayed software updates. iOS 15.0.2 and iPadOS 15.0.2 contain important fixes for issues in iOS and iPadOS 15.0 and 15.0.1. Learn [about the security content of iOS 15.0.2 and iPadOS 15.0.2](https://support.apple.com/kb/HT212846) .

Administrators can adjust the software update delay to allow users to install iOS 15.0.2 and iPadOS 15.0.2, which was posted on October 11, 2021, or install a specific OS version using the Schedule OS Update command. Refer to your MDM vendor for instructions on adjusting the delay or sending this command.
