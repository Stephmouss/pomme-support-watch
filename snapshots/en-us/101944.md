# When and how to use diagnostics mode with iPhone and iPad

Diagnostics mode is a part of Recovery Assistant for iPhone and iPad. Diagnostics mode allows you to check for potential hardware or software issues on your device or to finish a repair for a replaced part.

## Learn about diagnostics mode

Diagnostics mode allows you to run tests to verify if your device's hardware and software are functioning properly. It guides you through tests for components like the display, camera, and Face ID. You might use it to troubleshoot a specific concern or to finish a repair for a part that's been replaced.

## What you need

Recovery Assistant and diagnostics mode are available on these devices:

- iPhone 14 models and later

- iPad Pro M4 and later

- iPad Air M2 and later

- iPad mini (A17 Pro)

- iPad (A16)

To use diagnostics mode, your device needs access to a Wi-Fi network.

## Start diagnostics mode

- Start Recovery Assistant by turning off your device and pressing and holding the side button when your device starts up.

- Tap Diagnostics Mode.

[Learn more about Recovery Assistant](https://support.apple.com/en-us/123114)

## Learn about the tests

You can run the following tests in diagnostics mode.

### Mobile Resource Inspector

Mobile Resource Inspector is an initial triage tool that checks the device's software version, verifies the presence of certain parts, and checks whether the parts pass basic functionality tests.

### Audio

Consider your surroundings before running this test; your device will play loud test tones through the speakers.

This test asks you to verify that you hear certain tones and that they aren't distorted. Next, to confirm that each microphone can detect sound, the test asks you to record a short audio clip. The recording is used only during the test and is deleted after the test.

### Display pixel anomalies

This test helps identify pixel anomalies and other display-panel issues. The test shows a series of colors and patterns:

- For each color or pattern, draw or tap on the display to indicate if you see any anomalies. If you mark an area accidentally, tap the rectangle to remove it.

- Swipe left with two fingers to proceed through each color and pattern.

- When you're finished, press Done.

If you want to exit the test, press the side button or one of the volume buttons.

### Multi-Touch

A case or screen protector could interfere with this test; if you have a case or screen protector, remove it before starting the test.

This test helps identify issues with Multi-Touch response:

- Slide your finger over the whole display to identify any areas of the display that don't respond properly to touch.

- As you slide your finger, blue rectangles appear on the display indicating areas that are responding to touch.

### Face ID

This test checks the Face ID sensors.

- Hold the device about an arm's length away, facing you, until the test is finished.

- This test can take about a minute. You don't need to stay still or look at the device during the test.

The test doesn't take a photo, and the scans aren't saved.

### Camera image quality

This test helps identify camera image-quality issues for the front and rear cameras.

- The test will ask you to take a photo using each camera. To evaluate image quality, use a solid white paper or wall, or a photo test chart.

- After you take a photo, indicate any camera-quality issues by drawing or tapping the issue with your finger. If you mark an area of the photo accidentally, tap the rectangle to remove it.

All photos taken for this test appear only during the test and aren't saved.

## If diagnostics mode finds an issue

If diagnostics mode finds an issue, you might need service. [Get service](https://getsupport.apple.com/?caller=kbase) .

When evaluating your device, the service provider might run additional tests or might run one or more tests again.
