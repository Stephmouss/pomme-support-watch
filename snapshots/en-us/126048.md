# If Pixelmator Pro for iPad isn't working

First, check the compatibility of any third-party hardware or software and back up your device and content. Then, try each troubleshooting step, testing after each step to see if your issue is resolved.

If you want to subscribe to Pixelmator Pro or change your subscription, [check the Pixelmator Pro User Guide](https://support.apple.com/guide/pixelmator-pro/ed6ey8wwpkpr/ipados) .

## Before you begin

- If you just updated Pixelmator Pro or iPadOS and Pixelmator Pro isn't working, any third-party software or hardware you're using might not be compatible. Contact developers or manufacturers of all the third-party items that you're using to check for compatibility with the version of Pixelmator Pro and iPadOS you're using.

- [Back up your iPad](https://support.apple.com/guide/ipad/ipad9a74df05xx/ipados) before troubleshooting Pixelmator Pro. You can also [export individual photos, videos, and documents](https://support.apple.com/guide/pixelmator-pro/pixa7f02d291/ipados) .

## Troubleshoot Pixelmator Pro for iPad

After each step, test Pixelmator Pro to see if you fixed your issue.

### 1. Restart your iPad

To restart your iPad, [turn it off, then turn it back on](https://support.apple.com/en-us/101603) .

### 2. Disconnect external devices

If an external device like a camera or storage device is connected to your iPad, disconnect it:

- Turn off your iPad.

- Disconnect all external devices.

- Turn on your iPad.

If the issue only occurs when a particular external device is connected, you might need to update or service the device. Contact the manufacturer for support.

### 3. Check system requirements

Pixelmator Pro for iPad [requires iPadOS 26 or later](https://support.apple.com/en-us/125029#specs) . To check the version of iPadOS that's currently installed on your iPad:

- Open the Settings app.

- Select General, then tap About.

- Tap on iPadOS Version.

If your iPad is using a version of iPadOS that's earlier than iPadOS 26, check that any third party software you're using is compatible with the latest version of iPadOS, then [update iPadOS](https://support.apple.com/en-us/118575) .

[Learn more about iPadOS versions](https://support.apple.com/en-us/109065)

### 4. Make sure the app is working as expected

To make sure the app is performing as you expect, check the [Pixelmator Pro for iPad User Guide](https://support.apple.com/guide/pixelmator-pro/welcome/ipados) . You can search the User Guide for key terms shown in alerts, alert icons, or error messages.

### 5. Update Pixelmator Pro for iPad

Try to complete all active documents before updating.

- [Back up your iPad](https://support.apple.com/guide/ipad/ipad9a74df05xx/ipados) before troubleshooting Pixelmator Pro. You can also [export individual photos, videos, and documents](https://support.apple.com/guide/pixelmator-pro/pixa7f02d291/ipados) .

- [Update Pixelmator Pro for iPad](https://support.apple.com/guide/ipad/ipad05566c91/ipados) .

### 6. Check camera or storage device firmware

For any external devices you're using like cameras or storage devices, check with the manufacturer for firmware updates. Follow the manufacturer's instructions to update.

### 7. Check that you're using a supported media format.

[Learn about the image formats, video formats, and file types supported by Pixelmator Pro](https://support.apple.com/guide/pixelmator-pro/a7veyq8q24zq/ipados)

### 8. Test with a new document

If you can't reproduce the issue using test media, the issue might be related to the source file in the affected project.

- Create test media for Pixelmator Pro for iPad:

- Open Pixelmator Pro, then tap Create a Document.

- In the Basic section of the templates browser, tap the Basic Square Post template, then tap Create.

- Tap the document name in the toolbar, choose PNG from the Format menu pop-up menu, then tap Export.

- Open the exported PNG file in Pixelmator Pro, then try to recreate the issue using the test media. In Pixelmator Pro, tap "Create a Document" to create a new document

If Pixelmator seems to be working as expected, try to get a new copy of the source file that you were using when you were experiencing issues with Pixelmator.

### 9. Remove and reinstall Pixelmator Pro for iPad

When you delete the Pixelmator Pro for iPad app from your iPad, back up your projects before deleting the app from your iPad first.

- [Back up your iPad](https://support.apple.com/guide/ipad/ipad9a74df05xx/ipados) or [export individual photos, videos, and documents](https://support.apple.com/guide/pixelmator-pro/pixa7f02d291/ipados) .

- [Remove Pixelmator Pro](https://support.apple.com/guide/ipad/ipad0aed1df8/26/ipados/26) from your iPad.

- [Redownload Pixelmator Pro](https://support.apple.com/en-us/102417) from the App Store.

- Test with a template from the Basic section of the Templates browser.

- If the issue no longer occurs, open the document you need to work on.
