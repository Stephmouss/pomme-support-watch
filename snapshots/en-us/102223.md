# Import or share notes and files to the Notes app

Keep your notes in one place on Mac, iPhone, and iPad.

## Before you begin

Update your [Mac to the latest macOS](https://support.apple.com/en-us/108382) and your [iPhone or iPad to the latest iOS or iPadOS](https://support.apple.com/en-us/118575) .

## Import text files to Notes

On Mac, Notes can import the following text file types:

- .txt

- .rtf

- .rtfd

- .html

- .enex

- .md

Each text file converts to a new note.

- Open Notes.

- From the Notes sidebar, choose a folder in either iCloud* or On My Mac.

- Choose Import to Notes from the File menu in the menu bar.

- Choose the text file(s) or folder(s) that you want to import. If the notes are organized in folders, click Preserve folder structure on import." If you can't find this setting, click Show Options.

- Click Import.

- Click Import again in the "Import to Notes?" window.

If you chose iCloud, imports go in an Imported Notes folder in the iCloud section in Notes. Otherwise, this folder appears in the On My Mac section in Notes.

Each Evernote file (.enex) can include multiple notes, and Notes converts each to a new note. If an Evernote file has an attachment or feature that Notes doesn't support, the attachment or feature isn't imported.

## Import Markdown files (.md) to Notes

In macOS Tahoe 26, iOS 26, iPadOS 26, and later, Notes converts Markdown syntax to rich text that maintains formatting.

On Mac:

- Open Notes.

- Choose Import Markdown from the File menu in the menu bar.

- Select one or more .md files.

- Click Import.

- Click Import again in the "Import to Notes?" window.

If you use iCloud,* imports go in an Imported Notes folder in the iCloud section in Notes. Otherwise, this folder appears in the On My Mac section in Notes.

On iPhone and iPad, follow the steps for sharing with the Files app.

## Share files to Notes with the Files app

On iPhone and iPad:

- Open the Files app.

- Touch and hold a file.

- Tap Share.

[Image: iPhone, screen shows the menu that opens when you tap and hold a file.]

- Tap Notes.

- Save as a new note in iCloud* or On My Device, or save to an existing note in iCloud or On My Device.

## Share files to Notes with Finder

On Mac:

- Open Finder.

- Control-click a file.

- Select Share.

- Select Notes.

- Save as a new note in iCloud* or On My Mac, or save to an existing note in iCloud or On My Mac.

## Share files to Notes with Mail

On Mac, iPhone, and iPad:

- Open Mail.

- Open an email with a note or file.

- On Mac, control-click the note or file, then select Share. On iPhone and iPad, touch and hold the note or file, then tap Share.

[Image: iPhone, screen shows a menu open for sharing a note to Notes.]

- Select Notes.

- Save as a new note in iCloud* or On My Device, or save to an existing note in iCloud or On My Device.

* iCloud notes are available on any device signed in to your Apple Account.
