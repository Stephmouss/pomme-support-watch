# If an app continues running in the background after you quit it

Starting in macOS 27 Golden Gate, your Mac shows you when an app continues running in the background after you quit it. The first time this happens with an app, you see a notification. Additionally, you see an indication that it's running in the background when you hover over the icon in the Dock.

[Image: An icon in the Dock for an app that is running in the background. When the cursor hovers over the icon, the name of the app and the text "Running in Background" appear over the app.]

## Why apps run in the background

An app might continue running briefly in the background to complete tasks like:

- Checking for updates, syncing data, or performing other tasks that help the app run.

- Retaining access to any sensors (like your camera, microphone, or screen capture) or personal data that you allowed access to while using the app.

While an app continues to run in the background, it might slow the performance of your Mac.

## What you can do

When an app continues to run in the background, you have several options:

- Reopen the app: Click the icon in the dock to reopen the app.

- Stop this app from running in the background: Control-click the icon, then choose Stop Running in Background. You can also [choose to prevent the app from running in the background in the future](https://support.apple.com/en-us/125671#manage) .

[Image: Control-click menu for an app running in the background with a button to stop running the app.]

## Manage apps that can run in the background in System Settings

You can see which apps are allowed to run in the background and manage this behavior for each app.

- From the Apple menu, choose System Settings.

- Choose General, then Login Items & Extensions.

- Under Background App Activity, find the app you want to manage.

- Turn the app's ability to run in the background on or off.

If you turn off an app's ability to run in the background, the app might not work as expected. For example, it might not update automatically or sync your data.

## If an app doesn't work after you stop it from running in the background

If an app doesn't work as expected after you turn off its ability to run in the background, turn it back on in System Settings:

- From the Apple menu, choose System Settings.

- Choose General, then Login Items & Extensions.

- Under Background App Activity, find the app and turn its ability to run in the background on.

If you don't want the app to run in the background but it's required for the app to work, contact the app developer.

[Contact an app developer >](https://support.apple.com/en-us/102435)
