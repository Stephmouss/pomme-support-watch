# Logic Pro for iPad release notes

Learn about the main features of Logic Pro for iPad.

## New in Logic Pro for iPad 3.3

New features and enhancements

- Beat Breaker

- Includes new filter and resonance modes with high or low pass filters per slice.

- Includes panning mode to allow panning left and right per slice.

- Includes randomization for all modes, or per mode including controls for probability and intensity.

- Alchemy

- Granular engine has been expanded with Granular Sync.

- Now includes formant shifting.

- New sound pack

- Includes loops, one-shots, and field recordings processed with Alchemy's new Granular Sync.

- Other enhancements

- The Flex & Follow interface has been redesigned.

- Drum Machine Designer pads can now be copied and pasted in Edit mode.

- Lessons now appear in search results when using the app-wide search feature.

- Notes in the Piano Roll now use an updated default color scheme.

- A new setting is available in App Settings to change how notes are colorized in the Piano Roll.

- A Repeat command is now available in the Piano Roll.

- Icons have been added to items in the main menu.

- A Bypass command is now available in the shortcut menu for effect and send slots in the channel strip.

- The Original Tempo parameter is now available in the Audio Region Inspector.

Stability and reliability

- Resolves an issue where the Undo and Redo buttons in the Control Bar would not resize when the system text size was changed.

- Resolves an issue where the Horizontal Channel Strip would not display the correct plug-ins after changing the track selection.

- Resolves an issue where the Default Region Type indicator in the Track Header was misleading when no explicit type was set.

- Resolves an issue where the Region Inspector would not visually update its displayed values.

- Fixes a label where "S-Curve" is now correctly displayed as "S Curve."

- Resolves an issue where the navigator position setting would not be retained.

- Resolves an issue where adding an Apple Loop to an existing track would always rename the track.

- Resolves an issue where track names from Logic Pro for Mac projects were not preserved when opened in Logic Pro for iPad.

- Restores the ability to display the Fretboard Play Surface.

- Resolves an issue where dragging certain loops to the search field would not reorder the loop list correctly.

- Resolves an issue where changing the Transpose value in Region Settings would not update the Piano Roll display or the pitch of note events.

- Resolves an issue where Logic Pro could become unresponsive while downloading sound packs.

- Resolves an issue where text in the Settings menu appeared in an incorrect color.

- Resolves an issue where a forward slash in a project name was displayed as a colon while the document was open.

- Resolves an issue where spatial audio files created in Voice Memos could not be loaded into Quick Sampler or Sample Alchemy when dragged to the Track header.

- Resolves an issue where changes to Flex settings in Project Settings would not update the Default Region Type setting.

- Resolves an issue where changing the color of a Take Folder would not update the color of the active Take.

- Resolves an issue where switching Takes in a Live Loops cell would not update the Piano Roll.

- Resolves an issue where the Automation mode indicator in the Track Header was not updated after deleting Track-Based Automation.

- Resolves an issue where adding an Audio Loop to the Tracks area would create an Audio Track without an input assignment.

- Resolves an issue where selecting a track header in Automation mode would not select the associated regions or update the displayed content in the Editor.

- Resolves an issue where the hairline marker at the end of a moved Cycle region was missing.

- Resolves an issue where Logic Pro could quit unexpectedly due to a UIKit rendering error.

- Resolves an issue where the confirmation dialog for deleting all installed sound packs would not consistently appear.

- Resolves an issue where the Delete All option was not available in the expected location.

- Resolves an issue where enabling or disabling modes in the Beat Breaker Randomize popover would cause the interface to flicker.

- Resolves an issue where a previously defined Sample Folder would remain listed in the Content Browser without displaying any content.

- Resolves an issue where Studio Piano instruments would incorrectly appear as uninstalled in the Sound Library.

- Resolves an issue where incorrect automation values were displayed in the Track Header.

- Resolves an issue where the default Region-Based Automation fader value was not updated in Editor views when other regions in the project contained automation.

- Resolves an issue where the Automation Value tile would not display the current value.

- Resolves an issue where the Region automation priority setting was not applied correctly, which could cause conflicting automation behavior.

- Restores the ability to insert the AU High Pass Filter plug-in.

Accessibility

- VoiceOver can now access the Cycle area by tapping directly on it in the Time Ruler.

- Resolves an issue where VoiceOver read the Square waveform as Pulse in the LFO tab.

- VoiceOver now correctly reads the Replace on Selection button label.

- VoiceOver can now interact with the Follow Rhythm of Track pop-up menu in the Session Player Patterns editor.

- VoiceOver can now change the type of Session Player in the Session Player Editor.

Control surfaces

- Live Loops controls can now be assigned using MIDI Learn.

- The Auto-Enable External Sync and Tap Tempo setting for MIDI Learn is now available in Logic Pro for iPad.

Drum Machine Designer

- Resolves an issue where the Drum Machine Designer Edit Pad menu would open unexpectedly when performing a quick scroll gesture on a pad.

Software instruments and effects

- Fixes a capitalization issue where "max. Wheels" is now correctly displayed.

- Resolves an issue where the Auto-Compensate button label in the External Instrument plug-in was truncated.

- Resolves an issue where the Boost Limit parameter label in the Match EQ plug-in window was truncated.

- Resolves an issue where the Plug-in Details view would not update when turning a track on or off.

General

- Smart Tempo project settings have been renamed for improved clarity.
