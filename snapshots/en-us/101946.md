# Fix inaccurate Flex Pitch analysis in Logic Pro for Mac

Learn what to do if Flex Pitch assigns audio files to note C0 instead of the correct notes in the Audio Track Editor.

In Logic Pro 10.7.5 or 10.7.6 on macOS Ventura, Logic Pro can incorrectly assign audio files analyzed with Flex Pitch to note C0. If this happens, update Logic Pro, then reanalyze the files.

## Update Logic Pro

First, [update your app to the latest version of Logic Pro for Mac](https://apps.apple.com/us/app/logic-pro/id634148309?mt=12) .

## Reanalyze the audio files

After you update Logic Pro, reanalyze any audio regions that were incorrectly assigned to note C0.

- With the project open in Logic Pro, double-click the affected audio region in the Tracks area to open it in the Audio Track Editor.

- If necessary, click the Track tab in the Audio File Editor to switch to the Audio Track Editor.

- To see the Flex Pitch Notes, click the Show/Hide Flex button in the Audio Track Editor (or press Command-F).

- Make sure to select Flex Pitch from the Flex Mode pop-up menu.

- Click Edit in the Audio Track Editor, then choose Analyze Audio for Flex Editing.

- Repeat these steps for any other audio regions that were incorrectly analyzed by Flex Pitch.
