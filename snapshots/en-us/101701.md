# If you can’t enter a value in the color palette in Final Cut Pro for iPad

When adjusting the color of elements like text in the Sliders tab of the color palette, use the sliders or a Magic Keyboard.

You can adjust colors for elements like text and text effects by tapping a color well in the inspector, then using the options in the color palette. If you're using the Sliders option to make numerical adjustments to color, you might not be able to enter the color values when you tap an existing value.

If you have a Magic Keyboard for your iPad, connect it to enter numerical values in these fields. Or use the sliders instead.
