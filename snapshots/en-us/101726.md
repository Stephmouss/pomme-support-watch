# Use REDCODE RAW media in Final Cut Pro on Mac computers with Apple silicon

To import REDCODE RAW (R3D) files into Final Cut Pro on a Mac computer with Apple silicon, install Rosetta.

To install Rosetta for Final Cut Pro, follow these steps:

- In Final Cut Pro, choose Help > Install Rosetta.

- Follow the prompts to install Rosetta.

Once you've installed Rosetta, you can [import R3D files into Final Cut Pro](https://support.apple.com/guide/final-cut-pro/import-redcode-raw-files-ver715436b78/mac) . For more information, [contact RED](http://www.red.com) .
