# What's new for enterprise in iPadOS 27

Learn about the enterprise content that Apple has released for iPadOS 27.

iPadOS updates improve the stability, performance, or compatibility of your device and are recommended for all users. Device administrators can manage software updates using a device management service.

For information about general improvements, learn about updates to iPadOS 27.

For details about the security content of these updates, see [Apple security releases](https://support.apple.com/100100) .

## iPadOS 27

iPadOS 27 includes new features such as AppleCare log collection, privacy consent for apps and websites, and enhancements to Return to Service.

#### Device management

- Device management can configure a consolidated consent prompt for users to grant an app or website the necessary default privacy permissions.

- On devices with iOS 27, iPadOS 27, macOS 27, and tvOS 27, log collection required as part of an AppleCare ticket can be started remotely on supervised devices using device management.

- New status items are available that provide proactive information about a device, including the enrollment type, lockdown mode status, and when it is waiting in Setup Assistant for the device management service.

- New network configurations are available in declarative device management including VPN, DNS, and relay.

- Device management can restrict the use of Siri AI, Visual Intelligence, and Natural Language Calendar Event Editing.

- Legacy MDM profiles can now be delivered as declarative assets.

- The new Liquid Glass setup pane can be skipped by device management.

- Legacy software update management no longer functions in all 27.0 operating systems. This includes: software update commands, software update queries, recommended cadence settings, and software update restrictions, like deferrals and Background Security Improvements. IT teams should use declarative software update management to configure and enforce updates on devices with increased user transparency and more control.

- Software updates can be enforced on a supervised device when it receives a Return to Service erase command.

#### Bug fixes and other improvements

- After applying and removing a Single App Mode payload, app will no longer disappear from the Home Screen and Dock.

- The AllowSignIn key in com.apple.configuration.external-intelligence.settings correctly prevents users from signing in to ChatGPT.

- Setting Enabled to false in the com.apple.configuration.external-intelligence.settings declaration correctly disables the ChatGPT extension.

- Disabling Siri via MDM no longer causes the Siri settings table cell to disappear, preventing users from modifying Apple Intelligence settings.

- The allowListedAppBundleIDs restriction will not prevent devices from accepting files via AirDrop.
