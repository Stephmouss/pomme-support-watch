# Move a Final Cut Pro library

Move a Final Cut Pro library to an external drive to save space or to edit your project on another Mac.

You can copy or move Final Cut Pro libraries and related assets from within Final Cut Pro. For more control over the process of moving libraries and related assets, move libraries manually.

## Use Final Cut Pro to move a library

You can use the Copy to Library command to copy or move Final Cut Pro libraries to an external drive, to another Mac, or to another location.

[Copy or move libraries from within Final Cut Pro](https://support.apple.com/guide/final-cut-pro/ver0be4a6320/mac)

## Move a library manually

### Before you move a library

If you want to open the library on another Mac for editing or collaboration:

- Consolidate media. Source media files linked to the [clips in your project](https://support.apple.com/guide/final-cut-pro/ver3b4e6d1/mac) and Motion content might not be located in the library you want to move. Consolidating media ensures that you’ll have all the content you need to work on your project on another Mac.

- Install third-party plug-ins and special fonts on the other Mac using the installers provided by the manufacturer. Moving your library to another Mac doesn’t move your third-party plug-ins and special fonts. [Make sure that each plug-in is compatible](https://support.apple.com/en-us/105044#software_compatibility) with the versions of macOS and Final Cut Pro on the other Mac.

### Prepare your external drive

You can store libraries on an external storage device such as a USB drive, FireWire drive, or Thunderbolt drive. [Format the drive as APFS](https://support.apple.com/guide/disk-utility/dskutl14079/mac)

You can’t store your library on an external drive that's being used for [Time Machine backups](https://support.apple.com/en-us/104984) .

### Remove generated files

Final Cut Pro creates generated files such as [render files](https://support.apple.com/guide/final-cut-pro/ver68a8c250/mac) , [optimized files, and proxy media files](https://support.apple.com/guide/final-cut-pro/verb8e5f6fd/mac) in the background while you’re working on a project. Before you move a Final Cut Pro library, you can delete generated files to save space.

- To see how much space generated files take up, select the library in the Libraries sidebar, then scroll to Cache in the Library Properties window.

- Choose File > Delete Generated Library Files.

- To save the most space, select all options, then click OK.

The next time you open and work on your project, Final Cut Pro regenerates render files. If you delete optimized and proxy media files, you'll have to regenerate them manually when you reopen the library.

### Move the library

After removing generated files, move the library.

- To locate the library file, select the library in the Libraries sidebar, then choose File > Reveal in Finder. A new Finder window opens with the library selected.

- Quit Final Cut Pro.

- In the Finder, drag the library file to your external storage device.

### Consolidate media

If you’re moving a library to work on a project on another Mac, you might want to consolidate source media files and Motion content in the library you’ve moved. Consolidate media after you've moved the library.

- To show the Libraries sidebar in Final Cut Pro, choose Window > Show In Workspace > Sidebar, or click the Libraries sidebar button .

[Image: No alt supplied for Image]

- In the Libraries sidebar, select the library that you want to consolidate your media in.

[Image: Final Cut Pro interface showing the Libraries sidebar.]

- In the Library Properties inspector, click Modify Settings.

[Image: Screenshot of Final Cut Pro's Library Properties window, highlighting Storage Locations and the Consolidate button.]

- For the content you want to save with the library, choose "In Library" from each pop-up menu, then click OK. If you created any custom Motion effects, transitions, titles, or generators, make sure to also [set the storage location for Motion Content](https://support.apple.com/guide/final-cut-pro/ver7db6ffe77/mac) to "In Library."

- In the Library Properties inspector, click Consolidate in the Media and Motion Content sections.

- To view the progress of the consolidation, choose Window > Background Tasks.

- When consolidation is finished, double-click the library file in the new location to open it in Final Cut Pro.*

- If you moved the library to save space on your Mac, check the library that you moved to make sure it contains all your media, then drag the original library file on your Mac to the Trash.

* If you see [a missing item alert icon](https://support.apple.com/guide/final-cut-pro/verd1f977a7/mac) , you might need to [relink clips](https://support.apple.com/guide/final-cut-pro/relink-clips-to-media-files-ver26f5c8c9/mac) .
