# If you hear pops or audio dropouts when using MainStage

If you hear pops or audio dropouts when using the headphone jack of your Mac with MainStage, reduce the number of cores MainStage uses, increase the I/O buffer size, or use an external audio interface.

## Reduce the number of cores

- Choose MainStage > Preferences > Audio.

- Click Advanced Settings in the Audio section.

- Drag the CPU Usage slider to the left to reduce the number of cores used by MainStage.

## Increase the I/O buffer size

- Choose MainStage > Preferences > Audio.

- Click Advanced Settings in the Audio section.

- Choose a larger size from the I/O Buffer Size pop-up menu. Increasing [the I/O buffer size increases latency](https://support.apple.com/kb/HT202982) .

## Use an external audio interface

Use an external audio interface for audio output from MainStage instead of the headphone jack. Consult the manufacturer’s documentation regarding installation of any required software for the interface, as well as for operational information.

To use an audio interface with Mainstage:

- Connect the external audio interface to your Mac.

- Open MainStage, then choose MainStage > Preferences > Audio.

- Choose the external audio interface from the Audio Output pop-up menu.

- Optionally, choose the external audio interface from the Audio Input pop-up menu.

- Click Apply Changes.
