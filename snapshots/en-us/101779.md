# Copy a custom Drum Machine Designer kit to another Mac

If you created a Drum Machine Designer kit in Logic Pro for Mac using your own samples, you can save the kit and use it in Logic Pro on another Mac.

A Drum Machine Designer kit is made up of the samples in the kit, plus a PATCH file that stores the kit's pad assignments and other settings. You can save these components, then copy them to another Mac for use with Logic Pro 10.5 or later. You can use an external drive, iCloud Drive, AirDrop, email, or third-party cloud services to transfer these components to the other Mac.

## Save your kit's settings as a PATCH file

- Open the Logic Pro project with the custom kit you want to save.

- To open the Drum Machine Designer window, click DMD in the Instrument slot of the channel strip.

- Select the kit name pad at the top of the Drum Machine Designer window, where the name of the track appears. This ensures that you save the complete kit as a patch.

- ﻿If you have just a kit pad selected, you will only save the associated kit piece as a patch.

- If necessary, click the Library button.

- Click Save at the bottom of the Library, then enter a name for your custom kit. To make sure your custom kit appears in the User Patches folder in the Library, save it to this location in your Home folder: ~/Music/Audio Music Apps/Patches/Instrument.

- Click Save in the Save dialog.

- Go to ~/Music/Audio Music Apps/Patches/Instrument/, then copy the PATCH file to the other Mac.

## Save your kit's samples

- Create a new empty project with a new Software Instrument track.

- Select the track, then choose your custom kit from the User Patches folder in the Library.

- Choose File > Save.

- In the Save dialog, select Folder to save your project as a folder, select “Sampler audio data,” enter a name and choose a location for the project, then click Save.

- In the Finder, open the folder you just created for your project. Locate the subfolder called Quick Sampler, which contains the samples used in your kit.

- Copy the Quick Sampler folder to the other Mac.

## Rename and move folders on the other Mac

- On the other Mac, locate the Quick Sampler folder and the PATCH file.

- Rename the Quick Sampler folder with the same name you gave to the PATCH file of your custom kit. For example, if your PATCH file is named MyDrumKit.patch, rename the Quick Sampler folder “MyDrumKit.”

- In the Finder, move the PATCH file and the renamed folder to this location in the Home folder: ~/Music/Audio Music Apps/Patches/Instrument/.

You can now load your custom DMD kit from the Library in any Logic Pro project.
