# Use MDM to enable Remote Management in macOS

Learn how to control a remote Mac that is managed with Mobile Device Management (MDM).

To control a remote Mac that is managed by Mobile Device Management (MDM), use the [Enable Remote Desktop command](https://support.apple.com/guide/deployment/mdm-command-list-dep789n2k1qp/web) . The Enable Remote Desktop command turns on [Remote Management](https://support.apple.com/guide/mac-help/mh11851/) for all users with the "Observe" and "Control" options enabled.
