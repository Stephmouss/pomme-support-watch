# About SynthID watermarks in images created or edited with Apple Intelligence

Images you create or edit with Apple Intelligence include a hidden SynthID watermark. This watermark can help identify that an image was created or modified using AI. Learn more about images with SynthID watermarks at [SynthID.com](http://synthid.com) .

## About the watermark

Starting with iOS 27.2, iPadOS 27.2, macOS 27.2, and visionOS 27.2, some Apple Intelligence tools will add an invisible SynthID watermark to images that you create or edit:

- Clean Up, Extend, and Spatial Reframing in Photos

- Image Playground and Image Wand

Images you create or edit before updating to iOS 27.2, iPadOS 27.2, or macOS 27.2 won't have a SynthID watermark until you edit them with one of the tools listed.

## Check an image for a SynthID watermark

The watermark is imperceptible to people, and doesn't change how the image looks, but can be read by a SynthID detector. To check for a watermark, go to [synthid.com](https://synthid.com) in a web browser and upload an image. Follow the on-screen steps to see the result.
