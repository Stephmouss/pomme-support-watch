# macOS 27 Golden Gate is compatible with these computers

macOS 27 Golden Gate is the latest major version of the Mac operating system. You can install it on any of these Mac models.

If you have a Mac with Apple silicon, you can [upgrade to macOS 27](https://support.apple.com/en-us/127455) . If your Mac isn't compatible, you might be able to [install an earlier version of macOS](https://support.apple.com/en-us/102662) instead.
