# How to download iOS 26

Check if your iPhone supports iOS 26, then download and install the update automatically or manually.

[Image: iOS 26 icon, featuring the number 26.]

Before you update, [back up your device](https://support.apple.com/en-us/118426) to keep a copy of your important information.

## Turn on automatic updates

You can set up your iPhone to install updates automatically:

- Open Settings.

- Tap General.

- Tap Software Update.

- Tap Automatic Updates.

- Choose Automatically Install or Automatically Download.

- Automatically Install: iPhone downloads and installs the update overnight while charging and connected to Wi-Fi. You’re notified before iPhone installs an update.

- Automatically Download: Downloads updates automatically when your iPhone is connected to Wi-Fi, charging, and locked. To see this option, first turn off Automatically Install.

## Update iPhone manually

At any time, you can check for and install software updates:

- Open Settings.

- Tap General.

- Tap Software Update.

- If an update is available, tap Download and Install.

- Follow the onscreen instructions.

## Install the software update

If an update is already downloaded but not installed:

- Open Settings.

- Tap Update to iOS 26.

- Tap Update Now or Update Tonight.

- Follow the onscreen instructions.

## View more details
