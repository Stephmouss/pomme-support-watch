# If you can't download or install iCloud for Windows

If you can't download, install, or update iCloud for Windows on your PC, make sure that you meet the system requirements and have a Microsoft account and an Apple Account. Then check for additional media or server-related messages.

## If iCloud for Windows doesn't download or install from the Microsoft Store

To install iCloud for Windows 11 or later, make sure that you:

- Update your version of Windows to the May 2019 Update or later. Learn more about the [minimum system requirements](https://support.apple.com/en-us/118308) for iCloud for Windows.

- Set up a Microsoft account. You can [create one on the Microsoft website](https://signup.live.com/signup) .

- Know your Apple Account and Apple Account password. Learn what to do if you [forgot your Apple Account password](https://support.apple.com/en-us/102656) or need to [find your Apple Account email address](https://support.apple.com/en-us/102677) .

For general upgrade and installation fixes, visit the [Microsoft support site](https://support.microsoft.com/windows/ea144c24-513d-a60e-40df-31ff78b3158a) .

## If you see a message that your computer is missing Media features

Windows Media Player plays the video and audio files on your PC. You need Media Player to install iCloud for Windows. If you try to download iCloud for Windows 11 or later and get a message that says you need to Install Media Feature Pack to use iCloud, select Download. Then follow the instructions on the next screen.

If you turned off Windows Media Features, or if your PC didn't come with Windows Media Player, iCloud for Windows won't install.

[Image: iCloud for Windows dialog box: "Install Media Feature Pack to use iCloud. Select Download."]

### Turn on Windows Media Player

- Go to Control Panel.

- Click All Control Panel Items, then click Programs and Features.

- Click "Turn Windows features on or off."

- Check the box for Media Features to turn it back on.

- Click OK.

If you see a message to restart your PC, restart your computer and then install iCloud for Windows.

### If your PC didn't come with Windows Media Player

If you're in Europe or South Korea and your PC didn't come with Windows Media Player, you can [download the Media Feature Pack](https://www.microsoft.com/download/details.aspx?id=49919) from the Microsoft website.

## If iCloud for Windows 13 relaunches when you click iCloud Passwords

If you pinned the [iCloud Passwords](https://support.apple.com/guide/icloud-windows/icwa812f1681/) shortcut to your taskbar in earlier versions of iCloud for Windows and then upgraded to iCloud for Windows 13, unpin the iCloud Passwords shortcut, then create a new shortcut from the Start menu.

## If you see a “can’t connect to server” message

- Check your internet connection.

- Check the [System Status page](https://www.apple.com/support/systemstatus/) to find out if there are any known issues.

- If there's an outage or maintenance, try again later.
