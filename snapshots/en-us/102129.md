# About the security content of Apple Music 3.9.10 for Android

This document describes the security content of Apple Music 3.9.10 for Android.

## About Apple security updates

For our customers' protection, Apple doesn't disclose, discuss, or confirm security issues until an investigation has occurred and patches or releases are available. Recent releases are listed on the [Apple security updates](https://support.apple.com/kb/HT201222) page.

For more information about security, see the [Apple Product Security](https://support.apple.com/kb/HT201220) page. You can encrypt communications with Apple using the [Apple Product Security PGP Key](https://support.apple.com/kb/HT201601) .

Apple security documents reference vulnerabilities by [CVE-ID](https://cve.mitre.org/about/) when possible.

## Apple Music 3.9.10 for Android

Released June 14, 2022

### Apple Music on Android

Available for: Android version 5.0 and later

Impact: An app may be able to access user-sensitive data

Description: This issue was addressed with improved state management.

CVE-2022-32836: hluwa

### Apple Music on Android

Available for: Android version 5.0 and later

Impact: A user in a privileged network position may intercept SSL/TLS connections

Description: This issue was addressed with using HTTPS when sending information over the network.

CVE-2022-32906: David Coomber of Info-Sec.CA

### Apple Music on Android

Available for: Android version 5.0 and later

Impact: An app may be able to access user-sensitive data

Description: A logic issue was addressed with improved state management.
