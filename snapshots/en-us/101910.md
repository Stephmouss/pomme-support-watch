# How many displays can be connected to Mac Studio

The number of external displays that you can use at the same time depends on your Mac model and the resolution and refresh rate of each display.

[Identify your Mac Studio model](https://support.apple.com/en-us/102231) , then learn how many displays can be connected to that model, and at which resolutions and refresh rates:

- [Mac Studio with M5 Max chip](https://support.apple.com/en-us/148405)

- [Mac Studio with M5 Ultra chip](https://support.apple.com/en-us/148406)

- [Mac Studio (2025) with M4 Max](https://support.apple.com/en-us/148504)

- [Mac Studio (2025) with M3 Ultra](https://support.apple.com/en-us/148505)

- [Mac Studio (2023) with M2 Max](https://support.apple.com/en-us/148506)

- [Mac Studio (2023) with M2 Ultra](https://support.apple.com/en-us/121267)

- [Mac Studio (2022)](https://support.apple.com/en-us/148507)

- Earlier models: [Check the technical specifications](https://support.apple.com/docs) for that model for a display support overview.
