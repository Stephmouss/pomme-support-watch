# Create or open ZIP files on your iPhone, iPad, or Apple Vision Pro

If you need to email a large file or create an archive, a ZIP file can help save space. Here's how to create or open a ZIP file.

## Create a ZIP file on your iPhone

- Open the Files app, then choose a location like On My iPhone or iCloud Drive.

- Tap the More button , then tap Select.

[Image: On an iPhone with iOS 27, after you tap the More button, Select is listed at the top of the menu.]

- Choose one or more files.

- Tap the More button in the lower right, then tap Compress.

[Image: In iOS 27, after you tap the More button, Compress is listed in the menu that appears.]

If you selected one file, a ZIP file with the same file name saves to that folder. If you selected multiple files, a ZIP archive named Archive.zip saves to that folder. To change its name, touch and hold on the ZIP archive, then select Rename.

## Open a ZIP file on your iPhone

- Open the Files app, then find the ZIP file or archive you want to uncompress.

- Tap the ZIP file or archive. A folder is created containing the files. To change the folder name, touch and hold on the folder, then tap Rename.

- Tap to open the folder.

## Create a ZIP file on your iPad or Apple Vision Pro

- Open the Files app, then choose a location like On My [device] or iCloud Drive.

- Tap Select, then choose one or more files.

- Tap the More button , then tap Compress. If you selected one file, a ZIP file with the same file name saves to that folder. If you selected multiple files, a ZIP archive named Archive.zip saves to that folder. To change its name, touch and hold on the ZIP archive, then select Rename.

[Image: In iPadOS 27, after you tap the More button, Compress is listed in the menu that appears.]

## Open a ZIP file on your iPad or Apple Vision Pro

- Open the Files app, then find the ZIP file or archive you want to uncompress.

- Tap the ZIP file or archive. A folder is created containing the files. To change the folder name, touch and hold on the folder, then tap Rename.

- Tap to open the folder.
