# Learn keyboard shortcuts for Maps on the web

Use keyboard shortcuts to do things that normally require a mouse or trackpad, such as rotating a map or showing and hiding tools.

## Use common Maps keyboard shortcuts

Keyboard shortcuts use one or more of these modifier keys, which in menus are abbreviated using symbols:

- Control (or Ctrl) ⌃

- Option (or Alt) ⌥

- Shift ⇧

- Up Arrow ▲

- Down Arrow ▼

- Left Arrow ◀

- Right Arrow ▶

On keyboards made for Windows PCs, press the Alt key instead of Option.

Depending on the device you use, [Maps on the web works best on the latest versions of these browsers](https://support.apple.com/120585) . Use the following shortcuts to:

### Show or hide tools

- Show or hide Sidebar: Shift-S

- Show or hide Guides: Shift-G

- Show or hide Directions: Shift-R

- Show or hide Look-around: Shift-K

- Show or hide Search: Shift-F

### Change your view

- Change to Standard Map: Option-1

- Change to Hybrid Map: Option-2

- Change to Satellite Map: Option-3

### Move and manage your map

- Zoom in: Plus sign (+)

- Zoom out: Minus sign (-)

- Rotate back to north : Shift-Option-Up Arrow

- Enable user-location or go to user-location : Control-Option-L

- Drop a pin in the center of the map: Option-P

- Rotate the map: Option-Left Arrow, Option-Right Arrow

- Pan the map: Arrow keys
