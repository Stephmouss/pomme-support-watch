# Use your Apple keyboard in Windows with Boot Camp

If you've used Boot Camp to install Microsoft Windows on your Mac, the keyboard you use for macOS can also be used for Windows.

## Mac equivalents of Windows keys

Windows logo : Press Command (⌘).

[Image: boot-camp-mac-keyboard-mapping-command-windows]

Backspace or Delete : Press Delete.

[Image: boot-camp-mac-keyboard-mapping-delete-backspace]

Enter or ⏎: Press Return.

[Image: boot-camp-mac-keyboard-mapping-return-enter]

Alt (left) : Press Option (⌥).

[Image: boot-camp-mac-keyboard-mapping-option-alt]

Alt GR (right) : Press Option + Control.

[Image: boot-camp-mac-keyboard-mapping-option-control-alt-gr-right-alt]

Applications : This key isn't available on Apple keyboards.

[Image: boot-camp-mac-keyboard-mapping-applications-menu]

## Use the On-Screen Keyboard for other functions

If your Apple keyboard doesn't include the following keys, you can recreate them in Windows using the [On-Screen Keyboard](https://support.microsoft.com/en-us/help/10762/windows-use-on-screen-keyboard) .

- Pause/Break

- Insert

- Forward Delete

- Home

- End

- Page Up

- Page Down

- Number Lock

- Scroll Lock

## Use the Snipping Tool to print screen

To recreate the Print Screen and Print Active Window function in Windows, [use the Snipping Tool](https://support.microsoft.com/en-us/help/13776/windows-use-snipping-tool-to-capture-screenshots) .

## If your keyboard isn't working as expected in Windows

If your Apple keyboard works as expected in macOS but not in Windows, try these solutions:

- [Install the latest Apple software updates for Windows](https://support.apple.com/kb/HT208038) .

- [Install the latest Windows support software](https://support.apple.com/kb/HT204923) .

- If you're using Microsoft Windows 10 N, [install the latest Media Feature Pack](https://www.microsoft.com/en-us/software-download/mediafeaturepack) .
