# How to download the Beats app when you can’t use Google Play

If you don't have access to the Google Play Store, you can download the Beats app directly.

Follow these steps on your Android device: 1

- [Download the Beats app for Android installer](https://tempo.api.beatsbydre.com/v3/mobile_apps/android/download) .

- Use your device's file browser 2 to find the installer for the Beats app for Android with filename ending in .apk. On many devices, you can find this .apk file in a downloads folder.

- Tap the file to install it.

- If an alert says to change your security settings to install from unknown sources, follow the onscreen steps. After you change your settings, you might need to tap a Back button to return to the file browser. Then you can install the .apk file.

Now you can [use the Beats app for Android](https://support.apple.com/kb/HT210322) .

- In China mainland, you can also download the Beats app for Android from [Huawei AppGallery](https://appgallery.huawei.com/app/C107398457) or [Tencent App Store](https://sj.qq.com/appdetail/com.apple.bnd) .

- If you don't have a file-system explorer, search for one in an app store for Android apps.
