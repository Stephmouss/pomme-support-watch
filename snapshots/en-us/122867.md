# macOS Tahoe 26 is compatible with these computers

You can install macOS Tahoe 26 on any of these Mac models.

[Learn how to upgrade to macOS Tahoe 26](https://support.apple.com/en-us/122727) , the latest version of the Mac operating system. If your Mac isn't compatible with macOS Tahoe, you might be able to [upgrade to an earlier version of macOS](https://support.apple.com/en-us/102662) instead.
