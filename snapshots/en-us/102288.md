# Use Tags and Smart Folders in Notes on your iPhone and iPad

Use tags to quickly categorize your notes so you can easily find them later. Just add one or more tags—like #work or #shopping—anywhere in a note. You can also use Smart Folders for even more organization and search options.

## Before you begin

[Update your iPhone or iPad](https://support.apple.com/en-us/118575) to the latest iOS or iPadOS.

## Add a tag to a note

In iOS 15, iPadOS 15, and later, you can add a tag anywhere in a note, including the title:

- Open a note in the Notes app.

- Type # followed by a tag name.

- Add a space or tap enter. The text will change color to show the tag has been added.

Tag names need to be one continuous word, but you can use hyphens, numbers, and underscores to make tag names longer—for example, #gardening-supplies. You can also add tags in your drawings with Apple Pencil on iPad: just sketch # and the tag name within a note.

To add a tag to multiple notes:

- Go to a folder with the list of notes.

- Tap the More button , then tap Select Notes.

- Select the notes, then tap Tags at the bottom of the screen.

[Image: iPhone, screen shows Notes app with four notes selected.]

- Select the tags you want to add to the notes, then tap the Checkmark button .

- If you create a tag on a device running iOS 15, iPadOS 15, or later, the tag appears on your other Apple devices running iOS 14, iPadOS 14, macOS Big Sur, or later. If your other devices use older software, the tag may appear as plain text.

- You can't lock a note that has a tag, and you can't add a tag to a locked note.

### If you are unable to create tags in Notes

- Open Settings.

- Tap Apps.

- Tap Notes.

- Check if Auto Convert to Tag is enabled.

## View and share your notes with tags

When you create a tag, you can find it in the note itself and in the Tags browser.

- Open Notes.

- Scroll to the Tags browser below your list of Folders.

- Tap All Tags to see a list of every note with tags, or tap a specific tag to see a list of all notes with that tag.

You can also tap two or more tags and filter to show notes containing all of the selected tags (for example, both #Gardening and #Grocery) or any of the selected tags (for example, either #Gardening or #Grocery).

[Image: iPhone, screen shows two notes with the Gardening tag.]

If you share a tagged note with someone who's using iOS 14, iPadOS 14, macOS Big Sur, or later, they should see the tagged word and have it appear in their Tags browser. If you share a tagged note with someone who’s using an older software version, the note will be shared but the tag may appear as plain text.

## Rename or delete tags from your notes

With iOS 15, iPadOS 15, or later, you can rename your tags or delete them when you’re done using them.

- Open Notes.

- Go to the Tags browser at the bottom of the Folders list view.

- Touch and hold the tag you want to edit.

- In the pop-up menu, tap Rename Tag or Delete Tag.

[Image: iPhone, screen shows the Shopping tag selected with the options to rename or delete it.]

- Type a new name and tap Rename to confirm, or tap Delete to confirm.

The Tags browser only shows tags that are used in your notes. If a tag is no longer used in any of your notes, it's removed from the Tags browser.

## Create a Smart Folder

Smart Folders are a great way to further organize notes without moving them from their original folders. In Smart Folders, you enable filters that determine which notes appear, so you can easily access certain ones and categorize them in different ways.

To create a Smart Folder:

- Open Notes.

- Tap the New Folder button .

- Enter a name for your folder, then tap Make Into Smart Folder.

- Choose the filters you want to use to automatically select notes for your Smart Folder, then tap the Checkmark button . You can choose filters based on tags, when a note was created, when a note was last edited, and more.

- Tap the Checkmark button again to create your Smart Folder.

[Image: iPhone, screen shows notes with two tags being filtered for.]

You can also create a Smart Folder from the Tags browser. Just tap the tag, then tap the More button , tap Create Smart Folder, add a name, and tap the Checkmark button .

### Convert an existing folder to a Smart Folder

- Open Notes.

- View the folder you want to convert and tap the More button .

- Scroll down and tap Convert to Smart Folder.

When you convert a folder, its notes are moved to the Notes folder and tagged with the name of the Smart Folder. You can’t convert shared folders, a folder with a subfolder, or a folder that contains locked notes.

When you convert a folder to a Smart Folder, it can't be undone. If you no longer want the Smart Folder, you need to delete it.

### Edit a Smart Folder

- Open Notes.

- Touch and hold a Smart Folder.

- Tap Edit Smart Folder.

[Image: iPhone, screen shows a Smart Folder being edited.]

- Change the name or tap Manage Smart Folder to change the current filters.

- Tap the Checkmark button .
