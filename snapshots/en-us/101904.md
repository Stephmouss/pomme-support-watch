# Prepare to update macOS Server in macOS Monterey

To use macOS Server in macOS Monterey, a newer version of macOS Server is required.

macOS Server 5.11.1 and earlier is not compatible with macOS Monterey. To use macOS Server with macOS Monterey, update to macOS Server 5.12.
