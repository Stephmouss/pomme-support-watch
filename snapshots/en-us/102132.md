# Download the Beats app if your country, region, or device doesn't have Google Play

Learn how to download the Beats app on Android if you can't access Google Play. You might need to adjust your security settings to complete the installation.

## Download the app

- If you're able to access Google Play, [download the Beats app from Google Play](https://play.google.com/store/apps/details?id=com.apple.bnd) .

- If you can't access Google Play, [download the app from Beats](https://tempo.api.beatsbydre.com/v3/mobile_apps/android/download) .

## Install the app

- Swipe down from the top of your phone's Home screen to open the notification drawer.

- Tap Download file to begin the installation.

- If you see a message that says, "Your phone is not allowed to install unknown app", tap Settings.

- A confirmation screen appears. Select "Allow from the source". You’ll need to complete this process the next time you update the app.

- If you see a message that asks, "Do you want to install this application?" tap Install. The Beats app installs on your device.

- Open the Beats app.
