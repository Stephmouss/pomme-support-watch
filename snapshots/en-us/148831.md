# What’s new for enterprise in visionOS 27

Learn about the enterprise content that Apple has released for visionOS 27.

visionOS updates improve the stability, performance, or compatibility of your device and are recommended for all users. Device administrators can [manage software updates](https://support.apple.com/guide/deployment/install-and-enforce-software-updates-depd30715cbb) using a device management service.

For information about general improvements, [learn about updates to visionOS 27](https://support.apple.com/en-us/149067) .

For details about the security content of these updates, see [Apple security releases](https://support.apple.com/100100) .

## visionOS 27

visionOS 27 includes new features, bug fixes, and improvements for enterprise and education deployments.

- New network configurations are available in declarative device management including VPN, DNS, and relay.

- Software updates can be enforced on a supervised device when it receives a Return to Service erase command.

- New status items are available that provide proactive information about a device, including the enrollment type and when it is waiting in Setup Assistant for the device management service.

- Device management can restrict the use of Siri AI and Natural Language Calendar Event Editing.

- Device management information and managed app content is no longer restored from backup. This includes the enrollment profile, management configuration, and supervision status. Devices registered in Apple School Manager or Apple Business automatically enroll through Automated Device Enrollment after the device restores, ensuring they receive current management state rather than a stale configuration from the backup.

- visionOS now supports the allowBluetoothModification and allowChat restrictions.

- Legacy MDM profiles can now be delivered as declarative assets.

- Resolved an issue where Apple Vision Pro was not erased after the number of failed passcode attempts specified by maxFailedAttempts in a device management passcode policy.
