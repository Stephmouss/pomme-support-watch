# Back up Logic Pro for Mac

Before you update Logic Pro, you should back up the currently installed version of the Logic Pro app and your existing projects.

## Back up the Logic Pro app

- Create a new folder in the Applications folder. Name the folder with the name and version of the application (for example, "Logic Pro 11.1.2"). To check the version of Logic Pro you have, open the application and choose About Logic Pro from the Logic Pro menu.

- Select the Logic Pro application in the Applications folder. Choose File > Compress "Logic Pro." It will take a few minutes to compress.

- Move the resulting "Logic Pro.zip" file into the folder you created in step 1.

- If you need to save space on your startup disk, move the folder containing the ZIP file to an external storage device, then delete the folder in your Applications folder.

### Reinstall a backed-up version of the Logic Pro app

If updating your app causes issues, reinstall the backed-up version of the app so you can continue working on your projects.

- Drag the currently installed version of the Logic Pro app from the Applications folder to the Trash, then empty the Trash.

- Locate the backup copy of Logic Pro, then double-click the ZIP file to uncompress it.

- If you uncompressed the ZIP file anywhere other than the Applications folder, drag the unzipped Logic Pro app file to the Applications folder.

## Back up Logic Pro Projects

When you back up your Logic Pro projects, you can work on your projects on another Mac. You should also periodically back up your Logic Pro projects as a safety measure.

- [Consolidate the assets of each project](https://support.apple.com/guide/logicpro/consolidate-assets-in-a-project-lgcpce09b9d8/mac) so all the audio files and related content in the project are located in the same place.

- Back up your Logic Pro projects:

- Use a system-wide backup solution like [Time Machine](https://support.apple.com/en-us/HT201250) .

- [Copy your projects to an external storage device](https://support.apple.com/guide/mac-help/mchl027f1d66/mac) .
