# How to write User Tips

Share your valuable knowledge about Apple products with the Apple Support Community by creating User Tips.

User Tips are informative tips and tricks created and maintained by community members to help others with their Apple products and services. When you get to Level 5 in [the Apple Support Community](https://discussions.apple.com/welcome) , you can write new User Tips. If you’ve repeated the same bit of information in various replies to other members’ questions, it might be good content for a User Tip. Everyone in the community can give feedback about whether or not a User Tip is helpful by voting. Helpful upvotes give points to the author.

## Create a User Tip

To create a User Tip, select Create Tip, then select the topic where you want to create the new User Tip.

### User Tip features

- The user information of the author appears at the top of each User Tip.

- Comments at the bottom of each User Tip let community members, Level 5 and above, give feedback to the author. Comments can be viewed by other users.

- You'll receive points every time someone upvotes your User Tip as helpful.

### Guidelines for User Tips

- Be considerate. User Tips are maintained for the benefit of the community.

- Be helpful. If you've reached Level 5 or above, leave comments to provide feedback to the tip author.

- Be thoughtful. User Tips follow the same Apple Support Community Terms of Use and are moderated accordingly.

- Be cool. Anyone who abuses this privilege will lose their access to create and edit User Tips.

### Write great User Tips

- Limit the title to 45 characters or less so that it’s easy to read in search results.

- Place key words at the beginning of the User Tip title.

- Use headings and ordered lists to organize information.
