# Change the default web browser or email app on Mac

The default web browser on your Mac is Safari, so it’s the app that opens when you click a web link. The default email app is Mail, so it’s the app that opens when you click an email link. If you want to use a different web browser or email app for these actions, follow these steps to change the default.

## Change the default web browser

[Find out which version of macOS you're using](https://support.apple.com/en-us/109033) , then follow the appropriate steps.

### In macOS Ventura 13 or later

- Install the other web browser that you want to use as your new default web browser.

- From the Apple menu  in the corner of your screen, choose System Settings.

- Click Desktop & Dock in the sidebar.

- Scroll down on the right and choose a web browser from the "Default web browser" menu.

### In earlier versions of macOS

- Install the other web browser that you want to use as your new default web browser.

- From the Apple menu  in the corner of your screen, choose System Preferences.

- Click General.

- Choose a web browser from the "Default web browser" menu.

## Change the default email app

- Install the other email app that you want to use as your new default email app.

- Open the Mail app and make sure that it's [set up to use an email account](https://support.apple.com/guide/mail/mail35803/mac) .

- You can remove or disable the account in Mail settings after you complete the remaining steps.

- If you don't want to temporarily add an email account, check the settings of your other email app: it might offer a way to set itself as the default email app.

- From the Mail menu in the menu bar, choose Settings (or Preferences).

- Click General, then choose an email app from the "Default email reader" pop-up menu. If you don't see your email app in the menu, choose Select from the menu, then select your email app from the file dialog that opens.

If you're using webmail (email in a web browser) instead of an email app, you can choose a web browser from the "Default email reader" menu in Mail, but the browser might not open webmail automatically when you click email links. Some third-party browsers and webmail services might have their own settings to change this behavior.
