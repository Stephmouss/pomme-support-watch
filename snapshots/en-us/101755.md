# GarageBand for iOS: Issues with songs created with newer version of app

Learn what to do if you have issues with songs created with a newer version of GarageBand for iOS.

If a song was created in a newer version of GarageBand for iOS than the version you are using, some features may not behave as you expect them to. For example, Autoplay in Smart Instruments may not loop properly if the song was created with a time signature not supported by the version of GarageBand for iOS you are using.

For the best results, use the same or a newer version of GarageBand for iOS for playing songs.
