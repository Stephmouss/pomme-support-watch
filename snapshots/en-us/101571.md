# How many displays can be connected to MacBook Pro

The number of external displays that you can use at the same time depends on your Mac model and the resolution and refresh rate of each display.

[Identify your MacBook Pro model](https://support.apple.com/en-us/108052) , then learn how many displays can be connected to that model, and at which resolutions and refresh rates:

- [MacBook Pro with PROLED XDR Display and M5 Max chip](https://support.apple.com/en-us/149453)

- [MacBook Pro with PROLED XDR Display and M5 Pro chip](https://support.apple.com/en-us/149454)

- [MacBook Pro with M6 chip](https://support.apple.com/en-us/149456)

- [MacBook Pro with M5 Max chip](https://support.apple.com/en-us/149458)

- [MacBook Pro with M5 Pro chip](https://support.apple.com/en-us/149461)

- [MacBook Pro with M5 chip](https://support.apple.com/en-us/149463)

- [MacBook Pro with M4 Max chip](https://support.apple.com/en-us/149473)

- [MacBook Pro with M4 chip and M4 Pro chip](https://support.apple.com/en-us/149474)

- [MacBook Pro with M2 Max or M3 Max chip](https://support.apple.com/en-us/149475)

- [MacBook Pro with M2 Pro or M3 Pro chip](https://support.apple.com/en-us/149476)

- [MacBook Pro with M3 chip](https://support.apple.com/en-us/149477)

- Earlier models: [Check the technical specifications](https://support.apple.com/docs) for that model for a display support overview.
