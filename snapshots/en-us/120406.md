# If you can't find ChromaGlow, Stem Splitter, or other Logic Pro features on Mac

Some Logic Pro features aren’t available on an Intel-based Mac or when running Logic Pro in Rosetta on a Mac with Apple silicon.

## Feature availability

These Logic Pro features aren’t available on an Intel-based Mac or when running Logic Pro in Rosetta on a Mac with Apple silicon:

- Stem Splitter

- ChromaGlow

- Valve, Transparent, and Punch Character presets in Mastering Assistant

If you are running Logic Pro in Rosetta, confirm that you have to use Rosetta. In most cases you don't have to.

## Confirm that you have to use Rosetta

The only reason to use Logic Pro in Rosetta on a Mac with Apple silicon is if you’re using a third-party plug-in like Melodyne by Celemony in ARA mode in a project. If you’re not sure if a favorite third-party plug-in needs to be used in ARA-mode, check with the manufacturer.

If you aren’t using these kinds plug-ins on a project, you can open Logic Pro natively, which will give you full access to Logic Pro features:

- Quit Logic Pro.

- Control-click the Logic Pro app in the Applications folder, then choose Get Info.

- Deselect “Open using Rosetta.”

- Open Logic Pro.
