# If your Mac starts up to error -1008F

Your Mac tried unsuccessfully to start up from macOS Recovery over the internet.

[Image: macos-catalina-recovery-alert-1008f]

A globe with an exclamation point means that your Mac tried to start up from macOS Recovery over the internet, but couldn't. If this is shown with error -1008F, one of these solutions should help.

- [Start up from macOS Recovery](https://support.apple.com/en-us/102518) , but use Option-Command-R at startup instead of Command-R or Shift-Option-Command-R.

- Or [disable Activation Lock](https://support.apple.com/en-us/102541) . When you're done using macOS Recovery, you can enable Activation Lock again.
