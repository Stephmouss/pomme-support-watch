# What’s new for enterprise in visionOS 2

Learn about the enterprise content that Apple has released for visionOS 2.

visionOS 2 updates improve the stability, performance, or compatibility of your device and are recommended for all users.

For information about general improvements, [learn about visionOS 2 updates](https://support.apple.com/121164) .

For details about the security content of these updates, see [Apple security releases](https://support.apple.com/100100) .

## visionOS 2.4

- MDM can use declarative device management to manage apps installed as Required on visionOS.

- MDM can define passwords, identities, and certificates for managed apps and extensions that adopt the ManagedApp framework.

- MDM can be configured to both authenticate using EnrollmentSSO and install a required app that is different from the enrollmentSSO during account-driven enrollment.

- MDM can manage Apple Intelligence features using the same restrictions as iOS, iPadOS, and macOS.

- When using TLS_ECDHE_RSA or TLS_DHE_RSA cipher suites, TLS certificates containing a Key Usage extension must have Digital Signature key usage set.

- When using the TLS_RSA cipher suite, TLS certificates containing a Key Usage extension must have Key Encipherment key usage set.

## visionOS 2.2

Service discovery as part of account-driven enrollment can request the well-known resource from an alternative location specified by the MDM solution linked to Apple School Manager or Apple Business Manager.

## visionOS 2

visionOS 2 includes new features, bug fixes, and improvements for enterprise and education deployments.

- visionOS now supports [Automated Device Enrollment](https://support.apple.com/102300) in a mobile device management (MDM) solution using Apple Business Manager and Apple School Manager.

- MDM can configure more settings such as device lock, Activation Lock, and passcode management.

- New APIs grant enhanced sensor access and increased platform control that allows you to create more powerful enterprise solutions and spatial experiences with Apple Vision Pro. [Enterprise APIs](https://developer.apple.com/documentation/visionOS/building-spatial-experiences-for-business-apps-with-enterprise-apis) are eligible for business use only, and apps developed with them can only be privately distributed as proprietary in-house apps or [Custom Apps](https://support.apple.com/guide/deployment/distribute-custom-apps-dep0113f6e18/web) using Apple Business Manager.
