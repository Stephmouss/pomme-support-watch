# Compressor 4.1: Troubleshooting Distributed Processing

If Compressor 4.1 isn't working as expected when using Distributed Processing, try these steps to isolate and resolve the issue.

Important : Back up your Compressor custom settings.

Prior to performing the steps in this article, make sure that you have a current backup of your Compressor custom settings. Your backups are located in ~/Library/Application Support/Compressor, and your custom settings are located in the Settings folder.

- Reset Compressor's Distributed Processing Note : If you're transcoding using a group of shared computers, follow these steps on all computers in the group.

- In Compressor, choose Compressor > Preferences (or press Command-Comma) and select My Computer.

- Deselect “Allow other computers to process batches on my computer.”

- Quit Compressor by choosing Compressor > Quit Compressor (or press Command-Q).

- In the Finder, hold down the Option key and choose Library from the Go menu.

- In the Library folder that opens, open the Application Support folder. Move the Compressor folder to the Trash.

- If you've used Compressor 3.5.x or 4.0.x on your computer, you may have an Apple Qmaster folder on your system that you can remove. See the steps below to remove this folder, or continue to step 7.

- Restart your computer.

Compressor 4.0.x - remove the existing Apple Qmaster folder

- If Compressor 4.1 is running, quit Compressor by choosing Compressor > Quit Compressor.

- In the Finder, hold down the Option key and choose Library from the Go menu.

- In the Library folder that opens, open the Application Support folder. Move the Apple Qmaster folder to the Trash.

- Restart your computer.

Compressor 3.5.x - remove the existing Apple Qmaster folder

- If Compressor is running, quit Compressor by choosing Compressor > Quit Compressor.

- In the Finder, open your startup disk and navigate to /Library/Application Support/Apple Qmaster/.

- Move the Apple Qmaster folder to the Trash.

- Restart your computer.

2. Resolve the "...cannot be processed on more than one computer because file copy is not supported" alert

You may see this alert if NFS cannot export the location of the source file. This could be due to the drive that your source file is located on having certain permissions, such as being set up as a network volume or formatted as ExFAT.

If you receive this alert when submitting a batch using a group of shared computers, follow these steps:

- In Compressor, choose Compressor > Preferences (or press Command-Comma) and then select Shared Computers.

- From the list of shared computers (on the left), select the group you're submitting a batch to and deselect "Enable automatic file sharing."

- Then, manually mount the volume that the source file is located on for each computer in the group.
