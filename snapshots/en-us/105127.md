# If you can’t dictate text, type accented characters, or select emoji in the Touch Bar of your Mac

These features might not work if you've installed the third-party product Webroot SecureAnywhere.

Webroot SecureAnywhere is made by Webroot Inc. When this software is installed on your Mac using its default settings, you might notice these symptoms:

- Text that you dictate doesn't appear as expected.

- You don't see any accented characters when you hold down a letter key.

- You can't select items such as emoji in the Touch Bar of your MacBook Pro.

Follow these steps to fix the issue:

- Click the Webroot SecureAnywhere icon in the menu bar.

- Choose Pause Secure Keyboard Entry.

A [Webroot support article](https://answers.webroot.com/Webroot/ukp.aspx?vw=1&solutionid=1369) provides more information about this solution.

[Contact the vendor](https://support.apple.com/103190) for additional information.
