# Final Cut Pro, Motion 5, Compressor 4: Run Software Update after installation to install Pro Video Formats

After installing Final Cut Pro, Motion 5, or Compressor 4, be sure to run Software Update to download and install Pro Video Formats.

This update is recommended for all users of Final Cut Pro, Motion 5, or Compressor 4.

From the Apple () menu, choose Software Update. For more information, see [OS X: Updating OS X and Mac App Store apps](http://support.apple.com/kb/HT1338) .
