# What's new for enterprise in iPadOS 18

Learn about the enterprise content that Apple has released for iPadOS 18.

iPadOS 18 updates improve the stability, performance, or compatibility of your device and are recommended for all users. Device administrators can [manage software updates](https://support.apple.com/guide/deployment/depafd2fad80) using a device management service.

For information about general improvements, [learn about iPadOS 18 updates](https://support.apple.com/121162) .

For details about the security content of these updates, see [Apple security releases](https://support.apple.com/100100) .

## iPadOS 18.6

- Temporary sessions defined by a device management service on Shared iPad will now log out when the timer expires.

- Managed apps are now able to browse managed locations in the Files picker.

- The certificate picker no longer fails to display for Single Sign-On web applications.

## iPadOS 18.5

- Shared iPads now have screen recording available in Control Center.

- Emails sent over poor or no network connection will no longer be purged from the device.

- Fixed an issue where enabling Apple Intelligence could cause threads in Mail to only show the most recent message.

- Resolved an issue where some supported paper sizes were not displaying as options for printing.

- Enterprise apps will no longer fail to launch.

- The wallpaper MDM command no longer hangs and will not disrupt further communication with affected devices.

## iPadOS 18.4

- MDM can disable Apple Intelligence reports, smart replies in Mail, and content summaries in Safari.

- MDM can control whether the default calling and messaging apps can be modified.

- In iPadOS, battery health can now be queried via MDM as with iOS.

- MDM can be configured to both authenticate using EnrollmentSSO and install a required app that is different from the enrollmentSSO during account-driven enrollment.

- When using TLS_ECDHE_RSA or TLS_DHE_RSA cipher suites, TLS certificates containing a Key Usage extension must have Digital Signature key usage set.

- When using the TLS_RSA cipher suite, TLS certificates containing a Key Usage extension must have Key Encipherment key usage set.

- Updates are no longer triggered when replacing an existing DDM software update.

- Resolved an issue where Control Center could not be modified when a Home Screen Layout payload was applied.

- When the App Store is disabled, the ability to enable “Always Allow” for cellular downloads is no longer removed from Settings.

## iPadOS 18.3

- Apple Intelligence is turned on automatically after updating to iPadOS 18.3 or during device setup unless MDM skips the Apple Intelligence setup pane.

- MDM can require sign-in from a specified Workspace ID for requests to external intelligence integrations such as ChatGPT.

- MDM can disable transcription summarization in Notes.

- Improves reliability of SSO to prevent logins from timing out and falling back to username and password prompts.

## iPadOS 18.2

- MDM can manage Apple Intelligence Integrations including ChatGPT.

- MDM can restrict Apple Intelligence image generation in Image Playgrounds and other apps.

- Multi-factor authentication in Safari reliably accepts the PIN for hardware security keys.

- A default browser can be set, and users can be prevented from modifying the default browser, using MDM.

- New skip keys have been added to allow automated enrollments in Apple Configurator to complete.

- Service discovery as part of account-driven enrollment can request the well-known resource from an alternative location specified by the MDM solution linked to Apple School Manager or Apple Business Manager.

## iPadOS 18.1

- MDM can disable RCS messages.

- MDM can manage Writing Tools and Mail summarization.

- Messages.app restriction can no longer be bypassed using ShareSheet.

- Users can no longer deactivate per-app VPN.

- Seventh-generation iPad can now successfully scan QR codes with Camera app.

- MDM can disable the ability to record phone calls.

- MDM can disable the ability to hide apps.

- MDM can block apps from being locked by users, which also blocks the ability to hide the app.

## iPadOS 18.0.1

Improved reliability for single sign-on authentication in Safari.

## iPadOS 18

iPadOS includes new features, bug fixes, and improvements for enterprise and education deployments.

### Education

- The Calculator app is now available on iPad.

- Restrictions for Math Notes, Math Notes keyboard, scientific mode, and unit conversions are available in MDM and Assessment mode.

### Device Management

- Software updates can now be managed entirely with declarative device management, replacing the MDM profiles for software update restrictions, settings, and software update commands and queries.

- MDM can manage which Safari extensions are allowed, always on or always off, and what websites they can access.

- On supervised devices, organizations can disable a user’s ability to hide and lock apps.

- The allowVPNCreation restriction now prevents VPN settings from being modified by unmanaged apps.

- Profile-based User Enrollment is no longer supported. For [User Enrollment](https://support.apple.com/guide/deployment/user-enrollment-and-mdm-dep23db2037d/1/web/1.0#dep6c59a3144) , sign in to a Managed Apple Account in Settings.

- A new MDM restriction can be set to prevent eSIM from being removed when a device is erased locally. When using the MDM erase command, eSIM can still be cleared, regardless of whether the restriction is in place.

- The MDM restrictions and commands for managing alternative marketplaces on iOS are now available for iPadOS.

### Bug fixes and other improvements

- Proprietary in-house apps installed without the use of MDM will now require a device restart to complete trust of the distribution identity. Identities trusted prior to upgrading will be preserved.

- The Security Framework can now import PKCS12 files created with AES-256-CBC encryption.

- Users with complex passwords no longer need to lock and unlock a device with a home button to see the keyboard.

- Devices with host pairing restricted can connect to Xcode on Mac computers with the correct supervision identity.

- Shared iPad users can authenticate while network extensions are in use.
