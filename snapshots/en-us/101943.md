# Import Sony XAVC and XDCAM media in Final Cut Pro

You need to install additional software to import Sony XAVC and XDCAM media.

## If you use Final Cut Pro version 10.2

Final Cut Pro 10.2 supports Sony XAVC, XAVC S, XDCAM, XDCAM HD, and XDCAM EX media.

Before importing Sony XAVC and XDCAM media, verify that Pro Video Formats is installed on your system. [Check for software updates](http://support.apple.com/kb/HT201541) and, if necessary, install the latest Pro Video Formats. (You can also [manually download](http://support.apple.com/kb/dl1396) Pro Video Formats from the Apple Support website.) No additional software is required.

To learn how to import media, read these topics in Final Cut Pro 10.2 Help:

- [Import from file-based cameras](http://help.apple.com/finalcutpro/mac/10.2/#verd0e78ca8)

- [Import from a hard disk](http://help.apple.com/finalcutpro/mac/10.2/#ver418155a4)

## If you use Final Cut Pro version 10.1.4 or earlier

Final Cut Pro 10.1.4 and earlier support Sony XAVC, XDCAM, XDCAM HD, and XDCAM EX media.

Before importing Sony XAVC and XDCAM media, verify that Pro Video Formats and the Sony XAVC/XDCAM Plug-in for Apple are installed on your system. [Check for software updates](http://support.apple.com/kb/HT201541) and, if necessary, install the latest Pro Video Formats. (You can also [manually download](http://support.apple.com/kb/dl1396) Pro Video Formats from the Apple Support website.)

If you need to install the Sony plug-in, manually download it from the [Sony Creative Software Download page](http://www.sonycreativesoftware.com/pdzk-lt2) . Review the included release notes, and then install the Sony plug-in.

To learn how to import media, read these topics in Final Cut Pro 10.1.4 Help:

- [Import from file-based cameras](http://help.apple.com/finalcutpro/mac/10.1/#verd0e78ca8)

- [Import from a hard disk](http://help.apple.com/finalcutpro/mac/10.1/#ver418155a4)
