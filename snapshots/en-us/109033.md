# Find out which macOS your Mac is using

Learn which Mac operating system (macOS) is installed on your Mac, and whether it's the latest (newest, most recent) version. If a product or feature requires a later version of macOS, check macOS compatibility to find out whether you can upgrade to that version.

- [Which macOS is installed?](https://support.apple.com/en-us/109033#aboutthismac)

- [Which macOS is the latest?](https://support.apple.com/en-us/109033#latest)

- [Check macOS compatibility](https://support.apple.com/en-us/109033#compatibility)

- [Upgrade to a later macOS](https://support.apple.com/en-us/109033#upgrade)

## Which macOS is installed?

From the Apple menu  in the upper-left corner of your screen, choose About This Mac. The window that opens might differ from this example, but it always includes the name and version number of the macOS that your Mac is currently using. If you need the build number as well, click the version number to see it.

[Image: About This Mac window.]
