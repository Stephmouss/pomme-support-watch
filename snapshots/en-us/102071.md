# If you can’t record audio from an external source on Mac

To record audio from an external source using an audio input like the built-in mic on your Mac, an external USB microphone, or an external audio interface, check that the app you're using has access to the audio input on your Mac.

When trying to record, an alert might say that audio input isn't accessible. Or you might not hear sound, see waveforms, or see audio meters move when recording. This can happen if you the app you're using to record audio doesn't have your permission to access audio inputs. Depending on [which macOS you're using](https://support.apple.com/kb/HT201260) , follow the steps below to allow the app to access audio inputs.

## In macOS Ventura or later

- Quit the app you're using to record audio.

- Choose Apple menu  > System Settings, then click Privacy & Security.

- Click Microphone.

- Turn on the setting for each app that needs access to the built-in mic, an external USB mic, or the inputs on an external audio interface.

[Image: macOS Ventura settings panel showing microphone permissions for apps]

- Open the app and try to record audio again.

If you're using an external mic or audio interface to record audio and it's still not working, check with the manufacturer of your device for software updates and information on compatibility.

## In macOS Monterey, Big Sur, Catalina, or Mojave

- Quit the app you're using to record audio.

- Choose Apple menu  > System Preferences, then click Security & Privacy.

- In the Privacy pane, click Microphone.

- Select each app that needs access the built-in mic, an external USB mic, or the inputs on an external audio interface.

[Image: macOS Security & Privacy preferences Privacy tab with Microphone selected.]

- Open the app and try to record audio again.

If you're using an external mic or audio interface to record audio and it's still not working, check with the manufacturer of your device for software updates and information on compatibility.
