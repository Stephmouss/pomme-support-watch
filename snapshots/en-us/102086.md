# Use Apple Studio Display or Pro Display XDR with Boot Camp

You can use these Apple displays with Microsoft Windows on certain Mac models. Just make sure that your software is up to date.

## Check compatibility

If you've installed the [latest software updates](https://support.apple.com/en-us/102086#updates) , you can use these Apple displays with Microsoft Windows 10 on certain Intel-based Mac models.

### Studio Display

Supports Boot Camp with macOS Monterey 12.3 or later on these Intel-based Mac models:

- 16-inch [MacBook Pro](https://support.apple.com/kb/HT201300) introduced in 2019

- 15-inch MacBook Pro introduced in 2016 through 2019

- 13-inch MacBook Pro introduced in 2016 through 2020

- [MacBook Air](https://support.apple.com/kb/HT201862) introduced in 2018 through 2020

- [iMac](https://support.apple.com/kb/HT201634) introduced in 2017 through 2020

- [iMac Pro](https://support.apple.com/kb/HT201634)

- [Mac mini](https://support.apple.com/kb/HT201894) introduced in 2018

- [Mac Pro](https://support.apple.com/kb/HT202888) introduced in 2019

### Pro Display XDR

Supports Boot Camp with macOS Catalina 10.15.2 or later on these Intel-based Mac models:

- 15-inch or 16-inch [MacBook Pro](https://support.apple.com/kb/HT201300) introduced in 2018 through 2020

- [iMac](https://support.apple.com/kb/HT201634) introduced in 2019 or 2020

- [Mac Pro](https://support.apple.com/kb/HT202888) introduced in 2019

## Update your software

Neither display requires additional setup, but make sure that your software is up to date:

- [Install the latest macOS updates](https://support.apple.com/kb/HT201541) . You must be using macOS to receive updates for your display.

- If you haven't already done so, [use Boot Camp Assistant to install Windows 10](https://support.apple.com/kb/HT201468) .

- [Start up your Mac in Windows](https://support.apple.com/kb/HT208123) , then [use Apple Software Update](https://support.apple.com/kb/HT208038) to install the latest Apple updates for Windows.

## Learn more

Mac computers might not support video over Thunderbolt 3 when Windows is in [Safe Mode](https://support.microsoft.com/en-us/help/12376/windows-10-start-your-pc-in-safe-mode) or the Windows Recovery Environment. Video in those modes remains available to displays connected to a different display port, such as HDMI.
