# How to upgrade to macOS 27 Golden Gate

macOS 27 introduces Siri AI powered by Apple Intelligence, new parental controls, and an expansive set of improvements that make your Mac even more responsive, reliable, and delightful.

[Image: MacBook displaying the macOS Golden Gate desktop.]

To learn more about the powerful capabilities in macOS 27 Golden Gate, visit [apple.com/os/macos](https://www.apple.com/os/macos) .

## Check compatibility with macOS 27

macOS 27 is compatible with any Mac with Apple silicon, which includes any Mac with an M-series chip or A-series chip.

[Learn which Mac computers are compatible with macOS 27](https://support.apple.com/en-us/127255)

## Make a backup before upgrading

Before installing any macOS upgrade, it's a good idea to back up your files.

[Learn how to back up your Mac](https://support.apple.com/en-us/102307)

## Download and install macOS 27

Software Update is the fastest and easiest way to find, download, and install macOS 27 and other Apple software updates. And it offers only updates that are compatible with your Mac.

- Use Spotlight in the menu bar to search for Software Update, then open it from the search results. Or open it from System Settings: Choose Apple menu  > System Settings, click General in the sidebar, then click Software Update on the right.

- When Software Update opens, it automatically checks for any new Apple software. If macOS 27 is available for your Mac model, install it by clicking the button to update, upgrade, or restart now.

[Learn more about how to use Software Update](https://support.apple.com/en-us/108382)
