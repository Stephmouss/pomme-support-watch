# About Logic Pro for Mac

Learn more about Logic Pro.

## How to get Logic Pro

You can purchase and download Logic Pro from the [Mac App Store.](https://apps.apple.com/us/app/logic-pro-x/id634148309) You can also get a subscription to [Apple Creator Studio](https://www.apple.com/apple-creator-studio/) , which includes Logic Pro.

## Third-party audio interface compatibility

Logic Pro works with any audio interface that's compatible with your version of macOS. If the device requires a driver to function, make sure an up-to-date driver is included with the device or that one is available from the manufacturer.

## Compatibility with older Logic projects

You can open projects from Logic 5 or later with the latest version of Logic Pro.
