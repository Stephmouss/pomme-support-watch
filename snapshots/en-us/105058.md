# Upgrade a Shared iPad to iPadOS 17

You can't upgrade a Shared iPad to iPadOS 17 if there are existing user accounts on the iPad.

If you use your Mobile Device Management (MDM) solution to upgrade a Shared iPad, the upgrade won't install if there are existing user accounts on the iPad. If you use the Finder or Apple Configurator on a Mac to update the Shared iPad, the existing users won't be able to log in after the upgrade.

Instead, use your MDM solution to remove the existing users from the iPad before you upgrade, or use the Finder or Apple Configurator on a Mac to erase the iPad before you upgrade.

If your custom wallpaper disappears from Shared iPads after you upgrade the iPad to iPadOS 17, you can use your MDM solution to redistribute it.
