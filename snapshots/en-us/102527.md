# Using Intel-based apps on a Mac with Apple silicon

When opening an Intel-based app, you might be notified that support is ending for Intel-based apps, and that the app or a component used by the app will not work with a future release of macOS (macOS 28). For optimal performance and future compatibility, update the app for Apple silicon.

- [Update Intel-based apps for Apple silicon](https://support.apple.com/en-us/102527#update)

- [Identify Intel-based apps](https://support.apple.com/en-us/102527#identify)

- [Install and use Rosetta to run Intel-based apps](https://support.apple.com/en-us/102527#use)

## About Intel-based apps, Rosetta, and the transition to Apple silicon

In 2020 [Apple announced the transition](https://www.apple.com/newsroom/2020/06/apple-announces-mac-transition-to-apple-silicon/) from Mac computers with Intel processors to [Mac computers with Apple silicon](https://support.apple.com/en-us/116943) . To ease this transition, Apple created Rosetta:

- Rosetta works in the background to automatically translate your [Intel-based apps](https://support.apple.com/en-us/102527#identify) for use with Apple silicon. This has given app developers and users more time to update their apps for Apple silicon.

- Rosetta is available for any Mac with Apple silicon using [macOS 27 or earlier](https://support.apple.com/en-us/109033) . Starting with macOS 28, the next major macOS release, Rosetta functionality will be available only for certain older, unmaintained games that rely on Intel-based frameworks.

## Update your Intel-based apps for Apple silicon

For optimal performance and future compatibility, update your [Intel-based apps](https://support.apple.com/en-us/102527#identify) by replacing them with a "Universal" or "Apple silicon" version of the app, instead of relying on Rosetta to translate the app for use with Apple silicon.

- If you got the app from the App Store, you can [use the App Store to find and install updates](https://support.apple.com/en-us/102629) , if available.

- Or check the developer’s website for a "Universal" or "Apple silicon" version of the app. A link to their website might be offered in the notification you received about the app.

- Some apps offer a built-in way to get updates. Look for a "Check for Updates" option or similar in the app’s menus or settings.

- If necessary, [contact the app developer](https://support.apple.com/en-us/103190) to learn whether an update for Apple silicon is available or planned.

Some apps might include or use components, such as extensions or updaters, that need to be updated separately. If you added functionality to your app by installing Intel-based plug-ins, extensions, or other add-ons from a different developer, remember to update those as well.

## Identify your Intel-based apps

When opening an Intel-based app, you might be notified that support is ending for Intel-based apps, and that your app or a component used by your app will not work with a future release of macOS (macOS 28). You can also use the Finder or System Settings to learn which apps require an update for Apple silicon.

### Use the Finder

- Locate the app in the Finder. Most apps are in the Applications folder, which you can access from the sidebar of any Finder window.

- Click the app once to select it.

- From the File menu in the Finder menu bar, choose Get Info. Or press Command-I.

- In the Info window that opens, find the information shown after Kind:

- Application (Intel): The app is made for a Mac with an Intel processor. You should [update the app for Apple silicon](https://support.apple.com/en-us/102527#update) .

- Application (Universal): The app is made for both a Mac with Apple silicon and a Mac with an Intel processor.

- Application (Apple silicon): The app is made for a Mac with Apple silicon.

[Image: Info window for an Intel-based app.]

### Use System Settings

- Make sure that you’re using macOS 27 Golden Gate or later.

- From the Apple menu , choose System Settings.

- Click General in the sidebar, then click About on the right.

- In the macOS section, click the Details button next to Intel-based Apps.

[Image: Intel-based Apps section in the General pane of System Settings.]

- A list of Intel-based apps appears, showing apps that you recently used or that are installed in common locations. To show an app in the Finder or move it to the Trash, move your pointer over the app’s name, click the More Info button , then choose Show App in Finder or Move to Trash.

## Install and use Rosetta to run Intel-based apps

Use either of these methods to install Rosetta for [macOS 27 or earlier](https://support.apple.com/en-us/109033) . Remember, Rosetta is not an app that you manually open or interact with, but works automatically in the background.

### Open any Intel-based app

- Make sure that your Mac is connected to the internet.

- Open any [Intel-based app](https://support.apple.com/en-us/102527#identify) .

- If the app opens, Rosetta is already installed and working in the background.

- If you’re asked to install Rosetta, click Install and enter your macOS user name and password to allow installation to proceed.

[Image: Prompt to install Rosetta when opening an Intel-based app.]

### Or use Terminal

- Make sure that your Mac is connected to the internet.

- Open Terminal, which is in the Utilities folder of your Applications folder.

- Type or paste this command in the Terminal window:

- softwareupdate --install-rosetta

- Press Return and follow the onscreen instructions.

## Learn more

If the Info window for an app shows an "Open using Rosetta" setting, the app is Universal and the app developer chose to include this setting. It forces the app to open as an Intel-based app instead of an app for Apple silicon, which allows it to use Intel-only plug-ins, extensions, and other add-ons. If you later update the add-on for Apple silicon, deselect this setting.
