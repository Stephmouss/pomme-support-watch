# Use Apple Reference Image to capture photos and verify they were taken on iPhone 18 Pro or iPhone 18 Pro Max

On iPhone 18 Pro and iPhone 18 Pro Max, you can use Apple Reference Image to verify the authenticity of a photo. The new Main camera is able to securely capture and sign photo data at the pixel level right on the sensor when using Reference mode in the Camera app. The resulting reference image is like a secure digital negative, which you can compare with the regular photo to see whether that photo has been edited or altered.

## How Apple Reference Image works

Apple Reference Image is an opt-in mode in Camera. When you turn on Reference mode and capture a photo, the camera will capture securely timestamped sensor data, which you can then develop and view as an unalterable reference image in the Photos app. You can develop, view, and share reference images in Photos on any iPhone, iPad, or Mac with iOS 27, iPadOS 27, macOS 27, or later.

In the EU, Reference mode is not available in Camera, but users with iOS 27, iPadOS 27, and macOS 27 can develop and view reference images. In China mainland, users with iOS 27, iPadOS 27, and macOS 27 cannot capture or develop reference images, but they can view reference images that have been shared with them.

## Set up Apple Reference Image

Apple Reference Image is off by default. To use Apple Reference Image, set up Reference mode in the Settings app. You only have to do this one time.

- Go to the Settings app.

- Tap Camera, then tap Reference Image.

[Image: iPhone screen showing Reference Image settings with Save Captures to Photo Library toggle enabled.]

- Tap Add Reference Mode, then follow the onscreen instructions.

## Turn Apple Reference Image off or on

After you've set up Apple Reference Image, you can turn Reference mode off or on from Camera settings:

- Go to the Settings app.

- Tap Camera, then tap Reference Image.

- Turn Add Reference Mode off or on.

[Image: iPhone screen showing Reference Image settings with Reference Mode enabled.]

If you turn off Apple Reference Image, Reference mode will not be available in the Camera app until you turn Add Reference Mode back on.

## Take a photo with a reference image

- Open Camera on your iPhone.

- Swipe to select Reference mode.

- Tap the Shutter button , or click the Camera Control, to take the photo.

Your iPhone captures a regular photo in addition to signed data from the Main camera sensor, which preserves what the camera originally saw.

You can capture Live Photos, Portraits, and use Photographic Styles in Reference mode, but some Camera features, such as Night Mode, are unavailable.

Reference images require additional device storage and iCloud storage:

- Photos captured at 12 MP or 24 MP resolution require ~8-10 MB in additional storage for undeveloped reference image data and ~3 MB for developed reference image data.

- Photos captured at 48 MP resolution require ~35-40 MB in additional storage for undeveloped reference image data and ~7-8 MB for developed reference image data.

## Find reference images

You can find all photos with reference images in the Photos app in your collections of photos and videos organized by media type:

- On your iPhone or iPad: Tap Collections, scroll down, then tap Media Types. Tap Reference.

- On your Mac: In the Media Types section of the sidebar, click Reference.

## Develop a reference image

Before you can view or share a reference image, it must be developed in the Photos app:

- On your iPhone, go to the Photos app.

- Open a photo taken in Reference mode.

- Tap the Reference badge in the top-left corner of the photo.

When you develop the photo, your iPhone sends the reference image data and associated metadata—including the camera sensor's signature and secure timestamps—to Private Cloud Compute to be developed into a viewable image and to authenticate the photo. You need an internet connection to develop a reference image.

## View reference information

After a reference image has been developed, you can visually compare it with the photo so that you can see if any edits, such as a crop, color adjustment, or an adjustment made with generative AI, have been made. You can also view the reference image's metadata.

You can view a reference image on an iPhone, iPad, or Mac with iOS 27, iPadOS 27, macOS 27, or later.

### Compare a reference image with a photo

- In Photos, open the photo, then tap the Reference badge in the top-left corner to view the reference image.

- Tap the image to switch between the reference image and the photo. Any edits, such as a crop, color adjustment, or an adjustment made with generative AI, will be visible in the comparison. Because the reference image has minimal processing applied, it will have less contrast and lower saturation than the photo.

### View reference image metadata

- In Photos, open the photo, tap the Reference badge in the top-left corner of the photo.

- Tap the Info button to view the reference image's metadata.

## Share a reference image

When you share or export a photo that has a reference image, you can choose whether to include the reference image.

A reference image can be viewed only on an iPhone, iPad, or Mac with iOS 27, iPadOS 27, macOS 27, or later.

If you share a Reference mode photo before reference image has been developed, it may include sensitive information about your device, such as the serial number, and the full image frame regardless of the zoom setting at capture.

### Include the reference image every time you share

To include the reference image every time you share a Reference mode photo, turn on Share Reference Image:

- On iPhone 18 Pro, iPhone 18 Pro Max, or later: Go to the Settings app. Tap Camera, then tap Reference Image. Turn on Share Reference Image.

- On other iPhone models: Go to the Settings app. Tap Apps, then tap Photos. Turn on Share Reference Image.

### Include or leave out the reference image for a single share

- Select the photo you want to share, then tap the Share button .

- Tap Options in the Share window, then turn Reference Image on or off.

- Share the photo—for example, with AirDrop or Messages—or export it to an external device.

If you turn on All Photos Data in Options in the Share window, original quality files will include edit history and metadata like location, depth information, and captions.

## Include a reference image when you transfer photos

To include the reference image when you transfer photos to a Mac or PC, turn on Transfer Reference Image:

- On iPhone 18 Pro, iPhone 18 Pro Max, or later: Go to the Settings app. Tap Camera, then tap Reference Image. Turn on Transfer Reference Image.

- On other iPhone models: Go to the Settings app. Tap Apps, then tap Photos. Tap Transfer to Mac or PC, then turn on Transfer Reference Image.

When you transfer a photo with a reference image, it includes the reference image data, but the reference image can be viewed only on an iPhone, iPad, or Mac with iOS 27, iPadOS 27, macOS 27, or later.

## If you see an Unable to Process Reference Image error

If you see an error that an image can't be processed, check your internet connection. You need an internet connection to develop a reference image.
