# If you can’t create an Apple Account or see “your account cannot be created at this time”

Learn what to do if you can’t create an Apple Account. You can try again later, or try a different way to create an Apple Account.

## If this isn’t the first Apple Account that you’ve tried to create

If you already have an Apple Account and you’re trying to create additional accounts, there are alternatives depending on what you’re trying to do.

- If you’re trying to create an account because you forgot your Apple Account password, [reset your password](https://support.apple.com/en-us/102656) .

- If you’re trying to create an Apple Account and see a message that says the email address or phone number is unavailable or can’t be used, then an Apple Account already exists that uses it. Try a different email address or phone number, or [reset your password](https://support.apple.com/en-us/102656) for that account.

- If you’re trying to create an Apple Account for a child, [use Family Sharing to create an Apple Account for a child instead](https://support.apple.com/en-us/102617) .

- If you’re trying to set up multiple accounts for a business or employees, [learn how to use Managed Apple Accounts in Apple Business](https://support.apple.com/guide/business/axm78b477c81) .

## If you still need help

If you can’t create your Apple Account, there are some things you can try.

### Use an Apple device or app

If you have an Apple device, use that to create your account in Settings or System Settings. If you have a Windows PC or Android device, try creating your account on the web at [account.apple.com](https://account.apple.com) .

### Update to the latest software

Your Apple device or Apple app might not be up to date.

- [Update to the latest version of iOS or iPadOS](https://support.apple.com/en-us/118575)

- [Update to the latest version of macOS](https://support.apple.com/en-us/108382)

- On a Windows PC or Android phone, update your operating system and check for the latest updates to Apple’s apps

### If this is your first Apple Account

If you still see “your account cannot be created at this time” on a device with up-to-date software, [get suggestions](https://getsupport.apple.com/?caller=kbase) on what to try next.

### Check your internet connection

Make sure you can open webpages in your device’s web browser. If you can open webpages, try again later to create an Apple Account. You might want to switch to cellular data or a different Wi-Fi network, if available. You can also [check Apple’s System Status page](https://www.apple.com/support/systemstatus/) to see if there’s an outage in your country or region.
