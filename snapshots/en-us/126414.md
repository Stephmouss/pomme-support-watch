# If Compressor won't open after a macOS update

Update to Compressor 4.11.1 or later.

Update to Compressor 4.11.1 if you updated to these macOS versions and can’t open Compressor:

- macOS Tahoe 26.3

- macOS Sequoia 15.7.4

If you updated to macOS Sonoma 14.8.4 and can't open Compressor:

- Update to macOS Sequoia 15.6 or later.

- Update to Compressor 4.11.1 or later.

Compressor 4.11.1 also addresses a security issue. If you need to continue using Compressor 4.11 or earlier, [be advised of the security issue](https://support.apple.com/en-us/125693) . You can [set macOS Firewall to deny incoming connections into the Compressor app](https://support.apple.com/guide/mac-help/mh11783/mac) if you are using it only for local encoding.
