# GarageBand: Mouse clicks while using the Musical Typing keyboard may cause delayed, stuck, or dropped notes

If you click the mouse while using the Musical Typing keyboard, some notes may sound late, get stuck, or not sound at all.

For best results, avoid using the mouse when you are using the Musical Typing keyboard.
