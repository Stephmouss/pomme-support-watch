# Lion Server : le site Web par défaut est inaccessible après l’ajout d’un second site Web

Après l’ajout d’un second site Web, le site Web par défaut ne peut plus être chargé. Les services Web, comme les wikis et le gestionnaire de profils, peuvent également ne plus être accessibles.

Lorsque vous utilisez un service d’hébergement Web virtuel par nom, définissez chaque adresse IP de domaine sur « tous » dans la section Web de Server.app.

## Informations supplémentaires

Plusieurs éléments importants sont à prendre en compte lorsque vous utilisez un service d’hébergement Web virtuel :

- Le service Web répond aux requêtes en fonction de l’adresse IP du serveur réceptionnant la requête, avant que le nom de domaine ou l’URL demandé(e) soit pris(e) en considération.

- Les services Web sont uniquement accessibles via le site générique par défaut. Certains services, comme le gestionnaire de profils, continuent à s’exécuter, mais ne sont pas accessibles si un second site Web est assigné à l’adresse IP unique du serveur dans la section Web de l’application Serveur.

- Des informations supplémentaires, relatives aux services d’hébergement Web virtuels, sont disponibles à l’adresse [http://httpd.apache.org/docs/2.2/vhosts/](http://httpd.apache.org/docs/2.2/vhosts/) .
