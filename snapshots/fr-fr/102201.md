# Mise à jour des pilotes graphiques AMD pour Windows dans Boot Camp

Téléchargez et installez les derniers pilotes graphiques AMD pour Windows sur les modèles de Mac dotés de cartes graphiques AMD.

Si vous exécutez Windows sur votre Mac à l’aide de Boot Camp, vous pouvez accéder au site Web d’AMD pour télécharger la dernière version de leurs pilotes pour Windows. Les ordinateurs Mac à processeur Intel suivants sont dotés de cartes graphiques AMD :

- [MacBook Pro](https://support.apple.com/fr-fr/HT201300) 15 pouces commercialisé de 2015 à 2019

- MacBook Pro 16 pouces commercialisé à partir de 2019

- [iMac](https://support.apple.com/fr-fr/HT201634) 27 pouces commercialisé de 2014 à 2020

- [iMac](https://support.apple.com/fr-fr/HT201634) 21,5 pouces avec écran Retina commercialisé de 2017 à 2019

- iMac Pro commercialisé en 2017

- [Mac Pro](https://support.apple.com/fr-fr/HT202888) commercialisé de 2013 à 2019

## Vérifier la version de vos pilotes graphiques AMD

- Démarrez votre Mac sous Windows.

- Suivez l'une de ces étapes pour ouvrir les réglages Radeon :

- Cliquez avec le bouton droit de la souris sur le bureau et sélectionnez AMD Radeon Settings (Réglages AMD Radeon).

- Cliquez sur Radeon Settings (Réglages Radeon) dans la zone de notification.

- Choisissez AMD Radeon Settings (Réglages AMD Radeon) dans le menu Programmes.

- Dans les réglages Radeon, cliquez sur l’onglet System (Système), puis sur l’onglet Software (Logiciel).

- Le numéro de version est indiqué sous Driver Packaging Version (Version du package de pilotes).

## Télécharger et installer les derniers pilotes graphiques AMD

- Sous Windows, accédez à la [page Apple Boot Camp Software Graphics Drivers](https://www.amd.com/fr/support/kb/release-notes/apple-boot-camp) du site web AMD.

- Recherchez la version des pilotes compatible avec votre modèle de Mac. S’il s’agit d’une version ultérieure (numéro supérieur) à celle qui est installée sur votre Mac, cliquez sur Download (Télécharger).

- Décompressez le fichier ZIP téléchargé, puis exécutez l’app Setup depuis le dossier résultant pour installer les pilotes.
