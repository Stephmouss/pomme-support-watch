# Création de bannières relatives aux politiques sous macOS

Découvrez comment créer des bannières personnalisées qui apparaîtront dans la fenêtre d’ouverture de session de votre Mac.

Une bannière relative à une politique s’affiche dans la fenêtre d’ouverture de session. Vous devez en accepter les termes avant de pouvoir continuer.

## À propos des bannières relatives aux politiques

Vous pouvez [ajouter un court message à la fenêtre d’ouverture de session](https://support.apple.com/guide/mac-help/display-a-message-in-the-mac-login-window-mh35890/mac) qui s’affiche lorsque votre Mac est verrouillé. Vous pouvez également créer une bannière relative à une politique afin d’afficher un message plus long qui doit être accepté avant que la connexion soit possible. Ceci peut s’avérer utile si vous souhaitez que les utilisateurs soient tenus d’accepter des conditions générales particulières avant de pouvoir employer l’ordinateur, notamment celles d’une politique d’utilisation acceptable.

### Création d’une bannière

- Créez un document au format texte brut (.txt) ou enrichi (.rtf) contenant les termes à afficher dans la bannière.

- Accédez à Fichier, puis sélectionnez Enregistrer.

- Saisissez PolicyBanner comme nom du document.

- Copiez le fichier PolicyBanner dans le dossier /Bibliothèque/Sécurité/.

Lors du prochain redémarrage de l’ordinateur, la bannière apparaîtra à la place de l’écran d’ouverture de session habituel.

## Si la bannière n’apparaît pas

Si votre bannière ne s’affiche pas, effectuez les actions suivantes.

### Vérification de FileVault

Si vous utilisez [le chiffrement complet du disque à l’aide de FileVault](https://support.apple.com/guide/mac-help/protect-data-on-your-mac-with-filevault-mh11785/mac) sur votre ordinateur, la bannière de politique apparaît après la première connexion d’un utilisateur, avant que le bureau n’apparaisse. La première connexion permet de déverrouiller le disque de démarrage.

### Vérification des autorisations

Dans certains cas, il peut être nécessaire de modifier les autorisations du fichier PolicyBanner.

Avec un fichier PolicyBanner au format .txt ou .rtf, configurez les autorisations de sorte que tous les utilisateurs bénéficient de privilèges de lecture, à l’aide de l’option Tout le monde (Autre) :

sudo chmod o+r /Library/Security/PolicyBanner.txt

sudo chmod o+r /Library/Security/PolicyBanner.rtf

Avec un fichier PolicyBanner au format .rtfd, configurez les autorisations de sorte que tous les utilisateurs bénéficient de privilèges de lecture et d’exécution, à l’aide de l’option Tout le monde (Autre) :

sudo chmod -R o+rx /Library/Security/PolicyBanner.rtfd

### Modification du volume de prédémarrage

Si la bannière n’apparaît toujours pas, modifiez le volume de prédémarrage :

diskutil apfs updatePreboot /
