# Activer les descriptions audio sur votre iPhone ou iPad

Sur l’iPhone ou l’iPad, vous pouvez activer les descriptions audio afin d’écouter une description des scènes des vidéos que vous regardez.

## Utiliser des descriptions audio dans Réglages

- Accédez à Réglages > Accessibilité.

- Touchez Descriptions audio.

- Activez l’option Descriptions audio.

[Image: Bouton Descriptions audio dans Réglages sur l’iPhone]

## Activer les descriptions audio dans l’app Apple TV

- Ouvrez l’app Apple TV.

- Lancez une vidéo, puis touchez l’écran pour afficher les commandes de lecture.

- Choisissez la piste de description audio à utiliser.

Déterminez [si un film ou une série TV comporte des descriptions audio](https://support.apple.com/HT205742) .

## Si vous ne voyez pas de descriptions audio

- Les vidéos ne comportent pas toutes des pistes de description audio. Consultez la documentation accompagnant votre vidéo pour en savoir plus.

- Un certain nombre d’apps et de sites web tiers proposent des commandes audio personnalisées pour les vidéos. Si ces commandes n’apparaissent pas lorsque vous visionnez une vidéo sur un site web, consultez la documentation ou contactez le gestionnaire du site ou le développeur de l’app pour obtenir plus d’informations.

- Déterminez [si un film ou une série TV comporte des descriptions audio](https://support.apple.com/HT205742) .

Si vous avez désactivé les descriptions audio, mais que vous entendez toujours les descriptions de menu, il est possible que la fonction VoiceOver soit activée. Apprenez à [désactiver VoiceOver](https://support.apple.com/guide/iphone/turn-on-and-practice-voiceover-iph3e2e415f/ios) .

Découvrez comment activer les descriptions audio sur un autre appareil :

- [Activer les descriptions audio sur Mac](https://support.apple.com/HT205800) .

- [Activer les descriptions audio sur un PC Windows](https://support.apple.com/HT205798) .

- [Activer les descriptions audio sur l’Apple TV](https://support.apple.com/HT205799) .

L’app Apple TV n’est pas disponible dans certains pays ou certaines régions. Découvrez [où l’app Apple TV est disponible](https://support.apple.com/HT208083) .
