# Si vous ne pouvez pas vous déconnecter en raison de restrictions, ou si votre compte Apple apparaît en grisé dans Réglages

Si vous ne pouvez pas vous déconnecter de votre compte Apple, ou si votre compte Apple apparaît en grisé dans Réglages sur votre iPhone ou iPad, vérifiez si un code d’accès Temps d’écran et/ou des restrictions Temps d'écran ont été activés.

- [Si vous ne pouvez pas vous déconnecter en raison de restrictions](https://support.apple.com/fr-fr/101973#restrictions)

- [Si votre compte Apple est grisé dans l’app Réglages](https://support.apple.com/fr-fr/101973#account-gray)

- [Si vous faites partie d’un groupe de partage familial en tant qu’enfant ou adolescent(e)](https://support.apple.com/fr-fr/101973#child)

## Si vous ne pouvez pas vous déconnecter en raison de restrictions

Si vous ne pouvez pas vous déconnecter de votre compte Apple sur votre iPhone ou iPad et que le message « Sign out is not available due to restrictions » (Déconnexion non disponible en raison de restrictions) s’affiche, un code d'accès Temps d’écran a peut-être été activé. Vérifiez si un code d’accès Temps d’écran a été activé, puis désactivez-le pour vous déconnecter de votre compte Apple.

[Image: Écran d’iPhone sur lequel le bouton « Se déconnecter » apparaît grisé dans l’app Réglages en raison des restrictions de Temps d’écran.]

### Désactiver votre code d’accès Temps d’écran

- Ouvrez l’app Réglages, puis touchez Temps d’écran.

- Faites défiler l’écran vers le bas, puis touchez Modifier le code de « Temps d’écran ».

- Touchez Désactiver le code de « Temps d’écran », puis saisissez votre code d’accès pour le désactiver.

[Découvrir la marche à suivre en cas d’oubli de votre code Temps d’écran](https://support.apple.com/102677)

## Si votre compte Apple est grisé dans l’app Réglages

Si votre compte Apple est grisé dans l’app Réglages, certaines restrictions de temps d’écran ont peut-être été activées pour votre appareil.

[Image: Écran d’iPhone affichant le nom du ou de la propriétaire en grisé dans Réglages, ce qui indique une restriction du compte Apple liée à Temps d’écran.]

### Vérifier les réglages Temps d’écran

- Ouvrez l’app Réglages, puis touchez Temps d’écran.

- Touchez Contenu et confidentialité dans la section Restrictions.

- Si l’option Contenu et confidentialité est activée, faites défiler l’écran vers le bas jusqu’à la section Autoriser les modifications de.

- Touchez Comptes et définissez l’option sur Autoriser. Si un message vous y invite, saisissez votre code de Temps d’écran.

- Puis, sur le même écran, vérifiez si d’autres réglages sont définis sur Ne pas autoriser. Si c’est le cas, touchez chacun de ces réglages, puis sélectionnez Autoriser. Si un message vous y invite, saisissez votre code de Temps d’écran.

[Image: Un écran d’iPhone affichant l’option Restrictions relatives au contenu et à la confidentialité que vous pouvez activer dans Temps d'écran.]

## Si vous faites partie d’un groupe de partage familial en tant qu’enfant ou adolescent(e)

Si vous faites partie d’un groupe de partage familial en tant qu’enfant et que votre parent ou tuteur a [configuré le contrôle parental](https://support.apple.com/105121) sur votre appareil, vous devez lui demander de saisir son code de Temps d’écran afin d’autoriser les modifications des réglages de votre appareil. Les modifications apportées au code de Temps d’écran d’un enfant doivent être effectuées sur l’appareil du parent ou du tuteur.
