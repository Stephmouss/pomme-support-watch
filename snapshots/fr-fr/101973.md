# Si vous ne pouvez pas vous déconnecter en raison de restrictions, ou si votre compte Apple apparaît en grisé dans Réglages

Si vous ne pouvez pas vous déconnecter de votre compte Apple, ou si votre compte Apple apparaît en grisé dans Réglages sur votre iPhone ou iPad, vérifiez si un code d’accès Temps d’écran et/ou des restrictions Temps d'écran ont été activés.

- [Si vous ne pouvez pas vous déconnecter en raison de restrictions](https://support.apple.com/fr-fr/101973#restrictions)

- [Si votre compte Apple est grisé dans l’app Réglages](https://support.apple.com/fr-fr/101973#account-gray)

- [Si vous êtes un enfant dans un groupe de Partage familial](https://support.apple.com/fr-fr/101973#Enfant)

## Si vous ne pouvez pas vous déconnecter en raison de restrictions

Si vous ne pouvez pas vous déconnecter de votre compte Apple sur votre iPhone ou iPad et que le message « Sign out is not available due to restrictions » (Déconnexion non disponible en raison de restrictions) s’affiche, un code d'accès Temps d’écran a peut-être été activé. Vérifiez si un code d’accès Temps d’écran a été activé, puis désactivez-le pour vous déconnecter de votre compte Apple.

[Image: iPhone, MacBook Pro et Apple Watch répertoriés dans les réglages, avec un bouton Se déconnecter désactivé.]

### Désactiver votre code d’accès Temps d’écran

- Ouvrez l’app Réglages, puis touchez Temps d’écran.

- Faites défiler l’écran vers le bas, puis touchez Gérer Temps d’écran.

- Touchez Modifier le code de Temps d’écran.

- Touchez Désactiver le code de « Temps d’écran », puis saisissez votre code d’accès pour le désactiver.

[Découvrez comment modifier le code de votre Temps d’écran](https://support.apple.com/102677)

## Si votre compte Apple est grisé dans l’app Réglages

Si votre compte Apple est grisé dans l’app Réglages, certaines restrictions de temps d’écran ont peut-être été activées pour votre appareil.

[Image: Écran Réglages de l’iPhone affichant les options Identifiant Apple, Mode Avion, Wi-Fi, Bluetooth et Données cellulaires.]

### Vérifier les réglages Temps d’écran

- Ouvrez l’app Réglages, puis touchez Temps d’écran.

- Touchez Contenu et confidentialité dans la section Restrictions.

- Si l’option Toutes les restrictions est activée, faites défiler l’écran jusqu’à Restrictions de confidentialité.

- Touchez Autoriser les modifications des réglages.

[Image: Écran de l’iPhone affichant Autoriser les modifications des réglages avec l’option Comptes définie sur Ne pas autoriser.]

- Touchez Comptes et définissez l’option sur Autoriser. Si un message vous y invite, saisissez votre code de Temps d’écran.

- Revenez à l’écran Autoriser les modifications des réglages et vérifiez si d’autres réglages sont définis sur Ne pas autoriser. Si c’est le cas, touchez chacun de ces réglages, puis sélectionnez Autoriser. Si un message vous y invite, saisissez votre code de Temps d’écran.

## Si vous êtes un enfant et que vous faites partie d’un groupe de partage familial

Si vous êtes un enfant dans un groupe de Partage familial et que votre parent ou tuteur [a configuré le contrôle parental pour gérer votre appareil](https://support.apple.com/105121) , vous devez lui demander de saisir le code de Temps d’écran pour autoriser les modifications des réglages de votre appareil. Les modifications du code de Temps d’écran d’un enfant doivent être effectuées sur l’appareil du responsable familial ou du parent/tuteur.
