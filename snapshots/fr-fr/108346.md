# Si vous ne parvenez pas à sauvegarder votre appareil iOS ou iPadOS sur un ordinateur ou le restaurer à partir d’une sauvegarde

Si vous ne parvenez pas à sauvegarder votre iPhone, iPad ou iPod touch sur un ordinateur, ou si vous ne pouvez pas restaurer votre appareil à partir d’une sauvegarde d’ordinateur, découvrez la marche à suivre.

## Effectuez un test après chaque étape

- Assurez-vous que votre [Mac](https://support.apple.com/fr-fr/108382) ou PC est à jour. Assurez-vous que vous avez la [dernière version de l’app Appareils Apple](https://support.apple.com/fr-fr/118406) ou la [dernière version d’iTunes](https://support.apple.com/fr-fr/118290) .

- Connectez votre appareil à votre ordinateur à l’aide d’un câble USB, et [localisez votre appareil sur votre ordinateur](https://support.apple.com/fr-fr/108392) . Si votre appareil n’apparaît pas dans le Finder, dans iTunes ni dans l’app Appareils Apple, [découvrez la marche à suivre](https://support.apple.com/fr-fr/108643) . Si vous avez oublié votre code d’accès ou si votre appareil est désactivé, [découvrez la marche à suivre](https://support.apple.com/fr-fr/118430) .

- Redémarrez tous vos appareils.

- Si votre ordinateur est un Mac, ignorez cette étape. Si vous utilisez un PC Windows et qu’iTunes ne répond pas ou que votre sauvegarde ne se termine pas, vous devrez peut-être [mettre à jour, modifier, désactiver ou désinstaller votre logiciel de sécurité](https://support.apple.com/fr-fr/111760) .

- Essayez de sauvegarder vos données sur un autre ordinateur si vous en possédez plusieurs. Sinon, [utilisez iCloud pour sauvegarder votre appareil](https://support.apple.com/fr-fr/118426) et [procédez à la restauration à partir de votre sauvegarde iCloud](https://support.apple.com/fr-fr/118105) .

- Si vous recevez un message indiquant qu’ [une erreur s’est produite](https://support.apple.com/fr-fr/108346#linkdown) , que votre [sauvegarde est corrompue ou incompatible](https://support.apple.com/fr-fr/108346#corrupt) , ou encore que [l’espace disque disponible est insuffisant](https://support.apple.com/fr-fr/108346#space) , reportez-vous aux paragraphes suivants pour connaître la marche à suivre.

### Si vous recevez un message vous indiquant qu’une erreur s’est produite

Si un message indique que votre ordinateur ne peut pas sauvegarder votre appareil en raison d’une erreur, vérifiez que vous avez [la dernière version d’iOS ou d’iPadOS](https://support.apple.com/fr-fr/118575) .

### Si vous recevez un message vous indiquant que l’espace disque disponible est insuffisant

Si l’espace disque de votre Mac ou PC est insuffisant au moment où vous essayez de sauvegarder les données de votre appareil, libérez de l’espace sur votre ordinateur.

### Si vous recevez un message vous indiquant que votre sauvegarde est corrompue ou incompatible

Si votre appareil iOS ou iPadOS ne parvient pas à effectuer une restauration à partir d’une sauvegarde car celle-ci est endommagée ou incompatible, assurez-vous que votre ordinateur est à jour. Si une erreur indique que votre logiciel iOS ou iPadOS est trop ancien, découvrez comment [mettre à jour votre appareil pour restaurer la sauvegarde](https://support.apple.com/fr-fr/108811) . Si vous ne parvenez toujours pas à restaurer la sauvegarde, il est possible que celle-ci soit inutilisable. Essayez d’utiliser une autre sauvegarde ou une sauvegarde iCloud.

## Obtenir davantage d’aide

- Si vous [avez oublié le code d’accès de votre appareil](https://support.apple.com/fr-fr/118430)

- Si vous [ne pouvez pas restaurer votre appareil iOS ou iPadOS à partir d’une sauvegarde car votre logiciel est trop ancien](https://support.apple.com/fr-fr/108811)

- Si vous avez besoin d’ [aide concernant une sauvegarde iCloud](https://support.apple.com/fr-fr/102563)
