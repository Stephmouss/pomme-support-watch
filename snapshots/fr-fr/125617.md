# Si vous remarquez une fuite de lumière ou des reflets dans votre Apple Vision Pro

Il est normal de voir quelques reflets sur les écrans de votre Apple Vision Pro, mais vous pouvez effectuer des ajustements pour optimiser votre expérience.

Pour identifier la cause d’une fuite de lumière ou de reflets dans votre Apple Vision Pro, utilisez-le dans une pièce bien éclairée et dans une pièce faiblement éclairée pour comparer votre expérience.

- Si votre expérience est meilleure dans la pièce faiblement éclairée, c’est que le problème est une fuite de lumière. Pour résoudre ce problème, vous pouvez [ajuster votre Vision Pro](https://support.apple.com/fr-fr/117730) ou [essayer un coussinet de cache anti-lumière plus fin](https://support.apple.com/fr-fr/119999#replace) . Si le problème persiste, [essayez un autre cache anti-lumière](https://support.apple.com/fr-fr/119999#help) . Une légère fuite de lumière autour du nez est normale. Pour un ajustement idéal, le cache anti-lumière doit être en contact avec les côtés de votre visage afin de limiter la fuite de lumière.

- Si votre expérience ne s’améliore pas dans la pièce faiblement éclairée, les reflets que vous pouvez voir dans le système optique sont causés par la lumière provenant de l’écran. C’est un comportement attendu pour les systèmes d’affichage utilisant une lentille. Pour réduire ces reflets, essayez de [visualiser votre contenu dans un environnement virtuel plus lumineux](https://support.apple.com/guide/apple-vision-pro/use-environments-tanb58c3cfaf/visionos) ou allumez les lumières dans votre espace.

Si vous avez encore besoin d’aide avec l’écran de votre Apple Vision Pro, [contactez l’assistance Apple](https://getsupport.apple.com/) .
