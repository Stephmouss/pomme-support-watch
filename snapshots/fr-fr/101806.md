# Création de fichiers multimédias de test pour Final Cut Pro

Découvrez comment créer un fichier multimédia fiable, dont vous pouvez vous servir pour isoler un problème dans Final Cut Pro pour Mac.

Si vous rencontrez un problème dans Final Cut Pro, vous pouvez créer un fichier multimédia fiable qui vous aidera à le résoudre. Appuyez-vous sur un fichier multimédia fiable pour dépanner une vaste gamme de problèmes, notamment les situations dans lesquelles le fichier multimédia ne se lit pas ou ne s’exporte pas comme prévu. Les étapes ci-dessous indiquent comment créer un fichier Apple ProRes 422 à partir de fichiers multimédias inclus avec Final Cut Pro. Ce fichier vous aidera ensuite à isoler votre problème dans Final Cut Pro.

## Installer du contenu supplémentaire

Avant de commencer, assurez-vous d’avoir installé le contenu supplémentaire de Final Cut Pro. Dans Final Cut Pro, sélectionnez Final Cut Pro > Télécharger d’autres contenus, puis cliquez sur « En savoir plus » dans Mise à jour de logiciels. Si le contenu supplémentaire de Final Cut Pro s’affiche dans la fenêtre, sélectionnez-le, puis cliquez sur Installer.

## Ajouter un repère d’emplacement

- Ouvrez Final Cut Pro.

- Choisissez Fichier > Nouveau > Bibliothèque.

- Saisissez le nom « Bibliothèque test », appuyez sur Commande + Maj + D, puis cliquez sur Enregistrer pour enregistrer la bibliothèque sur le bureau.

- Choisissez Fichier > Nouveau > Projet. Si le bouton situé en bas à droite de la boîte de dialogue s’intitule « Utiliser les réglages automatiques », cliquez dessus de manière à afficher le bouton « Utiliser les réglages personnalisés » à la place.

- Nommez le projet « Média test », puis cliquez sur OK.

- Choisissez Édition > Insérer Générateur > Repère d’emplacement, ou appuyez sur Commande + Option + W. Cliquez sur OK dans la fenêtre Propriétés vidéo. Le repère d’emplacement apparaît dans la timeline. Appuyez sur Maj + Z pour effectuer un zoom sur le repère d’emplacement et adapter sa taille à celle de la timeline.

## Ajouter un effet sonore

- Cliquez sur le bouton Photos et audio situé dans l’angle supérieur gauche de la fenêtre de Final Cut Pro.

- Cliquez sur Effets sonores.

- Saisissez « croissant » dans le champ de recherche situé au-dessus du navigateur. Un fichier nommé « Croissant » doit s’afficher dans les résultats de recherche.

- Faites glisser le fichier « Croissant » vers la timeline et déposez-le sous le fichier du repère d’emplacement.

- Appuyez sur Maj + Z pour effectuer un zoom sur la timeline.

- Sélectionnez le plan du repère d’emplacement dans la timeline, puis faites glisser la fin du plan de manière à l’aligner sur la fin de l’effet sonore Croissant.

## Exporter un fichier Apple ProRes 422

Une fois que vous avez créé le projet et y avez ajouté du contenu, partagez-le sous forme de fichier Apple ProRes 422 à l’aide de la commande Exporter le fichier.

- Sélectionnez Fichier > Partager > Exporter le fichier, cliquez sur Réglages, puis configurez les réglages de destination comme suit :

- Format : Vidéo et audio

- Codec vidéo : Apple ProRes 422

- Résolution : 1920 x 1080

- Format de fichier audio : PCM linéaire (film QuickTime)

- Activez l’option « Inclure les marqueurs de chapitre ».

- Action : Enregistrer uniquement.

- Cliquez sur Suivant.

- Saisissez le nom « Média test », appuyez sur Commande + Maj + D, puis cliquez sur Enregistrer pour enregistrer le fichier sur le bureau.

- Lorsque le message Partage réussi apparaît, cliquez sur Fermer.

## Utiliser le fichier multimédia de test

Pour tester Final Cut Pro à l’aide du fichier multimédia de test, [créez une bibliothèque](https://support.apple.com/guide/final-cut-pro/vera0e150af2/mac) et [create a new project](https://support.apple.com/guide/final-cut-pro/verdb79783e/mac) Ensuite, [importez le fichier multimédia de test dans le nouveau projet](https://support.apple.com/guide/final-cut-pro/ver418155a4/mac) . Essayez de reproduire le problème. Si le problème ne survient pas avec le fichier multimédia de test, il est possible que le dysfonctionnement provienne des fichiers multimédias du projet concerné. Si le problème persiste, vous devrez appliquer d’ [autres procédures afin d’isoler et de résoudre votre problème](https://support.apple.com/HT203477) .
