# Utiliser les touches de fonction sur un MacBook Pro avec Touch Bar

Maintenez la touche Fn (Fonction) enfoncée pour afficher les touches F1 à F12 dans la Touch Bar.

## Afficher les touches de fonction

Maintenez la touche Fn (Fonction) de votre clavier enfoncée pour afficher les touches F1 à F12 dans la [Touch Bar](https://support.apple.com/guide/mac-help/use-the-touch-bar-mchlbfd5b039/mac) .

Vous pouvez également configurer l’affichage automatique des touches de fonction lors de l’utilisation d’apps spécifiques :

- Choisissez le menu Pomme  > Réglages Système (ou Préférences Système), puis cliquez sur Clavier.

- Si vous utilisez MacOS Ventura ou une version ultérieure, cliquez sur Raccourcis clavier, puis sélectionnez Touches de fonction dans la liste de gauche.

- Si vous utilisez MacOS Monterey ou une version antérieure, cliquez sur Raccourcis en haut de la fenêtre, puis sélectionnez Touches de fonction dans la liste à gauche.

- Cliquez sur le bouton ajouter (+), puis sélectionnez une app dans la boîte de dialogue qui s'ouvre. Les touches de fonction apparaîtront automatiquement dans la Touch Bar chaque fois que vous utiliserez l’une des apps ajoutées dans cette fenêtre.

### Utiliser le clavier visuel

Au lieu d’afficher les touches de fonction dans la Touch Bar, vous pouvez utiliser les touches de fonction du clavier visuel.

- Choisissez le menu Pomme  > Réglages Système (ou Préférences Système), puis cliquez sur Clavier et effectuez l’une des étapes suivantes :

- Si vous utilisez macOS Ventura ou une version ultérieure, cliquez sur Modifier à côté de Sources d'entrée, puis sélectionnez « Afficher le menu d'entrée dans la barre de menus ».

- Si vous utilisez macOS Monterey ou Big Sur, sélectionnez « Afficher le menu de saisie dans la barre des menus » dans la sous-fenêtre Méthodes de saisie.

- Si vous utilisez macOS Catalina ou une version antérieure, sélectionnez « Afficher les visualiseurs de clavier et d’Emoji dans la barre des menus ».

- Cliquez sur l’icône du visualiseur dans la barre des menus, puis sélectionnez Afficher le visualiseur de clavier.

[Image: Capture d’écran de la barre des menus de macOS affichant le menu « Méthodes de saisie », avec en surbrillance l’option « Afficher le visualiseur de clavier », utilisée pour activer la fonction de clavier visuel]

- Cliquez sur la touche Fn du clavier visuel pour afficher toutes les touches de fonction.

## Afficher les touches de fonction lors de l’utilisation de Microsoft Windows

Maintenez la touche Fn (Fonction) de votre clavier enfoncée pour afficher les touches F1 à F12 dans la [Touch Bar](https://support.apple.com/HT207055) .

Vous pouvez également configurer les touches de fonction pour qu’elles s’affichent en permanence dans la Touch Bar :

- Dans la zone de notification à droite de la barre des tâches de Windows, cliquez sur la flèche orientée le haut pour afficher les icônes masquées.

- Cliquez sur l’ icône Boot Camp , puis choisissez Panneau de configuration Boot Camp dans le menu.

[Image: Panneau de configuration Boot Camp dans Windows 10.]

- Si un message vous demande si vous autorisez cette app à apporter des modifications, cliquez sur Oui.

- Cliquez sur l’onglet Clavier.

- Sélectionnez « Utiliser les touches F1, F2 et ainsi de suite, comme des touches de fonction standard ».

### Utiliser le clavier visuel

Au lieu d’afficher les touches de fonction dans la Touch Bar, vous pouvez utiliser le clavier visuel :

- Dans le menu Windows, sélectionnez Options d’ergonomie.

- Cliquez sur Clavier visuel.

- Cliquez sur la touche Fn du clavier visuel pour afficher toutes les touches de fonction.

[En savoir plus sur le clavier visuel sous Windows](https://support.microsoft.com/fr-fr/help/10762/windows-use-on-screen-keyboard) .
