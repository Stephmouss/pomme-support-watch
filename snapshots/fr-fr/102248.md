# Modifier le nom de votre Apple Watch

Renommez votre Apple Watch pour la reconnaître plus aisément.

## Comment modifier le nom de votre Apple Watch

- Sur votre appareil iOS, ouvrez l’app Apple Watch et touchez l’onglet Ma montre.

- Accédez à Général > Informations.

- Touchez la première ligne, qui contient le nom de votre appareil.

- Renommez votre appareil, puis touchez Terminé sur le clavier.
