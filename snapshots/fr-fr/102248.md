# Modifier le nom de votre Apple Watch

Renommez votre Apple Watch pour la reconnaître plus aisément.

## Comment modifier le nom de votre Apple Watch

- Sur votre iPhone, ouvrez l’app Apple Watch et touchez l’onglet Ma montre.

- Accédez à Général, puis touchez Informations.

- Touchez la première ligne, qui affiche le nom actuel de votre appareil.

- Renommez votre appareil, puis touchez le bouton Terminé sur le clavier.
