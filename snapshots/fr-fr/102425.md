# S’il vous est demandé de confirmer votre compte Apple lorsque vous contactez Apple

Lorsque vous contactez l’assistance Apple, il peut vous être demandé de confirmer votre compte Apple pour des raisons de sécurité.

Si vous contactez Apple, il peut vous être demandé de confirmer votre compte Apple de l’une des manières suivantes :

- Recevoir et confirmer une notification de confirmation de votre compte Apple, envoyée directement sur votre appareil.

- Générer un code PIN d’assistance temporaire sur votre appareil.

La confirmation de votre compte Apple permet à Apple d’accéder aux numéros de série de votre appareil et à certaines informations associées à votre compte Apple, afin que nous puissions vous aider plus rapidement.

Apple ne vous demandera jamais le mot de passe de votre compte Apple, vos codes de validation, votre clé de récupération, ni les informations de sécurité de votre compte.

## Recevoir une notification de confirmation de votre compte Apple

Apple peut envoyer une notification à l’appareil qui est associé à ce compte Apple :

- Touchez simplement Confirmer pour confirmer votre compte Apple sur l’appareil.

[Image: Touchez la notification pour confirmer votre compte Apple.]

- Si votre appareil n’est pas protégé par un code d’accès, vous devrez peut-être également saisir le mot de passe de votre compte Apple.

- Un message est également envoyé à l’adresse e-mail principale associée à votre compte Apple, que celui-ci ait été confirmé ou non.

Si vous recevez une notification de confirmation de votre compte Apple, mais que vous n’avez pas demandé à obtenir d’assistance auprès d’Apple, touchez Ne pas confirmer.

## Générer un code PIN d’assistance temporaire

Vous pouvez également générer un code PIN d’assistance temporaire pour confirmer votre compte Apple.

- Connectez-vous sur [account.apple.com](https://account.apple.com) .

- Si cela vous est demandé, saisissez le code de validation envoyé à votre appareil de confiance.

- Faites défiler l’écran jusqu’en bas et touchez Code PIN d’assistance. Touchez ensuite Générer un code PIN.

[Image: Touchez Code PIN d’assistance pour générer un code PIN d’assistance.]

- Lorsqu’Apple vous demande votre code PIN d’assistance, indiquez le numéro à quatre chiffres.

Votre code PIN est instantanément généré et s’affiche dans une fenêtre contextuelle indiquant également l’heure d’expiration du code. Les codes PIN que vous générez ne sont utilisables qu’une seule fois.

Selon la manière dont vous avez créé votre compte Apple, vous pourrez peut-être générer un code PIN d’assistance sans saisir de code de validation (par exemple, en répondant aux questions de sécurité).
