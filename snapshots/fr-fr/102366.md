# Partager sur une plateforme sociale depuis les apps vidéo Apple

Pour partager des vidéos réalisées avec les apps vidéo Apple sur iPhone, iPad ou Mac sur des plateformes sociales comme YouTube, Facebook et Vimeo, exportez la vidéo à l’aide du réglage Plateformes sociales dans l’app en question, puis chargez la vidéo à l’aide du site web ou de l’app de la plateforme sociale.

[Clips](https://support.apple.com/fr-fr/102366#clips)

[iMovie](https://support.apple.com/fr-fr/102366#imovie)

[Final Cut Pro pour Mac](https://support.apple.com/fr-fr/102366#fcp)

[Final Cut Pro pour iPad](https://support.apple.com/fr-fr/102366#fcp_iPad)

[Compressor](https://support.apple.com/fr-fr/102366#compressor)

[Motion](https://support.apple.com/fr-fr/102366#Motion)

## Partager sur une plateforme sociale à partir de Clips

- Si la vidéo que vous souhaitez partager n’est pas ouverte, touchez le bouton Projets dans l’angle supérieur gauche, puis choisissez un projet.

[Image: Aucun texte de remplacement pour l’image]

- Touchez le bouton Partager .

[Image: Aucun texte de remplacement pour l’image]

- Pour modifier les proportions, l’orientation et d’autres options avancées du projet, touchez Options, sélectionnez les options de votre choix, assurez-vous que l’option Vidéo est sélectionnée, puis touchez OK pour appliquer les nouveaux réglages.

- Touchez Enregistrer la vidéo pour enregistrer la vidéo finale dans la [photothèque sur votre iPhone ou iPad](https://support.apple.com/fr-fr/102366#learn) . Si [vous utilisez Photos iCloud](https://support.apple.com/fr-fr/108782) , vous pouvez également accéder à la vidéo depuis vos autres appareils Apple.

- Ouvrez l’app de la plateforme sociale sur votre appareil, connectez-vous à votre compte, puis chargez votre vidéo.

## Partager sur une plateforme sociale à partir d’iMovie

Suivez les étapes ci-dessous pour partager sur une plateforme sociale des vidéos réalisées avec iMovie sur votre iPhone, iPad ou Mac.

### Partager des vidéos d’iMovie sur votre iPhone ou iPad

- Dans le navigateur Projets d’iMovie, touchez le projet que vous souhaitez partager, touchez le bouton Partager , puis touchez Enregistrer ou partager la vidéo.

[Image: Aucun texte de remplacement pour l’image]

- Pour modifier la résolution et activer ou désactiver le HDR pour la vidéo exportée, touchez Options, sélectionnez les options de votre choix, puis touchez OK pour appliquer les nouveaux réglages.

- Touchez Enregistrer la vidéo pour enregistrer la vidéo finale dans la [photothèque sur votre iPhone ou iPad](https://support.apple.com/fr-fr/102366#learn) . Si [vous utilisez Photos iCloud](https://support.apple.com/fr-fr/108782) , vous pouvez également accéder à la vidéo depuis vos autres appareils Apple.

- Ouvrez l’app de la plateforme sociale sur votre appareil, connectez-vous à votre compte, puis chargez votre vidéo.

### Partager des vidéos d’iMovie sur votre Mac

- Une fois votre projet ouvert dans iMovie, cliquez sur le bouton Partager .

[Image: Aucun texte de remplacement pour l’image]

- Cliquez sur Plateformes sociales.

- Modifiez le titre et la description de votre vidéo, et ajoutez des balises.

- Cliquez sur le menu local Résolution et choisissez une taille pour votre vidéo.

- Choisissez un emplacement pour enregistrer le fichier vidéo, puis cliquez sur Enregistrer.

- À l’aide de Safari ou d’un autre navigateur web, connectez-vous à la plateforme sociale, puis chargez le fichier vidéo.

## Partager sur une plateforme sociale à partir de Final Cut Pro sur Mac

- Sélectionnez votre projet dans le navigateur Final Cut Pro, cliquez sur le bouton Partager , puis sélectionnez [Plateformes sociales](https://support.apple.com/guide/final-cut-pro/ver1d41f8374/mac) .

[Image: Aucun texte de remplacement pour l’image]

- Effectuez les étapes ci-dessous dans la fenêtre Partager :

- Cliquez sur Informations pour modifier le nom du plan, sa description et d’autres éléments.

- Cliquez sur Réglages pour choisir les paramètres de résolution, de compression et de sous-titrage.

- Cliquez sur Suivant, choisissez un emplacement pour enregistrer le fichier vidéo, puis cliquez sur Enregistrer.

- À l’aide de Safari ou d’un autre navigateur web, connectez-vous à la plateforme sociale, puis chargez le fichier vidéo.

## Partager sur une plateforme sociale à partir de Final Cut Pro pour iPad

- Pour un projet SDR Final Cut Pro pour iPad ou tout autre projet que vous souhaitez charger sur des sites de partage de vidéos, sélectionnez [l’option Plateformes sociales](https://support.apple.com/guide/final-cut-pro-ipad/dev8ce20673a/ipados) dans le menu local Préréglages lors du partage. L’option Plateformes sociales exporte la vidéo en utilisant le codec H.264, ce qui permet de réduire la taille de fichier et d’optimiser la compatibilité avec le maximum d’appareils.

- Pour un projet HDR que vous souhaitez charger sur une plateforme sociale, sélectionnez l’option Par défaut dans le menu local Préréglages.

[En savoir plus sur le partage de projets Final Cut Pro pour iPad](https://support.apple.com/guide/final-cut-pro-ipad/dev8ce20673a/ipados#deve546bd60a)

## Partager sur une plateforme sociale à partir de Compressor

- Dans Compressor, cliquez sur « Ajouter un fichier » dans la zone du lot, sélectionnez le fichier source à partager, puis cliquez sur Ajouter.

- Dans la fenêtre des réglages qui s’ouvre, sélectionnez [le triangle d’expansion Plateformes sociales](https://support.apple.com/guide/compressor/cpsr4c5ffdc9/mac) , choisissez la résolution du fichier, choisissez l’emplacement où vous souhaitez enregistrer le fichier transcodé, puis cliquez sur OK.

- Si le fichier source se trouve déjà dans la zone du lot, vous pouvez faire glisser un réglage de résolution Plateformes sociales situé dans la sous-fenêtre Préréglages sur le fichier source situé dans la zone du lot.

- Cliquez sur Lancer le lot.

- À l’aide de Safari ou d’un autre navigateur web, connectez-vous à la plateforme sociale, puis chargez le fichier vidéo.

## Partager sur une plateforme sociale à partir de Motion

- Une fois votre projet ouvert dans Motion, cliquez sur le bouton Partager , puis choisissez Exporter le film, Exporter en séquence ou Exporter l’audio.

[Image: null]

- Dans la fenêtre Exporter, cliquez sur Informations pour changer le nom du fichier, sa description et d’autres éléments.

- Cliquez sur Réglages, cliquez sur le menu local Format, puis choisissez Plateformes sociales. Vous pouvez également sélectionner la résolution, l’espace colorimétrique, les canaux de couleur et d’autres éléments de votre choix pour le fichier exporté.

- Cliquez sur Rendu pour définir la qualité de rendu ou pour ajouter un flou d’animation, une fusion d’images, un éclairage, des ombres, etc.

- Cliquez sur Suivant, choisissez l’emplacement où vous souhaitez enregistrer le fichier, puis cliquez sur Enregistrer.

- À l’aide de Safari ou d’un autre navigateur web, connectez-vous à la plateforme sociale, puis chargez le fichier vidéo.
