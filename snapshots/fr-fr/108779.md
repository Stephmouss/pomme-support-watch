# Gestion des données de l’app Santé sur votre iPhone, iPad ou Apple Watch

Configurez des apps et des accessoires de façon à ce qu’ils envoient des données à l’app Santé, ajoutez ou supprimez manuellement des données, et ajustez la façon dont l’app Santé hiérarchise les sources de données.

## À propos des données de santé

L’app Santé comptabilise automatiquement vos pas et les distances que vous parcourez en marchant et en courant. Si vous avez une Apple Watch jumelée, elle peut suivre automatiquement votre activité, vos données de fréquence cardiaque et vos données de l’app Pleine conscience. Vous pouvez également ajouter manuellement des données à partir d’autres applications de santé pour conserver vos informations au seul endroit.

En savoir plus sur les [données de santé suivies sur iPhone et Apple Watch](https://support.apple.com/com/guide/iphone/iphbb8259c61) .

## Comment ajouter manuellement des données de santé

- Ouvrez l’app Santé sur votre iPhone ou iPad.

- Sur votre iPhone, touchez l’onglet Parcourir. Si vous êtes sur votre iPad, touchez le bouton Barre latérale pour ouvrir la barre latérale.

- Touchez une catégorie, comme Activité, puis touchez une sous-catégorie, comme Nombre de pas.

- Touchez le bouton Ajouter des données dans le coin supérieur.

- Saisissez la date, l’heure et les données correspondant à cette activité.

- Lorsque vous avez terminé, touchez le bouton Terminé .

[Image: Un iPhone qui affiche les données d’étape saisies manuellement pour une date et une heure spécifiques.]

### Ajouter des données d’autres applications

- Ouvrez l’app Santé sur votre iPhone ou iPad.

- Touchez le bouton Profil dans le coin supérieur.

- Sous Confidentialité, touchez Apps pour voir vos apps compatibles avec Santé. Si une app ne s’affiche pas, il se peut qu’elle ne soit pas compatible.

- Touchez une app et activez les catégories de santé que vous souhaitez suivre à l’aide de l’app.

Vous devrez peut-être ouvrir l’app et en ajuster les réglages pour autoriser le partage de données avec l’app Santé.

## Si l’app Santé n’affiche pas votre nombre de pas ou d’autres informations

Assurez-vous d’avoir activé Suivi forme pour votre Apple Watch.

- Ouvrez l’app Santé sur votre iPhone ou iPad.

- Touchez le bouton Profil , puis touchez Appareils.

- Touchez votre Apple Watch.

- Touchez Réglages de confidentialité et activez le Suivi forme.

[Image: Un écran d’iPhone affichant les réglages de confidentialité de l’Apple Watch avec Suivi forme activé.]

## Supprimer les données de santé que vous avez saisies

Si vous avez saisi des informations incorrectes lors de l’ajout manuel d’informations de santé, vous pouvez supprimer le dossier.

- Ouvrez l’app Santé sur votre iPhone ou iPad.

- Sur votre iPhone, touchez l’onglet Parcourir. Si vous êtes sur votre iPad, touchez le bouton Barre latérale pour ouvrir la barre latérale.

- Touchez une catégorie, comme Activité, puis touchez une sous-catégorie, comme Nombre de pas.

- Faites défiler l’écran jusqu’à afficher Options, puis touchez Afficher toutes les données.

- Touchez Modifier dans l’angle supérieur.

- Touchez le bouton Supprimer à côté du dossier que vous souhaitez supprimer. Vous pouvez également toucher Tout supprimer pour supprimer tous les dossiers.

- Touchez OK.

## Supprimer les données de santé d’iCloud

Les informations de santé sont chiffrées lorsqu’elles sont stockées dans iCloud et lors de leur transfert entre iCloud et votre appareil. Le chiffrement de bout en bout requiert iOS 12 ou version ultérieure ainsi que l’identification à deux facteurs. Vous pouvez interrompre le stockage et supprimer vos données de santé d’iCloud.

- Ouvrez l’app Réglages sur votre iPhone ou iPad.

- Touchez [votre nom], puis iCloud.

- En regard de Enregistré sur iCloud, touchez Tout voir, puis touchez Santé.

- Désactivez Synchroniser cet iPhone.

- Touchez Gérer le stockage, puis touchez Supprimer les données d’iCloud.

- Touchez Désactiver et supprimer.

Si vos données de santé sont synchronisées sur iCloud, les données supprimées sur un appareil sont supprimées de tous les appareils synchronisés connectés au même compte iCloud.

## Gestion par l’app Santé de données provenant de plusieurs sources

L’app Santé accepte des données similaires provenant de plusieurs sources et les organise en fonction de leur provenance. Par défaut, l’app Santé utilise l’ordre de priorité suivant :

- Données de santé que vous saisissez manuellement.

- Données provenant de votre iPhone, iPad et Apple Watch.

- Données provenant d’apps et [d’appareils Bluetooth](https://support.apple.com/fr-fr/105108) .

Lorsque vous ajoutez une nouvelle source de données, celle-ci s’affiche au-dessus de toutes les apps et de tous les appareils qui communiquent des données à l’app Santé. Vous pouvez modifier l’ordre des sources à tout moment.

### Afficher et hiérarchiser vos sources de données

Vous pouvez vérifier quels appareils et applications mettent à jour des catégories de santé spécifiques et choisir les sources que l’app Santé utilise en premier.

- Ouvrez l’app Santé sur votre iPhone ou iPad.

- Sur votre iPhone, touchez l’onglet Parcourir. Si vous êtes sur votre iPad, touchez le bouton Barre latérale pour ouvrir la barre latérale.

- Touchez une catégorie, puis une sous-catégorie.

- Faites défiler l’écran vers le bas, puis touchez Sources de données et accès. Seules les sources qui contribuent à ce type de données s’affichent.

- Touchez Modifier.

- Touchez et maintenez le bouton Modifier l’ordre à côté d’une source de données, puis faites-le glisser vers le haut ou le bas dans la liste.

[Image: Un iPhone affichant l’écran Sources de données et accès où les sources de données peuvent être réorganisées.]

- Pour désactiver une source de données tierce, touchez la coche à côté de la source.

- Touchez le bouton Terminé .

Si plusieurs sources contribuent au même type de données, la source de données affichée en haut de la liste sera prioritaire sur les autres sources. Les nouvelles apps et nouveaux appareils que vous ajoutez sont automatiquement répertoriés en haut, au-dessus de votre iPhone ou iPad.

Les informations que vous créez ou recueillez sur vous-même sont [sous votre contrôle](https://support.apple.com/fr-fr/102515) et sont chiffrées avec votre code lorsque vous verrouillez votre iPhone. Lorsque vous supprimez l’app Santé, vos données de santé sont conservées sur votre iPhone. En savoir plus sur la [suppression des apps Apple intégrées de votre appareil](https://support.apple.com/fr-fr/118582) .
