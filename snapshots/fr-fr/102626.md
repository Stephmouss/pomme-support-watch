# Effectuer des achats à l’aide d’Apple Pay

Vous pouvez effectuer des achats à l’aide d’Apple Pay dans les magasins, depuis des apps, sur le Web et plus encore.

## Payer à l’aide d’Apple Pay dans les magasins et à d’autres endroits

Vous pouvez utiliser Apple Pay avec votre iPhone ou Apple Watch dans les magasins, les restaurants, les stations-service, les taxis et tout autre endroit où les [symboles de paiement sans contact appropriés](https://support.apple.com/120364) [apparaissent.](https://support.apple.com/120364) Si vous avez des questions, contactez le commerce ou l’émetteur de la carte.

### Paiement à l’aide de votre iPhone

- Pour utiliser votre carte par défaut :

- Si votre iPhone est doté de Face ID, appuyez deux fois sur le bouton latéral. Si vous y êtes invité, authentifiez-vous avec Face ID ou saisissez votre code d’accès pour ouvrir l’app Cartes d’Apple.

- Si votre iPhone est doté de Touch ID, appuyez deux fois sur le bouton principal.

- Pour utiliser une carte différente, touchez votre carte par défaut afin d’afficher les autres. Sélectionnez ensuite la carte adéquate, puis authentifiez-vous.

- Maintenez le haut de votre iPhone à proximité du lecteur sans contact, jusqu’à ce qu’une coche et la mention OK apparaissent sur l’écran.

[Image: Une carte de débit sur iPhone.]

Dans certains magasins, vous pouvez [utiliser Tap to Share pour finaliser votre achat](http://support.apple.com/127868) . Au moment du paiement, approchez votre iPhone du terminal de paiement. Ensuite, suivez les instructions qui s’affichent pour finaliser votre achat avec Apple Pay.

### Paiement à l’aide de votre Apple Watch

- Appuyez deux fois sur le bouton latéral.

- Votre carte par défaut s’affiche automatiquement. Faites défiler vers le bas pour en sélectionner une autre.

- Maintenez l’écran de votre Apple Watch à proximité du lecteur sans contact, jusqu’à ce que vous ressentiez une légère vibration et entendiez un bip.

[Image: Une carte de débit sur l’Apple Watch.]

Pour consulter vos achats récents, [consultez l’historique de vos transactions Apple Pay](https://support.apple.com/104954) .

## Comment utiliser Apple Pay en ligne ou dans des apps

Vous pouvez utiliser Apple Pay pour effectuer des achats en ligne ou depuis des apps, si cette option de paiement est proposée. 1,2

- Touchez le bouton Apple Pay ou choisissez Apple Pay comme mode de paiement.

- Pour utiliser un mode de paiement différent de votre carte par défaut, touchez Autres cartes et options de paiement différé ou Changer de mode de paiement. Vous pouvez également toucher votre carte par défaut et balayer l’écran pour afficher vos autres cartes.

- Si nécessaire, saisissez vos coordonnées et vos informations de facturation et d’expédition.

- Confirmez le paiement.

- iPhone ou iPad doté de Face ID : appuyez deux fois sur le bouton latéral, puis utilisez Face ID ou votre code d’accès.

- iPhone ou iPad sans Face ID : utilisez Touch ID ou votre code d’accès.

- Apple Vision Pro : utilisez Optic ID ou votre code d’accès.

- Apple Watch : appuyez deux fois sur le bouton latéral.

- Mac avec Touch ID : placez votre doigt sur Touch ID.

- Mac non doté de Touch ID : confirmez le paiement sur votre iPhone ou Apple Watch connecté(e) via le Bluetooth. Assurez-vous que vous êtes connecté avec le même compte Apple sur tous les appareils.

- Une fois le paiement effectué, la mention OK et une coche s’affichent à l’écran.

Découvrez comment [payer avec des récompenses](http://support.apple.com/120479) . Vous pouvez également [effectuer des achats par versements échelonnés](http://support.apple.com/120477) .

### Comment utiliser Apple Pay en scannant un code

Vous pouvez utiliser Apple Pay à partir de navigateurs tiers et d’autres emplacements sur un Mac, un PC ou d’autres appareils en scannant un code avec votre iPhone ou iPad. 3

- Touchez le bouton Apple Pay ou choisissez Apple Pay comme mode de paiement. Un code s’affiche à l’écran.

- Scannez ce code à l’aide de la caméra de votre iPhone ou iPad.

- Si nécessaire, saisissez vos coordonnées et vos informations de facturation et d’expédition.

- Confirmez le paiement.

- iPhone ou iPad doté de Face ID : appuyez deux fois sur le bouton latéral, puis utilisez Face ID ou votre code d’accès.

- iPhone ou iPad sans Face ID : utilisez Touch ID ou votre code d’accès.

- Une fois le paiement effectué, la mention OK et une coche s’affichent à l’écran.

- En Chine continentale, vous pouvez utiliser Apple Pay sur le Web dans Safari uniquement sur un iPhone ou iPad compatible doté de [la dernière version d’iOS ou iPadOS](https://support.apple.com/118575) . En Chine continentale, Apple Pay ne peut pas être utilisé avec un navigateur tiers.

- En Italie, vous pouvez utiliser votre iPhone et votre Apple Watch pour effectuer des achats à l’aide d’Apple Pay dans des magasins avec votre carte Maestro. Les cartes Maestro ne sont pas utilisables depuis des apps ou sur le Web. Aux Pays-Bas, vous pouvez ajouter des cartes Maestro sur tous les [appareils compatibles](https://support.apple.com/102896) , à l’exception des ordinateurs Mac.

- Apple Pay dans plus de navigateurs : disponible auprès des commerces participants sur les navigateurs et appareils compatibles. Cette fonctionnalité n’est pas disponible sur tous les marchés. Des exigences logicielles s’appliquent.

Pour utiliser Apple Pay, vous devez posséder une carte prise en charge délivrée par un établissement émetteur partenaire. Pour vérifier si votre carte est compatible avec Apple Pay, contactez l’établissement qui l’a émise. Apple Pay n’est pas disponible sur tous les marchés. [Consultez la liste des pays et régions où Apple Pay est disponible](https://www.apple.com/fr/ios/feature-availability/#apple-pay) .
