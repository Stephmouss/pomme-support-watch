# Comment se connecter automatiquement à un compte d’utilisateur Mac

Lorsque l’ouverture de session automatique est activée pour un compte d’utilisateur macOS, le Mac se connecte automatiquement à ce compte pendant le démarrage.

## Choisir le compte qui se connectera automatiquement

Suivez les étapes correspondant à la [version de macOS que vous utilisez](https://support.apple.com/fr-fr/109033) . Qu’un compte se connecte automatiquement ou non, vous devrez peut-être vous connecter manuellement suite à une fermeture de session, à une permutation sur un autre compte ou au verrouillage de votre écran.

### macOS Ventura 13 ou version ultérieure

- Dans le menu Apple , choisissez Réglages Système.

- Cliquez sur Utilisateurs et groupes dans la barre latérale, puis choisissez un compte dans le menu « Se connecter automatiquement en tant que ». [Le réglage est-il grisé ?](https://support.apple.com/fr-fr/102316#dimmed)

- Entrez le mot de passe du compte.

### Versions antérieures de macOS

- Dans le menu Pomme , choisissez Préférences Système.

- Cliquez sur Utilisateurs et groupes, cliquez sur le cadenas , puis saisissez le mot de passe de votre compte.

- Cliquez sur Options de connexion dans l’angle inférieur gauche.

- Choisissez un compte dans le menu « Connexion automatique ». [Le réglage est-il grisé ?](https://support.apple.com/fr-fr/102316#dimmed)

- Entrez le mot de passe du compte.

## Si le réglage est grisé ou indisponible

Si le réglage de connexion automatique est grisé ou n’affiche pas le nom du compte, une connexion manuelle est requise. Par exemple, une connexion manuelle est requise dans ces circonstances :

- [FileVault](https://support.apple.com/com/guide/mac-help/mh11785/mac) est activé.

- Votre Mac est supervisé par votre organisation à l’aide d’un profil qui interdit la connexion automatique.

- Le compte est configuré pour utiliser le mot de passe d’un compte Apple pour ouvrir une session. Dans ce cas, le message « Un utilisateur dont le dossier de départ est chiffré ne peut pas ouvrir de session automatiquement » peut également s’afficher. [Découvrez comment modifier le mot de passe d’ouverture de session](https://support.apple.com/guide/mac-help/mchlp1550/mac) .

## Se connecter après une veille ou après le lancement de l’économiseur d’écran

Il se peut que vous deviez toujours saisir votre mot de passe lorsque votre Mac sort de veille ou cesse d’utiliser l’économiseur d’écran. Vous pouvez modifier ce comportement comme suit :

- macOS Ventura 13 ou version ultérieure : choisissez Réglages Système dans le menu Pomme , puis cliquez sur Écran verrouillé dans la barre latérale. Sélectionnez l’option souhaitée pour « Exiger un mot de passe après le lancement de l’économiseur d’écran ou l’extinction de l’écran ». Ce réglage ne peut pas être modifié si la [recopie de l’iPhone](https://support.apple.com/fr-fr/120421) est configurée pour s’authentifier automatiquement.

- Versions antérieures de macOS : sélectionnez Préférences Système dans le menu Pomme , puis cliquez sur Sécurité et confidentialité. Sélectionnez l’option souhaitée pour « Exiger un mot de passe après la suspension d’activité ou l’activation de l’économiseur d’écran ».
