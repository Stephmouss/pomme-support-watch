# Si vous êtes invité à confirmer votre numéro de téléphone lors de l’activation de votre iPhone aux États-Unis

Lors de la première activation de votre iPhone aux États-Unis, celui-ci peut vous demander de confirmer votre numéro de téléphone. Cet article vous indique la marche à suivre.

Pour confirmer votre numéro, saisissez les informations du compte que vous avez utilisées lors de l’achat de l’iPhone. Procédez comme suit :

- Assurez-vous que le numéro de téléphone est celui que vous avez utilisé au moment de l’achat de l’iPhone. Ensuite, touchez Suivant.

[Image: Cet écran d’activation s’affiche pour que vous puissiez confirmer votre numéro de téléphone lorsque vous configurez votre iPhone pour la première fois.]

- Saisissez votre code postal de facturation et les quatre derniers chiffres de votre numéro de sécurité sociale. Ensuite, touchez Suivant.

[Image: Pour finaliser l’activation de votre nouvel iPhone, vous devez confirmer votre identité en saisissant un code postal de facturation et un numéro de sécurité sociale.]

Si un message indique que les informations saisies sont incorrectes, saisissez-les à nouveau. Si vous avez toujours besoin d’aide, [contactez Apple](https://getsupport.apple.com/?caller=kbase) .

Terminez la configuration de votre iPhone. Si vous souhaitez utiliser un autre numéro de téléphone par la suite, comme un numéro associé à un forfait familial, [contactez votre opérateur](https://support.apple.com/HT1937) . Selon votre opérateur et votre modèle d’iPhone, vous devrez peut-être obtenir une nouvelle carte SIM ou [eSIM](http://support.apple.com/HT212780) .

Vous pouvez modifier votre compte entre le moment où vous passez la commande et celui où vous terminez ce processus. Si tel est le cas, vous devrez éventuellement [contacter votre opérateur](https://support.apple.com/HT1937) pour activer entièrement votre téléphone.

## Si le numéro de téléphone n’est pas le vôtre

Si vous êtes l’acheteur d’origine de l’iPhone et que le numéro de téléphone que votre appareil vous demande de confirmer n’est pas le vôtre, [contactez l’assistance Apple](https://getsupport.apple.com/?caller=kbase&) pour obtenir de l’aide.
