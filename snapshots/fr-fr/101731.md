# GarageBand pour iOS : impossible de partager sur SoundCloud

Vous risquez de ne pas pouvoir partager une chanson sur SoundCloud lorsque vous utilisez la fonction Se connecter à Facebook. Il est possible que le message suivant s’affiche « Safari ne peut ouvrir la page car l’adresse n’est pas valide. ».

Ce problème est résolu dans GarageBand pour iOS 1.2.1. Mettez à jour GarageBand pour iOS vers la dernière version en touchant App Store sur votre appareil, puis Mises à jour.
