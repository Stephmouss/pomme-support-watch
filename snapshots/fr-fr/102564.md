# Si Safari ne fonctionne pas comme prévu sur Mac

Si Safari ne charge pas une page web correctement, cesse de répondre, se ferme de manière inattendue ou ne fonctionne pas comme prévu, ces solutions pourraient vous aider.

## À propos de ces solutions

Les solutions de cette page permettent de corriger le fonctionnement de Safari sur Mac, notamment pour les problèmes suivants :

- Une page web est vide, ne charge pas l’intégralité du contenu ou ne fonctionne pas comme prévu.

- Vous ne pouvez pas vous connecter à une page web, même si les informations de connexion sont correctes.

- Une page web vous demande de supprimer ou de réinitialiser les cookies.

- Safari est lent, se bloque ou se ferme inopinément.

Si vous utilisez un iPhone ou un iPad, découvrez les [solutions applicables à Safari sur iPhone et iPad](https://support.apple.com/fr-fr/102456) .

## Recharger la page

Dans le menu Présentation de Safari, choisissez Recharger la page. Ou appuyez sur Commande + R.

Si Safari ne recharge pas la page, quittez Safari, puis réessayez. Si Safari ne se ferme pas, vous pouvez appuyer sur Option + Commande + Échap pour [forcer la fermeture de Safari](https://support.apple.com/fr-fr/102586) .

Si Safari rouvre automatiquement des pages indésirables, quittez Safari, puis ouvrez Safari tout en maintenant la touche Maj enfoncée. [Apprenez à contrôler quelles fenêtres Safari rouvre automatiquement](https://support.apple.com/fr-fr/102192) .

## Installez les mises à jour logicielles et redémarrez

Safari est inclus avec macOS. Si une version ultérieure de Safari est disponible pour votre appareil, vous pouvez l'obtenir en suivant les étapes pour [mettre à jour macOS](https://support.apple.com/fr-fr/108382) . Si votre Mac ne redémarre pas automatiquement après la mise à jour, choisissez Redémarrer dans le menu Apple . Certaines [mises à jour en arrière-plan](https://support.apple.com/fr-fr/101591) importantes ne prennent effet qu’après le redémarrage.

## Vérifier les extensions Safari

Si vous avez installé des extensions Safari, désactivez-les. Dans le menu Safari, choisissez Réglages (ou Préférences). Cliquez sur Extensions, puis désélectionnez chaque extension pour la désactiver. [En savoir plus sur les extensions Safari](https://support.apple.com/fr-fr/102343) .

Si une extension est à l’origine du problème, assurez-vous que celle-ci est à jour.

## Vérifier les cookies, caches et autres données

Un site web peut stocker des cookies, des caches et d’autres données sur votre Mac. Des problèmes liés à ces données peuvent affecter votre utilisation du site web. Pour empêcher le site web d’utiliser ces données, affichez-le dans une fenêtre privée : dans le menu Fichier de Safari, choisissez Nouvelle fenêtre privée ou appuyez sur Maj + Commande + N.

Si cette opération fonctionne, suivez les étapes ci-dessous pour supprimer les données du site web, y compris ses caches et cookies. Le site web peut alors créer de nouvelles données si nécessaire. S’il s’agit d’un site web auquel vous vous connectez, assurez-vous de connaître vos informations de connexion avant de continuer.

- Dans le menu Safari, choisissez Réglages (ou Préférences).

- Cliquez sur Confidentialité, puis sur Gérer les données du site web.

- Sélectionnez le site web concerné dans la liste affichée.

- Cliquez sur Supprimer.

- Cliquez sur Terminé.

- Ouvrez à nouveau le site web dans une fenêtre de navigateur non privée.

## Vérifier les réglages de Safari

Il est possible que la page web ne soit pas compatible avec un ou plusieurs réglages du navigateur. Si besoin, vous pouvez désactiver les réglages en question. Dans le menu Safari, choisissez Réglages (ou Préférences). Cliquez ensuite sur Confidentialité, Sécurité, Sites web ou Avancé pour accéder à ces réglages :

- [Réglages Confidentialité](https://support.apple.com/guide/safari/sfri35610/mac) . Ces réglages s’appliquent à tous les sites web. Par exemple, un site web peut exiger l’autorisation du suivi intersite ou l’affichage de votre adresse IP.

- [Réglages Sécurité](https://support.apple.com/guide/safari/ibrw1074/mac/) . Ces réglages s’appliquent à tous les sites web. Par exemple, un site web peut exiger l’activation de JavaScript.

- [Réglages Sites web](https://support.apple.com/guide/safari/ibrwe2159f50/mac) . Ces réglages peuvent être configurés pour certains sites web. Par exemple, un site web peut vous demander de désactiver les bloqueurs de contenu, d’autoriser l’accès à votre caméra ou à votre microphone, d’autoriser les téléchargements ou d’autoriser les fenêtres contextuelles.

- [Réglages Avancés](https://support.apple.com/guide/safari/ibrw1075/mac) . Ces réglages s’appliquent à tous les sites web. Par exemple, un site web peut ne pas s’afficher correctement tant que vous ne réduisez pas les protections de la confidentialité avancées, par exemple en désélectionnant « Utiliser la protection avancée contre le suivi et le vol des empreintes numériques ». Vous devrez peut-être également ne pas bloquer les cookies.

## Vérifier le relais privé iCloud

Si vous vous abonnez à iCloud+ et que vous utilisez la fonctionnalité Relais privé, essayez de recharger la page sans Relais privé : dans le menu Présentation de Safari, sélectionnez Recharger et afficher l’adresse IP. Cet élément de menu n’apparaît que lorsque Relais privé est activé pour votre réseau. [En savoir plus sur le relais privé iCloud](https://support.apple.com/fr-fr/102602) .

## Vérifier le VPN ou un autre logiciel de sécurité

Si vous avez installé un VPN ou un autre logiciel qui surveille vos connexions réseau ou interagit avec celles-ci, ce logiciel peut nuire à votre utilisation du site web ou d’Internet. [En savoir plus sur les problèmes de réseau liés au VPN et à d’autres logiciels](https://support.apple.com/fr-fr/102281) .

## Vérifier les réglages réseau

Certains réglages réseau, tels que ceux concernant l’utilisation de [proxy settings](https://support.apple.com/guide/mac-help/mchlp2591/mac) ou de [réglages DNS](https://support.apple.com/guide/mac-help/mh14127/mac) personnalisés, peuvent affecter l’accès au contenu sur Internet. Même si vous n’avez pas modifié vos réglages réseau, il est possible que vous ayez installé un logiciel qui a modifié ces réglages pour vous.

Pour savoir si le problème est lié aux réglages réseau de votre Mac, essayez d’afficher la page à partir d’un autre navigateur web ou un autre appareil connecté au même réseau. Ou réinitialisez vos réglages réseau en [configurant un nouvel emplacement réseau](https://support.apple.com/fr-fr/105129) sur votre Mac.

Si le problème survient sur d’autres appareils et navigateurs web sur le même réseau, il est probablement lié au site web. Contactez le développeur du site web pour obtenir de l’aide.

## Signaler un problème sur un site web

Si le problème persiste et ne se produit qu’avec un site web en particulier, ou si le site web indique par erreur que Safari est obsolète, signalez le problème au propriétaire ou au développeur du site web.

À partir de Safari 26, vous pouvez également signaler le problème à Apple afin de l’aider à améliorer la compatibilité web. Safari 26 est inclus dans les dernières mises à jour pour macOS Sequoia 15 ou version ultérieure.

- [Recharger la page](https://support.apple.com/fr-fr/102564#reload) .

- Depuis le champ de recherche intelligente en haut de la fenêtre Safari, cliquez sur le bouton Menu de la page , puis choisissez Signaler un problème sur le site web. Cet élément de menu n’apparaît qu’après avoir rechargé la page dans Safari 26 ou version ultérieure.
