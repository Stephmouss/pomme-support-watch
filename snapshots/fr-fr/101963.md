# Si vous ne parvenez pas à graver un DVD ou un disque Blu-ray dans Final Cut Pro

Découvrez la marche à suivre si vous ne parvenez pas à partager des fichiers à partir de Final Cut Pro, Motion ou Compressor sur Mac vers un DVD ou un disque Blu-ray.

## Si une alerte s’affiche lors du partage sur DVD ou disque Blu-ray

Si vous utilisez un lecteur optique externe pour graver vos DVD et disques Blu-ray, une alerte peut s’afficher et la gravure de votre disque peut échouer. Si cela se produit, procédez comme suit :

- Éteignez votre Mac et débranchez tous les câbles USB reliant le lecteur optique à votre Mac. Rebranchez les câbles, rallumez votre Mac et essayez à nouveau de graver le disque.

- Si votre lecteur optique a besoin d’un bloc d’alimentation séparé, vérifiez que le bloc d’alimentation est branché à une source d’alimentation.

- Si votre lecteur utilise deux câbles USB pour la connexion à votre Mac, veillez à brancher les deux câbles. Lorsque le lecteur est utilisé pour lire un disque, un seul câble peut fournir une alimentation électrique suffisante. Cependant, il faut davantage d’énergie pour graver un DVD ou un disque Blu-ray, et il est donc important que les deux câbles soient branchés.

### En cas d’espace disque insuffisant sur votre disque dur

Pour pouvoir graver un disque, le disque dur de votre Mac doit disposer d’un espace suffisant pour accueillir le fichier vidéo. Vérifiez que le disque dur de votre Mac dispose d’un espace suffisant si l’un des cas suivants se produit lors de la gravure :

- Des alertes s’affichent, indiquant : « Une erreur est survenue lors de la gravure de votre disque. Veuillez vérifier si votre volume de démarrage a suffisamment d’espace. » ou « Finalisation : impossible de créer le DVD. Veuillez vérifier si votre volume de démarrage dispose de suffisamment d’espace disque. »

- Le processus de gravure de disque ralentit lorsque le taux d’achèvement se situe entre 57 % et 64 %, et l’application indique qu’il faudra plusieurs heures pour finir de graver le disque.

Si le disque dur de votre Mac dispose de suffisamment d’espace, essayez d’utiliser un autre type de disque. Pour un résultat optimal, préférez l’utilisation d’un disque BD-R ou d’un disque BD-RE vierge. Si vous devez utiliser un disque BD-RE qui contient des données, utilisez le Finder pour effacer le disque.

- Dans le Finder, cliquez sur le disque BD-RE monté tout en maintenant la touche Contrôle enfoncée, puis sélectionnez « Effacer le disque réinscriptible [nom actuel du disque BD-RE]. »

- Lorsque vous y êtes invité, cliquez sur Effacer. Toutes les données enregistrées sur le disque seront perdues.

- Une fois le disque effacé, essayez à nouveau de le graver à partir de Final Cut Pro, Motion ou Compressor.

## Si le partage sur DVD ou disque Blu-ray s’arrête à 66 % d’achèvement dans Final Cut Pro

Si le processus de partage s’arrête à 66 % d’achèvement dans la fenêtre de tâches en arrière-plan de Final Cut Pro, cela peut être ou ne pas être accompagné d’une alerte. En fonction de l’alerte qui s’affiche, ou si aucune ne s’affiche, suivez les procédures de cette section pour graver votre disque.

### Si le message « Impossible d’effectuer l’opération (erreur DSPPublishing error -29) » s’affiche

Si vous utilisez une image pour l’arrière-plan du menu du DVD, cette alerte peut s’afficher si vous avez déplacé le fichier de son emplacement d’origine. Remettez le fichier où il se trouvait lorsque vous l’avez ajouté à votre projet, puis répétez la procédure de partage sur DVD.

Si vous ne vous souvenez pas de l’endroit où se trouvait le fichier à l’origine, ajoutez-le à nouveau en tant qu’image d’arrière-plan du menu.

- Recherchez le fichier que vous souhaitez utiliser en tant qu’image d’arrière-plan du menu.

- Dans Final Cut Pro, choisissez Fichier > Partager > DVD.

- Cliquez sur Réglages.

- Cliquez sur le bouton Supprimer (X) en regard de l’option Arrière-plan pour supprimer l’image d’arrière-plan actuelle du menu.

- Cliquez sur le bouton Ajouter en regard de l’option Arrière-plan.

- Sélectionnez le fichier et cliquez sur Ouvrir.

Si le fichier utilisé pour l’image d’arrière-plan du menu est au format RAW, convertissez-la à un format de fichier tel que JPEG ou TIFF, puis ajoutez-la au projet.

### Si le message « Un disque réinscriptible, contenant des données, a été trouvé dans l’appareil de destination. » s’affiche

Cette alerte peut s’afficher lorsque vous partagez votre projet sur un DVD-RW ou un disque BD-RE comportant déjà des données. Si vous cliquez sur OK dans la fenêtre, mais que le partage s’arrête à 66 %, il est possible que le DVD ou le disque Blu-ray ait été monté par erreur dans le Finder. Cela peut empêcher votre Mac d’effacer les données existantes sur le disque avant d’y graver le nouveau projet. Vous pouvez également voir une alerte indiquant que le disque est en service.

Pour résoudre le problème, essayez de répéter la procédure de partage sur disque après avoir pris les mesures suivantes :

- Pour graver un DVD-RW ou un disque BD-RE contenant déjà des données, cliquer immédiatement sur OK pour effacer le disque. Ceci empêche le montage du disque dans le Finder.

- Redémarrer votre Mac.

- [Forcer à quitter](https://support.apple.com/kb/PH25420?locale=fr_FR) Création de disque.

### Si aucune alerte ne s’affiche, créer une image disque

Si le processus de partage s’arrête à 66 % d’achèvement et qu’aucune autre alerte ne s’affiche, essayez de créer une image disque et de graver le disque en utilisant l’image disque.

- Redémarrez votre Mac.

- Suivez la procédure pour créer une image disque DVD ou Blu-ray dans [Final Cut Pro](https://support.apple.com/kb/PH26164?locale=fr_FR) , [Motion](https://support.apple.com/kb/PH16620?locale=fr_FR) ou [Compressor](https://support.apple.com/kb/PH21201?locale=fr_FR) .

- Localisez le fichier de l’image disque (IMG) sur votre disque dur.

- Cliquez sur le fichier de l’image disque en maintenant la touche Contrôle enfoncée.

- Dans le menu, cliquez sur « Graver l’image disque [nom du disque] sur le disque » et suivez les instructions.

Les images disque sont également utiles pour archiver des projets tels qu’ils apparaissent sur disque, et si vous avez besoin de graver plusieurs exemplaires de disques d’un projet.

## Si votre disque saute lors de la lecture, a des problèmes de synchronisation ou n’affiche pas les sous-titres comme prévu

Si vous utilisez des disques réinscriptibles, notez que certains disques réinscriptibles qui ont été gravés plusieurs fois peuvent donner lieu à des problèmes de lecture dans certains lecteurs de DVD ou de disques Blu-ray. Essayez de graver un nouveau DVD-RW ou disque BD-RE.

## Si la destination intégrée à la fonction Créer un disque Blu-Ray donne lieu à un échec dans Compressor 4.4.2

Le transcodage peut échouer lors de l’utilisation de la destination intégrée à la fonction « Créer un disque Blu-Ray » avec des médias source de 23,98 ips. Changez la fréquence d’images, puis réessayez le transcodage.

- Choisissez Présentation > Terminé, ou appuyez sur Commande + 3.

- Cliquez sur le bouton Réutiliser de la tâche ayant échoué pour la copier dans la vue En cours.

[Image: bouton Réutiliser]

- Sélectionnez « H.264 pour Blu-ray » dans la zone du lot.

- Choisissez Fenêtre > Afficher l’inspecteur, ou appuyez sur Commande + 4, puis cliquez sur Vidéo dans l’inspecteur.

- Choisissez 29,97 dans le menu local Fréquence d’images.

- Cliquez sur Lancer le lot.
