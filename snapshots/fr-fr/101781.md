# Ajustement des modules avec VoiceOver dans Logic Pro pour Mac et MainStage

Utilisez la présentation des commandes dans les modules d’effets et d’instruments pour accéder à toutes les commandes avec VoiceOver.

Dans Logic Pro et MainStage, vous pouvez afficher les commandes des modules d’effets et d’instruments logiciels sous forme de liste pour un accès complet à VoiceOver.

- Dans la fenêtre du module dans Logic Pro ou MainStage, accédez au menu Affichage.

- Activez le menu Affichage, utilisez la touche fléchée vers le bas pour sélectionner Commandes dans le menu Affichage, puis appuyez sur Entrée pour passer à la présentation des commandes.

- Utilisez la navigation VoiceOver standard pour accéder aux paramètres individuels dans la présentation des commandes. Les paramètres disponibles pour l’édition dépendent de l’effet ou de l’instrument logiciel que vous éditez.

Vous pouvez configurer Logic Pro ou MainStage afin que les modules s’ouvrent toujours dans la présentation des commandes. Choisissez Logic Pro ou MainStage dans la barre de menus, puis choisissez Préférences > Afficher. Cliquez sur Table de mixage, puis sélectionnez « Ouvrir dans la présentation des commandes ».
