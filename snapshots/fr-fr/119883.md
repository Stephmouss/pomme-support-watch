# Enregistrer un document en tant que paquet ou fichier unique dans Pages, Numbers ou Keynote sur Mac

Si la taille de votre document est supérieure à 500 Mo et que le stockage de votre ordinateur n’utilise pas le format APFS (Apple File System), ou si vous travaillez dans une ancienne version de Pages, Numbers ou Keynote, l’app peut vous inviter à enregistrer le document en tant que paquet.

Un paquet est un ensemble de fichiers que votre Mac lit comme s’il s’agissait d’un seul fichier. Par défaut, Pages, Numbers et Keynote enregistrent automatiquement chaque document, feuille de calcul ou présentation dans un fichier unique. Si Pages, Numbers ou Keynote vous invite à enregistrer un document en tant que paquet, procédez comme suit :

- Si vous enregistrez le document sur votre disque dur, si un curseur d’attente s’affiche ou que vous constatez un ralentissement des performances lors de la modification du document, ou si vous enregistrez le document dans iCloud Drive, choisissez Utiliser un paquet.

- Si vous avez prévu de charger le document dans un service de partage dans le nuage tiers comme Box ou Dropbox à l’aide d’un navigateur web, choisissez Conserver un seul fichier.

À tout moment, vous pouvez convertir un fichier unique en paquet, et vice versa. Pour ce faire, ouvrez votre fichier. Ensuite, choisissez Fichier > Avancé > Changer de type de fichier, puis sélectionnez le type souhaité.

### Si un paquet est endommagé et ne peut pas être ouvert

Si le message « Impossible d’ouvrir [Document] pour le moment » s’affiche lorsque vous essayez d’ouvrir un fichier enregistré en tant que paquet, il est possible que le fichier soit endommagé. Un document enregistré en tant que paquet peut être endommagé s’il a été envoyé en pièce jointe ou chargé dans un service de partage dans le nuage tiers comme Box ou Dropbox à l’aide d’un navigateur web.

Si ce message apparaît, demandez à la personne qui a créé le fichier de vous le renvoyer après l’avoir enregistré dans un fichier unique.

[Contactez le fournisseur](https://support.apple.com/fr-fr/103190) pour plus d’informations.
