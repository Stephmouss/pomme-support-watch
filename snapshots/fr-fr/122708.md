# Si les images HDR ne sont pas correctement restituées dans Pixelmator Pro ou Photomator

Si les images HDR affichées dans Pixelmator Pro ou Photomator sont pâles ou désaturées, vérifiez les réglages de l’app et de l’appareil, la compatibilité entre le matériel et le logiciel, ainsi que vos fichiers multimédias source.

## Vérifier les réglages HDR dans Pixelmator Pro ou Photomator

- Selon l’app que vous utilisez, choisissez Pixelmator Pro ou Photomator dans la barre des menus, puis Réglages.

- Cliquez sur Général, puis sélectionnez « Charger le contenu HDR » si l’option n’est pas activée.

- Si vous retouchez une image, touchez ou cliquez sur le bouton retour pour revenir à la photothèque, puis rouvrez le fichier dans l’app.

[Image: null]

- Cliquez sur le bouton HDR dans la barre d’outils :

- Dans Pixelmator Pro, si le bouton HDR n’apparaît pas dans la barre d’outils, cela indique que le fichier multimédia n’est pas un fichier HDR.

- Dans Photomator, si le bouton HDR de la barre d’outils est grisé, cela indique que le fichier multimédia n’est pas un fichier HDR.

## Vérifier que votre écran prend en charge le format HDR

Si l’app détecte que votre écran n’est pas compatible avec le format HDR ou n’offre qu’une prise en charge partielle de ce format, une notification apparaît sous la case à cocher « Charger le contenu HDR » dans les réglages de Pixelmator Pro ou de Photomator. Si votre écran prend en charge le format HDR et que vous avez sélectionné l’option « Charger le contenu HDR », vous devrez peut-être activer le format HDR sur l’écran lui-même pour afficher et retoucher des contenus en HDR.

Les appareils Apple équipés d’écrans XDR offrent des performances optimales pour le traitement des contenus HDR. Les appareils Apple non équipés d’écrans XDR offrent une prise en charge partielle du format HDR, avec une luminosité maximale comprise entre 300 et 600 nits.

## Activer le format HDR sur un écran externe tiers

Si votre écran externe tiers dispose d’un réglage HDR et que celui-ci est désactivé, il est possible que Photomator ne détecte pas l’écran comme étant compatible avec le contenu HDR.

- Vérifiez si votre écran dispose d’un réglage intégré pour le format HDR. Si c’est le cas, activez-le. Reportez-vous à la documentation fournie avec l’écran ou contactez son fabricant pour obtenir de l’aide si vous ne trouvez pas ce réglage.

- Vérifiez les réglages HDR sur votre Mac :

- Choisissez le menu Pomme  > Réglages Système, puis cliquez sur Moniteurs.

- Dans les réglages Moniteurs de l’écran externe, assurez-vous que l’option Plage dynamique étendue est activée. Cette option apparaît uniquement pour les écrans tiers prenant en charge le format HDR10. Elle n’est pas disponible pour les écrans intégrés.

## Vérifier le format de votre fichier multimédia

Assurez-vous que le format du fichier que vous retouchez est compatible HDR :

- Ouvrez la fenêtre « Lire les informations » du fichier multimédia :

- Dans Pixelmator Pro, ouvrez l’image, puis appuyez sur Option + Commande + Maj + I.

- Dans Photomator sur Mac, sélectionnez le fichier dans l’explorateur de photos, puis appuyez sur Commande + I.

- Dans Photomator sur iPhone ou iPad, ouvrez l’image en mode de modification, touchez le bouton Plus, puis l’option Afficher les informations.

- Notez le format de l’image (tel que HEIF ou JPEG), puis consultez la liste des formats HDR pris en charge par l’app que vous utilisez :

- [Consultez les formats HDR pris en charge par Pixelmator Pro](https://support.pixelmator.com/faq-pixelmator-pro/advanced-workflows/working-with-hdr-content-in-pixelmator-pro) .

- [Consultez les formats pris en charge par Photomator](https://support.pixelmator.com/faq-photomator/advanced-workflows/working-with-hdr-content-in-photomator) .

Si le format de fichier n’est pas pris en charge, recréez l’image dans un format HDR pris en charge. Vous pouvez toujours retoucher et exporter l’image au format SDR (plage dynamique standard).

## Vérifier la version des logiciels sous macOS

Assurez-vous que vous utilisez les versions prises en charge de macOS et de Pixelmator Pro ou Photomator pour bénéficier de performances optimales avec du contenu HDR.

## Vérifier la version de macOS

La retouche d’images au format HDR dans Pixelmator Pro et Photomator sur Mac nécessite macOS Sonoma ou version ultérieure. Pour vérifier la version de macOS dont vous disposez, cliquez sur le menu Pomme , puis choisissez À propos de ce Mac. Si la version indiquée est macOS Ventura ou une version antérieure, assurez-vous que tous les logiciels tiers installés sur votre Mac sont compatibles avec la dernière version de macOS, puis [mettez à jour macOS](https://support.apple.com/fr-fr/108382) .

[En savoir plus sur les versions de macOS](https://support.apple.com/fr-fr/109033)

## Vérifier la version de Pixelmator Pro ou de Photomator sur Mac

Pour vérifier la version de l’app dont vous disposez, ouvrez l’app, puis choisissez About (À propos) > [nom de l’app]. Si la version de l’app est Photomator 3.1 ou Pixelmator Pro 3.4 ou une version antérieure, [commencez par la sauvegarder, puis mettez-la à jour](https://support.apple.com/fr-fr/122606) .

## Vérifier la version des logiciels sous iOS ou iPadOS

Assurez-vous que vous utilisez les versions prises en charge d’iOS ou d’iPadOS et de Photomator pour bénéficier de performances optimales avec du contenu HDR.

## Vérifier la version d’iOS ou d’iPadOS

Pour vérifier la version dont vous disposez, accédez à Réglages > Général > Informations. Si la version installée est antérieure à iOS 17 ou iPadOS 17, vous devrez [mettre à jour iOS ou iPadOS](https://support.apple.com/fr-fr/118575) .

### Vérifier la version de Photomator

- Accédez à Réglages.

- Touchez Apps. Vous devrez peut-être faire défiler l’écran vers le bas.

- Localisez l’app Photomator dans la liste et touchez son nom. La version de Photomator est indiquée sous Réglages Photomator. Si la version de l’app est Photomator 3.1 ou une version antérieure, vous devrez [la mettre à jour](https://support.apple.com/fr-fr/102629) .

Mettez à jour Photomator vers la version 3.2 ou ultérieure pour accéder aux fonctionnalités de retouche HDR complètes.

## Vérifier l’état d’activation du mode économie d’énergie sur votre iPhone ou iPad

Sur l’iPhone et l’iPad, vous ne pouvez pas retoucher ni exporter du contenu HDR si l’appareil est en mode économie d’énergie. Chargez votre appareil ou désactivez le mode économie d’énergie :

- Accédez à Réglages.

- Touchez Batterie.

- Désactivez l’option Mode économie d’énergie.
