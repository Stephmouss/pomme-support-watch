# GarageBand '11 : espace insuffisant pour terminer le téléchargement après l’achat depuis le Mac App Store

La première fois que vous ouvrez GarageBand '11 après l’avoir téléchargé depuis le Mac App Store, une alerte peut s’afficher, indiquant qu’il n’y a pas assez d’espace pour terminer le téléchargement.

Pour utiliser GarageBand, du contenu supplémentaire est nécessaire. Si vous n’avez pas déjà installé ce contenu, vous devez le télécharger. Il requiert 1,2 Go d’espace disque supplémentaire.

Libérez de l’espace disque en déplaçant certains de vos fichiers vers un autre disque (disque dur externe ou clé USB, par exemple) ou en supprimant les fichiers dont vous n’avez pas besoin, puis en vidant la corbeille.
