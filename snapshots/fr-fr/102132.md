# Télécharger l’app Beats si votre pays, votre région ou votre appareil ne dispose pas de Google Play

Découvrez comment télécharger l’app Beats sur un appareil Android si vous n’avez pas accès à Google Play. Vous devrez peut-être ajuster les réglages de sécurité pour procéder à l’installation.

## Télécharger l’app

- Si vous y avez accès, [téléchargez l’app Beats sur Google Play](https://play.google.com/store/apps/details?id=com.apple.bnd) .

- Si vous n’avez pas accès à Google Play, [téléchargez l’app à partir de Beats](https://tempo.api.beatsbydre.com/v3/mobile_apps/android/download) .

## Installer l’app

- Sur l’écran d’accueil de votre téléphone, effectuez un balayage vers le bas pour ouvrir les notifications.

- Touchez Télécharger le fichier pour commencer l’installation.

- Si le message « Votre téléphone n’est pas autorisé à installer une app inconnue » s’affiche, touchez Paramètres.

- Un écran de confirmation apparaît. Sélectionnez « Autorisation depuis cette source ». Vous devrez répéter cette procédure lorsque vous mettrez à jour l’app.

- Si un message vous demande « Voulez-vous installer cette application ? », touchez Installer. L’app Beats s’installe sur votre appareil.

- Ouvrez l’app Beats.
