# Mettre à jour la date d’achat de votre appareil à l’aide de votre preuve d’achat

Corrigez la date d’achat de votre appareil si la date d’expiration estimée de votre garantie limitée ou de la couverture de votre contrat AppleCare est incorrecte.

Pour demander la correction de la date d’achat de votre produit, vous devez envoyer la preuve d’achat d’origine de ce produit à Apple.

Le reçu que vous utilisez doit comporter les informations suivantes :

- Une description claire de votre appareil

- La date d’achat de l’appareil

- Un numéro de facture ou de reçu

- Le prix de l’appareil

- Les coordonnées du revendeur

- Le numéro de série de l’appareil

[Corriger la date d’achat de votre appareil](https://getsupport.apple.com/?caller=kbase)
