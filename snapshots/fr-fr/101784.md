# Utiliser VoiceOver avec une plage braille dynamique lors d’un appel téléphonique en mode RTT (texte en temps réel)

Apprenez à lire un appel téléphonique en mode RTT (texte en temps réel) et à y répondre lorsque vous utilisez une plage braille dynamique avec VoiceOver.

## Vérifier l’état des messages

VoiceOver utilise les trois premières cellules d’une plage braille pour fournir des informations sur l’état des messages.

- Si tous les points sont vides ("⠀"), cela signifie qu’il n’y a pas de messages non lus.

- Si les points 2,3,5,6 ("⠶") clignotent ensemble, un message attend votre réponse.

- Si les points 2,3,5,6 ("⠶") s’animent dans le sens des aiguilles d’une montre (2,5,6,3), cela signifie qu’un autre utilisateur RTT est en train d’écrire.

## Basculer entre vos brouillons et les messages entrants

Pour alterner la plage braille entre votre propre brouillon et le message d’un interlocuteur, appuyez sur le bouton de routage au-dessus de la cellule d’état RTT.

Pour attribuer cette commande à un bouton ou à un accord de commande différent sur votre plage braille :

- Accédez à Réglages > Accessibilité > VoiceOver > Commandes.

- Sous Appareils braille, sélectionnez votre plage braille.

- Sélectionnez Message TTY suivant ou Message TTY précédent pour modifier la commande.

Si votre plage braille est actuellement configurée pour afficher le texte entrant de l’interlocuteur, les cellules braille changeront en temps réel pour afficher le texte saisi par l’interlocuteur.
