# GarageBand pour iOS 1.2 : optimisation de la connectivité réseau lors d’une improvisation

Découvrez comment optimiser la connectivité réseau de votre improvisation dans GarageBand pour iOS.

Le mélange de différentes connexions réseau peut entraîner des problèmes lorsque vous tentez de rejoindre une improvisation ou peut provoquer une lecture désynchronisée sur les appareils. Les conseils ci-dessous vous aideront à optimiser la connectivité réseau :

- Tous les participants à une improvisation doivent utiliser le même type de connexion réseau : Wi-Fi ou Bluetooth.

- Si le réseau Wi-Fi disponible a un trafic réseau élevé, essayez d’utiliser le Bluetooth.

- Si des participants veulent faire des enregistrements audio avec l’enregistreur audio, l’ampli de guitare ou l’échantillonneur, l’utilisation d’un réseau Wi-Fi permet de réduire le temps nécessaire pour la collecte des enregistrements.

Pour sélectionner une connexion réseau spécifique :

## Bluetooth

- Ouvrez l’app Réglages et désactivez le Wi-Fi.

- Touchez la section Général et activez le Bluetooth.

- Reproduisez les étapes 1 et 2 pour tous les participants.

- Ouvrez les commandes d’improvisation dans GarageBand pour iOS.

- Créez ou rejoignez une improvisation.

## Wi-Fi

- Ouvrez l’app Réglages et activez le Wi-Fi.

- Touchez la section Général et désactivez le Bluetooth.

- Reproduisez les étapes 1 et 2 pour tous les participants. Assurez-vous que tous les participants se connectent au même réseau Wi-Fi.

- Ouvrez les commandes d’improvisation dans GarageBand pour iOS.

- Cliquez sur Annuler dans la boîte de dialogue « Voulez-vous activer le Bluetooth ? » .

- Créez ou rejoignez une improvisation.
