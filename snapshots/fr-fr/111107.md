# Vous connecter à un réseau Wi-Fi sur votre iPhone ou iPad

Connectez votre appareil aux réseaux Wi-Fi disponibles, qu’il s’agisse de réseaux publics, sécurisés ou précédemment utilisés.

## Se connecter à un réseau Wi-Fi

- Depuis votre écran d’accueil, accédez à Réglages, puis touchez Wi-Fi.

- Touchez Wi-Fi pour l’activer. Votre appareil recherche alors automatiquement les réseaux Wi-Fi disponibles.

- Touchez le nom du réseau Wi-Fi auquel vous souhaitez vous connecter. Il peut vous être demandé de saisir d’abord le mot de passe du réseau ou [d’accepter les conditions générales](https://support.apple.com/102554) . Si vous [ne connaissez pas le mot de passe du réseau Wi-Fi](https://support.apple.com/102511) , contactez votre administrateur réseau.

- Recherchez la coche bleue à côté du nom du réseau et l’icône Wi-Fi dans le coin supérieur de votre écran. Elles indiquent que votre connexion a réussi.
