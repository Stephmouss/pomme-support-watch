# Écoutez Mickey Mouse ou Minnie Mouse vous donner l’heure exacte

Si vous définissez Mickey Mouse ou Minnie Mouse comme cadran de montre, vous pouvez toucher l’écran pour les entendre vous donner l’heure.

## Choisir votre cadran

Vous pouvez [modifier le cadran de votre montre](https://support.apple.com/guide/watch/apda6559ad78) depuis votre Apple Watch ou votre iPhone.

Sur votre iPhone, ouvrez l’app Watch, touchez l’onglet Galerie de cadrans, choisissez Mickey Mouse ou Minnie Mouse, puis touchez Ajouter.

Si vous souhaitez [personnaliser le cadran de la montre](https://support.apple.com/guide/watch/apda6559ad78) , appuyez fermement sur l’écran de votre Apple Watch.

[Image: Galerie de cadrans affichant les options Mickey Mouse et Minnie Mouse.]

## Vérifier le mode silencieux

Pour ouvrir le centre de contrôle, appuyez sur le bouton latéral (sous watchOS 9 ou version antérieure, touchez de manière prolongée le bas de l’écran, puis effectuez un balayage vers le haut).

Ensuite, [assurez-vous que le mode silencieux est désactivé](https://support.apple.com/HT204793) . Si ce mode est activé, touchez pour le désactiver. Lorsque le mode silencieux est désactivé, l’icône apparaît grisée ou estompée.

Dans l’étape suivante, vous pourrez découvrir comment laisser Mickey Mouse ou Minnie Mouse énoncer l’heure même lorsque le mode silencieux est activé.

[Image: Centre de contrôle sur l’Apple Watch affichant le mode silencieux.]

## Vérifier les réglages de votre iPhone

Ouvrez l’app Apple Watch, touchez l’onglet Ma montre, puis Horloge.

Assurez-vous que l’option Dire l’heure est activée. Sélectionnez Toujours dire si vous voulez que Mickey Mouse ou Minnie Mouse indique l’heure même si votre montre est en mode silencieux.

Vous pouvez également effectuer ce réglage directement sur votre montre. Ouvrez Réglages, puis touchez Horloge.

[Image: Réglages de l’horloge de l’Apple Watch sur iPhone.]

## Écouter l’heure

Sur votre Apple Watch, touchez Mickey Mouse ou Minnie Mouse avec un doigt pour les entendre indiquer l’heure. Si vous possédez une Apple Watch Series 5 et modèles ultérieurs, notamment une Apple Watch Ultra et modèles ultérieurs, et que vous utilisez [Toujours activé](https://support.apple.com/HT210428) *, touchez deux fois votre écran lorsque celui-ci est inactif.

*L’Apple Watch SE ne prend pas en charge Toujours activé.

Lorsque la fonctionnalité Énoncer l’heure est activée, vous pouvez également écouter l’heure en maintenant deux doigts appuyés sur n’importe quel cadran de montre.

[Image: Minnie Mouse en jupe à pois rouge.]

## Si Mickey Mouse ou Minnie Mouse ne parle pas

Vous devrez peut-être télécharger sa voix:

- [Connectez votre Apple Watch à un réseau Wi-Fi fiable](https://support.apple.com/ht204562) , puis placez-la sur son chargeur.

- Patientez environ quinze minutes, puis touchez à nouveau l’écran.

Si vous n’entendez toujours pas sa voix, supprimez le cadran, puis ajoutez-le à nouveau :

- Maintenez votre doigt sur l’écran de votre Apple Watch.

- Effectuez un balayage de l’écran vers le haut sur le cadran de la montre Mickey Mouse ou Minnie Mouse, puis touchez Supprimer.

- Effectuez un balayage vers la gauche jusqu’à ce que le bouton d’ajout apparaisse, puis touchez-le.

[Image: bouton d’ajout]

- Tournez la Digital Crown, puis touchez Mickey Mouse ou Minnie Mouse pour ajouter à nouveau son cadran.

- Touchez l’écran pour écouter l’heure.

Si le problème persiste, [contactez l’assistance Apple](https://getsupport.apple.com/?caller=kbase) .
