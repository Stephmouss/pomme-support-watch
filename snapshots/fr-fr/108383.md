# Utiliser la 5G avec votre iPhone

Les modèles d’iPhone 12 ou ultérieurs fonctionnent avec les réseaux mobiles 5G de certains opérateurs. Découvrez comment utiliser la 5G avec votre appareil.

## Éléments requis

- Un modèle d’iPhone 12 ou ultérieur

- [Un opérateur prenant en charge la 5G](https://support.apple.com/fr-fr/109526)

- Un forfait mobile 5G 1

Si votre nouvel iPhone est fourni avec une carte SIM physique ou une eSIM, utilisez cette carte. Si ce n’est pas le cas, utilisez celle de votre ancien iPhone. Dans certaines situations, il peut être nécessaire de contacter votre opérateur pour que la carte SIM de votre ancien iPhone fasse l’objet de modifications afin de fonctionner sur un réseau 5G.

## Description des icônes 5G apparaissant dans la barre d’état

Lorsque vous vous trouvez dans une zone couverte par la 5G de votre opérateur et que vous activez votre forfait mobile 5G, une icône 5G s’affiche dans la barre d’état de votre iPhone :

[Image: Icône 5G.]

Le réseau 5G de votre opérateur est disponible et votre iPhone peut se connecter à Internet via ce réseau (non disponible dans certains pays et certaines régions) 2

[Image: Icônes 5G+, 5G UW, 5G UC et 5GA dans la barre d’état de l’iPhone, indiquant la disponibilité de réseaux 5G à plus haute fréquence.]

Le réseau 5G+, 5G UW, 5G UC ou 5GA de votre opérateur est disponible et peut inclure la fréquence 5G supérieure prise en charge par votre opérateur. Votre iPhone peut se connecter à Internet par l’intermédiaire de ce réseau (non disponible dans certains pays et certaines régions) 2

Découvrez comment procéder [si l’icône 5G n’apparaît pas dans la barre d’état](https://support.apple.com/fr-fr/108383#no-5g) .

## Description des options proposées avec la 5G

Contactez votre opérateur pour savoir s’il prend en charge la 5G et si votre forfait mobile est compatible avec la 5G.

Les réglages par défaut de la 5G de votre iPhone optimisent l’autonomie de la batterie, ainsi que l’utilisation des données dans le cadre de votre forfait mobile.

Vous pouvez personnaliser ces options afin de choisir quand utiliser la 5G, et pour définir le volume de données utilisées par certaines apps :

- Ouvrez l’app Réglages.

- Touchez Données cellulaires, puis Options, ou touchez Données mobiles.

- Touchez Options.

- Si vous utilisez la double SIM, touchez Données cellulaires, ou touchez Données mobiles, puis choisissez le numéro dont vous souhaitez modifier les options.

### Voix et données

[Image: Réglages Voix et données de l’iPhone, présentant les options 5G auto, 5G activée et LTE.]

Sélectionnez la manière dont votre iPhone se connecte au réseau 5G (ceci ayant une incidence sur l’autonomie de la batterie).

- 5G auto : cette option permet d’activer le mode Données intelligentes. Lorsque la 5G ne permet pas d’optimiser les performances de façon significative, votre iPhone bascule automatiquement sur le réseau LTE, ce qui permet d’économiser la batterie.

- L’icône 5G apparaît en fonction de la configuration du réseau de l’opérateur et, dans de rares cas, peut apparaître même lorsque la couverture 5G n’est pas disponible.

- 5G activée : cette option permet de toujours utiliser le réseau 5G lorsqu’il est disponible. Elle est toutefois susceptible de réduire l’autonomie de la batterie.

- LTE : cette option permet d’utiliser uniquement le réseau LTE, même lorsque la 5G est disponible.

Des réglages supplémentaires, tels que 5G SA et Voix sur 5G Standalone, peuvent être disponibles dans votre pays ou région. Pour obtenir des informations supplémentaires, contactez votre opérateur.

### Mode de données

[Image: Réglages Mode de données de l’iPhone : Autoriser davantage de données en 5G, Standard et Mode Faibles données.]

- Autoriser plus de données en 5G : cette option permet d’utiliser les fonctionnalités qui consomment davantage de données pour les apps et les tâches système. Ces fonctionnalités améliorent la qualité des appels FaceTime, permettent de regarder des contenus haute définition sur l’Apple TV, d’écouter des morceaux et des vidéos Apple Music et de bénéficier de mises à jour d’iOS via le réseau mobile ainsi que de sauvegardes iCloud automatiques.

- Grâce à ce réglage, votre iPhone peut utiliser automatiquement la 5G au lieu du Wi-Fi lorsque la connexion Wi-Fi est lente ou non sécurisée sur un réseau auquel vous vous connectez occasionnellement.

- Pour désactiver et activer cette fonctionnalité pour un réseau spécifique, ouvrez l’app Réglages et touchez Wi-Fi. Touchez le bouton d’informations à côté du réseau Wi-Fi, puis touchez Utiliser le Wi-Fi pour Internet.

- Ce réglage permet également aux apps tierces d’utiliser davantage de données mobiles pour des expériences améliorées.

- Il s’agit du réglage par défaut avec les forfaits de données illimitées fournis par certains opérateurs.

- Ce réglage occasionne une utilisation accrue des données mobiles.

- Standard : lorsque cette option est configurée, les mises à jour automatiques et les tâches en arrière-plan s’effectuent à l’aide des données mobiles, et la qualité des vidéos et des appels FaceTime est standard. Il s’agit généralement du mode défini par défaut.

- Mode Faibles données : cette option permet de limiter l’utilisation des données mobiles et du Wi-Fi en mettant en pause l’installation automatique des mises à jour et l’exécution des tâches en arrière-plan.

### Données à l’étranger

De nombreux opérateurs du monde entier prennent en charge l’itinérance 5G. Si ce n’est pas le cas du vôtre, vous pouvez utiliser les données mobiles via les réseaux 4G et LTE, ou faire l’acquisition d’une carte SIM ou eSIM locale permettant d’accéder à la 5G quand elle est disponible.

Contactez votre opérateur pour en savoir plus.

## Si l’icône 5G n’apparaît pas dans la barre d’état

- Contactez votre opérateur pour confirmer qu’il prend en charge la 5G et que votre forfait mobile est compatible avec la 5G.

- Assurez-vous de vous trouver dans une zone couverte par la 5G. Contactez votre opérateur si vous avez des doutes à ce sujet.

- Ouvrez l’app Réglages.

- Touchez Données cellulaires, puis Options, ou touchez Données mobiles, puis Options. Si l’écran ci-dessous s’affiche, cela signifie que votre appareil est compatible avec la 5G.

[Image: Écran des options de données cellulaires de l’iPhone affichant les réglages Données à l’étranger, Voix et données et Mode de données.]

- [Activez le mode avion](https://support.apple.com/fr-fr/108785) , puis désactivez-le.

Si la 5G n’est toujours pas détectée, contactez votre opérateur.

## Informations supplémentaires

- Si vous souhaitez utiliser la 5G avec une [double SIM](https://support.apple.com/fr-fr/109317) sur un modèle d’iPhone 12, vérifiez que votre appareil est doté d’iOS 14.5 ou version ultérieure.

- Pour toujours regarder les contenus dans la plus haute qualité :

- Ouvrez l’app Réglages.

- Touchez Apps.

- Touchez Musique.

- Touchez Qualité audio.

- Touchez Diffusion cellulaire, puis Haute qualité. Pour la TV, ouvrez l’app Réglages et touchez TV, puis touchez Réglages ou Données mobiles. Activez Utiliser les données cellulaires si nécessaire, puis touchez Haute qualité. Ces réglages impliquent une utilisation accrue des données mobiles. Le démarrage de la lecture peut prendre plus de temps.

- Si vous activez le [mode économie d’énergie](https://support.apple.com/fr-fr/101604) , la 5G est désactivée, sauf dans certains cas comme lors d’un streaming vidéo ou de téléchargements volumineux sur les modèles d’iPhone 12 et d’iPhone 13. Sur les modèles d’iPhone 12, le mode Économie d’énergie désactive la 5G autonome (le cas échéant).

1. Contactez votre opérateur pour savoir si vous disposez d’un forfait 5G. Si ce n’est pas le cas, il est possible que son activation vous soit facturée.

2. Les réseaux 5G à plus haute fréquence sont uniquement pris en charge aux États-Unis, sur les iPhone achetés dans ce pays.
