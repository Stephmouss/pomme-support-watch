# Transférer les données d’un PC vers un Mac avec l’Assistant migration

L’Assistant migration copie les contacts, calendriers, comptes de messagerie et autres données depuis votre PC Windows vers les emplacements appropriés de votre Mac. Il ne supprime pas les informations de votre ancien PC ni ne remplace le système d’exploitation (macOS) de votre Mac.

- [Se préparer](https://support.apple.com/fr-fr/102565#setup)

- [Utiliser l’Assistant migration](https://support.apple.com/fr-fr/102565#use)

- [Quelles données sont transférées et où ?](https://support.apple.com/fr-fr/102565#data)

- [Si la migration échoue](https://support.apple.com/fr-fr/102565#notransfer)

## Procédure préliminaire

- Assurez-vous que la version de Microsoft Windows de votre PC est à jour et que [macOS est à jour](https://support.apple.com/108382) sur votre Mac.

- Fermez toutes les apps et désactivez tous les réglages susceptibles d’empêcher votre PC d’effectuer d’autres tâches. Si vous avez installé un logiciel antivirus, un coupe-feu ou un logiciel VPN sur l’un ou l’autre des ordinateurs, désactivez-les également.

- Assurez-vous que votre Mac et votre PC sont à proximité l’un de l’autre et que le Wi-Fi et le Bluetooth sont activés. Si votre ancien PC ne prend pas en charge le mode Bluetooth faible énergie, un message peut vous indiquer qu’un adaptateur Bluetooth est nécessaire. Les adaptateurs Bluetooth qui se connectent au port USB de votre PC sont largement répandus.

- Si votre Mac est doté de macOS 13 ou d’une version antérieure, ou si vous ne connaissez pas la version actuellement installée, connectez les deux ordinateurs au même réseau, ou reliez-les directement à l’aide d’un câble Ethernet.

- Sur votre PC, téléchargez la version appropriée de l’Assistant migration Windows, en fonction de la version de macOS installée sur votre Mac :

Assistant migration Windows 3.2.0.0 | Prend en charge la migration de données à partir de Windows 10 ou version ultérieure vers : macOS 27 Golden Gate macOS Tahoe 26 macOS Sequoia 15 macOS Sonoma 14

Assistant migration Windows 2.4.5.0 | Prend en charge la migration de données à partir de Windows 7 ou version ultérieure vers : macOS Ventura 13 macOS Monterey 12

Assistant migration Windows 2.3.1.0 | Prend en charge la migration de données à partir de Windows 7 ou version ultérieure vers : macOS Big Sur 11

La version 2.2.0.1 , la version 2.1.2.0 et la version 1.0.5.7 de l’Assistant migration Windows restent disponibles pour procéder à la migration de données vers les versions antérieures de macOS.

## Utiliser l’Assistant migration

Ces étapes concernent l’Assistant migration Windows 3, mais la plupart des étapes sont similaires pour les versions antérieures.

### Sur votre Mac

- Déterminez si l’ouverture de l’Assistant migration est nécessaire :

- Si l’assistant réglages s’affiche au démarrage de votre Mac, vous aurez la possibilité de transférer vos informations lors de la configuration et il n’est pas nécessaire d’ouvrir Assistant migration.

- Si vous avez déjà effectué la procédure de configuration, ouvrez l’Assistant migration, qui est préinstallé sur votre Mac. Vous pouvez le rechercher et l’ouvrir [à l’aide de Spotlight](https://support.apple.com/guide/mac-help/search-with-spotlight-mchlp1008/mac) , ou y accéder dans le dossier Utilitaires de votre dossier Applications.

- Si on vous demande l’autorisation d’apporter des modifications, saisissez votre mot de passe administrateur.

- Lorsque l’Assistant migration (ou l’assistant réglages du Mac) vous demande comment vous souhaitez transférer vos informations, sélectionnez « À partir d’un PC Windows ». Cliquez sur Continuer.

[Image: Assistant migration avec l’option « À partir d’un PC Windows » sélectionnée.]

### Sur votre PC

- Lorsque votre Mac affiche un code et vous invite à le saisir sur votre PC, ouvrez l’Assistant migration Windows que vous avez téléchargé.

- Suivez les instructions à l’écran jusqu’à ce qu’un message vous invite à saisir le code affiché sur votre Mac. Saisissez le code, puis cliquez sur Continuer. Votre PC recherche votre Mac et s’y connecte.

[Image: Assistant migration sur PC : écran Saisir le code]

### Sur votre Mac

- Votre Mac calcule l’espace de stockage nécessaire pour transférer vos informations. Vous devrez peut-être faire défiler l’écran vers le bas pour voir la liste complète. Patientez jusqu’à la fin du calcul.

- Cochez la case à côté de chaque catégorie de fichiers que vous souhaitez transférer. Vous pouvez également cliquer sur la flèche d’expansion à côté d’une catégorie et sélectionner des éléments spécifiques à l’intérieur de celle-ci. Cliquez sur Continuer lorsque vous avez terminé.

[Image: Compte utilisateur et dossiers sélectionnés pour le transfert du PC vers le Mac.]

- Dans l’exemple illustré ici, Joe Lipscomb est un compte utilisateur. Il peut s’agir d’un compte administrateur ou d’un compte standard.

- Si vous transférez un compte administrateur, vous êtes invité à cliquer sur Définir le mot de passe et à saisir un mot de passe sécurisé. Mémorisez ce mot de passe. Celui-ci sera nécessaire pour vous connecter au compte sur votre nouveau Mac.

- Si vous transférez un compte standard, un mot de passe temporaire est attribué et apparaît à l’écran. Notez ce mot de passe. Lorsque de la première connexion à ce compte sur le Mac, l’utilisateur doit saisir ce mot de passe, puis saisir son propre nouveau mot de passe lorsqu’on le lui demande.

- Si un message vous demande le mot de passe d’un utilisateur existant déjà autorisé sur votre nouveau Mac, cliquez sur Autoriser, puis saisissez le mot de passe de ce compte.

- Les transferts importants peuvent prendre des heures et sembler s’arrêter de temps en temps. Une fois l’opération terminée, quittez l’Assistant migration.

- Lorsque votre Mac redémarre, utilisez le mot de passe que vous avez défini dans l’Assistant migration pour vous connecter au compte transféré sur votre Mac.

- Si vous avez besoin de transférer des informations à partir d’un autre compte d’utilisateur Windows, connectez-vous à ce dernier sur votre PC, puis répétez la procédure de cet article.

- [Autorisez votre Mac à accéder aux achats effectués avec votre compte Apple](https://support.apple.com/fr-fr/118292) . Vous devez effectuer cette étape avant de synchroniser ou de lire du contenu téléchargé depuis Apple.

## Quelles données sont transférées et où ?

Depuis votre PC | Vers votre Mac

E-mails et réglages de messagerie d’Outlook et de Windows Mail | App Mail

Contacts de l’app Contacts (Windows 10 ou version ultérieure), d’Outlook et du dossier Contacts de votre répertoire de base. | App Contacts

Rendez-vous du Calendrier (Windows 10 ou version ultérieure) et Outlook | App Calendrier

Tâches d’Outlook (si vous transférez des données vers un Mac doté de macOS 13 ou version ultérieure) | App Rappels

Music | App Musique

Podcasts | App Podcasts

Livres audio | App Livres

Films et séries TV | App TV

Page d’accueil et signets de Chrome, Edge, Firefox, Internet Explorer et Safari | Safari

Documents et autres fichiers de votre répertoire de base | Dossier de départ

Photos, que vous pouvez également ajouter manuellement à l’app Photos sur votre Mac, ou laisser cette dernière rechercher sur votre Mac des photos à importer | Dossier de départ

Images de bureau personnalisées, réglages de langue et de localisation. Réseaux Wi-Fi connus, si le Mac est doté de macOS 13 ou version ultérieure | System Settings

Fichiers et documents non système du disque système (généralement le lecteur C) et d’autres disques disponibles (nécessite l’utilisation de l’Assistant migration lorsque vous vous connectez à votre PC en tant qu’administrateur) | Dossier partagé de votre dossier de départ

## Si la migration échoue

Assurez-vous que vous avez [configuré vos ordinateurs](https://support.apple.com/fr-fr/102565#setup) correctement et que vous utilisez la bonne version de l’Assistant migration Windows sur votre PC.

L’utilitaire de vérification de disque (chkdsk) de votre PC peut vérifier les autres problèmes qui pourraient entraîner l’échec de la migration :

- Cliquez avec le bouton droit de la souris sur le bouton Démarrer, puis cliquez sur Exécuter.

- Saisissez cmd et appuyez sur Entrée. L’invite de commande s’ouvre.

- À l’invite, saisissez chkdsk et appuyez sur la touche Entrée.

- Si l’utilitaire détecte des problèmes, saisissez chkdsk drive: /F , où drive est la lettre représentant votre disque de démarrage Windows, par exemple C.

- Appuyez sur la touche Entrée.

- À l’invite, saisissez Y , puis redémarrez votre PC.

- Renouvelez ce processus jusqu’à ce que plus aucun problème ne soit identifié. Si l’utilitaire ne parvient pas à corriger tous les problèmes détectés, vous devrez peut-être faire réparer votre PC.

Si vous ne parvenez pas à résoudre le problème, utilisez un périphérique de stockage externe ou le [partage de fichiers](https://support.apple.com/guide/mac-help/mchlp1658/mac) pour copier des fichiers importants de votre PC vers votre Mac.
