# Utiliser un visiocasque avec Final Cut Pro et Motion

Pour utiliser un visiocasque avec Final Cut Pro 10.4 et Motion 5.4 ou versions ultérieures, connectez le casque, puis installez SteamVR sur votre Mac équipé du processeur Intel.

Un visiocasque vous permet de visualiser votre vidéo 360º tout en travaillant dans Final Cut Pro et Motion. L’utilisation d’un visiocasque n’est possible que si votre Mac possède la [configuration minimale requise pour le montage de vidéos 360°](https://www.apple.com/fr/final-cut-pro/specs/) et que le logiciel Steam est installé sur votre machine. Pour en savoir plus, accédez à la [page d’assistance SteamVR](https://help.steampowered.com/fr/wizard/HelpWithGame/?appid=250820) et reportez-vous à la documentation fournie avec votre casque.

## Télécharger Steam

Pour commencer, téléchargez et installez Steam.

- Vérifiez que votre ordinateur est bien connecté à Internet.

- Accédez à l’adresse [store.steampowered.com/about](http://store.steampowered.com/about) et cliquez sur Installer Steam.

- Dans le Finder, choisissez Aller > Téléchargements. Si vous avez modifié l’emplacement de téléchargement par défaut depuis votre navigateur, accédez au dossier que vous avez défini.

- Double-cliquez sur le fichier steam.dmg.

- Faites glisser Steam vers le dossier Applications.

- Dans le Finder, choisissez Aller > Applications, puis double-cliquez sur Steam pour ouvrir l’app.

## Configurer le logiciel SteamVR

Après avoir installé Steam, installez SteamVR.

- Avant de configurer le logiciel SteamVR, suivez les instructions fournies avec votre visiocasque afin de configurer ce dernier.

- Dans Steam, créez un compte ou connectez-vous à un compte existant en suivant les invites à l’écran, puis choisissez Bibliothèque.

- Cliquez sur le menu local Jeux à gauche, puis cochez la case Outils.

- Saisissez SteamVR dans le champ de recherche.

- Cliquez avec le bouton droit sur SteamVR ou cliquez sur l’icône en forme d’engrenage, puis choisissez Propriétés dans le menu.

- Dans la fenêtre Propriétés, cliquez sur Bêtas, choisissez « macos_default - Public default branch (macOS) », puis fermez la fenêtre des propriétés.

- Cliquez sur Installer.

- Pour créer un raccourci vers SteamVR sur le bureau, sélectionnez « Créer un raccourci sur le bureau », puis cliquez sur Suivant. Vous pourrez ainsi ouvrir SteamVR directement, sans avoir à le faire depuis l’app Steam.

- Une fois le logiciel SteamVR installé, cliquez sur Terminé.

- Dans la liste Bibliothèque, double-cliquez sur SteamVR pour ouvrir l’app.

- Vous pouvez à présent fermer l’app Steam et conserver SteamVR en arrière-plan. Si vous avez connecté correctement votre casque, son voyant LED doit s’allumer en vert. Si SteamVR affiche une erreur ou si le voyant LED du casque est rouge, consultez la [page d’assistance SteamVR](https://support.steampowered.com/kb_article.php?ref=8566-SDZC-9326&l=french) pour obtenir davantage d’informations.

- Dans la fenêtre de configuration de pièce, sélectionnez « Utilisation debout uniquement ».

- Pour visualiser votre vidéo 360º dans Final Cut Pro ou Motion, choisissez Fenêtre > Sortie dans le visiocasque.

## Gérer Steam et SteamVR

Pour quitter SteamVR, vous devez à la fois fermer Steam et SteamVR.

Steam s’ouvre automatiquement lorsque vous vous connectez à votre Mac. Pour empêcher l’exécution automatique de Steam à l’ouverture de votre session Mac, procédez comme suit :

- Choisissez le menu Pomme > Préférences Système, puis cliquez sur Utilisateurs et groupes.

- Sélectionnez votre compte d’utilisateur, puis cliquez sur Ouverture, en haut de la fenêtre.

- Sélectionnez le nom de l’élément dont vous souhaitez empêcher l’ouverture automatique, puis cliquez sur le bouton Supprimer (-), en dessous de la liste.

Pour ouvrir manuellement SteamVR, double-cliquez sur le raccourci que vous avez créé sur le bureau.
