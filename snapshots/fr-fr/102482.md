# Mac : utilisation des gestes Multi-Touch

Avec un trackpad Multi-Touch, une Magic Mouse ou un écran tactile, vous pouvez toucher, balayer, pincer ou écarter un ou plusieurs doigts pour effectuer des actions utiles.

- [Gestes avec un trackpad](https://support.apple.com/fr-fr/102482#trackpad)

- [Gestes avec une Magic Mouse](https://support.apple.com/fr-fr/102482#magicmouse)

- [Gestes sur l’écran tactile](https://support.apple.com/fr-fr/102482#touchdisplay)

## Gestes avec un trackpad

Ces gestes nécessitent de disposer d’un Magic Trackpad ou d’un clavier Multi-Touch intégré. Si votre trackpad prend en charge la fonctionnalité Force Touch, vous pouvez aussi [effectuer des clics forcés et obtenir un retour haptique](https://support.apple.com/fr-fr/102309) .

Pour plus d’informations sur ces gestes, choisissez Réglages Système (ou Préférences Système) dans le menu Apple , puis cliquez sur Trackpad. Une fois dans cette fenêtre, vous pouvez activer ou désactiver un geste, modifier le type de geste associé à une action et découvrir comment fonctionnent les gestes sur votre Mac.

[Image: Main effectuant le geste de « clic simple » sur un trackpad de Mac.]

Clic simple

Touchez le trackpad avec un doigt pour effectuer un clic.

[Image: Main montrant un geste Multi-Touch sur un trackpad de Mac.]

Clic secondaire (clic droit)

Cliquez ou touchez avec deux doigts.

[Image: Main utilisant deux doigts sur un trackpad de Mac pour montrer des gestes Multi-Touch.]

Zoom intelligent

Avec deux doigts, touchez deux fois le trackpad pour effectuer un zoom avant ou arrière, sur une page web ou un PDF.

[Image: Deux doigts faisant défiler vers le haut sur un trackpad de Mac.]

Défilement

Effectuez un balayage à deux doigts vers le haut ou vers le bas 1

[Image: Main effectuant un geste de rotation à deux doigts sur un trackpad de Mac.]

Zoom avant et zoom arrière

Écartez vos doigts pour effectuer un zoom avant, ou un geste de pincement pour opérer un zoom arrière.

[Image: Main utilisant deux doigts pour effectuer le geste de rotation sur un trackpad de Mac.]

Rotation

Placez deux doigts légèrement écartés sur le trackpad, puis déplacez-les de manière circulaire afin de faire pivoter l’élément à l’écran.

[Image: Deux doigts effectuant une rotation sur un trackpad de Mac, illustrant le geste de rotation.]

Passage d’une page à une autre

Effectuez un balayage à deux doigts vers la gauche ou vers la droite, pour afficher la page suivante ou la page précédente.

[Image: Main effectuant un geste de balayage à deux doigts sur un trackpad.]

Ouverture du centre de notifications

Effectuez un balayage à deux doigts vers la gauche, en partant de l’extrémité droite du trackpad.

[Image: Main effectuant le geste de glissement à trois doigts sur un trackpad de Mac.]

Glissement à trois doigts

Effectuez un balayage à trois doigts pour déplacer des éléments à l’écran, puis cliquez dessus ou touchez-les pour les déplacer. [Activez cette fonctionnalité dans les réglages d’accessibilité](https://support.apple.com/fr-fr/102341) .

[Image: Main effectuant un geste Multi-Touch sur un trackpad de Mac, illustrant la fonctionnalité du trackpad.]

Recherche et détection de données

Touchez le trackpad avec trois doigts afin de rechercher un mot ou réaliser d’autres actions ayant trait aux dates, adresses, numéros de téléphone, etc.

[Image: Main effectuant un geste Multi-Touch sur un trackpad de Mac.]

Affichage du bureau

Placez votre pouce et trois autres doigts sur votre trackpad, puis écartez-les pour afficher votre bureau.

[Image: Main utilisant un trackpad pour effectuer un geste Multi-Touch.]

Apps

Effectuez un pincement avec le pouce et trois autres doigts pour afficher vos applications installées.

[Image: Main effectuant un balayage vers le haut à quatre doigts sur un trackpad de Mac pour ouvrir Mission Control.]

Ouverture de Mission Control

Effectuez un balayage à quatre doigts vers le haut 2 pour ouvrir [Mission Control](https://support.apple.com/guide/mac-help/mh35798/mac) .

[Image: Main effectuant un geste sur le trackpad d’un Mac.]

Activation du mode App Exposé

Effectuez un balayage à quatre doigts vers le bas 2 pour afficher l’ensemble des fenêtres de l’app que vous utilisez.

[Image: Main utilisant un trackpad pour effectuer un geste Multi-Touch sur un Mac.]

Passage d’une app en mode plein écran à une autre

Effectuez un balayage horizontal à quatre doigts 2 pour basculer entre des apps en mode plein écran et le bureau.

## Gestes avec une Magic Mouse

Ces gestes nécessitent une Magic Mouse, et les modèles de Magic Mouse dotés d’un port USB-C nécessitent macOS Sequoia 15.1 ou version ultérieure.

Pour plus d’informations sur ces gestes, choisissez Réglages Système (ou Préférences Système) dans le menu Apple , puis cliquez sur Souris. Une fois dans cette fenêtre, vous pouvez activer ou désactiver un geste, modifier le type de geste associé à une action et découvrir comment fonctionnent les gestes sur votre Mac.

[Image: Clic secondaire (clic droit)]

Clic secondaire (clic droit)

Cliquez sur le côté droit de la souris.

[Image: Défilement]

Défilement

Effectuez un balayage à un doigt vers le haut ou vers le bas 1

[Image: Zoom intelligent]

Zoom intelligent

Avec un doigt, touchez deux fois la souris pour effectuer un zoom avant ou arrière dans une page web ou un PDF.

[Image: Ouverture de Mission Control]

Ouverture de Mission Control

Touchez deux fois la souris avec deux doigts pour ouvrir [Mission Control](https://support.apple.com/guide/mac-help/mh35798/mac) .

[Image: Image illustrant les gestes de la Magic Mouse.]

Passage d’une app en mode plein écran à une autre

Effectuez un balayage horizontal à deux doigts pour basculer entre des apps en mode plein écran et le bureau.

[Image: Passage d’une page à une autre]

Passage d’une page à une autre

Effectuez un balayage à un doigt vers la gauche ou vers la droite pour afficher la page suivante ou la page précédente.

## Gestes sur l’écran tactile

Sur un MacBook Pro doté d’un écran PROLED XDR, vous pouvez effectuer des gestes directement sur la surface de l’écran.

[En savoir plus sur les gestes tactiles sur l’écran PROLED XDR](https://support.apple.com/guide/macbook-pro-proled-xdr/wv2xzgrweunx/mac)
