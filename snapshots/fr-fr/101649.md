# Si des fichiers ne se synchronisent pas avec iCloud Drive depuis Windows car le chemin d’accès est trop long

Si une notification s’affiche sur votre PC pour vous indiquer que certains de vos fichiers dans iCloud Drive ne seront pas synchronisés, découvrez la marche à suivre.

[Image: Capture d’écran d’une notification d’erreur iCloud Drive sous Windows indiquant : « Certains fichiers du dossier ‘RootTooLong_abcdefghijklm…’ ne seront pas synchronisés, car le chemin d’accès est trop long. »]

## Un nom de fichier ou un chemin d’accès est peut-être trop long

Une notification relative à un chemin d’accès trop long peut signifier ce qui suit :

- Un ou plusieurs noms de fichier sont trop longs.

- Le chemin d’accès est trop long. Un chemin d’accès peut inclure le nom du fichier et les noms de tous les dossiers et sous-dossiers permettant d’accéder à son emplacement de stockage.

Dans iCloud pour Windows 10.8 ou version ultérieure, un nom de fichier ou un chemin d’accès trop long empêche la synchronisation d’avoir lieu, mais les autres fichiers continueront à être synchronisés dans iCloud Drive. Le chemin d’accès au fichier qui est trop long apparaît également dans la notification, afin de vous permettre de localiser aisément le fichier à l’aide de la fonction de recherche de fichier.

Dans iCloud pour Windows 10 ou version antérieure, un nom de fichier ou un chemin d’accès trop long interrompt la synchronisation avec iCloud Drive de tous les fichiers présents dans ce dossier. Afin de vous assurer que vos autres fichiers restent synchronisés avec iCloud Drive, [téléchargez la dernière version d’iCloud pour Windows](https://support.apple.com/HT204283) .

### Rechercher le nom du fichier ou son chemin d’accès

Si vous connaissez le chemin d’accès impliqué dans le problème de synchronisation avec iCloud Drive, vous pouvez peut-être retrouver le fichier à l’aide de la fonction de recherche de fichiers. Pour faciliter la synchronisation des fichiers avec iCloud Drive, remplacez le nom des fichiers, dossiers ou sous-dossiers dans le chemin d’accès par un nom comportant moins de 256 caractères.

Si vous renommez un fichier ou un dossier, il est possible que la modification ne soit pas prise en compte par certaines apps tierces.
