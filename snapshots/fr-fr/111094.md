# Déplacement du contenu de Logic Pro pour Mac et de MainStage

N’hésitez pas à déplacer vos bibliothèques de sons Logic Pro et MainStage vers un périphérique de stockage externe : vous libérerez ainsi de l’espace sur votre Mac.

La bibliothèque de sons contient tous les sons utilisés par les instruments logiciels fournis avec Logic Pro et MainStage. Si vous avez installé ces deux apps sur le même Mac, elles partageront la même bibliothèque de sons. Si vous déplacez cette dernière, elle le sera pour les deux apps.

Vous pouvez stocker la bibliothèque de sons sur un périphérique de stockage externe tel qu’un lecteur SSD ou une clé USB. Une même bibliothèque de sons ne peut pas servir sur deux Mac différents. Si vous possédez plusieurs Mac exécutant Logic Pro ou MainStage, chacun d’entre eux doit disposer de sa propre bibliothèque de sons.

La façon dont vous déplacez la bibliothèque de sons dépend de votre version de Logic Pro ou de MainStage :

[Déplacer la bibliothèque de sons dans Logic Pro 12 ou MainStage 4 (ou version ultérieure)](https://support.apple.com/fr-fr/111094#move_12)

[Déplacer la bibliothèque de sons dans Logic Pro 11.2.2 ou MainStage 3.7.1 (ou version antérieure)](https://support.apple.com/fr-fr/111094#move_11.2.2)

Veillez à cliquer sur Autoriser lorsque Logic Pro ou MainStage demande l’autorisation d’accéder au périphérique externe.

## Déplacer la bibliothèque de sons dans Logic Pro 12 ou MainStage 4 (ou version ultérieure)

Par défaut, le fichier contenant la bibliothèque de sons dans Logic Pro 12 ou MainStage 4 (ou version ultérieure) est stocké dans le dossier Musique. Vous pouvez le déplacer vers n’importe quel emplacement à tout moment, y compris sur un périphérique de stockage externe :

- Dans le dossier Musique de votre Mac, recherchez le fichier « Logic Pro Library.bundle ».

- Faites glisser le fichier vers un autre emplacement. Si vous avez copié le fichier sur un périphérique de stockage externe, vous pouvez supprimer le fichier d’origine pour libérer de l’espace sur votre Mac.

## Déplacer la bibliothèque de sons dans Logic Pro 11.2.2 ou MainStage 3.7.1 (ou version antérieure)

- Assurez-vous d’être [connecté à votre Mac en tant qu’administrateur](https://support.apple.com/guide/mac-help/set-up-other-users-mtusr001/mac) .

- Connectez le périphérique de stockage à votre Mac.

- Si votre périphérique de stockage n’est pas formaté pour être utilisé avec un Mac, utilisez Utilitaire de disque pour [formater votre périphérique de stockage externe pour APFS ou Mac OS étendu (journalisé)](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac) .

- Vous ne pouvez pas stocker la bibliothèque de sons sur un volume utilisé pour les sauvegardes Time Machine.

- Vous pouvez [ajouter un volume APFS](https://support.apple.com/guide/disk-utility/add-delete-or-erase-apfs-volumes-dskua9e6a110/mac) au périphérique de stockage externe, puis utiliser un volume pour les sauvegardes Time Machine et l’autre pour le stockage d’autres fichiers.

- Ouvrez Logic Pro, puis sélectionnez Logic Pro > Bibliothèque de sons > Déplacer la bibliothèque de sons, ou MainStage > Bibliothèque de sons > Déplacer la bibliothèque de sons.

- Si vous êtes invité à autoriser l’app à accéder aux fichiers sur un périphérique amovible, cliquez sur Autoriser.

- Dans la fenêtre, sélectionnez le périphérique de stockage ou le volume sur lequel vous souhaitez stocker la bibliothèque de sons, puis cliquez sur Déplacer. Une notification apparaît à l’écran une fois le déplacement de la bibliothèque de sons terminé.

Si un message d’erreur indique que le contenu ne peut pas être déplacé, [autorisez Logic Pro ou MainStage à accéder à votre périphérique de stockage externe ou à votre volume](https://support.apple.com/fr-fr/111094#allow) .

Ne renommez pas le périphérique de stockage ni le volume après avoir déplacé la bibliothèque de sons. En effet, Logic Pro et MainStage ne seraient pas en mesure de localiser la bibliothèque de sons.

### Donner à Logic Pro ou MainStage l’accès à votre périphérique de stockage externe

Si un message d’erreur indique que le contenu ne peut pas être déplacé, autorisez l’app à accéder à votre périphérique de stockage externe ou à votre volume.

- Quittez Logic Pro ou MainStage.

- Sur votre Mac, choisissez le menu Pomme  > Réglages Système.

- Cliquez sur Confidentialité et sécurité, puis dans la barre latérale.

- Cliquez sur Fichiers et dossiers à droite.

- Cliquez sur Logic Pro ou MainStage pour afficher les options, puis activez Volumes amovibles.

### Rapatrier la bibliothèque de sons sur votre Mac

Après avoir déplacé la bibliothèque de sons sur un périphérique de stockage externe, il se peut que vous souhaitiez la rapatrier sur votre Mac. Cela peut notamment s’avérer utile pour effectuer une performance sans avoir à apporter votre périphérique de stockage.

- Sélectionnez Logic Pro > Bibliothèque de sons > Déplacer la bibliothèque de sons, ou MainStage > Bibliothèque de sons > Déplacer la bibliothèque de sons.

- Dans la fenêtre, sélectionnez Macintosh HD, puis cliquez sur Déplacer.

## Télécharger du contenu supplémentaire

Le contenu supplémentaire pour la bibliothèque de sons Logic Pro ou MainStage que vous téléchargez à partir du site Apple est installé dans le nouvel emplacement. Pour télécharger du contenu supplémentaire, choisissez Logic Pro > Ouvrir la bibliothèque de sons, sélectionnez le contenu que vous voulez télécharger, puis cliquez sur Installer. Pour installer tous les contenus, cliquez sur Sélectionner tous les éléments non installés, puis sur Installer.

## Si le périphérique de stockage externe contenant la bibliothèque de sons n’est pas connecté

Si le périphérique de stockage externe qui contient la bibliothèque de sons n’est pas connecté à votre Mac lorsque vous ouvrez Logic Pro ou MainStage, voici ce que vous pouvez faire :

- Pour ouvrir Logic Pro ou MainStage et utiliser la bibliothèque de sons sur le périphérique de stockage, connectez l’appareil et cliquez sur Réessayer.

- Pour continuer à utiliser l’app sans le contenu de la bibliothèque de sons, cliquez sur Ignorer. Toutes les pistes incorporant du contenu de la bibliothèque de sons manquante seront remplacées par des sons basiques.

- Pour installer la bibliothèque de sons sur votre Mac, cliquez une fois sur Réinitialiser, puis une nouvelle fois sur le même bouton. Logic Pro ou MainStage utilisera la bibliothèque de sons installée sur votre Mac. Vous pouvez ensuite déplacer à nouveau la bibliothèque de sons vers votre périphérique de stockage.
