# GarageBand : l’application peut se fermer de manière inopinée lors de la modification du niveau d’entrée dans les leçons de guitare Apprendre à jouer

Lorsque vous ajustez le niveau d’entrée dans les leçons de guitare Apprendre à jouer, GarageBand peut se fermer de manière inopinée si vous utilisez un Apogee Duet 2.

Ajustez le niveau de la guitare sur l’Apogee Duet 2 ou dans le logiciel Apogee Maestro 2.

Ce document sera mis à jour lorsque de nouveaux renseignements seront disponibles.
