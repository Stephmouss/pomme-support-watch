# Installation de Windows 10 sur votre Mac via l’assistant Boot Camp

Avec Boot Camp, vous pouvez installer Microsoft Windows 10 sur votre Mac à processeur Intel, puis basculer entre macOS et Windows lors du redémarrage de votre Mac.

## Ce dont vous avez besoin pour installer Windows 10 sur un Mac

Boot Camp requiert l’un de ces modèles de Mac à processeur Intel :

- [MacBook](https://support.apple.com/fr-fr/103257) commercialisé de 2015 à 2017

- [MacBook Air](https://support.apple.com/fr-fr/102869) commercialisé de 2012 à 2020, à l’exclusion du MacBook Air (M1, 2020)

- [MacBook Pro](https://support.apple.com/fr-fr/108052) commercialisé de 2012 à 2020, à l’exclusion du MacBook Pro (13 pouces, M1, 2020)

- [Mac mini](https://support.apple.com/fr-fr/102852) commercialisé de 2012 à 2018

- [iMac](https://support.apple.com/fr-fr/108054) commercialisé de 2012 à 2020 1

- [iMac Pro](https://support.apple.com/fr-fr/108054) (tous les modèles)

- [Mac Pro](https://support.apple.com/fr-fr/102887) commercialisé de 2013 à 2019

Les [dernières mises à jour de macOS](https://support.apple.com/fr-fr/108382) , pouvant contenir des mises à jour de l’assistant Boot Camp. L’assistant Boot Camp vous permettra d’installer Windows 10.

64 Go ou plus [d’espace de stockage disponible](https://support.apple.com/fr-fr/102624) sur votre disque de démarrage Mac :

- Vous pouvez effectuer l’installation avec 64 Go d’espace de stockage disponible, mais il est recommandé de disposer d’au moins 128 Go pour une expérience optimale. Les mises à jour automatiques de Windows nécessitent un tel espace ou plus.

- Si vous possédez un iMac Pro ou un Mac Pro avec 128 Go de mémoire (RAM) ou plus, votre disque de démarrage a besoin d’au moins autant d’espace de stockage disponible que votre Mac a de mémoire. 2

Une clé USB externe d’une capacité de 16 Go ou plus, à moins que vous n’utilisiez un [Mac qui n’a pas besoin de clé pour installer Windows](https://support.apple.com/fr-fr/102622#more) .

Une version 64 bits de Windows 10 Famille ou Windows 10 Professionnel sur une image disque (ISO) ou un autre support d’installation. Si vous installez Windows sur votre Mac pour la première fois, il doit s’agir d’une version complète de Windows, et non d’une mise à niveau.

- Si votre copie de Windows vous a été fournie sur une clé USB ou si vous ne disposez que d’une clé de produit Windows et d’aucun disque d’installation, [téléchargez une image disque de Windows 10 depuis le site de Microsoft](https://www.microsoft.com/fr-fr/software-download/windows10) .

- Si votre copie de Windows vous a été fournie sur DVD, vous devrez peut-être [créer une image disque](https://support.apple.com/fr-fr/101335) de ce DVD.

## Installer Windows 10 sur un Mac

Pour installer Windows 10, utilisez l’assistant Boot Camp fourni avec votre Mac.

### Vérifier les réglages de démarrage sécurisé

Si vous utilisez un [Mac doté de la puce Apple T2 Security](https://support.apple.com/fr-fr/103265) , Sécurité maximale est le réglage de démarrage sécurisé par défaut. Si vous l’avez défini sur Aucune sécurité, [rétablissez-le sur Sécurité maximale](https://support.apple.com/fr-fr/102522) avant d’installer Windows. Après avoir installé Windows, vous pouvez utiliser n’importe quel réglage de démarrage sécurisé sans affecter votre capacité à démarrer à partir de Windows.

### Créer une partition Windows à l’aide de l’assistant Boot Camp

Ouvrez l’assistant Boot Camp à partir du sous-dossier Utilitaires de votre dossier Applications. Suivez les instructions à l’écran.

- Si un message vous invite à insérer une clé USB, branchez la vôtre sur votre Mac. L’assistant Boot Camp l’utilisera pour créer un lecteur USB démarrable pour l’installation de Windows.

- Lorsque l’assistant Boot Camp vous demande de définir la taille de la partition Windows, n’oubliez pas les [exigences concernant l’espace de stockage](https://support.apple.com/fr-fr/102622#storage) minimum figurant dans la section précédente. Fixez une taille de partition qui répond à vos besoins, car vous ne pourrez plus modifier cette valeur par la suite.

### Formater la partition Windows (BOOTCAMP)

À la fin de l’assistant Boot Camp, votre Mac redémarre, puis affiche le programme d’installation de Windows. Si le programme d’installation demande où installer Windows, sélectionnez la partition BOOTCAMP et cliquez sur Formater. Dans la plupart des cas, le programme d’installation sélectionne et formate automatiquement la partition BOOTCAMP.

### Installer Windows

Débranchez tous les périphériques externes qui ne sont pas nécessaires pendant l’installation. Cliquez sur Suivant et suivez les instructions à l’écran pour démarrer l’installation de Windows.

### Utiliser le programme d’installation de Boot Camp sous Windows

Une fois l’installation de Windows terminée, votre Mac démarre sous Windows et ouvre la fenêtre de bienvenue du programme d’installation de Boot Camp. Suivez les instructions à l’écran pour installer Boot Camp ainsi que les pilotes de Windows. Lorsque vous avez terminé, vous êtes invité à redémarrer l’ordinateur.

- Si le programme d’installation de Boot Camp ne s’ouvre pas, [ouvrez-le manuellement](https://support.apple.com/fr-fr/102320) pour procéder à l’installation de Boot Camp.

- Si un écran externe est connecté à un [port Thunderbolt 3](https://support.apple.com/fr-fr/109523) de votre Mac, cet écran restera vide (écran noir, gris ou bleu) pendant environ deux minutes lors de l’installation.

## Basculer entre Windows et macOS

Redémarrez l’ordinateur, puis maintenez la touche Option (ou Alt) ⌥ enfoncée pendant le démarrage pour [basculer entre Windows et macOS](https://support.apple.com/fr-fr/102450) .

## Informations supplémentaires

Si vous possédez l’un des modèles de Mac à processeur Intel suivants, exécutant [OS X El Capitan ou version ultérieure](https://support.apple.com/fr-fr/109033) , vous n’avez pas besoin d’une clé USB pour installer Windows :

- [MacBook](https://support.apple.com/fr-fr/103257) (tous les modèles)

- [MacBook Air](https://support.apple.com/fr-fr/102869) commercialisé à partir de 2017 3

- [MacBook Pro](https://support.apple.com/fr-fr/108052) commercialisé à partir de 2015 3

- [iMac](https://support.apple.com/fr-fr/108054) commercialisé à partir de 2015

- [iMac Pro](https://support.apple.com/fr-fr/108054) (tous les modèles)

- [Mac Pro](https://support.apple.com/fr-fr/102887) commercialisé à partir de fin 2013

[Pour supprimer Windows de votre Mac, utilisez l’assistant Boot Camp](https://support.apple.com/guide/bootcamp-assistant/remove-windows-from-your-mac-using-boot-camp-bcmp59c41c31/mac) , et non un autre utilitaire.

Pour en savoir plus au sujet de l’utilisation de Windows sur votre Mac, ouvrez l’assistant Boot Camp et cliquez sur le bouton Ouvrir l’aide Boot Camp.

- Si vous possédez un iMac (Retina 5K, 27 pouces, fin 2014), un iMac (27 pouces, fin 2013) ou un iMac (27 pouces, fin 2012) doté d’un disque dur de 3 To et de macOS Mojave 10.14 ou version ultérieure, [une alerte peut s’afficher lors de l’installation](https://support.apple.com/fr-fr/100741) .

- Par exemple, si votre Mac dispose de 128 Go de mémoire, au moins 128 Go d’espace de stockage doivent être disponibles pour Windows sur votre disque de démarrage. Pour connaître la quantité de mémoire installée sur votre Mac, choisissez À propos de ce Mac dans le menu Pomme . Pour vérifier la quantité d’espace de stockage disponible, cliquez sur l’onglet Stockage dans la même fenêtre. Sous macOS Ventura 13 ou version ultérieure, choisissez Réglages Système dans le menu Pomme , cliquez sur Général dans la barre latérale, puis sur Stockage à droite.

- Une option proposée sur ces modèles de Mac était un disque dur de 128 Go. Apple recommande des disques durs de 256 Go ou plus afin de pouvoir créer une partition Boot Camp d’au moins 128 Go.
