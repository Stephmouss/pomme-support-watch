# Activer ou désactiver le mode Navigation privée sur votre iPad

Lorsque vous utilisez la navigation privée, les détails de votre navigation ne sont pas enregistrés et les sites web que vous visitez ne sont pas partagés avec vos autres appareils. Safari ne garde pas en mémoire les pages que vous consultez, votre historique de recherches ou les informations nécessaires au remplissage automatique.

## Activer le mode Navigation privée

- Ouvrez Safari sur votre iPad.

- Appuyez de façon prolongée sur le bouton Onglets .

[Image: null]

- Touchez Nouvel onglet privé.

[Image: iPad avec le menu des options de l’onglet Safari ouvert]

Lorsque la navigation privée est activée, la barre d’adresse de Safari apparaît noire ou sombre au lieu d’être blanche ou grise.

## Désactiver le mode Navigation privée

- Touchez le bouton Onglets .

[Image: null]

- Touchez [nombre] onglets ou touchez Page de démarrage.

[Image: iPad avec la vue Onglets Safari ouverte]
