# Carte RAID pour Mac Pro ou pour Xserve : le volume peut ne pas être monté après un arrêt ou un redémarrage incorrect

Après un arrêt ou un redémarrage incorrect :

- Les systèmes dotés d’une carte RAID pour Mac Pro ou pour Xserve peuvent démarrer avec un point d’interrogation clignotant, ou les volumes RAID peuvent ne pas être montés. L’utilitaire RAID peut indiquer que les volumes, les matrices RAID et les disques sont tous à l’état Opérant ou Bon.

- Un Xserve configuré avec un SSD et Mac OS X Server installé sur le SSD peuvent démarrer, mais le ou les volumes RAID configurés sur la carte RAID peuvent ne pas être montés.

Ces symptômes peuvent se produire si la carte LUN a été endommagée et doit être recréée.

## Démarrage à partir de différents supports et collecte d’informations

- Démarrez à partir d’un autre support amorçable, tel qu’un DVD d’installation, un disque FireWire externe ou un lecteur USB, ou le SSD interne avec un Xserve (début 2009).

- Ouvrez Informations Système et sélectionnez la vue « Matériel RAID » dans la barre latérale gauche.

- Vérifiez que les volumes, la matrice RAID et les lecteurs sont tous à l’état Opérant ou Bon.

- Dans la vue « Matériel RAID », accédez à Périphérique RAID > Carte RAID pour Xserve (ou Mac Pro) > Volumes. ## Résolution du problème

Remarque : ce processus peut être utilisé sur les volumes RAID amorçables sur lesquels Mac OS X 10.5.x, 10.6.x ou OS X Lion est installé. Le système d’exploitation ne sera pas mis à jour sur le volume RAID concerné.

### Pour le Xserve (début 2009) qui a été configuré avec un SSD

- Mettez à jour le logiciel Server installé sur le SSD vers Mac OS X Server 10.6.7 ou version ultérieure. Si Lion Server est installé, effectuez la mise à jour vers la version actuelle de Lion Server.

- Redémarrez le Xserve.

- Attendez que les volumes RAID soient montés. Cette opération peut prendre quelques minutes.

- Une fois les volumes montés, redémarrez le Xserve à partir du volume de démarrage habituel. Cela permettra au serveur de démarrer avec les volumes RAID disponibles au démarrage.

- Ouvrez l’utilitaire RAID.

- Sous « Contrôleur », cliquez sur « État ». La sous-fenêtre Évènements de la fenêtre de l’utilitaire RAID doit contenir une entrée pour chaque volume dont la carte LUN a été recréée.

### Pour les Mac Pro, Xserve (fin 2006), Xserve (début 2008) et Xserve (début 2009) sans SSD

- Installez Mac OS X 10.6.x ou OS X Lion (serveur ou client) sur un disque USB ou FireWire externe. Utilisez Mac OS X Server 10.6 pour les systèmes de serveurs ou Mac OS X 10.6 pour les systèmes clients.

- Si vous utilisez Mac OS X 10.6, effectuez une mise à jour vers Mac OS X 10.6.7 (serveur ou client) ou version ultérieure. Si OS X Lion (serveur ou client) est installé, effectuez la mise à jour vers la version actuelle de Lion.

- Démarrez le système concerné à partir du disque externe.

- Attendez que les volumes RAID soient montés. Cette opération peut prendre quelques minutes.

- Redémarrez le système à partir du volume de démarrage habituel.

- Ouvrez l’utilitaire RAID.

- Sous « Contrôleur », cliquez sur « État ». La sous-fenêtre Évènements de la fenêtre de l’utilitaire RAID doit contenir une entrée pour chaque volume dont la carte LUN a été recréée.

## Informations supplémentaires

Il est préférable d’effectuer cette procédure avec les disques installés sur l’ordinateur sur lequel ils se trouvent habituellement. Toutefois, il est possible de transférer les lecteurs vers un autre ordinateur configuré de la même manière et d’effectuer cette procédure sur les volumes RAID.

Le cas échéant, cette procédure doit être effectuée avec prudence.

Remarques

- Veillez à étiqueter tous les disques avec le numéro de baie dans lequel ils se trouvent actuellement afin de pouvoir les réinstaller dans le même ordre.

- Les matrices RAID configurées sur un Mac Pro (début 2009) ou un Mac Pro (mi-2010) ne seront pas reconnues sur un Mac Pro (original) ou un Mac Pro (début 2008).

- Les matrices RAID configurées sur un Xserve (début 2009) ne seront pas reconnues sur un Xserve (fin 2006) ou un Xserve (début 2008).

- Les modules de disques Apple déplacés depuis un Xserve (fin 2006) ou un Xserve (début 2008) ne doivent être déplacés que vers un autre Xserve (fin 2006) ou Xserve (début 2008). S’ils sont insérés dans un Xserve (début 2009), ils ne seront plus reconnus par la carte RAID pour Xserve dans le Xserve (fin 2006) ou le Xserve (début 2008) dans lequel ils ont été installés à l’origine. Le déplacement des lecteurs ou des modules de disques Apple vers les modèles Mac Pro (début 2009), Mac Pro (mi-2010) ou Xserve permet d’effectuer une migration matérielle sur les lecteurs.

- Si un autre Mac Pro est utilisé pour réparer le volume RAID, une carte RAID pour Mac Pro doit y être installée.

- Si un autre Xserve est utilisé pour réparer le volume RAID, une carte RAID pour Xserve doit y être installée.

- Si le volume RAID en cours de réparation a été configuré sur un Mac Pro (original) ou un Mac Pro (début 2008), le Mac Pro utilisé pour réparer le volume RAID ne peut être que l’un de ces deux modèles.

- Si le volume RAID en cours de réparation a été configuré sur un Mac Pro (début 2009) ou un Mac Pro (mi-2010), le Mac Pro utilisé pour réparer le volume RAID ne peut être que l’un de ces deux modèles.

- Si le volume RAID en cours de réparation a été configuré sur un Xserve (fin 2006) ou un Xserve (début 2008), le Xserve utilisé pour réparer le volume RAID peut être l’un de ces deux modèles.

- Si le volume RAID en cours de réparation a été configuré sur un Xserve (début 2009), le Xserve utilisé pour réparer le volume RAID doit également être un Xserve (début 2009).
