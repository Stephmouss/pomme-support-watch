# Utilisation de votre HomePod sur un réseau Wi-Fi 802.1X

Le HomePod peut se connecter à de nombreux réseaux Wi-Fi 802.1X de campus ou d’entreprise. Découvrez quels sont les réseaux pris en charge et comment vous y connecter.

Le HomePod peut rejoindre la plupart des réseaux Wi-Fi 802.1X et des réseaux captifs nécessitant des étapes de connexion supplémentaires, comme ceux des hôtels ou des résidences universitaires. Si votre réseau Wi-Fi 802.1X exige un certificat d’identité unique pour chaque appareil, installez un profil de configuration pour vous y connecter.

## Vérifier la configuration du réseau

Votre HomePod peut se connecter à des réseaux Wi-Fi 802.1X qui ne nécessitent pas de mot de passe à usage unique et qui utilisent l’un des types d’authentification suivants :

- PEAP

- EAP-TLS

- EAP-TTLS

- EAP-FAST

## Configurer votre HomePod

Avant de pouvoir vous connecter à un réseau Wi-Fi 802.1X, [configurez votre HomePod](https://support.apple.com/HT208241) sur un réseau Wi-Fi domestique ou privé, puis [mettez à jour votre HomePod et votre appareil iOS vers la dernière version](https://support.apple.com/HT208247) .

## Se connecter à un réseau Wi-Fi 802.1X

Vous pouvez partager la configuration Wi-Fi de votre iPhone ou iPad avec votre HomePod, ou installer un profil de configuration pour vous connecter automatiquement.

### Partager la configuration Wi-Fi de votre iPhone ou iPad

- Sur votre iPhone ou iPad, connectez-vous au réseau Wi-Fi 802.1X.

- Ouvrez l’app Maison.

- Touchez le HomePod, puis l’engrenage en bas à droite.

- Touchez « Connecter le HomePod à [nom du réseau] ».

- Une fois que votre HomePod est connecté au nouveau réseau, touchez Terminé.

### Se connecter automatiquement à l’aide d’un profil

Vous pouvez installer un profil de configuration permettant de connecter automatiquement le HomePod à un réseau Wi-Fi 802.1X. Votre administrateur réseau peut distribuer un profil par l’intermédiaire d’un site web ou d’un e-mail. Touchez le profil sur votre iPhone ou iPad, puis choisissez votre HomePod. Si votre HomePod n’apparaît pas, choisissez Autres appareils, puis sélectionnez-le. Ensuite, laissez-vous guider pour terminer l’installation.

## Trouvez votre adresse MAC

Votre administrateur réseau peut avoir besoin de l’adresse Wi-Fi de votre HomePod pour autoriser l’accès à certains réseaux Wi-Fi. Voici comment le trouver :

- Ouvrez l’app Maison sur votre iPhone ou iPad.

- Touchez le HomePod, puis l’engrenage en bas à droite.

- Pour les haut-parleurs du HomePod jumelés en stéréo, faites défiler vers le bas et touchez Haut-parleurs, puis touchez de manière prolongée le HomePod individuel.

- Faites défiler l’écran vers le bas pour trouver le nom de votre réseau Wi-Fi.

- Touchez le nom de votre réseau Wi-Fi pour révéler votre adresse Wi-Fi.

## Si le message « Certaines fonctionnalités peuvent être inutilisables sur ce réseau » apparaît lors de la configuration

Si vous configurez votre HomePod et que le message « Certaines fonctionnalités peuvent être inutilisables sur ce réseau » apparaît, vous êtes peut-être connecté à un réseau avec des capacités limitées.

Les paires stéréo HomePod, les requêtes personnelles, les minuteurs, l’utilisation du HomePod comme interphone et le son home cinéma avec le HomePod et l’Apple TV ne sont pas pris en charge sur les réseaux qui bloquent les communications pair-à-pair. Si ces fonctionnalités ne sont pas disponibles, contactez votre administrateur réseau.
