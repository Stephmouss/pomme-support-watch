# Si des événements apparaissent en double dans Calendrier iCloud

Voici comment masquer ou supprimer des calendriers ou des évènements sur votre iPhone, iPad, Mac ou PC.

## Masquer et afficher des calendriers

### Sur votre iPhone ou iPad

- Dans l’app Calendrier, touchez Calendriers.

- Dans la liste Calendriers, cochez ou désactivez la case d’un calendrier pour afficher ou masquer les événements associés.

- Touchez OK.

Si vous le souhaitez, vous pouvez également [vous désabonner des calendriers indésirables sur votre iPhone](https://support.apple.com/fr-fr/102444) .

### Sur votre Mac

- Dans l’app Calendrier, sélectionnez Afficher > Afficher la liste des calendriers.

- Dans la liste Calendriers, cochez ou désactivez la case d’un calendrier pour afficher ou masquer les événements associés. Pour afficher ou masquer les événements de tous les calendriers, maintenez la touche Commande enfoncée tout en sélectionnant ou désélectionnant la case d’un calendrier.

## Masquer et afficher les jours fériés et les anniversaires

### Sur votre iPhone ou iPad

- Dans l’app Calendrier, touchez Calendriers.

- Sélectionnez Jours fériés [pays] et Anniversaires pour ajouter à vos évènements les jours fériés de votre pays et les anniversaires récupérés à partir de Contacts, ou désélectionnez ces options pour les masquer de votre vue de calendrier.

- Touchez OK.

Si l’anniversaire de l’un de vos contacts apparaît plusieurs fois, vérifiez que vous n’avez pas enregistré plusieurs fiches de contact pour cette personne. Ouvrez l’app Contacts, touchez le champ de recherche situé en haut de l’écran, puis saisissez le nom du contact. Si plusieurs résultats apparaissent pour ce contact, touchez son nom, puis touchez Modifier pour gérer, supprimer ou regrouper ses coordonnées.

### Sur votre Mac

- Dans l’app Calendrier, sélectionnez Calendrier > Réglages, puis cliquez sur Général.

- Sélectionnez Afficher le calendrier des anniversaires ou Afficher le calendrier des jours de fête, ou désélectionnez ces options pour les masquer de votre vue de calendrier.

## Supprimer les calendriers locaux

### Sur votre Mac

- [Créez une copie des données de vos calendriers iCloud](https://support.apple.com/fr-fr/108306) .

- Cliquez sur Réglages > Comptes, puis cliquez sur le calendrier que vous souhaitez supprimer.

- Cliquez sur le signe moins dans l’angle inférieur gauche.

### Sur votre PC

- [Créez une copie des données de vos calendriers iCloud](https://support.apple.com/fr-fr/108306) .

- Dans la section Mes calendriers, effectuez un clic droit sur le calendrier à supprimer et choisissez Supprimer le calendrier. Dans Outlook, il est impossible de supprimer le calendrier par défaut. Vous devriez toutefois être en mesure de supprimer tous les autres calendriers, si vous disposez des autorisations appropriées.
