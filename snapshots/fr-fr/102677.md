# Modifier votre code de Temps d’écran sur un iPhone ou un iPad

Avec un code de Temps d’écran, vous vous assurez que les réglages que vous choisissez pour l’appareil de votre enfant ou le vôtre restent en vigueur. Découvrez la marche à suivre si vous avez oublié le code de Temps d’écran ou si vous souhaitez simplement le modifier.

- [Fonctionnement d’un code de Temps d’écran](https://support.apple.com/fr-fr/102677#how)

- [Réinitialiser le code de Temps d’écran sur l’iPhone ou l’iPad de votre enfant](https://support.apple.com/fr-fr/102677#reset-child)

- [Réinitialiser le code de Temps d’écran sur votre iPhone ou iPad](https://support.apple.com/fr-fr/102677#reset)

- [Si vous ne parvenez pas à réinitialiser votre code de Temps d’écran](https://support.apple.com/fr-fr/102677#cant-reset)

## Fonctionnement d’un code de Temps d’écran

Le code de Temps d’écran n’est pas le même que le code de déverrouillage de votre appareil. Il est important de vous souvenir de votre code de Temps d’écran, car vous en avez besoin pour modifier les réglages, les limites ou les restrictions de votre appareil ou de celui d’un enfant.

Pour que vos réglages Temps d’écran se synchronisent sur tous les appareils de votre groupe de partage familial, mettez à jour tous les appareils vers la dernière version de leur logiciel avant d’activer ou de modifier vos réglages Temps d’écran. Si vous avez activé l’option Partager entre les appareils, votre code est automatiquement mis à jour sur les appareils concernés après la réinitialisation.

Si vous utilisez le [partage familial](https://support.apple.com/108380) pour gérer le compte Apple d’un enfant, la personne responsable du partage familial, un parent ou un tuteur/une tutrice doit définir le code de Temps d’écran sur son propre appareil, pas sur celui de l’enfant.

## Réinitialiser le code de Temps d’écran sur l’iPhone ou l’iPad d’un enfant

Ces étapes s’appliquent à iOS 27 et iPadOS 27 et versions ultérieures. Découvrez comment [configurer un code de Temps d’écran pour l’appareil de votre enfant sous iOS 26 ou version antérieure](https://support.apple.com/guide/iphone/create-manage-track-a-screen-time-passcode-iph272b4c4bd/26/ios/26) .

- Sur l’appareil du responsable familial ou du parent/tuteur, ouvrez l’app Réglages.

- Touchez Famille, puis le nom de votre enfant. Si le nom de votre enfant n’apparaît pas sous Famille, assurez-vous que vous êtes tous les deux connectés à vos appareils avec votre propre compte Apple et que le compte de votre enfant fait partie du groupe de Partage familial.

- Touchez Code et gestion. Si vous ne voyez pas Code et gestion, vous devrez peut-être d’abord [configurer les contrôles d’utilisation et parentaux](https://support.apple.com/108806) , puis configurer un code de Temps d’écran.

- Touchez l’option Modifier le code de « Temps d’écran », puis répétez cette opération.

- Saisissez votre ancien code de Temps d’écran.

- Saisissez un nouveau code, puis répétez l’opération afin de le confirmer.

## Réinitialiser le code de Temps d’écran pour votre iPhone ou iPad

Ces étapes s’appliquent à iOS 27 et iPadOS 27 et versions ultérieures. Découvrez comment [configurer un code de Temps d’écran pour l’appareil de votre enfant sous iOS 26 ou version antérieure](https://support.apple.com/guide/iphone/create-manage-track-a-screen-time-passcode-iph272b4c4bd/26/ios/26) .

- Ouvrez l’app Réglages, puis touchez Temps d’écran.

- Touchez Code et gestion.

- Touchez l’option Modifier le code de « Temps d’écran », puis répétez cette opération. Vous devez vous authentifier avec Face ID ou saisir le code utilisé pour déverrouiller l’appareil. Le cas échéant, saisissez l’adresse e-mail de votre compte Apple et le mot de passe que vous avez utilisés pour configurer le code de Temps d’écran.

- Saisissez un nouveau code, puis répétez l’opération afin de le confirmer.

Il est recommandé de ne pas passer l’étape d’ajout d’un code de secours pour Temps d’écran. Si vous oubliez votre code de Temps d’écran, vous pourrez ainsi le réinitialiser à l’aide de votre compte Apple. Si vous devez récupérer votre code de Temps d’écran, vous devez utiliser le même compte que celui saisi lors de la configuration initiale de la récupération du code de Temps d’écran.

## Si vous ne parvenez pas à réinitialiser votre code de Temps d’écran

Si vous ne parvenez pas à réinitialiser votre code de Temps d’écran, vérifiez que vous utilisez bien la même adresse e-mail et le même mot de passe de compte Apple que ceux utilisés pour configurer le code de Temps d’écran. Il peut s’agir d’un autre compte Apple que celui auquel vous êtes connecté sur votre appareil. Si vous faites partie d’un groupe de partage familial, il peut s’agir du compte Apple d’un membre de votre famille ou de celui d’un enfant.
