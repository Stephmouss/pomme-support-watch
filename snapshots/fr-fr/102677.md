# Si vous avez oublié le code d’accès de Temps d’écran d’un iPhone ou d’un iPad

Avec un code de Temps d’écran, vous pouvez veiller à ce que les réglages que vous choisissez pour l’appareil de votre enfant restent en vigueur. Découvrez la marche à suivre si vous oubliez votre code de Temps d’écran ou si vous souhaitez simplement le réinitialiser.

- [Fonctionnement d’un code de Temps d’écran](https://support.apple.com/fr-fr/102677#how)

- [Réinitialiser le code de Temps d’écran sur l’iPhone ou l’iPad de votre enfant](https://support.apple.com/fr-fr/102677#reset-child)

- [Réinitialiser le code de Temps d’écran sur votre iPhone ou iPad](https://support.apple.com/fr-fr/102677#reset)

- [Si vous ne parvenez pas à réinitialiser votre code de Temps d’écran](https://support.apple.com/fr-fr/102677#cant-reset)

## Fonctionnement d’un code de Temps d’écran

Le code de Temps d’écran n’est pas le même que le code de déverrouillage de votre appareil. Il est important de vous souvenir de votre code de Temps d’écran, car vous en avez besoin pour modifier les réglages, les limites ou les restrictions de votre appareil ou de celui d’un enfant.

Pour que vos réglages Temps d’écran se synchronisent sur tous les appareils de votre groupe de partage familial, mettez à jour tous les appareils vers la dernière version de leur logiciel avant d’activer ou de modifier vos réglages Temps d’écran. Si vous avez activé l’option Partager entre les appareils, votre code est automatiquement mis à jour sur les appareils concernés après la réinitialisation.

Si vous utilisez le [partage familial](https://support.apple.com/108380) pour gérer le compte Apple d’un enfant, le responsable familial doit réinitialiser le code de Temps d’écran sur son propre appareil et non sur celui de l’enfant.

## Réinitialiser le code de Temps d’écran sur l’iPhone ou l’iPad d’un enfant

- Sur l’appareil du responsable familial, ouvrez l’app Réglages, puis touchez Temps d’écran.

- Demandez au client de faire défiler l’écran vers le bas et de sélectionner le nom de l’enfant sous Famille.

- Sous Restrictions, touchez Gérer le temps d’écran.

- Touchez l’option Modifier le code de « Temps d’écran », puis répétez cette opération.

- Saisissez un nouveau code, puis répétez l’opération afin de le confirmer.

## Réinitialiser le code de Temps d’écran pour votre iPhone ou iPad

- Ouvrez l’app Réglages, puis touchez Temps d’écran.

- Touchez l’option Modifier le code de « Temps d’écran », puis répétez cette opération.

- Le cas échéant, saisissez l’adresse e-mail de votre compte Apple et le mot de passe que vous avez utilisés pour configurer le code d’accès Temps d’écran. [Vous avez oublié le mot de passe de votre compte Apple](https://support.apple.com/102656) ?

- Saisissez un nouveau code, puis répétez l’opération afin de le confirmer.

Il est recommandé de ne pas passer l’étape d’ajout d’un code de secours pour Temps d’écran. Si vous oubliez votre code de Temps d’écran, vous pourrez ainsi le réinitialiser à l’aide de votre compte Apple. Si vous avez plusieurs comptes Apple, vous devez utiliser le même que celui que vous avez saisi lors de la configuration de votre code de secours pour Temps d’écran.

## Si vous ne parvenez pas à réinitialiser votre code de Temps d’écran

Si vous ne parvenez pas à réinitialiser votre code de Temps d’écran, vérifiez que vous utilisez bien la même adresse e-mail et le même mot de passe de compte Apple que ceux utilisés pour configurer le code de Temps d’écran. Il peut s’agir d’un autre compte Apple que celui auquel vous êtes connecté sur votre appareil. Si vous faites partie d’un groupe de partage familial, il peut s’agir du compte Apple d’un membre de votre famille ou de celui d’un enfant.
