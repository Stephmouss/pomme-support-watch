# Si vous ne parvenez pas à afficher les réglages de mappage des ports d’une borne d’accès AirPort après une mise à niveau d’OS X Server

Utilisez Trousseaux d’accès si vous ne parvenez pas à gérer une borne d’accès AirPort après une mise à niveau vers une nouvelle version d’OS X Server.

Après une mise à niveau ou une migration vers une nouvelle version d’OS X Server, il est possible que vous ne puissiez pas consulter ou gérer les réglages d’une borne d’accès AirPort Extreme ou AirPort Time Capsule que vous gériez précédemment à l’aide de l’app Serveur. Pour résoudre ce problème, supprimez l’entrée du trousseau correspondant à la borne d’accès concernée, à l’aide de l’utilitaire Trousseaux d’accès.

Avant d’effectuer ces étapes, assurez-vous que vous connaissez le mot de passe de votre borne d’accès. Le mot de passe permettant de gérer l’appareil peut être différent de celui utilisé avec le réseau Wi-Fi. Si vous ne connaissez pas ce mot de passe, vous pouvez le réinitialiser à partir de la borne d’accès.

- Quittez l’app Serveur si celle-ci est ouverte.

- Ouvrez Trousseaux d’accès à partir du dossier Utilitaires.

- À gauche de la fenêtre Trousseaux d’accès, sélectionnez le trousseau « Système ».

- Recherchez l’élément du trousseau correspondant à votre borne d’accès AirPort. Le « type » indiqué pour cet élément est « Mot de passe de la borne d’accès AirPort ».

- Sélectionnez cet élément du trousseau.

- Choisissez Édition > Supprimer pour supprimer cet élément.

- Saisissez un nom et un mot de passe d’administrateur lorsque vous y êtes invité.

- Ouvrez l’app Serveur.

Vous devriez à présent pouvoir cliquer sur la borne d’accès AirPort dans la colonne de gauche de l’app Serveur et vous authentifier. Cette opération crée une entrée de mot de passe dans le trousseau du système.
