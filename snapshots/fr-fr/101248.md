# Point de montage dupliqué dans /Volumes après un redémarrage inattendu

Si Mac OS X ou Mac OS X Server redémarre de manière inattendue, il se peut que le point de montage actuel répertorié dans /Volumes ne soit pas supprimé et qu’un nouveau (« faux ») point de montage, avec l’ajout d’un « 1 » à son nom, apparaisse (par exemple, « Mon volume 1 »). Cela peut entraîner des problèmes pour les applications qui dépendent du chemin d’accès à certains fichiers situés dans des volumes secondaires.

La procédure suivante pour Mac OS X Server permet de supprimer les points de montage dupliqués dans /Volumes. Remarque : le « faux » point de montage peut ou non être le volume dont le nom se termine par « 1 ». Dans le Finder, utilisez Lire les informations (ou utilisez du -sk dans la ligne de commande) pour identifier le point de montage de taille inférieure. Le plus petit est probablement le « faux » point de montage.

- Sur le serveur, connectez-vous au Finder en tant qu’utilisateur root ou administrateur.

- Si vous vous êtes connecté en tant qu’utilisateur root, ouvrez Gestionnaire de groupe de travail et connectez-vous en tant qu’utilisateur administrateur local, puis arrêtez tous les services de fichiers.

- Dans le Finder, accédez à /Volumes.

- Copiez le dossier du point de montage incorrect (ou « faux ») sur le bureau ou dans un autre volume. Ceci garantit qu’aucune donnée placée par inadvertance dans le faux point de montage ne sera perdue.

- Dans /Volumes, supprimez le dossier du « faux » point de montage vide. Authentifiez-vous si vous y êtes invité.

- Redémarrez le serveur.

Solution alternative avec la ligne de commande

Vous pouvez également suivre cette procédure à l’aide de la ligne de commande.

- Arrêtez et redémarrez le serveur.

- Démarrez en mode utilisateur unique.

- Saisissez la commande ci-dessous et appuyez sur Retour : mount -uw /

- Saisissez la commande ci-dessous et appuyez sur Retour : cd /Volumes

- Saisissez la commande ci-dessous et appuyez sur Retour pour déplacer le contenu du faux point de montage : mv "FalseVolumeName" /

- Saisissez reboot et appuyez sur Retour.

L’ordinateur redémarrera et montera le volume comme prévu.

Une fois que toutes les données du « faux » point de montage ont été copiées dans le volume où elles devraient se trouver, vous pouvez supprimer le dossier « FalseVolumeName » du volume de démarrage.
