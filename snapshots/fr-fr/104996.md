# Utiliser les apps web Safari sur Mac

À partir de macOS Sonoma 14, vous pouvez enregistrer une page web dans Safari en tant qu’app web, de façon à pouvoir y accéder en dehors de Safari. Les apps web offrent une expérience simplifiée, semblable à celle d’une app, et un accès facile à partir du Dock.

- [Créer une app web à partir d’une page web](https://support.apple.com/fr-fr/104996#create)

- [Changer les réglages d’une app web](https://support.apple.com/fr-fr/104996#settings)

- [Utiliser les notifications avec une app web](https://support.apple.com/fr-fr/104996#notifications)

## Quelle est la différence entre une app web et une page web ?

Lorsque vous utilisez une page web en tant qu’app web, celle-ci se comporte comme dans Safari. Pourtant, l’expérience d’utilisation d’une app web diffère de plusieurs façons.

- Une app web fonctionne indépendamment de Safari. Elle ne partage pas d’historique de navigation, de cookies, de données de site web, ni de [réglages](https://support.apple.com/fr-fr/104996#settings) avec Safari. Votre navigation reste ainsi séparée, comme avec [l’utilisation d’un profil Safari](https://support.apple.com/fr-fr/105100) . Ce que vous faites dans une app web reste dans l’app web.

- Une app web possède une barre d’outils simplifiée, avec un bouton Précédent, un bouton Suivant, un bouton Partager et des boutons liés aux éventuelles [extensions Safari](https://support.apple.com/fr-fr/102343) que vous avez installées. Si vous avez besoin de fonctionnalités Safari telles que des signets ou des onglets, vous pouvez facilement passer à Safari : cliquez sur le bouton Partager , puis choisissez Ouvrir dans Safari.

[Image: bouton Partager]

- Une app web peut avoir le nom ou l’icône de votre choix.

- Pour les sites web qui envoient des notifications, l’icône de l’app web dans le Dock peut afficher le nombre de notifications non lues.

Pour presque tout le reste, une app web fonctionne comme n’importe quelle autre app. Vous pouvez même l’ajouter aux éléments d’ouverture afin qu’elle [se lance automatiquement lorsque vous ouvrez une session](https://support.apple.com/guide/mac-help/mh15189/mac) .

## Créer une app web à partir d’une page web

Nécessite [macOS Sonoma 14 ou version ultérieure](https://support.apple.com/fr-fr/109033)

- Dans Safari, ouvrez la page web que vous souhaitez utiliser en tant qu’app web.

- Dans la barre de menus, choisissez Fichier > Ajouter au Dock. Vous pouvez également cliquer sur le bouton Partager dans la barre d’outils de Safari, puis choisir Ajouter au Dock.

[Image: bouton Partager]

- Saisissez le nom que vous souhaitez utiliser pour l’app web, puis cliquez sur Ajouter. L’app web est enregistrée dans le dossier Applications de votre dossier de départ et vous pouvez l’ouvrir à partir du Dock ou de Spotlight.

[Image: Invite qui apparaît après que vous avez choisi Ajouter au Dock.]

## Changer les réglages d’une app web

Ouvrez l’app web, cliquez sur le nom de l’app dans la barre de menus, puis choisissez Réglages dans le menu.

- Nom de l’application : saisissez un nouveau nom pour l’app.

- URL de l’application : saisissez une nouvelle URL pour l’app ou cliquez sur Utiliser la page active.

- Icône : cliquez sur l’icône présentée, puis choisissez une nouvelle image dans la boîte de dialogue qui s’affiche. Cette image devient la nouvelle icône de votre app web.

- Afficher les commandes de navigation : choisissez si la barre d’outils affiche le bouton Précédent, le bouton Suivant, le nom de l’app, le bouton Partager et tous les boutons liés aux extensions Safari que vous avez installées.

- Afficher la couleur dans la barre de titre : choisissez si la couleur de la barre de titre peut s’adapter à la couleur du site web.

[Image: Fenêtre des réglages de l’app web.]

À partir de l’onglet Confidentialité, vous pouvez ouvrir les réglages Confidentialité et sécurité, ou effacer les données du site web, notamment les cookies et les caches.

À partir de l’onglet Extensions, vous pouvez activer ou désactiver les [extensions Safari](https://support.apple.com/fr-fr/102343) de votre app web.

## Utiliser les notifications avec une app web

Si un site web est conçu pour vous envoyer des notifications à propos des contenus nouveaux ou mis à jour, il vous demande votre autorisation. Si vous cliquez sur Autoriser, ces notifications apparaissent sur l’écran de verrouillage et dans le centre de notifications.

Les apps web prennent en charge une fonctionnalité de notifications supplémentaire : le nombre de notifications non lues apparaît sous la forme d’une pastille rouge sur l’icône de l’app dans le Dock. Pour utiliser cette fonctionnalité, répondez à la demande de notifications du site web dans l’app web, pas dans Safari. L’app web apparaît ensuite dans les réglages de notifications : dans le menu Apple , choisissez Réglages Système, cliquez sur Notifications dans la barre latérale, puis sélectionnez l’app web dans la liste des applications à droite. Les apps web apparaissent sous le nom de l’app web, et non sous l’URL du site web.

## Supprimer une app web

Les apps web sont enregistrées dans le dossier Applications de votre dossier de départ. Pour supprimer une app web, ouvrez votre dossier de départ, par exemple en choisissant Aller > Départ dans la barre des menus du Finder. Ouvrez ensuite le dossier Applications et faites glisser l’app web dans la corbeille.
