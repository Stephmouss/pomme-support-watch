# Apple Remote Desktop : comment définir un nom Bonjour à distance

Dans Apple Remote Desktop 2 ou version ultérieure, la modification du nom d’un ordinateur distant, à l’aide de la commande Renommer les ordinateurs du menu Gérer, ne permet pas de modifier le nom Bonjour de cet ordinateur.

Pour définir un nom Bonjour, choisissez « Envoyer une commande UNIX... » dans le menu Gérer. Dans le menu Modèle de la fenêtre qui s’affiche, choisissez Configuration du système > Nom Bonjour. Cette opération entraîne le chargement d’un modèle comportant la commande suivante :

systemsetup -setlocalsubnetname name

Remplacez name par le nom Bonjour souhaité. L’extension « .local » est automatiquement ajoutée au nom Bonjour sélectionné.

Vous devez exécuter cette commande en tant qu’utilisateur root.

## Informations supplémentaires

Vous pouvez utiliser les caractères suivants dans un nom Bonjour :

- Lettres majuscules et minuscules

- Chiffres

- Tirets
