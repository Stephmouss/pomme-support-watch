# Si Logic Pro pour iPad ne fonctionne pas

Découvrez la marche à suivre si Logic Pro pour iPad ne s’ouvre pas, ne lit pas votre projet ou présente un autre problème de fonctionnement.

Les informations de cet article concernent le dépannage et la résolution de problèmes techniques. [En savoir plus sur votre abonnement](https://support.apple.com/HT213745)

## Essayer d’appliquer ces étapes dans l’ordre

- [Redémarrer votre iPad](https://support.apple.com/fr-fr/118109#restart)

- [Vérifier s’il existe une mise à jour d’iPadOS](https://support.apple.com/fr-fr/118109#iPadOS_update)

- [Vérifier s’il existe une mise à jour de Logic Pro pour iPad](https://support.apple.com/fr-fr/118109#update_app)

- [Consulter le guide d’utilisation](https://support.apple.com/fr-fr/118109#user_guide)

- [Faire un test avec un nouveau projet](https://support.apple.com/fr-fr/118109#new_project)

- [Déconnecter les périphériques externes](https://support.apple.com/fr-fr/118109#disconnect)

- [Utiliser le système audio intégré de votre iPad](https://support.apple.com/fr-fr/118109#built-in)

- [Si vous travaillez sur un projet sur votre iPad et votre Mac](https://support.apple.com/fr-fr/118109#roundtrip)

## Redémarrage de votre iPad

Pour redémarrer votre iPad, [éteignez-le, puis rallumez-le](https://support.apple.com/guide/ipad/ipad63d30b5a/ipados) .

[Haut de page](https://support.apple.com/fr-fr/118109#top)

## Vérifier s’il existe une mise à jour d’iPadOS

Sur votre iPad, accédez à Réglages > Général > Mise à jour logicielle. L’écran affiche la version actuellement installée d’iPadOS et indique si une mise à jour est disponible.

[Haut de page](https://support.apple.com/fr-fr/118109#top)

## Vérifier s’il existe une mise à jour de Logic Pro pour iPad

- Ouvrez l’App Store sur votre iPad.

- Touchez l’icône de votre profil en haut à droite.

- Si Logic Pro pour iPad apparaît sous Mises à jour disponibles, touchez Mettre à jour en regard de l’app.

[Haut de page](https://support.apple.com/fr-fr/118109#top)

## Consulter le guide d’utilisation

Consultez le [Guide d’utilisation de Logic Pro pour iPad](https://support.apple.com/guide/logicpro-ipad/welcome/ipados) pour obtenir des informations sur des fonctionnalités spécifiques. Vous pouvez rechercher dans ce guide les termes clés figurant dans les alertes, les icônes d’avertissement ou les messages d’erreur.

[Haut de page](https://support.apple.com/fr-fr/118109#top)

## Faire un test avec un nouveau projet

Vous pouvez [créer un nouveau projet](https://support.apple.com/guide/logicpro-ipad/create-projects-lpip00c529d9/1.0/ipados/16.0) et effectuer un test pour déterminer si le problème vient de votre projet ou de l’app Logic Pro.

- Dans Logic Pro, touchez le bouton Navigateur de projets à côté du nom du projet dans la barre des commandes.

[Image: bouton Navigateur de projets]

- Touchez le bouton Nouveau projet dans la barre des menus pour ouvrir le sélectionneur de nouveau projet.

[Image: bouton Nouveau projet]

- Dans le sélectionneur de nouveau projet, touchez le type de projet que vous souhaitez créer (Pistes ou Live Loops).

- [Ajoutez des boucles Apple Loops](https://support.apple.com/guide/logicpro-ipad/add-apple-loops-to-your-project-lpipc8b7f397/ipados) au nouveau projet.

- Essayez de reproduire le problème que vous rencontriez. Par exemple, si le projet avec lequel vous rencontrez un problème utilise un module tiers particulier, ajoutez-le au projet de test. Si le problème se reproduit, le module est peut-être endommagé ou doit peut-être être mis à jour.

[Haut de page](https://support.apple.com/fr-fr/118109#top)

## Déconnecter les périphériques externes

Si un périphérique externe comme une interface audio ou un périphérique de stockage est connecté à votre iPad, déconnectez-le :

- [Éteignez votre iPad](https://support.apple.com/guide/ipad/ipad63d30b5a/ipados) .

- Déconnectez tous les périphériques externes.

- [Allumez votre iPad](https://support.apple.com/guide/ipad/ipad63d30b5a/ipados) .

Si le problème se produit uniquement lorsqu’un périphérique externe spécifique est connecté, une mise à jour ou une réparation de ce dernier peut être nécessaire. Contactez le fabricant pour obtenir de l’aide.

[Haut de page](https://support.apple.com/fr-fr/118109#top)

## Utiliser le système audio intégré de votre iPad

Si vous utilisez une interface audio externe avec votre iPad, utilisez plutôt [les haut-parleurs et le microphone intégrés de votre iPad](https://support.apple.com/guide/logicpro-ipad/devices-LPIP53BD0492/1.1/ipados/17.0) .

- Dans Logic Pro pour iPad, touchez le bouton Plus sur le côté droit de la barre des commandes, puis touchez le bouton Réglages .

[Image: le bouton Plus]

[Image: le bouton Réglages]

- Touchez Réglages de l’app, puis Audio.

- Touchez Entrée, puis choisissez Microphone de l’iPad.

- Touchez Sortie, puis choisissez Haut-parleur.

Si le problème ne se produit pas lorsque vous changez d’E/S audio, vous devrez peut-être mettre à jour ou réparer le périphérique. Contactez le fabricant pour obtenir de l’aide.

[Haut de page](https://support.apple.com/fr-fr/118109#top)

## Si vous travaillez sur un projet sur votre iPad et votre Mac

Lorsque vous travaillez sur le même projet sur votre iPad et votre Mac, assurez-vous de [suivre les consignes pour réussir le transfert du projet](https://support.apple.com/HT213666) . Certaines fonctionnalités et certains formats ne sont pas compatibles avec les deux plates-formes.

[Haut de page](https://support.apple.com/fr-fr/118109#top)
