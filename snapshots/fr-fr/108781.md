# Utiliser les notifications sur votre iPhone ou votre iPad

Affichez et gérez vos notifications de façon à minimiser les interruptions, et assurez-vous de recevoir les notifications comme vous le souhaitez.

## Ouvrir les notifications à partir de l’écran de verrouillage

Vous pouvez consulter vos notifications récentes sur l’écran de verrouillage en saisissant votre iPhone ou en sortant votre iPad du mode veille. Vous pouvez également effectuer les actions suivantes depuis l’écran de verrouillage :

- Touchez une notification spécifique pour ouvrir l’app qui l’a émise.

- Touchez un groupe de notifications pour consulter toutes celles émises récemment par la même app.

- Effectuez un balayage vers la gauche sur une notification pour [gérer les alertes](https://support.apple.com/108781#manage-alerts) de cette app ou effacer la notification.

- Appuyez de manière prolongée sur une notification pour la consulter et effectuer des actions rapides si l’app qui l’a émise le permet.

Pour afficher le contenu des notifications sur l’écran verrouillé sans déverrouiller votre appareil, accédez à Réglages et touchez Notifications. Touchez Afficher les aperçus, puis sélectionnez Toujours.

Sous iOS 17 et versions ultérieures, vous pouvez également [visualiser vos notifications pendant que votre iPhone est en mode Veille](https://support.apple.com/guide/iphone/use-standby-iph878d77632/17.0/ios/17.0) .

[Image: Des notifications apparaissent sur l’écran verrouillé d’un iPhone 16 Pro.]

## Ouvrir les notifications depuis le centre de notifications

Le centre de notifications affiche l’historique de vos notifications. Vous pouvez ainsi revenir en arrière et consulter celles que vous avez manquées. Deux méthodes permettent d’afficher vos alertes depuis le centre de notifications :

- Depuis l’écran de verrouillage, effectuez un balayage vers le haut à partir du milieu de l’écran.

- Sur tout autre écran, effectuez un balayage vers le bas à partir du centre de la partie supérieure gauche de l’écran.

Pour effacer l’historique de vos notifications, touchez le bouton Fermer , puis Effacer.

[Image: Close button]

## Gérer les notifications

Pour gérer les notifications à partir de l’écran de verrouillage ou du centre de notifications :

- Effectuez un balayage vers la gauche sur une alerte ou un groupe d’alertes.

- Touchez Options, puis choisissez l’une des options suivantes :

- Pas d’alertes pendant 1 heure

- Pas d’alertes aujourd’hui

- Afficher les réglages

- Désactiver

[Image: Si vous effectuez un balayage vers la gauche sur une alerte, votre iPhone affiche les options de notification permettant de désactiver les alertes pendant une durée donnée ou de façon permanente.]

Vous pouvez également toucher Afficher les réglages pour changer le style ou les réglages des alertes émises par une app spécifique.

### Modifier l’affichage des notifications

- Accédez à Réglages

- Touchez Notifications.

- Sous Affichage, sélectionnez le mode d’affichage des notifications sur l’écran verrouillé :

- Nombre : affiche le nombre total de notifications en bas de l’écran. Vous pouvez toucher le nombre pour afficher les notifications.

- Pile : affiche les notifications sous forme de pile en bas de l’écran, avec la notification la plus récente en haut.

- Liste : affiche les notifications sous forme de liste.

[Image: Sous Réglages > Notifications, vous pouvez choisir comment vous voulez que vos notifications s’affichent, sous forme de nombre, de pile ou de liste.]

Vous devez disposer d’iOS 16 ou version ultérieure pour modifier l’affichage des notifications.

### Modifier le son des notifications pour une app spécifique

- Accédez à Réglages.

- Touchez Notifications.

- Sous Style, touchez l’app pour laquelle vous souhaitez modifier les notifications.

- Touchez Sons afin d’activer les alertes sonores pour cette app. Pour certaines apps comme FaceTime ou Messages, vous pouvez sélectionner un son spécifique qui sera lu chaque fois que vous recevrez une notification de cette app.

Si [le son de votre téléphone est coupé](https://support.apple.com/guide/iphone/silence-iphone-iph81c7fd7d1/ios) ou si le volume est à zéro, vous n’entendrez pas le son des notifications.

### Activer ou désactiver les résumés de notifications sous iOS 18.1

Si vous disposez d’un iPhone 16 ou d’un iPhone 15 Pro, d’un iPhone 15 Pro Max ou d’un modèle Pro ultérieur doté d’iOS 18.1, vous pouvez recevoir des résumés de notifications via Apple Intelligence. Lorsque vous activez l’option Résumer les notifications, votre iPhone résume les messages directs et les groupes de notifications pour les présenter de manière plus succincte et facile à lire. Ces résumés de notifications s’affichent en italique. Vous pouvez toujours toucher une notification réduite pour l’afficher en entier.

Pour activer ou désactiver les résumés de notification :

- Dans l’app Réglages, touchez Notifications.

- Touchez Résumer les notifications.

- Activez ou désactivez l’option Résumer les notifications.

Lorsque l’option Résumer les notifications est activée, vous pouvez également activer ou désactiver les résumés des notifications pour des apps particulières.

[Apple Intelligence est disponible](https://support.apple.com/121115) en version bêta sur l’iPhone 15 Pro, l’iPhone 15 Pro Max, tous les modèles d’iPhone 16 et ultérieurs, l’iPad mini (A17 Pro) et les modèles d’iPad avec puce M1 et ultérieurs, avec la langue de Siri et celle de l’appareil réglées sur la même [langue prise en charge](https://support.apple.com/121115#supportedlanguages) .

Apple Intelligence repose sur des modèles génératifs. Les résultats peuvent donc varier. Vérifiez l’exactitude des informations importantes.

### Activer ou désactiver les notifications prioritaires sous iOS 18.4

Si vous disposez d’un iPhone 16 ou d’un iPhone 15 Pro, d’un iPhone 15 Pro Max ou d’un modèle Pro ultérieur doté d’iOS 18.4, vous pouvez utiliser Apple Intelligence pour donner la priorité aux notifications importantes et urgentes. Les notifications prioritaires apparaissent en haut du centre de notification, afin que vous puissiez rattraper ce que vous avez éventuellement manqué. Vous pouvez toujours balayer l’écran vers le haut pour voir toutes les notifications.

- Dans l’app Réglages, touchez Notifications.

- Touchez Notifications prioritaires.

- Activez ou désactivez l’option Notifications prioritaires.

Pour désactiver les notifications prioritaires pour une app spécifique, accédez à Réglages, puis touchez Notifications. Sélectionnez Prioriser les notifications, puis désactivez l’option Notifications prioritaires pour l’app concernée.

### Modifier le style des alertes

- Accédez à Réglages et touchez Notifications.

- Sélectionnez une app sous Style.

- Sous Alertes, choisissez le style d’alerte souhaité.

Lorsque vous activez les pastilles, certaines icônes d’app peuvent afficher des informations. Si vous activez les pastilles pour Mail, par exemple, le nombre d’e-mails non lus dans votre boîte de réception apparaît au-dessus de l’icône Mail sur votre écran d’accueil.

Sous iOS 15 et iPadOS 15 (ou une version ultérieure), vous pouvez activer les alertes critiques pour les apps prises en charge afin de recevoir leurs notifications, même lorsque le son de votre iPhone est coupé ou qu’un mode de concentration est activé.

## Assurez-vous de recevoir les notifications comme vous le souhaitez

Si vous ne recevez pas les notifications comme vous l’avez souhaité, il se peut qu’un réglage de notification spécifique soit activé ou désactivé.
