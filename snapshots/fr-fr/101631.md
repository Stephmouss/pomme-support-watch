# Vérification de l’installation de Formats pro vidéo

Assurez-vous que Formats pro vidéo pour Final Cut Pro, Motion et Compressor est installé sur votre Mac.

Formats pro vidéo vous permet d’utiliser Final Cut Pro, Motion et Compressor avec un large éventail de formats vidéo, y compris des fichiers MXF. Utilisez [Informations système](https://support.apple.com/HT203001) pour vérifier si Formats pro vidéo est installé et, si oui, avec quelle version :

- Appuyez sur la touche Option et maintenez-la enfoncée, puis choisissez le menu Pomme  > Informations système.

- Dans la section Logiciel de la barre latérale, sélectionnez Installations.

- Pour trier les éléments par ordre alphabétique, cliquez sur l’en-tête de colonne Nom du logiciel afin que la flèche pointe vers le haut.

- Faites défiler la page jusqu’à ce que Formats pro vidéo apparaisse dans la colonne Nom du logiciel. La colonne Version indique le numéro de version logicielle de Formats pro vidéo.

Pour installer ou mettre à jour Formats pro vidéo sur un Mac doté de macOS Mojave, utilisez la fonctionnalité [Mise à jour de logiciels dans Préférences Système](https://support.apple.com/HT201541) *.
