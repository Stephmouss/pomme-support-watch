# Utiliser Final Cut Pro pour transcoder des fichiers vidéo QuickTime contenant des images PNG

Si vous utilisez des fichiers vidéo QuickTime contenant des images PNG incluant un canal alpha, utilisez Final Cut Pro 10.4.9 au lieu de Compressor pour les transcoder.

Ouvrez votre projet contenant les fichiers vidéo QuickTime avec images PNG avec un canal alpha Final Cut Pro 10.4.9. Choisissez Fichier > Partager, sélectionnez Fichier master, puis cliquez sur Réglages. Choisissez une option Apple ProRes dans le menu local Codec vidéo :

- Pour conserver le canal alpha, choisissez ProRes 4444 ou ProRes 4444XQ.

- Si vous n’avez pas besoin de conserver le canal alpha, vous pouvez choisir l’une des autres options ProRes.
