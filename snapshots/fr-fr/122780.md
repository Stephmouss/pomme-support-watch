# Si Pixelmator Pro ne fonctionne pas

Si Pixelmator Pro sur Mac ne fonctionne pas correctement et que vous ne connaissez pas l’origine du problème, vous pouvez tenter de l’isoler pour en identifier la cause.

## Avant de commencer le dépannage

- Si vous venez de mettre à jour Pixelmator Pro ou macOS et que Pixelmator Pro ne fonctionne pas, il est possible que des logiciels ou du matériel tiers ne soient pas compatibles. Contactez les développeurs ou les fabricants des composants tiers de votre système pour vérifier leur compatibilité avec les versions de Pixelmator Pro et de macOS que vous utilisez.

- Veillez à [sauvegarder la version actuelle de votre app et à désactiver les mises à jour automatiques](https://support.apple.com/fr-fr/122606) .

- Veillez également à [désigner la photothèque que vous souhaitez utiliser avec Pixelmator Pro en tant que photothèque système](https://support.apple.com/fr-fr/104946) dans l’app Photos.

## Dépannage de Pixelmator Pro sur Mac

Après avoir appliqué chacune des étapes ci-dessous, testez à nouveau Pixelmator Pro pour voir si le problème est résolu.

### 1. Redémarrer votre Mac

Choisissez Redémarrer dans le menu Apple .

### 2. Déconnectez les périphériques externes

Un périphérique externe incompatible ou défectueux peut parfois être à l’origine de problèmes dans Pixelmator Pro. Pour tester les périphériques externes, procédez comme suit :

- Quittez Pixelmator Pro, puis choisissez Éteindre dans le menu Apple .

- Déconnectez tous les périphériques externes, à l’exception de votre clavier et de votre souris.

- Pour les ordinateurs Mac basés sur Intel uniquement, [réinitialisez la mémoire NVRAM.](https://support.apple.com/HT204063) Vous ne devez effectuer cette tâche que la première fois que vous déconnectez les périphériques externes.

- Allumez votre Mac.

Si le problème se produit uniquement lorsqu’un périphérique spécifique est connecté, une mise à jour ou une réparation de ce dernier peut être nécessaire. Contactez le fabricant pour obtenir de l’aide.

### 3. Vérifier la configuration système requise

- [Vérifiez la configuration système requise pour Pixelmator Pro](https://support.apple.com/fr-fr/125029#specs) .

- Sur le Mac sur lequel vous exécutez Pixelmator Pro, choisissez À propos de ce Mac dans le menu Apple .

- La version actuellement installée est indiquée en regard de macOS dans la liste.

Si votre Mac est doté d’une version de macOS antérieure à macOS Monterey, vérifiez que les logiciels tiers que vous utilisez sont compatibles avec la dernière version de macOS, puis [mettez à jour macOS](https://support.apple.com/fr-fr/108382) .

[En savoir plus sur les versions de macOS](https://support.apple.com/fr-fr/109033)

### 4. Vérifier que l’app fonctionne normalement

Consultez le [guide d’utilisation de Pixelmator Pro](https://support.apple.com/guide/pixelmator-pro/welcome/macos) pour vérifier que l’app fonctionne normalement. Vous pouvez rechercher dans ce guide les termes clés figurant dans les alertes, les menus ou les messages d’erreur.

### 5. Mettre à jour Pixelmator Pro

Avant de procéder à la mise à jour, essayez de terminer tous les projets en cours, sauvegardez votre app et désactivez les mises à jour automatiques.

[Découvrez comment sauvegarder votre app et mettre à jour Pixelmator Pro et les autres apps pro](https://support.apple.com/fr-fr/122606)

### 6. Vérifier que Pixelmator Pro peut accéder à votre photothèque

Consultez les réglages Confidentialité et sécurité sur votre Mac pour vous assurer que l’app peut accéder à votre photothèque :

- Choisissez Réglages Système dans le menu Apple .

- Cliquez sur Confidentialité et sécurité dans la barre latérale.

- Cliquez sur Photos, puis assurez-vous que l’app Pixelmator Pro est activée.

Si les réglages Confidentialité et sécurité de votre Mac sont correctement configurés, mais que vous ne voyez pas les images de votre photothèque en sélectionnant Fichier > New from Photos (Nouveau depuis Photos) dans Pixelmator Pro, vous avez peut-être désigné une autre photothèque en tant que [photothèque système](https://support.apple.com/guide/photos/photo-library-overview-pht211de786/mac) .

#### Vérifier votre photothèque système

Pour accéder à votre photothèque dans Pixelmator Pro, celle-ci doit être désignée en tant que photothèque système. Vous devrez peut-être [désigner la photothèque](https://support.apple.com/fr-fr/104946) que vous souhaitez utiliser dans Pixelmator Pro en tant que photothèque système.

#### Vérifier que les photos et les images sont stockées sur un périphérique pris en charge

Votre photothèque ne peut pas être stockée sur un périphérique de stockage utilisé pour les sauvegardes Time Machine. Afin d’éviter une éventuelle perte de données, ne stockez pas vos photothèques sur des périphériques de stockage amovibles tels que des cartes SD ou des clés USB, ni sur un périphérique partagé sur un réseau ou Internet, y compris les services de stockage dans le cloud.

Si des photothèques que vous utilisez avec Pixelmator Pro sont stockées sur des périphériques de stockage externes tels que des disques SSD, vérifiez que ces périphériques sont [au format APFS](https://support.apple.com/guide/disk-utility/file-system-formats-dsku19ed921c/22.6/mac/15.0) . Les anciens périphériques de stockage externes peuvent également être au format macOS étendu.

Si vous devez déplacer votre photothèque sur un type de périphérique de stockage pris en charge, [découvrez la marche à suivre](https://support.apple.com/fr-fr/108345) .

Si vous achetez un lecteur externe préformaté avec un système de fichiers Windows tel que MS-DOS (FAT32), ExFAT ou NTFS, reformatez-le au format APFS.

### 7. Vérifier la compatibilité des fichiers multimédias

Pixelmator Pro prend en charge les formats PXD, JPEG, PNG, TIFF, HEIC, PSD, SVG, PDF, GIF, BMP, TGA, WebP, JPEG-2000 et [les formats RAW pris en charge par macOS.](https://support.apple.com/fr-fr/122870) Vérifiez le format du fichier multimédia pour vous assurer qu’il est compatible avec Pixelmator Pro.

- Dans Pixelmator Pro, ouvrez l’image, puis appuyez sur Option + Commande + Maj + I.

- Notez le format de l’image.

Si le format de fichier n’est pas pris en charge, recréez l’image dans un format HDR pris en charge. Vous pouvez toujours retoucher et exporter l’image au format SDR (plage dynamique standard).

### 8. Vérifier la compatibilité des logiciels tiers

Notez tous les logiciels tiers installés sur votre Mac. Il peut s’agir de modules vidéo et audio, d’autres apps de retouche d’image, ainsi que d’utilitaires, de logiciels de sécurité, d’antivirus et d’outils de suppression des logiciels malveillants. Contactez leurs développeurs pour vérifier que leurs produits sont compatibles avec les versions de Pixelmator Pro et de macOS installées sur votre ordinateur.

### 9. Vérifier le programme interne de l’appareil photo, de la caméra ou du périphérique de stockage

Vérifiez auprès du fabricant de chaque périphérique externe que vous utilisez, comme un appareil photo, une caméra ou un périphérique de stockage, si des mises à jour du logiciel ou du programme interne sont disponibles. Suivez les instructions du fabricant pour procéder à la mise à jour.

### 10. Effectuer un test depuis un nouveau compte d’utilisateur

[Créez un autre compte d’administrateur sur votre Mac](https://support.apple.com/guide/mac-help/add-a-user-or-group-mchl3e281fc9/mac) , puis tentez de reproduire le problème avec ce nouveau compte. Si le problème ne se produit pas avec le nouveau compte, des réglages, des fichiers ou des logiciels tiers du compte utilisateur initial peuvent être à l’origine du problème.

### 11. Effectuer un test avec un nouveau document

- Créez un fichier multimédia de test pour Pixelmator Pro :

- Ouvrez Pixelmator Pro, puis choisissez « Create a new document » (Créer un document) ou File > New (Fichier > Nouveau).

- Dans la section Basic de l’explorateur de modèles, double-cliquez sur le modèle Basic Square Post.

- Choisissez File > Export (Fichier > Exporter), sélectionnez PNG dans le menu local Format, puis cliquez sur Export (Exporter).

- Ouvrez le fichier PNG exporté dans Pixelmator Pro, puis essayez de reproduire le problème en utilisant le fichier multimédia de test. Dans Pixelmator Pro, choisissez File > New pour créer un document.

- Essayez de reproduire le problème en utilisant le fichier multimédia de test.

Si vous ne parvenez pas à reproduire le problème avec le fichier multimédia de test, le problème peut être lié au fichier source utilisé dans le projet. Essayez d’obtenir une autre copie du fichier source.

### 12. Réinitialiser Pixelmator Pro

- Quittez Pixelmator Pro.

- Ouvrez le Finder et choisissez Aller > Aller au dossier.

- Collez le chemin suivant dans le champ Aller au dossier : ~/Library/Containers

- Faites glisser tous les dossiers intitulés « Pixelmator Pro » vers la corbeille.

### 13. Supprimer et réinstaller Pixelmator Pro

Lorsque vous supprimez et réinstallez Pixelmator Pro, vos fichiers multimédias ne sont pas supprimés ni affectés de quelque manière que ce soit.

- Dans le Finder, choisissez Aller > Applications.

- Localisez l’app Pixelmator Pro et faites-la glisser vers la corbeille.

- [Réinstallez l’app depuis l’App Store](https://support.apple.com/fr-fr/122694) ou restaurez-la à partir d’une sauvegarde. Pour restaurer une copie de l’app Pixelmator Pro à partir d’une sauvegarde, faites glisser l’app depuis son emplacement de stockage vers votre dossier Applications.

### 14. Effectuer un test depuis un nouveau volume de votre Mac

Pour vous assurer que Pixelmator Pro, macOS et votre Mac fonctionnent correctement, procédez à une dernière vérification en créant un volume sur votre Mac. Installez macOS et Pixelmator Pro sur ce nouveau volume, puis effectuez un test avec un fichier multimédia de test.

- [Installez macOS sur un nouveau volume de votre disque de démarrage intégré](https://support.apple.com/fr-fr/118282) . Assurez-vous qu’il s’agit de la même version de macOS que celle que vous utilisez actuellement.

- Une fois l’installation de macOS terminée, configurez le Mac, puis définissez le [disque de démarrage par défaut](https://support.apple.com/guide/mac-help/mchlp1034/mac) sur le nouveau volume de test.

- Éteignez votre Mac et déconnectez tous les appareils, à l’exception d’un clavier et d’une souris ou d’un trackpad.

- Allumez votre Mac.

- Sous Emplacements dans la barre latérale du Finder, sélectionnez le volume principal (nommé par défaut Macintosh HD) , puis appuyez sur Commande + E pour démonter le volume principal. Seul le volume de test restera monté.

- [Installez Pixelmator Pro depuis l’App Store](https://support.apple.com/fr-fr/122694) . Veillez à vous connecter à l’App Store à l’aide du compte Apple utilisé lors de l’achat ou de l’abonnement à Pixelmator Pro.

- Créez un fichier multimédia de test pour Pixelmator Pro :

- Ouvrez Pixelmator Pro, puis choisissez « Create a new document » (Créer un document).

- Dans la section Basic de l’explorateur de modèles, double-cliquez sur le modèle Basic Square Post.

- Choisissez File > Export (Fichier > Exporter), sélectionnez PNG dans le menu local Format, puis cliquez sur Export (Exporter).

- Ouvrez le fichier PNG exporté dans Pixelmator Pro, puis essayez de reproduire le problème en utilisant le fichier multimédia de test.

- Essayez de reproduire le problème dans Pixelmator Pro à partir du nouveau volume. Si le problème ne survient pas, cela indique que Pixelmator Pro, macOS et votre Mac fonctionnent normalement. Le problème est très probablement lié aux images sur lesquelles vous travaillez, à un périphérique externe ou à d’autres produits tiers tels que des modules.

- Éteignez votre Mac, puis [suivez les instructions pour modifier votre disque de démarrage](https://support.apple.com/guide/mac-help/change-your-mac-startup-disk-mchlp1034/mac) , en veillant à choisir votre volume principal (nommé par défaut Macintosh HD) comme disque de démarrage.

- Sur le volume principal, vérifiez la compatibilité du matériel et des logiciels tiers et assurez-vous que vous avez mis à jour macOS vers la dernière version.

- Une fois les tests terminés, [supprimez le volume de test à l’aide d’Utilitaire de disque](https://support.apple.com/guide/disk-utility/add-delete-or-erase-apfs-volumes-dskua9e6a110/mac) .
