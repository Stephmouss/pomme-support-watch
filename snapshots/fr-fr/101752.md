# GarageBand pour iOS : il est possible que GarageBand demande à accéder à vos contacts

Lors du partage d’un morceau ou d’une sonnerie, il est possible que GarageBand vous demande l’autorisation d’accéder à vos contacts sur votre appareil.

Pour insérer automatiquement votre nom en tant qu’artiste ou compositeur d’une chanson, GarageBand vous demande l’autorisation d’accéder aux informations enregistrées dans votre app Contacts. Par ailleurs, GarageBand utilise cette autorisation pour assigner les sonneries ou les alertes que vous créez à un contact spécifique.

Sélectionnez « Assigner à un contact » lors du partage. Cette option vous permet de choisir une sonnerie ou une alerte SMS à associer à un contact.
