# Si vous ne parvenez pas à accepter les conditions générales d’iCloud

Un message d’erreur s’affiche lorsque vous essayez d’accepter les nouvelles conditions générales d’iCloud ? Mettez votre appareil à jour.

Lorsque vous essayez d’accepter les nouvelles conditions générales d’iCloud sur votre iPhone, iPad ou Apple Vision Pro, un message d’erreur indiquant : « Impossible d’effectuer l’action. Cette action ne peut pas être effectuée pour le moment. » peut s’afficher. Pour résoudre ce problème, mettez à jour votre iPhone ou iPad vers la [dernière version d’OS ou d’iPadOS](https://support.apple.com/fr-fr/118575) [,](https://support.apple.com/118575) ou votre Apple Vision Pro vers la [dernière version de visionOS](https://support.apple.com/fr-fr/118481) .
