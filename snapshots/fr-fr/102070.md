# Si l’assistant Boot Camp indique qu’il est impossible de créer votre volume USB ou que l’espace disponible est insuffisant

Vous devrez peut être mettre à jour votre version de macOS ou utiliser une édition ultérieure de Windows 10.

Dans certains cas, l’assistant Boot Camp peut indiquer que votre volume USB démarrable n’a pas pu être créé ou que l’espace disponible est insuffisant. Pour résoudre ce problème, procédez comme suit :

- Assurez-vous d’utiliser une clé USB de 16 Go ou plus.

- [Installez les dernières mises à jour de macOS](https://support.apple.com/fr-fr/HT201541) .

- [Téléchargez la dernière édition de Windows 10](https://www.microsoft.com/fr-fr/software-download/windows10ISO) sur le site Web de Microsoft, puis [utilisez l’assistant Boot Camp pour l’installer](https://support.apple.com/fr-fr/HT201468) .
