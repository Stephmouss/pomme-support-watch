# Réinitialiser votre iPhone, votre iPad ou votre iPod touch avec les réglages d’origine

Découvrez comment effacer les informations de votre iPhone, votre iPad ou votre iPod touch et restaurer les réglages par défaut de votre appareil.

Si vous avez également besoin d’effacer en toute sécurité les données de votre Apple Watch, [désactivez le jumelage de votre Apple Watch](https://support.apple.com/fr-fr/108372) .

## Créer une sauvegarde

[Sauvegardez votre appareil](https://support.apple.com/fr-fr/118426) afin de pouvoir restaurer votre contenu, vos réglages et vos apps sur un iPhone neuf ou effacé.

## Effacer les données et réinitialiser votre appareil

- Accédez à Réglages.

- Touchez Général.

- Touchez Transférer ou réinitialiser [l’appareil].

- Touchez Effacer contenu et réglages.

[Image: Écran Transférer ou réinitialiser l’iPhone avec le bouton Effacer contenu et réglages.]

- Touchez Continuer.

[Image: Écran Effacer cet iPhone avec une liste d’éléments qui seront supprimés et un bouton Continuer.]

- Indiquez si vous souhaitez [conserver ou supprimer votre eSIM](https://support.apple.com/fr-fr/102421) . Si vous effacez votre eSIM, vous devez [contacter votre opérateur pour réactiver votre forfait mobile](https://support.apple.com/109526) .

[Image: Un message d’alerte « Voulez-vous vraiment effacer toutes les données ? » avec les boutons Annuler, Conserver l’eSIM et effacer les données, et Supprimer l’eSIM et effacer les données affichés sous le message d’alerte.]

- Saisissez le code de votre appareil. [Vous avez oublié votre code d’accès ?](https://support.apple.com/fr-fr/118430)

- Patientez jusqu’à la fin de la sauvegarde.

- Saisissez le mot de passe de votre compte Apple. [Mot de passe de votre compte Apple oublié ?](https://support.apple.com/fr-fr/102656)

- Touchez le bouton Terminé sur votre clavier.

- Attendez que votre appareil soit réinitialisé.

Une fois le processus terminé, l’écran Bonjour s’affiche.
