# Réinitialiser votre iPhone, votre iPad ou votre iPod touch avec les réglages d’origine

Découvrez comment effacer les informations de votre iPhone, votre iPad ou votre iPod touch et restaurer les réglages par défaut de votre appareil.

Si vous avez également besoin d’effacer votre Apple Watch en toute sécurité, vous pouvez [suivre ces instructions pour annuler le jumelage de vos appareils](https://support.apple.com/fr-fr/108372) .

[Image: Lire la vidéo]

## Créer une sauvegarde

[Créer une sauvegarde](https://support.apple.com/fr-fr/118426) . Vous pouvez restaurer le contenu, les réglages et les apps de cette sauvegarde sur un iPhone neuf ou dont les données viennent d’être effacées.

## Effacer les données et réinitialiser votre appareil

- Accédez à Réglages.

- Touchez Général.

- Touchez Transférer ou réinitialiser [l’appareil].

- Touchez Effacer contenu et réglages.

[Image: Écran Transférer ou réinitialiser l’iPhone avec le bouton Effacer contenu et réglages.]

- Touchez Continuer.

[Image: Écran Effacer cet iPhone avec une liste d’éléments qui seront supprimés et un bouton Continuer.]

- Indiquez si vous souhaitez [conserver ou supprimer votre eSIM](https://support.apple.com/fr-fr/102421) . Si vous effacez votre eSIM, vous devez [contacter votre opérateur pour réactiver votre forfait mobile](https://support.apple.com/109526) .

[Image: Un message d’alerte « Voulez-vous vraiment effacer toutes les données ? » avec les boutons Annuler, Conserver l’eSIM et effacer les données, et Supprimer l’eSIM et effacer les données affichés sous le message d’alerte.]

- Saisissez le code de votre appareil.

- Saisissez le mot de passe de votre compte Apple.

- Attendre que les données de votre appareil soient effacées.

Une fois le processus de restauration terminé, l’écran Bonjour apparaîtra sur votre iPhone.

## Si vous ne parvenez pas à effacer les données de votre iPhone, votre iPad ou votre iPod touch

- Découvrez la marche à suivre [si vous avez oublié le code d’accès](https://support.apple.com/fr-fr/118430) de votre appareil, ou si vous désactivez votre appareil.

- Découvrez comment procéder [si vous avez oublié le mot de passe de votre compte Apple](https://support.apple.com/fr-fr/102656) .

- Si vous oubliez le code de Temps d’écran, vous pouvez [le réinitialiser](https://support.apple.com/fr-fr/102677) . Restaurer votre appareil à l’aide d’une sauvegarde ne permet pas de supprimer ce code d’accès.
