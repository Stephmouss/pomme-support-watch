# Utiliser plusieurs versions de macOS sur Mac

Si vous installez un macOS compatible sur un volume de stockage interne ou externe supplémentaire, votre Mac peut démarrer à partir de l’un ou l’autre de ces volumes.

## Avant de commencer

Cette configuration de « double démarrage » est un moyen pratique d’essayer une version ultérieure de macOS tout en conservant temporairement la version macOS actuellement installée pour les anciens logiciels qui en ont encore besoin.

Important : continuer d’utiliser une version antérieure de macOS après la mise à niveau n’est pas une solution viable à long terme. Les versions ultérieures de macOS peuvent installer des modifications conçues pour assurer la sécurité de votre Mac. Ces modifications sont susceptibles d’affecter la capacité de votre ordinateur à continuer d’utiliser une version beaucoup plus ancienne.

## Préparer un nouveau volume APFS pour le nouveau macOS

Si vous avez suffisamment d’espace de stockage libre, vous pouvez installer le nouveau macOS sur votre disque de démarrage intégré sans supprimer le macOS déjà installé. Vous pouvez également installer macOS sur un périphérique de stockage externe.

### Si l’installation est effectuée sur votre disque de démarrage intégré

Si vous souhaitez installer le nouveau macOS sur votre disque de démarrage intégré, créez un nouveau volume APFS pour le contenir.

- Assurez-vous que votre Mac est doté de [macOS High Sierra ou version ultérieure](https://support.apple.com/fr-fr/109033) . Les versions antérieures de macOS ne sont pas compatibles avec APFS.

- Ouvrez Utilitaire de disque à partir du sous-dossier Utilitaires de votre dossier Applications.

- Dans la barre latérale, sélectionnez votre volume APFS existant, tel que Macintosh HD.

- Dans le menu Édition de la barre des menus, choisissez Ajouter un volume APFS. Ou cliquez sur le bouton d’ajout de volume (+) dans la barre d’outils Utilitaire de disque. Ces options ne sont disponibles que lorsqu’un [volume au format APFS](https://support.apple.com/guide/disk-utility/dsku19ed921c/mac) est sélectionné.

- Saisissez un nom pour le nouveau volume, puis cliquez sur Ajouter.

- Une fois l’opération terminée, quittez Utilitaire de disque.

## Installer une version de macOS compatible sur le nouveau volume

- [Téléchargez le programme d’installation complet de macOS.](https://support.apple.com/fr-fr/102662)

- Lorsque le programme d’installation s’ouvre et vous invite à choisir l’emplacement d’installation, cliquez sur Afficher tous les disques, puis sélectionnez le nouveau volume avant de poursuivre l’installation.

[Image: Écran du programme d’installation de macOS affichant la sélection du volume d’installation.]

## Basculer entre les versions de macOS

- Suivez les instructions permettant de [changer le disque de démarrage de votre Mac](https://support.apple.com/guide/mac-help/mchlp1034/mac) .

- Redémarrez votre Mac pour démarrer à partir de l’autre volume.

- Répétez ces étapes si nécessaire pour choisir le volume à utiliser comme disque de démarrage.

Lorsque vous démarrez pour la première fois à partir du nouveau volume, un assistant réglages vous aide à créer un compte utilisateur. Une fois la configuration terminée, vous pouvez partager des fichiers entre les comptes utilisateur sur chaque volume. Pour en savoir plus, consultez l’article [Partager des fichiers avec les autres utilisateurs de votre Mac](https://support.apple.com/guide/mac-help/mchlp1122/mac) .

## Maintenir macOS à jour sur chaque volume

Pour obtenir les dernières mises à jour de chaque version de macOS, [vérifiez si des mises à jour logicielles sont disponibles](https://support.apple.com/fr-fr/108382) , puis démarrez à partir de l’autre volume et lancez à nouveau une recherche de mises à jour logicielles.

## Supprimer un volume

Si vous souhaitez supprimer un volume, y compris macOS et toutes les autres données de ce volume :

- Facultatif : [créez une sauvegarde](https://support.apple.com/fr-fr/104984) du volume que vous supprimez. Une fois le volume supprimé, cette sauvegarde peut vous permettre de [restaurer les fichiers](https://support.apple.com/fr-fr/102551) de ce volume.

- Démarrez votre Mac à partir d’un volume que vous ne supprimez pas.

- Ouvrez Utilitaire de disque.

- Dans la barre latérale d’Utilitaire de disque, sélectionnez le volume que vous souhaitez supprimer.

- Dans le menu Édition de la barre des menus, choisissez Supprimer le volume APFS. Ou cliquez sur le bouton de suppression de volume (–) dans la barre d'outils Utilitaire de disque.

- Cliquez sur Supprimer. Si le volume fait partie d’un groupe de volumes, supprimez le groupe de volumes lorsqu’un message vous y invite.
