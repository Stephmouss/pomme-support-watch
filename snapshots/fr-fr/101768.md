# Si des modèles Motion personnalisés n’apparaissent pas dans une bibliothèque Final Cut Pro

Lorsque vous ouvrez une bibliothèque Final Cut Pro dans laquelle vous avez enregistré des modèles Motion, il se peut que ces modèles n’apparaissent pas dans les navigateurs de Final Cut Pro.

Vous pouvez fermer la bibliothèque, puis la rouvrir pour que les modèles Motion soient à nouveau visibles. Vous devrez effectuer cette opération pour chaque bibliothèque affectée.
