# GarageBand pour iOS : pas de lecture audio sur les sorties avec Apogee Jam

Si vous utilisez un Apogee Jam et que vous branchez ou débranchez des haut-parleurs externes ou des écouteurs via la prise casque, la lecture audio peut ne pas basculer vers le haut-parleur intégré, les haut-parleurs externes ou les écouteurs.

[Redémarrez l’appareil](http://support.apple.com/kb/ht1430?viewlocale=fr_FR) pour résoudre ce problème.
