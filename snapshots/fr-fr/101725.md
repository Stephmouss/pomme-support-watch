# Utilisation d’un réseau privé pour des métadonnées Xsan sous macOS Server

Découvrez comment passer à un réseau de métadonnées privé après avoir créé un réseau SAN sous macOS Server.

Lorsque vous créez un réseau SAN sous OS X Yosemite ou version ultérieure, le trafic des métadonnées Xsan utilise le réseau public du serveur. Après avoir créé le réseau SAN, vous pouvez utiliser une commande dans Terminal pour passer à un réseau privé dans les cas suivants :

- Tous les contrôleurs de métadonnées Xsan utilisent OS X Yosemite 10.10.2 ou version ultérieure.

- Tous les membres du réseau SAN sont connectés aux réseaux public et privé.

## Modification d’un réseau de métadonnées privé

- Sous macOS Server, ouvrez Terminal.

- Utilisez cette commande sudo :

- sudo xsanctl changeIP oldIP newIP

Remplacez oldIP par l’adresse IP du contrôleur de métadonnées sur votre réseau public. Remplacez newIP par l’adresse IP de votre réseau de métadonnées privé.
