# Scanner un code QR avec votre iPhone ou iPad

Utilisez l’app Appareil photo ou le scanner de code pour accéder rapidement à des sites web, des apps, des tickets et autres.

## Comment scanner un code QR avec l’app Appareil photo ou le scanner de code

- Ouvrez l’app Appareil photo ou le scanner de code sur votre appareil :

- Ouvrez l’app Appareil photo à partir de l’écran d’accueil, de l’écran verrouillé ou du centre de contrôle, ou [à l’aide de la commande de l’appareil photo sur les modèles pris en charge](https://support.apple.com/guide/iphone/use-the-camera-control-iph0c397b154/ios) .

- Ouvrez le centre de contrôle et touchez le bouton [Scanner un code](https://support.apple.com/fr-fr/102680#codescanner) .

[Image: null]

Tenez votre appareil de sorte que le code QR apparaisse à l’écran, puis touchez le lien pour ouvrir le contenu associé.

[Image: iPhone affichant l’app Appareil photo avec un lien de code QR sélectionnable.]

## Ajouter le scanner de code au centre de contrôle

- [Ouvrez le centre de contrôle](https://support.apple.com/guide/iphone/aside/iph7c412b4db/18.0/ios/18.0) .

- Touchez de manière prolongée l’arrière-plan de l’écran, puis touchez Ajouter une commande.

- Dans la galerie du centre de contrôle, touchez la commande Scanner un code, puis touchez n’importe où sur l’écran pour revenir au centre de contrôle.
