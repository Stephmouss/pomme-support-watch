# Compressor 4.1 : résolution des problèmes relatifs au système de traitement distribué

Si Compressor 4.1 ne fonctionne pas comme prévu lors de l’utilisation du système de traitement distribué, essayez ces étapes pour isoler et résoudre le problème.

Important : effectuez une sauvegarde de vos réglages Compressor personnalisés.

Avant de réaliser la procédure décrite dans cet article, assurez-vous de disposer d’une sauvegarde récente des réglages Compressor personnalisés. Vos sauvegardes sont stockées dans le dossier ~/Bibliothèque/Application Support/Compressor. Les réglages personnalisés se trouvent, quant à eux, dans le dossier Réglages.

- Remarque : Note : If you're transcoding using a group of shared computers, follow these steps on all computers in the group.

- Dans Compressor, sélectionnez Compressor > Préférences (ou appuyez sur les touches Commande + Virgule), puis sélectionnez Mon ordinateur.

- Désélectionnez l’option « Autoriser d’autres ordinateur à traiter des lots sur mon ordinateur ».

- Quittez Compressor en sélectionnant Compressor > Quitter Compressor (ou appuyez sur les touches Commande + Q).

- Dans le Finder, maintenez la touche Option enfoncée et choisissez Bibliothèque dans le menu Aller.

- Dans le dossier Bibliothèque qui s’affiche, ouvrez le dossier Application Support. Placez le dossier Compressor dans la corbeille.

- Si vous avez utilisé Compressor 3.5.x ou 4.0.x sur votre ordinateur, il est possible que vous disposiez d’un dossier Apple Qmaster que vous pouvez supprimer. Reportez-vous aux étapes ci-dessous pour supprimer ce dossier, ou passez à l’étape 7.

- Redémarrez l’ordinateur.

Suppression du dossier Apple Qmaster existant (Compressor 4.0.x)

- Si Compressor 4.1 est en cours d’exécution, quittez Compressor en sélectionnant Compressor > Quitter Compressor.

- Dans le Finder, maintenez la touche Option enfoncée et choisissez Bibliothèque dans le menu Aller.

- Dans le dossier Bibliothèque qui s’affiche, ouvrez le dossier Application Support. Placez le dossier Apple Qmaster dans la corbeille.

- Redémarrez l’ordinateur.

Suppression du dossier Apple Qmaster existant (Compressor 3.5.x)

- Si Compressor est en cours d’exécution, quittez Compressor en sélectionnant Compressor > Quitter Compressor.

- Dans le Finder, ouvrez le disque de démarrage et accédez au dossier /Bibliothèque/Application Support/Apple Qmaster/.

- Placez le dossier Apple Qmaster dans la corbeille.

- Redémarrez l’ordinateur.

2. Résolution du problème provoquant l’apparition du message d’alerte « ... ne peut pas être traité sur plus d’un ordinateur car la copie de fichier n’est pas prise en charge »

Il se peut que ce message s’affiche si le système NFS ne parvient pas à copier le fichier source. Ce problème peut survenir si le disque sur lequel se trouvent les fichiers source est associé à certaines autorisations (lorsqu’il se trouve sur un volume réseau ou qu’il utilise le format ExFAT, par exemple).

Si vous recevez ce message d’alerte lors de l’envoi d’un lot à partir d’un groupe d’ordinateurs partagés, procédez comme suit :

- Dans Compressor, sélectionnez Compressor > Préférences (ou appuyez sur les touches Commande + Virgule), puis sélectionnez Ordinateurs partagés.

- Dans la liste des ordinateurs partagés (à gauche), sélectionnez le groupe auquel vous souhaitez envoyer le lot, puis désélectionnez l’option « Activer le partage automatique de fichiers ».

- Sur chacun des ordinateurs du groupe, montez ensuite manuellement le volume sur lequel se trouve le fichier source.
