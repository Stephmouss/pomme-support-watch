# À propos de la mise à jour 2.2.1 d’OS X Server

Consultez cet article pour en savoir plus sur la mise à jour 2.2.1 d’OS X Server.

Ce logiciel met à jour OS X Server 2.0, 2.1, 2.1.1 ou v2.2 vers 2.2.1. Il est recommandé à tous les utilisateurs d’OS X Server. Pour obtenir des informations sur les correctifs de sécurité de cette mise à jour, veuillez consulter ce site web : [http://support.apple.com/HT1222](http://support.apple.com/HT1222) .

Installation de la mise à jour

OS X Server version 2.2.1 est disponible sur le Mac App Store. Elle apparaît dans le volet Mises à jour si vous avez installé OS X Server (Mountain Lion) 2.0, 2.1, 2.1.1 ou 2.2. Cliquez sur le bouton Mettre à jour pour procéder à l’installation.

Lors de l’installation, le message « Remplacement de l’app Server détectée » peut s’afficher. Ceci est normal. L’intégralité des réglages et des données de l’app Server est conservée lors de la mise à jour.

Une fois l’installation terminée, ouvrez l’app Server afin de terminer l’installation de tous les services précédemment configurés.

Voici quelques-unes des améliorations apportées par cette mise à jour :

Service de mise en cache

- Introduction d’une nouvelle fonctionnalité, Service de mise en cache, qui accélère le téléchargement des logiciels distribués par Apple via le Mac App Store. Elle met en cache les mises à jour logicielles et les apps achetées sur le Mac App Store. Pour plus d’informations sur Service de mise en cache, choisissez Aide Server dans le menu Aide .

- Ajoute une clé ListenRangesOnly qui [permet](http://support.apple.com/HT5590) aux administrateurs serveur de restreindre les plages d’adresses IP du réseau disponibles.

- Prise en charge de la mise en cache des apps et des livres achetés via iTunes ou iTunes pour Windows 11.0.2 ou version ultérieure.

App Server

- Inclut une interface de gestion centralisée des certificats.

- Résout un problème de configuration lié à une erreur SSL.

- Inclut des correctifs supplémentaires pour la mise à niveau à partir de Lion Server.

- Résout un problème empêchant la modification du serveur de liste noire utilisé par le service Mail.

- Inclut des améliorations globales.

Pare-feu adaptatif

- Résout un problème entraînant une exception lors de l’utilisation de l’outil hb_summary.

Service Calendrier

- Résout un problème dans lequel les invitations Calendrier étaient toujours envoyées en anglais.

- Inclut des améliorations globales.

Service Mail

- Corrige un problème dans lequel freshclam et clamav ne fournissent pas de journaux sur les systèmes mis à niveau.

- Résout un problème empêchant le respect de la limite stricte du quota.

- Résout un problème empêchant la conservation de certains réglages lors de la mise à niveau à partir d’une version précédente d’OS X Server.

Service Contacts

- Résout un problème empêchant, dans certaines circonstances, le démarrage du service lors de l’utilisation d’un emplacement autre que celui par défaut pour le magasin de données.

- Ajoute la possibilité de rechercher des enregistrements contenant des caractères non anglais.

Service Messages

- Résout un problème empêchant, dans certaines circonstances, le démarrage du service lors de l’utilisation d’un emplacement autre que celui par défaut pour le magasin de données.

Gestionnaire de profils

- Ajoute la possibilité d’utiliser des groupes Active Directory avec le gestionnaire de profil.

- Ajoute la possibilité de supprimer des apps téléchargées dans le gestionnaire de profils.

- Inclut des améliorations de performances et d’autres améliorations globales.

Time Machine

- Permet de surveiller les ordinateurs qui ont effectué une sauvegarde, la date de la dernière sauvegarde et la taille de la sauvegarde.

## Informations supplémentaires

Le service DHCP peut ne pas démarrer automatiquement lors d’une mise à jour à partir d’une version précédente d’OS X Server configurée pour utiliser le service DHCP. Dans ce cas, ouvrez l’app Server et démarrez le service manuellement.

OS X Server 2.2 et 2.2.1 stockent les données Postgres nécessaires aux services dans leur propre emplacement (« /Library/Server/PostgreSQL For Server Services/Data » par défaut). Si vous migrez d’une version précédente d’OS X Server vers 2.2 ou 2.2.1, les données Postgres du système seront migrées de /Library/Server/PostgreSQL/Data vers « /Library/Server/PostgreSQL For Server Services/Data ». Tout contenu personnalisé que vous avez créé dans /Library/Server/PostgreSQL/Data y sera conservé après la mise à niveau vers OS X Server 2.2 ou 2.2.1. Si vous souhaitez accéder à ces données, ou si vous installez OS X Server 2.2 ou 2.2.1 pour la première fois et souhaitez créer de nouvelles données Postgres, vous devrez peut-être démarrer le service avec cette commande :

sudo serveradmin start postgres

Cela démarre un processus Postgres distinct de celui utilisé par les services, qui peut être utilisé pour votre propre contenu.
