# Utiliser les descriptions audio dans iTunes pour Windows

Si la vidéo que vous regardez comprend des descriptions audio (DA), vous pouvez les activer pour que les scènes des vidéos vous soient décrites.

## Activer les descriptions audio dans iTunes pour Windows

- Passez le pointeur sur votre vidéo.

- Cliquez sur l’icône en forme de bulle .

[Image: icône en forme de bulle]

- Choisissez la piste de description audio à utiliser.

[Image: windows-10-itunes-12-player-audio-subtitles-options]

## Activer automatiquement les descriptions audio

- Ouvrez iTunes pour Windows.

- Dans la barre de menus, cliquez sur Édition, puis choisissez Préférences.

- Cliquez sur Lecture.

- Sélectionnez Lire les descriptions audio si disponible.

## Informations supplémentaires

- Activez les descriptions audio [sur votre iPhone, iPad ou iPod touch](https://support.apple.com/HT205796) ou [votre Mac](https://support.apple.com/HT205800) ou [Apple TV](https://support.apple.com/HT205799) .

- [Rechercher du contenu comprenant une description audio](https://support.apple.com/HT205742) dans l’app Apple TV ou l’iTunes Store. Les vidéos ne comportent pas toutes des pistes de description audio.
