# À propos du rotor VoiceOver sur l’iPhone ou l’iPad

Vous pouvez utiliser le rotor VoiceOver pour modifier la manière dont ce service fonctionne. En effet, vous pouvez modifier le volume ou le débit vocal, passer d’un élément à l’autre sur l’écran, et bien plus encore.

[Image: iPhone présentant la page d’accueil apple.com/fr et le rotor VoiceOver. Les doigts d’une main tournent pour sélectionner une option de rotor.]

## Utilisation du rotor VoiceOver

Tout d’abord, si vous n’avez pas activé VoiceOver, faites-le maintenant :

- Accédez à Réglages > Accessibilité > VoiceOver.

- Activez VoiceOver.

Pour utiliser le rotor :

- Déplacez deux doigts sur l’écran de votre appareil iOS ou iPadOS, comme si vous faisiez tourner un cadran. La première option est énoncée par VoiceOver.

- Continuez à faire tourner vos doigts pour entendre les autres options.

- Soulevez vos doigts pour sélectionner une option.

- Une fois cela fait, déplacez un doigt vers le haut ou le bas de l’écran. Par exemple, si vous choisissez l’option Mots lorsqu’un document est ouvert, un déplacement vers le bas ou vers le haut permet de passer au mot suivant ou précédent.

## Options de navigation

Avec toutes ces options, déplacez un doigt du haut vers le bas pour passer à l’élément suivant, ou du bas vers le haut pour passer à l’élément précédent.

### Vérifier le texte à mesure de la saisie, grâce aux fonctionnalités Caractères, Mots et Lignes

- Caractères : permet de lire un caractère à la fois.

- Mots : permet de lire un mot à la fois.

- Lignes : permet de lire une ligne à la fois.

### Parcourir une page ou votre écran

- Conteneurs : permet de passer d’un conteneur à l’autre. Par exemple, le Dock et l’écran d’accueil sont des conteneurs.

- En-têtes : permet de passer d’un en-tête à l’autre. Pour utiliser cette option, accédez à Réglages > Mail, Contacts, Calendrier.

- Repères : permet de parcourir diverses bannières, divers liens ou divers boutons dans du contenu HTML (par exemple, sur une page web ou dans un e-mail au format HTML).

- Même élément : permet de passer d’un élément de même type à l’autre. Vous pouvez utiliser cette option lorsque plusieurs liens vous sont proposés dans le cadre d’une recherche dans Safari.

- Navigation verticale : permet de se déplacer vers le haut ou le bas à l’aide d’un glissement vertical à un doigt. Cette option peut être utilisée sur l’écran d’accueil.

- Texte statique : permet de passer d’un texte statique au format HTML à l’autre. Le texte statique se rapporte au texte principal d’une page, mais n’inclut pas les liens ni les noms de bouton, par exemple.

### Passer d’un lien à l’autre

- Liens : permet de passer au lien suivant.

- Liens visités : permet de passer au lien suivant, mais uniquement si vous avez déjà cliqué sur celui-ci.

- Liens non visités : permet de passer au lien suivant, mais uniquement si vous n’avez pas encore cliqué sur celui-ci.

- Liens internes : permet de passer au lien interne suivant sur une page web.

### Vous pouvez également vous déplacer sur une page en optant pour les options ci-dessous :

- Tableaux : permet de placer le curseur VoiceOver au début d’un tableau, sur une page web.

- Listes : permet de placer le curseur VoiceOver au début d’une liste, sur une page web.

- Boutons : permet de passer d’un bouton à l’autre, dans du contenu HTML.

- Contrôles de formulaire : permet de parcourir les divers boutons et menus lors de l’utilisation d’un formulaire.

- Champs de texte : permet de passer d’un champ de texte à l’autre dans du contenu HTML.

- Champs de recherche : permet de passer d’un champ de recherche à l’autre dans du contenu HTML.

- Images : permet d’accéder aux images.

## Modification de la méthode de saisie

Utilisez l’option Mode de saisie pour basculer entre les modes Saisie standard, Saisie tactile ou Saisie tactile directe. Faites glisser un doigt vers le haut ou le bas pour basculer entre ces modes.

Au lieu d’utiliser le rotor, vous pouvez vous rendre dans Réglages > Accessibilité > VoiceOver > Saisie > Style de saisie afin de choisir un mode de saisie.

### Saisie standard

Sélectionnez une touche du clavier en effectuant un balayage vers la gauche ou la droite, puis touchez deux fois l’écran pour saisir le caractère. Vous pouvez également déplacer un doigt au niveau du clavier pour sélectionner une touche puis, tout en le maintenant, toucher l’écran à l’aide d’un autre doigt.

La touche est énoncée par VoiceOver lorsque vous la sélectionnez, et à nouveau lorsque vous saisissez le caractère.

### Saisie tactile

Touchez une touche du clavier pour la sélectionner, puis relevez votre doigt pour saisir le caractère. En cas d’erreur, faites glisser votre doigt jusqu’à la touche désirée.

Le caractère correspondant à chaque touche est énoncé par VoiceOver dès que vous le touchez. Le caractère est saisi lorsque vous relevez votre doigt.

### Saisie tactile directe

Saisissez du texte comme vous le feriez si VoiceOver était désactivé. Ce mode entraîne la désactivation de VoiceOver uniquement en cas de saisie.

## Modifier le style de VoiceOver

Plusieurs options de rotor permettent de changer le style de VoiceOver. Faites glisser un doigt vers le haut ou le bas pour ajuster chaque réglage.

- Voix : permet de basculer entre les différentes voix et langues de VoiceOver.

- Débit vocal : permet d’accélérer ou de ralentir le débit de VoiceOver.

- Volume : permet de monter ou de baisser le volume de VoiceOver.

## Obtenir des descriptions en direct des informations visuelles autour de vous

Utilisez l’option de rotor Reconnaissance en direct pour analyser votre environnement et obtenir des descriptions en direct des scènes détectées dans la vue de la caméra. Vous pouvez également obtenir des descriptions d’images à l’écran et d’éléments d’interface utilisateur, même dans les apps et sur les pages web qui ne fournissent pas d’informations d’accessibilité.

[En savoir plus sur l’utilisation de Reconnaissance en direct](https://support.apple.com/guide/iphone/iph37e6b3844/ios)

Important : la fiabilité de la reconnaissance VoiceOver n’est pas suffisante dans des circonstances où vous pourriez être blessé, dans des situations d’urgence à haut risque ou pour la navigation, ou pour le diagnostic ou le traitement de problèmes médicaux.

## Choisir vos options de rotor

Certaines des options ci-dessus sont activées par défaut, alors que d’autres peuvent l’être en supplément. Vous pouvez voir la liste complète des options de rotor disponibles sous Réglages > Accessibilité > VoiceOver > Rotor > Éléments du rotor.

Pour choisir vos options de rotor :

- Accédez à Réglages > Accessibilité > VoiceOver > Rotor > Éléments du rotor.

- Sélectionnez les options désirées.

Pour changer l’ordre dans lequel les éléments apparaissent sur le rotor :

- Accédez à Réglages > Accessibilité > VoiceOver > Rotor > Éléments du rotor.

- Faites glisser le bouton Réorganiser [Élément] sur un élément pour le réorganiser.

Certaines options ne sont pas constamment activées, notamment l’option Mode de saisie, qui l’est uniquement lorsqu’un clavier est disponible.
