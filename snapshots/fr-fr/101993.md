# Utiliser Isolement de la voix, Large spectre ou le mode micro automatique sur votre iPhone ou votre iPad

Vous pouvez ajuster les réglages du microphone de façon à bloquer les bruits ambiants pour rendre votre voix encore plus claire, à ne pas filtrer les bruits ambiants si vous souhaitez faire ressortir votre voix et tous les sons qui vous entourent, ou à basculer automatiquement vers le mode le plus approprié.

## Éléments requis

- Pour utiliser la fonction Isolement de la voix ou Large Spectre pendant un appel audio ou vidéo FaceTime, ou dans certaines apps tierces, vous devez disposer d’iOS 15 ou version ultérieure.

- Pour utiliser Isolement de la voix dans une app d’enregistrement audio ou vidéo telle que Dictaphone, ou dans certaines apps tierces, vous avez besoin d’iOS 26 ou version ultérieure.

- Pour utiliser la fonction Isolement de la voix pendant un appel téléphonique, vous devez disposer d’iOS 16.4 ou version ultérieure. Le mode Large spectre n’est pas disponible pour les appels téléphoniques.

- Pour utiliser le mode micro automatique, vous devez disposer d’iOS 18 ou version ultérieure.

Vous pouvez utiliser Isolement de la voix et Large spectre sur ces appareils :

- iPhone XR, modèles d’iPhone XS et modèles ultérieurs

- iPad (8e génération) et modèles ultérieurs

- iPad Pro 13 pouces (M4)

- Tous les modèles d’iPad Pro 11 pouces

- iPad Pro 12,9 pouces (3e génération) et modèles ultérieurs

- iPad Air (3e génération) et modèles ultérieurs

- iPad mini (5e génération) et modèles ultérieurs

## Activer Isolement de la voix, Large spectre ou le mode micro automatique

- Lors d’un appel ou d’un enregistrement, effectuez un balayage vers le bas à partir de l’angle supérieur droit de votre écran pour ouvrir le centre de contrôle*.

- Appuyez sur Commandes [App].

[Image: iPhone affichant le centre de contrôle. Le bouton Téléphone Commandes se trouve en haut de l’écran.]

- Sous Audio et vidéo, sélectionnez un mode micro :

[Image: iPhone affichant les commandes audio du téléphone dans le centre de contrôle. Le mode micro automatique est sélectionné sous Audio et vidéo.]

- Automatique : utilise automatiquement le mode micro qui convient le mieux à votre type d’enregistrement. Par exemple, le mode automatique utilise Isolement de la voix pour bloquer les bruits ambiants pendant les appels passés à l’aide du récepteur, et il utilise le mode micro standard pour les appels utilisant le haut-parleur.

- Standard : utilise le traitement de voix standard.

- Isolement de la voix : donne la priorité à votre voix et bloque les bruits ambiants.

- Large spectre : ne filtre pas les bruits ambiants.

Votre sélection s’applique uniquement à l’app utilisée pour passer l’appel ou effectuer l’enregistrement. Les modes micro restent activés pour cette app jusqu’à ce que vous choisissiez un autre mode.

## Modifier les niveaux de gain en entrée

Dans iOS 26.1 et iPadOS 26.1, vous pouvez régler le niveau de gain en entrée sur les microphones et appareils filaires pris en charge, tels que les Earpods avec connecteur USB-C.

- Lors d’un appel ou d’un enregistrement, effectuez un balayage vers le bas à partir de l’angle supérieur droit de votre écran pour ouvrir le centre de contrôle.

- Appuyez sur Commandes [App].

- Sous Entrée audio, faites glisser le curseur pour régler le niveau de gain.

[Image: iPhone affichant le centre de contrôle avec une zone d’entrée audio et un curseur de gain.]

## Changer d’entrée audio

Si plusieurs périphériques audio sont connectés, vous pouvez changer d’entrée audio.

- Lors d’un appel ou d’un enregistrement, effectuez un balayage vers le bas à partir de l’angle supérieur droit de votre écran pour ouvrir le centre de contrôle.

- Appuyez sur Commandes [App].

- En regard d’Entrée audio, touchez l’appareil, puis le périphérique audio que vous souhaitez utiliser.

* Dans les apps compatibles, vous pouvez changer le mode micro avant un appel ou un enregistrement.
