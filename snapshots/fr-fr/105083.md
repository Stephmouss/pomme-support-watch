# Comment modifier des messages sur votre iPhone

Dans Messages sous iOS 16, iPadOS 16.1, macOS Ventura ou version ultérieure, vous pouvez modifier un message envoyé jusqu’à cinq fois dans les 15 minutes suivant son envoi.

## Modifier un message envoyé sous iOS 16 ou iPadOS 16.1 et versions ultérieures

- Dans l’app Messages, touchez une conversation.

- Touchez de manière prolongée le message que vous souhaitez modifier.

- Touchez Modifier.

[Image: Un iPhone affichant un message texte dans Messages avec l’option Modifier visible.]

4. Effectuez vos modifications, puis touchez la coche pour finaliser le message ou le X pour revenir au message d’origine.

Si vous apportez des modifications, le terme « Modifié » apparaît sous le message. Vous pouvez modifier un iMessage jusqu’à cinq fois au cours des 15 minutes suivant son envoi.

[Image: Un iPhone affichant un message texte modifié. Le terme « Modifié » apparaît sous le message.]

Pour modifier des messages, utilisez iMessage avec iOS 18, iPadOS 18, macOS Ventura ou une version ultérieure. Si vous modifiez un message envoyé à quelqu’un qui utilise une ancienne version d’iOS, iPadOS ou macOS, la version mise à jour apparaîtra sous la forme d’un second message, qui commencera par : « Modifié ».

## Afficher toutes les modifications apportées à un message

- Dans l’app Messages, touchez une conversation.

- Faites défiler l’écran jusqu’au message pour lequel vous souhaitez consulter l’historique des modifications.

- Touchez le terme « Modifié » sous le message actuel pour afficher le ou les messages précédents.

[Image: Écran d’iPhone affichant un message en dessous duquel figure la mention « Modifié », indiquant qu’un historique des modifications est disponible.]

Après que quelqu’un a modifié un message, tout le monde dans la conversation peut toucher le terme « Modifié » pour afficher l’historique des modifications.
