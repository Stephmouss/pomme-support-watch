# Importation d’e-mails existants dans Mail iCloud à partir de votre domaine de messagerie personnalisé

Lorsque vous utilisez un domaine de messagerie personnalisé avec Mail iCloud, vous pouvez importer les e-mails de votre ancien fournisseur de messagerie dans Mail iCloud et regrouper tous vos e-mails au même endroit. Vous pouvez importer les e-mails de votre domaine de messagerie personnalisé uniquement sur le Web à l’adresse iCloud.com.

Lorsque vous importez des e-mails existants :

- Vos messages apparaissent dans un nouveau dossier dans Mail iCloud avec le nom de votre ancienne adresse e-mail.

- Si vos e-mails étaient organisés dans plusieurs dossiers dans votre compte de messagerie précédent, ces dossiers figurent dans le nouveau dossier.

Avant d’importer vos e-mails dans Mail iCloud, vérifiez le nombre de messages que vous importez et [assurez-vous que vous disposez de suffisamment d’espace de stockage iCloud](https://support.apple.com/guide/icloud/mm039c13d410/) :

- Connectez-vous à votre ancien fournisseur de messagerie pour vérifier la quantité d’e-mails que vous importez.

- Si vous avez besoin de davantage d’espace de stockage, découvrez comment [gérer votre espace de stockage iCloud](https://support.apple.com/108922) .

Tous les fournisseurs de messagerie ne sont pas actuellement pris en charge.

## Importation de vos e-mails lors de la configuration du domaine de messagerie personnalisé

Quand vous [configurez votre domaine personnalisé pour Mail iCloud](https://support.apple.com/guide/icloud/mma473945269) , vous pouvez importer vos e-mails existants :

- Lorsque vous choisissez une adresse e-mail par défaut, vous avez la possibilité d’importer des e-mails.

- Sélectionnez l’adresse e-mail à partir de laquelle vous souhaitez importer des messages. Vous pourrez importer ultérieurement des messages provenant d’autres adresses e-mail.

- Sélectionnez Continuer pour vous connecter à votre ancien compte de messagerie et suivez les instructions à l’écran pour terminer l’importation de vos messages existants.

En fonction du nombre d’e-mails importés, leur affichage peut prendre un certain temps.

## Importation ultérieure d’e-mails

- Accédez à [iCloud.com/icloudplus](https://www.icloud.com/icloudplus) , puis connectez-vous à votre compte Apple.

- Cliquez sur Domaine de messagerie personnalisé.

- Sélectionnez l’adresse e-mail à partir de laquelle vous souhaitez importer des e-mails, faites défiler vers le bas et sélectionnez le bouton Importer l’adresse e-mail (ou cliquez sur le bouton Ajouter pour importer des e-mails à partir d’une autre adresse).

## Déplacement manuel de messages électroniques

Si vous ne pouvez pas importer vos e-mails existants, vous pouvez déplacer manuellement vos e-mails vers Mail iCloud à l’aide de l’app Mail.

[Organiser les e-mails dans des boîtes aux lettres sur l’iPhone](https://support.apple.com/guide/iphone/iph376ef8aa3/)

[Déplacer ou copier des e-mails entre des boîtes aux lettres dans Mail sur Mac](https://support.apple.com/guide/mail/mlhlp1000/)
