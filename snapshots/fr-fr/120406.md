# Si vous ne trouvez pas ChromaGlow, Stem Splitter ni d’autres fonctionnalités de Logic Pro sur votre Mac

Certaines fonctionnalités de Logic Pro ne sont pas disponibles sur les Mac à processeur Intel ou lors de l’exécution de Logic Pro dans Rosetta sur un Mac avec puce Apple.

## Disponibilité des fonctionnalités

Les fonctionnalités de Logic Pro suivantes ne sont pas disponibles sur un Mac à processeur Intel ou lors de l’exécution de Logic Pro dans Rosetta sur un Mac avec puce Apple :

- Stem Splitter

- ChromaGlow

- Préréglages Valve, Transparent et Punch dans l’assistant de masterisation

Si vous exécutez Logic Pro dans Rosetta, assurez-vous que l’utilisation de Rosetta est requise. Dans la plupart des cas, cela n’est pas nécessaire.

## Vérifier si l’utilisation de Rosetta est nécessaire

L’utilisation d’un module tiers tel que Melodyne de Celemony en mode ARA dans un projet est la seule raison nécessitant l’exécution de Logic Pro dans Rosetta sur un Mac avec puce Apple. Si vous ne savez pas si l’un de vos modules tiers doit impérativement être utilisé en mode ARA, renseignez-vous auprès de son fabricant.

Si vous n’utilisez aucun module de ce type dans un projet, vous pouvez ouvrir Logic Pro en mode natif afin d’accéder à l’ensemble des fonctionnalités de Logic Pro :

- Quittez Logic Pro.

- Tout en maintenant la touche Contrôle enfoncée, cliquez sur l’app Logic Pro dans le dossier Applications, puis choisissez Lire les informations.

- Désélectionnez « Ouvrir avec Rosetta ».

- Ouvrez Logic Pro.
