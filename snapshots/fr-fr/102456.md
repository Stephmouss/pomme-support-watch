# Si Safari ne parvient pas à afficher de sites web ou se ferme sur votre iPhone, iPad ou iPod touch

Si vous ne parvenez pas à afficher un site ou une page web, ou si Safari se ferme de manière inopinée, procédez comme indiqué dans cet article.

## Connectez-vous à un réseau différent

Essayez de charger un site web, comme le site [www.apple.com](https://www.apple.com) , par l’intermédiaire d’un réseau de données mobiles. Si vous n’avez pas de forfait de données mobiles, [connectez-vous à un autre réseau Wi-Fi](https://support.apple.com/fr-fr/111107) , puis chargez le site web.

Le cas échéant, [vérifiez les réglages de votre VPN](https://support.apple.com/fr-fr/102281) (réseau privé virtuel). Si un VPN est activé, certaines apps ou certains sites web peuvent bloquer le chargement de contenu.

## Redémarrer votre appareil

Éteignez votre appareil, puis rallumez-le :

- [Redémarrer votre iPhone](https://support.apple.com/fr-fr/118259)

- [Redémarrer votre iPad](https://support.apple.com/fr-fr/101603)

- [Redémarrer votre iPod touch](https://support.apple.com/fr-fr/102137)

## Effacer les données des sites web

Pour optimiser les performances de Safari, vous pouvez, occasionnellement, effacer les données des sites web :

- Accédez à Réglages, puis touchez Apps.

- Touchez Safari.

- Touchez Effacer historique, données de site.

- Confirmez en touchant Effacer l’historique.

## Activer JavaScript

Activez JavaScript s’il n’est pas déjà activé :

- Accédez à Réglages, puis touchez Apps.

- Touchez Safari.

- Touchez Avancé, puis activez JavaScript.

## Assistance supplémentaire

Si le problème persiste et n’affecte qu’un site web ou qu’une page web spécifique, vérifiez si le relais privé est activé. Vous pouvez [désactiver temporairement le relais privé dans les réglages iCloud](https://support.apple.com/fr-fr/102022) . Si Safari n’affiche toujours pas les sites web et que vous avez essayé toutes ces étapes, contactez le développeur du site web pour obtenir une aide supplémentaire.
