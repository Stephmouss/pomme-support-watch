# Comment forcer le redémarrage de votre iPod shuffle

Si votre iPod shuffle ne répond pas lorsque vous appuyez sur ses boutons, vous pouvez le forcer à redémarrer.

## Forcer le redémarrage de votre iPod shuffle

- Débranchez votre iPod shuffle de son chargeur et de votre ordinateur.

- Utilisez le commutateur d’alimentation pour éteindre votre iPod shuffle. Si vous voyez du vert près du commutateur, cela signifie que votre appareil est allumé. ( [Vous ne trouvez pas le commutateur d’alimentation ?](https://support.apple.com/fr-fr/102062#switch) )

- Patientez pendant dix secondes. Allumez ensuite à nouveau votre iPod shuffle.

[Image: Forcer le redémarrage de votre iPod shuffle]

Découvrez comment [charger votre iPod shuffle](https://support.apple.com/fr-fr/101397) .
