# Contrôler les fenêtres rouvertes par Safari sur Mac

Chaque fois que Safari s’ouvre, les fenêtres et les onglets de la session précédente, ou une ou plusieurs autres fenêtres ou onglets, peuvent se rouvrir.

## Choisir de rouvrir ou non les fenêtres dans Safari

Lorsque vous ouvrez Safari, l’app peut automatiquement restaurer les fenêtres ou onglets qui étaient ouverts lors de votre précédente session. Si vous souhaitez modifier ce comportement, suivez l’une des étapes ci-dessous :

- Pour empêcher la réouverture des fenêtres la prochaine fois que vous ouvrirez Safari, appuyez de façon prolongée sur la touche Maj pendant que vous ouvrez Safari.

- Pour empêcher la réouverture des fenêtres chaque fois que vous ouvrez Safari, [activez le réglage système « Fermer les fenêtres à la fermeture d’une application »](https://support.apple.com/fr-fr/102318) .

Après avoir activé le réglage système, vérifiez également les réglages de Safari :

- Dans le menu Safari, choisissez Réglages (ou Préférences).

- Dans la sous-fenêtre Général, choisissez un réglage dans le menu « Au démarrage, Safari ouvre : ».

- Si vous configurez Safari pour qu’il s’ouvre dans une nouvelle fenêtre, utilisez le menu « Les nouvelles fenêtres s’ouvrent avec : » pour définir la fenêtre ou les onglets de Safari à rouvrir.

## Si Safari rouvre des fenêtres indésirables

Après avoir vérifié vos réglages, si Safari continue de rouvrir une ou plusieurs fenêtres ou onglets indésirables, ou change constamment de moteur de recherche, un [site d’hameçonnage](https://support.apple.com/fr-fr/102568) peut vous avoir incité à installer un logiciel inconnu ou suspect. Si vous pensez avoir des logiciels malveillants ou des logiciels publicitaires sur votre Mac :

- [Mettez à jour macOS sur votre Mac](https://support.apple.com/fr-fr/108382) . S’il est déjà à jour, redémarrez votre Mac. Un outil intégré à macOS supprime les logiciels malveillants connus lors du redémarrage.

- Supprimez toutes les apps et [extensions Safari](https://support.apple.com/fr-fr/102343) inconnues ou suspectes.

- [Découvrez comment bloquer les fenêtres publicitaires et les fenêtres pop-up](https://support.apple.com/fr-fr/102524) .

- Supprimez tout profil de configuration du système inconnu ou suspect, même si le profil ne semble pas lié aux fenêtres indésirables. Pour supprimer un profil, sélectionnez-le dans Réglages Système, cliquez sur le bouton de suppression (-) sous la liste des profils, puis redémarrez votre Mac. Cependant, si votre Mac appartient à un établissement d’enseignement ou à une autre organisation, contactez son administrateur système avant de supprimer un profil utile. Pour accéder aux profils dans Réglages Système :

- macOS Sequoia 15 ou version ultérieure : dans le menu Pomme , choisissez Réglages Système. Cliquez sur Général dans la barre latérale, puis sur Gestion des appareils à droite.

- macOS Ventura 13 ou version ultérieure : dans le menu Pomme , choisissez Réglages Système. Cliquez sur Confidentialité et sécurité dans la barre latérale, puis faites défiler vers le bas et cliquez sur Profils à droite.

- Versions antérieures de macOS : dans le menu Pomme , choisissez Préférences Système, puis cliquez sur Profils.
