# Où trouver des téléchargements sur votre iPhone ou iPad

Si vous téléchargez un fichier sur votre iPhone ou iPad depuis Internet, vous pourrez le retrouver dans le dossier Téléchargements de l’app Fichiers.

## Trouver des téléchargements dans l’app Fichiers

- Ouvrez l’app Fichiers. L’icône bleue de l’app Fichiers ne se trouve pas sur votre écran d’accueil ? Balayez vers le bas depuis le centre de votre écran d’accueil, puis recherchez l’app Fichiers.

[Image: Recherchez « fichiers » sur votre iPhone. L’app Fichiers apparaît en haut des résultats.]

- Touchez l’onglet Explorer.

- Touchez iCloud Drive.

- Appuyez sur le dossier Téléchargements pour voir vos fichiers téléchargés.

[Image: Dans l’app Fichiers, accédez à iCloud Drive pour trouver le dossier Téléchargements.]

## Si vous venez de télécharger un fichier depuis Safari

- À côté du champ de recherche dans Safari, touchez le bouton Téléchargements.

- Touchez Téléchargements pour voir vos fichiers téléchargés.

[Image: Une fois que vous avez téléchargé un fichier dans Safari, un bouton Téléchargements apparaît à côté du champ de recherche.]
