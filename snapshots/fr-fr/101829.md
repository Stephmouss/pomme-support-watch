# Combien d’écrans pouvez-vous connecter au Mac Pro ?

Le nombre d’écrans externes que vous pouvez utiliser simultanément dépend de la résolution et du taux de rafraîchissement de chaque écran.

[Mac Pro (2023)](https://support.apple.com/fr-fr/101829#macpro2023)

[Autres modèles de Mac Pro](https://support.apple.com/fr-fr/101829#older-models)

L’utilisation d’un concentrateur compatible ou le branchement en série d’écrans vous permet d’installer jusqu’à deux écrans sur un seul port Thunderbolt, sans pour autant augmenter le nombre maximal d’écrans pris en charge. Connectez d’abord l’écran présentant la résolution la plus élevée.

## Mac Pro (2023)

Le Mac Pro (2023) prend en charge jusqu’à huit écrans externes simultanément, en fonction de la résolution et du taux de rafraîchissement de chaque écran externe.

### Groupes de ports

Le Mac Pro (2023) possède deux groupes de ports qui prennent chacun en charge jusqu’à quatre écrans. Un écran 8K (7 680 x 4 320) à 60 Hz ou 4K (3 840 x 2 160) à 240 Hz connecté via HDMI utilise la bande passante de deux écrans sur ce groupe de ports.

- Groupe de ports 1 : les quatre premiers ports Thunderbolt à l’arrière et le premier port HDMI à l’arrière

- Groupe de ports 2 : les deux derniers ports Thunderbolt à l’arrière, le deuxième port HDMI à l’arrière, et les deux ports Thunderbolt en haut du boîtier de tour ou à l’avant du boîtier en rack

### Configurations d’écran prises en charge

Découvrez les nombreuses configurations d’écrans que vous pouvez utiliser avec votre Mac Pro.

### Un écran externe

Fonctionne avec un écran externe dans une de ces configurations :

- Un écran jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt

- Un écran d’une résolution native pouvant aller jusqu’à 8K (7 680 x 4 320) à 60 Hz ou 4K (3 840 x 2 160) à 240 Hz via HDMI

### Deux écrans externes

Fonctionne avec deux écrans externes dans une de ces configurations :

- Deux écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt

- Deux écrans jusqu’à une résolution native de 8K (7 680 x 4 320) à 60 Hz ou 4K (3 840 x 2 160) à 240 Hz via HDMI

- Un écran jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt, et un écran jusqu’à une résolution native de 8K (7 680 x 4 320) à 60 Hz ou 4K (3 840 x 2 160) à 240 Hz via HDMI

### Trois écrans externes

Prise en charge de trois écrans externes dans n’importe laquelle de ces configurations :

- Trois écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt

- Deux écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt, et un écran jusqu’à une résolution native de 8K (7 680 x 4 320) à 60 Hz ou 4K (3 840 x 2 160) à 240 Hz via HDMI

- Deux écrans jusqu’à une résolution native de 8K (7 680 x 4 320) à 60 Hz ou 4K (3 840 x 2 160) à 240 Hz via HDMI, et un écran jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt

### Quatre écrans externes

Prise en charge de quatre écrans externes dans l’une des configurations suivantes :

- Quatre écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt

- Trois écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt sur le groupe de ports 1, et un écran jusqu’à une résolution native de 8K (7 680 x 4 320) à 60 Hz ou 4K (3 840 x 2 160) à 240 Hz via HDMI sur le groupe de ports 2

- Deux écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt, et deux écrans jusqu’à une résolution native de 8K (7 680 x 4 320) à 60 Hz ou 4K (3 840 x 2 160) à 240 Hz via HDMI

### Cinq écrans externes

Prise en charge de cinq écrans externes dans l’une des configurations suivantes :

- Quatre écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt sur le groupe de ports 1, et un écran jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt sur le groupe de ports 2

- Quatre écrans jusqu’à 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt sur le groupe de ports 1, et un écran jusqu’à 8K (7 680 x 4 320) à 60 Hz ou 4K (3 840 x 2 160) à 240 Hz via HDMI sur le groupe de ports 2

### Six écrans externes

Prise en charge de six écrans externes dans l’une des configurations suivantes :

- Quatre écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt sur le groupe de ports 1, et deux écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt sur le groupe de ports 2

- Deux écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt sur le groupe de ports 1, deux écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt sur le groupe de ports 2, et deux écrans jusqu’à une résolution native de 4K (3 840 x 2 160) à 144 Hz via HDMI

- Trois écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt sur le groupe de ports 1, deux écrans jusqu’à une résolution native de 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt sur le groupe de ports 2, et un écran jusqu’à une résolution native de 4K (3 840 x 2 160) à 144 Hz via HDMI sur le groupe de ports 2

### Sept écrans externes

Prise en charge de sept écrans externes dans la configuration suivante :

- Sept écrans jusqu’à une résolution native de 4K (3 840 x 2 160) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt et HDMI

### Huit écrans externes

Prise en charge de huit écrans externes dans la configuration suivante :

- Huit écrans jusqu’à une résolution native de 4K (3 840 x 2 160) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt et HDMI

## Autres modèles de Mac Pro

Consultez les caractéristiques techniques du [modèle de votre Mac Pro](https://support.apple.com/fr-fr/102887) afin d’avoir un aperçu du nombre maximal d’écrans externes pris en charge, ainsi que la résolution maximale et le taux de rafraîchissement de chacun d’eux.

## Nombre maximal d’écrans pris en charge

Dans Réglages Système > Moniteurs, les résolutions « À l’échelle » disponibles pour les écrans externes peuvent varier en fonction des ressources système disponibles et du type d’écrans connectés. Les résolutions « À l’échelle » présentées au-dessus de la valeur par défaut de macOS ne sont pas prises en compte dans les capacités maximales de prise en charge indiquées ci-dessus.
