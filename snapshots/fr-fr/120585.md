# Plans pour le Web est compatible avec ces navigateurs web

Selon l’appareil que vous utilisez, Plans pour le Web fonctionne mieux sur la dernière version de ces navigateurs.

## Sur votre Mac ou PC

- Safari (macOS uniquement)

- Edge

- Chrome

- Firefox

## Sur votre appareil mobile

- Safari (iOS ou iPadOS uniquement)

- Edge

- Chrome

- Firefox

La disponibilité des fonctionnalités peut varier selon la plateforme, la langue et la région.
