# Installer ou remplacer des modules SSD dans votre Mac Pro (2023)

Découvrez comment installer des modules SSD dans votre Mac Pro et les configurer à l’aide d’Apple Configurator.

Sur le Mac Pro, le lecteur SSD (Solid-State Drive) se présente sous la forme d’un ou de deux modules de stockage, selon la capacité. Les modules SSD sont associés à et chiffrés par la Secure Enclave de la puce M2 Ultra. Si vous remplacez les modules SSD, procédez à leur effacement et à leur configuration pour votre Mac Pro à l’aide d’Apple Configurator.

## Vérification de la configuration requise

Les éléments suivants sont nécessaires pour installer ou remplacer des modules SSD dans votre Mac Pro :

- Tournevis T8

- Câble USB-C vers USB-C prenant en charge l’alimentation et le transfert de données

- Les câbles Thunderbolt 3 ne sont pas compatibles.

- Un autre ordinateur Mac doté de [macOS 12.4 ou version ultérieure](https://support.apple.com/HT201541) et [d’Apple Configurator 2.12 ou version ultérieure](https://support.apple.com/HT208040)

- [Modules SSD compatibles avec le Mac Pro (2023)](https://www.apple.com/fr/shop/product/MR393ZM/A/kit-de-mise-à-niveau-ssd-2-to-apple-pour-mac-pro)

## Désinstaller et installer les modules SSD

Procédez aux étapes suivantes uniquement si toutes les données du module SSD existant ont été sauvegardées.

Une fois que l’opération de jumelage d’un nouveau module SSD a débuté, il est impossible de récupérer les données présentes sur le module SSD existant.

[Suivez ces instructions pour désinstaller et installer des modules SSD dans votre Mac Pro.](https://support.apple.com/guide/mac-pro/uninstall-and-install-ssd-modules-apd587f502f6/mac)

## Restaurer le programme interne

Après avoir installé les nouveaux modules SSD, [restaurez le programme interne de votre Mac Pro et effacez le stockage flash interne](https://support.apple.com/guide/apple-configurator-mac/revive-or-restore-a-mac-with-apple-silicon-apdd5f3c75ad/mac) .
