# Utiliser des apps cloud tierces dans l’app Fichiers

Vous pouvez ajouter des services cloud tiers tels que Google Drive, Box, Dropbox et Microsoft OneDrive à l’app Fichiers. Vous pourrez ensuite accéder à tous vos fichiers sur tous vos appareils.

## Ajouter des apps de stockage cloud tierces à l’app Fichiers

- Téléchargez et configurez l’app cloud tierce, telle que Dropbox, Microsoft OneDrive ou Google Drive.

- Ouvrez l’app Fichiers, puis touchez Explorer.

- Touchez le bouton Plus , puis touchez Modifier.

[Image: null]

[Image: Un iPhone doté d’iOS 26 présente l’onglet Explorer d’iCloud Drive après que vous avez touché le bouton Plus. Un menu s’ouvre et l’une de ses options est Modifier.]

- Activez les apps cloud tierces que vous souhaitez utiliser dans l’app Fichiers. Touchez le bouton OK .

[Image: null]

[Image: Un iPhone doté d’iOS 26 présente l’onglet Explorer d’iCloud Drive après que vous avez touché Modifier. Sous Emplacements, les options iCloud Drive, Sur mon iPhone, Box et Dropbox sont répertoriées.]

Si l’un des services dans le cloud tiers que vous utilisez n’apparaît pas dans l’app Fichiers, contactez votre fournisseur de services.

## Déplacer des fichiers d’une app cloud tierce vers l’app Fichiers

- Dans l’app Fichiers, recherchez le fichier tiers que vous souhaitez déplacer.

- Touchez de façon prolongée le fichier jusqu’à ce qu’un menu apparaisse, puis touchez Déplacer.

- Sélectionnez le dossier dans lequel vous souhaitez déplacer votre fichier.

- Sous iOS 26, touchez le bouton Ok . Sous iOS 18 ou version antérieure, touchez à nouveau Déplacer.
