# GarageBand : message d’erreur « Core Audio Plug-in EXS24... not available » (Module externe Core Audio EXS24... non disponible) lors du chargement d’un morceau

Si vous créez un morceau dans GarageBand sur un ordinateur, puis que vous essayez de l’ouvrir dans GarageBand sur un autre ordinateur, un message d’alerte peut s’afficher, indiquant que le module externe Core Audio EXS24 n’est pas disponible.

Cela peut se produire si vous créez le morceau dans GarageBand 2, puis que vous essayez de l’ouvrir dans GarageBand 1 sur un autre ordinateur. En effet, GarageBand 2 inclut de nouveaux modules externes non disponibles dans GarageBand 1. Cependant, cela peut également se produire si un morceau fait appel à des modules externes Jam Pack qui ne sont pas installés sur l’ordinateur sur lequel vous travaillez actuellement.

Pour plus de flexibilité, pensez à mettre à niveau tous les ordinateurs que vous utilisez vers la même version de GarageBand et installez les mêmes modules Jam Pack.
