# Un utilisateur d’Active Directory n’est pas averti lorsque le mot de passe saisi dans la fenêtre d’authentification n’est pas suffisamment complexe

Lorsqu’un utilisateur d’Active Directory tente de modifier son mot de passe dans la fenêtre d’authentification, il est possible que celle-ci réagisse si le nouveau mot de passe ne remplit pas les critères d’Active Directory en matière de complexité des mots de passe.

## Résolution

Effectuez une [mise à jour](http://support.apple.com/kb/HT1338?viewlocale=fr_FR) vers OS X Lion 10.7.4 ou version ultérieure.

## Informations supplémentaires

Si le problème persiste, contactez votre administrateur système Active Directory pour vérifier que le mot de passe remplit les critères minimum en matière de complexité.
