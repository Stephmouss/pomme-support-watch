# Si une sauvegarde Time Machine prend beaucoup de temps

Time Machine est conçu pour fonctionner en arrière-plan, sans interférer avec le fonctionnement normal de votre ordinateur. Time Machine sauvegarde uniquement les modifications apportées depuis la sauvegarde précédente. Une fois la première sauvegarde effectuée, les suivantes devraient donc être plus rapides.

## Rechercher des fichiers volumineux et fréquemment mis à jour

Certaines apps stockent les données dans des fichiers particulièrement volumineux et les mettent fréquemment à jour. La sauvegarde de ces fichiers peut prendre du temps, et Time Machine les sauvegarde chaque fois qu’une modification est détectée.

Vous pouvez [rechercher les documents volumineux et fréquemment utilisés](https://support.apple.com/guide/mac-help/syspf5a64aa6/mac) sur votre Mac, puis choisir d’ [exclure ces fichiers de votre sauvegarde Time Machine](https://support.apple.com/guide/mac-help/mh15622/mac) .

Vous pouvez aussi [contacter l’équipe de développement de l’app](https://support.apple.com/fr-fr/103190) pour savoir comment utiliser au mieux cette dernière avec Time Machine.

## Rechercher les applications qui sollicitent excessivement votre disque de sauvegarde

Certaines applications, telles que les utilitaires antivirus, peuvent occuper votre disque de sauvegarde en permanence en accédant fréquemment au disque pour rechercher ou enregistrer des éléments. Déterminez s’il est possible de modifier les réglages de ces apps pour éviter cela, et ainsi réserver votre disque de sauvegarde exclusivement à Time Machine.

## Connecter le disque de sauvegarde directement à votre Mac

Si vous utilisez votre disque de sauvegarde Time Machine sur un réseau, la vitesse de sauvegarde est affectée par les performances de votre réseau. Vous pouvez améliorer les performances en connectant le disque de sauvegarde directement à votre Mac.

## Mettre à niveau macOS et utiliser un disque de sauvegarde au format APFS

Si vous utilisez le même disque de sauvegarde Time Machine que celui que vous utilisiez avant de passer à macOS Big Sur ou version ultérieure, procédez comme suit :

- Assurez-vous que vous avez installé macOS Big Sur 11 ou version ultérieure. [Identifiez la version de macOS installée sur votre Mac](https://support.apple.com/fr-fr/109033) .

- Sélectionnez votre disque de sauvegarde dans Finder.

- Dans le menu Fichier de la barre de menus, choisissez Lire les informations. Dans la fenêtre qui s’ouvre, recherchez l’information « Format ».

- Si le format indiqué n’est pas APFS, mais que vous souhaitez améliorer les performances de Time Machine, [effacez le disque de sauvegarde à l’aide d’Utilitaire de disque](https://support.apple.com/guide/disk-utility/dskutl14079/mac) en choisissant le format APFS. Cette action supprime définitivement toutes les sauvegardes et autres données de ce disque.

- [Configurez Time Machine](https://support.apple.com/fr-fr/104984) pour utiliser à nouveau le disque de sauvegarde. Après la première sauvegarde, les sauvegardes suivantes devraient être plus rapides.
