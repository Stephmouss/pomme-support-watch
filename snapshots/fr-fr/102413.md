# Si l’app Mail sur votre Mac vous demande sans cesse votre mot de passe

L’app Mail peut indiquer qu’elle ne parvient pas à se connecter à votre compte de messagerie et vous inviter de manière répétée à saisir votre mot de passe.

Si votre Mac est connecté à Internet mais qu’il vous invite soudainement à saisir le mot de passe de votre compte de messagerie, il est généralement recommandé de réessayer ultérieurement. Si nécessaire, vous pouvez contacter votre fournisseur de messagerie afin que celui-ci vous aide à résoudre le problème. [Découvrez comment résoudre les problèmes liés à Mail iCloud](https://support.apple.com/fr-fr/102562) .

## Pourquoi l’app Mail vous demande-t-elle votre mot de passe ?

Lorsque Mail parvient à se connecter à votre fournisseur de messagerie, mais que celui-ci n’accepte pas votre mot de passe de messagerie, l’app ne peut pas se connecter à votre compte et vous invite à saisir votre mot de passe.

Votre fournisseur de messagerie peut refuser votre mot de passe pour diverses raisons, dont les suivantes :

- Vous n’utilisez pas votre mot de passe de messagerie actuel. Si vous l’avez modifié sur un autre appareil, assurez-vous que vous utilisez le même mot de passe sur votre Mac.

- Votre fournisseur de messagerie exige une modification ou une réinitialisation de votre mot de passe pour des raisons de sécurité. Par exemple, si vous utilisez la [validation en deux étapes de Google](http://www.google.com/landing/2step/) , l’accès à votre compte Gmail dans Mail nécessite le [mot de passe d’application approprié](https://support.google.com/accounts/answer/185833?hl=fr) .

- Votre fournisseur de messagerie a désactivé ou suspendu votre compte. Contactez-le pour obtenir de l’aide.

- Votre fournisseur de messagerie a changé sa méthode d’authentification. Dans ce cas, vous devrez peut-être [supprimer votre compte, puis l’ajouter à nouveau](https://support.apple.com/fr-fr/102413#remove) .

## Vérifier votre mot de passe dans les réglages Comptes Internet

Selon le type de compte de messagerie que vous utilisez, il se peut que vous puissiez corriger votre mot de passe en procédant comme suit :

- Fermez l’app Mail. Si elle ne se ferme pas, vous pouvez [forcer sa fermeture](https://support.apple.com/fr-fr/102586) .

- Dans le menu Pomme , choisissez Réglages Système (ou Préférences Système), puis cliquez sur Comptes Internet.

- Cliquez sur votre compte de messagerie.

- Cliquez sur le bouton Détails, le cas échéant.

- Si un champ de mot de passe s’affiche pour votre compte, supprimez le mot de passe et saisissez le mot de passe approprié.

- Fermez la fenêtre des réglages, puis ouvrez Mail et réessayez d’utiliser votre compte.

Si Mail vous invite toujours à saisir votre mot de passe, il est probable que celui que vous avez fourni soit incorrect. Votre fournisseur de messagerie peut vous aider à vérifier les réglages de votre compte de messagerie et à vous assurer que vous utilisez le bon mot de passe.

## Effectuer un test via la messagerie web

De nombreux fournisseurs de messagerie proposent un service de messagerie web. Ce type de service vous permet d’utiliser votre messagerie à l’aide d’un navigateur web comme Safari, au lieu d’une app de messagerie telle que Mail. Par exemple, si vous possédez un compte Mail iCloud, vous pouvez envoyer et recevoir des e-mails depuis le site [iCloud.com](https://www.icloud.com/) .

Le mot de passe que vous utilisez avec Mail étant habituellement le même que celui que vous utilisez avec la messagerie web, essayez de vous connecter à la messagerie web à l’aide de ce mot de passe. Si le problème persiste, il est probable que votre mot de passe soit incorrect. Votre fournisseur de messagerie peut vous aider à vérifier les réglages de votre compte et à vous assurer que vous utilisez le mot de passe approprié pour l’app Mail.

## Supprimer votre compte, puis l’ajouter à nouveau

Si aucune autre solution ne fonctionne, [supprimez, puis ajoutez à nouveau votre compte de messagerie dans Mail](https://support.apple.com/guide/mail/mail35803/mac) . Lorsque vous ajoutez le compte, veillez à [choisir le bon fournisseur de services de messagerie](https://support.apple.com/fr-fr/102088) en fonction de votre adresse e-mail. Ensuite, réessayez d’envoyer et de recevoir des e-mails.
