# Si vous oubliez votre nouveau code d’accès, utilisez votre ancien code pour déverrouiller votre iPhone ou votre iPad dans un délai de 72 heures.

La fonctionnalité Réinitialisation du code vous permet d’utiliser temporairement votre ancien code d’accès pour retrouver l’accès à votre iPhone ou à votre iPad, sans avoir besoin d’utiliser un ordinateur ni de réinitialiser votre appareil.

## À propos de la fonctionnalité Réinitialisation du code

Lorsque vous modifiez votre code d’accès dans iOS 17, iPadOS 17 et versions ultérieures, la fonctionnalité Réinitialisation du code vous permet d’utiliser l’ancien code pendant 72 heures pour accéder à votre iPhone ou à votre iPad. Si vous déverrouillez votre appareil de cette façon, vous devrez modifier à nouveau votre code d’accès immédiatement.

Si vous oubliez votre code d’accès, commencez par essayer la fonctionnalité Réinitialisation du code. Si vous ne pouvez pas utiliser la fonctionnalité Réinitialisation du code, vous pouvez [réinitialiser votre iPhone ou votre iPad sans ordinateur](https://support.apple.com/105090) afin de récupérer l’accès à votre appareil Apple. Enfin, si vous ne pouvez pas utiliser la fonctionnalité Réinitialisation du code, et que vous ne pouvez pas réinitialiser votre iPhone ou votre iPad directement sur l’appareil, vous pouvez [réinitialiser votre iPhone ou votre iPad à l’aide d’un ordinateur](https://support.apple.com/118430) .

## Utiliser Réinitialisation du code

- Sur votre écran de verrouillage, après cinq tentatives infructueuses de saisie du code d’accès, l’écran « [Appareil] non disponible » s’affiche. Lorsque l’invite s’affiche, touchez Code oublié ? dans l’angle inférieur de l’écran.

[Image: L’écran « iPhone indisponible », avec l’option « Code oublié ? » permettant de lancer la procédure de réinitialisation.]

- Touchez Saisissez l’ancien code.

[Image: Écran d’iPhone affichant l’option « Code oublié ? », avec un bouton « Essayer la réinitialisation du code » permettant d’utiliser temporairement l’ancien code après qu’il a été modifié sous iOS 17 ou version ultérieure.]

- Saisissez votre ancien code d’accès, puis suivez les instructions à l’écran pour définir un nouveau code.

Si vous utilisez iOS 17 ou iPadOS 17, ou une version ultérieure, l’option Code oublié ? apparaît lorsque vous ne pouvez pas accéder à votre appareil, que vous êtes connecté à un réseau mobile ou Wi-Fi, ainsi qu’à votre compte Apple, et que la fonctionnalité Localiser est activée.

Si vous utilisez iOS 15.2, iPadOS 15.2, iOS 16 ou iPadOS 16, l’option Effacer [appareil] apparaît lorsque vous ne pouvez pas accéder à votre appareil, que vous êtes connecté à un réseau mobile ou Wi-Fi, ainsi qu’à votre compte Apple, et que la fonctionnalité Localiser est activée.
