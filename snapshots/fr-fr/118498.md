# Réinitialisation des réglages usine de votre Apple Vision Pro

Suivez ces étapes pour effacer les informations de votre Apple Vision Pro en toute sécurité et restaurer votre appareil à ses réglages d’usine.

- [Sauvegardez votre Apple Vision Pro](https://support.apple.com/guide/apple-vision-pro/tan1f03417ed/) de façon à pouvoir restaurer vos données ultérieurement.

- Après avoir sauvegardé vos données, ouvrez Réglages, touchez Général, puis touchez Transférer ou réinitialiser l’Apple Vision Pro.

- Touchez Effacer contenu et réglages.

- Si vous y êtes invité, saisissez le code d’accès de votre appareil ou le mot de passe de votre compte Apple. Vous avez oublié le [mot de passe de votre compte Apple](https://support.apple.com/102656) ?

- Confirmez que vous souhaitez effacer les données de votre appareil.

- Attendre que les données de votre appareil soient effacées. L’effacement complet de vos données peut prendre quelques minutes.
