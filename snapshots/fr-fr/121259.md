# Utiliser l’écriture manuscrite dans Notes sur votre iPad

Affinez votre écriture, corrigez son orthographe et collez du texte avec le style de votre propre écriture manuscrite dans Notes sur iOS 18.

Sous iPadOS 18, Notes utilise un modèle sur l’appareil permettant de recréer une écriture manuscrite dans un style similaire au vôtre. Vous pouvez également ajuster votre écriture manuscrite tout en préservant votre propre style et personnalité.

## Améliorer automatiquement votre écriture manuscrite

- Dans une note, touchez le bouton Annoter.

- Touchez le bouton Plus.

- Activez l’amélioration automatique de l’écriture manuscrite.

[Image: Pour activer l’option Améliorer automatiquement l’écriture manuscrite dans Notes, touchez le bouton Annoter, puis touchez le bouton Plus pour afficher cette option.]

### Améliorer manuellement votre écriture manuscrite

- Dans une note, sélectionnez le texte que vous souhaitez améliorer.

- Faites glisser le curseur pour ajuster votre sélection si besoin.

- Touchez Affinage.

[Image: Sous iPadOS 18, mettez du texte en surbrillance et choisissez Affinage dans Notes pour ajuster et redresser votre écriture.]

[Redresser votre écriture dans Notes sur votre iPhone](https://support.apple.com/guide/iphone/add-drawings-and-handwriting-iphd939f0a1c/ios)

## Corriger l’orthographe de votre texte manuscrit

- Dans une note, touchez le bouton Annoter et sélectionnez un outil.

- Utilisez votre doigt ou votre Apple Pencil pour commencer à écrire.

- Si vous avez mal orthographié un mot, touchez la ligne bleue en pointillé qui apparaît.

[Image: Sous iOS 18, Notes vérifie automatiquement l’orthographe lors de la saisie manuscrite. Les erreurs sont signalées par des points bleus.]

- Touchez l’orthographe suggérée pour ajuster automatiquement votre texte manuscrit.

[Corriger l’orthographe de votre texte manuscrit dans Notes sur votre iPhone](https://support.apple.com/guide/iphone/add-drawings-and-handwriting-iphd939f0a1c/ios)

## Copiez le texte, puis collez-le dans sous forme d’écriture manuscrite sur votre iPad

- Sélectionnez et copiez le texte d’un site web, d’un message, d’un e-mail ou autre sur votre iPad.

- Lancez l’app Notes et ouvrez une note contenant du texte manuscrit.

- Touchez un espace vide dans une zone d’écriture manuscrite de votre note pour afficher le menu des options.

- Touchez Coller.

Si vous n’avez jamais essayé la saisie manuscrite dans Notes auparavant, l’option d’écriture manuscrite n’apparaitra pas. Vous devrez peut-être rédiger quelques paragraphes avec votre propre écriture pour activer la fonctionnalité. La fonctionnalité Coller sous forme d’écriture manuscrite offre de meilleurs résultats lorsque le texte copié est inséré dans une note manuscrite existante.

[En savoir plus sur l’écriture manuscrite dans Notes sur votre iPad](https://support.apple.com/guide/ipad/add-drawings-and-handwriting-ipada87a6078/ipados)

## Rayez et maintenez appuyé votre Apple Pencil pour effacer du texte manuscrit sur votre iPad

- Dans Notes, ouvrez une note contenant une écriture manuscrite.

- Touchez le bouton Annoter.

- Sélectionnez un outil de dessin, comme l’outil pastel, le marqueur ou le stylo.

- Rayez et maintenez appuyé votre Apple Pencil pour effacer l’écriture manuscrite.
