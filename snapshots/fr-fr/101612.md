# Si Touch ID ne fonctionne pas sur votre iPhone ou iPad

Découvrez la marche à suivre si vous ne parvenez pas à déverrouiller votre appareil iOS à l’aide de Touch ID, à enregistrer une empreinte ou s’il vous est demandé de saisir votre code d’accès.

## Où se trouve le capteur Touch ID ?

Le capteur Touch ID se trouve sur le bouton principal ou sur le bouton supérieur dans le cas de l’iPad mini (6e génération) et de l’iPad Air (4e et 5e générations). Lorsque vous suivez les étapes ci-dessous, les instructions qui s’affichent à l’écran vous indiquent quel bouton employer. Si vous ne savez pas où se trouvent ces boutons sur votre iPad, [consultez cet article pour connaître leur emplacement](https://support.apple.com/102354) .

Étapes à suivre. Essayez d’utiliser Touch ID après chaque étape :

- Assurez-vous que votre appareil est doté de la [dernière version d’iOS ou d’iPadOS](http://support.apple.com/118575) .

- Veillez à ce que vos doigts et le capteur Touch ID soient propres et secs*. Nettoyez le capteur Touch ID à l’aide d’un chiffon propre et non pelucheux pour retirer la poussière ou les débris éventuels.

- Votre doigt doit recouvrir entièrement le capteur Touch ID, anneau métallique compris. Lors de l’enregistrement de l’empreinte, ne touchez pas le bouton trop rapidement et ne bougez pas votre doigt.

- Si vous utilisez un étui, une coque ou un protège-écran, assurez-vous que cet accessoire ne couvre pas le capteur Touch ID ni l’anneau périphérique.

- Accédez à Réglages, puis touchez Touch ID et code. Vérifiez ensuite que l’option Déverrouiller l’iPhone ou iTunes Store et App Store est activée et que vous avez enregistré une ou plusieurs empreintes.

- Essayez d’enregistrer une autre empreinte.

## Le problème persiste ?

Si les étapes précédentes n’ont rien donné, que le message « Échec – Impossible de terminer la configuration de Touch ID » s’affiche, que vous ne pouvez toujours pas activer Touch ID ou que Touch ID est grisé, une réparation peut être nécessaire.

[Obtenir une assistance](https://getsupport.apple.com/?caller=ikb)

## Si vous devez saisir votre code d’accès

Vous devrez peut-être saisir votre code d’accès ou votre compte Apple au lieu d’utiliser Touch ID dans les situations suivantes :

- Vous venez de redémarrer votre appareil.

- La reconnaissance de votre empreinte a échoué cinq fois de suite

- Plus de 48 heures se sont écoulées depuis le dernier déverrouillage de votre appareil.

- Vous n’avez pas déverrouillé votre iPhone avec le code d’accès au cours des 6,5 derniers jours, et vous ne l’avez pas déverrouillé avec Face ID ni Touch ID au cours des 4 dernières heures.

- Votre iPhone reçoit une commande de verrouillage à distance.

- Vous enregistrez ou supprimez des empreintes digitales.

- Vous essayez d’ouvrir la section Touch ID et code du menu Réglages.

- Vous utilisez [Appel d’urgence](https://support.apple.com/guide/iphone/contact-emergency-services-iph3c99374c/ios)

- Vous [consultez votre fiche médicale.](https://support.apple.com/guide/iphone/set-up-and-view-your-medical-id-iph08022b192/ios)

* L’humidité, les lotions, la sueur, les huiles, les coupures ou une peau sèche peuvent nuire à la reconnaissance de l’empreinte digitale. Certaines activités peuvent également avoir une incidence sur la reconnaissance des empreintes, si vous tentez d’enregistrer vos empreintes après avoir effectué celles-ci. Elles incluent l’exercice physique, le fait de prendre une douche, la nage, la cuisine et toute autre action pouvant temporairement affecter vos empreintes digitales.
