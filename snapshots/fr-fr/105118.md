# Utiliser le mode Jeu

Sur votre iPhone, iPad ou Mac, vous pouvez utiliser le mode Jeu pour donner automatiquement la priorité aux performances de votre jeu, afin d’obtenir une fréquence d’images plus fluide et plus cohérente, ainsi qu’une meilleure réactivité du jeu.

## Que fait le mode Jeu ?

- Le mode Jeu optimise votre expérience de jeu en permettant à votre jeu d’accéder en priorité à votre CPU et à votre GPU, réduisant ainsi l’utilisation de ces derniers pour les tâches en arrière-plan. Cela permet d’obtenir une fréquence d’images plus fluide et plus cohérente, et d’améliorer la réactivité du jeu.

- Le mode Jeu double également la fréquence d’échantillonnage du Bluetooth, ce qui réduit la latence d’entrée et la latence audio pour les accessoires sans fil comme les manettes de jeu et les AirPods.

## Configuration requise pour utiliser le mode Jeu

- iPhone doté d’iOS 18 ou version ultérieure et d’un jeu compatible

- iPad doté d’iPadOS 18 ou version ultérieure et d’un jeu compatible

- [Mac avec puce Apple](https://support.apple.com/fr-fr/116943) et [macOS Sonoma 14 ou version ultérieure](https://support.apple.com/fr-fr/109033) et un jeu qui prend en charge le [mode plein écran de macOS](https://support.apple.com/guide/mac-help/mchl9c21d2be/mac) . Si votre jeu prend en charge ce type de mode plein écran, il affiche le bouton Plein écran de macOS dans le coin de la fenêtre du jeu, et un clic sur ce bouton active le mode plein écran.

## Activer ou désactiver le mode Jeu

Lorsque votre jeu passe en mode plein écran, cela active automatiquement le mode Jeu. Lorsque vous quittez le jeu, le mode Jeu est automatiquement désactivé. Vous pouvez également activer ou désactiver manuellement le mode Jeu lorsque votre jeu est en mode plein écran.

### Sur un iPhone ou un iPad

- Pendant que votre jeu est ouvert et en mode plein écran, ouvrez la superposition de jeu :

- Effectuez un balayage vers le bas à partir de l’angle supérieur droit de l’écran pour ouvrir le centre de contrôle.

- Dans le centre de contrôle, en haut de l’écran, le nom de votre jeu suivi de « Incrustation dans les jeux » doit s’afficher. Touchez Incrustation dans les jeux.

- Touchez le bouton Commandes dans la superposition de jeu.

- Touchez Mode Jeu. Si vous désactivez le mode Jeu de cette manière, il restera désactivé pour ce jeu jusqu’à ce que vous le réactiviez, même si vous quittez et rouvrez le jeu.

[Image: Affichage de la fonctionnalité Incrustation dans les jeux sur iPhone. Le bouton Commandes se trouve en haut de l’écran.]

### Sur un Mac

Suivez les étapes appropriées, en fonction de la version de macOS que vous utilisez.

#### macOS Tahoe 26 ou version ultérieure

- Pendant que votre jeu est en mode plein écran, ouvrez la superposition de jeu :

- Cliquez sur l’icône Jeu dans la barre des menus. (Pour afficher la barre des menus lorsque l’affichage est en mode plein écran, déplacez votre pointeur vers le haut de l’écran.) Si vous utilisez également un mode de [concentration Jeux](https://support.apple.com/guide/mac-help/mchl613dc43f/mac) , la barre des menus peut afficher une icône Jeu pour le mode de concentration et une autre pour Game Overlay.

- Ou appuyez sur Commande-Esc ⎋.

- Game Overlay s’affiche dans le coin de votre écran. Cliquez sur le bouton Réglages dans Game Overlay.

- Cliquez sur Mode Jeu. Si vous désactivez le mode Jeu de cette manière, il restera désactivé pour ce jeu jusqu’à ce que vous le réactiviez, même si vous quittez et rouvrez le jeu.

[Image: Affichage du volet Réglages de la fonctionnalité Incrustation dans les jeux sur Mac.]

#### macOS Sequoia 15 ou macOS Sonoma 14

- Pendant que votre jeu est en plein écran, cliquez sur le menu Jeu dans la barre des menus. (Pour afficher la barre des menus lorsque l’affichage est en mode plein écran, déplacez votre pointeur vers le haut de l’écran.)

- Choisissez Désactiver le mode Jeu ou Activer le mode Jeu. Si vous désactivez le mode Jeu de cette façon, il reste désactivé pour ce jeu jusqu’à ce que vous le réactiviez, même si vous quittez et rouvrez le jeu.

## Informations supplémentaires

- Une pression sur le bouton principal d’une manette de jeu sans fil compatible peut ouvrir Game Overlay, Jeux ou Spotlight, en fonction du jeu et des réglages de votre manette. En savoir plus sur [la personnalisation des boutons et des fonctionnalités de la manette](https://support.apple.com/fr-fr/111099) .

- Pour filtrer les notifications et les distractions pendant que vous jouez, vous pouvez configurer un mode de concentration Jeu vidéo sur votre [iPhone](https://support.apple.com/guide/iphone/iphd6288a67f/26/ios) , [iPad](https://support.apple.com/guide/ipad/ipad2789d162/ipados) , ou [Mac](https://support.apple.com/guide/mac-help/mchl613dc43f/mac) . Par défaut, le mode de concentration Jeu vidéo s’active chaque fois que vous connectez une manette de jeu sans fil à votre appareil.
