# Utiliser le mode Jeu

Sur votre iPhone, iPad ou Mac, vous pouvez utiliser le mode Jeu pour donner automatiquement la priorité aux performances de votre jeu, afin d’obtenir une fréquence d’images plus fluide et plus cohérente, ainsi qu’une meilleure réactivité du jeu.

## Que fait le mode Jeu ?

- Le mode Jeu optimise votre expérience de jeu en permettant à votre jeu d’accéder en priorité à votre CPU et à votre GPU, réduisant ainsi l’utilisation de ces derniers pour les tâches en arrière-plan. Cela permet d’obtenir une fréquence d’images plus fluide et plus cohérente, et d’améliorer la réactivité du jeu.

- Le mode Jeu double également la fréquence d’échantillonnage du Bluetooth, ce qui réduit la latence d’entrée et la latence audio pour les accessoires sans fil comme les manettes de jeu et les AirPods.

## Configuration requise pour utiliser le mode Jeu

- iPhone doté d’iOS 18 ou version ultérieure et d’un jeu compatible.

- iPad doté d’iPadOS 18 ou version ultérieure et d’un jeu compatible.

- [Mac avec puce Apple](https://support.apple.com/fr-fr/116943) et doté de [macOS Sonoma 14 ou version ultérieure](https://support.apple.com/fr-fr/109033) , ainsi que d’un jeu compatible avec le [mode plein écran intégré à macOS](https://support.apple.com/guide/mac-help/mchl9c21d2be/mac) . Si votre jeu prend en charge ce mode plein écran, il affiche le bouton plein écran de macOS dans l’angle de la fenêtre du jeu.

## Activer ou désactiver le mode Jeu sur iPhone ou iPad

Lorsque votre jeu passe en mode plein écran, cela active automatiquement le mode Jeu. Lorsque vous quittez le jeu, le mode Jeu est automatiquement désactivé. Vous pouvez également suivre les étapes ci-dessous pour désactiver ou activer le mode Jeu pendant que votre jeu est encore en plein écran.

- Pendant que votre jeu est en mode plein écran, effectuez un balayage vers le bas à partir de l’angle supérieur droit de votre écran pour ouvrir le centre de contrôle.

- Dans le centre de contrôle, en haut de l’écran, le nom de votre jeu suivi de « Incrustation dans les jeux » doit s’afficher. Touchez Incrustation dans les jeux.

- Touchez le bouton Commandes , puis touchez Mode Jeu. Si vous désactivez le mode Jeu de cette façon, il reste désactivé pour ce jeu jusqu’à ce que vous le réactiviez, même si vous quittez et rouvrez le jeu.

## Activer ou désactiver le mode Jeu sur Mac

Lorsque votre jeu passe en mode plein écran, cela active automatiquement le mode Jeu. Le fait de quitter le mode plein écran ou de quitter le jeu désactive automatiquement le mode Jeu. Vous pouvez également suivre les étapes ci-dessous pour désactiver ou activer le mode Jeu pendant que votre jeu est encore en plein écran.

### macOS Tahoe 26 ou version ultérieure

- Pendant que votre jeu est en plein écran, appuyez sur les touches Commande + Échap ⎋ pour ouvrir Incrustation dans les jeux dans l’angle de l’écran. Vous pouvez également cliquer sur l’icône Jeu dans la barre des menus. (Pour afficher la barre des menus lorsque l’affichage est en mode plein écran, déplacez votre pointeur vers le haut de l’écran.)

[Image: null]

- Dans Incrustation dans les jeux, cliquez sur le bouton Réglages , puis cliquez sur Mode Jeu. Si vous désactivez le mode Jeu de cette façon, il reste désactivé pour ce jeu jusqu’à ce que vous le réactiviez, même si vous quittez et rouvrez le jeu.

[Image: null]

[Image: Affichage du volet Réglages de la fonctionnalité Incrustation dans les jeux sur Mac.]

### macOS Sequoia 15 ou macOS Sonoma 14

- Pendant que votre jeu est en plein écran, cliquez sur le menu Jeu dans la barre des menus. (Pour afficher la barre des menus lorsque l’affichage est en mode plein écran, déplacez votre pointeur vers le haut de l’écran.)

[Image: null]

- Choisissez Désactiver le mode Jeu ou Activer le mode Jeu. Si vous désactivez le mode Jeu de cette façon, il reste désactivé pour ce jeu jusqu’à ce que vous le réactiviez, même si vous quittez et rouvrez le jeu.

## Informations supplémentaires

- Vous pouvez également utiliser une manette de jeu sans fil compatible pour accéder à la fonctionnalité Incrustation dans les jeux, en fonction des réglages de votre manette. Découvrez comment [connecter une manette de jeu sans fil à votre appareil](https://support.apple.com/fr-fr/111099) .

- Pour filtrer les notifications et les distractions pendant que vous jouez, vous pouvez configurer un mode de concentration Jeu vidéo sur votre [iPhone](https://support.apple.com/guide/iphone/iphd6288a67f/26/ios) , [iPad](https://support.apple.com/guide/ipad/ipad2789d162/ipados) , ou [Mac](https://support.apple.com/guide/mac-help/mchl613dc43f/mac) . Par défaut, le mode de concentration Jeu vidéo s’active chaque fois que vous connectez une manette de jeu sans fil à votre appareil.
