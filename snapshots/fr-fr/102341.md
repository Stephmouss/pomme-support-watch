# Activer le glissement à trois doigts pour le trackpad de votre Mac

Faire glisser des éléments à l’aide d’un geste à trois doigts est une option disponible pour les trackpads compatibles avec Force Touch.

Les noms des réglages varient en fonction de la version de macOS que vous utilisez :

- Dans le menu Pomme , choisissez Réglages Système (ou Préférences Système).

- Cliquez sur Accessibilité.

- Cliquez sur Contrôle du pointeur (ou Souris et trackpad).

- Cliquez sur le bouton Options du trackpad.

- Activez la fonctionnalité « Utiliser le trackpad pour le glissement » (ou « Activer le glissement »).

- Dans le menu local, choisissez le style de glissement Faire glisser avec 3 doigts.

- Cliquez sur OK.

[En savoir plus sur ces options de trackpad](https://support.apple.com/guide/mac-help/unac899/mac)
