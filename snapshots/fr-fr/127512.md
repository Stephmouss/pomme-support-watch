# Utiliser Demander l’autorisation de naviguer pour approuver les sites web auxquels votre enfant peut accéder

Temps d’écran propose des contrôles parentaux, par exemple Demander l’autorisation de naviguer, de sorte que lorsque votre enfant souhaite visiter un nouveau site web dans Safari et dans d’autres navigateurs pris en charge sur son iPhone, iPad ou Mac, il doit demander votre autorisation. Chaque site web approuvé est ajouté à la liste d’autorisations, que vous pouvez modifier à tout moment.

## Procédure préliminaire

- [Assurez-vous que le partage familial est configuré](https://setup.icloud.com/family/messages?aaaction=showFamilyInvite&inviteCode=organizer_create&campaign=kbArticle) .

- [Créez un compte enfant pour votre enfant](https://support.apple.com/102617) , s’il n’en a pas déjà un. Assurez-vous ensuite que le compte de votre enfant fait partie de votre groupe de partage familial. Il est important que votre enfant ait son propre compte Apple et ne partage pas de compte Apple avec quelqu’un d’autre, par exemple un autre membre de la famille.

- Mettez à jour tous les appareils de votre groupe de partage familial vers iOS 27, iPadOS 27, macOS 27, watchOS 27 ou visionOS 27. Puis [mettez à jour vos contrôles parentaux](https://support.apple.com/guide/child-safety/jrzvk3ml3unm) , requis pour utiliser la fonctionnalité Demander l’autorisation de naviguer.

- Assurez-vous que l’organisateur du partage familial ou un parent/tuteur est ajouté à la liste de contacts de l’enfant afin que les demandes de l’enfant puissent être envoyées pour approbation.

## Activer l’option Demander l’autorisation de naviguer

Avec Demander l’autorisation de naviguer, vous décidez des sites web que votre enfant peut visiter dans Safari et dans les navigateurs pris en charge 1 . Lorsqu’il souhaite visiter un nouveau site web, il doit demander votre autorisation. Vous pouvez également autoriser des sites web à l’avance afin que votre enfant ait toujours ce dont il a besoin (par exemple, un site web pour l’école). Si vous approuvez une demande Demander l’autorisation de naviguer, votre enfant pourra accéder au site web, sauf si vous décidez de le bloquer plus tard. Si vous refusez la demande, le site web ne sera pas disponible sur l’appareil de votre enfant.

L’accès aux sites web pour adultes est limité. La fonctionnalité Demander l’autorisation de naviguer est activée par défaut pour les enfants de moins de 13 ans et la fonctionnalité Limiter les sites web pour adultes est activée par défaut pour les enfants de moins de 18 ans. 2

### Sur votre iPhone ou iPad

- Ouvrez l’app Réglages, touchez Famille, puis touchez le nom de votre enfant.

- Touchez Apps et sites web, puis Restrictions.

- Faites défiler l’écran jusqu’à la section Sites web, puis touchez Filtrage.

- Choisissez Sites web autorisés uniquement ou Limiter les sites web pour adultes. Saisissez votre code de Temps d’écran si un message vous y invite.

[Image: Écran d’iPhone affichant les options de filtrage de sites web : Sites web autorisés uniquement, Limiter les sites web pour adultes et Accès illimité.]

### Sur votre Mac

- Choisissez le menu Apple , cliquez sur Réglages Système, puis cliquez sur Famille.

- Cliquez sur le nom de votre enfant, puis sur Apps et sites web.

- Cliquez sur Restrictions.

- Faites défiler l’écran jusqu’à la section Sites web, puis cliquez sur Filtrage.

- Choisissez Sites web autorisés uniquement. Saisissez votre code de Temps d’écran si un message vous y invite.

[Image: Écran affichant les options de filtrage de sites web dans les réglages du partage familial.]

## Approuver ou refuser une demande Demander l’autorisation de naviguer

L’organisateur du partage familial ou un parent/tuteur peut approuver ou refuser une demande sur son iPhone, iPad ou Mac. Il peut également approuver ou refuser la demande sur l’appareil de l’enfant à l’aide du code Temps d’écran.

### Approuver ou refuser sur votre appareil

- Ouvrez le message pour voir le site web auquel votre enfant souhaite accéder.

- Approuvez ou refusez la demande.

### Approuver ou refuser sur l’appareil de votre enfant

- Sur le site web auquel votre enfant souhaite accéder, touchez Demander l’autorisation.

- Touchez Saisir le code Temps d’écran, puis suivez les instructions à l’écran.

Une fois le site web approuvé, votre enfant y aura accès. Si vous refusez une demande, votre enfant reçoit une notification pour l’en informer. Si vous ne répondez pas dans les 24 heures, l’enfant devra à nouveau effectuer la demande.

## Bloquer un site web spécifique

Si vous avez déjà approuvé un site web pour votre enfant, celui-ci apparaîtra dans la liste Autorisées de la section Apps et sites web. Vous pouvez à tout moment bloquer un site web spécifique dans Safari et dans les navigateurs pris en charge sur l’appareil de votre enfant.

### Sur votre iPhone ou iPad

- Ouvrez l’app Réglages, puis touchez Famille.

- Touchez le nom de votre enfant, puis Apps et sites web.

- Touchez le site web dans la liste, puis Bloquer le site web.

[Image: Écran d’iPhone affichant les réglages Demander l’autorisation de naviguer avec une liste de sites web approuvés.]

- Touchez à nouveau Bloquer le site web pour confirmer. Saisissez votre code de Temps d’écran si un message vous y invite.

### Sur votre Mac

- Choisissez le menu Apple , cliquez sur Réglages Système, puis cliquez sur Famille.

- Cliquez sur le nom de votre enfant, puis sur Apps et sites web.

- Cliquez sur le site web dans la liste, puis sur Bloquer.

[Image: Écran de Mac affichant l’accès aux sites web d’un enfant avec des options pour approuver ou refuser.]

- Cliquez sur Bloquer le site web pour confirmer, puis sur OK.

1 La fonctionnalité Demander l’autorisation de naviguer est disponible dans Safari et d’autres apps de navigation prises en charge sous iOS 27, iPadOS 27 et macOS 27 après la mise à niveau de Temps d’écran. Lorsqu’elle est activée, watchOS et visionOS affichent uniquement les sites web approuvés.

2 L’âge limite varie selon l’État, le pays ou la région. [Obtenez plus d’informations sur les réglages et fonctionnalités relatifs aux enfants en fonction des pays ou régions.](https://support.apple.com/125666)
