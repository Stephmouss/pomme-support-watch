# Supprimer un mode de paiement associé à votre compte Apple

Découvrez comment supprimer un mode de paiement. Si vous ne parvenez pas à le supprimer, vous devrez peut-être résilier des abonnements, désactiver le partage des achats ou régulariser un solde débiteur.

## Supprimer un mode de paiement

Si vous avez souscrit des abonnements comme iCloud+, si votre solde est débiteur ou si vous faites partie d’un groupe de partage familial et que vous utilisez le partage des achats, au moins un mode de paiement doit rester associé à votre compte. Découvrez [ce qu’il faut faire si vous ne parvenez pas à supprimer un mode de paiement](https://support.apple.com/fr-fr/118291#troubleshooting) .

## Supprimer un mode de paiement sur votre iPhone, iPad ou Apple Vision Pro

- Ouvrez l’app Réglages.

- Touchez votre nom.

- Touchez Paiement et livraison.

- Touchez Modifier.

- Appuyez sur le bouton Supprimer à côté du mode de paiement.

[Image: null]

- Touchez Supprimer pour confirmer.

[Image: iPhone affichant les réglages Paiement et livraison. Pour supprimer un mode de paiement, touchez-le, puis touchez Supprimer.]

## Supprimer un mode de paiement sur votre Mac

- Ouvrez l’App Store.

- Cliquez sur votre nom ou sur le bouton Se connecter.

- Cliquez sur Réglages du compte.

- Cliquez sur Modes de paiement.

- Cliquez sur Modifier.

- Cliquez sur le bouton Supprime à côté du mode de paiement.

[Image: null]

- Cliquez sur Supprimer pour confirmer cette action.

[Image: Écran macOS affichant les réglages Edit Payment Information (Modifier les informations de paiement). Pour supprimer un mode de paiement, cliquez dessus, puis sur Remove Payment Method (Supprimer le mode de paiement).]

## Supprimer un mode de paiement sur votre PC Windows

- Sur votre PC Windows, ouvrez l’app Apple Music ou l’app Apple TV. Découvrez [comment obtenir les apps d’Apple pour Windows](https://support.apple.com/fr-fr/118290) .

- Cliquez sur votre nom en bas de la barre latérale, puis choisissez Voir mon compte. Vous devrez peut-être vous connecter à votre compte Apple.

[Image: Écran Windows montrant l’app Apple Music. Pour voir votre compte, cliquez sur votre nom en bas de la barre latérale, puis cliquez sur Voir mon compte.]

- Cliquez sur Gérer les paiements en regard de l’intitulé Informations de paiement.

- Cliquez sur Modifier.

- Cliquez sur Supprimer le mode de paiement.

[Image: Écran Windows affichant les réglages Modifier les informations de paiement (Modifier les informations de paiement) dans l’app Apple Music. Pour supprimer votre mode de paiement, cliquez sur Remove Payment Method (Supprimer le mode de paiement) en bas de l’écran.]

### Supprimer votre mode de paiement sur une ancienne version d’iTunes pour Windows

- Si votre PC Windows n’est pas compatible avec l’app Apple Music ou l’app Apple TV, ouvrez iTunes.

- Dans la barre des menus située en haut de la fenêtre iTunes, choisissez Compte, puis Voir mon compte.

- Choisissez Gérer les paiements.

- Choisissez Modifier.

- Cliquez sur Supprimer le mode de paiement.

## Supprimer un mode de paiement en ligne

Vous pouvez également supprimer un mode de paiement après vous être connecté sur [account.apple.com](https://account.apple.com/account/manage/section/payment) . Dans certains cas, vous devrez peut-être ajouter un nouveau mode de paiement afin de supprimer le mode de paiement existant.

## Si vous ne parvenez pas à supprimer un mode de paiement

### Si vous avez un abonnement

Si vous avez des abonnements comme iCloud+, au moins un mode de paiement doit rester associé à votre compte. Vous pouvez [résilier votre abonnement auprès d’Apple](https://support.apple.com/fr-fr/118428) Une fois la période d’abonnement terminée, supprimez votre mode de paiement.

### Si vous faites partie d’un groupe de partage familial et que vous utilisez le partage des achats

Le responsable familial doit disposer d’un mode de paiement enregistré. Si vous êtes le responsable familial, [désactivez le partage des achats](https://support.apple.com/fr-fr/108774) , puis supprimez le mode de paiement.

### Si vous avez un solde impayé

Vous ne pourrez peut-être pas supprimer un mode de paiement. À la place, [modifiez votre mode de paiement](https://support.apple.com/fr-fr/118293) .

#### Si vous ne parvenez toujours pas à supprimer un mode de paiement

Si vous ne parvenez toujours pas à supprimer un mode de paiement, [contactez l’assistance Apple](https://getsupport.apple.com/?caller=kbase) .
