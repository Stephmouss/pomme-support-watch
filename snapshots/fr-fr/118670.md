# Passer d’un appareil Android à un iPhone ou un iPad

Prêt à passer à iOS ? Téléchargez l’application Migrer vers iOS pour passer en toute simplicité d’un appareil Android à un iPhone ou iPad.

Si vous possédez un appareil Android compatible exécutant une version compatible d’Android 17, vous pouvez [passer à iOS ou iPadOS sans l’application Migrer vers iOS](https://support.apple.com/fr-fr/118670#noapp) . Sinon, [téléchargez l’application Migrer vers iOS depuis Google Play](https://play.google.com/store/apps/details?id=com.apple.movetoios) pour effectuer la migration

Si vous ne pouvez pas utiliser le Google Play Store, découvrez [comment télécharger l’application Migrer vers iOS](https://support.apple.com/101590) .

## Avant de commencer

- Assurez-vous que le Wi-Fi est activé sur votre appareil Android, puis branchez ce dernier, ainsi que votre nouvel appareil iOS, sur une source d’alimentation.

- Vous pouvez également utiliser un câble USB-C pour connecter directement votre appareil Android et votre iPhone et ainsi accélérer le transfert.

- Assurez-vous que le contenu que vous souhaitez déplacer, y compris celui se trouvant sur votre carte Micro SD externe, peut être stocké sur votre nouvel appareil iOS.

- Pour transférer vos favoris Chrome, installez la dernière version de ce navigateur sur votre appareil Android.

## Démarrez sur votre appareil Apple

Allumez votre nouvel appareil Apple et placez-le près de votre appareil Android.

Sur votre appareil Apple, suivez les instructions de configuration à l’écran.

Sur l’écran Démarrage rapide, touchez Configurer sans autre appareil [Apple], puis continuez à suivre les instructions à l’écran. Il vous sera peut-être demandé [d’activer votre eSIM](https://support.apple.com/118669) .

[Image: Si vous placez votre ancien téléphone à côté de votre nouvel iPhone, l’application « Migrer vers iOS » vous permettra de transférer les données sans fil.]

## Touchez Migrer des données depuis Android

Accédez à l’écran Transférez vos apps et vos données. Touchez ensuite Depuis Android, puis Transférer avec l’app. (Si vous avez déjà terminé la configuration, vous devez [effacer le contenu de votre appareil iOS](https://support.apple.com/108931) et recommencer. Si vous ne souhaitez pas effacer le contenu de votre appareil, vous pouvez également [le transférer manuellement](https://support.apple.com/104965) .)

[Image: Pendant le processus de transfert, vous pouvez choisir les apps et les informations que vous souhaitez migrer.]

## Ouvrez et configurez l’application Migrer vers iOS

Ouvrez l’application Migrer vers iOS sur votre appareil Android. Si vous n’avez pas l’application Migrer vers iOS, vous pouvez toucher le bouton Code QR sur votre nouvel appareil iOS et scanner le code QR à l’aide de la caméra de votre appareil Android pour ouvrir le Google Play Store.

Pour commencer à utiliser l’application Migrer vers iOS :

- Touchez Continuer.

- Lisez les conditions générales qui s’affichent, puis touchez Accepter pour continuer.

- Touchez Envoyer automatiquement ou Ne pas envoyer pour choisir comment partager les données de l’application avec Apple.

- Touchez Continuer et activez les autorisations de localisation si nécessaire.

- Touchez Continuer et activez les autorisations de notification si nécessaire.

Si vous connectez votre appareil Android et votre iPhone à l’aide d’un câble, une fenêtre contextuelle peut s’afficher, vous invitant à ajuster les réglages USB sur votre appareil Android avant de pouvoir démarrer l’application Migrer vers iOS.

## Attendez l’affichage d’un code

Sur votre appareil iOS, touchez Continuer lorsque l’écran « Migrer d’Android » s’affiche. Patientez jusqu’à ce qu’un code à dix ou six chiffres apparaisse. Si votre appareil Android indique que votre connexion Internet est faible, vous pouvez ignorer ce message.

[Image: Un code à usage unique confirme que les deux appareils sont connectés.]

[Si vous ne recevez pas de code à six chiffres, découvrez la marche à suivre pour réinitialiser votre appareil et générer ce code.](https://support.apple.com/120035)

## Saisissez le code

Saisissez le code sur votre appareil Android.

## Connectez-vous à un réseau Wi-Fi temporaire

Votre appareil iOS crée un réseau Wi-Fi temporaire. Lorsqu’un message vous le demande, touchez Connexion pour vous connecter à ce réseau sur votre appareil Android, puis attendez que l’écran Transférer des données s’affiche.

## Sélectionnez le contenu à transférer, puis patientez

Sur votre appareil Android, sélectionnez le contenu que vous souhaitez transférer (contacts, SMS, historique des appels ou fichiers audio, par exemple), puis touchez Continuer.

N’effectuez ensuite aucune opération sur vos appareils, même si votre appareil Android indique que le processus est terminé. Attendez que la barre de progression affichée sur votre appareil iOS soit entièrement remplie. Gardez vos appareils à proximité l’un de l’autre et branchés sur une source d’alimentation jusqu’à la fin du transfert. Cette étape peut prendre un certain temps, selon la quantité de données à transférer.

L’application transfère alors vos contacts, l’historique de vos messages, vos SMS, les photos et vidéos de votre appareil photo, vos albums photo, vos fichiers et dossiers, vos réglages d’accessibilité, vos réglages d’affichage, vos signets web, vos comptes de messagerie, vos messages et fichiers multimédias WhatsApp, vos mémos vocaux, l’historique de vos appels et vos calendriers. Si elles sont disponibles dans Google Play et dans l’App Store et qu’elles prennent en charge la fonctionnalité de transfert, certaines de vos apps gratuites sont également transférées. Une fois le transfert terminé, vous pouvez télécharger toutes les apps gratuites mises en correspondance dans l’App Store.

## Transférez votre numéro de téléphone et votre carte SIM ou votre eSIM

Vous pouvez ensuite activer votre numéro de téléphone, ainsi que votre carte SIM ou votre [eSIM](https://support.apple.com/118669) , sur votre iPhone ou iPad. Il est possible que l’on vous dirige vers le site web de votre opérateur pour finaliser cette activation.

## Configurez votre appareil iOS

Une fois la barre de progression pleine sur votre appareil iOS, touchez OK sur votre appareil Android. Touchez ensuite Continuer sur l’appareil iOS, puis suivez les instructions à l’écran afin de [terminer la configuration](https://support.apple.com/105132) .

Assurez-vous que tout le contenu a été transféré. Vous devez [transférer manuellement vos morceaux de musique, livres et fichiers PDF](https://support.apple.com/104965) .

Vous avez besoin de récupérer les apps qui se trouvaient sur votre appareil Android ? [Accédez à l’App Store](https://support.apple.com/102590) sur votre appareil iOS pour les télécharger.

## En cas de problèmes de transfert

- N’effectuez aucune opération sur vos appareils tant que le transfert des données n’est pas terminé. L’application Migrer vers iOS doit rester ouverte au premier plan pendant tout le processus. Si vous ouvrez une autre application, ou prenez un appel avec votre appareil Android avant la fin du transfert, ce dernier échoue.

- Sur votre appareil Android, désactivez les apps ou réglages qui pourraient affecter votre connexion Wi-Fi, comme Sprint Connections Optimizer ou Smart Network Switch. Ensuite, accédez à Wi-Fi dans Réglages et maintenez votre doigt appuyé sur chaque réseau connu, puis oubliez-les. Ensuite, essayez à nouveau de procéder au transfert.

- [Redémarrez](https://support.apple.com/118259) vos deux appareils et réessayez.

- Désactivez la connexion de données mobiles sur votre appareil Android. Ensuite, essayez à nouveau de procéder au transfert.

## En cas de problèmes après le transfert

- Obtenez de l’aide [si vous ne parvenez pas à vous connecter à Messages](https://support.apple.com/119859) ou [si Messages ne fonctionne pas comme attendu après le transfert de votre contenu](https://support.apple.com/118433) .

- [Si des apps de votre appareil Android n’apparaissent pas sur votre nouvel appareil iOS, téléchargez-les sur ce dernier depuis l’App Store](https://support.apple.com/102590) .

- Il se peut que la totalité de vos données n’ait pas été transférée, du fait d’un manque d’espace, sur l’appareil iOS. Dans ce cas, [effacez les données de votre appareil iOS](https://support.apple.com/108931) et recommencez le transfert. Assurez-vous que le volume de données à transférer ne dépasse pas l’espace disponible sur votre appareil iOS. [Vérifiez l’espace de stockage sur votre iPhone ou iPad](https://support.apple.com/108429) .

## Transférer votre eSIM et vos données depuis Android vers iOS ou iPadOS sans utiliser l’application Migrer vers iOS

- Commencez par configurer votre iPhone ou iPad. Sur la page Transférez vos apps et vos données, touchez Depuis Android.

- Touchez Transférer sans app.

[Image: Sous iOS 26.5, sur les appareils compatibles, vous pouvez transférer vos données d’un appareil Android vers iOS ou iPadOS sans utiliser l’application Migrer vers iOS.]

- Placez votre appareil Android à côté de votre appareil iOS ou iPadOS, puis touchez Continuer.

- Utilisez la caméra de votre appareil Android pour scanner le code QR sur votre iPhone ou votre iPad et vous connecter.

[Image: Lorsque vous utilisez iOS ou iPadOS pour transférer des données depuis un appareil Android, scannez un code QR lors de la configuration pour connecter vos deux appareils.]

- Sur votre appareil Android, sélectionnez les données que vous souhaitez transférer (photos, contacts, calendriers, historique des appels ou des messages, par exemple) depuis votre appareil Android vers votre iPhone ou votre iPad.

- Une fois le transfert de données terminé, touchez Continuer sur votre iPhone ou iPad.

- Si vous souhaitez transférer une eSIM, sélectionnez le numéro sur votre appareil Android, puis touchez Transférer.

- Une fois le transfert de l’eSIM terminé, touchez Continuer pour terminer la configuration sur votre iPhone ou iPad.

Vous souhaitez transférer des données dans l’autre sens ? [Transférer des données et une eSIM d’iOS ou iPadOS vers Android](https://support.apple.com/126058) .

Pour effectuer le transfert sans l’application Migrer vers iOS, vous devez disposer d’une version compatible d’Android 17 ou version ultérieure. Consultez le fabricant de votre appareil pour savoir si celui-ci prend en charge l’eSIM et le transfert de données sans app.

### Si vous ne parvenez pas à scanner le code QR lorsque vous essayez de transférer des données ou une eSIM sans l’application Migrer vers iOS

Lorsque vous transférez des données ou votre eSIM d’un appareil Android vers votre iPhone ou iPad, vous pouvez utiliser votre appareil Android pour scanner un code QR affiché sur votre iPhone ou votre iPad afin de lancer le processus de transfert. Si vous ne parvenez pas à scanner le code QR, vous pouvez aussi entrer vos informations manuellement pour terminer le processus de transfert.

- Commencez par configurer votre iPhone ou iPad. Sur la page Transférez vos apps et vos données, touchez Depuis Android.

- Lorsque le code QR apparaît, touchez Autres options.

- Sur votre appareil Android, accédez à Paramètres et ouvrez Services Google.

- Sur votre appareil Android, touchez ensuite Tous les services. Touchez ensuite Jumeler avec iPhone ou iPad, puis Copier les données.

- Sur votre appareil Android, saisissez l’identifiant de session et le code de jumelage affichés sur votre iPhone ou iPad, puis touchez Continuer. Si vous ne savez pas où saisir l’identifiant de session et le code de jumelage, consultez le fabricant de votre appareil.

- Terminez le processus de transfert sur votre iPhone ou iPad.
