# Si Messages est en cours d’indexation et que les liens et photos partagés n’apparaissent pas dans vos conversations

Si vous ne trouvez pas les photos de vos conversations ou si une alerte relative à l’indexation de Messages s’affiche, vous devrez peut-être vérifier vos réglages iCloud pour Messages.

Lorsque vous mettez à jour le logiciel de votre iPhone ou que vous transférez vos données vers un nouvel iPhone, il se peut qu’un certain délai soit nécessaire avant que les liens, photos ou autres contenus multimédias partagés apparaissent dans les conversations de Messages. Les liens partagés, les photos et les autres contenus s’afficheront une fois l’indexation de Messages terminée. Les transferts de données nécessitent une connexion Wi-Fi, et le processus d’indexation s’effectue plus rapidement lorsque votre iPhone est verrouillé et connecté à Internet via le Wi-Fi ou Ethernet. En fonction des tâches exécutées en arrière-plan et de la taille des données enregistrées dans Messages, le processus peut être rapide ou prendre jusqu’à quelques jours.

Si vous utilisiez auparavant iCloud pour sauvegarder vos données et que vous ne trouvez pas les liens partagés, les photos ou d’autres contenus multimédias dans les conversations de Messages après un certain temps, vous pouvez désactiver, puis réactiver iCloud pour Messages pour redémarrer le processus d’indexation :

- Dans l’app Réglages, touchez votre nom.

- Touchez iCloud.

- Touchez Messages.

- Désactivez l’option Utiliser sur cet iPhone, puis réactivez-la.
