# OS X Server (Mavericks) : affichage d’un message d’alerte lors de l’ajout, au service Xcode, d’une équipe de développement Apple

Lorsque vous tentez d’ajouter une équipe de développement au service Xcode, il est possible que le message d’alerte suivant s’affiche :

« Le serveur a rencontré une erreur avec le service pour les développeurs Apple.

Veuillez réessayer ultérieurement. Si le problème persiste, contactez l’assistance technique pour les développeurs Apple afin d’obtenir de l’aide. »

## Résolution du problème

Pour ajouter un serveur à votre équipe, connectez-vous à l’aide de l’identifiant Apple de l’agent, ou de celui de l’administrateur d’une équipe de développeurs Apple enregistrée. Pour vérifier l’adhésion d’une équipe et les rôles alloués aux membres, contactez [l’assistance du programme pour les développeurs Apple](https://developer.apple.com/contact/) .

## Informations supplémentaires

Le fichier system.log peut vous permettre d’obtenir plus d’informations. Le message suivant peut, par exemple, s’y trouver : « Vous n’êtes pas autorisé à effectuer cette opération. Consultez un administrateur de votre équipe ou, pour obtenir de l’aide, contactez l’assistance du programme pour les développeurs Apple ».
