# Allumer un Mac mini, un Mac Studio ou un iMac sans appuyer sur son bouton d’alimentation

Certains ordinateurs de bureau Mac peuvent être configurés de manière à s’allumer automatiquement lorsque vous les reliez à une source d’alimentation. Cette fonctionnalité peut être utile si le bouton d’alimentation de l’ordinateur n’est pas facilement accessible.

## Configuration système requise

Cette fonctionnalité est disponible sous [macOS Tahoe 26.5 ou version ultérieure](https://support.apple.com/fr-fr/109033) sur les ordinateurs suivants :

- [Mac mini](https://support.apple.com/fr-fr/102852) commercialisés à partir de 2024

- [Mac Studio](https://support.apple.com/fr-fr/102231) commercialisés à partir de 2025

- [iMac](https://support.apple.com/fr-fr/108054) commercialisés à partir de 2024

## Configurer votre Mac pour démarrer après le branchement sur une source d’alimentation

- Dans le menu Pomme , choisissez Réglages Système.

- Cliquez sur Énergie dans la barre latérale.

- Dans le menu « Démarrer après le branchement sur une source de courant » à droite, sélectionnez Toujours. Ce réglage est disponible uniquement sur les ordinateurs qui répondent à la configuration système requise.

Désormais, votre Mac s’allumera automatiquement chaque fois que vous le connecterez à l’alimentation, par exemple en le branchant sur une prise de courant ou en rétablissant l’alimentation à l’aide d’un interrupteur externe. L’ordinateur s’allumera également automatiquement lorsque l’alimentation sera rétablie après une panne de courant.

Si votre Mac est resté connecté à l’alimentation après son arrêt, il est préférable de patienter environ 30 secondes entre le moment où vous le déconnectez et celui où vous le reconnectez à l’alimentation pour l’allumer. Ce délai permet au bloc d’alimentation de votre Mac de se décharger.
