# Redémarrage du service Apple Mobile Device sous Windows

Si un iPhone, iPad ou iPod touch n’est pas reconnu dans iTunes sous Windows, le service Apple Mobile Device peut avoir besoin d’être redémarré.

## Comment redémarrer le service Apple Mobile Device

L’erreur suivante peut s’afficher lors de la connexion de votre appareil : « Cet [appareil] ne peut pas être utilisé car le service Apple Mobile Device n’a pas été démarré. »

Procédez comme suit pour redémarrer le service Apple Mobile Device :

- Fermez iTunes et déconnectez les iPhone, iPad ou iPod connectés.

- Accédez à la commande Exécuter en appuyant simultanément sur la touche du logo Windows et sur la touche R du clavier de votre ordinateur.

- Saisissez services.msc, puis cliquez sur OK. La console de services doit s’ouvrir.

- Cliquez avec le bouton droit de la souris sur Service Apple Mobile Device, puis sur Propriétés dans le menu contextuel.

[Image: Console Services de Windows affichant Service Apple Mobile Device en surbrillance]

- Définissez le menu local Type de démarrage sur Automatique.

[Image: Fenêtre Propriétés du service Apple Mobile Device dans la console Services de Windows, utilisée pour configurer le service en vue du redémarrage.]

- Cliquez sur Arrêter le service.

- Une fois le service arrêté, cliquez sur Démarrer le service.

- Cliquez sur OK.

- Redémarrez l’ordinateur.

- Ouvrez iTunes et connectez l’appareil.

## Informations supplémentaires

Si le service Apple Mobile Device ne démarre toujours pas ou s’il s’arrête de manière inopinée, cela peut être dû à un logiciel de sécurité tiers. Découvrez comment [résoudre les problèmes entre iTunes et les logiciels de sécurité tiers](https://support.apple.com/HT201413) .

Si le service Apple Mobile Device n’est pas à l’origine du problème, découvrez comment [dépanner d’autres causes de problèmes de reconnaissance des appareils](https://support.apple.com/HT204095) .
