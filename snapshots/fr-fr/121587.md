# Vérifier le mode du micro sur Mac lors d’un enregistrement audio dans Logic Pro ou GarageBand

Si le son est différent de ce à quoi vous vous attendez lorsque du contenu audio est enregistré sur votre Mac, vérifiez que le mode du micro est réglé sur Standard.

Les autres réglages du mode du micro sont conçus pour réduire les bruits de fond lors d’appels téléphoniques, d’appels FaceTime et de visioconférences. Ils modifient cependant le son de l’entrée audio, qu’il s’agisse du micro intégré de votre Mac ou de sources audio externes. Assurez-vous de définir le mode du micro sur Standard lorsque du contenu audio est enregistré dans un but créatif.

- Lorsqu’une app qui utilise l’entrée audio, comme Logic Pro, est ouverte sur votre Mac, cliquez sur l’icône Modes de micro dans la barre des menus. Si l’icône n’apparaît pas dans la barre des menus, la fonctionnalité Modes du micro ne s’applique pas à l’app que vous utilisez.

[Image: null]

- Si plusieurs apps prenant en charge les modes du micro sont ouvertes, cliquez sur l’application dans le menu Mode du micro.

- Sous Mode du micro, cliquez sur Standard.
