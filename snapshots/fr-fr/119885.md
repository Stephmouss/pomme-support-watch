## Utiliser Keynote sur iPhone ou iPad

Découvrez comment choisir un thème, ajouter du contenu, modifier l’apparence d’une diapositive et plus encore.

### Choisir un thème et ajouter du contenu

Pour créer une présentation Keynote, choisissez d’abord un thème. Les thèmes contiennent des dispositions de diapositive préconçues que vous pouvez utiliser comme point de départ pour votre présentation.

- Dans le gestionnaire de documents, touchez Choisir un thème ou le bouton Créer une présentation , puis touchez un thème. Si vous êtes en train de modifier une présentation, touchez le bouton de retour pour ouvrir le gestionnaire de documents.

[Image: Aucun texte de remplacement pour l’image]

- Si vous disposez d’un abonnement Apple Creator Studio, vous pouvez également toucher Générer une présentation pour sélectionner un thème et générer une présentation à partir d’une description textuelle.*

- Si vous choisissez un thème premium et que vous ne disposez pas d’un abonnement Apple Creator Studio, un aperçu du thème s’affichera et vous aurez la possibilité de vous abonner.

- Pour ajouter une diapositive, touchez le bouton Ajouter une diapositive au bas de l’écran, puis choisissez une disposition.

[Image: Aucun texte de remplacement pour l’image]

- Pour insérer votre propre texte, touchez deux fois le texte dans l’espace prévu à cet effet.

- Si la diapositive contient une image d’espace réservé que vous souhaitez remplacer, touchez le bouton Remplacer le fichier multimédia sur l’image d’espace réservé, puis choisissez votre propre image.

[Image: Aucun texte de remplacement pour l’image]

### Modifier la taille des diapositives

Vous pouvez modifier la taille des diapositives afin de les adapter à un format d’écran spécifique. Il est possible que le contenu des diapositives soit déplacé pour tenir compte du nouveau format d’image.

- Ouvrez votre présentation dans Keynote.

- Sur l’iPhone, touchez le bouton Plus . Sur l’iPad, touchez le nom du document ou le bouton Plus en fonction de ce que vous voyez dans la barre d’outils.

[Image: Aucun texte de remplacement pour l’image]

- Touchez Options de la présentation, puis Configuration de la présentation.

- Touchez Taille des diapositives en bas de la fenêtre, touchez une nouvelle taille, puis touchez Terminé.

- Si vous choisissez l’option Personnalisée, saisissez les dimensions des diapositives, puis touchez OK.

- Touchez le bouton Diapositive précédente ou le bouton Diapositive suivante pour prévisualiser les diapositives dans leur nouvelle taille.

[Image: Aucun texte de remplacement pour l’image]

- Touchez OK.

### Modifier l’apparence d’une diapositive

Pour modifier rapidement l’apparence d’une diapositive, vous pouvez lui appliquer une autre disposition. Lorsque vous changez la disposition d’une diapositive, le contenu précédemment ajouté apparaît dans la nouvelle disposition.

- Sélectionnez une ou plusieurs diapositives.

- Touchez le bouton Format , puis touchez Disposition.

[Image: Aucun texte de remplacement pour l’image]

- Effectuez un balayage pour parcourir toutes les dispositions de diapositive, puis touchez celle que vous souhaitez appliquer.

- Une fois que vous avez terminé, touchez le bouton de fermeture .

[Image: Aucun texte de remplacement pour l’image]

### Modifier l’apparence d’une présentation entière

Pour modifier rapidement l’apparence d’une présentation entière, vous pouvez, à tout moment, choisir un autre thème. Si vous avez ajouté du contenu, celui-ci est inséré dans les diapositives du nouveau thème. Toutes les personnalisations que vous avez appliquées, comme la couleur du texte, apparaissent dans le nouveau thème.

- Ouvrez votre présentation dans Keynote.

- Sur l’iPhone, touchez le bouton Plus . Sur l’iPad, touchez le nom du document ou le bouton Plus en fonction de ce que vous voyez dans la barre d’outils.

[Image: Aucun texte de remplacement pour l’image]

- Touchez Options de la présentation, puis Configuration de la présentation.

- Touchez Thèmes en bas de la fenêtre.

- Touchez un thème ou effectuez un balayage pour en afficher davantage.

- Une fois l’opération terminée, touchez OK.

### Modifier des dispositions de diapositive

Vous pouvez modifier des dispositions de diapositive pour modifier rapidement plusieurs diapositives d’une présentation à la fois. Vous pouvez modifier la disposition d’une diapositive, ajouter du texte, des images et d’autres objets. Les modifications apportées aux dispositions de diapositive affectent les diapositives de votre présentation qui les utilisent.

- Touchez l’arrière-plan d’une diapositive. Dans le menu qui apparaît, touchez Modifier la disposition de diapositive.

- Dans la barre latérale, touchez une diapositive que vous souhaitez modifier.

- Choisissez ce que vous voulez faire : réorganiser le contenu, ajouter du texte, des images ou d’autres objets.

- Une fois que vous avez terminé de modifier les dispositions de diapositive, touchez OK dans l’angle supérieur droit de l’écran.

## Utiliser Keynote pour Mac

Découvrez comment choisir un thème, ajouter du contenu, modifier l’apparence d’une diapositive et plus encore.

### Choisir un thème et ajouter du contenu

- Dans Keynote, choisissez Fichier > Nouveau, puis, dans le sélecteur de thèmes, double-cliquez sur celui que vous souhaitez utiliser. Si le sélecteur de thèmes n’apparaît pas, maintenez la touche Option enfoncée, sélectionnez Fichier > Créer à partir de la liste de thèmes, puis double-cliquez sur le thème à appliquer.

- Si vous choisissez un thème premium et que vous ne disposez pas d’un abonnement Apple Creator Studio, un aperçu du thème s’affichera et vous aurez la possibilité de vous abonner.

- Si vous disposez d’un abonnement Apple Creator Studio, vous pouvez cliquer sur Générer dans l’angle inférieur droit de la fenêtre pour générer votre présentation à partir d’une description textuelle.*

- Pour ajouter une diapositive, cliquez sur le bouton Ajouter une diapositive dans la barre d’outils, puis cliquez sur une disposition.

[Image: Aucun texte de remplacement pour l’image]

- Pour saisir votre propre texte, double-cliquez sur le texte dans l’espace prévu à cet effet.

- Pour remplacer une image d’espace réservé, cliquez sur le bouton Remplacer le fichier multimédia sur l’image d’espace réservé, puis choisissez une image.

[Image: Aucun texte de remplacement pour l’image]

### Modifier la taille des diapositives

Vous pouvez modifier la taille des diapositives afin de les adapter à un format d’écran ou de projecteur spécifique. Il est possible que le contenu des diapositives soit déplacé pour tenir compte du nouveau format d’image.

- Cliquez sur le bouton Document , puis cliquez sur l’onglet Document.

[Image: Aucun texte de remplacement pour l’image]

- Choisissez une taille de diapositive dans le menu local Taille des diapositives.

- Si vous choisissez l’option Personnaliser, saisissez les dimensions des diapositives, puis cliquez sur OK.

### Modifier l’apparence d’une diapositive

Pour modifier rapidement l’apparence d’une diapositive, vous pouvez lui appliquer une autre disposition. Lorsque vous changez la disposition d’une diapositive, le contenu précédemment ajouté apparaît dans la nouvelle disposition.

- Cliquez sur le bouton Présentation , sélectionnez Navigateur, puis sélectionnez les diapositives que vous souhaitez modifier.

[Image: Aucun texte de remplacement pour l’image]

- Cliquez sur le bouton Format , cliquez sur Disposition de la diapositive, puis cliquez sur une disposition pour l’appliquer aux diapositives sélectionnées.

[Image: Aucun texte de remplacement pour l’image]

### Modifier l’apparence d’une présentation entière

Pour modifier l’apparence d’une présentation entière, vous pouvez, à tout moment, choisir un autre thème. Si vous avez ajouté du contenu, celui-ci est inséré dans les diapositives du nouveau thème.

- Cliquez sur le bouton Document , puis cliquez sur l’onglet Document.

[Image: Aucun texte de remplacement pour l’image]

- Cliquez sur Modifier le thème.

- Double-cliquez sur un autre thème.

- Afin que les personnalisations que vous avez appliquées apparaissent dans le nouveau thème, par exemple la couleur du texte, sélectionnez « Conserver vos modifications de style ».

Il est toujours possible d’annuler un changement de thème si vous préfériez le précédent.

### Modifier des dispositions de diapositive

Vous pouvez modifier des dispositions de diapositive pour modifier rapidement plusieurs diapositives d’une présentation à la fois.

- Dans la barre des menus, sélectionnez Présentation > Modifier les dispositions de diapositive.

- Dans la barre latérale, sélectionnez une disposition de diapositive que vous souhaitez modifier.

- Choisissez ce que vous voulez faire : réorganiser le contenu, ajouter du texte, des images ou d’autres objets.

- Une fois que vous avez terminé de modifier les dispositions de diapositive, touchez Terminé dans l’angle inférieur droit de l’écran.

Les modifications apportées aux dispositions de diapositive affectent les diapositives de votre présentation qui les utilisent.

## Keynote pour iCloud

Vous pouvez choisir un thème lors de la création d’une présentation Keynote en ligne sur iCloud.com.

- Dans le gestionnaire de présentations, cliquez sur le bouton Nouvelle présentation .

[Image: Aucun texte de remplacement pour l’image]

- Double-cliquez sur un thème. La présentation s’ouvre dans un nouvel onglet ou une nouvelle fenêtre de votre navigateur.

- Pour ajouter des diapositives, cliquez sur le bouton Ajouter dans le navigateur de diapositives, puis cliquez sur une disposition.

[Image: Aucun texte de remplacement pour l’image]

- Pour saisir votre propre texte dans une diapositive, double-cliquez sur le texte dans l’espace prévu à cet effet.

- Pour ajouter l’une de vos images à une diapositive, faites-la glisser depuis une fenêtre de votre ordinateur vers un espace réservé destiné à accueillir une image.

Si vous voulez modifier l’apparence des diapositives, leur taille ou le thème après avoir initialement créé votre présentation dans Keynote pour iCloud, ouvrez cette dernière dans Keynote sur votre iPhone, iPad ou Mac.
