# Apple Remote Desktop : clients indisponibles si l’écran est verrouillé ou en mode Rideau lors de la déconnexion

Si vous faites usage de Remote Desktop pour contrôler un client à l’aide du mode Rideau, puis vous déconnectez sur le client distant, la session de contrôle prend fin et vous ne pouvez plus reprendre le contrôle du client, à moins d’en forcer le redémarrage.

Ceci peut également se produire si vous verrouillez l’écran du client avant d’en prendre le contrôle.

Ne vous déconnectez pas sur le client distant si le mode Rideau est activé.

Commencez par fermer toutes les fenêtres contenant des informations importantes et interrompez la session de contrôle (déverrouillez l’écran si nécessaire). Démarrez une nouvelle session de contrôle en mode normal (et non en mode Rideau), puis déconnectez-vous.
