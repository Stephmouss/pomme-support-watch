# Combien d’écrans pouvez-vous connecter au Mac mini ?

Le nombre d’écrans externes que vous pouvez utiliser simultanément dépend de votre modèle de Mac et de la résolution et du taux de rafraîchissement de chaque écran.

- [Mac mini (2024) avec puce M4](https://support.apple.com/fr-fr/102194#mac-mini-2024)

- [Mac mini (2024) avec puce M4 Pro](https://support.apple.com/fr-fr/102194#mac-mini-2024-pro)

- [Mac mini (2023) avec puce M2](https://support.apple.com/fr-fr/102194#2023-m2)

- [Mac mini (2023) avec puce M2 Pro](https://support.apple.com/fr-fr/102194#2023-m2-pro)

- [Autres modèles de Mac mini](https://support.apple.com/fr-fr/102194#older-models)

L’utilisation d’un concentrateur compatible ou le branchement en série d’écrans vous permet d’installer jusqu’à deux écrans sur un seul port Thunderbolt, sans pour autant augmenter le nombre maximal d’écrans pris en charge. Connectez d’abord l’écran présentant la résolution la plus élevée.

## Mac mini (2024) avec puce M4

Le Mac mini (2024) avec puce M4 prend en charge jusqu’à trois écrans externes simultanément, en fonction de la résolution et du taux de rafraîchissement de chaque écran externe.

### Un écran externe

Prise en charge d’un écran externe avec la configuration suivante :

- Un écran d’une résolution native pouvant aller jusqu’à 8K (7 680 x 4 320) à 60 Hz, 5K (5 120 x 2 880) à 120 Hz ou 4K (3 840 x 2 160) à 240 Hz via Thunderbolt ou HDMI

### Deux écrans externes

Fonctionne avec deux écrans externes dans une de ces configurations :

- Un écran d’une résolution native pouvant aller jusqu’à 8K (7 680 x 4 320) à 60 Hz, 5K (5 120 x 2 880) à 120 Hz ou 4K (3 840 x 2 160) à 240 Hz via Thunderbolt ou HDMI, et un écran d’une résolution native pouvant aller jusqu’à 5K (5 120 x 2 880) à 60 Hz via Thunderbolt

- Un écran d’une résolution native pouvant aller jusqu’à 8K (7 680 x 4 320) à 60 Hz, 5K (5 120 x 2 880) à 120 Hz ou 4K à 240 Hz via Thunderbolt, et un écran d’une résolution native pouvant aller jusqu’à 4K (3 840 x 2 160) à 60 Hz via HDMI

- Deux écrans d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2160) à 144 Hz via Thunderbolt ou HDMI

### Trois écrans externes

Prise en charge de trois écrans externes dans n’importe laquelle de ces configurations :

- Deux écrans d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt ou HDMI, et un écran d’une résolution native pouvant aller jusqu’à 5K (5 120 x 2 880) à 60 Hz via Thunderbolt

- Deux écrans d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt, et un écran d’une résolution native pouvant aller jusqu’à 4K (3 840 x 2 160) à 60 Hz via HDMI

## Mac mini (2024) avec puce M4 Pro

Le Mac mini (2024) avec puce M4 Pro prend en charge jusqu’à trois écrans externes simultanément, en fonction de la résolution et du taux de rafraîchissement de chaque écran externe.

### Un écran externe

Prise en charge d’un écran externe avec la configuration suivante :

- Un écran d’une résolution native pouvant aller jusqu’à 8K (7 680 x 4 320) à 60 Hz, 5K (5 120 x 2 880) à 120 Hz ou 4K (3 840 x 2 160) à 240 Hz via Thunderbolt ou HDMI

### Deux écrans externes

Prise en charge de deux écrans externes avec la configuration suivante :

- Un écran d’une résolution native pouvant aller jusqu’à 8K (7 680 x 4 320) à 60 Hz, 5K (5 120 x 2 880) à 120 Hz ou 4K (3 840 x 2 160) à 240 Hz, et un écran d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt ou HDMI

### Trois écrans externes

Prise en charge de trois écrans externes avec la configuration suivante :

- Trois écrans d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz ou 4K (3 840 x 2 160) à 144 Hz via Thunderbolt ou HDMI

## Mac mini (2023) avec puce M2

Le Mac mini (2023) avec puce M2 prend en charge jusqu’à deux écrans externes simultanément, en fonction de la résolution et du taux de rafraîchissement de chaque écran externe.

### Un écran externe

Fonctionne avec un écran externe dans une de ces configurations :

- Un écran d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz via Thunderbolt

- Un écran d’une résolution native pouvant aller jusqu’à 4K (3 840 x 2 160) à 60 Hz via HDMI

### Deux écrans externes

Fonctionne avec deux écrans externes dans une de ces configurations :

- Un écran d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz via Thunderbolt, et un écran d’une résolution native pouvant aller jusqu’à 5K (5 120 x 2 880) à 60 Hz via Thunderbolt

- Un écran d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz via Thunderbolt, et un écran d’une résolution native pouvant aller jusqu’à 4K (3 840 x 2 160) à 60 Hz via HDMI

## Mac mini (2023) avec puce M2 Pro

Le Mac mini (2023) avec puce M2 Pro prend en charge jusqu’à trois écrans externes simultanément, en fonction de la résolution et du taux de rafraîchissement de chaque écran externe.

### Un écran externe

Fonctionne avec un écran externe dans une de ces configurations :

- Un écran d’une résolution native pouvant aller jusqu’à 8K (7 680 x 4 320) à 60 Hz ou 4K (3 840 x 2 160) à 240 Hz via HDMI

- Un écran d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz via Thunderbolt

### Deux écrans externes

Fonctionne avec deux écrans externes dans une de ces configurations :

- Deux écrans d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz via Thunderbolt

- Un écran d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz via Thunderbolt, et un écran d’une résolution native pouvant aller jusqu’à 4K (3 840 x 2 160) à 144 Hz via HDMI

### Trois écrans externes

Prise en charge de trois écrans externes avec la configuration suivante :

- Deux écrans d’une résolution native pouvant aller jusqu’à 6K (6 144 x 3 456) à 60 Hz via Thunderbolt, et un écran d’une résolution native pouvant aller jusqu’à 4K (3 840 x 2 160) à 60 Hz via HDMI

## Autres modèles de Mac mini

Consultez les caractéristiques techniques de votre [modèle de Mac mini](https://support.apple.com/fr-fr/102852) afin de connaître le nombre maximal d’écrans externes acceptés, ainsi que la résolution maximale et le taux de rafraîchissement de chacun d’eux.

## Nombre maximal d’écrans pris en charge

Les résolutions à l’échelle disponibles pour les écrans externes dans les [réglages Moniteurs](https://support.apple.com/guide/mac-help/displays-settings-on-mac-mh40768/mac) peuvent varier en fonction des ressources système disponibles et du type des écrans connectés. Les résolutions à l’échelle supérieures à la résolution par défaut de macOS ne sont pas prises en compte dans les capacités maximales de prise en charge indiquées ci-dessus.
