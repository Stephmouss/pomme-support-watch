# Télécharger l’app Migrer vers iOS lorsque vous ne pouvez pas utiliser Google Play

Si vous n’avez pas accès au Google Play Store, vous pouvez télécharger directement l’app Migrer vers iOS.

Si vous avez un appareil Android compatible qui exécute une version compatible d’Android 17, vous pouvez [effectuer un transfert vers iOS ou iPadOS sans l’app Migrer vers iOS](https://support.apple.com/118670#noapp) . Sinon, téléchargez l’app Migrer vers iOS depuis Google Play pour procéder au transfert.

## Télécharger le fichier APK Migrer vers iOS

Suivez ces étapes sur votre appareil Android :

- Téléchargez le programme d’installation Migrer vers iOS :

- [Android 6.0 et versions ultérieures (universel - recommandé)](https://secure-appldnld.apple.com/android/082-51988-20250520-5EA7105F-4AE0-42D3-BE06-D8EAA506E827/com.apple.movetoios-4.0.3-universal-release.apk)

- [Android 6.0 et versions ultérieures (64 bits uniquement)](https://secure-appldnld.apple.com/android/082-51988-20250520-45F1954D-3F8D-4BB0-B429-078AE411F69A/com.apple.movetoios-4.0.3-arm64-v8a-release.apk)

- Utilisez le navigateur de fichiers de votre appareil* pour rechercher le programme d’installation de Migrer vers iOS, dont le nom de fichier se termine par .apk. Sur de nombreux appareils, vous trouverez ce fichier .apk dans un dossier de téléchargements.

- Touchez le fichier pour l’installer.

- Si une alerte vous invite à modifier vos réglages de sécurité pour vous permettre de procéder à une installation à partir de sources inconnues, suivez les étapes à l’écran. Après avoir modifié vos réglages, vous devrez peut-être toucher un bouton de retour pour revenir au navigateur de fichiers. Ensuite, vous pourrez installer le fichier .apk.

Vous pouvez à présent [utiliser l’app Migrer vers iOS](https://support.apple.com/118670) .
