# OS X Server : à propos du partage de fichiers sur les images disque

Découvrez comment partager les fichiers qui se trouvent sur une image disque (.dmg).

Sous OS X Server, il est possible de partager des fichiers se trouvant sur une image disque en montant cette dernière, puis en la partageant à l’aide de l’application Serveur. Si vous redémarrez le serveur, l’image disque doit être montée une nouvelle fois, manuellement, pour permettre aux clients d’y accéder.

Remarque : pour partager une image disque à l’aide du protocole AFP, commencez par effectuer une mise à jour du serveur vers OS X Mountain Lion 10.8.2 ou version ultérieure.
