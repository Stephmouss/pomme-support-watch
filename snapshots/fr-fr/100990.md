# OS X Server : comment déverrouiller un compte d’utilisateur

Lorsqu’un utilisateur tente à de trop nombreuses reprises de se connecter à OS X Server, et ce sans succès, le compte en question est verrouillé si la limite définie pour le serveur est atteinte. Procédez comme indiqué ci-dessous pour déverrouiller un compte d’utilisateur et en rétablir l’accès.

Utilisez l’application Serveur pour réinitialiser le mot de passe associé au compte d’utilisateur. Si vous le souhaitez, vous pouvez également faire en sorte que l’utilisateur dont vous avez déverrouillé le compte soit invité à personnaliser son mot de passe après sa connexion.
