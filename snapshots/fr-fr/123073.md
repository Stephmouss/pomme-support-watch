# À propos des informations d’accessibilité affichées pour les apps dans l’App Store

Les équipes de développement d’apps peuvent ajouter des étiquettes informatives sur l’accessibilité sur la page produit de leurs apps dans l’App Store. Ces étiquettes vous permettent d’en savoir plus sur les fonctionnalités d’accessibilité prises en charge par les apps avant de les télécharger.

## À propos des étiquettes informatives sur l’accessibilité

Si une équipe de développement choisit de partager des informations relatives à l’accessibilité de son app dans l’App Store, ces informations apparaissent dans la section Accessibilité de la page produit de l’app. Vous pouvez consulter l’étiquette informative sur l’accessibilité d’une app pour savoir si celle-ci prend en charge des fonctionnalités d’accessibilité, notamment les suivantes :

- VoiceOver

- Voice Control

- Police plus grande

- Interface sombre

- Différencier sans couleur seule

- Contraste suffisant

- Animations réduites

- Sous-titres

- Descriptions audio

Pour en savoir plus sur les fonctionnalités pouvant apparaître dans une étiquette, comprendre leur utilité et découvrir comment les équipes de développement évaluent l’accessibilité de leurs apps, consultez l’App Store :
