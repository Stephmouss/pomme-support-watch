# OS X Server (Mavericks) : des clients ne peuvent pas se connecter au service VPN via le protocole L2TP

Sous OS X Server (Mavericks), il est possible que le service VPN n’accepte plus les connexions L2TP. Ceci peut se produire si le client et le serveur sont situés derrière des passerelles NAT distinctes.

Effectuez une mise à jour vers OS X Mavericks 10.9.1, puis installez la [mise à jour VPN pour OS X Server](http://support.apple.com/kb/HT6080?viewlocale=fr_FR) .

Ce document sera mis à jour lorsque de nouveaux renseignements seront disponibles.
