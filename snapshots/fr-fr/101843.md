# À propos de Xsan dans macOS Server 5.11.1 et macOS Server 5.12

Grâce aux outils Xsan de gestion de ligne de commande intégrés à macOS Big Sur et version ultérieure, vous n’avez plus besoin de macOS Server pour créer et administrer les réseaux de stockage Xsan.

Pour créer et administrer les réseaux de stockage Xsan, vous pouvez utiliser xsanctl , un outil de ligne de commande intégré à macOS Big Sur et version ultérieure. Il prend en charge les dernières fonctionnalités de Xsan et est compatible avec Quantum StorNext 7. Pour en savoir plus sur cet outil, saisissez man xsanctl dans Terminal.

Sous macOS Server 5.11.1, l’interface de configuration Xsan est masquée pour les nouvelles installations de macOS Server, mais continue de fonctionner normalement pour les installations de mise à niveau.

L’interface de configuration Xsan a été supprimée de macOS Server 5.12. Pour en savoir plus sur la migration vers les nouveaux outils, consultez le [guide de gestion Xsan](https://developer.apple.com/fr/support/downloads/Xsan-Management-Guide.pdf) (PDF).
