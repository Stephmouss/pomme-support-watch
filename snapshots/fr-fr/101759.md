# Un filigrane ne s’affiche pas dans un fichier transcodé

Il arrive qu’un fichier source ne soit pas correctement transcodé dans Compressor 4.2. Consultez cet article pour connaître les raisons de ce problème et obtenir des solutions.

Si le fichier source contient l’un des éléments suivants :

- Une vidéo en filigrane

- Un point d’entrée placé après le filigrane, sur le fichier source

Il se peut que le filigrane ne s’affiche pas dans l’aperçu de la tâche ou dans le fichier transcodé. Par exemple, si le fichier source contient une vidéo en filigrane d’une durée de deux minutes et un point d’entrée placé à la troisième minute, le filigrane peut ne pas apparaître.

Pour résoudre ce problème, transcodez le fichier à deux reprises : une première fois pour créer un film ne nécessitant pas de point d’entrée, une seconde dans le but d’ajouter le filigrane. Procédez comme suit :

- Supprimez le filigrane du fichier source d’origine. Ne supprimez pas le point d’entrée.

- Transcodez le lot en haute qualité (utilisez, par exemple, le réglage ProRes 422 HQ).

- Créez un second lot dans Compressor.

- Ajoutez le film transcodé à ce lot.

- Ajoutez la vidéo en filigrane au fichier source.

- Transcodez le second lot.

Le second fichier transcodé comporte désormais le filigrane.
