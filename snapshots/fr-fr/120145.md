# Comment configurer Optic ID

Lorsque le code d’accès est activé, vous pouvez utiliser Optic ID pour déverrouiller votre Apple Vision Pro, effectuer des achats, et bien plus encore. Découvrez comment configurer Optic ID et ce que vous pouvez faire si vous ne parvenez pas à utiliser cette fonctionnalité.

[Configurer Optic ID](https://support.apple.com/fr-fr/120145#setup)

[Utiliser Optic ID](https://support.apple.com/fr-fr/120145#use)

[Obtenir de l’aide pour configurer ou utiliser Optic ID](https://support.apple.com/fr-fr/120145#help)

## Configurer Optic ID

- Accédez à Réglages, puis choisissez Optic ID et code.

- Sélectionnez Configurer Optic ID, et suivez les instructions à l’écran. Si vous avez besoin d’une correction de la vue, vous pouvez configurer Optic ID avec vos ZEISS Optical Inserts déjà jumelés, ou sans vos ZEISS Optical Inserts. Si vous configurez Optic ID sans ZEISS Optical Inserts, vous pourrez configurer ultérieurement Optic ID avec ZEISS Optical Inserts dans Réglages.

- Si vous n’avez pas déjà configuré de code d’accès, vous êtes invité à en créer un.

- Une fois Optic ID configuré, vous pouvez [activer le réglage « L’iPhone à proximité prend en charge Optic ID »](https://support.apple.com/fr-fr/120145#nearby_iphone) afin d’utiliser votre iPhone pour activer Optic ID lorsque vous allumez ou redémarrez votre Apple Vision Pro.

Vous pouvez configurer Optic ID pour jusqu’à deux paires de ZEISS Optical Inserts.

### Activer « L’iPhone à proximité prend en charge Optic ID »

Si vous êtes connecté à votre iPhone doté d’iOS 17.1 ou version ultérieure et à votre Apple Vision Pro avec le même compte Apple, avoir votre iPhone à proximité peut activer Optic ID lorsque vous allumez ou redémarrez votre Apple Vision Pro.

- Accédez à Réglages > Optic ID et code.

- Sous « L’iPhone à proximité prend en charge Optic ID », touchez votre iPhone.

Vous pouvez utiliser cette fonctionnalité si votre iPhone se trouve à proximité et a été déverrouillé au cours de la dernière heure.

### Réinitialiser Optic ID

- Accédez à Réglages.

- Sélectionnez Optic ID et code.

- Saisissez votre code d’accès, puis sélectionnez Réinitialiser Optic ID. Si vous utilisez des ZEISS Optical Inserts, sélectionnez Réinitialiser Optic ID pour [vos ZEISS Optical Inserts] ou, pour réinitialiser entièrement Optic ID, choisissez Réinitialiser Optic ID pour tous les inserts optiques.

### Accessibilité

Si vous avez un œil directeur, vous pouvez choisir de contrôler l’Apple Vision Pro avec un seul œil. Lorsque vous choisissez cette option, seul cet œil est utilisé avec Optic ID.

Si vous êtes aveugle ou malvoyant, l’enregistrement Optic ID peut être possible si vous regardez bien devant vous, au centre de l’écran, pendant la configuration. Si vous choisissez de ne pas utiliser Optic ID ou que cette solution n’est pas réalisable, vous pouvez déverrouiller votre appareil et utiliser la fonctionnalité Persona via un code d’accès.

[En savoir plus sur l’accessibilité pour l’Apple Vision Pro](https://support.apple.com/guide/apple-vision-pro/tan426c48bdc/)

## Utiliser Optic ID

Vous pouvez utiliser Optic ID pour déverrouiller votre Apple Vision Pro, pour effectuer des achats avec Apple Pay, pour vous connecter à certaines apps et pour remplir automatiquement les noms d’utilisateur et mots de passe de sites web dans Safari. Après avoir configuré Optic ID, vous devez quand même parfois [saisir manuellement le code de votre appareil](https://support.apple.com/fr-fr/120145#passcode) .

### Déverrouiller votre Apple Vision Pro avec Optic ID

Pour déverrouiller votre Apple Vision Pro avec Optic ID, mettez votre Apple Vision Pro, puis regardez directement l’icône Optic ID. Si le déverrouillage échoue, vous pouvez toucher l’icône Optic ID du clavier pour réessayer, ou utiliser votre code d’accès.

### Utiliser Optic ID pour effectuer des achats

Pour effectuer un achat à l’aide d’Optic ID dans une app ou sur un site web dans Safari, accédez à Réglages > Optic ID et code, puis assurez-vous que le réglage « Cartes et Apple Pay » est activé. Ensuite :

- Touchez le bouton Acheter avec Apple Pay ou sélectionnez Apple Pay comme mode de paiement. Vérifiez vos informations de paiement.

- Appuyez deux fois sur le bouton supérieur, puis regardez directement l’icône Optic ID.

- Attendez que la mention OK et une coche s’affichent à l’écran.

Pour acheter du contenu à l’aide d’Optic ID dans l’iTunes Store, l’App Store et la librairie, accédez à Réglages > Optic ID et code, puis assurez-vous que le réglage « iTunes Store et App Store » est activé. Ensuite, procédez comme suit :

- Ouvrez l’iTunes Store, l’App Store ou la librairie, puis sélectionnez l’article que vous souhaitez acheter.

- Lorsque vous êtes invité à payer, appuyez deux fois sur le bouton supérieur, puis regardez directement l’icône Optic ID.

- Attendez que la mention OK et une coche s’affichent à l’écran.

### Connexion à des apps

- Ouvrez l’app et touchez Se connecter.

- Si vous y êtes invité, autorisez l’app à utiliser votre nom d’utilisateur ou votre mot de passe.

- Regardez directement l’icône Optic ID pour vous connecter.

Pour consulter et contrôler les apps auxquelles vous pouvez vous connecter à l’aide d’Optic ID, accédez à Réglages > Optic ID et code, puis touchez « Autres apps ».

Certaines apps iPad sur l’Apple Vision Pro peuvent vous inviter à vous connecter avec Face ID. Vous pouvez utiliser Optic ID à la place.

### Remplissage automatique du champ du mot de passe dans Safari

- Accédez à Réglages > Optic ID et code, puis activez « Remplissage automatique des mots de passe ».

- Ouvrez Safari et allez sur un site web.

- Touchez le champ de connexion. Si votre nom d’utilisateur ou votre mot de passe s’affiche au-dessus du clavier, touchez-le.

- Regardez directement l’icône Optic ID pour remplir automatiquement votre nom d’utilisateur et votre mot de passe.

### Lorsque vous avez besoin d’utiliser un code d’accès

Une fois que vous avez configuré Optic ID, vous devez saisir votre code d’accès pour déverrouiller votre Apple Vision Pro dans les cas suivants :

- Vous allumez ou redémarrez l’Apple Vision Pro et vous n’avez pas configuré l’activation d’Optic ID par l’iPhone.

- Vous n’avez pas déverrouillé l’Apple Vision Pro depuis plus de 48 heures.

- Vous n’avez pas déverrouillé l’Apple Vision Pro avec le code d’accès au cours des 6,5 derniers jours, et vous ne l’avez pas déverrouillé avec Optic ID au cours des 4 dernières heures.

- Vous avez effectué cinq tentatives infructueuses consécutives de déverrouillage de l’Apple Vision Pro avec Optic ID.

Une fois que vous aurez saisi votre code d’accès, vous pourrez à nouveau utiliser Optic ID.

## Obtenir de l’aide pour configurer ou utiliser Optic ID

Si vous ne parvenez pas à configurer ou à utiliser Optic ID, procédez comme suit :

- Assurez-vous que votre [Apple Vision Pro est correctement ajusté](https://support.apple.com/fr-fr/117730) et que rien n’obstrue votre vision. Vous devrez peut-être installer un [coussinet de cache anti-lumière d’une autre taille](https://support.apple.com/fr-fr/120051) ou un [cache anti-lumière d’une autre taille](https://support.apple.com/fr-fr/119999#help) .

- Si vous utilisez des lentilles de contact dures, il se peut que cela ait une incidence sur votre expérience de l’Apple Vision Pro.

- Assurez-vous que [l’Apple Vision Pro a une vue dégagée de vos yeux](https://support.apple.com/fr-fr/118513#open_eyes) , et que vous utilisez uniquement des aides ou des accessoires visuels pris en charge, tels que des ZEISS Optical Inserts. Si vous portez des lentilles de contact à visée esthétique, retirez-les et réessayez d’utiliser l’Apple Vision Pro.

- [Nettoyez les écrans de votre Apple Vision Pro et vos ZEISS Optical Inserts.](https://support.apple.com/fr-fr/119574)

- [Recommencez le jumelage de vos ZEISS Optical Inserts.](https://support.apple.com/fr-fr/117731)

- [Réinitialisez entièrement Optic ID](https://support.apple.com/fr-fr/120145#reset) , puis [reconfigurez cette fonctionnalité](https://support.apple.com/fr-fr/120145#setup) .

Si le problème persiste, [contactez l’assistance Apple](https://getsupport.apple.com/?caller=kbase) .
