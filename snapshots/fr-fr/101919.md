# Utiliser le stockage partagé avec Final Cut Pro

Final Cut Pro 10.4 ou version ultérieure pour Mac vous permet de stocker des bibliothèques sur des systèmes de stockage partagés utilisant le protocole de système de fichiers NFS ou SMB, ainsi que sur d’autres volumes de stockage partagés, sur Mac.

## Où stocker les bibliothèques Final Cut Pro et les données multimédias externes

Avant de stocker des bibliothèques et des ressources Final Cut Pro sur votre Mac, vérifiez que tous les systèmes accédant aux bibliothèques et aux données multimédias externes respectent la configuration minimale requise pour Final Cut Pro.

- Stockez les bibliothèques Final Cut Pro sur des [volumes de stockage locaux](https://support.apple.com/HT200243) , un SAN tel qu’un ?locale=fr_FRvolume de stockage Xsan*, des volumes utilisant le système de fichiers NFS ou SMB, et des systèmes de stockage partagés utilisant le protocole NFS ou SMB.

- Si vous employez un système de stockage partagé qui utilise le protocole SMB, le volume SMB doit provenir d’un serveur macOS ou d’un serveur Linux exécutant Samba 4.3.4 ou version ultérieure, configuré avec des modules permettant la compatibilité Apple.

- Stockez les données externes sur un volume de stockage partagé.

* Le serveur Xsan et les systèmes client doivent exécuter la même version de macOS.

## Comment configurer un système Network Attached Storage (NAS) Linux pour Final Cut Pro

Un volume SMB sur NAS Linux doit provenir d’un serveur Linux exécutant Samba 4.3.4 ou version ultérieure, configuré avec des modules permettant la compatibilité Apple.
