# Créer un réglage permettant d’encoder des médias entrelacés au format H.264 dans Compressor 4.2.1

Vous pouvez créer un réglage personnalisé permettant d’encoder facilement des médias entrelacés au format H.264.

Suivez ces étapes pour créer un réglage permettant d’encoder des médias entrelacés au format H.264 dans Compressor 4.2.1.

- Ouvrez Compressor.

- Dans la sous-fenêtre Réglages (Commande + Maj + 1), choisissez Nouveau réglage dans le menu local Ajouter un réglage.

- Dans la fenêtre qui apparaît, choisissez le format de transcodage « QuickTime Movie » dans le menu local.

- Saisissez un nom et une description pour le réglage, puis cliquez sur OK. Le nouveau réglage apparaît dans la section Personnalisés de la sous-fenêtre Réglages.

- Pour modifier les propriétés de votre nouveau réglage personnalisé, cliquez sur l’inspecteur vidéo pour ajuster les commandes. Si celui-ci est masqué, cliquez sur le bouton situé en haut à droite de la fenêtre Compressor.

- Dans la section Propriétés vidéo de l’inspecteur vidéo, cliquez sur le bouton Modifier à côté de « Réglages QuickTime » pour afficher la fenêtre Réglages de compression vidéo standard.

- Choisissez « H.264 » dans le menu local Type de compression.

- Dans la section Compressor, sélectionnez l’option « Codage plus rapide (passage unique) » et cliquez sur OK.

- Dans la sous-fenêtre Vidéo de l’inspecteur, sélectionnez l’ordre des champs entrelacés de votre choix (supérieure en 1er ou inférieure en 1er) à l’aide du menu local Ordre des champs.
