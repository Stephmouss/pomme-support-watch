# Utiliser une solution MDM pour activer la gestion à distance sous macOS

Découvrez comment contrôler un Mac distant géré avec un service MDM (gestion des appareils mobiles).

Pour contrôler un Mac distant géré avec un service MDM (gestion des appareils mobiles), utilisez la [commande Activer Remote Desktop](https://support.apple.com/guide/deployment/dep789n2k1qp/web) . La commande Activer Remote Desktop permet d’appliquer la [gestion à distance](https://support.apple.com/guide/mac-help/mh11851/mac)
