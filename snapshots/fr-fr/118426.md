# Comment sauvegarder les données de votre iPhone, iPad ou iPod touch

La création de sauvegardes vous permet de garder à disposition une copie de vos données si vous devez remplacer votre iPhone, iPad ou iPod touch, notamment si celui-ci est perdu ou endommagé.

## Choisir une méthode de sauvegarde

Avant de commencer, découvrez la [différence entre les sauvegardes iCloud et les sauvegardes effectuées avec un ordinateur](https://support.apple.com/ht204136) . Sélectionnez ensuite la méthode qui vous convient le mieux.

[Sauvegarder avec iCloud](https://support.apple.com/HT211228)
