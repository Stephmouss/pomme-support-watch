# Utiliser le démarrage rapide pour configurer l’iPhone ou l’iPad d’un enfant

Si vous êtes un parent ou un tuteur dans un groupe de partage familial, vous pouvez utiliser votre iPhone ou votre iPad pour configurer le nouvel appareil d’un enfant avec vos préférences de contrôle parental.

Si votre appareil et le nouvel appareil de votre enfant ont tous deux été mis à jour vers iOS 16 ou iPadOS 16 (ou une version ultérieure), vous pouvez utiliser le démarrage rapide pour configurer automatiquement le nouvel appareil de votre enfant avec vos préférences de contrôle parental. Si iOS 15 ou iPadOS 15 (ou une version antérieure) est installé sur l’un des appareils ou les deux, [vous pouvez configurer l’appareil manuellement](https://support.apple.com/fr-fr/108310) .

## Configurer l’appareil d’un enfant avec le démarrage rapide

- Allumez le nouvel appareil de votre enfant et balayez l’écran vers le haut pour le déverrouiller.

- Sélectionnez votre pays/région et votre langue.

- Placez votre appareil à proximité du nouvel appareil de votre enfant. Suivez ensuite les étapes ci-dessous sur votre appareil.

- Lorsque la fiche Nouvel [appareil] s’affiche, touchez Continuer.

[Image: Nouvel iPad apparaît dans la partie inférieure de l’écran.]

- Attendez qu’une animation apparaisse sur le nouvel appareil de votre enfant. Tenez votre appareil au-dessus de celui de votre enfant, puis centrez l’animation dans le viseur.

- Choisissez qui utilisera le nouvel appareil, puis touchez Continuer. Seuls les enfants de moins de 13 ans sont affichés dans votre groupe de partage familial*. Vous pouvez aussi choisir Créer un compte Enfant si vous souhaitez ajouter un enfant qui ne fait pas encore partie de votre groupe de partage familial.

[Image: Dans l’écran « Qui voulez-vous connecter à cet iPad », vous pouvez choisir de vous connecter vous-même, de connecter un enfant, ou sélectionner Créer un compte Enfant.]

- Suivez les étapes à l’écran pour terminer la configuration du nouvel appareil de votre enfant. Si vous configurez un appareil pour un enfant existant dans votre groupe de partage familial, vous pouvez paramétrer automatiquement son contrôle parental actuel. Si vous choisissez de créer un compte Enfant, vous pouvez créer le compte Apple de votre enfant, puis définir vos préférences de contrôle parental.

* L’âge limite varie selon le pays ou la région.

[Découvrez comment configurer l’iPhone d’un enfant sans utiliser « Démarrage rapide » ou dans Réglages sous iOS 18.4](https://support.apple.com/guide/iphone/set-up-a-childs-device-iphfd0b65920/ios)
