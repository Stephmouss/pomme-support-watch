# Si vous ne parvenez pas à charger un projet sur SoundCloud à partir de Logic Pro ou de GarageBand sur votre Mac

Si le chargement échoue, vous pouvez exporter le morceau de musique en tant que fichier, puis le charger sur le site web de SoundCloud ou avec l’app SoundCloud.

## Charger votre projet Logic Pro sur SoundCloud

- Décidez si vous souhaitez charger l’intégralité du projet ou seulement une section :

- Pour charger l’intégralité du projet, assurez-vous que les pistes que vous souhaitez inclure dans le bounce sont acheminées vers la sortie principale (sortie 1-2) et ne sont pas en mode silence dans la zone Pistes de Logic Pro ou la table de mixage.

- Pour charger une section du projet, [définissez la plage de lecture en boucle et activez le mode Cycle](https://support.apple.com/fr-fr/guide/logicpro/use-the-cycle-area-lgcp59e41e86/mac) . Lorsque le mode Cycle est activé, la plage du bounce correspond aux positions du locator.

- Dans Logic Pro, choisissez Fichier > Bounce, puis Projet ou Section.

- Définissez vos options de bounce :

- Cochez la case PCM et assurez-vous que la destination PCM est sélectionnée.

- Choisissez AIFF ou WAVE dans le menu contextuel Format de fichier.

- Choisissez 16 bits dans le menu contextuel Résolution.

- Choisissez 48 000 dans le menu contextuel Fréquence d’échantillonnage.

- Choisissez Entrelacé dans le menu contextuel Type de fichier.

- Choisissez d’autres options comme les points de début et de fin et le mode.

- Cliquez sur OK.

- Choisissez un emplacement pour le fichier audio, puis cliquez sur Bounce.

- Dans un navigateur, connectez-vous à votre compte SoundCloud, cliquez sur Uploader sur le site web de SoundCloud, puis chargez votre fichier audio.

## Charger votre morceau GarageBand sur SoundCloud depuis un Mac

- Dans GarageBand sur votre Mac, choisissez Partager > Exporter le morceau vers le disque.

- Définissez vos options d’exportation :

- Choisissez AIFF ou WAVE.

- Choisissez 16 bits sans compression dans le menu contextuel Qualité.

- Pour exporter uniquement la partie du morceau couverte par la zone en boucle, ou seulement la partie du projet définie par des régions sélectionnées, cochez la case « Exporter la zone en boucle ou la durée des régions sélectionnées (si la lecture en boucle est désactivée) ».

- Sélectionnez un emplacement pour le fichier audio, puis cliquez sur Exporter.

- Connectez-vous à votre compte SoundCloud dans un navigateur, cliquez sur Uploader sur le site web de SoundCloud, puis chargez votre fichier audio.
