# Corriger une analyse Flex Pitch inexacte dans Logic Pro pour Mac

Découvrez la marche à suivre si Flex Pitch attribue des fichiers audio à la note C0 au lieu des notes correctes dans l’éditeur de piste audio.

Dans Logic Pro 10.7.5 ou 10.7.6 sur macOS Ventura, Logic Pro peut attribuer incorrectement les fichiers audio analysés avec Flex Pitch à la note C0. Si cela se produit, mettez à jour Logic Pro, puis analysez à nouveau les fichiers.

## Mettre à jour Logic Pro

Tout d’abord, [installez la dernière version de Logic Pro pour Mac](https://apps.apple.com/fr/app/logic-pro/id634148309?mt=12) .

## Analyser à nouveau les fichiers audio

Après avoir mis à jour Logic Pro, analysez à nouveau toutes les régions audio qui ont été affectées incorrectement à la note C0.

- Une fois le projet ouvert dans Logic Pro, double-cliquez sur la région audio concernée dans la zone Pistes pour l’ouvrir dans l’éditeur de piste audio.

- Si nécessaire, cliquez sur l’onglet Piste de l’éditeur de fichier audio pour basculer vers l’éditeur de piste audio.

- Pour afficher les notes Flex Pitch, cliquez sur le bouton Afficher/Masquer Flex dans l’éditeur de piste audio (ou appuyez sur Commande + F).

- Assurez-vous de sélectionner Flex Pitch dans le menu local Mode Flex.

- Cliquez sur Modifier dans l’éditeur de piste audio, puis choisissez Analyser l’audio à la recherche de montages Flex.

- Répétez ces étapes pour toute autre région audio qui a été incorrectement analysée par Flex Pitch.
