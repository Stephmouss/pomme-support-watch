# Utilisation des préréglages et des modes de référence avec votre écran Apple

Découvrez comment utiliser les préréglages d’utilisation générale et les modes de référence inclus avec certains MacBook ou écrans Apple, et comment créer des modes de référence personnalisés adaptés aux besoins spécifiques de vos flux de travail.

- [Choisir un préréglage ou un mode de référence](https://support.apple.com/fr-fr/108321#choose)

- [Choisir des préréglages ou des modes de référence favoris](https://support.apple.com/fr-fr/108321#favorite)

- [En savoir plus sur les préréglages et les modes de référence](https://support.apple.com/fr-fr/108321#learn)

- [Créer des modes de référence personnalisés](https://support.apple.com/fr-fr/108321#custom)

Le MacBook Pro, le MacBook Pro avec écran PROLED XDR, le Studio Display XDR, le Studio Display et le Pro Display XDR incluent plusieurs préréglages et modes de référence qui couvrent les flux de production de création de contenu typiques pour plusieurs types de médias. Si vous avez un flux opérationnel personnalisé pour les couleurs, vous pouvez créer des modes de référence personnalisés adaptés à vos besoins.

## Choisir un préréglage ou un mode de référence

Pour choisir un préréglage ou un mode de référence dans Réglages du système (ou Préférences Système) :

- Dans le menu Apple , choisissez Réglages Système (ou Préférences Système).

- Cliquez sur Moniteurs.

- Si plusieurs écrans sont connectés :

- Sous macOS Ventura 13 ou version ultérieure, sélectionnez l’écran en haut de la fenêtre Moniteurs.

- Dans les versions antérieures de macOS, cliquez sur Réglages d’affichage, puis sélectionnez l’écran dans la barre latérale.

- Dans le menu local Préréglage, choisissez un préréglage ou un mode de référence.

Vous pouvez également choisir un préréglage ou un mode de référence dans le centre de contrôle :

- Cliquez sur l’icône du centre de contrôle dans la barre des menus.

[Image: Aucun texte de remplacement pour l’image]

- Cliquez sur Écran.

- Cliquez sur le bouton avec flèche en regard de l’écran avec lequel vous souhaitez utiliser le préréglage ou mode de référence, puis sélectionnez un mode. Pour passer rapidement d’un mode à l’autre, choisissez les préréglages ou modes de référence que vous souhaitez afficher dans le centre de contrôle.

[Image: Aucun texte de remplacement pour l’image]

Les réglages True Tone, Night Shift et Luminosité automatique, le curseur de luminosité et les contrôles de la luminosité par le clavier peuvent ne pas être disponibles avec le mode sélectionné.

## Choisir vos préréglages ou modes de référence préférés

Vous pouvez choisir les préréglages ou modes de référence qui apparaissent dans la section Moniteur du centre de contrôle :

- Dans le menu Apple , choisissez Réglages Système (ou Préférences Système).

- Cliquez sur Moniteurs.

- Si plusieurs écrans sont connectés :

- Sous macOS Ventura 13 ou version ultérieure, sélectionnez l’écran en haut de la fenêtre Moniteurs.

- Dans les versions antérieures de macOS, cliquez sur Réglages d’affichage, puis sélectionnez l’écran dans la barre latérale.

- Cliquez sur le menu local Préréglage, puis sélectionnez Personnaliser les préréglages.

- Dans la colonne « Afficher dans le menu », sélectionnez les préréglages ou modes de référence que vous souhaitez afficher dans le centre de contrôle, puis cliquez sur Terminé.

## Informations sur les préréglages et les modes de référence

Les préréglages ou modes de référence inclus avec votre écran répondent aux exigences de production vidéo HDR, HD, SD et de bien d’autres types de support. Chacun de ces modes configure l’espace colorimétrique, le point blanc, le gamma et la luminosité de votre écran.

### Préréglages d’usage général

#### Écran Apple XDR (espace colorimétrique P3 et luminosité de 2 000 nits)

Sur le Studio Display XDR et le MacBook Pro avec écran PROLED XDR, utilisez ce mode pour les environnements domestiques et professionnels classiques. Il se base sur la large gamme de couleurs P3 utilisée par les écrans Apple et intègre une gamme dynamique élevée offrant jusqu’à 2 000 nits de luminosité.

#### Écran Apple XDR (espace colorimétrique P3 + Adobe RGB et luminosité de 2 000 nits)

Sur le Studio Display XDR et le MacBook Pro avec écran PROLED XDR, utilisez ce mode pour les environnements domestiques et professionnels classiques. Ce mode se base à la fois sur la gamme de couleurs P3 et Adobe RGB afin de prendre en charge divers flux opérationnels créatifs et de productivité, et offre une prise en charge de la plage dynamique élevée (HDR) avec une luminosité pouvant atteindre 2 000 nits.

#### Écran Apple XDR (espace colorimétrique P3 et luminosité de 1 600 nits)

Sur le MacBook Pro, utilisez ce mode pour les environnements personnels et professionnels en général. Il se base sur la large gamme de couleurs P3 utilisée par les écrans Apple et intègre la technologie XDR (gamme dynamique extrême) offrant jusqu’à 1 600 nits de luminosité.

#### Pro Display XDR (espace colorimétrique P3 et luminosité de 1 600 nits)

Sur le Pro Display XDR, utilisez ce mode pour les environnements personnels et professionnels en général. Il se base sur la large gamme de couleurs P3 utilisée par les écrans Apple et intègre la technologie XDR (gamme dynamique extrême) offrant jusqu’à 1 600 nits de luminosité.

#### Écran Apple (espace colorimétrique P3 et luminosité de 500 nits)

Ce mode est destiné aux environnements personnels et professionnels en général. Il se base sur la large gamme de couleurs P3 et offre une plage de luminosité pouvant atteindre 500 nits, caractéristique des écrans intégrés Apple.

#### Écran Apple (espace colorimétrique P3 et luminosité de 600 nits)

Ce mode est destiné aux environnements personnels et professionnels en général. Il se base sur la large gamme de couleurs P3 et offre une plage de luminosité pouvant atteindre 600 nits, caractéristique des écrans intégrés Apple.

### Modes de référence

#### Vidéo HDR (espace colorimétrique P3 et fonction de transfert ST 2084)

Utilisez ce mode sur le MacBook Pro, le MacBook Pro avec écran PROLED XDR, le Pro Display XDR ou le Studio Display XDR pour les flux de production vidéo 4K ou ultra-haute définition jusqu’à 1¬000¬nits (plein écran en continu), faisant appel aux couleurs primaires P3 à large gamme et à l’EOTF SMPTE ST-2084 à plage dynamique élevée. Par ailleurs, ce mode a été conçu pour des conditions d’éclairage contrôlées configurées conformément à la recommandation BT.2100 du secteur des radiocommunications de l’UIT.

#### Vidéo HDTV (recommandations BT.709 et BT.1886)

Ce mode est destiné à la production vidéo haute définition dans le cadre des recommandations BT.709 et BT.1886 de l’UIT. Il a été conçu pour des conditions d’éclairage contrôlées configurées conformément à la recommandation BT.2035 du secteur des radiocommunications de l’UIT.

#### Vidéo NTSC (BT.601 SMPTE-C)

Ce mode est destiné à la production de vidéos d’archive ou au format standard, dans le cadre de la recommandation BT.601 de l’UIT et de l’espace colorimétrique SMPTE-C. Il a été conçu pour des conditions d’éclairage contrôlées configurées conformément à la recommandation BT.2035 du secteur des radiocommunications de l’UIT.

#### Vidéo PAL et SECAM (recommandation BT.601 et espace colorimétrique EBU)

Ce mode est destiné à la production de vidéos d’archive ou au format standard, dans le cadre de la recommandation BT.601 de l’UIT et de l’espace colorimétrique Tech 3213 de l’EBU. Il a été conçu pour des conditions d’éclairage contrôlées configurées conformément à la recommandation BT.2035 du secteur des radiocommunications de l’UIT.

#### Cinéma numérique (espace colorimétrique DCI-P3)

Utilisez ce mode pour les flux de travail de cinéma et de postproduction utilisant l’espace colorimétrique de cinéma P3 et le point blanc de cinéma numérique. Il a été conçu pour des conditions d’éclairage contrôlées configurées conformément à la recommandation SMPTE RP 431-2:2011.

#### Cinéma numérique (espace colorimétrique P3 et point blanc D65)

Utilisez ce mode pour les flux de travail de cinéma et de postproduction utilisant l’espace colorimétrique de cinéma P3 avec le point blanc D65. Il a été conçu pour des conditions d’éclairage contrôlées configurées conformément à la recommandation SMPTE RP 431-2:2011.

#### Graphisme et impression (espace colorimétrique P3 et point blanc D50)

Ce mode est destiné aux domaines de la conception graphique, de l’impression et de l’édition. Il se base sur l’espace colorimétrique P3 et offre une gamme de couleurs plus étendue qu’avec un écran sRGB classique. Au lieu du D65, il utilise le point blanc D50 généralement utilisé pour évaluer la couleur des sorties imprimées et est conçu pour des environnements de visualisation contrôlés conformément aux spécifications ISO 3664 : 2009.

#### Conception graphique et impression (Adobe RGB et point blanc D50)

Sur le Studio Display XDR et le MacBook Pro avec écran PROLED XDR, utilisez ce mode pour les processus de conception graphique, d’impression et de publication qui utilisent les couleurs primaires Adobe RGB. Il se base sur l’espace colorimétrique Adobe RGB et offre une gamme de couleurs plus étendue qu’avec un écran sRGB classique. Au lieu du D65, il utilise le point blanc D50 généralement utilisé pour évaluer la couleur des sorties imprimées et est conçu pour des environnements de visualisation contrôlés conformément aux spécifications ISO 3664 : 2009.

#### Photographie HDR (espace colorimétrique P3 et point blanc D65)

Sur le Studio Display XDR et le MacBook Pro avec écran PROLED XDR, utilisez ce mode pour les flux de production habituels de photographie numérique HDR. Ce mode utilise les primaires P3 à large gamme de couleurs avec le point blanc D65 généralement utilisé pour l’affichage sur écran et est conçu pour des environnements de visualisation correctement configurés et contrôlés.

#### Photographie (espace colorimétrique P3 et point blanc D65)

Ce mode est typiquement destiné à la photographie numérique SDR. Ce mode utilise les primaires P3 à large gamme de couleurs avec le point blanc D65 généralement utilisé pour l’affichage sur écran et est conçu pour des environnements de visualisation correctement configurés et contrôlés.

#### Photographie (Adobe RGB et point blanc D65)

Sur le Studio Display XDR et le MacBook Pro avec écran PROLED XDR, utilisez ce mode pour les flux de production habituels de photographie numérique HDR. Ce mode utilise les couleurs primaires Adobe RGB avec le point blanc D65 généralement utilisé pour la visualisation sur écran et est conçu pour des environnements de visualisation correctement configurés et contrôlés.

#### Internet et Web (espace colorimétrique sRGB)

Ce mode est destiné à la création de contenus conçus pour le Web ou d’autres usages en ligne. Il se base sur l’espace colorimétrique sRGB (voir norme IEC 61966-2-1:1999), largement compatible, conformément à la recommandation de niveau 3 applicable au module de couleurs CSS W3C. Il a été conçu pour des conditions d’éclairage contrôlées correctement configurées (une intensité lumineuse de 64 lux est recommandée).

#### Imagerie médicale (DICOM - 350 nits)

Sur le Studio Display XDR et le MacBook Pro avec écran PROLED XDR*, utilisez ce mode pour les flux de travail d’imagerie médicale qui suivent les recommandations de l’AAPM TG270 pour la radiologie générale. Ce mode, qui utilise la fonction de transfert DICOM-GSDF, est conçu pour un environnement de visionnage contrôlé de 25 lux, avec un rapport de luminance de 350:1 et une luminance maximale de 350 nits.

#### Imagerie médicale (DICOM - 600 nits)

Sur le Studio Display XDR et le MacBook Pro avec écran PROLED XDR*, utilisez ce mode pour les processus d’imagerie médicale qui suivent les recommandations de l’AAPM TG18. Ce mode, qui utilise la fonction de transfert DICOM-GSDF, est conçu pour un environnement de visionnage contrôlé de 25 lux, avec un rapport de luminance de 600:1 et une luminance maximale de 600 nits.

## Créer des modes de référence personnalisés

Les utilisateurs et les utilisatrices avancé(e)s peuvent créer des modes de référence personnalisés adaptés aux besoins de flux opérationnel uniques grâce à différentes options de gamme de couleurs, de point blanc, de luminance et de fonction de transfert. [Obtenez des informations supplémentaires sur les options avancées que vous pouvez configurer pour les modes de référence personnalisés](https://support.apple.com/guide/mac-help/mchl50ecf3c4) .

### Création d’un mode de référence personnalisé

- Dans le menu Apple , choisissez Réglages Système (ou Préférences Système).

- Cliquez sur Moniteurs.

- Si plusieurs écrans sont connectés :

- Sous macOS Ventura 13 ou version ultérieure, sélectionnez l’écran en haut de la fenêtre Moniteurs.

- Dans les versions antérieures de macOS, cliquez sur Réglages d’affichage, puis sélectionnez l’écran dans la barre latérale.

- Sélectionnez le menu local Préréglages, puis Personnaliser.

- Cliquez sur le bouton Ajouter , puis personnalisez les réglages pour votre mode de référence.

[Image: Aucun texte de remplacement pour l’image]

- Saisissez un nom et une description pour votre mode de référence, puis cliquez sur Enregistrer le préréglage.

### Importation et exportation de modes de référence personnalisés

- Dans le menu Apple , choisissez Réglages Système (ou Préférences Système).

- Cliquez sur Moniteurs.

- Si plusieurs écrans sont connectés :

- Sous macOS Ventura 13 ou version ultérieure, sélectionnez l’écran en haut de la fenêtre Moniteurs.

- Dans les versions antérieures de macOS, cliquez sur Réglages d’affichage, puis sélectionnez l’écran dans la barre latérale.

- Cliquez sur le menu local Préréglages, choisissez Personnaliser, puis effectuez l’une des opérations suivantes :

- Pour importer un mode de référence, sélectionnez le menu Action , choisissez Importer, sélectionnez le fichier que vous souhaitez importer, puis cliquez sur Ouvrir.

[Image: Aucun texte de remplacement pour l’image]

- Pour exporter un mode de référence, choisissez-en un, sélectionnez le menu Action , choisissez Exporter, puis cliquez sur Enregistrer.

[Image: Aucun texte de remplacement pour l’image]
