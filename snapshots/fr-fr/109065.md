# Identification de la version du logiciel de votre iPhone, iPad ou iPod touch

Utilisez votre appareil ou un ordinateur pour trouver la version d’iOS sur votre iPhone ou iPod touch, ou la version d’iPadOS sur votre iPad.

## Trouver la version du logiciel sur votre appareil

- Ouvrez Réglages.

- Touchez Général.

- Touchez Informations.

- Trouvez la version du logiciel à côté de Version d’iOS ou Version d’iPadOS.

[Image: L’écran Informations dans Réglages sur iPhone, avec la version d’iOS indiquant 27.0.]

## Trouver la version du logiciel à l’aide d’un ordinateur

- Ouvrez l’app correspondant à votre ordinateur :

- Le Finder sur un Mac doté de [macOS Catalina ou version ultérieure](https://support.apple.com/fr-fr/109033#latest)

- iTunes sur un Mac doté de [macOS Mojave ou version antérieure](https://support.apple.com/fr-fr/109033#latest)

- iTunes ou l’ [app Appareils Apple](https://support.apple.com/en-euro/guide/devices-windows/welcome/windows) sur un PC Windows

- Connectez votre appareil à votre ordinateur.

- Sélectionnez votre appareil. Si votre appareil n’apparaît pas, [obtenez de l’aide pour le connecter à votre ordinateur](https://support.apple.com/fr-fr/108643) .

- Trouvez la version du logiciel dans l’onglet Général du Finder ou de l’app Appareils Apple, ou dans l’onglet Résumé d’iTunes.

[Image: L’onglet Général dans le Finder pour un iPhone connecté, avec Logiciel : iOS 27.0 en surbrillance.]
