# Télécharger et installer macOS

Utilisez l’une de ces méthodes pour télécharger et installer la version actuelle ou une version antérieure du système d’exploitation Mac sur les ordinateurs Mac compatibles. Chaque version de macOS comprend les dernières apps intégrées disponibles pour cette version, notamment Safari, Mail et Apple Music (anciennement iTunes).

- [Utiliser Mise à jour de logiciels](https://support.apple.com/fr-fr/102662#softwareupdate)

- [Utiliser la fonctionnalité de récupération de macOS](https://support.apple.com/fr-fr/102662#recovery)

- [Utiliser l’App Store](https://support.apple.com/fr-fr/102662#appstore)

- [Utiliser un navigateur web pour les versions plus anciennes](https://support.apple.com/fr-fr/102662#browser)

- [Utiliser Terminal](https://support.apple.com/fr-fr/102662#terminal)

- [Utiliser un programme d’installation amorçable](https://support.apple.com/fr-fr/102662#bootable)

- [Vérifier la compatibilité macOS](https://support.apple.com/fr-fr/102662#compatibility)

## Utiliser Mise à jour de logiciels

La fonctionnalité Mise à jour de logiciels est le moyen le plus rapide et le plus simple d’obtenir des mises à jour et des mises à niveau de macOS. Elle peut par ailleurs nécessiter moins d’espace de stockage pour les télécharger et les installer. Mise à jour de logiciels affiche uniquement le logiciel compatible avec votre Mac. Si cette fonctionnalité indique que votre Mac est à jour, alors aucun nouveau logiciel n’est actuellement disponible pour votre Mac.

[Mettre à jour ou mettre à niveau macOS à l’aide de Mise à jour de logiciels](https://support.apple.com/fr-fr/108382)

## Utiliser la fonctionnalité de récupération de macOS

Si vous souhaitez réinstaller macOS, si l’installation à l’aide de Mise à jour de logiciels a échoué ou si votre [Mac ne démarre pas complètement](https://support.apple.com/fr-fr/102675) parce qu’il n’a pas de système d’exploitation fonctionnel, vous pouvez démarrer à partir de Récupération macOS, puis réinstaller macOS à partir de là.

[Réinstallation de macOS à l’aide de la fonctionnalité de récupération de macOS](https://support.apple.com/fr-fr/102655)

## Utiliser l’App Store

- Vérifiez que le Mac que vous utilisez pour télécharger macOS est [compatible avec cette version de macOS](https://support.apple.com/fr-fr/102662#compatibility) .

- Si vous téléchargez macOS pour [créer un programme d’installation amorçable](https://support.apple.com/fr-fr/102662#bootable) , vérifiez que votre Mac utilise macOS Mojave 10.14 ou version ultérieure.

- Utilisez ces liens pour trouver macOS dans l’App Store. Si ces liens ne fonctionnent pas comme prévu, réessayez en utilisant Safari, qui se trouve dans le dossier Applications.

- Tahoe 26 (utilisez [Mise à jour de logiciels](https://support.apple.com/fr-fr/102662#softwareupdate) ou [Terminal](https://support.apple.com/fr-fr/102662#terminal) )

- [Sequoia 15](macappstores://apps.apple.com/app/macos-sequoia/id6596773750?mt=12)

- [Sonoma 14](macappstores://apps.apple.com/app/macos-sonoma/id6450717509?mt=12)

- [Ventura 13](macappstores://apps.apple.com/app/macos-ventura/id1638787999?mt=12)

- [Monterey 12](macappstores://apps.apple.com/app/macos-monterey/id1576738294?mt=12)

- [Big Sur 11](macappstores://apps.apple.com/app/macos-big-sur/id1526878132?mt=12)

- [Catalina 10.15](macappstores://apps.apple.com/app/macos-catalina/id1466841314?mt=12)

- [Mojave 10.14](macappstores://apps.apple.com/app/macos-mojave/id1398502828?mt=12)

- [High Sierra 10.13](macappstores://apps.apple.com/app/macos-high-sierra/id1246284741?mt=12)

- Cliquez sur le bouton Obtenir dans l’App Store pour commencer le téléchargement.

- Si la mise à jour logicielle s’ouvre et vous demande si vous souhaitez télécharger macOS, autorisez le téléchargement.

- Si la version de macOS que vous essayez de télécharger n’est pas compatible avec votre Mac, le bouton Obtenir peut apparaître grisé dans l’App Store, ou un message peut indiquer que cette version de macOS n’est pas compatible avec cet appareil ou que la version de macOS demandée n’est pas disponible.

- Une fois que le téléchargement dans le dossier Applications est terminé, le programme d’installation s’ouvre automatiquement. Suivez les instructions d’installation qui s’affichent à l’écran. Vous pouvez également quitter sans effectuer l’installation, ce qui vous permet de conserver le programme d’installation dans le dossier Applications afin de l’utiliser ultérieurement.

## Utiliser un navigateur web pour les versions plus anciennes

- Vérifiez que le Mac que vous utilisez pour télécharger macOS est compatible avec ce macOS. Dans le cas contraire, vous ne pourrez pas effectuer ces étapes.

- Utilisez ces liens pour télécharger un fichier d’image disque pour macOS (.dmg). Si ces liens ne fonctionnent pas comme prévu, réessayez en utilisant Safari, qui se trouve dans le dossier Applications.

- [Sierra 10.12](http://updates-http.cdn-apple.com/2019/cert/061-39476-20191023-48f365f4-0015-4c41-9f44-39d3d2aca067/InstallOS.dmg)

- [El Capitan 10.11](http://updates-http.cdn-apple.com/2019/cert/061-41424-20191024-218af9ec-cf50-4516-9011-228c78eda3d2/InstallMacOSX.dmg)

- [Yosemite 10.10](http://updates-http.cdn-apple.com/2019/cert/061-41343-20191023-02465f92-3ab5-4c92-bfe2-b725447a070d/InstallMacOSX.dmg)

- [Mountain Lion 10.8](https://updates.cdn-apple.com/2021/macos/031-0627-20210614-90D11F33-1A65-42DD-BBEA-E1D9F43A6B3F/InstallMacOSX.dmg)

- [Lion 10.7](https://updates.cdn-apple.com/2021/macos/041-7683-20210614-E610947E-C7CE-46EB-8860-D26D71F0D3EA/InstallMacOSX.dmg)

- Par défaut, Safari télécharge l’image disque dans votre dossier Téléchargements. Vous pouvez alors l’ouvrir à partir du Dock ou en choisissant Téléchargements dans le menu Aller du Finder. [En savoir plus sur le téléchargement d’éléments à l’aide de Safari](https://support.apple.com/guide/safari/sfri40598/mac) .

- Double-cliquez sur le fichier .dmg pour l’ouvrir et voir le fichier .pkg qu’il contient.

- Double-cliquez sur le fichier .pkg, puis suivez les instructions qui s’affichent à l’écran pour installer le programme d’installation de macOS dans le dossier Applications.

- Ouvrez le dossier Applications et double-cliquez sur le programme d’installation de macOS, nommé Installer [ nom de la version ]. Suivez les instructions d’installation qui s’affichent à l’écran.

## Utiliser Terminal

Vous pouvez utiliser Terminal pour télécharger le programme d’installation des versions de macOS compatibles, à condition qu’elles ne soient pas antérieures à la version fournie avec votre Mac, ou celui de la version la plus proche encore disponible.

- Assurez-vous que votre Mac est doté de macOS Catalina 10.15 ou d’une version ultérieure.

- Ouvrez Terminal, qui se trouve dans le sous-dossier Utilitaires du dossier Applications. Vous pouvez également rechercher et ouvrir cette app à l’aide de Spotlight dans la barre des menus.

[Image: null]

- Entrez la commande suivante dans Terminal, en remplaçant <number> par le [numéro de la dernière version de macOS](https://support.apple.com/fr-fr/109033#latest) compatible que vous souhaitez télécharger : softwareupdate --fetch-full-installer --full-installer-version <number>

- Exemple : softwareupdate --fetch-full-installer --full-installer-version 26.1

- Exemple : softwareupdate --fetch-full-installer --full-installer-version 15.7.2

- Appuyez sur la touche Retour pour valider la commande. À mesure que macOS se télécharge dans le dossier Applications, Terminal indique la progression de l’installation (téléchargement) sous forme de pourcentage. Si Terminal indique que la mise à jour est introuvable, cela signifie que cette version de macOS n’est pas disponible pour votre Mac. Vous pouvez entrer la commande softwareupdate --list-full-installers pour obtenir la liste des versions de macOS actuellement disponibles pour votre Mac.

- Lorsque Terminal indique que l’installation est terminée, le téléchargement est terminé. Ouvrez le dossier Applications et double-cliquez sur le programme d’installation de macOS, nommé Installer [ nom de la version ], puis suivez les instructions qui s’affichent à l’écran pour procéder à l’installation. Vous pouvez aussi conserver le programme d’installation dans le dossier Applications afin de l’utiliser ultérieurement.

## Utiliser un programme d’installation amorçable

Un programme d’installation amorçable peut s’avérer utile quand vous souhaitez installer macOS sur plusieurs ordinateurs sans télécharger le programme d’installation à chaque fois, ou lorsque vous ne pouvez pas l’installer à l’aide de la fonctionnalité de récupération de macOS ou en utilisant les autres méthodes.

Pour télécharger un programme d’installation permettant de créer un programme d’installation démarrable, suivez les étapes de cet article afin de procéder au téléchargement via l’App Store, un navigateur web ou Terminal sur un Mac compatible.

[Création d’un programme d’installation amorçable pour macOS](https://support.apple.com/fr-fr/101578)
