# À propos de la technologie de sécurité avancée Touch ID

Découvrez comment Touch ID vous aide à protéger les informations de votre iPhone, iPad et Mac.

Nous stockons une grande partie de notre vie numérique sur nos appareils Apple. C’est pourquoi nous vous recommandons de toujours utiliser un code d’accès ou un mot de passe pour mieux protéger ces informations importantes ainsi que la confidentialité de vos données. Le recours à Touch ID sur votre iPhone, iPad ou Mac vous permet d’utiliser facilement vos empreintes digitales plutôt qu’un mot de passe pour de nombreuses opérations courantes. Grâce à un simple contact du doigt, le capteur analyse rapidement votre empreinte et déverrouille automatiquement votre appareil. Vous pouvez utiliser cette technologie pour effectuer des achats dans l’iTunes Store, l’App Store et Apple Books, ou encore avec Apple Pay. Les développeurs peuvent également vous autoriser à utiliser Touch ID pour vous connecter à leurs applications.

## Technologies avancées

Les composants matériels et logiciels utiles au fonctionnement de Touch ID constituent le nec plus ultra. Le bouton est composé de cristal de saphir, l’un des matériaux les plus purs et résistants au monde. Celui-ci sert à la fois de protection au capteur et permet de faire le point sur votre empreinte. Le bouton de l’iPhone et de l’iPad est doté d’un anneau en acier qui détecte la présence de votre doigt et indique à Touch ID d’analyser votre empreinte digitale.

Le capteur de toucher capacitif avancé permet de capturer des images en haute résolution de petites sections de votre empreinte, collectées sur les couches inférieures de votre peau. Touch ID analyse ensuite ces informations avec un très haut niveau de précision. Votre empreinte est associée à l’une des trois formes les plus courantes : en arc, en boucle ou en spirale. Le détail des lignes de votre empreinte (invisible à l’œil nu) est également enregistré. Leurs variations mineures, souvent causées par les pores de la peau, sont quant à elles scrupuleusement examinées.

Touch ID peut analyser plusieurs empreintes, quelle que soit leur orientation. Une représentation mathématique de votre empreinte est ensuite générée, puis comparée aux données d’identification digitale définies sur votre appareil, afin de déverrouiller ce dernier. Touch ID stocke uniquement cette représentation mathématique de votre empreinte ; jamais d’images de votre doigt. La représentation mathématique de votre empreinte digitale est mise à jour chaque fois que Touch ID la reconnaît, afin d’améliorer la précision de l’authentification.

## Fonctionnalités de sécurité

Chaque empreinte étant unique, il est peu probable que deux d’entre elles soient assez similaires, même en partie, pour que Touch ID les confonde. La probabilité d’une telle situation est de 1 sur 50 000 pour chaque empreinte enregistrée. En outre, Touch ID n’autorise que cinq tentatives d’identification par empreinte digitale avant de demander la saisie d’un code d’accès. En comparaison, la probabilité qu’un utilisateur devine votre code d’accès à 4 chiffres est de 1 sur 10 000. De plus, il arrive que certains codes à quatre chiffres, comme « 1234 », soient faciles à deviner. Les empreintes digitales, en revanche, vous protègent contre ce type de risques.

Pour commencer à utiliser Touch ID, vous devez d’abord créer un code d’accès sur votre iPhone ou iPad (ou un mot de passe sur votre Mac). Vous devez saisir votre code d’accès ou mot de passe (c’est une mesure de sécurité supplémentaire) :

- Après un redémarrage de votre iPhone, iPad ou Mac

- Lorsque plus de 48 heures se sont écoulées depuis le dernier déverrouillage de votre appareil

- Pour ajouter ou supprimer une empreinte digitale à utiliser avec Touch ID

- Pour modifier le code d’accès de votre iPhone ou iPad ou le mot de passe du système de votre Mac, ou pour modifier d’autres réglages de sécurité comme FileVault sur votre Mac

- Si les cinq tentatives d’identification d’affilée autorisées par Touch ID ont été atteintes

- Lorsque vous vous déconnectez de votre Mac

Pour plus de sécurité, vous pouvez choisir un mot de passe alphanumérique long et complexe. Sur votre iPhone ou iPad, touchez Options de code, puis sélectionnez Code alphanumérique personnalisé.

En cas de perte ou de vol de votre appareil, vous pouvez empêcher toute utilisation de Touch ID visant à déverrouiller votre appareil à l’aide du mode Perdu de Localiser. Votre iPhone et votre iPad offrent une protection supplémentaire contre le vol avec le verrouillage d’activation, qui nécessite un compte Apple et un mot de passe pour désactiver Localiser sur iPhone, effacer les données ou réactiver votre appareil. En cas de perte ou de vol de votre Mac avec Touch ID, l’effacement à distance de l’appareil désactive également Touch ID.

Vous pouvez également utiliser Touch ID pour acheter du contenu dans l’iTunes Store, l’App Store et Apple Books, au lieu de saisir le mot de passe de votre compte Apple.

Touch ID peut être utilisé par plusieurs utilisateurs sur un Mac, facilitant ainsi le partage d’un système en toute sécurité. Chaque compte utilisateur peut reconnaître jusqu’à trois empreintes, et le système peut reconnaître un total de cinq empreintes.

## Secure Enclave

La puce de votre appareil profite d’une architecture de sécurité avancée, appelée « Secure Enclave ». Celle-ci permet de protéger vos codes d’accès et vos données liées aux empreintes. Touch ID ne conserve aucune image de votre empreinte digitale. En revanche, elle s’appuie uniquement sur une représentation mathématique. Personne ne peut déterminer votre empreinte à partir de cette dernière.

Les données relatives à vos empreintes sont chiffrées, stockées sur disque et protégées par une clé, uniquement accessible via Secure Enclave. Touch ID utilise les données en question pour vérifier que votre empreinte correspond aux informations enregistrées sur l’appareil. Celles-ci ne sont pas accessibles via le système d’exploitation de votre appareil ou par toute application installée sur ce dernier. Elles ne sont jamais stockées sur les serveurs Apple, ni sauvegardées dans iCloud ou dans tout autre emplacement. Elles sont incompatibles avec les autres bases de données d’empreintes.
