# Serveur de mise à jour de logiciels : désactivation de la méthode TRACE d’Apache

Certains clients souhaitent désactiver la méthode TRACE d’Apache dans le serveur de mise à jour de logiciels.

Important : sauvegardez le fichier swupd.conf avant de le modifier.

Pour savoir comment modifier les fichiers de configuration sous OS X Server, consultez [cet](http://support.apple.com/kb/HT4850?viewlocale=fr_FR) article.

### Pour le serveur de mise à jour de logiciels sous OS X Server

- Désactivez le serveur de mise à jour de logiciels dans Server.app.

- Allez dans /Bibliothèque/Server/Software\ Update/Config/.

- Ouvrez le fichier swupd.conf.

- Ajoutez la commande « TraceEnable off » à la fin de la section « Global Environment » du fichier.

- Enregistrez le fichier au format texte.

- Démarrez le serveur de mise à jour de logiciels.

### Pour le serveur de mise à jour de logiciels sous Lion Server et Mac OS X Server 10.6.x

- Désactivez le serveur de mise à jour de logiciels dans Server.app ou Admin Serveur.

- Allez dans /private/etc/swupd/.

- Ouvrez le fichier swupd.conf dans un éditeur de texte.

- Ajoutez la commande « TraceEnable off » à la fin de la section « Global Environment » du fichier.

- Enregistrez le fichier au format texte.

- Démarrez le serveur de mise à jour de logiciels.
