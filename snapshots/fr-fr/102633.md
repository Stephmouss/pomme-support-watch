# Si vous avez oublié le mot de passe de connexion à votre Mac

Si vous ne vous souvenez pas du mot de passe de connexion à votre compte utilisateur Mac ou si le mot de passe ne fonctionne pas, suivez les étapes ci-dessous. Vous ne pouvez pas désactiver le mot de passe de connexion ni vous connecter à votre Mac sans celui-ci, mais il est possible que vous puissiez le réinitialiser.

[Image: Fenêtre d’ouverture de session macOS Sequoia avec une icône en forme de point d’interrogation à côté du champ du mot de passe.]

- [Redémarrer votre Mac](https://support.apple.com/fr-fr/102633#restart)

- [Saisir le mot de passe de votre compte utilisateur Mac](https://support.apple.com/fr-fr/102633#enterpassword)

- [Utiliser les options de réinitialisation de la fenêtre de connexion](https://support.apple.com/fr-fr/102633#resetfromlogin)

- [Utiliser les options de réinitialisation de la fonctionnalité de récupération](https://support.apple.com/fr-fr/102633#resetfromrecovery)

- [Si vous n’avez pas votre clé de secours](https://support.apple.com/fr-fr/102633#nokey)

- [Si vous ne parvenez pas à réinitialiser votre mot de passe de connexion](https://support.apple.com/fr-fr/102633#noreset)

## Redémarrer votre Mac

Redémarrez votre Mac. Si vous ne voyez aucune option de redémarrage, maintenez le bouton d’alimentation de votre Mac (ou Touch ID) enfoncé pendant 10 secondes, jusqu’à ce que votre Mac s’éteigne. Ensuite, rallumez-le.

Votre Mac devrait maintenant démarrer et afficher la fenêtre d’ouverture de session. Si votre Mac ne démarre pas jusqu’à la fenêtre d’ouverture de session et reste bloqué sur un autre écran, par exemple un écran vide, un écran du verrouillage d’activation ou un symbole de verrouillage, [découvrez comment procéder si votre Mac ne démarre pas complètement](https://support.apple.com/fr-fr/102675) .

## Saisir le mot de passe de votre compte utilisateur Mac

Lorsque votre Mac démarre et affiche la fenêtre de connexion, saisissez le mot de passe que vous utilisez pour vous connecter à votre compte utilisateur Mac.

- Saisissez votre mot de passe de connexion Mac, et non le mot de passe, l’adresse e-mail ou le numéro de téléphone associé à votre compte Apple.

- Utilisez les caractères majuscules ou minuscules appropriés de votre mot de passe. Si la touche de verrouillage des majuscules est activée sur votre clavier, le champ de saisie du mot de passe affiche un symbole Verrouillage des majuscules .

[Image: symbole Verrouillage des majuscules]

- Vérifiez le menu Saisie dans le coin de la fenêtre de connexion pour vous assurer que votre clavier est réglé sur la bonne langue.

[Image: menu Saisie]

Si votre mot de passe de connexion ne fonctionne toujours pas, [utilisez les options de réinitialisation dans la fenêtre de connexion](https://support.apple.com/fr-fr/102633#resetfromlogin) .

Si votre appareil est déjà connecté à votre propre compte utilisateur ou à un autre compte administrateur, vous pouvez plutôt [modifier votre mot de passe de connexion dans les réglages Utilisateurs et groupes](https://support.apple.com/guide/mac-help/mchlp1550/mac) .

## Utiliser les options de réinitialisation de la fenêtre de connexion

Si vous voyez un point d’interrogation à côté du champ de saisie de mot de passe, cliquez dessus. Vous pourrez alors voir l’un des éléments suivants :

[Image: point d’interrogation]

- Un indice sur le mot de passe (si vous avez ajouté un indice lors de la configuration de votre compte).

- Un message de réinitialisation, tel que « Redémarrer et afficher les options de réinitialisation de mot de passe » ou « Le réinitialiser à l’aide de votre clé de secours » ou « Le réinitialiser à l’aide de votre identifiant Apple ».

Si aucun message de réinitialisation ou point d’interrogation ne s’affiche :

- Réessayez après avoir saisi un mot de passe jusqu’à trois fois.

- Suivez ensuite les étapes ci-dessous, selon ce qui s’affiche : un [message de réinitialisation](https://support.apple.com/fr-fr/102633#showoptions) , un [message indiquant que votre compte est verrouillé](https://support.apple.com/fr-fr/102633#locked) ou [aucun message](https://support.apple.com/fr-fr/102633#nomessage) .

[Image: Options de réinitialisation du mot de passe à côté du champ de mot de passe dans la fenêtre d’ouverture de session.]

### Si vous voyez un message de réinitialisation

- Si la fenêtre de connexion affiche un message de réinitialisation, cliquez sur ce dernier pour commencer le processus de réinitialisation.

- Suivez les instructions à l’écran, qui varient en fonction de la configuration de votre Mac. À mesure que vous suivez les instructions :

- Si une invite de connexion à votre compte Apple s’affiche, saisissez l’adresse e-mail ou le numéro de téléphone associé(e) à votre compte Apple, puis saisissez le mot de passe correspondant (et non votre nom ou votre mot de passe de connexion). Il peut vous être demandé de saisir un code de validation envoyé à vos autres appareils. Vous pouvez ensuite sélectionner la personne pour laquelle réinitialiser le mot de passe.

- S’il vous est demandé de sélectionner un volume à récupérer, sélectionnez votre disque de démarrage, tel que Macintosh HD.

- S’il vous est demandé de sélectionner un utilisateur ou une utilisatrice dont vous connaissez le mot de passe, cliquez sur « Vous avez oublié tous les mots de passe ? ».

- S’il vous est demandé de saisir votre clé de secours FileVault, saisissez la chaîne de lettres et de chiffres qui compose la clé de secours. [Vous n’avez pas votre clé de secours ?](https://support.apple.com/fr-fr/102633#nokey)

- Si un message vous demande de désactiver ce Mac, autorisez votre Mac à se désactiver. Cette action est temporaire.

- Si un message vous demande de créer un nouveau trousseau pour stocker les mots de passe de l’utilisateur ou de l’utilisatrice, autorisez votre Mac à créer un nouveau trousseau.

- Une fois que vous aurez fourni les informations demandées, vous devrez créer un nouveau mot de passe pour votre compte. Vous pourrez ensuite redémarrer votre Mac et vous connecter avec le nouveau mot de passe.

Si vous n’avez pas pu suivre ces étapes pour réinitialiser votre mot de passe, [utilisez les options de réinitialisation de la fonctionnalité de récupération](https://support.apple.com/fr-fr/102633#resetfromrecovery) .

### Si vous voyez un message indiquant que votre compte est verrouillé

Si votre compte est verrouillé après des tentatives de connexion répétées, attendez que le temps indiqué soit écoulé, puis [redémarrez votre Mac](https://support.apple.com/fr-fr/102633#restart) et réessayez. Si le problème persiste, [utilisez les options de réinitialisation de la fonctionnalité de récupération](https://support.apple.com/fr-fr/102633#resetfromrecovery) .

### Si vous ne voyez aucun message

Si aucun message de réinitialisation n’apparaît dans la fenêtre de connexion après que vous avez tenté de saisir un mot de passe jusqu’à trois fois, [redémarrez votre Mac](https://support.apple.com/fr-fr/102633#restart) et réessayez. Si le problème persiste, [utilisez les options de réinitialisation de la fonctionnalité de récupération](https://support.apple.com/fr-fr/102633#resetfromrecovery) .

## Utiliser les options de réinitialisation de la fonctionnalité de récupération

Si vous n’avez pas pu réinitialiser votre mot de passe à l’aide des options de réinitialisation de la fenêtre de connexion :

- Suivez les étapes permettant de [démarrer à partir de Récupération macOS](https://support.apple.com/fr-fr/102518) .

- Lors du démarrage à partir de la fonctionnalité de récupération, un message vous demande de sélectionner un utilisateur ou une utilisatrice dont vous connaissez le mot de passe. Cliquez sur « Vous avez oublié tous les mots de passe ? ».

[Image: Fenêtre Récupération macOS affichant le message « Vous avez oublié tous les mots de passe ? » sous un nom d’utilisateur.]

- Suivez les instructions à l’écran, qui varient en fonction de la configuration de votre Mac. À mesure que vous suivez les instructions :

- Si une invite de connexion à votre compte Apple s’affiche, saisissez l’adresse e-mail ou le numéro de téléphone associé(e) à votre compte Apple, puis saisissez le mot de passe correspondant. Il peut vous être demandé de saisir un code de validation envoyé à vos autres appareils. Vous pouvez ensuite sélectionner la personne pour laquelle réinitialiser le mot de passe.

- S’il vous est demandé de saisir votre clé de secours FileVault, saisissez la chaîne de lettres et de chiffres qui compose la clé de secours. [Vous n’avez pas votre clé de secours ?](https://support.apple.com/fr-fr/102633#nokey)

- S’il vous est demandé de sélectionner un volume à récupérer, sélectionnez votre disque de démarrage, tel que Macintosh HD.

- Si un message vous demande de désactiver ce Mac, autorisez votre Mac à se désactiver. Cette action est temporaire.

- Lorsque vous avez terminé, cliquez sur Accéder à la fonctionnalité de récupération. Lorsque vous êtes en mode de récupération, des options de restauration à partir de Time Machine, de réinstallation de macOS, etc. sont visibles :

[Image: Fenêtre Utilitaires dans Récupération macOS.]

- Lorsque vous suivez les instructions précédentes, si une procédure de réinitialisation de votre mot de passe vous a été proposée et que vous avez pu la suivre, choisissez Redémarrer dans le menu Apple , puis connectez-vous à l’aide de votre nouveau mot de passe.

- Si aucune procédure de réinitialisation de votre mot de passe ne vous a été proposée ou si vous n’avez pas pu la suivre, choisissez Terminal dans le menu Utilitaires de la barre des menus.

- Dans la fenêtre Terminal qui s’ouvre, tapez resetpassword , puis appuyez sur Retour.

[Image: Fenêtre Terminal après la saisie de « resetpassword » dans l’invite de commande.]

- Dans la fenêtre qui s’ouvre, choisissez une option de réinitialisation, telle que « J’ai oublié mon mot de passe » ou « Je ne parviens pas à me connecter avec mon mot de passe ». Cliquez sur Suivant et suivez les instructions à l’écran.

[Image: Fenêtre Réinitialiser le mot de passe dans Récupération macOS]

- Une fois que vous aurez fourni les informations demandées, vous devrez créer un nouveau mot de passe pour votre compte et celui de tout autre utilisateur ou toute autre utilisatrice. Vous pourrez ensuite redémarrer votre Mac et vous connecter avec le nouveau mot de passe.

Si vous ne pouvez pas suivre ces étapes pour réinitialiser votre mot de passe, découvrez ce qu’il faut faire [si vous ne parvenez pas à réinitialiser votre mot de passe de connexion](https://support.apple.com/fr-fr/102633#noreset) .

## Si vous n’avez pas votre clé de secours

Une clé de secours FileVault est un code alphanumérique composé de 24 caractères. Cette clé diffère d’une [clé de secours de compte Apple](https://support.apple.com/fr-fr/109345) ; vous ne pouvez donc pas utiliser une clé de secours de compte Apple à la place d’une clé de secours FileVault.

Si le Mac qui demande la clé de secours FileVault utilise macOS Tahoe 26 ou une version ultérieure, la clé peut être disponible dans [l’app Mots de passe](https://support.apple.com/fr-fr/120758) sur l’un de vos autres appareils :

- Assurez-vous que votre autre appareil (iPhone, iPad ou Mac) est connecté au même compte Apple que le Mac qui demande votre clé de secours. Ouvrez ensuite Mots de passe sur cet appareil.

- Dans Mots de passe, saisissez « clé de secours » dans le champ de recherche.

- Si les résultats de la recherche incluent le nom du Mac qui demande votre clé de secours, sélectionnez-le, puis touchez ou cliquez sur les points dans le champ Clé de secours pour révéler la clé de ce Mac.

## Si vous ne parvenez pas à réinitialiser votre mot de passe de connexion

Si aucune autre solution ne fonctionne, vous pouvez récupérer l’accès à votre Mac en l’effaçant. Cela supprime définitivement chaque compte utilisateur, son mot de passe et ses données de votre Mac.

- Éteignez votre Mac, puis [redémarrez à partir de la fonctionnalité de récupération de macOS](https://support.apple.com/fr-fr/102518) . Lorsqu’un message vous demande de sélectionner un utilisateur ou une utilisatrice dont vous connaissez le mot de passe, choisissez Effacer ce Mac dans le menu Assistant de récupération, en haut de l’écran.

- Dans la fenêtre qui s’ouvre, cliquez sur Effacer le Mac, puis sur Effacer le Mac pour confirmer. Une fois votre Mac effacé, il redémarre automatiquement.

[Image: Fenêtre Effacer le Mac dans Récupération de macOS, avertissant que cette action supprimera l’ensemble du contenu multimédia, des données et des réglages de ce Mac.]

- Si votre Mac démarre en affichant un point d’interrogation, éteignez-le, redémarrez à partir de la fonctionnalité de récupération de macOS, puis [réinstallez macOS](https://support.apple.com/fr-fr/102655) à partir de la fonctionnalité de récupération.

- Si votre Mac démarre sur une fenêtre Activer le Mac, choisissez un réseau Wi-Fi dans le menu Wi-Fi , puis saisissez les informations de votre compte Apple (et non votre nom ou votre mot de passe de connexion) lorsqu’un message vous y invite.

[Image: null]

- Une fois votre Mac activé, cliquez sur Accéder à la fonctionnalité de récupération, puis [réinstallez macOS](https://support.apple.com/fr-fr/102655) à partir de la fonctionnalité de récupération.
