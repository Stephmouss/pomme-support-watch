# Si vous avez oublié le mot de passe de connexion à votre Mac

Si vous ne vous souvenez plus du mot de passe de connexion de votre Mac ou si celui-ci ne fonctionne pas, vous pourrez peut-être le réinitialiser.

[Image: Fenêtre de connexion de macOS Golden Gate avec une icône de point d’interrogation à côté du champ de mot de passe.]

## Redémarrer votre Mac

Redémarrez votre Mac. Si vous ne voyez aucune option de redémarrage, maintenez le bouton d’alimentation de votre Mac (ou Touch ID) enfoncé pendant 10 secondes, jusqu’à ce que votre Mac s’éteigne. Ensuite, rallumez-le.

Votre Mac devrait maintenant démarrer et afficher la fenêtre d’ouverture de session. Si l’ordinateur reste bloqué sur un autre écran, tel qu’un écran vide, l’écran Verrouillage d’activation ou un symbole de cadenas, [découvrez la marche à suivre si votre Mac ne démarre pas complètement](https://support.apple.com/fr-fr/102675) .

## Saisir le mot de passe de votre compte utilisateur Mac

Lorsque votre Mac démarre et affiche la fenêtre de connexion, saisissez le mot de passe que vous utilisez pour vous connecter à votre compte utilisateur Mac.

- Saisissez votre mot de passe de connexion Mac, et non le mot de passe, l’adresse e-mail ou le numéro de téléphone associé à votre compte Apple.

- Utilisez les caractères majuscules ou minuscules appropriés de votre mot de passe. Si la touche de verrouillage des majuscules est activée sur votre clavier, le champ de saisie du mot de passe affiche un symbole Verrouillage des majuscules .

[Image: symbole Verrouillage des majuscules]

- Vérifiez le menu Saisie dans le coin de la fenêtre de connexion pour vous assurer que votre clavier est réglé sur la bonne langue.

[Image: menu Saisie]

Si votre mot de passe de connexion ne fonctionne toujours pas, [utilisez les options de réinitialisation dans la fenêtre de connexion](https://support.apple.com/fr-fr/102633#resetfromlogin) .

Si vous êtes déjà connecté à votre propre compte d’utilisateur ou si vous pouvez vous connecter à un autre compte administrateur, vous pouvez plutôt [modifier votre mot de passe de connexion dans les réglages « Utilisateurs et groupes »](https://support.apple.com/guide/mac-help/mchlp1550/mac) .

## Utiliser les options de réinitialisation de la fenêtre de connexion

Si vous voyez un point d’interrogation à côté du champ de saisie de mot de passe, cliquez dessus. Vous pourrez alors voir l’un des éléments suivants :

[Image: point d’interrogation]

- Un indice sur le mot de passe (si vous avez ajouté un indice lors de la configuration de votre compte).

- Un message de réinitialisation, tel que « Réinitialiser le mot de passe » ou « Redémarrer et afficher les options de réinitialisation du mot de passe ».

Si aucun message de réinitialisation ou point d’interrogation ne s’affiche :

- Réessayez après avoir saisi un mot de passe jusqu’à trois fois.

- Procédez ensuite en fonction de ce qui s’affiche : un [message de réinitialisation](https://support.apple.com/fr-fr/102633#showoptions) , un [message indiquant que votre compte est verrouillé](https://support.apple.com/fr-fr/102633#locked) ou [aucun message](https://support.apple.com/fr-fr/102633#nomessage) .

### Si vous voyez un message de réinitialisation

- Si la fenêtre de connexion affiche un message de réinitialisation, tel que « Réinitialiser le mot de passe » ou « Redémarrer et afficher les options de réinitialisation du mot de passe », cliquez sur le message pour commencer le processus de réinitialisation.

- Suivez les instructions à l’écran, qui varient en fonction de la configuration de votre Mac.

- S’il vous est demandé de saisir votre clé de secours, saisissez les lettres et les chiffres de la clé de secours. Une clé de secours ne contient pas les lettres I (i) ou S, ni les chiffres 1 ou 0. [Vous n’avez pas votre clé de secours ?](https://support.apple.com/fr-fr/102633#nokey)

- Si une invite de connexion à votre compte Apple s’affiche, saisissez l’adresse e-mail ou le numéro de téléphone associé(e) à votre compte Apple, puis saisissez le mot de passe correspondant. Il peut vous être demandé de saisir un code de validation envoyé à vos autres appareils. Vous pouvez ensuite sélectionner la personne pour laquelle réinitialiser le mot de passe.

- S’il vous est demandé de sélectionner un volume à récupérer, sélectionnez votre disque de démarrage, tel que Macintosh HD.

- S’il vous est demandé de sélectionner un utilisateur ou une utilisatrice dont vous connaissez le mot de passe, cliquez sur « Vous avez oublié tous les mots de passe ? ».

- Si un message vous demande de désactiver ce Mac, autorisez votre Mac à se désactiver. Cette action est temporaire.

- Si un message vous demande de créer un nouveau trousseau pour stocker les mots de passe de l’utilisateur ou de l’utilisatrice, autorisez votre Mac à créer un nouveau trousseau.

- Une fois que vous aurez fourni les informations demandées, vous devrez créer un nouveau mot de passe pour votre compte. Vous pourrez ensuite redémarrer votre Mac et vous connecter avec le nouveau mot de passe.

Si vous n’avez pas pu suivre ces étapes pour réinitialiser votre mot de passe, [utilisez les options de réinitialisation de la fonctionnalité de récupération](https://support.apple.com/fr-fr/102633#resetfromrecovery) .

### Si vous voyez un message indiquant que votre compte est verrouillé

Si votre compte est verrouillé après des tentatives de connexion répétées, attendez que le temps indiqué soit écoulé, puis [redémarrez votre Mac](https://support.apple.com/fr-fr/102633#restart) et réessayez. Si le problème persiste, [utilisez les options de réinitialisation de la fonctionnalité de récupération](https://support.apple.com/fr-fr/102633#resetfromrecovery) .

### Si vous ne voyez aucun message

Si aucun message de réinitialisation n’apparaît dans la fenêtre de connexion après que vous avez tenté de saisir un mot de passe jusqu’à trois fois, [redémarrez votre Mac](https://support.apple.com/fr-fr/102633#restart) et réessayez. Si le problème persiste, [utilisez les options de réinitialisation de la fonctionnalité de récupération](https://support.apple.com/fr-fr/102633#resetfromrecovery) .

## Utiliser les options de réinitialisation de la fonctionnalité de récupération

Si vous n’avez pas pu réinitialiser votre mot de passe à l’aide des options de réinitialisation de la fenêtre de connexion, vous pourrez peut-être le réinitialiser à partir de Récupération macOS.

- Suivez les étapes permettant de [démarrer à partir de Récupération macOS](https://support.apple.com/fr-fr/102518) .

- Lorsqu’il vous est demandé de sélectionner un utilisateur dont vous connaissez le mot de passe, cliquez sur « Tous les mots de passe ont été oubliés ? ».

[Image: Fenêtre Récupération macOS affichant le message « Vous avez oublié tous les mots de passe ? » sous un nom d’utilisateur.]

- Suivez les instructions à l’écran, qui varient en fonction de la configuration de votre Mac.

- S’il vous est demandé de vous connecter au compte Apple précédemment utilisé avec ce Mac, saisissez l’adresse e-mail ou le numéro de téléphone de ce compte Apple, puis saisissez son mot de passe.

- S’il vous est demandé de saisir votre clé de secours, saisissez les lettres et les chiffres de la clé de secours. Une clé de secours ne contient pas les lettres I (i) ou S, ni les chiffres 1 ou 0. [Vous n’avez pas votre clé de secours ?](https://support.apple.com/fr-fr/102633#nokey)

- S’il vous est demandé de sélectionner un volume à récupérer, sélectionnez votre disque de démarrage, tel que Macintosh HD.

- Si un message vous demande de désactiver ce Mac, autorisez votre Mac à se désactiver. Cette action est temporaire.

- Cliquez sur Quitter la récupération lorsque vous voyez cette option. Vous êtes dans la fonctionnalité de récupération lorsque vous voyez des options pour restaurer à partir de Time Machine, réinstaller macOS, etc.

[Image: Fenêtre Utilitaires de la fonctionnalité de récupération de macOS.]

- Pendant le démarrage à partir de Récupération :

- S’il vous a été demandé de créer un mot de passe de connexion et que vous avez pu le faire, choisissez Redémarrer dans le menu Apple , puis connectez-vous avec votre nouveau mot de passe.

- S’il ne vous a pas été demandé de créer un mot de passe de connexion ou si vous n’avez pas pu le faire, passez à l’étape suivante en restant dans Récupération.

- Dans le menu Utilitaires de la barre de menus, choisissez Terminal.

- Dans la fenêtre qui s’ouvre, tapez resetpassword , puis appuyez sur Retour.

[Image: Fenêtre Terminal après la saisie de « resetpassword » dans l’invite de commande.]

- Dans la fenêtre qui s’ouvre, sélectionnez « J’ai oublié mon mot de passe » ou « Mon mot de passe ne fonctionne pas lorsque je me connecte ». Cliquez sur Suivant.

[Image: Fenêtre Réinitialiser le mot de passe dans Récupération macOS.]

- Une fois que vous aurez fourni les informations demandées, vous devrez créer un nouveau mot de passe pour votre compte et celui de tout autre utilisateur ou toute autre utilisatrice. Vous pourrez ensuite redémarrer votre Mac et vous connecter avec le nouveau mot de passe.

Si vous ne pouvez pas suivre ces étapes pour réinitialiser votre mot de passe, découvrez ce qu’il faut faire [si vous ne parvenez pas à réinitialiser votre mot de passe de connexion](https://support.apple.com/fr-fr/102633#noreset) .

## Si vous n’avez pas votre clé de secours

Une [clé de secours FileVault](https://support.apple.com/guide/mac-help/mh35880/mac) est un code alphanumérique de 24 caractères créé lorsque FileVault est activé. Elle est différente d’une [clé de secours de compte Apple](https://support.apple.com/fr-fr/109345) . Si vous n’avez pas votre clé de secours FileVault, mais que le Mac qui la demande utilise macOS Tahoe 26 ou une version ultérieure, la clé peut être disponible dans l’ [app Mots de passe](https://support.apple.com/fr-fr/120758) sur l’un de vos autres appareils, comme un iPhone, un iPad ou un autre Mac.

- Assurez-vous que votre autre appareil est connecté au même compte Apple que le Mac qui demande votre clé de secours. L’option [Mots de passe et trousseau iCloud doit également être activée](https://support.apple.com/fr-fr/109016) dans les réglages iCloud.

- Ouvrez l’app Mots de passe.

- Saisissez « clé de secours » dans le champ de recherche.

- Si les résultats de la recherche incluent le nom du Mac qui demande votre clé de secours, ouvrez cet élément. Touchez ou cliquez ensuite sur les points dans le champ Clé de secours pour afficher la clé de ce Mac.

[Image: Clé de secours FileVault pour un Mac dans l’app Mots de passe sur iPhone.]

Si vous ne parvenez toujours pas à trouver votre clé de secours, [utilisez les options de réinitialisation dans Récupération](https://support.apple.com/fr-fr/102633#resetfromrecovery) .

## Si vous ne parvenez pas à réinitialiser votre mot de passe de connexion

Si aucune autre solution ne fonctionne, vous pouvez récupérer l’accès à votre Mac en l’effaçant. Cela supprime définitivement chaque compte utilisateur, son mot de passe et ses données de votre Mac.

- Éteignez votre Mac.

- [Démarrez à partir de la fonctionnalité de récupération de macOS](https://support.apple.com/fr-fr/102518) . Lorsqu’il vous est demandé de sélectionner un utilisateur dont vous connaissez le mot de passe, choisissez Effacer le Mac dans le menu Assistant de récupération de la barre des menus.

- Dans la fenêtre qui s’ouvre, cliquez sur Effacer le Mac, puis sur Effacer le Mac pour confirmer. Une fois votre Mac effacé, il redémarre automatiquement.

[Image: Fenêtre Effacer le Mac dans Récupération de macOS, avertissant que cette action supprimera l’ensemble du contenu multimédia, des données et des réglages de ce Mac.]

- Si votre Mac démarre sur un point d’interrogation, éteignez votre Mac, puis [réinstallez macOS](https://support.apple.com/fr-fr/102655) à partir de Récupération.

- Si votre Mac démarre sur une fenêtre Activer le Mac :

- Si vous y êtes invité, choisissez un réseau Wi-Fi dans le menu Wi-Fi ou connectez un câble réseau.

- Saisissez les informations de votre compte Apple (et non votre nom d’utilisateur ou votre mot de passe) lorsque vous y êtes invité.

- Une fois votre Mac activé, cliquez sur Accéder à la fonctionnalité de récupération, puis [réinstallez macOS](https://support.apple.com/fr-fr/102655) à partir de la fonctionnalité de récupération.
