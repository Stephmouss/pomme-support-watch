# OS X Server : envoi d’invitations, de notifications et de messages d’alerte par e-mail lorsqu’un relais SMTP est requis

Des invitations, notifications ou messages d’alerte peuvent être envoyés par de nombreux services d’OS X Server. Ces derniers comprennent notamment les services associés à la mise en cache, aux certificats, au disque, au coupe-feu, à la messagerie, à la configuration réseau, au gestionnaire de profils, à la fonctionnalité Mises à jour de logiciels et à Time Machine.

Vous pouvez configurer OS X Server afin que celui-ci prenne en charge le serveur de relais SMTP fournis par votre FAI, le cas échéant.

Grâce à OS X Server, vous bénéficiez de deux serveurs SMTP intégrés : le serveur du service de messagerie d’OS X et le serveur Sendmail. Les invitations, notifications et messages d’alerte envoyés par e-mail sont transmis via le service de messagerie d’OS X Server, lorsque celui-ci est configuré et activé. Le serveur Sendmail est utilisé lorsque le service de messagerie d’OS X Server est désactivé.

Pour utiliser un relais SMTP, vous devez spécifier l’adresse de votre serveur SMTP et, le cas échéant, vos informations d’authentification lors de la configuration du serveur de messagerie d’OS X. Le service de messagerie d’OS X Server et le serveur Sendmail utilisent les mêmes réglages et fichiers de configuration :

- Ouvrez l’application Serveur.

- Dans la sous-fenêtre Mail, sélectionnez « Faire transiter le courrier sortant par le FAI ».

- Si cette option est déjà sélectionnée, cliquez sur le bouton Modifier. Un message vous invitant à saisir les informations de connexion associées à votre serveur de relais apparaît.

- Sélectionnez l’option « Faire transiter le courrier sortant par le FAI ».

- Cliquez sur le bouton Modifier.

- Saisissez le nom DNS ou l’adresse IP du serveur de relais.

- Si besoin, vous pouvez indiquer un numéro de port personnalisé. Pour ce faire, ajoutez deux-points après le nom d’hôte ou l’adresse IP, puis saisissez le numéro de port souhaité (exemple : 17.172.224.47:587 ou exemple.com:587). Vous pouvez désactiver la recherche dans les enregistrements Mail Exchange (MX) en saisissant votre adresse IP, ou votre nom d’hôte, entre crochets (exemple : [17.172.224.47] ou [exemple.com]).

- Si votre relais nécessite une authentification avant l’envoi des e-mails, sélectionnez « Activer l’authentification de relais SMTP », puis saisissez le nom d’utilisateur et le mot de passe requis. Si vous activez cette option, vos identifiants sont envoyés via la méthode d’authentification disponible la plus performante : CRAM-MD5, Digest-MD5 ou Kerberos.

Il n’est pas nécessaire de démarrer ou de redémarrer le service de messagerie d’OS X. Les réglages définis sont automatiquement appliqués au service de messagerie d’OS X Server et au serveur Sendmail.
