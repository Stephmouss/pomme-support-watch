# Utiliser Shazam sur des appareils Android

Utilisez Shazam pour identifier un morceau que vous entendez à la radio, dans un magasin, sur votre appareil (avec ou sans casque)… ou partout où vous entendez de la musique enregistrée.

Retrouvez vos Shazams précédents dans la Bibliothèque et écoutez des extraits pour découvrir de nouveaux titres. Créez un compte Shazam pour enregistrer tous vos Shazams, au cas où il arriverait quelque chose à votre appareil.

## Identifier de la musique avec Shazam

Pour identifier de la musique avec Shazam :

- Ouvrez l’app Shazam sur votre appareil, puis touchez le bouton Shazam .

[Image: Aucun texte de remplacement pour l’image]

- Touchez de manière prolongée l’app Shazam dans le tiroir d’apps, puis touchez Shazam maintenant.

Une fois que Shazam a identifié le morceau, celui-ci est enregistré dans votre Bibliothèque Shazam.

Après avoir identifié un morceau, vous pouvez vous connecter à Apple Music et à d’autres services de musique pour [écouter votre shazam](https://support.apple.com/HT210237) .

Même si vous ne disposez pas d’une connexion Internet, l’app crée une empreinte numérique unique pour rechercher le titre dans la base de données Shazam la prochaine fois que votre appareil sera connecté à Internet. Si un morceau ne peut pas être identifié, il disparaît de vos Shazams en attente.

### Utiliser Auto Shazam

Pour que Shazam identifie automatiquement la musique diffusée autour de vous, activez Auto Shazam en procédant comme suit :

- Touchez de manière prolongée l’app Shazam dans le tiroir d’apps, puis touchez Auto Shazam.

- Ouvrez l’app Shazam sur votre appareil, puis touchez de manière prolongée le bouton Shazam .

[Image: Aucun texte de remplacement pour l’image]

Lorsque la fonction Auto Shazam est activée, Shazam associe ce que vous entendez avec les morceaux de la base de données Shazam, même si vous basculez vers une autre app. Shazam n’enregistre ni ne stocke jamais ce qu’il entend.

Vous trouverez ensuite les Shazams identifiés avec Auto Shazam dans votre Bibliothèque, regroupés par date.

Pour désactiver l’option Auto Shazam, touchez le bouton Shazam.

### Utiliser Notification pour identifier la musique en effectuant un balayage et en touchant l’écran

Lorsque vous êtes dans une autre app, vous pouvez accéder à Shazam dans la barre de notification pour identifier de la musique :

- Effectuez un balayage vers le bas pour afficher Shazam dans la barre de notification.

- Touchez Shazam pour commencer à identifier de la musique.

- Pour fermer la notification, effectuez un balayage vers la Bibliothèque dans l’app Shazam, touchez le bouton Réglages , puis désactivez l’option « Shazam via la notification ».

[Image: Aucun texte de remplacement pour l’image]

### Utiliser Pop-Up Shazam pour identifier de la musique

- Ouvrez l’app Shazam, effectuez un balayage vers la Bibliothèque, puis touchez le bouton Réglages .

[Image: Aucun texte de remplacement pour l’image]

- Activez l’option « Shazam via Pop-Up », touchez Accéder aux paramètres, Shazam, puis activez « Autoriser la superposition d’applis ».

- Lorsque vous êtes dans une autre app, touchez le bouton Pop-Up Shazam pour identifier la musique diffusée dans cette app.

[Image: Aucun texte de remplacement pour l’image]

- Pour supprimer le bouton flottant, faites-le glisser vers le X en bas de l’écran.

Pour afficher de nouveau Pop-Up Shazam, effectuez un balayage depuis le haut de l’écran et touchez la notification. Si vous n’avez pas activé « Shazam via la notification », ouvrez l’app Shazam et Shazamez un morceau. Pendant que Shazam identifie un morceau, placez Shazam en arrière-plan. Le bouton Pop-up réapparaît à l’écran.

### Autres moyens d’identifier de la musique

- Utilisez Shazam sur votre appareil Wear OS.

- Dans les réglages Shazam, activez « Shazamer lorsque l’appli démarre » pour identifier automatiquement de la musique lorsque vous ouvrez l’app.

## Retrouver vos Shazams précédents

Vous pouvez retrouver vos Shazams précédents dans la Bibliothèque. Dans l’app Shazam, effectuez un balayage vers la Bibliothèque ou touchez le bouton Bibliothèque.

Pour supprimer un Shazam, touchez le bouton Plus à côté du Shazam en question dans la Bibliothèque, puis touchez « Supprimer de votre bibliothèque ».

[Image: Aucun texte de remplacement pour l’image]

Vous pouvez également [enregistrer vos Shazams](https://support.apple.com/fr-fr/118557#Save) afin de ne pas les perdre si quelque chose arrivait à votre appareil.

## Enregistrer vos Shazams

Pour enregistrer vos Shazams, créez un compte à l’aide d’un compte Google ou d’une adresse e-mail.

- Dans Shazam, effectuez un balayage vers la Bibliothèque, puis touchez le bouton Réglages .

[Image: Aucun texte de remplacement pour l’image]

- Touchez S’inscrire ou Se connecter.

- Pour vous connecter à l’aide d’un compte Google, touchez Se connecter avec Google, puis suivez les instructions.

- Pour vous connecter à l’aide d’une adresse e-mail :

- Touchez Se connecter avec une adresse e-mail, puis saisissez la vôtre.

- Consultez votre boîte mail depuis le même appareil, puis touchez Confirmer dans l’e-mail. Si vous n’avez pas reçu d’e-mail, touchez Renvoyer dans l’app Shazam, ou recommencez.

Pour accéder à vos précédents Shazams de n’importe où, utilisez le même compte pour vous connecter sur [www.shazam.com/fr/myshazam](https://www.shazam.com/fr/myshazam)

### Supprimer votre compte Shazam

- Dans Shazam, effectuez un balayage vers la Bibliothèque, puis touchez le bouton Réglages .

[Image: Aucun texte de remplacement pour l’image]

- Faites défiler la page jusqu’en bas, puis touchez Se déconnecter.

- Si vous utilisez Shazam sur d’autres appareils, déconnectez-vous de Shazam sur ces appareils.

- Consultez la page [shazam.com/fr/privacy](https://www.shazam.com/fr/privacy) .

- Faites défiler la page jusqu’en bas, puis touchez ou cliquez sur Supprimer votre compte.

- Connectez-vous avec le compte que vous souhaitez supprimer.

- Faites défiler la page Supprimer votre compte jusqu’en bas, puis cliquez sur Supprimer votre compte. Toute information personnelle provenant des services connectés sera supprimée dans les 30 jours.

### Obtenir une copie de vos données Shazam

- Consultez la page [shazam.com/fr/privacy](https://www.shazam.com/fr/privacy) .

- Touchez ou cliquez sur Télécharger vos données.

- Connectez-vous au compte pour lequel vous souhaitez obtenir une copie des données, puis suivez les instructions.

- Saisissez l’adresse e-mail à laquelle vous souhaitez que vos informations soient envoyées, puis cliquez sur « Envoyer mes données ». Vous recevrez vos données par e-mail sous 30 jours.
