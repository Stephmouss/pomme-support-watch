# Contrôle d’une présentation Keynote à l’aide de Keynote Remote

Vous pouvez contrôler votre présentation Keynote à partir d’un iPhone, iPad ou iPod touch via la fonctionnalité Keynote Remote.

- [Configuration système requise](https://support.apple.com/fr-fr/119886#req)

- [Jumelage de Keynote Remote avec votre Mac](https://support.apple.com/fr-fr/119886#linkmac)

- [Jumelage de Keynote Remote avec un autre iPhone ou iPad](https://support.apple.com/fr-fr/119886#linkios)

- [Utilisation de Keynote Remote](https://support.apple.com/fr-fr/119886#use)

## Configuration système requise

La fonctionnalité Keynote Remote est incluse dans Keynote pour iPhone et iPad. Voici ce dont vous avez besoin afin de contrôler votre présentation avec Keynote Remote :

- Un iPhone, iPad ou iPod touch doté de Keynote 2.1 ou version ultérieure pour iPhone ou iPad

- Un Mac équipé de Keynote pour Mac 6.1 ou version ultérieure

- Un appareil distant jumelé avec votre Mac ou un autre iPhone, iPad ou iPod touch

## Jumelage de Keynote Remote avec votre Mac

Vous pouvez lire votre présentation sur votre Mac et la contrôler à distance avec votre iPhone, iPad ou iPod touch.

- [Activez le Wi-Fi sur votre iPhone ou iPad](https://support.apple.com/HT202639) , ainsi que [sur votre Mac](https://support.apple.com/HT201974) .

- Ouvrez Keynote sur votre Mac.

- Dans la barre des menus, sélectionnez Keynote > Réglages (ou Préférences), cliquez sur Télécommandes, puis cochez la case « Activer ».

- Sur votre iPhone ou iPad, ouvrez l’app Keynote, puis touchez le bouton Keynote Remote dans la barre d’outils. Si le bouton Keynote Remote n’apparaît pas, touchez le bouton Retour , puis le bouton Keynote Remote.

- Sur votre iPhone ou iPad, touchez Continuer.

- Sur votre Mac, cliquez sur Jumeler en regard du nom de votre iPhone ou iPad.

- Assurez-vous que le code d’accès à quatre chiffres est identique sur les deux appareils, puis cliquez sur Confirmer sur votre Mac.

Après avoir jumelé vos appareils, découvrez comment [utiliser Keynote Remote](https://support.apple.com/fr-fr/119886#use) .

## Jumelage de Keynote Remote avec un autre iPhone ou iPad

Vous pouvez lire votre présentation sur un premier iPhone ou iPad et la contrôler à distance avec un second.

- [Activez le Wi-Fi sur les deux appareils](https://support.apple.com/HT202639) .

- Ouvrez votre fichier Keynote sur l’appareil sur lequel vous allez effectuer la présentation.

- Touchez le bouton Plus dans la barre d’outils, touchez Télécommande Keynote, puis Activer la télécommande.

[Image: Aucun texte de remplacement pour l’image]

- Sur l’appareil que vous souhaitez utiliser en tant que télécommande, ouvrez l’app Keynote.

- Touchez le bouton Keynote Remote dans la barre d’outils. Si le bouton Keynote Remote n’apparaît pas, touchez le bouton Retour , puis le bouton Keynote Remote.

[Image: Aucun texte de remplacement pour l’image]

- Sur votre iPhone ou iPad, touchez Continuer.

- Sur l’appareil contenant la présentation, touchez Jumeler, en regard de l’appareil distant.

- Assurez-vous que le code d’accès à quatre chiffres est identique sur vos appareils, puis cliquez sur Confirmer.

Après avoir jumelé vos appareils, découvrez comment [utiliser Keynote Remote](https://support.apple.com/fr-fr/119886#use) .

## Utilisation de Keynote Remote

- Une fois Keynote Remote jumelé avec votre Mac, iPhone ou iPad, procédez comme suit pour contrôler votre diaporama.

- [Activez le Wi-Fi sur votre iPhone ou iPad](https://support.apple.com/HT202639) , ainsi que [sur votre Mac](https://support.apple.com/HT201974) .

- Ouvrez votre fichier Keynote sur l’appareil sur lequel vous allez effectuer la présentation.

- Sur l’appareil doté de Keynote Remote, ouvrez l’app Keynote, puis touchez le bouton Keynote Remote . Si le bouton Keynote Remote n’apparaît pas, touchez le bouton Retour , puis le bouton Keynote Remote.

[Image: bouton Retour]

- Touchez Lire, puis choisissez ce que vous voulez faire :

- Pour utiliser une disposition différente, touchez le bouton Disposition , puis sélectionnez une option.

- Pour passer à la diapositive suivante ou précédente, effectuez un balayage dans le sens correspondant.

- Pour mettre en surbrillance ou en évidence des parties d’une diapositive lors d’une présentation, touchez le bouton Surligneur , puis choisissez une option. Pour désactiver le surligneur, touchez le bouton Fermer .

[Image: Aucun texte de remplacement pour l’image]

- Pour terminer la présentation, touchez le bouton Fermer ou effectuez un balayage vers le bas avec deux doigts.

Si vos appareils ne restent pas connectés, connectez [votre Mac](https://support.apple.com/HT201974) et [votre iPhone ou iPad](https://support.apple.com/HT202639) au même réseau Wi-Fi.

## Informations supplémentaires

- Avant de lire votre diaporama, vous pouvez activer la fonctionnalité Ne pas déranger [sur votre Mac](https://support.apple.com/HT204079) et [sur votre iPhone ou iPad](https://support.apple.com/HT204321) .

- [Utilisez Keynote avec une Apple Watch](https://support.apple.com/HT204623)

- Apprenez à utiliser [AirPlay](https://support.apple.com/HT204289) pour lire votre présentation depuis Keynote sur une Apple TV.
