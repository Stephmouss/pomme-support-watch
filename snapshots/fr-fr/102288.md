# Utiliser les tags et les dossiers intelligents dans Notes sur votre iPhone et iPad

Classez rapidement vos notes à l’aide de tags afin de pouvoir les retrouver plus facilement. Ajoutez simplement un ou plusieurs tags (#travail ou #achats, par exemple) à n’importe quel emplacement dans une note. Vous pouvez également utiliser les dossiers intelligents pour accéder à encore plus d’options d’organisation et de recherche.

## Avant de commencer

[Mettez à jour votre iPhone ou iPad](https://support.apple.com/fr-fr/118575) vers la dernière version d’iOS ou d’iPadOS.

## Ajouter un tag à une note

Sous iOS 15, iPadOS 15 ou version ultérieure, vous pouvez ajouter un tag n’importe où dans une note, y compris dans son titre :

- Ouvrez une note dans l’app Notes.

- Saisissez le symbole # suivi d’un nom de tag.

- Ajoutez une espace ou touchez Entrée. La couleur du texte change pour indiquer que le tag a été ajouté.

Les noms de tags ne doivent pas comporter d’espace, mais vous pouvez en créer de plus longs en insérant des traits d’union, des chiffres et des traits de soulignement, par exemple #matériel-jardinage. Vous pouvez également ajouter des tags dans un dessin avec l’Apple Pencil sur un iPad : il suffit de dessiner le symbole # et d’écrire le nom du tag dans une note.

Pour ajouter un tag à plusieurs notes :

- Accédez au dossier contenant la liste des notes concernées.

- Touchez le bouton Plus , puis l’option Sélectionner des notes.

[Image: null]

- Sélectionnez les notes de votre choix, puis touchez Tags en bas de l’écran.

[Image: Écran d’iPhone affichant l’app Notes avec quatre notes sélectionnées]

- Sélectionnez les tags que vous souhaitez ajouter aux notes, puis touchez la coche .

[Image: null]

- Si vous créez un tag sur un appareil doté d’iOS 15, d’iPadOS 15 ou d’une version ultérieure, ce tag apparaîtra sur vos autres appareils Apple fonctionnant sous iOS 14, iPadOS 14, macOS Big Sur ou version ultérieure. Si la version du logiciel de vos autres appareils est plus ancienne, le tag peut s’afficher sous forme de texte brut.

- Vous ne pouvez pas verrouiller une note qui contient un tag ni ajouter de tag à une note verrouillée.

### Si vous ne parvenez pas à créer des tags dans Notes

- Ouvrez Réglages.

- Touchez Apps.

- Touchez Notes.

- Vérifiez si l’option Convertir automatiquement en tag est activée.

## Afficher et partager les notes contenant des tags

Lorsque vous créez un tag, vous pouvez le retrouver dans la note elle-même ainsi que dans le navigateur de tags.

- Ouvrez Notes.

- Faites défiler l’écran jusqu’au navigateur de tags situé sous la liste de vos dossiers.

- Touchez Tous les tags pour afficher une liste de toutes les notes qui en contiennent, ou touchez un tag particulier pour afficher la liste de toutes les notes associées à ce tag.

Vous pouvez également toucher plusieurs tags et choisir une option de filtrage pour afficher les notes correspondant à l’ensemble des tags sélectionnés (par exemple, à la fois #jardinage et #courses) ou à n’importe lequel des tags sélectionnés (par exemple, soit #jardinage, soit #courses).

[Image: Écran d’iPhone affichant deux notes avec le tag Jardinage]

Si vous partagez une note contenant un tag avec une personne qui utilise iOS 14, iPadOS 14, macOS Big Sur ou version ultérieure, le mot du tag s’affichera sur son appareil et apparaîtra dans son navigateur de tags. Si vous partagez une note contenant un tag avec une personne qui utilise une version logicielle plus ancienne, la note sera partagée, mais le tag pourra s’afficher sous forme de texte brut.

## Renommer ou supprimer des tags de vos notes

Sous iOS 15, iPadOS 15 ou version ultérieure, vous pouvez renommer vos tags ou les supprimer lorsque vous n’en avez plus besoin.

- Ouvrez Notes.

- Accédez au navigateur de tags en bas de la liste des dossiers.

- Touchez de manière prolongée le tag que vous souhaitez modifier.

- Dans le menu contextuel, touchez Renommer le tag ou Supprimer le tag.

[Image: Écran d’iPhone affichant le tag Achats sélectionné avec les options permettant de le renommer ou de le supprimer]

- Saisissez un nouveau nom et touchez Renommer pour confirmer, ou touchez Supprimer pour confirmer.

Le navigateur de tags affiche uniquement les tags qui sont utilisés dans vos notes. Si un tag ne figure plus dans aucune de vos notes, il est supprimé du navigateur de tags.

## Créer un dossier intelligent

Les dossiers intelligents sont particulièrement utiles pour mieux organiser vos notes sans les déplacer des dossiers d’origine. Dans un dossier intelligent, vous appliquez des filtres qui déterminent les notes qui doivent y apparaître. Vous pouvez ainsi accéder facilement à certaines notes et les organiser de différentes manières.

Pour créer un dossier intelligent :

- Ouvrez Notes.

- Touchez le bouton Nouveau dossier .

[Image: null]

- Saisissez un nom de dossier, puis touchez Convertir en dossier intelligent.

- Choisissez les filtres à appliquer pour sélectionner automatiquement les notes de votre dossier intelligent, puis touchez la coche . Vous pouvez choisir des filtres basés sur des tags, la date de création d’une note, la date de dernière modification d’une note, etc.

[Image: null]

- Touchez la coche une nouvelle fois pour créer votre dossier intelligent.

[Image: null]

[Image: Écran d’iPhone affichant des notes filtrées selon deux tags]

Vous pouvez également créer un dossier intelligent à partir du navigateur de tags. Touchez simplement le tag, puis le bouton Plus . Touchez Créer un dossier intelligent, saisissez un nom, puis touchez la coche .

[Image: null]

### Convertir un dossier en dossier intelligent

- Ouvrez Notes.

- Affichez le dossier que vous souhaitez convertir et touchez le bouton Plus .

[Image: null]

- Faites défiler l’écran vers le bas, puis touchez Convertir en dossier intelligent.

Lorsque vous convertissez un dossier, ses notes sont déplacées dans le dossier Notes et associées à un tag dont le nom correspond à celui du dossier intelligent. Vous ne pouvez pas convertir un dossier partagé, un dossier comportant un sous-dossier, ni un dossier contenant des notes verrouillées.

La conversion d’un dossier en dossier intelligent est irréversible. Si vous ne souhaitez pas conserver un dossier intelligent, vous devez le supprimer.

### Modifier un dossier intelligent

- Ouvrez Notes.

- Appuyez de façon prolongée sur un dossier intelligent.

- Touchez Modifier le dossier intelligent.

[Image: Écran d’iPhone affichant un dossier intelligent en cours de modification]

- Changez le nom ou touchez Gérer le dossier intelligent pour modifier les filtres actuels.

- Touchez la coche .

[Image: null]
