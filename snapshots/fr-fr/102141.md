# Si l’assistant Boot Camp cesse de répondre ou indique que l’installation de Boot Camp a échoué

Il est possible que vous deviez mettre à jour macOS ou utiliser une édition ultérieure de Windows 10.

Dans certains cas, l’assistant Boot Camp peut cesser de répondre ou indiquer que l’installation de Boot Camp a échoué lors de la copie des fichiers d’installation de Windows. Pour résoudre le problème, procédez comme suit :

- Si l’assistant Boot Camp est ouvert, mais ne répond pas, appuyez sur les touches Option + Cmd + Échap pour [forcer la fermeture de l’application](https://support.apple.com/fr-fr/HT201276) .

- [Installez les dernières mises à jour de macOS](https://support.apple.com/fr-fr/HT201541) , celles-ci pouvant comprendre des mises à jour de Boot Camp.

- [Téléchargez la dernière édition de Windows 10](https://www.microsoft.com/fr-fr/software-download/windows10ISO) sur le site de Microsoft. Ensuite, [procédez à son installation à l’aide de l’assistant Boot Camp](https://support.apple.com/fr-fr/HT201468) .

Si l’assistant Boot Camp indique que le disque de démarrage ne peut être ni partitionné, ni restauré en une seule partition, procédez comme suit :

- Ouvrez Utilitaire de disque à partir du sous-dossier Utilitaires de votre dossier Applications.

- Sélectionnez votre disque de démarrage Mac (Macintosh HD) dans la barre latérale.

- Cliquez sur Partitionner dans la barre d’outils de l’Utilitaire de disque.

- Si l’Utilitaire de disque vous demande si vous souhaitez ajouter un volume au conteneur ou partitionner le périphérique, cliquez sur Partitionner.

- Dans le graphique qui s’affiche, sélectionnez OSXRESERVED, puis cliquez sur le bouton de suppression (–) situé sous le graphique.

- Sélectionnez BOOTCAMP dans le graphique, puis cliquez sur le bouton de suppression (–).

- OSXRESERVED et BOOTCAMP sont des partitions vides que l’assistant Boot Camp a créées au cours de l’installation qui a échoué.

- Cliquez sur Appliquer, puis sur Partitionner pour confirmer votre choix.

- Ouvrez l’assistant Boot Camp et réessayez d’installer Windows.
