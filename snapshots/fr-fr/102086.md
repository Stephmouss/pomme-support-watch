# Utiliser l’Apple Studio Display ou le Pro Display XDR avec Boot Camp

Vous pouvez utiliser ces écrans Apple avec Microsoft Windows sur certains modèles de Mac. Assurez-vous simplement que vos logiciels sont à jour.

## Vérifier la compatibilité

Si vous avez installé les [dernières mises à jour logicielles](https://support.apple.com/fr-fr/102086#updates) , vous pouvez utiliser ces écrans Apple avec Microsoft Windows 10 sur certains modèles de Mac à processeur Intel.

### Studio Display

Prend en charge Boot Camp sous macOS Monterey 12.3 ou versions ultérieures sur ces modèles de Mac à processeur Intel :

- [MacBook Pro](https://support.apple.com/fr-fr/HT201300) 16 pouces commercialisés en 2019

- MacBook Pro 15 pouces commercialisés de 2016 à 2019

- MacBook Pro 13 pouces commercialisés de 2016 à 2020

- [MacBook Air](https://support.apple.com/fr-fr/HT201862) commercialisés de 2018 à 2020

- [iMac](https://support.apple.com/fr-fr/HT201634) commercialisés de 2017 à 2020

- [iMac Pro](https://support.apple.com/fr-fr/HT201634)

- [Mac mini](https://support.apple.com/fr-fr/HT201894) commercialisés en 2018

- [Mac Pro](https://support.apple.com/fr-fr/HT202888) commercialisés en 2019

### Pro Display XDR

Prend en charge Boot Camp sous macOS Catalina 10.15.2 ou versions ultérieures sur ces modèles de Mac à processeur Intel :

- [MacBook Pro](https://support.apple.com/fr-fr/HT201300) 15 ou 16 pouces commercialisés de 2018 à 2020

- [iMac](https://support.apple.com/fr-fr/HT201634) commercialisés en 2019 ou 2020

- [Mac Pro](https://support.apple.com/fr-fr/HT202888) commercialisés en 2019

## Mettre à jour vos logiciels

Aucun de ces écrans ne nécessite de configuration supplémentaire, mais assurez-vous que vos logiciels sont à jour :

- [Installez les dernières mises à jour de macOS](https://support.apple.com/fr-fr/HT201541) . Vous devez utiliser macOS pour recevoir des mises à jour pour votre écran.

- Si vous ne l’avez pas déjà fait, [installez Windows 10 à l’aide de l’assistant Boot Camp](https://support.apple.com/fr-fr/HT201468) .

- [Démarrez votre Mac sous Windows](https://support.apple.com/fr-fr/HT208123) , puis installez les dernières mises à jour Apple pour Windows [à l’aide de l’outil Mise à jour de logiciels Apple](https://support.apple.com/fr-fr/HT208038) .

## Informations supplémentaires

Il est possible que la sortie vidéo via Thunderbolt 3 ne soit pas prise en charge sur les ordinateurs Mac lors de l’exécution de Windows en [mode sans échec](https://support.microsoft.com/en-us/help/12376/windows-10-start-your-pc-in-safe-mode) ou de l’Environnement de récupération Windows. Dans ces modes, la sortie vidéo reste disponible sur les écrans connectés à un autre port d’affichage, tel que HDMI.
