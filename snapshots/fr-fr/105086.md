# Créer des listes de courses dans Rappels sur votre iPhone

Sous iOS 17 et versions ultérieures, vous pouvez choisir Courses comme type de liste dans Rappels. À mesure que vous ajoutez des articles, l’app Rappels les trie automatiquement en catégories pour faciliter vos achats.

## Créer une liste de courses dans Rappels

Pour utiliser les listes de courses, vous devez activer iCloud pour Rappels. [Configurez iCloud pour Rappels sur tous vos appareils](https://support.apple.com/guide/icloud/set-up-reminders-mmbf52194b5a/1.0/icloud/1.0)

1. Dans l’app Rappels, touchez le bouton Ajouter une liste ou Ajouter une liste. Choisissez le compte que vous souhaitez utiliser si nécessaire.

[Image: null]

[Image: Sur la page Listes dans Rappels, touchez le bouton Ajouter une liste pour en créer une.]

2. Personnalisez votre liste avec un nom et une icône, puis touchez Type de liste.

3. Touchez Courses.

[Image: Sous iOS 17 et versions ultérieures, vous pouvez choisir « Courses » comme type de liste dans Rappels.]

4. Touchez le bouton OK .

[Image: null]

À mesure que vous ajoutez des éléments à la liste, Rappels les classe et les réorganise automatiquement par type d’aliments, par exemple Produits frais, Viande ou Aliments surgelés.

[Image: Les éléments d’une liste Courses dans Rappels sont automatiquement classés à mesure que vous les ajoutez.]

### Personnaliser votre liste Courses

Vous pouvez rapidement déplacer un élément vers une autre catégorie que celle choisie par l’app Rappels si vous le souhaitez. Touchez l’élément de manière prolongée, puis faites-le glisser vers une autre catégorie. Lorsque vous classez manuellement un article de course, votre liste de courses mémorise votre préférence et l’appliquera la prochaine fois que vous ajouterez cet article.

Si vous ne voyez pas la section que vous recherchez, essayez de toucher le bouton Infos sur l’élément que vous souhaitez reclasser :

1. Touchez le bouton Infos .

[Image: null]

2. Faites défiler l’écran et touchez Section.

[Image: Si Rappels ne classe pas correctement un article de course, vous pouvez classer ce dernier manuellement dans la section de votre choix.]

3. Choisissez une section où classer l’article. Si vous ne voyez pas la bonne section, touchez Nouvelle section avec sélection et saisissez une section personnalisée.

4. Touchez le bouton OK .

[Image: null]

Pour renommer une section, touchez son nom dans votre liste Rappels pour le modifier.
