# Si vous ne pouvez pas voir vos photos après avoir rejoint une photothèque partagée iCloud

Si vous avez déplacé des photos vers une photothèque partagée, vous ne pourrez pas les voir sur un iPhone ou un iPod touch doté d’iOS 16 ou version antérieure, un iPad doté d’iPadOS 15 ou version antérieure, un Mac doté de macOS Monterey ou version antérieure, une Apple TV dotée de tvOS 15 ou version antérieure, ou un PC doté d’iCloud pour Windows 13 ou version antérieure.

La photothèque partagée iCloud n’est disponible que sur un iPhone doté d’iOS 16.1 ou version ultérieure, un iPad doté d’iPadOS 16.1 ou version ultérieure, un Mac doté de macOS Ventura 13 ou version ultérieure, une Apple TV dotée de tvOS 16 ou version ultérieure, ou un PC doté d’iCloud pour Windows 14 ou version ultérieure. Si vous ouvrez l’app Photos sur un appareil qui n’a pas été mis à jour vers une version compatible, vous ne verrez pas les photos que vous avez déplacées de votre photothèque personnelle vers votre photothèque partagée. [En savoir plus sur la photothèque partagée iCloud](https://support.apple.com/118229) .

Pour voir vos photos, utilisez un appareil mis à jour vers une version compatible d’iOS, iPadOS, macOS ou tvOS. Vous pouvez également les afficher depuis [iCloud.com](https://icloud.com/) à l’aide de n’importe quel appareil, quelle qu’en soit la version logicielle.
