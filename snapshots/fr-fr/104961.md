# Accéder à vos mots de passe Wi-Fi enregistrés sur iPhone ou iPad

Sous iOS 16 et iPadOS 16.1 et versions ultérieures, vous pouvez utiliser votre code d’accès, Face ID ou Touch ID pour afficher et copier les mots de passe Wi-Fi.

## Trouver le mot de passe de votre réseau actuel

- Dans l’application Réglages, touchez Wi-Fi.

- Recherchez le réseau Wi-Fi que vous utilisez actuellement.

- Touchez le bouton Infos .

[Image: Infos]

- Touchez le champ Mot de passe.

[Image: Capture d’écran Réglages > Wi‑Fi de l’iPhone montrant comment afficher le mot de passe du réseau Wi‑Fi auquel l’iPhone est connecté]

- À l’aide de votre [code d’accès](https://support.apple.com/HT204060) , de [Face ID](https://support.apple.com/HT208109) ou de [Touch ID](https://support.apple.com/HT201371) , déverrouillez et affichez le mot de passe.

[Découvrez comment partager des mots de passe Wi-Fi](https://support.apple.com/102635)

## Trouver les mots de passe des réseaux auxquels l'appareil a été connecté précédemment.

- Dans l’application Réglages, touchez Wi-Fi.

- Touchez Modifier dans l’angle supérieur droit.

[Image: Sous iOS, pour trouver les mots de passe des réseaux Wi-Fi auxquels votre appareil s’est déjà connecté, accédez à Réglages > Wi-Fi > Modifier, puis touchez le bouton d’informations à côté d’un réseau.]

- À l’aide de votre [code d’accès](https://support.apple.com/119586) , de [Face ID](https://support.apple.com/108411) , ou de [Touch ID](https://support.apple.com/102528) , déverrouillez et affichez les réseaux auxquels votre appareil a déjà été connecté.

- Appuyez sur le bouton d’informations à côté d’un réseau doté d’une icône de verrou .

[Image: null]

- Appuyez sur le champ Mot de passe pour l’afficher.

Sous iOS 18, vous pouvez également [utiliser l’app Mots de passe](https://support.apple.com/guide/iphone/use-passwords-on-iphone-iphd18e98624/ios/) pour rechercher, copier et partager les mots de passe Wi-Fi des réseaux auxquels votre appareil a déjà été connecté :

- Servez-vous de votre code d’accès, de Face ID ou de Touch ID pour ouvrir l'app Mots de passe.

- Touchez Wi-Fi.

[Image: Capture d’écran de l’app Mots de passe sur iPhone : sous iOS 18, vous pouvez ouvrir l’app Mots de passe pour trouver des informations sur les réseaux Wi‑Fi auxquels vous vous êtes déjà connecté.]

- Touchez le réseau Wi-Fi dont vous souhaitez afficher le mot de passe.

- Touchez le champ Mot de passe pour afficher le mot de passe.
