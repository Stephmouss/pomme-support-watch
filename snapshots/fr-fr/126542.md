# Obtenir les patchs manquants de la bibliothèque de sons dans Logic Pro pour Mac

Pour réinstaller les patchs de la bibliothèque de sons manquants après la mise à jour vers Logic Pro 12.0, mettez à jour vers Logic Pro 12.2 ou une version ultérieure, puis téléchargez les packs de sons de patchs, d’instruments et de boucles Logic Pro Legacy.

## Obtenir les patchs manquants de la bibliothèque de sons

- [Mettre à jour vers Logic Pro 12.2 ou une version ultérieure](https://support.apple.com/fr-fr/122606) , puis ouvrez Logic Pro.

- Cliquez sur Logic Pro dans la barre de menus, puis choisissez Bibliothèque de sons.

- Saisissez « Logic Pro Legacy » dans le champ de recherche en haut de la fenêtre de la bibliothèque de sons.

- Sélectionnez l’un des anciens paquets de sons que vous souhaitez installer, puis cliquez sur Installer à côté de chaque paquet de sons :

- Anciens patchs Logic Pro

- Anciens instruments Logic Pro

- Anciennes boucles Logic Pro
