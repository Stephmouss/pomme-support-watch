# Rendre un ancien code obsolète après avoir changé le code d’accès de votre iPhone ou de votre iPad

Par défaut, la fonctionnalité Réinitialisation du code vous permet d’utiliser votre ancien code d’accès pendant 72 heures pour accéder à votre iPhone ou à votre iPad.

Si vous avez oublié un code d’accès que vous avez modifié au cours des dernières 72 heures, utilisez la fonctionnalité [Réinitialisation du code](https://support.apple.com/105039) pour accéder temporairement à votre iPhone ou à votre iPad à l’aide de votre ancien code. Si vous déverrouillez votre appareil de cette façon, vous devrez modifier à nouveau votre code d’accès immédiatement.

Si vous souhaitez que votre ancien code d’accès devienne obsolète avant le délai de 72 heures, vous pouvez effectuer la procédure suivante dans l’app Réglages :

- Dans l’app Réglages, touchez Face ID et code (ou Touch ID et code).

- Utilisez Face ID ou saisissez votre code d’accès actuel.

- Touchez Rendre le code précédent obsolète.
