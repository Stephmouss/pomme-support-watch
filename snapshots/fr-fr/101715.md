# Ajouter un masque de forme à un plan 360º stéréoscopique dans Final Cut Pro

Final Cut Pro 10.4 vous permet d’ajouter un masque de forme à un étalonnage des couleurs que vous avez appliqué à un plan 360º stéréoscopique.

Pour ce faire, créez le masque de forme pour l’étalonnage des couleurs dans une des vues du plan stéréoscopique. Ensuite, à l’aide d’un copier-coller, ajoutez le masque de forme de cette vue vers l’autre vue.

- Dans la timeline du projet, [ajoutez un étalonnage des couleurs](https://help.apple.com/finalcutpro/mac/10.4/#ver9f5631358) à votre plan stéréoscopique.

- Dans l’inspecteur vidéo, [ajoutez le masque de forme](https://help.apple.com/finalcutpro/mac/10.4/#ver40b00ffe) à cet étalonnage des couleurs.

- Placez le masque de forme sur la zone que vous souhaitez masquer dans l’une des vues uniquement. Apportez les autres réglages souhaités au masque de forme. Assurez-vous que celui-ci ne dépasse pas les bords du plan à 360°. Si tel est le cas, la sphère 360° ne sera pas transparente lors du visionnage avec un casque de réalité virtuelle (VR) ou dans le visualiseur 360°.

- Sélectionnez le plan dans la timeline du projet, puis choisissez Édition > Copier.

- Assurez-vous que le plan est toujours sélectionné et choisissez Édition > Coller les attributs. Ensuite, sous Effets, sélectionnez l’étalonnage des couleurs pour le masque de forme. Décochez toutes les autres cases de la fenêtre.

- Cliquez sur Coller. Une copie de l’étalonnage des couleurs comprenant le masque de forme est alors créée.

- Cliquez sur le menu local dans la partie supérieure de l’inspecteur de couleur, puis choisissez cette copie de l’étalonnage des couleurs. Par exemple, si vous avez copié « Roue des couleurs 1 », choisissez « Roue des couleurs 2 » dans le menu local.

- Dans la liste située en bas de l’inspecteur de couleur, sélectionnez le masque de forme pour qu’il affiche un contour jaune.

- Dans le visualiseur, faites glisser le masque de forme vers l’autre vue. En principe, les deux vues devraient contenir les masques de forme pour l’étalonnage des couleurs. Pour éviter toute disparité évidente sur les axes X ou Y entre les deux vues, assurez-vous d’aligner les centres des deux masques de forme sur les objets sous-jacents.
