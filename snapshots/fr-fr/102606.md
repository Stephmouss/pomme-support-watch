# Obtenir un code de validation et se connecter à l’aide de l’identification à deux facteurs

Si vous avez activé l’identification à deux facteurs, vous aurez besoin d’un code de validation pour vous connecter à votre compte Apple sur un nouvel appareil ou dans un nouveau navigateur.

Chaque fois que vous [vous connectez à votre compte Apple](https://support.apple.com/fr-fr/111001) sur un nouvel appareil ou dans un nouveau navigateur, vous confirmerez votre identité avec votre mot de passe et un code de validation à six chiffres. Il existe plusieurs façons d’obtenir un code de validation. Vous pouvez utiliser le code qui s’affiche sur votre appareil de confiance, recevoir un code par SMS ou via un appel téléphonique.

Il n’est pas toujours nécessaire de saisir un code de validation. Dans certains cas, votre numéro de téléphone de confiance peut être automatiquement validé en arrière-plan sur votre iPhone. Vous vous épargnez une étape, et votre compte est toujours protégé par l’identification à deux facteurs.

## Utilisation du code qui s’affiche sur votre appareil de confiance

Lorsque vous vous connectez, le code de validation s’affiche automatiquement sur vos appareils de confiance.

- Connectez-vous à votre compte Apple sur un nouvel appareil ou dans un nouveau navigateur.

- Une notification doit alors s’afficher sur l’un de vos appareils de confiance.

[Image: Carte avec Washington mis en évidence. La légende indique qu’un compte Apple est utilisé pour se connecter sur le Web près d’Ashburn, Virginie.]

- Choisissez Autoriser pour recevoir votre code de validation.

- Saisissez ce code sur votre autre appareil pour vous connecter.

L’affichage automatique des codes de validation nécessite qu’un appareil soit doté de la [configuration système minimale requise](https://support.apple.com/fr-fr/118308) . L’Apple Watch affichera automatiquement un code de validation sous watchOS 6 ou version ultérieure.

La notification peut inclure une carte indiquant la localisation approximative de la tentative de connexion. Celle-ci est basée sur l’adresse IP du nouvel appareil et peut refléter le réseau auquel il est connecté, plutôt que la position physique exacte. Si vous êtes la personne qui essaie de se connecter, mais que vous ne reconnaissez pas la localisation, vous pouvez toujours appuyer sur Autoriser et afficher le code de validation.

## Obtention d’un code par SMS ou appel téléphonique

Si vous n’avez pas accès à un appareil de confiance, vous pouvez demander l’envoi, par SMS ou appel téléphonique, de votre code de validation à un numéro de téléphone que vous avez défini comme fiable.

- Sélectionnez « Vous n’avez pas reçu de code ? » ou « Vous n’avez pas accès à vos appareils ? » sur l’écran du code de validation.

- Demandez l’envoi du code à votre numéro de téléphone de confiance.

- Apple vous envoie alors le code de validation par SMS ou appel téléphonique. Si vous utilisez le filtrage des expéditeurs inconnus dans l’app Messages, recherchez-y votre code de vérification.

[Image: Un code de validation s’affiche sur un iPhone de confiance]

- Saisissez-le sur le nouvel appareil afin de terminer le processus de connexion.

Si vous filtrez les expéditeurs inconnus, vous pouvez toujours recevoir des messages urgents, notamment les codes de vérification d’Apple, dans votre boîte de réception Messages. Accédez à Réglages, puis touchez Apps. Touchez Messages, puis faites défiler l’écran jusqu’à la section Expéditeurs inconnus et choisissez Autoriser les notifications. Activez ensuite les notifications pour les messages urgents.

## Si vous n’avez pas accès à vos appareils de confiance ou à vos numéros de téléphone de confiance

Si vous n’avez temporairement pas accès à vos appareils de confiance ou à votre numéro de téléphone de confiance, le moyen le plus rapide d’accéder à votre compte est d’attendre d’y avoir accès dans les prochains jours. Ensuite, connectez-vous à l’aide de l’identification à deux facteurs. Après cela, vous pouvez également [ajouter des numéros de téléphone de confiance supplémentaires à votre compte](https://support.apple.com/fr-fr/122621) pour l’avenir.

Si vous n’avez définitivement plus accès à vos appareils de confiance ou à votre numéro de téléphone de confiance, vous pouvez toujours tenter de récupérer l’accès à votre compte.

- Essayez de vous connecter à votre compte Apple.

- Sélectionnez « Vous n’avez pas reçu de code ? » ou « Vous n’avez pas accès à vos appareils ? » sur l’écran du code de validation.

- Choisissez « Impossible d’utiliser [numéro de téléphone] ».

- Si vous n’avez accès à aucun numéro de téléphone de confiance enregistré sur votre compte Apple, vous pouvez lancer le processus pour récupérer l’accès à votre compte. Suivez les instructions qui s’affichent à l’écran.

Selon les informations que vous êtes en mesure de fournir pour confirmer votre identité, plusieurs jours peuvent être nécessaires avant que vous puissiez de nouveau accéder à votre compte. Contacter Apple ne permet pas d’accélérer le processus.
