# Si Logic Pro pour Mac se bloque après une mise à jour

L’ouverture de Logic Pro après la mise à jour à partir de Logic Pro 10.5 ou d’une version antérieure peut prendre plus de temps que prévu. En effet, Logic Pro 10.5.1 et les versions ultérieures incluent des optimisations des performances pour la compatibilité des Audio Units.

Logic Pro analyse vos modules la première fois qu’il s’ouvre après une mise à jour. Cette analyse doit être terminée avant que Logic Pro puisse s’ouvrir.

- Si vous utilisez de nombreux modules tiers, l’analyse peut prendre 10 minutes ou plus.

- Si un problème avec l’un de vos modules est détecté, Logic Pro peut suspendre l’analyse ou ne plus répondre.

Si vous pensez que vous avez attendu assez longtemps pour savoir que l’analyse ne progresse pas ou que Logic Pro a cessé de répondre, essayez ces solutions :

- Ouvrez [Mission Control](https://support.apple.com/fr-fr/HT204100) pour obtenir un aperçu de toutes les fenêtres ouvertes sur votre Mac, y compris les alertes liées à vos modules. Par exemple, vous pouvez découvrir une alerte indiquant qu’une période de démonstration a expiré ou que vous devez connecter un dongle de licence USB. Cliquez sur ces alertes dans Mission Control, puis traitez chacune d’elles afin que l’analyse puisse continuer.

- [Forcez la fermeture de Logic Pro](https://support.apple.com/fr-fr/HT201276) , puis assurez-vous que tous vos modules sont à jour. [Supprimez tous les modules incompatibles](https://support.apple.com/fr-fr/HT201199) avant d’ouvrir à nouveau Logic Pro. Apple ne recommande pas d’essayer de rendre compatible un module d’extension 32 bits en utilisant un enveloppeur 64 bits.
