# Comment utiliser AirDrop sur iPhone et iPad

Activez et utilisez AirDrop pour partager et recevoir des photos, des documents et plus encore avec les appareils Apple à proximité.

- [Avant de commencer](https://support.apple.com/fr-fr/119857#start)

- [Partager avec une personne qui figure parmi vos contacts](https://support.apple.com/fr-fr/119857#contacts)

- [Partager avec une personne qui ne figure pas parmi vos contacts](https://support.apple.com/fr-fr/119857#notcontacts)

## Avant de commencer

- Assurez-vous que la personne à qui vous envoyez du contenu se trouve à proximité et que vous avez tous les deux activé le Wi-Fi et le Bluetooth. Si l’un de vous a activé le partage de connexion, désactivez-le.

- Si les deux appareils sont dotés d’iOS 17 ou version ultérieure, essayez de les rapprocher pour partager du contenu via AirDrop.

## Partager avec une personne qui figure parmi vos contacts

- Sur votre appareil, ouvrez l’app à partir de laquelle vous souhaitez partager du contenu. Par exemple, si vous souhaitez partager une photo, ouvrez l’app Photos.

- Dans votre photothèque, touchez Sélectionner, puis la ou les photos que vous souhaitez partager.

- Touchez le bouton Partager , puis AirDrop.

[Image: null]

- Si une personne qui figure parmi vos contacts se trouve à proximité, elle apparaît sous Personnes. Touchez le nom de la personne avec qui vous souhaitez partager.

[Image: Deux contacts AirDrop, affichés dans la liste Personnes sur iPhone.]

- Demandez à l’autre personne de toucher Accepter sur son appareil.

## Partager avec une personne qui ne figure pas parmi vos contacts

- Sur votre appareil, ouvrez l’app à partir de laquelle vous souhaitez partager du contenu. Par exemple, si vous souhaitez partager un fichier, ouvrez l’app Fichiers.

- Touchez le bouton Plus , puis touchez Sélectionner et le ou les fichiers que vous souhaitez partager.

[Image: null]

- Touchez le bouton Partager , puis AirDrop.

[Image: null]

- Demandez à l’autre personne d’ouvrir le centre de contrôle sur son appareil et de procéder comme suit : toucher de manière prolongée les commandes de connectivité, toucher AirDrop, puis Tout le monde pendant 10 minutes.

[Image: Commandes de connectivité affichées sur l’iPhone, avec AirDrop réglé sur Tout le monde pendant 10 minutes.]

- Sur votre appareil, touchez l’autre personne sous Personnes. Si les deux appareils utilisent iOS 26.2 ou une version ultérieure, un message s’affiche demandant d’utiliser [un code AirDrop](https://support.apple.com/guide/iphone/iphcd8b9f0af/) .

- Demandez à la personne de toucher Obtenir le code AirDrop sur son appareil, puis de vous communiquer le code à saisir sur votre appareil. La personne est ajoutée temporairement à vos contacts pour une durée de 30 jours. Si vous le souhaitez, vous pouvez supprimer la personne plus tôt dans l’app Contacts.

[Image: Code AirDrop affiché sur l’iPhone du destinataire, avec des instructions pour partager le code avec l’expéditeur.]

Sous iOS 16.2 et versions ultérieures, le réglage intitulé Tout le monde pendant 10 minutes change automatiquement après 10 minutes. Si vous êtes connecté(e) à votre compte Apple, il revient à Contacts uniquement. Dans le cas contraire, il revient à Réception désactivée.
