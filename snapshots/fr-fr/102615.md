# Récupérer les messages texte supprimés sur votre iPhone ou iPad

Sous iOS 16 et iPadOS 16.1, ou versions ultérieures, vous pouvez récupérer des conversations et des messages que vous avez supprimés dans l’app Messages.

## Récupérer une conversation ou un message supprimé

- Dans Messages, touchez le bouton Filtres sur la page des conversations. Si vous utilisez iOS 18, touchez Modifier sur la page des conversations.

- Touchez Suppressions récentes .

[Image: Aucun texte de remplacement fourni pour l’image]

[Image: Sur la page des conversations de Messages, touchez Modifier pour accéder à l’option permettant d’afficher les messages récemment supprimés.]

- Choisissez les conversations comportant les messages que vous souhaitez restaurer, puis touchez Récupérer.

[Image: Sur la page Suppressions récentes de Messages, touchez la conversation comportant les messages que vous souhaitez récupérer.]

- Touchez Récupérer le message ou Récupérer [nombre] messages.

Pour récupérer des messages et des conversations supprimés, vous devez utiliser iOS 16 ou iPadOS 16.1, ou des versions ultérieures. Vous pouvez uniquement récupérer des messages et des conversations que vous avez supprimés au cours des 30 à 40 derniers jours. Si vous supprimez un message avant de passer à iOS 16, iPadOS 16 ou une version ultérieure, vous ne pouvez pas le récupérer.

[Découvrez la marche à suivre pour supprimer un message ou une conversation dans Messages sur votre iPhone.](https://support.apple.com/guide/iphone/delete-messages-iph2c9c4bfcb/ios)
