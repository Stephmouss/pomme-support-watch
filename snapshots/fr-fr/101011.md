# À propos d’Apple Remote Desktop 3.7

Consultez cet article pour en savoir plus sur Apple Remote Desktop 3.7.

Apple Remote Desktop 3.7 inclut une mise à jour pour l’application Remote Desktop et les clients administrés à distance par cette dernière.

Comment effectuer la mise à jour

Pour les utilisateurs ayant acheté Remote Desktop dans le Mac App Store, la mise à jour est disponible depuis l’onglet Mises à jour du Mac App Store. Pour les utilisateurs ayant installé Remote Desktop depuis un disque physique, la mise à jour est disponible sous forme de [mise à jour logicielle](http://support.apple.com/kb/HT1338?viewlocale=fr_FR) automatique et sous forme de téléchargement manuel depuis la page [Téléchargements du site d’assistance Apple](http://support.apple.com/fr_FR/downloads/#serversandenterprisesoftware) .

La mise à jour des clients est disponible sous forme de [mise à jour logicielle](http://support.apple.com/kb/HT1338?viewlocale=fr_FR) automatique et sous forme de téléchargement manuel depuis la page [Téléchargements du site d’assistance Apple](http://support.apple.com/fr_FR/downloads/#serversandenterprisesoftware) . Vous pouvez également utiliser Remote Desktop 3.7 pour mettre les clients à jour vers la version 3.7. Pour ce faire, sélectionnez Mettre à jour le logiciel client depuis le menu Gérer. Le logiciel client Remote Desktop 3.7 est inclus sous OS X Mavericks.

Configuration système requise

- Remote Desktop 3.7 requiert OS X Lion 10.7.5, Mountain Lion ou Mavericks.

- La mise à jour Remote Desktop 3.7 requiert Apple Remote Desktop 3.0 ou version ultérieure.

- OS X Mavericks requiert Remote Desktop 3.7 ou version ultérieure.

Nouveautés

Cette mise à jour améliore la stabilité et la fiabilité générales de l’application Remote Desktop. Elle inclut également les améliorations suivantes :

- La prise en charge d’OS X Mavericks ;

- Un presse-papiers partagé permettant d’effectuer automatiquement des copier-coller entre des ordinateurs locaux et à distance ;

- Une prise en charge améliorée des systèmes Mac dotés de plusieurs écrans ou de plusieurs adresses IP ;

- Une amélioration de la fonctionnalité d’observation d’écrans multiples, grâce à une prise en charge des gestes permettant de passer d’un écran à l’autre par un simple balayage ;

- La résolution des problèmes de troncation des résultats de commandes UNIX distantes.
