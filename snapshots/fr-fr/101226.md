# Utiliser Gestionnaire de profils pour empêcher l’installation de versions bêta d’OS X

Vous pouvez utiliser Gestionnaire de profils pour empêcher la mise à disposition de préversions du logiciel sur les ordinateurs Mac exécutant OS X.

## Empêcher l’installation de versions bêta d’OS X

Des préversions du logiciel Apple peuvent s’afficher sur les Mac des utilisateurs enregistrés dans le cadre du [programme OS X Bêta](https://appleseed.apple.com/sp/betaprogram) . Vous pouvez utiliser Gestionnaire de profils dans OS X Server 3.2.1 et version ultérieure pour bloquer l’accès aux préversions d’OS X Yosemite disponibles depuis ce programme.

- Saisissez le nom de domaine com.apple.SoftwareUpdate.

- Saisissez la clé AllowPreReleaseInstallation.

- Définissez le type de clé sur Booléen.

- Ne cochez pas la case située en dessous de la colonne Valeur, de sorte que la valeur de la clé soit définie sur Faux.

Enregistrez ces modifications, puis transmettez le profil à vos systèmes clients. Les ordinateurs Mac qui l’utiliseront ne seront plus en mesure d’installer les préversions d’OS X Yosemite à partir du programme OS X bêta.

Si vous ne disposez pas du gestionnaire, vous pouvez créer votre propre profil. Téléchargez [ce fichier](http://km.support.apple.com/library/APPLE/APPLECARE_ALLGEOS/HT6311/HT6311-BlockYosemiteBeta.mobileconfig.zip) afin d’obtenir un exemple de profil. Diffusez ensuite votre profil sur vos systèmes clients à l’aide d’un e-mail, d’une page Web, de la [fonctionnalité de configuration et de distribution de profils sans fil](https://developer.apple.com/library/ios/documentation/networkinginternet/conceptual/iphoneotaconfiguration/Introduction/Introduction.html) , ou d’un serveur de gestion des appareils mobiles.

Les étapes décrites dans cet article permettent uniquement d’empêcher l’installation des préversions du logiciel à partir du programme OS X bêta. Elles n’empêchent pas l’installation des versions finales d’OS X.
