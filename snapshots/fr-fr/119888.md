# Choisir un type de document dans Pages sur Mac, iPhone ou iPad

Utilisez un document de traitement de texte pour les lettres ou les rapports, ou utilisez un document de mise en page pour les newsletters ou les prospectus.

- Dans un document de traitement de texte, le texte passe d’une page à l’autre et de nouvelles pages sont créées automatiquement lorsque vous atteignez la fin d’une page. C’est donc le format idéal pour un document comme un rapport ou une lettre avec du texte comme contenu principal.

- Dans un document de mise en page, vous pouvez réorganiser manuellement les pages et positionner librement des zones de texte, des images et d’autres objets sur la page. Utilisez la mise en page pour les newsletters, les prospectus et autres documents qui contiennent de nombreux éléments graphiques.

Les modèles de Pages sont conçus pour le traitement de texte ou la mise en page. Si vous décidez de changer le type d’un document après avoir choisi un modèle, vous pouvez le convertir à tout moment.

## Choisir un type de document sur Mac

Vous pouvez créer un document de traitement de texte ou de mise en page standard en sélectionnant [le modèle approprié](https://support.apple.com/guide/pages/tan5c52a733c/mac) . Vous pouvez également modifier le type d’un document après avoir commencé à travailler dessus.

### Créer un document standard

Dans Pages, choisissez Fichier > Nouveau, puis choisissez une option en fonction du type de document que vous souhaitez créer :

- Pour créer un document de traitement de texte standard, double-cliquez sur le modèle Vierge ou Vierge – Paysage dans la catégorie Standard du sélecteur de modèle.

- Pour créer un document de mise en page standard, double-cliquez sur le modèle de mise en page vierge dans la catégorie Standard. D’autres catégories de modèles, telles que Bulletins d’info et Livres – Paysage, proposent des modèles basés sur le type de document de mise en page.

Pages utilise votre [fiche personnelle](https://support.apple.com/guide/contacts/adrb3525ca49/mac) Si un message vous invite à autoriser Pages à accéder à vos coordonnées, cliquez sur OK pour accepter, ou choisissez Pages > Réglages, puis activez l’option « Utiliser ma fiche personnelle de Contacts pour remplir les informations de l’expéditeur ». Vous pouvez consulter ou modifier la liste des [apps autorisées à accéder à vos coordonnées](https://support.apple.com/guide/mac-help/mh40711/mac) dans Réglages Système.

### Changer de type de document

La conversion du type d’un document peut avoir une incidence sur le contenu que vous avez précédemment ajouté.

Si vous n’êtes pas sûr du type de document actuel, consultez le menu Fichier. Si le menu Fichier contient l’option « Convertir en Mise en page », cela indique qu’il s’agit d’un document de traitement de texte. Si l’option « Convertir en traitement de texte » apparaît, il s’agit d’un document de mise en page.

- Pour convertir un document de mise en page en document de traitement de texte, ouvrez le document, puis choisissez Fichier > Convertir en traitement de texte.

- Pour convertir un document de traitement de texte en document de mise en page, ouvrez le document, choisissez Fichier > Convertir en Mise en page, puis cliquez sur Convertir. Cliquez sur Annuler si vous n’avez pas enregistré le contenu du document et que vous ne souhaitez pas le perdre après la conversion.

Si vous devez revenir au document d’origine, appuyez sur Commande + Z pour annuler les actions les plus récentes, ou vous pouvez [rétablir la version précédente du document](https://support.apple.com/guide/pages/tan7f1de6ec5/mac) .

## Choisir un type de document sur iPhone ou iPad

Vous pouvez créer un document de traitement de texte ou de mise en page standard en sélectionnant le modèle approprié. Vous pouvez également modifier le type d’un document après avoir commencé à travailler dessus.

### Créer un document de traitement de texte

Lorsque vous ouvrez Pages, touchez Commencer à écrire pour créer un document de traitement de texte standard. Ou touchez Choisir un modèle, puis le modèle Vierge ou Vierge – Paysage dans la catégorie Standard.

Si le gestionnaire de documents s’affiche à l’ouverture de Pages, touchez le bouton Nouveau document en haut de l’écran, touchez Choisir un modèle, puis le modèle Vierge ou Vierge - Paysage dans la catégorie Standard. Si un document est ouvert, touchez le bouton Retour dans l’angle supérieur gauche pour accéder au gestionnaire de documents.

### Créer un document de mise en page

Pour créer un document de mise en page standard, ouvrez Pages, touchez Choisir un modèle, puis le modèle de mise en page vierge dans la catégorie Standard. D’autres catégories de modèles, telles que Bulletins d’info et Livres – Paysage, proposent également des modèles basés sur le type de document de mise en page.

### Changer de type de document

Vous pouvez changer le type du document actif à tout moment. Si vous avez déjà choisi un modèle et ajouté du contenu au document, la modification de son type peut affecter le contenu. Veillez à enregistrer une copie du document avant de changer de type de document.

Pour vérifier le type de document que vous utilisez et pour en changer :

- Touchez un coin du document pour éviter de sélectionner du texte ou des objets.

- Sur l’iPhone, touchez le bouton Plus . Sur l’iPad, touchez le nom du document ou le bouton Plus en fonction de ce que vous voyez dans la barre d’outils.

[Image: Aucun texte de remplacement pour l’image]

- Touchez Options du document, Configuration du document, puis Document :

- Si l’option Corps du document est activée, il s’agit d’un document de traitement de texte.

- Si l’option Corps du document est désactivée, il s’agit d’un document de mise en page.

- Pour passer à un autre type de document :

- Pour convertir le document de mise en page en document de traitement de texte, activez Corps du document.

- Pour convertir le document de traitement de texte en document de mise en page, désactivez Corps du document, puis touchez Convertir. Touchez Annuler si vous n’avez pas enregistré le contenu du document et que vous ne souhaitez pas le perdre après la conversion.

- Si vous souhaitez revenir au document d’origine, touchez le bouton Annuler pour annuler les actions les plus récentes. Vous pouvez également [rétablir la version précédente du document](https://support.apple.com/guide/pages-ipad/restore-an-earlier-version-of-a-document-tan7f1de6ec5/ipados) .
