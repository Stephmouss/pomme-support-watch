# Utiliser un mot de passe administrateur lorsque vous importez des utilisateurs à partir d’un fichier pour l’accès à FileVault

Lorsque vous utilisez la commande fdesetup pour importer des utilisateurs à partir d’un fichier, spécifiez un mot de passe administrateur dans le champ du mot de passe de premier niveau.

Lorsque vous préparez un fichier .plist afin d’activer une liste d’utilisateurs pour la commande fdesetup add -inputplist , utilisez le mot de passe d’un administrateur dans le champ du mot de passe de premier niveau.

Remarque : la saisie de la clé de secours dans le champ du mot de passe de premier niveau peut entraîner le renvoi d’une erreur. Utilisez plutôt le mot de passe d’un administrateur.

## Informations supplémentaires

Pour plus d’informations sur l’utilisation de cet outil de ligne de commande, veuillez consulter la page man de la commande fdesetup .

Voici un exemple de fichier de liste de propriétés pouvant être importé :

Nom d’utilisateur admin Mot de passe Apple123 AdditionalUsers Nom d’utilisateur travis Mot de passe topsecret

- admin est le nom abrégé d’un utilisateur administrateur.

- Apple123 est le mot de passe de l’utilisateur « admin ».

- travis est le nom abrégé d’un utilisateur à activer.

- topsecret est le mot de passe de l’utilisateur « travis ».
