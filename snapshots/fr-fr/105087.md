# Si les messages de votre iPhone apparaissent dans des bulles vertes

Pourquoi les messages de votre iPhone apparaissent-ils dans des bulles vertes ? Les messages RCS et MMS/SMS apparaissent dans des bulles de texte vertes sur votre appareil. Découvrez comment faire pour qu’ils apparaissent dans des bulles bleues à la place.

## Pourquoi vos messages apparaissent dans des bulles vertes au lieu de bulles bleues

L’affichage d’une bulle verte au lieu d’une bulle bleue indique que le message a été envoyé via RCS, MMS ou SMS et non iMessage. Cela peut se produire pour plusieurs raisons :

- L’appareil du destinataire du message n’est pas de marque Apple.

- iMessage est désactivé sur votre appareil ou celui du destinataire.

- iMessage est temporairement indisponible sur votre appareil ou celui du destinataire.

- Vous devrez peut-être [mettre à jour vos réglages pour Messages après avoir configuré un nouvel appareil](https://support.apple.com/118433#esim) .

[Découvrir la différence entre les messages iMessage et RCS ou MMS/SMS](https://support.apple.com/104972)

## Activez iMessages pour que vos messages apparaissent dans des bulles bleues quand cela est possible

- Dans l’app Réglages, touchez Apps.

- Touchez Messages.

- Activez iMessage.

[Image: Capture d’écran des réglages de l’iPhone : pour que vos messages apparaissent dans des bulles bleues, activez iMessage en accédant à Réglages > Messages, puis en activant iMessage.]

4. Si nécessaire, touchez Envoi et réception pour [choisir si vous souhaitez démarrer de nouvelles conversations à partir de votre numéro de téléphone ou de votre adresse e-mail](https://support.apple.com/101744) .
