# Suivre et écouter des podcasts dans Apple Podcasts sur iPhone et iPad

Suivez vos podcasts préférés et contrôlez leur écoute à l’aide de diverses fonctionnalités, notamment en changeant la vitesse de lecture ou en effectuant un retour ou une avance rapide.

## Procédure préliminaire

[Mettez à jour votre iPhone ou iPad vers la dernière version d’iOS ou d’iPadOS](https://support.apple.com/fr-fr/118575)

## Suivre des podcasts sur iPhone ou iPad

Lorsque vous suivez un podcast, les nouveaux épisodes sont automatiquement téléchargés sur votre appareil. Vous pouvez également recevoir une notification dès que de nouveaux épisodes sont disponibles.

- Ouvrez l’app Podcasts.

- Recherchez le podcast que vous souhaitez suivre. [Vous avez besoin d’aide pour trouver les podcasts que vous aimez ?](https://support.apple.com/fr-fr/guide/iphone/iph19bb8e705/ios)

- Touchez l’émission pour voir sa page d’informations.

- Touchez le bouton Plus .

[Image: null]

Pour accéder aux podcasts que vous suivez ou à ceux que vous avez ajoutés manuellement à l’aide d’une URL, affichez l’onglet Bibliothèque. Ensuite, touchez Podcasts.

Vous souhaitez écouter des podcasts avec du contenu premium ? [Découvrez comment souscrire des abonnements à Apple Podcasts.](https://support.apple.com/fr-fr/108378)

## Arrêter de suivre des podcasts sur iPhone ou iPad

- Ouvrez l’app Podcasts.

- Sur votre iPhone, touchez la barre d’onglets, puis touchez l’onglet Bibliothèque. Sur votre iPad, accédez à Bibliothèque dans la barre latérale.

- Appuyez sur Podcasts, puis sur un podcast pour voir sa page d’informations.

- Touchez le bouton Plus pour le podcast.

[Image: null]

- Touchez le bouton Ne plus suivre .

[Image: null]

- Si vous avez téléchargé des épisodes, vous pouvez choisir de conserver tous vos épisodes téléchargés ou de les supprimer de votre bibliothèque. Touchez la page du podcast pour conserver vos épisodes téléchargés. Si vous les conservez, les nouveaux épisodes ne seront pas téléchargés, mais les épisodes déjà présents dans votre bibliothèque ne seront pas supprimés.

Si vous arrêtez de suivre un podcast avec du contenu premium, votre abonnement reste actif.

[Découvrez comment résilier un abonnement](https://support.apple.com/fr-fr/118428)

## Réorganiser votre file d’attente

- Ouvrez l’app Podcasts.

- Recherchez le podcast que vous souhaitez ajouter à votre file d’attente.

- Touchez le podcast pour afficher sa page d’informations et rechercher l’épisode que vous souhaitez ajouter.

- Touchez le bouton Plus à côté de l’épisode.

[Image: null]

- Touchez Lire ensuite pour écouter l’épisode après celui que vous écoutez actuellement, ou touchez Ajouter à la file d’attente pour placer l’épisode à la fin de votre file d’attente.

[Image: null]

- Pour réorganiser votre file d’attente Pour vous ou votre file d’attente personnalisée, touchez le mini-lecteur au bas de l’écran, puis touchez le bouton File d’attente .

[Image: null]

- Pour déplacer l’épisode, maintenez le doigt sur le bouton Réorganiser et faites-le glisser.

## Regarder des podcasts vidéo

Certains podcasts proposent une version vidéo que vous pouvez regarder dans l’app Podcasts.

### Regarder un podcast vidéo

- Ouvrez l’app Podcasts.

- Recherchez un podcast proposant une version vidéo et lancez sa lecture.

- Touchez le mini-lecteur au bas de l’écran.

- Sous la barre de lecture, touchez Activer la vidéo pour lire la version vidéo du podcast. Touchez Désactiver la vidéo pour lire la version audio.

[Image: Le mini-lecteur est ouvert dans l’app Podcasts sur iPhone. Le bouton Activer la vidéo est encerclé, montrant sa position sous la barre de lecture.]

Vous pouvez [utiliser Image dans l’image](https://support.apple.com/fr-fr/guide/iphone/iphcc3587b5d/ios) pour continuer à regarder la vidéo tout en utilisant d’autres apps. Si vous fermez Image dans l’image, la version audio du podcast continuera d’être lue. Mettez le podcast en pause pour arrêter la lecture.

### Modifier vos préférences liées aux podcasts vidéo

- Ouvrez l’app Réglages.

- Touchez Apps, puis sélectionnez Podcasts.

- Diffusez des vidéos uniquement via Wi-Fi : accédez aux préférences de diffusion vidéo et désactivez l’option Autoriser via cellulaire.

- Téléchargez automatiquement les versions vidéo d’une émission : accédez à Téléchargements auto et activez Télécharger la vidéo. Vous pouvez décider d’effectuer les téléchargements via le réseau cellulaire en touchant Autoriser via cellulaire, puis en sélectionnant Audio seulement ou Vidéo.

## Accélérer ou ralentir un épisode de podcast

- Ouvrez l’app Podcasts et commencez à écouter un épisode.

- Touchez le mini-lecteur au bas de l’écran pour afficher les commandes audio.

- Touchez le bouton Vitesse de lecture , puis sélectionnez une vitesse dans le menu qui apparaît. Vous pouvez également toucher et faire glisser le menu de vitesse pour obtenir une vitesse de lecture spécifique.

## Afficher la transcription d’un podcast

- Ouvrez l’app Podcasts et commencez à écouter un épisode.

- Touchez le mini-lecteur en bas de l’écran pour développer le lecteur plein écran.

- Touchez le bouton Transcription . Si le bouton Transcription est grisé, les transcriptions ne sont pas disponibles pour cet épisode.

[Image: null]

Dans la vue de la transcription, vous pouvez :

- Suivre vos podcasts préférés tout en lisant les transcriptions synchronisées.

- Avancer ou reculer dans le podcast et toucher la section que vous souhaitez écouter.

- Touchez de façon prolongée une section pour sélectionner le texte ou le partager.

- Toucher Rechercher pour trouver des mots spécifiques et accéder directement à ces sections.

- Affichez les chapitres de l’émission et touchez-les pour accéder à cette section du podcast.

- Trouvez des liens vers des morceaux et d’autres contenus mentionnés dans le podcast, ou suivez les podcasts mentionnés.

- Signaler un problème avec la transcription. Pour cela, touchez la section de façon prolongée, puis Signaler un problème et suivez les instructions à l’écran.

Les transcriptions ne sont pas disponibles en Biélorussie et en Russie.
