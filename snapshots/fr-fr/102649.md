# Consulter la liste des appareils sur lesquels vous êtes connecté(e) à l’aide de votre compte Apple

Découvrez quels appareils apparaissent dans la liste des appareils de votre compte Apple, comment trouver les informations de votre appareil et comment supprimer un appareil.

## Quand supprimer un appareil de la liste

Si vous avez égaré votre appareil, l’app [Localiser](https://support.apple.com/fr-fr/101593) peut vous permettre de le retrouver et de prendre les mesures nécessaires à la protection des données qu’il contient.

Si vous n’utilisez plus votre appareil, n’y avez plus accès ou ne le reconnaissez pas, vous devez le supprimer de la liste.

Les appareils que vous supprimez de la liste n’auront plus accès à iCloud, à l’app Localiser ou à tout autre service Apple, et n’afficheront plus de codes de vérification pour l’identification à deux facteurs. L’appareil ne réapparaîtra dans la liste que si vous vous connectez à nouveau sur celui-ci.

## Trouver ou supprimer des appareils dans votre liste

Lorsque vous vous connectez à votre compte Apple sur un appareil, celui-ci est ajouté à l’écran de votre compte Apple. Depuis cet écran, vous pouvez voir quels sont les appareils de confiance, ceux sur lesquels vous êtes actuellement connecté(e), et vous en déconnecter à distance, si nécessaire.

### Afficher les appareils sur lesquels vous êtes connecté(e) depuis votre iPhone ou iPad

- Touchez Réglages, [votre nom], puis faites défiler vers le bas pour accéder à une liste d’appareils.

[Image: Réglages de l’iPhone affichant une liste d’appareils]

- Touchez le nom d’un appareil afin d’obtenir des informations sur celui-ci (modèle, numéro de série, version du logiciel). Vous pouvez également savoir s’il s’agit d’un appareil de confiance qui peut recevoir les codes de validation associés au compte Apple. La nature des informations présentées peut varier en fonction du type d’appareil. Vous devrez peut-être vous authentifier pour accéder aux informations de l’appareil.

- Si vous souhaitez supprimer cet appareil de votre compte en vous déconnectant à distance, touchez Supprimer du compte. Lisez le message qui s’affiche, puis confirmez que vous souhaitez supprimer cet appareil.

### Afficher la liste des appareils sur lesquels vous êtes connecté(e) depuis votre Mac

- Choisissez le menu Apple , puis choisissez Réglages Système.

- Cliquez sur [votre nom], puis faites défiler vers le bas pour accéder à une liste d’appareils.

[Image: Réglages du Mac affichant une liste d’appareils]

- Cliquez sur le nom d’un appareil afin d’obtenir des informations sur celui-ci (modèle, numéro de série, version du logiciel). Vous pouvez également savoir s’il s’agit d’un appareil de confiance qui peut recevoir les codes de validation associés au compte Apple. La nature des informations présentées peut varier en fonction du type d’appareil. Vous devrez peut-être vous authentifier pour accéder aux informations de l’appareil.

- Si vous souhaitez supprimer cet appareil de votre compte en vous déconnectant à distance, cliquez sur Supprimer du compte. Lisez le message qui s’affiche, puis confirmez que vous souhaitez supprimer cet appareil.

### Consulter la liste des appareils sur lesquels vous êtes connecté(e) depuis votre PC Windows

- Ouvrez iCloud pour Windows.

- En haut, cliquez sur Détails du compte.

- La liste des appareils sur lesquels vous êtes connecté(e) s’affiche. La nature des informations présentées peut varier en fonction du type d’appareil.

### Consulter la liste des appareils sur lesquels vous êtes connecté(e) depuis le Web

Si vous utilisez un PC Windows, un appareil mobile Android ou si vous ne possédez pas d’appareils Apple, vous pouvez vous connecter sur le Web pour consulter la liste des appareils de votre compte Apple.

- Connectez-vous à votre compte Apple sur [account.apple.com](https://account.apple.com/) , puis sélectionnez Appareils.

[Image: Site web du compte Apple affichant les appareils associés à un compte]

- Si vos appareils ne s’affichent pas, cliquez sur Afficher les détails pour vous authentifier et afficher les informations de l’appareil.

- Cliquez sur le nom d’un appareil afin d’obtenir des informations sur celui-ci (modèle, numéro de série, version du logiciel). Vous pouvez également savoir s’il s’agit d’un appareil de confiance qui peut recevoir les codes de validation associés au compte Apple. La nature des informations présentées peut varier en fonction du type d’appareil.

- Si vous souhaitez supprimer cet appareil de votre compte en vous déconnectant à distance, cliquez sur Supprimer du compte. Lisez le message qui s’affiche, puis confirmez que vous souhaitez supprimer cet appareil.

## Supprimer définitivement un appareil depuis la page de votre compte

Si vous êtes toujours connecté(e) à votre compte Apple sur l’appareil, celui-ci peut réapparaître à l’écran de votre compte Apple une fois connecté à Internet. Pour supprimer définitivement l’appareil de l’écran de votre compte, déconnectez-vous d’iCloud, de Contenu multimédia et achats, d’iMessage, de FaceTime et de Game Center sur cet appareil, ou effacez les données de l’appareil.
