# Vérifier les appareils connectés à votre compte Apple

Découvrez quels appareils apparaissent dans la liste des appareils de votre compte Apple, comment trouver les informations relatives à votre appareil et comment supprimer un appareil si vous ne l’utilisez plus.

## Ce que peuvent faire les appareils connectés à votre compte Apple

Lorsque vous vous connectez à votre compte Apple sur un appareil, celui-ci est ajouté à la liste des appareils de votre compte Apple. Cette liste inclut les appareils mobiles Android, les PC Windows et les appareils de streaming que vous utilisez avec votre compte Apple pour Apple Music ou Apple TV. Selon le type d’appareil, vous pouvez utiliser les appareils connectés à votre compte Apple pour :

- Modifier votre mot de passe

- Recevoir des codes de validation pour l’identification à deux facteurs

- Modifier vos informations personnelles

- Effectuer une synchronisation avec iCloud

## Quand supprimer un appareil de la liste

Si vous n’utilisez plus votre appareil ou que vous ne le reconnaissez pas, vous pouvez le supprimer de la liste. Les appareils que vous supprimez de votre compte n’auront plus accès à iCloud, à l’app Localiser ou à tout autre service Apple, et n’afficheront plus de codes de vérification pour l’identification à deux facteurs. L’appareil ne réapparaîtra dans la liste que si vous vous connectez à nouveau sur celui-ci.

En cas de perte ou si vous ne souhaitez plus utiliser votre appareil Apple, [découvrez la marche à suivre](https://support.apple.com/fr-fr/102649#permanentlyremove) .

## Afficher ou supprimer des appareils dans votre liste

Vous pouvez vous déconnecter de votre compte Apple à distance, si nécessaire.

### Sur votre iPhone ou iPad

- Ouvrez Réglages.

- Touchez [votre nom], puis faites défiler vers le bas pour accéder à une liste d’appareils.

[Image: Réglages de l’iPhone affichant une liste d’appareils.]

- Touchez le nom d’un appareil pour afficher ses informations.

- Si vous souhaitez supprimer cet appareil de votre compte en vous déconnectant à distance, touchez Supprimer du compte. Lisez le message qui s’affiche, puis confirmez que vous souhaitez supprimer cet appareil.

En cas de perte ou si vous ne souhaitez plus utiliser votre appareil Apple, [découvrez la marche à suivre](https://support.apple.com/fr-fr/102649#permanentlyremove) .

### Sur votre Mac

- Choisissez le menu Apple , puis choisissez Réglages Système.

- Cliquez sur [votre nom], puis faites défiler vers le bas pour accéder à une liste d’appareils.

[Image: Réglages du Mac affichant une liste d’appareils.]

- Cliquez sur le nom d’un appareil pour afficher ses informations.

- Si vous souhaitez supprimer cet appareil de votre compte en vous déconnectant à distance, cliquez sur Supprimer du compte. Lisez le message qui s’affiche, puis confirmez que vous souhaitez supprimer cet appareil.

En cas de perte ou si vous ne souhaitez plus utiliser votre appareil Apple, [découvrez la marche à suivre](https://support.apple.com/fr-fr/102649#permanentlyremove) .

### Sur le Web

Si vous utilisez un PC Windows, un appareil mobile Android ou si vous ne possédez pas d’appareils Apple, vous pouvez vous connecter sur le Web pour consulter la liste des appareils de votre compte Apple.

- Connectez-vous à votre compte Apple sur [account.apple.com](https://account.apple.com) .

- Sélectionnez Appareils. Si vos appareils ne s’affichent pas, cliquez sur Afficher les détails pour vous authentifier et afficher les informations de l’appareil.

[Image: Site web du compte Apple affichant les appareils associés à un compte.]

- Cliquez sur le nom d’un appareil pour afficher ses informations.

- Si vous souhaitez supprimer cet appareil de votre compte en vous déconnectant à distance, cliquez sur Supprimer du compte. Lisez le message qui s’affiche, puis confirmez que vous souhaitez supprimer cet appareil.

En cas de perte ou si vous ne souhaitez plus utiliser votre appareil Apple, [découvrez la marche à suivre](https://support.apple.com/fr-fr/102649#permanentlyremove) .

## En cas de perte ou si vous ne souhaitez plus utiliser votre appareil Apple

Si vous êtes toujours connecté(e) à votre compte Apple sur l’appareil, celui-ci peut réapparaître à l’écran de votre compte Apple une fois connecté à Internet.

- Pour supprimer définitivement un appareil Apple de votre compte, [accédez à Réglages sur cet appareil et déconnectez-vous](https://support.apple.com/fr-fr/104958) .

- Si votre appareil Apple est perdu ou manquant, protégez les données de votre compte. [Utilisez l’app Localiser pour activer le mode Perdu ou effacer les données de votre appareil à distance](https://support.apple.com/fr-fr/120837) .
