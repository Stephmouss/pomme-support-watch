# GarageBand pour iOS : fonction Joindre les régions non disponible

La fonction Joindre n’est pas disponible pour les enregistrements audio, les enregistrements d’ampli de guitare et les boucles Apple Loops.

La fonction Joindre n’est pas disponible pour les enregistrements d’instrument tactile.
