# Configurer une eSIM sur un iPad

Obtenez des informations sur l’eSIM et sur la configuration d’une eSIM sur votre iPad.

## Qu’est-ce que l’eSIM sur l’iPad ?

Une eSIM est une carte SIM numérique standard intégrée à votre iPad qui vous évite d’avoir à utiliser une carte SIM physique. Cette fonctionnalité innovante vous permet de basculer sans effort entre des cartes SIM, de gérer huit eSIM ou plus et d’activer de nouveaux forfaits de façon numérique. Avec l’eSIM, vous profitez d’une plus grande flexibilité, d’un meilleur confort d’utilisation, d’une meilleure sécurité et d’une connectivité fluide, en particulier lorsque vous voyagez à l’étranger.

Lorsque vous voyagez à l’étranger, vous pouvez utiliser l’itinérance proposée par votre opérateur de base ou acheter une eSIM auprès d’un opérateur local prenant en charge l’eSIM dans le pays ou la région que vous visitez. [Trouvez des opérateurs mobiles et des fournisseurs de services mondiaux proposant le service eSIM sur l’iPad](https://support.apple.com/fr-fr/119577) dans le pays ou la région où vous vous rendez.

[En savoir plus à propos des données mobiles sur l’iPad](https://www.apple.com/fr/ipad/cellular/)

## Éléments requis

- [Un opérateur mobile ou un prestataire de services international prenant en charge l’eSIM](https://support.apple.com/fr-fr/119577)

- Un iPad prenant en charge l’eSIM :

- iPad Pro 13 pouces (M4, M5) Wi-Fi + Cellular*

- iPad Pro 11 pouces (M4, M5) Wi-Fi + Cellular*

- iPad Pro 11 pouces (de la 1re à la 4e génération) Wi-Fi + Cellular

- iPad Pro 12,9 pouces (de la 3e à la 6e génération) Wi-Fi + Cellular

- iPad Air 13 pouces (M2, M3, M4) Wi-Fi + Cellular*

- iPad Air 11 pouces (M2, M3, M4) Wi-Fi + Cellular*

- iPad Air (de la 3e à la 5e génération) Wi-Fi + Cellular

- iPad (A16) Wi-Fi + Cellular*

- iPad (de la 7e à la 10e génération) Wi-Fi + Cellular

- iPad mini (A17 Pro) Wi-Fi + Cellular *

- iPad mini (5e et 6e générations) Wi-Fi + Cellular

L’activation d’un forfait de données cellulaires avec une eSIM en Chine continentale n’est disponible qu’avec les [modèles d’iPad prenant en charge l’eSIM en Chine continentale](https://support.apple.com/fr-fr/104991) . [Identifiez votre modèle d’iPad](https://support.apple.com/fr-fr/108043) . [Contactez China Unicom pour en savoir plus.](https://mall.10010.com/static/homepage/subjectpage/5980000010023.html)

* Les modèles d’iPad (A16) Wi-Fi + Cellular et modèles ultérieurs, les modèles d’iPad Pro (M4) Wi-Fi + Cellular et modèles ultérieurs, les modèles d’iPad Air (M2) Wi-Fi + Cellular et modèles ultérieurs, ainsi que les modèles d’iPad mini (A17 Pro) Wi-Fi + Cellular et modèles ultérieurs sont activés à l’aide d’une eSIM et ne sont pas dotés d’une carte SIM physique.

## Activer une eSIM sur un iPad

Il existe plusieurs façons d’activer les données mobiles sur un iPad à l’aide de l’eSIM. Pour configurer un forfait de données mobiles avec une eSIM sur votre iPad, utilisez eSIM Carrier Activation (Activation de l’eSIM par l’opérateur), transférez votre forfait depuis un autre iPad, rejoignez un forfait de données mobiles pour iPhone existant, recherchez un nouveau forfait, utilisez un code QR ou utilisez l’app pour iPad de votre opérateur.

[Image: Écran d’iPad Pro affichant les options de forfait de données cellulaires pour la configuration d’une eSIM.]

### Utiliser l’activation de l’eSIM par l’opérateur sur iPad

Si votre opérateur prend en charge les services d’activation d’eSIM, il peut attribuer une nouvelle eSIM à votre iPad. Si une eSIM a été attribuée à votre iPad lorsque vous l’avez acheté, allumez votre iPad et suivez les instructions à l’écran. Votre eSIM sera installée via la configuration.

Si vous avez contacté votre opérateur pour obtenir une eSIM après avoir configuré votre iPad, et que celui-ci a configuré eSIM Carrier Activation (Activation de l’eSIM par l’opérateur) :

- Touchez la notification Forfait cellulaire prêt à être installé lorsqu’elle s’affiche.

- Dans l’app Réglages, touchez « Forfait cellulaire prêt à être installé ».

- Touchez Continuer.

Si le forfait que vous avez activé remplace le forfait de votre carte SIM physique, retirez cette dernière, puis redémarrez votre iPad.

### Transférer votre forfait depuis un autre iPad

Certains opérateurs prennent en charge le transfert rapide de l’eSIM, qui vous permet de transférer l’eSIM de votre ancien iPad sur votre nouvel iPad sans avoir à contacter votre opérateur. Si vous êtes invité à transférer votre forfait pendant la configuration, suivez les instructions à l’écran.

Vous pouvez également transférer votre eSIM depuis un autre iPad après la configuration comme suit :

- Assurez-vous que votre iPad utilise [la dernière version d’iPadOS](https://support.apple.com/fr-fr/118575) .

- Ouvrez l’app Réglages.

- Touchez Données cellulaires, puis Transférer un forfait iPad.

- S’il est disponible, touchez le bouton Transfert en regard de la ligne désirée.

- Suivez les instructions à l’écran pour transférer le service. Vous devrez peut-être patienter quelques minutes pour que l’activation s’effectue.

Si le bouton Transfert ne s’affiche pas ou si vous ne pouvez pas transférer votre forfait, vous devrez peut-être contacter votre opérateur. 1

1 Votre iPad est régi par les politiques de votre fournisseur de téléphonie mobile, qui peuvent prévoir des restrictions quant au transfert d’un forfait de données. Contactez votre opérateur pour obtenir des informations supplémentaires. Si vous ne savez pas quel opérateur appeler, ouvrez l’app Réglages sur votre iPad et touchez Opérateur.

### Rejoindre un forfait pour iPhone existant

Si votre opérateur le permet, vous pouvez configurer un forfait de données mobiles en ajoutant votre iPad à un forfait de données mobiles pour iPhone existant.

- Assurez-vous que votre iPad utilise [la dernière version d’iPadOS](https://support.apple.com/fr-fr/118575) .

- Ouvrez l’app Réglages.

- Touchez Données cellulaires.

- Touchez Rejoindre le forfait iPhone, puis suivez les instructions à l’écran.

Si vous ne pouvez pas sélectionner Rejoindre le forfait iPhone, assurez-vous que vous avez activé le Wi-Fi sur l’iPad et que vous avez utilisé le même compte Apple pour vous connecter sur votre iPhone et sur votre iPad.

### Rechercher et configurer un nouveau forfait

Certains opérateurs traitent l’achat et la configuration d’un forfait de données mobiles directement sur votre iPad.

- Consultez la liste des opérateurs locaux disponibles et assurez-vous que le service de localisation est activé.

- Ouvrez l’app Réglages.

- Touchez Confidentialité et sécurité.

- Touchez Service de localisation.

- Activez le service de localisation.

- Assurez-vous que votre iPad utilise [la dernière version d’iPadOS](https://support.apple.com/fr-fr/118575) .

- Configurez le nouveau forfait.

- Ouvrez l’app Réglages.

- Touchez Données cellulaires, puis Trouver un nouveau forfait.

- Sélectionnez un opérateur dans la liste des opérateurs locaux.

- Suivez les instructions à l’écran pour configurer et activer votre nouveau forfait de données mobiles sur votre iPad.

### Utiliser un code QR

Vous pouvez utiliser un code QR fourni par votre opérateur pour activer une eSIM sur votre iPad.

Activez une eSIM avec un code QR lorsque vous configurez votre iPad pour la première fois comme suit :

- Lorsque vous arrivez à l’écran Configurer un forfait cellulaire, touchez Utiliser un code QR.

- Suivez les instructions à l’écran.

Activez une eSIM avec un code QR après avoir configuré votre iPad comme suit :

- Contactez votre opérateur pour obtenir un code QR.

- Ouvrez l’app Appareil photo et scannez votre code QR. Touchez la notification « Forfait cellulaire détecté » lorsqu’elle s’affiche.

- Si vous utilisez un iPad doté d’iPadOS 17.4 ou version ultérieure et que vous disposez d’un code QR reçu dans un e-mail de votre opérateur ou obtenu sur la page web de ce dernier, touchez le code QR de façon prolongée, puis touchez Ajouter une carte eSIM.

- Touchez Continuer.

- Touchez Ajouter un forfait cellulaire.

Votre opérateur peut exiger l’utilisation d’un code de confirmation pour une authentification supplémentaire. Entrez le code de confirmation fourni par l’opérateur lorsque vous y êtes invité.

### Autres méthodes d’activation de l’eSIM

Certains opérateurs peuvent prendre en charge d’autres méthodes d’activation de l’eSIM pour vous permettre de configurer un forfait de données mobiles sur votre iPad.

#### Utiliser un lien

Si votre opérateur vous envoie un lien pour télécharger et activer votre eSIM, procédez comme suit :

- Sur votre iPad doté d’iPadOS 17.4 ou version ultérieure, touchez le lien.

- Lorsque la notification Activer la nouvelle eSIM apparaît, touchez Autoriser.

- Touchez Continuer.

#### Utiliser l’application de l’opérateur

Si votre opérateur prend en charge l’activation de l’eSIM à l’aide d’une app, téléchargez l’app de votre opérateur sur l’App Store et suivez les instructions à l’écran.
