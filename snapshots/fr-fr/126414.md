# Si Compressor ne s’ouvre pas après une mise à jour de macOS

Passez à Compressor 4.11.1 ou une version ultérieure.

Passez à Compressor 4.11.1 si vous avez effectué une mise à jour vers ces versions de macOS et ne pouvez pas ouvrir Compressor :

- macOS Tahoe 26.3

- macOS Sequoia 15.7.4

Si vous avez effectué une mise à jour vers macOS Sonoma 14.8.4 et ne pouvez pas ouvrir Compressor :

- Passez à macOS Sequoia 15.6 ou une version ultérieure.

- Passez à Compressor 4.11.1 ou une version ultérieure.

Compressor 4.11.1 corrige également une faille de sécurité. Si vous devez continuer à utiliser Compressor 4.11 ou une version antérieure, [prenez note de ce problème de sécurité](https://support.apple.com/fr-fr/125693) . Vous pouvez [configurer le pare-feu de macOS pour refuser les connexions entrantes dans l’app Compressor](https://support.apple.com/guide/mac-help/mh11783/mac) si vous l’utilisez uniquement pour l’encodage local.
