# Définir un code de Temps d’écran sur un iPhone ou un iPad

Vous pouvez créer un code de Temps d’écran pour vous assurer que les réglages que vous choisissez pour l’appareil de votre enfant ou le vôtre restent en vigueur. Cela signifie que le code doit être saisi pour pouvoir modifier des réglages de Temps d’écran. Lorsqu’un code de Temps d’écran est activé sur l’appareil d’un enfant, vous recevez une notification chaque fois que ce code est saisi sur l’appareil en question.

Le code de Temps d’écran diffère du code de déverrouillage de votre appareil ou de celui de l’enfant. Il est important de conserver et de mémoriser votre code de Temps d’écran, car vous en avez besoin pour changer les réglages Temps d’écran de votre appareil ou de celui de votre enfant. Vous pouvez modifier ou supprimer un code de Temps d’écran à tout moment.

Si vous utilisez le [partage familial](https://support.apple.com/108380) pour gérer le compte Apple d’un enfant, la personne responsable du partage familial ou un parent/tuteur doit définir le code de Temps d’écran de l’enfant sur son propre appareil, pas sur celui de l’enfant.

[Découvrez la marche à suivre pour modifier votre code de Temps d’écran](https://support.apple.com/102677)

## Définir un code de Temps d’écran pour l’iPhone ou l’iPad de votre enfant

- Ouvrez l’app Réglages, puis touchez Temps d’écran.

- Faites défiler l’écran vers le bas et touchez le nom de votre enfant sous Famille. Si le nom de votre enfant n’apparaît pas sous Famille, assurez-vous que votre appareil et celui de votre enfant sont connectés chacun au bon compte Apple et que le partage familial est configuré.

- Touchez Gérer le temps d’écran, puis Verrouiller les réglages Temps d’écran.

[Image: Écran d’iPhone affichant les réglages Gérer le temps d’écran pour un enfant, avec l’option Verrouiller les réglages Temps d’écran mise en évidence.]

- Saisissez un code à quatre chiffres, puis saisissez-le à nouveau pour le confirmer.

## Définir un code de Temps d’écran pour votre iPhone ou iPad

- Ouvrez l’app Réglages, puis touchez Temps d’écran.

- Faites défiler l’écran vers le bas, touchez Gérer le temps d’écran, puis Verrouiller les réglages Temps d’écran.

[Image: Écran d’iPhone affichant les réglages Gérer le temps d’écran, avec un bouton permettant de verrouiller les réglages Temps d’écran.]

- Saisissez un code à quatre chiffres, puis saisissez-le à nouveau pour le confirmer.

- Pour ajouter un code de secours pour Temps d’écran, saisissez l’adresse e-mail ou le numéro de téléphone et le mot de passe associés à votre compte Apple.

[Image: Écran d’iPhone affichant les options Code de secours pour « Temps d’écran », avec les champs pour l’identifiant Apple et le mot de passe.]

Il est recommandé de ne pas passer l’étape d’ajout d’un code de secours pour Temps d’écran. Si vous oubliez votre code de Temps d’écran, vous pourrez ainsi le réinitialiser à l’aide de votre compte Apple. Si vous avez plusieurs comptes Apple, vous devez utiliser celui que vous avez utilisé lors de la configuration initiale de votre code de secours pour Temps d’écran.

Il est important de se souvenir du compte Apple utilisé pour votre code de secours pour Temps d’écran. Sans ce compte, vous ne pourrez pas supprimer ni réinitialiser votre code de Temps d’écran, et Apple ne sera pas en mesure de vous fournir cette information.
