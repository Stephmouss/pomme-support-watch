# Comment créer un code de Temps d’écran sur un iPhone ou un iPad

Vous pouvez créer un code de Temps d’écran afin que les réglages que vous choisissez pour l’appareil de votre enfant ou le vôtre restent en place. Cela signifie que le code doit être saisi pour pouvoir modifier des réglages de Temps d’écran. Lorsqu’un code de Temps d’écran est activé pour l’appareil d’un enfant, vous recevez une notification chaque fois qu’il utilise le code sur son appareil.

- [Fonctionnement d’un code de Temps d’écran](https://support.apple.com/fr-fr/126533#how)

- [Comment configurer un code de Temps d’écran pour l’iPhone ou l’iPad de votre enfant](https://support.apple.com/fr-fr/126533#child)

- [Comment configurer un code de Temps d’écran pour votre propre iPhone ou iPad](https://support.apple.com/fr-fr/126533#adult)

## Fonctionnement d’un code de Temps d’écran

Le code de Temps d’écran n’est pas le même que le code de déverrouillage de votre appareil. Il est important de conserver et de mémoriser votre code de Temps d’écran, car vous en avez besoin pour changer les réglages Temps d’écran de votre appareil ou de celui de votre enfant.

Pour vous assurer que vos réglages de Temps d’écran se synchronisent sur tous les appareils de votre groupe de partage familial, mettez à jour tous les appareils vers la dernière version du logiciel avant d’activer ou de modifier vos réglages de Temps d’écran. Si vous avez activé l’option Partager entre les appareils, votre code est automatiquement mis à jour sur les appareils concernés après la réinitialisation.

Si vous utilisez le [partage familial](https://support.apple.com/108380) pour gérer le compte Apple d’un enfant, la personne responsable du partage familial, un parent ou un tuteur/une tutrice doit définir le code de Temps d’écran sur son propre appareil, pas sur celui de l’enfant.

[Découvrez la marche à suivre si vous avez oublié votre code de Temps d’écran ou si vous avez simplement besoin de le réinitialiser](https://support.apple.com/102677)

## Comment configurer un code de Temps d’écran pour l’appareil de votre enfant

Ces étapes s’appliquent à iOS 27 et iPadOS 27 et versions ultérieures. Découvrez comment [configurer un code de Temps d’écran pour l’appareil de votre enfant sous iOS 26 ou version antérieure](https://support.apple.com/guide/iphone/create-manage-track-a-screen-time-passcode-iph272b4c4bd/26/ios/26) .

- Sur l’iPhone ou l’iPad de la personne responsable du partage familial ou du parent/tuteur, ouvrez l’app Réglages.

- Touchez Famille, puis le nom de votre enfant. Si le nom de votre enfant n’apparaît pas sous Famille, assurez-vous que vous êtes tous les deux connectés à vos appareils avec votre propre compte Apple et que le compte de votre enfant fait partie du groupe de Partage familial.

- Touchez Code et gestion. Si vous ne voyez pas Code et gestion, vous devrez peut-être [configurer d’abord l’utilisation et le contrôle parental](https://support.apple.com/108806) , puis configurer le code de Temps d’écran.

- Touchez Verrouiller les réglages de Temps d’écran.

- Saisissez un code à quatre chiffres, puis saisissez-le à nouveau pour le confirmer.

[Image: Écran d’iPhone affichant les réglages Gérer le temps d’écran pour un enfant, avec l’option Verrouiller les réglages Temps d’écran mise en évidence.]

## Configurer un code de Temps d’écran pour votre propre iPhone ou iPad

Ces étapes s’appliquent à iOS 27 et iPadOS 27 et versions ultérieures. Découvrez comment [configurer un code de Temps d’écran sur votre iPhone avec iOS 26](https://support.apple.com/guide/iphone/create-manage-track-a-screen-time-passcode-iph272b4c4bd/26/ios/26) .

- Ouvrez l’app Réglages, puis faites défiler l’écran vers le bas et touchez Temps d’écran.

- Faites défiler l’écran vers le bas, touchez Code d’accès et gestion.

- Touchez Verrouiller les réglages de Temps d’écran.

[Image: Écran d’iPhone affichant les réglages Gérer le temps d’écran, avec un bouton permettant de verrouiller les réglages Temps d’écran.]

- Saisissez un code à quatre chiffres, puis saisissez-le à nouveau pour le confirmer.

- Pour ajouter un code de secours pour Temps d’écran, saisissez l’adresse e-mail ou le numéro de téléphone et le mot de passe associés à votre compte Apple.

[Image: Écran d’iPhone affichant les options de récupération du code de Temps d’écran, avec des champs pour le compte Apple et le mot de passe.]

Il est recommandé de ne pas passer l’étape d’ajout d’un code de secours pour Temps d’écran. Si vous oubliez votre code de Temps d’écran, vous pourrez ainsi le réinitialiser à l’aide de votre compte Apple. Si vous devez récupérer votre code de Temps d’écran, vous devez utiliser le même compte que celui saisi lors de la configuration initiale de la récupération du code de Temps d’écran.

Il est important de mémoriser le compte Apple que vous avez utilisé pour la récupération de votre code de Temps d’écran, car sans lui, vous ne pourrez pas supprimer ni réinitialiser votre code de Temps d’écran, et Apple pourrait ne pas être en mesure de vous fournir ces informations.
