# Utiliser les extensions Safari sur votre Mac

Les extensions Safari viennent s’ajouter aux fonctionnalités existantes de Safari. Grâce à elles, vous pouvez adapter votre navigation en fonction de vos besoins. Elles vous permettent d’obtenir des informations utiles sur une page web spécifique, de vous tenir au fait de l’actualité, d’utiliser vos services préférés, de modifier l’apparence de votre navigateur, et bien plus encore. Voici comment les installer, les désinstaller ou les partager sur différents appareils.

- [Installer des extensions](https://support.apple.com/fr-fr/102343#install)

- [Activer des extensions](https://support.apple.com/fr-fr/102343#turnon)

- [Désactiver des extensions](https://support.apple.com/fr-fr/102343#turnoff)

- [Désinstaller des extensions](https://support.apple.com/fr-fr/102343#uninstall)

- [Partager les extensions entre des appareils](https://support.apple.com/fr-fr/102343#share)

## Installation des extensions

L’App Store permet de télécharger et d’installer des extensions Safari en toute facilité. Toutes les extensions disponibles dans l’App Store sont vérifiées, signées et hébergées par Apple pour garantir votre sécurité, et sont également mises à jour automatiquement.

- Commencez par [installer les dernières mises à jour de macOS](https://support.apple.com/fr-fr/108382) afin de vous assurer que vous disposez de la version la plus récente de Safari. Safari 12 ou version ultérieure est nécessaire afin de pouvoir télécharger des extensions Safari dans l’App Store.

- Ouvrez Safari. Dans le menu Safari de la barre des menus, choisissez Extensions Safari.

- L’App Store s’ouvre sur la page Extensions Safari. Pour télécharger et installer une extension, cliquez sur Obtenir ou sur le prix. Vous devrez peut-être vous connecter à l’aide de votre compte Apple.

- Cliquez sur Installer.

- Une fois l’extension installée, cliquez sur Ouvrir et suivez les instructions à l’écran fournies par l’extension.

## Activer des extensions

Après avoir installé une extension, procédez comme suit pour l’activer.

- Ouvrez Safari. Dans le menu Safari de la barre des menus, sélectionnez Réglages (ou Préférences).

- Cliquez sur Extensions.

- Cochez la case en regard du nom de l’extension. [Découvrez la marche à suivre si vous ne pouvez pas activer les extensions](https://support.apple.com/fr-fr/108379) .

[Lors de l’utilisation de profils Safari](https://support.apple.com/fr-fr/105100) , les extensions disponibles pour le profil par défaut sont gérées dans l’onglet Extensions principal des réglages Safari. Les extensions des autres profils peuvent être gérées de manière indépendante dans l’onglet Profils, qui possède son propre onglet Extensions pour chaque profil. Par défaut, les extensions sont désactivées pour chaque nouveau profil.

[Lorsque vous naviguez dans une fenêtre privée](https://support.apple.com/guide/safari/browse-privately-ibrw1069/mac) sous macOS Sonoma 14 ou version ultérieure, toutes les extensions qui nécessitent un accès à des sites web sont désactivées par défaut. Pour utiliser une extension lorsque vous naviguez de manière privée :

- Dans le menu Safari de la barre des menus, choisissez Réglages.

- Cliquez sur Extensions.

- Sélectionnez l’extension dans la barre latérale, puis sélectionnez « Autoriser en navigation privée » à droite.

- Que la navigation soit privée ou non, vous pouvez également restreindre l’accès d’une extension à certains sites web. Cliquez sur le bouton Modifier les sites web pour afficher l’extension dans les réglages Sites web. Vous pouvez alors autoriser l’accès, le refuser ou exiger que les sites web demandent votre autorisation.

## Désactiver des extensions

- Dans le menu Safari de la barre des menus, sélectionnez Réglages (ou Préférences).

- Cliquez sur Extensions.

- Pour désactiver une extension, désélectionnez la case correspondante.

## Désinstaller des extensions

Il est recommandé de désinstaller les extensions dont vous ne parvenez pas à déterminer le rôle ou que vous ne souhaitez plus utiliser.

- Ouvrez Safari. Dans le menu Safari de la barre des menus, sélectionnez Réglages (ou Préférences).

- Cliquez sur Extensions.

- Pour désinstaller une extension, sélectionnez-la, puis cliquez sur le bouton Désinstaller.

## Partager les extensions entre des appareils

À partir de macOS Ventura 13, iOS 16 et iPadOS 16, vous pouvez partager les extensions entre votre Mac, iPhone et iPad :

- Sur votre Mac, ouvrez Safari. Dans le menu Safari, choisissez Réglages, puis cliquez sur Extensions. Sélectionnez « Partager entre les appareils » en bas de la fenêtre.

- Sur votre iPhone ou iPad, ouvrez Réglages, touchez Apps, Safari, Extensions, puis activez Partager entre les appareils.

Si une extension installée sur un appareil est également compatible avec vos autres appareils, elle apparaît automatiquement dans les réglages des extensions sur ces appareils. Cliquez sur le bouton Obtenir ou l’ icône iCloud à côté de l’extension pour la télécharger. Lorsque vous activez ou désactivez l’extension, vos autres appareils affichent la même modification.

## Informations supplémentaires

La plupart des modules web ne sont plus pris en charge par Safari. En vue d’accélérer le chargement des pages web, d’économiser de l’énergie et de renforcer la sécurité, Safari est optimisé pour le contenu utilisant la norme web HTML5, pour laquelle aucun module n’est nécessaire. Si vous souhaitez améliorer et personnaliser l’expérience de navigation, utilisez des extensions Safari à la place des modules web.

Les informations se rapportant à des produits non fabriqués par Apple, ou à des sites Web indépendants qui ne sont ni contrôlés ni testés par Apple, sont fournies uniquement à titre indicatif et ne constituent aucune recommandation. Apple ne saurait être tenu responsable de problèmes liés à l’utilisation de tels sites ou produits tiers, ou à leurs performances. Apple ne garantit en aucune façon la fiabilité d’un site Web tiers ni l’exactitude des informations que ce dernier propose. [Contactez le fournisseur](https://support.apple.com/fr-fr/103190) pour plus d’informations.
