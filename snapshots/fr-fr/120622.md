# Empêcher un ordinateur portable Mac de s’allumer lors de l’ouverture de son couvercle ou de sa connexion à une source d’alimentation

Un ordinateur portable Mac avec puce Apple s’allume et démarre automatiquement lorsque vous ouvrez son couvercle ou que vous le connectez à une source d’alimentation. Sous macOS Sequoia 15 ou version ultérieure, vous pouvez modifier ce comportement tout en gardant la possibilité d’allumer votre Mac à l’aide de son clavier ou de son trackpad.

- Assurez-vous que votre [ordinateur portable Mac avec puce Apple](https://support.apple.com/fr-fr/116943) est doté de macOS Sequoia ou version ultérieure.

- Ouvrez Terminal (dans Applications > Utilitaires).

- Saisissez l’une de ces commandes dans Terminal, puis appuyez sur Retour :

- Pour empêcher l’ordinateur de démarrer lors de l’ouverture du couvercle ou de sa connexion à une source d’alimentation : sudo nvram BootPreference=%00

- Pour empêcher l’ordinateur de démarrer uniquement lors de l’ouverture du couvercle : sudo nvram BootPreference=%01

- Pour empêcher l’ordinateur de démarrer uniquement lors de sa connexion à une source d’alimentation : sudo nvram BootPreference=%02

- Saisissez votre mot de passe d’administrateur lorsque vous y êtes invité (Terminal n’affiche pas le mot de passe lors de sa saisie), puis appuyez sur Retour.

Pour annuler l’une des commandes précédentes et réactiver le démarrage automatique lors de l’ouverture du couvercle ou de la connexion à une source d’alimentation, saisissez sudo nvram -d BootPreference dans Terminal.
