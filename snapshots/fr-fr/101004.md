# Lion Server : le serveur de fichiers SMB fonctionne avec Mac OS X 10.6 et Windows XP ou version ultérieure

Le serveur de fichiers SMB inclus avec OS X Lion fonctionne avec les clients SMB utilisant le standard UNICODE et profitant d’un niveau de sécurité étendu, comme Mac OS X 10.6 Snow Leopard.

Mac OS X 10.6.x et Microsoft Windows XP ou version ultérieure utilisent le standard UNICODE et profitent d’un niveau de sécurité étendu. Les clients exécutant Mac OS X 10.5 ou version antérieure doivent utiliser le protocole AFP.
