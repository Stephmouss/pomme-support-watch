# En cas de saisie impossible d’une valeur dans la palette de couleurs de Final Cut Pro pour iPad

Pour modifier la couleur des éléments tels que le texte dans l’onglet Curseurs de la palette de couleurs, utilisez les curseurs ou un Magic Keyboard.

Vous pouvez modifier les couleurs des éléments tels que le texte et les effets de texte en appuyant sur un cadre de couleur dans l’inspecteur, puis en utilisant les options de la palette de couleurs. Si vous utilisez l’option Curseurs pour modifier la valeur numérique de la couleur, il se peut que vous ne puissiez pas saisir les valeurs de couleur lorsque vous touchez une valeur existante.

Si vous avez un Magic Keyboard pour votre iPad, connectez-le pour saisir des valeurs numériques dans ces champs. Vous pouvez également utiliser les curseurs.
