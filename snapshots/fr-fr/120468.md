# Utiliser iCloud sur une machine virtuelle

Sur une machine virtuelle sous macOS Sequoia ou version ultérieure, vous pouvez utiliser plusieurs de vos fonctionnalités iCloud préférées, mais d’autres ne sont pas disponibles.

## Fonctionnalités iCloud disponibles sur une machine virtuelle

Pour vous connecter à votre compte Apple sur une machine virtuelle, votre machine hôte doit être mise à jour vers macOS Sequoia ou version ultérieure. Lorsque vous vous connectez à votre compte Apple sur une machine virtuelle, vous pouvez utiliser des services tels que Messages, FaceTime et la plupart des fonctionnalités iCloud, comme vous le feriez sur un appareil Apple.

## Fonctionnalités iCloud non disponibles sur une machine virtuelle

- Sauvegarde iCloud

- Find My

- Services multimédias Apple, comme les apps, films, morceaux de musique, livres, etc.

- Apple Cartes

Si vous devez modifier votre compte Apple, notamment mettre à jour vos informations de paiement ou récupérer votre compte, ou si vous devez créer un autre compte Apple, vous aurez besoin d’un iPhone, d’un iPad, de l’Apple Vision Pro, d’un Mac ou de vous rendre sur [iCloud.com](https://www.icloud.com) .
