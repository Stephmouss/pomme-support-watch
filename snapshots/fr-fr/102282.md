# Autoriser la connexion d’accessoires USB et autres à votre Mac

Sur les ordinateurs portables Mac avec puce Apple, il peut être nécessaire d’approuver les nouveaux accessoires avant qu’ils puissent se connecter.

## Autoriser la connexion d’accessoires

[Image: Boîte de dialogue Mac affichant le message « Voulez-vous connecter l’accessoire USB à ce Mac ? », avec les boutons « Ne pas autoriser » et « Autoriser ».]

Lorsque vous utilisez un accessoire nouveau ou inconnu, qu’il s’agisse d’un accessoire USB ou Thunderbolt ou d’une carte SD, avec votre [ordinateur portable Mac avec puce Apple](https://support.apple.com/fr-fr/116943) , une alerte vous demande d’autoriser l’accessoire à se connecter.

- Si votre Mac est verrouillé, vous devez le déverrouiller avant de pouvoir autoriser la connexion d’un accessoire.

- Si votre Mac est resté verrouillé pendant trois jours ou plus, vous devrez peut-être le déverrouiller pour utiliser un accessoire que vous avez précédemment autorisé.

- Si vous cliquez sur Ne pas autoriser dans l’alerte, votre Mac ne reconnaîtra pas l’accessoire ou ne lui permettra pas d’accéder aux données stockées sur l’ordinateur. La prochaine fois que vous connecterez l’accessoire, il vous sera à nouveau demandé de l’autoriser.

- Les accessoires peuvent toujours se recharger ou charger votre Mac, même si vous choisissez Ne pas autoriser.

## Modifier le réglage autorisant la connexion des accessoires

Par défaut, votre ordinateur portable Mac avec puce Apple vous demande d’autoriser la connexion d’un accessoire nouveau ou inconnu. Pour modifier ce comportement :

- Dans le menu Pomme , choisissez Réglages Système.

- Sélectionnez Confidentialité et sécurité.

- Faites défiler l’écran vers le bas et cliquez sur Accessoires, puis choisissez un réglage dans le menu situé en regard de l’option « Autoriser les accessoires à se connecter » :

- Toujours demander : approuvez manuellement chaque accessoire, à chaque connexion.

- Demander pour les nouveaux accessoires : approuvez manuellement les nouveaux accessoires lors de leur première connexion (réglage par défaut).

- Autoriser automatiquement au déverrouillage : approuvez automatiquement les accessoires lors de leur connexion à votre Mac déverrouillé.

- Toujours autoriser : approuvez automatiquement tous les accessoires lors de leur connexion.

[Image: Fenêtre Réglages Système affichant les réglages Confidentialité et sécurité sur Mac, permettant de modifier la configuration de l’option Autoriser les accessoires à se connecter.]

Sur les ordinateurs portables Mac avec puce Apple supervisés, les administrateurs peuvent contrôler ce réglage : [Gérer ce réglage à l’aide d’Apple Configurator](https://support.apple.com/guide/deployment/depf8a4cb051) .

## Si vous utilisez votre ordinateur portable Mac avec le couvercle fermé

Vous devez tout d’abord autoriser un écran externe, une souris et un clavier à se connecter à votre ordinateur portable Mac. Vous pouvez ensuite utiliser votre Mac le couvercle fermé (ou avec une station d’accueil dans laquelle vous placez votre Mac avec le couvercle fermé) et autoriser d’autres accessoires à se connecter sans ouvrir le couvercle.
