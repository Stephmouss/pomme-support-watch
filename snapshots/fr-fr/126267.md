# Imprimer des fichiers PDF comportant différents formats de papier sur Mac

Pour imprimer correctement un fichier PDF contenant des pages de différents formats (par exemple, Lettre, Légal, A4 ou A5), faites glisser le fichier PDF dans la liste d’attente d’impression adéquate du Centre d’impression. Votre imprimante saura alors dans quel format de papier imprimer chaque page.

## Éléments requis

Pour imprimer en plusieurs formats de papier à l’aide du logiciel intégré de votre ordinateur, vous avez besoin de [macOS Sequoia 15 ou version ultérieure](https://support.apple.com/fr-fr/109033) et d’une imprimante compatible avec AirPrint qui prend en charge le langage d’impression PDF. Vérifiez les caractéristiques techniques de votre imprimante pour savoir quels langages elle prend en charge.

## Imprimer des fichiers PDF comportant différents formats de papier

- [Utilisez Spotlight](https://support.apple.com/guide/mac-help/mchlp1008/mac) pour rechercher et ouvrir le Centre d’impression. Vous pouvez également l’ouvrir à partir du dossier Utilitaires de votre dossier Applications ou en procédant comme suit :

- Dans le menu Pomme , choisissez Réglages Système.

- Cliquez sur Imprimantes et scanners dans la barre latérale, puis cliquez sur votre imprimante à droite.

- Cliquez sur le bouton Liste d’attente d’impression.

- Si le Centre d’impression affiche plusieurs imprimantes, assurez-vous que la bonne imprimante est sélectionnée.

- Pour envoyer le document à l’imprimante, faites glisser le fichier PDF depuis le Finder vers la liste d’attente d’impression sur le côté droit du Centre d’impression. Si vous le faites glisser vers l’icône du Centre d’impression dans le Finder ou le Dock, il sera imprimé par votre [imprimante par défaut](https://support.apple.com/guide/mac-help/mchlp1036/mac) .

## Informations supplémentaires

Pour créer un fichier PDF comportant différents formats de papier, vous pouvez [enregistrer un fichier PDF](https://support.apple.com/guide/mac-help/mchlp153/mac) distinct pour chaque format de papier, puis [combiner ces fichiers PDF](https://support.apple.com/guide/preview/prvw43696/mac) . Lorsque vous les combinez, vous pouvez réorganiser les pages dans l’ordre dans lequel vous souhaitez les imprimer.
