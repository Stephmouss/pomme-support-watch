# Conversion de plans à 360° dans Final Cut Pro

Avec Final Cut Pro, vous pouvez mélanger des plans monoscopiques à 360° et des plans stéréoscopiques à 360° dans vos projets sur Mac.

Vous pouvez convertir un plan monoscopique à 360° pour l’utiliser dans un projet stéréoscopique à 360° ou, à l’inverse, convertir un plan stéréoscopique à 360° pour l’utiliser dans un projet monoscopique à 360°.

## Convertir un plan monoscopique en plan stéréoscopique

Vous pouvez convertir un plan monoscopique en plan stéréoscopique supérieur ou inférieur. Lorsqu’un plan monoscopique est converti en plan stéréoscopique, la perception de la profondeur propre aux véritables plans stéréoscopiques n’est pas reproduite. À la place, la même image est reproduite dans les deux vues.

- Cliquez sur Final Cut Pro > Préférences > Montage, puis sur « Pourcentages » dans le menu local Unités de l’inspecteur.

- Dans le navigateur, sélectionnez le plan monoscopique que vous souhaitez convertir, puis cliquez sur Fenêtre > Afficher dans l’espace de travail > Inspecteur (ou appuyez sur les touches Commande + 5) pour ouvrir l’inspecteur.

- Cliquez sur le bouton Infos dans l’inspecteur, puis cliquez sur Au-dessus/En dessous dans le menu local Mode Stéréoscopie. Une fois la conversion effectuée, l’image apparaît au format 1:1 dans le visualiseur.

- Sélectionnez le plan dans le navigateur, puis cliquez sur Plan > Ouvrir un plan pour l’ouvrir dans la timeline. Si une boîte de dialogue apparaît et vous demande si vous souhaitez modifier le contenu du plan, cliquez sur Continuer.

- Dans l’inspecteur, cliquez sur le bouton Inspecteur Vidéo , passez le pointeur de votre souris sur Transformer, puis cliquez sur Afficher. Définissez les paramètres de transformation suivants :

[Image: Aucun texte de remplacement pour l’image]

- Définissez la variable « Position Y » sur 25 %.

- Définissez la variable « Échelle Y » sur 50 %.

- Cliquez sur le plan dans la timeline tout en appuyant sur la touche Option, puis faites-le glisser vers le haut pour créer une copie de plan connecté. Si le plan comprend une piste audio, copiez uniquement la partie vidéo.

- Sélectionnez le plan connecté, puis vérifiez que la case « Transformer » est cochée dans l’inspecteur vidéo. Survolez ensuite la commande « Transformer » avec le pointeur de la souris, cliquez sur Afficher, puis définissez la variable « Position Y » sur -25 %.

## Convertir un plan stéréoscopique en plan monoscopique

Seuls les plans stéréoscopiques supérieurs et inférieurs peuvent être convertis en plans monoscopiques.

- Cliquez sur Final Cut Pro > Préférences > Montage, puis sur « Pourcentages » dans le menu local Unités de l’inspecteur.

- Dans le navigateur, sélectionnez le plan stéréoscopique à 360° que vous souhaitez convertir, puis cliquez sur Fenêtre > Afficher dans l’espace de travail > Inspecteur (ou appuyez sur les touches Commande + 5) pour ouvrir l’inspecteur.

- Cliquez sur le bouton Infos dans l’inspecteur, puis cliquez sur Monoscopique dans le menu local Mode Stéréoscopie. Une fois la conversion effectuée, l’image apparaît au format 2:1 dans le visualiseur.

[Image: Aucun texte de remplacement pour l’image]

- Sélectionnez le plan s’il ne l’est plus, puis cliquez sur Plan > Ouvrir un plan. Le contenu du plan apparaît dans la timeline. Il est possible qu’une boîte de dialogue s’affiche et vous demande si vous souhaitez modifier le contenu du plan. Si tel est le cas, cliquez sur Continuer.

- Cliquez sur l’icône de l’inspecteur vidéo. Une fois dans l’inspecteur vidéo, survolez la commande « Transformer » avec le pointeur de la souris et cliquez sur Afficher. Définissez les paramètres de transformation suivants :

- Définissez la variable « Position Y » sur -50 %.

- Définissez la variable « Échelle Y » sur 200 %.

- Dans l’inspecteur vidéo, survolez la commande « Recadrer » avec le pointeur de la souris, cliquez sur Afficher, puis définissez la variable « En bas » sur 50.

## Partager votre plan

Une fois votre plan converti, vous pouvez le partager sous la forme d’un fichier master Apple ProRes.

- Sélectionnez le plan dans le navigateur, puis cliquez sur Partager > Fichier master.

- Dans l’onglet « Infos », cliquez sur le nom du fichier pour le renommer, modifier sa description et le nom du créateur, et ajouter ou supprimer des mots clés.

- Cliquez sur Réglages, puis procédez comme suit :

- Dans le menu local « Codec vidéo », choisissez n’importe quel format Apple ProRes.

- Dans le menu local « Une fois terminé », cliquez sur « Ne rien faire ».

- Cliquez sur Suivant, choisissez un emplacement pour vos fichiers, puis cliquez sur Enregistrer.

Une notification vous informe lorsque votre fichier a bien été partagé. Vous pouvez maintenant importer à nouveau le plan dans Final Cut Pro et l’utiliser en tant que plan natif dans son nouveau format.
