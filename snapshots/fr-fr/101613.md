# À propos des modes d’alimentation de votre Mac

Les modes d’alimentation vous permettent d’adapter les performances de votre Mac à la charge de travail.

## Mode Économie d’énergie

[Le mode économie d’énergie](https://support.apple.com/guide/mac-help/change-battery-preferences-mchlfc3b7879/mac) réduit la consommation d’énergie pour augmenter l’autonomie de la batterie. Sous macOS Sequoia 15.1 ou version ultérieure, le mode économie d’énergie réduit également le bruit du ventilateur pour les tâches nécessitant des environnements silencieux (sur les modèles dotés d’un système de refroidissement actif) et permet une consommation d’énergie réduite si votre Mac reste allumé en permanence.

Le mode économie d’énergie, qui vous permet de réduire le bruit du ventilateur (sur les modèles dotés d’un système de refroidissement actif) et de bénéficier d’une consommation d’énergie réduite, est disponible sur les modèles suivants :

## Mode Performance

Le mode Performance permet aux ventilateurs de tourner plus rapidement. La capacité de refroidissement supplémentaire permet au système de fournir des performances supérieures dans le cadre de charges de travail très intensives. Lorsque le mode Performance est activé, le ventilateur peut émettre plus de bruit.

Le mode Performance peut accélérer les processus exigeants en ressources de traitement graphique, tels que l’étalonnage colorimétrique de vidéos aux formats 8K ProRes 4444 et 8K DNxHR. Lorsque le mode Performance est activé, vous pouvez constater une lecture plus fluide et une exportation plus rapide dans les applications de montage vidéo et 3D.

Vous pouvez utiliser le mode Performance sur les modèles suivants :

- [MacBook Pro (14 pouces, M5 Pro ou M5 Max)](https://support.apple.com/fr-fr/108052)

- [MacBook Pro (16 pouces, M5 Pro ou M5 Max)](https://support.apple.com/fr-fr/108052)

- [MacBook Pro (14 pouces, 2024) avec puce M4 Pro ou M4 Max](https://support.apple.com/fr-fr/108052)

- [MacBook Pro (16 pouces, 2024)](https://support.apple.com/fr-fr/108052)

- [MacBook Pro (14 pouces, novembre 2023) avec M3 Max](https://support.apple.com/fr-fr/108052)

- [MacBook Pro (16 pouces, novembre 2023) avec M3 Max](https://support.apple.com/fr-fr/108052)

- [MacBook Pro (16 pouces, 2023) avec M2 Max](https://support.apple.com/fr-fr/108052)

- [MacBook Pro (16 pouces, 2021) avec M1 Max](https://support.apple.com/fr-fr/108052)

- [Mac mini (2024) avec puce M4 Pro](https://support.apple.com/fr-fr/102852)

Pour les MacBook Pro 14 pouces avec puce M4 Pro ou M5 Pro, l’ [adaptateur secteur USB-C 96 W](https://www.apple.com/fr/shop/product/mw2l3zm/a/adaptateur-secteur-usb%E2%80%91c-96-w) est recommandé pour utiliser le mode Performance pendant la charge.

## Sélectionner un mode d’alimentation

Par défaut, votre Mac est réglé sur le mode Automatique pour équilibrer la consommation d’énergie et les performances.

Vous pouvez configurer des modes d’énergie différents qui seront activés lorsque votre Mac fonctionne sur batterie et lorsqu’il est connecté à son adaptateur secteur. Les modes d’alimentation peuvent être utilisés que votre Mac soit connecté à une source d’alimentation ou non.

Sous macOS Ventura ou version ultérieure :

- Dans le menu Pomme , choisissez Réglages Système (ou Préférences Système), puis cliquez sur Batterie ou (Énergie sur les ordinateurs de bureau).

- Choisissez Mode économie d’énergie, Automatique ou Mode Performance dans le menu local « Sur batterie » ou « Sur adaptateur secteur », sous Mode d’énergie. Sous macOS Sequoia 15.1 ou version ultérieure, vous pouvez également sélectionner les modes d’énergie dans le Centre de contrôle.

[Image: Options du mode Énergie dans les réglages Batterie sur Mac.]

Sous macOS Monterey ou version antérieure :

- Dans le menu Pomme , choisissez Préférences Système, puis cliquez sur Batterie.

- Cliquez sur Batterie ou Adaptateur secteur dans la barre latérale, puis choisissez Économie d’énergie, Automatique ou Mode Performance dans le menu local Mode d’énergie.

[Image: Changement du mode d’énergie dans Préférences Système sur Mac.]

## Vérifier si un mode d’alimentation est activé

Pour voir si le mode Économie d’énergie ou le mode Performance est activé, cliquez sur l’icône de batterie ou d’éclair dans la barre des menus pour afficher le menu d’état de la batterie.
