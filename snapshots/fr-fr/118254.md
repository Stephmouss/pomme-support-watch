# Installer des apps d’entreprise personnalisées sous iOS, iPadOS et visionOS

Découvrez comment installer et approuver les apps personnalisées créées par votre entreprise.

Cet article est destiné aux administrateurs système d’un établissement d’enseignement, d’une entreprise ou de toute autre organisation.

[L’Apple Developer Enterprise Program](https://developer.apple.com/programs/enterprise/) peut vous permettre de créer et de distribuer des apps d’entreprise propriétaires destinées à un usage interne. Toutefois, vous devez approuver ces apps avant de pouvoir les ouvrir.

Apple recommande d’utiliser une solution de gestion des appareils mobiles (MDM) pour distribuer les apps. Les apps installées de cette manière sont gérées, l’approbation se fait automatiquement et cela n’exige pas qu’un utilisateur approuve manuellement le développeur.

Vous pouvez également installer des apps à partir d’un site web sécurisé géré par votre entreprise. Dans le cas d’une installation manuelle, vous devez également les approuver manuellement.

## Approuver les développeurs d’apps d’entreprise installées manuellement

- Lors de la première ouverture d’une app d’entreprise installée manuellement, une notification vous indique que son développeur n’a pas été approuvé sur votre appareil et que vous ne pourrez donc pas utiliser l’app. Touchez Annuler et passez à l’étape suivante.

[Image: Message Développeur Entreprise non approuvé affiché sur l’écran de l’iPhone, empêchant l’ouverture de l’app tant que le développeur n’est pas approuvé.]

- Touchez Réglages > Général > VPN et gestion de l’appareil.

- Dans la section App d’entreprise, touchez le nom du développeur de l’app.

[Image: Écran d’iPhone affichant le menu VPN et gestion de l’appareil.]

- Touchez Se fier à « [nom du développeur] » pour poursuivre. Sous iOS 18, iPadOS 18 et visionOS 2 et versions ultérieures, touchez « Autoriser et redémarrer » pour approuver le développeur. Dans les versions logicielles antérieures, touchez Se fier pour approuver.

- Après le redémarrage de votre appareil, suivez les instructions à l’écran pour terminer le processus et approuver le développeur.

Une fois le développeur approuvé, vous pouvez installer manuellement d’autres apps de ce développeur et les ouvrir immédiatement.

Après la première vérification d’une app, votre iPhone, iPad ou Apple Vision Pro doit procéder régulièrement à une nouvelle vérification du certificat de son développeur afin de prolonger l’approbation. Si ces nouvelles vérifications n’aboutissent pas, un message peut apparaître pour vous informer que l’approbation expirera bientôt.

## Supprimer l’approbation accordée à un développeur d’apps

Lorsque vous approuvez un développeur d’apps, celui-ci est considéré comme fiable jusqu’à ce que vous supprimiez toutes ses apps à l’aide du bouton Supprimer l’app.

[Image: Écran d’iPhone affichant un message permettant de supprimer une app d’entreprise.]

## Si une app installée manuellement n’est pas vérifiée

Une connexion à Internet est requise afin que le certificat du développeur de l’app puisse être vérifié lors de l’approbation. Si vous vous trouvez derrière un coupe-feu, assurez-vous que celui-ci est configuré de sorte à autoriser les connexions à l’adresse https://ppq.apple.com. Si vous ne disposez d’aucune connexion à Internet, la vérification ne peut être effectuée et le message Non vérifié s’affiche. Pour utiliser l’app, connectez-vous à Internet et touchez le bouton Vérifier l’app.

[Image: Écran d’iPhone affichant un message permettant de vérifier si une app d’entreprise peut être approuvée.]
