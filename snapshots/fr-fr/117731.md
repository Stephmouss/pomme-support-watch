# Fixer et jumeler vos ZEISS Optical Inserts

Une fois que vous avez acheté une paire de ZEISS Optical Inserts, vous devez les fixer à votre Apple Vision Pro, puis les jumeler.

[Fixer et jumeler vos ZEISS Optical Inserts](https://support.apple.com/fr-fr/117731#attach)

[Jumeler ou annuler le jumelage de vos ZEISS Optical Inserts sous Réglages](https://support.apple.com/fr-fr/117731#pair)

[Trouver votre code de jumelage ou votre numéro de série](https://support.apple.com/fr-fr/117731#pairing_code)

[Si vous ne parvenez pas à sélectionner vos ZEISS Optical Inserts](https://support.apple.com/fr-fr/117731#troubleshoot)

## Fixer et jumeler vos ZEISS Optical Inserts

- Placez votre Apple Vision Pro à l’intérieur de sa housse et posez-le sur une surface plane.

- Tenez un ZEISS Optical Insert par les bords pour éviter de laisser des traces de doigt. Chaque ZEISS Optical Insert est marqué au laser d’un « L » ou d’un « R » pour indiquer la gauche ou la droite. La ligne blanche en haut de chaque ZEISS Optical Insert indique le haut. Positionnez le ZEISS Optical Insert avec l’indicateur « L » ou « R » dirigé vers l’intérieur, vers l’arête du nez.

- Placez le ZEISS Optical Insert au-dessus de l’écran. Il s’enclenche magnétiquement lorsqu’il est connecté. Répétez l’opération pour le deuxième ZEISS Optical Insert. Vous devez fixer les deux ZEISS Optical Inserts, même si vous n’avez besoin d’une correction de la vue que pour un seul œil.

- Mettez votre Vision Pro, assurez-vous de le manipuler par la monture, et suivez les instructions à l’écran pour ajuster l’alignement des écrans.

- Au début de la configuration du regard, un message vous invitant à jumeler vos ZEISS Optical Inserts s’affiche. Si vous ne voyez pas l’invitation, appuyez quatre fois sur le bouton supérieur, tournez la Digital Crown pour sélectionner Jumeler de nouveaux inserts optiques, et appuyez sur la Digital Crown pour commencer.

- Recherchez le code de jumelage fourni dans l’emballage de vos ZEISS Optical Inserts, ou dans l’app Santé. [Vous ne trouvez pas votre code de jumelage ?](https://support.apple.com/fr-fr/117731#pairing_code) Si vous n’arrivez pas à lire votre code de jumelage ou s’il ne fonctionne pas :

- Essayez d’augmenter l’éclairage de la pièce dans laquelle vous vous trouvez.

- Enregistrez vos ZEISS Optical Inserts à l’adresse [https://myzeissvision.zeiss.com/](https://myzeissvision.zeiss.com/) , puis utilisez le code généré sur cette page.

## Jumeler ou annuler le jumelage de vos ZEISS Optical Inserts sous Réglages

Votre Apple Vision Pro vous invite automatiquement à effectuer le jumelage une fois que vous avez fixé vos ZEISS Optical Inserts. Vous pouvez également configurer ou jumeler vos ZEISS Optical Inserts à tout moment sous Réglages. Vérifiez que vous disposez du code de jumelage fourni avec vos ZEISS Optical Inserts. [Vous ne trouvez pas votre code de jumelage ?](https://support.apple.com/fr-fr/117731#pairing_code)

Si vous avez un iPhone ou un iPad associé au même compte Apple que votre Apple Vision Pro, un dossier de santé est automatiquement ajouté à l’app Santé, contenant votre ordonnance, votre numéro de série et le code de jumelage de vos ZEISS Optical Inserts. Cela vous permet d’accéder facilement au code de jumelage directement sur votre iPhone ou votre iPad.

### Jumeler vos ZEISS Optical Inserts sous Réglages

- Fixez vos ZEISS Optical Inserts, si ce n’est pas déjà fait.

- Mettez votre appareil et assurez-vous que le suivi du regard et des mains est configuré.

- Appuyez quatre fois sur le bouton supérieur, puis utilisez la Digital Crown pour sélectionner Jumeler de nouveaux inserts optiques.

- Ou accédez à Réglages, puis touchez Regards et mains. Sous Affichage et inserts optiques, sélectionnez Configurer de nouveaux inserts optiques.

- Procédez au jumelage en scannant le code présent dans l’emballage. [Vous ne trouvez pas votre code de jumelage ?](https://support.apple.com/fr-fr/117731#pairing_code) Si vous n’arrivez pas à lire votre code de jumelage ou s’il ne fonctionne pas :

- Essayez d’augmenter l’éclairage de la pièce dans laquelle vous vous trouvez.

- Enregistrez vos ZEISS Optical Inserts à l’adresse [https://myzeissvision.zeiss.com/](https://myzeissvision.zeiss.com/) , puis utilisez le code généré sur cette page.

Vous pouvez également suivre ces instructions pour jumeler un autre jeu de ZEISS Optical Inserts avec votre Apple Vision Pro. Avant de changer de paire de ZEISS Optical Inserts, si une invite s’affiche, entrez votre code d’accès, puis utilisez la Digital Crown pour sélectionner le jeu de ZEISS Optical Inserts approprié.

### Supprimer un jumelage

Si vous n’avez plus besoin d’une paire spécifique de ZEISS Optical Inserts et que vous souhaitez les retirer de votre appareil :

- Accédez à Réglages, puis touchez Regards et mains.

- Sous Affichage et inserts optiques, sélectionnez vos ZEISS Optical Inserts.

- Sélectionnez Oublier ces inserts optiques.

## Trouver votre code de jumelage ou votre numéro de série

Vos ZEISS Optical Inserts sont fournis avec un code de jumelage dont vous avez besoin pour la configuration. Il se trouve dans l’emballage, sur une carte séparée. Veillez à bien conserver ce code. Il vous sera utile si vous avez besoin d’aide avec vos ZEISS Optical Inserts. Si vous ne trouvez pas votre code de jumelage :

- Dans l’app Santé, accédez à Parcourir, touchez Mensurations, puis Ordonnance ophtalmologique.

- Regardez dans l’emballage de vos ZEISS Optical Inserts.

- Vous pouvez également vous rendre à l’adresse [https://myzeissvision.zeiss.com/](https://myzeissvision.zeiss.com/) pour enregistrer vos ZEISS Optical Inserts à l’aide de leur numéro de série. Une fois que vous avez enregistré vos ZEISS Optical Inserts, vous pouvez les rechercher et accéder à votre code de jumelage.

Le numéro de série est imprimé au dos du cadre de chaque ZEISS Optical Insert. Si vous avez ajouté votre ordonnance à l’app Santé, vous pouvez également retrouver votre numéro de série dans la section Ordonnance ophtalmologique.

## Si vous ne parvenez pas à sélectionner vos ZEISS Optical Inserts

- Si vos ZEISS Optical Inserts ou votre module optique sont sales ou endommagés, vous ne pourrez peut-être pas enregistrer vos ZEISS Optical Inserts, ni les sélectionner pour les utiliser sur votre Vision Pro.

- Assurez-vous que les deux ZEISS Optical Inserts sont correctement fixés à votre Vision Pro.

- Si vous avez plusieurs paires de ZEISS Optical Inserts, assurez-vous que la paire qui est fixée est une paire assortie.

- Assurez-vous de ne pas utiliser d’accessoires tiers tels que des protections d’objectif.
