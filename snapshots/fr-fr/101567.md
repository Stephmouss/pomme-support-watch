# Modifier le mot de passe de votre compte Apple

Découvrez comment utiliser un appareil de confiance pour modifier le mot de passe de votre compte Apple ou celui d’un enfant.

L’identifiant Apple est désormais un compte Apple. Vous pouvez toujours vous connecter avec la même adresse e-mail ou les mêmes numéro de téléphone et mot de passe.

## Utiliser un appareil Apple de confiance

La méthode la plus simple et la plus sûre de modifier le mot de passe de votre compte Apple consiste à utiliser votre iPhone ou un autre appareil de confiance, à savoir un appareil sur lequel vous vous êtes déjà connecté à votre compte Apple à l’aide de l’identification à deux facteurs, afin que nous sachions qu’il s’agit du vôtre.

## Modifier le mot de passe associé à votre compte Apple sur votre iPhone, iPad, Apple Watch ou Apple Vision Pro

- Ouvrez l’app Réglages, puis touchez [votre nom].

- Touchez Connexion et sécurité.

- Touchez Modifier le mot de passe.

[Image: iPhone affichant le bouton Modifier le mot de passe dans les réglages.]

- Suivez les instructions à l’écran pour modifier le mot de passe de votre compte Apple.

Il se peut que vous deviez attendre une heure avant de modifier le mot de passe de votre compte Apple ou d’autres réglages de sécurité importants. En savoir plus [sur la protection en cas de vol de l’appareil](https://support.apple.com/fr-fr/120340) et sur les situations où un délai de sécurité peut être nécessaire.

## Modifier le mot de passe de votre compte Apple sur votre Mac

- Choisissez le menu Apple , puis Réglages Système.

- Cliquez sur [votre nom], puis sur Connexion et sécurité.

- Cliquez sur Modifier le mot de passe.

- Saisissez le mot de passe utilisé pour déverrouiller votre Mac. Suivez les instructions à l’écran pour modifier le mot de passe de votre compte Apple.

[Image: Mac affichant les réglages de connexion et de sécurité du compte Apple.]

## Modifier le mot de passe de votre compte Apple sur le Web

Dans la mesure du possible, le site web du compte Apple vous redirige vers un appareil de confiance pour gérer votre compte Apple. Toutefois, si vous ne disposez pas d’un appareil de confiance, vous pourrez peut-être modifier le mot de passe de votre compte Apple sur le web.

Rendez-vous sur [account.apple.com](https://account.apple.com) et connectez-vous à votre compte Apple. Sélectionnez ensuite Connexion et sécurité et choisissez Mot de passe.

## Modifier le mot de passe associé à votre compte Apple sur votre iPhone, iPad ou Apple Vision Pro

Si vous possédez un iPhone, un iPad ou un Apple Vision Pro doté de la [dernière version d’iOS, d’iPadOS](https://support.apple.com/fr-fr/118575) ou de [visionOS](https://support.apple.com/fr-fr/118481) et que l’identification à deux facteurs est activée pour votre compte Apple, vous pouvez modifier le mot de passe associé au compte Apple d’un compte enfant dans votre groupe de partage familial. Vous pouvez également modifier le mot de passe du compte d’un enfant dans Réglages sur son propre appareil.

- Touchez Réglages, puis Famille. Sélectionnez le compte de votre enfant.

- Touchez Compte Apple et mot de passe.

- Touchez Modifier le mot de passe de [nom de l’enfant].

- Suivez les instructions à l’écran pour modifier le mot de passe du compte Apple de l’enfant.

[En savoir plus sur un compte Apple pour votre enfant de moins de 13 ans (âge variable en fonction de la région)](https://support.apple.com/fr-fr/102617)
