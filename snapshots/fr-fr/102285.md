# Utiliser les réseaux Wi-Fi 6E ou Wi-Fi 7 avec les appareils Apple

Les appareils Apple en mesure de se connecter à un réseau Wi‑Fi 6E ou Wi‑Fi 7 peuvent utiliser la bande Wi‑Fi de 6 GHz du réseau pour offrir des connexions Wi‑Fi plus rapides et plus fiables. Ils peuvent également être configurés pour utiliser uniquement les bandes de 2,4 GHz ou de 5 GHz de ce réseau.

## Ce dont vous avez besoin pour vous connecter à un réseau Wi-Fi 6E ou Wi-Fi 7

Pour vous connecter à un réseau Wi-Fi 6E ou Wi-Fi 7, vous devez disposer d’un appareil Apple compatible avec le Wi-Fi 6E ou une version ultérieure :

- [MacBook Pro](https://support.apple.com/fr-fr/108052) commercialisés à partir de 2023

- [MacBook Air](https://support.apple.com/fr-fr/102869) commercialisés à partir de 2024

- MacBook Neo

- [iMac](https://support.apple.com/fr-fr/108054) commercialisés à partir de 2023

- [Mac mini](https://support.apple.com/fr-fr/102852) commercialisés à partir de 2023

- [Mac Studio](https://support.apple.com/fr-fr/102231) commercialisés à partir de 2023

- [Mac Pro](https://support.apple.com/fr-fr/102887) commercialisés à partir de 2023

- [iPhone](https://support.apple.com/fr-fr/108044) 15 Pro, iPhone 15 Pro Max ou modèle ultérieur (à l’exception des iPhone 15, iPhone 15 Plus, iPhone 16e et iPhone 17e)

- [iPad Pro](https://support.apple.com/fr-fr/108043#ipadpro) 11 pouces (4e génération), iPad Pro 12,9 pouces (6e génération) ou version ultérieure

- [iPad Air](https://support.apple.com/fr-fr/108043#ipadair) 11 pouces (M2), iPad Air 13 pouces (M2), ou version ultérieure

- [iPad mini](https://support.apple.com/fr-fr/108043#ipadmini) (A17 Pro) ou version ultérieure

Pour créer un réseau Wi‑Fi 6E, vous avez besoin d’un routeur ou d’un point d’accès Wi‑Fi compatible avec le Wi‑Fi 6E. Pour créer un réseau Wi‑Fi 7, vous avez besoin d’un routeur ou d’un point d’accès Wi‑Fi compatible avec le Wi‑Fi 7.

## À propos des réseaux Wi-Fi 6E et Wi-Fi 7 avec compatibilité limitée

Pour de meilleures performances avec les appareils Apple, le routeur Wi-Fi fournissant le réseau doit utiliser un seul nom de réseau (SSID) sur toutes ses bandes Wi-Fi : la bande de 2,4 GHz, la bande de 5 GHz et la bande de 6 GHz.

Si le routeur n’utilise pas le même nom pour les trois bandes, votre appareil identifie le réseau comme ayant une compatibilité limitée. Il trouve ensuite le nom du réseau 5 GHz correspondant et vous demande si vous souhaitez le rejoindre pour une meilleure compatibilité :

[Image: Boîte de dialogue iOS demandant si vous souhaitez également rejoindre le réseau Wi-Fi 5G]

- Si vous sélectionnez OK ou Se connecter, votre appareil se connecte au réseau 5 GHz sans bénéficier de certains des avantages du Wi-Fi 6E ou du Wi-Fi 7.

- Si vous sélectionnez Plus tard, votre appareil continue d’utiliser le réseau 6 GHz, mais votre expérience globale avec certaines activités sur le réseau risque de ne pas se dérouler comme prévu.

Si vous êtes administrateur du routeur Wi-Fi, vous pouvez, sur sa page web de configuration ou sur son app, modifier le nom de chaque bande afin qu’il soit le même pour toutes. Votre appareil peut ensuite se connecter au réseau 6 GHz en bénéficiant d’une parfaite compatibilité. Pour en savoir plus sur les noms de réseau et les autres réglages, consultez les [réglages recommandés pour les routeurs et les points d’accès Wi-Fi](https://support.apple.com/fr-fr/102766) .

## Comment désactiver le mode Wi-Fi 6E sur votre appareil

Pour les réseaux Wi-Fi 6E ou Wi-Fi 7 qui utilisent un nom de réseau unique (SSID) comme cela est recommandé, si vous rencontrez des problèmes de réseau, vous pouvez désactiver le mode Wi-Fi 6E lorsque votre appareil est connecté à ce réseau. Ainsi, votre appareil n’utilisera plus la bande 6 GHz de ce réseau. L’utilisation du Wi-Fi 6E ou Wi-Fi 7 sur d’autres réseaux n’est pas affectée.

### Mac

- Dans le menu Apple , choisissez Réglages Système.

- Cliquez sur Wi-Fi, puis sur le bouton Détails affiché à côté du nom du réseau Wi-Fi 6E auquel vous êtes connecté(e).

- Dans le menu local à côté du mode Wi-Fi 6E, choisissez Désactivé. Cette option apparaît uniquement lorsque votre [appareil compatible](https://support.apple.com/fr-fr/102285#requirements) est connecté à un réseau Wi-Fi 6E ou Wi-Fi 7.

### iPhone, iPad

- Ouvrez Réglages, puis touchez Wi-Fi.

- Touchez le nom du réseau Wi-Fi 6E auquel vous êtes connecté(e).

- Touchez le mode Wi-Fi 6E, puis Désactivé. Cette option apparaît uniquement lorsque votre [appareil compatible](https://support.apple.com/fr-fr/102285#requirements) est connecté à un réseau Wi-Fi 6E ou Wi-Fi 7.
