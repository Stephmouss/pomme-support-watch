# Si vous recevez le message « Données iCloud non synchronisées »

Si vos données iCloud ne se synchronisent pas, vérifiez si vous avez des pastilles dans Réglages. Suivez ensuite les instructions qui s’affichent sur votre appareil.

- Ouvrez Réglages sur votre appareil.

- Vérifiez si des pastilles sont présentes.

- Touchez ou cliquez sur la pastille, puis suivez les instructions qui s’affichent.

- Si un message vous y invite, authentifiez votre compte.

Si le message « Données iCloud non synchronisées » apparaît toujours après l’authentification de votre compte, [contactez l’Assistance Apple](https://getsupport.apple.com/?caller=kbase) .
