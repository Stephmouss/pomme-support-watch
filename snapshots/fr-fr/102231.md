# Identifier le modèle de votre Mac Studio

Consultez ces informations pour savoir quel modèle de Mac Studio vous possédez et où il s’inscrit dans l’histoire du Mac Studio.

## Trouver le nom de votre modèle de Mac

Le moyen le plus simple pour trouver le nom de modèle de votre Mac consiste à sélectionner la commande À propos de ce Mac dans le menu Apple  situé dans l’angle de l’écran. Découvrez la procédure à suivre pour [trouver le nom de modèle ou le numéro de série de votre Mac](https://support.apple.com/fr-fr/102767) , même lorsque vous n’avez pas votre Mac ou qu’il ne démarre pas complètement.
