# Identifier le modèle de votre Mac Studio

Consultez ces informations pour savoir quel modèle de Mac Studio vous possédez et où il s’inscrit dans l’histoire du Mac Studio.

## Trouver le nom de modèle de votre Mac

Le moyen le plus simple pour trouver le nom de modèle de votre Mac consiste à sélectionner la commande À propos de ce Mac dans le menu Pomme  situé dans l’angle de l’écran. Découvrez comment [trouver le nom de modèle ou le numéro de série de votre Mac](https://support.apple.com/fr-fr/102767) , même lorsque vous n’avez pas accès à votre Mac ou que celui-ci ne démarre pas complètement.

## Mac Studio (2025)

[Image: Avant et arrière du Mac Studio (2025).]

Puce : M4 Max

Ports avant : deux ports USB-C

Identifiant du modèle : Mac16,9

Dernier système d’exploitation compatible : macOS Tahoe 26

Références : MU963xx/A

[Caractéristiques techniques du Mac Studio (2025)](https://support.apple.com/fr-fr/122211)

[Guide d’utilisation du Mac Studio (2025)](https://support.apple.com/guide/mac-studio/welcome/mac)
