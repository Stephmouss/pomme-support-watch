# Verrouillage d’activation du Mac

Le verrouillage d’activation est conçu pour empêcher une tierce personne d’utiliser votre Mac en cas de perte ou de vol.

## À propos du verrouillage d’activation

Le verrouillage d’activation permet de sécuriser votre Mac, y compris [en cas de perte ou de vol](https://support.apple.com/fr-fr/102481) , et peut accroître vos chances de le retrouver. Lorsque le verrouillage d’activation est en place, toute personne qui voudrait désactiver la fonctionnalité Localiser, effacer les données de votre Mac ou le réactiver et l’utiliser devra au préalable saisir le mot de passe de votre compte Apple ou le code d’accès de l’appareil. Même si vous effacez à distance les données de votre Mac, le verrouillage d’activation continuera d’empêcher d’autres personnes de le réactiver sans votre autorisation. Pour cela, il vous suffit de laisser la fonctionnalité Localiser activée et de vous souvenir de l’adresse e-mail/du numéro de téléphone et du mot de passe de votre compte Apple.

## Activer le verrouillage d’activation

Si votre Mac dispose de la [configuration système requise pour le verrouillage d’activation](https://support.apple.com/fr-fr/102541#requirements) , activez la fonctionnalité [Localiser](https://support.apple.com/fr-fr/102648) pour mettre en place le verrouillage d’activation. Celui-ci restera activé tant que la fonctionnalité Localiser sera, elle aussi, activée.

- Dans le menu Apple , choisissez Réglages Système.

- Cliquez sur votre nom dans la barre latérale, puis cliquez sur iCloud à droite.

- Cliquez sur le bouton Tout afficher (ou sur le bouton Afficher plus d’apps).

- Cliquez sur Localiser mon Mac, puis cliquez sur le bouton pour activer la fonctionnalité.

## Désactiver le verrouillage d’activation

Pour désactiver le verrouillage d’activation, désactiver la fonctionnalité Localiser:

- Dans le menu Pomme , choisissez Réglages Système.

- Cliquez sur votre nom dans la barre latérale, puis cliquez sur iCloud à droite.

- Cliquez sur le bouton Tout afficher (ou sur le bouton Afficher plus d’apps).

- Cliquez sur Localiser mon Mac, puis cliquez sur le bouton pour désactiver la fonctionnalité. Saisissez le mot de passe de votre compte Apple lorsque l’invite correspondante s’affiche.

Ou si le Mac est hors ligne, vous pouvez désactiver le verrouillage d’activation sur le Web :

- Rendez-vous sur la page [www.iCloud.com/find](https://www.icloud.com/find) .

- Connectez-vous à votre compte Apple.

- Sélectionnez le Mac à supprimer du compte iCloud.

- Cliquez sur Supprimer.

Lorsqu’une pièce d’un produit est utilisée pour en réparer un autre, cette pièce peut être associée au compte Apple d’une autre personne. Si votre [Mac avec puce Apple](https://support.apple.com/fr-fr/116943) et [macOS Tahoe 26 ou version ultérieure](https://support.apple.com/fr-fr/109033) a été préalablement réparé, ou en cas de doute, [utilisez l’Assistant de réparation pour vérifier s’il reste une réparation inachevée](https://support.apple.com/fr-fr/123128) .

## Configuration système requise pour le verrouillage d’activation

- [Mac avec puce Apple](https://support.apple.com/fr-fr/116943) doté de macOS Catalina 10.15 ou version ultérieure. La [politique de sécurité doit être définie sur Sécurité maximale](https://support.apple.com/guide/mac-help/change-startup-disk-security-settings-a-mac-mchl768f7291/mac) , c’est-à-dire le réglage par défaut.

- [Mac avec puce Apple T2 Security](https://support.apple.com/fr-fr/103265) doté de macOS Catalina 10.15 ou version ultérieure. La sécurité au démarrage doit être définie sur [Démarrage sécurisé avec l’option « Ne pas autoriser le démarrage à partir de supports externes ou amovibles »](https://support.apple.com/fr-fr/102522) , c’est-à-dire le réglage par défaut.

- [Identification à deux facteurs pour le compte Apple](https://support.apple.com/fr-fr/102660)

## Besoin d’aide supplémentaire ?

Si vous avez besoin d’aide pour désactiver le verrouillage d’activation et que vous êtes en possession d’une preuve d’achat, vous pouvez [formuler une demande d’assistance concernant le verrouillage d’activation.](https://al-support.apple.com/#/kbase)
