# Signaler les e-mails indésirables et réduire leur nombre dans Mail iCloud

Mail iCloud bloque la plupart des e-mails indésirables, ou spams, dans votre boîte de réception. Voici comment supprimer et signaler les e-mails indésirables.

## Signaler les e-mails indésirables

Pour vous assurer que l’app Mail marque automatiquement les futurs messages provenant du même expéditeur comme indésirables, vous pouvez signaler les messages comme indésirables. Lorsque vous marquez un e-mail comme indésirable, vous pouvez améliorer le filtrage de Mail iCloud et réduire le nombre de messages indésirables à venir.

### Sur votre iPhone ou iPad

- Dans l’app Mail, effectuez un balayage vers la gauche sur le message.

- Touchez Options, puis Placer dans Indésirables.

### Sur votre Mac

- Dans Mail, sélectionnez le message.

- Cliquez sur le bouton Indésirable dans la barre d’outils de Mail. Ou faites glisser le message dans le dossier Indésirables de la barre latérale.

### Sur icloud.com

- Dans Mail, sélectionnez le message.

- Cliquez sur Plus d’actions, puis choisissez Déplacer le message vers Indésirable. Ou faites glisser le message dans le dossier Indésirables de la barre latérale.

## Marquez les e-mails légitimes comme n’étant pas des e-mails indésirables

Le filtrage des e-mails indésirables peut entraîner le blocage d’un message légitime et l’empêcher d’arriver dans votre boîte de réception. Si un e-mail légitime est filtré de manière accidentelle, vous pouvez le signaler comme n’étant pas un e-mail indésirable. Les futurs messages du même expéditeur ne sont pas marqués comme indésirables et atteignent bien votre boîte de réception :

- Sur votre iPhone ou iPad, ouvrez le message dans le dossier Indésirables, touchez le bouton Déplacer vers un dossier , puis touchez Réception pour déplacer le message.

- Sur votre Mac, sélectionnez le message dans le dossier Indésirables et cliquez sur le bouton Indésirable dans la barre d’outils de Mail. Vous pouvez également faire glisser le message vers la boîte de réception dans la barre latérale.

- Sur [iCloud.com](https://www.icloud.com) , cliquez sur le dossier Indésirables dans la barre latérale et sélectionnez le message. Choisissez Déplacer le message, puis sélectionnez Boîte de réception, puis cliquez sur Déplacer. Vous pouvez également faire glisser le message vers la boîte de réception dans la barre latérale.

- Dans les autres clients de messagerie, déplacez le message depuis le dossier du courrier indésirable vers la boîte de réception.

Les e-mails venant de vos contacts iCloud ou de conversations récentes ne seront pas envoyés dans le dossier Indésirables.

Si vous remarquez que plusieurs e-mails sont retardés, retournés ou non distribués, contactez [l’Assistance iCloud](https://www.apple.com/support/icloud/) . Les e-mails placés dans le dossier Indésirables sont automatiquement supprimés au bout de 30 jours.

## Réduire la quantité de spams

Pour réduire la quantité de spams que vous recevez, n’ouvrez pas les e-mails suspects, activez l’option Protéger votre activité dans Mail, et utilisez un alias de messagerie.

### N’ouvrez pas les e-mails suspects

Supprimez tous les messages ressemblant à des e-mails indésirables, sans même les ouvrir. Découvrez comment [supprimer des e-mails sur votre iPhone ou iPad](https://support.apple.com/fr-fr/102428) , ainsi que [sur votre Mac](https://support.apple.com/guide/mail/mlhlp1001/mac) . Vous pouvez également [gérer le courrier indésirable sur icloud.com](https://support.apple.com/guide/icloud/mm6b1a2ced/icloud) .

Lorsque vous ouvrez e-mail indésirable, cela peut indiquer aux spammeurs que leur message a été ouvert dans un compte de messagerie actif.

### Modifiez les réglages de protection de la confidentialité de Mail

Les spammeurs utilisent la fonctionnalité de chargement d’images pour déterminer si votre compte de messagerie est actif. Pour désactiver le chargement automatique des images :

#### Sur un iPhone ou un iPad

- Accédez à Réglages, puis touchez Apps.

- Touchez Mail, puis sélectionnez Protection de la confidentialité.

- Activez l’option Protéger votre activité dans Mail.

#### Sur un Mac

- Dans Mail, choisissez Réglages (ou Préférences) dans le menu Mail de la barre des menus.

- Cliquez sur Confidentialité, puis sélectionnez Protéger votre activité dans Mail.

#### Sur icloud.com

- Accédez à [icloud.com/mail](https://www.icloud.com/mail/) , puis cliquez sur le bouton Réglages .

- Choisissez Confidentialité et sécurité, puis activez Protéger l’activité dans Mail.

### Utiliser un alias de messagerie iCloud ou Masquer mon adresse e-mail avec iCloud+

Vous pouvez utiliser un alias de messagerie iCloud pour empêcher les e-mails indésirables d’atteindre votre adresse e-mail iCloud principale. Avec un abonnement iCloud+, la fonctionnalité Masquer mon adresse e-mail vous permet de générer des adresses aléatoires et uniques à partager avec des sites web ou des apps et de garder votre adresse personnelle privée.

[Découvrez comment créer et utiliser un alias d’adresse e-mail sur icloud.com](https://support.apple.com/guide/icloud/mm6b1a490a/)

[Découvrez comment utiliser Masquer mon adresse e-mail dans iCloud+ sur vos appareils](https://support.apple.com/guide/icloud/mm9d9012c9e8/)
