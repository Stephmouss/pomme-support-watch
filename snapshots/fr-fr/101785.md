# GarageBand pour iOS : son déformé avec Audiobus et les périphériques multicanaux

Lorsque vous utilisez Audiobus pour effectuer un enregistrement dans GarageBand à partir d’une application compatible, il peut arriver que le son soit déformé après vous être connecté à une interface audio multicanaux.

L’application compatible Audiobus doit être mise à jour. Contactez son fournisseur pour obtenir de plus amples informations.
