# Identifier votre modèle d’Apple Vision Pro

Découvrez comment identifier le modèle d’Apple Vision Pro dont vous disposez à l’aide de son numéro de modèle et d’autres informations.

## Trouver le modèle ou le numéro

Pour trouver le nom du modèle ou le numéro de votre Apple Vision Pro, accédez à Réglages > Général > Informations.

## Apple Vision Pro (M5)

[Image: Un Apple Vision Pro avec un bandeau tissé gris et un écran avant noir brillant.]

Numéro de modèle : A3416

Année de commercialisation : 2025

Capacité : 256 Go, 512 Go, 1 To

[Caractéristiques](https://www.apple.com/fr/apple-vision-pro/specs/)
