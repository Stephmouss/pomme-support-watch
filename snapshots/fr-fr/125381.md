# Contrôler MainStage à distance à l’aide d’une app VNC

Pour contrôler MainStage à distance depuis un iPhone ou un iPad, utilisez une app VNC (Virtual Network Computing) tierce comme RealVNC Viewer.

Il n’est pas possible de contrôler MainStage 4.0 ou version ultérieure avec Logic Remote. Pour contrôler MainStage à distance, vous pouvez utiliser RealVNC Viewer ou une autre app VNC. Cet article décrit la marche à suivre pour connecter un Mac exécutant MainStage à partir d’un iPad à l’aide de RealVNC.

## Activer les réglages de partage d’écran sur votre Mac

- Sur le Mac que vous utilisez pour MainStage, accédez à Réglages > Général, puis touchez Partage.

- Si la gestion à distance est activée, désactivez-la. Le partage d’écran et la gestion à distance ne peuvent pas être activés en même temps.

- Cliquez sur le bouton d’informations à côté de Partage d’écran.

[Image: null]

- Activez le partage d’écran et notez l’adresse de votre Mac (par exemple, 192.168.x.x). Vous l’utiliserez pour connecter RealVNC à votre Mac.

- Vous pouvez également [définir plus d’options de partage d’écran](https://support.apple.com/guide/mac-help/turn-screen-sharing-on-or-off-mh11848/mac) .

- Lorsque vous avez fini de configurer le partage d’écran, cliquez sur Terminé.

- Ouvrez MainStage sur votre Mac.

## Télécharger et ouvrir RealVNC Viewer sur votre iPhone ou iPad

- Sur votre iPhone ou iPad, ouvrez l’App Store et téléchargez RealVNC Viewer.

- Ouvrez RealVNC, puis touchez le bouton plus en haut à droite de l’écran pour créer une connexion directe à votre Mac.

- Sur l’écran Details (Détails), entrez l’adresse de votre Mac telle qu’elle apparaît dans les réglages de partage d’écran. Vous l’avez notée lorsque vous avez activé le partage d’écran.

- Saisissez un nom pour le Mac auquel vous vous connectez, touchez Save (Enregistrer), puis Done (Terminé). Une icône représentant votre Mac apparaît dans le carnet d’adresses.

- Touchez le bouton d’informations sur votre Mac dans le carnet d’adresses.

- Touchez Interaction, puis Touch Panel (Écran tactile). Vous pouvez ainsi toucher ou faire glisser les commandes MainStage sur votre iPhone ou iPad pour les régler.

- Définissez d’autres options, puis touchez Connect (Connecter).

- Touchez Continue (Continuer), saisissez vos nom d’utilisateur et mot de passe Mac, puis appuyez sur Continue (Continuer).
