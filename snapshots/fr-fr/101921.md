# Modifier le nombre de cœurs utilisés par Logic Pro pour Mac

Gérez la façon dont Logic Pro utilise les cœurs de votre Mac grâce au réglage Segments de calcul.

Par défaut, le réglage Segments de calcul est défini sur Automatique, qui est le réglage recommandé. Si vous utilisez simultanément une application sollicitant fortement le processeur, comme une app de montage vidéo, vous pouvez optimiser les performances en [choisissant le nombre de segments de calcul](https://support.apple.com/fr-fr/101921#choose) utilisés par Logic Pro.

## Utiliser le réglage Automatique pour les segments de calcul

Avec le réglage Automatique, Logic Pro alloue automatiquement le nombre de segments de calcul que l’app peut utiliser pour le traitement audio. Ce réglage offre un équilibre entre performances et fiabilité lors de l’utilisation de Logic Pro.

Pour savoir combien de segments de calcul ont été alloués par le réglage Automatique, double-cliquez sur le VU-mètre du CPU ou du disque dur dans l’écran de la barre d’outils. Les barres verticales dans la colonne Segments de calcul indiquent le nombre de segments de calcul utilisés par Logic Pro. Sur un Mac à processeur Intel prenant en charge la technologie Hyper-Threading, deux VU-mètres sont affichés pour chaque cœur.

[Image: Vu-mètre des performances Logic Pro affichant les curseurs Segments de calcul et E/S lecteur]

Si vous ne voyez pas les VU-mètres CPU et HD sur le panneau LCD :

- Cliquez sur le triangle de développement du Mode d’affichage, à droite de l’écran dans la barre d’outils.

- Choisissez Personnalisé. Les VU-mètres du CPU et du disque dur apparaissent sur la droite de l’écran.

- Double-cliquez sur un VU-mètre du CPU ou du disque dur pour ouvrir la fenêtre VU-mètre des performances.

## Choisir le nombre de segments de calcul

Pour choisir le nombre de segments de calcul utilisé par Logic Pro :

- Sélectionnez Logic Pro > Réglages (ou Préférences) > Audio.

- Cliquez sur la fenêtre contextuelle Segments de calcul, puis sélectionnez une option. Les options disponibles dépendent du nombre de cœurs du CPU de votre Mac et de la prise en charge ou non de la technologie Hyper-Threading, dans le cas d’un Mac à processeur Intel.

- Cliquez sur Appliquer.

De nombreux facteurs influencent la façon dont macOS distribue la charge de travail aux cœurs de votre Mac. La valeur optimale pour le réglage Segments de calcul peut varier en fonction des applications que vous utilisez simultanément, de votre produit et de vos projets Logic Pro. Sélectionner le plus grand nombre de segments de calcul ne constitue pas toujours le meilleur choix. Essayez différents réglages pour déterminer le meilleur équilibre entre performances et fiabilité.
