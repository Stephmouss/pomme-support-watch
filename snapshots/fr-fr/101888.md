# Utiliser le module MPX Radeon Pro W5500X avec votre Mac Pro (2019)

Découvrez les différentes configurations d’affichage que vous pouvez utiliser avec votre module MPX sur votre Mac Pro (2019).

Le module MPX Radeon Pro W5500X comporte un processeur graphique AMD Radeon Pro W5500X doté de 8 Go de mémoire GDDR5 ainsi que de deux ports HDMI 2.0. Lorsque vous utilisez le module MPX Radeon Pro W5500X avec votre Mac Pro, vous pouvez également vous servir des ports Thunderbolt 3 situés sur le dessus* et à l’arrière de votre Mac Pro pour connecter des écrans supplémentaires.

## Connecter des écrans à un seul module MPX Radeon Pro W5500X

Si vous installez un seul module Radeon Pro W5500X MPX, vous pouvez connecter jusqu'à deux écrans 4K avec des résolutions de 3 840 x 2 160 à 60 Hz aux ports HDMI de votre module MPX.

Vous pouvez également connecter jusqu'à deux écrans supplémentaires aux ports Thunderbolt 3 de votre Mac Pro dans ces configurations :

- Un écran Apple Pro Display XDR avec une résolution de 6 016 x 3 384 à 60 Hz.

- Un écran 5K avec une résolution de 5 120 x 2 880 à 60 Hz.

- Deux écrans 4K avec une résolution de 3 840 x 2 160 à 60 Hz.

## Connecter des écrans à deux modules MPX Radeon Pro W5500X

Si vous installez deux modules MPX Radeon Pro W5500X, vous pouvez connecter jusqu'à quatre écrans 4K avec des résolutions de 3 840 x 2 160 à 60 Hz aux ports HDMI de vos modules MPX.

Vous pouvez également connecter jusqu'à quatre écrans supplémentaires aux ports Thunderbolt 3 de votre Mac Pro dans ces configurations :

- Deux écrans Apple Pro Display XDR avec des résolutions de 6 016 x 3 384 à 60 Hz connectés aux ports Thunderbolt 3 en haut* et à l'arrière de votre Mac Pro.

- Deux écrans 5K avec une résolution de 5 120 x 2 880 à 60 Hz.

- Quatre écrans 4K avec une résolution de 3 840 x 2 160 à 60 Hz.

## Utiliser le module MPX Radeon Pro W5500X avec Microsoft Windows

Si vous utilisez [Boot Camp](https://support.apple.com/fr-fr/boot-camp) et que l’utilitaire est déjà configuré sur votre Mac, installez les pilotes AMD avant d’installer le module MPX Radeon Pro W5500X :

- Démarrez votre Mac sous Windows.

- Accédez au [site web d’AMD](https://www.amd.com/fr) , cliquez sur Téléchargements et assistance, puis sur Pilotes.

- Sélectionnez votre produit dans la liste, et non dans le menu : sélectionnez d’abord « Graphics », « Mac Graphics » dans la colonne suivante, puis « Apple Boot Camp » dans la dernière colonne.

- Cliquez sur Soumettre pour afficher la liste des pilotes disponibles.

- Recherchez la version des pilotes compatible avec votre modèle de Mac, puis cliquez sur Télécharger.

- Décompressez le fichier ZIP téléchargé, puis exécutez l’app Setup depuis le dossier résultant pour installer les pilotes.

- Éteignez votre Mac, puis installez le module MPX Radeon Pro W5500X.
