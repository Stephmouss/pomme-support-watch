# Partager votre position avec votre groupe de partage familial

Avec le partage familial, vous pouvez partager votre position avec votre groupe familial dans Localiser, Messages et Plans. Vous pouvez aussi aider les membres de votre famille à retrouver leurs appareils égarés.

## Fonctionnement

Le ou la responsable du partage familial configure le partage de position pour l’ensemble du groupe familial. Une fois le partage de position activé, la position du ou de la responsable est automatiquement partagée avec tout le monde et avec tous les nouveaux membres de la famille ajoutés au groupe ultérieurement. Ensuite, chaque membre de la famille peut choisir de partager ou non sa position avec le reste du groupe familial. Lorsque vous acceptez le partage de votre position, les membres de votre famille voient votre position dans l’app Localiser et dans Messages.

Si votre appareil est perdu ou volé et que le partage de position est activé, vous pouvez demander à un membre de votre famille [d’utiliser l’app Localiser](https://support.apple.com/104978) pour vous aider à le localiser.

## Partager votre position avec un membre de votre famille

Vous pouvez partager votre position dans Réglages ou l’app Localiser et [arrêter le partage](https://support.apple.com/105122#stopsharing) à tout moment.

### Si vous avez déjà configuré un groupe de partage familial

- Sur votre iPhone ou iPad, ouvrez l’app Réglages. Sur votre Mac, choisissez le menu Apple , puis cliquez sur Réglages Système.

- Touchez ou cliquez sur Famille, puis touchez ou cliquez sur Partage de position.

- Sous Partage de votre position avec, choisissez les membres de votre famille avec lesquels partager votre position.

Vous pouvez également activer l’option Partager la position automatiquement afin que votre position soit automatiquement partagée avec les nouveaux membres de la famille ajoutés au groupe ultérieurement.

### Si vous n’avez pas encore configuré le partage familial

- Sur votre iPhone, iPad ou Mac, ouvrez l’app Localiser.

- Touchez ou cliquez sur l’onglet Personnes.

- Sélectionnez le nom d’un membre de votre famille, puis touchez le bouton Plus .

- Touchez ou cliquez sur Partager ma position.

## Recevoir des notifications sur la position d’un membre de votre famille

Si vous voulez savoir quand un proche est arrivé à un endroit ou en est parti, ou s’il ne se trouve pas dans un lieu spécifique pendant une période donnée, vous pouvez configurer des notifications récurrentes.

[Découvrez comment configurer des notifications récurrentes basées sur la position](https://support.apple.com/guide/iphone/notified-friends-change-location-iph843dd79b6/18.0/ios/18.0)

## Sélectionner l’appareil depuis lequel partager sa position

Vous pouvez partager votre position à partir d’un autre appareil. Par exemple, si vous partagez votre position à partir d’un iPad, vous pouvez à la place la partager depuis un iPhone qui vous appartient.

- Sur l’iPhone ou l’iPad à partir duquel vous souhaitez partager votre position, ouvrez l’app Réglages.

- Touchez votre nom, puis Localiser.

- Touchez Utiliser la position de cet [appareil].

## Obtenir de l’aide pour retrouver un appareil égaré

Si vous avez activé Localiser pour votre appareil et que vous partagez votre position avec votre groupe de partage familial, votre famille pourra vous aider à le retrouver si vous l’avez égaré. Les membres de votre famille peuvent :

- savoir où se trouve l’appareil et déterminer si celui-ci est en ligne ou non ;

- déclencher un signal sonore sur l’appareil pour le retrouver plus facilement ;

- activer le mode Perdu pour votre appareil si celui-ci a été configuré avec un code d’accès ;

- effacer l’appareil à distance.

[Découvrez comment retrouver un appareil Apple perdu ou un AirTag à l’aide de l’app Localiser.](https://support.apple.com/104978)

Si vous ne partagez pas votre position géographique, les membres de votre famille n’auront pas accès aux informations sur la localisation de votre appareil. En revanche, ils peuvent quand même vous aider. Ils peuvent notamment savoir si l’appareil égaré est en ligne ou non, lui faire émettre un signal sonore, le placer en mode Perdu ou l’effacer à distance.

## Partager votre position dans Messages ou Plans

Sous iOS 17 ou iPadOS 17 ou version ultérieure, vous pouvez partager votre heure d’arrivée prévue ou votre position dans l’app Plans ou Messages. Utilisez Accompagnement pour prévenir un proche une fois que vous êtes à destination. Vous pouvez également utiliser la position en temps réel pour obtenir un itinéraire guidé en voyage.

[Découvrez comment partager votre position dans Messages ou Plans.](https://support.apple.com/105104)
