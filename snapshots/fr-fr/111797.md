# Utiliser Rideau d’écran avec VoiceOver pour votre Mac, iPhone, iPad, iPod touch et Apple Watch

Si vous utilisez VoiceOver sur votre appareil, Rideau d’écran vous permet d’éteindre l’écran pour préserver votre vie privée, ou lorsque vous utilisez votre appareil mais n’avez pas besoin de l’écran.

## À propos de Rideau d’écran

Lorsque Rideau d’écran est activé, votre appareil, ainsi que la navigation VoiceOver, restent actifs, même si votre écran est éteint. Par exemple, si vous souhaitez consulter votre compte bancaire dans un lieu public, Rideau d’écran désactive votre écran afin que ces informations ne soient pas visibles.

Pour utiliser Rideau d’écran sur votre appareil, VoiceOver doit être activé.

## Utiliser Rideau d’écran sur votre Mac

Lorsque VoiceOver est activé, utilisez la commande suivante pour activer Rideau d’écran :

- Appuyez sur les touches [VO](https://help.apple.com/voiceover/info/guide/10.13/#/voe845cb3fad) + Maj + Fn + _

Utilisez la même commande pour désactiver Rideau d’écran.

### Si vous utilisez le commandeur trackpad sur votre Mac

- Utilisez trois doigts pour toucher trois fois votre trackpad.

- Pour désactiver Rideau d’écran, touchez à nouveau trois fois votre trackpad avec trois doigts.

Apprenez à [contrôler VoiceOver avec le commandeur trackPad](https://support.apple.com/fr-fr/HT205770) ici.

### Utiliser le guide d’aide de la commande VoiceOver sur votre Mac pour activer Rideau d’écran

- Appuyez sur VO-HH pour accéder au guide d’aide de la commande VoiceOver.

- Saisissez les mots « Rideau d’écran » et appuyez sur la touche Retour.

## Utiliser Rideau d’écran sur votre iPhone, iPad et iPod touch

Pour activer ou désactiver Rideau d’écran par geste :

- Sortir votre appareil du mode veille.

- Avec trois doigts, touchez l’écran trois fois rapidement. Si la fonction Zoom est utilisée avec VoiceOver, touchez l’écran quatre fois avec trois doigts.

Si vous utilisez un clavier Bluetooth avec votre appareil, appuyez sur les touches Ctrl, Option, Maj et S pour activer ou désactiver Rideau d’écran.

## Utiliser Rideau d’écran sur votre Apple Watch

Utiliser votre iPhone pour activer Rideau d’écran sur votre Apple Watch :

- Sur votre iPhone, ouvrez l’app Apple Watch et accédez à Ma montre.

- Touchez Accessibilité > VoiceOver > Rideau d’écran. Ce réglage maintient Rideau d’écran actif lorsque VoiceOver est activé.

- Pour désactiver Rideau d’écran, répétez ces étapes.

## Informations supplémentaires

Vous pouvez toujours effectuer des captures d’écran sur votre appareil iOS lorsque Rideau d’écran est activé.
