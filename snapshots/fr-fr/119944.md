# Recopier le contenu de votre Apple Vision Pro sur un autre appareil

Découvrez comment recopier ce que vous voyez sur l’Apple Vision Pro sur un iPhone, un iPad, un Mac, une Apple TV ou une smart TV compatible avec AirPlay. L’Apple Vision Pro peut également servir de récepteur AirPlay pour afficher l’écran d’un autre appareil.

## Avant de commencer

- Pour recopier la vue de votre Apple Vision Pro, vous avez besoin d’un iPhone doté d’iOS 17.2 ou version ultérieure, d’un iPad doté d’iPadOS 17.2 ou version ultérieure, [d’un Mac compatible doté de macOS Monterey ou version ultérieure](https://support.apple.com/108046#airplaytomac) , d’une Apple TV 4K (2e génération ou modèle ultérieur) ou d’une Smart TV compatible avec AirPlay.

- Pour utiliser le récepteur AirPlay sur votre Vision Pro, celui-ci doit être doté de [visionOS 2 ou version ultérieure](https://support.apple.com/118481) .

- Vérifiez sur votre autre appareil que le récepteur AirPlay (ou AirPlay) est activé comme décrit dans la section suivante.

- Assurez-vous que le Wi-Fi et le Bluetooth sont activés sur les deux appareils.

## Recopier la vue de votre Apple Vision Pro

- Connectez votre Vision Pro au même réseau Wi-Fi que votre autre appareil.

- Activez le récepteur AirPlay ou AirPlay sur votre autre appareil :

- Sur votre Mac : dans le menu Pomme , choisissez Réglages Système (ou Préférences Système). Cliquez sur Général dans la barre latérale, puis sur AirDrop et Handoff à droite, puis activez Récepteur AirPlay. Si vous disposez de macOS Monterey, [découvrez comment activer le récepteur AirPlay](https://support.apple.com/guide/mac-help/set-up-your-mac-to-be-an-airplay-receiver-mchleee00ec8/12.0/mac/12.0) .

- Sur votre iPhone ou iPad : ouvrez l’app Apple Vision Pro, puis touchez l’onglet Vision Pro. Touchez Récepteur AirPlay, puis activez-le.

- Sur votre Apple TV : ouvrez Réglages, sélectionnez AirPlay et HomeKit, puis AirPlay pour l’activer.

- Sur votre smart TV compatible avec AirPlay : contactez le fabricant de votre téléviseur pour savoir comment activer AirPlay.

- [Ouvrez le centre de contrôle](https://support.apple.com/guide/apple-vision-pro/open-control-center-tand3233e05b/visionos) .

- Dans la partie droite du Centre de contrôle, faites défiler jusqu’au bouton Recopier ma vue , puis touchez-le.

[Image: null]

- Sélectionnez votre autre appareil.* Selon les réglages de l’autre appareil, vous devrez peut-être toucher Accepter et saisir un code d’accès ou un mot de passe pour démarrer la recopie.

- Pour arrêter la recopie, ouvrez le Centre de contrôle, touchez le bouton Recopier ma vue , puis touchez Ne plus recopier.

[Image: null]

La vue partagée par la recopie vidéo s’affiche avec une résolution maximale de 1080p sur votre appareil compatible avec AirPlay. Lorsque vous recopiez votre vue, l’icône devient verte pour indiquer que la recopie est active. Un voyant blanc clignotant sur l’écran EyeSight indique aux autres que vous partagez votre vue.

[Image: null]

Si vous lisez une vidéo protégée telle qu’un film, une série TV ou un clip vidéo acheté(e) auprès d’Apple, un écran noir s’affiche. L’Apple Vision Pro ne prend pas en charge la recopie de ces types de vidéos sur d’autres appareils.

* Si vous êtes dans l’Union européenne, l’app Apple Vision Pro doit être ouverte au premier plan sur votre iPhone ou iPad pour la faire apparaître dans le Centre de contrôle de l’Apple Vision Pro.

### Changer la sortie audio

- Ouvrez le centre de contrôle.

- Dans la partie droite du Centre de contrôle, faites défiler jusqu’au bouton Recopier ma vue , puis touchez-le.

[Image: null]

- Sélectionnez un appareil dans la zone Redirection audio.

## Autoriser la recopie du contenu d’autres appareils sur votre Apple Vision Pro

Vous pouvez activer l’option Récepteur AirPlay sur votre Vision Pro afin que d’autres appareils puissent y recopier leur écran ou leur vue via AirPlay lorsque vous le portez.

- Ouvrez Réglages, puis touchez AirPlay et Continuité.

- Activez l’option Récepteur AirPlay.

Afin de définir qui peut recopier du contenu sur votre Vision Pro, touchez « Autoriser AirPlay pour », puis « Utilisateur actif » ou « Tout le monde ». Pour demander un mot de passe avant qu’une autre personne puisse activer la recopie sur votre Vision Pro, activez l’option « Exiger le mot de passe », puis définissez le mot de passe.

## Si vous ne parvenez pas à vous connecter

- Vérifiez que le Wi-Fi et le Bluetooth sont activés sur votre Vision Pro et votre autre appareil.

- Assurez-vous que les deux appareils sont connectés au même réseau Wi-Fi.

- Si l’option « Autoriser AirPlay pour » est définie sur « Utilisateur actif » dans les réglages AirPlay de votre autre appareil, veillez à ce que les deux appareils soient connectés au même compte Apple.
