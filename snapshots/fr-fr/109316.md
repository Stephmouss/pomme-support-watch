# Déverrouiller votre iPhone pour l’utiliser avec un autre opérateur

Votre iPhone peut être verrouillé sur le réseau de votre opérateur. Le déverrouillage de votre iPhone permet d’utiliser ce dernier avec d’autres opérateurs.

## À propos du déverrouillage

Pour déterminer si votre iPhone est verrouillé, procédez comme suit :

- Ouvrez l’app Réglages.

- Touchez Général.

- Touchez Informations. Si le message « Aucune restriction de SIM » apparaît à côté de Verrouillage de l’opérateur, votre iPhone est déverrouillé.

Si vous ne souhaitez pas changer d’opérateur et que votre appareil est verrouillé parce que vous avez oublié le code d’accès, il n’est pas nécessaire d’appliquer la procédure décrite dans cet article. [Découvrez comment réinitialiser votre code d’accès](https://support.apple.com/fr-fr/118430) .

Apple ne peut pas déverrouiller votre iPhone pour que vous puissiez l’utiliser avec un autre opérateur. Seul votre opérateur actuel est en mesure de déverrouiller votre iPhone.

## Contacter votre opérateur

Seul votre opérateur est en mesure de déverrouiller votre iPhone.

Le traitement de votre demande de déverrouillage de votre iPhone peut prendre quelques jours. Contactez votre opérateur pour vérifier l’état de votre demande.

Une fois que votre opérateur a confirmé qu’il a déverrouillé votre iPhone, passez en revue les scénarios applicables.

### Si vous avez besoin d’activer une eSIM auprès d’un autre opérateur que votre opérateur actuel

[Découvrez comment configurer une eSIM sur votre iPhone](https://support.apple.com/fr-fr/118669)

### Si vous possédez une carte SIM fournie par un autre opérateur que votre opérateur actuel

Suivez les étapes suivantes pour finaliser le déverrouillage de votre iPhone.

- [Retirez votre carte SIM](https://support.apple.com/fr-fr/109357) .

- Insérez la nouvelle carte SIM. Votre appareil s’active.

### Si vous n’avez pas d’autre carte SIM

Suivez les étapes suivantes pour finaliser le déverrouillage de votre iPhone.

- [Sauvegardez votre iPhone](https://support.apple.com/fr-fr/118426) .

- Après avoir effectué une sauvegarde, [effacez votre iPhone](https://support.apple.com/fr-fr/108931) .

- [Restaurez votre iPhone](https://support.apple.com/fr-fr/118105) à partir de la sauvegarde que vous venez d’effectuer.

## Obtenir de l’aide

Le message suivant peut s’afficher sur votre ordinateur ou iPhone : « The SIM card inserted in this iPhone does not appear to be supported. Only compatible SIM cards from a supported carrier may be used to activate iPhone. Please insert the SIM card that came with your iPhone or visit a supported carrier store. » (La carte SIM insérée dans cet iPhone ne semble pas être prise en charge. Seules les cartes SIM compatibles d’un opérateur agréé peuvent être utilisées pour activer l’iPhone. Veuillez insérer la carte SIM fournie avec votre iPhone ou vous rendre dans le magasin d’un opérateur agréé.)

Si ce message s’affiche sur votre appareil doté d’iOS 14 ou version ultérieure, procédez comme suit :

- Ouvrez l’app Réglages.

- Touchez Général.

- Touchez Informations.

- Sous Verrouillage de l’opérateur, un message doit indiquer « Aucune restriction de SIM ». Si vous ne voyez pas ce message, [contactez votre opérateur](https://support.apple.com/fr-fr/109526) .

Si votre appareil est doté d’iOS 13 (ou version antérieure), procédez comme suit :

- [Contactez votre opérateur](https://support.apple.com/fr-fr/109526) pour confirmer qu’il a appliqué le déverrouillage dans son système.

- [Réinitialisez](https://support.apple.com/fr-fr/118105) votre iPhone aux réglages par défaut.

- [Restaurez votre iPhone à partir d’une sauvegarde](https://support.apple.com/fr-fr/118105) .
