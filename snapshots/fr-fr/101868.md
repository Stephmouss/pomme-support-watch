# Utiliser le module MPX Radeon Pro W6800X Duo avec votre Mac Pro (2019)

Découvrez les différentes configurations d’affichage que vous pouvez utiliser avec le module MPX de votre Mac Pro (2019).

Le module MPX Radeon Pro W6800X Duo intègre deux processeurs graphiques AMD Radeon Pro W6800X dotés de 32 Go de mémoire GDDR6 chacun, quatre ports Thunderbolt 3 et un port HDMI 2.0. Les ports Thunderbolt 3 vous permettent de connecter des écrans et des périphériques externes à votre Mac Pro. Vous pouvez également connecter des écrans supplémentaires grâce aux ports Thunderbolt 3 situés en haut* et à l’arrière de votre Mac Pro.

Si vous utilisez [Boot Camp](https://support.apple.com/fr-fr/boot-camp) et que vous installez une carte graphique tierce d’AMD, vous devrez peut-être [utiliser d’autres pilotes AMD sous Windows](https://support.apple.com/HT210560) .

## À propos des ports et des bus

[Image: Schéma montrant la disposition des ports du module MPX Radeon Pro W6800X Duo, avec un port HDMI et quatre ports Thunderbolt 3 répartis entre le bus 0 et le bus 1.]

Le module MPX est doté de deux bus pour ses ports Thunderbolt 3. Si vous connectez deux écrans 5K ou 6K aux ports Thunderbolt 3 de votre module MPX, connectez un écran par bus.

Si vous connectez un écran au port HDMI de votre module MPX, les ports Thunderbolt 3 du bus 0 peuvent prendre en charge un écran supplémentaire d’une résolution de 4K maximum. Si vous avez besoin de produire du son sur un écran connecté au port HDMI et que d’autres écrans sont connectés via Thunderbolt 3, ne connectez pas d’écran au port Thunderbolt 3 situé à côté du port HDMI.

## Connecter des écrans à un seul module MPX Radeon Pro W6800X Duo

Si vous installez un seul module MPX Radeon Pro W6800X Duo, vous pouvez connecter jusqu’à huit écrans via Thunderbolt 3 dans les configurations suivantes.

Six écrans Pro Display XDR avec des résolutions de 6016 x 3384 à 60 Hz connectés de la façon suivante :

- Deux écrans sur le bus 0

- Deux écrans sur le bus 1

- Un écran sur un port Thunderbolt 3 en haut* de votre Mac

- Un écran sur un port Thunderbolt 3 à l’arrière (carte d’E/S Apple) de votre Mac

Quatre écrans 5K avec des résolutions de 5120 x 2880 à 60 Hz connectés de la façon suivante :

- Un écran sur le bus 0

- Un écran sur le bus 1

- Un écran sur un port Thunderbolt 3 en haut* de votre Mac

- Un écran sur un port Thunderbolt 3 à l’arrière (carte d’E/S Apple) de votre Mac

Huit écrans 4K avec des résolutions de 3840 x 2160 à 60 Hz connectés de la façon suivante :

- Un écran sur chaque port Thunderbolt 3

## Connecter des écrans à deux modules MPX Radeon Pro W6800X Duo

Si vous installez deux modules MPX Radeon Pro W6800X Duo, vous pouvez connecter jusqu’à 12 écrans via Thunderbolt 3 dans les configurations suivantes.

Dix écrans Pro Display XDR avec des résolutions de 6016 x 3384 à 60 Hz connectés de la façon suivante :

- Deux écrans : un sur le bus 0 de chaque carte

- Deux écrans : un sur le bus 1 de chaque carte

- Un écran sur un port Thunderbolt 3 en haut* de votre Mac

- Un écran sur un port Thunderbolt 3 à l’arrière (carte d’E/S Apple) de votre Mac

Six écrans 5K avec des résolutions de 5120 x 2880 à 60 Hz connectés de la façon suivante :

- Deux écrans : un sur le bus 0 de chaque carte

- Deux écrans : un sur le bus 1 de chaque carte

- Un écran sur un port Thunderbolt 3 en haut* de votre Mac

- Un écran sur un port Thunderbolt 3 à l’arrière (carte d’E/S Apple) de votre Mac

Douze écrans 4K avec des résolutions de 3840 x 2160 à 60 Hz connectés de la façon suivante :

- Un écran sur chaque port Thunderbolt 3

## Utiliser Infinity Fabric Link

Infinity Fabric Link est préinstallé sur votre module MPX et permet un transfert de données jusqu’à cinq fois plus rapide entre les processeurs graphiques.

- Lorsque vous vous servez d’un seul module MPX Radeon Pro W6800X Duo, le cavalier Infinity Fabric Link doit être installé afin que les apps prenant en charge Infinity Fabric Link puissent l’utiliser.

- Lorsque vous utilisez deux modules MPX Radeon Pro W6800X Duo, le pont Infinity Fabric Link doit être installé afin que les quatre processeurs graphiques puissent fonctionner ensemble dans les apps prises en charge :

[Image: Mac Pro avec le pont Infinity Fabric Link pour le module MPX Radeon Pro W6800X Duo.]

Le pont Infinity Fabric Link pour le module MPX Radeon Pro W6800X Duo (modèle A2667) n’est pas compatible avec les modules MPX Radeon Pro des précédentes générations.

Si vous utilisez Boot Camp et que vous avez installé un pont Infinity Fabric Link, vous ne pouvez pas connecter d’écrans aux ports Thunderbolt 3 du bus 1 et du haut* de votre Mac Pro.
