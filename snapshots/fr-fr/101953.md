# iPod shuffle (4e génération) : activer et utiliser VoiceOver

Découvrez comment activer et utiliser VoiceOver sur votre iPod shuffle (4e génération).

En activant la fonctionnalité VoiceOver dans iTunes pour iPod shuffle (4e génération), vous pouvez entendre le titre des morceaux, le nom des artistes et des listes de lecture lorsque vous écoutez de la musique sur votre iPod shuffle. VoiceOver vous indique également l’état de la batterie et d’autres messages. Vous pouvez activer VoiceOver lorsque vous avez configuré votre iPod pour la première fois avec iTunes, ou vous pouvez le configurer ultérieurement dans le bouton Résumé, dans les réglages de l’iPod, dans iTunes. Lorsque vous sélectionnez l’option permettant d’activer VoiceOver dans l’Assistant réglages iPod ou dans le bouton Résumé, vous êtes guidé tout au long du processus d’installation de VoiceOver Kit.

## Pour activer VoiceOver lorsque vous configurez l’iPod shuffle

- Connectez l’iPod shuffle à votre ordinateur.

- Suivez les instructions qui s’affichent dans iTunes. « Activer VoiceOver » est sélectionné par défaut.

- Cliquez sur Continuer.

- Dans le bouton Résumé, sous Retour audio, choisissez la langue souhaitée dans le menu Langue. Cette option définit la langue des messages vocaux du système et des noms de playlists, ainsi que de nombreux titres de chansons et noms d’artistes.

- Cliquez sur Appliquer. Une fois la configuration terminée, VoiceOver est activé sur l’iPod shuffle.

Remarque : pour choisir une langue différente pour certaines chansons, procédez comme suit.

- Sélectionnez les morceaux dans iTunes.

- Sélectionnez Fichier > Lire les informations .

- Choisissez une langue VoiceOver dans le menu local de l’onglet Options.

- Cliquez sur OK.

## Pour activer VoiceOver ultérieurement

- Connectez l’iPod shuffle à votre ordinateur.

- Dans iTunes, sélectionnez l’iPod shuffle dans la liste des appareils, puis cliquez sur le bouton Résumé.

- Sous Retour audio, sélectionnez Activer VoiceOver.

- Cliquez sur Appliquer.

- Choisissez la langue souhaitée dans le menu, sous Retour audio.

- Cliquez sur Appliquer. Une fois la synchronisation terminée, VoiceOver est activé.

## Pour désactiver VoiceOver

- Dans iTunes, sélectionnez l’iPod shuffle dans la liste des appareils, puis cliquez sur le bouton Résumé.

- Sous Retour audio, désélectionnez Activer VoiceOver.

- Cliquez sur Appliquer.

Une fois la synchronisation terminée, VoiceOver est désactivé. Vous entendrez toujours certaines annonces du système en anglais sur l’iPod shuffle, comme l’état de la batterie, les messages d’erreur et un menu générique de playlists numérotées. Vous n’entendrez pas les titres des morceaux et les noms des artistes.

## Pour entendre une annonce sur la piste en cours

Appuyez sur le bouton VoiceOver de l’iPod pendant la lecture. Vous entendrez le titre de la piste en cours et le nom de l’artiste. Vous pouvez également utiliser VoiceOver pour accéder à un autre titre lorsque vous écoutez des annonces de pistes.

## Pour utiliser les annonces de pistes pour naviguer

- Si l’iPod shuffle est en cours de lecture, appuyez sur :

- le bouton VoiceOver pour entendre l’annonce de la piste en cours ;

- Suivant/Avance rapide pour passer à la piste suivante et entendre l’annonce de la piste suivante ;

- Précédent/Retour rapide pour revenir à la piste précédente et entendre l’annonce de la piste précédente.

- Si l’iPod shuffle est en pause, appuyez sur :

- le bouton VoiceOver pour entendre l’annonce de la piste en cours ;

- Suivant/Avance rapide pour entendre la prochaine annonce ;

- Précédent/Retour rapide pour entendre l’annonce précédente ;

- le bouton VoiceOver ou Lecture/Pause pour lire la piste annoncée.

## Modifier les playlists

Lorsque VoiceOver est activé, vous pouvez entendre le titre et choisir n’importe quelle playlist que vous avez synchronisée avec l’iPod shuffle. Si des livres audio ou des podcasts audio sont synchronisés avec l’iPod shuffle, leurs titres sont également lus dans le menu des playlists. Si VoiceOver est désactivé dans iTunes, les playlists sont numérotées, mais pas nommées (par exemple, « Playlist 1, Playlist 2 », etc.).

Le menu des playlists annonce les éléments dans cet ordre :

- La playlist en cours (le cas échéant)

- « Tous les morceaux » (playlist par défaut de tous les morceaux sur l’iPod shuffle)

- Toutes les playlists, y compris les playlists Genius, par ordre alphabétique

- Tous les mix Genius, par ordre alphabétique

- Tous les podcasts, par ordre alphabétique

- Toutes les collections iTunes U, par ordre alphabétique

- Tous les livres audio, par ordre alphabétique

## Pour choisir un élément dans le menu des playlists

- Appuyez sur le bouton VoiceOver et maintenez-le enfoncé. Vous entendez les noms de vos playlists.

- Lorsque vous entendez le nom de la playlist souhaitée, appuyez sur le bouton VoiceOver ou Lecture/Pause pour la sélectionner. Le premier élément de votre playlist est joué. Lorsque vous écoutez le menu des playlists, vous pouvez appuyer sur Suivant/Avance rapide ou Précédent/Retour rapide pour avancer ou reculer dans le menu des playlists.

Pour redémarrer une playlist, suivez ces étapes pour sélectionner la playlist de votre choix.

## Pour quitter le menu des playlists

Appuyez sur le bouton VoiceOver et maintenez-le enfoncé.
