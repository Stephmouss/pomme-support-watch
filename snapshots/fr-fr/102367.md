# Comment activer l’utilisateur root ou modifier le mot de passe root sur Mac

Les administrateurs Mac peuvent utiliser le compte d’utilisateur root pour effectuer des tâches qui requièrent un accès à davantage de zones du système.

Il est plus sûr d’utiliser la commande sudo dans Terminal que d’activer l’utilisateur root. Pour en savoir plus sur sudo , ouvrez l’app Terminal et saisissez man sudo .

Le compte d’utilisateur dénommé root est un superutilisateur doté de droits de lecture et d’écriture sur davantage de zones du système, y compris sur des fichiers stockés dans d’autres comptes utilisateur macOS. L’utilisateur root est désactivé par défaut, et il n’est pas destiné à un usage courant. Ses privilèges permettent de modifier les fichiers requis par votre Mac et, pour annuler ces changements, vous pourriez devoir [réinstaller macOS](https://support.apple.com/HT204904) . Désactivez toujours l’utilisateur root après avoir terminé votre tâche.

## Utiliser Utilitaire d’annuaire

Utilisez Spotlight pour trouver et ouvrir Utilitaire d’annuaire, ou suivez ces étapes :

- Dans le menu Aller de la barre des menus du Finder, choisissez Aller au dossier.

- Saisissez ou collez /System/Library/CoreServices/Applications/ , puis appuyez sur Retour.

- Ouvrez Utilitaire d’annuaire à partir de la fenêtre qui s’ouvre.

### Pour activer ou désactiver l’utilisateur root

Dans la fenêtre Utilitaire d’annuaire, cliquez sur le cadenas , puis entrez un nom et un mot de passe d’administrateur.

[Image: icône de cadenas]

- Pour activer l’utilisateur root : dans le menu Édition, choisissez Activer l’utilisateur root. Entrez ensuite le mot de passe que vous souhaitez utiliser. Vous pouvez ensuite [ouvrir une session en tant qu’utilisateur root](https://support.apple.com/fr-fr/102367#login) .

- Pour désactiver l’utilisateur root : dans le menu Édition, choisissez Désactiver l’utilisateur root.

### Pour changer le mot de passe root

Dans la fenêtre Utilitaire d’annuaire, cliquez sur le cadenas , puis entrez un nom et un mot de passe d’administrateur. Dans le menu Édition, choisissez Modifier le mot de passe root.

[Image: icône de cadenas]

## Se connecter avec le compte d’utilisateur root

Lorsque l’utilisateur root est activé, vous disposez de ses privilèges uniquement lorsque vous vous connectez en tant qu’utilisateur root.

- Dans le menu Pomme , choisissez Fermer la session pour vous déconnecter de votre compte utilisateur actuel.

- Dans la fenêtre de connexion, connectez-vous avec le nom d’utilisateur « root » et le mot de passe que vous avez créé pour l’utilisateur root. Si la fenêtre d’ouverture de session affiche une liste d’utilisateurs, cliquez sur Autre et connectez-vous.

N’oubliez pas de désactiver l’utilisateur root une fois votre tâche effectuée.
