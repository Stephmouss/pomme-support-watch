# Affichage d’un message d’erreur lors de la synchronisation audio et MIDI dans Logic Pro pour Mac

Découvrez la marche à suivre si le message « Erreur de tentative de synchronisation audio et MIDI » s’affiche dans Logic Pro.

Cette alerte peut s’afficher lorsque la fréquence d’échantillonnage d’un signal audio entrant ne correspond pas à celle du projet ou qu’elle est sujette à des variations. C’est notamment le cas si vous utilisez une interface audio externe, un appareil de synchronisation externe ou des modules.

Suivez les recommandations de cet article pour éviter que ce message d’erreur n’interrompe votre session. Après chaque recommandation, essayez de lire à nouveau votre projet pour vérifier si le message s’affiche toujours. Si c’est le cas, essayez la recommandation suivante jusqu’à ce que l’alerte disparaisse.

## Vérifier les réglages de la fréquence d’échantillonnage

Lorsque vous utilisez une interface audio externe avec Logic Pro, la fréquence d’échantillonnage de votre interface doit s’adapter automatiquement à celle de votre projet. Or, il arrive parfois que les paramètres des fréquences d’échantillonnage ne correspondent pas. Assurez-vous qu’ils sont identiques.

### Vérifier la fréquence d’échantillonnage sur votre interface externe

La plupart des interfaces audio externes possèdent une application (généralement accessible dans les Préférences Système ou dans le dossier Applications) qui vous permet de consulter et de modifier les réglages matériels, y compris les fréquences d’échantillonnage de l’appareil. Pour obtenir plus d’informations, consultez la documentation de votre appareil.

### Vérifier la fréquence d’échantillonnage dans Logic Pro

Pour vérifier la fréquence d’échantillonnage de votre projet, choisissez Fichier >Réglages Projet > Audio. Si la fréquence d’échantillonnage de votre projet ne correspond pas à celle de votre interface, sélectionnez la fréquence d’échantillonnage appropriée dans le menu local Fréquence d’échantillonnage.

Si la fréquence d’échantillonnage de votre projet correspond à celle de votre interface, sélectionnez une autre fréquence d’échantillonnage dans le menu local Fréquence d’échantillonnage, puis rétablissez la fréquence d’origine.

## Vérifier les réglages de l’horloge sur les appareils numériques

Si vous utilisez une interface audio externe reliée à un autre appareil numérique, veillez à ce qu’une seule interface soit la source d’horloge principale. Pour plus d’informations, consultez la documentation de votre interface.

## Vérifier la configuration du périphérique agrégé

Si vous avez combiné plusieurs interfaces audio externes en configurant un [périphérique agrégé](https://support.apple.com/102171)

- Connectez les appareils entre eux via l’horloge mondiale, SPDIF, Lightpipe ou AES/EBU.

- Désignez un périphérique comme source d’horloge principale.

Pour plus d’informations, consultez la documentation de vos interfaces.

## Augmenter la taille de buffer E/S

Pour augmenter la taille de buffer E/S dans Logic Pro, choisissez Logic Pro > Préférences > Audio, puis sélectionnez une taille plus importante dans le menu local Taille de buffer E/S.

## Gel de pistes

[Gelez toutes les pistes de votre projet](https://support.apple.com/guide/logicpro/freeze-tracks-lgcpf1cbfd51/mac) qui comportent des modules.

## Vérifier les réglages de synchronisation

Vérifiez les réglages de synchronisation si vous synchronisez d’autres applications ou périphériques avec Logic Pro, ou si vous synchronisez Logic Pro avec une autre application ou un autre appareil.

### Synchronisation d’autres applications ou périphériques avec Logic Pro

Si vous synchronisez une autre application ou un autre périphérique générant un timecode MIDI (MTC) ou une horloge MIDI avec Logic Pro, désactivez « Activer automatiquement la synchronisation externe et le Tap Tempo ». Choisissez Fichier > Réglages Projet > Synchronisation, puis désactivez « Activer automatiquement la synchronisation externe et le Tap Tempo ».

### Synchronisation de Logic Pro avec d’autres applications ou appareils

Si vous synchronisez Logic Pro avec une autre application ou un autre périphérique via l’horloge MTC, procédez comme suit :

- Assurez-vous que l’application ou l’appareil générant l’horloge MTC ne génère pas d’horloge MIDI. Pour plus d’informations, consultez la documentation de votre application ou appareil.

- Ouvrez votre projet Logic Pro, choisissez Fichier > Réglages Projet > Synchronisation, cliquez sur l’onglet Audio, puis sélectionnez Externe ou Libre dans le menu local Core Audio.

## Ignorer l’ensemble Reaktor

Si votre projet inclut une piste d’instrument logiciel avec un ensemble Reaktor dont le LFO se synchronise avec le tempo du morceau, essayez de [contourner le module ou de le supprimer de la piste](https://support.apple.com/109315) .

## Utiliser le système audio intégré

Si vous utilisez une interface audio externe, essayez d’utiliser le système audio intégré de votre Mac au lieu de cette interface.

- Débranchez l’interface audio externe de votre Mac.

- Ouvrez Logic Pro, puis choisissez Logic Pro > Préférences > Audio.

- Choisissez Sortie intégrée dans le menu local Sortie audio.

- Choisissez Micro intégré (ou Entrée intégrée, selon votre ordinateur) dans le menu local Entrée audio.

Si aucun message d’avertissement ne s’affiche, il peut être nécessaire de mettre à jour ou de réparer votre interface audio. Contactez le fabricant pour obtenir de l’aide.
