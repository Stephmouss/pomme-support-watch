# Mettre à jour les logiciels Apple pour Microsoft Windows

Pour conserver vos logiciels Apple pour Microsoft Windows à jour sur votre PC, utilisez le Microsoft Store et Apple Software Update.

## Rechercher des mises à jour dans le Microsoft Store

Utilisez le [Microsoft Store sous Windows](https://apps.microsoft.com/) pour obtenir la version la plus récente des apps qu’Apple fournit pour Windows, notamment iCloud, Apple Music, Apple TV, Appareils Apple et iTunes. Le Microsoft Store conserve ensuite automatiquement vos logiciels à jour, mais vous pouvez également l’ouvrir et rechercher manuellement des mises à jour.

## Rechercher des mises à jour dans Apple Software Update

Si vous avez installé des apps Apple pour Windows plus anciennes, ou si vous avez utilisé Boot Camp pour installer Windows sur un Mac, vous disposez également d’Apple Software Update. Pour trouver cet outil, utilisez la zone de recherche située dans la barre des tâches de Windows. Par défaut, Apple Software Update recherche des mises à jour une fois par semaine et chaque fois que vous l’ouvrez.

- Si vous disposez de Windows 10 ou version ultérieure sur un PC, utilisez le Microsoft Store pour obtenir les apps Apple pour Windows les plus récentes. Vous n’aurez ensuite plus besoin d’Apple Software Update.

- Si vous disposez de Windows 10 ou version ultérieure sur un Mac, utilisez le Microsoft Store pour obtenir les apps Apple pour Windows les plus récentes. Utilisez ensuite à la fois le Microsoft Store et Apple Software Update pour conserver tous vos logiciels Apple pour Windows à jour.
