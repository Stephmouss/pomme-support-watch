# Restaurer un iPhone, un iPad ou un iPod touch nécessitant une version plus récente d’iOS ou d’iPadOS

Si vous restaurez votre iPhone, iPad ou iPod touch, une version plus récente d’iOS ou d’iPadOS peut être nécessaire. C’est le cas si vous effectuez la restauration à partir d’une sauvegarde iCloud ou d’un ordinateur.

## Restauration à partir d’une sauvegarde iCloud

Votre sauvegarde iCloud peut nécessiter une version plus récente d’iOS ou d’iPadOS. Si c’est le cas, mettez à jour votre appareil avant de procéder à la restauration. Si vous installez la mise à jour, votre appareil se met à jour automatiquement, puis restaure votre sauvegarde.

## Restauration à partir d’un ordinateur

Votre sauvegarde peut nécessiter une version plus récente d’iOS ou d’iPadOS. Si c’est le cas, un message d’erreur s’affiche, indiquant que vous ne pouvez pas la restaurer.

### Configurer, mettre à jour et effacer votre appareil

- [À partir de l’écran Transférer vos apps et données](https://support.apple.com/fr-fr/105132) de votre appareil, touchez Ne pas transférer les apps et les données. Si vous avez touché Restaurer à partir d’une sauvegarde iCloud, touchez Retour pour revenir à l’écran Configurer.

[Image: Options pour transférer les apps et les données pendant la configuration de l’appareil.]

- Poursuivez la procédure. Vous pouvez ignorer les étapes de configuration de votre compte Apple, de Touch ID ou de Face ID, et du code d’accès.

- Une fois la configuration terminée, mettez à jour votre appareil. [dernière version d’iOS ou d’iPadOS](https://support.apple.com/fr-fr/118575) .

- Patientez jusqu’à la fin de la mise à jour, ainsi que pendant le redémarrage de votre appareil.

- Accédez à Réglages.

- Touchez Général.

- Touchez Transférer ou réinitialiser [l’appareil].

- Touchez Effacer contenu et réglages.

Une fois les données de votre appareil effacées, celui-ci redémarre et l’écran Bonjour s’affiche dans l’Assistant réglages.

Vous pouvez maintenant configurer à nouveau votre appareil et restaurer vos données à partir d’une sauvegarde.
