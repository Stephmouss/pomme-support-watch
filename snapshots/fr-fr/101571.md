# Combien d’écrans peuvent être connectés au MacBook Pro ?

Le nombre d’écrans externes que vous pouvez utiliser simultanément dépend de votre modèle de Mac et de la résolution et du taux de rafraîchissement de chaque écran.

[Identifiez le modèle de votre MacBook Pro](https://support.apple.com/fr-fr/108052) , puis découvrez combien d’écrans peuvent être connectés à ce modèle, ainsi qu’à quelles résolutions et à quels taux de rafraîchissement :

- [MacBook Pro avec écran PROLED XDR et puce M5 Max](https://support.apple.com/fr-fr/149453)

- [MacBook Pro avec écran PROLED XDR et puce M5 Pro](https://support.apple.com/fr-fr/149454)

- [MacBook Pro avec puce M6](https://support.apple.com/fr-fr/149456)

- [MacBook Pro avec puce M5 Max](https://support.apple.com/fr-fr/149458)

- [MacBook Pro avec puce M5 Pro](https://support.apple.com/fr-fr/149461)

- [MacBook Pro avec puce M5](https://support.apple.com/fr-fr/149463)

- [MacBook Pro avec puce M4 Max](https://support.apple.com/fr-fr/149473)

- [MacBook Pro avec puce M4 et puce M4 Pro](https://support.apple.com/fr-fr/149474)

- [MacBook Pro avec puce M2 Max ou M3 Max](https://support.apple.com/fr-fr/149475)

- [MacBook Pro avec puce M2 Pro ou M3 Pro](https://support.apple.com/fr-fr/149476)

- [MacBook Pro avec puce M3](https://support.apple.com/fr-fr/149477)

- Modèles antérieurs : [Consultez les caractéristiques techniques](https://support.apple.com/docs) de ce modèle pour obtenir un aperçu de la prise en charge des écrans.
