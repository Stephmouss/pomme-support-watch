# Combinaisons de touches utilisables sur un Mac lors du démarrage

Découvrez les fonctionnalités et outils Mac auxquels vous pouvez accéder en maintenant une ou plusieurs touches enfoncées lors du démarrage de votre ordinateur.

## Sur un Mac avec puce Apple

[Déterminez si vous avez un Mac avec puce Apple](https://support.apple.com/fr-fr/116943)

- Allumez votre Mac et maintenez le bouton d’alimentation enfoncé pendant le démarrage.

- Relâchez le bouton d’alimentation lorsque [l’écran des options de démarrage](https://support.apple.com/fr-fr/102342) apparaît. Celui-ci affiche les disques de démarrage et une icône Options en forme d’engrenage.

- Cette fenêtre vous permet de démarrer l’ordinateur à partir d’un autre disque, de le démarrer en mode sans échec, d’accéder à la fonctionnalité de récupération de macOS, etc.

## Sur un Mac à processeur Intel

Si votre Mac n’est pas doté d’une puce Apple, vous disposez d’un Mac à processeur Intel.

### Conseils d’utilisation de ces combinaisons de touches

- Appuyez simultanément sur toutes les touches de la combinaison, et non l’une après l’autre.

- Si une combinaison de touches ne fonctionne pas lors du redémarrage, commencez par éteindre votre Mac. Si vous ne parvenez pas à éteindre le Mac, maintenez son bouton d’alimentation enfoncé pendant 10 secondes, jusqu’à ce qu’il s’éteigne. Ensuite, allumez votre Mac en appuyant sur son bouton d’alimentation, puis appuyez sur les touches de la combinaison et maintenez-les enfoncées.

- Vous devrez peut-être patienter quelques secondes avant d’appuyer sur les touches, le temps que votre Mac détecte le clavier lors du démarrage. Sur certains claviers, un voyant clignote brièvement lors du démarrage, indiquant que le clavier a bien été détecté et est prêt à l’emploi.

- Si vous utilisez un clavier sans fil, branchez-le sur votre Mac, si possible. Vous pouvez également utiliser le clavier intégré ou un clavier filaire. Si vous utilisez un clavier conçu pour PC, comme un clavier avec un logo Windows, essayez d’utiliser un clavier Mac à la place.

- Certaines combinaisons de touches ne fonctionnent pas lorsqu’un mot de passe de programme interne est configuré sur votre Mac. [Désactivez le mot de passe du programme interne](https://support.apple.com/fr-fr/102384) au préalable.

- Si vous utilisez Boot Camp pour démarrer à partir de Microsoft Windows, configurez les [préférences du disque de démarrage](https://support.apple.com/guide/mac-help/change-your-mac-startup-disk-mchlp1034/mac) pour démarrer à partir de macOS. Ensuite, éteignez ou redémarrez votre ordinateur, puis réessayez.

### Combinaisons de touches pour un Mac à processeur Intel

Commande (⌘) + R : permet de démarrer à partir du système de récupération de macOS intégré. Vous pouvez également utiliser les touches Option + Commande + R ou Maj + Option + Commande + R pour démarrer à partir de la fonctionnalité de récupération de macOS sur Internet. [La fonctionnalité de récupération de macOS installe différentes versions de macOS](https://support.apple.com/fr-fr/102655) selon la combinaison de touches utilisée au démarrage.

Option (⌥) ou Alt : permet de démarrer à partir du [gestionnaire de démarrage](https://support.apple.com/guide/mac-help/change-your-mac-startup-disk-mchlp1034/mac) , afin de sélectionner un autre disque ou volume de démarrage disponible.

Option + Commande + P + R : permet de [réinitialiser la mémoire NVRAM](https://support.apple.com/fr-fr/102539) ou PRAM.

Maj (⇧) : permet de démarrer en [mode sans échec](https://support.apple.com/fr-fr/116946) .

D : permet de démarrer à partir de l’utilitaire [Diagnostics Apple](https://support.apple.com/fr-fr/102550) . Vous pouvez également appuyer sur Option + D pour démarrer à partir de cet utilitaire sur Internet.

N : permet de démarrer à partir d’un serveur NetBoot, [si votre Mac prend en charge les volumes de démarrage réseau](https://support.apple.com/fr-fr/101676) . Pour utiliser l’image de démarrage par défaut stockée sur le serveur, maintenez les touches Option + N enfoncées.

Commande + S : permet de démarrer en mode Utilisateur unique. Cette commande est désactivée dans macOS Mojave ou version ultérieure.

T : permet de démarrer en [mode disque cible](https://support.apple.com/guide/mac-help/transfer-files-mac-computers-target-disk-mode-mchlp1443/mac) .

Commande + V : permet de démarrer en mode Détaillé.

Éjection (⏏) , F12 , bouton de la souris ou du trackpad : permet d’éjecter un support amovible, tel qu’un disque optique.
