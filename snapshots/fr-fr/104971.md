Découvrez comment organiser vos e-mails avec des boîtes aux lettres personnalisées, des boîtes aux lettres VIP et des drapeaux. Apprenez également à utiliser les catégories pour trier vos e-mails dans iOS 18.2.

## Utiliser les boîtes aux lettres

Une boîte aux lettres est un dossier dans lequel vous pouvez organiser vos e-mails. Dans l’app Mail, vous pouvez utiliser les boîtes aux lettres standard, telles que Réception, Envoyés, Corbeille, Rappel, Suivi et Envoyer plus tard, ou créer des boîtes aux lettres personnalisées. Vous pouvez également mettre en évidence certains e-mails à l’aide de la fonctionnalité VIP et des drapeaux.

### Créer des boîtes aux lettres personnalisées

- Dans la liste Boîtes, touchez Modifier dans l’angle supérieur droit, puis touchez Nouvelle boîte aux lettres.

- Attribuez un nom à votre boîte aux lettres. Si vous disposez de plusieurs comptes de messagerie configurés sur votre appareil, touchez Emplacement et sélectionnez le compte sur lequel vous souhaitez créer une boîte aux lettres. Découvrez comment [ajouter un compte de messagerie](https://support.apple.com/102619) sur votre appareil.

- Touchez Enregistrer, puis OK.

[Image: Dans l’app Mail sur votre iPhone, touchez l’option Nouvelle boîte aux lettres pour créer des boîtes aux lettres personnalisées afin de vous organiser.]

Vous pourrez trouver votre nouvelle boîte aux lettres dans la liste Boîtes, dans le compte où vous l’avez créée.

### Déplacer vos e-mails vers une boîte aux lettres

- Accédez à votre boîte de réception dans Mail.

- Touchez Sélectionner dans le coin supérieur droit.

- Sélectionnez les e-mails, puis touchez le bouton Dossier .

[Image: null]

- Choisissez la boîte aux lettres vers laquelle vous souhaitez déplacer les e-mails.

[Image: Dans l’app Mail, vous pouvez déplacer manuellement un e-mail dans des boîtes aux lettres spécifiques depuis votre boîte de réception.]

### Supprimer des boîtes aux lettres

Si vous supprimez une boîte aux lettres personnalisée, tous les e-mails qu’elle contient sont également supprimés, y compris sur votre compte. Avant de supprimer une boîte aux lettres, vous pouvez déplacer vos e-mails vers une autre boîte aux lettres.

Pour supprimer une boîte aux lettres personnalisée :

- Accédez à la liste Boîtes et touchez Modifier dans l’angle supérieur droit.

- Touchez la boîte aux lettres que vous souhaitez supprimer.

- Touchez Supprimer la boîte aux lettres.

- Touchez Supprimer, puis OK.

Vous pouvez uniquement supprimer les boîtes aux lettres personnalisées.

Découvrez comment [supprimer des e-mails individuels](https://support.apple.com/102428) sur votre iPhone ou votre iPad.

## Utiliser la boîte aux lettres VIP

Dans l’app Mail, il est possible de définir certaines personnes en tant que VIP pour faciliter le suivi de leurs messages. Une étoile s’affiche en regard du nom des VIP dans l’en-tête des messages. Votre boîte aux lettres VIP figure dans la liste de vos boîtes aux lettres.

[Image: étoile]

Si votre boîte aux lettres VIP n’apparaît pas, assurez-vous qu’elle est activée. Accédez à Mail, touchez Modifier, puis assurez-vous que l’option VIP est sélectionnée dans la liste des boîtes aux lettres.

### Ajouter un VIP

- Ouvrez un e-mail.

- Touchez le nom ou l’adresse e-mail de l’expéditeur dans l’en-tête de l’e-mail, puis touchez Voir la fiche de contact.

- Touchez Ajouter aux VIP.

[Image: Si vous touchez Ajouter aux VIP sur une carte de contact, les e-mails de cette personne s’afficheront automatiquement dans votre dossier VIP.]

### Modifier les alertes VIP

- Ouvrez Mail.

- Touchez le bouton Infos à côté de VIP.

[Image: le bouton Infos]

- Touchez Alertes VIP.

- Sélectionnez les alertes que vous souhaitez définir.

## Utiliser les drapeaux

Vous pouvez ajouter un drapeau aux e-mails pour faciliter le suivi des messages. Il est même possible d’ajouter des drapeaux de couleurs différentes. Lorsque vous ajoutez un drapeau à un e-mail, une icône de drapeau s’affiche en regard du fil de discussion.

[Image: icône de drapeau]

[Image: Dans l’app Mail sur iPhone, effectuez un balayage vers la gauche sur un e-mail pour afficher rapidement l’option d’ajout de drapeau à l’e-mail.]

Pour utiliser le drapeau par défaut :

- Accédez à la boîte aux lettres contenant l’e-mail auquel vous souhaitez ajouter un drapeau.

- Effectuez un balayage vers la gauche sur l’e-mail.

- Touchez Drapeau.

[Image: Dans l’app Mail sous iOS, vous pouvez définir une couleur spécifique pour les messages marqués d’un drapeau dans un fil de discussion.]

Pour modifier la couleur d’un drapeau :

- Accédez à un fil de discussion.

- Touchez le bouton Répondre .

[Image: le bouton Répondre]

- Touchez Marquer d’un drapeau, puis sélectionnez la couleur que vous souhaitez utiliser pour ce drapeau.

Si vous [utilisez la vue des catégories dans l’app Mail sous iOS 18.2](https://support.apple.com/guide/iphone/use-categories-iphfe4a36baf/ios) , vous ne pouvez pas ajouter de drapeau aux e-mails catégorisés comme Publicités, Alertes ou Transactions.

### Trouver les e-mails marqués d’un drapeau

- Dans l’app Mail, accédez à la liste de vos boîtes aux lettres.

- Touchez Modifier dans l’angle supérieur droit.

- Sélectionnez Avec drapeau.

- Touchez OK. Votre boîte aux lettres Avec drapeau apparaît maintenant dans la liste de vos boîtes aux lettres.

## Utiliser la catégorisation dans iOS 18.2

Dans iOS 18.2, [vous pouvez utiliser les catégories](https://support.apple.com/guide/iphone/use-categories-iphfe4a36baf/ios) afin que Mail trie automatiquement vos e-mails en quatre catégories :

- La catégorie Principale regroupe les e-mails urgents ou les messages récents de vos contacts.

- La catégorie Transactions regroupe les reçus et les mises à jour de commandes.

- La catégorie Alertes regroupe les actualités et les réseaux sociaux.

- La catégorie Publicités regroupe les e-mails d’entreprises et d’organisations.

Vous pouvez toujours déplacer des e-mails individuels vers des boîtes aux lettres spécifiques lorsque vous utilisez la vue des catégories.

Lorsque vous utilisez les catégories, la pastille de l’app Mail sur votre écran d’accueil n’affiche que le nombre de messages non lus dans votre catégorie Principale. [En savoir plus sur les notifications de l’app Mail sur votre iPhone](https://support.apple.com/108412) .

Pour afficher tous vos e-mails à la fois lorsque vous utilisez les catégories, effectuez un balayage vers la gauche sur le menu des catégories pour afficher l’option Tous les e-mails. Vous pouvez également toucher le bouton Plus et choisir Présentation par liste pour passer à la vue globale.

[Image: null]

[Image: Sous iOS 26, touchez le bouton Plus dans l’app Mail lorsque les catégories sont activées pour en savoir plus sur chaque catégorie.]

Pour utiliser les catégories dans l’app Mail, vous devez disposer d’un iPhone doté d’iOS 18.2.
