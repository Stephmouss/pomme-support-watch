# Si vous ne pouvez pas activer d’extensions dans Safari pour Mac

Découvrez la procédure à suivre si vous ne pouvez pas cocher la case permettant d’activer une extension dans les réglages de Safari sur votre Mac.

Depuis macOS Catalina, votre Mac comprend une fonctionnalité de sécurité conçue pour empêcher les logiciels malveillants de vous inciter à activer une extension Safari. Dans certains cas, l’utilisation d’un logiciel légitime doté de certaines fonctionnalités d’enregistrement d’écran ou d’accessibilité a une incidence sur cette fonctionnalité. Si cela se produit :

- Un message indiquant que Safari a détecté une app ou un service interférant avec un clic peut s’afficher.

- Il se peut que vous ne puissiez pas activer les extensions Safari dans les réglages de Safari. Vous pouvez désélectionner une case pour désactiver une extension, mais vous ne pouvez pas cocher une case pour l’activer.

Pour résoudre ce problème, [installez les dernières mises à jour de logiciels Apple](https://support.apple.com/HT201541) , puis réessayez. Après la mise à jour de votre logiciel, si vous ne pouvez toujours pas activer les extensions dans Safari pour Mac :

- [Démarrez votre Mac en mode sans échec](https://support.apple.com/HT201262) .

- Ouvrez Safari et activez toutes les extensions Safari que vous souhaitez utiliser.

- Redémarrez votre Mac.

Des informations générales sur l’utilisation des extensions Safari sont disponibles pour [les Mac](https://support.apple.com/HT203051) , [les iPhone](https://support.apple.com/guide/iphone/get-extensions-iphab0432bf6/ios) et [les iPad](https://support.apple.com/guide/ipad/get-extensions-ipada7ca2a18/ipados) .
