# Utiliser des boucles Session Player dans Logic Pro pour Mac

Ajoutez rapidement des lignes de batterie, de basse et de clavier à l’aide de boucles Session Player, un type de boucles Apple Loop que vous pouvez personnaliser afin de les adapter à votre projet.

Logic Pro comprend de nombreuses boucles Apple Loops interprétées par les joueurs Session Players. Ajoutez rapidement des rythmiques, des lignes de basse et de clavier en faisant glisser une boucle Session Player du navigateur de boucles vers votre projet.

## Vérifier les réglages de latence des modules Logic Pro

Avant d’ajouter une boucle Session Player, vérifiez les réglages de latence des modules :

- Sélectionnez Logic Pro dans la barre des menus et choisissez Réglages, puis Audio.

- Cliquez sur Général.

- Dans la section Temps de latence du module, sélectionnez « Pre-roll en lecture » ou choisissez Non dans le menu local Compensation.

## Rechercher une boucle Session Player

- Cliquez sur le bouton Navigateur de boucles situé dans l’angle supérieur droit de la fenêtre Logic Pro ou appuyez sur la touche O de votre clavier. Les boucles Session Player sont identifiées par une icône jaune dans le navigateur de boucles.

- Pour afficher uniquement les boucles Session Player dans le navigateur de boucles, sélectionnez Session Player dans le menu local Paquets de sons situé dans la partie supérieure du navigateur de boucles.

- Pour écouter une boucle, cliquez dessus dans le navigateur de boucles.

- Pour régler le volume d’écoute des boucles, ajustez le curseur de volume situé en bas du navigateur de boucles.

## Ajouter une boucle Session Player à votre projet

Une fois que vous avez choisi une boucle Session Player, faites-la glisser vers un emplacement vide de la zone Pistes ou une cellule vide de la grille des boucles. Logic Pro crée automatiquement une piste avec une région de la boucle Session Player. Si la boucle contient des accords, vous avez la possibilité de [les copier sur la piste d’accords](https://support.apple.com/guide/logicpro/lgcp516b16d1/mac/14.4#lgcp00c3130a) afin que d’autres Session Players dans le projet puissent les suivre.

Une fois la boucle ajoutée, vous pouvez [modifier la performance](https://support.apple.com/guide/logicpro/lgcp74b34026/mac) en utilisant l’éditeur de Session Player et en ajustant les réglages de tranche de console. Logic Pro configure automatiquement tous les réglages dans l’éditeur de Session Player.

## Modifier le patch par défaut d’une boucle Session Player

Lorsque vous ajoutez une boucle Session Player à une nouvelle piste, elle est lue en utilisant un patch par défaut. Mais il est possible de changer de patch. Sélectionnez la piste avec la boucle Session Player, puis choisissez un autre patch dans la bibliothèque.

Par exemple, vous pouvez ajouter la boucle « Arpeggiated Piano 01 », puis remplacer le patch Studio Piano (Piano de studio) par le patch Studio Cellos (Violoncelles de studio) pour écouter la boucle jouée par des cordes au lieu d’un piano.

## Ajouter de boucles Session Player supplémentaires

- Lorsque vous ajoutez une boucle à une piste Session Player existante, elle est lue en utilisant un patch par défaut qui dépend du style de la boucle. Par exemple, si vous ajoutez une boucle de batterie à une piste sur laquelle vous avez déjà ajouté une boucle de piano, la boucle de batterie est lue avec des sons de piano au lieu de sons de batterie.

- Si vous ajoutez des boucles Session Player de plusieurs joueurs à une même piste, le son des boucles peut être différent de celui de leur aperçu audio. Le patch change et le nouveau joueur interprète les réglages à sa façon.
