# Sauvegarder Logic Pro pour Mac

Avant de mettre à jour Logic Pro, il est recommandé de sauvegarder la version actuellement installée de l’app ainsi que vos projets.

## Sauvegarder l’app Logic Pro

- Créez un dossier dans le dossier Applications. Intitulez ce dossier en fonction du nom et de la version de l’application (par exemple, « Logic Pro 11.1.2 »). Pour connaître la version de Logic Pro dont vous disposez, ouvrez l’application et choisissez À propos de Logic Pro dans le menu Logic Pro.

- Sélectionnez l’application Logic Pro dans le dossier Applications. Choisissez Fichier > Compresser « Logic Pro ». La compression peut durer quelques minutes.

- Placez le fichier « Logic Pro.zip » ainsi obtenu dans le dossier créé à l’étape 1.

- Si vous avez besoin d’économiser de l’espace sur votre disque de démarrage, déplacez le dossier contenant le fichier ZIP vers un périphérique de stockage externe, puis supprimez le dossier de votre dossier Applications.

### Réinstaller une version sauvegardée de l’app Logic Pro

Si la mise à jour de l’app entraîne des problèmes, réinstallez la version sauvegardée afin de pouvoir continuer à travailler sur vos projets.

- Faites glisser la version actuellement installée de l’app Logic Pro du dossier Applications vers la corbeille, puis videz la corbeille.

- Accédez à la copie de sauvegarde de Logic Pro, puis double-cliquez sur le fichier ZIP pour le décompresser.

- Si vous avez décompressé le fichier ZIP à un autre emplacement que dans le dossier Applications, faites glisser le fichier non compressé de l’app Logic Pro vers le dossier Applications.

## Sauvegarder les projets Logic Pro

La création d’une sauvegarde de vos projets Logic Pro vous permet de travailler sur vos projets sur un autre Mac. Vous devez également sauvegarder régulièrement vos projets Logic Pro, par mesure de sécurité.

- [Consolidez les ressources de chaque projet](https://support.apple.com/guide/logicpro/consolidate-assets-in-a-project-lgcpce09b9d8/mac) afin de regrouper au même endroit tous leurs fichiers audio et contenus associés.

- Pour sauvegarder vos projets Logic Pro :

- Utilisez une solution de sauvegarde système, telle que [Time Machine](https://support.apple.com/HT201250) .

- [Copiez vos projets sur un périphérique de stockage externe](https://support.apple.com/guide/mac-help/mchl027f1d66/mac) .
