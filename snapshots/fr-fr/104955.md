# Accéder aux mots de passe et clés d’accès enregistrés sur votre iPhone

Découvrez comment afficher et modifier les mots de passe et clés d’accès enregistrés sur votre iPhone ou iPad.

## Afficher les mots de passe et clés d’accès enregistrés dans Mots de passe

Pour utiliser l’app Mots de passe, effectuez la mise à jour vers iOS 18.

- Ouvrez l’app Mots de passe.

- Déverrouillez l’accès à l’app à l’aide de Face ID ou Touch ID ou saisissez votre code.

[Image: L’app Mots de passe sur iPhone.]

- Pour afficher un mot de passe ou une clé d’accès, choisissez une catégorie ou un groupe partagé, puis sélectionnez un site web ou une app.

[Image: Recherche d’un mot de passe enregistré dans l’app Mots de passe.]

- Pour mettre à jour un mot de passe, touchez Modifier, puis Modifier le mot de passe.

- Pour supprimer un mot de passe ou une clé d’accès, touchez Modifier, puis Supprimer. Sous iOS 17 ou version antérieure, sélectionnez le site web ou l’app, puis touchez Supprimer le mot de passe ou Supprimer la clé d’accès.

## Afficher les mots de passe et clés d’accès enregistrés sous iOS 17 ou version antérieure

- Touchez Réglages, faites défiler l’écran vers le bas et touchez Mots de passe.

- Utilisez Face ID ou Touch ID lorsque vous y êtes invité, ou saisissez votre code d’accès.

- Pour afficher un mot de passe ou une clé d’accès, sélectionnez un site web ou une app.

- Pour mettre à jour un mot de passe, touchez Modifier.

- Pour supprimer un mot de passe ou une clé d’accès, touchez Supprimer le mot de passe ou Supprimer la clé d’accès.

## Demander à Siri de retrouver des mots de passe enregistrés

Attirez l’attention de Siri, puis dites quelque chose comme « Montre-moi mes mots de passe ». Si vous recherchez le mot de passe d’un site web ou d’une app spécifique, essayez de dire quelque chose comme « Quel est mon mot de passe pour Hulu ? »

## Si vous ne retrouvez pas un mot de passe ou une clé d’accès enregistrés

- Vérifiez que vous avez bien accès à tous vos mots de passe et clés d’accès. Dans l’app Mots de passe, choisissez la catégorie Tout. Sous iOS 17 ou version antérieure, l’écran Réglages doit indiquer « Mots de passe » en haut, et non le nom d’un groupe partagé ou « Mes mots de passe ».

- Vérifiez les suppressions récentes : dans l’app Mots de passe, touchez Supprimés. Sous iOS 17 ou version antérieure, accédez à Réglages, faites défiler l’écran vers le bas et touchez Mots de passe. Touchez ensuite Suppressions récentes.

- Si vous avez plusieurs appareils Apple, assurez-vous que le trousseau iCloud est activé.

- Lorsque vous déplacez un mot de passe ou une clé d’accès vers un groupe partagé, cet élément est visible uniquement sur les appareils dotés d’un logiciel compatible. Si vous ne trouvez pas un mot de passe ou une clé d’accès enregistrés que vous avez déplacés vers un groupe partagé sur un autre appareil, assurez-vous que votre iPhone fonctionne sous iOS 17 ou version ultérieure.

- [Accédez à vos mots de passe Wi-Fi enregistrés.](https://support.apple.com/fr-fr/104961)

## Enregistrer vos mots de passe et clés d’accès sur tous vos appareils avec le trousseau iCloud

Le trousseau iCloud met à jour vos mots de passe, vos clés d’accès et vos autres informations sécurisées sur votre iPhone, iPad, Mac ou PC.

- [Découvrir comment configurer le trousseau iCloud](https://support.apple.com/fr-fr/109016)

- [Configurer Mots de passe iCloud sur votre PC](https://support.apple.com/guide/icloud-windows/icw2babf5e03)

## Stocker les informations de cartes de crédit à l’aide du remplissage automatique

La fonctionnalité de remplissage automatique renseigne automatiquement certains éléments, tels que les informations de cartes de crédit précédemment enregistrées, celles des contacts enregistrés dans l’app Contacts, etc.

[Configurer et utiliser le remplissage automatique dans Safari sur votre iPhone](https://support.apple.com/guide/iphone/iphccfb450b7)
