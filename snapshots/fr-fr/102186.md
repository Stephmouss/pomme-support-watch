# Déplacer votre bibliothèque iMovie pour Mac

Pour libérer de l’espace sur votre Mac, déplacez votre bibliothèque iMovie vers un périphérique de stockage externe.

Une bibliothèque iMovie contient vos projets iMovie, ainsi que l’ensemble des fichiers multimédias et données utilisés dans vos projets. Les bibliothèques iMovie pouvant devenir très volumineuses, vous pouvez les stocker sur un périphérique de stockage externe et libérer ainsi de l’espace sur votre Mac. Avant de déplacer une bibliothèque iMovie, il est recommandé de [sauvegarder les données de votre Mac](https://support.apple.com/HT201250) .

## Préparer votre périphérique de stockage externe

Vous pouvez stocker votre photothèque sur un périphérique de stockage externe tel qu’un lecteur USB ou Thunderbolt [dans un format compatible Mac comme APFS ou Mac OS étendu (journalisé)](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac) . Apple déconseille de stocker les bibliothèques iMovie sur des périphériques comme des cartes SD, des clés USB ou sur un réseau de stockage partagé.

Vous ne pouvez pas stocker votre bibliothèque sur un périphérique de stockage utilisé pour les sauvegardes Time Machine.

## Déplacer une bibliothèque vers un périphérique de stockage externe

- Quittez iMovie.

- Dans le Finder, choisissez Aller dans la barre de menus, puis Départ.

- Ouvrez le dossier Vidéos, puis faites glisser le fichier intitulé Bibliothèque iMovie vers votre périphérique de stockage externe. Si le fichier ne se trouve pas dans le dossier Films, [recherchez Bibliothèque iMovie à l’aide de Spotlight](https://support.apple.com/guide/mac-help/mchlp1008/mac) .

- Une fois le fichier de la bibliothèque copié, cliquez deux fois dessus depuis le périphérique de stockage externe pour l’ouvrir dans iMovie. Si un message d’alerte vous invite à autoriser iMovie à accéder à un volume amovible, cliquez sur OK.

- Assurez-vous que la bibliothèque que vous avez déplacée contient tous vos fichiers multimédias, puis faites glisser le fichier d’origine du dossier Vidéos de votre Mac vers la corbeille.

- Videz la corbeille.

Lorsque vous enregistrez vos projets après avoir déplacé la bibliothèque, tout le contenu importé dans iMovie ainsi que vos projets sont enregistrés dans le nouvel emplacement.

## Si vous déconnectez le périphérique de stockage externe

Si le périphérique de stockage contenant la bibliothèque est connecté, la bibliothèque que vous avez déplacée s’ouvre automatiquement lorsque vous ouvrez iMovie. Si le périphérique de stockage n’est pas connecté, iMovie s’ouvre dans une nouvelle bibliothèque vide créée dans le dossier Films sur votre Mac. iMovie enregistre vos projets et vos fichiers multimédias importés dans la nouvelle bibliothèque.

Si vous souhaitez ouvrir la bibliothèque que vous avez déplacée vers un périphérique de stockage externe, connectez ce dernier, puis double-cliquez sur le fichier de la bibliothèque iMovie. Vous pouvez ensuite [déplacer des plans, des évènements et des projets entre des bibliothèques](https://support.apple.com/guide/imovie/mov3fa25bae7/mac) .
