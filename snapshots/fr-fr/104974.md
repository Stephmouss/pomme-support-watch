# Répondre à des messages spécifiques sur votre iPhone et iPad

Sous iOS 18 et iPadOS 18 ou version ultérieure, vous pouvez répondre directement à un message spécifique et attirer l’attention sur certains messages et certaines personnes en utilisant des mentions.

## Comment répondre à un message spécifique

- Ouvrez une conversation dans Messages.

- Maintenez le doigt sur une bulle de message, puis touchez le bouton Répondre .

[Image: null]

[Image: Un iPhone affichant le menu de réponse ciblée après un appui prolongé sur une bulle de message pour envoyer une réponse ciblée]

- Saisissez votre message, puis touchez le bouton Envoyer .

[Image: null]

Vous pouvez répondre à un message spécifique dans des conversations avec une personne ou un groupe.

## Comment utiliser les mentions

- Ouvrez une conversation dans Messages.

- Saisissez le nom d’un contact, puis touchez son nom lorsqu’il apparaît. Vous pouvez également saisir @ suivi du nom du contact.

[Image: Un iPhone montrant comment envoyer une mention dans un message]

Selon les réglages définis par votre contact, celui-ci pourra recevoir une notification même s’il a coupé le son de la conversation. Pour modifier ce réglage de notification :

- Dans l’app Réglages, touchez Apps.

- Touchez Messages.

- Faites défiler l’écran jusqu’à Mentions, puis activez ou désactivez l’option Me prévenir.
