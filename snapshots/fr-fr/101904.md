# Préparation de la mise à jour de macOS Server sous macOS Monterey

Pour utiliser macOS Server sous macOS Monterey, une version plus récente de macOS Server est requise.

macOS Server 5.11.1 ou version antérieure n’est pas compatible avec macOS Monterey. Pour utiliser macOS Server avec macOS Monterey, effectuez la mise à jour vers macOS Server 5.12.
