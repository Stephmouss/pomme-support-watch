# Mac OS X : Montage de dossiers partagés à l’aide d’une url afp:// ou de la commande mount_afp

Vous pouvez monter un volume partagé sur un serveur AFP avec une URL au format afp://monserveur.mondomaine.com/Sharepoint/Dossier, ou dans Terminal, vous pouvez utiliser la commande mount_afp .

Dans Mail.app ou Safari, lorsque vous cliquez sur une URL au format afp://monserveur.mondomaine.com/Sharepoint/Dossier, le Finder monte le volume nommé Sharepoint sur le serveur AFP monserveur.mondomaine.com et ouvre une fenêtre affichant le contenu du répertoire nommé Dossier. Si vous faites glisser le texte de l’URL vers votre bureau, cela crée un lien AFP sur lequel vous pouvez double-cliquer pour ouvrir ce dossier.

La commande mount_afp peut être utilisée dans une fenêtre Terminal ou un script shell pour monter un dossier partagé sur un serveur AFP. Pour plus d’informations, saisissez la commande suivante dans une fenêtre Terminal :

man mount_afp

## Informations supplémentaires

### Informations sur Mac OS X versions 10.6 à 10.6.6

Le chemin de montage du dossier partagé est différent sous Mac OS X versions 10.6 à 10.6.6 par rapport aux autres versions de Mac OS X.

Une URL pointant vers un fichier sur le serveur (par exemple, afp://monserveur.mondomaine.com/Sharepoint/Dossier/Fichier.txt) ne fonctionnera pas. Ce problème est résolu sous Mac OS X 10.6.7 et versions ultérieures.

Sous Mac OS X versions 10.6 à 10.6.6, si la cible de l’URL ou de la commande mount_afp est un dossier au sein de Sharepoint, le dossier sera monté. Sous Mac OS X versions 10.0 à 10.5, et Mac OS X 10.6.7 ou version ultérieure (y compris OS X Lion), Sharepoint est monté.

Exemple : afp://monserveur.mondomaine.com/Sharepoint/Dossier

Lorsque vous cliquez sur ce lien sous Mac OS X versions 10.0 à 10.5 et 10.6.7 et versions ultérieures, le Finder monte le volume Sharepoint. Le chemin d’accès local au dossier partagé sera /Volumes/SharePoint/Dossier/.

Lorsque vous cliquez sur ce lien sous Mac OS X versions 10.6 à 10.6.6, le Finder monte le dossier de sous-répertoire Dossier. Le chemin d’accès local au dossier partagé sera /Volumes/Dossier/.

Exemple :

mount_afp afp://monserveur.mondomaine.com/Sharepoint/Dossier /Volumes/mntpnt

Sous Mac OS X 10.5 et 10.6.7 ou version ultérieure, cette commande permet de monter le volume Sharepoint dans /Volumes/mntpnt. Le chemin d’accès local au dossier partagé sera /Volumes/mntpnt/Dossier/.

Sous Mac OS X versions 10.6 à 10.6.6, cette commande permet de monter le sous-répertoire Dossier dans /Volumes/mntpnt. Le chemin d’accès local au dossier partagé sera /Volumes/mntpnt/.
