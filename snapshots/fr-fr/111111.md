# Utiliser AssistiveTouch sur votre Apple Watch

Avec AssistiveTouch, vous pouvez utiliser votre Apple Watch et naviguer sur celle-ci avec des gestes de la main.

## Éléments requis

AssistiveTouch est compatible avec l’Apple Watch Series 4 et modèles ultérieurs, l’Apple Watch SE (1ʳᵉ génération) et modèles ultérieurs, ainsi que l’Apple Watch Ultra et modèles ultérieurs. Assurez-vous que vous disposez de la [dernière version de watchOS](https://support.apple.com/fr-fr/108926) .

## Activer AssistiveTouch sur votre Apple Watch

- Ouvrez l’app Réglages sur votre Apple Watch.

- Touchez Accessibilité, puis AssistiveTouch.

- Touchez AssistiveTouch pour l’activer, puis OK pour confirmer. Vous pouvez également toucher Essayer pour voir une présentation visuelle.

Vous pouvez également [utiliser Siri sur votre Apple Watch](https://support.apple.com/guide/watch/use-siri-apd02f71f945/watchos) pour activer AssistiveTouch. L’app Apple Watch sur votre iPhone permet également d’activer AssistiveTouch et de personnaliser toutes les fonctionnalités associées.

Le geste universel Toucher deux fois n’est pas disponible lorsque vous activez AssistiveTouch.

## Naviguer sur votre Apple Watch à l’aide de gestes de la main

Lorsque vous levez votre poignet, un anneau bleu autour de l’écran de votre Apple Watch indique que la fonctionnalité AssistiveTouch est activée. Pour activer AssistiveTouch, serrez rapidement votre poing deux fois.

Une fois AssistiveTouch activé, un anneau de focus apparaît autour du premier élément de votre écran. Il indique que vous pouvez toucher l’élément via AssistiveTouch.

Vous pouvez modifier la couleur de l’anneau de focus : ouvrez Réglages sur votre Apple Watch, touchez Accessibilité, touchez AssistiveTouch, touchez Couleur, puis choisissez une nouvelle couleur. Vous pouvez également désactiver l’anneau de focus dans les Réglages : touchez Accessibilité, touchez AssistiveTouch, touchez Gestes de la main, touchez Geste d’activation, puis touchez Signal visuel pour l’activer ou le désactiver.

Avec les actions par défaut, vous pouvez naviguer sur votre Apple Watch à l’aide des gestes suivants :

- Passer à l’élément suivant : Toucher (joignez le pouce et l’index) [Lecture](https://support.apple.com/fr-fr/111111) [Pause](https://support.apple.com/fr-fr/111111) [Relancer](https://support.apple.com/fr-fr/111111)

- Reculer d’un élément : Toucher deux fois (joignez rapidement le pouce et l’index deux fois) [Lecture](https://support.apple.com/fr-fr/111111) [Pause](https://support.apple.com/fr-fr/111111) [Relancer](https://support.apple.com/fr-fr/111111)

- Toucher un élément : serrement (serrez le poing) [Lecture](https://support.apple.com/fr-fr/111111) [Pause](https://support.apple.com/fr-fr/111111) [Relancer](https://support.apple.com/fr-fr/111111)

- Afficher le [menu Action](https://support.apple.com/fr-fr/111111#actionmenu) : Serrer le poing deux fois (serrez rapidement le poing deux fois). Le menu Action vous permet d’effectuer un certain nombre d’actions via AssistiveTouch, comme faire défiler l’écran, appuyer sur la Digital Crown, etc. [Lecture](https://support.apple.com/fr-fr/111111) [Pause](https://support.apple.com/fr-fr/111111) [Relancer](https://support.apple.com/fr-fr/111111)

### Personnaliser les gestes de la main AssistiveTouch

- Ouvrez l’app Réglages sur votre Apple Watch ou l’app Apple Watch sur votre iPhone.

- Touchez Accessibilité, touchez AssistiveTouch, puis touchez Gestes de la main.

- Touchez un geste, puis sélectionnez l’action que vous souhaitez effectuer lorsque vous effectuez ce geste.

Vous pouvez également personnaliser le geste de la main qui active AssistiveTouch. Dans Réglages, accédez à Accessibilité, touchez AssistiveTouch, touchez Gestes de la main, puis touchez Geste d’activation.

### Utiliser le curseur manuel ou automatique

Si le curseur manuel est activé, vous pouvez utiliser des gestes de la main pour contrôler le déplacement d’AssistiveTouch vers l’élément suivant sur votre écran et contrôler l’élément que vous avez touché.

Si le curseur automatique est activé, votre Apple Watch passe automatiquement d’un élément à l’autre. Vous pouvez utiliser les gestes par défaut suivants avec le curseur automatique :

- Afficher le menu Action : Toucher

- Inverser la direction : Toucher deux fois

- Lorsque le curseur automatique est activé, si vous serrez le poing une ou deux fois, vous exécuterez l’action associée à ces gestes.

## Utiliser la fonctionnalité Confirmer avec AssistiveTouch

- Ouvrez l’app Réglages sur votre Apple Watch.

- Touchez Accessibilité, puis AssistiveTouch.

- Touchez Confirmer avec AssistiveTouch, puis Continuer.

- Appuyez deux fois sur le bouton latéral, puis saisissez votre code d’accès.

- Appuyez à nouveau deux fois sur le bouton latéral pour confirmer.

Une fois que vous avez activé cette fonctionnalité, vous pouvez utiliser les gestes de la main AssistiveTouch chaque fois que vous devez appuyer deux fois sur le bouton latéral, par exemple lors du déverrouillage de votre Mac ou de la confirmation d’un paiement Apple Pay. Lorsque vous confirmez un paiement Apple Pay, vous devez également saisir votre code d’accès.

## Naviguer sur votre Apple Watch avec le pointeur de mouvement

Le pointeur de mouvement constitue une autre façon d’utiliser AssistiveTouch. Il apparaît sous la forme d’une icône de cercle sur l’écran de votre Apple Watch et vous pouvez contrôler ses mouvements en inclinant votre montre. Pour activer le pointeur de mouvement, secouez votre poignet ou utilisez le menu Action.

### Activer le pointeur de mouvement en secouant votre poignet

- Ouvrez l’app Réglages sur votre Apple Watch.

- Touchez Accessibilité, touchez AssistiveTouch, touchez Pointeur de mouvement, puis touchez Contrôle d’attente.

- Touchez Contrôle d’attente pour activer la fonctionnalité.

- Touchez Secouer pour commencer si vous souhaitez que le pointeur de mouvement apparaisse lorsque vous secouez le poignet.

- Levez votre Apple Watch, puis secouez votre poignet pour faire apparaître le pointeur de mouvement.

### Activer le pointeur de mouvement à l’aide du menu Action

- Affichez le menu Action en effectuant un geste de la main. Le geste par défaut est un double serrement du poing.

- Avancez dans le menu Action en utilisant le geste de toucher par défaut jusqu’à ce que l’option Interaction soit sélectionnée, puis touchez-la en serrant le poing.

- Touchez Pointeur de mouvement.

Lorsque vous déplacez le pointeur de mouvement et que celui-ci passe sur un élément, vous pouvez toucher ce dernier d’un simple geste de la main. Vous pouvez autoriser le pointeur de mouvement à sélectionner automatiquement l’élément après un laps de temps donné. Vous pouvez également configurer le pointeur de mouvement de façon à afficher le menu Action lorsqu’il sélectionne un élément sur votre écran.

Le pointeur de mouvement peut vous aider à effectuer un balayage sur l’écran de votre Apple Watch avec les bords actifs. Lorsque vous passez le pointeur de mouvement à proximité d’un bord de l’écran, un balayage est effectué dans cette direction. Vous pouvez personnaliser ces bords actifs dans Réglages : touchez Accessibilité, touchez AssistiveTouch, puis touchez Pointeur de mouvement.

## Utiliser le menu Action AssistiveTouch

Le menu Action est composé d’une liste d’éléments que vous pouvez toucher pour effectuer des actions dans toutes les zones de votre Apple Watch. Il s’adapte au contexte : il évolue donc afin d’afficher les actions pertinentes en fonction de votre utilisation de l’Apple Watch.

Pour utiliser le menu Action, effectuez le geste de la main qui lui est associé (double serrement du poing par défaut). Utilisez ensuite des gestes pour avancer ou reculer dans la liste des éléments, et pour toucher un élément.

Pour personnaliser le menu d’action AssistiveTouch, ouvrez Réglages, touchez Accessibilité, touchez AssistiveTouch, puis touchez Personnaliser le menu.

- toucher Ajouter une action sous Favoris, puis toucher une action que vous souhaitez voir apparaître dans le menu Action à côté des éléments par défaut ;

- choisir l’emplacement d’affichage du menu Action ;

- augmenter la taille du menu.

### Utiliser le défilement automatique dans le menu Action

Le défilement automatique permet d’utiliser des gestes de la main pour effectuer des actions telles que tourner la Digital Crown ou effectuer un balayage vers le haut ou vers le bas sur l’écran de votre montre.

- Affichez le menu Action en effectuant un geste de la main. Le geste par défaut est un double serrement du poing.

- Avancez dans le menu Action en utilisant le geste de toucher par défaut jusqu’à ce que l’option Défilement automatique soit sélectionnée, puis touchez-la en serrant le poing.

- Utilisez le geste de toucher pour parcourir les options de défilement automatique, puis serrez le poing pour en sélectionner une.

Les actions de défilement automatique sont contextuelles et s’adaptent au contenu de votre écran. Par exemple, si vous utilisez une app audio, le fait de sélectionner la Digital Crown augmente le volume. Lorsque vous utilisez la fonctionnalité de défilement automatique, des instructions s’affichent à l’écran pour vous aider à l’utiliser.

## Utiliser des actions rapides lorsque vous recevez des alertes

Les actions rapides vous aident à répondre lorsque votre Apple Watch affiche une alerte. Par exemple, lorsque vous recevez un appel entrant, une invite vous indique que vous pouvez serrer le poing deux fois pour y répondre. Vous pouvez également utiliser des actions rapides pour répéter une alarme ou arrêter un minuteur. Pour ignorer l’action rapide, effectuez un double toucher.

Pour activer ou désactiver les actions rapides, ouvrez Réglages, touchez Accessibilité, puis Actions rapides.
