# Si vous ne parvenez pas à trouver ou à utiliser vos achats intégrés

Si vous ne parvenez pas à utiliser ou à trouver les achats intégrés que vous avez effectués, essayez de les restaurer.

## Restaurer des achats intégrés

Certains achats intégrés (achats de monnaie fictive ou d’astuces pour un jeu, par exemple) sont consommables, ce qui signifie qu’ils s’amenuisent à mesure que vous les utilisez. Vous ne pouvez pas restaurer des achats consommables. [Découvrez les différents types d’achats intégrés](https://support.apple.com/fr-fr/108813) .

Vous pouvez parfois restaurer un achat non consommable, comme une mise à niveau vers une version professionnelle, une fonctionnalité supplémentaire dans un jeu ou un abonnement :

- Ouvrez l’app que vous avez utilisée pour acheter l’article.

- Recherchez une option de restauration. Vous pouvez la trouver dans le magasin de l’app, le menu principal, le menu des réglages ou le menu des options.

## Si vous essayez de restaurer un achat, mais que rien ne se passe ou qu’un message d’erreur s’affiche

- Assurez-vous d’être connecté avec le même compte Apple que celui utilisé pour effectuer l’achat.

- [Assurez-vous que les achats intégrés sont autorisés sur votre appareil](https://support.apple.com/fr-fr/102470) .

- Redémarrez votre appareil.

- Si l’achat vous a été facturé, mais que vous ne parvenez toujours pas à le restaurer, [contactez le développeur de l’app](https://support.apple.com/fr-fr/102435) . Vous pouvez également [signaler un problème à Apple](https://reportaproblem.apple.com/?s=6) .
