# Si votre Mac indique qu’il a rencontré un problème lors du démarrage

Le système de récupération de macOS Tahoe 26 ou version ultérieure comprend l’Assistant de récupération, un utilitaire conçu pour s’ouvrir automatiquement lorsque votre Mac rencontre un problème qui empêche son démarrage. L’Assistant de récupération tente d’identifier le problème et de le résoudre.

## Utiliser l’Assistant de récupération

Nécessite macOS Tahoe 26 ou version ultérieure

Si votre Mac présente certains comportements au démarrage, il se peut qu’il redémarre automatiquement et ouvre l’Assistant de récupération :

[Image: Assistant de récupération sous macOS Tahoe 26]

- L’Assistant de récupération affiche un symbole de premiers secours et indique que ce Mac a rencontré un problème lors du démarrage. Cliquez sur Continuer.

- Lisez les informations relatives à la collecte des données de diagnostic, qui sont traitées conformément à [l’Engagement de confidentialité d’Apple](https://www.apple.com/legal/privacy/fr-ww/) . Choisissez ensuite si vous souhaitez ou non envoyer ces données à Apple. Votre choix n’a pas d’impact sur le résultat.

- S’il vous est demandé de saisir un mot de passe pour déverrouiller le disque, saisissez le mot de passe d’administration qui vous sert à ouvrir une session sur votre Mac. Cliquez sur Déverrouiller.

- L’Assistant de récupération a besoin d’une connexion Internet pour télécharger les dernières informations sur les problèmes logiciels que votre Mac pourrait rencontrer. Si un message vous le demande, choisissez un réseau Wi-Fi. Les réseaux captifs et les réseaux nécessitant une authentification 802.1X ne sont pas pris en charge.

- Une fois le processus de récupération terminé, l’Assistant de récupération signale soit qu’il a réussi à récupérer les données de votre appareil, soit qu’il n’a pas pu les récupérer, soit qu’aucun problème connu n’a été détecté. Cliquez sur Redémarrer le Mac.

- Si votre Mac démarre correctement, il se peut que vous receviez une notification vous invitant à récupérer vos données iCloud. Cliquez sur la notification pour ouvrir Réglages Système, ou choisissez Réglages Système dans le menu Pomme , puis cliquez sur Recover iCloud Data (Récupérer les données iCloud) dans la barre latérale. Un message vous invite ensuite à vous connecter à votre compte Apple.

- Si votre Mac ne démarre pas correctement, cela signifie qu’il présente un problème que l’Assistant de récupération ne peut pas résoudre. Dans ce cas, découvrez ce que vous pouvez faire d’autre [si votre Mac ne démarre pas complètement](https://support.apple.com/fr-fr/102675) . Par exemple, vous devrez peut-être [réparer votre disque de démarrage](https://support.apple.com/fr-fr/102611) ou [réinstaller macOS](https://support.apple.com/fr-fr/102655) .

## Informations supplémentaires

- L’Assistant de récupération est également accessible depuis le menu Utilitaires dans [Récupération macOS](https://support.apple.com/fr-fr/102518) . Vous ne devriez pas avoir besoin d’ouvrir l’Assistant de récupération manuellement, sauf si l’assistance Apple ou un autre article d’assistance le recommande.

- Si vous avez besoin de quitter l’Assistant de récupération pour revenir à Récupération macOS, appuyez sur les touches Commande + Q ou choisissez Quitter dans le menu Assistant de récupération d’appareil de la barre des menus.
