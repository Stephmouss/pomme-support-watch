# Projets ouverts créés avec des versions antérieures de Logic Pro pour Mac

Si vous ouvrez un projet créé avec une version antérieure de Logic Pro, celui-ci peut présenter des routages de sortie inattendus et d’autres problèmes empêchant une lecture correcte.

Cela peut se produire si vous essayez d’ouvrir un projet créé à l’origine dans Logic 4, 5 ou 6, que vous avez ensuite ouvert et enregistré dans Logic Pro 7, 8 ou 9. Voici comment travailler avec ces projets dans les versions les plus récentes de Logic Pro :

- Si vous ne l’avez pas déjà fait, ouvrez le projet dans Logic Pro 10 ou une version ultérieure, enregistrez-le, puis fermez-le.

- Créez un projet Logic Pro vide.

- Choisissez Fichier > Importer > Projets Logic, sélectionnez l’ancien projet que vous avez enregistré, puis cliquez sur Importer. Toutes les pistes de l’ancien projet apparaissent dans le navigateur sur le côté droit de la fenêtre principale de Logic Pro.

- Pour chaque piste audio ou d’instrument que vous souhaitez ajouter au nouveau projet, cochez la case Contenu. Pour sélectionner toutes les pistes, y compris les pistes auxiliaires et de sortie, appuyez sur Cmd-A, puis cochez la case d’une piste.

- Cliquez sur tous les autres paramètres que vous souhaitez importer dans le nouveau projet, à l’exception des réglages d’E/S.

- Cliquez sur Ajouter au bas du navigateur.

Les pistes sélectionnées sont ajoutées à la zone Pistes, avec les autres paramètres que vous avez sélectionnés dans le navigateur.
