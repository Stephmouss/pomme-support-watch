# Réaliser une capture d’écran sur votre iPhone

Enregistrez rapidement le contenu de votre écran.

Après avoir pris une capture d’écran dans iOS 26, votre appareil affiche automatiquement la capture d’écran avec des outils rapides disponibles. Vous pouvez [dessiner sur l’image avec la fonctionnalité Annotation](https://support.apple.com/119875) , recadrer votre image, envoyer la capture d’écran à d’autres apps ou contacts, ou toucher le bouton Enregistrer pour choisir où enregistrer votre capture d’écran sur votre appareil.

Dans iOS 18 et versions antérieures, une vignette apparaît temporairement dans le coin inférieur gauche de votre écran. Touchez la vignette pour l’ouvrir, ou effectuez un balayage vers la gauche sur celle-ci pour la faire disparaître de l’écran.

## Comment faire une capture d’écran sur un iPhone avec Face ID

- Appuyez simultanément sur le bouton latéral et sur le bouton d’augmentation du volume. [Lecture](https://support.apple.com/fr-fr/102616) [Pause](https://support.apple.com/fr-fr/102616) [Relancer](https://support.apple.com/fr-fr/102616)

- Relâchez rapidement les deux boutons.

- Après avoir réalisé une capture d'écran, retouchez-la, partagez-la ou enregistrez-la. Dans iOS 18 ou versions antérieures, une vignette apparaît temporairement dans le coin inférieur gauche de votre écran. Touchez la vignette pour l’ouvrir, ou effectuez un balayage vers la gauche sur celle-ci pour la faire disparaître de l’écran.

## Réaliser une capture d’écran sur les modèles d’iPhone avec Touch ID et bouton latéral

- Appuyez simultanément sur le bouton latéral et sur le bouton principal.

- Relâchez rapidement les deux boutons.

- Après avoir réalisé une capture d'écran, retouchez-la, partagez-la ou enregistrez-la. Dans iOS 18 ou versions antérieures, une vignette apparaît temporairement dans le coin inférieur gauche de votre écran. Touchez la vignette pour l’ouvrir, ou effectuez un balayage vers la gauche sur celle-ci pour la faire disparaître de l’écran.

- Appuyez simultanément sur le bouton supérieur et sur le bouton principal.

- Relâchez rapidement les deux boutons.

- Après avoir réalisé une capture d'écran, retouchez-la, partagez-la ou enregistrez-la. ## Emplacement des captures d’écran

Ouvrez Photos, puis allez dans Collections et touchez Types de média. Touchez Captures d’écran.
