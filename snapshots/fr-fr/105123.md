# Utilisation du mode Express avec des cartes de transport, des billets et des clés dans l’app Cartes d’Apple

Avec le mode Express, vous pouvez utiliser des cartes, des billets, des coupons et des clés compatibles dans l’app Cartes d’un simple geste.

Avec le mode Express, vous pouvez utiliser [certains billets et certaines cartes et clés](https://support.apple.com/guide/iphone/iphc05dba539/ios) dans l’app Cartes d’Apple sans avoir à réactiver ou déverrouiller votre appareil, ni à vous authentifier avec Face ID, Touch ID ou votre code d’accès. Vous pouvez peut-être même utiliser votre carte, billet ou clé lorsque votre appareil a besoin d’être chargé.

## Sélectionner le mode Express pour une carte de transport ou de paiement, un billet ou une clé

Lorsque vous ajoutez une carte de transport éligible ou toute autre carte, clé ou billet compatible dans l’app Cartes d’Apple, le mode Express est activé par défaut. Vous pouvez également modifier quels sont les cartes, billets ou clés qui utilisent le mode Express.

- Avec le mode Express, plusieurs cartes, billets, coupons et clés peuvent être actifs simultanément dans l’app Cartes. Par exemple, vous pouvez activer le mode Express pour une carte d’étudiant et une clé de voiture.

- Il est possible que vous ne puissiez pas activer le mode Express pour plusieurs cartes, billets et clés du même type ou du même émetteur. Par exemple, vous ne pouvez activer le mode Express que pour une seule carte d’étudiant d’un seul établissement.

- Avec certains billets, vous pourrez peut-être activer le mode Express pour plusieurs billets du même type.

- Pour chaque réseau de transport, vous pouvez activer le mode Express pour une carte de transport. Vous pouvez également définir une carte de paiement pour payer votre trajet là où votre carte de transport n’est pas acceptée.

### Sélectionner le mode Express pour une carte de transport ou de paiement, un billet ou une clé sur votre iPhone

- Ouvrez l’app Cartes et sélectionnez une carte, un billet ou une clé.

- Touchez le bouton Plus , puis touchez Données de la carte.

- Touchez Réglages de Transport express ou Mode Express.

- Sélectionnez votre carte de transport ou de paiement préférée, ou tout autre billet ou clé compatible.

### Sélectionner le mode Express pour une carte de transport ou de paiement, un billet ou une clé sur votre Apple Watch

- Ouvrez l’app Apple Watch sur votre iPhone.

- Dans l’onglet Ma montre, touchez Cartes et Apple Pay.

- Touchez Carte de transport express, sélectionnez une carte de transport ou de paiement, puis authentifiez-vous sur votre Apple Watch avec votre code d’accès.

### Cartes, clés et billets compatibles

Vous pouvez sélectionner le mode Express pour les cartes, les clés et billets compatibles, notamment :

- [Cartes de transport ou de paiement pour prendre les transports en commun](https://support.apple.com/fr-fr/105079)

- [Cartes d’étudiant](https://support.apple.com/fr-fr/118274)

- [Clés de voiture](https://support.apple.com/fr-fr/118271)

- [Clés de scooter](https://support.apple.com/fr-fr/118491)

- [Clés de chambre d’hôtel](https://support.apple.com/fr-fr/118273)

- [Autres billets compatibles](https://support.apple.com/fr-fr/111112)

## Utiliser le mode Express sur votre iPhone ou Apple Watch

- Placez le haut de votre iPhone ou l’écran de votre Apple Watch à proximité du lecteur sans contact.

- Une fois la transaction effectuée, une coche et la mention OK s’affichent sur votre appareil. Si vous utilisez les transports en commun, la porte du terminal s’ouvre et peut émettre un bip.

Et voilà, pas besoin de sortir votre appareil du mode veille ou de le déverrouiller, de vous authentifier à l’aide de Face ID, de Touch ID ou de votre code d’accès, ni d’ouvrir l’app Cartes.

## Utiliser le mode Express avec le mode Réserve

Vous pourrez peut-être utiliser vos cartes, billets et clés avec le mode Express sur votre iPhone, même si votre appareil a besoin d’être chargé. Le mode Réserve fonctionne pendant une durée maximale de cinq heures avec certains billets et certaines cartes et clés dont le mode Express est activé.

Pour vérifier les cartes, les clés et les billets qui peuvent être utilisés avec le mode Réserve, appuyez sur le bouton latéral ou sur le bouton principal lorsque votre iPhone a besoin d’être chargé. Cependant, si vous procédez ainsi fréquemment, le mode Réserve pourrait considérablement se réduire. Si vous éteignez votre iPhone, cette fonctionnalité n’est pas disponible.

[En savoir plus sur les cartes Express en mode Réserve](https://support.apple.com/guide/security/sec90cd29d1f)
