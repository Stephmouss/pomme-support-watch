# Utilisation de cartes graphiques AMD sous Microsoft Windows sur un Mac Pro (2019)

Les cartes graphiques AMD peuvent ne pas fonctionner sous Microsoft Windows lorsque votre module Apple MPX et ses pilotes sont également installés.

Si vous installez une carte graphique AMD standard sur votre Mac Pro (2019), vous pouvez rencontrer ces symptômes lorsque vous utilisez Boot Camp pour exécuter Microsoft Windows :

- Aucun affichage sur l’écran connecté à la carte graphique AMD que vous avez installée

- Aucun affichage sur l’écran connecté à un port Thunderbolt 3 de votre Mac

Si vous souhaitez utiliser votre carte graphique AMD tierce sous Windows, procédez comme suit pour supprimer le module Apple MPX et ses pilotes, puis installez votre carte AMD et ses pilotes.

## Utiliser le HDMI pour la vidéo (le cas échéant)

Si vous avez déjà installé votre carte graphique AMD et qu’aucune image n’apparaît sur vos écrans connectés, vous pouvez utiliser le HDMI pour la vidéo au lieu de retirer votre carte AMD :

- Maintenez le [bouton d’alimentation](https://support.apple.com/fr-fr/HT201150) enfoncé pendant 10 secondes, jusqu’à ce que votre Mac s’éteigne.

- Débranchez tous les écrans de votre Mac, puis branchez un écran sur le port HDMI du module MPX.

- Démarrez à nouveau votre Mac sous Windows. Vous devriez maintenant voir une image s’afficher sur votre écran.

- Si vous souhaitez utiliser votre carte graphique AMD pour la vidéo, procédez comme suit sous Microsoft Windows.

## Supprimer le module MPX et ses pilotes

- Dans le Panneau de configuration, cliquez sur Programmes, puis sur Programmes et fonctionnalités.

- Faites un clic droit sur le programme nommé AMD Radeon Software, puis sélectionnez Modifier.

- Cliquez sur Clean Uninstall (Désinstallation propre), puis suivez les instructions à l’écran pour supprimer les pilotes.

- Éteignez votre Mac, puis retirez le module MPX.

Du fait de la désinstallation du module MPX et de ses pilotes, les ports Thunderbolt 3 situés sur le dessus et à l’arrière de votre Mac ne peuvent plus être utilisés pour la vidéo.

## Installer la carte graphique AMD et ses pilotes

- Installez votre carte AMD, si ce n’est pas déjà fait.

- Branchez votre écran sur votre carte AMD.

- Démarrez votre Mac sous Windows.

- Windows devrait automatiquement vous inviter à installer les pilotes de la carte AMD. Si ce n’est pas le cas, téléchargez et installez les pilotes appropriés depuis la page Pilotes et support du [site Web d’AMD](https://www.amd.com/fr) .

- Redémarrez votre Mac sous Windows.

## Informations supplémentaires

Si vous souhaitez utiliser à nouveau votre module MPX au lieu de votre carte AMD, la procédure sous Windows est similaire à celle décrite ci-dessus, mais en sens inverse :

- Désinstallez les pilotes de votre carte AMD, puis redémarrez votre Mac.

- Éteignez votre Mac, puis installez le module MPX et retirez la carte AMD.

- Connectez votre écran au port HDMI du module MPX, puis redémarrez votre Mac.

- [Téléchargez et installez les derniers pilotes graphiques AMD](https://support.apple.com/fr-fr/HT208908) pour Mac Pro.

- Redémarrez votre Mac. Vous pouvez désormais utiliser un autre port vidéo si vous ne souhaitez pas utiliser le HDMI.
