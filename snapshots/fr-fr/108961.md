# Convertir un morceau vers un autre format de fichier sur votre Mac avec l’app Apple Music

Sur votre Mac, vous pouvez convertir un morceau vers un autre format de fichier et conserver une copie de l’original.

## À propos de la compression

Lorsque vous convertissez un morceau dans certains formats compressés, des données peuvent être perdues. Ces formats compressés permettent d’obtenir des fichiers de taille beaucoup plus petite, ce qui vous permet de stocker plus de morceaux, cependant la qualité sonore peut ne pas être aussi bonne que celle du format original non compressé.

Pour obtenir de meilleurs résultats, si vous souhaitez écouter votre musique dans un autre format, importez à nouveau la source d’origine et utilisez le nouveau format d’encodage. Il est possible que vous n’entendiez pas la différence entre un morceau compressé et un morceau non compressé. Cela peut dépendre du morceau, de vos haut-parleurs ou écouteurs, ou de votre appareil.

Si vous compressez un morceau et qu’il perd des données, vous ne pouvez pas le décompresser pour récupérer les données. Si vous convertissez un morceau d’un format compressé vers un format non compressé, sa qualité ne s’améliore pas. Le fichier prend simplement plus d’espace sur le disque. Par exemple, lorsque vous convertissez un morceau du format MP3 (compressé) au format AIFF (non compressé), le morceau prend beaucoup plus de place sur votre disque dur, mais la qualité du son est la même qu’avec le fichier compressé. Pour profiter des formats non compressés, vous devez importer des morceaux dans ces formats.

## Convertir des morceaux de votre bibliothèque musicale sur votre Mac

- Ouvrez l’app Musique.

- Dans la barre des menus, choisissez Musique, puis Réglages.

- Cliquez sur l’onglet Fichiers, puis sur Réglages d’importation.

- Cliquez sur le menu en regard de Importer avec, puis sélectionnez le format d’encodage auquel vous souhaitez convertir le morceau.

- Cliquez sur OK.

- Sélectionnez les morceaux de votre bibliothèque que vous souhaitez convertir.

- Choisissez Fichier, puis Convertir.

- Choisissez Créer la version [format].

Les nouveaux fichiers des morceaux s’affichent dans votre bibliothèque à côté des fichiers d’origine.

## Convertir des morceaux à partir de fichiers se trouvant dans un dossier ou sur un disque sur votre Mac

Vous pouvez importer des morceaux dans l’app Apple Music et les convertir en même temps. Cela crée une copie convertie du fichier dans votre bibliothèque musicale, en fonction de vos préférences.

- Ouvrez l’app Musique.

- Dans la barre des menus, choisissez Musique, puis Réglages.

- Cliquez sur l’onglet Fichiers, puis sur Réglages d’importation.

- Cliquez sur le menu en regard de Importer avec, puis sélectionnez le format d’encodage auquel vous souhaitez convertir les morceaux.

- Cliquez sur OK.

- Sur votre clavier, maintenez la touche Option enfoncée et choisissez Fichier > Convertir > Convertir en [préférence d’importation].

- Sélectionnez le dossier ou le disque contenant les morceaux que vous souhaitez importer et convertir.

Les morceaux dans leur format d’origine et les morceaux convertis s’affichent dans votre bibliothèque.

## Remarque concernant les droits d’auteur

Vous pouvez utiliser l’app Apple Music pour reproduire des contenus. Sa licence vous est accordée uniquement pour vous permettre de reproduire les éléments suivants :

- Contenu non protégé par des droits d’auteur

- Contenu dont vous possédez les droits d’auteur

- Contenu que vous avez le droit de reproduire

Si vous souhaitez obtenir des précisions sur votre droit à copier du contenu, contactez votre conseiller juridique. Pour plus d’informations, consultez les [Conditions générales des services multimédias Apple](http://www.apple.com/legal/itunes/ww/) .

Les morceaux les plus anciens sont encodés au format AAC protégé, qui empêche leur conversion.
