# Conversion du format de fichier d’un morceau avec l’app Apple Music ou iTunes pour Windows

Découvrez comment convertir le format de fichier d’un morceau tout en conservant une copie du format d’origine.

Grâce à l’app Apple Music sur Mac ou à iTunes pour Windows, vous pouvez convertir des fichiers audio pour passer de formats compressés à des formats non compressés, et inversement. Vous pouvez ainsi importer des fichiers non compressés dans votre bibliothèque musicale sous la forme de fichiers compressés pour économiser de l’espace disque. Entre autres formats compressés, on compte le MP3 et l’Encodeur Apple Lossless. Pour les formats non compressés, on trouve par exemple AIFF ou WAV.

Lorsque vous convertissez un format compressé en un autre ou un format non compressé en un format compressé, il se peut que vous remarquiez une diminution de la qualité du son.

Obtenez des informations supplémentaires sur la [compression audio](https://support.apple.com/fr-fr/108961#compression) .

Pour obtenir de meilleurs résultats, si vous souhaitez écouter votre musique dans un autre format, importez à nouveau la source d’origine et utilisez le nouveau format d’encodage.

Vous pouvez convertir le format des morceaux qui se trouvent dans votre bibliothèque musicale, dans un dossier ou sur un disque.

## Convertir des morceaux dans votre bibliothèque musicale

Suivez les instructions ci-dessous en fonction de votre appareil.

### Sur votre Mac

- Ouvrez l’app Apple Music.

- Dans la barre des menus, choisissez Musique > Réglages.

- Cliquez sur l’onglet Fichiers, puis sur Réglages d’importation.

- Cliquez sur le menu en regard de Importer avec, puis sélectionnez le format d’encodage auquel vous souhaitez convertir le morceau.

- Cliquez sur OK.

- Sélectionnez les morceaux de votre bibliothèque que vous souhaitez convertir.

- Sélectionnez Fichier > Convertir, puis Créer une version [format].

Les nouveaux fichiers des morceaux s’affichent dans votre bibliothèque à côté des fichiers d’origine.

### Sur votre PC

- Ouvrez iTunes pour Windows.

- Dans la barre de menus, choisissez Édition > Préférences.

- Cliquez sur l’onglet Général, puis sur Réglages d’importation.

- Cliquez sur le menu en regard de Importer avec, puis sélectionnez le format d’encodage auquel vous souhaitez convertir le morceau.

- Cliquez sur OK.

- Sélectionnez les morceaux de votre bibliothèque que vous souhaitez convertir.

- Sélectionnez Fichier > Convertir, puis Créer une version [format].

Les nouveaux fichiers des morceaux s’affichent dans votre bibliothèque à côté des fichiers d’origine.

## Convertir des morceaux à partir des fichiers d’un dossier ou d’un disque

Vous pouvez importer des morceaux dans l’app Apple Music ou iTunes pour Windows, et les convertir dans le même temps. Vous créez ainsi une copie convertie du fichier dans votre bibliothèque musicale, en fonction de vos préférences dans l’app Apple Music ou iTunes pour Windows.

Pour convertir tous les morceaux d’un dossier ou d’un disque, suivez les instructions ci-dessous associées à votre appareil.

Les morceaux les plus anciens sont encodés au format AAC protégé, qui empêche leur conversion.

### Sur votre Mac

- Ouvrez l’app Apple Music.

- Dans la barre des menus, choisissez Musique > Réglages.

- Cliquez sur l’onglet Fichiers, puis sur Réglages d’importation.

- Cliquez sur le menu en regard de Importer avec, puis sélectionnez le format d’encodage auquel vous souhaitez convertir les morceaux.

- Cliquez sur OK.

- Sur votre clavier, appuyez sur la touche Option, maintenez-la enfoncée et choisissez Fichier > Convertir > Convertir en [préférence d’importation].

- Sélectionnez le dossier ou le disque contenant les morceaux que vous souhaitez importer et convertir.

Les morceaux dans leur format d’origine et les morceaux convertis s’affichent dans votre bibliothèque.

### Sur votre PC

- Ouvrez iTunes pour Windows.

- Dans la barre de menus, choisissez Édition > Préférences.

- Cliquez sur l’onglet Général, puis sur Réglages d’importation.

- Cliquez sur le menu en regard de Importer avec, puis sélectionnez le format d’encodage auquel vous souhaitez convertir les morceaux.

- Cliquez sur OK.

- Sur votre clavier, appuyez sur la touche Maj, maintenez-la enfoncée et choisissez Fichier > Convertir > Convertir en [préférence d’importation].

- Sélectionnez le dossier ou le disque contenant les morceaux que vous souhaitez importer et convertir.

Les morceaux dans leur format d’origine et les morceaux convertis s’affichent dans votre bibliothèque.

## Informations supplémentaires

Lorsque vous convertissez un fichier avec l’app Apple Music ou iTunes pour Windows, le fichier d’origine reste inchangé au même emplacement. L’app Apple Music et iTunes pour Windows créent le fichier converti à partir d’une copie du morceau original.

### À propos de la compression

Lorsque vous convertissez un morceau dans certains formats compressés, des données peuvent être perdues. Ces formats compressés génèrent des fichiers de taille beaucoup plus limitée, ce qui vous permet de stocker plus de morceaux. Toutefois, la qualité du son peut ne pas être aussi bonne qu’avec le format d’origine non compressé.

Il est possible que vous n’entendiez pas la différence entre un morceau compressé et un morceau non compressé. Cela peut dépendre du morceau, de vos haut-parleurs ou écouteurs, ou de votre appareil.

Si vous compressez un morceau et qu’il perd des données, vous ne pouvez pas le décompresser pour récupérer les données. Si vous convertissez un morceau d’un format compressé vers un format non compressé, sa qualité ne s’améliore pas. Le fichier prend simplement plus d’espace sur le disque. Par exemple, lorsque vous convertissez un morceau du format MP3 (compressé) au format AIFF (non compressé), le morceau prend beaucoup plus de place sur votre disque dur, mais la qualité du son est la même qu’avec le fichier compressé. Pour profiter des formats non compressés, vous devez importer des morceaux dans ces formats.
