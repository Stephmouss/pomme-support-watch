# Utiliser Temps d’écran sur l’Apple Vision Pro

Sous visionOS, la fonctionnalité Temps d’écran vous permet d’activer des restrictions relatives au contenu et à la confidentialité afin de gérer les contenus, les apps et les réglages. Vous pouvez également limiter les contenus explicites, les achats et les modifications apportées aux réglages de confidentialité.

En savoir plus sur les [ressources sur la parentalité numérique fournies par le gouvernement français](https://jeprotegemonenfant.gouv.fr/) .

Vous pouvez à tout moment modifier ou désactiver ces réglages, pour vous-même ou pour un enfant de votre groupe de partage familial.

- Dans votre Apple Vision Pro, ouvrez Réglages. Touchez Temps d'écran, puis Contenu et confidentialité.

- Sélectionnez le réglage Activer les restrictions, puis définissez les contrôles souhaités :

- Achats dans l’iTunes et l’App Store : limitez ou bloquez les achats dans l’App Store, et exigez un mot de passe pour les achats dans iTunes, Livres et l’App Store.

- Apps et fonctionnalités approuvées : choisissez les apps et les fonctionnalités que vous souhaitez voir sur l’écran d’accueil. La désactivation d’une app ou d’une fonctionnalité n’entraîne pas sa suppression d’Apple Vision Pro.

- App Store, contenu multimédia, Web et jeux : définissez des restrictions sur les types de contenus disponibles dans les services multimédias Apple, sur le Web et dans Game Center.

- Intelligence et Siri : choisissez les fonctionnalités Apple Intelligence et Siri que vous souhaitez autoriser sur l’Apple Vision Pro.

- Afin de limiter les modifications, touchez Verrouiller les réglages Temps d’écran, puis définissez le code d’accès requis pour modifier les réglages.

Si vous avez défini des réglages Temps d’écran pour un enfant de votre groupe familial*, certains réglages permettant de limiter l’utilisation ou la communication, tels que Limites d’app, Temps d’arrêt ou Sécurité des communications, ne sont pas disponibles sur l’Apple Vision Pro et ne seront pas visibles sur le compte enfant utilisé sur l’Apple Vision Pro.

* L’âge limite varie selon le pays ou la région.
