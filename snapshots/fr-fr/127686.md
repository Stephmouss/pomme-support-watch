# À propos de l’Assistance connectivité

Utilisez les données cellulaires en plus du Wi-Fi pour bénéficier d’une connexion Internet plus fiable.

L’Assistance connectivité utilise les données cellulaires pour améliorer votre connexion lorsque le Wi-Fi est lent ou inutilisable, par exemple dans votre jardin ou votre allée, ou dans un café, un aéroport, un stade et dans bien d’autres endroits.

L’Assistance connectivité s’affiche dans les réglages Wi-Fi - elle remplace et supplante l’Assistance Wi-Fi, qui se trouvait auparavant dans les réglages des données cellulaires. Si l’Assistance Wi-Fi était activée lorsque vous avez mis à jour votre logiciel, l’Assistance connectivité est activée par défaut. Si l’Assistance Wi-Fi était désactivée, vous pouvez activer manuellement l’Assistance connectivité.

## Activer ou désactiver l’Assistance connectivité

- [Mettez à jour votre iPhone vers la dernière version d’iOS ou d’iPadOS](https://support.apple.com/fr-fr/118575) .

- Dans Réglages, touchez Wi-Fi, puis assurez-vous que le Wi-Fi est activé.

- Faites défiler l’écran vers le bas, puis activez ou désactivez l’Assistance connectivité. Si vous souhaitez rester connecté en permanence au Wi-Fi pour une configuration de routeur spécifique (par exemple, votre bloqueur de publicités), vous pouvez [désactiver l’Assistance connectivité pour ce réseau particulier](https://support.apple.com/guide/iphone/manage-wi-fi-settings-iphw5gjwl8k2/ios#iphac9e3fcd6) .

Lorsque l’Assistance connectivité est activée, votre consommation de données cellulaires peut augmenter. Si vous le souhaitez, vous pouvez [vérifier votre consommation de données cellulaires ou en effectuer la réinitialisation](https://support.apple.com/fr-fr/109323) .

L’Assistance connectivité n’est pas utilisée lorsque votre iPhone est en itinérance à l’étranger, en mode Faibles données cellulaires ou avec certaines apps tierces qui diffusent du contenu audio et vidéo en streaming.
