# Activer ou désactiver la navigation privée sur votre iPhone

En mode de navigation privée, Safari ne consigne pas les pages que vous consultez, l’historique de vos recherches, ni vos informations de remplissage automatique. Le mode de navigation privée bloque également les traqueurs connus, supprime le suivi permettant d’identifier des utilisateurs à partir des URL et active des protections contre les techniques avancées de vol d’empreintes numériques.

## Activer la navigation privée

Lorsque la navigation privée est activée, la barre d’adresse de Safari apparaît noire ou sombre au lieu d’être blanche ou grise.

- Ouvrez Safari sur votre iPhone.

- Touchez le bouton Plus .

[Image: null]

- Touchez Nouvel onglet privé.

Sous iOS 17 ou version antérieure, ouvrez Safari, puis touchez le bouton Onglets . Effectuez un balayage vers le bouton du groupe d’onglets Privée, puis touchez l’onglet que vous souhaitez ouvrir.

[Image: Aucun texte de remplacement pour l’image]

Pour plus de confidentialité, vous pouvez verrouiller le mode de navigation privée lorsque vous ne l’utilisez pas. Dès que vous verrouillez votre appareil, vos onglets privés dans Safari se verrouillent également. Lorsque vous déverrouillez à nouveau votre appareil, il vous suffit de déverrouiller le mode de navigation privée avec Touch ID, Face ID ou le code de votre appareil.

[En savoir plus sur le verrouillage des onglets de navigation privée](https://support.apple.com/fr-fr/105028)

## Désactiver la navigation privée

Lorsque la navigation privée est désactivée, la barre d’adresse de Safari apparaît en blanc ou en gris.

- Ouvrez Safari sur votre iPhone.

- Touchez le bouton Plus .

[Image: null]

- Touchez Nouvel onglet.

Sous iOS 17 ou version antérieure, ouvrez Safari sur votre iPhone, puis touchez le bouton Onglets . Effectuez un balayage vers le bouton du groupe d’onglets [nombre] onglets, puis touchez l’onglet que vous souhaitez ouvrir.
