# Activer ou désactiver Fonctions fondées sur l’attention sur votre iPhone ou iPad Pro

Apprenez-en davantage sur les fonctions fondées sur l’attention sur l’iPhone X et les modèles ultérieurs, ou sur l’iPad Pro 11 pouces, l’iPad Pro 12,9 pouces ou l’iPad Pro 13 pouces.

## Que sont les fonctions fondées sur l’attention ?

Avec les fonctions fondées sur l’attention, les iPhone et iPad dotés de Face ID peuvent vérifier si vous prêtez attention à votre appareil et prendre des mesures immédiates. Avec la caméra TrueDepth*, cela fonctionne même si vous ne vous enregistrez pas dans Face ID et peut inclure des fonctionnalités telles que :

- Lorsque vous regardez en direction de votre appareil, votre écran ne s’assombrira pas tant que vous continuerez de regarder votre téléphone.

- Lorsque vous regardez votre appareil, le volume de vos alertes sera réduit.

[Image: Écran « Face ID et code », affichant les options « Exiger l’attention pour Face ID » et « Fonctions fondées sur l’attention » à l’état activé.]

Si vous ne souhaitez pas utiliser ces fonctionnalités, ouvrez l’app Réglages, touchez Face ID et code, et désactivez Fonctions fondées sur l’attention.

* La caméra TrueDepth est disponible sur l’iPhone X et les modèles ultérieurs, à l’exception de l’iPhone SE, et sur les iPad Pro 11 pouces, iPad Pro 12,9 pouces (3e à 6e générations) et iPad Pro 13 pouces.
