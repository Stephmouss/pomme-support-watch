# Si vous ne parvenez pas à ajouter un fichier multimédia à un document collaboratif dans Pages, Numbers ou Keynote

Si vous recevez une alerte indiquant que vous ne pouvez pas ajouter une image, un film ou un fichier audio à un document collaboratif, réduisez la taille du fichier ou du document entier.

La taille du fichier multimédia que vous essayez d’ajouter peut rendre le document collaboratif trop volumineux. La taille maximale des documents collaboratifs est de 2 Go pour les documents partagés avec iCloud (4 Go si vous disposez d’un abonnement Apple Creator Studio) et de 1 Go pour les documents partagés avec Box (avec ou sans abonnement Apple Creator Studio).

## Réduire la taille du fichier multimédia

Vous pouvez utiliser ces apps Mac pour réduire la taille des fichiers image, film ou audio :

- Utilisez Aperçu pour [convertir un fichier image dans un format moins volumineux](https://support.apple.com/guide/preview/convert-graphics-file-types-prvw1012/mac) et obtenir, par exemple, un fichier JPEG avec une qualité d’image inférieure.

- Utilisez QuickTime Player pour [exporter un film dans une résolution inférieure](https://support.apple.com/guide/quicktime-player/export-movies-qtp20e395859/mac) , par exemple au format 480P.

- Utilisez l’app Musique pour [convertir un fichier audio dans un format plus compressé](https://support.apple.com/HT204310) , tel que MP3.

Après avoir réduit la taille du fichier multimédia, essayez de l’ajouter au document collaboratif. Si vous ne parvenez toujours pas à ajouter le fichier multimédia, [réduisez la taille du document entier](https://support.apple.com/fr-fr/119884#Reduce_document) .

## Réduire la taille du document

Sur le Mac, vous pouvez réduire la taille de tout le document Pages, Numbers ou Keynote afin de pouvoir collaborer avec d’autres personnes sur celui-ci. L’app réduit automatiquement les images, raccourcit les films et les fichiers audio ou modifie le format ou la qualité des images et des films.

- Si vous êtes le propriétaire du document et que vous le partagez, [arrêtez de partager le document, la feuille de calcul ou la présentation](https://support.apple.com/HT206181#stop) .

- Dans le document ouvert, sélectionnez Fichier > Réduire la taille du fichier.

- Sélectionnez les ajustements que vous souhaitez effectuer. La taille actuelle du document et celle qui sera obtenue en fonction des ajustements sélectionnés sont affichées dans la partie supérieure de la fenêtre.

- Réduire le fichier :

- Sélectionnez Réduire ce fichier pour appliquer les réglages au document d’origine.

- Sélectionnez Réduire une copie pour appliquer les réglages à une copie du document et conserver le document d’origine. Nommez la copie du document, sélectionnez un emplacement pour l’enregistrer, puis cliquez sur Enregistrer.

- Invitez d’autres personnes à collaborer sur le document.

## Si vous ne parvenez toujours pas à ajouter un fichier multimédia à un document collaboratif

- Si vous êtes le propriétaire du document, [arrêtez le partage du document, de la feuille de calcul ou de la présentation](https://support.apple.com/HT206181#stop) , ajoutez le fichier, puis recommencez le partage.

- Si le document se trouve dans un [dossier partagé](https://support.apple.com/guide/mac-help/mchl91854a7a) , faites-le glisser à l’extérieur de ce dossier, ajoutez le fichier multimédia, puis faites de nouveau glisser le document dans le dossier partagé.

## Si votre document collaboratif contient un fichier multimédia endommagé

Si votre document collaboratif contient des fichiers multimédias endommagés, tels que des photos ou des vidéos, une fenêtre répertoriant ces fichiers s’affiche lorsque vous ouvrez le document. Pour réparer le document, arrêtez son partage, remplacez les fichiers, puis recommencez le partage. Si le document se trouve dans un dossier partagé, faites-le glisser hors du dossier, remplacez le fichier, puis faites de nouveau glisser le document dans le dossier partagé.
