# Si Pixelmator Pro pour iPad ne fonctionne pas

Tout d’abord, vérifiez la compatibilité de tout matériel ou logiciel tiers, puis sauvegardez les données de votre appareil. Ensuite, essayez d’effectuer chaque étape de dépannage et vérifiez si le problème est réglé après chacune d’elles.

Si vous souhaitez vous abonner à Pixelmator Pro ou modifier votre abonnement, [consultez le guide d’utilisation de Pixelmator Pro](https://support.apple.com/guide/pixelmator-pro/ed6ey8wwpkpr/ipados) .

## Avant de commencer

- Si vous venez de mettre à jour Pixelmator Pro ou iPadOS et que Pixelmator Pro ne fonctionne pas, il est possible que des logiciels ou du matériel tiers ne soient pas compatibles. Contactez les équipes de développement ou les fabricants de tous les éléments tiers que vous utilisez pour vérifier leur compatibilité avec la version de Pixelmator Pro et d’iPadOS que vous utilisez.

- [Sauvegardez les données de votre iPad](https://support.apple.com/guide/ipad/ipad9a74df05xx/ipados) avant d’essayer de résoudre tout problème lié à Pixelmator Pro. Vous pouvez également [exporter des photos, vidéos et documents individuels](https://support.apple.com/guide/pixelmator-pro/pixa7f02d291/ipados) .

## Résoudre les problèmes liés à Pixelmator Pro pour iPad

Après chaque étape, testez à nouveau Pixelmator Pro pour voir si le problème est résolu.

### 1. Redémarrer votre iPad

Pour redémarrer votre iPad, [éteignez-le, puis rallumez-le](https://support.apple.com/fr-fr/101603) .

### 2. Déconnectez les périphériques externes

Si un périphérique externe comme une caméra ou un périphérique de stockage est connecté à votre iPad, déconnectez-le :

- Éteignez votre iPad.

- Déconnectez tous les périphériques externes.

- Allumez votre iPad.

Si le problème se produit uniquement lorsqu’un périphérique externe spécifique est connecté, une mise à jour ou une réparation de ce dernier peut être nécessaire. Contactez le fabricant pour obtenir de l’aide.

### 3. Vérifier la configuration système requise

Pixelmator Pro pour iPad [nécessite iPadOS 26 ou version ultérieure](https://support.apple.com/fr-fr/125029#specs) . Pour vérifier la version d’iPadOS actuellement installée sur votre iPad, procédez comme suit :

- Ouvrez l’app Réglages.

- Sélectionnez Général, puis touchez Informations.

- Touchez Version d’iPadOS.

Si votre iPad est doté d’une version d’iPadOS antérieure à iPadOS 26, vérifiez que les logiciels tiers que vous utilisez sont compatibles avec la dernière version d’iPadOS, puis [mettez à jour iPadOS](https://support.apple.com/fr-fr/118575) .

[En savoir plus sur les versions d’iPadOS](https://support.apple.com/fr-fr/109065)

### 4. Vérifier que l’app fonctionne normalement

Pour vous assurer que l’app fonctionne normalement, consultez le [Guide d’utilisation de Pixelmator Pro pour iPad](https://support.apple.com/guide/pixelmator-pro/welcome/ipados) . Vous pouvez rechercher dans ce guide les termes clés figurant dans les alertes, les icônes d’avertissement ou les messages d’erreur.

### 5. Mettre à jour Pixelmator Pro pour iPad

Essayez de finaliser et d’enregistrer tous les documents ouverts avant d’effectuer la mise à jour.

- [Sauvegardez les données de votre iPad](https://support.apple.com/guide/ipad/ipad9a74df05xx/ipados) avant d’essayer de résoudre tout problème lié à Pixelmator Pro. Vous pouvez également [exporter des photos, vidéos et documents individuels](https://support.apple.com/guide/pixelmator-pro/pixa7f02d291/ipados) .

- [Mettez à jour Pixelmator Pro pour iPad](https://support.apple.com/guide/ipad/ipad05566c91/ipados) .

### 6. Vérifier le programme interne de l’appareil photo, de la caméra ou du périphérique de stockage

Vérifiez auprès du fabricant de chaque périphérique externe que vous utilisez, comme un appareil photo, une caméra ou un périphérique de stockage, si des mises à jour du programme interne sont disponibles. Suivez les instructions du fabricant pour procéder à la mise à jour.

### 7. Vérifier que vous utilisez un format multimédia pris en charge

[Découvrir les formats d’image, les formats vidéo et les types de fichiers pris en charge par Pixelmator Pro](https://support.apple.com/guide/pixelmator-pro/a7veyq8q24zq/ipados)

### 8. Effectuer un test avec un nouveau document

Si vous ne parvenez pas à reproduire le problème avec le fichier multimédia de test, le problème peut être lié au fichier source utilisé dans le projet.

- Créez un fichier multimédia de test dans Pixelmator Pro pour iPad :

- Ouvrez Pixelmator Pro, puis touchez Créer un document.

- Dans la section Basique du navigateur de modèles, touchez le modèle Publication carrée basique, puis touchez Créer.

- Touchez le nom du document dans la barre d’outils, choisissez PNG dans le menu local Format, puis touchez Exporter.

- Ouvrez le fichier PNG exporté dans Pixelmator Pro, puis essayez de reproduire le problème en utilisant le fichier multimédia de test. Dans Pixelmator Pro, touchez Créer un document pour créer un document.

Si Pixelmator semble fonctionner normalement, essayez d’obtenir une nouvelle copie du fichier source que vous utilisiez lorsque vous rencontriez des problèmes avec Pixelmator.

### 9. Supprimer et réinstaller Pixelmator Pro pour iPad

Sauvegardez vos projets avant de supprimer l’app Pixelmator Pro pour iPad de votre iPad.

- [Sauvegardez les données de votre iPad](https://support.apple.com/guide/ipad/ipad9a74df05xx/ipados) ou [exportez vos photos, vidéos et documents individuels](https://support.apple.com/guide/pixelmator-pro/pixa7f02d291/ipados) .

- [Supprimez Pixelmator Pro](https://support.apple.com/guide/ipad/ipad0aed1df8/26/ipados/26) de votre iPad.

- [Téléchargez à nouveau Pixelmator Pro](https://support.apple.com/fr-fr/102417) depuis l’App Store.

- Effectuez un test avec un modèle de la section Basique du navigateur de modèles.

- Si le problème ne se produit plus, ouvrez le document sur lequel vous avez besoin de travailler.
