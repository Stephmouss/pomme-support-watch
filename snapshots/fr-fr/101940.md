# Si vous ne parvenez pas connecter Logic Remote à votre Mac

Pour connecter Logic Remote à Logic Pro, ou GarageBand sur votre Mac, vérifiez les réglages réseau de vos appareils ou supprimez les surfaces de contrôle précédemment connectées de Logic Pro.

Si vous souhaitez contrôler MainStage 4 ou une version ultérieure à distance, [utilisez une app de connexion réseau virtuel (VNC) comme RealVNC](https://support.apple.com/fr-fr/125381) .

## Veiller à ce que tous les appareils se trouvent sur le même réseau Wi-Fi

L’iPhone ou iPad qui exécute Logic Remote et le Mac qui exécute Logic Pro doivent se trouver sur le même réseau Wi-Fi :

- [Connexion à un réseau Wi-Fi sur votre iPhone, iPad ou iPod touch](https://support.apple.com/HT202639)

- [Connexion à un réseau Wi-Fi sur votre Mac](https://support.apple.com/HT201735)

## Veiller à ce que Logic Remote puisse accéder au réseau local

Sous iOS 14 et iPadOS 14 ou version ultérieure, toute app souhaitant interagir avec des appareils de votre réseau doit en demander l’autorisation la première fois qu’elle tente de parcourir votre réseau local. Vous pouvez vérifier que l’app peut accéder à votre réseau local :

- Dans l’app Réglages, accédez à Confidentialité > Réseau local.

- Assurez-vous que Logic Remote est activé.

## Modifier les réglages du coupe-feu de votre Mac

Les réglages du coupe-feu de votre Mac peuvent empêcher la connexion de Logic Remote.

### macOS Ventura ou version ultérieure

- Choisissez Réglages Système dans le menu Pomme , puis cliquez sur Réseau dans la barre latérale.

- Cliquez sur Coupe-feu.

- Cliquez sur le bouton Options.

- Désactivez « Bloquer toutes les connexions entrantes », puis cliquez sur OK.

- [Connexion à Logic Remote](https://support.apple.com/guide/logicremote-logicpro-ipad/get-started-chsff8c943/ipados)

### macOS Monterey ou version antérieure

- Choisissez Préférences Système dans le menu Pomme .

- Dans la fenêtre Préférences Système, cliquez sur Sécurité et confidentialité.

- Dans la sous-fenêtre Sécurité et confidentialité, cliquez sur l’onglet Coupe-feu.

- Cliquez sur l’icône de verrouillage située dans l’angle inférieur gauche de la sous-fenêtre Coupe-feu, puis saisissez un nom d’utilisateur et un mot de passe d’administrateur.

- Cliquez sur le bouton Options du coupe-feu.

- Décochez la case « Bloquer toutes les connexions entrantes », puis cliquez sur OK.

- [Connexion à Logic Remote](https://support.apple.com/guide/logicremote-logicpro-ipad/get-started-chsff8c943/ipados) .

## Supprimer de Logic Pro les instances de Logic Remote

Si vous avez utilisé Logic Remote avec Logic Pro sur le Mac avec lequel vous rencontrez des problèmes, essayez dans les paramètres de Logic Pro de supprimer ces instances de Logic Remote.

- Dans Logic Pro, choisissez Logic Pro dans la barre de menus, puis Surfaces de contrôle > Configuration.

- Sélectionnez un périphérique Logic Remote à droite.

- Choisissez Modifier dans la fenêtre Configuration des surfaces de contrôle, puis sélectionnez Supprimer. Si votre périphérique Logic Remote est connecté, une alerte s’affiche vous demandant si vous souhaitez supprimer l’appareil. Cliquez sur Supprimer.

- Supprimez tous les autres périphériques Logic Remote qui apparaissent dans la fenêtre.

- [Connexion à Logic Remote](https://support.apple.com/guide/logicremote-logicpro-ipad/get-started-chsff8c943/ipados) .

## Supprimer un appareil TouchOSC de Logic Pro

Il est possible que Logic Remote ne parvienne pas à se connecter si vous avez précédemment ajouté un appareil TouchOSC en tant que surface de contrôle pour Logic Pro. Vérifiez si un appareil TouchOSC apparaît dans Logic Pro et supprimez-le si c’est le cas.

- Fermez Logic Remote.

- Ouvrez Logic Pro sur votre Mac.

- Sélectionnez Logic Pro > Surfaces de contrôle > Configuration.

- Vérifiez si un appareil TouchOSC apparaît dans la fenêtre. Si tel est le cas, sélectionnez cet appareil, appuyez sur la touche de suppression, puis cliquez sur OK.

- Si d’autres instances de Logic Remote apparaissent dans la fenêtre, supprimez-les.

- [Connexion à Logic Remote](https://support.apple.com/guide/logicremote-logicpro-ipad/get-started-chsff8c943/ipados) .
