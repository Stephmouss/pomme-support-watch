# Ajout de citations à vos documents Pages avec le module EndNote

Découvrez comment installer et utiliser le module EndNote pour Pages afin d’ajouter des citations et d’élaborer une liste de références.

Pour utiliser le module EndNote actuel, EndNote X6 ou version ultérieure doit être installé sur votre Mac. Découvrez comment obtenir [EndNote](https://www.endnote.com) .

Pour utiliser le module EndNote, il est recommandé d’avoir installé Pages 6.2 ou version ultérieure.

- Si vous utilisez EndNote X9.3 ou version ultérieure, téléchargez et installez [la dernière version du module EndNote pour Pages](https://support.apple.com/kb/DL2014?locale=fr_FR) . Si votre Mac est doté de macOS Catalina ou version ultérieure, EndNote X9.3 est requis.

- Si vous utilisez EndNote X9.2 ou version antérieure, téléchargez et installez [la version 3.1 du module EndNote pour Pages](https://support.apple.com/kb/DL1916?locale=fr_FR) .

- Si vous utilisez une version de Pages comprise entre 5.0 et 6.1.1 ainsi qu’EndNote X9.2 ou version antérieure, téléchargez et installez [la version 2.0 du module EndNote pour Pages](https://support.apple.com/kb/DL1692?locale=fr_FR)

## Ajouter une citation

- Ouvrez votre bibliothèque EndNote.

- Dans Pages, ouvrez le document dans lequel vous souhaitez ajouter une citation.

- Sélectionnez le texte que vous souhaitez citer, puis choisissez le bouton de menu Insérer > Citation EndNote. Si l’option Citation EndNote n’est pas disponible, accédez à Inspecteur de documents > onglet Document et assurez-vous que l’option Corps du document est sélectionnée.

[Image: Aucun texte de remplacement pour l’image]

- Dans la fenêtre de recherche de Citation EndNote, recherchez l’auteur, le titre ou l’année de l’œuvre que vous souhaitez citer.

- Sélectionnez la citation que vous souhaitez ajouter et prévisualisez-la. Si vous ne souhaitez pas insérer la citation dans le texte, mais que vous voulez ajouter la source à votre bibliographie, assurez-vous de sélectionner « N’insérer que dans la bibliographie ». Cliquez sur Insérer.

Votre citation est ajoutée après le texte sélectionné, et l’œuvre est ajoutée à la bibliographie à la fin de votre document.

Si vous supprimez l’unique citation d’une source, Pages supprime automatiquement cette dernière de votre bibliographie.
