# À quoi vous attendre lorsque vous êtes en contact avec l’assistance Apple

Si vous contactez ou êtes contacté par l’assistance Apple, il vous faudra peut-être fournir des informations pour faciliter la résolution de votre problème.

## Vérification de votre compte Apple par l’assistance Apple

L’assistance Apple peut vous demander de fournir un code PIN d’assistance. Un code PIN d’assistance est un code temporaire que vous pouvez générer sur [https://account.apple.com](https://account.apple.com) après vous être connecté à votre compte. Il permet à l’assistance Apple de confirmer que vous êtes bien le titulaire du compte. Le code PIN d’assistance ne donne pas accès à votre appareil, à votre compte ni à vos données. Si un lien vous est envoyé pour générer le code PIN d’assistance, ne cliquez pas dessus, car il pourrait s’agir d’une arnaque. Suivez le lien ci-dessus ou saisissez « https://account.apple.com » dans votre navigateur.

[S’il vous est demandé de confirmer votre compte Apple lorsque vous contactez Apple](https://support.apple.com/fr-fr/102425)

## Évitez les procédés d‘ingénierie sociale

Les représentants d’Apple ne vous contacteront jamais pour vous demander d’effectuer les actions suivantes :

- Ouvrir un lien qui vous a été envoyé et vous connecter à un site web.

- Fournir votre mot de passe, le code d’accès de votre appareil ou votre code d’identification à deux facteurs, ou le saisir sur une page web, même si elle ressemble à un site web Apple officiel.

- Toucher « Autoriser » sur votre appareil afin qu’un autre appareil puisse se connecter à votre compte.

- Modifier les réglages de sécurité du compte, par exemple ajouter un nouveau numéro de téléphone de confiance pour votre compte.

- Désactiver les fonctionnalités de sécurité telles que l’identification à deux facteurs ou la protection en cas de vol de l’appareil.

- Désactiver Localiser pour vous aider à retrouver un appareil perdu ou volé, ou pour une réclamation dans le cadre d’un contrat AppleCare+ avec couverture en cas de perte ou de vol. Il peut vous être demandé de désactiver Localiser (ou de supprimer un appareil de l’app Localiser) dans le cadre de l’organisation d’une réparation auprès d’AppleCare, d’un magasin Apple ou d’un centre de services agréé, ou lorsque vous échangez ou retournez un appareil directement auprès d’Apple.

Si un individu prétendant travailler chez Apple réalise l’une des actions ci-dessus, il s’agit d’un escroc qui lance une attaque d’ingénierie sociale. Mettez fin à l’appel ou au contact.

[En savoir plus sur la façon de vous protéger contre l’ingénierie sociale et d’autres types de fraude](https://support.apple.com/fr-fr/102568)
