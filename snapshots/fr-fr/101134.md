# Gestionnaire de groupe de travail : activation de la journalisation Web du contrôle parental pour les utilisateurs réseau

Si vous utilisez Gestionnaire de groupe de travail afin d’appliquer le contrôle parental pour vos utilisateurs réseau, la journalisation des sites Web consultés par des utilisateurs ne s’effectue pas automatiquement. Vous pouvez utiliser Gestionnaire de groupe de travail pour importer un fichier de préférences configuré afin d’activer la journalisation.

Sur chaque ordinateur client, les données brutes se trouvent dans /Bibliothèque/Application Support/Apple/ParentalControls/Users/nom abrégé du compte/events.data.

Procédez comme suit sur un ordinateur client pour générer le fichier de préférences nécessaire :

- Ouvrez une session en tant qu’administrateur.

- Créez un compte local appelé « Web Log », avec le nom abrégé « weblog », dans la sous-fenêtre Comptes des Préférences Système.

- Activez le contrôle parental pour le compte Web Log.

- Fermez la session ouverte avec le compte d’administrateur.

- Ouvrez une session avec le compte Web Log. Ceci permet de créer les listes de propriétés nécessaires.

- Fermez la session ouverte avec le compte Web Log.

- Ouvrez une session en tant qu’administrateur.

- Copiez le fichier /Bibliothèque/Managed Preferences/weblog/com.apple.familycontrols.logging.plist dans votre serveur Open Directory.

- Supprimez ou désactivez le compte Web Log.

- Fermez la session ouverte sur l’ordinateur du client.

Sur votre serveur Open Directory :

- Ouvrez Gestionnaire de groupe de travail, sélectionnez le groupe ou le groupe d’ordinateurs pour lequel vous activez la journalisation des sites Web, puis cliquez sur l’icône Préférences située dans la barre d’outils.

- Cliquez sur l’onglet Détails.

- Cliquez sur Ajouter (+), au-dessous de la liste des préférences gérées.

- Accédez à l’emplacement dans lequel vous avez copié le fichier de préférences, puis sélectionnez le fichier com.apple.familycontrols.logging.plist.

- Choisissez Toujours pour l’option « Gestion des préférences importées » dans le panneau de navigation du fichier.

- Cliquez sur Ajouter.

- Dans la liste des préférences gérées, double-cliquez sur l’entrée com.apple.familycontrols.logging .

- Cliquez sur le triangle d’expansion pour afficher le contenu du domaine de préférences « Toujours ». La propriété « Web » permet de contrôler l’activation ou la désactivation de la journalisation Web. Cette propriété doit être définie sur Vrai.

Répétez ces étapes dans Gestionnaire de groupe de travail, si nécessaire, avec tous les groupes ou groupes d’ordinateurs pour lesquels vous devez activer la journalisation Web.

Dans la mesure où les préférences gérées peuvent être mises en cache, les postes de travail doivent être redémarrés après l’importation et l’activation des paramètres de journalisation Web. Lorsque des utilisateurs provenant de groupes pour lesquels la journalisation est activée ouvrent une session, ou lorsque des utilisateurs ouvrent une session sur un ordinateur membre d’un groupe d’ordinateurs pour lequel la journalisation est activée, le système doit procéder à la journalisation des sites Web qu’ils consultent. Si vous bloquez certains sites Web, ceci est également consigné dans le fichier events.data.

## Informations supplémentaires

Quelques éléments importants sont à prendre en considération lors de la consultation du fichier events.data :

- Ce fichier events.data se trouve sur le poste de travail local ou mobile, et n’est pas stocké ou automatiquement copié sur un serveur. Vous devez copier le fichier events.data depuis les postes de travail locaux, ou accéder au fichier events.data directement sur le poste de travail, afin de consulter la liste des sites Web sur lesquels l’utilisateur s’est rendu.

- Le fichier events.data est une base de données SQLite3 qui n’est généralement pas lisible par des applications comme des éditeurs de texte. Vous devez utiliser une application qui lit le format de base de données SQLite3 pour afficher les données stockées dans ce fichier. sqlite3 , un utilitaire en ligne de commande open source pouvant lire ce fichier, est inclus avec Mac OS X. AppleCare ne fournit pas d’assistance pour la commande sqlite3. Des instructions détaillées concernant l’utilisation de la commande sqlite3 sont disponibles dans la documentation intégrée. Vous pouvez accéder à ces instructions en exécutant la commande suivante dans Terminal : man sqlite3.

- Vous pouvez obtenir des informations supplémentaires sur SQLite à l’adresse < [http://www.sqlite.org/](http://www.sqlite.org/) > et à l’adresse < [http://www.sqlite.org/docs.html](http://www.sqlite.org/docs.html) >.

Remarque : le format du fichier events.data est susceptible d’être modifié.
