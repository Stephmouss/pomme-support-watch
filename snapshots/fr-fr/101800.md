# Sauvegarder MainStage

Avant de mettre à jour MainStage, sauvegardez votre copie actuelle de l’application MainStage et de vos concerts existants.

La sauvegarde de l’application MainStage vous permet de déplacer vos concerts vers un autre Mac afin que vous puissiez continuer à les utiliser dans la version antérieure de l’app s’il y a un problème après la mise à jour.

## Sauvegarder l’app MainStage

- Créez un dossier dans le dossier Applications.

- Intitulez ce dossier en fonction du nom et de la version de l’application (par exemple, « MainStage 3.6 »). Pour vérifier la version de MainStage dont vous disposez, ouvrez l’app, puis choisissez À propos de MainStage dans le menu MainStage.

- Sélectionnez l’app MainStage dans le dossier Applications, puis choisissez Fichier > Compresser « MainStage ». Cette opération peut prendre quelques minutes.

- Déplacez le fichier « MainStage.zip » ainsi obtenu dans le dossier créé à l’étape 1.

- Déplacez le dossier contenant le fichier ZIP vers un disque de sauvegarde.

## Sauvegarder vos concerts MainStage

Pour sauvegarder vos concerts MainStage, vous pouvez utiliser une solution de sauvegarde à l’échelle du système, telle que [Time Machine](https://support.apple.com/HT201250)

Par défaut, vos fichiers de concert se trouvent dans le dossier MainStage de votre dossier Musique.
