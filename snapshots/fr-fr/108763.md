# Procédure de désinstallation d’une version bêta d’iOS ou d’iPadOS

Les membres du [programme de logiciels bêta d’Apple](https://beta.apple.com/sp/betaprogram/guide#ios) , du programme Customer Seeding et de l’ [Apple Developer Program](https://developer.apple.com/ios/) peuvent essayer les versions bêta d’iOS ou d’iPadOS. Si vous avez installé une version bêta d’iOS et que vous n’en voulez plus, vous pouvez revenir à la dernière version publique d’iOS ou d’iPadOS.

[Arrêter de recevoir les versions bêta d’iOS ou d’iPadOS](https://support.apple.com/fr-fr/108763#remove)

[Restaurer la version actuelle d’iOS ou d’iPadOS](https://support.apple.com/fr-fr/108763#restore)

[Effectuer la mise à jour lorsqu’une alerte indique qu’une nouvelle mise à jour d’iOS ou d’iPadOS est disponible](https://support.apple.com/fr-fr/108763#update)

## Arrêter de recevoir les versions bêta d’iOS ou d’iPadOS

Pour les appareils dotés d’iOS 16.4 ou d’iPadOS 16.4, ou version ultérieure :

- Accédez à Réglages.

- Touchez Général.

- Touchez Mise à jour logicielle.

- Touchez Mises à jour bêta.

- Touchez Non.

Sur les appareils dotés d’iOS 16.3.1 ou d’iPadOS 16.3, ou version antérieure :

- Accédez à Réglages.

- Touchez Général.

- Touchez VPN et gestion de l’appareil.

- Touchez le profil de logiciel bêta iOS ou iPadOS qui apparaît.

- Touchez Supprimer le profil. Lorsqu’un message vous y invite, saisissez le code de votre appareil, puis touchez Supprimer. Lorsque vous supprimez le profil, votre appareil ne reçoit plus de versions bêta publiques.

Si vous avez installé une version bêta d’iOS ou d’iPadOS à l’aide d’un ordinateur, vous devez [restaurer iOS ou iPadOS pour supprimer la version bêta](https://support.apple.com/fr-fr/108763#restore) .

## Restaurer la version actuelle d’iOS ou d’iPadOS

Pour supprimer la version bêta d’iOS ou d‘iPadOS et installer la version publique actuelle d’iOS ou d’iPadOS, vous devez effacer et restaurer les données de votre appareil.

Après avoir effacé et restauré les données de votre appareil, vous pouvez configurer ce dernier à partir d’une sauvegarde archivée, si vous en avez une.

Les sauvegardes créées pendant l’utilisation du logiciel bêta peuvent ne pas être compatibles avec les versions antérieures d’iOS ou d’iPadOS. Si vous ne possédez pas de sauvegarde plus ancienne utilisant la version actuelle d’iOS ou d’iPadOS, vous ne pourrez peut-être pas restaurer votre appareil avec votre sauvegarde la plus récente.

- Assurez-vous que votre ordinateur est doté de la [dernière version de macOS](https://support.apple.com/fr-fr/108382) ou de la [dernière version de l’app Appareils Apple](https://support.apple.com/guide/devices-windows/welcome/windows) .

- Connectez votre appareil à votre ordinateur, puis placez votre appareil en mode de récupération en suivant les étapes ci-dessous :

- Sur un iPad sans bouton principal : appuyez brièvement sur le bouton de volume le plus proche du bouton supérieur. Appuyez brièvement sur le bouton de volume le plus éloigné du bouton du haut. Appuyez sur le bouton du haut et maintenez-le enfoncé jusqu’à ce que l’iPad redémarre. En cas de doute, [découvrez sur quels boutons vous devez appuyer pour redémarrer votre iPad](https://support.apple.com/fr-fr/102642) . Continuez à le maintenir enfoncé jusqu’à ce que votre iPad passe en mode de récupération.

- Pour l’iPhone 8 et les modèles ultérieurs : appuyez brièvement sur le bouton d’augmentation du volume. Appuyez brièvement sur le bouton de diminution du volume. Ensuite, maintenez le bouton latéral enfoncé jusqu’à ce que l’écran du mode de récupération apparaisse.

- Cliquez sur l’option Restaurer lorsqu’elle apparaît pour effacer les données de votre appareil et installer la version actuelle non bêta d’iOS ou d’iPadOS. Si le téléchargement dure plus de 15 minutes et que l’écran du mode de récupération se ferme, attendez la fin du téléchargement, puis répétez l’étape 2.

- Attendez que la restauration se termine. Si un message vous y invite, connectez-vous à votre compte Apple, ce qui permet de [supprimer le verrouillage d’activation](https://support.apple.com/fr-fr/108794) . Si la restauration échoue, [découvrez la marche à suivre](https://support.apple.com/fr-fr/108308) .

Une fois la restauration terminée, vous pouvez configurer votre appareil à partir de votre sauvegarde archivée, qui doit correspondre à une version antérieure d’iOS ou d’iPadOS.

Si vous sauvegardez les données d’un appareil doté de la version bêta d’iOS ou d’iPadOS dans iCloud ou votre ordinateur, la sauvegarde ne fonctionnera pas avec des versions antérieures d’iOS ou d’iPadOS. Par exemple, si vous aviez la version bêta d’iOS 18.2 et que vous revenez à iOS 18.1, [vous ne pourrez pas restaurer une sauvegarde que vous avez créée sous la version bêta d’iOS](https://support.apple.com/fr-fr/108811) . Essayez plutôt d’effectuer une restauration à partir d’une sauvegarde que vous avez créée avant d’installer la version bêta d’iOS ou d’iPadOS.

## Effectuer une mise à jour lorsqu’une nouvelle version d’iOS ou d’iPadOS est disponible

Si votre iPhone ou iPad indique qu’une mise à jour logicielle est disponible, la version bêta d’iOS ou d’iPadOS sur votre appareil a expiré. Vous devez effectuer une mise à jour :

- Accédez à Réglages.

- Touchez Général.

- Touchez Mise à jour logicielle.

- [Installez la mise à jour](https://support.apple.com/fr-fr/118575) .
