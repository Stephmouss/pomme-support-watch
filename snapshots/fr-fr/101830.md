# Si votre Mac ne peut pas enregistrer de fichiers sur un lecteur externe

Si vous parvenez à lire des fichiers depuis un périphérique de stockage externe directement connecté à votre Mac, mais que vous ne parvenez pas à écrire des fichiers sur ce périphérique, essayez ces solutions.

## Vérifier l’espace de stockage

Si le périphérique de stockage ne dispose pas de suffisamment d’espace de stockage libre pour contenir le fichier, votre Mac vous en informera. Pour libérer de l’espace de stockage, [supprimez un ou plusieurs fichiers du périphérique de stockage](http:// https://support.apple.com/guide/mac-help/mchlp1093/mac) . Vous pouvez également libérer de l’espace en [compressant des fichiers](https://support.apple.com/guide/mac-help/mchlp2528/mac) .

## Vérifier le format

- Sélectionnez votre périphérique de stockage externe dans le Finder, soit sur le bureau, soit dans la barre latérale d’une fenêtre du Finder.

- Dans le menu Fichier, choisissez Lire des informations. Ou appuyez sur Commande + I.

- Dans la fenêtre Infos qui s’ouvre, le format répertorié doit être l’un des [formats disponibles dans Utilitaire de disque](https://support.apple.com/guide/disk-utility/dsku19ed921c/mac) :

- APFS ou Mac OS étendu : il s’agit de formats Mac.

- MS-DOS (FAT) ou ExFat : il s’agit de formats compatibles Windows.

- Utilitaire de disque ne prend pas en charge le format NTFS. Il se peut que la lecture de fichiers de ce format fonctionne sur votre Mac, mais pas l’écriture.

- Si le périphérique de stockage n’utilise pas l’un de ces formats, [utilisez Utilitaire de disque pour effacer et reformater le périphérique de stockage](https://support.apple.com/guide/disk-utility/dskutl14079/mac) .

## Vérifier Time Machine

Si vous [configurez Time Machine](https://support.apple.com/fr-fr/104984) pour utiliser ce périphérique de stockage pour les sauvegardes, il ne peut alors pas être utilisé pour d’autres fichiers.

## Vérifier les permissions

- Sélectionnez votre périphérique de stockage externe dans le Finder, soit sur le bureau, soit dans la barre latérale d’une fenêtre du Finder.

- Dans le menu Fichier, choisissez Lire des informations. Ou appuyez sur Commande + I.

- Dans la fenêtre Infos qui s’ouvre, ouvrez la section Partage et permissions en bas et assurez-vous que la case « Ignorer les autorisations de ce volume » est cochée. Pour modifier ce réglage, vous devrez peut-être au préalable cliquer sur l’icône de cadenas et saisir un mot de passe administrateur.

## Rechercher des erreurs

[Utilisez Utilitaire de disque pour détecter et réparer les erreurs de disque](https://support.apple.com/fr-fr/102611) . Si Utilitaire de disque localise des erreurs qu’il ne peut pas réparer, ou si aucune des autres solutions ne fonctionne, [utilisez Utilitaire de disque pour effacer et reformater le périphérique de stockage](https://support.apple.com/guide/disk-utility/dskutl14079/mac) .
