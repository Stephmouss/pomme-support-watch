# Rechercher l’identifiant Exchange de votre appareil

Si vous êtes amené à demander de l’aide pour utiliser votre iPhone, iPad ou iPod touch, vous devrez dans certains cas fournir l’identifiant Exchange de votre appareil aux administrateurs Exchange.

## Connaître l’identifiant Exchange d’un appareil sous iOS 11 et versions ultérieures

- Accédez à Réglages > Mots de passe et comptes.

- Sélectionnez Ajouter un compte.

- Dans la liste, choisissez Microsoft Exchange. Votre identifiant Exchange s’affiche dans la partie inférieure de l’écran.

[Image: Capture d’écran des réglages de l’iPhone montrant l’emplacement de l’identifiant Exchange de l’appareil]

Si vous restaurez les réglages par défaut de votre appareil ou si vous passez à un nouvel appareil, vous recevez un nouvel identifiant Exchange d’appareil.
