# Reconstruction de l’index des boucles dans GarageBand 6 ou version antérieure

Dans certaines situations, l’index des boucles ne peut plus être utilisé et doit être reconstruit.

Vous êtes alors susceptible de rencontrer les problèmes suivants :

- Un message indiquant qu’aucune boucle Apple Loop n’a été trouvée s’affiche lorsque vous ouvrez le navigateur de boucles.

- Les boutons du navigateur de boucles sont grisés et aucune boucle n’apparaît dans le navigateur.

- D’autres problèmes liés aux boucles Apple Loops surviennent.

Pour reconstruire les fichiers d’index, procédez comme suit :

- Ouvrez une session avec un compte d’administrateur.

- Si GarageBand est ouvert, fermez cette app.

- Dans le Dock, cliquez sur l’icône du Finder.

- À partir du menu Aller , choisissez Aller au dossier .

- Saisissez l’adresse du répertoire (consultez [cet article](http://support.apple.com/HT1045) pour en savoir plus).

- Cliquez sur Aller.

- Faites glisser tous les fichiers « Search Index » du dossier « Apple Loops Index » vers la corbeille (ceux-ci seront recréés par la suite).

- Ouvrez GarageBand.

- Cliquez sur le bouton Navigateur de boucles. Il se peut que le message « Aucune boucle Apple Loop détectée » s’affiche.

- Dans le Dock, cliquez sur l’icône du Finder.

- À partir du menu Aller , choisissez Aller au dossier .

- Saisissez l’adresse du répertoire (consultez [cet article](http://support.apple.com/HT1045) pour en savoir plus).

- Cliquez sur Aller.

- Localisez le dossier Apple Loops et faites-le glisser vers le navigateur de boucles de GarageBand.

- Répétez l’ensemble des étapes 11 à 14 avec tous les fichiers de boucles, en vérifiant chaque emplacement mentionné dans [cet article](http://support.apple.com/HT1045) .

La dernière étape permet de réindexer le dossier Apple Loops. Si vous disposez de Jam Pack GarageBand, répétez la dernière étape avec le dossier Jam Pack GarageBand.
