# Si vous recevez un message sur votre iPhone ou iPad indiquant que votre code de déverrouillage a expiré

Votre appareil iOS ou iPadOS utilise probablement un profil de gestion des appareils mobiles qui vous demande de modifier votre code.

[Image: Un iPhone doté d’iOS 12 affiche l’invite : « Votre code de déverrouillage de l’iPhone a expiré. »]

La gestion des appareils mobiles (MDM) est un ensemble d’outils de développement logiciels permettant de configurer les appareils Apple de manière sécurisée et sans fil, qu’ils appartiennent à l’utilisateur ou à l’organisation. Les fonctionnalités MDM incluent la mise à jour des logiciels et des réglages des appareils, le suivi de la conformité aux politiques de l’organisation et l’effacement ou le verrouillage à distance des appareils.

Si vous recevez une alerte sur votre iPhone ou iPad indiquant que votre code de déverrouillage a expiré, il peut s’agir d’une exigence MDM.

En savoir plus sur la [gestion des appareils mobiles](https://support.apple.com/guide/deployment/welcome/web) ou la différence entre les [codes d’accès](https://support.apple.com/119586) et les [mots de passe](https://support.apple.com/104955) .

## Modifier le code de déverrouillage de votre iPhone ou iPad

- Ouvrez l’app Réglages.

- Touchez Face ID et code, puis saisissez votre code d’accès, ou utilisez Face ID pour déverrouiller les réglages.

- Touchez Changer le code.

- Saisissez votre code d’accès actuel pour commencer le processus.

- Saisissez le nouveau code d’accès que vous souhaitez utiliser.

- Saisissez à nouveau le nouveau code d’accès pour confirmer la modification.

[Découvrir la marche à suivre en cas d’oubli du code d’accès de votre iPad ou iPhone](https://support.apple.com/105090)

## Vérifier si votre iPhone ou iPad fait partie d’une solution de gestion des appareils mobiles

- Dans l’app Réglages, touchez Général.

- Touchez VPN et gestion de l’appareil, puis recherchez les profils installés sous Gestion des appareils mobiles.

- Touchez un profil sous Gestion des appareils mobiles.

- Touchez Plus de détails.

- Touchez Gestion des appareils mobiles, puis consultez la liste des droits des appareils pour savoir si un code d’accès est requis.

Si la liste des droits inclut une politique de code d’accès, vous pouvez contacter votre organisation pour obtenir plus d’informations sur son approche en matière de gestion des appareils mobiles.
