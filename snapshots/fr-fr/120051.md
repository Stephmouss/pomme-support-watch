# Si vos yeux sont trop proches ou trop éloignés des écrans de votre Apple Vision Pro

Afin d’éviter une blessure aux yeux lors d’une chute ou d’une collision et de maintenir la précision des saisies effectuées avec le regard, utilisez le coussinet du cache anti-lumière recommandé. Celui-ci garantit que les lentilles de votre Apple Vision Pro restent à une distance suffisante de vos yeux.

## Remplacer le coussinet du cache anti-lumière

- Dans l’emballage de votre Apple Vision Pro, identifiez le coussinet du cache anti-lumière recommandé dans le message d’alerte de visionOS :

- Si vos yeux sont trop proches de l’écran, choisissez le coussinet du cache anti-lumière N+ ou W+ plus épais.

- Si vos yeux sont trop éloignés de l’écran, choisissez le coussinet du cache anti-lumière N ou W plus fin. Il s’agit du coussinet qui était installé sur le cache anti-lumière lorsque vous avez ouvert l’emballage pour la première fois.

[Image: Cache anti-lumière de l’Apple Vision Pro avec options de taille : XS, S, M, L]

- Pour retirer le coussinet du cache anti-lumière que vous utilisez actuellement, séparez-le du cache anti-lumière en tirant dessus.

[Image: Schéma de l’Apple Vision Pro, avec une flèche indiquant l’emplacement du coussinet du cache anti-lumière.]

- Pour installer le coussinet du cache anti-lumière recommandé, approchez-le du cache anti-lumière jusqu’à ce qu’il se fixe magnétiquement.

[Image: Apple Vision Pro avec une flèche pointant vers le coussinet du cache anti-lumière, dont le remplacement est abordé dans l’article.]

Il est important de toujours porter la taille de cache anti-lumière et de coussinet du cache anti-lumière adaptée à votre visage. Si vos yeux sont trop proches des lentilles de votre Apple Vision Pro, il existe un risque de blessure en cas de chute ou de collision. Si vos yeux sont trop éloignés des lentilles, la précision des saisies effectuées avec le regard et la qualité d’image peuvent s’en trouver réduites. Si vous utilisez une mauvaise taille de coussinet du cache anti-lumière, il est possible que vous ne puissiez pas [configurer ou utiliser Optic ID](https://support.apple.com/HT213962) .

## Besoin d’aide supplémentaire ?

Si le message continue de s’afficher après avoir remplacé le coussinet du cache anti-lumière :

- Si vous avez acheté votre Apple Vision Pro en ligne ou par téléphone, accédez à l’adresse [https://secure.store.apple.com/fr/shop/vision/fit/help](https://secure.store.apple.com/fr/shop/vision/fit/help) , ou composez le 0800 046 046.

- Si vous avez acheté votre Apple Vision Pro dans un Apple Store, rendez-vous dans l’Apple Store le plus proche.
