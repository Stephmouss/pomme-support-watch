# Importation de médias Sony XAVC et XDCAM dans Final Cut Pro

Pour importer des médias Sony XAVC et XDCAM, vous devez installer des logiciels supplémentaires.

## Si vous utilisez Final Cut Pro 10.2

Final Cut Pro 10.2 est compatible avec les médias Sony XAVC, XAVC S, XDCAM, XDCAM HD et XDCAM EX.

Avant d’importer des médias Sony XAVC et XDCAM, vérifiez que le logiciel Pro Video Formats est installé sur votre ordinateur. [Vérifiez également si des mises à jour sont disponibles](http://support.apple.com/fr-fr/HT201541) et, si nécessaire, installez la dernière version du logiciel Pro Video Formats. Ce logiciel peut également être [téléchargé manuellement](http://support.apple.com/kb/dl1396?viewlocale=fr_FR) sur le site web d’Apple. Aucun logiciel supplémentaire n’est requis.

Pour savoir comment importer des médias, consultez les rubriques suivantes dans l’aide Final Cut Pro 10.2 :

- [Importation à partir des caméras à système de fichiers](https://help.apple.com/finalcutpro/mac/10.2/#verd0e78ca8)

- [Importation à partir d’un disque dur](https://help.apple.com/finalcutpro/mac/10.2/#ver418155a4)

## Si vous utilisez Final Cut Pro 10.1.4 ou une version antérieure

Final Cut Pro 10.1.4 et les versions antérieures sont compatibles avec les fichiers Sony XAVC, XDCAM, XDCAM HD et XDCAM EX.

Avant d’importer des médias Sony XAVC et XDCAM, vérifiez que le logiciel Pro Video Formats et le module Sony XAVC/XDCAM sont installés sur votre ordinateur. [Vérifiez également si des mises à jour sont disponibles](http://support.apple.com/fr-fr/HT201541) et, si nécessaire, installez la dernière version du logiciel Pro Video Formats. Ce logiciel peut également être [téléchargé manuellement](http://support.apple.com/kb/dl1396?viewlocale=fr_FR) sur le site web d’Apple.

Si vous souhaitez installer le module Sony, téléchargez-le manuellement sur [cette page](https://www.sonycreativesoftware.com/fr/pdzk-lt2) . Consultez les notes de version, puis installez le module.

Pour savoir comment importer des médias, consultez les rubriques suivantes dans l’aide Final Cut Pro 10.1.4 :

- [Importation à partir des caméras à système de fichiers](https://help.apple.com/finalcutpro/mac/10.1/#verd0e78ca8)

- [Importation à partir d’un disque dur](https://help.apple.com/finalcutpro/mac/10.1/#ver418155a4)
