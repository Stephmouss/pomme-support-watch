# Si vous entendez des claquements ou des perturbations lorsque vous utilisez MainStage

Si vous entendez des claquements ou des perturbations lorsque vous utilisez la prise casque de votre Mac avec MainStage, réduisez le nombre de cœurs utilisés par MainStage, augmentez la taille de la mémoire tampon d’E/S ou utilisez une interface audio externe.

## Réduisez le nombre de cœurs

- Sélectionnez MainStage > Préférences > Audio.

- Cliquez sur Réglages avancés dans la section Audio.

- Faites glisser le curseur Utilisation CPU vers la gauche pour réduire le nombre de cœurs utilisés par MainStage.

## Augmentez la taille de la mémoire tampon d’E/S

- Sélectionnez MainStage > Préférences > Audio.

- Cliquez sur Réglages avancés dans la section Audio.

- Choisissez une taille plus importante dans le menu local Taille Buffer E/S. L’augmentation de [la taille de la mémoire tampon d’E/S entraîne une hausse de la latence](https://support.apple.com/fr-fr/HT202982) .

## Utilisez une interface audio externe

Utilisez une interface audio externe pour la sortie audio à partir de MainStage au lieu de la prise casque. Consultez la documentation du fabricant concernant l’installation de tout logiciel nécessaire pour l’interface, ainsi que pour obtenir des informations sur le fonctionnement.

Pour utiliser une interface audio avec MainStage :

- Connectez l’interface audio externe à votre Mac.

- Ouvrez MainStage, puis choisissez MainStage > Préférences > Audio.

- Dans le menu contextuel de la sortie Audio, sélectionnez l’interface audio externe.

- Si vous le souhaitez, choisissez l’interface audio externe dans le menu local Entrée audio.

- Cliquez sur Appliquer les modifications.
