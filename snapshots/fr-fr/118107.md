# Restaurer les réglages par défaut de votre iPhone, iPad ou iPod à l’aide d’un ordinateur

Effacez le contenu de votre appareil et installez la dernière version du logiciel à l’aide d’un ordinateur. Cette restauration des réglages par défaut efface toutes les données et tous les réglages de votre iPhone, iPad ou iPod.

[Image: Lire la vidéo]

## Préparer votre appareil

- Mettez à jour votre Mac ou PC.

- [Créez une sauvegarde](https://support.apple.com/fr-fr/118426) .

- Accédez à Réglages.

- Touchez [votre nom].

- Touchez Localiser.

- Touchez Localiser mon [appareil].

- Désactivez Localiser mon [appareil].

- Saisissez le mot de passe de votre compte Apple.

- Touchez le bouton Terminé sur votre clavier.

## Restaurer les réglages par défaut de votre appareil

- Connectez votre appareil à votre ordinateur.

- Si l’alerte « Autoriser la connexion de l’accessoire ? » s’affiche sur votre ordinateur, cliquez sur Autoriser.

- Ouvrez le Finder sur un Mac ou [l’app Appareils Apple](https://support.apple.com/fr-fr/guide/devices-windows/welcome/windows) sur un PC. [Identifiez la version de macOS installée sur votre Mac](https://support.apple.com/fr-fr/109033) .

- [Sélectionnez votre appareil](https://support.apple.com/fr-fr/108392) lorsqu’il apparaît sur votre ordinateur.

- Si un message vous demande le code d’accès de votre appareil ou si vous souhaitez faire confiance à cet ordinateur, procédez comme indiqué à l’écran. [Si vous avez oublié votre code d’accès](https://support.apple.com/fr-fr/118430) , obtenez de l’aide.

- Cliquez sur Restaurer [appareil] sur votre ordinateur*. [Assurez-vous d’avoir désactivé la fonctionnalité Localiser, comme décrit ci-dessus](https://support.apple.com/fr-fr/118107#prepare) .

- Cliquez sur Restaurer pour confirmer. Votre ordinateur efface votre appareil et installe la version la plus récente d’iOS, d’iPadOS ou du logiciel de l’iPod.

[Image: Boîte de dialogue de confirmation du Finder demandant si vous souhaitez vraiment restaurer les réglages par défaut de l’iPhone, après avoir cliqué sur Restaurer l’iPhone.]

Une fois le processus de restauration terminé, l’écran Bonjour apparaîtra sur votre appareil.

* La restauration d’un iPhone n’entraîne pas la suppression de votre eSIM. [Découvrez comment effacer votre eSIM en cas de besoin](https://support.apple.com/fr-fr/102421) .
