# À propos de la prise en charge des disques Mac OS Extended chiffrés dans macOS 28 ou version ultérieure

Dans macOS 28 et versions ultérieures, le format de système de fichiers Mac OS Extended ne sera pris en charge que pour les volumes (disques et autres périphériques de stockage) qui ne sont pas chiffrés. Pour garantir la compatibilité avec les futures versions de macOS, déchiffrez ou reformatez les volumes Mac OS Extended chiffrés.

## Vérifier le format et le chiffrement du volume

À partir de macOS 26, votre Mac peut vous notifier que vous utilisez un disque Mac OS Extended chiffré et qu’il ne sera pas compatible avec macOS 28 ou versions ultérieures.

La notification identifiera le volume par son nom, mais si vous souhaitez confirmer que le volume utilise le format Mac OS Extended et qu’il est chiffré :

- Ouvrez Utilitaire de disque à partir du sous-dossier Utilitaires de votre dossier Applications. Vous pouvez également [utiliser Spotlight](https://support.apple.com/guide/mac-help/mchlp1008/mac) pour le trouver et l’ouvrir.

- Dans le menu Présentation de la barre de menus, choisissez Afficher uniquement les volumes.

- Dans la barre latérale de l’Utilitaire de disque, sélectionnez le nom du volume.

- Recherchez les informations affichées directement sous le nom du volume à droite. Si vous voyez à la fois « Mac OS Extended » et « Chiffré » pour votre volume, ce volume ne sera pas compatible avec macOS 28 et versions ultérieures. Exemple :

- CoreStorage Logical Volume • Mac OS Extended (Case-sensitive, Journaled, Encrypted)

macOS 28 et versions ultérieures continueront à prendre en charge les volumes non chiffrés utilisant le format Mac OS Extended. Mac OS Extended est également connu sous le nom de HFS Plus (ou HFS+).

## Convertir, déchiffrer ou reformater le volume

Pour tout volume Mac OS Extended chiffré que vous souhaitez utiliser avec macOS 28 ou une version ultérieure lorsqu’elle sera disponible, effectuez l’une de ces opérations avant d’installer la mise à niveau.

### Convertir le volume au format APFS chiffré

Cette solution ne s’applique pas aux [disques de sauvegarde Time Machine chiffrés](https://support.apple.com/fr-fr/102423) .

- Ouvrez Utilitaire de disque à partir du sous-dossier Utilitaires de votre dossier Applications. Vous pouvez également [utiliser Spotlight](https://support.apple.com/guide/mac-help/mchlp1008/mac) pour le trouver et l’ouvrir.

- Dans le menu Présentation de la barre de menus, choisissez Afficher uniquement les volumes.

- Dans la barre latérale de l’Utilitaire de disque, sélectionnez le nom du volume.

- Dans le menu Édition de la barre des menus, choisissez Convertir en APFS, puis cliquez sur Convertir pour confirmer.

- Quittez l’Utilitaire de disque lorsque vous avez terminé.

### Ou déchiffrer le volume

Cette solution ne s’applique pas aux [disques de sauvegarde Time Machine chiffrés](https://support.apple.com/fr-fr/102423) .

- Connectez le lecteur à votre Mac et saisissez le mot de passe de chiffrement pour le déverrouiller.

- Maintenez la touche Contrôle enfoncée et cliquez sur l’icône du lecteur sur le bureau ou dans la barre latérale d’une fenêtre du Finder, puis choisissez Déchiffrer dans le menu contextuel qui apparaît.

- Saisissez à nouveau le mot de passe de chiffrement lorsqu’on vous le demande, puis attendez la fin du déchiffrement. Cette opération prend du temps, en particulier pour les volumes de grande taille. Pour vérifier la progression du déchiffrage, vous pouvez saisir diskutil cs list dans Terminal, qui se trouve dans le dossier Utilitaires de votre dossier Applications. Vous pouvez également utiliser Spotlight pour le trouver et l’ouvrir.

Une fois l’opération terminée, le volume continuera d’utiliser le format Mac OS Extended, mais il ne sera pas chiffré.

### Ou reformater le volume

Sauvegardez toutes les données que vous souhaitez conserver, puis effacez et reformatez le volume au format APFS ou APFS (chiffré). Cette opération supprime définitivement toutes les données du volume, mais garantit la compatibilité avec les futures versions de macOS.

[Effacer et reformater un périphérique de stockage dans Utilitaire de disque sur Mac](https://support.apple.com/guide/disk-utility/dskutl14079/mac)
