# Ajouter une clé de résident à l’app Cartes d’Apple sur un iPhone ou une Apple Watch

Suivez les instructions de votre société immobilière pour ajouter une clé de résident à l’app Cartes pour votre immeuble, votre copropriété ou tout autre espace commun.

Pour ajouter votre clé de résident sur votre iPhone ou votre Apple Watch, vous devez disposer des éléments suivants :

- La version la plus récente [d’iOS](https://support.apple.com/118575) ou de [watchOS](https://support.apple.com/108926)

- Un compte Apple connecté à iCloud avec l’identification à deux facteurs activée

Les clés de résident ne sont utilisables que pour les appartements et copropriétés participants. Si vous vivez dans une propriété participante, vous pouvez avoir besoin d’un compte d’utilisateur associé à la propriété pour ajouter votre clé à l’app Cartes. Pour toute question relative à l’éligibilité de votre appartement ou copropriété ou concernant votre compte d’utilisateur, contactez la société qui gère votre immeuble ou votre copropriété.

## Comment ajouter une clé de résident sur votre iPhone pour votre appartement ou votre copropriété

- Ouvrez l’app, l’e-mail, le message texte ou toute autre communication de votre société immobilière et suivez les instructions pour ajouter votre clé.

- Touchez Ajouter à l’app Cartes.

[Image: Aucun texte de remplacement pour l’image]

- Suivez les instructions à l’écran pour ajouter votre clé.

Si vous louez ou possédez plusieurs locaux dans le même bâtiment, vérifiez auprès de votre société immobilière si vous pouvez ajouter une seule clé pour tous vos locaux.

Lorsque vous ajoutez une clé, le [mode Express](https://support.apple.com/105123) est automatiquement activé. Il vous permet d’utiliser votre clé en plaçant simplement l’appareil contre la serrure.

Si vous n’avez plus besoin de votre clé, découvrez comment [la supprimer de l’app Cartes](https://support.apple.com/102544) .

### Comment ajouter votre clé sur votre Apple Watch

Lorsque vous ajoutez votre clé sur votre iPhone, elle est automatiquement ajoutée sur votre Apple Watch. Vous pouvez également l’ajouter manuellement.

- Ouvrez l’app Apple Watch sur votre iPhone jumelé.

- Touchez Cartes et Apple Pay.

- Touchez le bouton Ajouter à côté de votre clé.

[Image: Aucun texte de remplacement pour l’image]

### Comment ajouter une clé de résident précédemment ajoutée

Si vous recevez un nouvel appareil, vous pouvez ajouter à nouveau des clés de résident déjà ajoutées, et ce, directement dans l’app Cartes.

- Sur votre iPhone, ouvrez l’app Cartes.

- Touchez le bouton Ajouter .

[Image: Aucun texte de remplacement pour l’image]

- Touchez Cartes trouvées pour vous.

- Touchez ensuite votre clé de résident et suivez les instructions à l’écran.

## Comment utiliser votre clé de résident sur votre iPhone ou votre Apple Watch

- Placez le haut de votre iPhone ou l’écran de votre Apple Watch devant la serrure.

- Si votre clé permet l’accès, la porte se déverrouille. Une coche et OK s’afficheront sur votre appareil.

Si vous avez désactivé le mode Express, vous pouvez utiliser votre clé de résident dans l’app Cartes :

- Ouvrez l’app Cartes:

- iPhone doté de Face ID : cliquez deux fois sur le bouton latéral.

- iPhone doté de Touch ID : posez votre doigt sur le capteur Touch ID.

- Apple Watch : appuyez deux fois sur le bouton latéral.

- Choisissez votre clé :

- iPhone : touchez votre carte par défaut pour afficher vos autres cartes. Touchez votre clé et authentifiez-vous à l’aide de Face ID, de Touch ID ou de votre code d’accès.

- Apple Watch : faites défiler l’écran vers le bas pour localiser votre clé.

- Placez le haut de votre iPhone ou l’écran de votre Apple Watch devant la serrure.

- Si votre clé permet l’accès, la porte se déverrouille. Une coche et OK s’afficheront sur votre appareil.

## Si votre iPhone doit être rechargé

En fonction du modèle de votre iPhone, vous pouvez [utiliser votre clé de résident même lorsque la batterie de votre iPhone est déchargée](https://support.apple.com/105123#powerreserve) .

## Si vous avez besoin d’aide concernant votre clé de résident

- Votre société immobilière peut désactiver votre clé. Dans ce cas, vous ne pourrez plus utiliser votre clé sur votre appareil et vous aurez la possibilité de la supprimer de l’app Cartes

- En cas de perte ou de vol de votre appareil, vous pouvez [le marquer comme perdu](https://support.apple.com/104978#markaslost) . Cette action désactive automatiquement toutes les cartes figurant dans l’app Cartes, y compris votre clé.

## Comment configurer une clé de domicile sur votre iPhone pour votre serrure HomeKit

Dans l’app Maison, vous pouvez ajouter une serrure intelligente et [configurer une clé de domicile](https://support.apple.com/guide/iphone/unlock-your-door-with-a-home-key-iph0dc255875/ios) . Vous pouvez ensuite déverrouiller votre porte et en partager l’accès avec des invités.
