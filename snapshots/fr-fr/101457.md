# Lion Server : l’assistant Open Directory peut ne pas afficher l’adresse du serveur Open Directory maître lors de la mise hors service d’une réplique

Lors de la désactivation d’une réplique de serveur Open Directory exécutant Mac OS X Lion, l’assistant Open Directory peut ne pas afficher l’adresse IP ou le nom DNS du serveur Open Directory maître.

Saisissez les identifiants de l’administrateur Open Directory, puis cliquez sur Continuer.

La réplique mettra à jour la configuration du serveur Open Directory maître lors de la mise hors service.
