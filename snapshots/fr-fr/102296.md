# Créer une liste de tâches avec Notes

Découvrez comment créer des listes de tâches sur votre iPhone, iPad ou iPod touch.

## Avant de commencer

- Assurez-vous que votre iPhone, iPad ou iPod touch dispose de la [dernière version d’iOS ou d’iPadOS](https://support.apple.com/fr-fr/118575) .

- Pour utiliser les fonctionnalités les plus récentes de Notes, vérifiez que vous avez configuré Notes avec iCloud ou que vos notes sont enregistrées sur votre appareil. Pour configurer Notes avec iCloud, accédez à Réglages > Apps > Notes > Compte par défaut, puis sélectionnez iCloud. Pour configurer Notes sur votre appareil uniquement, accédez à Réglages > Notes, puis sélectionnez Compte « Sur mon [appareil] ». Plusieurs fonctionnalités ne fonctionnent pas avec d’autres fournisseurs de services de messagerie.

## Comment créer une liste de tâches

- Ouvrez l’app Notes.

- Touchez le bouton Rédiger pour créer une nouvelle note.

[Image: Rédiger une nouvelle note]

- Saisissez un titre et touchez Retour.

- Touchez le bouton Liste de tâches pour commencer la liste. Chaque fois que vous touchez Retour, un nouvel élément est ajouté à la liste.

[Image: bouton Liste de tâches]

- Touchez le cercle vide pour cocher une tâche effectuée.

[Image: iPhone montrant comment créer une liste de tâches]

Pour créer une liste dans une note existante, placez le curseur à l’endroit où vous souhaitez commencer. Touchez ensuite le bouton Liste de tâches et créez votre liste.

[Image: bouton Liste de tâches]

## Comment organiser vos listes de tâches

Lorsque vous créez une liste de tâches, il est facile de l’organiser. Voici des exemples de ce que vous pouvez faire :

- Réorganiser les éléments via la fonction glisser-déposer. Faites simplement glisser l’élément de la liste à l’endroit souhaité.

- Balayer pour appliquer un retrait à certains éléments. Effectuez un balayage vers la droite sur l’élément de la liste pour effectuer un retrait et vers la gauche pour inverser le retrait.

- Déplacer automatiquement les éléments cochés vers le bas. Accédez à Réglages > Apps > Notes, touchez Trier les éléments cochés, puis touchez Manuellement ou Automatiquement.

- Cocher les éléments à mesure que vous les remplissez ou décocher tous les éléments pour recommencer.

## Comment partager une liste de tâches

- Ouvrez l’app Notes.

- Accédez à la note avec la liste, puis touchez le bouton Partager .

[Image: Aucun texte de remplacement pour l’image]

- Sélectionnez Collaborer, puis choisissez comment vous souhaitez envoyer votre invitation.
