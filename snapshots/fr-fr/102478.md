# Si vous n’arrivez pas à configurer une eSIM sur votre iPhone

Découvrez la marche à suivre si vous n’arrivez pas à configurer une eSIM sur votre iPhone.

[En savoir plus sur l’eSIM](https://support.apple.com/fr-fr/118669)

## Éléments requis

- Votre nouvel iPhone doit être connecté à un réseau Wi-Fi ou à un partage de connexion. Dans certains pays et certaines régions, les modèles d’iPhone avec eSIM uniquement peuvent être activés sans réseau Wi-Fi.

- Un forfait cellulaire et une eSIM actifs pour votre iPhone via un [opérateur proposant le service eSIM.](https://support.apple.com/fr-fr/101569)

- [Votre ou vos iPhone doivent utiliser la dernière version d’iOS compatible](https://support.apple.com/fr-fr/118575) .

## Étapes à suivre

Après chacune des étapes ci-dessous, ouvrez le centre de contrôle en effectuant un balayage vers le bas à partir de l’angle supérieur droit de l’écran. Vérifiez si votre opérateur est affiché dans la barre d’état. Si ce n’est pas le cas, passez à l’étape suivante.

- [Activez le mode Avion, puis désactivez-le](https://support.apple.com/fr-fr/108785) .

- Ouvrez l’app Réglages, puis touchez Données cellulaires. Vérifiez si le numéro que vous essayez d’activer est affiché. Si c’est le cas, désactivez-le, puis réactivez-le.

- Redémarrez votre appareil.

Sur les modèles d’iPhone dotés d’iOS 18 ou version ultérieure, vous pouvez [télécharger la dernière version de l’app Assistance Apple](https://apps.apple.com/fr/app/apple-support/id1130498044?ppid=5e7c213d-dd8a-485d-acc0-e724f97419e6) afin d’exécuter des diagnostics supplémentaires qui peuvent aider à déterminer l’origine du problème de votre appareil.

## Vérifier les réglages de l’opérateur

Vérifiez les réglages de l’opérateur sur votre appareil.

- Ouvrez l’app Réglages.

- Touchez Général

- Touchez Informations.

- Faites défiler l’écran jusqu’à la section eSIM. Le nom de l’opérateur et le numéro de version de votre iPhone sont indiqués en regard du champ Opérateur. Touchez le numéro de version. Si une mise à jour est disponible, il vous sera demandé de sélectionner OK ou Mettre à jour.

## Contacter votre opérateur

Si vous ne parvenez toujours pas à configurer une eSIM sur votre iPhone, [contactez votre opérateur](https://support.apple.com/fr-fr/101569) .

Il peut s’avérer utile de récupérer les informations suivantes à l’avance :

- Notez le message d’erreur affiché sur votre iPhone.

- Récupérez les identifiants de votre iPhone et de votre compte opérateur :

- Votre numéro de téléphone

- Le mot de passe et/ou le code PIN de votre compte opérateur

- Le numéro IMEI ou EID de votre iPhone. Pour les trouver, ouvrez l’app Réglages. Touchez Général, puis Informations.
