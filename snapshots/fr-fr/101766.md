# Si vous utilisez une carte intelligente pour vous connecter à votre Mac et réinitialisez votre mot de passe Active Directory à partir d’un autre ordinateur - Assistance Apple (FR)

Si vous réinitialisez votre mot de passe Active Directory à partir d’un autre ordinateur et utilisez une carte intelligente et FileVault, découvrez comment vous connecter à votre Mac sous macOS Catalina 10.15.4 ou version ultérieure.

Si vous réinitialisez votre mot de passe Active Directory à partir d’un autre ordinateur et utilisez une carte intelligente et FileVault, découvrez comment vous connecter à votre Mac sous macOS Catalina 10.15.4 ou version ultérieure.

- Redémarrez votre Mac.

- Saisissez votre ancien mot de passe utilisateur Active Directory dans la première fenêtre de connexion.

- Saisissez votre nouveau mot de passe utilisateur Active Directory dans la deuxième fenêtre de connexion.

Désormais, chaque fois que vous redémarrez votre Mac, vous pouvez utiliser votre carte intelligente pour vous connecter dans la deuxième fenêtre de connexion.
