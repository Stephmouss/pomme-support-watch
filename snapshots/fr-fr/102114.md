# Définition des restrictions applicables au code d’accès sur une Apple Watch

Découvrez comment les restrictions de code d’accès de votre iPhone s’appliquent à l’Apple Watch qui lui est associée.

Cet article s’adresse aux administrateurs qui utilisent des profils de configuration, la gestion des appareils mobiles ou des règles Exchange pour gérer les restrictions de code d’accès.

## Restrictions applicables au code d’accès

Les restrictions que vous définissez peuvent également concerner une Apple Watch lorsque celle-ci est jumelée à un iPhone géré.

### Codes d’accès numériques

L’Apple Watch prend en charge les codes d’accès numériques. Si les restrictions appliquées permettent l’utilisation de codes numériques, l’Apple Watch en tient compte.

Par exemple, vous pouvez demander un code d’accès d’au moins six chiffres uniques pour un iPhone. Dans ce cas, les utilisateurs devront se conformer à cette règle au moment de définir le code d’accès de l’Apple Watch associée. Conseillez aux utilisateurs de définir un code d’accès différent de celui qu’ils utilisent sur leur iPhone.

### Codes d’accès alphanumériques ou complexes

Si vous demandez un code d’accès pour iPhone avec des lettres ou des caractères spéciaux, vous ne pouvez pas en définir de semblable sur une Apple Watch. Au lieu de cela, les utilisateurs devront déverrouiller leur iPhone pour déverrouiller leur Apple Watch. Ouvrez l’application Apple Watch sur l’iPhone jumelé, appuyez sur l’onglet Ma montre, puis appuyez sur Code > Déverrouiller avec l’iPhone.
