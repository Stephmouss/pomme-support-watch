# Utiliser le mode Avion sur votre iPhone, iPad, Apple Watch et Apple Vision Pro

Le mode Avion vous permet de désactiver les données mobiles et le Wi-Fi sur votre appareil pendant un vol.

## Activation du mode Avion

- Sur votre iPhone, iPad ou Apple Vision Pro, ouvrez le centre de contrôle, puis touchez le bouton du mode Avion . Cette action désactive toutes les communications radio à l’exception du Bluetooth. L’activation du mode Avion permet également d’économiser la batterie, de réduire les frais d’itinérance quand vous voyagez et de forcer une actualisation du signal.

[Image: bouton du mode Avion]

- Sur votre Apple Watch, appuyez sur le bouton latéral pour ouvrir le centre de contrôle, puis touchez le bouton du mode Avion . Dans watchOS 9 et versions antérieures, effectuez un balayage vers le haut du cadran pour ouvrir le centre de contrôle.

[Image: bouton du mode Avion]

Si la compagnie aérienne le permet, vous pouvez utiliser le [Wi-Fi et le Bluetooth](https://support.apple.com/fr-fr/102412) lorsque le mode Avion est actif. Si vous désactivez le Bluetooth alors que le mode Avion est actif, votre appareil désactive le Bluetooth à la prochaine activation du mode Avion.

Apple Vision Pro utilise uniquement le Wi-Fi. [En savoir plus sur le mode Voyage de l’Apple Vision Pro](https://support.apple.com/fr-fr/118510) .

## Recopier les réglages du mode Avion entre des appareils

- Ouvrez l’app Apple Watch sur votre iPhone.

- Touchez Général, puis Mode avion.

- Touchez pour activer Comme l’iPhone.
