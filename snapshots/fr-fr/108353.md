# À propos des sauvegardes chiffrées sur votre iPhone, iPad ou iPod touch

Pour protéger les sauvegardes de votre iPhone, iPad ou iPod touch sur votre ordinateur, vous pouvez utiliser la protection par mot de passe et le chiffrement.

- [Chiffrer vos sauvegardes](https://support.apple.com/fr-fr/108353#encrypt)

- [Voir vos sauvegardes chiffrées](https://support.apple.com/fr-fr/108353#view)

- [Désactiver le chiffrement des sauvegardes](https://support.apple.com/fr-fr/108353#off)

- [Réinitialiser le mot de passe de votre sauvegarde chiffrée](https://support.apple.com/fr-fr/108353#reset-password)

## Chiffrer la sauvegarde de votre iPhone, iPad ou iPod touch

L’option « Chiffrer la sauvegarde locale » du Finder, de l’app [Appareils Apple](https://support.apple.com/guide/devices-windows/welcome/windows) ou d’ [iTunes](https://support.apple.com/fr-fr/118290) verrouille et encode vos informations. Les sauvegardes chiffrées peuvent inclure des informations non comprises dans les sauvegardes non chiffrées :

- Les mots de passe enregistrés

- Les réglages Wi-Fi

- L’historique des sites web consultés

- Les données de l’app Santé

- Historique des appels

Les sauvegardes chiffrées n’incluent pas les données de Face ID, de Touch ID, ni du code d’accès de l’appareil.

Votre sauvegarde n’est pas chiffrée par défaut. Pour chiffrer une sauvegarde dans le Finder, dans l’app Appareils Apple ou dans iTunes pour la première fois, activez l’option « Chiffrer la sauvegarde locale » protégée par un mot de passe. Une fois cette option activée, le système chiffre les sauvegardes de votre appareil. Vous pouvez également effectuer une sauvegarde dans iCloud, qui chiffre vos informations.

## Chiffrer vos sauvegardes

- Accédez au Finder sur votre Mac ou ouvrez l’app Appareils Apple sur votre PC. Si vous n’avez pas installé l’app Appareils Apple sur votre PC, ou si votre Mac est doté de macOS Mojave ou version antérieure, ouvrez iTunes. [Identifiez la version de macOS installée sur votre Mac](https://support.apple.com/fr-fr/109033) .

- Utilisez un câble USB pour connecter votre appareil à votre ordinateur.

- [Recherchez votre appareil sur votre ordinateur](https://support.apple.com/fr-fr/108392) .

- Dans l’onglet Général ou Résumé, sélectionnez « Chiffrer la sauvegarde locale » dans la section Sauvegardes.

[Image: Fenêtre du Finder avec l’option « Chiffrer la sauvegarde locale » sélectionnée sous Sauvegardes.]

- Créez un mot de passe quand un message vous y invite. Vous avez besoin de ce mot de passe pour utiliser la sauvegarde. Découvrez la marche à suivre si [vous avez oublié votre mot de passe](https://support.apple.com/fr-fr/108313) .

Une fois votre mot de passe confirmé, la sauvegarde démarre et remplace immédiatement vos sauvegardes précédentes en les chiffrant. Une fois l’opération terminée, assurez-vous que votre sauvegarde chiffrée a été correctement réalisée.

## Voir vos sauvegardes chiffrées

Si vous avez configuré le Finder, l’app Appareils Apple ou iTunes pour chiffrer vos sauvegardes, la case « Chiffrer la sauvegarde locale » est cochée dans l’onglet Général ou Résumé.

- Accédez au Finder ou ouvrez l’app Appareils Apple. Si vous n’avez pas installé l’app Appareils Apple sur votre PC, ou si votre Mac est doté de macOS Mojave ou version antérieure, ouvrez iTunes. [Identifiez la version de macOS installée sur votre Mac](https://support.apple.com/fr-fr/109033) .

- Utilisez un câble USB pour connecter votre appareil à votre ordinateur.

- Cliquez sur l’onglet Général.

- Cliquez sur le bouton Gérer les sauvegardes.

- Dans la fenêtre iTunes, sélectionnez Édition, puis Préférences sous Windows. Ou, sélectionnez iTunes, puis Préférences.

- Cliquez sur l’onglet Appareils.

- Voyez si un cadenas figure à côté du nom de votre appareil. Si vous voyez un cadenas , c’est que le système a chiffré la sauvegarde. Vous devriez également voir la date et l’heure auxquelles le système a créé la sauvegarde.

[Image: null]

[Image: Liste de sauvegardes d’appareils dans le Finder sur Mac, avec un symbole de cadenas indiquant une sauvegarde chiffrée.]

- Cliquez sur OK pour fermer la fenêtre de sauvegarde.

## Désactiver le chiffrement des sauvegardes

- Décochez la case « Chiffrer la sauvegarde locale » dans la fenêtre du Finder, la fenêtre de l’app Appareils Apple ou la fenêtre iTunes.

- Entrez le mot de passe. Si vous avez oublié votre mot de passe, deux options s’offrent à vous :

- [Effectuez une sauvegarde et une restauration à l’aide d’iCloud](https://support.apple.com/fr-fr/118105) .

- [Réinitialisez le mot de passe de votre sauvegarde](https://support.apple.com/fr-fr/108313) .

## Réinitialiser le mot de passe de votre sauvegarde chiffrée

Vous ne pouvez pas utiliser les sauvegardes chiffrées précédentes, mais le Finder ou iTunes vous permettent de sauvegarder vos données actuelles et de définir un nouveau mot de passe de sauvegarde.

[Découvrez comment réinitialiser votre mot de passe et créer une autre sauvegarde chiffrée](https://support.apple.com/fr-fr/108313)
