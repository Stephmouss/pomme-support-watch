# Supprimer ou désactiver des modules Audio Units dans Logic Pro pour Mac ou MainStage

Lorsque Logic Pro ou MainStage ne fonctionne pas correctement, essayez de supprimer ou de désactiver les modules Audio Units tiers si vous en utilisez.

Suivez les recommandations ci-dessous en fonction du problème que vous rencontrez :

- Si vous parvenez à ouvrir Logic Pro ou MainStage, mais que vous rencontrez des problèmes avec votre projet ou concert, [supprimez des modules Audio Units de votre projet](https://support.apple.com/fr-fr/109315#disable) .

- Si vous ne parvenez pas à ouvrir Logic Pro ou MainStage, [désactivez les modules Audio Units](https://support.apple.com/fr-fr/109315#remove) .

- Si vous ne trouvez pas un module récemment installé, [découvrez ce qu’il faut faire.](https://support.apple.com/fr-fr/122179)

Avant de commencer à dépanner les modules Audio Units, [assurez-vous auprès du fabricant](https://support.apple.com/fr-fr/103190) que le module est compatible avec votre version de macOS et si une mise à jour est disponible.

## Supprimer des modules Audio Units de votre projet ou concert

Si vous rencontrez un problème avec un projet Logic Pro spécifique qui utilise des modules Audio Units, ouvrez d’abord Logic Pro sans les modules Audio Units. Si le problème ne se présente plus, vous pouvez alors supprimer les modules Audio Units un à un de votre projet afin de déterminer si un module spécifique est à l’origine du problème.

Si vous rencontrez un problème avec un concert MainStage, commencez le dépannage en [supprimant un à un les modules Audio Units](https://support.apple.com/fr-fr/109315#removing) du concert.

### Ouvrir Logic Pro sans Audio Units

- Si Logic Pro est ouvert, quittez l’app.

- Ouvrez Logic Pro et maintenez immédiatement la touche Contrôle enfoncée avant que le projet ne s’ouvre.

- Dans le message qui s’affiche, cliquez sur Lancer sans Audio Units.

- Ouvrez le projet que vous dépannez.

Si cela résout le problème, supprimez les modules Audio Units un à un de votre projet Logic Pro.

Si cela ne résout pas le problème, [essayez d’autres méthodes de dépannage](https://support.apple.com/fr-fr/119881) .

### Supprimer un à un les modules Audio Units de votre projet Logic Pro ou de votre concert MainStage

Si le problème ne se présente plus lorsque vous ouvrez Logic Pro sans Audio Units, supprimez chaque module Audio Units de votre projet Logic Pro pour déterminer le module en cause. Vous pouvez également procéder de cette façon pour dépanner les modules Audio Units dans MainStage.

- Si vous avez ouvert Logic Pro sans Audio Units, fermez Logic Pro.

- Ouvrez Logic Pro ou MainStage, puis ouvrez le projet ou le concert avec lequel vous rencontrez des problèmes.

- Enregistrez une copie de votre projet ou de votre concert.

- Fermez le projet ou le concert d’origine.

- Ouvrez la copie du projet ou du concert.

- Choisissez Aucun module dans un emplacement d’effets occupé pour supprimer un module Audio Units.

- Essayez de reproduire le problème.

Si votre problème persiste après avoir supprimé un module, retirez-en un autre, puis lancez le test à nouveau. Faites un test chaque fois que vous retirez un module.

Si la suppression d’un module spécifique résout le problème, réinstallez-le ou vérifiez auprès du fabricant s’il existe une mise à jour ou une assistance disponible. Vous pouvez également remplacer le module par un module similaire d’Apple ou d’un autre fabricant.

## Désactiver les modules Audio Units

Si vous ne parvenez pas à ouvrir Logic Pro ou MainStage, déplacez les fichiers installés des modules Audio Units tiers. Vous pouvez également déplacer un fichier de module si vous constatez qu’un module spécifique est à l’origine d’un problème dans un projet.

- Dans la barre de menus du Finder, choisissez Aller > Aller au dossier, saisissez « /Library/Audio/Plug-Ins/Components » dans le champ Aller au dossier, puis cliquez sur Aller.

- Si vous ne trouvez pas les fichiers à cet emplacement, consultez la bibliothèque de votre dossier de départ. Dans la barre de menus du Finder, choisissez Aller > Aller au dossier, saisissez « ~/Library/Audio/Plug-Ins/Components » dans le champ Aller au dossier, puis cliquez sur Aller.

- Si vous pensez qu’un module spécifique peut être à l’origine du problème, localisez le fichier du module dans le dossier, maintenez la touche Commande appuyée, puis faites-le glisser vers le bureau ou un autre emplacement, tel qu’un dossier dédié à cette procédure.

- Redémarrez votre Mac.

- Essayez de rouvrir Logic Pro.

Si vous ne parvenez toujours pas à ouvrir Logic Pro ou MainStage :

- Créez un dossier sur le bureau.

- Déplacez tous les fichiers de module qui se trouvent à leur emplacement d’installation vers le nouveau dossier. Pour les déplacer, maintenez la touche Commande enfoncée tout en les faisant glisser ou supprimez les fichiers d’origine de leur emplacement d’origine après les avoir déplacés vers le nouvel emplacement.

- Essayez d’ouvrir Logic Pro ou MainStage.

- Si vous parvenez à ouvrir l’app, replacez chaque fichier de module à son emplacement d’origine, un à un. Quittez et rouvrez l’app après avoir replacé chaque fichier de module.

- Si vous ne parvenez pas à ouvrir l’app après avoir replacé un fichier de module spécifique, il est possible que celui-ci soit corrompu ou incompatible. Essayez de réinstaller le module ou vérifiez auprès de son fabricant si une mise à jour est disponible.
