# Lion Server : rediriger des clients vers un serveur de mise à jour de logiciels

Découvrez comment rediriger des clients vers un serveur de mise à jour de logiciels.

Lion Server peut distribuer des mises à jour logicielles aux clients qui exécutent OS X Lion, Mac OS X 10.6 et Mac OS X 10.5.

Lion Server utilise une URL unique qui redirige vers un catalogue propre à chaque version de Mac OS X :

http://su.domain_name.com:8088/index.sucatalog

…dans laquelle su.domain_name.com est remplacé par le nom d’hôte complet du serveur de mise à jour de logiciels, et où 8088 est le port par défaut du service de mise à jour de logiciels. Si vous modifiez le numéro du port associé à la fonctionnalité Mise à jour de logiciels dans Admin Serveur, vous devez également le modifier dans l’URL afin que les deux numéros soient identiques.

Vous pouvez diriger les clients vers votre serveur de mise à jour de logiciels en créant des données utiles Mise à jour de logiciels dans Gestionnaire de profils, en gérant les préférences de mise à jour de logiciels dans Gestionnaire de groupe de travail ou en saisissant la commande suivante directement sur les ordinateurs clients :

sudo defaults write /Library/Preferences/com.apple.SoftwareUpdate CatalogURL URL

Remplacez URL par l’URL du serveur de mise à jour de logiciels, en incluant le numéro du port et le fichier catalogue, comme décrit ci-dessus.
