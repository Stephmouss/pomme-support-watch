# Si vous recevez le message d’alerte « AirPods différents »

Vous pouvez recevoir le message d’alerte « AirPods différents » si les AirPods dans le boîtier de charge ne sont pas de la même génération ou appartiennent à quelqu’un d’autre, ou si le message d’alerte « AirPods différents » apparaît dans l’app Localiser.

## Si les AirPods dans le boîtier de charge ne sont pas de la même génération

- [Identifiez vos AirPods](https://support.apple.com/fr-fr/109525) pour déterminer quels modèles d’AirPods appartiennent à ce boîtier de charge.

- [Utilisez l’app Localiser pour localiser vos AirPods manquants](https://support.apple.com/fr-fr/109020) et diffusez un son pour vous aider à identifier celui qui ne correspond pas.

## Si les AirPods dans le boîtier de charge appartiennent à quelqu’un d’autre

- Si vous avez confondu l’un des AirPods d’une autre personne avec l’un des vôtres, le message d’alerte « AirPods différents » s’affiche sur votre appareil et sur celui de cette même personne. [Utilisez l’app Localiser pour localiser vos AirPods manquants](https://support.apple.com/fr-fr/109020) et diffusez un son pour vous aider à identifier celui qui ne correspond pas.

- Si vous recevez ce message d’alerte après avoir reçu un AirPod ou un boîtier de charge de remplacement, [configurez vos AirPods ou votre boîtier de charge de remplacement](https://support.apple.com/fr-fr/102520) .

## Si le message d’alerte « AirPods différents » apparaît dans l’app Localiser

- Vous pouvez recevoir le message d’alerte « AirPods différents » si vous essayez de jumeler des AirPods qui sont déjà jumelés avec un autre compte Apple. Les AirPods ne peuvent être associés qu’avec un seul compte Apple pour une utilisation avec l’app Localiser.

- Si vous souhaitez utiliser des AirPods que quelqu’un d’autre a utilisés ou des AirPods que vous avez utilisés avec un autre compte Apple, [les AirPods doivent d’abord être supprimés de l’autre compte Apple](https://support.apple.com/fr-fr/102620) .

- Si vous recevez ce message d’alerte après avoir supprimé les AirPods de l’autre compte Apple, [configurez vos AirPods ou votre boîtier de charge de remplacement](https://support.apple.com/fr-fr/102520) .

## Remplacer l’AirPod manquant

Si vous ne parvenez pas à retrouver votre AirPod, vous pouvez [en demander un de remplacement auprès de l’assistance Apple](https://getsupport.apple.com/?caller=kbase&symptom_id=2336) .
