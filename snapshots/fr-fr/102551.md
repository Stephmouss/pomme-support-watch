# Restaurer des données de votre Mac à partir d’une sauvegarde

Utilisez l’Assistant migration pour transférer des fichiers de votre sauvegarde Time Machine vers votre Mac.

Si vous avez effectué une sauvegarde Time Machine de votre Mac, l’Assistant migration peut l’utiliser pour restaurer tous vos fichiers personnels, notamment les apps et tout le contenu de votre compte utilisateur. Si vous préférez ne restaurer que quelques fichiers ou des versions antérieures de ces fichiers, [découvrez comment utiliser Time Machine pour restaurer des fichiers spécifiques](https://support.apple.com/guide/mac-help/mh11422/mac) à la place.

## Utiliser l’Assistant migration

- Si vous devez réinstaller macOS, faites-le avant de continuer. Par exemple, si votre Mac démarre avec un point d’interrogation clignotant, vous devez d’abord réinstaller macOS. [Découvrez comment réinstaller macOS](https://support.apple.com/fr-fr/102655) .

- Vérifiez que votre disque de sauvegarde Time Machine est connecté à votre Mac et qu’il est allumé.

- Ouvrez l’Assistant migration :

- Si votre Mac démarre sur un Assistant réglages demandant des informations comme votre pays et votre réseau, passez à l’étape suivante, car l’Assistant réglages comprend un Assistant migration.

- Si vous avez déjà terminé la configuration initiale de votre Mac, ouvrez l’Assistant migration. Vous pouvez y accéder dans le sous-dossier Utilitaires de votre dossier Applications. Vous pouvez également [utiliser Spotlight](https://support.apple.com/guide/mac-help/mchlp1008/mac) pour le trouver et l’ouvrir. Si on vous demande l’autorisation d’apporter des modifications, saisissez votre mot de passe administrateur.

- Lorsqu’il vous est demandé de sélectionner la méthode de transfert des données, choisissez l’option À partir d’un Mac, de Time Machine ou d’un disque de démarrage. Cliquez ensuite sur Continuer.

[Image: Assistant migration avec l’option « À partir d’un Mac, de Time Machine ou d’un disque de démarrage » sélectionnée.]

- Sélectionnez votre disque de sauvegarde Time Machine. Cela peut prendre quelques instants à apparaître. Cliquez ensuite sur Continuer.

[Image: Assistant migration affichant l’icône sélectionnée d’un disque Time Machine.]

- Sélectionnez une sauvegarde et cliquez sur Continuer. Si l’option Continuer est grisée ou si vous souhaitez utiliser une sauvegarde plus ancienne, cliquez sur la flèche d’expansion à côté de la sauvegarde affichée, puis sélectionnez une sauvegarde.

[Image: null]

[Image: Assistant migration affichant les sauvegardes d’un Mac sur le disque Time Machine sélectionné.]

- L’Assistant migration calcule la quantité d’espace de stockage utilisée par toutes vos informations, y compris les applications, les comptes utilisateur, les fichiers, les dossiers et les réglages. Patientez jusqu’à la fin du calcul.

- Cochez la case à côté de chaque catégorie de fichiers que vous souhaitez transférer. Vous pouvez également cliquer sur la flèche d’expansion à côté d’une catégorie et sélectionner des éléments spécifiques à l’intérieur de celle-ci. Cliquez sur Continuer lorsque vous avez terminé.

[Image: null]

[Image: Assistant migration affichant les différentes catégories d’informations.]

- Dans l’exemple illustré, Danny Rico et Olivia Rico sont des comptes utilisateur.

- Si vous transférez un compte administrateur, vous êtes invité à cliquer sur Définir le mot de passe et à saisir un mot de passe sécurisé. Mémorisez ce mot de passe. Vous en aurez besoin pour vous connecter au compte sur votre Mac.

- Si vous transférez un compte standard, un mot de passe temporaire est attribué et apparaît à l’écran. Notez ce mot de passe. Lorsque l’utilisateur se connecte pour la première fois, il doit saisir ce mot de passe, puis saisir son propre nouveau mot de passe lorsqu’on le lui demande.

[Image: Assistant migration affichant les options de mot de passe pour un compte administrateur et non administrateur.]

- Si un compte avec le même nom existe déjà sur votre Mac, vous devez choisir entre les options suivantes :

- Remplacer le compte sur votre Mac par le compte de la sauvegarde Time Machine. Vous pouvez également avoir la possibilité de conserver une copie des données du compte remplacé en les déplaçant vers le dossier Utilisateurs supprimés, où vous pouvez accéder à ces données ultérieurement.

- Ou renommer l’ancien compte avant de le transférer sur votre Mac. Les deux comptes sont ainsi conservés, afin que vous puissiez vous y connecter séparément sur votre Mac.

[Image: Assistant migration affichant les options de remplacement ou de conservation pour un compte existant.]

- Si on vous demande le mot de passe d’un utilisateur existant déjà autorisé sur votre Mac, cliquez sur Autoriser, puis saisissez le mot de passe de ce compte.

- Les transferts importants peuvent prendre des heures et sembler s’arrêter de temps en temps. Une fois l’opération terminée, quittez l’Assistant migration, puis connectez-vous au compte migré sur votre Mac.
