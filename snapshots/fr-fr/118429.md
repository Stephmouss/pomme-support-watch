# Ajouter un mode de paiement à votre compte Apple

Ajoutez un mode de paiement que vous et votre famille pouvez utiliser pour l’App Store, les abonnements et plus encore. Un mode de paiement peut être requis pour télécharger ou mettre à jour certaines apps gratuites.

## Ajouter un mode de paiement sur votre appareil

Vous pouvez utiliser votre appareil pour ajouter un mode de paiement à votre compte Apple.

### Ajouter un mode de paiement sur votre iPhone

- Dans Réglages, touchez votre nom.

- Touchez Paiement et livraison. Il vous sera peut-être demandé de vous connecter à votre compte Apple.

- Touchez Ajouter un mode de paiement.

[Image: Écran d’iPhone montrant les réglages Paiement et livraison d’un compte Apple. Pour ajouter un mode de paiement, touchez Ajouter un mode de paiement.]

- Saisissez les informations relatives au mode de paiement, puis vérifiez que votre nom, votre adresse de facturation et vos autres informations sont exacts et qu’ils correspondent aux données enregistrées auprès de votre établissement financier.

- Touchez OK.

Si vous avez déjà enregistré un mode de paiement, découvrez comment [modifier ou mettre à jour votre mode de paiement](https://support.apple.com/fr-fr/118293) .

#### Réorganiser les modes de paiement sur votre iPhone

- Sur l’écran Paiement et livraison, touchez Modifier.

- Touchez un mode de paiement et maintenez votre doigt appuyé pour le faire glisser vers le haut ou vers le bas de votre liste de modes de paiement.

- Touchez OK.

### Ajouter un mode de paiement sur votre Mac

- Dans l’App Store, cliquez sur votre nom au bas de la barre latérale. Ou cliquez sur le bouton Connexion et connectez-vous à votre compte Apple.

- Sur la page qui s’affiche, cliquez sur votre nom. Il vous sera peut-être demandé de vous connecter à votre compte Apple.

- Cliquez sur Modes de paiement.

- Cliquez sur Ajouter un mode de paiement.

- Saisissez les informations relatives au mode de paiement, puis vérifiez que votre nom, votre adresse de facturation et vos autres informations sont exacts et qu’ils correspondent aux données enregistrées auprès de votre établissement financier.

- Cliquez sur Terminé.

[Image: Écran d’un Mac affichant les réglages Gérer les paiements dans l’App Store.]

Si vous avez déjà enregistré un mode de paiement, découvrez comment [modifier ou mettre à jour votre mode de paiement](https://support.apple.com/fr-fr/118293) .

#### Réorganiser les modes de paiement sur votre Mac

- Sur l’écran Gérer les paiements, cliquez sur Modifier.

- Cliquez de manière prolongée sur un mode de paiement pour le faire glisser vers le haut ou le bas de votre liste de modes de paiement.

- Cliquez sur Terminé.

### Ajouter un mode de paiement sur votre PC Windows

- Ouvrez l’app Musique ou l’app Apple TV.

- Cliquez sur votre nom en bas de la barre latérale. Ou, cliquez sur Se connecter, puis connectez-vous à votre compte Apple.

- Cliquez sur Voir mon compte. Vous devrez peut-être vous connecter à votre compte Apple.

[Image: Écran Windows montrant l’app Apple Music. Pour gérer votre mode de paiement, cliquez sur votre nom en bas de la barre latérale, puis cliquez sur Voir mon compte.]

- Cliquez sur Gérer les paiements en regard de l’intitulé Mode de paiement.

- Cliquez sur Ajouter un mode de paiement.

[Image: Écran Windows montrant les réglages Gérer les paiements dans l’app Apple Music. Pour ajouter un mode de paiement, cliquez sur Ajouter un mode de paiement.]

- Saisissez les informations relatives au mode de paiement, puis vérifiez que votre nom, votre adresse de facturation et vos autres informations sont exacts et qu’ils correspondent aux données enregistrées auprès de votre établissement financier.

- Cliquez sur Terminé.

Si vous avez déjà enregistré un mode de paiement, découvrez comment [modifier ou mettre à jour votre mode de paiement](https://support.apple.com/fr-fr/118293) .

#### Réorganiser les modes de paiement sur votre PC Windows

Sur l’écran Gérer les paiements, utilisez les flèches situées à côté de chaque mode de paiement pour le déplacer vers le haut ou le bas de votre liste de modes de paiement.

## Ajouter un mode de paiement en ligne

Vous pouvez également ajouter un mode de paiement lorsque vous vous connectez à [account.apple.com](https://account.apple.com) .

## Si vous ne parvenez pas à ajouter un mode de paiement

- Assurez-vous que votre nom, votre adresse de facturation et vos autres informations sont exacts et qu’ils correspondent aux données enregistrées auprès de votre établissement financier.

- Vérifiez les différents [modes de paiement possibles avec votre compte Apple](https://support.apple.com/fr-fr/111741) dans votre pays ou région.

- Si vous utilisez un mode de paiement autorisé, mais que votre compte Apple est associé à une zone géographique différente de la vôtre, [modifiez votre pays ou votre région en conséquence](https://support.apple.com/fr-fr/118283) .

- Certains modes de paiement nécessitent une vérification via l’app de votre banque, l’envoi d’un SMS ou tout autre moyen. Contactez votre banque pour obtenir de l’aide si vous ne parvenez pas à effectuer cette vérification.
