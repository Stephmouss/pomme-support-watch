# Ajouter davantage de langues pour vos listes de courses dans Rappels sous iOS

Vous utilisez plusieurs langues sur votre téléphone ? Activer une autre langue dans Rappels pour vos listes de courses aide Rappels à mieux trier automatiquement les produits et ingrédients.

Après avoir ajouté des langues supplémentaires pour vos listes de courses sous iOS 18, Rappels est mieux à même de reconnaître les aliments et de les trier automatiquement lorsque vous utilisez les listes de courses.

## Sélectionner une langue supplémentaire pour la catégorisation des courses

- Dans Paramètres, touchez Apps.

- Touchez Rappels.

- Touchez Ajouter une langue sous Catégorisation des courses.

[Image: Sous iOS 26, vous pouvez ajouter des langues supplémentaires pour la catégorisation des courses dans Rappels.]

- Sélectionnez Définir automatiquement pour votre iPhone afin choisir une langue en fonction de votre emplacement et de vos réglages de clavier, de langue et de région. Vous pouvez également désactiver ce réglage et toucher Langues afin de sélectionner des langues spécifiques pour vos listes de courses.

Pour pouvoir ajouter une langue pour la catégorisation des courses, vous devez disposer d’un iPhone doté d’iOS 18. Dans un premier temps, les seules options de langue disponibles sont les suivantes : chinois simplifié, français, allemand, japonais, coréen, espagnol (Amérique latine) et espagnol (Espagne).

[Créer des listes de courses dans Rappels sur votre iPhone](https://support.apple.com/105086)
