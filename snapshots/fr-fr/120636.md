# Si vous ne parvenez pas à créer un compte Apple ou si vous voyez le message « Impossible de créer votre compte pour le moment »

Découvrez la marche à suivre si vous ne parvenez pas à créer un compte Apple. Vous pouvez réessayer plus tard ou essayer une autre méthode pour créer un compte Apple.

## Si ce n’est pas le premier compte Apple que vous essayez de créer

Si vous avez déjà un compte Apple et que vous essayez de créer un autre compte, il existe des solutions alternatives en fonction de ce que vous essayez de faire.

- Si vous essayez de créer un compte parce que vous avez oublié le mot de passe associé à votre compte Apple, [réinitialisez votre mot de passe](https://support.apple.com/fr-fr/102656) .

- Si vous essayez de créer un compte Apple et que vous voyez un message indiquant que l’adresse e-mail ou le numéro de téléphone n’est pas disponible ou ne peut pas être utilisé, cela signifie qu’un compte Apple existant l’utilise déjà. Essayez une autre adresse e-mail ou un autre numéro de téléphone, ou [réinitialisez le mot de passe](https://support.apple.com/fr-fr/102656) de ce compte.

- Si vous essayez de créer un compte Apple pour un enfant, [optez plutôt pour le partage familial](https://support.apple.com/fr-fr/102617) .

- Si vous essayez de configurer plusieurs comptes pour une entreprise ou des membres du personnel, [découvrez comment utiliser les comptes Apple gérés dans Apple Business](https://support.apple.com/guide/business/axm78b477c81) .

## Si le problème persiste

Si vous ne parvenez pas à créer votre compte Apple, vous pouvez essayer de suivre ces étapes.

### Utiliser un appareil Apple ou une app Apple

Si vous possédez un appareil Apple, créez votre compte sur cet appareil, dans Réglages ou Réglages Système. Si vous avez un PC Windows ou un appareil Android, essayez de créer votre compte sur le Web à l’adresse [account.apple.com](https://account.apple.com) .

### Installer la dernière version logicielle

Votre appareil Apple ou votre app Apple n’est peut-être pas à jour.

- [Installez la dernière version d’iOS ou d’iPadOS.](https://support.apple.com/fr-fr/118575)

- [Installez la dernière version de macOS.](https://support.apple.com/fr-fr/108382)

- Sur votre PC Windows ou votre téléphone Android, mettez à jour le système d’exploitation et vérifiez si des mises à jour sont disponibles pour vos apps Apple

### S’il s’agit de votre premier compte Apple

Si vous voyez toujours le message « Impossible de créer votre compte pour le moment » sur un appareil doté d’un logiciel à jour, [obtenez des suggestions](https://getsupport.apple.com/?caller=kbase) sur ce que vous pouvez tenter d’effectuer ensuite.

### Vérifier votre connexion Internet

Vérifiez que vous pouvez ouvrir des pages web dans le navigateur web de votre appareil. Si vous y parvenez, réessayez de créer un compte Apple plus tard. Vous pouvez aussi essayer de vous connecter au réseau de données mobiles ou à un autre réseau Wi-Fi s’il y en a un de disponible. Vous pouvez également vérifier si une panne est en cours dans votre pays ou votre région.

[Consultez la page État du système d’Apple.](https://www.apple.com/fr/support/systemstatus/)
