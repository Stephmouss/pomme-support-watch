# Que se passe-t-il après avoir sélectionné l’option Se déconnecter sans effacer ?

Découvrez quelles informations restent sur votre appareil et ce qui se passe après la reconnexion à votre compte Apple lorsque vous sélectionnez Se déconnecter sans effacer sur votre iPhone ou iPad.

- [Quelles données restent sur votre appareil lorsque vous sélectionnez l’option Se déconnecter sans effacer ?](https://support.apple.com/fr-fr/122682#data_on_device)

- [Comment conserver les données iCloud qui n’ont pas été synchronisées ?](https://support.apple.com/fr-fr/122682#keep_unsynced_data)

- [Que se passe-t-il lorsque vous fusionnez des données iCloud ?](https://support.apple.com/fr-fr/122682#merge_icloud_data)

## Quelles données restent sur votre appareil lorsque vous sélectionnez l’option Se déconnecter sans effacer ?

Si vous souhaitez vous déconnecter de votre compte Apple sur votre iPhone, mais que vous prévoyez de garder l’appareil pour vous, vous pouvez sélectionner l’option Se déconnecter sans effacer. Cela vous permet de vous déconnecter de votre compte Apple sans effacer votre appareil afin que vous puissiez vous reconnecter plus rapidement.

Lorsque vous choisissez cette option, la plupart des données restent sur votre appareil, y compris les suivantes :

- Santé

- Passwords

- Contacts

- Photos

- Documents

- Apps

- Signets

- Cartes, billets et coupons dans Cartes

- Données qui n’ont pas encore été synchronisées avec iCloud

Pour supprimer toutes ces données de votre appareil lorsque vous vous déconnectez de votre compte Apple, choisissez plutôt Effacer cet iPhone.

Pour éviter toute perte de données, assurez-vous de disposer d’une [sauvegarde iCloud](https://support.apple.com/fr-fr/108366) à jour avant de vous déconnecter. Si vous avez récemment apporté des modifications au contenu synchronisé avec iCloud, attendez avant de vous déconnecter ou utilisez le site [icloud.com](https://www.icloud.com/) ou un autre appareil pour vous assurer que vos modifications sont synchronisées.

[En savoir plus sur les éléments sauvegardés par iCloud](https://support.apple.com/fr-fr/108770)

## Comment conserver les données iCloud qui n’ont pas été synchronisées ?

Dans certains cas, vous pouvez recevoir un avertissement indiquant que les données qui n’ont pas encore été synchronisées avec iCloud seront supprimées de l’appareil si vous choisissez Se déconnecter sans effacer. Si vous recevez cet avertissement :

- Assurez-vous de disposer d’une bonne connexion Wi-Fi.

- [Vérifiez que vous n’avez pas dépassé votre quota de stockage iCloud](https://support.apple.com/guide/icloud/mm039c13d410/) . Si vous l’avez dépassé, [découvrez comment libérer de l’espace](https://support.apple.com/fr-fr/108922) .

- Ouvrez l’app Réglages, touchez votre nom, puis touchez iCloud.

- Vérifiez que l’icône d’état à côté d’Enregistré sur iCloud est verte. Si elle est jaune ou rouge, vérifiez le message d’état, puis suivez les instructions à l’écran pour reprendre la synchronisation.

- Utilisez le site [icloud.com](https://www.icloud.com/) ou un autre appareil pour vous assurer que vos modifications sont synchronisées.

Vous pouvez également [archiver ou effectuer des copies de ces données iCloud](https://support.apple.com/fr-fr/108306) avant de vous déconnecter.

## Que se passe-t-il lorsque vous fusionnez des données iCloud ?

Si le propriétaire précédent ou la propriétaire précédente de l’appareil a sélectionné l’option Se déconnecter sans effacer et que vous vous connectez à cet appareil avec votre compte Apple, les données de l’appareil sont fusionnées avec vos données iCloud, puis synchronisées avec vos autres appareils.

Si vous ne souhaitez pas fusionner vos données iCloud avec les données du propriétaire précédent ou de la propriétaire précédente de l’appareil, touchez Revenir sur l’écran « Voulez-vous fusionner vos données iCloud et les données de cet [appareil] ? ». Pour supprimer les données laissées par le propriétaire précédent ou la propriétaire précédente de l’appareil, touchez Continuer sur l’écran « Les données précédentes seront supprimées de cet iPhone ».
