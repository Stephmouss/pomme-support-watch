# Connexion aux services AFP hérités

Découvrez comment activer les méthodes d’authentification héritées pour le client AFP sous OS X Lion ou versions ultérieures, afin de pouvoir vous connecter à des serveurs AFP plus anciens.

Les méthodes d’authentification plus anciennes et moins sécurisées ne sont pas activées par défaut dans OS X Lion et versions ultérieures. Vous pouvez activer une ou plusieurs de ces méthodes pour prendre en charge les appareils ou les protocoles hérités en procédant comme suit :

1. Ouvrez Terminal.

2. Exécutez les commandes suivantes :

sudo chmod o+w /Library/Preferences sudo defaults write /Library/Preferences/com.apple.AppleShareClient afp_host_prefs_version -int 1

3. Établissez une connexion AFP avec un autre système afin que le fichier de préférences du client AFP soit rempli avec l’ensemble de valeurs par défaut. Remarque : vous devez vous connecter en tant qu’utilisateur ou utilisatrice enregistré(e), et non en tant qu’invité(e).

4. Exécutez la commande suivante pour obtenir la liste des méthodes d’authentification utilisateur (UAM) désactivées :

defaults read /Library/Preferences/com.apple.AppleShareClient afp_disabled_uams

5. Par défaut, les UAM désactivées sont « Cleartxt Passwrd », « MS2.0 », « 2-Way Randnum exchange » et « DHCAST128 ». Remarque : si aucune liste ne s’affiche, redémarrez votre ordinateur et répétez l’étape 3.

6. Pour activer l’une de ces UAM, supprimez-la de la liste des UAM désactivées. Par exemple, cette commande active DHCAST128 en le supprimant de la liste des méthodes d’authentification désactivées :

sudo defaults write /Library/Preferences/com.apple.AppleShareClient afp_disabled_uams -array "Cleartxt Passwrd" "MS2.0" "2-Way Randnum exchange"

7. Une fois les modifications souhaitées effectuées, restaurez les autorisations dans le dossier « Preferences » à l’aide de cette commande :

sudo chmod o-w /Library/Preferences

## Informations supplémentaires

Si vous souhaitez annuler les modifications décrites ci-dessus, vous pouvez supprimer le fichier /Library/Preferences/com.apple.AppleShareClient ou utiliser la commande suivante pour réactiver l’ensemble par défaut des anciennes UAM :

sudo defaults write /Library/Preferences/com.apple.AppleShareClient afp_disabled_uams -array "Cleartxt Passwrd" "MS2.0" "2-Way Randnum exchange" "DHCAST128"
