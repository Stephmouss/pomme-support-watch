# Réinitialiser votre iPad et votre code d’accès à l’aide de votre Mac ou de votre PC

À l’aide d’un ordinateur, placez votre iPad en mode de récupération pour pouvoir effacer ses données et le configurer à nouveau.

Si vous l’avez oublié, commencez par essayer de [réinitialiser votre code d’accès](https://support.apple.com/105039) . Si vous ne pouvez pas utiliser la fonctionnalité Réinitialisation du code, vous pouvez [réinitialiser votre iPhone ou votre iPad sans ordinateur](https://support.apple.com/105090) afin de récupérer l’accès à votre appareil Apple. Enfin, si vous ne pouvez pas utiliser la fonctionnalité Réinitialisation du code, et que vous ne pouvez pas réinitialiser votre iPhone ou votre iPad directement sur l’appareil, vous pouvez réinitialiser votre iPhone ou iPad à l’aide d’un ordinateur.

## Éléments requis

- Mac ou PC Windows

- Câble permettant de charger votre iPad

- Connexion Internet

- Jusqu’à 60 minutes

Ce processus supprime vos données et vos réglages, y compris votre code d’accès, et vous permet ainsi de configurer à nouveau votre iPad.

## Éteignez votre iPad

- Débranchez votre iPad de l’ordinateur, s’il est connecté.

- Éteignez votre iPad en suivant la méthode correspondant à votre modèle :

- Si votre iPad ne possède pas de bouton principal, appuyez simultanément sur l’un des boutons de volume et sur le bouton supérieur jusqu’à ce que le curseur Éteindre apparaisse. [Lecture](https://support.apple.com/fr-fr/119858) [Pause](https://support.apple.com/fr-fr/119858) [Relancer](https://support.apple.com/fr-fr/119858)

- Si votre iPad est doté d’un bouton principal, appuyez sur le bouton supérieur jusqu’à ce que le curseur Éteindre apparaisse. [Lecture](https://support.apple.com/fr-fr/119858) [Pause](https://support.apple.com/fr-fr/119858) [Relancer](https://support.apple.com/fr-fr/119858)

- Faites glisser le curseur pour éteindre votre iPad, puis patientez une minute pour vous assurer qu’il est complètement éteint.

## Mettez votre iPad en mode de récupération

- Connectez votre iPad à votre ordinateur à l’aide d’un câble USB.

- Gardez votre iPad connecté et appuyez sur les boutons suivants en fonction de votre modèle d’iPad :

- Pour les modèles d’iPad sans bouton principal : appuyez brièvement sur le bouton de volume le plus proche du bouton du haut. Appuyez brièvement sur le bouton de volume le plus éloigné du bouton du haut. Maintenez le bouton supérieur enfoncé. [Lecture](https://support.apple.com/fr-fr/119858) [Pause](https://support.apple.com/fr-fr/119858) [Relancer](https://support.apple.com/fr-fr/119858)

- Sur les modèles d’iPad avec bouton principal : maintenez le bouton principal et le bouton supérieur (ou latéral) enfoncés. [Lecture](https://support.apple.com/fr-fr/119858) [Pause](https://support.apple.com/fr-fr/119858) [Relancer](https://support.apple.com/fr-fr/119858)

- Maintenez le bouton enfoncé lorsque le logo Apple apparaît. Ne relâchez pas le bouton avant qu’une image représentant un ordinateur et un câble ne soit apparue, puis relâchez-le.

- Si l’écran du code d’accès s’affiche, vous devez éteindre votre iPad et recommencer.

Si vous devez réinitialiser votre iPad avec un ordinateur, que vous n’en avez pas et que vous ne pouvez pas en emprunter, vous pouvez vous rendre dans [un magasin Apple Store ou un centre de services agréé Apple](https://locate.apple.com/) pour obtenir de l’aide.

## Restaurez votre iPad

- Localisez votre iPad dans le Finder ou dans l’app Appareils Apple sur l’ordinateur auquel il est connecté. (Découvrez comment [localiser votre iPad connecté](https://support.apple.com/108392) .)

- Choisissez Restaurer sur l’écran vous invitant à procéder à une restauration ou à une mise à jour. Votre ordinateur télécharge le logiciel adapté à votre iPad et lance le processus de restauration. Si le téléchargement dure plus de 15 minutes et que votre appareil quitte l’écran du mode de récupération, laissez le téléchargement se terminer, puis éteignez votre iPad et recommencez.

[Image: Option de restauration ou de mise à jour lorsque vous connectez votre iPad à un ordinateur doté de macOS Ventura]

- Attendez que le processus se termine.

Si vous utilisez un PC Windows pour réinitialiser votre iPad, l’app Appareils Apple doit être installée. [Procurez-vous l’app Appareils Apple sur le Microsoft Store](https://apps.microsoft.com/detail/9np83lwlpz9k) et [découvrez comment restaurer votre iPad à l’aide de cette app](https://support.apple.com/guide/devices-windows/restore-your-device-to-factory-settings-mchl21d802fe/1.4/windows/10) sur votre PC Windows.

## Suivez les instructions à l’écran pour configurer votre iPad

Une fois le processus de restauration terminé, l’écran Bonjour apparaîtra sur votre iPad. Déconnectez votre iPad de l’ordinateur, puis [configurez et utilisez votre iPad.](https://support.apple.com/fr-fr/105132)
