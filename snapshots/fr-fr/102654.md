# Vous connecter à des apps avec votre compte Apple en utilisant des mots de passe pour applications

Les mots de passe pour applications vous permettent de vous connecter à votre compte Apple dans des apps créées par des développeurs autres qu’Apple.

Certaines apps créées par des développeurs autres qu’Apple vous demandent de vous connecter avec votre compte Apple pour pouvoir accéder à des informations telles que les e-mails, les contacts et les calendriers que vous stockez dans iCloud. Pour éviter que le mot de passe de votre compte Apple ne soit stocké ou collecté par ces applications, vous pouvez choisir de créer un mot de passe pour votre compte Apple à n’utiliser qu’avec ces applications.

Ce mot de passe pour application est à utiliser lorsque les applications vous demandent de vous connecter avec votre compte Apple.

Pour générer et utiliser des mots de passe pour applications, votre compte Apple doit être protégé par l’ [identification à deux facteurs](https://support.apple.com/fr-fr/102660) .

Pour les apps tierces prises en charge qui accèdent à votre messagerie, votre calendrier et vos contacts iCloud, vous pouvez [autoriser l’app à l’aide de votre compte Apple](https://support.apple.com/fr-fr/121539) au lieu d’utiliser un mot de passe pour application.

## Générer un mot de passe pour application

- Connectez-vous à votre compte Apple sur [account.apple.com](https://account.apple.com) .

- Dans la section Connexion et sécurité, sélectionnez Mots de passe pour applications.

- Sélectionnez Générer un mot de passe pour application, puis suivez les étapes à l’écran.

Saisissez ou collez le mot de passe pour application dans le champ du mot de passe de l’application lors de la connexion à votre compte Apple.

## Révoquer un mot de passe pour application

25 mots de passe pour application peuvent être actifs en même temps. Si nécessaire, vous pouvez révoquer ces derniers individuellement ou globalement.

- Connectez-vous à [account.apple.com](https://account.apple.com) .

- Dans la section Connexion et sécurité, sélectionnez Mots de passe pour applications.

- Sélectionnez le bouton Supprimer à côté du mot de passe que vous souhaitez supprimer ou sur Tout révoquer.

[Image: signe moins dans un cercle.]

Une fois un mot de passe désactivé, l’app à laquelle il est associé est déconnectée de votre compte, tant qu’un nouveau mot de passe n’est pas créé et que vous ne vous connectez pas à nouveau.

Chaque fois que vous modifiez ou réinitialisez le mot de passe principal de votre compte Apple, tous vos mots de passe pour applications sont automatiquement révoqués pour protéger la sécurité de votre compte. Vous devez alors créer un nouveau mot de passe pour application pour les apps pour lesquelles vous souhaitez continuer à utiliser ce type de mot de passe.
