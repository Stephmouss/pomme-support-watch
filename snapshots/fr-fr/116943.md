# Ordinateurs Mac avec puce Apple

À partir de certains modèles commercialisés fin 2020, Apple a entamé la transition des processeurs Intel vers la puce Apple sur les ordinateurs Mac.

Les modèles de Mac suivants sont équipés d’une puce Apple :

- [MacBook Neo](https://support.apple.com/fr-fr/126322)

- [MacBook Pro](https://support.apple.com/fr-fr/108052) commercialisés à partir de 2021, plus MacBook Pro (13 pouces, M1, 2020)

- [MacBook Air](https://support.apple.com/fr-fr/102869) commercialisés à partir de 2022, plus MacBook Air (M1, 2020)

- [iMac](https://support.apple.com/fr-fr/108054) commercialisés à partir de 2021

- [Mac mini](https://support.apple.com/fr-fr/102852) commercialisés à partir de 2020

- [Mac Studio](https://support.apple.com/fr-fr/102231) commercialisés à partir de 2022

- [Mac Pro](https://support.apple.com/fr-fr/102887) commercialisés en 2023

Sur un ordinateur Mac avec puce Apple, la fenêtre À propos de ce Mac affiche un élément intitulé Puce, suivi du nom de la puce. Vous pouvez ouvrir la fenêtre À propos de ce Mac à partir du menu Apple  dans l’angle de votre écran.

Un Mac avec un processeur Intel n’est pas un Mac avec une puce Apple. Sur un Mac équipé d’un processeur Intel, la fenêtre À propos de ce Mac affiche un élément intitulé Processeur, suivi du nom d’un processeur Intel.
