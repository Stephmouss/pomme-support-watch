# Réception d’une alerte ‘getIGDPortmaps’ dans OS X Server

Utilisez ces commandes Terminal si vous recevez des messages mentionnant « IGD » lorsque vous essayez d’administrer un appareil AirPort.

Si vous avez effectué une mise à niveau à partir d’une version antérieure d’OS X Server, un message d’alerte peut s’afficher dans Server.app lorsque vous essayez de configurer un appareil AirPort :

« Une erreur s’est produite sur le serveur lors du traitement d’une commande. L’erreur s’est produite lors du traitement d’une commande de type 'getIGDPortmaps' dans le plug-in 'servermgr_network' ».

Vous pouvez également voir une répétition de messages dans le journal système, par exemple :

servermgrd[2594] : impossible de se connecter à IGD, aucune information sur l’état n’est disponible, l’erreur est Error Domain=com.apple.ACPDevice Code=-6753 « Impossible de terminer l’opération. (com.apple.ACPDevice error -6753.) »

Si ce message d’alerte vous empêche d’administrer votre appareil AirPort à partir de Server.app, utilisez les commandes Terminal suivantes :

sudo /usr/libexec/PlistBuddy -c "delete :managedIGD" /Library/Server/Network/Config/autoportmap.plist sudo /usr/libexec/PlistBuddy -c "delete :lastIGD" /Library/Server/Network/Config/autoportmap.plist

Après avoir saisi ces commandes, ces messages ne devraient plus apparaître.
