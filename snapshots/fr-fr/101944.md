# Quand et comment utiliser le mode diagnostic avec l’iPhone et l’iPad

Le mode diagnostic fait partie de l’Assistant de récupération pour l’iPhone et l’iPad. Le mode diagnostic vous permet de rechercher d’éventuels problèmes matériels ou logiciels sur votre appareil ou de finaliser une réparation pour une pièce remplacée.

## En savoir plus sur le mode diagnostic

Le mode diagnostic vous permet d’exécuter des tests pour vérifier si le matériel et le logiciel de votre appareil fonctionnent correctement. Il vous guide pendant des tests pour des composants comme l’écran, l’appareil photo et Face ID. Vous pouvez l’utiliser pour résoudre un problème spécifique ou pour finaliser la réparation d’une pièce qui a été remplacée.

## Éléments requis

L’Assistant de récupération et le mode diagnostic sont disponibles sur les appareils suivants :

- Modèles d’iPhone 14 et ultérieurs

- iPad Pro M4 et modèles ultérieurs

- iPad Air M2 et modèles ultérieurs

- iPad mini (A17 Pro)

- iPad (A16)

Pour utiliser le mode diagnostic, votre appareil doit avoir accès à un réseau Wi-Fi.

## Démarrer le mode diagnostic

- Démarrez l’Assistant de récupération en éteignant votre appareil, puis en appuyant de façon prolongée le bouton latéral lorsque votre appareil démarre.

- Touchez Mode diagnostic.

[En savoir plus sur l’Assistant de récupération](https://support.apple.com/fr-fr/123114)

## En savoir plus sur les tests

Vous pouvez exécuter les tests suivants en mode diagnostic.

### Mobile Resource Inspector

Mobile Resource Inspector est un premier outil de tri qui vérifie la version logicielle de l’appareil, la présence de certaines pièces et si les pièces réussissent les tests de fonctionnalité de base.

### Audio

Tenez compte de votre environnement avant d’exécuter ce test ; votre appareil émettra des sonneries de test fortes par les haut-parleurs.

Ce test vous demande de vérifier que vous entendez certaines sonneries et qu’elles ne sont pas déformées. Ensuite, pour confirmer que chaque microphone peut détecter le son, le test vous demande d’enregistrer un court extrait audio. L’enregistrement est utilisé uniquement pendant le test et est supprimé après le test.

### Anomalies de pixels de l’écran

Ce test permet d’identifier les anomalies de pixels et d’autres problèmes liés à la dalle de l’écran. Le test affiche une série de couleurs et de motifs :

- Pour chaque couleur ou motif, dessinez ou touchez l’écran pour indiquer si vous voyez des anomalies. Si vous marquez une zone par accident, touchez le rectangle pour le supprimer.

- Balayez l’écran vers la gauche avec deux doigts pour passer à chaque couleur et motif.

- Lorsque vous avez terminé, appuyez sur Terminé.

Si vous souhaitez quitter le test, appuyez sur le bouton latéral ou sur l’un des boutons de volume.

### Multi-Touch

Un étui ou un protège-écran pourrait interférer avec ce test ; si vous avez un étui ou un protège-écran, retirez-le avant de commencer le test.

Ce test permet d’identifier les problèmes de réponse du Multi-Touch :

- Faites glisser votre doigt sur la totalité de l’écran pour identifier les zones de l’écran qui ne répondent pas correctement au toucher.

- Pendant que vous faites glisser votre doigt, des rectangles bleus apparaissent sur l’écran, indiquant les zones qui répondent au toucher.

### Face ID

Ce test vérifie les capteurs Face ID.

- Tenez l’appareil à bout de bras, face à vous, jusqu’à la fin du test.

- Ce test peut prendre environ une minute. Vous n’avez pas besoin de rester immobile ni de regarder l’appareil pendant le test.

Le test ne prend pas de photo et les numérisations ne sont pas enregistrées.

### Qualité d’image de l’appareil photo

Ce test permet d’identifier les problèmes de qualité d’image des appareils photo avant et arrière.

- Le test vous demandera de prendre une photo avec chaque appareil photo. Pour évaluer la qualité de l’image, utilisez une feuille de papier ou un mur blanc uni, ou une charte de test photo.

- Après avoir pris une photo, indiquez tout problème de qualité de l’appareil photo en dessinant ou en touchant le problème avec votre doigt. Si vous marquez accidentellement une zone de la photo, touchez le rectangle pour la supprimer.

Toutes les photos prises pour ce test n’apparaissent que pendant le test et ne sont pas enregistrées.

## Si le mode diagnostic détecte un problème

Si le mode diagnostic détecte un problème, une réparation peut être nécessaire. [Obtenir une réparation](https://getsupport.apple.com/?caller=kbase) .

Lors de l’évaluation de votre appareil, le centre de services peut exécuter des tests supplémentaires ou réexécuter un ou plusieurs tests.
