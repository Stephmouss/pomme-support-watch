# Serveur de mise à jour logicielle : la ligne de commande est requise pour trouver et installer les mises à jour logicielles sur les clients d’un réseau fermé

Il est possible que les mises à jour logicielles ne s’affichent pas dans le Mac App Store sur les clients d’un environnement réseau fermé.

Une connexion Internet active est nécessaire pour que le Mac App Store affiche les mises à jour logicielles. Si un client se trouve dans un environnement réseau fermé, le message d’alerte suivant peut s’afficher lors d’une recherche des mises à jour disponibles : « L’App Store ne peut vérifier une connexion sécurisée avec l’App Store ». Si vous cliquez sur Continuer, la sous-fenêtre Mises à jour s’affiche sans aucune mise à jour, avec le message, « Connexion à l’App Store impossible ».

Pour distribuer des mises à jour aux Mac connectés à un réseau fermé :

- Configurez un serveur local de mise à jour logicielle à l’aide d’OS X Server.

- [Redirigez](http://support.apple.com/HT4069) vos Mac vers votre serveur de mise à jour logicielle.

- Pour installer les mises à jour logicielles, utilisez l’outil de ligne de commande softwareupdate sur chaque client Mac.
