# Si le trousseau iCloud ne s’active pas ou ne se synchronise pas

Découvrez la marche à suivre si vous ne voyez pas les éléments de votre trousseau, si Safari n’enregistre pas votre mot de passe ou si vous avez besoin d’aide pour le remplissage automatique.

[Consultez la page État du système pour déterminer si une panne est survenue](https://www.apple.com/fr/support/systemstatus/) . Si le système ne connaît aucune panne, essayez les étapes qui correspondent au problème rencontré :

- [Si vous ne voyez pas les éléments de votre trousseau iCloud](https://support.apple.com/fr-fr/102441#missing)

- [Si Safari n’enregistre pas ou ne renseigne pas automatiquement les informations de vos comptes alors que le trousseau iCloud est activé](https://support.apple.com/fr-fr/102441#save)

- [Si Safari n’enregistre pas votre mot de passe pour un site web](https://support.apple.com/fr-fr/102441#password)

## Si vous ne voyez pas les éléments de votre trousseau iCloud

Il existe plusieurs raisons pour lesquelles vous pourriez ne pas être en mesure de trouver les informations de votre trousseau iCloud.

### Vous avez effectué une restauration à partir d’une sauvegarde iCloud, puis constaté que des éléments du trousseau iCloud étaient manquants ?

Les éléments du trousseau iCloud ne font pas partie de la sauvegarde iCloud parce qu’ils sont régulièrement synchronisés avec iCloud. Pour voir si vous avez activé le trousseau iCloud :

- Sur iPhone ou iPad : ouvrez l’app Réglages, touchez [votre nom], puis touchez iCloud. Sous Enregistré sur iCloud, touchez Mots de passe. Sous iOS 17 ou version antérieure, touchez Mots de passe et trousseau. Assurez-vous d'avoir activé la fonctionnalité Synchroniser cet [appareil].

- Sur Mac : choisissez le menu Apple , cliquez sur Réglages Système, sur votre nom, puis sur iCloud. Cliquez sur Mots de passe. Sous macOS Sonoma ou version antérieure, cliquez sur Mots de passe et trousseau. Assurez-vous que vous avez activé la fonctionnalité Synchroniser ce Mac.

### Vous avez désactivé le trousseau iCloud sur tous vos appareils ?

Si tel est le cas, votre trousseau iCloud a été supprimé du cloud. Si, au moment où vous désactivez le trousseau iCloud, vous choisissez de supprimer de vos appareils les éléments contenus dans le trousseau, ce dernier est également supprimé des appareils. Vous devez [configurer le trousseau iCloud](https://support.apple.com/fr-fr/109016) et ajouter à nouveau les éléments.

### Sur votre Mac, avez-vous utilisé Trousseaux d’accès pour réinitialiser votre trousseau iCloud ?

Si tel est le cas, macOS a supprimé les éléments de votre trousseau iCloud. Essayez de configurer à nouveau le trousseau iCloud. Avant toute nouvelle réinitialisation du trousseau Mac, désactivez temporairement le trousseau macOS dans les réglages iCloud.

## Si le trousseau iCloud est activé, mais que Safari n’enregistre pas ou ne renseigne pas automatiquement les informations de compte ou de carte de crédit

Si Safari ne renseigne pas automatiquement vos noms de compte, mots de passe, clés d’accès ou informations de carte de crédit, ou ne vous demande pas de les enregistrer, assurez-vous que vos appareils sont dotés des dernières versions d’iOS, d’iPadOS et de macOS.

Si le problème persiste, vérifiez les réglages Remplissage automatique et Navigation privée sur votre appareil :

### Sur votre iPhone ou iPad

- Pour les noms de compte et les mots de passe : ouvrez l’app Réglages, touchez Général, puis Remplissage automatique et mots de passe. Sous iOS 17 ou version antérieure, accédez à Réglages, touchez Mots de passe, puis Options des mots de passe. Ensuite, vérifiez que vous avez activé « Remplir automatiquement les mots de passe et les clés d’accès ».

- Pour les informations de carte de crédit : ouvrez l’app Réglages, faites défiler l’écran vers le bas et touchez Apps, touchez Safari, puis touchez Remplissage auto. Sous iOS 17 ou version antérieure, accédez à Réglages, touchez Safari, puis touchez Remplissage auto. Vérifiez que vous avez activé « Cartes de crédit ».

- Pour désactiver le mode Navigation privée : ouvrez Safari. Si la barre de navigation de Safari est noire ou sombre, et non blanche ou gris clair, [désactivez la navigation privée](https://support.apple.com/fr-fr/105030) . Lorsque le mode Navigation privée est activé, Safari n'enregistre pas les noms de compte ni les mots de passe.

Vous avez toujours besoin dʼaide pour remplir automatiquement les informations de carte de crédit ? Dans Safari, touchez le champ de saisie des informations de carte de crédit, puis touchez l’option Remplir autom. la carte au-dessus du clavier.

### Sur votre Mac

- Sélectionnez Safari, cliquez sur Réglages, puis sur Remplissage automatique.

- Assurez-vous que l’option « les noms et mots de passe d’utilisateurs » est sélectionnée. Pour les informations de carte de crédit, vérifiez que l’option « Cartes bancaires » est sélectionnée.

- [Vérifiez si le mode Navigation privée est activé](https://support.apple.com/guide/safari/ibrw1069) . Safari n’enregistre pas les noms de compte ni les mots de passe lorsque la navigation privée est activée.

Vous avez toujours besoin dʼaide pour remplir automatiquement les informations de carte de crédit ? Dans Safari, cliquez sur un champ de carte de crédit pour afficher le message vous demandant de choisir la carte de crédit à utiliser à partir de votre trousseau iCloud.

## Si Safari n’enregistre pas le mot de passe d’un site web

Certains sites web empêchent l’enregistrement des mots de passe. Les noms de compte, les mots de passe et les clés d’accès utilisés sur ces sites ne sont ni enregistrés ni renseignés automatiquement.
