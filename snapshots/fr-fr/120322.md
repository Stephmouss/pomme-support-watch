# Si vous avez oublié le code d’accès de votre Apple Vision Pro

Si vous êtes connecté à votre compte Apple sur votre Apple Vision Pro, vous pouvez retrouver l’accès à votre appareil en l’effaçant et en le configurant à nouveau.

Lorsque vous saisissez un code d’accès erroné sur votre Apple Vision Pro quatre fois de suite, un message d’alerte vous indique que votre appareil n’est pas disponible. Si vous avez oublié le code d’accès de votre Apple Vision Pro, vous devez effacer l’appareil, puis le configurer à nouveau.

[Image: Notification indiquant que l’Apple Vision Pro n’est pas disponible, avec un bouton que l’utilisateur peut toucher en cas d’oubli de son code]

## Avant d’effacer et de réinitialiser votre Apple Vision Pro

Vous avez besoin du mot de passe du compte Apple que vous avez utilisé pour configurer votre Apple Vision Pro. Si vous n’êtes pas connecté à votre compte Apple sur l’Apple Vision Pro, [contactez l’assistance Apple](https://getsupport.apple.com/?caller=kbase) pour obtenir de l’aide.

Cette procédure entraîne l’effacement de votre Apple Vision Pro. Vous pourrez restaurer vos données à partir de la sauvegarde iCloud si vous avez sauvegardé votre appareil. Vous pourrez également télécharger à nouveau d’autres informations stockées dans iCloud, comme celles des apps Photos et Messages.

## Effacer votre Apple Vision Pro si vous avez oublié votre code d’accès

- Touchez le bouton « Code oublié ? » qui apparaît après quatre tentatives infructueuses de saisie du code d’accès.

- Touchez Commencer la réinitialisation de l’Apple Vision Pro.

- Si vous y êtes invité, choisissez un réseau Wi-Fi auquel vous connecter.

- Saisissez le mot de passe de votre compte Apple pour vous déconnecter de votre compte Apple.

- Touchez Effacer l’Apple Vision Pro pour confirmer, puis enlevez votre Apple Vision Pro.

Après l’effacement et le redémarrage de votre Apple Vision Pro, remettez l’appareil et suivez les instructions à l’écran pour commencer la configuration de visionOS. Vous pouvez [restaurer vos données et réglages à partir d’une sauvegarde](https://support.apple.com/guide/apple-vision-pro/back-up-and-restore-tan1f03417ed/visionos) , ou configurer votre Apple Vision Pro en tant que nouvel appareil.

## Bénéficier d’une assistance

Si vous avez encore besoin d’aide avec votre code d’accès, [contactez l’assistance Apple](https://getsupport.apple.com/?caller=kbase) .
