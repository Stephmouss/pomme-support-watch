# Si vous avez besoin de modifier ou de mettre à jour le mode de paiement de votre compte Apple

Les informations de paiement que vous utilisez pour vos achats et abonnements de contenus multimédias Apple peuvent être automatiquement mises à jour par votre établissement financier. Découvrez comment modifier votre mode de paiement manuellement.

## Mettre à jour votre mode de paiement

## Mise à jour de votre mode de paiement sur votre iPhone, iPad ou Apple Vision Pro

- Dans Réglages, touchez votre nom.

- Touchez Paiement et livraison. Il vous sera peut-être demandé de vous connecter à votre compte Apple.

- Si vous souhaitez mettre à jour les informations de facturation d’une carte existante, touchez le mode de paiement, puis touchez Modifier.

- Saisissez vos nouvelles informations de facturation, puis touchez le bouton Terminé .

### En cas de problème, changez de mode de paiement

- Dans Réglages, touchez votre nom.

- Touchez Paiement et livraison. Il vous sera peut-être demandé de vous connecter à votre compte Apple.

- Touchez Ajouter un mode de paiement, entrez le nouveau mode de paiement, puis touchez Terminé.

- Touchez Modifier.

- Touchez le bouton de suppression rouge à côté de l’ancien mode de paiement, puis touchez Supprimer.

- Si vous le souhaitez, vous pouvez ensuite ajouter à nouveau l’ancien mode de paiement avec les informations de facturation mises à jour.

## Mise à jour de votre mode de paiement sur votre Mac

- Dans l’App Store, cliquez sur votre nom dans la barre latérale. Ou cliquez sur le bouton Connexion et connectez-vous à votre compte Apple, puis cliquez sur votre nom dans la barre latérale.

- Cliquez sur Réglages du compte. Il vous sera peut-être demandé de vous connecter à votre compte Apple.

- Cliquez sur Modes de paiement.

- Si vous devez mettre à jour les informations de facturation d’une carte existante, cliquez sur le mode de paiement, puis sur Modifier.

- Saisissez vos nouvelles informations de facturation, puis cliquez sur Terminé.

### En cas de problème, changez de mode de paiement

- Dans l’App Store, cliquez sur votre nom dans la barre latérale. Ou cliquez sur le bouton Connexion et connectez-vous à votre compte Apple, puis cliquez sur votre nom dans la barre latérale.

- Cliquez sur Réglages du compte. Il vous sera peut-être demandé de vous connecter à votre compte Apple.

- Cliquez sur Modes de paiement.

[Image: Écran macOS indiquant Gérer les paiements.]

- Cliquez sur Ajouter un mode de paiement, puis saisissez le nouveau mode de paiement. Cliquez sur Terminé.

- Cliquez sur Modifier.

- Cliquez sur le bouton de suppression rouge à côté de l’ancien mode de paiement, puis sur Supprimer.

- Si vous le souhaitez, vous pouvez ensuite ajouter à nouveau l’ancien mode de paiement avec les informations de facturation mises à jour.

## Mise à jour de votre mode de paiement sur votre PC Windows

- Sur votre PC Windows, ouvrez l’app Apple Music ou l’app Apple TV. Découvrez [comment obtenir les apps Apple pour Windows](https://support.apple.com/HT210384) .

- Cliquez sur votre nom en bas de la barre latérale, puis cliquez sur Voir mon compte. Il vous sera peut-être demandé de vous connecter d’abord à votre compte Apple. (Si vous avez iTunes pour Windows, choisissez Compte dans la barre des menus, puis sélectionnez Voir mon compte.)

[Image: Écran de l’app Apple Music ou Apple TV sous Windows, avec les options Afficher le profil et Voir mon compte.]

- Cliquez sur Gérer les paiements en regard de l’intitulé Mode de paiement.

- Si vous souhaitez mettre à jour les informations de facturation d’une carte existante, cliquez sur Modifier à côté du mode de paiement.

- Saisissez vos nouvelles informations de facturation, puis cliquez sur Terminé.

### En cas de problème, changez de mode de paiement

- Sur votre PC Windows, ouvrez l’app Apple Music ou l’app Apple TV. Découvrez [comment obtenir les apps d’Apple pour Windows](https://support.apple.com/fr-fr/118290)

- Cliquez sur votre nom en bas de la barre latérale, puis cliquez sur Voir mon compte. Il vous sera peut-être demandé de vous connecter d’abord à votre compte Apple. (Si vous avez iTunes pour Windows, choisissez Compte dans la barre des menus, puis sélectionnez Voir mon compte.)

- Cliquez sur Gérer les paiements en regard de l’intitulé Mode de paiement.

- Cliquez sur Ajouter un mode de paiement, puis entrez le nouveau mode de paiement. Cliquez sur Terminé.

- Cliquez sur Modifier à côté de l’ancien mode de paiement, puis cliquez sur Supprimer le mode de paiement.

- Si vous le souhaitez, vous pouvez ensuite ajouter à nouveau l’ancien mode de paiement avec les informations de facturation mises à jour.

## Autres façons de gérer vos modes de paiement

- Si vous devez ajouter un nouveau mode de paiement ou modifier l’ordre dans lequel vos modes de paiement sont facturés, [découvrez comment ajouter un mode de paiement à votre compte Apple](https://support.apple.com/fr-fr/118429) .

- Si vous déménagez dans un nouveau pays ou une nouvelle région, [découvrez comment modifier la région ou le pays associé à votre compte Apple](https://support.apple.com/fr-fr/118283) .

- Si vous souhaitez modifier vos informations Apple Pay, [découvrez comment modifier ou supprimer les cartes de paiement que vous utilisez avec Apple Pay](https://support.apple.com/fr-fr/118219) .

- [Découvrez ce qu’il faut faire si vous ne parvenez pas à supprimer un mode de paiement](https://support.apple.com/fr-fr/118291) .
