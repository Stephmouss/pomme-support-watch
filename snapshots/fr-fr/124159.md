# Consulter et récupérer les messages indésirables sur votre iPhone

Dans Messages, la détection du spam sur l’appareil filtre automatiquement les messages indésirables dans votre dossier Indésirables.

Sous iOS 26 et versions ultérieures, le filtrage du spam dans Messages protège les utilisateurs des messages potentiellement dérangeants ou dangereux. Ce réglage est activé par défaut. Vous ne recevez pas de notification pour les messages considérés comme indésirables. Ces messages apparaissent dans le dossier Indésirables de l’app Messages. Si vous pensez que des messages considérés à tort comme indésirables ont été automatiquement filtrés et déplacés dans le dossier Indésirables, vous pouvez les consulter et les restaurer.

## Activer ou désactiver le filtrage du spam

- Ouvrez Messages.

- Touchez le bouton Filtres .

- Touchez Gérer le filtrage, puis touchez Filtrer les indésirables pour activer ou désactiver la fonctionnalité. La fonctionnalité Filtrer les indésirables est activée par défaut sous iOS 26.

Vous pouvez également l’activer ou la désactiver dans l’app Réglages. Accédez à Réglages, touchez Apps, touchez Messages, puis faites défiler l’écran vers le bas pour activer ou désactiver la fonctionnalité Filtrer les indésirables.

## Afficher les messages identifiés comme indésirables

- Dans Messages, touchez le bouton Filtres .

- Touchez Indésirables.

- Touchez le message que vous souhaitez consulter.

Vous ne pouvez pas répondre aux messages indésirables ni cliquer sur les liens qu’ils contiennent tant que vous ne les avez pas déplacés vers votre boîte de réception.

## Récupérer les messages identifiés comme indésirables

- Dans Messages, touchez le bouton Filtres .

- Touchez Indésirables.

- Touchez le message que vous souhaitez consulter.

- Touchez Désirables.

- Touchez Placer dans la boîte de réception ou Move to Inbox and Report Not Spam (Placer dans la boîte de réception et signaler comme désirable). Le message que vous avez sélectionné apparaît désormais dans votre liste de conversations.

[Découvrez comment consulter les messages provenant d’expéditeurs inconnus sous iOS 26](https://support.apple.com/125068)
