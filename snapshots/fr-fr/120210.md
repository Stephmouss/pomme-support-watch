# Si Live Multicam ne fonctionne pas dans Final Cut Pro

Découvrez comment procéder si Live Multicam ne fonctionne pas dans Final Cut Pro pour iPad, si les appareils exécutant Final Cut Camera ne se connectent pas ou si Live Multicam présente un autre problème de fonctionnement.

## Avant de commencer

- [Mettez à jour Final Cut Pro pour iPad](https://support.apple.com/guide/ipad/update-apps-ipad05566c91/ipados) vers la dernière version.

- [Sauvegardez vos projets et médias Final Cut Pro pour iPad.](https://support.apple.com/guide/final-cut-pro-ipad/dev49e6feccf/ipados)

- [Sauvegardez les vidéos qui ont été enregistrées avec Final Cut Camera.](https://support.apple.com/guide/final-cut-pro-ipad/deve4c4cad2f/ipados#aria-dev8ef7950ae)

- Connectez tous les appareils à une source d’alimentation.

- Pour des résultats optimaux, [suivez les meilleures pratiques pour utiliser Live Multicam](https://support.apple.com/guide/final-cut-pro-ipad/dev3d39640dd/ipados) .

## Essayer d’appliquer ces étapes dans l’ordre

Après chaque étape de cette liste, vérifiez le fonctionnement de Live Multicam pour déterminer si le problème est résolu.

- [Redémarrer tous les appareils](https://support.apple.com/fr-fr/120210#Restart)

- [Déconnecter les périphériques externes](https://support.apple.com/fr-fr/120210#Disconnect)

- [Vérifier la configuration système requise](https://support.apple.com/fr-fr/120210#Requirements)

- [Vérifier que l’app fonctionne normalement](https://support.apple.com/fr-fr/120210#Guide)

- [Vérifier le Wi-Fi et le Bluetooth](https://support.apple.com/fr-fr/120210#Connectivity)

- [Vérifier que les appareils sont détectables](https://support.apple.com/fr-fr/120210#Discoverability)

- [Vérifier l’espace de stockage disponible](https://support.apple.com/fr-fr/120210#Storage)

- [Vérifier le format du périphérique de stockage externe](https://support.apple.com/fr-fr/120210#Format)

- [Supprimer et réinstaller Final Cut Pro pour iPad et Final Cut Camera](https://support.apple.com/fr-fr/120210#Reinstall)

## Redémarrer les appareils

Redémarrez tous les appareils que vous utilisez avec Live Multicam en les éteignant, puis en les rallumant.

- [Redémarrer l’iPhone](https://support.apple.com/guide/iphone/iph841379c3d/ios)

- [Redémarrer l’iPad](https://support.apple.com/guide/ipad/ipad63d30b5a/ipados)

[Haut de page](https://support.apple.com/fr-fr/120210#Top)

## Déconnecter les périphériques externes

Si un périphérique externe tel qu’un microphone ou un périphérique de stockage est connecté à votre appareil, déconnectez-le :

- Éteignez l’iPhone ou l’iPad sur lequel le problème se produit.

- Déconnectez tous les périphériques de stockage externes ou microphones.

- Allumez l’iPhone ou l’iPad.

Si le problème se produit uniquement lorsqu’un périphérique externe particulier est connecté, une mise à jour ou une réparation de ce dernier peut être nécessaire. Contactez le fabricant pour obtenir de l’aide.

[Haut de page](https://support.apple.com/fr-fr/120210#Top)

## Vérifier la configuration système requise

Assurez-vous que vos appareils disposent de la [configuration système requise pour Final Cut Pro pour iPad et Final Cut Camera](https://www.apple.com/fr/final-cut-pro-for-ipad/#footnote-9) .

[Haut de page](https://support.apple.com/fr-fr/120210#Top)

## Vérifier que l’app fonctionne normalement

Consultez la [section Live Multicam du guide d’utilisation de Final Cut Pro pour iPad](https://support.apple.com/guide/final-cut-pro-ipad/dev619b965f2/ipados) et [l’Aide de Final Cut Camera](https://support.apple.com/guide/final-cut-pro-ipad/dev154067693/ipados) pour savoir comment configurer et utiliser Live Multicam. Vous pouvez effectuer une recherche dans ce guide pour trouver des informations sur les termes clés figurant dans l’app, les alertes, les icônes d’avertissement et les messages d’erreur.

[Haut de page](https://support.apple.com/fr-fr/120210#Top)

## Vérifier le Wi-Fi et le Bluetooth

Live Multicam met en œuvre un processus de streaming et de transfert nécessitant une connexion sans fil point à point. Le Wi-Fi et le Bluetooth doivent donc tous deux être activés. Toutefois, il n’est pas nécessaire que les appareils soient connectés à un réseau Wi-Fi pour que Live Multicam fonctionne.

- Assurez-vous que le Wi-Fi est activé.

- Assurez-vous que le Bluetooth est activé.

- Vérifiez que tous les appareils sont connectés au même compte Apple.

- Si tous vos appareils sont connectés au même compte Apple, activez le [trousseau iCloud](https://support.apple.com/109016) afin qu’ils se connectent de manière transparente.

- Si vous utilisez un appareil connecté à un autre compte Apple, vous pouvez le connecter à l’aide d’un code de jumelage :

- Ouvrez Final Cut Camera sur l’appareil, touchez le bouton Se connecter à Live Multicam , puis le nom de l’iPad exécutant Final Cut Pro, sous Autres appareils.

[Image: null]

- Un code s’affiche sur l’écran de l’iPad.

- Dans Final Cut Camera, saisissez le code dans la fenêtre Demande de jumelage de la caméra, puis touchez OK.

Durant une session Live Multicam et le transfert des médias, assurez-vous que Final Cut Pro pour iPad ou Final Cut Camera est l’app active sur l’appareil correspondant.

[Haut de page](https://support.apple.com/fr-fr/120210#Top)

## Vérifier que les appareils exécutant Final Cut Camera sont détectables

Lorsque vous ouvrez Final Cut Camera sur un appareil que vous souhaitez utiliser dans une session Live Multicam, vous devez avoir effectué la procédure de configuration Bienvenue dans Live Multicam* afin que l’appareil soit détectable.

Si le Wi-Fi et le Bluetooth sont activés sur l’appareil Final Cut Camera et que vous ne parvenez pas à le connecter à l’iPad exécutant Final Cut Pro, effectuez la procédure de configuration Bienvenue dans Live Multicam :

- Dans Final Cut Camera, touchez le bouton Se connecter à Live Multicam , puis Continuer.

[Image: null]

- Suivez les instructions à l’écran pour que l’appareil soit détectable.

* La procédure de configuration Bienvenue dans Live Multicam est distincte de la procédure de configuration Bienvenue dans Final Cut Camera. Celle-ci permet d’autoriser l’app Final Cut Camera à accéder à la caméra et au microphone de l’appareil.

[Haut de page](https://support.apple.com/fr-fr/120210#Top)

## Vérifier l’espace de stockage disponible

- Vérifiez que vous disposez de suffisamment d’espace libre sur votre iPad ou périphérique de stockage externe, en fonction de l’emplacement de stockage de votre projet Live Multicam :

- [Vérifier l’espace de stockage sur votre iPhone et iPad](https://support.apple.com/fr-fr/108429)

- Pour vérifier la quantité d’espace disponible sur un périphérique de stockage externe connecté à un iPad, ouvrez l’app Fichiers, touchez de manière prolongée le périphérique de stockage externe dans la barre latérale, puis choisissez Lire les informations.

- Si vous décidez de libérer de l’espace en supprimant des fichiers de l’app Final Cut Camera, les fichiers supprimés sont déplacés vers le dossier Suppressions récentes de l’app Fichiers, où ils sont conservés pendant 30 jours. Pour libérer de l’espace immédiatement, [supprimez manuellement les fichiers à partir du dossier Suppressions récentes](https://support.apple.com/guide/final-cut-pro-ipad/deve4c4cad2f/2.0/ipados#aria-dev9a303ebb5) . Si vous souhaitez utiliser les fichiers avant leur suppression définitive, vous pouvez les restaurer dans le navigateur de Final Cut Camera.

- Pour éviter de supprimer des fichiers par inadvertance, vous pouvez [sauvegarder vos fichiers Final Cut Camera](https://support.apple.com/guide/final-cut-pro-ipad/dev49e6feccf/ipados) avant de procéder à leur suppression.

- Lorsque vous arrêtez l’enregistrement d’une session Live Multicam, les fichiers vidéo originaux sont transférés en arrière-plan dans le projet Live Multicam. Assurez-vous que vous disposez d’un espace de stockage suffisant afin que le fichier de chaque appareil Final Cut Camera puisse être transféré dans le projet Final Cut Pro pour iPad.

[Haut de page](https://support.apple.com/fr-fr/120210#Top)

## Vérifier le format du périphérique de stockage externe

- Si vous enregistrez avec des appareils Final Cut Camera sur un stockage externe, vérifiez que celui-ci remplit les [conditions requises pour enregistrer sur un périphérique de stockage externe et qu’il est correctement formaté.](https://support.apple.com/guide/final-cut-pro-ipad/dev6b8c9521d/ipados#aria-devf6ddd66d8)

- Si vous stockez des projets Live Multicam sur un périphérique de stockage externe, vérifiez que celui-ci remplit les [conditions requises pour monter ou enregistrer sur un périphérique de stockage externe et qu’il est correctement formaté.](https://support.apple.com/guide/final-cut-pro-ipad/deva1de5e706/2.0/ipados)

[Haut de page](https://support.apple.com/fr-fr/120210#Top)

## Supprimer et réinstaller Final Cut Pro pour iPad et Final Cut Camera

La suppression de l’app Final Cut Pro pour iPad entraîne la suppression définitive de tous les projets enregistrés localement sur l’iPad. La suppression de l’app Final Cut Camera entraîne la suppression définitive de toutes les vidéos enregistrées localement sur l’appareil.

Pour supprimer et réinstaller Final Cut Pro pour iPad et Final Cut Camera :

- Essayez de terminer tous les projets actifs.

- Si vous ne l’avez pas déjà fait, [sauvegardez vos projets et médias Final Cut Pro pour iPad](https://support.apple.com/guide/final-cut-pro-ipad/dev49e6feccf/ipados) ainsi que [les vidéos qui ont été enregistrées avec Final Cut Camera](https://support.apple.com/guide/final-cut-pro-ipad/deve4c4cad2f/ipados#aria-dev8ef7950ae) .

- Touchez de manière prolongée l’icône de l’app sur l’écran d’accueil, puis touchez Supprimer l’app.

- Ouvrez l’App Store et touchez le bouton Mon compte (ou votre photo) en haut à droite. Touchez Apps, puis Mes apps.

- Recherchez Final Cut Pro pour iPad ou Final Cut Camera dans la liste, puis touchez le bouton Télécharger.

[Haut de page](https://support.apple.com/fr-fr/120210#Top)
