# Si vous êtes invité à créer un nouveau code de sécurité iCloud

Sous iOS 8.4 ou version antérieure et OS X 10.10.4 ou version antérieure, il se peut que le message suivant s’affiche lors de l’utilisation du trousseau iCloud : « Un nouveau code de sécurité doit être créé suite à une modification des serveurs du trousseau iCloud ».

Cet article ne s’applique pas aux comptes pour lesquels l’ [identification à deux facteurs](https://support.apple.com/HT204915) est activée. Sur votre iPhone, iPad ou iPod touch, touchez Réglages, [votre nom], puis Mot de passe et sécurité pour voir si vous avez activé l’identification à deux facteurs. Sur votre Mac, choisissez le menu Pomme  > Préférences Système, cliquez sur Identifiant Apple et sélectionnez Mot de passe et sécurité.

Si ce message s’affiche, vous pouvez mettre à jour le système d’exploitation de votre appareil et poursuivre sans modifier votre code de sécurité iCloud. Votre code de sécurité iCloud permet de confirmer votre identité lorsque vous configurez le trousseau iCloud sur un nouvel appareil, et lorsque vous restaurez ce même trousseau.

[Image: Capture d’écran d’un iPhone affichant le message « Un nouveau code de sécurité doit être créé suite à une modification des serveurs du trousseau iCloud ».]

## Sur votre iPhone, iPad ou iPod touch

Touchez Plus tard dans le menu du message, puis mettez à jour votre [appareil vers la dernière version d’iOS](https://support.apple.com/HT204204) .

Si vous ne procédez pas à cette mise à jour, le message s’affiche de nouveau 24 heures après.

Si vous sélectionnez Plus tard à trois reprises, sans mettre à jour l’appareil, le trousseau iCloud est désactivé et le message ne réapparaît plus. La désactivation du trousseau iCloud n’entraîne aucune modification de votre trousseau local. Cependant, votre nom d’utilisateur, vos mots de passe et les autres éléments du trousseau ne sont plus mis à jour sur tous vos appareils. En outre, il est impossible de récupérer le trousseau iCloud à partir d’iCloud.

## Sur votre Mac

Cliquez sur Créer un nouveau code dans le menu du message, réduisez la fenêtre qui s’affiche, puis mettez à jour votre [Mac vers la dernière version de macOS](https://support.apple.com/HT201541) .

[Image: Capture d’écran d’une boîte de dialogue Mac intitulée « Un nouveau code de sécurité iCloud doit être créé », avec une icône représentant des clés et le bouton « Créer un nouveau code » sélectionné.]

Si vous sélectionnez l’option Réinitialiser et désactiver, votre trousseau iCloud est supprimé d’iCloud et désactivé sur l’appareil. Cela n’a pas d’incidence sur votre trousseau local. Cependant, votre nom d’utilisateur, vos mots de passe et les autres éléments du trousseau ne sont plus mis à jour sur tous vos appareils.

## Création d’un nouveau code de sécurité iCloud

Lorsque le message s’affiche, vous pouvez également choisir de créer un nouveau code. Vous pourrez ainsi continuer d’utiliser le trousseau iCloud sur votre appareil.

Sélectionnez l’option Créer un nouveau code pour mettre à jour votre code de sécurité iCloud, puis suivez les instructions qui s’affichent à l’écran.

Optez pour un code facilement mémorisable. Le code de sécurité iCloud permet de confirmer votre identité lorsque vous configurez le trousseau iCloud sur un nouvel appareil, et lorsque vous restaurez ce même trousseau.

## Informations supplémentaires

- Si le trousseau iCloud est désactivé, installez la dernière version d’iOS ou de macOS, puis configurez à nouveau le trousseau iCloud.

- Consultez l’article [Questions et réponses sur le trousseau iCloud](https://support.apple.com/HT204085) .

- Consultez le [guide de sécurité iOS](https://www.apple.com/fr/business/docs/iOS_Security_Guide.pdf) pour en savoir plus sur les codes de sécurité iCloud.
