# Personnaliser les notifications Mail sur votre iPhone ou iPad

Recevez des alertes lorsque vous recevez des e-mails, ou affichez sur votre écran d’accueil le nombre d’e-mails non lus de votre boîte de réception.

## Modifier les réglages des notifications Mail

- Dans l’app Réglages, touchez Apps.

- Touchez Mail.

- Touchez Notifications.

- Touchez Personnaliser les notifications.

- Touchez le compte de messagerie.

- Activez les réglages que vous souhaitez utiliser, comme Alertes ou Pastilles.

Lorsque vous activez Pastilles, le nombre d’e-mails non lus de votre boîte de réception apparaît au-dessus de l’app Mail sur votre écran d’accueil.

Lorsque vous activez Alertes, vous accédez à une option vous permettant de personnaliser vos sons et de changer la sonnerie ou le son de l’alerte. Vous entendrez le son sélectionné lorsque vous recevrez un e-mail.

Si vous souhaitez que les notifications de Mail émettent un son, [choisissez le son, la fréquence et l’apparence de vos notifications](https://support.apple.com/fr-fr/guide/iphone/iph7c3d96bab/ios) . Si votre [appareil est en silencieux](https://support.apple.com/fr-fr/guide/iphone/iph81c7fd7d1/ios) , vos notifications n’émettront aucun son.

## À propos de la pastille indiquant les messages non lus dans Mail sous iOS 18.2

Lorsque vous [utilisez la présentation par catégories dans Mail sous iOS 18.2](https://support.apple.com/fr-fr/guide/iphone/iphfe4a36baf/ios) , la pastille de l’app Mail sur l’écran d’accueil indique uniquement le nombre de messages non lus dans la catégorie Principal. Vous pouvez modifier les réglages des notifications de Mail afin que cette pastille affiche le nombre total de messages non lus :

- Dans l’app Réglages, touchez Apps.

- Touchez Mail.

- Touchez Notifications.

- Touchez Personnaliser les notifications.

- Sous Nombre dans la pastille, touchez Tous les messages non lus.
