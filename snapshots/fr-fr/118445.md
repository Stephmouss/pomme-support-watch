## Découvrez ce dont vous avez besoin pour utiliser Photos iCloud sur PC

- Windows 10 ou version ultérieure

- Votre compte Apple

- [iCloud pour Windows](https://support.apple.com/fr-fr/103232)

## Afficher les photos et vidéos chargées vers Photos iCloud depuis votre PC

Après avoir [chargé les photos de votre PC vers Photos iCloud](https://support.apple.com/guide/icloud-windows/icw2c68705cc/) , vous pouvez les afficher et les gérer dans l’app Photos sur [iCloud.com](https://icloud.com/) et vos appareils Apple.

## Télécharger des photos et vidéos iCloud sur votre PC Windows

### Dans iCloud pour Windows 11.1 et versions ultérieures

- [Configurer Photos sur iCloud pour Windows](https://support.apple.com/guide/icloud-windows/icw9f0ba665f/) . Les versions optimisées de toutes les photos et vidéos sont automatiquement téléchargées sur votre PC.

- Ouvrez la photo ou la vidéo pour télécharger les versions complètes de vos photos et vidéos.

### Dans iCloud pour Windows 10 et versions antérieures

- [Configurer Photos sur iCloud pour Windows](https://support.apple.com/guide/icloud-windows/icw9f0ba665f/) . Les nouvelles photos et vidéos sont automatiquement téléchargées dans le dossier C:\Utilisateurs\votre nom\Images\Photos iCloud\Téléchargements.

- Pour télécharger des photos et vidéos par année, cliquez sur iCloud dans la zone de notification de Windows, puis sur Télécharger des photos.

## Vérifier l’état du téléchargement ou du chargement

Vous pouvez ajouter iCloud pour Windows à la barre d’état afin de voir la progression de vos chargements et téléchargements iCloud.

- Cliquez sur l’icône iCloud située dans la zone de notification de Windows sur votre PC.

- Si iCloud n’apparaît pas, cliquez sur Afficher les icônes masquées dans la zone de notification.

## Afficher les versions modifiées de photos sur votre PC

Dans la dernière version d’iCloud pour Windows, les modifications et suppressions sont automatiquement téléchargées.

Dans iCloud pour Windows 10 et versions antérieures, Photos iCloud télécharge vos photos une seule fois sur votre PC Windows. Si vous les modifiez ultérieurement, la nouvelle version n’est pas téléchargée. Pour enregistrer la version modifiée sur votre PC, téléchargez-la manuellement depuis [iCloud.com](https://icloud.com/) . Vous pouvez également télécharger l’ensemble des photos et vidéos créées la même année.

- Cliquez sur l’icône iCloud située dans la zone de notification de Windows sur votre PC.

- Cliquez sur Télécharger des photos.

- Sélectionnez les photos et vidéos de votre choix, puis cliquez sur Télécharger.

Si vous modifiez, sur votre PC, une photo déjà chargée dans Photos iCloud, vous pouvez changer son nom de fichier pour la charger une nouvelle fois dans Photos iCloud.

## Copier des photos dans un dossier iCloud

- Ouvrez une fenêtre de l’explorateur de fichiers.

- Dans la sous-fenêtre Navigation (barre latérale), cliquez sur Photos iCloud. Si vous utilisez une version antérieure d’iCloud pour Windows, accédez à Favoris, puis cliquez sur Photos iCloud.

- Dans une autre fenêtre, ouvrez le dossier dans lequel vous stockez actuellement les photos que vous souhaitez ajouter à Photos iCloud.

- Sélectionnez les photos que vous souhaitez ajouter.

- Faites-les glisser vers le dossier Photos iCloud. Dans les versions antérieures d’iCloud pour Windows, faites-les glisser dans Favoris et cliquez sur Photos iCloud, puis sur Chargements.

## Si vous avez des photos en double

Dans iCloud pour Windows 7.x, vous voyez à la fois une vidéo et l’image fixe principale pour chaque Live Photo téléchargée à partir de Photos iCloud. Si vous effectuez la mise à niveau vers la dernière version d’iCloud pour Windows, un fichier JPEG ou MOV s’affiche pour chaque Live Photo actuellement stockée dans Photos iCloud, au lieu d’une vidéo et d’une image fixe.

Vous pouvez également voir des copies supplémentaires de vos photos lorsque celles-ci sont modifiées dans l’app Photos d’iOS ou de macOS avant d’être téléchargées sur votre PC. [En savoir plus sur les photos modifiées dans Photos iCloud](https://support.apple.com/fr-fr/118445#editedphotos) .

## Supprimer des photos et des vidéos dans Photos iCloud

Dans iCloud pour Windows 11.1 et versions ultérieures, les photos et vidéos que vous supprimez de votre appareil Apple ou d’ [iCloud.com](https://icloud.com/) seront supprimées de votre PC, sauf si vous les avez épinglées. Et lorsque vous supprimez une photo ou une vidéo sur votre PC, l’un des évènements suivants se produit :

- iCloud pour Windows 14 ou version ultérieure : iCloud supprime les fichiers de votre PC et de Photos iCloud. Si vous supprimez un fichier de Microsoft Photos, iCloud le supprime également de Photos iCloud.

- Versions antérieures d’iCloud pour Windows : les fichiers et les miniatures sont supprimés de votre PC, mais sont toujours stockés dans Photos iCloud. Si vous modifiez une photo ou une vidéo sur un autre appareil, la miniature réapparaît sur votre PC.

[Découvrez comment supprimer ou récupérer des photos et des vidéos dans iCloud pour Windows](https://support.apple.com/guide/icloud-windows/icw5c1e2d1a7/)

## Découvrez comment Photos iCloud gère les photos RAW

La fonctionnalité Photos iCloud conserve toutes vos photos RAW, de même que les fichiers JPEG intégrés, dans leur format d’origine. Vous pouvez télécharger et modifier ces images sur votre ordinateur Mac ou PC. En outre, il est possible d’en afficher une miniature sur votre Mac.

## Si le message « Nous avons détecté que vous utilisez une ancienne version de Windows » s’affiche

Si vous exécutez une ancienne version de Windows 10, le message suivant peut s’afficher : « Nous avons détecté que vous utilisez une ancienne version de Windows. La capacité de Photos iCloud sera légèrement limitée sur cette version de Windows. » Pour profiter de toutes les fonctionnalités de Photos iCloud :

- Effectuez une mise à niveau vers Windows 10 build 18363 ou version ultérieure.

- Téléchargez et installez le [décodeur HEVC](https://apps.microsoft.com/detail/9n4wgh0z6vhq) et le [module HEIF](https://apps.microsoft.com/detail/9pmmsr1cgpwg) depuis le Microsoft Store.
