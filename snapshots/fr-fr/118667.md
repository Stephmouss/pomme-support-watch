# Utiliser Contrôle de sélection sur votre appareil pour contrôler un autre appareil Apple

Avec la fonction Utiliser d’autres appareils pour le contrôle de sélection, vous pouvez contrôler vos autres appareils Apple à distance sur le même réseau Wi-Fi, sans avoir à modifier les connexions des boutons. Cela vous permet de naviguer sur votre Mac ou votre Apple TV avec les mêmes boutons que ceux que vous utilisez pour contrôler votre iPhone.

## Utiliser votre iPhone, iPad ou iPod touch pour contrôler un autre appareil

- Connecter vos appareils au même réseau Wi-Fi.

- Connectez-vous à iCloud à l’aide du même compte Apple sur les deux appareils.

- Si vous souhaitez contrôler un Mac, choisissez Réglages Système dans le menu Pomme  de votre Mac, cliquez sur Accessibilité dans la barre latérale, puis cliquez sur Contrôle de sélection à droite. Sélectionnez « Autoriser le changement de plateforme à contrôler votre ordinateur ».

- [Activez le contrôle de sélection sur votre iPhone, iPad ou iPod touch](https://support.apple.com/fr-fr/119835) .

- À l’aide du commutateur, sélectionnez Appareil dans le menu Contrôle de sélection.

[Image: Écran d’iPhone affichant le menu Contrôle de sélection, utilisé pour contrôler d’autres appareils.]

- Sélectionnez Utiliser un autre appareil.

[Image: Écran d’iPhone affichant le menu Contrôle de sélection avec l’option « Utiliser un autre appareil » sélectionnée, illustrant comment contrôler un autre appareil Apple.]

- Sélectionnez l’appareil que vous souhaitez contrôler, puis Connecter. Vous pouvez désormais utiliser le bouton connecté à votre iPhone, iPad ou iPod touch pour contrôler l’autre appareil.

## Utiliser votre Mac pour contrôler un autre appareil

- Connecter vos appareils au même réseau Wi-Fi.

- Connectez-vous à iCloud à l’aide du même compte Apple sur les deux appareils.

- [Activez le contrôle de sélection sur votre Mac](https://support.apple.com/guide/mac-help/mh43607/mac) .

- À l’aide du commutateur, sélectionnez Appareils dans la sous-fenêtre Accueil du menu Contrôle de sélection.

[Image: Panneau d’accueil Contrôle de sélection sur Mac, affichant les icônes Mail, Curseur, Dock, Personnalisé, Appareils, Scanner, Emplacement et Redémarrer, utilisées pour naviguer dans Contrôle de sélection.]

- Sélectionnez l’appareil que vous souhaitez contrôler, puis Connecter. Vous pouvez désormais utiliser le bouton connecté à votre Mac pour contrôler l’autre appareil.

## Désactiver le contrôle d’un autre appareil

Pour désactiver le contrôle d’un autre appareil, appuyez de façon prolongée sur votre bouton pendant dix secondes. Votre commutateur contrôlera à nouveau l’appareil d’origine. Vous pouvez également procéder comme suit.

### Désactiver le contrôle d’un Mac

- À l’aide du commutateur, sélectionnez Appareils dans la sous-fenêtre Accueil du menu Contrôle de sélection.

- Sélectionnez Déconnecter. Votre bouton contrôlera à nouveau l’appareil d’origine.

### Désactiver le contrôle d’un iPhone, iPad ou iPod touch

- À l’aide du commutateur, sélectionnez Appareil dans le menu Contrôle de sélection.

- Sélectionnez Arrêter d’utiliser l’appareil. Votre bouton contrôlera à nouveau l’appareil d’origine.

[Image: Écran d’iPhone affichant le menu Contrôle de sélection, avec l’option « Appareil » en surbrillance, une étape permettant d’arrêter de contrôler un autre appareil.]

## Désactiver le contrôle de sélection

Si vous souhaitez désactiver complètement le contrôle de sélection, procédez comme suit sur votre appareil :

### Désactiver le contrôle de sélection sur un iPhone, iPad ou iPod touch

À l’aide de votre commutateur, ouvrez Réglages, touchez Accessibilité, touchez Contrôle de sélection, puis désactivez le réglage. Vous pouvez également appuyer trois fois sur le bouton principal ou sur le bouton latéral de certains modèles pour quitter à tout moment le contrôle de sélection.

### Désactiver le contrôle de sélection sur un Mac

À l’aide de votre commutateur, sélectionnez Préférences Système dans le menu Pomme . Dans la barre latérale, cliquez sur Accessibilité, cliquez sur Contrôle de sélection, puis désactivez Contrôle de sélection.
