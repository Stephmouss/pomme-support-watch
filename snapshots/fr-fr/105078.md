# Utiliser la fonctionnalité Masquer mon adresse e-mail avec le service Se connecter avec Apple

Lorsque vous utilisez le service Se connecter avec Apple pour créer un compte sur une app ou un site web, vous pouvez utiliser la fonctionnalité Masquer mon adresse e-mail pour préserver la confidentialité de votre adresse e-mail personnelle.

## Fonctionnement de Masquer mon adresse e-mail

La fonctionnalité Masquer mon adresse e-mail génère des adresses e-mail uniques et aléatoires qui transfèrent automatiquement les messages vers votre boîte de réception personnelle. Chaque adresse n’appartient qu’à vous. Vous pouvez lire et répondre directement aux e-mails envoyés à ces adresses sans divulguer votre adresse e-mail personnelle.

Si vous créez un compte depuis une app ou un site web compatible avec le service Se connecter avec Apple, vous pouvez choisir de partager votre adresse e-mail si vous connaissez bien l’app ou le site, ou au contraire la masquer si vous préférez la protéger. Si vous choisissez l’option Masquer mon adresse e-mail, seule l’app ou seul le site web par le biais de laquelle ou duquel vous avez créé votre compte peut utiliser l’adresse e-mail aléatoire en question pour communiquer avec vous. Lorsque vous sélectionnez cette option dans Se connecter avec Apple, les adresses e-mail générées par Masquer mon adresse e-mail utilisent le domaine d’adresse @privaterelay.appleid.com. Cela signifie que seuls les e-mails envoyés à partir des adresses e-mail désignées par l’app ou le site web seront automatiquement transférés vers l’adresse e-mail vérifiée définie sur votre compte Apple.

Le contenu des messages transitant via la fonctionnalité « Masquer mon adresse e-mail » ne fait l’objet d’aucun traitement ou d’aucune lecture de la part d’Apple, excepté dans le cadre de la procédure habituelle de filtrage des courriers indésirables que nous devons suivre pour conserver notre statut de fournisseur de messagerie fiable. Tous les e-mails sont supprimés de nos serveurs relais quelques secondes après vous avoir été remis.

[En savoir plus sur le service Se connecter avec Apple](https://support.apple.com/102609)

## Consultation des adresses e-mail générées par la fonctionnalité Masquer mon adresse e-mail

Pour voir les adresses e-mail générées par la fonctionnalité Masquer mon adresse e-mail et utilisées avec le service Se connecter avec Apple, procédez comme suit.

### Sur votre iPhone ou iPad

- Ouvrez l’app Réglages, puis touchez votre nom.

- Touchez Se connecter avec Apple. À partir de là, vous pouvez voir les apps et les sites web qui utilisent le service Se connecter avec Apple. Pour voir si vous avez utilisé la fonctionnalité Masquer mon adresse e-mail pour une app ou un site web en particulier, sélectionnez l’app ou le site web dans la liste. Si vous avez utilisé la fonctionnalité Masquer mon adresse e-mail, le domaine @privaterelay.appleid.com devrait s’afficher pour l’app ou le site web en question.

### Sur votre Mac

- Sélectionnez le menu Pomme , puis cliquez sur Réglages Système.

- Cliquez sur votre nom, puis cliquez sur Se connecter avec Apple.

- Choisissez l’app ou le site web.

## Gestion des adresses e-mail générées par la fonctionnalité Masquer mon adresse e-mail

Si vous avez un abonnement iCloud+, vous pouvez modifier l’adresse e-mail utilisée pour transférer les e-mails vers l’adresse e-mail vérifiée définie sur votre compte Apple.

### Sur votre iPhone ou iPad

- Ouvrez l’app Réglages.

- Touchez votre nom, puis iCloud.

- Touchez Masquer mon adresse e-mail dans la section Fonctionnalités iCloud+.

- Faites défiler l’écran vers le bas, touchez Renvoyer vers, puis sélectionnez l’adresse que vous souhaitez utiliser.

### Sur votre Mac

- Sélectionnez le menu Pomme , puis cliquez sur Réglages Système.

- Cliquez sur votre nom, puis sur iCloud.

- Sélectionnez Masquer mon adresse e-mail dans la section Fonctionnalités iCloud+.

- Localisez le menu Renvoyer vers et sélectionnez l’adresse e-mail que vous souhaitez utiliser.
