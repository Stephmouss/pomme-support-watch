# Acheter de la musique depuis l’iTunes Store sur votre PC

Découvrez comment acheter de la musique depuis l’iTunes Store dans l’app Apple Music ou iTunes pour Windows.

## Acheter de la musique sur l’iTunes Store dans l’app Apple Music pour Windows

L’iTunes Store peut être masqué dans l’app Apple Music pour Windows. Suivez les instructions ci-dessous pour retrouver l’iTunes Store et pouvoir acheter de la musique.

### Trouver l’iTunes Store dans l’app Apple Music pour Windows

- Ouvrez l’app Apple Music.

- En haut de l’app Apple Music, cliquez sur Actions de la barre latérale .

[Image: null]

- Cliquez sur Réglages.

- Cliquez sur Général.

- Cliquez sur Afficher, puis sélectionnez iTunes Store.

[Image: Réglages Général de l’app Apple Music pour Windows. L’iTunes Store est sélectionné.]

### Acheter de la musique sur l’iTunes Store dans l’app Apple Music pour Windows

- Ouvrez l’app Apple Music.

- Cliquez dans le champ de recherche, puis saisissez le titre du morceau ou de l’album que vous souhaitez acheter.

- Cliquez sur le bouton iTunes Store dans l’angle supérieur droit. [Vous ne voyez pas l’iTunes Store ?](https://support.apple.com/fr-fr/118286#itunesstore)

[Image: Page Parcourir les catégories de l’app Apple Music pour Windows. L’iTunes Store est sélectionné en haut à droite.]

- Cliquez sur le prix à côté du morceau ou de l’album pour l’acheter.

- Connectez-vous à l’aide de votre compte Apple pour finaliser l’achat. [Vous avez besoin d’aide ?](https://support.apple.com/fr-fr/102627)

Les morceaux achetés figurent dans votre bibliothèque dans l’app Musique.

## Acheter de la musique dans iTunes pour Windows

- Ouvrez iTunes pour Windows.

- Choisissez Musique dans le menu local, puis cliquez sur Store dans la barre de navigation.

- Dans le champ de recherche, saisissez le titre du morceau ou de l’album que vous souhaitez acheter.

- Cliquez sur le prix à côté du morceau ou de l’album.

- Connectez-vous à l’aide de votre compte Apple pour finaliser l’achat. [Vous avez besoin d’aide ?](https://support.apple.com/fr-fr/102627)

Une fois que vous avez acheté de la musique, vous pouvez y accéder dans votre bibliothèque musicale iTunes.
