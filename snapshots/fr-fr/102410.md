# Connecter une imprimante AirPrint à un réseau Wi-Fi

Vous pouvez connecter une imprimante compatible AirPrint à un réseau Wi-Fi pour imprimer sans fil depuis votre iPhone, iPad, Mac ou Apple Vision Pro.

Ces informations générales ne sont spécifiques à aucun modèle particulier d’ [imprimante compatible AirPrint](https://support.apple.com/fr-fr/102895) . Elles fournissent uniquement un aperçu des méthodes de configuration courantes. Pour connaître la procédure détaillée, consultez la documentation de l’imprimante ou contactez son fabricant.

## Si l’imprimante comporte un écran intégré

Sur les imprimantes dotées d’un écran tactile ou d’un autre type d’écran intégré (panneau de contrôle), la sélection ou la saisie du nom de votre réseau Wi-Fi et de son mot de passe s’effectuent généralement par l’intermédiaire de cet écran. Consultez la documentation de l’imprimante pour en savoir plus.

## Si l’imprimante peut se connecter à votre Mac via USB

Vous pouvez utiliser une connexion USB pour configurer l’impression Wi-Fi.

- Connectez l’imprimante à votre Mac à l’aide du câble USB approprié.

- Installez le logiciel Mac fourni avec l’imprimante et assurez-vous qu’il comporte un assistant de configuration d’imprimante.

- Utilisez l’assistant de configuration pour connecter l’imprimante à votre réseau Wi-Fi. Consultez la documentation de l’imprimante pour en savoir plus.

- Débranchez le câble USB de l’imprimante et du Mac. L’imprimante doit rester connectée au réseau Wi-Fi.

## Si l’imprimante peut créer un réseau Wi-Fi ad hoc

Il est possible que vous puissiez configurer l’impression Wi-Fi en utilisant un Mac et le propre réseau Wi-Fi ad hoc de l’imprimante.

- Installez le logiciel Mac fourni avec l’imprimante et assurez-vous qu’il comporte un assistant de configuration d’imprimante.

- Assurez-vous que le réseau Wi-Fi ad hoc de l’imprimante est activé. Consultez la documentation de l’imprimante pour en savoir plus.

- Dans le menu Wi-Fi de la barre des menus, sélectionnez le nom du réseau Wi-Fi ad hoc de l’imprimante. Tant que votre Mac est connecté au réseau de l’imprimante, il ne peut pas se connecter à Internet ou à d’autres services sur votre réseau Wi-Fi standard.

[Image: menu Wi-Fi]

- Utilisez l’assistant de configuration pour connecter l’imprimante à votre réseau Wi-Fi. Consultez la documentation de l’imprimante pour en savoir plus. Il se peut que l’imprimante redémarre avant de se connecter au réseau.

- Accédez à nouveau au menu Wi-Fi de votre Mac et reconnectez-vous à votre réseau Wi-Fi habituel.

## Si l’imprimante utilise la configuration Wi-Fi protégée (WPS)

Si votre imprimante prend en charge le protocole WPS, consultez la documentation de votre routeur Wi-Fi pour en savoir plus sur la procédure d’ajout d’une imprimante WPS.

## Informations supplémentaires

Une fois l’imprimante connectée à votre réseau Wi-Fi, vous pouvez commencer à imprimer :

- [Imprimer depuis votre iPhone ou iPad](https://support.apple.com/fr-fr/109349)

- [Imprimer depuis votre Mac](https://support.apple.com/guide/mac-help/print-documents-mh35838/mac)
