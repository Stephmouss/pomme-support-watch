# Ajouter et supprimer des personnes dans les messages collectifs sur votre iPhone ou iPad

Découvrez comment ajouter et supprimer des personnes dans des messages collectifs sur votre iPhone ou iPad.

Vous ne pouvez ajouter une personne à un message collectif que si elle utilise un appareil Apple et que le message en question comporte déjà au moins trois personnes. Pour qu’il soit possible de retirer quelqu’un du groupe, celui-ci doit comporter au moins quatre personnes, et toutes doivent utiliser un appareil Apple.

## Ajouter une personne à un message collectif

- Touchez le message collectif auquel vous souhaitez ajouter une personne.

- Touchez les icônes de groupe en haut de la discussion.

- Dans la liste des contacts, touchez Ajouter .

[Image: null]

[Image: Pour ajouter un contact à votre conversation de groupe iMessage, touchez le bouton Ajouter sur la page du groupe.]

- Saisissez le nom du contact que vous souhaitez ajouter, puis touchez le bouton Terminé .

[Image: null]

## Supprimer une personne d’un message collectif

- Touchez le message collectif qui contient le contact que vous souhaitez supprimer.

- Touchez les icônes de groupe en haut de la discussion.

- Dans la liste des contacts, touchez de manière prolongée le nom de la personne que vous souhaitez supprimer.

- Touchez Retirer du groupe, puis Supprimer.

[Image: Sur la page du groupe de votre message collectif, touchez de manière prolongée le nom d’un contact pour afficher l’option Retirer du groupe.]

Si vous [invitez d’autres personnes dans votre message collectif à collaborer à un projet](https://support.apple.com/guide/iphone/collaborate-on-projects-iphf08c82a16/ios) , ces contacts peuvent toujours avoir accès au projet même s’ils ont été supprimés du message collectif. Généralement, l’accès est contrôlé par les applications qui hébergent le projet.

Vous souhaitez vous retirer d’un message collectif ? Découvrez comment désactiver les notifications d’un message collectif ou [quitter une conversation de groupe dans l’app Messages](https://support.apple.com/102448) .

## Si vous ne pouvez pas ajouter ou supprimer quelqu’un dans un message collectif

- Vous ne pouvez supprimer quelqu’un que si le groupe compte au moins quatre personnes, et que chacune utilise un appareil Apple, tel qu’un iPhone ou un iPad.

- Vous ne pouvez ajouter une personne à un message collectif que si elle utilise un appareil Apple. Si vous souhaitez ajouter une personne à un message collectif mais qu’elle utilise un appareil autre qu’Apple, vous devez créer un nouveau message collectif. Ce message utilisera le format SMS/MMS/RCS par défaut puisqu’une personne utilise un appareil autre qu’Apple. Découvrez la [différence entre les messages SMS/MMS/RCS et iMessage](https://support.apple.com/104972) .

- Vous pouvez ajouter quelqu’un à un message collectif uniquement si le groupe comprend déjà au moins trois personnes. Vous ne pouvez pas ajouter quelqu’un à une conversation Messages que vous avez déjà eue avec une seule autre personne.
