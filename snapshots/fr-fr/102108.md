# Configuration de réglages réseau avancés dans l’Assistant réglages iOS

Découvrez comment utiliser l’Assistant réglages iOS pour définir des proxys et d’autres options de configuration de réseau avancées pour votre environnement d’entreprise.

Si vous êtes l’administrateur système d’une entreprise, conseillez aux utilisateurs de définir leurs nouveaux appareils pour des configurations de réseau avancées avec l’Assistant réglages iOS.

- Sur l’écran Bonjour, appuyez sur le bouton principal ou effectuez un balayage vers le haut.

- Sélectionnez une langue.

- Sélectionnez un pays ou une région.

- Sur l’écran Démarrage rapide, choisissez Configurer manuellement.

- Sur l’écran Choisir un réseau Wi-Fi, appuyez sur le bouton principal, ou sur le bouton latéral et maintenez ce dernier enfoncé pendant 2 secondes.

- Touchez Réglages Wi-Fi.

- Touchez le bouton d’informations en regard du nom du réseau.

[Image: Bouton d’informations]

Depuis cet écran, vous pouvez ajuster les réglages suivants :

- Configurer un proxy HTTP

- Définir des réglages réseau statiques

- Activer le protocole BootP

- Configurer le DNS
