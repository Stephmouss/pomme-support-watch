# Ajouter un masque de tracé à un plan stéréoscopique à 360º dans Final Cut Pro

Si l’une des vues d’un plan stéréoscopique présente un défaut tel qu’une tache sur l’objectif, vous pouvez masquer ce défaut à l’aide de l’effet Masque de tracé dans Final Cut Pro.

Pour masquer un défaut dans l’une des vues d’un plan stéréoscopique, ajoutez un masque de tracé autour de la zone correspondante dans l’autre vue sans défaut. Pour réussir à masquer un défaut avec cette technique, l’une des vues ne doit pas présenter ce défaut dans la même zone.

- Cliquez sur Final Cut Pro > Préférences > Montage, puis cliquez sur Pixels dans le menu local Unités de l’inspecteur.

- Sélectionnez votre plan dans le navigateur ou la timeline, cliquez sur Fenêtre > Afficher dans l’espace de travail > Inspecteur (ou appuyez sur Commande + 4), puis cliquez sur le bouton Infos . Les dimensions du plan apparaissent en haut de l’inspecteur d’informations. Divisez la dimension Y par deux et notez le résultat. Par exemple, si un plan fait 4096 x 2048 de dimension, la moitié de la dimension Y est 1024.

[Image: bouton Infos]

- Maintenez la touche Option enfoncée, puis faites glisser le plan comportant le défaut vers le haut dans la timeline. Le plan dupliqué devrait apparaître directement au-dessus du plan d’origine.

- Cliquez sur Fenêtre > Afficher dans l’espace de travail > Effets (ou appuyez sur Commande + 5).

- Dans la colonne de gauche du navigateur Effets, cliquez sur la catégorie Masques, puis faites glisser l’effet Masque de tracé vers le plan dupliqué.

- Dans le visualiseur, repérez la zone dans la vue qui ne présente pas le défaut, puis ajoutez des points de contrôle autour de cette zone. Par exemple, si le défaut se trouve dans la vue supérieure (l’œil gauche), ajoutez des points de contrôle autour de la même zone dans la vue inférieure (l’œil droit).

- Pour finaliser la forme initiale du masque, cliquez sur le tout premier point de contrôle.

- Pour afficher l’inspecteur de vidéos, cliquez sur Fenêtre > Afficher dans l’espace de travail > Inspecteur (ou appuyez sur Commande + 5), puis cliquez sur le bouton Inspecteur de vidéos .

[Image: bouton Inspecteur de vidéos]

- Dans la section Masque de tracé de l’inspecteur de vidéos, cliquez sur la flèche d’expansion à côté de Transformations.

[Image: triangle d’expansion]

- Dans la section Transformations, apportez la modification suivante au paramètre Position Y :

- Si vous corrigez un défaut dans la vue supérieure (l’œil gauche), saisissez la valeur que vous avez notée à l’étape 2 précédée du signe moins. Par exemple, pour un plan de 4096 x 2048, vous saisiriez « –1024 » dans le champ Position Y.

- Si vous corrigez un défaut dans la vue inférieure (l’œil droit), saisissez simplement la valeur que vous avez notée à l’étape 2. Par exemple, pour un plan de 4096 x 2048, vous saisiriez « 1024 » dans le champ Position Y.

- Pour prévisualiser le masque, sélectionnez le plan d’origine dans la timeline, puis appuyez sur la touche V de votre clavier pour désactiver ce plan. Le masque de tracé apparaît dans le visualiseur. Appuyez à nouveau sur la touche V pour réactiver le plan.

Ne modifiez pas les paramètres de la section Transformer de l’inspecteur de vidéos, car cela modifierait la position du masque.
