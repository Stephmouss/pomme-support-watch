# Cartes PCIe pouvant être installées sur votre Mac Pro (2019)

Consultez cet article pour en savoir plus sur les modules MPX Apple et certaines cartes PCIe tierces pouvant être installés sur votre Mac Pro.

Le Mac Pro commercialisé en 2019 est doté de huit emplacements pour carte PCIe :

- Quatre emplacements double largeur

- Trois emplacements simple largeur

- Un emplacement demi-longueur comportant, par défaut, la [carte d’E/S Apple](https://support.apple.com/fr-fr/101644#appleio)

Le Mac Pro comporte un ou deux modules MPX Radeon Pro occupant les emplacements 1 - 2 et 3 - 4. Vous pouvez les choisir lors de la commande de votre Mac Pro, ou les acheter séparément auprès d’Apple. Découvrez comment [installer des cartes PCI sur votre Mac Pro (2019)](https://support.apple.com/fr-fr/HT210104) .

## Modules graphiques Apple MPX

Apple propose actuellement plusieurs modules MPX (pour « Mac Pro Expansion ») comportant des processeurs graphiques AMD Radeon Pro. Les modules MPX Radeon Pro peuvent être insérés dans les emplacements 1 - 2 et 3 - 4, et vous pouvez en installer un ou deux de chaque type :

- [Modules MPX 580X Radeon Pro](https://support.apple.com/fr-fr/HT210319) : un uniquement

- [Modules MPX W5500X Radeon Pro](https://support.apple.com/fr-fr/HT210957) : un ou deux

- [Modules MPX W5700X Radeon Pro](https://support.apple.com/fr-fr/HT210968) : un ou deux

- [Module MPX W6600X Radeon Pro](https://support.apple.com/fr-fr/HT213098) : un module uniquement

- [Modules MPX W6800X Radeon Pro](https://support.apple.com/fr-fr/HT212547) : un ou deux

- [Modules MPX W6900X Radeon Pro](https://support.apple.com/fr-fr/HT212579) : un ou deux

- [Modules MPX W6800X Duo Radeon Pro](https://support.apple.com/fr-fr/HT212546) : un ou deux

- [Modules MPX Vega II Radeon Pro](https://support.apple.com/fr-fr/HT210316) : un ou deux

- [Modules MPX Vega II Duo Radeon Pro](https://support.apple.com/fr-fr/HT210392) : un ou deux

Vous pouvez installer jusqu’à deux modules MPX Radeon Pro de n’importe quelle configuration sur votre Mac Pro. Vous pouvez aussi utiliser des modules MPX Radeon en association avec d’autres cartes graphiques PCIe tierces. Si vous faites usage de [Boot Camp](https://support.apple.com/fr-fr/boot-camp) , l’emploi d’un module MPX Radeon et d’une carte graphique AMD tierce n’est pas possible lorsque votre Mac exécute Windows. Découvrez comment [utiliser des cartes graphiques AMD sous Microsoft Windows sur un Mac Pro (2019)](https://support.apple.com/fr-fr/HT210560) .

## Carte d’E/S Apple

Le Mac Pro est fourni avec la carte d’E/S Apple, dotée de trois ports Thunderbolt 3, de deux ports USB-A et d’une prise casque 3,5 mm. Cette même carte est préinstallée dans l’emplacement 8 et ne peut pas être insérée dans un autre.

## Cartes PCIe tierces

Vous pouvez installer de nombreuses cartes PCIe différentes sur votre Mac Pro, comme des cartes Fibre Channel, des cartes réseau fibre optique et des cartes d’interface pro vidéo et audio. Le bus PCIe de votre Mac Pro permet de bénéficier d’une puissance auxiliaire pouvant atteindre 300 W. Si votre carte PCIe nécessite de profiter d’une puissance supplémentaire, par exemple via l’association d’un processeur graphique, utilisez le [câble auxiliaire Belkin](https://www.apple.com/fr/shop/product/HMUJ2) .

Le Mac Pro est compatible avec les processeurs graphiques pris en charge par les [processeurs graphiques externes](https://support.apple.com/fr-fr/HT208544) . Si vous faites usage de [Boot Camp](https://support.apple.com/fr-fr/boot-camp) et souhaitez installer une carte NVIDIA afin de l’utiliser sous Windows sur votre Mac, n’insérez pas celle-ci dans l’emplacement 2. Découvrez comment [utiliser des cartes graphiques AMD sous Microsoft Windows sur un Mac Pro (2019)](https://support.apple.com/fr-fr/HT210560) .

Il est possible que certaines cartes PCIe plus anciennes nécessitent l’emploi de ROM en option 32 bits (Option ROM) non compatibles avec votre Mac Pro. Si vous [installez une carte PCI de ce type](https://support.apple.com/fr-fr/HT210104#32) , il est possible que votre Mac Pro ne démarre pas correctement.

## Afterburner

« Afterburner » est le nom d’une carte d’accélération matérielle conçue par Apple. [En savoir plus sur Afterburner](https://support.apple.com/fr-fr/HT210748) .

## Cartes RAID

Si vous souhaitez augmenter votre capacité de stockage, vous pouvez installer une carte RAID tierce, comme une carte RAID SAS. Vous pouvez également insérer le [module MPX RAID 32 To Promise Pegasus R4i](https://support.apple.com/fr-fr/HT210768) dans l’une des deux baies MPX. Si vous faites usage de [Boot Camp](https://support.apple.com/fr-fr/boot-camp) sur votre Mac, [les volumes RAID Apple ne sont pas compatibles avec Windows](https://support.apple.com/fr-fr/HT201803) .
