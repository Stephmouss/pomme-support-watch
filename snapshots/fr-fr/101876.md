# Annulation et rétablissement des modifications apportées à la table de mixage et aux modules dans Logic Pro

Dans Logic Pro 10.4, vous pouvez annuler et rétablir des modifications apportées à la table de mixage, à l’ensemble des modules inclus avec Logic Pro et à certains modules tiers.

Vous pouvez également accéder aux modifications apportées à la table de mixage et aux modules dans le projet en cours à partir de la fenêtre Historique d’annulation.

## Annulation de la dernière modification apportée à la table de mixage ou aux modules

Vous pouvez annuler des modifications apportées à des paramètres de la table de mixage tels que les niveaux de curseur et le panoramique. Vous pouvez également annuler des modifications apportées aux modules. Pour annuler la dernière modification effectuée, il vous suffit de choisir Édition > Annuler ou d’appuyer sur les touches Cmd + Z.

Pour annuler ou rétablir la dernière modification apportée à un module spécifique, ouvrez le module, puis cliquez sur Annuler ou Rétablir dans la fenêtre du module. Pour inclure toutes les modifications apportées au module dans la fenêtre Historique d’annulation, cliquez sur le menu Réglages dans la fenêtre du module, puis choisissez « Inclure les étapes d’annulation du module dans l’historique d’annulation du projet ».

[Image: Menu Édition de la table de mixage dans Logic Pro.]

Vous pouvez aussi annuler et rétablir des modifications apportées à la table de mixage et aux modules à l’aide du menu Édition de la table de mixage. Pour afficher la table de mixage, cliquez sur le bouton Table de mixage . Sinon, choisissez Fenêtre > Afficher la table de mixage pour ouvrir la table de mixage dans une fenêtre qui lui est propre. Cliquez sur Édition dans la table de mixage, puis choisissez l’une des options suivantes :

[Image: Aucun texte de remplacement pour l’image]

- Pour annuler ou rétablir la dernière modification apportée à la table de mixage, choisissez Table de mixage Annuler ou Table de mixage Rétablir.

- Vous pouvez annuler ou rétablir les dernières modifications apportées aux tranches de console sélectionnées, par exemple le réglage d’un curseur. Sélectionnez les tranches de console à prendre en compte dans la table de mixage, puis choisissez « Annuler les tranches de console sélectionnées » ou « Rétablir les tranches de console sélectionnées ».

- Pour inclure toutes les modifications apportées à la table de mixage que vous pouvez annuler dans la fenêtre Historique d’annulation, cliquez sur « Inclure les annulations de table de mixage dans l’historique d’annulation du projet ».

[Image: Capture d’écran montrant le réglage « Inclure les annulations de table de mixage dans l’historique d’annulation du projet » dans Logic Pro.]

## Utilisation de l’historique d’annulation

La fenêtre Historique d’annulation vous permet d’accéder à une liste de modifications que vous pouvez annuler et rétablir. Vous pouvez également accéder aux modifications apportées à la table de mixage et aux modules qui peuvent être annulées et rétablies. Choisissez Édition > Historique d’annulation, puis cliquez sur Table de mixage ou sur Module. Toutes les modifications apparaissent dans l’ordre dans lequel elles ont été effectuées.

Pour annuler ou rétablir plusieurs étapes, cliquez sur une étape pour annuler ou rétablir toutes les étapes entre celle sur laquelle vous avez cliqué et les étapes en surbrillance.
