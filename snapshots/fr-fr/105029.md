# Comment transformer une Live Photo en vidéo sur votre iPhone

Vous pouvez sélectionner une Live Photo dans vos Albums et la transformer en vidéo à enregistrer ou partager.

- Dans l’app Photos, effectuez un balayage vers le haut jusqu’à Types de médias, puis touchez Live Photos.

- Touchez pour sélectionner une Live Photo.

- Touchez le bouton Plus dans l’angle supérieur droit et sélectionnez Enregistrer comme vidéo.

[Image: Aucun texte de remplacement pour l’image]

Vous pouvez retrouver votre nouvelle vidéo dans l’album Enregistrées récemment. La Live Photo restera accessible dans l’album Live Photos.

Vous pouvez [utiliser iMovie pour combiner plusieurs vidéos](https://support.apple.com/guide/imovie-iphone/welcome/ios) qui ont été créées à partir de Live Photos.
