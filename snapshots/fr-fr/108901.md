# Problèmes lors de l’installation ou de la mise à jour d’iTunes pour Windows

Si vous ne parvenez pas à installer iTunes sur votre PC Windows, ou si le message « Erreur 2 » ou « Apple Application Support introuvable » s’affiche une fois le logiciel installé, suivez les étapes ci-dessous.

## Vérifiez que vous avez ouvert une session sur votre ordinateur à l’aide d’un compte d’administrateur

Si vous n’êtes pas sûr de posséder un compte administrateur, consultez l’article [Comment me connecter en tant qu’administrateur ?](http://windows.microsoft.com/fr-fr/windows7/How-do-I-log-on-as-an-administrator)

Vous pouvez également consulter le système d’aide de votre ordinateur, contacter votre service informatique, ou vous rendre à l’adresse [http://support.microsoft.com](http://support.microsoft.com/) .

## Installez les dernières mises à jour de Microsoft Windows

Pour télécharger les dernières mises à jour, consultez le site web [Microsoft Windows Update](http://www.windowsupdate.com) .

Si vous ne parvenez pas à installer les mises à jour, consultez le système d’aide de votre ordinateur, contactez votre service informatique ou rendez-vous à l’adresse [https://support.microsoft.com](https://support.microsoft.com) .

## Téléchargez la dernière version prise en charge d’iTunes sur Microsoft Store

[Accédez au Microsoft Store pour télécharger la dernière version d’iTunes pour Windows 10](https://www.microsoft.com/store/apps/9pb2mz1zmb1s)

Après avoir téléchargé iTunes, vérifiez si des mises à jour sont disponibles dans Microsoft Store.

Si vous ne pouvez pas télécharger ou mettre à jour iTunes à partir du Microsoft Store, contactez Microsoft pour obtenir de l’aide.

## Désactivez les logiciels provoquant des conflits

Certains processus en arrière-plan peuvent empêcher l’installation de certaines applications, comme iTunes.

Si vous avez installé un logiciel de sécurité et que vous rencontrez des difficultés pour installer iTunes pour Windows, vous devrez peut-être [désactiver ou désinstaller le logiciel de sécurité](https://support.apple.com/HT201413) pour résoudre le problème.

## Redémarrer l’ordinateur

Après le redémarrage, essayez à nouveau d’installer iTunes.

## Assistance supplémentaire

Si les étapes de cet article ne vous permettent pas de résoudre le problème, vous devriez trouver une solution sur le [site web du Support Microsoft](http://support.microsoft.com/) .
