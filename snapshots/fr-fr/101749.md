# GarageBand pour iOS : partage de morceaux avec iTunes pour Windows

Windows affiche les morceaux GarageBand sous forme de dossiers. En outre, vous ne pouvez pas ajouter ces dossiers dans iTunes pour Windows.

Ce problème est résolu dans les versions 11.4 et ultérieures d’iTunes pour Windows. Installez la dernière version d’iTunes.
