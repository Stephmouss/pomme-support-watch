# Utiliser le module MPX Radeon Pro 580X avec votre Mac Pro (2019)

Découvrez les nombreuses configurations d’affichage différentes que vous pouvez utiliser avec votre module MPX sur votre Mac Pro (2019).

Le module MPX Radeon Pro 580X comporte un processeur graphique AMD Radeon Pro 580X doté de 8 Go de mémoire GDDR5 ainsi que deux ports HDMI 2.0. Lorsque vous utilisez le module MPX Radeon Pro 580X avec votre Mac Pro, vous pouvez également vous servir des ports Thunderbolt 3 situés sur le dessus* et à l’arrière de votre Mac Pro pour connecter des écrans supplémentaires.

## Connecter des écrans à l’aide de votre module MPX Radeon Pro 580X

Vous pouvez connecter jusqu’à six écrans dans les configurations suivantes :

- Deux Pro Display XDR avec des résolutions de 6016 x 3384 à 60 Hz connectés aux ports Thunderbolt 3 de votre Mac Pro. Connectez un écran à un port Thunderbolt 3 situé sur le dessus* de votre Mac Pro et l’autre écran à un port Thunderbolt 3 situé à l’arrière de votre Mac Pro.

- Deux écrans 5K avec des résolutions de 5120 x 2880 à 60 Hz connectés via Thunderbolt 3 et deux écrans 4K avec des résolutions de 3840 x 2160 à 60 Hz connectés via HDMI. Connectez le premier écran 5K à un port Thunderbolt 3 situé sur le dessus* de votre Mac Pro et le second écran 5K à un port Thunderbolt 3 situé à l’arrière de votre Mac Pro.

- Six écrans 4K avec des résolutions de 3840 x 2160 à 60 Hz connectés via HDMI et Thunderbolt 3.
