# Si Logic Pro pour Mac ne fonctionne pas

Découvrez la marche à suivre si Logic Pro ne s’ouvre pas, si vous ne parvenez pas à lire ou à enregistrer un projet, ou pour tout autre problème.

## Avant de commencer

- Si vous venez de mettre à jour Logic Pro ou macOS et que Logic Pro ne fonctionne pas, les modules Audio Units tiers ou le matériel externe (comme une interface audio) que vous utilisez peuvent ne pas être compatibles. Prenez note de l’ensemble des modules Audio Units tiers et du matériel que vous utilisez avec votre Mac, puis [contactez les équipes de développement](https://support.apple.com/103190) pour vous assurer que leurs produits sont compatibles avec les mises à jour de Logic Pro et de macOS que vous souhaitez installer.

- [Sauvegardez la version actuellement installée de Logic Pro et vos projets Logic Pro](https://support.apple.com/fr-fr/102029) .

- Si vous utilisez un périphérique de stockage externe pour stocker vos projets ou votre bibliothèque audio Logic Pro, [assurez-vous qu’il utilise le format APFS](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac) . Si vous devez reformater votre périphérique de stockage, vous devrez copier le contenu du lecteur que vous ne voulez pas perdre au préalable. Si votre bibliothèque de sons se trouve sur le périphérique de stockage, vous pouvez [la réinstaller après avoir reformaté votre lecteur](https://support.apple.com/guide/logicpro/manage-logic-pro-content-lgcpf77e757d/mac) .

## Résoudre les problèmes de Logic Pro pour Mac

Après avoir appliqué chacune des étapes ci-dessous, testez à nouveau Logic Pro pour voir si le problème est résolu.

### 1. Redémarrer votre Mac

Choisissez Redémarrer dans le menu Apple .

### 2. Mettre à jour Logic Pro

Choisissez le menu Apple  > App Store, puis cliquez sur Mises à jour dans la barre latérale de l’App Store. Si une mise à jour de Logic Pro est disponible, cliquez sur le bouton Mettre à jour pour la télécharger et l’installer.

### 3. Vérifier la compatibilité de vos appareils et logiciels

Si vous utilisez une interface audio externe, une interface MIDI, un système de stockage, une surface de contrôle ou un module tiers, vérifiez que cet élément est compatible avec la dernière version de Logic Pro. [Contactez le fabricant pour obtenir de l’aide](https://support.apple.com/fr-fr/103190) . Si une mise à jour est disponible, suivez les instructions du fabricant pour mettre à jour votre appareil ou votre logiciel.

### 4. Déconnecter les périphériques externes

Déconnectez les périphériques externes de votre Mac, tels que les périphériques MIDI et les interfaces audio, l’un après l’autre. Effectuez un test après chaque déconnexion d’un périphérique. Si le problème se produit uniquement lorsqu’un périphérique externe spécifique est connecté, une mise à jour ou une réparation de ce dernier peut être nécessaire. Contactez le fabricant pour obtenir de l’aide.

### 5. Utiliser le système audio intégré avec Logic Pro

Si vous utilisez une interface audio externe, essayez d’utiliser le système audio intégré de votre Mac au lieu de cette interface.

- Débranchez l’interface audio externe de votre Mac.

- Ouvrez Logic Pro, choisissez Logic Pro, puis sélectionnez Réglages (ou Préférences).

- Dans la fenêtre Réglages, choisissez Audio, puis sélectionnez Appareils.

[Image: logic-pro-10-7-7-settings-audio-devices]

- Sélectionnez Sortie intégrée dans le menu local Sortie audio.

- Choisissez Micro intégré (ou Entrée intégrée, selon votre ordinateur) dans le menu local du périphérique d’entrée.

- Ouvrez et lancez un projet qui ne fonctionnait pas correctement.

Si le projet s’ouvre et se lance correctement, vous avez peut-être besoin de mettre à jour ou de réparer votre interface audio. Contactez le fabricant pour obtenir de l’aide.

Si vous n’utilisez pas d’interface audio externe, essayez de [contourner les modules Audio Units tiers](https://support.apple.com/fr-fr/109315) .

### 6. Ouvrir Logic Pro sans entrée ni sortie audio

- Ouvrez Logic Pro et maintenez immédiatement la touche Contrôle enfoncée avant que le projet ne s’ouvre.

- Sur le message qui s’affiche, cliquez sur Ne pas lancer.

Si Logic Pro s’ouvre, vous devrez peut-être mettre à jour ou réparer votre interface audio externe. Contactez le fabricant pour obtenir de l’aide. Cela signifie qu’un module Audio Units tiers est peut-être endommagé ou n’est peut-être pas compatible avec votre version de Logic Pro. Vous pouvez essayer de [contourner les modules](https://support.apple.com/HT201199) pour résoudre votre problème.

### 7. Vérifier le mode micro sur votre Mac

Si le son est différent de ce à quoi vous vous attendez lorsque du contenu audio est enregistré sur votre Mac, [vérifiez que le mode du micro est réglé sur Standard](https://support.apple.com/fr-fr/121587) .

### 8. Contourner tous les modules Audio Units tiers

Pour contourner tous les modules Audio Units tiers :

- Si Logic Pro est ouvert, quittez l’app.

- Ouvrez Logic Pro et maintenez immédiatement la touche Contrôle enfoncée avant que le projet ne s’ouvre.

- Dans le message qui s’affiche, cliquez sur Lancer sans Audio Units.

Si le problème ne se produit pas lorsque tous les modules Audio Units tiers sont désactivés, vous pouvez [poursuivre le dépannage des modules Audio Units en les contournant l’un après l’autre](https://support.apple.com/HT201199) .

### 9. Faire un test avec un nouveau projet

Vous pouvez créer un autre projet et le tester pour vérifier si le problème est lié à votre projet ou à l’app Logic Pro.

- Si Logic Pro est ouvert, quittez l’app.

- Ouvrez Logic Pro, puis appuyez sur Maj + Commande + N pour créer un projet vide.

- [Ajoutez des boucles Apple Loops](https://support.apple.com/guide/logicpro/add-apple-loops-to-your-projects-lgcp516b16d1/mac) au nouveau projet.

- Essayez de reproduire le problème que vous rencontriez. Par exemple, si le projet avec lequel vous rencontrez un problème utilise un module tiers particulier, ajoutez-le au projet de test. Si le problème se reproduit, le module est peut-être endommagé ou doit peut-être être mis à jour.

### 10. Faire un test avec un nouveau compte utilisateur

[Créez un autre compte utilisateur standard ou administrateur sur votre Mac](https://support.apple.com/guide/mac-help/add-a-user-or-group-mchl3e281fc9/mac) , puis essayez de reproduire le problème dans ce nouveau compte utilisateur. Si le problème ne se produit pas avec le nouveau compte utilisateur, les réglages ou les fichiers du compte d’origine peuvent être à l’origine du problème.

### 11. Réinitialiser le fichier de préférences des surfaces de contrôle

Si vous utilisez une surface de contrôle avec Logic Pro, essayez de réinitialiser le fichier de préférences des surfaces de contrôle.

- Quittez Logic Pro.

- Dans la barre de menus du Finder, choisissez Aller > Aller au dossier.

- Saisissez ~/Bibliothèque/Préférences.

- Sélectionnez le fichier « com.apple.logic.pro.cs » dans le dossier Préférences, puis choisissez Fichier > Nouveau dossier avec « com.apple.logic.pro.cs ».

- Redémarrer votre Mac.

- Ouvrez Logic Pro.

- En fonction de la surface de contrôle, vous devrez peut-être [l’ajouter à nouveau afin de pouvoir l’utiliser avec Logic Pro](https://support.apple.com/guide/logicpro/add-a-control-surface-to-logic-pro-ctls718ddc0e/mac) .

- Si vous utilisez Logic Remote, un message vous invitera à [reconnecter Logic Remote](https://support.apple.com/guide/logicremote-mainstage-ipad/connect-logic-remote-chsa0054e974/ipados) lors de la première ouverture de l’app Logic Remote suivant la suppression du fichier PLIST.

- Si vous utilisez un appareil compatible avec le protocole EuCon, il n’est pas nécessaire de l’ajouter dans Logic Pro.

### 12. Réinitialiser les réglages de Logic Pro

La réinitialisation des réglages de Logic Pro n’a pas d’impact sur les fichiers, les préréglages ou les patchs du projet. Toutefois, tous les réglages personnalisés que vous aurez créés seront supprimés.

- Sélectionnez Logic Pro > Réglages (ou Préférences).

- Notez tous les réglages spécifiques que vous avez définis.

- Dans le menu Réglages (ou Préférences) de Logic Pro, sélectionnez Réinitialiser tous les réglages (ou toutes les préférences) sauf les raccourcis clavier. Cela affecte les réglages comme suit :

- Les réglages généraux définis par l’utilisateur ou l’utilisatrice sont réinitialisés.

- Les valeurs par défaut des réglages de la barre des commandes sont réinitialisées.

- Les réglages avancés sont désactivés.

- Les valeurs par défaut sont réinitialisées pour l’en-tête de piste.

- Les valeurs par défaut de la boîte de dialogue Nouvelles pistes sont réinitialisées.

Après la réinitialisation, ouvrez votre projet et essayez de reproduire le problème. Vous devrez peut-être [réactiver les réglages avancés](https://support.apple.com/guide/logicpro/advanced-settings-lgcpb6dcc6fa/mac) . Si le problème ne se produit plus, ouvrez les réglages de Logic Pro et appliquez à nouveau vos réglages personnalisés.

### 13. Réinitialiser le fichier PLIST de Logic Pro

Les réglages généraux à l’échelle de l’app pour Logic Pro sont stockés dans un fichier PLIST. Si vous possédez la version par achat unique de Logic Pro et que vous avez également souscrit un abonnement à la version Apple Creator Studio et l’avez téléchargée, vos réglages personnalisés existants sont copiés dans un nouveau fichier PLIST lorsque vous ouvrez la version par abonnement pour la première fois.

Vous aurez donc deux fichiers PLIST, un pour chaque version de l’app. Lors du dépannage, veillez à choisir le fichier PLIST correspondant à la version de Logic Pro concernée.

- Dans Logic Pro, notez tous les réglages personnalisés que vous avez pu définir et [enregistrez les raccourcis clavier personnalisés que vous avez créés](https://support.apple.com/guide/logicpro/browse-import-and-save-key-commands-lgcp68d9ced1/mac) .

- Quittez Logic Pro.

- Dans la barre de menus du Finder, choisissez Aller > Aller au dossier.

- Saisissez ~/Bibliothèque/Préférences, puis cliquez sur Aller.

- Choisissez l’un des fichiers suivants en fonction de la version de Logic Pro que vous dépannez :

- Pour la version par achat unique de Logic Pro, sélectionnez le fichier « com.apple.logic10.plist » dans le dossier Préférences.

- Pour la version Apple Creator Studio, sélectionnez « com.apple.mobilelogic ».

- Une fois le fichier sélectionné, choisissez Fichier > Nouveau dossier avec « com.apple.logic10.plist » ou « com.apple.mobilelogic ».

- Si vous avez effectué une mise à niveau depuis Logic 9 ou une version antérieure vers Logic Pro, déplacez le fichier « com.apple.logic.pro » dans le nouveau dossier créé à l’étape précédente.

- Redémarrer votre Mac.

Après avoir déplacé les fichiers PLIST d’origine vers un nouveau dossier, ouvrez votre projet et essayez de reproduire le problème. Si le problème ne se produit plus, il est probablement dû à un réglage Logic Pro que vous avez appliqué, ou le fichier PLIST est endommagé. Réappliquez les réglages personnalisés un par un pour essayer d’isoler le réglage à l’origine du problème.

### 14. Réinstaller Logic Pro pour Mac

Pour supprimer et réinstaller Logic Pro :

- Dans le Finder, choisissez Aller > Applications.

- Recherchez l’app Logic Pro et faites-la glisser dans la corbeille.

- [Réinstallez Logic Pro à partir de l’App Store pour Mac](https://apps.apple.com/fr/app/logic-pro/id634148309?mt=12) ou restaurez l’app à partir d’une sauvegarde. Lorsque vous restaurez une copie de l’app Logic Pro à partir d’une sauvegarde, vous pouvez la faire glisser depuis son emplacement de stockage vers le dossier Applications, ou [restaurer Logic Pro à partir d’une sauvegarde Time Machine](https://support.apple.com/fr-fr/104984) .
