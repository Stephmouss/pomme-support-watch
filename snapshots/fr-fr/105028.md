# Comment utiliser la navigation privée verrouillée dans Safari

Verrouillez vos fenêtres privées, afin de pouvoir les garder ouvertes et privées même lorsque vous vous éloignez de votre appareil.

## Naviguer en privé dans Safari sur votre appareil Apple

Lorsque vous utilisez la navigation privée, Safari ne consigne ni les pages que vous avez consultées, ni l’historique de vos recherches, ni vos informations de remplissage automatique. La navigation privée vous protège également du suivi en empêchant le chargement des traqueurs connus et en supprimant le suivi utilisé pour identifier les utilisateurs individuels des URL au fur et à mesure que vous naviguez.

Pour plus de confidentialité, vos fenêtres privées peuvent se verrouiller lorsque vous ne les utilisez pas.

- Lorsque votre appareil est verrouillé ou en veille, ou si vous n’utilisez pas activement Safari, vos fenêtres privées dans Safari se verrouillent.

- Lorsque vous déverrouillez ou activez votre appareil, ou que vous recommencez à utiliser Safari, il vous suffit de déverrouiller votre fenêtre privée avec Touch ID, Face ID ou le code d’accès ou le mot de passe de votre appareil.

Le verrouillage de la navigation privée est disponible à partir d’iOS 17, d’iPadOS 17 et de Safari 17 ou version ultérieure pour macOS Monterey 12 ou version ultérieure. Si vous ne trouvez pas l’option pour verrouiller les fenêtres privées, mettez à jour votre appareil vers la dernière version du logiciel.

- [Activer la navigation privée sur iPhone](https://support.apple.com/fr-fr/105030)

- [Activer la navigation privée sur Mac](https://support.apple.com/guide/safari/ibrw1069)

La navigation privée verrouillée est activée par défaut sous macOS. Sous iOS et iPadOS, vous avez la possibilité d’activer la navigation privée verrouillée lorsque vous utilisez la navigation privée pour la première fois après la mise à jour vers le logiciel compatible, ou vous pouvez l’activer dans Réglages.

## Comment activer ou désactiver la navigation privée verrouillée sur iPhone ou iPad

- Ouvrez l’app Réglages.

- Faites défiler vers le bas et touchez Safari.

- Faites défiler vers le bas jusqu’à Confidentialité et sécurité, puis activez Exiger l’utilisation de Face ID (ou Touch ID) pour déverrouiller la navigation privée. Ou désactivez cette option si vous ne souhaitez pas que vos fenêtres privées se verrouillent.

[Image: Dans les réglages de Safari, vous pouvez exiger l’utilisation de Face ID pour déverrouiller les fenêtres de navigation privée.]

## Comment activer ou désactiver la navigation privée verrouillée sur Mac

- Ouvrez Safari.

- Dans le menu Safari, choisissez Réglages.

- Cliquez sur Confidentialité.

- En regard de Navigation privée, sélectionnez « Exiger Touch ID pour afficher les onglets verrouillés. » Ou désélectionnez cette option si vous ne souhaitez pas que vos fenêtres privées se verrouillent.

[Image: Sur Mac, accédez à Safari > Réglages, puis choisissez Confidentialité et activez Touch ID pour afficher les onglets verrouillés.]

## Lorsque les fenêtres privées se verrouillent

[Image: Une fenêtre privée verrouillée dans Safari sur iPhone.]

- Sur iPhone ou iPad, les fenêtres privées se verrouillent lorsque Safari ne s’exécute pas au premier plan ou lorsque vous étiez précédemment en navigation privée. Elles se verrouillent également lorsque votre appareil se verrouille.

- Sur Mac, les fenêtres privées se verrouillent lorsque Safari n’est pas la fenêtre active pendant un certain temps. Elles se verrouillent également lorsque vous verrouillez votre Mac, lorsqu’il se met en veille ou lorsqu’un économiseur d’écran se lance.

- Sur Mac, vous pouvez verrouiller manuellement toutes les fenêtres privées : dans le menu Fenêtre de la barre de menus Safari, choisissez Verrouiller toutes les fenêtres privées.

- Les fenêtres privées ne se verrouillent pas si vous n’avez pas chargé de page web.

- Les fenêtres privées ne se verrouillent pas si vous lisez un contenu audio ou une vidéo.
