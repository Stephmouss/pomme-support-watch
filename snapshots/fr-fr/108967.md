# Sauvegarder votre iPhone, iPad ou iPod touch avec Windows

La création de sauvegardes vous permet de garder à disposition une copie de vos données si vous devez remplacer votre iPhone, iPad ou iPod touch, notamment si celui-ci est perdu ou endommagé.

- Passez sur le Finder sur votre Mac, ou ouvrez [l’app Appareils Apple](https://support.apple.com/guide/devices-windows/welcome/windows) sur votre PC. Si votre PC ne dispose pas de l’app Appareils Apple, ou si votre Mac fonctionne sous macOS Mojave ou version antérieure, ouvrez [iTunes](https://support.apple.com/HT210384) .

- Connectez votre appareil à votre PC à l’aide du câble fourni avec votre appareil. [Trouvez les câbles adaptés à votre appareil](https://www.apple.com/fr/shop/accessories/all/charging-essentials) .

- Si un message vous demande le code d’accès de votre appareil ou si vous souhaitez faire confiance à cet ordinateur, procédez comme indiqué à l’écran. [Obtenez de l’aide si vous avez oublié votre code d’accès](https://support.apple.com/HT204306) .

- [Localisez votre appareil dans iTunes](https://support.apple.com/HT203060) .

[Image: Icône iPhone dans la barre d’outils d’iTunes, utilisée pour accéder aux réglages de sauvegarde de l’iPhone.]

- Cliquez sur Général dans l’app Appareils Apple ou sur Résumé dans iTunes.

- Si vous souhaitez enregistrer les données de santé et d’activité contenues sur votre appareil ou votre Apple Watch, vous devez chiffrer votre sauvegarde. Cochez la case « Chiffrer la sauvegarde locale » et créez un mot de passe. Enregistrez votre mot de passe dans un endroit sûr, car il vous sera impossible de récupérer vos sauvegardes chiffrées sans ce mot de passe.

- Cliquez sur Sauvegarder maintenant.

[Image: Curseur passant sur le bouton Sauvegarder maintenant dans iTunes pour Windows.]

Au terme du processus, la date et l’heure de votre dernière sauvegarde s’affichent dans la fenêtre d’iTunes.

[Image: Date et heure de la sauvegarde locale la plus récente d’un appareil connecté dans iTunes pour Windows.]
