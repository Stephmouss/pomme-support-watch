# Si vous recevez un message d’échec d’authentification dans Mail sous iOS

Votre iPhone ne peut pas vérifier votre nom d’utilisateur et votre mot de passe de messagerie auprès de votre fournisseur de messagerie, et vous devrez peut-être saisir à nouveau vos informations d’identification.

Il est possible que vous recevez un message d’échec d’authentification si votre téléphone ne parvient pas à vérifier votre nom d’utilisateur ou votre mot de passe auprès de votre fournisseur de messagerie. Cela peut se produire après un changement de mot de passe, l’expiration d’un jeton de sécurité ou si l’Identification à deux facteurs requiert un mot de passe spécifique à l’app. Pour authentifier à nouveau votre compte de messagerie :

- Dans l’app Réglages, touchez Apps.

- Touchez Mail.

- Touchez Comptes de messagerie.

- Touchez le compte qui affiche le message d’échec d’authentification.

- Désactivez, puis réactivez Mail.

- Saisissez à nouveau votre adresse e-mail et votre mot de passe si nécessaire.

Si les problèmes d’authentification persistent, vous devrez peut-être [redémarrer votre iPhone](https://support.apple.com/118259) ou [supprimer le compte de messagerie et l’ajouter à nouveau](https://support.apple.com/guide/iphone/add-and-remove-email-accounts-iph44d1ae58a/ios) .
