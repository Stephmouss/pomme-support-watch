# Enregistrer votre configuration Apple Vision Pro sur un iPhone ou un iPad

Découvrez comment enregistrer la configuration de votre regard et de vos mains pour l’Apple Vision Pro, ainsi que les informations de vos ZEISS Optical Inserts, sur votre iPhone ou iPad. Vous pourrez ensuite utiliser ces données enregistrées pour plus de commodité lorsque vous utiliserez l’Apple Vision Pro d’une autre personne en tant qu’utilisateur invité ou utilisatrice invitée, ou lorsque vous restaurerez ou configurerez votre propre Apple Vision Pro.

## Étapes préliminaires

Assurez-vous que vos appareils sont à jour. L’enregistrement de votre configuration Apple Vision Pro nécessite visionOS 26 ou version ultérieure. Vous avez également besoin d’iOS 26 ou version ultérieure sur votre iPhone, ou d’iPadOS 26 ou version ultérieure sur votre iPad.

## Comment enregistrer votre configuration Apple Vision Pro en tant qu’invité(e)

- Portez un Apple Vision Pro qu’une personne vous a laissé utiliser, puis commencez une [Session Utilisateur invité](https://support.apple.com/fr-fr/117742) .

- Approchez votre iPhone ou iPad. Si vous n’avez pas enregistré votre configuration Apple Vision Pro auparavant, une fenêtre apparaît sur votre iPhone ou iPad indiquant qu’aucune configuration n’est enregistrée.

- Touchez Commencer la configuration. Une fenêtre apparaît indiquant Regardez ici avec lʼApple Vision Pro.

- Regardez le code sur votre iPhone ou iPad. Lorsque l’Apple Vision Pro reconnaît votre iPhone ou iPad, une coche apparaît et une courte vidéo vous présente l’Apple Vision Pro.

- Effectuez le processus de configuration du regard et des mains, puis commencez à utiliser l’Apple Vision Pro en tant qu’invité(e).

Vos données de configuration, y compris la configuration du regard et des mains et les informations sur les ZEISS Optical Inserts, sont enregistrées sur votre iPhone ou iPad et vous pourrez les utiliser la prochaine fois que vous démarrerez une session d’utilisateur invité. Votre configuration est également synchronisée dans iCloud afin que vous puissiez l’utiliser sur vos appareils Apple.

### Enregistrer votre configuration Apple Vision Pro après avoir démarré une session d’utilisateur invité

Si vous démarrez une session d’utilisateur invité sans enregistrer vos données de configuration, vous pouvez les enregistrer sur votre iPhone ou iPad pendant que vous utilisez l’Apple Vision Pro.

- [Ouvrez le centre de contrôle](https://support.apple.com/guide/apple-vision-pro/open-control-center-tand3233e05b/visionos) sur l’Apple Vision Pro.

- Touchez Utilisateur invité à droite.

- Touchez Enregistrer la configuration sur l’iPhone ou l’iPad.

- Approchez votre iPhone ou iPad, puis suivez les instructions à l’écran.

## Utiliser votre configuration enregistrée lorsque vous utilisez l’Apple Vision Pro en tant qu’invité(e)

- Portez un Apple Vision Pro qu’une personne vous a laissé utiliser, puis commencez une [Session Utilisateur invité](https://support.apple.com/fr-fr/117742) .

- Si l’option Utiliser la configuration de l’invité récent s’affiche et que vous n’étiez pas l’utilisateur invité le plus récent ou l’utilisatrice invitée la plus récente, utilisez la Digital Crown pour sélectionner Configurer comme nouvel invité.

- Approchez votre iPhone ou iPad. Une fenêtre Apple Vision Pro apparaît sur votre appareil.

- Touchez Utiliser la configuration enregistrée.

- Regardez le code sur votre iPhone ou iPad. Lorsque l’Apple Vision Pro reconnaît votre iPhone ou iPad, une coche apparaît.

- Commencez à utiliser l’Apple Vision Pro en tant qu’invité(e).

## Utiliser votre configuration enregistrée lors de la configuration de l’Apple Vision Pro

Si vous avez configuré un Apple Vision Pro avec visionOS 26 ou version ultérieure, vos informations de configuration sont enregistrées dans iCloud. Ces réglages sont automatiquement appliqués lorsque vous [configurez l’Apple Vision Pro](https://support.apple.com/com/guide/apple-vision-pro/turn-on-and-set-up-devd5d9e3a52/visionos) à l’aide de l’option Démarrage rapide.

## Supprimer vos données de configuration Apple Vision Pro enregistrées

Vous pouvez supprimer vos données de configuration enregistrées pendant une session d’utilisateur invité. Vous pouvez également les supprimer d’iCloud et de votre iPhone ou iPad.

### Supprimer vos données de configuration pendant une session d’utilisateur invité

- [Ouvrez le centre de contrôle](https://support.apple.com/guide/apple-vision-pro/open-control-center-tand3233e05b/visionos) sur l’Apple Vision Pro.

- Touchez Utilisateur invité à droite.

- Touchez Supprimer la configuration du regard et des mains. Vos informations de configuration seront supprimées lorsque vous retirerez l’Apple Vision Pro.

### Supprimer vos données de configuration d’iCloud

Si vous avez enregistré votre configuration Apple Vision Pro sur votre iPhone ou iPad, ces données sont également stockées dans iCloud. Vous pouvez supprimer votre configuration dans les réglages iCloud :

- Ouvrez Réglages sur votre iPhone, iPad ou Apple Vision Pro.

- Touchez votre nom.

- Touchez iCloud.

- Touchez Enregistré sur iCloud.

- Touchez Configuration de l’Apple Vision Pro.

- Touchez Gérer les données stockées sur iCloud.

- Touchez Supprimer les données d’iCloud, puis Désactiver et supprimer pour confirmer.

Cela supprime votre configuration Apple Vision Pro d’iCloud, ainsi que de tous vos appareils iPhone ou iPad sur lesquels ces informations sont synchronisées dans iCloud.

### Supprimer vos données de configuration de votre iPhone ou iPad

Si vous avez enregistré votre configuration Apple Vision Pro sur votre iPhone ou iPad et que la synchronisation n’est pas activée dans les réglages iCloud, vous pouvez supprimer les informations de configuration à partir du stockage local de votre appareil :

- Accédez à Réglages sur votre iPhone ou iPad.

- Touchez Général.

- Touchez Stockage de l’iPhone ou Stockage de l’iPad.

- Touchez la barre de recherche et recherchez Configuration de l’Apple Vision Pro.

- Touchez Configuration de l’Apple Vision Pro dans les résultats de la recherche.

- Touchez Supprimer les données, puis Supprimer pour confirmer.
