# À propos de la mise à jour du service Xcode pour OS X Server (Mavericks)

La mise à jour du service Xcode pour OS X Server (Mavericks) permet de remédier à un problème pouvant entraîner l’interruption de l’intégration de bots sur des serveurs sans tête, exécutant OS X Mavericks 10.9.2.

Cette mise à jour est disponible en tant que [mise à jour logicielle](http://support.apple.com/kb/HT1338?viewlocale=fr_FR) dans le Mac App Store et en tant que téléchargement manuel sur la [page Téléchargements](http://support.apple.com/fr_FR/downloads/) .

Si vous utilisez le service Xcode sous OS X Server (Mavericks), installez les mises à jour suivantes :

- La mise à jour 10.9.2 d’OS X Mavericks ;

- La mise à jour du service Xcode pour OS X Server ;

- La mise à jour 3.0.3 d’OS X Server.
