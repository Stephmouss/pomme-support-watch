# Utiliser un code PIN de carte SIM sur votre iPhone ou iPad

Le verrouillage de votre carte SIM ou eSIM à l’aide d’un code PIN (numéro d’identification personnel) nécessite la saisie d’un code d’identification pour passer des appels téléphoniques ou utiliser des données mobiles.

Pour empêcher toute autre personne de passer des appels téléphoniques et d’utiliser les données mobiles via votre carte SIM ou eSIM, vous pouvez demander la saisie d’un code PIN de carte SIM. Chaque fois que vous redémarrerez votre appareil ou retirerez la carte SIM, votre carte SIM ou eSIM se verrouillera automatiquement et le message « SIM verrouillée » s’affichera dans la barre d’état.

N’essayez pas de deviner le code PIN de votre carte SIM. Une saisie erronée peut verrouiller votre carte SIM ou eSIM de manière permanente, ce qui vous obligerait à la remplacer.

## Activer ou désactiver le code PIN de votre carte SIM

- Ouvrez l’app Réglages.

- Touchez Données cellulaires.

- Si vous possédez un iPhone avec une seule carte SIM ou eSIM, touchez PIN de la carte SIM et activez ou désactivez le code PIN de votre carte SIM.

- Si vous possédez un iPhone avec une double SIM ou eSIM, touchez le numéro que vous souhaitez modifier, puis touchez PIN de la carte SIM. Activez ou désactivez le code PIN de votre carte SIM.

- Si vous possédez un iPad, touchez PIN de la carte SIM et activez ou désactivez le code PIN de votre carte SIM.

- Si vous y êtes invité, saisissez le code PIN de votre carte SIM. Si vous n’en avez jamais utilisé auparavant, saisissez le code PIN par défaut fourni par votre opérateur. Si vous ne connaissez pas le code PIN par défaut, n’essayez pas de le deviner. Consultez la page du service client de votre opérateur ou les documents qui étaient fournis avec votre forfait mobile. Sinon, vous pouvez également contacter votre opérateur.

- Touchez OK.

## Si vous avez oublié ou si vous ne connaissez pas le code PIN de votre carte SIM

N’essayez jamais de deviner le code PIN ou PUK (Personal Unlocking Key) d’une carte SIM * . Une saisie erronée peut verrouiller votre carte SIM ou eSIM de manière permanente, ce qui vous obligerait à la remplacer.

Si votre appareil demande de saisir un code PIN ou un autre code que vous ne connaissez pas, procédez comme suit :

- Contactez l’opérateur qui vous a donné la carte SIM ou eSIM. Si vous ne savez pas quel opérateur appeler et si vous possédez un appareil avec une carte SIM physique, retirez la [carte SIM de votre iPhone](https://support.apple.com/HT201337) ou de votre [iPad](https://support.apple.com/HT212767) et vérifiez si le nom ou le logo de l’opérateur figure dessus.

- Si vous ne savez pas quel opérateur appeler et que votre appareil dispose d’une eSIM, ouvrez l’app Réglages et touchez Données cellulaires. Le nom de votre opérateur apparaît immédiatement au-dessus de l’option « Activer cette ligne ».

- Demandez à votre opérateur de vous aider à déverrouiller votre carte SIM ou eSIM en utilisant le code PIN ou PUK par défaut.

- Si vous ne pouvez pas déverrouiller votre carte SIM ou eSIM avec le code PIN ou PUK ou si une alerte affiche le message « Code PUK épuisé », demandez une nouvelle carte SIM ou eSIM.

* Si vous saisissez un code PIN de carte SIM incorrect à de trop nombreuses reprises, il est possible que votre opérateur mobile puisse vous donner un code PUK.
