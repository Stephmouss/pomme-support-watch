# À propos de la sécurité en matière de collaboration sur iWork et Box

Découvrez comment ouvrir et accéder aux fichiers sur les serveurs Box et Apple lorsque vous collaborez sur des documents iWork stockés sur Box.

Pour faciliter la collaboration sur iWork, les documents doivent d’abord être transférés sur des serveurs Apple. Les documents sont exploités en mémoire, puis chiffrés et mis en cache pour optimiser les performances d’édition. Box fournit et sécurise les clés de chiffrement utilisées pour protéger les documents en cache.

Pour déchiffrer un document mis en cache en vue d’une modification ultérieure, les serveurs Apple obtiennent les clés de chiffrement nécessaires auprès de Box via un jeton d’accès, qui est d’abord transmis à l’app iWork, puis aux serveurs Apple. Ce jeton n’est valable que 24 heures. Si les utilisateurs travaillent toujours sur le document, le jeton d’accès est automatiquement renouvelé, excepté sur le Web où aucun renouvellement n’est effectué. Sur Box, l’accès aux clés de chiffrement peut être refusé si l’utilisateur n’est plus autorisé à travailler sur le document.

Les documents chiffrés sont mis en cache sur les serveurs Apple pendant 28 jours maximum, après quoi ils sont automatiquement supprimés. Les documents en cache sont déchiffrés uniquement lorsqu’un utilisateur a ouvert un document iWork partagé ou un document iWork sur le Web et que Box donne accès à la clé requise.
