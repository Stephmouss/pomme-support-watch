# Utilisation de la 5G avec votre iPad

Découvrez comment utiliser un forfait cellulaire 5G avec votre iPad.

## Éléments requis

- Un [opérateur prenant en charge la 5G](https://support.apple.com/fr-fr/118626)

- Un [forfait mobile 5G actif](https://support.apple.com/fr-fr/104990)

- Un des modèles d’iPad suivants :

- iPad Pro 13 pouces (M4, M5) Wi-Fi + Cellular

- iPad Pro 11 pouces (M4, M5) Wi-Fi + Cellular

- iPad Pro 11 pouces (3e et 4 générations) Wi-Fi + Cellular

- iPad Pro 12,9 pouces (5e et 6e générations) Wi-Fi + Cellular

- iPad Air 13 pouces (M2, M3, M4) Wi-Fi + Cellular

- iPad Air 11 pouces (M2, M3, M4) Wi-Fi + Cellular

- iPad Air (5e génération) Wi-Fi + Cellular

- iPad (A16) Wi-Fi + Cellular

- iPad (10e génération) Wi-Fi + Cellular

- iPad mini (A17 Pro) Wi-Fi + Cellular

- iPad mini (6e génération) Wi-Fi + Cellular

[Découvrez comment identifier votre modèle d’iPad](https://support.apple.com/fr-fr/108043)

## Description des icônes 5G apparaissant dans la barre d’état

Lorsque vous vous trouvez dans une zone où la 5G est prise en charge par votre opérateur, et si vous disposez du forfait mobile adéquat, une icône 5G s’affiche dans la barre d’état de votre iPad :

[Image: icône 5g ios15]

Le réseau 5G de votre opérateur est disponible et votre iPad peut se connecter à Internet par l’intermédiaire de ce réseau (disponible dans certains pays et certaines régions).

[Image: icônes 5gplus, 5guw et 5guc ios15]

Le réseau 5G+, 5G UW ou 5G UC de votre opérateur est disponible. Votre iPad peut se connecter à Internet par l’intermédiaire de ce réseau (disponible dans certains pays et certaines régions).

## Description des options proposées avec la 5G

Les réglages par défaut de la 5G de l’iPad sont définis de sorte à optimiser l’autonomie de la batterie, ainsi que l’utilisation des données en fonction de votre forfait mobile. Vous pouvez personnaliser ces options afin de choisir quand utiliser la 5G, et pour définir le volume de données utilisées par certaines apps.

Pour accéder à ces options :

- Ouvrez l’app Réglages.

- Touchez Données cellulaires, puis Options.

### Choisir comment votre iPad utilise le réseau 5G

[Image: Capture d’écran des options de données cellulaires pour l’utilisation du réseau 5G sur un iPad doté d’iOS 15.]

- 5G auto : cette option permet d’activer le mode Données intelligentes. Lorsque la 5G ne permet pas d’optimiser les performances de façon significative, votre iPad bascule automatiquement sur le réseau LTE, ce qui préserve l’autonomie de la batterie. L’icône 5G apparaît en fonction de la configuration du réseau de l’opérateur et, dans de rares cas, peut apparaître même lorsque la couverture 5G n’est pas disponible.

- 5G activée : cette option permet de toujours utiliser le réseau 5G lorsqu’il est disponible. Elle est toutefois susceptible de réduire l’autonomie de la batterie.

- LTE : cette option permet d’utiliser uniquement le réseau LTE, même lorsque la 5G est disponible.

### Mode de données

[Image: Capture d’écran des options de mode de données sur un iPad doté d’iOS 15]

- Autoriser plus de données sur 5G : cette option permet d’activer des fonctionnalités d’utilisation des données plus avancées pour les apps et les tâches système. Ces fonctionnalités améliorent la qualité des appels FaceTime et permettent de regarder des contenus haute définition sur l’Apple TV, d’écouter des morceaux et des vidéos Apple Music, de bénéficier de mises à jour d’iPadOS via le réseau mobile et de générer des sauvegardes iCloud automatiques.

- Avec ce réglage, votre iPad peut automatiquement utiliser la 5G au lieu du Wi-Fi lorsqu’un réseau auquel vous vous connectez occasionnellement est lent ou non sécurisé. Pour activer ou désactiver cette fonctionnalité pour certains réseaux, procédez comme suit :

- Ouvrez l’app Réglages.

- Touchez Wi-Fi.

- Touchez le bouton d’informations en regard du réseau Wi-Fi, puis touchez Utiliser le Wi-Fi pour Internet.

- Ce réglage permet également aux apps tierces d’utiliser davantage de données mobiles pour des expériences améliorées.

- Il s’agit du réglage par défaut avec les forfaits de données illimitées fournis par certains opérateurs.

- Ce réglage occasionne une utilisation accrue des données mobiles.

- Standard : lorsque cette option est configurée, les mises à jour automatiques et les tâches en arrière-plan s’effectuent à l’aide des données mobiles, et la qualité des vidéos et des appels FaceTime est standard. Il s’agit généralement du mode défini par défaut.

- Mode Faibles données : cette option permet de limiter l’utilisation des données mobiles et du Wi-Fi en mettant en pause l’installation automatique des mises à jour et l’exécution des tâches en arrière-plan.

### Données à l’étranger

De nombreux opérateurs du monde entier prennent en charge l’itinérance 5G. Si ce n’est pas le cas du vôtre, vous pouvez utiliser les données mobiles via les réseaux 4G et LTE, ou faire l’acquisition d’une carte SIM ou eSIM locale permettant d’accéder à la 5G quand elle est disponible.

Contactez votre opérateur pour en savoir plus.

## Si l’icône 5G n’apparaît pas dans la barre d’état

- Assurez-vous de vous trouver dans une zone couverte par la 5G. Si vous n’êtes pas sûr, contactez votre opérateur.

- Ouvrez l’app Réglages.

- Touchez Données cellulaires, puis Options. Si vous ne voyez pas cet écran, [assurez-vous que votre opérateur prend en charge la 5G](https://support.apple.com/fr-fr/118626) .

[Image: Capture d’écran des options de données cellulaires sur un iPad doté d’iOS 15.]

- [Activez le mode avion](https://support.apple.com/fr-fr/108785) , puis désactivez-le.

- Si la 5G n’est toujours pas détectée, contactez votre opérateur.
