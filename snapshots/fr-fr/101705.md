# Si les icônes de l’écran de verrouillage sont agrandies sur votre iPhone, iPad ou iPod touch

Si les icônes de l’écran de verrouillage sont trop grosses ou si leur taille est agrandie pour s’adapter aux dimensions de l’écran, il est possible que la fonctionnalité Zoom soit activée sur votre appareil. Lisez cet article pour savoir comment la désactiver.

## Désactiver le zoom dans les réglages de votre appareil

[Image: iPhone avec un écran de verrouillage sur lequel la fonctionnalité Zoom est activée]

Si l’app Réglages n’apparaît pas sur votre écran de verrouillage car les icônes sont agrandies, touchez deux fois l’écran avec trois doigts pour effectuer un zoom arrière.

[Image: iPhone affichant les options d’accessibilité pour la fonctionnalité Zoom]

Pour désactiver Zoom :

- Accédez à Réglages > Accessibilité > Zoom.

- Appuyez pour désactiver Zoom.

## Désactiver Zoom dans le Finder ou iTunes

Vous pouvez également désactiver la fonctionnalité Zoom à partir du Finder ou d’iTunes :

- Connectez votre iPhone, iPad ou iPod touch à un ordinateur.

- Sur un Mac doté de macOS Catalina ou version ultérieure, ouvrez une fenêtre du Finder. Sur un Mac doté de macOS Mojave ou version antérieure, ou sur un PC, ouvrez iTunes.

- [Sélectionnez votre appareil](https://support.apple.com/HT203060) lorsqu’il apparaît dans le Finder ou iTunes.

- Cliquez sur Configurer Accessibilité.

[Image: Fenêtre du Finder affichant les options de configuration de l’accessibilité avec un iPhone connecté]

- Pour désactiver le zoom, décochez la case Zoom.

[Image: Fenêtre du Finder affichant les options pour activer ou désactiver la fonctionnalité Zoom avec un iPhone connecté]

- Cliquez sur OK.
