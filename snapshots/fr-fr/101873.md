# Si vous ne parvenez pas à trouver des boucles Apple Loops dans Logic Pro ou GarageBand pour Mac

Pour résoudre les problèmes liés aux boucles Apple Loops, réindexez la bibliothèque de boucles Apple Loops.

Si vous déplacez des boucles du dossier Apple Loops vers un autre emplacement, il est possible qu’elles soient introuvables ou que vous rencontriez d’autres problèmes. Vous pouvez réindexer votre bibliothèque de boucles Apple Loops pour essayer de résoudre ces problèmes :

- Cliquez sur le bouton Navigateur de boucles dans la barre d’outils pour ouvrir le navigateur de boucles.

- Cliquez sur le menu local dans la partie supérieure du navigateur de boucles.

- Faites défiler jusqu’à la fin du menu, puis choisissez Réindexer toutes les boucles.
