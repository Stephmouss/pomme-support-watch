# Découvrir les raccourcis clavier utilisables dans Plans pour le Web

Utilisez des raccourcis clavier pour les actions qui s’effectuent normalement à l’aide d’une souris ou d’un trackpad, comme la rotation d’une carte ou l’affichage et le masquage des outils.

## Utiliser les raccourcis clavier courants dans Plans

Les raccourcis clavier comprennent une ou plusieurs des touches de modification suivantes, qui sont représentées par des symboles dans les menus :

- Contrôle (ou Ctrl) ⌃

- Option (ou Alt) ⌥

- Maj ⇧

- Flèche vers le haut ▲

- Flèche vers le bas ▼

- Flèche vers la gauche ◀

- Flèche vers la droite ▶

Sur les claviers conçus pour les PC Windows, appuyez sur la touche Alt au lieu de la touche Option.

Selon l’appareil que vous utilisez, [Plans pour le Web fonctionne de manière optimale dans les dernières versions de ces navigateurs](https://support.apple.com/120585) . Utilisez les raccourcis suivants pour les opérations indiquées ci-dessous :

### Afficher ou masquer les outils

- Afficher ou masquer la barre latérale : Maj + S

- Afficher ou masquer les guides : Maj + G

- Afficher ou masquer les itinéraires : Maj + R

- Afficher ou masquer la vue à 360° : Maj + K

- Afficher ou masquer la recherche : Maj + F

### Changer d’affichage

- Passer à la carte standard : Option + 1

- Passer à la carte hybride : Option + 2

- Passer à la carte satellite : Option + 3

### Déplacer et gérer la carte

- Zoom avant : touche Plus (+)

- Zoom arrière : touche Moins (-)

- Réorienter la carte au nord : Maj + Option + Flèche vers le haut

- Activer la position de l’utilisateur ou y accéder : Contrôle + Option + L

- Placer un repère au centre de la carte : Option + P

- Faire pivoter la carte : Option + Flèche vers la gauche, Option + Flèche vers la droite

- Déplacer la carte : touches fléchées
