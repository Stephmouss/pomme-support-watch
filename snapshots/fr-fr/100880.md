# Utilisation d’outils Active Directory pour gérer des adhésions de groupe

OS X comprend un éditeur de répertoires qui vous permet de consulter et de modifier des attributs dans un répertoire externe. Cependant, vous ne pouvez pas l’utiliser pour modifier des adhésions de groupe dans le cas d’utilisateurs Active Directory.

Pour modifier des adhésions de groupe dans le cas d’utilisateurs ou de groupes Active Directory, utilisez des outils spécifiques à Active Directory.

Ces outils incluent notamment le composant logiciel intégrable MMC Utilisateurs et ordinateurs Active Directory. Pour obtenir des informations supplémentaires sur cet outil, consultez [cette page Microsoft](http://technet.microsoft.com/fr-fr/library/cc754217.aspx) .

Les outils en ligne de commande dscl ou dseditgroup peuvent être utilisés pour obtenir des informations sur les adhésions de groupe, mais pas pour modifier ces dernières.
