# Apple Remote Desktop : impossible de créer un programme d’installation client personnalisé après la mise à jour vers OS X Lion 10.7.3 ou 10.7.4

Après la mise à jour vers OS X Lion 10.7.3 ou 10.7.4, il se peut que les utilisateurs d’Apple Remote Desktop 3.5.1 ne soient pas en mesure de créer un programme d’installation client personnalisé à l’aide de l’option Créer un programme d’installation client du menu Fichier. S’ils essaient de le faire, il est possible que l’application affiche le message d’alerte suivant : « Une erreur est survenue lors de la création d’un programme d’installation personnalisé. ».

Téléchargez et installez la dernière version du [client Apple Remote Desktop](http://support.apple.com/kb/index?page=search&src=support_site.home.search&locale=fr_FR&q=Apple%20Remote%20Desktop%20Client) pour pouvoir à nouveau personnaliser des programmes d’installation clients dans l’application Apple Remote Desktop 3.5.1.
