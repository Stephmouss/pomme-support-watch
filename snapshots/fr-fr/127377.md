# Si votre Mac bloque le collage d’une commande ou un script dans Terminal

Votre Mac affiche une alerte lorsqu’il détecte une activité de collage suspecte ou des logiciels malveillants connus dans des commandes et des scripts.

## Si votre Mac affiche une alerte indiquant un logiciel malveillant potentiel et un collage bloqué

Cette alerte apparaît si vous n’utilisez pas régulièrement Terminal et que vous avez copié la commande depuis un site web, une app de discussion, ou une app de messagerie ou d’e-mail.

Des escrocs utilisent ces canaux pour inciter les gens à coller des commandes malveillantes dans Terminal afin de nuire à votre Mac ou de compromettre votre vie privée. Cette alerte vous permet de vous assurer que vous n’exécutez pas une commande inattendue à votre insu.

[Image: Alerte indiquant qu’une commande que vous essayez de coller dans Terminal peut être malveillante, avec la possibilité de tout de même la coller si vous avez la certitude qu’elle provient d’une source fiable.]

Si vous recevez cette alerte :

- Votre Mac n’a pas été endommagé.

- Ne collez pas la commande, sauf si vous savez avec certitude ce qu’elle fait et d’où elle vient.

- Si vous savez que la commande provient d’une source fiable, vous pouvez cliquer sur Coller quand même. Coller une commande qui déclenche une alerte de logiciel malveillant potentiel risque d’endommager votre Mac ou de compromettre votre vie privée.

[En savoir plus sur l’identification et la prévention des escroqueries d’ingénierie sociale](https://support.apple.com/fr-fr/102568)

## Si votre Mac affiche une alerte « Logiciel malveillant détecté, collage bloqué » ou « Script malveillant bloqué »

Ces alertes apparaissent si macOS détecte qu’une commande ou un script contient un logiciel malveillant connu et le bloque.

[Image: Alerte signalant que la commande que vous essayez de coller dans Terminal contient un logiciel malveillant.]

[Image: Alerte signalant que macOS a bloqué un script contenant un logiciel malveillant.]

Si l’un de ces messages d’alerte s’affiche :

- Votre Mac n’a pas été endommagé.

- Ne collez pas la commande ou n’exécutez pas le script.

- Si vous estimez que cette commande ou ce script a été bloqué parce que le site web concerné par la tentative d’accès été incorrectement signalé comme frauduleux, vous pouvez [signaler une erreur](https://websitereview.apple.com) .
