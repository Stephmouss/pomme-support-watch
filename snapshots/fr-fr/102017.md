# Sauvegarder et restaurer des documents et des données à partir d’apps gérées

Découvrez les options à choisir pour sauvegarder et restaurer des documents et des données à partir d’apps MDM sous iOS et iPadOS.

Vous pouvez utiliser la fonctionnalité de gestion des appareils mobiles (MDM) pour assigner une app à un utilisateur ou à un appareil spécifique. Lorsque vous utilisez la MDM pour installer une app, deux possibilités s’offrent à vous :

- Empêcher la sauvegarde des documents et données de l’app

- Supprimer l’app lorsque le profil MDM est supprimé

Ces options permettent de déterminer si et comment vous pouvez sauvegarder et restaurer des documents et des données d’apps.

## Sauvegarder et restaurer des documents et des données d’apps

Les documents et les données d’apps peuvent être inclus lorsque vous sauvegardez un appareil iOS ou iPadOS sur iCloud, dans le Finder ou dans iTunes, selon les options que vous choisissez lorsque la solution MDM installe une app :

- Si vous choisissez d’empêcher la sauvegarde des données de l’app (Prevent backup of the app data), les utilisateurs ne peuvent pas sauvegarder, ni restaurer les documents et données associés à l’app.

- Si vous choisissez de supprimer l’app lorsque le profil MDM est supprimé (Remove app when MDM profile is removed), les utilisateurs peuvent sauvegarder les données de cette app, mais ils peuvent restaurer les données uniquement sur le même appareil. S’ils restaurent la sauvegarde sur un nouvel appareil, les données ne sont pas restaurées.

- Si vous ne choisissez aucune de ces options, les utilisateurs peuvent sauvegarder et restaurer les données de l’app sur le même appareil ou sur un nouvel appareil. Certaines apps peuvent également choisir d’exclure les données des sauvegardes ou d’empêcher leurs données d’être restaurées sur un autre appareil.

Pour plus d’informations, consultez la documentation de votre solution MDM.

## Réinstaller les apps gérées

Si les données d’une app gérée sont restaurées à partir d’iCloud, l’app est réinstallée automatiquement si elle a été attribuée à un utilisateur. Elle est également réinstallée automatiquement si elle a été attribuée à un appareil et que la sauvegarde a été restaurée sur le même appareil.

L’app n’est pas réinstallée automatiquement si la sauvegarde est restaurée par Apple Configurator, le Finder ou iTunes.

Si l’app n’a pas été réinstallée automatiquement, la solution MDM peut la réinstaller.
