# À propos des connexions Bluetooth, Wi-Fi et mobile sur votre Apple Watch

Découvrez comment l’Apple Watch utilise les connexions Bluetooth et Wi-Fi. Et découvrez comment la connexion mobile s’intègre sur les modèles GPS + Cellular.

Pour profiter de toutes les fonctionnalités de votre Apple Watch, vous devez activer le Wi-Fi et le Bluetooth sur [l’iPhone jumelé](https://support.apple.com/109015) . [Ouvrez le centre de contrôle](https://support.apple.com/108330) sur votre iPhone, puis assurez-vous que le Wi-Fi et le Bluetooth sont activés.

[Image: null]

Votre Apple Watch utilise le Wi-Fi et le Bluetooth pour communiquer avec votre iPhone jumelé. Votre montre peut également se connecter via un réseau mobile (si disponible). Votre montre alterne entre le Wi-Fi et le Bluetooth de manière intelligente pour choisir la connexion la plus économe en énergie. Voici comment procéder :

[Image: Centre de contrôle de l’iPhone affichant le Wi-Fi et le Bluetooth]

- Votre Apple Watch utilise le Bluetooth lorsque votre iPhone est à proximité, ce qui lui permet de consommer moins d’énergie.

- Si le Bluetooth n’est pas disponible, l’Apple Watch essaie de se connecter au Wi-Fi. Par exemple, si une [connexion Wi-Fi compatible](https://support.apple.com/fr-fr/109319#wifi) est disponible et que votre iPhone n’est pas suffisamment proche pour qu’une connexion Bluetooth puisse être établie, l’Apple Watch se connecte en Wi-Fi.

- Si le Bluetooth et le Wi-Fi ne sont pas disponibles, et que vous disposez d’un forfait de données mobiles, les modèles d’Apple Watch avec connectivité au réseau mobile peuvent se connecter aux réseaux mobiles.

## Connexion à un réseau Wi-Fi compatible

Votre Apple Watch peut se connecter à un réseau Wi-Fi :

- si votre iPhone s’est déjà connecté à ce réseau, alors qu’il était relié à votre montre via le Bluetooth ;

- si le réseau Wi-Fi est de type 802.11b/g/n 2,4 GHz ou 5 GHz (2,4 GHz uniquement sur l’Apple Watch Series 5 et les modèles ultérieurs ainsi que l’Apple Watch SE).

Lorsque votre Apple Watch se connecte à un réseau Wi-Fi compatible plutôt que de se connecter par l’intermédiaire de votre iPhone, l’icône Wi-Fi s’affiche dans le centre de contrôle.

[Image: Aucun texte de remplacement pour lʼimage]

Votre Apple Watch ne peut pas se connecter à des réseaux publics nécessitant la saisie d’identifiants, un abonnement ou un profil.

### Choisir un réseau Wi-Fi

Découvrez comment [choisir le réseau Wi-Fi auquel votre Apple Watch se connecte](https://support.apple.com/111818) .

### Désactiver ou réactiver le Wi-Fi

Appuyez sur le bouton latéral pour ouvrir le centre de contrôle. Touchez l’icône Wi-Fi . L’icône s’estompe et votre appareil se déconnecte du réseau auquel vous étiez connecté.

[Image: Aucun texte de remplacement pour lʼimage]

Seuls les modèles GPS + Cellular d’Apple Watch peuvent se déconnecter des réseaux Wi-Fi. Une fois que vous vous êtes déconnecté, votre Apple Watch ne rejoindra pas automatiquement le réseau Wi-Fi dont vous vous êtes déconnecté. Pour vous reconnecter, vous devez :

- vous activiez le Wi-Fi dans le centre de contrôle ;

- vous vous rendiez dans un autre endroit ;

- attendre 5 h du matin (heure locale) ;

- vous redémarriez votre appareil.

## Utiliser un réseau mobile

Les modèles GPS + Cellular d’Apple Watch peuvent se connecter au réseau mobile. Avec une connexion mobile, vous pouvez passer des appels ou utiliser des apps ou des données lorsque votre iPhone n’est pas à proximité ou quand votre montre n’est pas connectée à un réseau Wi-Fi. Découvrez comment [ajouter votre Apple Watch à votre forfait de données mobiles](https://support.apple.com/119601) .

### Vérifier l’intensité du signal

Appuyez sur le bouton latéral pour ouvrir le centre de contrôle. Vérifiez le bouton Données cellulaires .

[Image: null]

[Image: Centre de contrôle de l’Apple Watch affichant la connexion mobile]

Le bouton Données cellulaires devient vert lorsque vous disposez d’une connexion. Le nombre de barres indique l’intensité du signal.

[Image: null]

[Image: Centre de contrôle de l’Apple Watch affichant la connexion Wi-Fi]

Le bouton Données cellulaires devient blanc lorsque votre forfait mobile est actif, mais que votre Apple Watch est connectée à votre iPhone ou au Wi-Fi.

[Image: null]

### Activer ou désactiver les données mobiles

Appuyez sur le bouton latéral pour ouvrir le centre de contrôle. Touchez le bouton Données cellulaires , puis désactivez Données cellulaires.

[Image: null]

Il se peut que certaines apps ne se mettent pas à jour si votre montre n’est pas connectée à votre iPhone.

## Vérifier la connexion entre votre iPhone et votre Apple Watch

- Consultez le cadran de votre montre. Si l’ icône rouge de déconnexion ou l’ icône rouge en forme de X s’affichent, aucune connexion n’est établie.

[Image: null]

- Ouvrez le centre de contrôle en appuyant sur le bouton latéral (sous watchOS 9 ou version antérieure, touchez de manière prolongée le bas de l’écran, puis effectuez un balayage vers le haut). Si l’icône rouge de déconnexion ou l’icône rouge en forme de X s’affichent, aucune connexion n’est établie.

[Image: null]

- Touchez l’ icône iPhone dans le centre de contrôle. Si vos appareils sont connectés, votre iPhone émet un son.

[Image: null]
