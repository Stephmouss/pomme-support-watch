# Motion 5 : l’analyse du type alpha d’un média, comportant un canal alpha, peut ne pas être effectuée correctement

Lorsqu’un fichier multimédia comportant un canal alpha est importé dans Motion, le type alpha du canal peut ne pas être identifié correctement.

Dans la sous-fenêtre Média de l’inspecteur, choisissez l’option appropriée (voir ci-dessous) depuis le menu local, afin de définir manuellement le type alpha.

- Aucun/Ignorer : il s’agit du réglage par défaut pour les objets ne comportant pas de canal alpha. Cette option vous permet également d’ignorer le canal alpha existant de l’objet, afin d’obtenir un ensemble solide.

- Droit : les types alpha droits sont conservés séparément des canaux rouge, vert et bleu d’une image. Les fichiers multimédia comportant des canaux alpha droits s’affichent correctement lorsqu’ils sont utilisés dans une composition, mais pas lorsqu’ils sont visualisés dans une autre application. Les effets translucides, tels que l’éclairage volumétrique et le reflet d’objectif sur une image générée par un ordinateur, peuvent s’afficher de manière déformée jusqu’à ce que le plan soit utilisé dans une composition. Si l’option Droit est sélectionnée, mais qu’une bordure noire, blanche ou colorée s’affiche autour de l’objet, le réglage n’est pas défini correctement et l’une des options Prémultiplié doit être modifiée, en fonction de la couleur de la bordure.

- Noir prémultiplié : ce type de canal alpha est multiplié avec les canaux rouge, vert et bleu du plan. Les objets comportant des canaux alpha prémultipliés s’affichent donc toujours correctement, même avec des effets d’éclairage translucides, car l’ensemble de l’image est précomposé par rapport à une couleur solide. Avec cette option, les canaux alpha sont considérés comme ayant été précomposés par rapport à du noir.

- Blanc prémultiplié : avec cette option, les canaux alpha sont considérés comme ayant été précomposés par rapport à du blanc.

Informations supplémentaires sur les canaux alpha

Les plans vidéo ordinaires et les fichiers image comportent trois canaux d’informations, respectivement pour le rouge, le vert et le bleu. Plusieurs formats de fichiers vidéo et image prennent également en charge un canal alpha, comprenant des informations supplémentaires qui définissent les zones de transparence. Un canal alpha constitue une échelle de gris dans laquelle le blanc représente les zones dont l’opacité est de 100 % (solide), les zones grises représentent les zones partiellement opaques et les zones noires représentent les zones dont l’opacité est de 0 % (transparent).

Lorsque vous importez un plan QuickTime ou un fichier image dans votre projet, son canal alpha est immédiatement reconnu par Motion. Le canal alpha est ensuite utilisé pour composer cet objet par rapport à tout autre objet se trouvant derrière.

Il existe deux manières différentes d’insérer des informations sur le canal alpha dans des fichiers, et Motion essaie de déterminer automatiquement quel type de canal alpha est utilisé par un objet en particulier :

- Droit : les types alpha droits sont conservés séparément des canaux rouge, vert et bleu d’une image. Les fichiers multimédia comportant des canaux alpha droits s’affichent correctement lorsqu’ils sont utilisés dans une composition, mais pas lorsqu’ils sont visualisés dans une autre application. Les effets translucides, tels que l’éclairage volumétrique et le reflet d’objectif sur une image générée par un ordinateur, peuvent s’afficher de manière déformée jusqu’à ce que le plan soit utilisé dans une composition.

- Prémultiplié : ce type de canal alpha est multiplié avec les canaux rouge, vert et bleu du plan. Les objets comportant des canaux alpha prémultipliés s’affichent donc toujours correctement, même avec des effets d’éclairage translucides, car l’ensemble de l’image est précomposé par rapport à une couleur solide. En général, les canaux alphas prémultipliés sont multipliés par rapport à du noir ou du blanc.

Le type alpha d’un objet importe uniquement lorsque Motion ne parvient pas à l’identifier correctement. Si le canal alpha d’un objet est défini sur Droit dans la liste Média, alors qu’il est déjà prémultiplié, il peut s’afficher avec une bordure de la couleur prémultipliée sur ses contours. Dans ce cas, vous pouvez sélectionner le plan qui pose problème dans la liste Média, puis modifier le paramètre Type alpha dans la sous-fenêtre Média de l’inspecteur.
