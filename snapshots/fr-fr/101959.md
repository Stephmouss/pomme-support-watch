# Téléchargez la collection de sons Toy Box pour GarageBand pour macOS

Pour télécharger les effets sonores d’animaux, moyens de transport et voix inclus dans la collection de sons Toy Box, téléchargez la collection complète de sons pour GarageBand.

Pour télécharger la collection de sons Toy Box, assurez-vous que votre Mac avec GarageBand est connecté à Internet.

- Ouvrez GarageBand, puis choisissez GarageBand> Bibliothèque de sons > Télécharger tous les sons disponibles.

- Cliquez sur Continuer.

- Une fois les nouveaux sons téléchargés, vous pouvez y accéder dans le Navigateur de boucles. Pour ouvrir le navigateur de boucles, cliquez sur le bouton Navigateur de boucles dans la barre de commandes. Cliquez sur le menu local Paquets de boucles, puis choisissez Toy Box dans le menu.
