# Utiliser l’Image de référence Apple pour prendre des photos et vérifier qu’elles ont été prises avec un iPhone 18 Pro ou un iPhone 18 Pro Max

Sur l’iPhone 18 Pro et l’iPhone 18 Pro Max, vous pouvez utiliser l’Image de référence Apple pour vérifier l’authenticité d’une photo. Le nouvel appareil photo principal peut capturer et signer en toute sécurité les données de la photo au niveau du pixel, directement sur le capteur, lorsque vous utilisez le mode Référence dans l’app Appareil photo. L’image de référence résultante est comme un négatif numérique sécurisé, que vous pouvez comparer avec la photo normale pour voir si celle-ci a été modifiée ou altérée.

## Fonctionnement de l’Image de référence Apple

L’Image de référence Apple est un mode optionnel dans Appareil photo. Lorsque vous activez le mode Référence et que vous prenez une photo, l’appareil photo capture des données de capteur horodatées de manière sécurisée, que vous pouvez ensuite développer et afficher sous forme d’image de référence inaltérable dans l’app Photos. Vous pouvez développer, afficher et partager des images de référence dans Photos sur n’importe quel iPhone, iPad ou Mac doté d’iOS 27, d’iPadOS 27, de macOS 27 ou d’une version ultérieure.

Dans l’UE, le mode Référence n’est pas disponible dans Appareil photo, mais les personnes utilisant iOS 27, iPadOS 27 et macOS 27 peuvent développer et afficher des images de référence. En Chine continentale, les personnes utilisant iOS 27, iPadOS 27 et macOS 27 ne peuvent pas prendre ou développer d’images de référence, mais elles peuvent afficher les images de référence qui ont été partagées avec elles.

## Configurer l’Image de référence Apple

L’Image de référence Apple est désactivée par défaut. Pour utiliser l’Image de référence Apple, configurez le mode Référence dans l’app Réglages. Vous n’avez à le faire qu’une seule fois.

- Ouvrez l’app Réglages.

- Touchez Appareil photo, puis Image de référence.

[Image: Écran d’iPhone affichant les réglages de l’Image de référence avec le bouton Enregistrer les captures dans la photothèque activé.]

- Touchez Ajouter le mode Référence, puis suivez les instructions à l’écran.

## Activer ou désactiver l’Image de référence Apple

Après avoir configuré l’Image de référence Apple, vous pouvez activer ou désactiver le mode Référence dans les réglages d’Appareil photo :

- Ouvrez l’app Réglages.

- Touchez Appareil photo, puis Image de référence.

- Activez ou désactivez l’option Ajouter le mode Référence.

[Image: Écran d’iPhone affichant les réglages de l’Image de référence avec le mode Référence activé.]

Si vous désactivez l’Image de référence Apple, le mode Référence ne sera pas disponible dans l’app Appareil photo tant que vous n’aurez pas réactivé l’option Ajouter le mode Référence.

## Prendre une photo avec une image de référence

- Ouvrez Appareil photo sur votre iPhone.

- Balayez l’écran pour sélectionner le mode Référence.

- Touchez le bouton de l’obturateur , ou cliquez sur la commande de l’appareil photo, pour prendre la photo.

Votre iPhone prend une photo normale en plus des données signées du capteur de l’appareil photo principal, ce qui préserve ce que l’appareil photo a vu à l’origine.

Vous pouvez prendre des Live Photos, des portraits et utiliser les Styles photographiques en mode Référence, mais certaines fonctionnalités de l’appareil photo, comme le mode Nuit, ne sont pas disponibles.

Les images de référence nécessitent un espace de stockage supplémentaire sur l’appareil et sur iCloud :

- Les photos prises avec une résolution de 12 Mpx ou 24 Mpx nécessitent environ 8 à 10 Mo d’espace de stockage supplémentaire pour les données d’image de référence non développées et environ 3 Mo pour les données d’image de référence développées.

- Les photos prises avec une résolution de 48 Mpx nécessitent environ 35 à 40 Mo d’espace de stockage supplémentaire pour les données d’image de référence non développées et environ 7 à 8 Mo pour les données d’image de référence développées.

## Rechercher des images de référence

Vous pouvez trouver toutes les photos avec des images de référence dans l’app Photos, dans vos collections de photos et de vidéos organisées par type de média :

- Sur votre iPhone ou iPad : touchez Collections, faites défiler vers le bas, puis touchez Types de média. Touchez Référence.

- Sur votre Mac : dans la section Types de média de la barre latérale, cliquez sur Référence.

## Développer une image de référence

Avant de pouvoir afficher ou partager une image de référence, celle-ci doit être développée dans l’app Photos :

- Sur votre iPhone, accédez à l’app Photos.

- Ouvrez une photo prise en mode Référence.

- Touchez le badge Référence dans le coin supérieur gauche de la photo.

Lorsque vous développez la photo, votre iPhone envoie les données de l’image de référence et les métadonnées associées (y compris la signature du capteur de l’appareil photo et les horodatages sécurisés) à Private Cloud Compute pour qu’elles soient développées en une image visible et pour authentifier la photo. Vous avez besoin d’une connexion Internet pour développer une image de référence.

## Afficher les informations de référence

Une fois qu’une image de référence a été développée, vous pouvez la comparer visuellement avec la photo pour voir si des modifications, comme un recadrage, un ajustement des couleurs ou un ajustement effectué avec l’IA générative, ont été apportées. Vous pouvez également afficher les métadonnées de l’image de référence.

Vous pouvez afficher une image de référence sur un iPhone, un iPad ou un Mac doté d’iOS 27, d’iPadOS 27, de macOS 27 ou d’une version ultérieure.

### Comparer une image de référence avec une photo

- Dans Photos, ouvrez la photo, puis touchez le badge Référence dans le coin supérieur gauche pour afficher l’image de référence.

- Touchez l’image pour basculer entre l’image de référence et la photo. Toutes les modifications, comme un recadrage, un ajustement des couleurs ou un ajustement effectué avec l’IA générative, seront visibles dans la comparaison. Comme l’image de référence a subi un traitement minimal, son contraste et sa saturation seront inférieurs à ceux de la photo.

### Afficher les métadonnées de l’image de référence

- Dans Photos, ouvrez la photo, touchez le badge Référence dans le coin supérieur gauche de la photo.

- Touchez le bouton Infos pour afficher les métadonnées de l’image de référence.

## Partager une image de référence

Lorsque vous partagez ou exportez une photo qui possède une image de référence, vous pouvez choisir d’inclure ou non l’image de référence.

Une image de référence ne peut être affichée que sur un iPhone, un iPad ou un Mac doté d’iOS 27, d’iPadOS 27, de macOS 27 ou d’une version ultérieure.

Si vous partagez une photo en mode Référence avant que l’image de référence n’ait été développée, elle peut inclure des informations sensibles sur votre appareil, comme le numéro de série, et le cadre complet de l’image, quel que soit le réglage du zoom au moment de la prise de vue.

### Inclure l’image de référence à chaque partage

Pour inclure l’image de référence chaque fois que vous partagez une photo en mode Référence, activez Partager l’image de référence :

- Sur l’iPhone 18 Pro, l’iPhone 18 Pro Max ou un modèle ultérieur : accédez à l’app Réglages. Touchez Appareil photo, puis Image de référence. Activez Partager l’image de référence.

- Sur les autres modèles d’iPhone : accédez à l’app Réglages. Touchez Apps, puis Photos. Activez Partager l’image de référence.

### Inclure ou exclure l’image de référence pour un partage unique

- Sélectionnez la photo que vous souhaitez partager, puis touchez le bouton Partager .

- Touchez Options dans la fenêtre de partage, puis activez ou désactivez Image de référence.

- Partagez la photo (par exemple, avec AirDrop ou Messages) ou exportez-la vers un appareil externe.

Si vous activez Toutes les données des photos dans les options de la fenêtre de partage, les fichiers de qualité d’origine incluront l’historique des modifications et les métadonnées comme le lieu, les informations de profondeur et les légendes.

## Inclure une image de référence lors du transfert de photos

Pour inclure l’image de référence lorsque vous transférez des photos vers un Mac ou un PC, activez Transférer l’image de référence :

- Sur l’iPhone 18 Pro, l’iPhone 18 Pro Max ou un modèle ultérieur : accédez à l’app Réglages. Touchez Appareil photo, puis Image de référence. Activez Transférer l’image de référence.

- Sur les autres modèles d’iPhone : accédez à l’app Réglages. Touchez Apps, puis Photos. Touchez Transférer vers un Mac ou un PC, puis activez Transférer l’image de référence.

Lorsque vous transférez une photo avec une image de référence, les données de l’image de référence sont incluses, mais l’image de référence ne peut être affichée que sur un iPhone, un iPad ou un Mac doté d’iOS 27, d’iPadOS 27, de macOS 27 ou d’une version ultérieure.

## Si vous voyez une erreur « Impossible de traiter l’image de référence »

Si vous voyez une erreur indiquant qu’une image ne peut pas être traitée, vérifiez votre connexion Internet. Vous avez besoin d’une connexion Internet pour développer une image de référence.
