# Effacer un Mac à processeur Intel à l’aide d’Utilitaire de disque

Découvrez comment effacer (formater) le disque de démarrage intégré d’un ordinateur Mac à processeur Intel.

Ces étapes ne s’appliquent pas aux [ordinateurs Mac avec puce Apple](https://support.apple.com/fr-fr/116943) . Si vous disposez d’un Mac avec puce Apple, suivez la procédure pour [effacer un Mac avec puce Apple](https://support.apple.com/fr-fr/102506) .

## Avant d’effacer votre Mac

- Si vous souhaitez restaurer les réglages par défaut de votre Mac, par exemple pour le préparer pour un nouveau propriétaire, [découvrez la procédure à suivre avant de vendre, de céder ou d’échanger votre Mac](https://support.apple.com/fr-fr/102773) .

- Si vous utilisez [macOS Monterey ou version ultérieure](https://support.apple.com/109033) , suivez les instructions permettant [d’effacer tous les contenus et réglages](https://support.apple.com/102664) plutôt que celles de cet article. Il est également recommandé d’effectuer cette opération lorsque vous vendez, donnez ou échangez votre Mac.

- [Effectuez une sauvegarde](https://support.apple.com/fr-fr/104984) de tous les fichiers que vous souhaitez conserver. L’effacement du contenu de votre Mac entraîne la suppression définitive des fichiers.

## Démarrer à partir de la fonctionnalité Récupération de macOS

Pour effacer le disque de démarrage de votre Mac avec Utilitaire de disque, vous devez d’abord démarrer à partir de la fonctionnalité Récupération de macOS ou à partir d’un autre disque.

[Comment démarrer à partir de la fonctionnalité Récupération macOS](https://support.apple.com/fr-fr/102518)

## Utiliser la fonction d’effacement d’Utilitaire de disque

- Dans la liste des utilitaires qui s’affiche dans Récupération, sélectionnez Utilitaire de disque, puis cliquez sur Continuer.

[Image: Fenêtre Utilitaires de la fonctionnalité de récupération de macOS]

- Sélectionnez Macintosh HD dans la barre latérale de la fenêtre Utilitaire de disque. [Découvrez comment procéder si « Macintosh HD » ne s’affiche pas.](https://support.apple.com/fr-fr/102639#nodisk)

- Cliquez sur le bouton Effacer dans la barre d’outils, puis spécifiez un nom et un format :

[Image: bouton Effacer]

- Nom : Macintosh HD

- Format : APFS ou Mac OS étendu (journalisé), comme recommandé par Utilitaire de disque

- Cliquez sur Effacer le groupe de volumes. Si ce bouton n’apparaît pas, cliquez sur Effacer.

[Image: Effacement d’un groupe de volumes dans Utilitaire de disque à partir du mode Récupération sous macOS Monterey]

- Si vous y êtes invité, saisissez les informations de votre compte Apple. [Vous avez oublié votre compte Apple ?](https://support.apple.com/fr-fr/102627)

- Facultatif : si vous avez déjà ajouté des volumes internes autres que « Macintosh HD » à l’aide d’Utilitaire de disque, vous pouvez les effacer individuellement en suivant la même procédure.

- Une fois l’opération terminée, quittez l’Utilitaire de disque pour revenir à la fenêtre des utilitaires de la fonctionnalité de récupération.

- Si vous souhaitez redémarrer à partir du disque que vous venez d’effacer, sélectionnez Réinstaller macOS dans la fenêtre des utilitaires, puis cliquez sur Continuer et suivez les instructions à l’écran pour [réinstaller macOS](https://support.apple.com/fr-fr/102655) .

## Si le volume Macintosh HD n’apparaît pas dans Utilitaire de disque

- Votre disque de démarrage intégré doit être le premier élément répertorié dans la barre latérale d’Utilitaire de disque. Il porte le nom « Macintosh HD », sauf si vous l’avez modifié. Si vous ne le voyez pas, choisissez Éteindre dans le menu Pomme , puis débranchez tous les périphériques non essentiels de votre Mac et réessayez.

- Si votre disque ne s’affiche toujours pas dans Utilitaire de disque, ou si Utilitaire de disque signale un échec de l’effacement, une réparation de votre Mac est peut-être nécessaire.
