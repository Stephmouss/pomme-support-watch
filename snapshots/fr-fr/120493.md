# Convertir un fichier M4A en MP3 sur Mac

Utilisez les apps Musique ou GarageBand sur votre Mac pour convertir un fichier M4A en MP3.

## Convertir un fichier M4A en MP3 avec l’app Musique

- Dans la barre des menus de Musique, choisissez Musique > Réglages.

- Cliquez sur l’onglet Fichiers, puis sur Réglages d’importation.

- Choisissez Encodeur MP3 dans le menu local Importer via, puis cliquez sur OK.

- Si le fichier M4A ne fait pas partie de votre bibliothèque musicale, faites-le glisser du Finder vers Musique.

- Sélectionnez le fichier M4A à convertir dans l’app Musique. Si vous ne parvenez pas à le retrouver, cliquez sur Ajouts récents dans la barre latérale pour y accéder.

- Choisissez Fichier > Convertir > Créer une version MP3. Le nouveau fichier MP3 apparaît dans votre bibliothèque, à côté du fichier M4A d’origine.

- Pour accéder au fichier converti, sélectionnez le morceau dans Musique, puis choisissez Fichier > Afficher dans le Finder.

## Convertir un fichier M4A en MP3 avec GarageBand

- Dans la barre des menus de GarageBand, choisissez Fichier > Nouveau, sélectionnez Projet vide, puis cliquez sur Choisir.

- Cliquez sur Nouveau projet dans la barre latérale de la fenêtre, sélectionnez Projet vide, puis cliquez sur Choisir.

- Dans la fenêtre Créer une piste, sélectionnez Mic (Micro) ou Line (Ligne).

- Faites glisser le fichier M4A du Finder vers la zone Pistes de GarageBand.

- Cliquez sur le bouton Métronome pour désactiver le métronome.

[Image: null]

[Image: Zone Pistes de GarageBand montrant le fichier sélectionné et le métronome désactivé.]

- Sélectionnez le fichier dans la zone Pistes, puis choisissez Partager > Exporter le morceau vers le disque.

- Dans la fenêtre Exporter le morceau vers le disque :

[Image: Image montrant la fenêtre Exporter le morceau vers le disque.]

- Sélectionnez MP3.

- Choisissez le réglage de qualité du fichier dans le menu local Qualité.

- Sélectionnez l’option « Exporter la zone en boucle ou la durée des régions sélectionnées (si la lecture en boucle est désactivée) ».

- Choisissez un emplacement et un nom pour le fichier.

- Cliquez sur Exporter.

- Pour ajouter le fichier converti à l’app Musique, accédez à son emplacement, puis faites-le glisser vers Musique.
