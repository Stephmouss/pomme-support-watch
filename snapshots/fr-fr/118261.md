# Visualiser les paiements préautorisés dans l’app Cartes d’Apple

Lorsque vous utilisez Apple Pay, vous pouvez consulter et gérer les paiements préautorisés tels que les abonnements, les paiements différés, les factures mensuelles et les paiements échelonnés dans l’app Cartes.

Pour visualiser les paiements préautorisés dans l’app Cartes, vous avez besoin des éléments suivants :

- Un iPhone doté de [la version la plus récente d’iOS](https://support.apple.com/118575)

- Un compte Apple connecté à votre iPhone

## Effectuer des paiements préautorisés à l’aide d’Apple Pay

Les apps et les sites web participants peuvent vous permettre d’effectuer des paiements préautorisés à l’aide d’Apple Pay pour des frais récurrents ou différés. Il suffit de sélectionner l’option Apple Pay au moment du règlement.

Avec les cartes prises en charge, vous pouvez visualiser ces paiements préautorisés dans l’app Cartes.

Pour vous permettre d’accéder aux options de gestion des paiements préautorisés, Apple doit collecter et conserver certaines données relatives à ces paiements. Apple sait quel commerçant est associé à votre paiement préautorisé, mais pas ce que vous avez acheté, ni combien vous avez payé.

## Consulter les paiements préautorisés

- Sur votre iPhone, ouvrez l’app Cartes.

- Touchez le bouton Plus , puis touchez Paiements préautorisés.

- Touchez un commerçant pour afficher plus de détails.

Pour gérer vos préférences de paiement, touchez Gérer avec [commerçant] pour vous rendre sur le site du commerçant.

Si vous ne pouvez pas modifier ou annuler le paiement préautorisé sur le site du commerçant, vous pouvez toucher Révoquer l’autorisation de paiement pour demander à ce que le commerçant ne facture pas le mode de paiement Apple Pay pour les futures transactions.

## Si vous révoquez une autorisation de paiement dans l’app Cartes d’Apple

Pour gérer ou révoquer une autorisation de paiement, rendez-vous sur le site web ou dans l’app du commerçant. Si nécessaire, vous pouvez également révoquer une autorisation de paiement dans l’app Cartes.

- Lorsque vous révoquez une autorisation de paiement dans l’app Cartes, vous n’annulez pas l’abonnement ni les autres paiements associés. Au lieu de cela, Apple demande au commerçant de ne pas facturer le mode de paiement Apple Pay pour les transactions futures.

- Dans certains cas, des frais peuvent quand même s’appliquer. Pour être sûr de ne pas être facturé, rendez-vous sur le site ou dans l’app du commerçant pour gérer vos préférences de paiement directement auprès du commerçant.

Avec les paiements préautorisés, les conditions de service s’appliquent entre le commerçant et vous.

## Si vous supprimez une carte de paiement connectée à un paiement préautorisé de l’app Cartes d’Apple

Le paiement préautorisé n’est pas annulé et les éventuels comptes associés ne sont pas fermés. Pour gérer vos préférences de paiement, touchez Voir les commerçants préautorisés dans l’alerte qui s’affiche lorsque vous supprimez la carte de paiement. Touchez ensuite le commerçant > Gérer avec [commerçant] pour vous rendre sur le site web du commerçant.

## Si votre interface de commerçant préautorisé est différente

L’interface de commerçant préautorisé peut être différente si le commerçant participant ne partage pas les informations de votre abonnement dans l’app Cartes.
