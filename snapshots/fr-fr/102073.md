# Achat sécurisé auprès d’Apple de crédit utilisable dans le cadre du programme d’achat en volume (VPP)

Une fois que votre organisation a acheté du crédit VPP auprès d’Apple, l’acheteur du contenu peut consulter l’historique des commandes et télécharger les codes d’utilisation depuis une boîte de réception sécurisée.

## Acheter du crédit VPP

En tant que cliente Apple School Manager ou Apple Business, votre organisation peut [acheter du crédit VPP](https://support.apple.com/103244) auprès d’Apple ou d’un revendeur Agréé Apple. Lorsqu’un membre de votre organisation achète du crédit VPP, celui-ci doit fournir les informations suivantes :

- La valeur du crédit, que l’acheteur doit calculer à partir du montant total d’argent nécessaire pour le compte de l’acheteur de contenu

- Le nom de l’établissement ou de la société

- Le nom et le compte Apple d’un acheteur de contenu enregistré

Le compte de l’acheteur de contenu est validé et, lorsque la commande est prête, nous envoyons un e-mail contenant un lien vers une boîte de réception sécurisée. L’acheteur de contenu peut alors accéder au crédit VPP de votre organisation à partir de cette boîte de réception sécurisée.

## Utiliser la boîte de réception sécurisée

Vous pouvez [vous connecter à la boîte de réception sécurisée](https://volumepurchaseprogramcredit.apple.com/itunes/index.do) Une fois connecté, vous pouvez télécharger une feuille de calcul dans laquelle apparaît le code d’utilisation associé à chaque commande de crédit VPP. Vous pouvez utiliser ce code pour acheter du contenu à l’aide d’Apps et livres dans Apple School Manager ou Apple Business.

## Renvoyer du crédit VPP

Le crédit VPP est disponible au téléchargement pendant 90 jours dans la boîte de réception sécurisée. Passé ce délai, votre organisation peut renvoyer le crédit VPP si celui-ci a été acheté via l’Apple Store en ligne personnalisé de votre établissement.

- Accédez à votre Apple Store en ligne personnalisé.

- Dans le menu Compte, sélectionnez Vérifier l’état de votre commande.

- Connectez-vous au compte Apple avec lequel le crédit VPP a été acheté. Vous pouvez également saisir le numéro de commande.

- Cliquez sur Renvoyer le crédit.

Si vous n’avez pas acheté le crédit par l’intermédiaire de l’Apple Store en ligne personnalisé de votre établissement, AppleCare peut renvoyer le crédit VPP.

- Envoyez une demande à l’aide du formulaire [Assistance pour les entreprises et l’éducation](https://support.apple.com/fr-fr/business-education-programs) .

- Saisissez vos coordonnées et le nom de votre organisation.

- Pour le type d’organisation, sélectionnez Entreprise ou Éducation.

- Pour le problème, sélectionnez Autre.

- Dans la section « Détails sur votre problème », indiquez le numéro de commande de chaque crédit VPP et demandez à ce que votre crédit VPP arrivé à expiration soit renvoyé à votre compte Apple.

- Cliquez sur Envoyer.
