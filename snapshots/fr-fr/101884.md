# Utiliser vos écouteurs PowerBeats Pro après une réparation ou un remplacement

Découvrez comment utiliser vos écouteurs Powerbeats Pro après une réparation ou un remplacement.

Configurer vos Powerbeats Pro réparés ou de remplacement

- Placez les deux écouteurs Powerbeats Pro dans votre boîtier de charge. Laissez le couvercle ouvert.

- Vérifiez le voyant d’état sur le bord avant du boîtier. Il devrait clignoter en rouge.

- Maintenez enfoncé le bouton système situé à l’intérieur du boîtier pendant cinq secondes. Le voyant d’état doit clignoter en blanc. S’il clignote toujours en rouge, branchez le boîtier sur une source d’alimentation, fermez le couvercle et attendez 20 minutes.

- Jumelez vos Powerbeats Pro avec votre appareil.

Jumeler les écouteurs avec un iPhone

- En laissant vos écouteurs à l’intérieur et le boîtier ouvert, placez les Powerbeats Pro à côté de votre iPhone déverrouillé. Une animation de configuration s’affiche sur votre iPhone.

- Suivez les instructions à l’écran.

Jumeler les écouteurs avec un autre appareil

- Vérifiez que vous avez activé le Bluetooth sur votre appareil.

- En laissant vos écouteurs à l’intérieur et le boîtier ouvert, maintenez le bouton système de vos Powerbeats Pro enfoncé jusqu’à ce que le voyant clignote.

- Ouvrez le menu Bluetooth sur votre appareil. Par exemple, sur votre Mac, choisissez le menu Pomme () > Préférences Système, puis cliquez sur Bluetooth.

- Dans la liste des appareils Bluetooth détectés, sélectionnez vos Powerbeats Pro.
