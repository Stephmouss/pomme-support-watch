# Si vous ne parvenez pas à accéder aux licences dans Apple Configurator

Découvrez la marche à suivre si vous ne parvenez pas à accéder à vos licences après la migration vers Apps et livres dans Apple School Manager.

## Révoquer toutes les licences attribuées

- Ouvrez Apple Configurator.

- Choisissez Compte.

- Sélectionnez Se connecter, puis connectez-vous à l’App Store avec votre compte Apple géré.

- Choisissez Fenêtre, puis sélectionnez Attributions VPP.

- Cliquez sur le triangle situé en regard d’une app pour afficher le numéro de série des appareils auxquels elle est attribuée.

- Sélectionnez un appareil dans la liste, cliquez sur Supprimer dans la barre d’outils, puis sur Révoquer.

- Répétez les étapes 4 et 5 pour révoquer les licences des éventuelles autres apps.

## Transférer vos anciennes licences

Après avoir révoqué toutes les licences attribuées, suivez ces étapes.

- Connectez-vous à Apple School Manager.

- Cliquez sur Réglages, puis sur Apps et livres.

- Transférez toutes les anciennes licences.

## Créer un site pour Apple Configurator

Après avoir transféré vos anciennes licences, suivez ces étapes.

- Cliquez sur Sites.

- Cliquez sur Ajouter un nouveau site*.

- Saisissez les informations du nouveau site, puis cliquez sur Enregistrer. Ce site sera uniquement utilisé par Apple Configurator.

## Créer un gestionnaire de contenu

Après avoir créé un site, suivez ces étapes.

- Cliquez sur Comptes.

- Cliquez sur Ajouter un nouveau compte*.

- Saisissez les informations du compte, sélectionnez le rôle Gestionnaire de contenu, puis choisissez le nouveau site pour Apple Configurator.

- Cliquez sur Enregistrer la personne.

- Cliquez sur Créer les informations de connexion, notez le nom et le mot de passe, puis déconnectez-vous.

## Acheter des licences gratuites sur le nouveau site

Après avoir créé un gestionnaire de contenu, suivez ces étapes.

- Connectez-vous à Apple School Manager avec le compte du nouveau gestionnaire de contenu.

- Cliquez sur Apps et livres.

- Sélectionnez Premiers pas, puis transférez les licences vers le nouveau site si vous y êtes invité.

- Recherchez une app gratuite que vous souhaitez déployer.

- Sélectionnez l’app dans les résultats de la recherche.

- Choisissez le site Apple Configurator que vous avez créé.

- Saisissez une quantité, puis cliquez sur Obtenir.

- Une fois que les licences apparaissent comme disponibles, connectez-vous à Apple Configurator.

## Connectez-vous à Apple Configurator.

Après avoir récupéré les licences gratuites sur le nouveau site, procédez comme suit :

- Ouvrez Apple Configurator.

- Choisissez Compte.

- Sélectionnez Se connecter, puis connectez-vous avec le compte du nouveau gestionnaire de contenu.

- Choisissez Fenêtre.

- Sélectionnez Attributions d’achat en volume, puis vérifiez que les licences sont répertoriées.

Une fois ces étapes terminées, vous pouvez transférer des licences vers le nouvel emplacement Apple Configurator tout en étant connecté avec un compte de gestionnaire de contenu.
