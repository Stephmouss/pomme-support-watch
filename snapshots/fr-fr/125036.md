# À propos de la bibliothèque de sons Logic Pro et MainStage sur Mac

Après la mise à jour vers Logic Pro 12 ou MainStage 4 à partir de versions antérieures, votre bibliothèque de sons est automatiquement clonée dans un nouveau fichier de lot consolidé.

À partir de Logic Pro 12 et MainStage 4, tous les fichiers de la bibliothèque de sons inclus avec Logic Pro et MainStage, tels que les patchs d’instruments logiciels, les boucles Apple Loops et les échantillons, sont stockés dans un seul fichier intitulé « Logic Pro Library.bundle ». Le nouveau fichier rationalise les processus de la bibliothèque de sons, comme l’utilisation de celle-ci sur d’autres ordinateurs et sa relocalisation vers un périphérique de stockage externe.

La façon dont votre bibliothèque de sons est clonée dépend de son emplacement actuel.

## Si votre bibliothèque de sons se trouve sur votre Mac

Lorsque vous ouvrez Logic Pro 12 ou MainStage 4 pour la première fois, l’app clone votre bibliothèque de sons. Le nouveau fichier se trouve dans votre dossier Musique. L’opération de clonage ne nécessite aucun espace de stockage supplémentaire. Vous n’avez pas besoin de supprimer les anciens fichiers de la bibliothèque de sons pour optimiser l’espace de stockage sur votre Mac. Lorsque vous téléchargez un nouveau contenu de la bibliothèque de sons, il est stocké dans le nouveau fichier de la bibliothèque de sons.

Vous pouvez travailler sur des projets pendant que Logic Pro ou MainStage clone votre bibliothèque de sons. Si vous fermez l’app pendant le processus de clonage, ce dernier reprend automatiquement lorsque vous rouvrez l’app.

## Si votre bibliothèque de sons se trouve sur un périphérique de stockage externe

Si vous avez [déplacé votre bibliothèque de sons vers un périphérique externe](https://support.apple.com/fr-fr/111094) , la façon dont Logic Pro ou MainStage crée le nouveau fichier de la bibliothèque de sons varie selon que votre périphérique de stockage utilise ou non le format APFS.

[Le format APFS (Apple File System)](https://support.apple.com/guide/disk-utility/file-system-formats-dsku19ed921c/mac) est le système de fichiers par défaut utilisé pour formater les appareils Apple et les périphériques de stockage externes.

### Vérifier le format de votre périphérique de stockage externe

- Dans le Finder, sélectionnez le périphérique de stockage dans la barre latérale.

- Sélectionnez Fichier > Lire les informations. Le format du périphérique de stockage apparaît dans la section Général.

### Périphériques de stockage au format APFS

Si vous avez formaté votre périphérique de stockage externe en APFS, Logic Pro ou MainStage clone votre bibliothèque de sons à l’emplacement actuel et ne nécessite aucun espace de stockage supplémentaire. Lorsque vous téléchargez un nouveau contenu de la bibliothèque de sons, il est stocké dans le nouveau fichier de la bibliothèque sur le périphérique de stockage externe.

### Périphériques de stockage au format Mac OS étendu ou utilisant des systèmes de fichiers compatibles avec Windows

Si votre bibliothèque de sons se trouve sur un périphérique externe au format Mac OS étendu ou utilisant un système de fichiers Windows comme MS-DOS (FAT) ou ExFAT, Logic Pro ou MainStage fait une copie de votre bibliothèque de sons dans le nouveau type de fichier. Le périphérique de stockage doit disposer de suffisamment d’espace libre pour accueillir à la fois les anciens éléments de la bibliothèque et le nouveau fichier de la bibliothèque.

#### Si vous avez suffisamment d’espace sur votre périphérique de stockage

Une fois que Logic Pro ou MainStage a terminé la copie de la bibliothèque, vous pouvez supprimer les fichiers d’origine de la bibliothèque de sons pour récupérer de l’espace sur votre périphérique de stockage. Si d’anciennes versions des apps sont installées, ne supprimez pas la bibliothèque de sons d’origine. Le nouveau fichier de la bibliothèque de sons n’est pas compatible avec les anciennes versions des apps.

#### Si vous n’avez pas assez d’espace sur votre périphérique de stockage

Une alerte apparaît et indique que le périphérique de stockage ne dispose pas d’assez d’espace libre pour le nouveau fichier de la bibliothèque de sons. Pour stocker le nouveau fichier de la bibliothèque de sons sur ce périphérique de stockage :

- Notez l’espace libre dont votre périphérique de stockage a besoin, puis cliquez sur OK dans l’alerte.

- Quittez Logic Pro ou MainStage.

- Pour libérer de l’espace sur votre périphérique de stockage externe :

- Supprimez des éléments du périphérique de stockage, puis videz la corbeille.

- Déplacez des éléments du périphérique de stockage vers un autre emplacement, par exemple le bureau de votre Mac.

- Rouvrez Logic Pro ou MainStage. Cliquez sur Continuer dans la boîte de dialogue relative à la copie de votre bibliothèque de sons.

Vous pouvez également effectuer l’une des opérations suivantes :

- [Effacer et reformater le périphérique de stockage en APFS](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac)

- Vous procurer un nouveau périphérique de stockage et [le formater en APFS](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac)

Si vous choisissez l’une de ces options, vous devrez télécharger les sons que vous souhaitez, puis déplacer la bibliothèque vers le périphérique de stockage :

- Ouvrez Logic Pro (ou MainStage), puis choisissez Logic Pro (ou MainStage) > Bibliothèque de sons.

- Cliquez sur Gérer les paquets dans la bibliothèque de sons, puis téléchargez les paquets de sons que vous souhaitez.

- [Déplacez la bibliothèque de sons vers le périphérique de stockage reformaté ou le nouveau](https://support.apple.com/fr-fr/111094) .
