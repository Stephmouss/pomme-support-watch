# Si vous ne pouvez pas utiliser votre Apple Gift Card, App Store Card ou carte cadeau App Store & iTunes

Si vous ne pouvez pas utiliser votre carte cadeau dans l’App Store ou l’iTunes Store, voici quelques solutions que vous pouvez essayer.

## Si un message s’affiche lorsque vous essayez d’utiliser votre carte cadeau

- [La carte n’est pas valide](https://support.apple.com/fr-fr/108285#invalid)

- [La carte a déjà été utilisée](https://support.apple.com/fr-fr/108285#redeemed)

- [La carte n’est pas activée](https://support.apple.com/fr-fr/108285#inactive)

- [Le code doit être utilisé dans un autre pays ou région](https://support.apple.com/fr-fr/108285#differentcountry)

### La carte n’est pas valide

Si un message s’affiche, indiquant que votre carte n’est pas valide :

- Vérifiez que votre carte n’est pas une carte cadeau Apple Store. Les cartes cadeaux Apple Store sont grises, blanches, argentées ou dorées. Vous ne pouvez pas utiliser les cartes cadeaux Apple Store dans l’App Store ou l’iTunes Store. Découvrez la marche à suivre [si vous possédez une carte cadeau Apple Store ou une carte cadeau dont vous ne connaissez pas le type](https://support.apple.com/fr-fr/118407) .

- Essayez de saisir votre code de téléchargement manuellement. Lorsque vous [utilisez une carte cadeau](https://support.apple.com/fr-fr/118242) , touchez ou cliquez sur « Saisir votre code manuellement ». Assurez-vous de saisir le code de téléchargement qui commence par « X », et non un numéro différent sur la carte.

- Veillez à saisir les bons caractères. Certains chiffres et certaines lettres peuvent facilement se confondre, tels que :

- La lettre B et le chiffre 8

- Les lettres D et O

- La lettre E et le chiffre 3

- La lettre G et le chiffre 6

- Les lettres O et Q

- La lettre O et le chiffre 0

- La lettre S et le chiffre 5

- Les lettres U et V

- La lettre Z et le chiffre 2

### La carte a déjà été utilisée

Si vous voyez un message indiquant que votre carte a déjà été utilisée, cela est peut-être le cas. Déconnectez-vous de l’App Store ou de l’iTunes Store sur tous vos appareils, puis reconnectez-vous. Cette opération actualise le solde de votre compte Apple. Découvrez comment [vérifier le solde de votre compte Apple](https://support.apple.com/fr-fr/119902) .

### La carte n’est pas activée

Si vous recevez un message indiquant que votre carte n’a pas été correctement activée, il se peut qu’elle n’ait pas été activée par le détaillant qui vous l’a vendue. Adressez-vous à lui afin de résoudre ce problème.

### Le code doit être utilisé dans un autre pays ou région

Si un message vous indique que le code doit être utilisé dans un autre Store, cela signifie que la carte a probablement été achetée dans un autre pays ou une autre région. Vous ne pouvez pas utiliser les Apple Gift Cards, App Store Cards ou cartes cadeaux App Store & iTunes en dehors du pays ou de la région d’achat. Par exemple, si vous avez acheté une Apple Gift Card en France, vous ne pouvez pas l’utiliser dans l’App Store aux États-Unis. Si vous possédez une carte cadeau physique, vous pouvez vous rendre chez le revendeur où la carte a été achetée.

## Si le code de votre carte cadeau est illisible

Si vous ne pouvez pas lire le code au verso de votre carte parce qu’elle est rayée ou endommagée, contactez l’assistance Apple.

## Si le problème persiste

Si vous avez encore besoin d’aide, [contactez l’assistance Apple](https://getsupport.apple.com/?caller=kbase&PGF=PGF63003&category_id=SC0082&symptom_id=20256) .

### Vous devrez peut-être fournir les éléments suivants :

- Une image entière du recto et du verso de votre carte.

- Reçu indiquant la date d’achat de la carte

- Le numéro de série de votre carte.

### Trouver votre numéro de série

Le numéro de série et le code commençant par « X » qui vous permet d’utiliser la carte sont deux choses différentes. Les numéros de série se trouvent au verso de votre carte. Voici quelques exemples d’emplacements où vous pourriez voir le numéro de série :
