# Identification à deux facteurs pour le compte Apple

L’identification à deux facteurs est conçue pour s’assurer que vous êtes la seule personne à pouvoir accéder à votre compte. Découvrez son fonctionnement et comment l’activer.

[Image: Lire une vidéo montrant comment utiliser un code de validation à six chiffres pour vous connecter à votre compte Apple.]

## Qu’est-ce que l’identification à deux facteurs ?

L’identification à deux facteurs offre une protection supplémentaire pour votre compte Apple. Elle permet ainsi de garantir que vous êtes la seule personne pouvant accéder à votre compte, même si quelqu’un d’autre connaît votre mot de passe.

L’identification à deux facteurs améliore considérablement la sécurité de votre compte Apple et des données que vous stockez auprès d’Apple. Lorsque vous vous connectez à votre compte Apple sur un nouvel appareil ou sur le Web pour la première fois, vous devez avoir à disposition :

- Le mot de passe de votre compte Apple.

- Le code de validation à six chiffres qui s’affiche automatiquement sur vos appareils de confiance ou qui est envoyé à votre numéro de téléphone de confiance.

L’identification à deux facteurs est la méthode de sécurité par défaut pour la plupart des comptes. Certains services et certaines fonctionnalités Apple, tels qu’Apple Pay et Se connecter avec Apple, nécessitent une identification à deux facteurs. De plus, Apple vous recommande de protéger vos appareils :

- En saisissant un code d’accès (ou un mot de passe de connexion sur Mac),

- En activant Face ID, Touch ID ou Optic ID, si votre appareil est compatible.

[En savoir plus sur les appareils de confiance et les numéros de téléphone de confiance](https://support.apple.com/fr-fr/122621)

## Que se passe-t-il lorsque vous vous connectez à l’aide de l’identification à deux facteurs ?

Lorsque vous vous connecterez à votre compte Apple sur un nouvel appareil ou sur le Web, vous devrez peut-être saisir un code de validation. Si vous utilisez du [contenu chiffré de bout en bout stocké sur iCloud](https://support.apple.com/fr-fr/102651) sur un appareil Apple, il vous sera peut-être également demandé de saisir le code d’accès de l’un de vos appareils.

Après la première connexion, vous n’aurez plus besoin de saisir de code de validation sur cet appareil, sauf si :

- Vous vous déconnectez complètement de votre compte Apple sur cet appareil.

- Vous effacez le contenu de l’appareil.

- Vous devez modifier votre mot de passe pour des raisons de sécurité.

## Activation de l’identification à deux facteurs pour votre compte Apple

La plupart des comptes utilisent déjà l’identification à deux facteurs. Si vous n’utilisez pas l’identification à deux facteurs pour votre compte Apple, vous pouvez l’activer à l’aide de votre appareil ou sur le Web.

### Sur votre appareil Apple

- Accédez à Réglages sur votre iPhone ou iPad, ou à Réglages Système sur votre Mac.

- Sélectionnez [votre nom], puis Connexion et sécurité.

- Activez l’identification à deux facteurs, puis suivez les instructions qui s’affichent à l’écran.

### Sur le Web

- Rendez-vous sur [account.apple.com](https://account.apple.com/) et connectez-vous à votre compte Apple.

- Vous devrez peut-être saisir un code qui vous sera envoyé à votre adresse e-mail ou répondre à des questions de sécurité.

- Touchez Mettre à niveau la sécurité du compte, puis suivez les instructions qui s’affichent à l’écran.

Si vous avez utilisé l’identification à deux facteurs pour créer votre compte Apple, cette protection supplémentaire ne peut pas être supprimée. Si vous avez récemment activé l’identification à deux facteurs, vous avez la possibilité de réduire la sécurité de votre compte dans les deux semaines suivant l’activation.
