# Convertir un fichier MOV au format MP4 sur Mac

Vous pouvez facilement convertir un fichier MOV au format MP4 sur votre Mac afin de pouvoir charger une vidéo sur un site web ou l’ouvrir dans d’autres apps qui ne prennent pas en charge les fichiers MOV.

- Pour convertir rapidement un fichier MOV utilisant le codec H.264, il vous suffit de [remplacer l’extension de nom de fichier du fichier MOV](https://support.apple.com/fr-fr/120755#File_extension) par MP4.

- Pour ajuster la résolution ou la taille du fichier, ou pour convertir un fichier utilisant un codec autre que H.264, [utilisez iMovie](https://support.apple.com/fr-fr/120755#iMovie) .

Pour maîtriser davantage les processus de conversion et d’exportation de fichiers vidéo, utilisez Final Cut Pro ou Compressor, tous deux disponibles sur le Mac App Store.

## Modifier l’extension de nom de fichier pour convertir un fichier MOV au format MP4

- Dans le Finder, recherchez le fichier MOV que vous souhaitez convertir.

- Sélectionnez le fichier, puis choisissez Fichier > Lire les informations. Dans la section Plus d’informations, assurez-vous que l’un des codecs est H.264. Si le fichier utilise un codec autre que H.264, [utilisez iMovie pour le convertir](https://support.apple.com/fr-fr/120755#iMovie) .

[Image: Fenêtre Lire les informations pour un fichier MOV utilisant le codec H.264]

- Si vous souhaitez conserver le fichier MOV d’origine avant de le convertir, cliquez dessus tout en maintenant la touche Contrôle enfoncée, puis choisissez Dupliquer pour créer une copie.

- Cliquez sur le fichier MOV tout en maintenant la touche Contrôle enfoncée, puis choisissez Renommer.

- Sélectionnez l’extension de nom de fichier MOV, saisissez « mp4 » après le point, puis appuyez sur Retour.

- Choisissez « Utiliser .mp4 » dans la fenêtre qui s’affiche.

Le type de fichier est modifié, mais la résolution de la vidéo et la taille du fichier MP4 restent identiques au fichier MOV d’origine. Si vous souhaitez réduire la taille du fichier vidéo ou modifier la résolution ou la qualité de la vidéo, convertissez cette dernière en utilisant iMovie.

Si la vidéo ne charge pas sur le site web ou l’app après avoir modifié l’extension du fichier, [utilisez iMovie pour convertir le fichier MOV d’origine](https://support.apple.com/fr-fr/120755#iMovie) .

## Convertir un fichier MOV au format MP4 avec iMovie pour Mac

- Ouvrez iMovie sur votre Mac. Cliquez sur Créer dans la vue Projets, puis choisissez Film. Si vous travaillez déjà sur une vidéo, cliquez sur Projets pour accéder à la vue Projets.

- Cliquez sur le bouton Importer en haut de la fenêtre iMovie, puis recherchez le fichier MOV que vous souhaitez convertir.

- Sélectionnez le fichier MOV, puis cliquez sur Importer la sélection. Le fichier MOV est ajouté au navigateur de projets dans iMovie.

- Sélectionnez le fichier MOV dans le navigateur, puis choisissez Modifier > Ajouter à la vidéo (ou appuyez sur la touche E).

[Image: Commande Ajouter à la vidéo du menu Fichier dans iMovie]

- Cliquez sur le bouton Partager , puis choisissez Exporter le fichier.

[Image: null]

- Si vous souhaitez réduire la taille du fichier converti, cliquez sur Qualité dans le menu local, puis sélectionnez Moyenne ou Faible. Vous pouvez également réduire la taille du fichier en diminuant la résolution. La taille estimée du fichier converti est indiquée sous la vignette.

- Cliquez sur Suivant, choisissez un emplacement pour l’exportation du fichier MP4, puis cliquez sur Enregistrer.

## Convertir et exporter des fichiers vidéo avec Final Cut Pro ou Compressor

Vous pouvez utiliser Final Cut Pro sur votre Mac [pour convertir des fichiers MOV et exporter des projets au format MP4](https://support.apple.com/guide/final-cut-pro/export-final-mastering-files-ver0192a47b8/mac) .

Pour une conversion et une exportation de fichiers vidéo optimales, utilisez [Compressor, disponible sur le Mac App Store](https://apps.apple.com/fr/app/compressor/id424390742) . Consultez le [guide d’utilisation de Compressor](https://support.apple.com/guide/compressor/welcome/mac) pour plus d’informations.
