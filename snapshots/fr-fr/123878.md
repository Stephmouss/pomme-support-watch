# Transférer votre eSIM d’un appareil Android vers un iPhone

Si vous transférez une eSIM d’un smartphone d’une autre marque qu’Apple vers un iPhone, vous devrez peut-être contacter votre opérateur. Il peut transférer votre eSIM soit via l’activation de l’eSIM par l’opérateur, soit en vous fournissant un code QR. En savoir plus sur [la configuration de votre iPhone avec une eSIM](https://support.apple.com/fr-fr/118669) [.](https://support.apple.com/en-us/118669)

Avec iOS 26 et versions ultérieures, certains opérateurs et fabricants de smartphones fournissent une assistance pour le transfert de votre SIM d’Android vers l’iPhone, ou inversement. Si votre opérateur ou votre appareil ne fournit pas d’assistance pour la fonctionnalité de transfert de votre eSIM d’Android vers l’iPhone, contactez votre opérateur pour activer votre eSIM.

## Éléments requis

- Un opérateur pris en charge :

- États-Unis : AT&T, Cricket, FirstNet, T-Mobile, Verizon, Xfinity Mobile

- Autriche : A1, Magenta

- Brésil : TIM

- Canada : Bell, Koodo, Lucky Mobile, Telus, Virgin Mobile

- Tchéquie : T-Mobile

- France : Free Mobile, Orange, SFR

- Allemagne : Telekom, 1&1

- Japon : au, UQ

- Mexique : AT&T

- Pays-Bas : KPN

- Slovaquie : Slovak Telekom

- Suisse : Swisscom

- Royaume-Uni : EE

- Un iPhone 11, iPhone 11 Pro, iPhone 11 Pro Max ou un modèle ultérieur doté d’iOS 26 ou d’une version ultérieure

- Un smartphone Android compatible doté d’Android 16 ou version ultérieure Pour savoir si votre appareil Android est compatible, vérifiez auprès du fabricant de votre smartphone.

- Vous devez connecter votre iPhone et votre smartphone Android à un réseau Wi-Fi et activer le Bluetooth.

## Transférer votre eSIM d’Android vers l’iPhone lors de la configuration d’un nouvel iPhone

Si vos appareils sont compatibles, vous pouvez transférer votre eSIM depuis votre smartphone Android lors de la configuration de votre nouvel iPhone. Découvrez comment [transférer votre eSIM et vos données d’Android vers iOS ou iPadOS sans l’app Migrer vers iOS](https://support.apple.com/118670#noapp) .

Une fois que vous avez transféré votre eSIM sur votre nouvel iPhone, la carte SIM de votre appareil Android se désactive.

## Transférer votre eSIM d’Android vers l’iPhone dans l’app Réglages

Après avoir configuré votre nouvel iPhone, transférez votre eSIM de votre smartphone Android vers l’iPhone dans l’app Réglages.

Avant de commencer, placez vos téléphones côte à côte afin de pouvoir lire les invites des deux appareils.

- Sur votre iPhone, ouvrez l’app Réglages.

- Touchez Activer le forfait cellulaire, puis Transférer à partir d’Android. Si votre iPhone est déjà doté d’une autre carte SIM, touchez Données cellulaires, puis Ajouter une carte eSIM et Transférer à partir d’Android.

- Touchez Transférer à partir d’Android. Un code QR sera généré. Si vous ne parvenez pas à scanner le code QR sur votre iPhone, consultez la section [Utiliser d’autres options si vous ne parvenez pas à scanner le code QR de l’iPhone](https://support.apple.com/fr-fr/123878#otheroptions) . Sinon, passez à l’étape suivante.

- Utilisez la caméra de votre smartphone Android pour scanner le code QR sur votre iPhone.

- Sur votre appareil Android, sélectionnez le numéro de téléphone que vous souhaitez transférer et touchez Transférer.

- Si un message vous y invite, touchez Oui pour utiliser la carte SIM transférée comme eSIM principale.

- Une fois le transfert terminé, touchez Terminé sur votre iPhone, puis OK.

- Passez un appel téléphonique sur votre iPhone pour vérifier sa connectivité mobile. Si vous ne parvenez pas à passer un appel, contactez votre opérateur.

Une fois que vous avez transféré votre eSIM sur votre nouvel iPhone, la carte SIM de votre appareil Android se désactive.

## Utiliser d’autres options si vous ne pouvez pas scanner le code QR de l’iPhone

- Sur votre iPhone, sélectionnez Autres options sous le code QR.

- Sur votre appareil Android, ouvrez l’app Paramètres.

- Touchez Services Google.

- Touchez Tous les services.

- Touchez Jumeler avec iPhone ou iPad.

- Touchez Transférer l’eSIM.

- Saisissez l’identifiant de session et le code de jumelage qui s’affiche sur votre iPhone, puis touchez Suivant.

- Sélectionnez le numéro de téléphone que vous souhaitez transférer et touchez Transférer.

- Si un message vous y invite, touchez Oui pour utiliser la carte SIM transférée comme eSIM principale.

- Une fois le transfert terminé, touchez Terminé sur votre iPhone, puis OK.

- Passez un appel téléphonique sur votre iPhone pour vérifier sa connectivité mobile. Si vous ne parvenez pas à passer un appel, contactez votre opérateur.

Une fois que vous avez transféré votre eSIM sur votre nouvel iPhone, la carte SIM de votre appareil Android se désactive.

## Obtenir de l’aide

Si vous ne parvenez pas à transférer votre carte SIM de votre appareil Android vers votre iPhone avec l’une de ces méthodes, contactez votre opérateur.
