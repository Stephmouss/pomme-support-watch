# Si GarageBand ne fonctionne pas sur votre Mac

Découvrez la marche à suivre si GarageBand sur votre Mac ne s’ouvre pas, si vous ne parvenez pas à lire ou à enregistrer un projet, ou pour tout autre problème.

## Essayer d’appliquer ces étapes dans l’ordre

- [Redémarrer votre Mac](https://support.apple.com/fr-fr/102247#A)

- [Mettre à jour GarageBand](https://support.apple.com/fr-fr/102247#B)

- [Vérifier la compatibilité de votre appareil ou de votre logiciel](https://support.apple.com/fr-fr/102247#C)

- [Utiliser le système audio intégré à GarageBand](https://support.apple.com/fr-fr/102247#D)

- [Ouvrir GarageBand sans entrée ni sortie audio](https://support.apple.com/fr-fr/102247#E)

- [Désactiver les modules Audio Units](https://support.apple.com/fr-fr/102247#F)

- [Faire un test avec un nouveau projet](https://support.apple.com/fr-fr/102247#G)

- [Tester GarageBand avec un nouveau compte d’utilisateur](https://support.apple.com/fr-fr/102247#H)

- [Réinitialiser les préférences GarageBand](https://support.apple.com/fr-fr/102247#I)

### Redémarrer votre Mac

Choisissez Redémarrer dans le menu Pomme .

[Haut de page](https://support.apple.com/fr-fr/102247#top)

### Mettre à jour GarageBand

Choisissez le menu Pomme  > App Store, puis cliquez sur Mises à jour dans la barre d’outils. Si une mise à jour de GarageBand est disponible, cliquez sur le bouton Mettre à jour pour la télécharger et l’installer.

[Haut de page](https://support.apple.com/fr-fr/102247#top)

### Vérifier la compatibilité de votre appareil ou de votre logiciel

Si vous utilisez une interface audio externe, une interface MIDI, un système de stockage, une surface de contrôle ou un module tiers, vérifiez que cet élément est compatible avec la dernière version de GarageBand. [Contactez le fabricant pour obtenir de l’aide](https://support.apple.com/fr-fr/103190) . Si une mise à jour est disponible, suivez les instructions du fabricant pour mettre à jour votre appareil ou votre logiciel.

[Haut de page](https://support.apple.com/fr-fr/102247#top)

### Utiliser le système audio intégré à GarageBand

Si vous utilisez une interface audio externe, essayez d’utiliser le système audio intégré de votre Mac au lieu de cette interface.

- Débranchez l’interface audio externe de votre Mac.

- Ouvrez GarageBand, puis choisissez GarageBand > Préférences > Audio/MIDI.

[Image: Désactivation des unités audio dans les préférences de GarageBand sous elcap]

- Choisissez Sortie intégrée dans le menu local Sortie audio.

- Choisissez Micro intégré (ou Entrée intégrée, selon votre ordinateur) dans le menu local Entrée audio.

- Ouvrez et lisez un projet qui ne fonctionnait pas correctement.

Si le projet s’ouvre et se lance correctement, vous avez peut-être besoin de mettre à jour ou de réparer votre interface audio. Contactez le fabricant pour obtenir de l’aide.

[Haut de page](https://support.apple.com/fr-fr/102247#top)

### Ouvrir GarageBand sans entrée ni sortie audio

- Ouvrez GarageBand et maintenez immédiatement la touche Contrôle enfoncée avant qu’un projet ne s’ouvre.

- Sur le message qui s’affiche, cliquez sur Ne pas lancer.

[Image: Lancement du pilote de Core Audio dans GarageBand sous elcap]

Si GarageBand s’ouvre, cela peut indiquer les points suivants :

- Vous avez peut-être besoin de mettre à jour ou de réparer votre interface audio externe. Contactez le fabricant pour obtenir de l’aide.

- Un module Audio Units est peut-être endommagé ou n’est peut-être pas compatible avec votre version de GarageBand. Désactivez les modules pour continuer à résoudre votre problème.

[Haut de page](https://support.apple.com/fr-fr/102247#top)

### Désactiver les modules Audio Units

Si vous utilisez des modules Audio Units, essayez de les désactiver. Des modules Audio Units défectueux ou non compatibles peuvent engendrer des comportements inattendus dans GarageBand.

Pour désactiver les modules Audio Units :

- Ouvrez un projet dans GarageBand.

- Accédez à GarageBand > Préférences > Audio/MIDI et désélectionnez Audio Units.

- Lancez un projet qui ne fonctionnait pas correctement.

Si le projet s’ouvre et se lance correctement, un module utilisé dans le projet est peut-être endommagé ou incompatible avec votre version de GarageBand. Contactez le fabricant du module pour obtenir de l’aide.

[Haut de page](https://support.apple.com/fr-fr/102247#top)

### Faire un test avec un nouveau projet

Vous pouvez créer un autre projet et le tester pour vérifier si le problème provient de votre projet ou de l’app GarageBand.

- Si GarageBand est ouvert, quittez l’app.

- Ouvrez GarageBand et choisissez Fichier > Nouveau.

- Choisissez Projet vide dans la fenêtre Nouveau projet.

- Ajoutez des fichiers audio ou Apple Loops au nouveau projet.

- Essayez de reproduire le problème que vous rencontriez. Par exemple, si le projet avec lequel vous rencontrez un problème utilise un module tiers particulier, ajoutez-le au projet de test. Si le problème se reproduit, le module est peut-être endommagé ou doit peut-être être mis à jour.

[Haut de page](https://support.apple.com/fr-fr/102247#top)

### Tester GarageBand avec un nouveau compte d’utilisateur

[Créez un autre compte utilisateur sur votre Mac](https://support.apple.com/guide/mac-help/mtusr001/mac) , puis essayez de recréer le problème dans le nouveau compte utilisateur. Si le problème ne se produit pas avec le nouveau compte utilisateur, les réglages du compte d’origine peuvent être à l’origine du problème.

[Haut de page](https://support.apple.com/fr-fr/102247#top)

### Réinitialiser les préférences GarageBand

La réinitialisation des préférences n’a pas d’impact sur les fichiers, les réglages prédéfinis ou les correctifs du projet. Toutefois, tous les réglages personnalisés que vous avez créés sont supprimés.

- Choisissez GarageBand > Préférences et notez les préférences spécifiques que vous avez définies.

- Fermez GarageBand.

- Dans le Finder, choisissez Utilitaires à partir du menu Aller.

- Ouvrez Terminal.

- Copiez la commande suivante, collez-la dans Terminal, puis appuyez sur Retour : defaults delete com.apple.garageband10

- Si vous avez déjà effectué une mise à jour à partir d’une version précédente de GarageBand, copiez également cette commande, collez-la dans Terminal, puis appuyez sur Retour : defaults delete com.apple.garageband

- Redémarrez l’ordinateur.

Une fois le Mac redémarré, ouvrez GarageBand et essayez de reproduire le problème que vous rencontriez. Si le problème ne se reproduit plus, ouvrez les préférences GarageBand et appliquez à nouveau vos réglages personnalisés.

[Haut de page](https://support.apple.com/fr-fr/102247#top)
