# Où sont installées les boucles Apple Loops pour Logic Pro pour Mac et MainStage ?

Vous trouverez les fichiers Apple Loops (boucles d’origine et personnalisées) dans les dossiers de la bibliothèque de votre Mac.

Lorsque vous choisissez d’installer les boucles Apple Loops incluses dans Logic Pro et MainStage, les fichiers sont enregistrés dans /Bibliothèque/Audio/Apple Loops/Apple. Les patchs individuels (fichiers CAF) de chaque collection se trouvent dans ces sous-dossiers :

- 01 Hip Hop

- 02 Electro House

- 03 Dubstep

- 04 Modern RnB

- 05 Tech House

- 06 Deep House

- 07 Chillwave

- Boucles Apple Loops pour GarageBand

- Effets sonores iLife

- Jam Pack 1

- Jam Pack Remix Tools

- Jam Pack Rhythm Section

- Jam Pack Symphony Orchestra

- Jam Pack Voices

- Jam Pack World Music

Les boucles Apple Loops personnalisées que vous avez créées se trouvent dans la bibliothèque de votre dossier de départ, à laquelle vous pouvez accéder à partir du Finder :

- Choisissez Aller > Aller au dossier dans la barre des menus.

- Saisissez ~/Bibliothèque/Audio/Apple Loops dans le champ « Aller au dossier ».

- Cliquez sur Aller.
