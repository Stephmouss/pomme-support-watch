# Si Face ID ne fonctionne pas sur votre iPhone ou iPad Pro

Découvrez comment procéder si vous ne parvenez pas à déverrouiller votre iPhone ou iPad, à authentifier des achats ou à vous connecter à des apps à l’aide de Face ID, ou si vous êtes invité à saisir votre code d’accès.

## Rechercher des mises à jour

[Mettez à jour votre iPhone ou iPad vers la dernière version d’iOS ou d’iPadOS](https://support.apple.com/118575) . Assurez-vous également que [votre modèle d’iPhone ou d’iPad prend en charge Face ID](https://support.apple.com/102854) .

## Vérifier les réglages de Face ID

Pour vérifier les réglages de Face ID, accédez à Réglages, puis touchez Face ID et code. Assurez-vous que [Face ID est configuré](https://support.apple.com/108411) et que les fonctionnalités avec lesquelles vous essayez de l’utiliser sont activées.

[Image: Écran d’iPhone affichant les réglages Face ID et code avec des boutons d’activation pour Face ID, le déverrouillage de l’iPhone et d’autres fonctionnalités.]

## S’assurer qu’aucun élément extérieur n’obstrue la caméra TrueDepth

Retirez tout ce qui pourrait obstruer la caméra TrueDepth, comme une tache, un étui ou une protection d’écran. Sur les modèles d’iPhone 18 Pro, la caméra TrueDepth se trouve en haut de l’appareil, vers l’angle gauche.

Si vous utilisez un iPad ou un modèle d’iPhone 18 Pro en orientation paysage, assurez-vous que votre doigt ou la paume de votre main ne couvre pas la caméra TrueDepth.

[Image: Lorsque vous utilisez Face ID avec votre iPhone en orientation portrait, vous risquez moins de couvrir la caméra TrueDepth avec votre doigt.]

## S’assurer que rien ne couvre votre visage

Veillez à ce que vos yeux, votre nez et votre bouche soient entièrement visibles pour la caméra TrueDepth. Par défaut, Face ID ne fonctionne pas si quelque chose couvre votre bouche et votre nez.

Si vous portez un masque et que vous avez déjà [configuré Face ID pour fonctionner avec un masque](https://support.apple.com/102452) *, assurez-vous que rien ne couvre vos yeux. Vous devrez peut-être tenir votre iPhone plus haut ou essayer de le tenir plus haut et plus près si vous portez un masque. Si votre masque remonte trop haut sur votre visage ou qu’il est trop près de vos yeux, il est possible que l’iPhone ne se déverrouille pas.

Face ID fonctionne avec de nombreuses paires de lunettes de soleil. Néanmoins, Face ID n’est pas conçu pour vous reconnaître lorsque vous portez à la fois un masque et des lunettes de soleil. Toutefois, les modèles conçus pour filtrer certains types de lumière peuvent bloquer la lumière infrarouge utilisée par la caméra TrueDepth. Essayez d’utiliser Face ID sans vos lunettes de soleil.

Si Face ID ne fonctionne pas avec la nouvelle caméra TrueDepth des modèles d’iPhone 18 Pro , essayez :

- Retrait des protections d’écran de confidentialité.

- Retirez vos lunettes ou ajustez votre masque si vous portez les deux dans un environnement peu éclairé.

- Retirez le maquillage prononcé ou les masques de beauté.

- Évitez un contre-jour extrême dû au soleil.

## Ajouter une seconde apparence

Il se peut que vous deviez saisir votre code plus souvent après la configuration initiale de Face ID. Toutefois, pour la plupart des personnes, Face ID apprend en continu au fur et à mesure des changements.

Face ID fonctionne avec de nombreuses lunettes de vue ou à verres transparents. Si Face ID ne fonctionne pas avec vos lunettes de vue ou à verres transparents sur les modèles d’iPhone 18 Pro, essayez d’ [ajouter une autre apparence](https://support.apple.com/guide/iphone/set-up-face-id-iph6d162927a/ios) tout en portant vos lunettes.

Si votre apparence est susceptible de changer considérablement (pilosité faciale, maquillage prononcé ou autres changements), vous pouvez [configurer une autre apparence](https://support.apple.com/guide/iphone/set-up-face-id-iph6d162927a/ios) afin que Face ID continue de vous reconnaître.

## Placer la caméra TrueDepth face à soi

Face ID fonctionne en mode Portrait et Paysage sur les iPhone 13 et modèles ultérieurs exécutant iOS 16 ou version ultérieure. Sur les modèles d’iPhone antérieurs, Face ID fonctionne uniquement en mode Portrait lorsque vous faites face à la caméra TrueDepth. Sur l’iPad, Face ID fonctionne quelle que soit l’orientation.

Lorsque vous utilisez Face ID avec un masque sur votre iPhone, la fonctionnalité n’est disponible qu’en orientation portrait. Face ID avec un masque ne fonctionne pas sur l’iPad.

La caméra TrueDepth offre une profondeur de champ similaire à celle que vous obtenez lorsque vous prenez un selfie ou passez un appel FaceTime. Que votre iPhone ou iPad soit posé sur une surface ou que vous le teniez dans une position naturelle, veillez à ce qu’il se trouve à une longueur de bras au maximum (25 à 50 cm) de votre visage.

## Redémarrer votre appareil

[Redémarrez votre iPhone](https://support.apple.com/118259) ou [iPad](https://support.apple.com/101603) et saisissez votre code d’accès. Essayez à nouveau d’utiliser Face ID.

## Réinitialiser Face ID

Si vous avez toujours besoin d’aide, réinitialisez Face ID, puis configurez à nouveau la fonctionnalité. Accédez à Réglages, touchez Face ID et code, puis touchez Réinitialiser Face ID. Ensuite, touchez [Configurer Face ID](https://support.apple.com/108411) pour configurer à nouveau cette fonctionnalité.

## Obtenir une assistance

Si Face ID vous invite à plusieurs reprises à placer votre visage dans le cadre sans poursuivre le processus de configuration ou si votre appareil photo ne fonctionne pas et que vous ne parvenez pas à configurer Face ID sur votre iPhone, une réparation pourrait être nécessaire. [Obtenez une assistance](https://getsupport.apple.com/?caller=kbase)

Seul un technicien formé peut réparer votre appareil. Une réparation ou modification inadéquate du système de laser ou une utilisation pour celui-ci de composants non-Apple peut empêcher le bon fonctionnement des mécanismes de sécurité et peut entraîner une exposition dangereuse et des blessures oculaires ou cutanées.

[Découvrez les cas dans lesquels vous devez saisir un code d’accès, même si Face ID fonctionne normalement.](https://support.apple.com/guide/security/face-id-touch-id-passcodes-and-passwords-sec9479035f1/web)

[Découvrez la marche à suivre si une alerte indique que Face ID a été désactivé](https://support.apple.com/105130)

* En mode Portrait, vous pouvez utiliser Face ID avec un masque sur l’iPhone 12 et les modèles ultérieurs dotés d’iOS 15.4 ou version ultérieure. Face ID ne fonctionne pas en mode Paysage lorsque vous portez un masque.
