# Utiliser le mode de concentration Conduite sur votre iPhone pour vous concentrer sur la route

Avec iOS 15 et version ultérieure, le mode de concentration Conduite vous aide à rester concentré sur la route. Lorsque vous l’activez, les SMS et autres notifications sont silencieux ou limités.

Lorsque vous avez configuré le mode de concentration Conduite, vous pouvez [demander à Siri de vous lire les réponses](https://support.apple.com/guide/iphone/iph838fd6fd4/ios) Les appels entrants sont autorisés uniquement lorsque l’iPhone est connecté à CarPlay, à un système Bluetooth de voiture ou à un accessoire mains libres.

## Configurer le mode de concentration Conduite

- Dans l’app Réglages, touchez Concentration.

- Touchez le bouton Ajouter , puis touchez Conduite.

[Image: Aucun texte de remplacement pour l’image]

- Touchez Personnaliser le mode de concentration.

[Image: Écran initial de configuration du mode de concentration Conduite sous Réglages.]

- Suivez les instructions à l’écran pour configurer vos options, comme les notifications autorisées.

## Activer ou désactiver le mode de concentration Conduite

Si vous avez déjà configuré le mode de concentration Conduite, vous pouvez l’activer ou le désactiver rapidement à partir du centre de contrôle :

- [Ouvrez le centre de contrôle](https://support.apple.com/HT202769) .

- Touchez de manière prolongée la fonctionnalité Concentration, puis touchez la fonctionnalité Conduite pour l’activer ou la désactiver.

[Image: Affichage des modes de concentration dans le centre de contrôle avec le mode de concentration Conduite activé]

Lorsque le mode de concentration Conduite est activé, l’icône Conduite apparaît dans la barre d’état et sur l’écran de verrouillage, et votre état est automatiquement affiché dans l’app Messages. Lorsqu’une personne vous envoie un message, elle voit que vous avez désactivé les notifications, mais elle peut toujours vous avertir en cas d’urgence.

## Activer automatiquement le mode de concentration Conduite

- Dans l’app Réglages, touchez Concentration.

- Touchez Conduite.

- Touchez Pendant la conduite sous Activer automatiquement, puis sélectionnez l’une des options suivantes :

[Image: Réglages d’activation du mode de concentration Conduite]

- Automatiquement : la fonctionnalité Conduite s’activera en fonction des mouvements détectés.

- Si connecté au Bluetooth embarqué : la fonctionnalité Conduite est activée lorsque votre iPhone est connecté à des appareils Bluetooth embarqués.

- Manuellement : la fonctionnalité Conduite peut être activée manuellement depuis le centre de contrôle.

- Activer avec CarPlay : la fonctionnalité Conduite est activée automatiquement lorsque votre iPhone est connecté à CarPlay.

## Personnaliser les notifications

Pour autoriser ou masquer les notifications envoyées par certaines personnes :

- Dans l’app Réglages, touchez Concentration.

- Touchez Conduite.

- Sous Notifications autorisées, touchez Personnes.

- Touchez Autoriser les notifications de ou Masquer les notifications de.

[Image: Réglages de notification du mode de concentration Conduite]

- Touchez Ajouter des personnes, puis sélectionnez les contacts pour lequel vous souhaitez autoriser ou masquer les notifications.

## Partager votre statut Concentration

Lorsque vous configurez le mode de concentration Conduite, vous pouvez activer le statut Concentration afin que les applications indiquent que les notifications sont masquées lorsque des gens vous envoient un message. Le nom de la personne à l’origine du message n’est jamais partagé, car les applications savent seulement que vous avez masqué les notifications, mais elles ne savent pas quel mode Concentration est activé. Lorsque vous activez un mode de concentration, le statut Concentration est partagé sur toutes les apps pour lesquelles vous avez accordé une autorisation.

Pour activer le statut Concentration :

- Dans l’app Réglages, touchez Concentration.

- Touchez Statut Concentration.

- Activez le mode de concentration Conduite.

[Image: Pour afficher les réglages de partage du statut Concentration sous Réglages, touchez Concentration. Ensuite, touchez Statut Concentration.]

* Pour partager le statut de concentration, le réglage Partager entre les appareils doit être activé.

## Activer la réponse automatique

Avec Réponse automatique, les favoris et ceux dont vous autorisez les notifications reçoivent une réponse automatique lorsque le mode de concentration Conduite est activé. Ils peuvent quand même choisir de vous avertir en envoyant un message « urgent » supplémentaire.

- Dans l’app Réglages, touchez Concentration.

- Touchez Conduite.

- Touchez Réponse automatique.

- Sélectionnez une option, comme Personne, Récents, Favoris ou Tous les contacts.

[Image: Dans l’app Réglages, accédez aux réglages de réponse automatique du mode de concentration Conduite en touchant Concentration, puis Réponse automatique.]

Vous pouvez personnaliser le message de réponse automatique que les autres utilisateurs reçoivent lorsqu’ils vous envoient un message alors que le mode de concentration Conduite est activé.
