# Modifier l’apparence du texte dans Pages sur Mac, iPhone ou iPad

Modifiez la couleur, l’alignement et l’espacement du texte dans votre document Pages.

## Modifier l’apparence du texte dans Pages sur Mac

Sélectionnez le texte et modifiez sa couleur, son alignement et son espacement. Vous pouvez également sélectionner et mettre en forme des plages de texte non adjacentes en maintenant la touche Commande de votre clavier enfoncée et en sélectionnant le texte.

### Modifier la couleur du texte

- Sélectionnez le texte.

- Cliquez sur le bouton Format dans la barre d’outils pour afficher la barre latérale Format.

[Image: Aucun texte de remplacement pour l’image]

- Cliquez sur le bouton Style dans la barre latérale. Si le texte se trouve dans une zone de texte, un tableau ou une forme, cliquez d’abord sur l’onglet Texte en haut de la barre latérale, puis sur le bouton Style.

- Cliquez sur le menu contextuel sous la section Police, choisissez Couleur du texte, puis sélectionnez votre couleur en choisissant l’une des options suivantes :

- Pour sélectionner une couleur assortie à votre modèle, cliquez sur la source de couleur et choisissez-en une.

- Pour sélectionner n’importe quelle couleur, cliquez sur la roue des couleurs et choisissez une couleur parmi les palettes.

Vous pouvez également [remplir le texte avec un dégradé ou une image](https://support.apple.com/guide/pages/tan2484da646/mac) et [modifier la couleur du texte pour vos commentaires et les modifications que vous apportez en suivi des modifications](https://support.apple.com/guide/pages/set-author-name-and-comment-color-tan6704f1b0f/mac) .

### Aligner le texte

L’alignement détermine l’apparence des bords du texte dans votre document. Vous pouvez aligner le texte dans des paragraphes, des zones de texte, des formes ou des cellules de tableau.

- Choisissez le texte que vous souhaitez aligner :

- Pour aligner tout le texte d’un paragraphe en particulier, cliquez n’importe où dans le paragraphe.

- Pour aligner tout le texte de plusieurs paragraphes, sélectionnez les paragraphes.

- Pour aligner le texte dans une zone de texte ou une forme, cliquez sur la zone de texte ou sur la forme.

- Pour aligner le texte dans un tableau, sélectionnez les cellules, les lignes ou les colonnes concernées.

- Cliquez sur le bouton Format dans la barre d’outils, puis sur le bouton Style dans la barre latérale Format.

[Image: Aucun texte de remplacement pour l’image]

- Si le texte se trouve dans une zone de texte, un tableau ou une forme, cliquez d’abord sur l’onglet Texte en haut de la barre latérale, puis sur le bouton Style.

- Cliquez sur les boutons d’alignement pour aligner horizontalement votre texte :

- Pour aligner le texte à gauche, cliquez sur le bouton d’alignement à gauche .

[Image: Aucun texte de remplacement pour l’image]

- Pour centrer le texte, cliquez sur le bouton d’alignement au centre .

[Image: Aucun texte de remplacement pour l’image]

- Pour aligner le texte à droite, cliquez sur le bouton d’alignement à droite .

[Image: Aucun texte de remplacement pour l’image]

- Pour justifier le texte et l’aligner autant à droite qu’à gauche, cliquez sur le bouton de justification du texte .

[Image: Aucun texte de remplacement pour l’image]

- Pour augmenter le retrait du texte, cliquez sur le bouton d’augmentation du retrait du texte .

[Image: Aucun texte de remplacement pour l’image]

- Pour diminuer le retrait du texte, cliquez sur le bouton de diminution du retrait du texte .

[Image: Aucun texte de remplacement pour l’image]

- Pour aligner verticalement le texte dans une zone de texte, une forme ou une cellule de tableau, cliquez sur le bouton d’alignement vertical pour aligner le texte en haut , au milieu ou en bas du conteneur.

[Image: Aucun texte de remplacement pour l’image]

### Modifier l’espacement du texte

Vous pouvez modifier l’espacement entre les lignes de texte et l’espacement avant ou après un paragraphe.

- Sélectionnez n’importe quelle partie du texte que vous souhaitez aligner, cliquez sur une zone de texte ou une forme contenant du texte, ou, s’il s’agit d’un tableau, cliquez sur une cellule ou sélectionnez une ligne ou une colonne.

- Cliquez sur le bouton Format dans la barre d’outils, puis sur le bouton Style dans la barre latérale Format.

[Image: Aucun texte de remplacement pour l’image]

- Si le texte se trouve dans une zone de texte, un tableau ou une forme, cliquez d’abord sur l’onglet Texte en haut de la barre latérale, puis sur le bouton Style.

- Pour modifier l’espacement entre les lignes du texte, cliquez sur le menu contextuel Espacement et sélectionnez une option.

- Pour modifier l’espacement avant ou après le paragraphe sélectionné, cliquez sur les flèches Avant le paragraphe et Après le paragraphe.

### Options de style de texte avancées

Vous pouvez également [régler l’espacement entre les caractères](https://support.apple.com/guide/pages/ligatures-tanc87eaca89/mac) et [élever et abaisser le texte par rapport au texte adjacent](https://support.apple.com/guide/pages/raise-and-lower-characters-and-text-tan4745152e4/mac) . Lorsque vous avez terminé de mettre en forme votre texte, vous pouvez [enregistrer cette apparence en tant que style de caractère personnalisé](https://support.apple.com/guide/pages/create-and-use-character-styles-tan7aaef6765/mac) pour pouvoir l’appliquer facilement à d’autres textes de votre document.

## Modifier l’apparence du texte dans Pages sur iPhone ou iPad

Sélectionnez le texte et modifiez sa couleur, son alignement et son espacement. Si vous avez connecté un clavier et une souris ou un trackpad externes à votre iPad, vous pouvez sélectionner et mettre en forme des plages de texte non adjacentes en maintenant la touche Commande de votre clavier enfoncée et en sélectionnant le texte avec la souris ou le trackpad.

Si le bouton Édition s’affiche dans la barre d’outils lorsque vous ouvrez le document, touchez-le afin de pouvoir modifier le document.

### Modifier la couleur du texte

- Sélectionnez le texte.

- Touchez le bouton Format dans la barre d’outils.

[Image: Aucun texte de remplacement pour l’image]

- Si le texte se trouve dans une zone de texte, un tableau ou une forme, touchez Texte.

- Touchez le bouton Couleur du texte, puis Préréglage ou Couleur, et sélectionnez une couleur.

- Touchez Dégradé ou Image pour [remplir le texte avec des dégradés ou des images](https://support.apple.com/guide/pages-ipad/tana29e86157/ipados) .

- Touchez Texte pour définir d’autres options de texte comme le type de police, la taille de la police et bien plus.

### Aligner le texte

L’alignement détermine l’apparence des bords du texte dans votre document. Vous pouvez aligner le texte dans des paragraphes, des zones de texte, des formes ou des cellules de tableau.

- Choisissez le texte que vous souhaitez aligner :

- Pour aligner tout le texte d’un paragraphe en particulier, touchez n’importe où dans le paragraphe.

- Pour aligner tout le texte de plusieurs paragraphes, sélectionnez les paragraphes.

- Pour aligner le texte dans une zone de texte ou une forme, touchez la zone de texte ou la forme.

- Pour aligner le texte dans un tableau, touchez une cellule du tableau ou sélectionnez une ligne ou une colonne.

- Touchez le bouton Format dans la barre d’outils.

[Image: Aucun texte de remplacement pour l’image]

- Si le texte se trouve dans une zone de texte, un tableau ou une forme, touchez Texte.

- Cliquez sur les boutons d’alignement pour aligner horizontalement votre texte :

- Pour aligner le texte à gauche, touchez le bouton d’alignement à gauche .

[Image: Aucun texte de remplacement pour l’image]

- Pour centrer le texte, touchez le bouton d’alignement au centre .

[Image: Aucun texte de remplacement pour l’image]

- Pour aligner le texte à droite, touchez le bouton d’alignement à droite .

[Image: Aucun texte de remplacement pour l’image]

[Image: Aucun texte de remplacement pour l’image]

- Pour augmenter le retrait du texte, touchez le bouton d’augmentation du retrait du texte .

[Image: Aucun texte de remplacement pour l’image]

- Pour diminuer le retrait du texte, touchez le bouton de diminution du retrait du texte .

[Image: Aucun texte de remplacement pour l’image]

- Pour aligner verticalement le texte dans un conteneur, comme une zone de texte, une forme ou une cellule de tableau, touchez le bouton d’alignement vertical pour aligner le texte en haut , au milieu ou en bas du conteneur.

[Image: Aucun texte de remplacement pour l’image]

### Modifier l’espacement du texte

Vous pouvez modifier l’espacement entre les lignes de texte et l’espacement avant ou après un paragraphe.

- Sélectionnez n’importe quelle partie du texte que vous souhaitez aligner, touchez une zone de texte ou une forme contenant du texte, ou, s’il s’agit d’un tableau, touchez une cellule ou sélectionnez une ligne ou une colonne.

- Touchez le bouton Format dans la barre d’outils, puis Style.

[Image: Aucun texte de remplacement pour l’image]

- Si le texte se trouve dans une zone de texte, un tableau ou une forme, touchez Texte.

- Touchez Interligne.

- Pour modifier l’espacement entre les lignes, touchez les boutons plus ou moins de l’option Espacement.

- Pour modifier l’espacement avant ou après le paragraphe sélectionné, touchez les boutons plus ou moins pour Avant ou Après.

Vous pouvez également [régler l’espacement entre les caractères](https://support.apple.com/guide/pages-ipad/ligatures-tan2dabc524b) et [élever et abaisser le texte par rapport au texte adjacent](https://support.apple.com/guide/pages-ipad/make-characters-superscript-or-subscript-tan45cc97092/) .
