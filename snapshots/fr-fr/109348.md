# Ajouter votre ordonnance ophtalmologique dans l’app Santé

Vous pouvez ajouter et stocker votre ordonnance ophtalmologique dans l’app Santé afin d’accéder facilement aux informations relatives à votre vision ou à vos verres correcteurs ou lentilles correctrices.

## Ajouter votre ordonnance ophtalmologique

Si un fichier image ou PDF de votre ordonnance est enregistré sur votre iPhone, vous pouvez le télécharger dans l’app Santé. Si ce n’est pas le cas, vous pouvez aussi ajouter manuellement les informations relatives à votre ordonnance ophtalmologique.

### Ajouter votre ordonnance ophtalmologique à partir d’une image

- Sur votre iPhone ou iPad, ouvrez l’app Santé.

- Sur votre iPhone, touchez l’onglet Parcourir. Si vous êtes sur votre iPad, touchez le bouton de la barre latérale pour ouvrir la barre latérale.

- Touchez Mensurations, puis Ordonnance ophtalmologique.

- Touchez Ajouter une ordonnance.

[Image: iPhone affichant l’option Ajouter une ordonnance ainsi que des informations sur les ordonnances ophtalmologiques.]

- Touchez Date d’émission pour saisir la date d’entrée en vigueur de votre ordonnance.

- Touchez Ajouter une image.

[Image: iPhone affichant les options Scanner un document, Choisir une photo ou Ajouter depuis Fichiers lors de l’ajout d’une ordonnance ophtalmologique.]

- Touchez Scanner un document si vous avez une version papier de votre ordonnance à scanner. Touchez Choisir une photo si votre ordonnance est enregistrée dans l’app Photos. Touchez Ajouter depuis Fichiers si votre ordonnance est enregistrée dans l’app Fichiers.

- Scannez ou localisez votre ordonnance, puis touchez le bouton Terminé .

- Touchez le bouton Terminé si vous n’avez pas besoin de saisir les détails de votre ordonnance. Si ces détails sont requis dans votre pays ou région, touchez Obligatoire ou Ajouter à côté d’un champ pour les ajouter.

- Touchez le bouton Terminé dans le coin supérieur.

### Ajouter manuellement votre ordonnance ophtalmologique

Tous les pays ou toutes les régions n’ayant pas besoin des mêmes champs ou mesures, les ordonnances ophtalmologiques peuvent varier. Si vous ajoutez manuellement votre ordonnance ophtalmologique, il vous suffit de renseigner les informations pertinentes pour votre pays ou votre région.

- Sur votre iPhone ou iPad, ouvrez l’app Santé.

- Sur votre iPhone, touchez l’onglet Parcourir. Si vous êtes sur votre iPad, touchez le bouton de la barre latérale pour ouvrir la barre latérale.

- Touchez Mensurations, puis Ordonnance ophtalmologique.

- Touchez Ajouter une ordonnance.

- Touchez un champ ou touchez Ajouter à côté du champ pour le modifier.

[Image: iPhone illustrant l’ajout manuel de la valeur de sphère Œil droit d’une ordonnance ophtalmologique.]

- Une fois que vous avez ajouté les détails de votre ordonnance, touchez le bouton Terminé dans le coin supérieur.
