# Comment utiliser le clic forcé et le retour tactile sur les trackpads Apple

Les trackpads équipés de la technologie Force Touch disposent de capteurs sous leur surface afin de détecter les différences de pression que vous exercez. Ces capteurs permettent l’utilisation des fonctionnalités de détection de pression telles que le clic forcé. Le trackpad comprend également un retour tactile.

## Que sont le clic forcé et le retour tactile ?

Le clic forcé et le retour tactile sont des fonctionnalités des trackpads Force Touch.

- Pour effectuer un clic forcé, appuyez de manière prolongée sur le trackpad jusqu’à ce que vous sentiez un clic plus fort après le premier clic. Ce deuxième clic est un clic forcé. Il permet d’effectuer certaines actions en fonction du contexte.

- Le retour tactile est la réponse tactile que vous ressentez sur un trackpad Force Touch lorsque vous effectuez un clic ou des actions telles que l’alignement de formes, de texte ou d’autres objets dans les apps prises en charge.

[Les gestes Multi-Touch](https://support.apple.com/fr-fr/102482) sont pris en charge à la fois par les trackpads Force Touch et les trackpads Multi-Touch.

## Votre trackpad dispose-t-il des fonctionnalités de clic forcé et de retour tactile ?

Les trackpads qui incluent la technologie Force Touch prennent en charge le clic forcé et le retour tactile. La plupart des ordinateurs portables Mac récents sont dotés de la technologie Force Touch, tout comme les modèles rechargeables de Magic Trackpad. Pour tous ces trackpads, les [réglages du trackpad](https://support.apple.com/guide/mac-help/mchlp1226/mac) incluent un réglage Clic forcé et retour tactile :

- Dans le menu Apple , choisissez Réglages Système (ou Préférences Système).

- Cliquez sur Trackpad.

- Dans la sous-fenêtre Pointer et cliquer des réglages du trackpad, recherchez Clic forcé et retour tactile. Ce réglage est disponible uniquement si vous utilisez un trackpad Force Touch qui possède ces fonctionnalités. Les trackpads Apple sans Force Touch utilisent un clic mécanique plutôt qu’un clic forcé, et ne produisent pas de retour tactile.

## Quelles sont les possibilités offertes par le clic forcé ?

Pour effectuer un clic forcé, appuyez de manière prolongée sur le trackpad jusqu’à ce que vous sentiez un clic plus fort après le premier clic. Voici quelques-unes des possibilités offertes par les fonctionnalités de détection de pression comme le clic forcé, ainsi que des alternatives qui fonctionnent également avec des trackpads qui n’intègrent pas la technologie Force Touch.

Sur les trackpads avec Force Touch | Alternatives

Recherche : effectuez un clic forcé sur le texte d’une page web, d’un e-mail ou d’un document afin d’afficher plus d’informations sur le texte provenant de sources comme un dictionnaire, Wikipédia, et bien plus encore. 1 | Touchez le trackpad avec trois doigts. 2 Vous pouvez également faire un contrôle-clic sur le texte et choisir Chercher dans le menu contextuel.

Détection de données : effectuez un clic forcé sur une date, une adresse, un lieu, un numéro de téléphone, un évènement de calendrier, un numéro de vol, un numéro de suivi de colis, une URL, entre autres, pour voir une fenêtre contextuelle avec un aperçu des informations liées à ces données. Différents types de données peuvent être détectés selon les apps. | Touchez le trackpad avec trois doigts. 2 Vous pouvez également déplacer votre pointeur sur le texte, puis cliquer sur la flèche dans la zone qui le décrit, le cas échéant.

Coup d’œil : cliquez sur un fichier dans le Finder pour voir un aperçu de son contenu. | Touchez le trackpad avec trois doigts. 2 Vous pouvez également cliquer une fois sur un fichier pour le sélectionner, puis appuyer sur la barre d’espace.

Modification du nom de fichier : effectuez un clic forcé sur le nom d’un fichier dans le Finder pour le modifier. | Cliquez sur le fichier pour le sélectionner, puis appuyez sur Retour.

App Exposé : effectuez un clic forcé sur une app dans le Dock pour voir toutes les fenêtres ouvertes pour cette app. | Cliquez de façon prolongée ou faites un contrôle-clic sur l’app, puis choisissez Afficher toutes les fenêtres dans le menu contextuel. D’autres méthodes sont également disponibles .

Marquage d’un repère dans Plans : effectuez un clic forcé sur un emplacement pour y déposer une épingle. | Cliquez de façon prolongée ou faites un contrôle-clic sur le lieu, puis choisissez Marquer le lieu dans le menu contextuel.

Contrôles de médias à vitesse variable : dans les apps prises en charge, faites varier la pression sur le trackpad lorsque vous cliquez sur les boutons de contrôle des médias, tels que l’avance ou le retour rapide. | Dans certaines apps, vous pouvez cliquer sur le contrôle des médias plus d’une fois à la place.

L’option Clic forcé à un doigt doit être sélectionnée pour le réglage Recherche et détection de données dans les réglages du trackpad. L’option Toucher avec 3 doigts doit être sélectionnée pour le réglage Recherche et détection de données dans les réglages du trackpad. Ce réglage est disponible pour les trackpads Force Touch et les trackpads Multi-Touch.

Un trackpad Force Touch ne permet pas de faire de clic, de clic forcé ou de retour tactile lorsqu’il est désactivé.
