# GarageBand pour Mac 10 : les modules Audio Units peuvent ne pas fonctionner correctement

Il est possible que les modules Audio Units ne fonctionnent pas correctement dans GarageBand pour Mac 10.

GarageBand pour Mac est une application en 64 bits, fonctionnant avec les modules Audio Units en 64 bits. Les modules Audio Units en 32 bits ne sont pas compatibles.

Contactez le concepteur du module pour savoir si une version mise à jour de celui-ci, compatible avec GarageBand pour Mac, est disponible.

Si vous rencontrez des difficultés avec un module Audio Units en 64 bits dans GarageBand, effectuez une mise à jour vers GarageBand 10.0.1.

Si certains modules Audio Units nécessitent une autorisation, il peut être nécessaire de les autoriser à nouveau avant de pouvoir les utiliser.
