# Lion Server : impossibilité de se connecter au serveur L2TP VPN à l’aide du nom complet

Si vous tentez de vous connecter à un serveur L2TP VPN Lion Server à partir d’un client Lion, il est possible que le message d’alerte « Le serveur L2TP VPN ne répond pas. Essayez de vous reconnecter. Si le problème persiste, vérifiez vos réglages et contactez votre administrateur. » s’affiche.

Vous devez utiliser le nom court du compte de l’utilisateur lors de la connexion. L’utilisation du nom complet du compte engendre le problème ci-dessus.

## Informations supplémentaires

Il est possible qu’un message indiquant que l’authentification n’a pas eu lieu s’affiche avec les clients Mac OS X 10.6.
