# Mettre à jour votre iPhone, iPad ou iPod touch avec iTunes

Découvrez comment installer la dernière version d’iOS ou d’iPadOS sur votre iPhone, iPad ou iPod touch à l’aide de votre ordinateur.

Si vous ne parvenez pas à [mettre à jour votre appareil en mode sans fil](https://support.apple.com/fr-fr/118575) , vous pouvez effectuer la mise à jour manuellement à l’aide d’iTunes sur un ordinateur de confiance.

## Préparer la mise à jour

- [Sauvegardez les données de votre appareil](https://support.apple.com/fr-fr/118426) à l’aide d’iCloud ou de votre ordinateur.

- Si vous possédez un Mac, vérifiez qu’il est doté de macOS Mojave ou version antérieure. Vous utilisez un Mac doté de macOS Catalina ou version ultérieure ? [Mettez à jour votre appareil avec le Finder à la place](https://support.apple.com/HT212185) . Si vous ne connaissez pas votre version de macOS, vous pouvez [identifier la version de macOS installée sur votre Mac](https://support.apple.com/fr-fr/109033) .

- Si votre ordinateur utilise la fonctionnalité Partage de connexion sur l’appareil que vous mettez à jour, connectez-le à un autre réseau Wi-Fi ou Ethernet avant de procéder à la mise à jour.

## Mettre à jour votre iPhone, iPad ou iPod touch avec iTunes

- Ouvrez iTunes sur votre Mac doté de macOS Mojave ou version antérieure ou sur votre PC Windows.

- Connectez votre appareil à votre ordinateur.

- Cliquez sur le bouton représentant votre appareil dans la barre d’outils d’iTunes. [Vous ne voyez pas votre appareil](https://support.apple.com/fr-fr/108643) ?

- Cliquez sur l’onglet Résumé.

- Cliquez sur Rechercher les mises à jour.

[Image: Curseur survolant le bouton « Rechercher les mises à jour » dans l’onglet Résumé d’iTunes.]

- Cliquez sur Télécharger et mettre à jour, puis suivez les instructions qui s’affichent à l’écran.

- Si un message vous y invite, saisissez votre code d’accès. [Vous avez oublié votre code d’accès ?](https://support.apple.com/fr-fr/118430)

## Si votre ordinateur affiche des messages d’alerte

Obtenez de l’aide si [un message d’alerte s’affiche lors de la mise à jour de votre appareil avec votre ordinateur](https://support.apple.com/fr-fr/109057) .

## Si vous avez besoin de plus d’espace pour installer une mise à jour

Si vous avez besoin de plus d’espace pour installer une mise à jour, vous pouvez [supprimer manuellement du contenu sur votre appareil](https://support.apple.com/fr-fr/108327) .
