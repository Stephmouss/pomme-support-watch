# Empêcher la production de sons non désirés dans GarageBand

Découvrez comment empêcher la production de sons non désirés dans GarageBand.

Des sons non désirés s’ajoutent dans les passages silencieux de vos enregistrements d’instruments réels ? La fonctionnalité Noise Gate de GarageBand permet de régler ce problème.

Les effets tels que la distorsion, la surmultiplication et les simulateurs d’ampli impliquent l’amplification du signal d’entrée des instruments réels. Cette amplification peut également augmenter les sons d’instruments et les bruits de fond qui passent autrement inaperçus. La fonctionnalité Noise Gate peut faire en sorte que ces sons non désirés et de faible niveau n’entrent pas dans les effets

Pour réduire le bruit dans un passage silencieux :

- Sélectionnez la piste souhaitée.

- Cliquez sur l’icône du casque pour isoler la piste.

- Ouvrez la fenêtre des informations de la piste.

- Développez la fenêtre pour voir les « détails ».

- Cochez la case Gate.

- Commencez à jouer le morceau.

- Ajustez le curseur Gate de sorte que le bruit disparaisse des passages silencieux, mais que l’instrument continue à jouer normalement ailleurs.
