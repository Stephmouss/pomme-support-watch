# À propos de Logic Pro pour iPad

Une fois abonné, vous aurez accès à la collection complète d’outils de création professionnels sophistiqués de Logic Pro pour iPad pour l’écriture de morceaux, la création de rythmes, l’édition et le mixage.

## Appareils compatibles

- Un iPad compatible :

- iPad Pro 11 pouces (1re génération) ou modèle ultérieur

- iPad Pro 12,9 pouces (3e génération) ou modèle ultérieur

- iPad Air (3e génération) ou modèle ultérieur

- iPad (8e génération) ou modèle ultérieur

- iPad mini (5e génération) ou modèle ultérieur

- Un Mac avec Logic Pro 10.7.8 ou version ultérieure, si vous souhaitez [travailler sur le même projet Logic Pro sur l’iPad et le Mac](https://support.apple.com/fr-fr/101624) .

## S’abonner à Logic Pro pour iPad

Logic Pro pour iPad est inclus avec [Apple Creator Studio](https://www.apple.com/fr/apple-creator-studio/) , en plus de Logic Pro pour Mac, Final Cut Pro, Pixelmator Pro, Motion, Compressor et MainStage. À cela s’ajoutent de nouvelles fonctionnalités d’IA et du contenu premium dans Keynote, Pages, Numbers et Freeform.

Lorsque vous vous abonnez à Apple Creator Studio, votre abonnement individuel existant à Logic Pro pour iPad ne sera pas renouvelé automatiquement à la prochaine date de facturation. Vous pouvez demander un remboursement au prorata pour le reste de cet abonnement. Si vous décidez de ne pas utiliser Apple Creator Studio, vous pouvez réactiver votre abonnement individuel à Logic Pro pour iPad à tout moment.

Lorsque vous vous abonnez à Apple Creator Studio, votre abonnement individuel change [selon que vous êtes l’unique titulaire de l’abonnement ou que vous le partagez avec les membres de votre famille](https://support.apple.com/fr-fr/126080) .

## Commencer à utiliser Logic Pro pour iPad

Pour commencer, vous pouvez [créer un projet dans Logic Pro pour iPad](https://support.apple.com/guide/logicpro-ipad/create-projects-lpip00c529d9/ipados) . Vous pouvez également ouvrir des projets GarageBand pour iOS et Logic Pro pour Mac dans Logic Pro pour iPad.

[Ouvrir des projets GarageBand dans Logic Pro pour iPad](https://support.apple.com/fr-fr/101622)

[Travailler avec des projets dans Logic Pro pour Mac et Logic Pro pour iPad](https://support.apple.com/fr-fr/101624)

Logic Pro pour iPad comprend des leçons guidées pour vous aider à en savoir plus sur l’utilisation de l’app. Dans le sélectionneur de nouveau projet, touchez une leçon guidée sous Apprendre et explorer. Si un morceau est déjà ouvert, touchez le bouton Navigateur de projets, puis touchez Créer un projet pour accéder au sélectionneur du nouveau projet. Touchez Tout voir pour accéder à l’ensemble de la collection de cours.

Vous pouvez également télécharger un projet de démonstration, des grilles Live Loops préremplies et des paquets de sons contenant des sons, des Apple Loops et d’autres contenus à utiliser dans vos projets.

## Utiliser du matériel externe avec Logic Pro pour iPad

Vous pouvez utiliser des interfaces audio externes, des microphones et des périphériques MIDI compatibles (y compris des périphériques MIDI Bluetooth) avec Logic Pro pour iPad. Par défaut, Logic Pro pour iPad se connecte automatiquement aux périphériques audio que vous avez connectés au port de votre iPad. Logic Pro pour iPad offre autant d’entrées et de sorties simultanées que le matériel connecté.

Pour ajuster les réglages des entrées audio, des sorties audio et des périphériques MIDI, ouvrez un projet, touchez le bouton Plus , puis touchez Réglages. Dans la fenêtre qui s’affiche, touchez Réglages de l’app, puis touchez l’une des options suivantes :

## Utiliser des modules avec Logic Pro pour iPad

Vous pouvez utiliser les modules intégrés à Logic Pro pour iPad, ainsi que des extensions Audio Units V3 tierces.

### Utiliser les modules intégrés

Logic Pro pour iPad comprend une vaste collection de modules d’effets et d’instruments de qualité professionnelle, qui sont automatiquement installés lorsque vous téléchargez l’app pour la première fois. Bon nombre de ces modules sont disponibles à la fois dans Logic Pro pour iPad et dans Logic Pro pour Mac. Lorsque vous les utilisez dans un projet, les réglages de ces effets seront les mêmes, que vous ouvriez le projet sur iPad ou Mac. Par ailleurs, vous pouvez modifier les réglages de ces modules dans le projet sur les deux plateformes.

### Utiliser des effets tiers

Logic Pro pour iPad prend en charge des instruments et effets tiers au format des extensions Audio Units V3, que vous pouvez télécharger et installer à partir de l’App Store de l’iPad.

Selon le fabricant, un module compatible avec Logic Pro pour Mac peut être proposé dans une version au format AU V3 Extensions compatible avec Logic Pro pour iPad. Ces modules doivent être installés séparément. Pour l’iPad, ces programmes d’installation peuvent être obtenus sur l’App Store de l’iPad. Sur Mac, ces programmes d’installation peuvent être obtenus sur le Mac App Store ou directement auprès du fabricant. Ainsi, lorsque vous travaillez sur un projet sur Mac et iPad, vous pouvez utiliser le module sur les deux plateformes.

Certains fabricants proposent également un achat universel, ce qui vous permet d’acheter le module une fois, mais fournit des programmes d’installation compatibles pour les deux plateformes.

Si vous ouvrez un projet Logic Pro pour Mac sur votre iPad qui utilise un module dont il n’existe pas de version compatible pour l’iPad, ou si vous n’avez pas installé la version des extensions AU V3 sur votre iPad, vous recevrez une alerte pour vous en informer. Les modules incompatibles sont désactivés, mais vous pouvez toujours ouvrir et modifier le projet.
