# Vous ne parvenez pas établir une liaison avec un domaine Windows en utilisant une seule partie du nom de domaine

Kerberos ne peut exécuter de demande d’enregistrement SRV DNS avec une seule partie du nom de domaine. Ajoutez un point (.) à votre nom de domaine pour résoudre ce problème.

Si vous ne parvenez pas relier votre Mac à un domaine Active Directory en utilisant une seule partie du nom, vous devez indiquer le nom complet du domaine du serveur.

Lorsque vous suivez les étapes ci-dessous, remplacez « w2003 » utilisé dans l’exemple par votre nom de domaine.

## Préférences Utilisateurs et groupes

Procédez comme suit pour mettre à jour votre nom de domaine à partir des préférences Utilisateurs et groupes.

- Ouvrez Préférences Système

- Cliquez sur Utilisateurs et groupes.

- Cliquez sur Options de connexion.

- Cliquez sur l’icône de cadenas, puis authentifiez-vous à l’aide de votre nom d’administrateur et de votre mot de passe.

- Cliquez sur Rejoindre.

- Saisissez le nom de domaine en ajoutant le point (par exemple, « w2003. ») dans le champ Serveur.

- Dans le champ d’authentification qui apparaît, saisissez les valeurs appropriées, puis cliquez sur OK.

## Utilitaire d’annuaire

Procédez comme suit pour mettre à jour votre nom de domaine à partir de l’Utilitaire d’annuaire.

- Cliquez sur le bouton en forme de cadenas pour vous authentifier.

- Double-cliquez sur Active Directory.

- Saisissez le domaine en ajoutant le point (par exemple, « w2003. »).

- Cliquez sur le bouton Relier.

- Dans la sous-fenêtre suivante, l’unité d’organisation (UO) où est stocké l’enregistrement de l’ordinateur n’est pas correcte. Elle devrait ressembler à ceci : "CN=Computers,DC=w2003,dc="

- Supprimez « ,dc= » à la fin de l’entrée de manière à ce que l’unité d’organisation de l’ordinateur ressemble à "CN=Computers,DC=w2003", puis cliquez sur OK.

## Ligne de commande

Procédez comme suit pour modifier une partie du nom de domaine à partir de la ligne de commande. Par exemple, cette commande Terminal permet d’ajouter un point à un domaine appelé w2003 :

sudo dsconfigad -add 'w2003.' -username -password

Après avoir modifié la partie de votre nom de domaine, reliez à nouveau votre serveur ou votre client au domaine en suivant ces étapes.
