# Personnaliser les prononciations de VoiceOver sur votre iPhone ou votre iPad

Découvrez comment modifier la façon dont VoiceOver prononce certains mots ou certaines expressions (comme votre nom, votre ville, etc.).

## Ajouter une prononciation

- Dans Réglages, accédez à Accessibilité > VoiceOver > Parole > Prononciations.

- Touchez le bouton Ajouter .

[Image: bouton Ajouter]

- Dans le champ Phrase, saisissez le mot ou l’expression que vous souhaitez personnaliser.

[Image: Écran d’iPhone montrant le mot SIM dans le champ Phrase et la prononciation de SIM dans le champ Substitution.]

- Dans le champ Substitution, vous avez deux choix :

- Vous pouvez écrire phonétiquement la prononciation de l'expression.

- Ou vous pouvez toucher le bouton Dicter le remplacement pour dire l'expression selon la prononciation souhaitée*. Touchez chaque suggestion pour la lire, puis sélectionnez OK lorsque vous avez choisi celle que vous souhaitez utiliser.

[Image: bouton remplacement]

- Choisissez quelles langues seront concernées par cette prononciation, quelle voix la dira, si la casse doit être ignorée dans le mot et à quelles apps cette prononciation s’appliquera.

- Touchez Lecture pour écouter la prononciation. Lorsque vous avez terminé, touchez Retour pour l’enregistrer.

* Pour utiliser Dicter une substitution, activez l’option Activer Dictée dans Réglages > Général > Clavier.

## Supprimer une prononciation

- Dans Réglages, accédez à Accessibilité > VoiceOver > Parole > Prononciations.

- Touchez Modifier.

- Touchez le bouton Supprimer à côté de la prononciation à supprimer, puis touchez Supprimer.

[Image: bouton Supprimer]
