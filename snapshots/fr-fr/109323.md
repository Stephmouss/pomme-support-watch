# Utiliser les données cellulaires sur votre iPhone ou iPad

Découvrez comment contrôler votre consommation de données cellulaires et apprenez à activer et désactiver l’utilisation des données cellulaires pour toutes les apps ou certaines d’entre elles.

## Activer ou désactiver les données cellulaires

Pour activer ou désactiver les données cellulaires :

- Ouvrez l’app Réglages.

- Touchez Données cellulaires.

- Touchez le curseur en regard de Données cellulaires pour activer ou désactiver les données cellulaires.

- Si votre iPhone est doté de plusieurs cartes SIM, touchez Cellulaire, puis touchez Données cellulaires. Si vous utilisez un iPad, il est possible que les options soient Réglages, puis Données cellulaires.

[Image: Menu des réglages d’iOS 26 présentant les options cellulaires]

Selon votre opérateur et votre appareil, vous pouvez disposer d’options supplémentaires. Celles-ci sont répertoriées dans Options. Si votre iPhone est doté de plusieurs cartes SIM, choisissez une ligne (sous Cartes SIM) pour accéder aux options :

- Activer l’accès aux réseaux LTE, 4G ou 3G : vous pouvez sélectionner le type de connexion réseau à utiliser pour la voix et les données. Obtenez plus d’informations [sur ces options](https://support.apple.com/fr-fr/109019) . Obtenez plus d’informations sur les options de données avec la 5G sur votre [iPhone](https://support.apple.com/fr-fr/108383) ou sur votre [iPad](https://support.apple.com/fr-fr/108787) .

- Activer ou désactiver l’option Voix à l’étranger : avec les réseaux CDMA, vous pouvez désactiver l’option Voix à l’étranger afin d’éviter les frais liés à l’utilisation des réseaux d’autres opérateurs.

- Activer ou désactiver l’option Données à l’étranger : lors de vos voyages à l’étranger, vous pouvez désactiver l’option Données à l’étranger afin d’éviter les frais d’itinérance. Si vous disposez d’un forfait de données international, il peut être préférable de ne pas désactiver l’option Données à l’étranger. Obtenez plus d’informations sur [les déplacements à l’étranger avec votre iPhone ou votre iPad](https://support.apple.com/fr-fr/109037) .

Selon votre opérateur, l’option Données à l’étranger peut être utilisée lorsque vous voyagez au sein de votre pays. Contactez votre opérateur pour en savoir plus sur sa politique en matière de données à l’étranger ou d’autres réglages des données cellulaires. Vous pouvez activer ou désactiver les données cellulaires afin d’empêcher les apps et les services d’utiliser le réseau cellulaire pour se connecter à Internet. Lorsque les données cellulaires sont activées, les apps et les services utilisent votre connexion mobile lorsque le réseau Wi-Fi est indisponible. Dans ce cas, l’utilisation de certaines fonctionnalités et de certains services avec les données cellulaires est susceptible d’entraîner des frais. Contactez votre opérateur pour en savoir plus sur les frais éventuels.

## Afficher votre consommation de données

Pour voir la quantité de données cellulaires que vous avez utilisée :

- Ouvrez l’app Réglages.

- Touchez Données cellulaires. Si vous utilisez un iPad, il est possible que les options soient plutôt Réglages, puis Données cellulaires.

- Si votre appareil est inscrit à la solution de gestion des appareils mobiles, touchez Services système, puis Comptes d’entreprise pour afficher les données associées.

[Image: Menu des réglages d’iOS 26 présentant les options de données cellulaires]

- Faites défiler vers le bas pour consulter la liste des apps qui consomment des données cellulaires. Si vous ne voulez pas qu’une app utilise des données cellulaires, vous pouvez les désactiver pour cette app. Lorsque les données cellulaires sont désactivées, les apps accèdent aux données uniquement via un réseau Wi-Fi.

- Pour voir l’utilisation des données cellulaires pour les services système individuels :

- Ouvrez l’app Réglages.

- Touchez Données cellulaires ou Données mobiles.

- Touchez Services système dans la liste sous Données cellulaires. Il n’est pas possible d’activer ou de désactiver les données cellulaires pour des services système individuels.

- Vous pouvez consulter les statistiques de consommation de données d’une app sur la période en cours, ainsi que les statistiques de consommation de données de toutes les apps lorsque vous avez utilisé l’itinérance. Pour réinitialiser ces statistiques :

- Ouvrez l’app Réglages.

- Touchez Données cellulaires ou Données mobiles

- Touchez Réinitialiser les statistiques.

- Lorsque vous utilisez un iPhone avec double SIM, vous pouvez voir la consommation de données cellulaires pour le numéro sélectionné pour les données cellulaires.

Pour obtenir les statistiques de consommation de données cellulaires les plus précises sur la période en cours, contactez votre opérateur.

## Obtenir de l’aide

- Découvrez la marche à suivre [si vous ne parvenez toujours pas à vous connecter à un réseau cellulaire](https://support.apple.com/fr-fr/120000) .

- Si vous utilisez un compte Exchange ActiveSync alors que vous avez désactivé les données cellulaires pour Mail et Calendrier, celui-ci risque de continuer à utiliser des données cellulaires. Pour voir l’utilisation des données cellulaires de votre compte Exchange ActiveSync :

- Ouvrez l’app Réglages.

- Touchez Données cellulaires.

- Touchez Services système.

- Si elle est activée, l’option Assistance Wi-Fi bascule automatiquement sur les données cellulaires lorsque la connexion Wi-Fi est mauvaise. L’option Assistance Wi-Fi est activée par défaut. Cela risque d’entraîner une utilisation supplémentaire de données cellulaires, ce qui pourrait, selon votre forfait de données, se traduire par des frais supplémentaires. Vous pouvez désactiver l’option Assistance Wi-Fi dans Réglages. [En savoir plus sur l’option Assistance Wi-Fi](https://support.apple.com/fr-fr/102228)
