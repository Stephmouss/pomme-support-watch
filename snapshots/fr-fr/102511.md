# Si vous avez besoin d’aide pour votre mot de passe Wi-Fi

Si vous ne connaissez pas ou ne vous souvenez pas du mot de passe d’un réseau Wi-Fi, essayez l’une des solutions ci-dessous.

## Identifier un réseau protégé par un mot de passe

Si un cadenas apparaît en regard du nom d’un réseau Wi-Fi, ce dernier est protégé par un mot de passe. Les mots de passe Wi-Fi sont sensibles à la casse. Veillez donc à respecter la casse de votre mot de passe.

## Obtenir le mot de passe Wi-Fi à partir d’un autre appareil

Les autres appareils Apple qui se sont déjà connectés au réseau Wi-Fi peuvent partager son mot de passe avec votre appareil. Vous pouvez également consulter ou copier le mot de passe depuis ces appareils.

### Obtenir le mot de passe à partir d’un autre iPhone ou iPad

- [Partager un mot de passe Wi-Fi depuis un iPhone ou iPad](https://support.apple.com/fr-fr/102635)

- [Consulter les mots de passe Wi-Fi enregistrés sur iPhone ou iPad](https://support.apple.com/fr-fr/104961)

### Obtenir le mot de passe à partir d’un autre Mac

- [Partagez un mot de passe Wi-Fi à partir du Mac](https://support.apple.com/guide/mac-help/mchlp1179/mac) .

- Si le Mac est doté de [macOS Ventura ou version ultérieure](https://support.apple.com/fr-fr/109033) , vous pouvez également copier le mot de passe :

- Dans le menu Apple , choisissez Réglages Système.

- Cliquez sur Réseau dans la barre latérale, puis sur Wi-Fi à droite.

- Faites défiler vers le bas et cliquez sur Avancé pour ouvrir la liste des réseaux connus.

- Cliquez sur le bouton Plus en regard du nom du réseau, puis choisissez Copier le mot de passe.

[Image: Aucun texte de remplacement pour l’image]

- Collez le mot de passe à un autre emplacement pour le consulter. Si les deux appareils vous appartiennent, vous pourrez peut-être coller le mot de passe directement sur votre autre appareil [à l’aide du presse-papiers universel](https://support.apple.com/fr-fr/102430) .

## Rechercher le mot de passe Wi-Fi à d’autres endroits

- Si vous administrez le routeur Wi-Fi et que vous pouvez vous connecter à sa page web ou à son application d’administration, vous pourrez afficher ou modifier le mot de passe de son réseau.

- Si vous utilisez un réseau Wi-Fi public dans une bibliothèque, un hôtel, une entreprise ou un autre espace partagé, demandez de l’aide à un membre du personnel ou recherchez des panneaux ou des fiches d’information indiquant le nom et le mot de passe du réseau. Certains [réseaux Wi-Fi publics peuvent vous demander de vous connecter](https://support.apple.com/fr-fr/102554) après avoir rejoint le réseau.

- Recherchez la présence d’une étiquette sur le routeur Wi-Fi, vérifiez la documentation du routeur ou recherchez une fiche d’information laissée par la personne ou le fournisseur d’accès à Internet qui a configuré le routeur. Le nom de réseau par défaut (ou SSID) et le mot de passe (ou clé réseau) peuvent être affichés à ces emplacements et peuvent encore être d’actualité.

- Consultez la personne ou le fournisseur d’accès à Internet qui a configuré le routeur. Vous pouvez également contacter le fabricant du routeur. Ces personnes pourraient être en mesure de vous aider à récupérer ou à réinitialiser le mot de passe.

## Oublier le réseau Wi-Fi, puis le rejoindre à nouveau

Si votre appareil s’est déjà connecté au réseau à l’aide de l’ancien mot de passe de ce dernier et que vous souhaitez qu’il s’y connecte avec le nouveau mot de passe, vous pouvez oublier le réseau Wi-Fi, puis le rejoindre à nouveau. Lorsque vous rejoindrez à nouveau le réseau, il vous sera demandé de saisir son mot de passe actuel. [Découvrez comment oublier un réseau Wi-Fi](https://support.apple.com/fr-fr/102480) .
