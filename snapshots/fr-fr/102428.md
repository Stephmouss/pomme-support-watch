# Supprimer des e-mails sur votre iPhone ou iPad

Vous pouvez supprimer des e-mails d’un simple geste et sélectionner Corbeille ou Archiver comme option par défaut.

## Supprimer plusieurs e-mails à la fois

- Ouvrez Mail et accédez à votre boîte de réception.

- Touchez le bouton Plus en haut à droite, puis touchez Sélectionner.

[Image: null]

- Sélectionnez les e-mails que vous souhaitez supprimer. Pour sélectionner rapidement plusieurs e-mails, effectuez un balayage vers le bas sur les cases à cocher.

- Touchez le bouton Corbeille ou le bouton Archive . Si vous voyez uniquement l’option Archiver, touchez-la et maintenez votre doigt appuyé dessus pour afficher d’autres options, telles que Supprimer la sélection.

[Image: null]

[Image: Dans Mail sous iOS, vous pouvez supprimer plusieurs e-mails à la fois.]

Pour choisir Tout sélectionner lorsque vous sélectionnez des e-mails, utilisez Présentation par liste. Touchez le bouton Plus , puis touchez Présentation par liste.

[Image: null]

Pour supprimer un grand nombre d’e-mails, il peut être plus facile d’utiliser le site web de votre fournisseur de messagerie.

## Effectuer un balayage pour supprimer et autres façons d’éliminer un e-mail

Il existe plusieurs façons de supprimer un e-mail dans Mail sous iOS :

- Effectuez un balayage rapidement vers la gauche sur un seul e-mail.

- Touchez de manière prolongée un e-mail de votre boîte de réception, puis appuyez sur Supprimer l’e-mail dans le menu.

- Touchez le bouton Archive ou le bouton Corbeille à partir d’un e-mail.

[Image: null]

[Image: Dans Mail sous iOS, effectuez un balayage vers la gauche sur un e-mail dans votre boîte de réception pour le placer dans la corbeille.]

La [méthode de suppression de plusieurs e-mails](https://support.apple.com/fr-fr/102428#multiple) permet également de supprimer un seul e-mail.

## Supprimer les e-mails d’un expéditeur particulier avec la présentation par catégories sous iOS 18.2

- Dans l’app Mail, touchez un message que vous souhaitez supprimer. Une liste s’affiche avec tous les messages de cet expéditeur qui sont classés dans la même catégorie.

- Touchez le bouton Plus.

- Touchez Corbeille (tout).

Vous pouvez également effectuer un balayage vers la gauche sur un e-mail dans une liste de messages afin de le supprimer.

## Définir Supprimer ou Archiver comme option par défaut

Selon le type de compte de messagerie dont vous disposez, l’option Archiver peut s’afficher à la place de l’option Corbeille lorsque vous essayez de supprimer des e-mails. Vous pouvez modifier l’emplacement de vos messages supprimés dans vos réglages de Mail :

- Dans l’app Réglages, touchez Apps.

- Touchez Mail.

- Touchez Comptes Mail.

- Touchez votre compte.

- Touchez Réglages du compte.

- Touchez Avancé.

- Faites défiler l’écran jusqu’à la section « Placer les messages supprimés dans » et sélectionnez Messages supprimés ou Archives.

[Image: Vous pouvez choisir si l’action Archiver ou Corbeille doit s’afficher par défaut pour les e-mails dans Mail sous iOS.]
