# Connecter un accessoire Bluetooth tiers à votre iPhone ou iPad

Jumelez un accessoire Bluetooth à votre iPhone ou iPad pour diffuser de la musique et des vidéos, passer des appels et plus encore.

## Jumelage d’un accessoire Bluetooth

- Accédez à Réglages, puis touchez Bluetooth et activez le Bluetooth.

- Sous Mes appareils, recherchez l'accessoire que vous souhaitez jumeler. S’il n’apparaît pas, consultez le manuel ou les instructions en ligne de l'accessoire pour savoir comment rendre un appareil détectable dans Bluetooth.

- Touchez le nom de votre accessoire lorsqu'il apparaît. Vous devrez peut-être saisir votre code PIN ou code d’accès. Si vous avez besoin d'aide, consultez de nouveau le manuel ou les instructions en ligne de l'accessoire.

[Image: iPhone affichant les réglages Bluetooth, avec Bluetooth activé et Mes appareils montrant les appareils connectés et non connectés.]

- Répétez ces étapes pour jumeler plusieurs accessoires Bluetooth. Si plusieurs appareils Bluetooth sont jumelés à votre appareil, vous pouvez [choisir la source audio à utiliser](https://support.apple.com/105068) .

## Désactivation du jumelage d’un accessoire Bluetooth

- Accédez à Réglages, puis touchez Bluetooth.

- Touchez le bouton En savoir plus en regard de l’appareil dont vous voulez désactiver le jumelage. Lorsque vous désactivez le jumelage d'une accessoire, celui-ci se désactive sur tous les appareils connectés à votre compte Apple.

[Image: Aucun texte de remplacement pour l’image]

- Touchez Oublier cet appareil. Cela supprime l'accessoire de votre liste d'appareils Bluetooth disponibles, mais vous pouvez répéter la procédure d’ajout à tout moment.
