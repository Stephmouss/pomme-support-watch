# Désactiver les achats intégrés sur votre iPhone ou iPad à l’aide de la fonctionnalité Temps d’écran

La fonctionnalité Temps d’écran peut vous permettre d’éviter tout achat accidentel ou non autorisé sur l’App Store et les autres services Apple. Vous pouvez également demander un mot de passe pour les achats, empêcher certains types d’achats ou désactiver complètement les achats.

Pour empêcher les achats intégrés, vous devez d’abord activer la fonctionnalité Temps d’écran. [Découvrez comment activer et utiliser Temps d’écran](https://support.apple.com/fr-fr/108806) .

## Marche à suivre pour désactiver les achats intégrés sur votre iPhone ou iPad

- Lorsque Temps d’écran est activé, ouvrez Réglages, puis touchez Temps d’écran.

- Touchez Contenu et confidentialité dans la section Restrictions. Si vous y êtes invité, saisissez votre code, puis activez Restrictions de contenu et de confidentialité. Il vous sera demandé de saisir un code uniquement si vous en avez déjà créé un dans Temps d’écran. Découvrez comment [créer un code de Temps d’écran](https://support.apple.com/fr-fr/108806#lock-screen-time) .

[Image: Écran d’iPhone illustrant les réglages pour Contenu et confidentialité.]

- Touchez Achats dans l’iTunes et l’App Store.

- Touchez Achats intégrés, puis sélectionnez Ne pas autoriser. *

[Image: Écran d’iPhone illustrant les réglages utilisés pour désactiver Achats dans l’iTunes et l’App Store.]

* À partir de là, vous pouvez également demander un mot de passe pour les prochains achats sur iTunes, Books ou l’App Store.

## Autres moyens de contrôler les achats sur un appareil Apple

- Si un enfant de votre groupe de partage familial possède son propre appareil, [activez l’option Demande d’autorisation d’achat pour contrôler et approuver ses demandes d’achat](https://support.apple.com/fr-fr/105055) .

- Si des enfants ont accès à votre appareil, vous pouvez [demander un mot de passe pour chaque achat](https://support.apple.com/fr-fr/119848) .
