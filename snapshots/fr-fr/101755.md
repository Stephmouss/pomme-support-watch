# GarageBand pour iOS : problèmes liés aux morceaux créés avec une version plus récente de l’app

Découvrez la procédure à suivre si vous rencontrez des problèmes avec des morceaux créés à l’aide d’une version plus récente de GarageBand pour iOS.

Si un morceau a été créé dans une version plus récente de GarageBand pour iOS que la vôtre, certaines fonctionnalités peuvent ne pas fonctionner normalement. Par exemple, la fonctionnalité Autoplay avec les instruments tactiles pourrait ne pas fonctionner correctement en boucle si le morceau a été créé avec une signature temporelle incompatible avec votre version de GarageBand pour iOS.

Pour des performances optimales, utilisez la même version ou une version plus récente de GarageBand pour iOS pour lire des morceaux.
