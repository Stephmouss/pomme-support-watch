# Utilisation d’un clavier Apple sous Windows, avec Boot Camp

Si vous avez utilisé Boot Camp pour installer Microsoft Windows sur votre Mac, vous pouvez utiliser le même clavier sous Windows et macOS.

## Équivalence Mac des touches Windows

Logo Windows : appuyez sur Commande (⌘).

[Image: boot-camp-mac-keyboard-mapping-command-windows]

Retour arrière ou Suppression : appuyez sur Supprimer.

[Image: boot-camp-mac-keyboard-mapping-delete-backspace]

Entrée ou ⏎ : appuyez sur Retour.

[Image: boot-camp-mac-keyboard-mapping-return-enter]

Alt (gauche) : appuyez sur Option (⌥).

[Image: boot-camp-mac-keyboard-mapping-option-alt]

Alt GR (droite) : appuyez sur Option + Contrôle.

[Image: boot-camp-mac-keyboard-mapping-option-control-alt-gr-right-alt]

Applications : cette touche n’est pas disponible sur les claviers Apple.

[Image: boot-camp-mac-keyboard-mapping-applications-menu]

## Utilisation du clavier visuel pour accéder à d’autres fonctions

Si votre clavier Apple n’inclut pas les touches suivantes, vous pouvez les recréer sous Windows à l’aide du [clavier visuel](https://support.microsoft.com/fr-fr/help/10762/windows-use-on-screen-keyboard) .

- Pause/Attn

- Insérer

- Suppression (avant)

- Bouton principal

- Raccrocher

- Page précédente

- Page suivante

- Verr num

- Arrêt défil

## Utilisation de l’outil Capture d’écran pour effectuer des captures d’écran

Pour recréer les fonctions de capture d’écran et de capture d’écran de la fenêtre active sous Windows, [utilisez l’outil Capture d’écran](https://support.microsoft.com/fr-fr/help/13776/windows-use-snipping-tool-to-capture-screenshots) .

## Si votre clavier ne fonctionne pas comme prévu sous Windows

Si votre clavier Apple fonctionne comme prévu sous macOS, mais pas sous Windows, essayez ces solutions :

- [Installez les mises à jour les plus récentes des logiciels Apple pour Windows](https://support.apple.com/HT208038) .

- [Installez le logiciel de prise en charge de Windows le plus récent](https://support.apple.com/HT204923) .

- Si vous utilisez Microsoft Windows 10 N, [installez le dernier Media Feature Pack](https://www.microsoft.com/en-us/software-download/mediafeaturepack) .
