# Si l’avertissement « Non sécurisé » s’affiche lorsque vous naviguez avec Safari

Safari vous avertit quand le site web que vous visitez n’est pas sécurisé. Ne fournissez jamais votre mot de passe ou le numéro de votre carte de crédit à des sites donnant lieu à cet avertissement. Si vous avez besoin d’utiliser le site, contactez son propriétaire ou administrateur et informez-le que le site n’est pas sécurisé.

Dans l’un ou l’autre de ces cas, il est possible que le message « Non sécurisé », « Site web non sécurisé » ou « Cette connexion n’est pas sécurisée » s’affiche dans Safari :

- Le site web est chiffré, mais son certificat est expiré ou illégitime.

- Le certificat du site web est valide, mais la version de TLS n’est pas sécurisée (TLS version 1.1 ou antérieure).

- Le site web n’est pas chiffré et vous demande de saisir un mot de passe ou des informations de carte de crédit.

- Le site web utilise HTTP au lieu de HTTPS pour transmettre des informations vers Safari et depuis Safari.

Les réglages de sécurité de Safari se trouvent ici :

- Mac : ouvrez Safari. Dans le menu Safari, choisissez Réglages (ou Préférences), puis cliquez sur Sécurité.

- iPhone, iPad : ouvrez Réglages, touchez Apps, puis touchez Safari et faites défiler l’écran jusqu’à la section Confidentialité et sécurité.

Les informations se rapportant à des produits non fabriqués par Apple, ou à des sites Web indépendants qui ne sont ni contrôlés ni testés par Apple, sont fournies uniquement à titre indicatif et ne constituent aucune recommandation. Apple ne saurait être tenu responsable de problèmes liés à l’utilisation de tels sites ou produits tiers, ou à leurs performances. Apple ne garantit en aucune façon la fiabilité d’un site Web tiers ni l’exactitude des informations que ce dernier propose. [Contactez le fournisseur](https://support.apple.com/fr-fr/103190) pour plus d’informations.
