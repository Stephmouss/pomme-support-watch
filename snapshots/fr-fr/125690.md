# Utiliser des apps verrouillées avec la fonctionnalité Protection en cas de vol de l’appareil

Si la fonctionnalité Protection en cas de vol de l’appareil pour iPhone est activée, les apps verrouillées nécessitent Face ID ou Touch ID lorsque votre iPhone ne se trouve pas dans un lieu connu, sans possibilité d’utiliser votre code d’accès.

## Fonctionnement

La fonctionnalité Protection en cas de vol de l’appareil permet d’empêcher une personne qui a volé votre iPhone et qui connaît le code d’accès d’apporter des modifications critiques à votre compte ou à votre appareil, y compris en effectuant certaines actions comme l’ouverture d’une app verrouillée. Lorsque vous verrouillez une app alors que la fonctionnalité Protection en cas de vol de l’appareil est activée, vous étendez la couche de sécurité supplémentaire de la fonctionnalité à cette app.

- Protection en cas de vol de l’appareil : Face ID ou Touch ID (sans possibilité d’utiliser le code d’accès) est requis pour certaines actions, y compris l’ouverture d’une app verrouillée, lorsque votre iPhone ne se trouve pas dans un lieu connu tel que votre domicile et votre lieu de travail.

- Apps verrouillées : Face ID, Touch ID ou votre code d’accès est requis pour ouvrir les apps que vous choisissez de verrouiller.

- Ensemble : si vous verrouillez une app, elle ne peut être ouverte qu’avec Face ID ou Touch ID lorsque votre iPhone ne se trouve pas dans un lieu connu. Cela offre une couche de sécurité supplémentaire en cas de vol.

Par exemple, le verrouillage de l’app Mail permet d’empêcher une personne qui a volé votre iPhone et qui connaît votre code d’accès de trouver des informations personnelles sensibles dans vos e-mails, comme les codes d’identification à deux facteurs utilisés pour accéder à vos comptes bancaires et de réseaux sociaux.

[Découvrez la marche à suivre en cas de vol de votre iPhone](https://support.apple.com/fr-fr/120837)

## Activer la fonctionnalité Protection en cas de vol de l’appareil

- Accédez à l’app Réglages, puis touchez Face ID et code (ou Touch ID et code).

- Saisissez le code de votre appareil.

- Touchez Protection en cas de vol de l’appareil, puis activez la fonctionnalité.

[En savoir plus sur la protection en cas de vol de l’appareil pour iPhone](https://support.apple.com/fr-fr/120340)

## Verrouiller une app

- Accéder à l’écran d’accueil.

- Maintenez le doigt appuyé sur l’app que vous souhaitez verrouiller jusqu’à ce que le menu des actions rapides s’ouvre.

- Touchez Exiger Face ID (ou Touch ID).

[En savoir plus sur le verrouillage des apps](https://support.apple.com/guide/iphone/iph00f208d05/)
