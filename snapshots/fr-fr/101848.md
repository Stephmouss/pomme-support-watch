# Si vous n’entendez pas de son sur les pistes avec Native Instruments Maschine dans Logic Pro pour Mac 10.4.5 ou version ultérieure

Désactiver le chargement dynamique des modules ou forcer l’activation de la piste en créant une région dans la piste.

[Avec le chargement dynamique des modules dans Logic 10.4.5 et versions ultérieures](https://support.apple.com/HT209636) , Logic ne charge que les modules et instruments logiciels nécessaires pour lire le projet, ce qui permet d’ouvrir ce dernier plus rapidement. Native Instruments Maschine étant un type de module générateur, il produit un son sans aucune entrée provenant d’instrument MIDI externe ou de région audio sur sa piste. Logic prend généralement en charge les modules générateur et les maintient actifs lors du chargement d’un projet. Cependant, Maschine se réfère à Logic en tant que module de type instrument, ce qui signifie qu’un chargement dynamique des modules peut ne pas activer une piste si le module Maschine est inséré.

## Désactiver le chargement dynamique des modules

- Une fois le projet ouvert, choisissez Fichier > Réglages du projet > Général.

- Sous Ouvrir un projet, désélectionnez l’option « Ne charger que les modules nécessaires pour la lecture du projet ».

- Enregistrez le projet.

Si votre projet ne contient pas un grand nombre de pistes inutilisées avec des bibliothèques échantillons volumineuses, le temps de chargement du projet risque de ne pas être affecté par la désactivation du chargement dynamique des modules.

## Forcer l’activation de la piste avec une région

Si vous souhaitez conserver le chargement dynamique des modules activé, vous pouvez forcer Logic à activer la piste Maschine lors de l’ouverture du projet en ajoutant une région vide à la piste.

- Choisissez l’outil Crayon dans le menu Outils en haut de la fenêtre principale.

- Cliquez n’importe où sur la piste pour créer une région.

- Enregistrez le projet.
