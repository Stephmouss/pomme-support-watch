# Désactiver Rosetta dans Logic Pro pour Mac

Si vous utilisez Logic Pro sur un Mac avec puce Apple, l’ouverture de Logic Pro en mode natif vous donne accès à l’ensemble des fonctionnalités de Logic Pro.

Certaines fonctionnalités de Logic Pro ne sont pas disponibles lors de l’exécution de Logic Pro dans Rosetta sur un Mac avec puce Apple ou un Mac à processeur Intel. C’est le cas notamment de Stem Splitter, de ChromaGlow et de la plupart des préréglages de l’assistant de masterisation. Si vous avez configuré Logic Pro pour utiliser le mode Rosetta sur un Mac avec puce Apple, il peut être judicieux de vous assurer que l’utilisation de Rosetta est requise.* La plupart des modules pour Logic Pro ne nécessitent pas Rosetta.

Pour désactiver Rosetta dans Logic Pro pour Mac :

- Quittez Logic Pro.

- Tout en maintenant la touche Contrôle enfoncée, cliquez sur l’app Logic Pro dans le dossier Applications, puis choisissez Lire les informations.

- Désélectionnez « Ouvrir avec Rosetta ».

- Ouvrez Logic Pro.

* L’utilisation d’un module tiers tel que Melodyne de Celemony en mode ARA dans un projet est la seule raison nécessitant l’exécution de Logic Pro dans Rosetta sur un Mac avec puce Apple. Si vous ne savez pas si l’un de vos modules tiers doit impérativement être utilisé en mode ARA, renseignez-vous auprès de son fabricant.
