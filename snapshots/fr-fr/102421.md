# Comment effacer une eSIM de votre iPhone ou iPad

Si vous avez transféré le forfait de données ou le numéro de téléphone d’une eSIM vers un autre appareil, effacez l’eSIM. De même, si vous prévoyez de vendre, de faire reprendre ou de donner votre appareil, effacez l’eSIM.

- N’effacez pas une eSIM à des fins de dépannage, sauf si votre opérateur vous le demande.

- Si vous effacez une eSIM, vous devrez contacter votre opérateur pour en obtenir une nouvelle. Ensuite, [configurez la nouvelle eSIM](https://support.apple.com/fr-fr/119606) .

- Si vous souhaitez résilier votre forfait mobile, contactez votre opérateur.

## Effacer une eSIM de votre iPhone

- Ouvrez l’app Réglages.

- Touchez Données cellulaires.

- Si vous avez un seul forfait, touchez Supprimer l’eSIM.

- Si vous avez plusieurs forfaits, touchez le forfait que vous souhaitez effacer. Ensuite, touchez Supprimer le forfait.

## Effacer une eSIM de votre iPad

- Ouvrez l’app Réglages.

- Touchez Données cellulaires.

- Si vous avez un seul forfait, touchez Supprimer l’eSIM.

- Si vous avez plusieurs forfaits, touchez le forfait que vous souhaitez effacer. Ensuite, touchez Supprimer le forfait.

Si vous [effacez le contenu et les réglages](https://support.apple.com/fr-fr/108931) de votre iPhone ou iPad, vous pouvez choisir d’effacer votre eSIM ou de la conserver.

## Si vous effacez une eSIM sur un appareil utilisant Handoff

Si vous effacez une eSIM configurée sur un appareil qui utilise Handoff, vous devez contacter votre opérateur pour désactiver Handoff pour cette eSIM. Votre opérateur pourrait continuer à vous facturer des frais jusqu’à ce que vous demandiez la désactivation du service.
