# Effacer une eSIM sur votre iPhone ou iPad

Il peut être nécessaire d’effacer votre eSIM si vous avez transféré le forfait de données ou le numéro de téléphone associé sur un autre appareil ou si vous vous apprêtez à vendre, faire reprendre ou céder votre appareil.

N’effacez pas votre eSIM dans le cadre d’une procédure de dépannage, sauf indication contraire de votre opérateur.

Si vous effacez votre eSIM, vous devrez contacter votre opérateur afin d’en obtenir une nouvelle. Vous devrez ensuite [configurer votre nouvelle eSIM](https://support.apple.com/119606) .

### Effacer votre eSIM sur votre iPhone

- Accédez à Réglages.

- Touchez Données cellulaires. Ensuite :

- Si vous avez un seul forfait, touchez Supprimer l’eSIM.

- Si vous avez plusieurs forfaits, touchez le forfait que vous souhaitez effacer. Ensuite, touchez Supprimer le forfait.

### Effacer votre eSIM sur votre iPad

- Accédez à Réglages.

- Touchez Données cellulaires. Ensuite :

- Si vous avez un seul forfait, touchez Supprimer l’eSIM.

- Si vous avez plusieurs forfaits, touchez le forfait que vous souhaitez effacer. Ensuite, touchez Supprimer le forfait.

Si vous [effacez tous les contenus et réglages](https://support.apple.com/HT201274) de votre iPhone ou iPad, vous pouvez choisir d’effacer également votre eSIM, ou de la conserver.

Si vous souhaitez résilier votre forfait mobile, contactez votre opérateur.
