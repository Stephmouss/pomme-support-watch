# Utiliser le module MPX Radeon Pro W6900X avec votre Mac Pro (2019)

Découvrez les différentes configurations d’affichage que vous pouvez utiliser avec le module MPX de votre Mac Pro (2019).

Le module MPX Radeon Pro W6900X comporte un processeur graphique AMD Radeon Pro W6900X doté de 32 Go de mémoire GDDR6, ainsi que quatre ports Thunderbolt 3 et un port HDMI 2.0. Les ports Thunderbolt 3 vous permettent de connecter des écrans et des périphériques externes à votre Mac Pro. Vous pouvez également connecter des écrans supplémentaires grâce aux ports Thunderbolt 3 situés en haut* et à l’arrière de votre Mac Pro.

Si vous utilisez [Boot Camp](https://support.apple.com/boot-camp) et que vous installez une carte graphique tierce d’AMD, vous devrez peut-être [utiliser d’autres pilotes AMD sous Windows](https://support.apple.com/HT210560) .

## À propos des ports et des bus

[Image: Schéma illustrant les ports Thunderbolt 3 et HDMI du module MPX Radeon Pro W6900X, indiquant l’affectation des bus et les considérations relatives à la connexion des écrans.]

Le module MPX est doté de deux bus pour ses ports Thunderbolt 3. Si vous connectez deux écrans 5K ou 6K aux ports Thunderbolt 3 de votre module MPX, connectez un écran par bus.

Si vous connectez un écran au port HDMI de votre module MPX, les ports Thunderbolt 3 du bus 0 peuvent prendre en charge un écran supplémentaire d’une résolution de 4K maximum. Si vous avez besoin de produire du son sur un écran connecté au port HDMI et que d’autres écrans sont connectés via Thunderbolt 3, ne connectez pas d’écran au port Thunderbolt 3 situé à côté du port HDMI.

## Connecter des écrans à un seul module MPX Radeon Pro W6900X

Si vous installez un seul module MPX Radeon Pro W6900X, vous pouvez connecter jusqu’à six écrans via Thunderbolt 3 dans les configurations suivantes.

Trois écrans Pro Display XDR avec des résolutions de 6016 x 3384 à 60 Hz connectés comme suit :

- Un écran sur le bus 0

- Un écran sur le bus 1

- Un écran sur un port Thunderbolt 3 en haut* ou à l’arrière (carte d’E/S Apple) de votre Mac

Trois écrans 5K avec des résolutions de 5120 x 2880 à 60 Hz connectés comme suit :

- Un écran sur le bus 0

- Un écran sur le bus 1

- Un écran sur un port Thunderbolt 3 en haut* ou à l’arrière (carte d’E/S Apple) de votre Mac

Six écrans 4K avec des résolutions de 3840 x 2160 à 60 Hz connectés comme suit :

- Deux écrans sur le bus 0

- Deux écrans sur le bus 1

- Deux écrans sur les ports Thunderbolt 3 en haut* ou à l’arrière (carte d’E/S Apple) de votre Mac

## Connecter des écrans à deux modules MPX Radeon Pro W6900X

Si vous installez deux modules MPX Radeon Pro W6900X, vous pouvez connecter jusqu’à douze écrans via Thunderbolt 3 dans les configurations suivantes.

Six écrans Pro Display XDR avec des résolutions de 6016 x 3384 à 60 Hz connectés de la façon suivante :

- Deux écrans : un sur le bus 0 de chaque carte

- Deux écrans : un sur le bus 1 de chaque carte

- Un écran sur un port Thunderbolt 3 en haut* de votre Mac

- Un écran sur un port Thunderbolt 3 à l’arrière (carte d’E/S Apple) de votre Mac

Six écrans 5K avec des résolutions de 5120 x 2880 à 60 Hz connectés de la façon suivante :

- Deux écrans : un sur le bus 0 de chaque carte

- Deux écrans : un sur le bus 1 de chaque carte

- Un écran sur un port Thunderbolt 3 en haut* de votre Mac

- Un écran sur un port Thunderbolt 3 à l’arrière (carte d’E/S Apple) de votre Mac

Douze écrans 4K avec des résolutions de 3840 x 2160 à 60 Hz connectés de la façon suivante :

- Un écran sur chaque port Thunderbolt 3

### Connecter le pont Infinity Fabric Link

Si vous installez deux modules MPX Radeon Pro W6900X, vous pouvez les connecter au moyen d’un pont Infinity Fabric Link afin de bénéficier de meilleures performances et d’un transfert de données plus rapide entre les processeurs :

- Retirez les couvercles de chaque module MPX.

- Alignez les connecteurs du pont Infinity Fabric Link sur les connecteurs des modules MPX, puis appuyez doucement dessus.

- À l’aide d’un tournevis cruciforme, faites tourner les deux vis vers la droite, en position verrouillée.

[Image: Pont Infinity Fabric Link reliant deux modules MPX Radeon Pro W6900X.]

Le pont Infinity Fabric Link pour module MPX Radeon Pro W6900X (modèle A2666) n’est pas compatible avec les modules MPX Radeon Pro de génération précédente.

Si vous utilisez Boot Camp et que vous avez installé un pont Infinity Fabric Link, vous ne pouvez pas connecter d’écrans aux ports Thunderbolt 3 du bus 1 et du haut* de votre Mac Pro.
