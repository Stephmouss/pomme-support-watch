# Limites concernant la taille de la boîte aux lettres et l’envoi de messages dans iCloud

Découvrez quelles sont les limites concernant la taille des boîtes aux lettres Mail iCloud et l’envoi de messages avec ce service. L’application Mail iCloud est destinée à un usage personnel. L’envoi de messages est donc soumis à certaines limites.

## Limites concernant l’envoi de messages

Plusieurs mesures de sécurité sont mises en place afin de garantir que seuls les utilisateurs d’iCloud puissent envoyer des messages à l’aide de cette même fonctionnalité. L’une de ces mesures implique certaines limites, lesquelles concernent :

- le nombre total de messages que vous pouvez envoyer par jour (1 000 messages) ;

- le nombre de destinataires auxquels vous pouvez écrire chaque jour (1 000 destinataires) ;

- le nombre maximum de destinataires par message (500 destinataires) ;

- la taille des messages entrants et sortants (20 Mo et jusqu’à 5 Go si [Mail Drop](https://support.apple.com/kb/PH2629?locale=fr_FR)

Le service Mail iCloud est principalement destiné à un usage personnel. L’envoi groupé de courriers indésirables, via le serveur de messagerie iCloud, n’est pas autorisé. Le contrat d’adhésion et la politique d’utilisation d’iCloud sont détaillés dans les [conditions générales d’iCloud](http://www.apple.com/legal/icloud/ww/) .

En fonction de l’appareil (ou de la méthode) employé pour accéder à Mail iCloud, les messages d’alerte ci-dessous peuvent apparaître en cas de dépassement des limites d’envoi de messages :

- Sur votre iPhone, iPad ou iPod touch : une copie se trouve dans votre boîte d’envoi. L’envoi du message a échoué car vous avez dépassé votre limite d’envoi.

- Sur votre Mac : impossible d’envoyer le message via le serveur iCloud.

- Sur la messagerie web iCloud : impossible d’envoyer le message. Vous avez dépassé le nombre total de messages que vous pouvez envoyer par jour ou le nombre total de destinataires auxquels vous pouvez écrire chaque jour. Le problème peut aussi venir du nombre de destinataires : il y en a trop pour que ce message puisse être envoyé.

Si vous dépassez toujours les limites concernant l’envoi de messages, procédez comme suit :

- Vérifiez si des messages sont en attente dans votre boîte d’envoi. Renvoyez ou effacez les messages en attente.

- Vérifiez si un logiciel de surveillance du réseau se sert de votre compte Mail iCloud pour envoyer automatiquement des messages (comme un coupe-feu ou un logiciel de sécurité Internet configuré pour envoyer une alerte suite à la détection d’un éventuel problème de sécurité).

- Si vous envoyez des messages à des groupes, vérifiez que toutes les adresses e-mail des destinataires sont valides, par exemple qu’elles sont correctement orthographiées.
