# Si des utilisateurs ne parviennent pas à accéder à OS X Server à l’aide du protocole SSH

Sans emplacement de dossier Départ attribué, les utilisateurs risquent de ne pas pouvoir accéder à votre serveur à l’aide du protocole SSH.

Si des utilisateurs ne parviennent pas à accéder à votre serveur à l’aide du protocole SSH, cela peut être dû au fait qu’aucun dossier Départ ne leur a été attribué sur le serveur. Après avoir saisi un mot de passe trois fois, un message « autorisation refusée » s’affiche.

Vous pouvez savoir qu’un utilisateur a besoin d’un emplacement de dossier Départ si le fichier system.log sur l’ordinateur sur lequel l’ouverture de session à distance (SSH) est activée contient un message similaire à celui-ci :

sshd: [pam][]: in od_record_check_homedir(): failed: 7

Pour résoudre ce problème, attribuez à l’utilisateur un emplacement de dossier Départ sur le serveur. Les comptes d’utilisateur « Services uniquement » créés sous OS X Server et les comptes « Partage uniquement » créés sous OS X ne sont pas conçus pour se connecter à l’aide de l’ouverture de session à distance (SSH).
