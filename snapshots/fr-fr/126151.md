# Installer Keynote, Pages et Numbers 15.1 ou versions ultérieures pour Mac

Pour obtenir les dernières fonctionnalités de Keynote, Pages et Numbers, téléchargez les nouvelles versions 15.1 directement depuis l’App Store sur votre Mac.

Keynote, Pages et Numbers 15.1 sur Mac sont disponibles en tant que nouvelles apps plutôt qu’en tant que mises à jour des apps existantes.

## Vérifier votre numéro de version de Keynote, Pages et Numbers

- Dans chaque app, cliquez sur le nom de l’app dans la barre de menu, puis cliquez sur À propos de [ nom de l’app ].

- Votre numéro de version s’affiche sous le nom de l’app dans la fenêtre. Selon la version dont vous disposez, procédez comme suit :

- Si vous avez déjà installé Keynote, Pages et Numbers 14.5, [téléchargez Keynote, Pages et Numbers 15.1](https://support.apple.com/fr-fr/126151#update_to_15.1) depuis l’App Store.

- Si vous avez Keynote, Pages et Numbers 14.4 ou une version antérieure et que vous avez enregistré des mots de passe pour des documents protégés, [effectuez la mise à jour vers la version 14.5](https://support.apple.com/fr-fr/126151#update_to_14.5) avant de faire celle vers la version 15.1.

## Mise à jour vers Keynote, Pages et Numbers 14.5

Si vous avez actuellement Keynote, Pages et Numbers 14.4 ou une version antérieure et que vous avez enregistré des mots de passe pour des documents protégés que vous souhaitez conserver, mettez à jour manuellement les apps vers la version 14.5 :

- Ouvrez l’app App Store sur votre Mac.

- Cliquez sur Mises à jour dans la barre latérale, puis cliquez sur Mettre à jour à côté de chaque app que vous souhaitez mettre à jour, ou cliquez sur Tout mettre à jour.

- Ouvrez Keynote, Pages et Numbers 14.5 au moins une fois avant ou après le téléchargement et l’ouverture de la version 15.1.

Après avoir effectué la mise à jour vers la version 14.5, vous pouvez [télécharger Keynote, Pages et Numbers 15.1](https://support.apple.com/fr-fr/126151#update_to_15.1) .

## Télécharger Keynote, Pages et Numbers 15.1

- Ouvrez l’App Store sur votre Mac.

- Saisissez « Keynote, Pages, Numbers » dans le champ de recherche en haut de la fenêtre de l’App Store, puis appuyez sur la touche Retour.

- Cliquez sur le bouton de téléchargement à côté de chaque app.

- Une fois que vous avez téléchargé la version 15.1 des apps, celle-ci est identifiable grâce à une icône de mise à jour dans le dossier Applications de votre Mac*. Pour conserver les mots de passe de tous les documents protégés par mot de passe, veillez à ouvrir Keynote, Pages et Numbers 14.5 au moins une fois avant ou après le téléchargement et l’ouverture de la version 15.1.

## Gérer les fonctionnalités et les réglages après la mise à jour de Keynote, Pages et Numbers vers la version 15.1

Si vous utilisez déjà Keynote, Pages et Numbers, voici comment gérer ces fonctionnalités et réglages après la mise à jour.

Documents protégés par mot de passe : afin que les mots de passe enregistrés pour les documents protégés par mot de passe soient automatiquement transférés vers la version 15.1, ouvrez la version 14.5 de chaque app au moins une fois avant ou après le téléchargement de la version 15.1.

Documents récents : les documents récents créés dans les versions 14.4 ou antérieures n’apparaissent pas lorsque vous choisissez Ouvrir un élément récent dans le menu Fichier ou lorsque vous cliquez sur l’icône de l’app tout en maintenant la touche Contrôle enfoncée dans le Dock. Pour voir les documents récents, choisissez Ouvrir dans le menu Fichier, puis cliquez sur Récents dans la barre latérale. À mesure que d’anciens fichiers seront rouverts, d’autres documents apparaissent dans la section Récents.

Modèles et formes : si vous avez activé iCloud pour les apps, les formes et modèles personnalisés que vous avez enregistrés sont transférés vers Keynote, Pages et Numbers 15.1 ou version ultérieure.

Publipostage dans Pages : si vous avez ajouté un lien vers une feuille de calcul dans Publipostage sur la version 14.4 (ou version antérieure) de Pages, celui-ci ne sera pas transféré lorsqu’il sera ouvert dans la version 15.1 de Pages. Vous devrez rajouter le lien manuellement après l’ouverture dans Pages 15.1.

Notes dans Pages : l’ouverture de notes à partir de l’app Notes dans Pages 15.1 nécessite macOS Tahoe 26 ou une version ultérieure.

VoiceOver : utilisez la dernière version de macOS pour une expérience optimale.

* Si vous souhaitez économiser de l’espace de stockage sur votre Mac, vous pouvez faire glisser les versions 14.5 dans la corbeille, puis vider cette dernière. Si vous conservez les anciennes versions des apps en parallèle de la version 15.1, il est possible que vous receviez les notifications d’activité pour les documents collaboratifs en double. Vous pouvez [désactiver les notifications](https://support.apple.com/105052) dans les anciennes versions pour cesser de recevoir ces notifications.
