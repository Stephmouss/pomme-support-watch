# Si vous avez oublié le code d’accès de votre iPhone, iPad ou Apple Vision Pro, réinitialisez-le sans utiliser d’ordinateur

Lorsque vous voyez l’écran Verrouillage de sécurité ou un message indiquant que l’appareil n’est pas disponible sous iOS 15.2, iPadOS 15.2 ou des versions ultérieures, vous pouvez réinitialiser votre iPhone ou votre iPad directement sur cet appareil afin de pouvoir y accéder à nouveau.

## Éléments requis

- visionOS, ou iOS 15.2 ou iPadOS 15.2 ou version ultérieure

- App Localiser activée sur votre appareil

- Connexion active à un réseau mobile ou Wi-Fi

- Votre compte Apple et votre mot de passe

Si vous l’avez oublié, commencez par essayer de [réinitialiser votre code d’accès](https://support.apple.com/105039) . Si vous ne pouvez pas utiliser la fonctionnalité Réinitialisation du code, vous pouvez réinitialiser votre iPhone ou votre iPad sans ordinateur afin de récupérer l’accès à votre appareil Apple. Enfin, si vous ne pouvez pas utiliser la fonctionnalité Réinitialisation du code, et que vous ne pouvez pas réinitialiser votre iPhone ou votre iPad directement sur l’appareil, vous pouvez [réinitialiser votre iPhone ou votre iPad à l’aide d’un ordinateur](https://support.apple.com/118430) .

## Réinitialiser votre iPhone sous iOS 17 ou version ultérieure

Si vous utilisez une eSIM sous iOS 16 ou version antérieure, contactez votre opérateur avant de suivre ces instructions et demandez un code QR permettant de [reconfigurer votre eSIM](https://support.apple.com/118669) .

Si vous ne pouvez pas procéder de cette façon, vous pouvez [réinitialiser votre appareil à l’aide d’un ordinateur](https://support.apple.com/118430) .

- À partir de l’écran de verrouillage de votre appareil, essayez de saisir votre code d’accès jusqu’à ce que l’écran « [Appareil] indisponible » apparaisse.

- Lorsque vous le pouvez, touchez l’option « Code oublié ? ». Le bouton Code oublié ? apparaît uniquement si vous disposez d’une connexion mobile ou Wi-Fi active, et que la fonctionnalité Localiser est activée.

[Image: L’écran iPhone indisponible sous iOS 17 ou version ultérieure comprend une option « Code oublié ? ».]

- Sur l’écran de verrouillage de sécurité, touchez Lancer la réinitialisation de [Appareil] pour confirmer.

- Déconnectez-vous de votre compte Apple sur votre appareil en saisissant votre mot de passe.

- Touchez Effacer [appareil] pour supprimer définitivement toutes vos données et tous vos réglages. Si vous utilisez une eSIM avec iOS 17 ou version ultérieure, vous pouvez également conserver votre eSIM et effacer vos données, ou supprimer votre eSIM et effacer vos données.

[Image: Lorsque vous réinitialisez votre code d’accès sous iOS 17 ou version ultérieure, vous pouvez choisir de conserver ou de supprimer votre eSIM.]

6. Lorsque votre appareil redémarre, suivez les instructions à l’écran pour le reconfigurer, [restaurer vos données et réglages à partir d’une sauvegarde](https://support.apple.com/118105) , si vous en avez une, et définir un nouveau code d’accès.

Si vous utilisez iOS 17 ou version ultérieure, l’option « Code oublié ? » apparaît lorsque vous ne pouvez pas accéder à votre appareil, que vous êtes connecté à un réseau mobile ou Wi-Fi, ainsi qu’à votre compte Apple, et que la fonctionnalité Localiser est activée.

Si vous utilisez iOS 15.2 ou iOS 16, l’option Effacer [appareil] s’affiche lorsque vous ne pouvez pas accéder à votre appareil, que vous êtes connecté à un réseau mobile ou Wi-Fi, ainsi qu’à votre compte Apple, et que la fonctionnalité Localiser est activée.

## Réinitialiser votre iPad sous iPadOS 17 ou version ultérieure

- À partir de l’écran de verrouillage de votre appareil, essayez de saisir votre code d’accès jusqu’à ce que l’écran « [Appareil] indisponible » apparaisse.

- Lorsque vous le pouvez, touchez l’option « Code oublié ? ».

[Image: L’écran Appareil non disponible apparaît sur un iPad après une tentative de saisie de code d’accès infructueuse.]

- Sur l’écran de verrouillage de sécurité, touchez Lancer la réinitialisation de [Appareil] pour confirmer.

- Déconnectez-vous de votre compte Apple sur votre appareil en saisissant votre mot de passe.

- Touchez Effacer [appareil] pour supprimer définitivement toutes vos données et tous vos réglages.

[Image: Dans le cadre de la réinitialisation de votre iPad suite à un oubli de code d’accès, vous devez effacer vos fichiers multimédias, vos contenus et vos réglages.]

- Lorsque votre appareil redémarre, suivez les instructions à l’écran pour le reconfigurer, [restaurer vos données et réglages à partir d’une sauvegarde](https://support.apple.com/118105) , si vous en avez une, et définir un nouveau code d’accès.

Si vous ne pouvez pas procéder de cette façon, vous pouvez [réinitialiser votre appareil à l’aide d’un ordinateur](https://support.apple.com/119858) .

Si vous utilisez iPadOS 17 ou version ultérieure, l’option Code oublié ? apparaît lorsque vous ne pouvez pas accéder à votre appareil, que vous êtes connecté à un réseau mobile ou Wi-Fi, ainsi qu’à votre compte Apple, et que la fonctionnalité Localiser est activée.

Si vous utilisez iPadOS 15.2 ou iPadOS 16, l’option Effacer [appareil] apparaît lorsque vous ne pouvez pas accéder à votre appareil, que vous êtes connecté à un réseau mobile ou Wi-Fi, ainsi qu’à votre compte Apple, et que la fonctionnalité Localiser est activée.
