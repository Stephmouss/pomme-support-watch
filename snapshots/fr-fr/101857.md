# À propos des égaliseurs Vintage dans Logic Pro pour Mac et MainStage

Logic Pro et MainStage incluent trois modules Vintage EQ basés sur des modules égaliseurs classiques.

Les modules Vintage Tube EQ, Vintage Graphic EQ et Vintage Console EQ, inspirés des égaliseurs vintage des années 1950, 1960 et 1970, présentent les caractéristiques tonales distinctes des unités d’origine. Les égaliseurs vintage vous permettent d’ajouter des couleurs sonores à vos pistes audio.

Les trois modules d’égalisation vintage ont en commun un ensemble de commandes de sortie. Toutefois, chaque module dispose également de son propre ensemble de commandes d’égalisation.

## Régler les commandes de sortie de l’égaliseur

Vous pouvez coupler l’étape de sortie de tout module d’égalisation vintage avec un autre module d’égalisation vintage, quel qu’il soit. Dans le module, cliquez sur le menu contextuel Output Model (Modèle de sortie) et choisissez une option ou désactivez l’étape de sortie.

Pour ajouter de la coloration et de la saturation, réglez le potentiomètre Drive (Disque). Pour modifier le niveau de sortie global du module, faites glisser la commande verticalement dans le champ Volume.

Dans les égaliseurs matériels d’origine, toute amplification ou atténuation des fréquences entraîne des décalages de phase au niveau du signal. Avec les modules d’égalisation vintage, vous pouvez choisir le mode de traitement de ces décalages de phase. Cliquez sur le menu contextuel Phase et choisissez l’une des options suivantes :

- Sélectionnez Natural (Naturel) pour reproduire les décalages de phase d’amplification ou d’atténuation de l’égaliseur d’origine. Ce réglage présente moins de latence que le réglage Linear (Linéaire).

- Sélectionnez Linear (Linéaire) pour ne pas intégrer de décalage de phase. Ce réglage permet d’effectuer des amplifications ou des atténuations extrêmes.

## Régler le module Vintage Console EQ

[Image: Capture d’écran de l’interface du module Vintage Console EQ, montrant ses commandes]

Le module Vintage Console EQ reproduit la section d’égalisation du canal d’une table de mixage réputée et reconnue pour ses couleurs tonales. L’égaliseur vintage présente un filtre passif de coupe bas (passe haute) de troisième ordre, deux bandes d’égalisation sélectionnables, ainsi qu’une bande haute fréquence fixe de 12 kHz.

Pour activer ou désactiver chaque bande ou le coupe bas, cliquez sur les boutons situés au-dessus de chaque bande. Pour activer ou désactiver la section d’égalisation, cliquez sur le bouton In (Entrée). Si la section d’égalisation est désactivée, la section de sortie reste active.

## Régler le module Vintage Graphic EQ

[Image: Interface du module Vintage Graphic EQ, montrant ses curseurs de réglage de la fréquence]

Le module Vintage Graphic EQ reproduit un module d’égaliseur graphique pour table de mixage classique. Chaque bande d’égalisation offre 12 dB d’atténuation ou d’amplification avec le mode Proportional Q (Q proportionnel). Ainsi, plus vous amplifiez ou atténuez une fréquence, plus le filtre est affiné.

- Pour régler une fréquence, faites glisser un curseur.

- Pour modifier l’échelle des fréquences de tous les curseurs, faites glisser la commande dans le champ Tune (Régler). La mise à l’échelle des fréquences est proportionnelle. Vous pouvez ainsi adapter les bandes à la tonalité de votre projet.

- Pour activer ou désactiver l’intégralité du module, cliquez sur le bouton In (Entrée).

## Régler le module Vintage Tube EQ

[Image: Interface utilisateur graphique du module Vintage Tube EQ dans Logic Pro ou MainStage, affichant ses sections supérieure et inférieure avec des potentiomètres et des interrupteurs]

Le module Vintage Tube EQ reproduit deux égaliseurs classiques qui sont souvent associés. Le module présente deux sections. La section supérieure reproduit un égaliseur analogique à soupapes qui reste constant, que la section soit activée ou désactivée avec le commutateur In (Entrée). La section inférieure intègre les fréquences moyennes non présentes dans la section supérieure.

Dans la section supérieure, vous pouvez régler trois bandes d’égalisation :

- Pour configurer la basse fréquence, réglez le potentiomètre Low Freq (Basse fréquence). Pour amplifier cette fréquence, réglez le potentiomètre Low Boost (Amplification des basses fréquences). Pour atténuer cette fréquence, réglez le potentiomètre Low Atten (Atténuation des basses fréquences).

- Pour amplifier les hautes fréquences, réglez la fréquence avec le commutateur High Freq (Haute fréquence), configurez la bande passante de l’amplification ou de l’atténuation avec le potentiomètre High Bandwidth (Bande passante élevée), puis réglez le potentiomètre High Boost (Amplification des hautes fréquences).

- Pour atténuer les hautes fréquences, réglez la fréquence avec le potentiomètre High Atten Sel (Atténuation des hautes fréquences en plateau), puis réglez le potentiomètre High Atten (Atténuation des hautes fréquences).

Dans la section inférieure, vous pouvez affiner les fréquences moyennes.

- Pour amplifier les fréquences moyennes basses, réglez la fréquence avec le potentiomètre Low Freq (Basse fréquence), puis réglez le potentiomètre Low Peak (Pointe des basses fréquences).

- Pour atténuer les fréquences moyennes basses, réglez la fréquence avec le commutateur Dip Freq (Fréquence de baisse), puis réglez le potentiomètre Dip (Baisse).

- Pour amplifier les fréquences moyennes hautes, réglez la fréquence avec le commutateur High Freq (Haute fréquence), puis réglez le potentiomètre High Peak (Pointe des hautes fréquences).
