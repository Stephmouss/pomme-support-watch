# Autoriser ou retirer l’autorisation d’accès d’un ordinateur aux achats effectués avec votre compte Apple

Découvrez comment autoriser votre ordinateur à lire les achats effectués avec votre compte Apple, retirer l’autorisation d’accès d’un ordinateur aux achats associés à votre compte Apple et vérifier le nombre d’ordinateurs autorisés dont vous disposez.

[Informations sur l’autorisation de votre ordinateur](https://support.apple.com/fr-fr/118292#aboutauthorizing)

[Comment autoriser ou annuler l’autorisation de votre Mac](https://support.apple.com/fr-fr/118292#authorizemac)

[Comment autoriser ou annuler l’autorisation de votre PC Windows](https://support.apple.com/fr-fr/118292#authorizepc)

## Informations sur l’autorisation de votre ordinateur

- Vous pouvez autoriser jusqu’à cinq ordinateurs à la fois à lire les contenus que vous avez achetés avec votre compte Apple.

- Chaque ordinateur que vous autorisez est comptabilisé comme une autorisation, même si vous autorisez le même ordinateur plusieurs fois.

- Si vous avez déjà cinq ordinateurs autorisés et que vous souhaitez en autoriser un autre, vous devez d’abord annuler l’autorisation de l’un de vos ordinateurs.

- Vous ne pouvez autoriser qu’un ordinateur auquel vous avez accès. Vous ne pouvez pas autoriser un ordinateur à l’aide d’un autre ordinateur, ni à l’aide d’un iPhone ou d’un iPad.

- Une fois que vous avez autorisé votre ordinateur dans une app Apple, vous pouvez accéder à tous les achats effectués avec votre compte Apple dans les autres apps Apple.

- Une fois que vous avez autorisé votre ordinateur, celui-ci est associé à votre compte Apple pour les achats. Les autres appareils, comme les iPhone ou les iPad, ne comptent pas dans la limite des ordinateurs autorisés. Cependant, ils sont associés à votre compte Apple pour les achats. Découvrez comment [visualiser vos appareils associés](https://support.apple.com/fr-fr/118412) .

## Comment autoriser ou retirer l’autorisation d’accès de votre Mac

- Ouvrez l’app Musique ou l’app Apple TV. Dans la barre de menus, cliquez sur Compte et assurez-vous que vous êtes connecté à votre compte Apple.

- Dans le menu Compte, choisissez Autorisations, puis sélectionnez Autoriser cet ordinateur ou Retirer l’autorisation d’accès de cet ordinateur.

[Image: App Musique sur un Mac présentant le réglage Autoriser cet ordinateur ou Retirer l’autorisation d’accès de cet ordinateur.]

- Connectez-vous à votre compte Apple. [Vous avez oublié l’adresse e-mail ou le numéro de téléphone que vous utilisez avec votre compte Apple ?](https://support.apple.com/fr-fr/102627)

- Cliquez sur Autoriser ou Retirer l’autorisation d’accès.

### Afficher le nombre d’ordinateurs autorisés

- Ouvrez l’app Musique ou l’app Apple TV.

- Dans la barre de menus, choisissez Compte, puis sélectionnez Réglages du compte.

- Connectez-vous à votre compte Apple. [Vous avez oublié l’adresse e-mail ou le numéro de téléphone que vous utilisez avec votre compte Apple ?](https://support.apple.com/fr-fr/102627)

- Sur la page Données du compte, regardez à côté de l’intitulé Ordinateurs autorisés pour voir le nombre d’ordinateurs autorisés.

### Si vous devez retirer l’autorisation d’un ordinateur auquel vous n’avez pas accès

Pour retirer l’autorisation d’un ordinateur auquel vous n’avez pas accès, vous devez retirer l’autorisation de tous vos ordinateurs. puis autoriser à nouveau ceux que vous utilisez toujours. Vous pouvez annuler les autorisations de tous vos ordinateurs seulement une fois par an.

- Ouvrez l’app Musique ou l’app Apple TV.

- Choisissez Compte, puis Réglages du compte.

- Connectez-vous à votre compte Apple. [Vous avez oublié l’adresse e-mail ou le numéro de téléphone que vous utilisez avec votre compte Apple ?](https://support.apple.com/fr-fr/102627)

- Sur la page Données du compte, regardez à côté de l’intitulé Ordinateurs autorisés, puis cliquez sur Retirer toutes les autorisations. Si vous ne voyez pas cette option, c’est qu’il s’agit de votre seul ordinateur autorisé.

[Image: App Musique sur un Mac présentant la page Données du compte et le bouton Retirer toutes les autorisations.]

- [Autorisez à nouveau chaque ordinateur que vous utilisez](https://support.apple.com/fr-fr/118292#authorizemac) .

## Comment autoriser ou retirer l’autorisation de votre PC Windows

- Sur votre PC Windows, ouvrez l’app Apple Music ou l’app Apple TV.

- Cliquez sur votre nom en bas de la barre latérale. Il vous sera peut-être demandé de vous connecter d’abord à votre compte Apple.

- Cliquez sur Authorize Machine (Autoriser la machine) ou sur Deauthorize Machine (Annuler l’autorisation de la machine).

[Image: App Apple Music sur un PC Windows présentant les options Authorize Machine (Autoriser la machine) et Deauthorize Machine (Annuler l’autorisation de la machine)]

- Connectez-vous à votre compte Apple. [Vous avez oublié l’adresse e-mail ou le numéro de téléphone que vous utilisez avec votre compte Apple ?](https://support.apple.com/fr-fr/102627)

- Cliquez sur Autoriser ou Retirer l’autorisation d’accès.

### Afficher le nombre d’ordinateurs autorisés

- Sur votre PC Windows, ouvrez l’app Apple Music ou l’app Apple TV.

- Cliquez sur votre nom en bas de la barre latérale, puis cliquez sur Voir mon compte. Il vous sera peut-être demandé de vous connecter d’abord à votre compte Apple.

- Sur la page Données du compte, regardez à côté de l’intitulé Ordinateurs autorisés pour voir le nombre d’ordinateurs autorisés.

[Image: App Apple Music sur un PC Windows présentant la page Données du compte et le nombre d’ordinateurs autorisés]

### Si vous devez retirer l’autorisation d’un ordinateur auquel vous n’avez pas accès

Pour retirer l’autorisation d’un ordinateur auquel vous n’avez pas accès, vous devez retirer l’autorisation de tous vos ordinateurs. puis autoriser à nouveau ceux que vous utilisez toujours. Vous pouvez annuler les autorisations de tous vos ordinateurs seulement une fois par an.

- Sur votre PC Windows, ouvrez l’app Apple Music ou l’app Apple TV.

- Cliquez sur votre nom en bas de la barre latérale, puis cliquez sur Voir mon compte. Il vous sera peut-être demandé de vous connecter d’abord à votre compte Apple.

- Sur la page Données du compte, regardez à côté de l’intitulé Ordinateurs autorisés, puis cliquez sur Retirer toutes les autorisations. Si vous ne voyez pas cette option, c’est qu’il s’agit de votre seul ordinateur autorisé.

- [Autorisez à nouveau chaque ordinateur que vous utilisez.](https://support.apple.com/fr-fr/118292#authorizepc)
