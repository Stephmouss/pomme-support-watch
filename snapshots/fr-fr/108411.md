# Utilisation de Face ID sur votre iPhone ou iPad Pro

Face ID vous permet, en toute sécurité, de déverrouiller votre iPhone ou votre iPad, d’authentifier vos achats, de vous connecter à des apps et bien plus encore, le tout d’un simple regard.

[Configurer Face ID](https://support.apple.com/fr-fr/108411#setup)

[Effectuer des achats avec Face ID](https://support.apple.com/fr-fr/108411#purchases)

[Se connecter avec Face ID](https://support.apple.com/fr-fr/108411#passwords)

## Configurer Face ID

- Dans Réglages, touchez Face ID et code. Si un message vous y invite, saisissez votre code d’accès. Si vous n’avez pas [configuré de code d’accès](https://support.apple.com/119586) , il vous sera demandé d’en créer un qui permettra de vérifier votre identité.

- Assurez-vous d'être dans un endroit bien éclairé, puis touchez Configurer Face ID.

- Tenez votre appareil en orientation portrait, positionnez votre visage devant votre appareil, puis touchez Démarrer.

[Image: L’écran de l’iPhone affiche la configuration de Face ID avec un guide circulaire et l’icône d’un visage.]

- Placez votre visage dans le cadre, puis bougez doucement la tête pour compléter le cercle. Si vous ne pouvez pas bouger la tête, touchez Options d’accessibilité.

- Une fois la première analyse Face ID terminée, touchez Continuer.

- Bougez lentement la tête pour compléter le cercle une seconde fois.

- Touchez OK.

Assurez-vous de disposer d’un bon éclairage lorsque vous configurez Face ID.

Pour choisir les fonctionnalités avec lesquelles utiliser Face ID ou pour réinitialiser Face ID, accédez à Réglages, puis touchez Face ID et code.

[Découvrez les modèles d’iPhone et d’iPad prenant en charge Face ID](https://support.apple.com/102854)

Vous ne pouvez pas utiliser Face ID en mode Paysage lorsque la fonctionnalité Face ID avec un masque est activée.

## Utiliser Face ID

Le fonctionnement de Face ID est optimal lorsque votre iPhone ou votre iPad se trouve entre 25 et 50 cm de votre visage. Face ID fonctionne en mode Portrait et Paysage sur les iPhone 13 et modèles ultérieurs exécutant iOS 16 ou version ultérieure. Sur les modèles d’iPhone antérieurs, Face ID fonctionne uniquement en mode Portrait lorsque vous faites face à la caméra TrueDepth. Sur l’iPad, Face ID fonctionne quelle que soit l’orientation.

Vous pouvez [utiliser Face ID avec un masque](https://support.apple.com/102452) si vous utilisez un iPhone 12 ou ultérieur doté d’iOS 15.4 ou ultérieur. Lorsque vous utilisez Face ID avec un masque sur votre iPhone, cette fonctionnalité n’est disponible qu’en orientation portrait. Face ID avec un masque ne fonctionne pas sur l’iPad.

Face ID fonctionne avec de nombreuses lunettes de vue ou transparentes. Si Face ID ne fonctionne pas avec vos lunettes de vue ou transparentes, essayez de [configurer une autre apparence](https://support.apple.com/guide/iphone/set-up-face-id-iph6d162927a/ios) en portant vos lunettes. Si votre apparence est susceptible de changer radicalement (pilosité faciale, maquillage prononcé ou autres), vous pouvez [configurer une autre apparence](https://support.apple.com/guide/iphone/set-up-face-id-iph6d162927a/ios) afin que Face ID puisse continuer de vous reconnaître.

### Utiliser Face ID avec Apple Pay sur votre iPhone

Pour effectuer un achat dans un magasin :

- Assurez-vous [qu’Apple Pay est bien configuré](https://support.apple.com/108398) et activé dans Réglages, puis touchez Face ID et code.

- Pour utiliser votre carte par défaut, appuyez deux fois sur le bouton latéral. Pour utiliser une autre carte, appuyez deux fois sur le bouton latéral, touchez votre carte par défaut, puis sélectionnez une autre carte.

- Regardez votre iPhone pour vous authentifier à l’aide de Face ID. Si vous portez un masque facial qui couvre votre bouche et votre nez, mais que la fonction Face ID avec un masque n’a pas été configurée, touchez Payer avec le code et saisissez votre code d’accès à la place.

- Présentez le haut de votre iPhone à proximité du lecteur sans contact.

- Attendez que la mention OK et une coche s’affichent à l’écran.

Pour effectuer un achat au sein d’une app ou sur un site web dans Safari :

- Touchez le bouton Acheter avec Apple Pay ou sélectionnez Apple Pay comme mode de paiement. Vérifiez vos informations de paiement. Pour choisir une autre carte avec laquelle payer, touchez le bouton Suivant à côté de votre carte.

- Appuyez deux fois sur le bouton latéral, puis regardez votre iPhone ou votre iPad.

- Attendez que la mention OK et une coche s’affichent à l’écran.

### Utiliser Face ID dans l’iTunes Store, l’App Store et la libraire d’Apple Books

Pour effectuer des achats à l’aide de Face ID dans l’iTunes Store, l’App Store et la librairie, accédez à Réglages, puis touchez Face ID et code, et vérifiez que l’option iTunes Store et App Store est activée. Ensuite, procédez comme suit :

- Ouvrez l’iTunes Store, l’App Store ou la librairie, puis touchez un article que vous souhaitez acheter.

- Lorsque vous êtes invité à régler votre achat, appuyez deux fois sur le bouton latéral, puis regardez votre iPhone ou votre iPad.

[Image: L’écran de l’iPhone affiche un achat sur l’App Store pour Night Sky, invitant à double-cliquer et à confirmer avec Face ID.]

- Attendez que la mention OK et une coche s’affichent à l’écran.

Vous pouvez être invité à saisir le mot de passe associé à votre compte Apple lors de votre premier achat dans l’iTunes Store, l’App Store ou la librairie.

## Se connecter à des apps ou à d’autres sites web avec Face ID

Face ID vous permet de vous connecter à certaines apps, et de préremplir vos noms d’utilisateur et mots de passe sur les sites web dans Safari.

Afin de consulter et de contrôler les apps qui se servent de Face ID pour vous connecter, accédez à Réglages, touchez Face ID et code, puis touchez Autres apps.

Pour utiliser Face ID afin de renseigner automatiquement les noms d’utilisateur et les mots de passe enregistrés pour des sites web dans Safari, accédez à Réglages, touchez Face ID et code, et activez l’option Remplissage automatique des mots de passe.

Si vous utilisez une app compatible avec Face ID, mais que vous n’êtes pas invité à utiliser Face ID pour vous y connecter, il se peut que vous deviez d’abord vous connecter manuellement à l’app.
