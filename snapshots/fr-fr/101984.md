# Si « Téléchargement impossible » apparaît dans l’app Photos

Si certaines de vos photos ne se synchronisent pas avec iCloud, découvrez comment les déplacer de l’album Téléchargement impossible vers votre photothèque.

Lorsque vous consultez l’état de votre photothèque au bas de l’app Photos sur votre iPhone, iPad ou Mac, un message peut vous indiquer que certaines photos ou vidéos ne peuvent pas être synchronisées avec Photos iCloud. Le message d’état « Échec de la synchronisation de [nombre] éléments avec iCloud » peut également s’afficher, et un nouvel album Téléchargement impossible peut apparaître dans l’app Photos.

Pour ajouter ces photos ou vidéos à Photos iCloud, vous pouvez essayer de les exporter à partir de l’app Photos, puis de les réimporter. Les modifications et les mots-clés que vous avez précédemment appliqués à ces photos ou vidéos seront perdus.

## Charger à nouveau vos photos ou vidéos dans iCloud sur votre iPhone ou iPad

- Dans l’app Photos, choisissez l’album Téléchargement impossible.

- Touchez Sélectionner, puis Tout sélectionner, pour sélectionner tous les fichiers.

- Touchez le bouton Partager , puis faites défiler l’écran et touchez Enregistrer dans Fichiers. Dans « Sur mon iPhone », choisissez un emplacement, puis touchez Enregistrer pour enregistrer les fichiers sur votre appareil.

[Image: Aucun texte de remplacement pour l’image]

- [Ouvrez l’app Fichiers](https://support.apple.com/102570) pour vérifier que les fichiers ont bien été exportés.

- Pour supprimer les fichiers de l’album Téléchargement impossible, sélectionnez-les, puis touchez le bouton Corbeille et choisissez Supprimer. Sélectionnez l’album Supprimées récemment, touchez Sélectionner, puis choisissez les éléments à supprimer. Touchez les trois points, puis touchez Supprimer pour confirmer.

[Image: Aucun texte de remplacement pour l’image]

- Pour importer à nouveau les fichiers, choisissez le dossier contenant vos fichiers dans l’app Fichiers. Ensuite, touchez le bouton Partager , puis Enregistrer.

[Image: Aucun texte de remplacement pour l’image]

Une fois les fichiers réimportés, vous pouvez les supprimer de l’emplacement où vous les avez enregistrés afin de libérer de l’espace de stockage sur votre iPhone.

## Charger à nouveau vos photos ou vidéos dans iCloud sur votre Mac

Pour consulter les éléments qui n’ont pas pu être synchronisés avec iCloud dans l’app Photos, cliquez sur le bouton Afficher à côté du message au bas de la fenêtre Photothèque, ou cliquez sur Téléchargement impossible dans la barre latérale. Vous pouvez essayer de réimporter les éléments de l’album Téléchargement impossible dans votre photothèque pour les synchroniser avec Photos iCloud.

[Image: Le dossier Téléchargement impossible vous permet de consulter les photos qui n’ont pas été chargées dans votre photothèque iCloud.]

- Appuyez sur Commande + A pour sélectionner tous les éléments de l’album Téléchargement impossible. Choisissez Ficher, Exporter, puis sélectionnez Exporter les originaux non modifiés de [nombre] photos.

- Dans les boîtes de dialogue qui suivent, cliquez sur Exporter, choisissez un emplacement d’enregistrement, puis cliquez sur Exporter les originaux.

- Une fois les éléments exportés, vérifiez qu’ils sont toujours sélectionnés dans l’album, puis choisissez Image et sélectionnez Supprimer [nombre] photos ou vidéos.

- Cliquez sur Supprimer, puis sur OK.

- Choisissez l’album Supprimées récemment dans la barre latérale, puis choisissez Tout supprimer. Vous pouvez aussi sélectionner uniquement les éléments que vous venez de supprimer.

- Choisissez Fichier et cliquez sur Importer, puis sélectionnez les images que vous venez d’exporter. Pour tout élément correctement synchronisé avec Photos iCloud, les modifications ou les mots-clés que vous avez ajoutés aux éléments concernés peuvent être perdus.
