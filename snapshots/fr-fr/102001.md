# Utilisez le mode d’ouverture de session pour l’authentification 802.1X à un réseau

Vous pouvez vous authentifier sur un réseau à partir de la fenêtre d’ouverture de session lorsque votre Mac est configuré avec un service d’annuaire compatible et peut utiliser ce mode avec une solution de gestion des appareils mobiles.

Pour utiliser le mode d’ouverture de session pour l’authentification 802.1X sur votre Mac, voici ce dont vous avez besoin :

- Une liaison avec un serveur Active Directory (AD) ou Open Directory (OD)

- Un profil de configuration réseau installé qui active le mode d’ouverture de session pour l’interface Ethernet ou le réseau Wi-Fi souhaité

## Authentification avec le mode d’ouverture de session

Pour vous connecter à un réseau avec l’authentification 802.1X depuis l’écran d’ouverture de session, sélectionnez Autre dans la liste des utilisateurs, puis saisissez votre nom d’utilisateur et votre mot de passe. Dans le menu contextuel, sélectionnez ensuite l’interface réseau avec laquelle vous souhaitez vous authentifier, puis cliquez sur le bouton de connexion .

[Image: Bouton de connexion]

## Modification des options d’ouverture de session

Pour modifier l’ouverture de session afin de toujours demander le nom d’utilisateur et le mot de passe, procédez comme suit :

- Choisissez le menu Pomme () > Préférences Système, puis cliquez sur Utilisateurs et groupes.

- Dans la barre latérale, cliquez sur Options de connexion. Vous devrez peut-être cliquer sur l’icône de verrouillage dans l’angle inférieur gauche et vous authentifier avant de pouvoir apporter des modifications.

[Image: Icône de verrouillage des préférences système]

- À côté de « Ouverture de session par : », sélectionnez « Nom et mot de passe ».

Vous pouvez également utiliser un profil de configuration pour définir la fenêtre d’ouverture de session afin d’afficher les champs Nom et Mot de passe.

## Utilisation du mode d’ouverture de session avec FileVault

Lorsque vous utilisez FileVault, vous êtes automatiquement connecté à votre compte d’utilisateur après avoir déverrouillé votre disque. Pour utiliser l’authentification 802.1X à partir de la fenêtre d’ouverture de session lorsque FileVault est activé, désactivez la connexion automatique.

Pour désactiver la connexion automatique lorsque FileVault est activé, saisissez la commande suivante dans Terminal :

sudo defaults write /Library/Preferences/com.apple.loginwindow DisableFDEAutoLogin -bool YES

Si vous souhaitez réactiver la connexion automatique, saisissez la commande suivante dans Terminal :

sudo defaults delete /Library/Preferences/com.apple.loginwindow DisableFDEAutoLogin
