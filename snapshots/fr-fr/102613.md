# Migrer vers un nouveau Mac à l’aide de l’Assistant migration

L’Assistant migration transfère des documents, des apps, des comptes utilisateur et des réglages d’un Mac à un autre. Il ne supprime pas les informations de votre ancien Mac ni ne remplace le système d’exploitation (macOS) de votre nouveau Mac.

L’Assistant migration vous permet également de [transférer des fichiers à partir d’une sauvegarde Time Machine](https://support.apple.com/fr-fr/102551) de votre ancien Mac, ou [à partir d’un PC Windows](https://support.apple.com/fr-fr/102565) .

## Procédure préliminaire

- [Assurez-vous que macOS est à jour](https://support.apple.com/108382) sur chaque Mac. La même version de macOS ne doit pas nécessairement être installée sur chaque Mac.

- Pour procéder à un transfert sans fil, assurez-vous que le Wi-Fi est activé sur les deux ordinateurs et que ces derniers sont proches l’un de l’autre. Si l’un des deux Mac est doté d’ [OS X El Capitan ou version antérieure](https://support.apple.com/fr-fr/109033) , ou si vous hésitez, les deux ordinateurs doivent également être connectés au même réseau Wi-Fi.

- Si un antivirus, un coupe-feu ou un VPN est utilisé sur l’un ou l’autre des Mac, désactivez ce logiciel jusqu’à ce que vous ayez terminé.

## Utiliser l’Assistant migration

L’Assistant migration est inclus avec votre Mac, sous la forme d’une app et dans le cadre de l’Assistant réglages qui s’ouvre lorsque vous démarrez un nouveau Mac pour la première fois.

### Sur le nouveau Mac

- Ouvrez l’Assistant migration :

- Si votre Mac démarre sur un Assistant réglages demandant des informations comme votre pays et votre réseau, passez à l’étape suivante, car l’Assistant réglages comprend un Assistant migration.

- Si vous avez déjà terminé la configuration initiale de votre nouveau Mac, ouvrez l’Assistant migration. Vous pouvez y accéder dans le sous-dossier Utilitaires de votre dossier Applications. Vous pouvez également [utiliser Spotlight](https://support.apple.com/guide/mac-help/search-with-spotlight-mchlp1008/mac) pour le trouver et l’ouvrir. Si on vous demande l’autorisation d’apporter des modifications, saisissez votre mot de passe administrateur.

- Lorsqu’il vous est demandé de sélectionner la méthode de transfert des données, choisissez l’option À partir d’un Mac, de Time Machine ou d’un disque de démarrage. Cliquez sur Continuer.

[Image: Assistant migration avec l’option « À partir d’un Mac, de Time Machine ou d’un disque de démarrage » sélectionnée.]

### Sur l’ancien Mac

- Ouvrez l’Assistant migration, puis cliquez sur Continuer.

- Lorsque vous êtes invité à sélectionner la méthode de transfert des données, choisissez l’option Vers un autre Mac. Cliquez sur Continuer.

### Sur le nouveau Mac

Dans l’écran vous invitant à sélectionner un Mac, une sauvegarde Time Machine ou un autre disque de démarrage, sélectionnez l’icône de l’autre Mac. Cliquez sur Continuer.

[Image: Assistant migration avec l’icône de l’ancien Mac sélectionnée.]

### Sur l’ancien Mac

Si un code de sécurité s’affiche, assurez-vous qu’il est identique à celui apparaissant sur votre nouveau Mac. Cliquez sur Continuer.

### Sur le nouveau Mac

- L’Assistant migration calcule la quantité d’espace de stockage utilisée par toutes vos informations, y compris les applications, les comptes utilisateur, les fichiers, les dossiers et les réglages. Patientez jusqu’à la fin du calcul.

- Cochez la case à côté de chaque catégorie de fichiers que vous souhaitez transférer. Vous pouvez également cliquer sur la flèche d’expansion à côté d’une catégorie et sélectionner des éléments spécifiques à l’intérieur de celle-ci. Cliquez sur Continuer lorsque vous avez terminé.

[Image: null]

[Image: Assistant migration affichant les différentes catégories d’informations.]

- Dans l’exemple illustré, Danny Rico et Olivia Rico sont des comptes utilisateur.

- Si vous transférez un compte administrateur, vous êtes invité à cliquer sur Définir le mot de passe et à saisir un mot de passe sécurisé. Mémorisez ce mot de passe. Celui-ci sera nécessaire pour vous connecter au compte sur votre nouveau Mac.

- Si vous transférez un compte standard, un mot de passe temporaire est attribué et apparaît à l’écran. Notez ce mot de passe. Lorsque l’utilisateur ou l’utilisatrice se connecte pour la première fois, il ou elle doit saisir ce mot de passe, puis saisir son propre nouveau mot de passe lorsqu’on le lui demande.

[Image: Assistant migration affichant les options de mot de passe pour un compte administrateur et non administrateur.]

- Si un compte avec le même nom existe déjà sur votre nouveau Mac, vous devez choisir entre les options suivantes :

- Remplacer le compte de votre nouveau Mac par le compte de votre ancien Mac. Vous pouvez également avoir la possibilité de conserver une copie des données du compte remplacé en les déplaçant vers le dossier Utilisateurs supprimés, où vous pouvez accéder à ces données ultérieurement.

- Renommer l’ancien compte avant de le transférer sur votre nouveau Mac. Les deux comptes sont ainsi conservés, afin que vous puissiez vous y connecter séparément sur votre nouveau Mac.

[Image: Assistant migration affichant les options de remplacement ou de conservation pour un compte existant.]

- Si on vous demande le mot de passe d’un utilisateur existant ou d’une utilisatrice existante déjà autorisé(e) sur votre nouveau Mac, cliquez sur Autoriser, puis saisissez le mot de passe de ce compte.

[Image: Assistant migration demandant le mot de passe d’un compte existant pour autoriser le transfert.]

- Les transferts importants peuvent prendre des heures et sembler s’arrêter de temps en temps. Une fois l’Assistant migration terminé, quittez-le sur les deux ordinateurs, puis connectez-vous au compte migré sur votre nouveau Mac.

## Informations supplémentaires

- L’Assistant migration transfère vos e-mails, mais pour y accéder, vous devrez peut-être d’abord configurer à nouveau votre compte de messagerie dans votre app de messagerie.

- Si vous ne conservez pas votre ancien Mac, [découvrez la procédure à suivre avant de le vendre, de le céder ou de l’échanger](https://support.apple.com/fr-fr/102773) . Ces étapes incluent la possibilité d’effacer votre ancien Mac et de restaurer ses réglages par défaut.
