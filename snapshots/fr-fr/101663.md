# À propos du module de stockage MPX RAID Pegasus R4i Promise pour Mac Pro (2019)

Découvrez comment installer le module Pegasus R4i et l’utiliser avec votre Mac Pro (2019).

Conçu pour le Mac Pro (2019), le Pegasus R4i est un module MPX RAID plug-and-play doté de quatre disques durs SATA à 7 200 tr/min remplaçables de 8 To chacun, offrant une capacité de stockage brute de 32 To. Le module Pegasus R4i est fourni préformaté en RAID 5 matériel. En outre, macOS Catalina bénéficie d’une prise en charge intégrée de ce volume, permettant de l’utiliser immédiatement après son installation.

## Installer le module Pegasus R4i dans les emplacements 1 et 2 du Mac Pro

Pour profiter de performances optimales, Apple recommande [d’installer le module Pegasus R4i dans les emplacements 1 et 2 de votre Mac Pro](https://support.apple.com/fr-fr/HT210104) . Si un module MPX est déjà présent dans les emplacements 1 et 2, vous devrez le déplacer vers les emplacements 3 et 4 de votre Mac Pro. Vous pouvez également trouver des instructions d’installation dans le guide de démarrage rapide fourni avec le Pegasus R4i, ainsi que [sur le site web de Promise](https://www.promise.com/fr/Support) .

## Redémarrer le Mac Pro et installer le logiciel Pegasus Utility

Une fois que vous avez installé le module et redémarré votre Mac Pro, le Pegasus R4i apparaît en tant que volume. Lorsque le Mac Pro reconnaît le module pour la première fois, une série de tonalités est émise à partir du module lui-même. Une autre série de tonalités est émise lorsque vous ouvrez votre session et que le montage du volume réussit. Pour gérer le Pegasus R4i, installez le logiciel Pegasus Utility. Le programme d’installation se trouve sur le volume Pegasus. Pour obtenir de l’aide relative à la gestion de votre volume RAID à l’aide du logiciel Pegasus Utility, [visitez le site web de Promise](https://www.promise.com/fr/Support) .

## Désactiver la fonctionnalité Power Nap

Pour terminer, désactivez la [fonctionnalité Power Nap](https://support.apple.com/fr-fr/HT204032) sur votre Mac Pro : dans le Finder, choisissez Préférences Système > Économiseur d’énergie, puis désélectionnez l’option Activer Power Nap.

Avant d’expédier votre Mac Pro, retirez toujours le module de stockage Pegasus R4i de l’ordinateur afin d’éviter d’endommager ce dernier.
