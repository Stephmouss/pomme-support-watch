# Configurer iCloud Drive

Les fichiers et les dossiers que vous stockez dans iCloud Drive restent à jour sur tous vos appareils. Découvrez comment utiliser iCloud Drive sur votre iPhone, iPad, Apple Vision Pro, Mac ou PC, ou sur iCloud.com.

- [Configurer iCloud Drive sur votre iPhone, iPad ou Apple Vision Pro](https://support.apple.com/fr-fr/118443#iPhone)

- [Configurer iCloud Drive sur votre Mac](https://support.apple.com/fr-fr/118443#Mac)

- [Configurer iCloud Drive sur votre PC Windows](https://support.apple.com/fr-fr/118443#pc)

- [Accéder à iCloud Drive sur iCloud.com](https://support.apple.com/fr-fr/118443#web)

- [Trouver iCloud Drive sur votre appareil](https://support.apple.com/fr-fr/118443#learnmore)

## Configurer iCloud Drive sur votre iPhone, iPad ou Apple Vision Pro

- Mettez à jour votre appareil vers la dernière version d’iOS ou d’iPadOS, puis [connectez-vous à iCloud](https://www.apple.com/fr/icloud/setup/) avec le même compte Apple sur tous vos appareils.

- Ouvrez l’app Réglages, puis touchez votre nom.

- Touchez iCloud.

- Sous la section Enregistré sur iCloud ou Apps utilisant iCloud, touchez Synchroniser cet [appareil] pour activer iCloud Drive.

[Image: Écran d’iPhone illustrant les réglages iCloud Drive. Synchroniser cet iPhone est un commutateur sous la description d’iCloud Drive.]

[Trouver vos fichiers iCloud Drive dans l’app Fichiers](https://support.apple.com/102570)

## Configurer iCloud Drive sur votre Mac

- Mettez à jour votre appareil vers la dernière version de macOS, puis [connectez-vous à iCloud](https://www.apple.com/fr/icloud/setup/) avec le même compte Apple sur tous vos appareils.

- Accédez au menu Apple , cliquez sur Réglages Système, puis sur votre nom.

- Cliquez sur iCloud.

[Image: Dans vos réglages iCloud sur un Mac, l’espace de stockage utilisé apparaît en haut du menu. En dessous se trouve l’option Enregistré sur iCloud, où vous pouvez sélectionner Photos, Drive, Mots de passe et d’autres apps qui enregistrent des données dans iCloud.]

- Si un message vous y invite, connectez-vous à votre compte Apple.

- Sous Enregistré sur iCloud, cliquez sur Drive. Cliquez sur Synchroniser ce Mac pour activer iCloud Drive.

[Image: Écran de macOS illustrant les réglages iCloud Drive. Synchroniser ce Mac est un commutateur sous la description d’iCloud Drive.]

Pour ajouter les fichiers des dossiers Bureau et Documents de votre Mac à iCloud Drive, [activez les dossiers Bureau et Documents](https://support.apple.com/109344) .

- Si vous activez les dossiers Bureau et Documents dans iCloud Drive sur un deuxième Mac, les fichiers et les dossiers seront accessibles depuis un dossier portant le nom de ce Mac.

- Si vous ajoutez le dossier Bureau d’un second Mac, vous pouvez accéder à ses fichiers dans les dossiers Bureau et Documents sur iCloud Drive, dans un dossier portant le même nom que votre second Mac. Les fichiers de cet autre Mac ne sont pas automatiquement fusionnés avec ceux du premier.

Si vous utilisez déjà un autre fournisseur de services cloud pour synchroniser ou gérer vos dossiers Bureau et Documents, désactivez-le avant d’utiliser la fonctionnalité Bureau et Documents.

## Configurer iCloud Drive sur votre PC Windows

- Configurez iCloud Drive sur votre iPhone, votre iPad ou votre Mac.

- Sur un PC utilisant Windows 11 ou une version ultérieure, [téléchargez et installez iCloud pour Windows à partir du Microsoft Store](https://apps.microsoft.com/store/detail/icloud/9PKTQ5699M62) .

- Afin d’ouvrir iCloud pour Windows, cliquez sur Démarrer, sur Applications ou Programmes, puis sur iCloud pour Windows.

- Connectez-vous à votre compte Apple.

- À droite d’iCloud Drive, cliquez sur le bouton en forme de flèche , puis activez iCloud Drive.

[Image: Aucun texte de remplacement pour l’image]

- Cliquez sur Terminé.

## Accéder à iCloud Drive sur iCloud.com

- Rendez-vous sur [iCloud.com](https://icloud.com/) et connectez-vous à votre compte Apple.

- Cliquez sur Drive (ou iCloud Drive).

## Trouver iCloud Drive sur votre appareil

Une fois que vous avez configuré iCloud Drive, tous les documents qui étaient déjà stockés dans iCloud sont automatiquement déplacés vers iCloud Drive :

- Sur votre iPhone, iPad ou Apple Vision Pro, vous pouvez accéder à iCloud Drive via l’app Fichiers.

- Sur votre Mac, allez dans le Finder.

- Sur votre PC, accédez à iCloud Drive via l’Explorateur de fichiers.

- Sur [iCloud.com](https://icloud.com/) , connectez-vous, puis cliquez sur iCloud Drive.
