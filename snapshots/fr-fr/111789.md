# Utiliser le clavier flottant sur votre iPad

Sous iPadOS, vous pouvez réduire la taille du clavier flottant de votre iPad, afin de faciliter son utilisation avec une seule main. Vous pouvez ensuite rétablir la taille d’origine du clavier.

## Réduire la taille du clavier de votre iPad

- Ouvrez une app qui utilise le clavier iPadOS, comme Notes ou Messages.

- Placez deux doigts sur le clavier et effectuez un pincement pour réduire sa taille, ou touchez le bouton Masquer le clavier , puis sélectionnez Flottant.

[Image: null]

- Touchez de manière prolongée le bouton Plus pour déplacer le clavier sur votre écran.

[Image: null]

[Image: iPad présentant le clavier flottant]

Pour utiliser la frappe QuickPath à une seule main, il vous suffit de faire glisser votre doigt d’une lettre à la suivante pour saisir les mots souhaités.

## Rétablir la taille d’origine du clavier sur votre iPad

- Ouvrez une app qui utilise le clavier iPadOS, comme Notes ou Messages.

- Placez deux doigts sur le clavier flottant, puis écartez-les pour agrandir le clavier à sa taille maximale. Vous pouvez également toucher le bouton Plus , puis sélectionnez le bouton Intégral.
