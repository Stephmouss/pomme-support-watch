# Configurer un forfait de données mobiles sur votre iPad Wi-Fi + Cellular

Si vous possédez un iPad Wi-Fi + Cellular, vous pouvez souscrire un forfait de données mobiles. Vous resterez ainsi connecté même lorsque vous n’aurez plus accès à une borne Wi-Fi.

## Utiliser une eSIM

Il existe plusieurs façons d’activer les données mobiles sur un iPad à l’aide de l’eSIM. Pour configurer un forfait de données mobiles avec une eSIM sur votre iPad, utilisez eSIM Carrier Activation (Activation de l’eSIM par l’opérateur), transférez votre forfait depuis un autre iPad, rejoignez un forfait de données mobiles pour iPhone existant, recherchez un nouveau forfait, utilisez un code QR ou utilisez l’app pour iPad de votre opérateur.

[En savoir plus à propos de l’eSIM sur l’iPad](https://support.apple.com/fr-fr/119592)

[En savoir plus à propos des données mobiles sur l’iPad](https://www.apple.com/fr/ipad/cellular/)

[Identifiez votre modèle d’iPad](https://support.apple.com/fr-fr/108043)

En Chine continentale, l’activation d’un forfait de données mobiles avec une eSIM auprès d’un opérateur local est disponible uniquement avec les modèles d’iPad prenant en charge l’eSIM dans ce pays. [En savoir plus sur l’utilisation de l’eSIM avec votre iPad en Chine continentale](https://support.apple.com/fr-fr/104991) .

## Utiliser une carte SIM physique de votre opérateur

Si votre iPad prend en charge les cartes SIM physiques, vous pouvez utiliser celle de votre opérateur pour activer un forfait de données mobiles 1 . Si vous configurez un forfait de données mobiles avec une carte SIM physique auprès de votre opérateur local, la carte SIM sera activée. [Ouvrez le support pour carte SIM](https://support.apple.com/fr-fr/102392) et insérez la carte SIM de votre opérateur. Si vous possédez une carte SIM sur votre ancien iPad et que vous voulez la transférer sur votre nouvel iPad, [retirez-la](https://support.apple.com/fr-fr/102392) de votre ancien iPad et insérez-la dans le support pour carte SIM de votre nouvel iPad.

Si vous ne parvenez pas à vous connecter au réseau de données mobiles, assurez-vous que les données cellulaires sont activées dans l’app Réglages, sous Données cellulaires.

Si vous avez besoin d’aide pour transférer un forfait, ou si vous utilisez un compte d’entreprise ou postpayé, vous devrez peut-être contacter votre opérateur. 2

## Changer votre forfait

Pour modifier ou consulter l’état de votre forfait, ouvrez l’app Réglages et touchez Données cellulaires. Si vous avez configuré votre forfait de données mobiles auprès de votre opérateur, vous devrez peut-être le contacter directement pour modifier votre offre.

Vous pouvez disposer de plusieurs forfaits sur votre iPad en souscrivant à plusieurs opérateurs depuis votre iPad, en ajoutant plusieurs forfaits eSIM ou en insérant une carte SIM dans le support pour carte nano-SIM. Pour passer d’un forfait actif à un autre, procédez comme suit :

- Ouvrez l’app Réglages.

- Touchez Données cellulaires.

- Touchez le forfait que vous souhaitez utiliser dans la section Forfaits cellulaires.

## Désactiver votre forfait

Avec certains opérateurs, vous pouvez désactiver votre forfait de données mobiles prépayé ou postpayé sur votre appareil. Pour désactiver un forfait prépayé, qui est sans engagement, ne le renouvelez pas à la fin du mois.

Les forfaits postpayés se renouvellent chaque mois. Pour désactiver un forfait postpayé :

- Ouvrez l’app Réglages.

- Touchez Données cellulaires.

- Sélectionnez le nom de votre opérateur et choisissez de ne pas renouveler votre forfait.

Si un message d’erreur indique que le type de compte n’est pas pris en charge, ou si vous disposez d’une carte SIM de votre opérateur et que le bouton Gérer le compte Opérateur ne s’affiche pas, contactez votre opérateur et demandez-lui de désactiver votre compte.

## Si vous possédez un iPad avec une carte SIM Apple ou une carte SIM Apple intégrée

Depuis le 1er octobre 2022, la carte SIM Apple ne permet plus d’activer de nouveaux forfaits de données mobiles sur iPad. Contactez votre opérateur pour savoir comment activer un forfait de données mobiles sur iPad.

Si vous ne savez pas si votre iPad est compatible avec la carte SIM Apple, [identifiez votre modèle d’iPad](https://support.apple.com/fr-fr/108043) , puis cliquez sur le lien pour afficher ses caractéristiques techniques.
