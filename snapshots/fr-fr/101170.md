# OS X Mavericks : configuration de la méthode d’authentification liée à une file d’attente d’impression via un profil

La méthode d’authentification liée à une file d’attente peut être prédéfinie dans un profil de configuration.

Le Gestionnaire de profils ne permet pas d’utiliser l’interface utilisateur comme option de configuration, mais vous pouvez l’ajouter à un fichier .mobileconfig exporté. Les valeurs à ajouter au tableau de file d’attente d’impression sont les suivantes :

Option auth-info-required negotiate

Les méthodes d’authentification prises en charge sont définies par [CUPS](http://www.cups.org/documentation.php/doc-1.7/ref-cupsd-conf.html#AuthType) .

Voici un exemple de modèle de profil :

PayloadContent PayloadType com.apple.mcxprinting PayloadVersion 1 PayloadIdentifier YOUR.PAYLOAD.IDENTIFIER.HERE PayloadEnabled PayloadUUID YOUR_GENERATED_UUID PayloadDisplayName Printing RequireAdminToAddPrinters AllowLocalPrinters FooterFontSize 7 FooterFontName Helvetica DefaultPrinter UserPrinterList YOUR_PRINTER_QUEUE_NAME Option auth-info-required negotiate DeviceURI smb://SERVERNAME/YOUR_PRINTER_QUEUE_NAME DisplayName YOUR_PRINTER_DISPLAY_NAME Location PRINTER_LOCATION Model PRINTER_MODEL PrinterLocked PPDURL file://localhost/System/Library/Frameworks/ApplicationServices.framework/Versions/A/Frameworks/PrintCore.framework/Resources/Generic.ppd PayloadIdentifier YOUR.PAYLOAD.IDENTIFIER.HERE PayloadRemovalDisallowed PayloadScope User PayloadType Configuration PayloadUUID YOUR_GENERATED_UUID PayloadOrganization YOUR_PAYLOAD_ORGANIZATION_HERE PayloadVersion 1 PayloadDisplayName YOUR_PAYLOAD_DISPLAY_NAME_HERE
