# Trouver des fichiers sur votre iPhone ou iPad

Apprenez à retrouver vos fichiers, dossiers, téléchargements et autres éléments enregistrés dans l’app Fichiers sur votre iPhone ou iPad.

## Comment ouvrir des fichiers et des dossiers dans l’app Fichiers

- Sur votre iPhone ou iPad, touchez l’app Fichiers pour l’ouvrir.

- Si vous ne voyez pas l’icône de l’app Fichiers sur votre écran d’accueil, balayez vers le bas et recherchez l’app Fichiers.

[Image: Lorsque vous recherchez « fichiers » sur un iPhone, l’icône de l’app Fichiers apparaît en haut de l’écran, sous Meilleurs résultats.]

- Pour rechercher un nom de fichier, utilisez le champ de recherche de l’app Fichiers. Ou touchez l’onglet Explorer, puis choisissez un emplacement :

- Choisissez Sur mon iPhone ou Sur mon iPad pour les fichiers enregistrés localement sur votre appareil.

- Choisissez iCloud Drive pour les fichiers, dossiers et téléchargements synchronisés sur vos appareils dans iCloud Drive, notamment les documents Pages, Numbers et Keynote.

- Choisissez le nom de votre périphérique de stockage externe pour les fichiers stockés sur un [lecteur USB ou lecteur de carte SD](https://support.apple.com/guide/iphone/ph95baac91f/) connecté.

- Choisissez le nom d’une application tierce pour les fichiers enregistrés sur des [services cloud tiers que vous avez ajoutés à l’application Fichiers](https://support.apple.com/fr-fr/102238) , tels que Box, Dropbox et OneDrive.

- Touchez le fichier pour l’ouvrir.

## Si vous ne trouvez pas votre fichier

- Si vous ne trouvez pas une photo, consultez l’app Photos. Bien que vous puissiez enregistrer des photos sur iCloud Drive (ou un autre service cloud) dans l’app Fichiers, votre photothèque est stockée dans l’app Photos.

- Si vous ne trouvez pas un fichier téléchargé, consultez le dossier Téléchargements dans iCloud Drive.

- [Découvrez d’autres façons de parcourir, trier et personnaliser l’app Fichiers](https://support.apple.com/guide/iphone/iphe4bff8827) .
