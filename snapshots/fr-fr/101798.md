# Compressor 4.1 : affichage des messages d’alerte « Impossible à soumettre à la file d’attente » et « className is null », ou transcodage interrompu d’un lot

Procédez comme suit si le message d’alerte « Impossible à soumettre à la file d’attente » s’affiche dans Compressor 4.1 après avoir initialisé le transcodage d’un lot. Il est possible que, suite à l’affichage de ce message, vous soyez invité à redémarrer votre ordinateur, ou à vérifier que Compressor est correctement installé.

## Résolution

Avant de poursuivre, effectuez une sauvegarde de vos réglages personnalisés, situés à l’emplacement Bibliothèque/Application Support/Compressor/, dans votre dossier de départ.

Supprimez ensuite les sous-dossiers Compressor et Apple Qmaster du dossier de départ et du dossier Bibliothèque racine de votre disque de démarrage :

- Depuis le Finder, maintenez la touche Option enfoncée et choisissez Aller > Bibliothèque dans la barre de menus.

- Le dossier Bibliothèque s’ouvre. Ouvrez le dossier Application Support, puis faites glisser les dossiers Compressor et Apple Qmaster dans la corbeille (si présents).

- Accédez au niveau supérieur de votre disque de démarrage. Ouvrez le dossier Bibliothèque, puis le dossier Application Support, et faites glisser les dossiers Compressor et Apple Qmaster dans la corbeille (si présents).

- Redémarrez l’ordinateur.

Effectuez les étapes supplémentaires suivantes si le transcodage de certains lots continue à s’interrompre lorsque vous souhaitez transférer ces derniers à une liste d’ordinateurs partagés :

- Depuis le niveau supérieur de votre disque de démarrage, accédez à Utilisateurs/Partagé/Bibliothèque.

- Dans le dossier Bibliothèque, sélectionnez le dossier Application Support, puis choisissez Fichier > Lire les informations.

- La fenêtre d’informations, se rapportant au dossier Application Support, s’ouvre. Dans la section Partage et permissions de la fenêtre, modifiez les réglages liés aux permissions afin qu’un accès en lecture et en écriture soit attribué pour chaque élément.

- Redémarrez l’ordinateur.
