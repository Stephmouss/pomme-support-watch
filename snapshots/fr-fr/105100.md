# Utiliser des profils dans Safari sur Mac

À partir de Safari 17, vous pouvez utiliser des profils pour séparer vos activités de navigation en fonction de thèmes tels que le travail, la vie personnelle ou l’école. Chaque profil possède un historique, des cookies, des données de site web, des extensions, des groupes d’onglets et des favoris distincts.

- [Créer un profil](https://support.apple.com/fr-fr/105100#create)

- [Passer d’un profil à l’autre](https://support.apple.com/fr-fr/105100#switch)

- [Savoir comment les profils séparent les activités de navigation](https://support.apple.com/fr-fr/105100#shared)

- [Synchroniser des profils entre des appareils](https://support.apple.com/fr-fr/105100#sync)

- [Renommer un profil](https://support.apple.com/fr-fr/105100#rename)

- [Ouvrir des liens avec des profils](https://support.apple.com/fr-fr/105100#links)

- [Utiliser les onglets iCloud avec des profils](https://support.apple.com/fr-fr/105100#tabs)

- [Supprimer un profil](https://support.apple.com/fr-fr/105100#delete)

## Créer un profil

Nécessite Safari 17 ou version ultérieure*

Lorsque vous créez votre premier profil, votre historique, vos cookies, vos données de site web, vos extensions, vos groupes d’onglets et vos favoris actuels sont intégrés au profil par défaut, intitulé Vie personnelle. Les profils que vous créez s’ajoutent à ce profil par défaut.

- Ouvrez Safari. Dans le menu Safari de la barre des menus, choisissez Créer un profil. Vous pouvez également choisir Réglages, puis cliquer sur Profils.

- Cliquez sur Commencer à utiliser des profils. Configurez ensuite votre nouveau profil :

- Nom : le nom apparaîtra dans le nouveau bouton de la barre d’outils Safari pour ce profil.

- Symbole : le symbole apparaîtra dans le bouton de la barre d’outils Safari pour ce profil et dans l’arrière-plan par défaut de la page de démarrage du profil.

- Couleur : la couleur apparaîtra dans le bouton de la barre d’outils Safari pour ce profil et dans l’arrière-plan par défaut de la page de démarrage du profil.

- Favoris : si vous choisissez « Créer un nouveau dossier de signets », le nouveau dossier aura le même nom que ce profil. Les signets enregistrés dans le dossier des favoris apparaissent dans la barre des favoris du profil.

- Cliquez sur Créer un profil. Par défaut, Safari ouvre de nouvelles fenêtres et de nouveaux onglets sur votre page de démarrage.

[Image: Onglet Profils des réglages de Safari après la création d’un profil]

## Passer d’un profil à l’autre

Une fois que vous avez créé un profil, la barre d’outils de Safari affiche un bouton comportant le nom, le symbole et la couleur du profil ou du groupe d’onglets actuellement utilisé. Cliquez sur ce bouton pour ouvrir un menu, puis choisissez :

- Nouvelle fenêtre de [Profil] : ouvre une nouvelle fenêtre dans le profil. Vous pouvez également ouvrir une nouvelle fenêtre de profil en sélectionnant Nouvelle fenêtre [Profil] dans le menu Fichier de la barre des menus.

- Passer à la fenêtre [Profil] : passe à un autre profil sans ouvrir une nouvelle fenêtre. Pour que votre historique de navigation reste séparé, cette option est disponible uniquement à partir d’une fenêtre qui affiche votre page de démarrage ou une page vide, avant que vous ne vous rendiez sur une autre page.

[Image: Le nouveau bouton de la barre d’outils et son menu]

Si vous utilisez Concentration, vous pouvez ajouter un filtre Concentration qui passera automatiquement à un profil Safari spécifique chaque fois que vous utiliserez ce mode de concentration. [Obtenez plus d’informations sur la configuration d’un mode de concentration](https://support.apple.com/guide/mac-help/set-up-a-focus-to-stay-on-task-mchl613dc43f/mac) . Lorsque vous ajoutez un filtre Concentration, choisissez le filtre Safari, puis définissez le type de filtre sur Profil et choisissez le profil que vous souhaitez utiliser.

## Savoir comment les profils séparent les activités de navigation

Certaines fonctionnalités et certains réglages de Safari sont partagés entre les profils, notamment les informations de remplissage automatique et des mots de passe, les réglages de sécurité, les réglages des sites web et les réglages de confidentialité. D’autres ne sont pas partagés ou se comportent différemment.

### Signets

Des signets, notamment des favoris, sont disponibles pour tous les profils via le menu Signets ou la barre latérale . Cependant, la barre des Favoris, que vous pouvez afficher ou masquer à partir du menu Présentation, est partagée différemment :

[Image: barre latérale]

- La barre des Favoris est partagée uniquement entre les profils qui sont [configurés pour utiliser le même dossier Favoris](https://support.apple.com/fr-fr/105100#create) .

- [Les fenêtres de navigation privées](https://support.apple.com/guide/safari/browse-privately-ibrw1069/mac) utilisent la barre des Favoris du profil par défaut uniquement.

### Historique, cookies et autres données de sites web

L’historique de navigation, les cookies et les autres données de sites web ne sont pas partagés entre les profils.

- Lorsque vous commencez à utiliser un nouveau profil, les sites web ne possèdent pas les cookies ou les données de sites web nécessaires pour se souvenir de vous ; ils peuvent donc vous demander de vous connecter à nouveau.

- Lorsque vous [effacez votre historique](https://support.apple.com/guide/safari/clear-your-browsing-history-sfri47acf5d6/mac) , vous pouvez effacer tout l’historique ou uniquement celui d’un profil sélectionné.

### Groupes d’onglets

[Les groupes d’onglets](https://support.apple.com/guide/safari/group-tabs-ibrwa2d73908/mac) ne sont pas partagés entre les profils.

### Réglages de la page de démarrage

[Les réglages de la page de démarrage](https://support.apple.com/guide/safari/customize-a-start-page-ibrw01514823/mac) , ainsi que les réglages « Les nouveaux onglets ouvrent » et « Les nouvelles fenêtres ouvrent » ne sont pas partagés entre les profils.

### Extensions Safari

[Les extensions Safari](https://support.apple.com/HT203051) sont disponibles pour tous les profils, mais sont gérées (activées ou désactivées) de façon séparée.

- Les extensions du profil par défaut sont gérées dans l’onglet Extensions principal des réglages de Safari. Vous pouvez voir les profils qui utilisent chaque extension que vous sélectionnez dans cet onglet. Vous pouvez également désinstaller les extensions de tous les profils à partir de cet onglet.

- Les extensions des autres profils sont gérées dans l’onglet Profils, qui possède son propre onglet Extensions pour chaque profil. Par défaut, les extensions sont désactivées pour chaque nouveau profil.

[Image: Onglet Profils des réglages de Safari, présentant l’onglet Extensions d’un profil]

## Synchroniser des profils entre des appareils

Les profils se synchronisent automatiquement entre tous vos appareils qui utilisent Safari 17 ou version ultérieure, sont connectés avec le même compte Apple et pour lesquels Safari est activé dans la section iCloud des [réglages du compte Apple](https://support.apple.com/guide/mac-help/change-apple-id-settings-on-mac-mchlbf8fdc51/mac) .

## Renommer un profil

Vous pouvez changer le nom, le symbole et la couleur de tous les profils, y compris le profil par défaut. Mais il ne peut y avoir qu’un seul profil par défaut, et vous ne pouvez pas faire d’un autre profil le profil par défaut.

- Dans le menu Safari, choisissez Gérer les profils. Vous pouvez également choisir Réglages, puis cliquer sur Profils.

- Sélectionnez un profil à gauche.

- Dans le champ Nom à droite, saisissez un nouveau nom.

Le profil renommé continue d’utiliser son dossier Favoris existant. Par exemple, si vous avez sélectionné « Créer un nouveau dossier de signets » lors de la création d’un profil de recherche, le profil renommé continue d’utiliser le dossier de recherche pour les favoris. Si vous voulez renommer ce dossier, affichez vos signets dans la barre latérale , puis cliquez sur le dossier de recherche tout en appuyant sur la touche Contrôle et choisissez Renommer dans le menu contextuel.

[Image: barre latérale]

## Ouvrir des liens avec des profils

Par défaut, les liens extérieurs à Safari s’ouvrent dans le dernier profil utilisé. Mais vous pouvez ouvrir les liens vers des sites web spécifiques dans un profil spécifique. Par exemple, vous pouvez décider d’ouvrir les liens vers le site web de votre entreprise dans votre profil Travail, ou d’ouvrir les liens vers le site web de votre établissement scolaire dans votre profil Établissement.

- Accédez au site web que vous voulez configurer pour utiliser cette fonctionnalité.

- Dans le menu Safari, choisissez Réglages, puis cliquez sur Sites web.

- Dans la barre latérale, sélectionnez Ouvrir les liens avec ce profil. La liste des sites web ouverts apparaît à droite.

- Dans le menu contextuel situé à côté d’un site web, choisissez le profil que vous souhaitez utiliser pour ce site web.

Cette fonctionnalité marche uniquement avec les liens ouverts à l’extérieur de Safari, tels que les liens figurant dans Mail, Messages, le Finder ou d’autres apps. Le lien s’ouvre dans le profil que vous avez choisi pour ce site web, à moins que le site web ne soit déjà ouvert dans un autre profil.

[Image: Onglet Sites web des réglages de Safari, présentant la section Ouvrir les liens avec ce profil]

## Utiliser les onglets iCloud avec des profils

Lorsque vous utilisez la fonctionnalité [Onglets iCloud](https://support.apple.com/fr-fr/108409) avec un profil, les onglets iCloud affichés sur votre page de démarrage sont les onglets ouverts dans le même profil sur vos autres appareils qui utilisent les onglets iCloud. Pour voir les onglets ouverts dans un autre profil, [basculez sur ce profil](https://support.apple.com/fr-fr/105100#switch) .

## Supprimer un profil

Lorsque vous supprimez un profil, tout son historique, ses cookies et ses autres données de sites web sont également supprimés. Les favoris et les autres signets sont conservés.

- Dans le menu Safari, choisissez Gérer les profils. Vous pouvez également choisir Réglages, puis cliquer sur Profils.

- Sélectionnez un profil à gauche.

- Cliquez sur le bouton Supprimer (–) en bas de la liste, puis à l’invite correspondante, confirmez l’action.

Vous ne pouvez pas supprimer votre profil par défaut. Si vous supprimez tous les autres profils, Safari arrête d’utiliser des profils.

* Safari 17 est inclus avec macOS Sonoma ou version ultérieure et les dernières mises à jour de macOS Ventura et macOS Monterey. Il est également inclus avec iOS 17 ou version ultérieure pour iPhone, et iPadOS 17 ou version ultérieure pour iPad.
