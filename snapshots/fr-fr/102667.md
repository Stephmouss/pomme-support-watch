# Combiner des vidéos sur iPhone

Fusionnez plusieurs vidéos de votre photothèque à l’aide d’iMovie.

## Combiner des vidéos dans iMovie

- Ouvrez iMovie sur votre iPhone. Si vous n’avez pas l’app iMovie, vous pouvez [la télécharger gratuitement dans l’App Store](https://apps.apple.com/fr/app/imovie/id377298193) .

- Touchez Commencer un nouveau projet. Si vous ne voyez pas l’option Commencer un nouveau projet, touchez Projets pour revenir au navigateur de projets.

- Touchez Film.

[Image: capture-recadrée-ios-16-iphone-14-pro-imovie-nouveau-projet-film]

- Pour parcourir les vidéos de votre photothèque, touchez Données multimédias, Vidéos, puis Tout.

- Touchez une vidéo que vous souhaitez combiner dans votre film, puis sélectionnez-la en touchant la coche dans le menu contextuel. Les vidéos sélectionnées sont surlignées en orange.

[Image: coche]

- Sélectionnez toutes les autres vidéos que vous souhaitez combiner.

[Image: capture-recadrée-ios-16-iphone-14-pro-imovie-nouveau-projet-choisir-des-vidéos]

- Touchez Créer un film. Les vidéos sont combinées dans l’ordre dans lequel vous les avez sélectionnées, mais vous pouvez les réorganiser une fois le film créé.

- Pour regarder un aperçu du film, touchez le bouton de lecture :

- Si le résultat vous convient, touchez OK.

- Pour [changer l’ordre des vidéos](https://support.apple.com/HT213815#Order) ou [effectuer d’autres modifications](https://support.apple.com/HT213815#Edit) , touchez Modifier.

- Pour enregistrer votre nouvelle vidéo dans votre photothèque, touchez le bouton Partager, puis l’option Enregistrer la vidéo.

## Changer l’ordre des vidéos

Après avoir ajouté les vidéos, vous pouvez changer l’ordre dans lequel elles apparaissent dans le film. Dans la timeline d’iMovie (affichée sous la fenêtre d’aperçu), maintenez votre doigt appuyé sur la vidéo que vous souhaitez déplacer, puis faites-la glisser vers une nouvelle position.

Si vous ne voyez pas toutes les vidéos dans la timeline, effectuez un pincement sur la timeline pour zoomer en arrière.

## Modifier la vidéo

Après avoir combiné des vidéos, vous pouvez modifier la durée de chacune d’entre elles, ajouter des effets et plus encore dans la timeline d’iMovie.

- Pour modifier la durée de l’une des vidéos dans la timeline, touchez la vidéo pour la sélectionner (un contour jaune apparaît autour de la vidéo sélectionnée), puis faites glisser l’extrémité gauche ou droite du plan. Si vous ne pouvez pas faire glisser l’extrémité d’un plan pour le rallonger, cela signifie que vous avez déjà atteint sa durée maximale.

- Pour modifier les transitions vidéo, touchez l’icône située entre les deux clips dont vous souhaitez modifier la transition, puis choisissez une option telle que Aucune ou Balayer . Par défaut, la transition est définie sur Dissoudre.

[Image: Aucune]

[Image: Balayer]

[Image: capture-recadrée-ios-16-iphone-14-pro-imovie-transition]

- Pour ajouter d’autres vidéos, touchez le bouton d’ajout de données multimédias , puis Vidéos. Touchez Tout pour parcourir votre photothèque, puis sélectionnez les vidéos que vous souhaitez ajouter.

[Image: données multimédias]

- Une fois l’opération terminée, touchez OK.

## Partager votre vidéo

- Si le mode de modification est toujours activé, touchez OK.

- Touchez le bouton Partager .

[Image: bouton Partager]

- Choisissez Enregistrer la vidéo pour enregistrer la vidéo dans votre photothèque. Vous pouvez également l’envoyer à d’autres personnes en choisissant l’une des méthodes disponibles, comme AirDrop, Mail ou Messages.

[Image: capture-recadrée-ios-16-iphone-14-pro-imovie-enregistrer-la-vidéo]
