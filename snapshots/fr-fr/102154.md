# À propos des instantanés locaux de Time Machine

Time Machine vous permet de restaurer des fichiers à partir d’instantanés locaux des fichiers de votre Mac, même lorsque votre disque de sauvegarde Time Machine n’est pas disponible.

Il peut arriver que votre disque de sauvegarde Time Machine ne soit pas disponible. De ce fait, Time Machine stocke également certaines sauvegardes sur votre Mac. Il s’agit d’instantanés locaux.

## Utilisation des instantanés locaux

Lorsque votre disque de sauvegarde n’est pas disponible, Time Machine utilise automatiquement des instantanés locaux pour vous permettre de restaurer vos fichiers. Reconnectez votre disque de sauvegarde pour accéder à davantage de sauvegardes.

[Découvrez comment restaurer des fichiers depuis Time Machine](https://support.apple.com/guide/mac-help/restore-files-mh11422/mac)

## Fréquence d’enregistrement des instantanés locaux

Time Machine enregistre un instantané de votre disque de démarrage environ toutes les heures et le conserve pendant 24 heures. Un instantané supplémentaire de la dernière sauvegarde Time Machine réussie est conservé, jusqu’à ce que de l’espace soit nécessaire. De plus, sous macOS High Sierra et les versions ultérieures, un autre instantané est enregistré avant l’installation d’une mise à jour de macOS.

## Utilisation de l’espace de stockage par les instantanés

Votre Mac comptabilise l’espace utilisé par les instantanés comme de l’espace de stockage disponible. Il n’est pas nécessaire de se préoccuper de l’espace de stockage occupé par les instantanés locaux. En effet, ceux-ci n’utilisent pas l’espace alloué aux tâches telles que le téléchargement de fichiers, la copie de fichiers ou l’installation de nouveaux logiciels. Néanmoins, Time Machine ne stocke les instantanés que sur des disques disposant d’une quantité importante d’espace libre.

Time Machine supprime automatiquement les instantanés s’ils sont trop anciens ou lorsque de l’espace est nécessaire pour d’autres tâches. Si vous souhaitez supprimer manuellement les instantanés locaux, désactivez temporairement les sauvegardes automatiques :

- Ouvrez les réglages de Time Machine :

- Choisissez Réglages Time Machine (ou Préférences Time Machine) dans le menu Time Machine de la barre des menus.

- Ou sous macOS Ventura 13 ou version ultérieure, choisissez Réglages Système dans le menu Pomme , cliquez sur Général dans la barre latérale, puis sur Time Machine à droite.

- Ou dans les versions antérieures de macOS, choisissez Préférences Système dans le menu Pomme , puis cliquez sur Time Machine.

- Désactivez les sauvegardes automatiques dans les réglages de Time Machine :

- Sous macOS Ventura ou version ultérieure, cliquez sur Options, choisissez Manuellement dans le menu local Fréquence de sauvegarde, puis cliquez sur Terminé.

- Sous macOS Monterey ou version antérieure, désélectionnez l’option « Sauvegarder automatiquement » ou activez ou désactivez l’option à l’aide du commutateur, en fonction de ce que vous voyez.

- Patientez quelques minutes, pendant la suppression des instantanés locaux. Ensuite, réactivez les sauvegardes automatiques. Time Machine se souvient des disques de sauvegarde précédemment utilisés.
