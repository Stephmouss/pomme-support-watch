# Utiliser l’offre groupée d’apps pro pour l’Éducation

Lorsque vous achetez l’offre groupée d’apps pro pour l’Éducation, Apple vous envoie par e-mail cinq codes permettant de télécharger vos apps.

L’offre groupée d’apps pro pour l’Éducation comprend les versions disponibles sous forme d’achat unique de Final Cut Pro, Motion, Compressor, Logic Pro et MainStage. L’offre est préinstallée sur les Mac achetés sur l’ [Apple Store Éducation](https://www.apple.com/fr-edu/store) ou disponible sur l’ [Apple Store pour les établissements d’enseignement](https://ecommerce.apple.com/asb2bstorefront/fys?language=FR&country=FR) .

Chaque app est associée à un code de téléchargement, que vous trouverez dans les e-mails envoyés par Apple après votre achat. Il est important d’utiliser les cinq codes de téléchargement. Ceci vous permettra d’obtenir les futures mises à jour et d’installer les apps sur d’autres ordinateurs Mac connectés au même compte Apple.

Si vous avez acheté un Mac avec l’offre groupée d’apps pro pour l’Éducation préinstallée, vous ne recevrez pas de codes de téléchargement. À la place, vous devrez [adopter les apps.](https://support.apple.com/101869)

## Trouver les e-mails d’Apple contenant les codes de téléchargement

Après avoir acheté l’offre groupée, vous recevrez deux e-mails de la part d’Apple sous un à trois jours ouvrés :

- Le premier e-mail contient un mot de passe permettant d’ouvrir un fichier PDF joint au second e-mail.

- Le fichier PDF joint au second e-mail contient cinq codes de téléchargement, un pour chaque app de l’offre groupée. Le fichier PDF contient également le contrat de licence de chaque app.

Pour trouver ces e-mails, recherchez dans votre boîte de réception les e-mails dont l’objet est « Votre contrat de licence Apple ».

## Utiliser les codes de contenu dans l’App Store sur votre Mac

Une fois que vous avez trouvé l’e-mail contenant les codes, utilisez-les. Lorsque vous utilisez un code pour une app de l’offre groupée, la dernière version de l’app est automatiquement téléchargée depuis le Mac App Store.

- Sur votre Mac, [accédez directement à la page d’utilisation des codes de l’App Store](https://www.apple.com/fr/redeem) . Sinon, vous pouvez procéder comme suit :

- Ouvrez l’App Store.

- Cliquez sur votre nom ou sur le bouton de connexion dans la barre latérale.

- Cliquez sur Utiliser une carte cadeau.

- Si un message vous y invite, connectez-vous à votre compte Apple. Veillez à vous connecter au Mac App Store avec le compte Apple que vous souhaitez associer aux apps.

- Saisissez l’un des codes à 12 chiffres fournis dans le PDF que vous avez reçu par e-mail de la part d’Apple, puis cliquez sur Utiliser. Vous ne pouvez pas vous servir de la caméra de votre Mac pour utiliser ces codes. Vous devez les saisir manuellement.

- Si un message vous y invite, connectez-vous une nouvelle fois à votre compte Apple.

- En attendant que l’app se télécharge sur votre Mac, cliquez sur Utiliser un autre code, puis saisissez le code suivant.

- Répétez l’opération avec le code des autres apps de l’offre groupée.

Une fois téléchargées sur votre Mac, vos apps pro sont prêtes à être utilisées. Veillez à utiliser les cinq codes afin que toutes les apps de l’offre groupée soient associées à votre compte Apple. Ainsi, vous pourrez mettre à jour les apps et les installer sur vos autres Mac, le cas échéant.

## Si vous n’avez pas reçu les e-mails avec les codes de téléchargement

Si vous n’avez pas reçu les codes de téléchargement sous un à trois jours ouvrés à partir du moment où vous avez passé la commande, contactez l’Apple Store en ligne :

- Pour contacter l’Apple Store en ligne aux États-Unis, appelez le 1-800-MY–APPLE (1-800–692–7753).

- Pour d’autres pays ou régions, [accédez à la page web Contacter Apple](https://www.apple.com/fr/contact/) pour trouver le numéro de votre Apple Store.

Vous aurez besoin de votre numéro de commande, qui commence par un W et se trouve en haut de l’accusé de réception de la commande. Si vous avez besoin de rechercher cet e-mail, son objet comprend la mention « Nous traitons votre commande ».

## Si vous ne parvenez pas à utiliser un code de contenu

- Vérifiez que votre Mac dispose de la configuration minimale requise pour l’app dont vous souhaitez utiliser le code :

- [Final Cut Pro, Motion et Compressor](https://www.apple.com/fr/final-cut-pro/specs/)

- [Logic Pro](https://www.apple.com/fr/logic-pro/specs/)

- [MainStage](https://www.apple.com/fr/mainstage/)

- Choisissez Redémarrer dans le menu Apple  pour redémarrer le Mac.

- Déconnectez-vous, puis reconnectez-vous à l’App Store sur votre Mac :

- Pour vous déconnecter, choisissez Store dans la barre de menus de l’App Store, puis Déconnexion.

- Pour vous reconnecter, cliquez sur Se connecter dans l’angle inférieur gauche de la fenêtre de l’App Store, puis connectez-vous à votre compte Apple. Utilisez le compte que vous souhaitez associer à l’app.

- Réessayez d’utiliser le code. Assurez-vous de saisir les bons chiffres et les bonnes lettres. Certaines lettres et certains chiffres se ressemblent.

## Si vous devez installer ou réinstaller les apps que vous avez déjà téléchargées

- Dans l’App Store sur votre Mac, cliquez sur votre nom dans l’angle inférieur gauche ou sur Se connecter si vous n’êtes pas encore connecté. Connectez-vous au compte Apple que vous avez utilisé pour télécharger les apps de l’offre groupée.

- Trouvez l’app achetée que vous souhaitez installer ou réinstaller, puis cliquez sur le bouton Télécharger .
