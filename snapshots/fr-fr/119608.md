# Si vous ne pouvez pas partager un élément dans Final Cut Pro

Découvrez la marche à suivre si vous ne parvenez pas à partager des projets, des plans et d’autres éléments dans Final Cut Pro sur Mac.

## Si l’opération de partage a échoué

Le message « L’opération de partage [destination du partage] a échoué » peut s’afficher lorsque vous partagez un élément à partir d’une bibliothèque Final Cut Pro située sur un périphérique de stockage externe ou lorsque vous en partagez un vers un périphérique de stockage externe. Cet échec peut se produire si le périphérique de stockage n’est pas correctement formaté. Il peut également survenir lorsque [vous partagez des éléments vers des destinations](https://support.apple.com/guide/final-cut-pro/ver9d10063a/mac) autres que la destination associée à la commande Exporter le fichier.

Voici comment vérifier le format du périphérique de stockage :

- Dans le Finder, sélectionnez le périphérique de stockage.

- Sélectionnez Fichier > Lire les informations. Le format du lecteur apparaît dans la section Général de la fenêtre Lire les informations.

Les volumes locaux tels que les périphériques de stockage externes doivent [utiliser le format APFS ou Mac OS étendu](https://support.apple.com/fr-fr/102116) . Les bibliothèques Final Cut Pro peuvent également être stockées sur des volumes Xsan et un [stockage partagé qui utilise le protocole SMB ou NFS](https://support.apple.com/fr-fr/101919) .

Les périphériques de stockage externes sont parfois vendus préformatés avec des formats Windows tels que FAT32 ou exFAT. Si votre lecteur utilise l’un de ces formats, [reformatez-le en APFS](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac) pour obtenir de meilleurs résultats. Vous ne pouvez pas non plus utiliser les lecteurs permettant d’effectuer les [sauvegardes Time Machine](https://support.apple.com/HT201250) .

Avant de tenter à nouveau un partage, procédez de l’une des manières suivantes :

- [Déplacez votre bibliothèque](https://support.apple.com/fr-fr/119610) vers un volume correctement formaté.

- Sauvegardez les données se trouvant sur le périphérique de stockage, reformatez ce périphérique, puis transférez à nouveau les données dessus.

- Assurez-vous que le lecteur dispose de suffisamment d’espace de stockage pour la taille de fichier estimée dans la fenêtre de partage.

## Si vous obtenez le message « Erreur de rendu vidéo : 10008 » ou « Erreur : RenderFrameAt a retourné : # pour l’image absolue : ##### »

Si vous recevez l’un de ces messages lorsque vous essayez de partager votre projet, cela signifie que le plan affiché dans l’alerte est inutilisable. Le nom du plan et son emplacement de timecode apparaissent dans l’alerte afin que vous puissiez localiser le plan inutilisable dans votre projet.

Pour résoudre le problème, [importez à nouveau le plan source dans Final Cut Pro](https://support.apple.com/guide/final-cut-pro/verd0e78ca8/mac) . Avant d’importer un fichier multimédia dans Final Cut Pro, sauvegardez toujours le fichier source en [créant une archive de caméra](https://support.apple.com/guide/final-cut-pro/ver64e710fd/mac) . Ainsi, en cas de besoin, vous disposez toujours d’une copie que vous pourrez réimporter.

Si une sauvegarde ou [une archive de caméra créée dans Final Cut Pro](https://support.apple.com/guide/final-cut-pro/ver64e710fd/mac) Avant d’effectuer cet enregistrement, consultez le fabricant de la caméra pour savoir s’il existe des mises à jour du programme interne de votre caméra.

## Si le message « Impossible de partager l’élément qui fait encore référence à des données sur la caméra » s’affiche, ou si les options du menu Partager sont grisées

Vous pouvez rencontrer les situations suivantes lorsque vous essayez de partager un élément dans Final Cut Pro :

- Alerte « Impossible de partager l’élément qui fait encore référence à des données sur la caméra ».

- Une icône en forme de caméra peut s’afficher en bas à gauche de certains plans.

[Image: Aucun texte de remplacement pour l’image]

- Les options du menu Partager sont grisées.

Dans votre projet, recherchez n’importe quel plan avec une icône en forme de caméra . Cette icône indique que le plan n’a jamais été importé dans une bibliothèque Final Cut Pro. Au lieu de cela, celui-ci se trouve dans une caméra connectée, une carte mémoire, ou une archive de caméra. Ceci peut se produire si une caméra ou un autre périphérique a été déconnecté(e) avant la fin de l’importation du plan.

[Image: Aucun texte de remplacement pour l’image]

Utilisez le champ de recherche du navigateur pour trouver rapidement ces plans.

- Dans la barre latérale Bibliothèques, sélectionnez les bibliothèques, événements ou dossiers que vous souhaitez rechercher.

- Cliquez sur le bouton Rechercher en haut du navigateur et saisissez manquant dans le champ de recherche. Le navigateur affichera alors tous les fichiers manquants. Une icône en forme de caméra s’affiche à côté de tous les fichiers qui se trouvent sur une caméra connectée, sur une carte mémoire ou dans une archive de caméra.

[Image: Aucun texte de remplacement pour l’image]

Une fois que vous avez trouvé les plans concernés, vous devez les réimporter à partir de la source d’origine afin de partager l’élément.

### Importez à nouveau les plans

Pour importer à nouveau les plans, vous devez disposer des données multimédias d’origine sur une caméra, une carte mémoire ou dans une archive de caméra.

- Assurez-vous que le lecteur [défini en tant qu’emplacement de stockage de la bibliothèque de données multimédias](https://support.apple.com/guide/final-cut-pro/ver7db6ffe77/mac) dispose de suffisamment d’espace de stockage.

- Effectuez l’une des actions suivantes :

- Connectez la caméra contenant le plan à votre Mac et allumez-la.

- Insérez la [carte mémoire](https://support.apple.com/guide/final-cut-pro/verd0e789a4/mac) sur laquelle se trouve le plan dans votre Mac ou un lecteur de carte connecté.

- Assurez-vous que [l’archive de caméra](https://support.apple.com/guide/final-cut-pro/ver64e710fd/mac) contenant le plan se trouve dans l’une des archives de caméra Final Cut Pro de votre système.

- Dans Final Cut Pro, une icône de caméra apparaît toujours en regard de votre plan, mais vous pouvez désormais importer à nouveau ce dernier :

- Pour réimporter un plan, sélectionnez-le dans le [navigateur](https://support.apple.com/guide/final-cut-pro/ver91709375/mac) .

- Pour réimporter tous les plans d’un évènement, sélectionnez [l’évènement](https://support.apple.com/guide/final-cut-pro/vercc5fb0c4/mac) dans la barre latérale Bibliothèques.

- Choisissez Fichier > Importer > Réimporter depuis une caméra/archive.
