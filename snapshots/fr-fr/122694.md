# Installer Final Cut Pro, Logic Pro, Pixelmator Pro ou une autre app pro que vous avez déjà achetée

Si vous possédez déjà une app pro, y compris Motion, Compressor, MainStage et Photomator, vous pouvez la télécharger et l’installer sur un autre Mac sans avoir à l’acheter à nouveau.

Vous pouvez également la réinstaller sur le même Mac si vous avez dû effacer le contenu de l’ordinateur ou supprimer l’app pro afin de procéder au dépannage d’un problème.

## Installer une app pro que vous avez déjà achetée

- Ouvrez l’App Store sur votre Mac.

- Cliquez sur votre nom dans la barre latérale, puis recherchez l’app que vous souhaitez télécharger.

[Image: Le Mac App Store affichant les achats et les téléchargements associés au compte Apple actuellement connecté.]

- Si vous ne voyez pas votre nom dans la barre latérale, cliquez sur Se connecter, connectez-vous à votre compte Apple, puis cliquez sur votre photo dans la barre latérale.

- Si vous utilisez le partage familial, vous pouvez sélectionner le nom d’un membre de votre famille à côté de « Acheté par » pour afficher ses achats.

- Cliquez sur le bouton Télécharger de l’app. [Découvrez comment procéder si vous ne parvenez pas à télécharger à nouveau l’app](https://support.apple.com/fr-fr/108105) .

[Image: null]

- Ouvrez l’app. Si un message vous y invite, connectez-vous au compte Apple utilisé pour acheter l’app.

- Le cas échéant, installez les contenus inclus dans l’app que vous aviez installés précédemment, comme la bibliothèque de sons Logic Pro et le contenu supplémentaire de Final Cut Pro.

## Si vous ne parvenez pas à installer une app que vous avez déjà achetée

- Vérifiez que le compte Apple que vous utilisez est bien celui ayant servi à l’achat de l’app.

- Si vous réinstallez l’app par l’intermédiaire du partage familial, vous devez vous connecter à un compte Apple faisant partie du groupe familial qui partage l’app.

- Vous avez peut-être acheté l’app en utilisant un autre compte Apple. Vous pouvez [transférer vos achats vers un seul compte Apple pour les regrouper](https://support.apple.com/fr-fr/117267) .

- Il est possible que votre version de macOS ne soit pas compatible avec la dernière version de l’app. [Effectuez la mise à jour vers la dernière version de macOS](https://support.apple.com/fr-fr/108382) .

- Il se peut que votre Mac ne soit pas compatible avec la dernière version de macOS ou de l’app pro que vous souhaitez mettre à jour. [Identifiez la version de macOS installée sur votre Mac](https://support.apple.com/fr-fr/109033) .

- Vérifiez que l’app n’est pas masquée :

- Cliquez sur votre nom en bas à gauche (ou cliquez sur Connexion pour vous connecter).

- Cliquez sur Réglages du compte en haut de la fenêtre, puis connectez-vous à nouveau si nécessaire.

- Dans la fenêtre qui s’affiche, cliquez sur Gérer dans la section Éléments masqués, puis cliquez sur Afficher à droite de l’app que vous souhaitez afficher.

- Cela fait, cliquez sur Terminé.
