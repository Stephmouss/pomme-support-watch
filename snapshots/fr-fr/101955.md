# Utilisation des touches de modification au démarrage avec Logic Pro pour Mac

Si Logic Pro cesse de répondre ou se ferme de manière inopinée lors de son ouverture, utilisez les touches de modification au démarrage pour résoudre le problème.

Pour entrer dans l’un des modes de dépannage décrits dans cet article, ouvrez le dossier Applications, puis double-cliquez sur l’app Logic Pro. Maintenez la ou les touche(s) de modification respective(s) enfoncée(s) jusqu’à ce qu’une boîte de dialogue apparaisse ou que Logic Pro s’ouvre.

## Ouverture de Logic Pro sans audio ni modules

Appuyez sur la touche Ctrl pendant l’ouverture de l’app, puis choisissez l’une des options suivantes :

- Si vous cliquez sur Lancer, Logic Pro s’ouvrira normalement.

- Si vous cliquez sur Ne pas lancer, Logic Pro s’ouvrira, mais Core Audio sera désactivé. Aucune entrée ou sortie audio ne sera alors définie. Cette touche peut être utile pour exclure tout problème lié à un pilote Core Audio spécifique, en particulier si vous utilisez une interface audio externe. Dans certains cas, Logic Pro peut cesser de répondre ou se fermer de manière inopinée lors de l’initialisation de Core Audio. Si Logic Pro s’ouvre lorsque vous choisissez l’option Ne pas lancer, vous devrez peut-être mettre à jour ou réparer votre interface audio externe.

- Si vous cliquez sur Lancer sans Audio Units, Logic Pro s’ouvrira et Core Audio sera activé. En revanche, tous les modules Audio Units seront désactivés. Cette touche peut être utile pour résoudre les problèmes de modules, notamment ceux issus de modules tiers.

## Ouverture de Logic Pro en mode sans échec Audio Units

Appuyez sur Maj + Ctrl pour ouvrir Logic Pro avec uniquement les modules Audio Units validés.

Si vous avez installé des modules Audio Units qui ont échoué à l’analyse de validation, ouvrez Logic Pro dans ce mode. L’analyse de validation s’effectue automatiquement à la première ouverture de Logic Pro, lors de l’installation de nouveaux modules ou lors de mises à jour de modules existants.

## Ouverture de Logic Pro sans actions de démarrage automatique

À l’ouverture de Logic Pro, appuyez sur Option pour éviter le chargement automatique du projet le plus récent, les boîtes de dialogue Ouvrir et Modèles, ou toute autre option définie dans la sous-fenêtre Gestion du projet de la fenêtre de Logic Pro > Général > Réglages.

Cela permet d’exclure tout problème pouvant être causé par le projet actuellement chargé. Pour un dépannage plus approfondi, appuyez sur la touche Option, puis choisissez Fichier > Nouveau pour charger un projet par défaut vide.
