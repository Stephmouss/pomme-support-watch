# GarageBand pour Mac (v10.0) : le son des boucles peut être différent lorsqu’elles sont lues dans la zone Pistes et dans le navigateur de boucles

Le son de certaines boucles Apple Loops peut être différent quand elles sont lues dans la zone Pistes et lorsque vous les écoutez dans le navigateur de boucles.

Les boucles peuvent avoir été créées avec les effets Écho global et Réverbération activés. Pour ne plus entendre cette différence de son, activez l’option Écho global et Réverbération dans les Préférences Audio/MIDI de GarageBand 10.

[Image: Option Écho global et Réverbération dans les préférences Audio/MIDI de GarageBand 10.]
