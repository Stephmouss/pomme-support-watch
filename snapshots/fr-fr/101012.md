# À propos de la mise à jour 3.0.2 d’OS X Server

Cette mise à jour inclut des améliorations pour OS X Server (Mavericks).

Ce logiciel permet de mettre à jour OS X Server v3.0 et v3.0.1 vers la version 3.0.2, et nécessite OS X Mavericks 10.9.1 ou version ultérieure.

Afin de permettre les connexions L2TP au service VPN, vous devez également installer la [mise à jour VPN pour OS X Server](http://support.apple.com/kb/HT6080?viewlocale=fr_FR) . Installez tout d’abord la mise à jour OS X Mavericks 10.9.1. Après cela, installez la mise à jour 3.0.2 d’OS X Server et la [mise à jour VPN pour OS X Server](http://support.apple.com/kb/HT6080?viewlocale=fr_FR) (dans l’ordre de votre choix).

## Installation de la mise à jour

OS X Server 3.0.2 est disponible dans le Mac App Store. Si vous disposez d’OS X Server (Mavericks), la mise à jour s’affiche dans le volet Mises à jour. Cliquez sur le bouton METTRE À JOUR pour procéder à l’installation. Afin d’éviter toute interruption de service, les mises à jour de Serveur ne sont pas automatiquement installées, même si vous avez sélectionné l’option permettant d’installer automatiquement les mises à jour du Mac App Store.

Lors de l’installation, le message « Remplacement de l’application Serveur détecté. » s’affiche. Ceci est normal. L’intégralité des réglages et des données de l’application Serveur est conservée lors de la mise à jour.

Une fois l’installation effectuée, ouvrez l’application Serveur afin de terminer la configuration des services précédemment configurés.

## Que comprend cette mise à jour ?

La mise à jour 3.0.2 d’OS X Server permet de bénéficier des améliorations mentionnées ci-dessous.

Mise à jour et migration

- Le lancement initial d’OS X Server s’effectue de manière plus stable après une mise à jour ou une migration.

- Le service Mise à jour de logiciels propose désormais automatiquement des mises à jour aux clients Mavericks, après une mise à jour ou une migration.

- Le problème qui pouvait empêcher le démarrage du service DNS, après une mise à jour ou une migration, a été résolu.

Gestionnaire de profils

- L’envoi de notifications Push sur des périphériques gérés s’effectue de manière améliorée.

- Le problème qui pouvait empêcher certains utilisateurs du réseau de bénéficier de réglages gérés, sur des périphériques OS X, a été résolu.

- L’enregistrement d’utilisateurs Active Directory s’effectue de manière plus fiable.

- Le problème affectant l’importation de fichiers .csv, liés à des paramètres fictifs, a été résolu.

- La sélection d’applications comportant des caractères non romains dans leur nom s’effectue de manière plus fiable.

Service Xcode

- La connexion à un référentiel Git, via la commande ssh, s’effectue de manière améliorée.
