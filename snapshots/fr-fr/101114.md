# OS X Server : empêcher la mise en veille

Découvrez comment empêcher la mise en veille sur les Mac avec OS X Server.

Utilisez la commande Terminal suivante (avec un mot de passe administrateur) pour empêcher la mise en veille de l’ordinateur :

sudo pmset -a disablesleep 1

Lorsque la valeur est définie sur 1, toutes les fonctions de mise en veille sont désactivées. L’option Suspendre l’activité dans le menu Apple est également grisée.
