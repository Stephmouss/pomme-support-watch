# Créer une carte à l’aide du mode Siri dans Cartes d’Apple

Grâce au mode Siri, vous pouvez scanner un code-barres ou un code QR dans l’app Caméra ou prendre une capture d’écran d’un code numérique afin de créer des cartes et de les stocker dans l’app Cartes.

## Éléments requis

Pour créer une carte, vous devez disposer des éléments suivants :

- Un iPhone 15 Pro ou modèle ultérieur compatible avec [Apple Intelligence](https://support.apple.com/121115) *.

- La [dernière version d’iOS](https://support.apple.com/118575) .

- L’intelligence visuelle doit être activée.

## Créer une carte dans l’app Photos

- Sur votre iPhone, ouvrez l’app Photos.

- Sélectionner une photo d’un code-barres ou d’un code QR que vous avez prise.

- Touchez le bouton Infos ou effectuez un balayage vers le haut sur la photo.

- Si le code est détecté, le bouton Ajouter la carte à Cartes s’affiche.

[Image: Le bouton « Ajouter la carte à Cartes » dans la sous-fenêtre d’informations affichée sous la photo d’une carte de fidélité dans l’app Photos.]

- Touchez le bouton Ajouter la carte à Cartes.

- Apportez des modifications ou ajoutez des champs si nécessaire.

Vous pouvez également prendre une capture d’écran d’un code-barres ou d’un code QR. Une fois la capture d’écran réalisée, le bouton Ajouter la carte à Cartes apparaît.

## Créer une carte avec votre caméra

- Sur votre iPhone, ouvrez l’app Caméra.

- Prenez en photo une carte physique comportant un code-barres ou un code QR. Il peut s’agir d’une carte d’abonnement, par exemple.

- Touchez le bouton Ajouter la carte à Cartes.

Certains codes-barres ou codes QR sont actualisés et changent périodiquement, ce qui entraîne leur expiration. Si vous prenez en photo un document comportant un code-barres ou un code QR qui expire, comme une place de concert, la carte ne fonctionnera pas.

### Personnaliser vos cartes

Une fois votre carte ajoutée à l’app Cartes, vous pouvez modifier certains de ses champs. Vous pouvez ajouter votre nom, votre statut de membre, la durée d’une adhésion, un lieu, et plus encore. L’apparence de la carte peut également être personnalisée.

## Créer une carte manuellement dans l’app Cartes

- Sur votre iPhone, ouvrez l’app Cartes.

- Touchez le bouton Ajouter une carte , puis touchez Créer une carte.

- Touchez Créer une carte manuellement, puis choisissez un modèle de carte. Vous pouvez créer des cartes standard, d’adhésion et d’évènement.

- Personnalisez votre carte, par exemple en modifiant la couleur d’arrière-plan et en ajoutant du texte aux différents champs.

- Touchez la coche pour ajouter la carte à l’app Cartes.

Le modèle standard est adapté aux cartes d’assurance, aux cartes cadeaux ou aux cartes qui ne sont pas des cartes d’adhésion ni des billets d’évènement.

Dans l’app Cartes, votre nouvelle carte apparaîtra dans la pile de cartes et de billets en dessous de vos cartes de paiement.
