# Utiliser le module MPX Radeon Pro W6600X avec votre Mac Pro (2019)

Découvrez les nombreuses configurations d’écran dont vous pouvez bénéficier avec le module MPX Radeon Pro W6600X sur votre Mac Pro (2019).

Le module MPX Radeon Pro W6600X comporte un processeur graphique AMD Radeon Pro W6600X doté de 8 Go de mémoire GDDR6 ainsi que de deux ports HDMI. Lorsque vous utilisez le Radeon Pro W6600X avec votre Mac Pro, vous pouvez également vous servir des ports Thunderbolt 3 situés sur le dessus* et à l’arrière de votre Mac Pro pour connecter des écrans supplémentaires.

## Connecter des écrans à l’aide de votre Radeon Pro W6600X

Vous pouvez connecter jusqu’à 5 écrans avec les ports Thunderbolt de votre Mac et les ports HDMI du module MPX.

### Si vous connectez un écran au port HDMI

Si vous connectez un écran 4K d’une résolution de 3840 x 2160 à 60 Hz au port HDMI gauche de votre module MPX, vous pouvez connecter jusqu’à quatre écrans supplémentaires avec les configurations suivantes :

- Deux écrans Pro Display XDR d’une résolution de 6016 x 3384 à 60 Hz connectés aux ports Thunderbolt 3 de votre Mac. Connectez un écran à un port Thunderbolt 3 situé sur le dessus* de votre Mac et l’autre écran à un port Thunderbolt 3 situé à l’arrière de votre Mac (carte d’E/S Apple).

- Deux écrans 5K d’une résolution de 5120 x 2880 à 60 Hz connectés aux ports Thunderbolt 3 de votre Mac. Connectez un écran à un port Thunderbolt 3 situé sur le dessus* de votre Mac et l’autre écran à un port Thunderbolt 3 situé à l’arrière de votre Mac (carte d’E/S Apple).

- Quatre écrans 4K d’une résolution de 3840 x 2160 à 60 Hz connectés via Thunderbolt 3.

### Si vous connectez deux écrans aux ports HDMI

Si vous connectez deux écrans 4K d’une résolution de 3840 x 2160 à 60 Hz aux deux ports HDMI de votre module MPX, vous pouvez connecter jusqu’à deux écrans supplémentaires avec les configurations suivantes :

- Un écran Pro Display XDR d’une résolution de 6016 x 3384 à 60 Hz connecté à un des ports Thunderbolt 3 de votre Mac. Connectez l’écran à n’importe lequel des ports Thunderbolt 3 de votre Mac.

- Un écran 5K d’une résolution de 5120 x 2880 à 60 Hz connecté via Thunderbolt 3. Connectez l’écran à n’importe lequel des ports Thunderbolt 3 de votre Mac.

- Deux écrans 4K d’une résolution de 3840 x 2160 à 60 Hz connectés via Thunderbolt 3. Connectez un écran 4K à un port Thunderbolt 3 situé sur le dessus* de votre Mac et le second à un port Thunderbolt 3 situé à l’arrière de votre Mac (carte d’E/S Apple).
