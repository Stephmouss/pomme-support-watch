# Si vous ne parvenez pas à transférer un fichier sur un DVD ou un Blu-ray dans Final Cut Pro, Motion 5 ou Compressor

Si vous utilisez une image pour l’arrière-plan, le logo ou le titre, essayez de la convertir avec Aperçu.

Si vous essayez de transférer un fichier sur un DVD ou un Blu-ray en utilisant Final Cut Pro sur Mac, Motion ou Compressor, et que le message « L’opération de partage DVD a échoué » ou « L’opération de partage Blu-ray a échoué » apparaît, vérifiez le format du fichier que vous utilisez pour l’arrière-plan, le logo ou le titre.

## Vérifier le format de l’image

Sélectionnez l’image dans le Finder et choisissez Lire les informations. Si nécessaire, cliquez sur la flèche d’expansion située à côté de Général. Si « High Efficiency Image File Format » (HEIF) apparaît à côté de Type, convertissez le fichier dans un autre format avec Aperçu.

[Image: la flèche d’expansion]

## Convertir le fichier HEIF

- Cherchez le fichier dans le Finder, puis double-cliquez dessus pour l’ouvrir dans Aperçu.

- Choisissez Fichier > Exporter.

- Saisissez un nom, puis choisissez un emplacement pour le fichier.

- Appuyez sur la touche Option et maintenez-la enfoncée, cliquez sur le menu local Format, puis choisissez l’un des types de fichiers suivants :

- JPEG

- PNG

- TIFF

- PDF

- PSD

- BMP

- GIF

- Cliquez sur Enregistrer.

- Mettez à jour les éléments graphiques de votre menu avec le nouveau fichier converti, puis essayez à nouveau de transférer celui-ci sur un DVD ou un Blu-ray.
