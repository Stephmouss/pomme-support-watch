# Retrouver et gérer les sauvegardes de votre iPhone, iPad ou iPod touch

Accédez à la liste de vos sauvegardes iOS ou iPadOS sur votre Mac, PC ou appareil iOS ou iPadOS. Découvrez comment supprimer des sauvegardes, les copier et plus encore.

[Retrouver les sauvegardes stockées sur votre Mac](https://support.apple.com/fr-fr/108809#locate-mac)

[Retrouver les sauvegardes stockées sur votre PC](https://support.apple.com/fr-fr/108809#locate-pc)

[Gérer les sauvegardes dans le Finder ou l’app Appareils Apple](https://support.apple.com/fr-fr/108809#manage-backups)

## Retrouver les sauvegardes stockées sur votre Mac

- Dans le menu Aller de la barre des menus du Finder, choisissez Aller au dossier.

- Saisissez ou copiez et collez ~/Library/Application Support/MobileSync/Backup/ dans la fenêtre du chemin d’accès.

## Retrouver les sauvegardes stockées sur votre PC

- Appuyez sur la touche Windows + R pour ouvrir la boîte de dialogue Exécuter.

- Saisissez %USERPROFILE% si vous utilisez l’app Appareils Apple ou l’app iTunes du Microsoft Store.

- Si iTunes affiche « Aide > Rechercher les mises à jour » et que vous n’utilisez pas l’app Appareils Apple, saisissez %AppData% . Lorsque iTunes sur votre PC affiche « Aide > Rechercher les mises à jour », cette situation signifie généralement que vous disposez de l’ancienne version traditionnelle d’iTunes (pas celle du Microsoft Store) et que vous devez la mettre à jour manuellement à l’aide du menu Aide. Cependant, si vous avez la version du Microsoft Store, les mises à jour sont automatiques, et la référence %AppData% suggère d’éventuels problèmes liés à l’emplacement des fichiers ou une installation corrompue. Pour garder les logiciels Apple pour Microsoft Windows à jour sur votre PC, [utilisez Microsoft Store et Apple Software Update](https://support.apple.com/fr-fr/118406) .

## Gérer les sauvegardes dans le Finder ou l’app Appareils Apple

- Ouvrez le Finder ou l’app [Appareils Apple](https://support.apple.com/guide/devices-windows/welcome/windows) .

- Connectez votre appareil à l’aide d’un câble USB.

- Si votre appareil n’est pas sélectionné automatiquement, cliquez sur celui-ci. [Découvrez la marche à suivre si votre appareil n’apparaît pas](https://support.apple.com/fr-fr/108643) .

- Si nécessaire, confirmez que votre appareil peut être considéré comme un appareil de confiance. Cette opération est généralement nécessaire lorsque vous utilisez un nouvel appareil avec une sauvegarde d’un autre appareil de confiance.

- Sous l’onglet Général, cliquez sur « Gérer les sauvegardes » pour afficher la liste de vos sauvegardes. Ensuite, cliquez avec le bouton droit sur la sauvegarde de votre choix, puis choisissez Supprimer, Archiver, « Afficher dans le Finder » ou « Afficher dans l’Explorateur ».

[Image: Une fenêtre du Finder avec l’option « Afficher dans le Finder » sélectionnée]

- Une fois que vous avez terminé, cliquez sur OK pour revenir au Finder ou à l’app Appareils Apple.
