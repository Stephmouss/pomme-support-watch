# Retrouver et gérer les sauvegardes de votre iPhone, iPad ou iPod touch

Trouvez où votre Mac ou PC stocke les sauvegardes de votre iPhone et iPad. Puis supprimez ou archivez une sauvegarde dans le Finder ou l’app Appareils Apple.

[Retrouver les sauvegardes stockées sur votre Mac](https://support.apple.com/fr-fr/108809#locate-mac)

[Retrouver les sauvegardes stockées sur votre PC](https://support.apple.com/fr-fr/108809#locate-pc)

[Gérer vos sauvegardes](https://support.apple.com/fr-fr/108809#manage-backups)

## Retrouver les sauvegardes stockées sur votre Mac

- Dans le menu Aller de la barre des menus du Finder, choisissez Aller au dossier.

- Collez ou saisissez ~/Library/Application Support/MobileSync/Backup/ dans le champ de texte, puis appuyez sur Retour.

## Retrouver les sauvegardes stockées sur votre PC

- Appuyez sur la touche Windows + R.

- Saisissez %USERPROFILE%\Apple\MobileSync\Backup , puis appuyez sur Entrée.

- Si le dossier ne s’ouvre pas, saisissez %AppData%\Apple Computer\MobileSync\Backup à la place.

## Gérer vos sauvegardes

Une fois que vous avez supprimé une sauvegarde, vous ne pouvez plus la récupérer. Si vous souhaitez conserver une sauvegarde, archivez-la afin qu’elle ne soit pas remplacée par des sauvegardes ultérieures.

- Ouvrez le Finder ou l’app [Appareils Apple.](https://support.apple.com/guide/devices-windows/welcome/windows)

- Connectez votre appareil à votre ordinateur à l’aide d’un câble USB.

- Si votre appareil n’est pas sélectionné, cliquez dessus.

- Si un message vous le demande, touchez Faire confiance sur votre appareil et saisissez votre code d’accès.

- Cliquez sur l’onglet Général, puis sur Gérer les sauvegardes.

- Cliquez avec le bouton droit de la souris sur la sauvegarde de votre choix.

- Choisissez Supprimer, Archiver ou Afficher dans le Finder.

[Image: La zone de dialogue Sauvegardes de l’appareil dans le Finder avec une sauvegarde sélectionnée et son menu contextuel ouvert.]

- Une fois que vous avez terminé, cliquez sur OK.

Si votre appareil n’apparaît pas, consultez l’article [Résoudre le problème d’un appareil qui n’apparaît pas](https://support.apple.com/fr-fr/108643) .

Sur un PC, la troisième option est Afficher dans l’Explorateur.
