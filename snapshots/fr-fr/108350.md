# Utiliser le Mode sombre sur votre iPhone et votre iPad

Activez le Mode sombre pour optimiser le confort visuel en conditions de faible éclairage.

## Activer le Mode sombre dans Réglages

- Accédez à Réglages, puis touchez Luminosité et affichage.

[Image: Les réglages Apparence sous iOS 26.]

- Sélectionnez Sombre pour activer le Mode sombre.

## Activer le Mode sombre dans le centre de contrôle

- Ouvrez le centre de contrôle sur votre [iPhone](https://support.apple.com/fr-fr/108330) ou [votre iPad](https://support.apple.com/fr-fr/111790) .

- Touchez de manière prolongée la barre de luminosité.

- Sélectionnez Mode sombre pour activer ou désactiver l’option.

[Image: null]

## Ajouter le Mode sombre au centre de contrôle

Si le Mode sombre n’apparaît pas dans le centre de contrôle, vous pouvez l’ajouter.

- Ouvrez le centre de contrôle sur votre [iPhone](https://support.apple.com/fr-fr/108330) ou [votre iPad](https://support.apple.com/fr-fr/111790) .

- Touchez de manière prolongée un espace vide dans le centre de contrôle pour modifier l’écran.

- Touchez Ajouter une commande en bas de l’écran et sélectionnez Mode sombre pour l’ajouter au centre de contrôle.

[Image: null]

## Définir l’activation automatique du Mode sombre

- Accédez à Réglages, puis touchez Luminosité et affichage.

- Sélectionnez Automatique.

- Touchez Options pour planifier le Mode sombre.

Découvrez comment utiliser le [Mode sombre sur votre Mac](https://support.apple.com/guide/mac-help/mchl52e1c2d2/mac) .
