# Affichage et modification du nom du point d’accès de votre iPhone ou iPad

Découvrez comment afficher et modifier le nom du point d’accès utilisé par les services de données mobiles sur votre iPhone et votre iPad.

Le nom du point d’accès définit le chemin réseau nécessaire à toutes les connexions de données mobiles. Avec certains opérateurs, vous devez saisir les réglages du nom du point d’accès afin de configurer votre forfait mobile.

Vous ne pouvez modifier ou afficher le nom du point d’accès sur votre iPhone et votre iPad que si votre opérateur le permet. Si vous ne pouvez pas modifier vos réglages du nom du point d’accès, [contactez votre opérateur](https://support.apple.com/fr-fr/109526) .

## Renseigner automatiquement les réglages du nom du point d’accès

Si votre opérateur mobile prend en charge cette fonctionnalité, vous pouvez renseigner automatiquement les réglages du nom du point d’accès sous iOS 16, iPadOS 15 et versions ultérieures.

- Insérez votre carte SIM ou [configurez une eSIM](https://support.apple.com/fr-fr/118669) .

- Sur votre iPhone ou iPad, ouvrez l’app Réglages.

- Touchez Données cellulaires.

- Touchez Réseau de données cellulaires.

Si l’option permettant d’utiliser les réglages de l’opérateur n’apparaît pas, saisissez les réglages du nom du point d’accès.

## Afficher et modifier les réglages du nom du point d’accès

Si les réglages du nom du point d’accès sont incorrects, vous risquez de perdre la connexion à votre réseau de données mobiles et de devoir payer des frais supplémentaires. Ne modifiez pas le nom du point d’accès, sauf si votre opérateur ou l’administrateur de votre appareil mobile vous le demande. [Contactez votre opérateur](https://support.apple.com/fr-fr/109526) pour vérifier les réglages appropriés du nom du point d’accès.

Si votre opérateur le permet, vous pouvez consulter les réglages du nom du point d’accès à l’un des deux endroits suivants :

- Ouvrez l’app Réglages. Touchez Données cellulaires, puis sélectionnez Réseau de données cellulaires.

- Ouvrez l’app Réglages. Touchez Mobile Data (Données cellulaires), sélectionnez Mobile Data Options (Options des données cellulaires), puis Mobile Data Network (Réseau de données cellulaires).

Si votre appareil ne dispose d’aucune des deux options, [contactez votre opérateur](https://support.apple.com/fr-fr/109526) .

Pour modifier les réglages de votre appareil, touchez chaque champ et saisissez les informations fournies par votre opérateur. Les réglages devraient normalement être enregistrés automatiquement. En fonction de votre opérateur, il est possible que vous ne puissiez pas modifier ces réglages. Si un nom de point d’accès différent est requis par votre opérateur, il est possible que vous puissiez appliquer le réglage correct à l’aide d’un profil de configuration.

À moins d’utiliser un profil de configuration, la mise à jour d’iOS réinitialise les modifications apportées aux réglages du nom du point d’accès. Si vous modifiez ces réglages avant la mise à jour d’iOS, les réglages par défaut sont rétablis. Il se peut que deviez saisir à nouveau vos réglages après une mise à jour d’iOS.

## Rétablir les réglages du nom du point d’accès

Vous pouvez rétablir les informations par défaut du nom du point d’accès de votre opérateur.

- Ouvrez l’app Réglages.

- Touchez Données cellulaires.

- Touchez Réseau de données cellulaires.

- Touchez Réinitialiser les réglages. Si vous avez installé un profil de configuration, les réglages par défaut de ce profil sont appliqués à la place.

Si votre iPhone ou iPad est un appareil d’entreprise, vous devrez peut-être contacter l’administrateur de votre appareil mobile afin de modifier le nom du point d’accès. Si vous modifiez les réglages du nom du point d’accès qu’un administrateur d’appareil mobile a définis pour vous à partir d’un profil de configuration, vous pouvez annuler ces modifications :

- Sur l’iPhone : ouvrez l’app Réglages. Touchez Données cellulaires, puis Réseau de données cellulaires et sélectionnez Réinitialiser les réglages.

- Sur l’iPad : supprimez le profil de configuration, puis ajoutez-le à nouveau.

Si vous êtes un administrateur d’appareils mobiles, vous pouvez modifier le nom du point d’accès et d’autres réglages avancés à l’aide d’Apple Configurator ou d’une autre solution de gestion des appareils mobiles.

## Si vous configurez un nouvel appareil

Si vous configurez un nouvel appareil, vous devrez peut-être reconfigurer les réglages du nom du point d’accès pour vous reconnecter à votre opérateur.
