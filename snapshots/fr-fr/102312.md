# Déterminez quel processeur graphique est utilisé sur votre MacBook Pro

Découvrez comment déterminer si votre MacBook Pro utilise un processeur graphique (GPU) distinct ou intégré.

De nombreux ordinateurs portables MacBook Pro 15 pouces disposent de deux processeurs graphiques (GPU) : un processeur graphique distinct et un processeur graphique intégré. Le GPU distinct offre de meilleures performances graphiques, mais consomme davantage d’énergie. Le GPU intégré augmente l’autonomie de la batterie en consommant moins d’énergie.

## Déterminer si le GPU utilisé est le GPU distinct ou intégré

Pour déterminer quelles cartes graphiques sont utilisées, sélectionnez le menu Pomme () > À propos de ce Mac. Les cartes graphiques en cours d’utilisation apparaissent en regard de Graphisme. [Découvrez les GPU intégrés dont votre Mac peut être équipé](https://support.apple.com/fr-fr/101199) [.](https://support.apple.com/HT204349)

## Vérifiez si une app utilise un processeur graphique (GPU) dédié

Pour déterminer si une app utilise le processeur graphique distinct hautes performances, ouvrez Moniteur d’activité et cliquez sur l’onglet Énergie. Si la colonne Carte graphique n’apparaît pas, cela signifie que votre ordinateur dispose d’un seul processeur graphique.

Dans cet exemple, Final Cut Pro et Photos utilisent le GPU distinct aux performances plus élevées :

Voici quelques exemples d’apps et d’accessoires qui utilisent le GPU distinct aux performances plus élevées :

- Un écran externe
