# Élaguer une plage d’un plan dans la timeline de Final Cut Pro pour iPad

Si vous utilisez la commande Début de l’élagage ou Fin de l’élagage lorsqu’une plage de sélection est active dans un plan, l’opération s’applique à l’emplacement de la tête de lecture.

Au lieu d’utiliser le bouton Élaguer le début ou le bouton Élaguer la fin sur une plage de sélection, passez en mode Sélection de plan pour ajuster ou scinder un plan.

[Image: Aucun texte de remplacement pour l’image]

- Le projet étant ouvert, touchez la commande jaune Sélectionner dans l’angle supérieur gauche de la timeline, puis touchez Plan.

- Dans la timeline, touchez le plan que vous souhaitez élaguer ou scinder.

- Faites glisser la tête de lecture jusqu’à l’image où vous souhaitez appliquer l’opération.

[Image: Timeline de Final Cut Pro pour iPad affichant une plage de sélection]

- Dans l’angle inférieur droit de l’écran, touchez le bouton Scinder afin de scinder le plan, ou touchez le bouton Élaguer le début ou le bouton Élaguer la fin pour ajuster le plan. Si ces boutons sont grisés ou n’apparaissent pas, assurez-vous que le plan est sélectionné, que la tête de lecture est positionnée dessus ou que les boutons Volume et Animer ne sont pas activés.
