# Télécharger et supprimer des épisodes dans Apple Podcasts sur iPhone et iPad

Continuez à écouter les podcasts que vous suivez lorsque vous n’êtes pas connecté à un réseau Wi-Fi ou mobile.

- [Télécharger des épisodes de podcast](https://support.apple.com/fr-fr/102243#download)

- [Désactiver les téléchargements automatiques](https://support.apple.com/fr-fr/102243#automaticdownloads)

- [Modifier les réglages de téléchargement automatique](https://support.apple.com/fr-fr/102243#settings)

- [Supprimer des épisodes de podcast](https://support.apple.com/fr-fr/102243#delete)

## Télécharger des épisodes de podcast sur iPhone ou iPad

- Ouvrez l’app Podcasts.

- Recherchez une émission, puis sélectionnez-la.

- Touchez de manière prolongée l’épisode que vous souhaitez télécharger.

- Touchez Télécharger.

Lorsque vous suivez un podcast, l’épisode le plus récent est automatiquement téléchargé sur votre appareil.

## Désactiver les téléchargements automatiques

Si vous ne souhaitez pas que les nouveaux épisodes d’un podcast soient téléchargés automatiquement sur votre appareil, vous pouvez désactiver cette fonctionnalité.

### Désactiver les téléchargements automatiques pour un podcast

- Ouvrez l’app Podcasts.

- Recherchez une émission ou choisissez-en une dans votre bibliothèque.

- Touchez la coche en haut de l’écran.

- Touchez Désactiver les téléchargements automatiques.

### Cesser de télécharger tous les futurs épisodes des podcasts que vous suivez

- Ouvrez l’app Réglages.

- Touchez Apps, puis sélectionnez Podcasts.

- Sous Téléchargements auto, touchez Téléchargement automatique, puis choisissez Non.

## Modifier les réglages de téléchargement automatique

Choisissez le nombre de téléchargements que vous souhaitez conserver et si vous souhaitez télécharger des podcasts vidéo.

### Choisir le nombre d’épisodes que vous souhaitez télécharger automatiquement et conserver

- Ouvrez l’app Réglages.

- Touchez Apps, puis sélectionnez Podcasts.

- Sous Téléchargements auto, touchez Téléchargement automatique, puis choisissez le nombre d’épisodes que vous souhaitez télécharger, ou une période.

### Modifier vos réglages de téléchargement de podcasts vidéo

- Ouvrez l’app Réglages.

- Touchez Apps, puis sélectionnez Podcasts.

- Diffusez des vidéos uniquement via Wi-Fi : accédez aux préférences de diffusion vidéo et désactivez l’option Autoriser via cellulaire.

- Téléchargez automatiquement les versions vidéo d’une émission : accédez à Téléchargements auto et activez Télécharger la vidéo. Vous pouvez décider d’effectuer les téléchargements via le réseau cellulaire en touchant Autoriser via cellulaire, puis en sélectionnant Audio seulement ou Vidéo.

## Supprimer des épisodes de podcast sur iPhone ou iPad

Vous pouvez supprimer un épisode, tous les épisodes d’un podcast ou tous les épisodes téléchargés.

### Supprimer un épisode

- Ouvrez l’app Podcasts.

- Sur votre iPhone, accédez à l’onglet Bibliothèque, puis touchez Téléchargé. Sur votre iPad, accédez à Bibliothèque dans la barre latérale, puis touchez Téléchargé.

- Touchez l’émission.

- Recherchez l’épisode que vous souhaitez supprimer, puis touchez son nom de manière prolongée.

- Touchez Supprimer le téléchargement.

Les épisodes sont supprimés automatiquement 24 heures après leur lecture. Si vous ne souhaitez pas que les épisodes soient supprimés automatiquement, allez dans Réglages, Apps, puis faites défiler l’écran vers le bas jusqu’à Podcasts. Désactivez l’option Supprimer les téléchargements lus.

### Supprimer tous les épisodes d’un podcast

- Ouvrez l’app Podcasts.

- Sur votre iPhone, accédez à l’onglet Bibliothèque, puis touchez Téléchargé. Sur votre iPad, accédez à Bibliothèque dans la barre latérale, puis touchez Téléchargé.

- Touchez de manière prolongée l’émission que vous souhaitez supprimer.

- Touchez Supprimer les téléchargements.

### Supprimer tous les épisodes

- Ouvrez l’app Podcasts.

- Sur votre iPhone, accédez à l’onglet Bibliothèque, puis touchez Téléchargé. Sur votre iPad, accédez à Bibliothèque dans la barre latérale, puis touchez Téléchargé.

- Touchez le bouton Plus .

[Image: Icône du bouton Plus]

- Touchez Supprimer tous les téléchargements.

- Confirmez que vous souhaitez supprimer tous vos téléchargements.
