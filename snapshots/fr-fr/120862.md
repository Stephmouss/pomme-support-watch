# Si certaines données iCloud ne se synchronisent pas lorsqu’un ou une élève configure un nouvel appareil

Il sera peut-être demandé aux élèves de fournir un ancien code d’accès d’un appareil précédent afin de terminer la synchronisation des données iCloud sur un nouvel appareil.

Cet article est destiné aux équipes enseignantes et aux administrateurs et administratrices système qui aident des élèves à configurer de nouveaux appareils.

Les données chiffrées de bout en bout dans iCloud comprennent les mots de passe enregistrés, les signets et l’historique de Safari, Messages sur iCloud, l’historique de Plans et les Memoji. Apprenez-en plus sur la [sécurité des données iCloud](https://support.apple.com/102651) et sur la façon dont iCloud protège les données.

Les élèves peuvent suivre les étapes ci-dessous pour finir la synchronisation des données iCloud sur leurs nouveaux appareils.

## Synchroniser vos données iCloud

Si votre code d’accès actuel est différent de votre code d’accès précédent, saisissez le code d’accès de votre appareil précédent pour poursuivre les étapes de l’Assistant réglages et synchroniser vos données iCloud. Cependant, vos données iCloud ne seront pas complètement synchronisées tant que vous n’aurez pas accédé à Réglages pour terminer le processus.

Dans Réglages, touchez le message « Certaines données iCloud ne sont pas synchronisées » sous votre compte Apple géré. Ensuite, touchez « Reprendre la synchronisation des données » et effectuez l’une des opérations suivantes.

### Si vous vous souvenez du code d’accès de votre appareil précédent

Si le code d’accès de votre appareil actuel est différent de celui de votre appareil précédent, saisissez le code d’accès de votre appareil actuel, puis le code d’accès de votre appareil précédent.

### Si vous vous souvenez du code d’accès d’un autre appareil précédent

Si vous ne vous souvenez pas du code d’accès de votre appareil précédent, vous pouvez utiliser un code d’accès d’un autre appareil précédent en suivant ces étapes :

- Saisissez le code d’accès de votre appareil actuel.

- Touchez « Vous ne connaissez pas le code de l’[appareil] ? ».

- Choisissez un appareil dans la liste.

- Saisissez le code d’accès de cet appareil.

### Si vous ne vous souvenez d’aucun de vos codes d’accès précédents

Si vous ne parvenez toujours pas à vous souvenir de vos codes d’accès, vous devrez supprimer vos données chiffrées de bout en bout stockées dans iCloud pour continuer à utiliser iCloud sur l’appareil. Les données qui seront effacées comprennent les mots de passe enregistrés, les signets et l’historique de Safari, Messages sur iCloud, l’historique de Plans et les Memoji, mais n’incluent pas iCloud Drive ni d’autres catégories de données. Apprenez-en plus sur la [sécurité des données iCloud](https://support.apple.com/102651) et [l’utilisation de comptes Apple gérés dans Apple School Manager](https://support.apple.com/guide/apple-school-manager/use-managed-apple-ids-axm78b477c81/1/web/1) .

Pour continuer à supprimer vos données iCloud, procédez comme suit :

- Saisissez le code d’accès de votre appareil actuel.

- Touchez « Vous ne connaissez pas le code de l’[appareil] ? ».

- Touchez « Vous avez oublié tous vos codes ? ».

- Touchez Plus d’options.

- Touchez Supprimer les données iCloud.

- Touchez Supprimer définitivement les données.
