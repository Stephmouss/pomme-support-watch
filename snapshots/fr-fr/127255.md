# macOS 27 Golden Gate est compatible avec ces ordinateurs

macOS 27 Golden Gate est la dernière version majeure du système d’exploitation pour Mac. Vous pouvez l’installer sur n’importe lequel de ces modèles de Mac.

Si vous possédez un Mac avec une puce Apple, vous pouvez [mettre à niveau vers macOS 27](https://support.apple.com/fr-fr/127455) . Si votre Mac n’est pas compatible, vous pourrez peut-être [installer une version antérieure de macOS](https://support.apple.com/fr-fr/102662) à la place.

[Identifier votre MacBook Pro](https://support.apple.com/fr-fr/108052)
