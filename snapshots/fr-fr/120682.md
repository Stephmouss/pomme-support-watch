# Masquer les éléments gênants des pages web dans Safari

Si une page web affiche régulièrement un ou plusieurs éléments que vous trouvez gênants, la fonctionnalité Contrôle des distractions peut vous permettre de les masquer. Vous pouvez ensuite choisir de les afficher à nouveau.

- [Masquer des éléments gênants dans Safari](https://support.apple.com/fr-fr/120682#hide)

- [Afficher les éléments masqués dans Safari](https://support.apple.com/fr-fr/120682#unhide)

- [Informations supplémentaires](https://support.apple.com/fr-fr/120682#learnmore)

## Masquer des éléments gênants dans Safari

Important : la fonctionnalité Contrôle des distractions fonctionne de manière optimale avec les éléments qui ne changent pas régulièrement. Lorsque vous utilisez Contrôle des distractions pour la première fois, un message d’alerte vous rappelle que cette fonctionnalité ne masque pas de façon permanente les publicités ou d’autres éléments qui se mettent à jour fréquemment.

### Sur un Mac

Requiert macOS Sequoia ou version ultérieure

- Dans le champ de recherche intelligente de Safari, cliquez sur le bouton Menu de la page , puis choisissez Masquer les éléments gênants.

[Image: null]

[Image: Menu de la page avec l’option Masquer les éléments gênants sélectionnée.]

- Lorsque vous déplacez le pointeur sur la page, Safari affiche une bordure autour de chaque élément que vous pouvez masquer.

- Cliquez sur un élément pour le masquer. Vous pouvez également cliquer sur d’autres éléments pour les masquer.

- Cliquez sur OK dans le champ de recherche intelligente pour confirmer les modifications. Vous pouvez également cliquer sur Annuler.

### Sur un iPhone ou un iPad

Requiert iOS 18 ou version ultérieure, ou iPadOS 18 ou version ultérieure

- Dans le champ de recherche intelligente de Safari, touchez le bouton Menu de la page , puis touchez Masquer les éléments gênants.

[Image: null]

- Touchez l’élément que vous souhaitez masquer. Safari affiche une bordure autour de l’élément sélectionné.

[Image: Page web dans laquelle un élément à masquer est sélectionné.]

- Touchez n’importe quelle zone de l’élément pour le masquer. Vous pouvez également toucher d’autres éléments pour les masquer.

- Touchez OK dans le champ de recherche intelligente pour confirmer les modifications. Vous pouvez également toucher Annuler .

[Image: null]

## Afficher les éléments masqués dans Safari

Lorsque vous consultez une page web qui contient des éléments masqués, un œil barré d’une ligne s’affiche à côté du bouton Menu de la page. Touchez ou cliquez sur le bouton Menu de la page, puis sélectionnez Afficher les éléments masqués. Si vous avez masqué plusieurs éléments sur la page, un message vous demande de confirmer votre choix avant que les éléments s’affichent à nouveau.

[Image: null]

## Informations supplémentaires

- Si les éléments sont réutilisés de la même manière sur d’autres pages du même site web, ils sont également masqués sur ces pages. Les éléments masqués dans un profil Safari le sont également dans les autres profils Safari sur le même appareil. Les éléments masqués dans une [fenêtre de navigation privée](https://support.apple.com/guide/safari/browse-privately-ibrw1069/mac) ne le sont que dans celle-ci et ne restent pas masqués après avoir fermé Safari.

- Si vous avez installé une [extension Safari](https://support.apple.com/fr-fr/102343) pour bloquer du contenu sur Mac, le contrôle des distractions peut offrir de meilleurs résultats lorsque le réglage Bloqueurs de contenu est activé pour le site web. Dans la barre des menus de Safari, choisissez Safari > Réglages, cliquez sur l’onglet Sites web, puis cliquez sur Bloqueurs de contenu dans la barre latérale. Recherchez le site web à droite et vérifiez que le réglage est activé.

- Si vous utilisez l’option [Effacer l’historique](https://support.apple.com/guide/safari/clear-your-browsing-history-sfri47acf5d6/mac) sur votre Mac ou l’option [Effacer historique, données de site](https://support.apple.com/fr-fr/105082) sur votre iPhone ou iPad à partir du profil Safari par défaut, vous effacez également la liste de tous les éléments masqués sur cet appareil.

- [Découvrez comment bloquer les fenêtres publicitaires et les fenêtres pop-up dans Safari](https://support.apple.com/fr-fr/102524) .

- Pour lire des articles en éliminant les sources de distraction, utilisez le [lecteur sur Mac](https://support.apple.com/guide/safari/hide-ads-when-reading-sfri32632/mac) , le [lecteur sur iPhone](https://support.apple.com/guide/iphone/hide-ads-and-distractions-iphdc30e3b86/ios) ou le [lecteur sur iPad](https://support.apple.com/guide/ipad/hide-ads-and-distractions-ipad0669fc3c/ipados) .
