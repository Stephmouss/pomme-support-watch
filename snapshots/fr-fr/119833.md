# Télécharger l’app Beats lorsque vous ne pouvez pas utiliser Google Play

Si vous n’avez pas accès au Google Play Store, vous pouvez télécharger l’app Beats directement.

Suivez ces étapes sur votre appareil Android :

- [Téléchargez le programme d’installation de l’app Beats pour Android](https://tempo.api.beatsbydre.com/v3/mobile_apps/android/download) .

- À l’aide du navigateur de fichiers de votre appareil 2 recherchez le programme d’installation de l’app Beats pour Android, dont le nom de fichier se termine par .apk. Sur de nombreux appareils, vous trouverez ce fichier .apk dans un dossier de téléchargements.

- Touchez le fichier pour l’installer.

- Si une alerte vous invite à modifier vos réglages de sécurité pour vous permettre de procéder à une installation à partir de sources inconnues, suivez les étapes à l’écran. Après avoir modifié vos réglages, vous devrez peut-être toucher un bouton de retour pour revenir au navigateur de fichiers. Ensuite, vous pourrez installer le fichier .apk.

Vous pouvez désormais [utiliser l’app Beats pour Android](https://support.apple.com/HT210322) .

- En Chine continentale, vous pouvez également télécharger l’app Beats pour Android à partir de [Huawei AppGallery](https://appgallery.huawei.com/app/C107398457) ou [Tencent App Store](https://sj.qq.com/appdetail/com.apple.bnd) .

- Si vous n’avez pas d’explorateur de système de fichiers, recherchez-en un sur une plateforme de téléchargement d’apps Android.
