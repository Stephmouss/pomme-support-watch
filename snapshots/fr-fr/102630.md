# Gérer l’accès à vos données iCloud sur le Web

Pour davantage de contrôle sur vos données personnelles, vous pouvez choisir de désactiver l’accès à vos données iCloud sur le Web sous iOS 16.2, iPadOS 16.2 et macOS 13.1 ou version ultérieure.

Vous pouvez accéder aux données que vous stockez dans iCloud sur le Web à l’adresse [iCloud.com](https://icloud.com/) . Pour davantage de sécurité et de contrôle sur vos données personnelles, vous pouvez choisir de désactiver l’accès à vos données iCloud sur le Web. Celles-ci seront alors disponibles uniquement sur vos appareils de confiance.

Lorsque l’accès web est désactivé, vos données iCloud qui sont généralement disponibles en ligne sur le site iCloud.com, telles que vos e-mails, contacts, calendriers, photos, notes, rappels, fichiers et documents, sont uniquement accessibles sur votre appareil de confiance. Vous pouvez toujours trouver vos appareils sur iCloud.com/find.

Si vous activez l’option [Protection avancée des données pour iCloud](https://support.apple.com/fr-fr/108756) , l’accès aux données depuis iCloud.com est automatiquement désactivé. Toutefois, vous pouvez choisir de réactiver l’accès web et [d’autoriser un accès temporaire à vos données à l’aide de vos appareils de confiance](https://support.apple.com/fr-fr/102630#advanced) .

Sous iOS, iPadOS et macOS 26.4 ou version ultérieure, si vous choisissez d’activer l’accès web, vous pouvez également [activer l’option Autoriser la recherche](https://support.apple.com/fr-fr/126463) . Cela permet à vos appareils Apple de confiance de fournir des résultats de recherche pour iCloud Drive et Photos iCloud lorsque vous utilisez iCloud.com.

## Gérer l’accès à vos données iCloud sur le Web

Vous pouvez gérer l’accès à vos données sur iCloud.com dans les réglages iCloud sous iOS 16.2 ou version ultérieure, iPadOS 16.2 ou version ultérieure, ou macOS 13.1 ou version ultérieure.

### Sous iOS ou iPadOS 26.4 (ou version ultérieure)

- Ouvrez l’app Réglages.

- Touchez votre nom, puis iCloud.

- Touchez iCloud.com.

- Touchez Autoriser l’accès aux données et Autoriser la recherche pour désactiver ou activer ces options.

### Dans les versions antérieures d’iOS ou d’iPadOS

- Ouvrez l’app Réglages.

- Touchez votre nom, puis iCloud.

- Touchez Accéder aux données iCloud sur le Web pour activer ou désactiver l’option.

### Sous macOS 26.4 ou version ultérieure

- Dans le menu Pomme , choisissez Réglages Système.

- Cliquez sur votre nom, puis sur iCloud.

- Cliquez sur Accès aux données sur iCloud.com.

- Cliquez sur Autoriser l’accès aux données et Autoriser la recherche pour désactiver ou activer ces options.

### Dans les versions antérieures de macOS

- Dans le menu Pomme , choisissez Réglages Système.

- Cliquez sur votre nom, puis sur iCloud.

- Cliquez sur Accéder aux données iCloud sur le Web pour activer ou désactiver l’option.

Lorsque vous désactivez l’accès aux données iCloud sur le Web et que vous vous connectez ensuite à iCloud.com, un message d’alerte s’affiche. Ce message d’alerte confirme que l’accès web aux données iCloud est désactivé et que vous ne pouvez plus accéder à vos données. Pour réactiver l’accès web, cliquez sur le lien « Gérer sur un appareil » qui s’affiche sur iCloud.com. Suivez ensuite les instructions qui apparaissent sur l’un de vos appareils de confiance.

## Accès web et protection avancée des données pour iCloud

Si vous activez l’option [Protection avancée des données pour iCloud](https://support.apple.com/fr-fr/108756) , l’accès web à vos données iCloud sur iCloud.com est automatiquement désactivé. Cela garantit que vos données ne sont disponibles que sur vos appareils de confiance. Pour accéder à vos données iCloud sur le Web, procédez comme suit :

- Dans les réglages iCloud, activez l’option Autoriser l’accès aux données ou Accéder aux données iCloud sur le Web.

- Connectez-vous sur [iCloud.com](https://icloud.com/) .

- À partir de votre appareil de confiance, autorisez l’accès temporaire à vos données.

Une fois l’accès autorisé à partir de votre appareil de confiance, vous pouvez accéder à vos données sur iCloud.com. Pendant l’heure qui suit, votre appareil génère une approbation chaque fois que vous accédez à une nouvelle catégorie de données, telles que des photos, des notes ou des fichiers. Lorsque votre appareil donne accès à une nouvelle catégorie, vous recevez une notification.

Après une heure, vous devrez à nouveau donner votre approbation depuis votre appareil de confiance pour accéder à une nouvelle catégorie de données. Une fois que vous accédez à une catégorie de données, vous pouvez y accéder jusqu’à ce que vous vous déconnectiez d’iCloud.com ou fermiez la session de navigation.

Certaines données ne sont pas disponibles sur iCloud.com, telles que les données de l’app Santé et les mots de passe du trousseau iCloud.

## Accès web et privacy.apple.com

La désactivation de l’accès web aux données iCloud restreint également les données que vous pouvez récupérer en utilisant les [outils de gestion des données et de la confidentialité d’Apple](https://support.apple.com/fr-fr/102283) sur la [page Données et confidentialité d’Apple](https://privacy.apple.com/) . Vos données iCloud, notamment vos e-mails, contacts, calendriers, photos, notes, rappels, fichiers et documents, n’apparaîtront pas dans la liste de vos données disponibles. Pour accéder à ces données, vous devez réactiver l’accès web.

De plus, si vous avez activé la protection avancée des données pour iCloud, Apple n’est pas en mesure d’accéder aux données iCloud protégées par un chiffrement de bout en bout ni d’en fournir des copies, que vous ayez ou non autorisé l’accès web. [Découvrez quelles catégories de données sont protégées par le chiffrement de bout en bout](https://support.apple.com/fr-fr/102651) .

Certaines données personnelles stockées par Apple et associées à votre compte Apple restent accessibles sur la page privacy.apple.com, indépendamment de vos réglages d’accès web ou de protection des données. Cela inclut les informations de votre compte, l’historique de vos transactions et votre historique d’assistance.
