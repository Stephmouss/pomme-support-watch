# Obtenir un code de récupération pour un proche en tant que contact de récupération pour son compte Apple

En tant que contact de récupération, vous pouvez aider un proche à accéder à nouveau à son compte si celui-ci vient à être verrouillé.

## Avant d’aider un proche en tant que contact de récupération

- Mettez à jour votre iPhone, iPad ou Mac vers la dernière version de son logiciel. Vous avez besoin d’un appareil Apple exécutant iOS 15, iPadOS 15 ou macOS Monterey 12 ou version ultérieure.

- La personne concernée doit avoir déjà [commencé le processus de récupération de compte](https://support.apple.com/fr-fr/118574) .

- Si cela vous est demandé, [activez l’identification à deux facteurs](https://support.apple.com/fr-fr/102660) pour votre compte Apple.

- Si cela vous est demandé, [configurez un code d’accès sur votre iPhone ou iPad](https://support.apple.com/fr-fr/119586) .

Pour que vous puissiez intervenir en tant que contact de récupération, [un proche doit d’abord vous inviter](https://support.apple.com/fr-fr/102641) .

## Aider un proche à récupérer l’accès à son compte

Si l’un de vos proches n’a plus accès à son compte, il doit d’abord confirmer certaines informations liées à son compte Apple sur son appareil. Il doit ensuite vous contacter par téléphone ou en personne. Vous pouvez utiliser votre appareil pour générer un code de récupération à six chiffres que cette personne pourra saisir sur son appareil.

Communiquez-lui le code directement. Ne le transmettez pas à une tierce personne qui vous en ferait la demande pour elle.

### Sur votre iPhone ou iPad

- Accédez à Réglages, puis touchez [votre nom].

- Touchez Connexion et sécurité, puis Contacts de récupération.

- Faites défiler l’écran jusqu’à Récupération du compte pour, puis touchez le nom de votre contact.

- Touchez Obtenir un code de récupération.

[Image: Sur iPhone, obtenir un code de récupération pour aider un ami ou un membre de la famille à retrouver l'accès à son compte.]

- Lorsque la personne concernée est prête, communiquez-lui son code de récupération. Après avoir saisi le code sur son appareil, elle peut réinitialiser son mot de passe et recouvrer l’accès à son compte.

### Sur votre Mac

- Dans le menu Pomme , choisissez Réglages Système, puis cliquez sur [votre nom].

- Cliquez sur Connexion et sécurité, puis sur Contacts de récupération.

- Faites défiler l’écran jusqu’à Récupération du compte pour, puis cliquez sur le nom de votre contact.

- Cliquez sur Obtenir un code de récupération.

[Image: Un Mac affichant la fenêtre Réglages Système, avec le bouton Obtenir un code de récupération.]

- Lorsque la personne concernée est prête, communiquez-lui son code de récupération. Après avoir saisi le code sur son appareil, elle peut réinitialiser son mot de passe et recouvrer l’accès à son compte.
