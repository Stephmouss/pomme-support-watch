# Modification de la tonalité d’une région audio dans Logic Pro pour Mac

Vous pouvez transposer la tonalité d’une région audio en demi-tons et la régler précisément en cents.

Vous pouvez transposer ou régler précisément la tonalité de régions audio dans les pistes que vous avez déjà enregistrées afin qu’elle corresponde à la tonalité des instruments du projet. Par exemple, si vous avez changé la tonalité d’un projet, certaines de vos pistes vocales existantes risquent d’être discordantes.

- Sélectionnez une région dans la zone Pistes.

- Cliquez sur le bouton Inspecteur dans la barre des commandes ou appuyez sur la touche I de votre clavier.

- Dans l’inspecteur, si nécessaire, cliquez sur l’icône du triangle d’expansion à côté de Région pour afficher les paramètres de la région. Vous pouvez aussi appuyer sur les touches Option + R pour ouvrir l’inspecteur Région dans une fenêtre distincte.

- Pour transposer ou régler précisément la tonalité d’une région audio, procédez comme suit :

- Pour appliquer une valeur prédéfinie, cliquez sur le menu local Transposer ou Réglage précis, puis sélectionnez une valeur.

[Image: Sélection d’une valeur prédéfinie du menu local Transposer dans l’inspecteur de région.]

- Pour définir une valeur personnalisée, cliquez sur celle-ci et faites-la glisser dans le champ Transposer ou Réglage précis.

La région audio dans la zone Pistes et l’éditeur de pistes audio indique le nombre de demi-tons que vous transposez. Si vous changez la tonalité d’une région pendant sa lecture, vous entendrez immédiatement les changements.
