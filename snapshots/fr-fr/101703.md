# Si un droplet créé dans Compressor 4.2 ne s’ouvre pas dans une version antérieure

Pour utiliser un droplet Compressor 4.2 dans une version antérieure de l’app, recréez-le à l’aide de Compressor 4.1.3 ou d’une version antérieure.

Pour en savoir plus, consultez l’article [Création et usage de droplets](https://help.apple.com/compressor/mac/4.1/#/cpsr8747db7f) dans l’aide de Compressor 4.1.3.
