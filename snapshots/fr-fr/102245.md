# Utiliser S/MIME pour envoyer et recevoir des messages chiffrés dans l’app Mail sous iOS

iOS prend en charge S/MIME afin que vous puissiez envoyer des messages électroniques chiffrés.

Pour envoyer des messages chiffrés, installez un certificat S/MIME pour votre compte de messagerie. Vous pouvez obtenir des certificats S/MIME auprès d’une autorité de certification (AC) ou, si vous utilisez un compte Exchange, auprès de votre organisation. Vous avez également besoin du certificat du destinataire (clé publique).

## Activer le chiffrement des messages

Lors de la configuration des réglages S/MIME pour votre compte, vous pouvez activer une option permettant le chiffrement par défaut des nouveaux messages que vous rédigez :

- Ouvrez l’app Réglages.

- Choisissez Mail > Comptes.

- Sélectionnez le compte qui contient les messages que vous souhaitez chiffrer par défaut.

- Choisissez Compte > Avancé > Chiffrer par défaut, puis activez Chiffrer par défaut.

Lorsque vous transférez ou répondez à un message, l’état de chiffrement de votre message correspond à l’état du message entrant plutôt qu’au réglage par défaut du système. Vous pouvez également utiliser le bouton Verrouiller bleu dans le champ d’adresse pour modifier l’état de chiffrement d’un message sortant.

## Envoyer des messages chiffrés

Si le destinataire de votre message se trouve dans le même environnement Exchange que vous, iOS peut accéder directement au certificat requis pour le chiffrement du message. iOS récupère les certificats sur la GAL. Vous verrez le bouton Verrouiller dans le champ d’adresse lorsque vous composerez un message, et votre destinataire pourra le déchiffrer. Si vous n’utilisez pas de compte Exchange, ou si votre destinataire ne se trouve pas dans la même organisation, vous devez envoyer et recevoir des e-mails signés avant d’envoyer un message chiffré.

## Faire confiance à la signature manuelle d’un destinataire

Si la signature du destinataire prévu n’est pas fiable, suivez ces étapes pour installer le certificat du destinataire sur l’appareil :

- Dans un message signé de votre destinataire prévu, touchez l’adresse de l’expéditeur. Les signatures non fiables ont un point d’interrogation à droite de l’adresse de l’expéditeur. Mail indique les signatures valides avec une coche bleue à droite de l’adresse de l’expéditeur.

[Image: rouge]

- Si le certificat de l’expéditeur a été émis par une autorité non reconnue, vous pouvez installer manuellement le certificat pour cette adresse e-mail. Touchez Afficher le certificat.

- Pour installer et faire confiance au certificat de signature de l’expéditeur, touchez Installer.

- Le bouton Installer devient rouge et affiche Supprimer. Appuyez sur Terminé en haut à droite pour terminer le processus d’installation du certificat.

- iOS associe ce certificat numérique à l’adresse e-mail du destinataire, ce qui permet le chiffrement des messages.
