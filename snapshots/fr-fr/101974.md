# Protéger ou migrer des données pour Apple Configurator

Découvrez comment sauvegarder et restaurer des données à partir d’Apple Configurator.

Vous aurez peut-être besoin de réinstaller macOS sur votre poste de travail Apple Configurator ou de procéder à une migration vers un nouveau poste de travail. Procédez comme suit pour vous assurer de pouvoir continuer de superviser les mêmes appareils iOS.

## Sauvegarder vos données

Avant de réinstaller macOS ou de passer à un nouveau poste de travail, sauvegardez vos données Apple Configurator :

- Sur votre poste de travail, ouvrez Apple Configurator.

- Depuis le menu d’Apple Configurator , sélectionnez Préférences.

- Cliquez sur Organisations.

- Sélectionnez votre organisation, cliquez sur le bouton en forme d’engrenage , puis choisissez Exporter l’organisation.

[Image: icône en forme d’engrenage]

- Saisissez un mot de passe pour sécuriser le fichier de l’organisation.

- Saisissez un nom de fichier et un emplacement pour l’enregistrer, puis cliquez sur Enregistrer.

Conservez le fichier de votre organisation dans un emplacement sûr, jusqu’à ce que vous puissiez [restaurer vos données](https://support.apple.com/fr-fr/101974#restore) .

## Restaurer vos données

Lorsque vous réinstallez macOS ou que vous configurez un nouveau poste de travail, procédez comme suit pour importer les données de l’organisation :

- Sur votre poste de travail, ouvrez Apple Configurator.

- Depuis le menu d’Apple Configurator , sélectionnez Préférences.

- Cliquez sur Organisations.

- Sélectionnez votre organisation, cliquez sur le bouton en forme d’engrenage , puis choisissez Importer l’organisation.

[Image: icône en forme d’engrenage]

- Sélectionnez le fichier de l’organisation que vous avez enregistré, puis cliquez sur Importer.

- Saisissez le mot de passe que vous avez utilisé pour sécuriser le fichier, puis cliquez sur Envoyer.

Vous pouvez désormais continuer de superviser les appareils qui étaient configurés sur votre poste de travail d’origine.
