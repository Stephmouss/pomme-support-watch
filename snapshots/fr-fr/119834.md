# Ajouter des numéros de page et du texte aux en-têtes et aux pieds de page dans Pages sur Mac, iPhone ou iPad

Ajoutez des numéros de page et du texte aux en-têtes et aux pieds de page, puis définissez l’emplacement où vous souhaitez qu’ils apparaissent dans votre document.

## Ajouter des numéros de page et du texte aux en-têtes et aux pieds de page sur Mac

- Cliquez sur Document dans la barre d’outils. Dans un document de traitement de texte, vous devez également cliquer sur l’onglet Document.

- Pour activer les en-têtes ou les pieds de page, cochez les cases En-tête ou Pied de page.

- Déplacez le pointeur sur le haut ou le bas de la page jusqu’à ce que les trois champs d’en-tête ou de pied de page s’affichent, puis cliquez sur l’un d’entre eux.

- Si vous travaillez sur un document de traitement de texte et que vous ne voyez pas les champs, cliquez sur l’onglet Section en haut de la barre latérale du document et assurez-vous que l’option « Masquer sur la 1re page de la section » n’est pas sélectionnée.

- Pour ajouter des numéros de page, cliquez sur Insérer nº de page et choisissez un style de numérotation.

- Si vous ne voyez pas le menu local, cliquez sur Insérer dans la barre d’outils, puis choisissez Numéro de page.

- Pour ajouter du texte, cliquez dans l’un des champs d’en-tête ou de pied de page et commencez à saisir du texte.

- Pour modifier l’apparence du texte ou des numéros de page, sélectionnez le numéro de page dans l’en-tête ou le pied de page, cliquez sur le bouton Format de la barre d’outils, puis [formatez votre texte](https://support.apple.com/HT212947#iOS_iPadOS) .

- Pour modifier la distance séparant les en-têtes ou les pieds de page du bord supérieur ou inférieur de la page, cliquez sur les flèches ou saisissez des valeurs dans les zones situées sous les cases En-tête ou Pied de page de l’onglet Document de la barre latérale.

- Pour supprimer un en-tête ou un pied de page, désélectionnez la case En-tête ou Pied de page dans l’onglet Document de la barre latérale. Cette opération supprime le contenu de tous les en-têtes ou pieds de page de votre document.

Lorsque vous ajoutez des numéros de page, ils s’incrémentent automatiquement à mesure que vous ajoutez des pages. Dans les documents de traitement de texte comportant plusieurs sections, vous pouvez modifier les numéros de départ de chaque section. Dans les documents de mise en page, vous pouvez définir un numéro de départ différent pour une page. Vous pouvez également ajouter des numéros de page en dehors des en-têtes et des pieds de page. [En savoir plus sur l’ajout de numéros de page dans Pages sur Mac](https://support.apple.com/guide/pages/tan5387422b5/mac) .

## Ajouter des numéros de page et du texte aux en-têtes et aux pieds de page sur iPhone ou iPad

Pour utiliser les en-têtes et les pieds de page dans votre document, vous devez d’abord les activer. Vous pouvez ensuite ajouter les numéros de page, le texte et les images. Vous pouvez également définir l’emplacement où vous souhaitez que les en-têtes et les pieds de page apparaissent dans votre document Pages.

### Activer les en-têtes ou les pieds de page

Pour utiliser les en-têtes et les pieds de page dans votre document, vous devez d’abord les activer.

- Ouvrez votre document dans Pages.

- Sur l’iPhone, touchez le bouton Plus . Sur l’iPad, touchez le nom du document ou le bouton Plus en fonction de ce que vous voyez dans la barre d’outils.

[Image: Aucun texte de remplacement pour l’image]

- Touchez Options du document, puis Configuration du document.

- Activez les en-têtes ou les pieds de page.

- Pour supprimer un en-tête ou un pied de page, désactivez les en-têtes ou les pieds de page. Cette opération supprime le contenu des en-têtes ou des pieds de page de votre document.

### Ajouter des numéros de page à votre document

- Ouvrez votre document dans Pages.

- Activez les en-têtes ou les pieds de page.

- Sur l’iPhone, touchez le bouton Plus . Sur l’iPad, touchez le nom du document ou le bouton Plus en fonction de ce que vous voyez dans la barre d’outils.

[Image: Aucun texte de remplacement pour l’image]

- Touchez Options du document, puis Configuration du document.

- Touchez Plus d’options en bas des commandes.

- Touchez l’un des trois champs de l’en-tête ou du pied de page. Vous pouvez utiliser n’importe quelle combinaison de champs.

- Si vous travaillez sur un document de traitement de texte et que vous ne voyez pas les champs :

- Touchez le nom du document dans la barre d’outils. Si vous ne voyez pas le nom du document, touchez le bouton Plus.

- Touchez Options du document, puis Configuration du document.

- Touchez Section et assurez-vous que l’option Masquer sur la 1re page de la section est désactivée.

- Touchez Numéros de page, puis touchez une option de numérotation des pages.

- Pour modifier l’apparence des numéros de page, sélectionnez le numéro de page dans l’en-tête ou le pied de page, touchez le bouton Format , puis [formatez votre texte](https://support.apple.com/HT212947#iOS_iPadOS) .

[Image: Aucun texte de remplacement pour l’image]

Les numéros de page s’incrémentent automatiquement à mesure que vous ajoutez des pages. Dans les documents de traitement de texte comportant plusieurs sections, vous pouvez modifier les numéros de départ de chaque section. Dans les documents de mise en page, vous pouvez définir un numéro de départ différent pour une page. [En savoir plus sur l’ajout de numéros de page à votre document](https://support.apple.com/guide/pages-ipad/tan5387422b5/ipados) .

### Ajouter du texte et des images aux en-têtes et aux pieds de page

- Ouvrez votre document dans Pages.

- Sur l’iPhone, touchez le bouton Plus . Sur l’iPad, touchez le nom du document ou le bouton Plus en fonction de ce que vous voyez dans la barre d’outils.

[Image: Aucun texte de remplacement pour l’image]

- Touchez Options du document, puis Configuration du document.

- Touchez Plus d’options en bas des commandes.

- Touchez l’un des trois champs de l’en-tête ou du pied de page (vous pouvez utiliser n’importe quelle combinaison de champs).

- Pour ajouter ou modifier du texte dans les en-têtes ou les pieds de page, saisissez le texte de l’en-tête ou du pied de page, ou sélectionnez le texte que vous souhaitez modifier.

- Pour modifier l’aspect du texte, sélectionnez le texte, touchez le bouton Format , puis [formatez votre texte](https://support.apple.com/HT212947#iOS_iPadOS) .

[Image: Aucun texte de remplacement pour l’image]

### Définir l’emplacement des en-têtes et des pieds de page

- Ouvrez votre document dans Pages.

- Sur l’iPhone, touchez le bouton Plus . Sur l’iPad, touchez le nom du document ou le bouton Plus en fonction de ce que vous voyez dans la barre d’outils.

[Image: Aucun texte de remplacement pour l’image]

- Touchez Options du document, puis Configuration du document.

- Touchez Plus d’options.

- Pour définir la distance depuis le bord supérieur et le bord inférieur de la page, faites glisser les flèches au-dessus de l’en-tête et en dessous du pied de page.

La largeur des en-têtes et des pieds de page dépend des marges de gauche et de droite. Quand vous [définissez les marges des pages](https://support.apple.com/guide/pages-ipad/tanf2202113e/ipados) , vous définissez également la largeur des en-têtes et des pieds de page.
