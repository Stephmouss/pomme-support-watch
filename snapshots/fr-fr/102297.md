# Modifier le taux de rafraîchissement sur votre MacBook Pro ou votre écran Apple

Vous pouvez changer le taux de rafraîchissement sur votre MacBook Pro (16 pouces), votre MacBook Pro (14 pouces), votre écran Studio Display XDR ou Pro Display XDR.

Pour les tâches professionnelles comme le montage vidéo, vous pouvez définir le taux de rafraîchissement de votre écran afin qu’il corresponde à la fréquence d’images de la vidéo que vous éditez ou visionnez.

## Taux de rafraîchissement disponibles

En fonction de votre appareil, vous pouvez basculer entre ces taux de rafraîchissement sur votre écran Retina :

- 120 hertz

- 60 hertz

- 59,94 hertz

- 50 hertz

- 48 hertz

- 47,95 hertz

Vous pouvez utiliser un taux de rafraîchissement adaptatif jusqu’à 120 Hz sur certains appareils. Sur les modèles de MacBook Pro 14 pouces et 16 pouces équipés de la puce Apple, sélectionnez ProMotion. Sur les écrans Studio Display XDR, sélectionnez Adaptive (47-120 Hertz).

## Modifier le taux de rafraîchissement

Sélectionnez un taux de rafraîchissement qui correspond à la fréquence d’images de votre contenu. Par exemple, si le contenu affiché est de 24 images par seconde, sélectionnez le taux de rafraîchissement de 48 hertz.

- Dans le menu Pomme , choisissez Réglages Système (ou Préférences Système), puis cliquez sur Moniteurs.

- Cliquez sur le menu local Taux de rafraîchissement et choisissez un taux de rafraîchissement.

[Image: macos-ventura-system-settings-displays-refresh-rate]

Lorsque vous aurez terminé de visionner ou d’éditer le contenu vidéo, vous voudrez peut-être rétablir le taux de rafraîchissement par défaut de votre écran.

Sous macOS Catalina et macOS Big Sur, appuyez sur la touche Option et maintenez-la enfoncée pendant que vous sélectionnez le bouton À l’échelle pour afficher le menu de taux de rafraîchissement.
