# Utilisation de la technologie True Tone sur Mac

La technologie True Tone dont sont dotés le Mac avec écran Retina, l’Apple Studio Display, le Studio Display XDR et le Pro Display XDR exploite des capteurs multicanaux avancés pour ajuster la couleur et l’intensité de l’écran et de la Touch Bar en fonction de la lumière ambiante, ce qui confère un aspect plus naturel aux images.

## Activer True Tone

[Identifiez la version de macOS installée sur votre Mac](https://support.apple.com/fr-fr/109033) , puis suivez les étapes correspondantes.

### macOS Ventura 13 ou version ultérieure

- Dans le menu Apple, choisissez Réglages Système.

- Cliquez sur Moniteurs dans la barre latérale, puis sélectionnez votre écran en haut de la fenêtre.

- Activez True Tone dans les réglages qui s’affichent pour l’écran sélectionné. Ce réglage n’apparaît que pour les écrans compatibles avec la technologie True Tone.

### Versions antérieures de macOS

- Dans le menu Apple , choisissez Préférences Système.

- Cliquez sur Moniteurs. Si plusieurs écrans sont connectés, cliquez sur Réglages d’affichage et sélectionnez celui que vous souhaitez configurer.

- Activez True Tone dans les réglages qui s’affichent pour l’écran sélectionné. Ce réglage n’apparaît que pour les écrans compatibles avec la technologie True Tone.

## Technologie True Tone sur les écrans externes

L’Apple Studio Display, le Studio Display XDR et le Pro Display XDR utilisent des capteurs de lumière ambiante intégrés pour prendre en charge la technologie True Tone lorsque l’écran est connecté à un ordinateur Mac compatible.

La technologie True Tone permet également d’ajuster les images sur des écrans externes d’une taille maximale de 32 pouces (à l’exception des téléviseurs et des projecteurs) lorsqu’ils sont connectés à un ordinateur portable Mac dont le couvercle est ouvert ou à un iMac commercialisé à partir de 2020.

## Informations supplémentaires

- Certains réglages d’accessibilité de l’écran, notamment les réglages d’inversion du mode couleur, d’application d’un filtre en niveaux de gris ou d’augmentation du contraste, peuvent entraîner la désactivation de True Tone.

- Vous pouvez utiliser les technologies True Tone et [Night Shift](https://support.apple.com/fr-fr/102191) en même temps.
