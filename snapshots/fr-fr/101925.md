# À propos de MainStage

Découvrez MainStage.

### Où puis-je acheter et télécharger MainStage ?

[Achetez et téléchargez MainStage depuis le Mac App Store](https://apps.apple.com/fr/app/mainstage/id634159523?mt=12) .

### Quelle est la configuration système requise pour utiliser MainStage ?

La configuration minimale requise pour MainStage est la même que pour Logic Pro. [Vérifiez les caractéristiques techniques de Logic Pro](https://support.apple.com/kb/SP681?locale=fr_FR) .

### Quelles sont les nouveautés de MainStage ?

[Consultez les notes de version de MainStage pour en savoir plus](https://support.apple.com/fr-fr/HT200269) .

### Une version d’essai de MainStage est-elle disponible ?

Il n’existe pas de version d’essai de MainStage.

### Sur combien d’ordinateurs puis-je installer MainStage ?

Consultez les [conditions générales des services multimédias Apple](http://www.apple.com/legal/internet-services/itunes/fr/terms.html#APPS) pour en savoir plus.

### Comment acheter une licence en volume pour MainStage ?

Trouvez le numéro de téléphone approprié pour votre organisation à l’adresse [https://www.apple.com/fr/contact/](https://www.apple.com/fr/contact/) .

### Quelle documentation est disponible pour MainStage ?

[Accédez au guide d’utilisation de MainStage en ligne](https://support.apple.com/fr-fr/guide/mainstage/welcome/mac) .

### Quelles interfaces audio non conçues par Apple peuvent être utilisées avec MainStage ?

MainStage fonctionne avec toutes les interfaces audio compatibles avec votre version de macOS. Si l’installation d’un gestionnaire est nécessaire, assurez-vous qu’un tel gestionnaire est inclus avec l’appareil ou est proposé par le fabricant ; dans les deux cas, il doit être à jour.
