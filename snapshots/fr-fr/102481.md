# En cas de perte ou de vol de votre ordinateur Mac

Si vous avez configuré la fonctionnalité Localiser mon Mac avant la disparition de votre Mac, vous pouvez l’utiliser pour localiser et protéger votre appareil. Dans le cas contraire, vous pouvez quand même prendre des mesures pour protéger vos informations.

## Si vous avez configuré la fonctionnalité Localiser sur votre Mac égaré

- Sur un autre appareil Apple, ouvrez l’app Localiser. Ou sur le Web, connectez-vous à [icloud.com/find](https://icloud.com/find) .

- Sélectionnez l’onglet Appareils ou cliquez sur Tous les appareils.

- Sélectionnez votre Mac pour afficher son emplacement approximatif sur une carte. Si votre Mac n’est pas répertorié, [découvrez comment vous pouvez toujours protéger votre compte](https://support.apple.com/fr-fr/102481#nofindmy) .

- Si votre Mac se trouve à proximité, touchez ou cliquez sur Émettre un son pour vous aider, vous ou quelqu’un à proximité, à le trouver.

[Image: Un iPhone avec l’app Localiser ouverte et affichant l’emplacement d’un MacBook Air. L’option Émettre un son est sélectionnée. Le bouton est violet et indique « Émission d’un son… ».]

- Pour empêcher tout accès non autorisé, [touchez Mode Perdu dans l’app Localiser](https://support.apple.com/fr-fr/104978) ou [sélectionnez Mac égaré sur icloud.com](https://support.apple.com/guide/icloud/mmfc0f0165/) .* Si vous verrouillez un Mac avec puce Apple, il est verrouillé avec le mot de passe de votre compte Apple. Si vous possédez un Mac à processeur Intel sans puce T2 Security, vous pouvez le verrouiller à distance à l’aide d’un code d’accès.

- Signalez la perte ou le vol de votre Mac aux autorités locales. Il se peut que vous deviez leur indiquer le numéro de série de votre Mac. [Trouvez le numéro de série de votre appareil.](https://support.apple.com/fr-fr/102858)

- Si vous ne pensez pas pouvoir récupérer votre Mac égaré, vous pouvez [l’effacer à distance.](https://support.apple.com/fr-fr/104978) * Cette opération supprime toutes les données de votre Mac et empêche quiconque d’accéder à ces informations. Après avoir effacé votre Mac, vous ne pourrez plus le retrouver à l’aide de la fonctionnalité Localiser.

[Image: Un iPhone affichant l’écran Effacer le Mac pour un MacBook Air. Il affiche une image de ce modèle de Mac, le nom du Mac et le compte Apple qui lui est associé.]

- Supprimez votre Mac perdu ou volé de votre liste d’appareils de confiance.

* Pour que vous puissiez verrouiller ou effacer votre Mac, celui-ci doit être allumé et connecté à Internet. Si le Mac n’est pas connecté à Internet, vous pourrez peut-être voir quand même son emplacement dans l’app Localiser.

## Si vous ne trouvez pas votre Mac ou si vous n’avez pas configuré la fonctionnalité Localiser

Localiser mon Mac est le seul service Apple permettant de rechercher et de localiser un ordinateur Mac perdu. Si cette fonctionnalité n’a pas été configurée sur votre Mac avant que celui-ci ne soit égaré, ou si vous ne parvenez pas à le localiser, les opérations suivantes peuvent vous aider à protéger vos données :

- [Modifiez le mot de passe de votre compte Apple](https://support.apple.com/fr-fr/101567) pour empêcher l’accès à vos données iCloud ou l’utilisation d’autres services comme iMessage à partir de votre Mac.

- Changez également les mots de passe des autres comptes auxquels vous accédez régulièrement sur votre Mac, tels que vos comptes de messagerie, de banque en ligne ou de réseaux sociaux, par exemple Facebook et Twitter.

- Signalez la perte ou le vol de votre Mac aux autorités locales. Il est possible que vous deviez fournir le numéro de série de votre ordinateur. Cette information figure sur l’emballage de votre ordinateur ou sur son reçu d’achat.

## Si vous ne parvenez pas à déverrouiller votre Mac

- Connectez-vous à [icloud.com/find](https://icloud.com/find) , puis sélectionnez votre Mac dans le menu Appareils. Sélectionnez Déverrouiller et suivez les étapes pour vérifier votre identité.

- Sur un Mac à processeur Intel sans puce T2 Security, saisissez le code que vous avez créé lorsque vous avez verrouillé votre appareil à l’aide de l’app Localiser.

- Apportez votre Mac à un [centre de services agréé Apple](https://locate.apple.com/fr/fr/) avec votre preuve d’achat.

Vous pouvez consulter votre code d’accès pendant une durée limitée.
