# Si vous ne recevez pas de notification de l’app Messages sur votre iPhone ou iPad

Si vous ne recevez pas les notifications de l’app Messages comme vous le souhaitez, vous devrez peut-être vérifier vos réglages ou un appareil jumelé, comme une Apple Watch.

## Avant de commencer

- Si [votre appareil est en silencieux](https://support.apple.com/guide/iphone/silence-iphone-iph81c7fd7d1/ios) , les notifications n’émettront aucun son. [Choisissez le son, la fréquence et l’apparence de vos notifications](https://support.apple.com/guide/iphone/change-notification-settings-iph7c3d96bab/ios) .

- Si l’app Messages est ouverte et active sur votre appareil, vous ne recevez pas de notification pour chaque nouveau message.

- Si vous possédez une Apple Watch, les notifications s’affichent soit sur votre Apple Watch, soit sur votre iPhone, mais pas sur les deux. [Choisissez où vos notifications doivent apparaître](https://support.apple.com/108274#watch) .

## Vérifier si les alertes d’une conversation de l’app Messages ont été masquées

- Dans Messages, touchez la conversation pour laquelle vous n’avez pas reçu de notifications.

- Touchez l’image ou l’icône en haut de la conversation.

- Désactivez Masquer les alertes.

Lorsque vous activez Masquer les alertes, l’icône Masquer les alertes apparaît à côté de la conversation. Les notifications sont interrompues uniquement pour cette conversation, pas pour tout ce qui se trouve sur votre iPhone. Vous continuez de recevoir tous les autres messages et voyez les notifications associées sur votre écran de verrouillage.

## Vérifier si une conversation de l’app Messages a été filtrée

Dans iOS 26, la fonctionnalité Filtrer les indésirables de Messages est activée par défaut. Lorsque vous [activez aussi la fonctionnalité Filtrer les expéditeurs inconnus](https://support.apple.com/guide/iphone/screen-filter-report-and-block-texts-iph203ab0be4/ios) , vous ne recevez pas de notification pour les messages provenant d’expéditeurs inconnus ni pour les messages identifiés comme indésirables. Ces messages apparaissent dans le filtre Expéditeurs inconnus ou dans le dossier Indésirables de l’app Messages.

Vous pouvez [déplacer des messages du dossier Indésirables vers votre liste de conversations](https://support.apple.com/124159) ou [afficher un message d’un expéditeur inconnu et le marquer comme connu](https://support.apple.com/125068) . Vous recevrez alors des notifications pour ces messages.

## Vérifier vos réglages concernant les notifications de Messages

- Dans Réglages, touchez Apps.

- Touchez Messages.

- Activez Autoriser les notifications, puis personnalisez l’apparence, le son et le comportement des notifications Messages.

## Toujours recevoir les notifications d’un contact spécifique

Si vous définissez un contact comme contact d’urgence, les sons et les vibrations des notifications associées à ce contact seront émis, même lorsque toutes les autres notifications ont été masquées :

- Ouvrez l’app Contacts.

- Sélectionnez le contact dont vous souhaitez toujours recevoir les notifications, puis touchez Modifier.

- Touchez Sonnerie ou Son SMS, puis activez Priorité en cas d’urgence.

## Choisir si les notifications apparaissent sur votre Apple Watch ou votre iPhone

Si vous possédez une Apple Watch, [les notifications s’affichent soit sur votre Apple Watch, soit sur votre iPhone,](https://support.apple.com/108369) mais pas sur les deux. Pour choisir l’emplacement d’affichage des notifications :

- Dans l’app Apple Watch de votre iPhone, touchez Ma montre.

- Touchez Notifications.

- Touchez une app afin d’accéder à ses options.

Afin d’utiliser les mêmes réglages de notification pour les apps installées à la fois sur votre Apple Watch et sur votre iPhone, touchez Comme mon iPhone.

D’autres apps vous permettent de personnaliser les notifications. Touchez Personnalisé, puis choisissez une option :

- Autoriser les notifications : les notifications s’affichent dans le centre de notifications, et votre Apple Watch vous envoie une alerte.

- Envoyer au centre de notifications : les notifications sont envoyées directement au centre de notifications sans que votre Apple Watch vous envoie une alerte.

- Notifications désactivées : l’app n’envoie aucune notification.

Si vous personnalisez les notifications d’une app, vous pouvez aussi grouper les notifications de cette app. Touchez Grouper les notifications, puis choisissez une option : Désactivé, Automatiquement ou Par app.

[En savoir plus sur la réception des notifications, de la façon dont vous le souhaitez, sur votre iPhone](https://support.apple.com/108274)
