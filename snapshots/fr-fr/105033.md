# Partager des morceaux GarageBand pour iOS et Logic Pro pour iPad sur SoundCloud

Pour partager sur SoundCloud, enregistrez votre morceau en tant que fichier audio, puis chargez-le à l’aide de l’app SoundCloud sur votre appareil.

## Partager votre morceau GarageBand avec SoundCloud

- Dans GarageBand sur iPhone ou iPad, touchez Parcourir dans le navigateur Mes morceaux.

- Touchez Sélectionner, puis le morceau que vous souhaitez charger vers Soundcloud. Selon votre appareil, vous devrez peut-être toucher le bouton Plus, l’option Sélectionner, puis le morceau.

- Touchez le bouton Partager .

- Touchez Morceau pour exporter le morceau en tant que fichier audio stéréo.

- Choisissez la qualité du fichier audio. Pour obtenir de meilleurs résultats, choisissez Sans compression (WAV) ou Sans compression (AIFF).

- Saisissez les informations sur le morceau, puis touchez Partager.

- Touchez Enregistrer dans Fichiers, choisissez l’emplacement où vous souhaitez enregistrer le fichier audio (comme dans iCloud Drive ou sur votre appareil), puis touchez Enregistrer. Ne choisissez pas le dossier GarageBand pour iOS par défaut, où vos projets GarageBand sont enregistrés par défaut.

- Ouvrez l’app SoundCloud, puis chargez le fichier audio.

## Partager votre morceau Logic Pro pour iPad avec SoundCloud

- Dans la table de mixage de Logic Pro pour iPad, vérifiez que les pistes que vous souhaitez inclure dans l’exportation sont routées vers la sortie stéréo principale et que leur son n’est pas désactivé.

- Touchez le nom du projet dans l’angle supérieur gauche de l’écran, puis touchez Exporter.

- Si vous souhaitez exporter uniquement une partie du projet, désactivez l’option Durée entière du projet, puis ajustez les valeurs des champs Position de départ et Position de fin. Vous pouvez toucher les champs pour modifier les valeurs dans la boîte de dialogue de saisie numérique.

- Si le mode Cycle est activé, la zone de lecture en boucle détermine les positions de début et de fin.

- Choisissez le type de fichier audio qui sera exporté. Pour obtenir de meilleurs résultats, choisissez Sans compression (WAV) ou Sans compression (AIFF).

- Pour définir les options disponibles pour le type de fichier que vous avez sélectionné, touchez le bouton d’information , puis configurez les options. Lorsque vous avez terminé, touchez Exporter pour revenir à la fenêtre d’exportation principale.

- Pour afficher et définir des options d’exportation supplémentaires, touchez Détails du traitement, puis touchez Exporter pour revenir à la fenêtre d’exportation principale.

- Touchez Partager.

- Une fois le fichier bouncé, touchez Enregistrer dans Fichiers, choisissez l’emplacement où vous souhaitez enregistrer le fichier audio (comme dans iCloud Drive ou sur votre appareil), puis touchez Enregistrer. Ne choisissez pas le dossier Logic Pro pour iPad par défaut, où vos projets Logic Pro sont enregistrés par défaut.

- Ouvrez l’app SoundCloud, puis chargez le fichier audio.
