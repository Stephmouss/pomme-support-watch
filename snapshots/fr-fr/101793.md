# GarageBand : affichage du message « Code d’erreur -2 renvoyé par le gestionnaire CoreAudio »

Lorsque vous ouvrez GarageBand, vous pouvez recevoir ce message d’alerte :

« Code d’erreur -2 renvoyé par le gestionnaire CoreAudio »

Si vous cliquez sur le bouton Continuer, l’audio du projet ne sera pas lu.

Ce problème affecte GarageBand 3.0.2 ou version ultérieure.

Pour résoudre ce problème :

- Cliquez sur le bouton Continuer pour rejeter le message d’alerte.

- Dans le menu de l’application GarageBand , choisissez Préférences .

- Sélectionnez la sous-fenêtre Audio/MIDI.

- Définissez les menus Entrée audio et Sortie audio sur l’interface audio appropriée. Pour la plupart des utilisateurs, il s’agira de l’interface Audio intégré.

- Fermez la fenêtre Préférences.
