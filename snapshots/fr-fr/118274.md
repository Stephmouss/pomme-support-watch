# Ajouter votre carte d’étudiant à l’app Cartes d’Apple sur votre iPhone ou Apple Watch

Utilisez votre iPhone ou votre Apple Watch pour accéder à des lieux comme votre résidence, la bibliothèque et les évènements de votre campus. Vous pouvez également payer vos lessives, en-cas et repas sur le campus.

Pour ajouter une carte d’étudiant sur votre iPhone ou Apple Watch, vous avez besoin des éléments suivants :

- Un iPhone ou une Apple Watch* compatible avec la [dernière version d’iOS](https://support.apple.com/118575) ou de [watchOS](https://support.apple.com/108926) .*

- Votre appareil connecté avec votre compte Apple

- Un établissement d’enseignement supérieur participant*

- La dernière version de votre app scolaire sur l’App Store*

* Renseignez-vous auprès de votre établissement scolaire pour en savoir plus.

## Comment ajouter votre carte d’étudiant à l’app Cartes d’Apple

- Connectez-vous à votre app scolaire avec vos nom d’utilisateur et mot de passe pour votre établissement.

- Touchez Ajouter à l’app Cartes.

[Image: Bouton Ajouter à l’app Cartes]

- Suivez les instructions à l’écran.

Découvrez comment [supprimer votre carte d’étudiant de l’app Cartes](https://support.apple.com/102544) .

## Utiliser votre carte d’étudiant sur votre iPhone ou votre Apple Watch

Vous pouvez utiliser votre carte d’étudiant sur votre iPhone ou votre Apple Watch pour accéder à votre résidence ou bibliothèque, payer dans les cafés du campus, acheter vos livres et autres fournitures scolaires dans les boutiques du campus et dans tous les endroits où vous aviez l’habitude de présenter votre carte d’étudiant.

Le mode Express est automatiquement activé lorsque vous ajoutez votre carte d’étudiant à Apple Cartes, de sorte que vous pouvez l’utiliser d’un simple toucher. Il n’est pas nécessaire de réactiver ou de déverrouiller votre appareil, ni de vous authentifier avec Face ID, Touch ID ou votre code d’accès. Il vous suffit de placer votre appareil près du lecteur sans contact.

Apprenez-en davantage sur le [mode Express](https://support.apple.com/105123) .

### Comment utiliser votre carte d’étudiant sur votre iPhone ou votre Apple Watch

- Tenez le haut de votre iPhone, écran vers vous, ou l’écran de votre Apple Watch à proximité du lecteur sans contact.

- Si vous faites un achat, le caissier peut être amené à sélectionner le mode de paiement.

- Une fois l’opération réussie, une coche apparaît sur votre appareil.

En fonction du modèle de votre iPhone, il est possible que vous puissiez [utiliser votre carte d’étudiant même si votre iPhone a besoin d’être rechargé](https://support.apple.com/105123#powerreserve) .

Pour utiliser votre carte d’étudiant si vous avez désactivé le mode Express, ouvrez l’app Cartes sur votre appareil. Touchez ensuite votre carte d’étudiant, authentifiez-vous avec Face ID, Touch ID ou votre code d’accès, et tenez votre appareil à proximité du lecteur sans contact.

## Comment consulter les soldes de votre carte d’étudiant sur votre iPhone

- Ouvrez l’app Cartes.

- Touchez votre carte d’étudiant pour la consulter et trouver jusqu’à trois soldes de compte.

- Pour trouver plus de soldes, touchez le bouton Plus .

[Image: Aucun texte de remplacement pour l’image]

Pour verser de l’argent sur votre carte d’étudiant, utilisez l’app ou le site web de votre école, ou une machine de service interne sur le campus.

## En cas de perte ou de vol de votre appareil

- [Marquer votre appareil comme perdu](https://support.apple.com/104978#markaslost) . Cette action entraîne automatiquement la fin de l’accès à toutes les cartes et passes enregistrés dans Apple Cartes, y compris votre carte d’étudiant.

- Supprimez votre carte d’étudiant de l’app de votre école.

- Contactez le bureau de votre carte scolaire. Pour trouver ses coordonnées, ouvrez votre carte d’étudiant dans Apple Cartes. Touchez ensuite le bouton Plus , puis touchez Appeler.
