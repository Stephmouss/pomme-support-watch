# Masquer les indicateurs de confidentialité sur les écrans externes sous macOS

Sous macOS Sonoma 14.4 ou version ultérieure, vous pouvez choisir de masquer les indicateurs de confidentialité sur un écran externe lorsque vous visualisez une app en plein écran. Les indicateurs de confidentialité apparaissent toujours sur l’écran principal de votre Mac.

## Désactiver les indicateurs de confidentialité pour les écrans externes de votre Mac

Nécessite macOS Sonoma 14.4 ou version ultérieure

Les indicateurs de confidentialité sont les points orange et verts qui apparaissent à côté du centre de contrôle dans la barre des menus pour signaler que votre microphone ou votre caméra est en cours d’utilisation. Pour les masquer sur un écran externe lorsqu’une app est affichée en plein écran :

- [Démarrez à partir de la fonctionnalité de récupération de macOS](https://support.apple.com/fr-fr/102518) .

- Dans le menu Utilitaires de la barre des menus de la fonctionnalité de récupération de macOS, choisissez Terminal.

- Saisissez cette commande : system-override suppress-sw-camera-indication-on-external-displays=on

- Quittez Terminal.

- Dans le menu Pomme, choisissez Redémarrer, puis ouvrez une session à l’aide de votre compte utilisateur.

- Dans le menu Pomme, choisissez Réglages Système, puis cliquez sur Confidentialité et sécurité dans la barre latérale.

- Cliquez sur Microphone ou sur Caméra.

- Désactivez l’option Indicateurs de confidentialité.
