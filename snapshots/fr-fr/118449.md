# Masquer les indicateurs de confidentialité sur les écrans externes sous macOS

Dans macOS Sonoma 14.4 ou version ultérieure, vous pouvez choisir de masquer les indicateurs de confidentialité sur un écran externe secondaire lorsque vous affichez une app en plein écran. Les indicateurs de confidentialité continueront de s’afficher sur votre écran principal.

## Désactiver les indicateurs de confidentialité pour les écrans externes de votre Mac

Nécessite macOS Sonoma 14.4 ou version ultérieure

L’indicateur de confidentialité est le point orange (indicateur du micro) ou le point vert (indicateur de la caméra) qui apparaît dans la barre des menus pour indiquer que votre micro ou votre caméra est en cours d’utilisation. Pour masquer l’indicateur sur un écran externe secondaire lors de l’affichage d’une app en plein écran :

- [Démarrez à partir de la fonctionnalité de récupération de macOS](https://support.apple.com/fr-fr/102518) .

- Dans le menu Utilitaires de la barre des menus de la fonctionnalité de récupération de macOS, choisissez Terminal.

- Saisissez cette commande : system-override suppress-sw-camera-indication-on-external-displays=on

- Quittez Terminal.

- Dans le menu Apple, choisissez Redémarrer, puis ouvrez une session à l’aide de votre compte utilisateur.

- Dans le menu Apple, choisissez Réglages Système, puis cliquez sur Confidentialité et sécurité dans la barre latérale.

- Cliquez sur Microphone ou sur Caméra.

- Désactivez l’option Indicateurs de confidentialité.

Si l’écran externe n’est pas également votre écran principal, l’indicateur de confidentialité n’apparaît plus dans la barre des menus. (Si l’écran externe est le seul écran utilisé par votre Mac, il s’agit de l’écran principal.)
