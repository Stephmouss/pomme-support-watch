# Ajouter les fichiers de vos dossiers Bureau et Documents dans iCloud Drive

Lorsque vous activez le réglage Dossiers Bureau et Documents, vos dossiers Bureau et Documents sont stockés dans iCloud Drive. Cela vous permet d’accéder aux fichiers de votre Mac sur tous vos appareils.

- [Activer le réglage Dossiers Bureau et Documents](https://support.apple.com/fr-fr/109344#turn_on)

- [Trouver vos fichiers Bureau et Documents sur votre appareil](https://support.apple.com/fr-fr/109344#find)

- [Supprimer des fichiers des dossiers Bureau et Documents](https://support.apple.com/fr-fr/109344#icloud_delete_files)

- [Désactiver le réglage Dossiers Bureau et Documents](https://support.apple.com/fr-fr/109344#turn_off)

## Activer le réglage Dossiers Bureau et Documents

- [Configurez iCloud sur tous vos appareils](https://support.apple.com/guide/icloud/mmfc0f1e2a) .

- Sur votre Mac, dans le menu Apple , choisissez Réglages Système.

- Cliquez sur votre nom, puis sur iCloud.

- Cliquez sur Drive (ou iCloud Drive).

[Image: Réglages iCloud sur un Mac. Drive se trouve sous « Enregistré sur iCloud ».]

- Sous iCloud Drive, vérifiez que vous avez activé la synchronisation de ce Mac.

- Activez le réglage Dossiers Bureau et Documents.

[Image: Réglages iCloud Drive affichant l’option Dossiers Bureau et Documents activée.]

- Cliquez sur Terminé.

- Si vous avez plusieurs Mac, répétez ce processus sur tous ceux que vous souhaitez utiliser avec iCloud Drive.

### Si vous voulez également stocker vos fichiers avec un autre service de stockage dans le cloud

Si vous voulez stocker vos fichiers sur iCloud Drive et un autre service de stockage dans le cloud, vous pouvez conserver des copies séparées de vos fichiers sur les deux. Pour stocker des dossiers provenant d’un service cloud tiers, utilisez un autre emplacement de votre Mac, par exemple le dossier de départ.

Si la synchronisation ou la gestion de vos dossiers Bureau et Documents sont assurées par une fonctionnalité d’un autre fournisseur de services Cloud, vous devez désactiver cette fonctionnalité pour utiliser le réglage Dossiers Bureau et Documents.

### Si vous disposez de bibliothèques multimédias

iCloud Drive ne chargera pas sur vos autres appareils les types de fichiers de bibliothèques suivants qui proviennent de vos dossiers Bureau et Documents :

- Bibliothèques iMovie

- Photothèques Photos

- Photothèques Aperture

Ces fichiers sont répertoriés comme Inéligibles dans le Finder.

## Trouver vos fichiers Bureau et Documents sur votre appareil

Lorsque vous ajoutez vos dossiers Bureau et Documents dans iCloud Drive, tous les fichiers qu’ils contiennent sont déplacés dans iCloud et tout nouveau fichier créé y sera automatiquement stocké. Vous pourrez ensuite retrouver vos fichiers sur tous vos appareils.

Vos fichiers se synchronisent avec iCloud chaque fois que votre appareil se connecte à Internet. Le délai d’apparition de vos fichiers sur vos autres appareils peut varier selon la vitesse de votre connexion Internet.

### Sur votre Mac

- Sous macOS Tahoe 26 ou version ultérieure, vous trouverez vos dossiers Bureau et Documents dans iCloud Drive dans la barre latérale du Finder, sous Favoris. Chaque dossier présente une icône de nuage à côté de son nom.

- Dans les versions précédentes de macOS, les dossiers Bureau et Documents sont accessibles dans la section iCloud de la barre latérale du Finder.

- Si vous ajoutez un deuxième Bureau Mac, vous pouvez accéder à ces fichiers dans le dossier Bureau d’iCloud Drive. Le dossier possède le même nom que votre deuxième Mac.

- Vous pouvez également rechercher un fichier à l’aide de Spotlight.

### Sur votre iPhone ou iPad

- Ouvrez l’app Fichiers.

- Touchez Parcourir.

- Sous Emplacements, touchez iCloud Drive.

- Touchez le dossier Bureau ou le dossier Documents.

Vous pouvez utiliser n’importe quelle app compatible pour accéder à vos fichiers et les modifier.

### Sur icloud.com

- Connectez-vous à votre compte Apple sur [iCloud.com](https://www.icloud.com) .

- Rendez-vous sur iCloud Drive.

- Double-cliquez sur le dossier Bureau ou le dossier Documents.

Pour modifier ou utiliser le fichier, cliquez sur le bouton Télécharger afin de le télécharger. Lorsque vous avez terminé, chargez le fichier sur iCloud Drive pour que la dernière version se synchronise sur tous vos appareils. Vous pouvez modifier des fichiers Pages, Numbers ou Keynote sur le Web, et enregistrer les modifications directement sur iCloud Drive.

## Supprimer des fichiers des dossiers Bureau et Documents

Les fichiers que vous conservez dans les dossiers Bureau et Documents d’iCloud Drive sont stockés dans iCloud et utilisent votre stockage iCloud. Lorsque vous supprimez un fichier sur un appareil, le fichier est supprimé de tous les appareils sur lesquels vous êtes connecté(e) avec le même compte Apple. Vous pouvez accéder aux fichiers supprimés dans le dossier Supprimés récemment de l’app Fichiers ou sur [iCloud.com](https://www.icloud.com) pendant 30 jours. Passé ce délai, ces fichiers sont supprimés.

Pour libérer du stockage local sur votre appareil sans supprimer le fichier, touchez le fichier de façon prolongée, puis sélectionnez Supprimer le téléchargement.

## Désactiver le réglage Dossiers Bureau et Documents

Lorsque vous désactivez le réglage Dossiers Bureau et Documents sur votre Mac, vos fichiers sont conservés dans iCloud Drive et de nouveaux dossiers Bureau et Documents sont créés localement sur votre Mac dans le dossier de départ. Si vous désactivez iCloud Drive ou vous déconnectez d’iCloud, de nouveaux dossiers Bureau et Documents sont créés dans votre dossier de départ et vous pouvez choisir de conserver une copie locale de vos fichiers.

[Découvrez ce qui se passe lorsque vous désactivez le réglage Dossiers Bureau et Documents](https://support.apple.com/fr-fr/126628)
