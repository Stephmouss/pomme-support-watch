# Si vous ne parvenez pas à visionner des iTunes Extras

Découvrez la marche à suivre si vous ne parvenez pas à visionner ou à lire les iTunes Extras d’un film que vous avez acheté dans l’app Apple TV ou l’iTunes Store.

Si un film contient des iTunes Extras, le badge iTunes Extras apparaît sur la page de description du film dans l’app Apple TV ou l’iTunes Store.

Vous pouvez visionner les iTunes Extras dans l’app Apple TV sur un iPhone, un iPad, un iPod touch, un Mac et une Apple TV. Vous pouvez également les visionner dans iTunes pour Windows sur un PC.

Pour accéder aux iTunes Extras sur un iPhone, un iPad ou un iPod touch, touchez l’écran tout en visualisant le média en mode paysage, puis touchez Extras dans les commandes de lecture.

Les iTunes Extras ne sont pas disponibles dans tous les pays et toutes les régions. Découvrez [ce qui est proposé dans votre pays ou région](https://support.apple.com/HT204411) .

## Assurez-vous de disposer d’une connexion Internet fiable

Connectez votre appareil à un réseau Wi-Fi, puis réessayez. Si vous utilisez un iPhone ou un iPad doté d’une connexion mobile, allez dans Réglages et assurez-vous que [les données cellulaires sont activées pour l’app Apple TV](https://support.apple.com/HT201299) .

## Vérifiez si le film comporte des iTunes Extras

Sur votre iPhone, iPad, iPod touch, Mac ou Apple TV, ouvrez l’app Apple TV, puis accédez à l’onglet Bibliothèque.

Sur un PC, ouvrez iTunes pour Windows, sélectionnez Films dans le menu situé dans l’angle supérieur gauche, puis accédez à l’onglet Bibliothèque.

Sélectionnez un film pour ouvrir sa page de description. Le symbole iTunes Extras apparaît si le film en comporte.

Si vous n’avez pas acheté la version haute définition (HD) d’un film ou si vous avez loué ce dernier, celui-ci ne comportera pas d’iTunes Extras.

Les iTunes Extras ne sont pas disponibles dans l’app Apple TV sur les Smart TV et les appareils de streaming.

[Image: App Apple TV sur un iPhone, affichant le badge iTunes Extras sur la page de description d’un film.]

## Mettre à jour vos logiciels

Sur votre iPhone ou iPod touch, [effectuez une mise à jour vers la dernière version d’iOS](https://support.apple.com/HT204204) .

Sur votre iPad, [effectuez une mise à jour vers la dernière version d’iPadOS](https://support.apple.com/HT204204) .

Sur votre Mac, [effectuez une mise à jour vers la dernière version de macOS](https://support.apple.com/HT201541) .

Sur votre Apple TV, [effectuez une mise à jour vers la dernière version de tvOS](https://support.apple.com/HT202716) .

Sur un PC, assurez-vous que vous disposez de la [dernière version d’iTunes pour Windows](https://support.apple.com/HT210384) .

## Assistance supplémentaire

Si vous ne parvenez toujours pas à visionner les iTunes Extras, vous pouvez [signaler un problème lié à votre achat](https://reportaproblem.apple.com/?s=6) .

## Si vous avez acheté le film avant le 10 juillet 2014

Si vous avez acheté un film comportant des iTunes Extras avant le 10 juillet 2014, il se peut également que vous puissiez télécharger une version des iTunes Extras d’origine, le cas échéant, à partir de l’iTunes Store sur un Mac ou PC doté d’iTunes.

Lorsque vous téléchargez des iTunes Extras, ces derniers apparaissent sous la forme d’un élément séparé dans votre bibliothèque.
