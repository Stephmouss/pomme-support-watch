# Si vous ne parvenez pas à trouver un module récemment installé pour Logic Pro pour Mac ou MainStage

Découvrez la marche à suivre si vous avez installé un module Audio Units tiers, mais que celui-ci n’apparaît pas dans les emplacements de modules de Logic Pro ou de MainStage.

[Redémarrer votre Mac](https://support.apple.com/fr-fr/122179#restart)

[Vérifiez que le module est bien installé](https://support.apple.com/fr-fr/122179#confirm)

[Réanalyser le module](https://support.apple.com/fr-fr/122179#rescan)

[Réinitialiser tous les modules Audio Units dans Logic Pro et MainStage](https://support.apple.com/fr-fr/122179#reset)

[Réanalyser des modules Audio Units dans toutes les apps](https://support.apple.com/fr-fr/122179#rescan_all)

## Redémarrez votre Mac

Si votre Mac exécute macOS High Sierra ou une version ultérieure et qu’un module récemment installé n’apparaît pas dans Logic Pro ou MainStage, redémarrez votre Mac. Avant de redémarrer votre Mac, vérifiez que le module est compatible 64 bits. Les modules 32 bits ne sont pas compatibles avec Logic Pro et MainStage.

- Choisissez le menu Pomme  > Redémarrer.

- Ouvrez Logic Pro ou MainStage.

- Cliquez sur un slot d’effet audio, d’instrument ou d’effet MIDI pour vérifier si le module apparaît dans le menu local. Assurez-vous de vérifier les sous-menus, où les modules sont classés par fabricant.

Si le module n’est toujours pas disponible dans Logic Pro ou MainStage, assurez-vous qu’il est installé.

## Vérifier que le module est bien installé

Utilisez le gestionnaire de module pour confirmer que le module est installé.

- Choisissez Logic Pro > Réglages (ou Préférences) > Gestionnaire de module, ou MainStage > Réglages (ou Préférences) > Gestionnaire de module.

- Dans le gestionnaire de module, recherchez le module. Pour filtrer la liste par fabricant, cliquez sur le nom du fabricant dans la colonne de gauche.

- Si le message « non autorisé » apparaît dans la colonne Compatibilité du module, assurez-vous que celui-ci dispose des autorisations adéquates, conformément aux indications du fabricant.

- Réinstallez le module, puis redémarrez l’ordinateur.

- Ouvrez Logic Pro ou MainStage, puis vérifiez si le module apparaît dans le gestionnaire de module. S’il apparaît, ouvrez un projet ou un concert et assurez-vous que le module est disponible.

- Si le module apparaît dans le gestionnaire de module, mais n’est pas disponible dans un projet Logic Pro ou un concert MainStage, [réanalysez le module](https://support.apple.com/fr-fr/122179#rescan) .

- Si vous ne trouvez toujours pas le module dans le gestionnaire de module, [réinitialisez tous les modules Audio Units](https://support.apple.com/fr-fr/122179#rescan_all) .

## Réanalyser le module

Si le module apparaît dans le gestionnaire de module, mais n’est toujours pas disponible dans Logic Pro ou MainStage, analysez-le de nouveau.

- Dans le gestionnaire de module, recherchez le module à vérifier. Pour filtrer par fabricant, cliquez sur le nom de celui-ci dans la colonne de gauche.

- Si le message « échec de la validation » apparaît dans la colonne Compatibilité du module, sélectionnez ce dernier, puis cliquez sur Réinitialiser et réanalyser la sélection.

- Si le message « non autorisé » apparaît dans la colonne Compatibilité du module, assurez-vous que ce dernier dispose des autorisations adéquates, conformément aux indications du fabricant, puis analysez-le de nouveau.

- Si la validation du module échoue à nouveau, consultez son fabricant pour déterminer s’il est compatible avec votre version de macOS et si des mises à jour sont disponibles.

- Si le module n’apparaît pas dans le gestionnaire de module, essayez de [réinitialiser tous les modules Audio Units](https://support.apple.com/fr-fr/122179#rescan_all) .

## Réinitialiser tous les modules Audio Units dans Logic Pro et MainStage

Si vous ne trouvez pas un module récemment installé dans le gestionnaire de module de Logic Pro ou MainStage, essayez de réinitialiser tous les modules Audio Units à l’aide du gestionnaire de module. Lorsque vous réinitialisez les modules Audio Units dans Logic Pro, ils sont également réinitialisés dans MainStage.

- Choisissez Logic Pro > Réglages (ou Préférences) > Gestionnaire de module.

- Cliquez sur Réinitialisation complète des Audio Units.

- Fermez Logic Pro, puis rouvrez-le. Logic Pro analyse à nouveau tous les modules Audio Units installés.

- Vérifiez si le module est disponible dans Logic Pro ou MainStage.

Si le module n’apparaît toujours pas, consultez son fabricant pour déterminer s’il est compatible avec votre version de macOS et si des mises à jour sont disponibles.

## Réanalyser des modules Audio Units dans toutes les apps

En dernier recours, pour dépanner une app qui présente des problèmes de validation ou autres avec un module Audio Units spécifique, supprimez manuellement les fichiers AudioUnitCache pour forcer une nouvelle analyse complète. Vous pouvez également procéder ainsi pour réanalyser des modules MainStage si vous n’utilisez pas Logic Pro sur le même Mac.

Cette opération peut prendre du temps. Vous ne pourrez pas utiliser d’apps qui contiennent des Audio Units pendant la durée de l’analyse.

- Dans le Finder, appuyez sur la touche Option et choisissez Aller > Bibliothèque.

- Dans la fenêtre du Finder qui s’ouvre, recherchez le dossier AudioUnitCache dans le dossier Caches.

- Déplacez les fichiers du dossier AudioUnitCache vers le bureau ou un autre emplacement, comme un dossier dédié à cette procédure.

- Redémarrez l’ordinateur, puis ouvrez MainStage. Tous les modules Audio Units installés sont réanalysés. Si le module n’apparaît toujours pas, consultez son fabricant pour déterminer s’il est compatible avec votre version de macOS et si des mises à jour sont disponibles.
