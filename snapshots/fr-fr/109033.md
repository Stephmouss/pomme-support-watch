# Identifier la version de macOS installée sur votre Mac

Découvrez quel système d’exploitation Mac (macOS) est installé sur votre Mac, et s’il s’agit de la version la plus récente. Si un produit ou une fonctionnalité nécessite une version plus récente de macOS, vérifiez la compatibilité avec macOS de votre ordinateur pour savoir si vous pouvez passer à cette version.

- [Quelle version de macOS est installée ?](https://support.apple.com/fr-fr/109033#aboutthismac)

- [Quelle est la version la plus récente de macOS ?](https://support.apple.com/fr-fr/109033#latest)

- [Vérifier la compatibilité avec macOS](https://support.apple.com/fr-fr/109033#compatibility)

- [Passer à une version ultérieure de macOS](https://support.apple.com/fr-fr/109033#upgrade)

## Quelle version de macOS est installée ?

Dans le menu Apple  situé dans l’angle supérieur gauche de l’écran, choisissez À propos de ce Mac. La fenêtre qui s’ouvre peut être différente de celle de cet exemple, mais elle indique toujours le nom et le numéro de la version de macOS de votre Mac. Si vous souhaitez également connaître le numéro de build, vous pouvez l’afficher en cliquant sur le numéro de version.
