# Code de la souris sans fil Apple

Les souris sans fil Apple ne nécessitent généralement pas de code d’accès, mais certains logiciels en demandent un pour activer la souris. Par exemple, si vous utilisez votre souris sans fil Apple avec Boot Camp, le pilote générique de Windows peut demander un code d’accès.

Le code d’accès « 0000 » (quatre zéros) est intégré aux souris sans fil Apple. Si un logiciel de configuration vous demande un code d'accès, saisissez cette valeur.
