# Configurer votre iPhone ou iPad

Découvrez la marche à suivre pour configurer votre iPhone ou iPad.

Si vous avez déjà configuré votre nouvel appareil, mais que vous souhaitez recommencer l’opération, [découvrez comment effacer les données de votre iPhone ou de votre iPad](https://support.apple.com/108931) .

## Allumez votre iPhone ou iPad

Maintenez le bouton d’alimentation enfoncé jusqu’à ce que le logo Apple apparaisse. Le mot « Bonjour » s’affiche alors dans plusieurs langues. Suivez les instructions à l’écran pour commencer.

Si vous êtes non-voyant ou malvoyant, vous pouvez [activer la fonctionnalité VoiceOver ou Zoom](http://support.apple.com/111771) à partir de l’écran Bonjour.

[Image: L’écran « Bonjour » initial affiché lors de la configuration d’un nouvel iPhone ou iPad exécutant iOS 26.]

## Choisissez la taille du texte et des icônes sur votre téléphone

Sélectionnez la taille que vous préférez pour le texte et les icônes : Par défaut, Moyen ou Grand. À mesure que vous faites glisser l’icône entre ces tailles, le texte et les images sur cet écran Apparence changent, afin d’afficher un aperçu de l’option sélectionnée.

Lorsque vous êtes prêt, faites glisser l’icône vers la taille de votre choix et touchez Continuer.

[Image: Lors du processus de configuration de l’iPhone sous iOS 26, faites glisser une icône afin d’afficher un aperçu des tailles de texte et d’app, puis choisissez celle que vous souhaitez utiliser.]

## Utilisez le démarrage rapide ou effectuez une configuration manuelle

Si vous avez un autre appareil, vous pouvez l’utiliser pour [configurer automatiquement votre nouvel appareil avec le démarrage rapide](https://support.apple.com/102659) .

Si vous n’avez pas d’autre appareil, touchez Configurer sans autre appareil.

Vous pouvez alors toucher le bouton bleu d’accessibilité pour [définir des options d’accessibilité](https://support.apple.com/111780) .

[Image: Capture d’écran d’un iPhone lors de la configuration, affichant l’écran Démarrage rapide avec des icônes d’iPhone superposées.]

## Activez votre iPhone ou iPad

Vous devez vous connecter à un réseau Wi-Fi ou à un réseau mobile pour activer votre appareil et poursuivre sa configuration.

Touchez le réseau Wi-Fi que vous souhaitez utiliser ou, le cas échéant, touchez Continuer sans Wi-Fi pour utiliser le réseau mobile de votre appareil. Si vous configurez un iPhone ou un iPad (Wi-Fi + Cellular), il se peut que vous deviez d’abord insérer [la carte SIM dans votre iPhone](https://support.apple.com/109357) ou [la carte SIM dans votre iPad](https://support.apple.com/102392) . Il vous sera peut-être également demandé [d’activer votre eSIM](https://support.apple.com/118669) .

Obtenez de l’aide si vous [ne parvenez pas à vous connecter au Wi-Fi](https://support.apple.com/111786) ou à [activer votre iPhone](https://support.apple.com/109326) .

## Effectuez la configuration pour vous ou pour un enfant

Ensuite, choisissez si vous souhaitez configurer votre iPhone pour vous ou pour un enfant. Découvrez comment [créer un compte Apple pour un enfant de moins de 13 ans](https://support.apple.com/102617) , comment [configurer le partage familial](https://support.apple.com/108380) et comment [utiliser le contrôle parental sur l’iPhone d’un enfant](https://support.apple.com/105121) .

[Image: Lors du processus de configuration de l’iPhone sous iOS 26, vous pouvez choisir si le nouveau téléphone est pour vous ou pour un enfant de votre famille.]

## Configurez Face ID ou Touch ID et créez un code d’accès

Suivez les instructions à l’écran pour configurer [Face ID](https://support.apple.com/108411) ou [Touch ID](https://support.apple.com/102528) afin d’utiliser la reconnaissance faciale ou votre empreinte digitale pour déverrouiller votre appareil et effectuer des achats.

Définissez ensuite un code d’accès à six chiffres pour protéger vos données. Un code d’accès est requis pour utiliser certaines fonctionnalités, telles que Face ID, Touch ID et [Apple Pay](https://support.apple.com/108398) . Si vous souhaitez définir un code d’accès à quatre chiffres, un code personnalisé ou même aucun code, touchez Options de code.

## Restaurez ou transférez vos données et vos apps

Choisissez la façon dont vous souhaitez restaurer ou transférer vos données de votre ancien appareil vers votre nouvel appareil. Vous pouvez [utiliser une sauvegarde iCloud ou une sauvegarde effectuée à partir de votre ordinateur](https://support.apple.com/119967) , ou [migrer des données d’un appareil Android](https://support.apple.com/118670) .

Si vous ne disposez pas d’une sauvegarde ni d’un autre appareil, choisissez Ne pas transférer les apps et les données.

[Image: Options Transférer vos apps et données lorsque vous configurez un iPhone sous iOS 26]

## Connectez-vous avec votre compte Apple ou un autre appareil Apple

Saisissez l’adresse e-mail ou le numéro de téléphone que vous utilisez avec votre compte Apple, puis saisissez votre mot de passe. Vous pouvez également toucher « Vous avez oublié votre mot de passe ou vous n’avez pas de compte Apple ? » Vous pouvez alors récupérer votre compte Apple ou votre mot de passe, créer un compte Apple ou le configurer plus tard.

Si vous utilisez plusieurs comptes Apple, touchez Autres options de connexion, puis Utiliser plusieurs comptes.

Lorsque vous vous connectez à l’aide de votre compte Apple, il peut vous être demandé de saisir un code de validation à partir de votre ancien appareil.

[En savoir plus sur le mot de passe si vous avez oublié le mot de passe de votre compte Apple](https://support.apple.com/102656)

[Image: Écran « Connexion requise » lors de la configuration de l’iPhone sous iOS 26, affichant les options permettant de se connecter avec un compte Apple à l’aide d’une adresse e‑mail ou d’un numéro de téléphone, ou de « Configurer plus tard dans Réglages ».]

## Activez les mises à jour automatiques et configurez d’autres fonctionnalités

Suivez les instructions à l’écran pour autoriser iOS ou iPadOS à installer automatiquement les mises à jour et à configurer d’autres fonctionnalités, comme le service mobile et un numéro de téléphone ou [Apple Pay](https://support.apple.com/108398) :

- Il vous est ensuite demandé de configurer ou d’activer des services et des fonctionnalités tels que Siri. Sur certains appareils, il vous sera demandé de prononcer quelques phrases afin que Siri apprenne à reconnaître votre voix.

- Suivez ensuite les instructions à l’écran pour configurer la fonctionnalité [Temps d’écran](https://support.apple.com/108806) , qui vous permet de savoir le temps que vos enfants et vous-même passez sur vos appareils. Elle vous permet également de définir une durée limite d’utilisation quotidienne des apps.

- Ensuite, apprenez-en davantage sur les données que vous pouvez partager avec Apple et choisissez de partager ou non des données avec les développeurs d’apps.

- Touchez Clair ou Sombre pour voir un aperçu de ces modes sur votre iPhone. Touchez Automatique pour que votre iPhone bascule automatiquement entre les deux modes au fil de la journée. Quand vous êtes prêt, touchez Continuer.

- Si votre iPhone est un appareil compatible avec Apple Intelligence, vous pouvez configurer Apple Intelligence et [découvrir des fonctionnalités comme l’intelligence visuelle dans iOS 26](https://support.apple.com/guide/iphone/use-visual-intelligence-iph12eb1545e/26/ios/26) .

- Enfin, si vous avez configuré un iPhone 14 ou modèle ultérieur (tous les modèles), découvrez des fonctionnalités de sécurité comme [Appel d’urgence](https://support.apple.com/guide/personal-safety/emergency-call-text-iphone-apple-watch-ips4f0cd709b/web) , [Détection des accidents](https://support.apple.com/104959) et [SOS d’urgence par satellite](https://support.apple.com/105097) dans certains pays.
