# Suivre les commandes et les achats dans l’app Cartes d’Apple

Lorsque vous effectuez un achat sur votre iPhone, iPad ou Mac à partir d’une app ou d’un site web participant, vous pouvez suivre votre commande dans l’app Cartes sur votre iPhone.

## Suivre les commandes dans l’app Cartes d’Apple

Vous pouvez utiliser le suivi des commandes dans l’app Cartes pour :

- Consulter l’état de votre commande, la date d’arrivée estimée ou tout problème lié à votre commande

- Le cas échéant, consulter les détails de votre commande et les liens de suivi de la livraison

- Contacter le commerçant directement depuis l’app Cartes

Lorsque vous effectuez un achat, vous pouvez suivre les commandes éligibles dans l’app Cartes depuis votre iPhone :

- Automatiquement : suivez les commandes de certains achats effectués via Apple Pay sur des appareils exécutant iOS 16, iPadOS 16, macOS 13 ou version ultérieure.

- Manuellement : touchez le bouton Suivre avec Cartes d’Apple sur l’écran de confirmation de commande dans les apps avec iOS 17, iPadOS 17 ou sur le Web avec des appareils utilisant iOS 17, iPadOS 17 ou macOS Sonoma.

[Image: Un exemple du bouton « Suivre avec Cartes d’Apple »]

- Dans Mail : suivez les commandes dans l’app Mail sur les appareils compatibles avec Apple Intelligence exécutant iOS 26 ou une version ultérieure.

Pour afficher les commandes passées sur vos autres appareils, vous devez être connecté avec le même compte Apple.

## Suivre les achats et les commandes Apple Pay dans l’app Cartes d’Apple

- Sur votre iPhone, ouvrez l’app Cartes.

- Touchez le bouton Commandes , puis touchez une commande pour afficher plus de détails.

- Pour plus d’informations ou d’aide :

- Le cas échéant, touchez Gérer la commande, pour accéder au site web du commerçant.

- Le cas échéant, touchez Envoyer un e-mail à ce commerçant, pour contacter le commerçant.

- Touchez les e-mails répertoriés sous E-mail associé pour afficher les détails de l’e-mail.

- Suivez votre commande sur le site web de la compagnie d’expédition.

Vous pouvez également toucher une transaction récente pour voir les détails du suivi de la commande.

- Sur votre iPhone, ouvrez l’app Cartes.

- Touchez votre carte de crédit ou de débit.

- Touchez ensuite une transaction récente.

Le suivi des commandes peut ne pas être disponible pour toutes les commandes. Cela peut dépendre du commerçant ou du fait que les détails de votre commande se trouvent dans Mail ou Photos.

## Suivre les achats et les commandes dans Mail

Vous pouvez également suivre les achats et les commandes dans l’app Mail à l’aide d’Apple Intelligence.

- Ouvrez Réglages, puis touchez Cartes et Apple Pay.

- Touchez Suivi des commandes et assurez-vous que l’option Mail est activée.

- Dans l’e-mail relatif à votre commande, touchez Suivre. Vous serez peut-être invité à toucher Autoriser.

## En cas de problèmes avec vos informations de suivi de commande

L’app Cartes affiche les informations fournies par le commerçant. Si les informations que vous voyez dans l’app Cartes ne correspondent pas à vos attentes, ou si vous avez une question sur votre commande, sur les détails de votre commande ou sur les détails du reçu, contactez le commerçant pour en savoir plus.
