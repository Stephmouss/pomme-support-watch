# OS X Lion : la mise à niveau à partir de Mac OS X 10.6 ne fonctionne pas avec un RAID logiciel ; le message « Une erreur s’est produite lors de la préparation de l’installation. Essayez d’exécuter à nouveau cette application. » s’affiche

Lors d’une mise à niveau d’un système Mac OS X 10.6 Snow Leopard ou Mac OS X Server 10.6 vers Lion, le message suivant s’affiche si l’application « Installer Mac OS X Lion » est ouverte à partir d’un volume RAID logiciel :

« Une erreur s’est produite lors de la préparation de l’installation. Essayez d’exécuter à nouveau cette application. »

Si votre disque de démarrage Mac OS X 10.6 est un volume RAID logiciel

Copiez l’application « Installer Mac OS X Lion » à partir de votre dossier Applications vers un autre disque ne faisant pas partie d’un RAID logiciel. Vous pouvez utiliser un autre volume interne (si disponible) ou un lecteur externe, tel qu’une clé USB. Double-cliquez sur la copie du fichier « Installer Mac OS X Lion » sur le volume non RAID pour lancer l’installation.

Si votre disque de démarrage Mac OS X 10.6 n’est pas un volume RAID logiciel

Vérifiez que vous n’essayez pas d’utiliser une copie de l’application « Installer Mac OS X Lion » qui se trouve sur un volume RAID logiciel.
