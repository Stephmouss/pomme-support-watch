# Conserver votre reçu après l’achat d’un appareil Apple

Félicitations pour l’achat de votre nouvel appareil Apple ! Nous savons que vous voulez prendre grand soin de votre produit. Nous vous recommandons donc de conserver votre reçu et tout autre document important dans un endroit sûr.

Si jamais vous avez besoin de mettre à jour les dossiers de votre appareil, vous devrez nous présenter une copie du reçu d’achat d’origine. Si vous avez souscrit un contrat AppleCare, vous devez également conserver votre document de [preuve de couverture](https://support.apple.com/HT202710) .

Tous les documents doivent être émis par un revendeur agréé Apple et répondre aux critères suivants :

- Un reçu lisible

- Le reçu doit indiquer les informations suivantes :

- Une description claire de votre appareil

- La date d’achat de l’appareil

- Un numéro de facture ou de reçu

- Le prix de l’appareil

- Les coordonnées du revendeur. Il est préférable que le cachet ou le logo du revendeur soit également visible.

- Le numéro de série de l’appareil si le revendeur l’indique habituellement sur ses reçus.
