# Installer ou remplacer des modules SSD dans votre Mac Pro (2019)

Découvrez comment installer des modules SSD dans votre Mac Pro et les configurer à l’aide d’Apple Configurator.

Le Mac Pro prend en charge un ou deux modules SSD (Solid-State Drive) en fonction de la capacité. Les modules SSD sont jumelés avec la puce T2 Security et chiffrés par cette dernière. Si vous remplacez les modules SSD, procédez à leur effacement et à leur configuration pour votre Mac Pro à l’aide d’Apple Configurator.

## Vérification de la configuration requise

Les éléments suivants sont nécessaires pour installer ou remplacer des modules SSD dans votre Mac Pro :

- Tournevis T8

- Câble USB-C vers USB-C prenant en charge l’alimentation et le transfert de données

- Les câbles Thunderbolt 3 ne sont pas compatibles.

- Un autre ordinateur Mac doté de [macOS 10.14.6 ou version ultérieure](https://support.apple.com/fr-fr/108382) et d’ [Apple Configurator 2.12 ou version ultérieure](https://support.apple.com/fr-fr/109517)

- Modules SSD compatibles avec le Mac Pro (2019)

## Désinstaller et installer les modules SSD

Procédez aux étapes suivantes uniquement si toutes les données du module SSD existant ont été sauvegardées. Une fois que l’opération de jumelage d’un nouveau module SSD a débuté, il est impossible de récupérer les données présentes sur le module SSD existant.

[Suivez ces instructions pour désinstaller et installer des modules SSD dans votre Mac Pro.](https://support.apple.com/guide/mac-pro/uninstall-and-install-ssd-modules-apd587f502f6/mac)

## Restaurer le programme interne

Une fois les nouveaux modules SSD installés, [restaurez le programme interne de la puce Apple T2 Security et effacez le stockage flash interne de votre Mac](https://support.apple.com/guide/apple-configurator-mac/welcome/mac) .
