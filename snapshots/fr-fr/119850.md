# À propos de l’adaptateur Apple multiport AV numérique USB-C

Connectez un Mac doté d’un port Thunderbolt 4, Thunderbolt 3 ou USB-C à un écran HDMI, tout en chargeant votre Mac et en le connectant à un périphérique USB-A. Cet adaptateur peut également être utilisé avec les modèles d’iPad dotés d’un port Thunderbolt ou USB-C.

[Image: Vue du dessus et ports de l’adaptateur multiport AV numérique Apple]

L’ [adaptateur multiport AV numérique USB-C](https://www.apple.com/fr/shop/product/MUF82ZM/A/adaptateur-multiport-av-numérique-usb-c) connecte les appareils suivants à un écran utilisant un câble HDMI :

- [Mac doté d’un port Thunderbolt 4, Thunderbolt 3 ou USB-C](https://support.apple.com/HT201736)

- [iPad doté d’un port Thunderbolt ou USB-C](https://support.apple.com/HT201471)

Cet adaptateur permet également de connecter des périphériques USB-A à votre Mac ou iPad. Il comporte un port USB-C pour charger votre ordinateur portable Mac ou votre iPad. Les trois ports peuvent être utilisés simultanément.

## Se connecter à un écran avec HDMI

[Image: Port HDMI]

Utilisez le port HDMI de cet adaptateur avec un écran, un téléviseur ou un projecteur qui se connecte à l’aide d’un câble HDMI. Il est compatible avec le procédé HDCP et prend en charge les spécifications ci-dessous, en fonction du modèle de l’adaptateur.

Le modèle A2119 est le modèle le plus récent de cet adaptateur. Lorsqu’il est utilisé avec macOS Mojave 10.14.6 (ou version ultérieure) ou iOS 12.4 (ou version ultérieure), cet adaptateur prend en charge les résolutions et fréquences de rafraîchissements suivantes.

3 840 x 2 160 à 60 Hz avec les appareils suivants :

- [MacBook Pro](https://support.apple.com/HT201300) 16 pouces commercialisés à partir de 2019

- [MacBook Pro](https://support.apple.com/HT201300) 15 pouces commercialisés à partir de 2017

- [MacBook Pro](https://support.apple.com/HT201300)

- [MacBook Pro](https://support.apple.com/HT201300) 13 pouces avec puce Apple commercialisés à partir de 2020

- [MacBook Pro](https://support.apple.com/HT201300) 13 pouces avec quatre ports Thunderbolt 3 commercialisés en 2020

- [MacBook Air](https://support.apple.com/HT201862) commercialisés à partir de 2020

- [iMac](https://support.apple.com/HT201634) avec écran Retina commercialisés à partir de 2017

- iMac Pro

- [Mac mini](https://support.apple.com/HT201894) commercialisés à partir de 2018

- [Mac Studio](https://support.apple.com/HT213073) commercialisés à partir de 2022

- [Mac Pro](https://support.apple.com/HT202888) commercialisés à partir de 2019

- [iPad Pro](https://support.apple.com/HT201471) avec USB-C

- [iPad Air (5e génération)](https://support.apple.com/HT201471)

3 840 x 2 160 à 30 Hz avec les appareils suivants :

- [MacBook Pro](https://support.apple.com/HT201300)

- [Modèles de MacBook](https://support.apple.com/HT201608) commercialisés à partir de 2015

- [iMac](https://support.apple.com/HT201634) commercialisés à partir de 2017

- [iPad mini (6e génération)](https://support.apple.com/HT201471)

- [iPad Air (4e génération)](https://support.apple.com/HT201471)

Jusqu’à 1080p à 60 Hz

Le modèle A1621 prend en charge ces résolutions et fréquences de rafraîchissement lorsqu’il est utilisé avec macOS Sierra 10.12 (ou version ultérieure) ou avec iOS 12 (ou version ultérieure) :

- 3 840 x 2 160 à 30 Hz

- Jusqu’à 1080p à 60 Hz

Les vidéos de votre Mac ou iPad doivent apparaître dans les 10 secondes après avoir connecté votre écran, votre téléviseur ou votre projecteur.

## Identifier votre adaptateur

- Le numéro de modèle est imprimé sur l’emballage et sur le côté de l’adaptateur, près des ports.

- Lorsque l’adaptateur est connecté à un Mac, vous pouvez également consulter la section USB dans [Informations système](https://support.apple.com/HT203001) . L’identifiant du produit pour le modèle A2119 est 0x1463. Pour le modèle A1621, l’identifiant est 0x1460.

## Informations supplémentaires

Si vous rencontrez des problèmes avec cet adaptateur, débranchez-le. Vérifiez que vous avez branché correctement tous les câbles sur l’adaptateur avant de le connecter à votre Mac ou iPad.

[Apprenez à connecter un écran à votre Mac](https://support.apple.com/HT202351) .
