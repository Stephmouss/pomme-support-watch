# Utiliser Utilitaire de disque pour effacer un Mac avec puce Apple

Utilisez Utilitaire de disque pour effacer (formater) le disque de démarrage intégré de votre Mac. Vous pouvez ensuite réinstaller macOS pour permettre à votre Mac de redémarrer à partir de ce disque.

Ces instructions s’appliquent uniquement aux [ordinateurs Mac avec puce Apple](https://support.apple.com/fr-fr/116943) . Si vous ne disposez pas d’un Mac avec puce Apple, suivez les instructions permettant [d’effacer un Mac à processeur Intel](https://support.apple.com/fr-fr/102639) .

## Avant d’effacer votre Mac

- Si possible, [installez les dernières mises à jour de macOS](https://support.apple.com/fr-fr/108382) et [effectuez une sauvegarde](https://support.apple.com/fr-fr/102307) des fichiers que vous souhaitez conserver. L’effacement du contenu de votre Mac supprime définitivement ses fichiers.

- Lorsque vous [réinstallez macOS](https://support.apple.com/fr-fr/102655) après avoir réinitialisé votre Mac, si vous aviez précédemment mis à niveau macOS, vous pouvez vous retrouver avec la version de macOS installée avant cette mise à niveau. Ou si vous avez installé une [version bêta (préversion) de macOS](https://beta.apple.com/) , vous vous retrouvez avec la version précédente de macOS. Vous pourrez réinstaller les mises à jour ou mises à niveau de macOS ultérieurement.

- Si vous effacez le contenu de votre Mac parce que vous en cédez la propriété, [découvrez la procédure à suivre avant de vendre, de céder ou d’échanger votre Mac](https://support.apple.com/fr-fr/102773) .

- Ces étapes entraînent la déconnexion (dissociation) des appareils Bluetooth de votre Mac. Pour suivre ces instructions avec un clavier, une souris ou un trackpad Bluetooth, connectez-les à votre Mac à l’aide d’un câble USB, si possible.

## Démarrez à partir de la fonctionnalité de récupération de macOS

Pour effacer le disque de démarrage de votre Mac avec Utilitaire de disque, vous devez d’abord démarrer à partir de la fonctionnalité Récupération macOS ou à partir d’un autre disque. [Comment démarrer à partir de la fonctionnalité Récupération macOS](https://support.apple.com/102518) .

## Utiliser la fonction d’effacement d’Utilitaire de disque

- Lorsque la liste des utilitaires s’affiche dans Récupération de macOS, sélectionnez Utilitaire de disque, puis cliquez sur Continuer.

[Image: Fenêtre Utilitaires de la fonctionnalité de récupération de macOS.]

- Dans la section Interne de la barre latérale d’Utilitaire de disque, assurez-vous que le volume nommé Macintosh HD s’affiche. [Découvrez comment procéder si « Macintosh HD » ne s’affiche pas.](https://support.apple.com/fr-fr/102506#nodisk)

- Si vous avez précédemment ajouté un volume interne autre que Macintosh HD à votre disque de démarrage à l’aide d’Utilitaire de disque, sélectionnez-le dans la barre latérale, puis supprimez-le en cliquant sur le bouton de suppression de volume (-) dans la barre d’outils. (Pendant cette étape, ignorez les volumes internes nommés Macintosh HD ou Macintosh HD - Data, ainsi que tous les volumes des sections Externe et Images disque de la barre latérale.)

- Sélectionnez à présent Macintosh HD dans la barre latérale.

- Cliquez sur le bouton Effacer dans la barre d’outils, puis indiquez un nom et un format :

[Image: Aucun texte de remplacement pour l’image]

- Nom : Macintosh HD

- Format : APFS

- Cliquez sur Effacer. ou, s’il est disponible, sur le bouton Effacer le groupe de volumes.

[Image: Invite affichée dans Utilitaire de disque pour effacer un groupe de volumes.]

- Si un message vous le demande, saisissez les informations de votre compte Apple. [Vous avez oublié votre compte Apple ?](https://support.apple.com/fr-fr/102627)

- Lorsqu’un mesage vous invite à confirmer que vous souhaitez effacer ce Mac, cliquez sur Effacer ce Mac et redémarrer.

- Lorsque votre Mac redémarre, suivez les instructions à l’écran pour choisir votre langue.

- Votre Mac tente alors de s’activer, ce qui nécessite une connexion Internet. Choisissez un réseau Wi-Fi dans le menu Wi-Fi de la barre des menus ou branchez un câble réseau.

[Image: Aucun texte de remplacement pour l’image]

- Une fois votre Mac activé, cliquez sur Accéder aux utilitaires de récupération.

- Si vous souhaitez redémarrer à partir du disque que vous venez d’effacer, sélectionnez Réinstaller macOS dans la fenêtre des utilitaires, puis cliquez sur Continuer et suivez les instructions à l’écran. [En savoir plus sur la réinstallation de macOS](https://support.apple.com/fr-fr/102655) .

- Si vous avez effectué une sauvegarde Time Machine de votre Mac, vous pouvez [restaurer vos données à partir de la sauvegarde](https://support.apple.com/fr-fr/102551) après l’installation de macOS.

## Si le volume Macintosh HD n’apparaît pas dans Utilitaire de disque

- Votre disque de démarrage intégré doit être le premier élément répertorié dans la barre latérale d’Utilitaire de disque. Il porte le nom « Macintosh HD », sauf si vous l’avez modifié. S’il n’apparaît pas dans la barre latérale, choisissez Éteindre dans le menu Apple , puis débranchez tous les périphériques non essentiels de votre Mac et réessayez.

- Si votre disque ne s’affiche toujours pas dans Utilitaire de disque, ou si Utilitaire de disque signale un échec de l’effacement, une réparation de votre Mac est peut-être nécessaire.
