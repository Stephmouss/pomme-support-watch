# Si vous ne parvenez pas à installer du contenu supplémentaire pour Logic Pro pour Mac et MainStage

Si vous ne parvenez pas à installer la bibliothèque de sons complète de Logic Pro ou de MainStage, essayez d’installer des paquets de contenu individuels.

La bibliothèque de sons complète incluse avec Logic Pro et MainStage, qui comprend tous les contenus supplémentaires tels que les boucles Apple Loops et les ensembles de batterie, nécessite environ 72 Go d’espace de stockage disponible sur votre Mac. Si vous avez choisi de télécharger tous les sons supplémentaires et que vous ne parvenez pas à télécharger autant de contenus à la fois, vous pouvez installer ces contenus dans des paquets plus petits :

- Pour savoir combien d’espace de stockage disponible vous avez sur votre Mac, choisissez le menu Apple  > À propos de ce Mac, puis cliquez sur Stockage.

- Dans Logic Pro ou MainStage, choisissez Logic Pro (ou MainStage) > Bibliothèque de sons > Ouvrir le gestionnaire de bibliothèque de sons.

- Dans le gestionnaire de bibliothèque de sons, cochez la case correspondant au package de contenu que vous souhaitez télécharger, puis cliquez sur Installer.
