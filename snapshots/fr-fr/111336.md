# Utiliser un périphérique de stockage externe comme disque de démarrage du Mac

Si vous possédez un périphérique de stockage externe, tel qu’un lecteur USB ou Thunderbolt, vous pouvez installer macOS sur ce périphérique, puis l’utiliser comme disque de démarrage du Mac.

- [Avant de commencer](https://support.apple.com/fr-fr/111336#before-you-begin)

- [Connecter le périphérique de stockage à votre Mac](https://support.apple.com/fr-fr/111336#connect)

- [Vérifier le format du périphérique de stockage](https://support.apple.com/fr-fr/111336#erase)

- [Installer macOS sur le périphérique de stockage](https://support.apple.com/fr-fr/111336#install)

- [Autoriser le démarrage à partir de supports externes](https://support.apple.com/fr-fr/111336#allow)

- [Sélectionner le périphérique de stockage comme disque de démarrage](https://support.apple.com/fr-fr/111336#setstartup)

- [Maintenir macOS à jour sur le périphérique de stockage](https://support.apple.com/fr-fr/111336#update)

## Avant de commencer

- Sur un [Mac doté de la puce Apple](https://support.apple.com/fr-fr/116943) , le démarrage à partir d’un périphérique de stockage externe nécessite un disque de démarrage interne fonctionnel. Si votre disque de démarrage interne rencontre une défaillance matérielle, vous ne pouvez pas utiliser un disque de démarrage externe à la place.

- Si la version majeure de macOS installée sur votre disque de démarrage interne est différente de celle de votre disque de démarrage externe, sachez qu’une version plus récente de macOS sur l’un des disques peut installer des modifications conçues pour préserver la sécurité de votre Mac, et que ces modifications peuvent impacter la capacité de votre ordinateur à utiliser une version de macOS nettement antérieure sur l’autre disque.

## Connectez le périphérique de stockage à votre Mac

Assurez-vous que votre périphérique de stockage est branché sur le port approprié de votre Mac.

- Si vous utilisez un [Mac doté de la puce Apple](https://support.apple.com/fr-fr/116943) , branchez votre périphérique de stockage sur n’importe quel port compatible, à l’exception du port DFU. [Découvrez comment identifier le port DFU](https://support.apple.com/fr-fr/120694) . Une fois l’installation de macOS terminée, vous pouvez connecter votre périphérique de stockage à n’importe quel port compatible, y compris le port DFU.

- Si vous utilisez un autre Mac, branchez votre périphérique de stockage sur n’importe quel port compatible.

## Vérifier le format du périphérique de stockage

Un disque de démarrage du Mac nécessite l’un de ces formats de système de fichiers :

- Le format APFS est recommandé, en particulier si votre périphérique de stockage est un disque SSD (solid-state drive).

- Le format Mac OS étendu (journalisé), également appelé HFS Plus, est également acceptable pour les disques durs traditionnels, et il est requis pour macOS Sierra 10.12 ou une version antérieure.

Vous pouvez vous servir d’Utilitaire de disque pour sélectionner votre périphérique de stockage et voir le format qu’il utilise. Vous pouvez également [utiliser Utilitaire de disque pour l’effacer](https://support.apple.com/guide/disk-utility/dskutl14079/mac) dans l’un ou l’autre de ces formats.

## Installer macOS sur le périphérique de stockage

Cette installation de macOS sera propre à votre modèle de Mac. Elle ne permettra pas de démarrer d’autres modèles de Mac.

- Assurez-vous que le périphérique de stockage est [branché sur le port approprié](https://support.apple.com/fr-fr/111336#connect) de votre Mac.

- [Téléchargez macOS](https://support.apple.com/fr-fr/102662) . Si vous ne pouvez pas le faire parce que votre Mac ne peut pas démarrer à partir de son disque de démarrage interne, vous pouvez [installer macOS depuis Récupération macOS](https://support.apple.com/fr-fr/102655) ou depuis un autre Mac du même modèle à la place.

- Lorsque le programme d’installation vous demande de choisir l’emplacement d’installation, sélectionnez le périphérique de stockage externe avant de continuer. Il se peut que vous deviez d’abord cliquer sur Afficher tous les disques.

## Autoriser le démarrage à partir de supports externes

Si vous utilisez un [Mac doté de la puce de sécurité Apple T2](https://support.apple.com/fr-fr/103265) , utilisez l’Utilitaire Sécurité au démarrage pour autoriser votre Mac à démarrer à partir d’un support externe ou amovible. [Apprenez à vous servir de l’utilitaire Sécurité au démarrage](https://support.apple.com/fr-fr/102522) .

## Sélectionner le périphérique de stockage comme disque de démarrage

Après avoir installé macOS sur votre périphérique de stockage, vous pouvez [sélectionner ce périphérique de stockage comme disque de démarrage](https://support.apple.com/guide/mac-help/mchlp1034/mac) . Votre Mac peut ensuite démarrer à partir de ce disque au lieu de son disque de démarrage intégré.

## Maintenir macOS à jour sur le périphérique de stockage

Lorsque des mises à jour logicielles pour macOS sont disponibles :

- Assurez-vous que votre disque de démarrage externe est [branché sur le port approprié](https://support.apple.com/fr-fr/111336#connect) de votre Mac.

- Démarrez à partir de votre disque de démarrage externe plutôt que de votre disque de démarrage interne.

- [Utilisez la fonctionnalité Mise à jour de logiciels pour mettre à jour macOS](https://support.apple.com/fr-fr/108382) sur votre périphérique de stockage externe.

[Les améliorations de la sécurité en arrière-plan](https://support.apple.com/fr-fr/102657) sont disponibles uniquement lorsque votre Mac est démarré à partir de son stockage interne. Lorsque vous le démarrez à partir d’un périphérique de stockage externe, il reçoit ces améliorations dans le cadre d’une mise à jour logicielle ultérieure.
