# Sauvegarder votre iPhone ou iPad à l’aide de votre Mac

Une fois que vous avez sauvegardé votre iPhone ou votre iPad, vous disposez d’une copie de vos informations, que vous pourrez utiliser si jamais vous remplacez, perdez ou endommagez votre appareil.

[Effectuer une sauvegarde avec le Finder (macOS Catalina 10.15 ou version ultérieure)](https://support.apple.com/fr-fr/108796#with-the-finder)

[Effectuer une sauvegarde avec iTunes (macOS Mojave ou version antérieure)](https://support.apple.com/fr-fr/108796#with-itunes)

## Effectuer une sauvegarde avec le Finder (macOS Catalina 10.15 ou version ultérieure)

- Connectez votre iPhone ou iPad à votre Mac à l’aide d’un câble.

- Si un message vous demande si vous souhaitez [autoriser la connexion de l’accessoire](https://support.apple.com/fr-fr/102282) , cliquez sur Autoriser.

- Ouvrez le Finder.

- Dans la barre latérale du Finder, sélectionnez votre iPhone ou iPad. [Votre appareil n’apparaît pas ?](https://support.apple.com/fr-fr/108643)

- Si un message vous demande si vous souhaitez [faire confiance à cet ordinateur](https://support.apple.com/fr-fr/109054) , cliquez sur Se fier.

- Touchez Se fier sur votre iPhone ou iPad.

- Si un message vous y invite, saisissez le code d’accès de votre iPhone ou iPad. [Vous avez oublié votre code d’accès ?](https://support.apple.com/fr-fr/118430)

- Si vous souhaitez sauvegarder les données des apps Santé et Activité présentes sur votre appareil ou votre Apple Watch, sélectionnez « Chiffrer la sauvegarde locale » et créez un mot de passe. Vous ne pourrez pas récupérer votre sauvegarde sans ce mot de passe.

- Saisissez à nouveau le mot de passe pour le valider.

- Cliquez sur Définir le mot de passe.

- Cliquez sur Sauvegarder maintenant.

[Image: iPhone sélectionné dans la barre latérale d’une fenêtre du Finder sur un Mac, affichant ses options de sauvegarde et le bouton Sauvegarder maintenant pour lancer une sauvegarde.]

Votre iPhone ou iPad est en cours de sauvegarde.

Le statut de votre sauvegarde est mis à jour jusqu’à ce qu’elle soit terminée.

Une fois la sauvegarde effectuée, la date et l’heure de votre dernière sauvegarde apparaissent.

[Image: Fenêtre du Finder affichant les réglages et le statut de sauvegarde d’un iPhone, notamment la date et l’heure de la dernière sauvegarde.]

## Effectuer une sauvegarde avec iTunes (macOS Mojave ou version antérieure)

iTunes sauvegarde automatiquement les données de votre appareil lorsque vous le connectez à votre ordinateur. Mais vous pouvez également effectuer à tout moment une sauvegarde manuelle de votre appareil :

- Connectez votre iPhone ou iPad à votre Mac.

- Si un message vous demande si vous souhaitez autoriser la connexion de l’accessoire, cliquez sur Autoriser.

- Ouvrez iTunes.

- Sélectionnez votre appareil dans l’angle supérieur droit de la fenêtre iTunes. [Votre appareil n’apparaît pas ?](https://support.apple.com/fr-fr/108643)

- Si un message vous demande si vous souhaitez [faire confiance à cet ordinateur](https://support.apple.com/fr-fr/109054) , cliquez sur Se fier.

- Sur votre iPhone ou iPad, touchez Se fier.

- Si un message vous y invite, saisissez le code d’accès de votre iPhone ou iPad. [Vous avez oublié votre code d’accès ?](https://support.apple.com/fr-fr/118430)

- Si vous souhaitez sauvegarder les données des apps Santé et Activité présentes sur votre appareil ou votre Apple Watch, sélectionnez « Chiffrer la sauvegarde locale » et créez un mot de passe. Vous ne pourrez pas récupérer votre sauvegarde sans ce mot de passe.

- Saisissez à nouveau le mot de passe pour le valider.

- Cliquez sur Définir le mot de passe.

- Cliquez sur Sauvegarder maintenant.

Votre appareil est en cours de sauvegarde.

Le statut de votre sauvegarde est mis à jour jusqu’à ce qu’elle soit terminée.

Une fois la sauvegarde effectuée, la date et l’heure de votre dernière sauvegarde apparaissent.
