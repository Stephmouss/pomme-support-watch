# Si les vidéos en mode Cinématique de votre iPhone n’apparaissent pas lors de l’importation sur votre Mac ou ordinateur Windows

Si les vidéos récentes de votre iPhone n’apparaissent pas dans Photos ou Transfert d’images sur votre Mac ou sur votre ordinateur Windows, vous devrez peut-être terminer leur traitement sur votre iPhone.

Lorsque vous [enregistrez une vidéo en mode Cinématique](https://support.apple.com/guide/iphone/record-videos-in-cinematic-mode-ipha0706e2bc/18.0/ios/18.0) , votre iPhone lui applique automatiquement un traitement. Si votre iPhone n’a pas encore traité certaines de vos vidéos en mode Cinématique, celles-ci n’apparaissent pas dans les fenêtres d’importation lorsque vous connectez votre iPhone à votre Mac ou ordinateur Windows.

Procédez comme suit pour finaliser le traitement des vidéos sur votre iPhone :

- Si votre iPhone est connecté à votre Mac ou à votre ordinateur Windows, déconnectez-le.

- Ouvrez Photos sur votre iPhone, puis touchez Collections.

- Faites défiler l’écran vers le bas et touchez « Types de média », puis Cinématiques.

- Touchez « Traiter maintenant » au bas de l’album.

- Une fois le traitement terminé, connectez votre iPhone à votre Mac ou ordinateur Windows et terminez le processus d’importation.

- Si vous utilisez Photos iCloud, vous pouvez également attendre que vos vidéos soient chargées dans Photos iCloud pour y accéder sur d’autres appareils.
