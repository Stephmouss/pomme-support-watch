# Passer à un type d’abonnement différent

Modifiez le type de votre abonnement Apple pour passer, par exemple, à un abonnement mensuel, annuel ou étudiant.

## Modifier votre abonnement

## Modifier votre abonnement sur le web

- Accédez à [account.apple.com](https://account.apple.com) .

- Suivez les instructions qui s’affichent à l’écran. Vous devrez vous connecter à l’aide de votre compte Apple.

Vous pouvez également [annuler votre abonnement](https://support.apple.com/fr-fr/118428) . Si votre nouvel abonnement inclut la fonctionnalité de partage familial, découvrez comment [ajouter un membre de votre famille à votre abonnement](https://support.apple.com/fr-fr/108107) .

## Modifier votre abonnement sur votre iPhone, iPad ou Apple Vision Pro

- Ouvrez l’app Réglages.

- Touchez votre nom, puis Abonnements.

- Touchez l’abonnement que vous souhaitez modifier.

- Touchez Afficher tous les forfaits, puis suivez les instructions à l’écran pour finaliser l’achat.

[Image: iPhone 15 Pro présentant l’écran Abonnements. Pour voir les différents abonnements disponibles, touchez Voir tous les abonnements.]

Vous pouvez également [annuler votre abonnement](https://support.apple.com/fr-fr/118428) . Si votre nouvel abonnement inclut la fonctionnalité de partage familial, découvrez comment [ajouter un membre de votre famille à votre abonnement](https://support.apple.com/fr-fr/108107) .

## Modifier votre abonnement sur votre Mac

- Ouvrez l’app App Store.

- Cliquez sur votre nom dans la barre latérale. Si votre nom n’apparaît pas, cliquez sur Se connecter.

- Cliquez sur Réglages du compte. Vous pouvez être invité à vous connecter.

- Faites défiler jusqu’à la section Abonnements, puis cliquez sur Gérer.

[Image: Écran macOS présentant les réglages de gestion des abonnements dans l’App Store. Pour gérer vos abonnements, cliquez sur Gérer.]

- Cliquez sur l’abonnement que vous souhaitez modifier.

- Cliquez sur Afficher tous les forfaits. Suivez les instructions à l’écran pour finaliser l’achat.

Vous pouvez également [annuler votre abonnement](https://support.apple.com/fr-fr/118428) . Si votre nouvel abonnement inclut la fonctionnalité de partage familial, découvrez comment [ajouter un membre de votre famille à votre abonnement](https://support.apple.com/fr-fr/108107) .

## Modifier votre abonnement sur un PC Windows

- Ouvrez l’app Apple Music ou l’app Apple TV.

- Cliquez sur votre nom en bas de la barre latérale, puis choisissez Voir mon compte. Vous devrez peut-être d’abord vous connecter à votre compte Apple.

- Faites défiler jusqu’à la section Abonnements, puis cliquez sur Gérer.

[Image: Système d’exploitation Windows présentant l’écran Réglages de l’app Apple Music. Pour gérer vos abonnements, cliquez sur Gérer.]

- À côté de l’abonnement que vous souhaitez modifier, cliquez sur Modifier.

- Choisissez une autre option d’abonnement.

Vous pouvez également [annuler votre abonnement](https://support.apple.com/fr-fr/118428) . Si votre nouvel abonnement inclut la fonctionnalité de partage familial, découvrez comment [ajouter un membre de votre famille à votre abonnement](https://support.apple.com/fr-fr/108107) .
