# À propos du mode Isolement

Le mode Isolement aide à protéger les appareils contre les cyberattaques extrêmement rares et très sophistiquées.

## Qu’est-ce que le mode Isolement ?

Le mode Isolement est une protection extrême facultative destinée à de rares personnes susceptibles d’être personnellement ciblées (en raison de leur identité ou de leurs activités) par certaines des menaces numériques les plus sophistiquées. La plupart des personnes ne sont jamais visées par ce type d’attaque.

Lorsque le mode Isolement est activé, votre appareil ne fonctionne pas comme d’habitude. Afin de réduire la surface d’attaque pouvant être exploitée par des logiciels espions mercenaires très ciblés, l’accès à certaines apps, à certains sites web et à certaines fonctionnalités est strictement limité pour des raisons de sécurité. Il est alors possible que certains types d’utilisations ne soient pas du tout possibles.

Le mode Isolement est disponible pour iOS 16, iPadOS 16, watchOS 10 et macOS Ventura ou les versions ultérieures de ces appareils. Des protections supplémentaires sont disponibles à partir d’iOS 17, d’iPadOS 17, de watchOS 10 et de macOS Sonoma.

Pour une protection complète, mettez à jour vos appareils vers le dernier logiciel avant d’activer le mode Isolement.

## Comment le mode Isolement protège votre appareil

Lorsque le mode Isolement est activé, certaines apps et fonctionnalités fonctionnent différemment, y compris les suivantes :

- Messages : la plupart des types de pièces jointes sont bloqués, en dehors de certains fichiers image, vidéo et audio. Certaines fonctionnalités telles que les liens et les aperçus de liens ne sont pas disponibles.

- Navigation sur le Web : certaines technologies web complexes sont bloquées. Il se peut donc que certains sites web se chargent plus lentement ou ne fonctionnent pas correctement. De plus, les polices web risquent de ne pas s’afficher, et les images peuvent être remplacées par une icône d’image manquante.

- FaceTime : les appels FaceTime entrants sont bloqués, sauf si vous avez déjà appelé cette personne ou ce contact au cours des 30 derniers jours. Des fonctionnalités telles que SharePlay et Live Photos ne sont pas disponibles.

- Services Apple : les invitations entrantes pour les services Apple (par exemple, pour gérer un domicile dans l’app Maison) sont bloquées, sauf si vous avez déjà invité cette personne. La fonctionnalité Concentration et tout statut associé ne fonctionneront pas comme prévu. Game Center est également désactivé.

- Photos : lorsque vous partagez des photos, les informations de localisation sont exclues. Les albums partagés sont supprimés de l’app Photos, et les nouvelles invitations pour des albums partagés sont bloquées. Vous pouvez toujours afficher ces albums partagés sur d’autres appareils où le mode Isolement n’est pas activé.

- Connexions de l’appareil : pour connecter votre iPhone ou iPad à un accessoire ou à un autre ordinateur, l’appareil doit être déverrouillé. Pour connecter votre [ordinateur portable Mac avec puce Apple](https://support.apple.com/fr-fr/116943) à un accessoire, votre Mac doit être déverrouillé et vous devez fournir une approbation explicite.

- Connectivité sans fil : votre appareil ne se connecte pas automatiquement aux réseaux Wi-Fi non sécurisés et se déconnecte d’un réseau Wi-Fi non sécurisé lorsque vous activez le mode Isolement. La compatibilité mobile 2G et 3G est désactivée pour l’iPhone et l’iPad.

- Profils de configuration : aucun profil de configuration ne peut être installé, et l’appareil ne peut pas être inscrit à la gestion des appareils mobiles ni à la supervision des appareils lorsqu’il est en mode Isolement.

Les appels téléphoniques et les messages en texte brut continuent de fonctionner pendant que le mode Isolement est activé, même si l’Apple Watch jumelée n’émettra pas la sonnerie des appels entrants. Les fonctionnalités d’urgence telles que les appels d’urgence ne sont pas concernées.

## Comment activer le Mode Isolement

Pour une protection complète, vous devez mettre à jour tous vos appareils vers le dernier logiciel et activer le mode Isolement pour tous vos appareils.

- Le mode Isolement doit être activé séparément sur votre iPhone, iPad et Mac.

- Lorsque vous activez le mode Isolement sur votre iPhone, il l’est également sur votre Apple Watch.

- Lorsque vous activez le mode Isolement sur l’un de vos appareils, vous êtes invité à l’activer sur vos autres appareils Apple compatibles.

Lorsque le mode Isolement est activé, vous pouvez recevoir des notifications lorsqu’une app ou une fonctionnalité est limitée. Une bannière dans Safari indique que le mode Isolement est activé.

### Comment activer le mode Isolement sur l’iPhone ou l’iPad

- Ouvrez l’app Réglages.

- Touchez Confidentialité et sécurité.

- Faites défiler vers le bas, touchez Mode Isolement, puis Activer le mode Isolement.

[Image: Mode Isolement dans les réglages Confidentialité et sécurité sur l’iPhone.]

- Touchez Activer le mode Isolement.

- Touchez Activer et redémarrer, puis saisissez le code de votre appareil.

### Comment activer le mode Isolement sur Mac

- Dans le menu Apple , choisissez Réglages Système.

- Dans la barre latérale, cliquez sur Confidentialité et sécurité.

- Faites défiler vers le bas, cliquez sur Mode Isolement, puis sur Activer.

- Cliquez sur Activer le mode Isolement. Vous pouvez être invité à saisir le mot de passe de l’utilisateur.

- Cliquez sur Activer et redémarrer.

## Comment exclure des apps ou des sites web du mode Isolement

Lorsque votre appareil est en mode Isolement, vous pouvez empêcher que les restrictions WebKit affectent et limitent une app ou un site web dans Safari en l’excluant. Excluez uniquement des apps ou sites web de confiance et seulement si nécessaire.

### Sur un iPhone ou un iPad

Pour exclure un site web lors de la navigation : touchez le bouton Menu de la page , touchez le bouton Plus pour ouvrir le menu de la page, puis désactivez le mode Isolement pour ce site web.

[Image: null]

[Image: Pour exclure un site web des protections du mode Isolement, désactivez le mode Isolement dans les Réglages de la page de Safari.]

Pour exclure une app ou modifier vos sites web exclus :

- Ouvrez l’app Réglages.

- Touchez Confidentialité et sécurité.

- Sous Sécurité, touchez Mode Isolement.

- Touchez Configurer la navigation web.

[Image: Pour exclure une app ou modifier vos sites web exclus, touchez Configurer la navigation web.]

Pour exclure une app, désactivez-la dans le menu. Seules les apps que vous avez ouvertes depuis l’activation du mode Isolement et dont les fonctionnalités sont limitées sont affichées dans cette liste.

Pour modifier vos sites web exclus, touchez Sites web Safari exclus, puis Modifier.

### Sur un Mac

Pour exclure un site web lors de la navigation : dans le menu Safari, choisissez Réglages pour [site web]. Décochez ensuite la case Activer le mode Isolement. Pour inclure à nouveau le site web, cochez à nouveau la case.

Pour modifier vos sites web exclus :

- Dans la barre de menus de Safari, choisissez le menu Safari. Choisissez ensuite Réglages.

- Cliquez sur Sites web.

- Dans la barre latérale, faites défiler vers le bas et cliquez sur Mode Isolement.

- Dans le menu à côté d’un site web configuré, activez ou désactivez le mode Isolement.

## Profils de configuration et appareils gérés

Si un appareil est en mode Isolement, aucun nouveau profil de configuration ne peut être installé, et aucune inscription à la gestion des appareils mobiles ni à la supervision des appareils n’est possible. Si une personne souhaite installer un profil de configuration ou de gestion, elle doit désactiver le mode Isolement, installer le profil, puis réactiver le mode Isolement, si nécessaire. Ces restrictions empêchent les attaquants d’essayer d’installer des profils malveillants.

Un appareil reste géré s’il a été inscrit à la gestion des appareils mobiles avant que le mode Isolement ne soit activé. Les administrateurs système peuvent installer et supprimer des profils de configuration sur cet appareil.

Le mode Isolement n’est pas une option configurable par les administrateurs système pour la gestion des appareils mobiles, car il est destiné à un très faible nombre de personnes pouvant être ciblées par des cyberattaques extrêmes.
