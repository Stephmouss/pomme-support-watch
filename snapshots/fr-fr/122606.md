# Mettre à jour Final Cut Pro, Logic Pro, Pixelmator Pro ou d’autres apps pro

Pour mettre à jour une app pro, y compris Motion, Compressor, MainStage et Photomator, vous devez sauvegarder votre app existante, désactiver les mises à jour automatiques, puis mettre à jour l’app.

## Sauvegarder une app pro

- Dans le dossier Applications, cliquez sur l’app pro que vous souhaitez sauvegarder tout en maintenant la touche Contrôle enfoncée, puis choisissez [Lire les informations](https://support.apple.com/guide/mac-help/mchlp1774/mac) . Notez le numéro de version indiqué dans la fenêtre Lire les informations.

- Créez un dossier dans le dossier Applications et renommez-le en utilisant le nom et la version de l’app pro (par exemple, « Final Cut Pro 11 »).

- Sélectionnez l’app pro dans le dossier Applications, choisissez Fichier, puis Compresser [nom de l’app pro]. La compression de l’app peut durer quelques minutes.

- Déplacez le fichier ZIP obtenu dans le dossier que vous avez créé.

- Pour créer une sauvegarde du fichier ZIP, copiez le fichier sur un périphérique de stockage externe.

## Désactiver les mises à jour automatiques

Désactivez les mises à jour automatiques pour les apps pro et macOS afin de pouvoir vérifier la compatibilité des logiciels et du matériel tiers avant de procéder à la mise à jour.

- Sur votre Mac, choisissez le menu Apple , puis cliquez sur Réglages Système. Dans la barre latérale, cliquez sur Général.

- Cliquez sur Mise à jour de logiciels sur la droite.

- Cliquez sur le bouton Informations en regard de Mises à jour automatiques, désactivez les options « Installer les mises à jour de macOS » et « Installer les mises à jour d’applications depuis l’App Store », puis cliquez sur Terminé.

Si vous désactivez les mises à jour automatiques, vous devez mettre à jour manuellement les apps pro et toutes les autres apps que vous avez téléchargées depuis le Mac App Store. Vous devez également [mettre à jour manuellement macOS](https://support.apple.com/fr-fr/108382) .

## Mettre à jour manuellement une app pro

- Si vous utilisez des logiciels tiers (tels que des modules) ou du matériel externe (tel qu’une interface audio) avec votre app pro, [vérifiez auprès de leur développeur ou fabricant](https://support.apple.com/fr-fr/103190) qu’ils sont compatibles avec la dernière version de l’app pro.

- Assurez-vous que vous êtes [connecté(e) à votre Mac avec le compte Apple](https://support.apple.com/111001?device-type=mac) utilisé lors de l’achat de l’app.

- Ouvrez l’App Store.

- Dans la barre latérale, cliquez sur Mises à jour.

- Cliquez sur Mettre à jour à côté de l’app pro, ou cliquez sur Tout mettre à jour pour installer toutes les mises à jour d’app disponibles.

## Si vous ne parvenez pas à mettre à jour une app pro

- Dans l’App Store, si le bouton affiché en regard de l’app indique un prix au lieu de Mettre à jour ou Ouvrir, cela signifie que vous n’êtes pas connecté(e) au bon compte Apple sur votre Mac. Connectez-vous au compte Apple utilisé lors de l’achat de l’app. Si vous avez plusieurs comptes Apple, vous pouvez [transférer vos achats vers un seul compte Apple afin de les regrouper](https://support.apple.com/fr-fr/117267) , vous connecter à ce compte Apple, puis mettre à jour l’app.

- Il est possible que votre version de macOS ne soit pas compatible avec la dernière version de l’app. [Effectuez la mise à jour vers la dernière version de macOS](https://support.apple.com/fr-fr/108382) . Il se peut dans certains cas que votre Mac ne soit pas compatible avec la dernière version de macOS ou de l’app pro que vous souhaitez mettre à jour.

- Si vous avez acheté votre Mac avec l’app Final Cut Pro ou Logic Pro préinstallée, vous devez « adopter » l’app afin de pouvoir obtenir les mises à jour, l’installer sur d’autres appareils personnels et bénéficier d’autres avantages liés à son achat. [Découvrez comment adopter une app pro préinstallée](https://support.apple.com/fr-fr/101869) .

- Si vous ne parvenez toujours pas à mettre à jour une app pro ou si vous rencontrez un problème après une mise à jour, vous pouvez [réinstaller la copie de sauvegarde de l’app pro](https://support.apple.com/fr-fr/122694) pour continuer à travailler sur vos projets.

- Si aucune mise à jour pour une app que vous possédez n’est visible dans la section Mises à jour du Mac App Store alors que vous utilisez le bon compte Apple sur votre Mac, appuyez sur Commande-R pour actualiser la liste.

## Réinstaller une copie de sauvegarde d’une app pro

Vous pouvez réinstaller la copie de sauvegarde d’une app pro si sa mise à jour vous empêche de continuer à travailler.

- Faites glisser la version actuellement installée de l’app pro du dossier Applications vers la corbeille, puis videz la corbeille.

- Accédez à la copie de sauvegarde de l’app pro, puis double-cliquez sur le fichier ZIP pour le décompresser.

- Si nécessaire, faites glisser le fichier décompressé de l’app pro vers le dossier Applications.

- Pour créer une sauvegarde du fichier ZIP, copiez le fichier sur un périphérique de stockage externe.
