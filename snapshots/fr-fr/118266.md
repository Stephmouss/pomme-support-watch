# Si le solde de votre carte de transport ne se met pas à jour dans l’app Cartes d’Apple

Découvrez la marche à suivre si le solde de votre carte de transport ne se met pas à jour dans l’app Cartes d’Apple lorsque vous utilisez Apple Pay.

Commencez par [redémarrer votre iPhone](https://support.apple.com/118259) .

Si votre solde n’est toujours pas actualisé et que vous ne voyez pas les frais dans l’historique de vos transactions :

- Sur votre iPhone, ouvrez l’app Cartes, puis touchez votre carte de transport.

- Touchez le bouton Plus , puis touchez Données de la carte.

[Image: Aucun texte de remplacement pour l’image]

- Si vous voyez l’option, activez le mode Dépannage, puis authentifiez-vous avec Face ID, Touch ID ou votre code.

- Pour désactiver le mode Dépannage, touchez votre carte.

Si le solde ne se met pas à jour lorsque vous créditez votre carte de transport, [consultez les transactions récentes](https://support.apple.com/104954) de la carte de paiement avec laquelle vous avez ajouté l’argent à votre carte de transport. Si des frais apparaissent dans l’historique de vos transactions, il est possible que le solde de votre carte de transport soit correct, même si un montant différent s’affiche dans l’app Cartes.

Si cette procédure ne fonctionne pas, contactez l’émetteur de votre carte de transport.
