# Partager ou exporter votre vidéo iMovie

Partagez votre vidéo iMovie avec votre entourage par e-mail ou SMS, publiez-la sur les médias sociaux ou d’autres sites web, ou exportez-la pour la regarder sur d’autres appareils.

[iPhone ou iPad](https://support.apple.com/fr-fr/102371#IOS)

[Mac](https://support.apple.com/fr-fr/102371#Mac)

[Exporter votre vidéo au format MP4](https://support.apple.com/fr-fr/102371#MP4_Mac)

Lorsque vous partagez une vidéo, vous l’envoyez à d’autres personnes dans un format qui leur permet de la visionner sans avoir besoin d’iMovie. Lorsque vous exportez un projet iMovie, vous le convertissez dans un format qui permet de rendre votre vidéo compatible avec divers appareils, plates-formes ou sites web.

## Partager ou exporter votre vidéo sur iPhone ou iPad

Partagez votre vidéo depuis votre iPhone ou iPad par e-mail ou SMS, partagez votre projet sur les médias sociaux ou d’autres sites web, ou exportez-le pour le regarder sur un autre appareil.

### Partager votre vidéo par e-mail ou SMS

Vous pouvez envoyer une vidéo terminée à d’autres personnes dans un e-mail avec l’app Mail ou dans un message texte avec l’app Messages.

- Dans le navigateur de projets, touchez le projet iMovie à partager. Si un projet est ouvert pour modification, touchez Terminé dans l’angle supérieur gauche.

- Touchez le bouton Partager , puis touchez l’app Messages ou Mail.

[Image: bouton Partager]

- Complétez le message ou l’e-mail créé, puis touchez Envoyer.

- Si une alerte indiquant que le fichier est trop volumineux pour être envoyé s’affiche, vous pouvez réduire la taille du fichier vidéo ou l’envoyer d’une autre manière :

- Abandonnez votre message ou e-mail en cours, puis touchez de nouveau le bouton Partager.

- Touchez Options, puis choisissez une résolution inférieure. Le fait de choisir une résolution inférieure peut affecter la qualité de votre vidéo.

- Si vous souhaitez conserver la résolution la plus élevée possible pour votre vidéo, vous pouvez [envoyer un lien iCloud vers la vidéo ou utiliser Mail Drop](https://support.apple.com/guide/iphone/iph1c81f302d/ios) .

Si vous n’utilisez pas l’app Mail du Mac, choisissez Enregistrer dans Fichiers lorsque vous [exportez votre vidéo](https://support.apple.com/fr-fr/102371#Export_iOS) . Vous pouvez ensuite joindre la vidéo à un e-mail dans l’app de votre choix.

### Partager votre vidéo sur le Web

Pour partager votre vidéo sur les médias sociaux ou d’autres sites web, enregistrez-la dans votre photothèque, puis chargez-la.

- Dans le navigateur de projets, touchez le projet iMovie à partager, puis touchez le bouton Partager .

[Image: bouton Partager]

- Si vous souhaitez modifier la résolution de votre vidéo, touchez Options sous le titre de la vidéo, puis choisissez une résolution :

- La résolution 1080p offre la meilleure qualité vidéo pour la plupart des sites de médias sociaux.

- Les résolutions inférieures, comme 720p HD, génèrent des fichiers plus petits qui se chargent plus rapidement si la vitesse de votre connexion Internet est lente.

- Touchez Enregistrer la vidéo pour enregistrer la vidéo dans la photothèque de votre appareil.

- Effectuez l’une des opérations suivantes en fonction de l’emplacement où vous souhaitez charger votre vidéo :

- Ouvrez l’app Photos, sélectionnez la vidéo exportée dans votre photothèque, puis touchez Partager. S’il existe une app pour le service sur lequel vous souhaitez charger la vidéo, faites défiler la liste des apps en effectuant un balayage, puis sélectionnez l’app de votre choix.

- Ouvrez l’app du service que vous souhaitez utiliser, puis chargez la vidéo depuis cette dernière. Si l’app demande l’accès à votre photothèque, touchez une option.

- Accédez au site web sur lequel vous souhaitez charger la vidéo, puis chargez-la à partir du site web.

### Exporter votre vidéo pour la regarder sur un autre appareil

- Dans le navigateur de projets, touchez la vidéo à partager. Si un projet est ouvert pour modification, touchez Terminé dans l’angle supérieur gauche.

- Touchez le bouton Partager .

[Image: null]

- Pour modifier la résolution ou le format de votre vidéo, touchez Options, puis Terminé lorsque vous avez défini vos options.

- Choisissez l’emplacement dans lequel vous souhaitez exporter votre film :

- Pour utiliser AirDrop, touchez AirDrop, puis touchez votre photo de profil en haut de l’écran.

- Pour exporter la vidéo vers votre photothèque, touchez Enregistrer la vidéo. Si la fonctionnalité [Photos iCloud](https://support.apple.com/HT204264) est activée, la vidéo sera accessible sur tous vos appareils Apple connectés au même compte iCloud.

- Pour enregistrer votre vidéo sur iCloud Drive, dans un dossier de votre appareil ou dans un autre [service de stockage tiers activé dans l’app Fichiers](https://support.apple.com/HT206481#thirdparty) , touchez Enregistrer dans Fichiers, choisissez un emplacement, puis touchez Enregistrer.

Vous pouvez [exporter votre vidéo iMovie au format MP4](https://support.apple.com/fr-fr/102371#MP4_Mac) afin de pouvoir la charger sur des sites web ou l’ouvrir dans d’autres apps qui ne prennent pas en charge les fichiers MOV.

## Partager ou exporter votre vidéo iMovie sur Mac

Vous pouvez envoyer votre vidéo par e-mail directement depuis iMovie pour Mac. Si vous souhaitez ajouter le fichier vidéo à votre photothèque, enregistrez-le à un autre emplacement sur votre Mac ou dans iCloud, ou enregistrez-le sur un service de stockage dans le cloud tiers, puis enregistrez la vidéo en tant que fichier vidéo.

### Envoyer votre vidéo à partir d’iMovie

Si vous souhaitez envoyer la vidéo par e-mail à l’aide d’un autre client de messagerie ou d’un autre service, vous devez [l’enregistrer en tant que fichier](https://support.apple.com/fr-fr/102371#Save_as_file) .

- Dans le navigateur de projets, sélectionnez le projet iMovie que vous souhaitez envoyer, cliquez sur le bouton Plus , puis choisissez Partager le projet. Si un projet est ouvert pour modification, cliquez sur le bouton Partager .

[Image: null]

- Cliquez sur E-mail.

- Cliquez sur Partager. Si la vidéo dépasse la limite recommandée (généralement 10 Mo), un avertissement s’affiche sur l’écran de partage. Cliquez sur le menu local Résolution, puis choisissez une résolution qui réduit le fichier vidéo à une taille inférieure à 10 Mo (ou à la limite de votre service de messagerie).

[Image: Écran Partage par e-mail dans iMovie sur Mac affichant un avertissement indiquant que la vidéo est trop volumineuse pour être envoyée par e-mail et suggérant de réduire la résolution ou de partager la vidéo en tant que fichier.]

- Cliquez sur Partager. Une fois qu’iMovie a exporté la vidéo vers l’e-mail, une notification s’affiche.

- Complétez l’e-mail créé, puis cliquez sur Envoyer.

### Enregistrer la vidéo en tant que fichier

- Dans le navigateur de projets, sélectionnez le projet iMovie que vous souhaitez envoyer, cliquez sur le bouton Plus , puis choisissez Partager le projet. Si un projet est ouvert pour modification, cliquez sur le bouton Partager .

[Image: null]

- Cliquez sur Fichier.

- Cliquez sur le menu local Résolution et choisissez une taille pour votre vidéo. La résolution par défaut est fondée sur la résolution du contenu multimédia inclus dans votre vidéo, mais vous pouvez choisir d’autres résolutions en fonction de vos besoins :

- Pour produire un fichier plus petit qui charge plus rapidement sur le Web, choisissez une résolution inférieure.

- Pour produire un fichier plus volumineux (adapté à un affichage sur Mac ou sur un téléviseur haute définition via l’Apple TV, par exemple), choisissez une résolution plus élevée.

- Choisissez un emplacement pour enregistrer le fichier vidéo, puis cliquez sur Enregistrer.

- Pour ajouter le film à votre photothèque, faites glisser le fichier exporté dans l’app Photos. Si la fonctionnalité [Photos iCloud](https://support.apple.com/HT204264) est activée, la vidéo sera accessible sur tous vos appareils Apple connectés au même compte Apple.

### Partager votre film sur le Web

iMovie propose des réglages optimisés pour un partage sur des sites web comme YouTube et Facebook.

- Une fois votre projet ouvert dans iMovie, cliquez sur le bouton Partager .

[Image: bouton Partager]

- Cliquez sur YouTube et Facebook.

- Choisissez un emplacement pour enregistrer le fichier vidéo, puis cliquez sur Enregistrer.

- Dans un navigateur web, accédez au site web sur lequel vous souhaitez partager votre vidéo, puis chargez le fichier vidéo.

## Exporter votre vidéo sous forme de fichier MP4

Si vous souhaitez partager votre vidéo avec des appareils, des apps ou des sites web qui ne prennent pas en charge les fichiers MOV, vous pouvez exporter votre projet en tant que fichier MP4 à l’aide d’iMovie sur Mac.

- Pour exporter votre projet iMovie sur votre iPhone ou iPad sous forme de fichier MP4, vous devez d’abord [importer le projet iMovie créé sur iPhone ou iPad dans iMovie sur Mac](https://support.apple.com/guide/imovie/mov6c9c43596/mac) .

- Dans iMovie sur votre Mac, ouvrez votre projet iMovie, cliquez sur le bouton Partager , puis choisissez Exporter le fichier

[Image: null]

- Choisissez l’une des options suivantes dans la fenêtre d’exportation :

- Cliquez sur le menu local Qualité, puis choisissez Moyenne ou Faible.

- Cliquez sur le menu local Résolution, puis choisissez 720 ou 540.

- Afin d’ajuster le temps nécessaire à iMovie pour convertir le fichier, choisissez une option dans le menu local Compresser.

- Cliquez sur Suivant, choisissez un emplacement pour l’exportation du fichier MP4, puis cliquez sur Enregistrer.

## Apporter des modifications à votre vidéo après son partage

Si vous souhaitez apporter des modifications à votre vidéo, ouvrez le projet enregistré dans iMovie, effectuez vos modifications, puis partagez-le à nouveau lorsqu’il est terminé. Si vous souhaitez simplement raccourcir la vidéo ou modifier sa vitesse, vous pouvez [la modifier avec l’app Photos sur votre Mac, votre iPhone, votre iPad ou votre Apple Vision Pro](https://support.apple.com/fr-fr/104968) .
