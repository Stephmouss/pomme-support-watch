# Gérer vos apps avec Se connecter avec Apple

Lorsque vous utilisez le service Se connecter avec Apple, vous pouvez vous connecter à l’aide de votre compte Apple aux apps et aux sites web participants créés par des développeurs tiers. Découvrez comment voir et gérer les apps que vous utilisez avec le service Se connecter avec Apple.

## Examiner les apps que vous utilisez avec le service Se connecter avec Apple

Pour consulter la liste des apps que vous utilisez actuellement avec le service Se connecter avec Apple et gérer vos préférences pour chacune d’elles, accédez aux réglages du compte Apple sur votre appareil ou connectez-vous sur le Web. [Découvrez le service Se connecter avec Apple](https://support.apple.com/fr-fr/102609) .

### Sur votre iPhone ou iPad

- Ouvrez l’app Réglages, puis touchez [votre nom].

- Touchez Se connecter avec Apple.

[Image: Écran de l’iPhone montrant l’emplacement des Réglages pour le service Se connecter avec Apple]

### Sur votre Mac

- Choisissez le menu Pomme , puis cliquez sur Réglages Système.

- Cliquez sur [votre nom].

- Cliquez sur Se connecter avec Apple.

### Sur le Web

- Connectez-vous sur [account.apple.com](https://account.apple.com/) .

- Accédez au service Connexion et sécurité.

- Sélectionnez Se connecter avec Apple.

## Gérer vos réglages Se connecter avec Apple

Dans les réglages de votre compte Apple, vous voyez une liste des apps que vous utilisez avec le service Se connecter avec Apple. Pour voir les informations que vous aviez partagées au départ avec une app en particulier, sélectionnez celle-ci dans la liste. Vous pouvez également choisir de ne plus utiliser le service Se connecter avec Apple avec une app ou un site web.

Pour les comptes que vous avez configurés à l’aide du service Se connecter avec Apple, vous pouvez [partager les mots de passe dans l’app Mots de passe](https://support.apple.com/120758#share) .

Si vous utilisez un compte Apple géré à l’école ou sur le lieu de travail, contactez votre administrateur système pour gérer les apps que vous utilisez avec Se connecter avec Apple au travail et à l’école.

### Cesser d’utiliser le service Se connecter avec Apple avec une app

- Sur votre iPhone, ouvrez l’app Réglages, puis touchez [votre nom].

- Touchez Se connecter avec Apple.

- Sélectionnez l’app ou le développeur, puis touchez Supprimer. Suivez les étapes à l’écran pour confirmer que vous souhaitez arrêter d’utiliser Se connecter avec Apple pour cette app ou ce développeur.

[Image: Écran de l’iPhone montrant le bouton Supprimer pour arrêter d’utiliser Se connecter avec Apple]

### Que se passe-t-il si vous cessez d’utiliser le service Se connecter avec Apple avec une app ?

Lorsque vous cessez d’utiliser votre compte Apple avec une app, vous cessez d’être connecté à l’app sur votre appareil. Lors de la prochaine utilisation de l’app ou visite sur son site web compagnon, vous pouvez soit vous connecter à nouveau via Se connecter avec Apple, soit créer un autre compte.

Si vous décidez d’utiliser de nouveau le service Se connecter avec Apple, vous serez connecté au même compte que vous avez utilisé précédemment. Certaines apps peuvent vous permettre de définir un nouveau mot de passe pour votre compte existant afin que vous puissiez vous connecter à nouveau sans utiliser votre compte Apple.

Si vous supprimez votre compte dans une app où vous utilisez le service Se connecter avec Apple, il se peut que vous receviez un e-mail d’Apple indiquant que l’app a révoqué votre compte Se connecter avec Apple. Si vous souhaitez créer un autre compte avec cette app, vous devez partager votre nom et votre adresse e-mail avec l’app ou [créer un compte à l’aide du service Se connecter avec Apple.](https://support.apple.com/fr-fr/102379)

### Si vous cessez d’utiliser le service Se connecter avec Apple avec un développeur de multiples apps

Certains développeurs peuvent utiliser Se connecter avec Apple pour vous donner un compte pour plusieurs apps. Si c’est le cas et si vous désactivez le transfert des e-mails ou cessez d’utiliser Se connecter avec Apple pour une app, cela s’applique à toutes les apps de ce développeur.

## Gérer vos réglages pour la fonctionnalité Masquer mon adresse e-mail

Si vous décidez de [masquer votre adresse e-mail](https://support.apple.com/fr-fr/105078) pour une app, vous pouvez désactiver le transfert des e-mails vers votre adresse e-mail personnelle pour ne plus recevoir dans votre boîte de réception les messages d’un développeur en particulier. Vous pouvez également remplacer votre adresse de transfert par n’importe quelle adresse enregistrée dans votre compte Apple.

### Désactiver le transfert des e-mails

- Sur votre iPhone, ouvrez l’app Réglages, puis touchez [votre nom].

- Touchez iCloud.

- Faites défiler la page jusqu’à la section Fonctionnalités d’iCloud+, puis touchez Masquer mon adresse e-mail.

- Sélectionnez l’app ou le développeur, puis touchez pour désactiver la fonction Transférer à.

[Image: Écran d’iPhone montrant comment désactiver le transfert des e-mails]

### Modifier votre adresse e-mail de transfert

- Sur votre iPhone, ouvrez l’app Réglages, puis touchez [votre nom].

- Touchez iCloud.

- Faites défiler la page jusqu’à la section Fonctionnalités d’iCloud+, puis touchez Masquer mon adresse e-mail.

- Faites défiler vers le bas, puis touchez Transférer à.

- Sélectionnez l’adresse e-mail associée à votre compte Apple que vous souhaitez utiliser. Cela s’applique aux e-mails de toutes les apps et développeurs utilisant Masquer mon adresse e-mail.
