# Si le message « Erreur d’éjection du disque » s’affiche sur votre Mac Pro (2023)

Si un disque SATA interne se déconnecte de manière inopinée de votre Mac Pro, [effectuez une mise à jour vers macOS Ventura 13.5 ou une version ultérieure](https://support.apple.com/HT201541) .

Certains modèles de disques SATA internes peuvent se déconnecter de manière inopinée de votre ordinateur après la sortie de veille de votre Mac. Ceci peut se produire si votre Mac se met automatiquement en veille ou si vous le mettez manuellement en veille.

Pour résoudre ce problème, [effectuez la mise à jour vers macOS Ventura 13.5 ou version ultérieure](https://support.apple.com/108382) .
