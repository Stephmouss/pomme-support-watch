# S’il vous manque des fichiers dans iCloud Drive

Si vous remarquez que des fichiers ont disparu d’iCloud Drive, vous pouvez récupérer les fichiers supprimés récemment ou rechercher les fichiers manquants sur tous vos appareils.

## Récupérer des fichiers récemment supprimés

Vous pouvez retrouver les fichiers supprimés récemment dans le dossier Suppressions récentes de votre iPhone, iPad ou Apple Vision Pro, ou dans la Corbeille de votre Mac ou PC. Vos fichiers sont supprimés du dossier Suppressions récentes au bout de 30 jours.

### Sur votre iPhone, iPad ou Apple Vision Pro

- Ouvrez l’app Fichiers et touchez l’onglet Explorer.

- Sous Emplacements, touchez Suppressions récentes.

- Touchez le bouton Plus , puis touchez Sélectionner.

- Sélectionnez les fichiers que vous souhaitez conserver et touchez Récupérer. Pour récupérer un seul fichier, vous pouvez également toucher de manière prolongée le fichier, puis toucher Récupérer.

### Sur votre Mac

Recherchez les éléments manquants dans la corbeille:

- Si vous trouvez un fichier, faites-le glisser de la Corbeille vers le bureau ou un autre emplacement.

- Pour renvoyer un fichier supprimé vers son emplacement d’origine, cliquez sur le fichier en maintenant la touche Contrôle enfoncée, puis sélectionnez Remettre.

### Sur votre PC

- Accédez à la corbeille.

- Faites glisser le fichier ou le dossier vers votre bureau ou un autre emplacement. Pour déplacer le fichier vers iCloud Drive, faites-le glisser dans iCloud Drive dans le volet de navigation.

### Sur icloud.com

Recherchez vos fichiers dans Suppressions récentes. Si vous ne trouvez pas vos fichiers dans Suppressions récentes dans iCloud Drive, recherchez-les dans Récupération de données.

#### Récupérer des fichiers à partir de Suppressions récentes

- Rendez-vous sur [icloud.com/iclouddrive](https://www.icloud.com/iclouddrive) .

- Sélectionnez Suppressions récentes dans la barre latérale.

- Sélectionnez les fichiers que vous souhaitez récupérer, puis sélectionnez Récupérer. Ou sélectionnez Tout récupérer.

#### Restaurer des fichiers à partir de Récupération de données

- Rendez-vous sur [icloud.com/recovery](https://www.icloud.com/recovery/) .

- Cliquez sur Restaurer des fichiers.

- Cliquez sur Tout sélectionner ou sélectionnez les fichiers que vous souhaitez restaurer.

- Cliquez sur Restaurer.

Si vous modifiez iCloud Drive pendant la récupération des données, vous risquez d’interrompre le processus de récupération. Cela inclut la consultation d’iCloud Drive dans une autre fenêtre de navigateur et la modification ou la suppression de fichiers iCloud Drive.

## Rechercher dans d’autres emplacements

Vérifiez les services de stockage cloud tiers et les autres emplacements de stockage sur votre iPhone, iPad, Mac ou PC.

### Dans les apps et services tiers

Si vous utilisez un service de stockage cloud tiers, recherchez les fichiers manquants dans l’app ou le service en question. Si vous utilisez un [service de stockage cloud tiers dans le Finder ou l’app Fichiers](https://support.apple.com/fr-fr/102238) , sous Emplacements, vérifiez le dossier de cette app tierce.

### Sur votre iPhone ou iPad

- Ouvrez l’app Fichiers.

- Dans la zone de recherche, saisissez le nom du fichier ou des mots-clés.

### Sur votre Mac

- À l’aide de Spotlight, recherchez les fichiers manquants par nom ou mots-clés.

- Si vous disposez d’une sauvegarde Time Machine, recherchez-y les fichiers manquants.

- Vérifiez le contenu du dossier iCloud Drive (Archive) : ouvrez le Finder, sélectionnez Macintosh HD, cliquez sur Utilisateurs, puis sélectionnez [Nom d’utilisateur]. Si le dossier d’archive existe, la mention « iCloud Drive (Archive) » s’affiche. Si Macintosh HD n’apparaît pas dans le Finder, accédez au Finder, sélectionnez Réglages (ou Préférences), puis cliquez sur Barre latérale. Sous Emplacements, cochez Disques durs.

### Sur votre PC

- Cliquez sur le bouton Démarrer.

- Saisissez le nom du fichier ou les mots-clés qui y sont liés et appuyez sur Entrée.
