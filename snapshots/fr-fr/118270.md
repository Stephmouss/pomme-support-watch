# Obtenir un remboursement pour des achats effectués avec des cartes de crédit ou de débit via Apple Pay

Pour retourner un article et obtenir son remboursement via Apple Pay, vous devrez peut-être fournir des informations supplémentaires.

Les politiques de traitement d’un remboursement peuvent varier selon les commerçants. En général, vous pouvez retourner des achats réglés avec Apple Pay en présentant le reçu. Certains commerçants peuvent demander des informations supplémentaires, telles que les quatre derniers chiffres du numéro de carte Apple Pay utilisé pour votre mode de paiement. Lorsque le commerçant traite votre remboursement, votre carte de paiement est automatiquement créditée de la somme. En revanche, cela peut prendre plusieurs jours pour que la transaction apparaisse sur votre relevé de carte.

## Trouver votre numéro de carte Apple Pay

Votre numéro de carte physique et votre numéro de carte Apple Pay sont différents. Pour le remboursement d’achats effectués via Apple Pay, le commerçant peut utiliser le numéro de carte Apple Pay associé à votre carte de paiement dans l’app Cartes au lieu du numéro de votre carte de crédit ou de débit physique. Certains commerçants peuvent ne pas avoir besoin de votre numéro de carte Apple Pay ni celui de votre carte physique.

### Comment trouver le numéro de carte Apple Pay d’une carte de paiement sur votre iPhone

- Sur votre iPhone, ouvrez l’app Cartes.

- Touchez la carte avec laquelle vous avez réglé vos achats.

- Touchez le bouton Plus , puis touchez Numéro de carte.

### Comment trouver le numéro de carte Apple Pay d’une carte de paiement sur votre Apple Watch

- Sur votre Apple Watch, ouvrez l’app Cartes.

- Touchez la carte avec laquelle vous avez réglé vos achats.

- Faites défiler vers le bas, puis touchez Données de la carte.

Sur cet écran, les quatre derniers chiffres de votre numéro de carte Apple Pay s’affichent.

## Obtenir un remboursement sur une carte de paiement utilisée via Apple Pay

- Si le commerçant a besoin de votre carte de paiement pour effectuer le remboursement, ouvrez l’app Cartes sur l’appareil utilisé pour effectuer vos achats.

- Touchez la carte que vous souhaitez créditer.

- Appuyez deux fois sur le bouton latéral. Il est possible qu’il vous soit demandé de vous authentifier à l’aide de Face ID, Touch ID ou de votre code d’accès.

- Placez votre appareil à proximité du lecteur sans contact.
