# Keynote : comment empêcher l’ouverture d’applications pendant une présentation Keynote

Découvrez comment empêcher l’ouverture d’applications pendant une présentation Keynote.

Lors d’une présentation Keynote, il est possible que diverses applications s’ouvrent de manière inattendue. Les applications susceptibles de s’ouvrir sont notamment Apple Software Update, Exposé, Front Row ou toute application configurée pour s’exécuter selon une séquence de lancement planifiée. Pour éviter ce comportement, désactivez la possibilité pour toute autre application de s’ouvrir pendant une présentation dans les préférences de Keynote.

- Ouvrez Keynote.

- Ouvrez la fenêtre Préférences ( Keynote > Préférences... ).

- Sélectionnez l’onglet Diaporama .

- Désactivez Permettre l’utilisation de l’écran à Exposé, Dashboard et autres comme indiqué dans la capture d’écran ci-dessous.
