# Si MainStage ne fonctionne pas

Découvrez la marche à suivre si MainStage ne fonctionne pas comme prévu.

Avant de commencer, veillez à [sauvegarder l’application MainStage](https://support.apple.com/HT203004) .

## Essayer d’appliquer ces étapes dans l’ordre

Vérifiez le fonctionnement de MainStage après avoir appliqué chacune des étapes ci-dessous pour voir si le problème est résolu.

### Mettre à jour MainStage

Choisissez le menu Pomme  > App Store, puis cliquez sur Mises à jour dans la barre d’outils. Si une mise à jour de MainStage est disponible, cliquez sur le bouton Mettre à jour pour la télécharger et l’installer.

### Vérifier la compatibilité de votre appareil ou de votre logiciel

Si vous utilisez une interface audio externe, une interface MIDI, un système de stockage ou un module tiers, vérifiez que cet élément est compatible avec la version de macOS que vous utilisez. Contactez le fabricant pour obtenir de l’aide. Si une mise à jour est disponible, suivez les instructions du fabricant pour mettre à jour votre appareil ou votre logiciel.

### Utiliser le système audio intégré de votre Mac avec MainStage

Si vous utilisez une interface audio externe, essayez d’utiliser les haut-parleurs et le microphone intégrés de votre Mac au lieu de l’interface.

- Débranchez l’interface audio externe de votre Mac.

- Ouvrez MainStage, puis choisissez MainStage > Préférences > Audio.

- Choisissez les haut-parleurs de votre ordinateur dans le menu local Sortie audio.

- Choisissez le microphone de votre ordinateur dans le menu local Entrée audio.

- Effectuez un test à l’aide d’un concert, set ou patch posant problème.

Si l’utilisation du système audio intégré résout le problème, il peut être nécessaire de mettre à jour ou de réparer votre interface audio. Contactez le fabricant pour obtenir de l’aide.

### Contourner des modules Audio Units

Si vous utilisez des modules Audio Units tiers, essayez de les contourner ou de les supprimer.

[En savoir plus sur le dépannage des modules Audio Units](https://support.apple.com/HT201199)

### Créer un concert

Il arrive parfois que des fichiers de concert deviennent inutilisables et empêchent MainStage de fonctionner correctement. Créez un concert, puis testez MainStage pour vérifier si le fichier du concert d’origine est à l’origine du problème.

- Ouvrez MainStage, puis choisissez Fichier > Nouveau.

- Sélectionnez les appareils que vous voulez utiliser pour l’entrée et la sortie audio dans les menus locaux Entrée audio et Sortie audio de la boîte de dialogue.

- Cliquez sur une catégorie d’instrument à gauche, puis sélectionnez le modèle que vous souhaitez utiliser.

- Cliquez sur Choisir.

- Vérifiez si le problème se produit également avec le nouveau concert.

Si le problème ne se pose pas avec le nouveau concert, le concert avec lequel vous rencontrez des problèmes est peut-être endommagé. Vous pouvez essayer de [reconstruire le fichier de concert](https://support.apple.com/fr-fr/101941#rebuild) .

### Reconstruire un fichier de concert endommagé

Lorsque vous reconstruisez un concert, vous exportez la présentation, les sets et les patchs de ce concert, puis vous les importez dans un nouveau concert.

- Ouvrez le concert qui pose problème.

- Exportez la présentation, les sets et les patchs qui y sont associés :

- Cliquez sur Présentation dans la barre d’outils, puis sur le menu local Action de présentation en haut de la section Présentation, puis choisissez Exporter la présentation. Choisissez un emplacement pour enregistrer la présentation, puis cliquez sur Exporter.

- Pour exporter les sets et les patchs, cliquez sur Édition dans la barre d’outils, puis cliquez dans la Liste des patchs. Appuyez sur Commande + A (ou choisissez Édition > Tout sélectionner) pour sélectionner tous les sets et patchs présents dans la liste. Faites-les glisser sur le bureau ou dans un dossier.

- Fermez le concert.

- Créez un concert à partir du modèle de votre choix.

- Cliquez sur Présentation, appuyez sur Commande + A (ou choisissez Édition > Tout sélectionner) pour sélectionner tous les éléments de la section Présentation, puis appuyez sur la touche Supprimer pour les effacer.

- Importez la présentation, les sets et les patchs dans le nouveau concert :

- Cliquez sur le menu local Action de présentation , puis choisissez Importer la présentation. Sélectionnez la présentation que vous avez enregistrée à partir du concert d’origine, puis cliquez sur Importer.

- Cliquez sur Édition dans la barre d’outils, sélectionnez tous les sets et les patchs de la Liste des patchs, puis appuyez sur la touche Supprimer pour supprimer tous les patchs existants.

- Faites glisser les patchs du concert d’origine vers la liste des patchs. Il peut ensuite être nécessaire de réorganiser les sets et patchs.

- Testez le nouveau concert pour voir si le problème se pose.

### Tester MainStage avec un nouveau compte d’utilisateur

[Créez un autre compte utilisateur sur votre Mac](https://support.apple.com/guide/mac-help/mtusr001/mac) , puis essayez de recréer le problème dans le nouveau compte utilisateur. Si le problème ne se produit pas avec le nouveau compte utilisateur, les réglages ou les fichiers du compte d’origine peuvent être à l’origine du problème.

### Réinitialiser les préférences de MainStage

La réinitialisation des préférences n’a pas d’impact sur les fichiers de concert, les réglages prédéfinis ou les patchs. Toutefois, tous les réglages personnalisés que vous aurez créés seront supprimés. Notez vos réglages personnalisés actuels avant de procéder à la réinitialisation.

- Dans MainStage, choisissez MainStage > Préférences et notez tous les réglages spécifiques que vous avez définis.

- Quittez MainStage.

- Dans le Finder, appuyez sur la touche Option et choisissez Aller > Bibliothèque.

- Faites glisser le fichier intitulé « com.apple.mainstage3.plist » du dossier Préférences vers le bureau.

- Redémarrez votre Mac.

Une fois votre Mac redémarré, ouvrez MainStage et essayez de reproduire le problème. Si le problème ne se reproduit plus, ouvrez les préférences MainStage et appliquez à nouveau vos réglages personnalisés.
