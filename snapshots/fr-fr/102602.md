# À propos du relais privé iCloud

Disponible avec tout abonnement à iCloud+, le relais privé iCloud contribue à protéger votre confidentialité lorsque vous naviguez sur le Web dans Safari.

## Fonctionnement du relais privé

Habituellement, lorsque vous naviguez sur le Web, les informations vous concernant, comme les enregistrements DNS et les adresses IP, sont détectables par votre fournisseur réseau et par les sites que vous consultez. Ces informations peuvent permettre de déterminer votre identité et d’élaborer un profil en fonction de votre localisation et de votre historique de navigation au fil du temps.

Le relais privé iCloud est conçu pour protéger votre vie privée, en garantissant qu’aucune partie, même Apple, ne puisse savoir qui vous êtes ni quelles pages vous consultez sur le Web dans Safari.

Si vous activez le relais privé, vos requêtes sont transmises via deux relais Internet distincts et sécurisés.

- Votre adresse IP est détectable par votre fournisseur réseau et le premier relais, qui est géré par Apple. Vos enregistrements DNS, pour leur part, sont chiffrés afin qu’aucune partie ne puisse identifier l’adresse du site web sur lequel vous souhaitez vous rendre.

- Le second relais, géré par un fournisseur de contenu tiers, génère une adresse IP temporaire, déchiffre le nom du site web demandé et vous connecte à ce dernier.

Chacune de ces opérations est effectuée en appliquant les dernières normes Internet afin de vous garantir une expérience de navigation optimale tout en protégeant votre vie privée.

[Configurer le relais privé iCloud sur tous vos appareils](https://support.apple.com/guide/icloud/mm7dc25cb68f)

[Gérer le relais privé pour des sites web, des réseaux ou des réglages système spécifiques](https://support.apple.com/HT213548)

Le relais privé iCloud n’est pas disponible dans tous les pays ou régions. Sans accès à votre adresse IP, certains sites web peuvent nécessiter des étapes supplémentaires pour se connecter ou accéder au contenu.

## Tests de vitesse du relais privé et du réseau

Le relais privé utilise une connexion unique et sécurisée pour garantir la confidentialité des données et optimiser les performances. Ce procédé peut avoir un impact sur le débit indiqué dans les tests de vitesse du réseau, qui ouvrent généralement plusieurs connexions simultanées pour obtenir le meilleur résultat possible. Bien que certaines mesures de vitesse puissent sembler inférieures lorsque le relais privé est activé, vous profitez tout de même d’une expérience de navigation rapide et privée.
