# Si le message « Le nombre maximal de comptes gratuits pouvant être activés a été atteint » s’affiche

Vous avez dépassé le nombre de comptes que vous pouvez configurer par an avec iCloud sur un seul appareil.

Découvrez la marche à suivre [si vous ne parvenez pas à créer un compte Apple ou si vous voyez le message « Impossible de créer votre compte pour le moment »](https://support.apple.com/fr-fr/120636) .

## Pourquoi avez-vous reçu ce message ?

Si le message « Le nombre maximal de comptes gratuits pouvant être activés sur [cet appareil] a été atteint » s’affiche, cela signifie que vous avez dépassé le nombre de comptes Apple que vous pouvez configurer par an avec iCloud sur un seul appareil.

Ce message peut s’afficher dans les cas suivants :

- Vous vous connectez avec un compte Apple que vous avez créé sur le Web, une Apple TV 4K ou Apple TV HD, ou un appareil tiers, mais que vous n’avez pas encore configuré avec iCloud.

- Vous créez un compte Apple dans Réglages ou Réglages Système sur un appareil qui a déjà été utilisé pour créer d’autres comptes cette année.

- Vous vous connectez avec un compte Apple ayant [accès à iCloud uniquement via un navigateur web](https://support.apple.com/fr-fr/102447) .

## Que devez-vous faire ?

Si vous disposez d’un autre iPhone, iPad ou Mac, vous pouvez essayer de configurer iCloud à l’aide de votre compte Apple sur cet appareil. [Connectez-vous avec votre compte Apple](https://support.apple.com/fr-fr/111001) , puis suivez les instructions à l’écran pour commencer à utiliser iCloud. Si vous voyez toujours la même erreur, [cherchez à obtenir des suggestions](https://getsupport.apple.com/?caller=kbase) sur ce qu’il faut essayer ensuite.

Ou bien, si vous avez déjà configuré un compte Apple avec iCloud, [connectez-vous plutôt avec ce compte Apple](https://support.apple.com/fr-fr/111001) .

Votre compte Apple vous permet d’accéder aux services Apple tels que l’App Store, Apple Music, iCloud, iMessage, FaceTime et d’autres encore. Vous vous connectez à tous les services Apple à l’aide de ce compte Apple unique.
