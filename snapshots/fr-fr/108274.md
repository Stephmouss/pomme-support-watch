# Recevoir des notifications sur votre iPhone et Apple Watch

Si vous ne recevez pas les notifications comme vous le souhaitez ou comme prévu, vous devrez peut-être vérifier vos réglages ou un appareil jumelé, comme une Apple Watch.

[Réglages à vérifier pour les notifications d’apps](http://support.apple.com/108274#apps)

[Réglages à vérifier pour les notifications sur une Apple Watch jumelée](http://support.apple.com/108274#watch)

## Avant de commencer

- Si [votre appareil est en silencieux](https://support.apple.com/guide/iphone/silence-iphone-iph81c7fd7d1/ios) , vos notifications n’émettront aucun son. [Choisissez le son, la fréquence et l’apparence de vos notifications](https://support.apple.com/guide/iphone/change-notification-settings-iph7c3d96bab/ios) .

- Si vous utilisez une Apple Watch, par défaut, les notifications s’affichent soit sur votre Apple Watch, soit sur votre iPhone, mais pas sur les deux. [Choisissez l’endroit où apparaissent vos notifications](http://support.apple.com/108274#watch) .

- Si vous ne recevez pas [les notifications de l’app Messages comme vous le souhaitez ou comme prévu](https://support.apple.com/108127) , vous devrez peut-être modifier vos réglages pour certaines conversations ou vérifier vos dossiers pour voir si des messages provenant de personnes inconnues ou identifiés comme indésirables s’y trouvent.

## Vérifier les notifications d’une app spécifique

- Dans l’app Réglages, touchez Notifications.

- Touchez l’app pour laquelle vous ne recevez pas de notifications.

- Activez Autoriser les notifications, puis choisissez comment et où vous souhaitez recevoir les notifications.

Définissez des alertes pour choisir si les notifications apparaissent sur votre écran verrouillé, dans le centre de notifications ou sous la forme d’une bannière pendant que vous utilisez votre iPhone.

Lorsque vous activez le réglage Pastilles, certaines icônes d’app peuvent afficher des informations. Si vous activez Pastilles pour Mail, par exemple, le nombre d’e-mails non lus dans vos boîtes de réception apparaît au-dessus de l’icône Mail sur votre écran d’accueil.

Lorsque vous activez Annoncer les notifications, Siri lit les notifications de l’app à haute voix.

## Toujours recevoir les notifications d’une app spécifique

Sous iOS 15 ou version ultérieure, activez Alertes critiques pour recevoir les notifications des apps prises en charge même si toutes les autres notifications ont été masquées :

- Dans l’app Réglages, touchez Notifications.

- Sélectionnez une app sous Style.

- Activez Alertes critiques si ce réglage est disponible.

## Activer ou désactiver votre mode de concentration

Avec iOS 15 et iPadOS 15 ou une version ultérieure, Concentration vous permet de vous accorder des temps de tranquillité, lorsque vous avez besoin de vous concentrer ou de vous détacher de votre appareil. Vous pouvez [personnaliser les modes de concentration](https://support.apple.com/guide/iphone/allow-or-silence-notifications-for-a-focus-iph21d43af5b/ios) pour choisir quand vous souhaitez recevoir des alertes et des notifications, et pour sélectionner les apps ou les contacts qui peuvent générer des alertes et des notifications. Vous pouvez également [programmer un mode de concentration](https://support.apple.com/guide/iphone/turn-a-focus-on-or-off-iph5c3f5b77b/18.0/ios/18.0) pour qu’il s’active à certains moments ou après certaines actions.

- Ouvrez le centre de contrôle.

- Touchez le mode de concentration qui apparaît, comme Ne pas déranger ou Travail. (Si seule l’icône Concentration apparaît, c’est qu’aucun mode de concentration n’est activé.)

- Touchez à nouveau le mode de concentration pour le désactiver.

Si vous possédez d’autres appareils Apple associés, comme une Apple Watch ou un iPad, vérifiez si un mode de concentration s’applique également à ces appareils. Si vous activez [Partager entre les appareils](https://support.apple.com/guide/iphone/set-up-a-focus-iphd6288a67f/18.0/ios/18.0#iphd5eeb63ff) sur vos appareils Apple, puis activez un mode de concentration, celui-ci s’appliquera à l’ensemble de vos appareils liés.

## Autoriser les notifications même lorsqu’un mode de concentration est activé

- Dans l’app Réglages, touchez Concentration.

- Touchez le mode de concentration pour lequel vous souhaitez modifier les réglages de notification.

- Touchez Personnes ou Apps.

- Assurez-vous que l’option « Autoriser les notifications de » est sélectionnée, puis touchez Ajouter des personnes ou Ajouter des apps.

- Choisissez les personnes ou les apps dont vous souhaitez recevoir les notifications pendant que vous êtes en mode Concentration.

- Touchez OK.

[Image: Dans les réglages Concentration, vous pouvez ajouter les contacts dont vous souhaitez recevoir les notifications même lorsque le mode Concentration est activé.]

Vous ne pouvez pas autoriser de notifications d’apps avec le réglage Mode de concentration Conduite. D’autres modes de concentration, comme Sommeil ou Ne pas déranger, offrent plus de possibilités comme le masquage des notifications uniquement lorsque votre iPhone est verrouillé.

[Découvrez comment personnaliser vos modes de concentration.](https://support.apple.com/guide/iphone/allow-or-silence-notifications-for-a-focus-iph21d43af5b/16.0/ios/16.0)

## Choisir si les notifications apparaissent sur votre Apple Watch ou votre iPhone

Si vous utilisez une Apple Watch, par défaut, [les notifications s’affichent soit sur votre Apple Watch, soit sur votre iPhone](https://support.apple.com/108369) , mais pas sur les deux :

- Si votre iPhone est déverrouillé, vous recevez les notifications sur votre iPhone au lieu de votre Apple Watch.

- Si votre iPhone est verrouillé ou en veille, vous recevez les notifications sur votre Apple Watch, à moins que votre Apple Watch ne soit verrouillée. Lorsque vous lisez ou ignorez des notifications sur votre Apple Watch, elles sont également supprimées de votre iPhone.

### Vérifier les notifications d’une app spécifique sur votre Apple Watch

- Dans l’app Apple Watch sur votre iPhone, touchez Ma montre.

- Touchez Notifications.

- Touchez une app afin d’accéder à ses options.

Afin d’utiliser les mêmes réglages de notification pour les apps installées à la fois sur votre Apple Watch et sur votre iPhone, touchez Comme mon iPhone.

D’autres apps vous permettent de personnaliser les notifications. Touchez Personnalisé, puis choisissez une option :

- Autoriser les notifications : les notifications s’affichent dans le centre de notifications, et votre Apple Watch vous envoie une alerte.

- Envoyer au centre de notifications : les notifications sont envoyées directement au centre de notifications sans que votre Apple Watch vous envoie une alerte.

- Notifications désactivées : l’app n’envoie aucune notification.

Si vous personnalisez les notifications d’une app, vous pouvez aussi grouper les notifications de cette app. Touchez Grouper les notifications, puis choisissez une option : Désactivé, Automatiquement ou Par app.
