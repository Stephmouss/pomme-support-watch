# OS X Server : activation et désactivation du transfert automatique d’e-mails

La fonctionnalité de serveur de messagerie d’OS X Server peut transférer des e-mails de manière automatique.

## Instructions pour OS X Server (Mountain Lion)

- Dans l’app Server, accédez à Utilisateurs et sélectionnez un utilisateur.

- Cliquez sur l’icône en forme d’engrenage (ou sur le nom de l’utilisateur tout en maintenant la touche Contrôle enfoncée) et choisissez « Modifier les réglages liés aux e-mails… »

- Dans le menu local « Les e-mails doivent être : », sélectionnez « transférés ».

- Saisissez l’adresse e-mail de transfert dans le champ « à l’adresse : ».

## Instructions pour Lion Server

### Activation du transfert automatique pour un compte

Pour activer le transfert automatique pour un compte, exécutez les commandes suivantes dans Terminal sur le serveur. La première commande permet de passer en mode interactif.

sudo serveradmin command mail:command = setAutoForward mail:userID = (the_users_shortname) mail:fwdAddress = (the_emailaddress_to_forward_to_)

Appuyez sur Contrôle + D pour exécuter la commande.

Après avoir exécuté la commande en appuyant sur Contrôle + D, elle doit renvoyer l’identifiant utilisateur, l’identifiant GUID et l’adresse de transfert automatique saisie. Par exemple :

mail:userID = " mailuser1"

mail:userGUID = "A961DAFE-2FE5-4EEC-A2CB-CB6511E9B28D"

mail:fwdAddress = "my-user-ID@example.com"

Si l’utilisateur n’existe pas, le message suivant s’affiche :

mail:error = "user not found"

### Désactivation du transfert automatique pour un compte

Utilisez les mêmes commandes que ci-dessus, mais avec une valeur d’adresse vide :

sudo serveradmin command mail:command = setAutoForward mail:userID = mailuser1 mail:fwdAddress = ""

Appuyez sur Contrôle + D pour exécuter la commande.

Le résultat sera le même que ci-dessus, mais sans valeur associée à mail:fwdAddress. Exemple :

mail:userID = " mailuser1"

mail:userGUID = "A961DAFE-2FE5-4EEC-A2CB-CB6511E9B28D"

mail:fwdAddress = ""

Si vous saisissez un identifiant incorrect ou qui n’existe pas, le message suivant s’affiche :

mail:error = "user not found"

### Identification des comptes pour lesquels le transfert automatique est activé

Exécutez la commande suivante :

sudo serveradmin command mail:command = getAutoForward

La commande renvoie une liste des identifiants GUID et les adresses de transfert automatique. Par exemple :

$ sudo serveradmin command mail:command = getAutoForward

mail:1080C8CF-5432-4302-B3B7-0EEFB79106AD:fwdAddress = "my-userID-1@example.net"

mail:2DD1FB33-340F-408F-8C2A-D77B0A2431C7:fwdAddress = "my-userID-2@example.net"

## Informations supplémentaires

Vous pouvez également utiliser la commande set_user_mail_opts. Utilisez la commande man set_user_mail_opts pour consulter les informations relatives à son utilisation et à ses options.
