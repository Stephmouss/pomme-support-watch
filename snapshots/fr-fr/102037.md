# Modifier le gain des régions audio dans Logic Pro pour Mac

Vous pouvez modifier le gain des régions audio à l’aide de l’outil Gain, ou à partir de l’inspecteur de région ou de cellule.

La plage de modification du gain est de 60 dB : -30 dB à +30 dB.

## Modifier le gain des régions dans la zone Pistes à l’aide de l’outil Gain

- Sélectionnez une ou plusieurs régions, ou sélectionnez une zone à modifier avec l’outil Sélection. Cette zone peut inclure des parties de plusieurs régions.

- Sélectionnez le bouton de l’outil Gain dans le menu Outil de la zone Pistes.

- Faites glisser le pointeur verticalement sur la région pour augmenter ou diminuer le gain. La valeur numérique du gain se met à jour lorsque vous faites glisser. Si vous avez sélectionné une partie d’une région avec l’outil Sélection, puis ajusté le gain de la partie sélectionnée à l’aide de l’outil Gain, une région est créée et le changement de gain lui est appliqué.

[Image: Zone Pistes montrant l’utilisation de l’outil Gain pour ajuster le gain d’une région.]

## Modifier le gain dans l’inspecteur de région

- Sélectionnez une ou plusieurs régions dans la zone Pistes, ou une ou plusieurs cellules dans la grille Live Loops.

- Cliquez sur le bouton Inspecteur dans la barre d’outils.

- Cliquez sur l’inspecteur de région ou de cellule pour afficher les paramètres de région ou de cellule.

- Double-cliquez sur Gain, puis saisissez une valeur numérique en dB :

- Pour augmenter le gain, saisissez uniquement le nombre.

- Pour réduire le gain, appuyez sur la touche Moins (-), puis saisissez un nombre.
