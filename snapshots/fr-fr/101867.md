# Si les images vidéo de votre projet Final Cut Pro sont dans le désordre

Découvrez la procédure à suivre lorsque des images vidéo sont lues dans le désordre dans Final Cut Pro ou dans la version exportée d’un projet.

Final Cut Pro 10.6.4 corrige un problème d’images vidéo qui pouvaient apparaître dans le désordre dans un projet. Si vous avez rencontré ce problème, effectuez la mise à jour vers Final Cut Pro 10.6.4, supprimez les fichiers de rendu dans la bibliothèque du projet concerné, puis effectuez le rendu du projet.

## Mise à jour de Final Cut Pro

Commencez par effectuer une [mise à jour vers Final Cut Pro 10.6.4](https://support.apple.com/fr-fr/guide/app-store/update-apps-fir9b01adda3/mac) .

## Suppression des fichiers de rendu

Une fois la mise à jour installée, supprimez les fichiers de rendu dans la bibliothèque du projet dont les images vidéo sont dans le désordre :

- Dans la barre latérale Bibliothèques de Final Cut Pro, sélectionnez la bibliothèque concernée.

- Sélectionnez Fichier > Supprimer les fichiers de bibliothèque générés.

- Sélectionnez Supprimer les fichiers de rendu.

- Sélectionnez Supprimer les fichiers de rendu, cochez l’option Tout, puis cliquez sur OK.

## Rendu du projet

Après avoir supprimé les fichiers de rendu, effectuez le rendu de vos projets :

- Sélectionnez votre projet dans le navigateur Final Cut Pro.

- Choisissez Modifier > Tout rendre (ou appuyez sur Ctrl + Maj + R). Vous pouvez voir la progression du rendu dans la [fenêtre de tâches d’arrière-plan](https://support.apple.com/fr-fr/guide/final-cut-pro/view-background-tasks-ver64e71609/mac) .
