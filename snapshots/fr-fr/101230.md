# À propos de la mise à jour Lion Server 10.7.2

Ce logiciel permet de mettre à jour Lion Server 10.7 et 10.7.1 vers la version 10.7.2. Son installation est recommandée à tous les utilisateurs de Lion Server.

Important : prenez connaissance des points suivants avant de procéder à l’installation.

- N’interrompez pas la procédure d’installation. Si une coupure de courant ou toute autre interruption survient durant l’installation, effectuez la mise à jour à l’aide du programme d’installation autonome (voir ci-dessous) disponible sur la page [Téléchargements du site de l’assistance Apple](http://support.apple.com/fr_FR/downloads/) .

Installation

Trois méthodes permettent d’effectuer la mise à jour vers Lion Server 10.7.2 :

- Utilisation de la fonctionnalité Mise à jour de logiciels

- Installation à partir d’un programme d’installation autonome

- Installation sur un serveur distant via Admin Serveur ou l’utilitaire de ligne de commande softwareupdate command-line utility

Installation via l’outil Mise à jour de logiciels

Choisissez [Mise à jour de logiciels](http://support.apple.com/HT1338) Certaines mises à jour doivent être installées préalablement à d’autres. Il peut donc être nécessaire de lancer l’outil Mise à jour de logiciels à plusieurs reprises pour obtenir toutes les mises à jour disponibles. Si le message « Vos logiciels sont à jour » s’affiche, cela signifie que toutes les mises à jour disponibles ont été installées.

Programme d’installation autonome

Si vous souhaitez télécharger et installer manuellement la mise à jour, un programme d’installation est disponible sur la page [Téléchargements du site de l’assistance Apple](http://support.apple.com/fr_FR/downloads/) . Cette méthode est pratique si vous devez mettre à jour plusieurs ordinateurs, mais que vous ne souhaitez télécharger la mise à jour qu’une seule fois.

Installation à distance

Si vous devez installer la mise à jour sur un serveur distant, utilisez l’app Admin Serveur ou l’outil de ligne de commande

[softwareupdate](http://support.apple.com/HT1974)

.

Que comprend cette mise à jour ?

Cette mise à jour intègre les améliorations ci-dessous, ainsi que celles de la [mise à jour Lion Server 10.7.1](http://support.apple.com/HT4765) .

Services d’annuaire

- Corrige un problème qui pouvait empêcher les clients de Lion d’établir une liaison avec l’Open Directory de Lion Server à l’aide du protocole SSL.

- Corrige un problème de restauration d’une archive Open Directory créée sous Mac OS X Server 10.6 ou 10.5.

Partage de fichiers

- Permet aux utilisateurs d’accéder aux points de partage WebDAV même s’ils ne disposent pas d’un répertoire de départ sur le serveur.

Service iChat

- Corrige la prise en charge des réseaux IPv6.

Service de messagerie

- Permet aux utilisateurs des réseaux IPv6 d’accéder à la messagerie web.

Podcast

- Améliore la fiabilité de la bibliothèque de podcasts.

PostgreSQL

- Améliore la fiabilité des sauvegardes Time Machine de la base de données PostgreSQL.

Gestionnaire de profils

- Prend en charge les nouvelles fonctionnalités des solutions de gestion des appareils mobiles et des profils de configuration sous iOS 5.

- Corrige un problème qui empêchait le bouton Importer paramètres fictifs de fonctionner dans Safari.

- Corrige un problème de chargement de certains fichiers de préférences en tant que réglages personnalisés.

Important : pour éviter tout problème lors de l’utilisation du gestionnaire de profils pour verrouiller à distance un ordinateur sur lequel un mot de passe de programme interne de l’EFI a déjà été défini, tous les clients gérés doivent installer la mise à jour de la fonctionnalité de récupération d’OS X Lion.

App Server

- Permet désormais de [stocker certaines données de services sur un volume différent](http://support.apple.com/HT4974) .

- Permet désormais de consulter certains historiques de services dans l’app Server.

- Permet désormais de configurer plusieurs sites web avec des noms d’hôte différents sur la même adresse IP.

- Permet la création de répertoires de départ sur des points de partage SMB.

- Améliore la stabilité de l’app Server.

- Améliore la fiabilité des graphiques dans la sous-fenêtre des statistiques.

- Permet à l’app Server de répondre correctement aux modifications apportées à la configuration du répertoire par d’autres outils, tels qu’Admin Serveur ou la commande slapconfig.

- Corrige un problème lié à la sélection de plusieurs groupes à modifier.

- Corrige un problème d’enregistrement d’un profil de configuration dans la sous-fenêtre VPN.

Installation, configuration, mise à niveau et migration

Les améliorations apportées à l’installation, à la configuration, à la mise à niveau et à la migration sont disponibles lorsque vous installez Lion Server 10.7.2 ou procédez à une mise à niveau vers cette version. L’installation de Lion Server 10.7.2 sera mise à votre disposition sur le Mac App Store et depuis la fonctionnalité de récupération de Lion une fois la mise à jour disponible via Mise à jour de logiciels Apple.

- Vous pouvez désormais configurer un nouveau serveur Lion à l’aide d’un clavier Bluetooth.

- Vous pouvez désormais configurer un nouveau serveur Lion à l’aide du partage d’écran ou d’Apple Remote Desktop. Pour connaître la marche à suivre, reportez-vous à l’article [Lion Server : Configuration d’un serveur distant](http://support.apple.com/HT4938) .

- Lorsque [Lion Server est installé sur un volume vide](http://support.apple.com/HT4766) , le paquet logiciel serveur est désormais sélectionné par défaut.

- Améliore la mise à niveau ou la migration des serveurs qui hébergent plusieurs sites web.

- Les fichiers de configuration du service de mises à jour logicielles sont correctement transférés lors de la mise à niveau ou de la migration à partir de Mac OS X Server 10.6 ou 10.5.

- Le calendrier Wiki se lance correctement après la mise à niveau ou la migration à partir de Mac OS X Server 10.6 ou 10.5.

- Vous pouvez effectuer la migration d’une base de données du serveur de messagerie stockée sur un volume Xsan de Mac OS X Server 10.6 à Lion Server. Pour obtenir des instructions détaillées sur la migration, consultez [cet article](http://support.apple.com/HT4909) .

- Les configurations du serveur de messagerie personnalisées sont correctement transférées lors de la mise à niveau ou de la migration à partir de Mac OS X Server 10.6.

- Les configurations php.ini personnalisées sont correctement transférées lors de la mise à niveau ou de la migration à partir de Mac OS X Server 10.6.

- Les fichiers joints sont correctement transférés lors de la migration d’un Wiki d’un Lion Server à un autre.

Autres améliorations

- Améliore la sécurité de Mac OS X Server. Pour en savoir plus sur les correctifs de sécurité de Lion Server 10.7.2, consultez [cet article](http://support.apple.com/HT1222) .

- Lion Server 10.7.2 intègre également toutes les autres améliorations de la [mise à jour OS X Lion 10.7.2](http://support.apple.com/HT4767) (client).
