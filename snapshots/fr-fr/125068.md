# Afficher les conversations avec des expéditeurs inconnus dans Messages sur votre iPhone

Dans iOS 26, vous pouvez filtrer les messages provenant de numéros inconnus et afficher automatiquement ces messages dans un filtre séparé.

Dans iOS 26, [le réglage Filtrer les expéditeurs inconnus](https://support.apple.com/guide/iphone/screen-filter-report-and-block-texts-iph203ab0be4/ios) facilite l’organisation de vos messages et le choix des messages qui s’affichent dans votre liste de conversations.

## Activer ou désactiver le réglage Filtrer les expéditeurs inconnus dans iOS 26

Le réglage Filtrer les expéditeurs inconnus est désactivé par défaut dans iOS 26. Si le réglage Filtrer les expéditeurs inconnus est activé dans iOS 18, il reste activé lorsque vous passez à iOS 26.

Pour activer ce réglage :

- Ouvrez Messages.

- Touchez le bouton Filtres.

- Touchez Gérer le filtrage, puis faites défiler l’écran jusqu’à Expéditeurs inconnus et touchez Filtrer les expéditeurs inconnus pour activer ou désactiver le réglage.

Lorsque vous activez le réglage Filtrer les expéditeurs inconnus, les messages des expéditeurs inconnus s’affichent dans le filtre Expéditeurs inconnus.

Vous pouvez également activer ou désactiver ce réglage dans l’app Réglages. Accédez à Réglages, touchez Apps, Messages, puis faites défiler l’écran vers le bas jusqu’à Filtrer les expéditeurs inconnus pour activer ou désactiver le réglage.

## Afficher et déplacer les messages provenant d’expéditeurs inconnus dans iOS 26

Un expéditeur inconnu est par exemple une personne avec laquelle vous n’avez jamais interagi dans Messages ou bien une personne qui ne fait pas partie de vos contacts. Lorsque vous recevez un message d’un expéditeur inconnu, un badge indique que vous avez de nouveaux messages dans le filtre Expéditeurs inconnus.

Pour afficher un message d’un expéditeur inconnu :

- Dans Messages, touchez le bouton Filtres.

- Touchez Expéditeurs inconnus.

Si vous reconnaissez un expéditeur inconnu et que vous souhaitez le marquer comme expéditeur connu afin que ses messages s’affichent dans votre liste de conversation principale :

- ﻿Dans Messages, touchez le bouton Filtres.

- ﻿Touchez Expéditeurs inconnus.

- ﻿Touchez la conversation que vous souhaitez déplacer vers votre liste de conversations.

- Touchez Marquer comme connu.

Vous pouvez envoyer un message à un expéditeur inconnu avant de marquer ce dernier comme connu. Après avoir marqué un expéditeur comme connu, le message que vous avez sélectionné s’affiche dans votre liste de conversations. Ce contact peut alors vous joindre sur les apps de communication.

[Découvrez comment afficher et déplacer les messages identifiés comme indésirables dans iOS 26](https://support.apple.com/124159)

Si vous répondez à un message provenant d’un expéditeur inconnu, l’expéditeur n’est pas automatiquement marqué comme connu et le message n’est pas non plus déplacé vers votre liste de conversations.

## Gérer les notifications pour certains messages provenant d’expéditeurs inconnus

Les notifications sont activées par défaut pour les messages urgents, tels que les codes de vérification, les alertes ou les demandes urgentes. L’app Messages vous offre encore plus de contrôle sur les messages provenant d’expéditeurs inconnus qui peuvent vous envoyer des notifications. Pour gérer les notifications provenant d’expéditeurs inconnus :

- Dans l’app Réglages, touchez Apps.

- Touchez Messages.

- Faites défiler l’écran jusqu’à Expéditeurs inconnus et touchez Autoriser les notifications.

- Activez ou désactivez les types de messages pour lesquels vous souhaitez recevoir des notifications : Urgent, Personnels, Transactions ou Publicités.

Si vous autorisez les notifications pour les messages provenant d’expéditeurs inconnus, ces messages afficheront des notifications et seront visibles pendant huit heures dans votre liste de conversations. Après cela, ces messages s’afficheront dans la zone Expéditeurs inconnus.

Dans la plupart des pays et régions, les messages provenant d’expéditeurs inconnus vous envoient des notifications par défaut. Aux États-Unis, au Brésil et en Inde, vous pouvez ajuster vos réglages Messages pour choisir quels messages provenant d’expéditeurs inconnus génèrent des notifications.

Le filtrage des messages ne s’applique pas aux expéditeurs à qui vous avez répondu trois fois ou davantage. Les options pour les notifications provenant d’expéditeurs inconnus varient selon le pays et la région.

### Filtrer les SMS, MMS et messages RCS concernant des transactions et des publicités

L’app Messages peut également organiser vos SMS, MMS et messages RCS provenant d’expéditeurs inconnus concernant des transactions et des publicités. Pour activer ce réglage :

- Ouvrez Messages.

- Touchez le bouton Filtres.

- Touchez Gérer le filtrage.

- Touchez Filtre des messages texte, puis activez Filtre des messages texte et les éventuelles extensions tierces de filtrage de messages que vous installez.

Les filtres s’appliquent aux transactions et aux publicités (ou à tout autre type de message géré par vos extensions tierces de filtrage de messages). Le filtrage des messages texte ne s’applique pas aux expéditeurs auxquels vous avez répondu trois fois ou davantage. Si vous souhaitez arrêter les communications provenant de ces expéditeurs, essayez de [bloquer et signaler ces expéditeurs](https://support.apple.com/111104) .
