# Supprimer le verrouillage d’activation

Découvrez la marche à suivre si l’écran du verrouillage d’activation s’affiche sur votre appareil ou si un message vous invite à supprimer le verrouillage d’activation d’un appareil hors ligne qui n’est pas en votre possession.

## Supprimer le verrouillage d’activation de l’appareil

Suivez les étapes qui s’affichent à l’écran pour accéder au compte Apple et saisir le mot de passe utilisés pour configurer votre appareil ou le code d’accès de celui-ci. Si vous ne vous souvenez pas de votre compte Apple, essayez de vous connecter avec une adresse e-mail ou un numéro de téléphone que vous utilisez régulièrement pour les services Apple.

Découvrez comment [trouver votre compte Apple](https://support.apple.com/fr-fr/102627) ou [réinitialiser le mot de passe de votre compte Apple](https://support.apple.com/fr-fr/102656) .

Si votre appareil appartient à une entreprise ou à un établissement d’enseignement, veuillez contacter votre service ou responsable informatique.

## Supprimer le verrouillage d’activation sur le Web si l’appareil est hors ligne

- Accédez à [icloud.com/find](https://www.icloud.com/find) .

- Connectez-vous à votre compte Apple.

- Sélectionnez l’appareil à supprimer du compte iCloud.

- Cliquez sur Supprimer cet appareil.

Pour l’iPhone, vous pourrez peut-être supprimer le verrouillage d’activation sur le Web même si votre iPhone n’est pas hors ligne.

## Formuler une demande d’assistance

Si vous avez besoin d’aide pour supprimer le verrouillage d’activation et que vous êtes en possession d’une preuve d’achat, vous pouvez [formuler une demande d’assistance concernant le verrouillage d’activation.](https://al-support.apple.com/#/kbase)
