# Modifier les sous-titres, la langue audio ou les descriptions audio sur votre iPod nano

Sur l’iPod nano, vous pouvez utiliser des langues audio personnalisées, des sous-titres ou des sous-titres codés. Vous pouvez également utiliser des descriptions audio pour que les scènes dans des vidéos vous soient décrites.

## Modifier les sous-titres ou la langue audio

- Lancez une vidéo, puis touchez l’écran pour afficher les commandes de lecture.

- Touchez le bouton Sélection multimédia l’icône de la bulle de dialogue

- Sélectionnez la langue ou les sous-titres que vous souhaitez utiliser.

Si l’option SM ne s’affiche pas ou si vous souhaitez activer par défaut les sous-titres codés ou les sous-titres pour les personnes sourdes et malentendantes, accédez à Réglages > Accessibilité > Sous-titres codés et SM. Vous pouvez également personnaliser les sous-titres depuis cet écran.

## Activer les descriptions audio

Si la vidéo que vous visionnez inclut des descriptions audio, vous pouvez y accéder dans le menu Audio et sous-titres :

- Lorsque vous visionnez une vidéo dans l’app Vidéos, touchez l’écran pour afficher les commandes de lecture.

- Touchez le bouton Sélection multimédia pour ouvrir le menu Audio et sous-titres.

## Informations supplémentaires

- Les vidéos ne comportent pas toutes des pistes de description audio. Consultez la documentation accompagnant votre vidéo pour en savoir plus.

- Un certain nombre d’apps et de sites web tiers proposent des commandes audio personnalisées pour les vidéos. Si ces commandes n’apparaissent pas lorsque vous visionnez une vidéo sur un site web, consultez la documentation ou contactez le gestionnaire du site ou le développeur de l’app pour obtenir plus d’informations.
