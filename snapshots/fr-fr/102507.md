# Utilisation d’Emoji sur votre iPhone, iPad ou iPod touch

Les Emoji vous permettent de donner vie aux mots d’un simple toucher.

## Ajouter un Emoji

Le clavier des Emoji est disponible dans les apps utilisant le clavier standard, telles que Mail ou Messages. Pour ajouter un Emoji :

- Touchez le champ de texte, puis le bouton Emoji ou le globe .

[Image: Aucun texte de remplacement pour l’image]

[Image: bouton Clavier suivant]

- Touchez les icônes grises au bas du clavier pour passer d’une catégorie d’Emoji à une autre, ou effectuez un balayage vers la gauche ou vers la droite pour afficher des Emoji supplémentaires. Touchez l’horloge pour afficher les Emoji récemment utilisés. Vous pouvez également rechercher des Emoji à ajouter à l’aide du champ « Rechercher un Emoji ».

[Image: bouton de la catégorie Souvent utilisés]

- Pour changer la couleur de peau d’un Emoji en particulier, touchez-le de façon prolongée.

- Touchez un Emoji pour l’insérer dans le champ de texte.

[Image: Après avoir ajouté un Emoji à votre message, touchez le bouton Envoyer.]

## Toucher les mots à remplacer par des Emoji

L’app Messages vous indique les mots que vous pouvez remplacer par des Emoji.

- Ouvrez Messages, puis touchez le bouton Rédiger pour commencer un nouveau message, ou accédez à une conversation existante.

[Image: null]

- Rédigez votre message, puis touchez le bouton Emoji ou le globe de votre clavier.

[Image: Aucun texte de remplacement pour l’image]

[Image: bouton Clavier suivant]

- Attendez que les mots s’affichent en orange.

- Touchez un mot orange pour le remplacer par un Emoji. Si plusieurs Emoji peuvent remplacer un même mot, le champ de réponse rapide affiche les options disponibles.

- Touchez le bouton Envoyer pour envoyer votre message.

[Image: bouton Envoyer]

[Image: Touchez le bouton Emoji de votre clavier pour afficher les Emoji disponibles dans Messages.]

Si vous souhaitez remplacer un Emoji par le mot d’origine, il vous suffit de le toucher.

## Utiliser un Emoji prédictif

La [saisie prédictive](https://support.apple.com/104995) vous permet de saisir et de compléter des phrases entières d’un simple toucher. À mesure que vous tapez, vous voyez s’afficher des choix de mots ou d’expressions que vous êtes susceptible d’écrire en fonction de vos discussions passées et de votre style d’écriture. Des suggestions d’Emoji s’affichent également. Pour utiliser un Emoji prédictif, rédigez votre message et recherchez les suggestions dans le champ de saisie prédictive, puis touchez le caractère pour remplacer le mot ou ajouter un Emoji.

[Image: Sous iOS 26, la saisie prédictive suggère des Emoji lorsque vous utilisez Messages.]

Pour désactiver la saisie prédictive, touchez de façon prolongée le bouton Emoji ou le globe , touchez Réglages Clavier, puis désactivez l’option Prédiction.

[Image: Aucun texte de remplacement pour l’image]

[Image: bouton Clavier suivant]

## Le clavier des Emoji ne s’affiche pas ?

Si vous ne voyez pas le clavier des Emoji :

- Dans l’app Réglages, touchez Général.

- Touchez Clavier.

- Touchez Claviers, puis Ajouter un clavier.

- Touchez Emoji.
