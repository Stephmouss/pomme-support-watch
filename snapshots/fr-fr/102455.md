# Désactivation d’iMessage sur votre iPhone ou en ligne

Si vous utilisez un téléphone d’une marque autre qu’Apple et ne recevez ni message RCS ni SMS/MMS, il peut être nécessaire de désactiver iMessage.

## Désactiver iMessage sur votre iPhone

Si vous disposez encore de votre iPhone, vous pouvez désactiver iMessage en suivant les instructions ci-dessous :

- Si vous [avez transféré votre carte SIM](https://support.apple.com/fr-fr/109357) de votre iPhone vers un téléphone d’une marque autre qu’Apple, remettez-la dans votre iPhone.

- Vérifiez que vous êtes connecté(e) à votre réseau de données mobiles.

- Dans l’app Réglages, touchez Apps.

- Touchez Messages.

- Désactivez iMessage.

[Image: Dans Réglages, touchez Apps, puis Messages. Pour terminer, touchez pour désactiver iMessage.]

- Retournez dans Réglages, puis touchez Apps.

- Touchez FaceTime.

- Désactivez FaceTime.

[Image: Dans Réglages, touchez Apps. Touchez FaceTime, puis désactivez FaceTime]

## Désactiver iMessage en ligne

Si vous n’avez pas accès à votre iPhone, vous pouvez [Désactivez iMessage en ligne](https://selfsolve.apple.com/deregister-imessage/) . Une fois la désactivation terminée, votre numéro de téléphone est supprimé des services iMessage. Vous devriez être en mesure de recevoir immédiatement des SMS. Toutefois, quelques heures peuvent être nécessaires pour que certains appareils Apple détectent que vous n’utilisez pas iMessage pour l’envoi et la réception de messages.

Si une personne envoie un message à votre compte Apple avec iMessage, vous le recevrez sur vos autres appareils Apple. Si une personne vous envoie un SMS à votre numéro de téléphone, vous le recevrez sous la forme d’un message RCS ou d’un SMS ou MMS uniquement sur votre téléphone.
