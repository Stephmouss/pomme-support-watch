# Oubli du mot de passe de votre compte Apple

Vous ne parvenez pas à accéder à votre compte Apple ? Réinitialisez votre mot de passe pour retrouver l’accès.

L’identifiant Apple est désormais le compte Apple. Vous pouvez toujours vous connecter avec la même adresse e-mail ou les mêmes numéro de téléphone et mot de passe.

## Utiliser un appareil Apple de confiance

Pour réinitialiser votre mot de passe, la méthode la plus simple consiste à utiliser votre iPhone ou un autre appareil Apple de confiance déjà connecté à votre compte Apple. Cela permet à Apple de vérifier que l’appareil est bien le vôtre. Un code d’accès (ou un mot de passe sur un Mac) doit également être configuré sur votre appareil.

[La réinitialisation de votre mot de passe sur le Web](https://support.apple.com/fr-fr/102656#web-reset) est un autre moyen de recouvrer l’accès à votre compte si vous n’avez pas d’appareil de confiance.

## Réinitialiser le mot de passe de votre compte Apple sur votre iPhone, iPad ou Apple Vision Pro

[Image: Lire une vidéo montrant les étapes à suivre pour réinitialiser le mot de passe de votre compte Apple sur un iPhone]

- Ouvrez l’app Réglages, puis touchez [votre nom].

- Touchez Connexion et sécurité.

- Touchez Modifier le mot de passe.

[Image: iPhone affichant le bouton Modifier le mot de passe dans Réglages.]

- Saisissez le code de votre appareil. Suivez les instructions à l’écran pour modifier le mot de passe de votre compte Apple.

Il se peut que vous deviez attendre une heure avant de modifier le mot de passe de votre compte Apple ou d’autres réglages de sécurité importants. En savoir plus [sur la protection en cas de vol de l’appareil](https://support.apple.com/fr-fr/120340) et sur les situations où un délai de sécurité peut être nécessaire.

## Réinitialiser le mot de passe de votre compte Apple sur votre Mac

- Dans le menu Apple , choisissez Réglages Système.

- Cliquez sur [votre nom], puis sur Connexion et sécurité.

- Cliquez sur Modifier le mot de passe.

[Image: Mac affichant les réglages de connexion et de sécurité.]

- Saisissez le mot de passe utilisé pour déverrouiller votre Mac. Suivez les instructions à l’écran pour modifier le mot de passe de votre compte Apple.

## Si vous essayez de vous connecter sur un nouvel appareil Apple

Si vous n’êtes pas connecté à votre compte Apple sur un appareil Apple, vous pouvez sélectionner « Vous avez oublié votre mot de passe ou vous n’avez pas de compte Apple ? » pendant sa configuration sur l’écran de connexion au compte Apple.

Si vous n’avez pas effectué la connexion à votre compte lors de la configuration, vous pouvez réinitialiser votre mot de passe dans Réglages :

- iPhone ou iPad : ouvrez l’app Réglages, puis touchez Compte Apple. Sélectionnez « Connexion manuelle », puis touchez « Mot de passe oublié ? » et suivez les instructions à l’écran.

- Mac : choisissez Réglages Système dans le menu Apple . Cliquez sur Se connecter, puis cliquez sur « Mot de passe oublié » et suivez les instructions à l’écran.

## Si vous ne disposez pas d’un appareil de confiance

Si vous ne pouvez pas utiliser l’un de vos appareils de confiance, empruntez un appareil à un membre de votre famille ou à un proche. Vous pouvez également modifier votre mot de passe sur iforgot.apple.com.

### Réinitialiser le mot de passe de votre compte Apple avec l’app Assistance Apple sur un appareil que vous avez emprunté

Si vous ne disposez pas d’un appareil Apple, mais que vous avez accès à votre numéro de téléphone de confiance, utilisez l’app Assistance Apple. Vous pouvez emprunter un appareil Apple à un proche ou à un membre de votre famille, ou utiliser l’un de ceux qui sont disponibles dans un Apple Store.

- Ouvrez l’app Assistance Apple sur l’appareil Apple que vous avez emprunté. Si vous devez télécharger l’app Assistance Apple, [recherchez-la dans l’App Store](https://apps.apple.com/fr/app/apple-support/id1130498044?ppid=4c8ebb90-7c66-4a71-bcf6-5fc74eb7fa1e) .

- Faites défiler l’écran vers le bas jusqu’à Outils d’assistance, puis touchez Réinitialiser le mot de passe.

- Touchez « Aider quelqu’un d’autre ».

- Saisissez l’adresse e-mail ou le numéro de téléphone de votre compte Apple.

- Touchez Continuer et suivez les instructions à l’écran pour réinitialiser votre mot de passe.

Aucune information que vous saisissez ne sera stockée sur l’appareil.

### Réinitialiser le mot de passe de votre compte Apple sur le Web

Vous pouvez également recouvrer l’accès à votre compte en réinitialisant votre mot de passe sur le Web. Lorsque cela est possible, le navigateur web vous invite à utiliser un appareil de confiance.

Le processus de réinitialisation sur le Web peut prendre un peu plus de temps. Si vous aurez bientôt accès à l’un de vos appareils de confiance, il pourrait être plus simple et rapide de réinitialiser votre mot de passe à ce moment-là.

[Réinitialiser votre mot de passe sur le site iforgot.apple.com](https://iforgot.apple.com/)
