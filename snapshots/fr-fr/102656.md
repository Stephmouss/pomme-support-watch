# Si vous avez oublié votre mot de passe et que vous ne parvenez pas à vous connecter à votre compte Apple

Vous ne parvenez pas à vous connecter à votre compte Apple ? Le moyen le plus simple de réinitialiser votre mot de passe consiste à utiliser un appareil de confiance et votre numéro de téléphone de confiance.

L’identifiant Apple est désormais le compte Apple. Vous pouvez toujours vous connecter avec la même adresse e-mail ou les mêmes numéro de téléphone et mot de passe.

## Choisissez « Mot de passe oublié ? » et suivez les instructions à l’écran

Que vous configuriez un nouvel appareil, que vous vous connectiez à votre compte Apple dans l’app Réglages ou que vous effectuiez un achat dans l’App Store, recherchez « Mot de passe oublié ? » ou « Mot de passe oublié ou vous n’avez pas de compte Apple ? »

Suivez ensuite les instructions qui s’affichent à l’écran. Celles-ci vous redirigeront vers un appareil de confiance, vous demanderont des facteurs de récupération (tels qu’un code de validation pour l’identification à deux facteurs envoyé à votre numéro de téléphone de confiance) ou vous aideront à récupérer l’accès après un certain délai.

Un appareil de confiance est un iPhone, un iPad, une Apple Watch, un Apple Vision Pro ou un Mac sur lequel vous vous êtes déjà connecté à votre compte Apple à l’aide de l’identification à deux facteurs. Il s’agit d’un appareil que nous savons être le vôtre, il peut donc être utilisé pour vérifier votre identité. [En savoir plus sur les appareils et les numéros de téléphone de confiance](https://support.apple.com/fr-fr/122621) .

## Avant d’essayer de récupérer l’accès à votre compte Apple

- Si vous aurez bientôt accès à un appareil ou à un numéro de téléphone de confiance, vous devriez attendre de les avoir pour récupérer l’accès. Si vous attendez, vous pourrez récupérer l’accès à votre compte plus rapidement.

- Si vous pensez connaître votre mot de passe, mais que vous ne vous souvenez pas de l’adresse e-mail ou du numéro de téléphone de votre compte Apple, essayez différentes adresses e-mail ou différents numéros de téléphone qui pourraient être associés à votre compte. N’importe quelle adresse e-mail ou n’importe quel numéro de téléphone associé à votre compte Apple fonctionnera pour vous connecter.

## Modifier le mot de passe de votre compte Apple sur un appareil de confiance

Par exemple, vous essayez de vous connecter sur un nouvel iPad, mais vous ne vous souvenez plus de votre mot de passe, et vous êtes déjà connecté sur votre iPhone

Si vous disposez d’un appareil de confiance (un appareil sur lequel vous êtes déjà connecté avec votre compte Apple), il se peut que vous n’ayez pas besoin de passer par la récupération de compte. Puisque vous êtes déjà connecté sur cet appareil, vous devriez essayer de remplacer votre mot de passe par un autre que vous connaissez.

- [Modifier votre mot de passe sur l’iPhone, l’iPad, l’Apple Watch ou l’Apple Vision Pro](https://support.apple.com/fr-fr/101567#ios)

- [Modifier votre mot de passe sur Mac](https://support.apple.com/fr-fr/101567#macos)

## Façons de réinitialiser votre mot de passe et de récupérer l’accès à votre compte Apple sans appareil de confiance

Par exemple, vous avez un nouvel iPhone avec le même numéro de téléphone que celui que vous avez configuré pour recevoir les codes de validation d’Apple.

Si vous n’avez pas d’appareil de confiance, les options pour réinitialiser le mot de passe de votre compte Apple dépendent des facteurs de récupération dont vous disposez.

### Trouver vos facteurs de récupération

Si vous n’êtes pas connecté à un appareil Apple de confiance, vous pourrez peut-être quand même réinitialiser votre mot de passe, mais vous devrez vérifier votre identité. Des facteurs de récupération pourraient vous être demandés, tels que :

- Votre numéro de téléphone de confiance — Il s’agit d’un numéro de téléphone que vous avez configuré pour recevoir les codes de validation de l’identification à deux facteurs d’Apple.

- Un code de votre contact de récupération — Si vous avez configuré un contact de récupération, contactez-le pour vous assurer qu’il est prêt à vous fournir le code à 6 chiffres ou à vous aider à récupérer l’accès en personne.

- L’adresse e-mail de votre compte Apple — Assurez-vous que vous pouvez accéder à l’adresse e-mail associée à votre compte Apple.

- La carte de crédit associée à votre compte Apple — Il pourrait vous être demandé de confirmer le CVV de la carte de crédit associée à votre compte Apple. Si la vérification est refusée par l’émetteur de la carte, vous recevez une alerte indiquant que les informations que vous avez saisies sont incorrectes (même si vous avez correctement saisi le CVV). Si cela se produit, sélectionnez « Je n’ai pas accès à cette carte ».

- Une clé de secours ou des clés de sécurité pour votre compte Apple — Si vous avez configuré l’une de ces fonctionnalités de sécurité facultatives, le processus pour récupérer l’accès à votre compte est différent. Découvrez comment récupérer l’accès à l’aide de votre [clé de secours](https://support.apple.com/fr-fr/109345) ou de votre [clé de sécurité physique](https://support.apple.com/fr-fr/102637) .

Lorsque vous essayez de réinitialiser votre mot de passe, ces facteurs de récupération peuvent vous être demandés. Gardez-les donc à portée de main.

## Si vous ne parvenez pas à réinitialiser votre mot de passe, demandez une récupération de compte

Par exemple, vous avez échangé votre ancien iPhone, vous n’avez pas d’autre appareil de confiance et vous avez déjà commencé à utiliser un nouveau numéro de téléphone.

Si vous n’avez pas d’appareil de confiance pour modifier vos mots de passe et que vous ne pouvez pas fournir de facteurs de récupération pour réinitialiser votre mot de passe, vous pouvez demander une récupération de compte pour qu’Apple vous aide à récupérer l’accès. Pour votre sécurité, ce processus peut prendre un certain temps, voire plusieurs jours.

### Où démarrer la récupération de compte

- Safari — À l’aide d’un appareil doté d’iOS 17 ou version ultérieure, ou de macOS 27 ou version ultérieure, accédez à [iforgot.apple.com](http://iforgot.apple.com/) à l’aide de Safari et suivez les instructions. Lorsque cela est possible, le site web vous redirige vers un appareil de confiance pour modifier votre mot de passe.

- L’app Assistance — Vous pouvez utiliser l’app Assistance sur un appareil emprunté ou sur un appareil dans un Apple Store. Ouvrez l’app Assistance, faites défiler l’écran jusqu’à Outils d’assistance, sélectionnez Réinitialiser le mot de passe, puis « Aider quelqu’un d’autre ». Les informations que vous saisissez ne seront pas stockées sur l’appareil emprunté.

[Trouver l’app Assistance dans l’App Store](https://apps.apple.com/app/apple-support/id1130498044?ppid=5e7c213d-dd8a-485d-acc0-e724f97419e6)

### Après avoir démarré la récupération de compte

- Si vous avez démarré la récupération de compte sur un appareil doté d’iOS 17, d’iPadOS 17 ou de macOS 27 ou version ultérieure, vous pouvez continuer à utiliser l’appareil que vous avez utilisé pour démarrer la récupération de compte. Si vous avez démarré la récupération de compte sur le web, éteignez tous vos appareils Apple pendant le délai d’attente de la récupération de compte.

- Si vous vous souvenez de votre mot de passe, vous pouvez vous connecter à votre appareil. Votre demande de récupération de compte sera alors annulée.

- Si vous trouvez un appareil sur lequel vous êtes connecté avec votre compte Apple, comme un ancien iPad que vous aviez oublié, utilisez-le pour modifier le mot de passe de votre compte. Votre demande de récupération de compte sera alors annulée.

- Si vous ne pouvez pas utiliser cet appareil (par exemple, si vous ne vous souvenez pas du code d’accès), éteignez-le. L’activité d’un appareil connecté annulera votre demande.
