# Si vous avez oublié le code d’accès de votre iPod touch

Vous avez oublié le code d’accès de votre iPod touch ? Découvrez comment mettre votre iPod touch en mode de récupération afin de l’effacer et de le configurer à nouveau.

- [Vous avez oublié le code d’accès de votre iPhone ?](https://support.apple.com/HT204306)

- [Vous avez oublié le code d’accès de votre iPad ?](https://support.apple.com/HT211078)

Si vous saisissez un code d’accès incorrect à de trop nombreuses reprises sur l’écran de verrouillage de votre iPod touch, vous recevrez un message d’alerte vous signalant que votre iPod touch est désactivé. (Découvrez la marche à suivre [si l’écran « [Appareil] non disponible » ou « Verrouillage de sécurité » s’affiche sur votre iPod touch](https://support.apple.com/HT212951) .)

Si vous saisissez à nouveau un code incorrect lors de la tentative suivante, vous devrez utiliser un ordinateur pour mettre votre iPod touch en mode de récupération. Ce processus supprime vos données et vos réglages, y compris votre code d’accès, et vous permet ainsi de configurer à nouveau votre iPod touch.

Après avoir effacé votre iPod touch, vous pouvez restaurer vos données et réglages à partir d’une sauvegarde. Si vous n’en avez fait aucune, vous pouvez le configurer en tant que nouvel appareil, puis télécharger les données dont vous disposez éventuellement dans iCloud.

[Image: Un iPod touch affichant un message qui indique que l’iPod est désactivé]

## Étape 1 : assurez-vous que vous disposez d’un ordinateur (Mac ou PC)

Ce processus requiert un Mac ou un PC. Si vous utilisez un PC, assurez-vous qu’il est doté de Windows 10 ou version ultérieure et que l’app [Appareils Apple](https://support.apple.com/guide/devices-windows/welcome/windows) ou [iTunes](https://support.apple.com/HT210384) est installé(e). Vous avez également besoin du câble fourni avec votre iPod touch, ou d’un câble compatible, pour connecter votre iPod touch à l’ordinateur.

Si vous n’avez pas accès à un ordinateur et que vous ne pouvez pas en emprunter un, vous devez vous rendre dans un [magasin Apple Store ou un centre de services agréé Apple](https://locate.apple.com/) pour obtenir de l’aide.

## Étape 2 : éteignez votre iPod touch

- Débranchez votre iPod touch de l’ordinateur, le cas échéant.

- Appuyez sur le bouton supérieur jusqu’à ce que le curseur Éteindre apparaisse.

[Image: Un iPod touch indiquant l’emplacement du bouton supérieur]

- Faites glisser le curseur pour éteindre votre iPod touch, puis patientez une minute pour vous assurer qu’il est complètement éteint.

## Étape 3 : mettez votre iPod touch en mode de récupération

- Préparez-vous en cherchant sur votre iPod touch le bouton que vous devrez maintenir enfoncé à l’étape suivante :

- Sur l’iPod touch (7e génération), utilisez le bouton de réduction du volume.

[Image: Un iPod touch indiquant l’emplacement du bouton de réduction du volume]

- Sur l’iPod touch (6e génération et modèles antérieurs), utilisez le bouton principal.

[Image: Un iPod touch indiquant l’emplacement du bouton principal]

- Appuyez sur le bouton correspondant à votre modèle d’iPod touch et maintenez-le enfoncé pendant que vous le connectez à l’ordinateur. Ne relâchez pas le bouton.

- Maintenez le bouton enfoncé jusqu’à ce que l’écran de connexion à votre ordinateur apparaisse sur votre iPod touch, puis relâchez-le.

[Image: Un iPod touch affichant l’écran du mode de récupération]

Si l’écran du code d’accès s’affiche, vous devez [éteindre votre iPod touch](https://support.apple.com/HT211080#turnoff) et recommencer.

Si vous n’arrivez pas à accéder à l’écran de connexion à votre ordinateur sur votre iPod touch et que vous avez besoin d’aide, [contactez l’assistance Apple](https://getsupport.apple.com/?caller=kbase&SG=SG003&category_id=SC0043&symptom_id=23249) .

## Étape 4 : restaurez votre iPod touch

- Repérez votre iPod touch dans le Finder, dans l’app Appareils Apple ou dans iTunes sur l’ordinateur auquel il est connecté. (Découvrez comment [localiser votre iPod touch connecté](https://support.apple.com/HT203060) .)

- Choisissez Restaurer sur l’écran vous invitant à procéder à une restauration ou à une mise à jour. Votre ordinateur télécharge le logiciel adapté à votre iPod touch et lance le processus de restauration. Si le téléchargement dure plus de 15 minutes et que l’écran de connexion à votre ordinateur se ferme, laissez le téléchargement se terminer, puis [éteignez votre iPod touch](https://support.apple.com/HT211080#turnoff) et recommencez.

[Image: Une fenêtre Mac montrant le bouton de restauration]

- Attendez que le processus se termine.

- Déconnectez votre iPod touch de l’ordinateur, puis [configurez-le pour pouvoir l’utiliser](https://support.apple.com/HT202033) .

## Besoin d’aide supplémentaire ?

Si vous ne pouvez effectuer aucune de ces étapes, si vous êtes toujours invité à saisir un code d’accès ou si vous avez besoin d’aide, [contactez l’assistance Apple](https://getsupport.apple.com/?caller=kbase&SG=SG003&category_id=SC0043&symptom_id=23249) .
