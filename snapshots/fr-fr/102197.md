# Utiliser la fonctionnalité Partagé avec vous sur votre iPhone et iPad

Vous pouvez utiliser Partagé avec vous pour retrouver du contenu que d’autres personnes partagent avec vous depuis les apps Musique, Apple TV, News, Photos, Podcasts et Safari.

## Trouver du contenu partagé

Le contenu qui est partagé avec vous dans l’app Messages est automatiquement organisé dans une section Partagé avec vous dans les apps Musique, Apple TV, News, Photos, Podcasts et Safari.

[Image: Icône d’Apple Music]

Musique : touchez l’onglet Écouter. Une section Partagé avec vous doit être disponible.

[Image: Icône de l’app Apple TV]

TV : touchez l’onglet Regarder. Partagé avec vous affiche les films et les séries qui ont été partagés avec vous.

[Image: Icône de l’app Safari]

Safari : ouvrez un nouvel onglet de navigateur et faites défiler la page au-delà de vos favoris sur la page de démarrage. Faites défiler l’écran vers le bas jusqu’à ce que la section Partagé avec vous apparaisse.

[Image: Icône de l’app Photos]

Photos : touchez l’onglet Pour vous, puis faites défiler l’écran vers le bas jusqu’à la section Partagé avec vous. Lorsque vous recevez plusieurs photos dans Messages, elles apparaissent sous la forme d’un collage que vous pouvez parcourir facilement.

[Image: Icône de l’app Podcasts]

Podcasts : touchez l’onglet Écouter et faites défiler l’écran jusqu’à ce que la section Partagé avec vous apparaisse.

[Image: Icône de l’app News]

News : touchez l’onglet Today (Aujourd’hui) et faites défiler l’écran jusqu’à ce que la section Partagé avec vous apparaisse.

Depuis chaque app prenant en charge la fonctionnalité Partagé avec vous, vous pouvez facilement répondre à la personne qui vous a envoyé le contenu. Touchez le nom de la personne figurant sous ou à côté du contenu partagé, puis répondez dans Messages.

## Continuer la conversation

Le contenu qui est partagé avec vous est automatiquement étiqueté dans les apps correspondantes. Cela vous permet de voir ultérieurement qui a partagé le contenu avec vous et de poursuivre facilement la conversation à ce sujet. Voici comment procéder :

- Accédez à la section Partagé avec vous de l’app.

- Touchez le contenu qui a été partagé avec vous.

- Touchez l’étiquette « De [Nom] » en regard du contenu.

- Répondez au contenu partagé, puis touchez le bouton Envoyer. .

## Épingler du contenu

Vous pouvez rapidement épingler dans Messages le contenu qui vous intéresse pour en garder une trace dans Partagé avec vous, dans les recherches effectuées dans Messages et dans la vue détaillée de la conversation. Voici comment procéder :

- Accédez à la conversation dans Messages.

- Maintenez votre doigt appuyé sur l’élément dans le fil de discussion.

- Touchez le bouton Épingler .

[Image: null]

[Image: iPhone affichant l’option d’épinglage du contenu]

Répétez les étapes pour détacher le contenu.

Pour rechercher du contenu épinglé :

- Accédez à la conversation dans Messages.

- Touchez le nom en haut du fil de discussion.

- Faites défiler l’écran vers le bas jusqu’à ce que la section Épingles apparaisse.

Vous pouvez également toucher la barre de recherche dans Messages pour afficher une section Épingles.

Vous pouvez enregistrer les photos dans votre photothèque, mais pas les épingler.

## Partager du contenu

Pour partager du contenu via l’app Messages sur les différentes apps qui prennent en charge la fonctionnalité Partagé avec vous :

Musique : sélectionnez le morceau ou l’album que vous souhaitez partager, puis touchez le bouton Plus . Touchez ensuite Partager , choisissez Messages, puis sélectionnez votre contact et envoyez le message.

[Image: null]

TV : sélectionnez la série TV ou le film que vous souhaitez partager, touchez le bouton Partager , choisissez Messages, puis sélectionnez votre contact et envoyez le message.

[Image: null]

Safari : accédez au site web que vous souhaitez partager, touchez le bouton Partager , choisissez Messages, puis sélectionnez votre contact et envoyez le message.

[Image: null]

Photos : sélectionnez la photo que vous souhaitez partager, touchez le bouton Partager , choisissez Messages, puis sélectionnez votre contact et envoyez le message.

[Image: null]

Podcasts : sélectionnez le podcast que vous souhaitez partager, touchez le bouton Plus , puis touchez le bouton Partager . Choisissez Messages, puis sélectionnez votre contact et envoyez le message.

[Image: null]

News : sélectionnez l’article que vous souhaitez partager, touchez le bouton Plus, puis touchez Partager l’article . Choisissez Messages, puis sélectionnez votre contact et envoyez le message.

## Contrôler le contenu partagé qui s’affiche dans les apps

Pour personnaliser le contenu qui apparaît dans la section Partagé avec vous :

- Accédez à Messages, puis touchez la conversation dont vous souhaitez masquer le contenu.

- Touchez le nom en haut du fil de discussion.

- Désactivez l’option Afficher dans Partagé avec vous.

[Image: iPhone affichant le bouton permettant d’activer ou de désactiver l’option Afficher dans Partagé avec vous]

- Touchez OK.

Le contenu apparaîtra toujours dans le fil de discussion de Messages, mais plus dans la section Partagé avec vous.

## Supprimer le contenu partagé

- Accédez à la section Partagé avec vous de l’app.

- Maintenez votre doigt appuyé sur la vignette du contenu, tel qu’un article d’actualités ou un podcast.

- Touchez Supprimer.

En fonction de l’app, vous pouvez voir différentes options pour supprimer le contenu partagé.

Pour personnaliser le contenu partagé que vous voyez dans Partagé avec vous dans les apps correspondantes :

- Accédez à Réglages > Apps > Messages.

- Touchez Partagé avec vous.

- Choisissez les apps dans lesquelles vous souhaitez voir le contenu partagé.

[Image: iPhone affichant les options de personnalisation des apps dans lesquelles vous voyez le contenu partagé]
