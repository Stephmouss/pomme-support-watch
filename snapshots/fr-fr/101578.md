# Création d’un programme d’installation amorçable pour macOS

Vous pouvez installer le système d’exploitation du Mac en utilisant une clé USB ou un autre volume secondaire comme disque de démarrage. Ces instructions sont principalement destinées aux administrateurs système et autres utilisateurs et utilisatrices avec de l’expérience.

- [Télécharger le programme d’installation complet de macOS](https://support.apple.com/fr-fr/101578#download)

- [Connecter une clé USB et la renommer](https://support.apple.com/fr-fr/101578#connect)

- [Copier la commande appropriée](https://support.apple.com/fr-fr/101578#copycommand)

- [Saisir la commande dans Terminal](https://support.apple.com/fr-fr/101578#entercommand)

- [Utiliser le programme d’installation amorçable](https://support.apple.com/fr-fr/101578#use)

## Avez-vous besoin d’un programme d’installation amorçable ?

Vous n’avez pas besoin d’un programme d’installation amorçable pour [mettre à niveau](https://support.apple.com/fr-fr/108382) ou [réinstaller macOS](https://support.apple.com/fr-fr/102655) . Toutefois, cela peut s’avérer utile si l’une de ces procédures ou une [autre méthode d’installation de macOS](https://support.apple.com/fr-fr/102662) échoue, ou si vous souhaitez installer macOS sur plusieurs ordinateurs sans télécharger chaque fois le programme d’installation.

La création d’un programme d’installation amorçable est différente de la [préparation d’un périphérique de stockage externe que vous utiliserez comme disque de démarrage](https://support.apple.com/fr-fr/111336) .

## Télécharger le programme d’installation complet de macOS

- Obtenez le programme d’installation complet en le téléchargeant depuis l’App Store, votre navigateur web ou Terminal à l’aide des instructions de l’article [Télécharger et installer macOS](https://support.apple.com/fr-fr/102662) .

- Pour obtenir le programme d’installation, téléchargez-le simplement, sans l’exécuter. Si le programme d’installation s’ouvre automatiquement après son téléchargement, fermez-le.

- Dans la plupart des cas, vous devez procéder au téléchargement à partir d’un Mac compatible avec la version de macOS que vous souhaitez obtenir. Pour les versions de macOS antérieures à macOS High Sierra 10.13, vous devez également créer le programme d’installation amorçable sur un modèle de Mac antérieur compatible avec cette version.

- Administrateurs d’entreprise : procédez au téléchargement depuis le site d’Apple, et non depuis un serveur de mise à jour hébergé localement.

- Vérifiez le nom du programme d’installation après l’avoir téléchargé. Il doit s’agir d’une app dont le nom est « Installer [Nom de la version] », comme « Installer macOS Tahoe ». Si le fichier est une image disque (.dmg) ou un paquet (.pkg), consultez les instructions de téléchargement pour savoir comment obtenir le programme d’installation à partir de ces fichiers.

- Vérifiez l’emplacement du programme d’installation. Celui-ci doit se trouver dans le dossier Applications, auquel vous pouvez accéder en choisissant Aller > Applications dans la barre des menus du Finder. Si nécessaire, déplacez le programme d’installation dans ce dossier.

## Connecter une clé USB et la renommer

- Connectez une clé USB ou un autre volume secondaire directement à votre Mac. Lors de la création du programme d’installation amorçable, cette clé sera effacée en utilisant le format approprié, Mac OS étendu (journalisé).

- Vérifiez la capacité de stockage de la clé. Une clé de 32 Go est dotée d’un espace de stockage plus que suffisant pour télécharger n’importe quel programme d’installation de macOS. Une clé de 16 Go est quant à elle suffisante pour la plupart des versions antérieures de macOS. Terminal vous avertira si l’espace de stockage n’est pas suffisant.

- [Renommez](https://support.apple.com/guide/mac-help/mchlp1144/mac) la clé pour l’intituler « MyVolume », le nom utilisé dans les commandes Terminal ci-dessous.

## Copier la commande appropriée

Cliquez trois fois ou faites glisser votre souris dans la zone correspondant à la version de macOS que vous avez téléchargée pour sélectionner la commande entière. Appuyez ensuite sur Commande + C pour copier la commande dans le presse-papiers.

### Tahoe

sudo /Applications/Install\ macOS\ Tahoe.app/Contents/Resources/createinstallmedia --volume /Volumes/MyVolume

### Sequoia

sudo /Applications/Install\ macOS\ Sequoia.app/Contents/Resources/createinstallmedia --volume /Volumes/MyVolume

### Sonoma

sudo /Applications/Install\ macOS\ Sonoma.app/Contents/Resources/createinstallmedia --volume /Volumes/MyVolume

### Ventura

sudo /Applications/Install\ macOS\ Ventura.app/Contents/Resources/createinstallmedia --volume /Volumes/MyVolume

### Monterey

sudo /Applications/Install\ macOS\ Monterey.app/Contents/Resources/createinstallmedia --volume /Volumes/MyVolume

### Big Sur

sudo /Applications/Install\ macOS\ Big\ Sur.app/Contents/Resources/createinstallmedia --volume /Volumes/MyVolume

### Catalina

sudo /Applications/Install\ macOS\ Catalina.app/Contents/Resources/createinstallmedia --volume /Volumes/MyVolume

### Mojave

sudo /Applications/Install\ macOS\ Mojave.app/Contents/Resources/createinstallmedia --volume /Volumes/MyVolume

### High Sierra

sudo /Applications/Install\ macOS\ High\ Sierra.app/Contents/Resources/createinstallmedia --volume /Volumes/MyVolume

### El Capitan

sudo /Applications/Install\ OS\ X\ El\ Capitan.app/Contents/Resources/createinstallmedia --volume /Volumes/MyVolume --applicationpath /Applications/Install\ OS\ X\ El\ Capitan.app

## Saisir la commande dans Terminal

- Ouvrez Terminal, dans le sous-dossier Utilitaires du dossier Applications. Vous pouvez également rechercher et ouvrir cette app en utilisant Spotlight dans la barre des menus.

[Image: null]

- Collez la commande que vous avez copiée ci-dessus ou saisissez-la dans Terminal. Appuyez ensuite sur la touche Retour pour valider la commande.

- Lorsque vous y êtes invité, saisissez votre mot de passe d’administrateur et appuyez sur Retour. Terminal n’affiche aucun des caractères au cours de la saisie.

- Si un message vous indique que le programme d’installation ne semble pas être une application d’installation valide, supprimez-le, [réparez votre disque de démarrage à l’aide d’Utilitaire de disque](https://support.apple.com/fr-fr/102611) , puis téléchargez à nouveau le programme d’installation.

- Si un message vous indique que la commande est introuvable, assurez-vous que vous avez saisi la bonne commande et que le programme d’installation se trouve dans votre dossier Applications et se nomme bien « Installer [Nom de la version] ». Si vous créez le programme d’installation amorçable sur un Mac doté de macOS Sierra 10.12.6 ou version antérieure, ajoutez --applicationpath à la commande, suivi du chemin d’accès au programme d’installation approprié, comme à la fin de la commande fournie pour El Capitan.

- Lorsque vous y êtes invité, saisissez Y pour confirmer l’effacement du volume, puis appuyez sur Retour. Terminal affiche la progression à mesure que le volume est effacé.

- Si un message vous indique que Terminal souhaite accéder à des fichiers sur un volume amovible, cliquez sur OK pour autoriser Terminal à continuer.

- Si Terminal ne parvient pas à effacer le volume, [effacez-le à l’aide d’Utilitaire de disque](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac) en choisissant le format Mac OS étendu (journalisé), puis réessayez.

- Une fois que Terminal indique que le support d’installation est prêt, votre clé USB doit avoir le même nom que le programme d’installation, comme « Installer macOS Tahoe ».

- Quittez Terminal, éjectez la clé et déconnectez-la de votre Mac. Vous pouvez à présent supprimer le programme d’installation de votre dossier Applications.

## Utiliser le programme d’installation amorçable

Suivez les instructions correspondant au modèle de Mac sur lequel vous utilisez le programme d’installation amorçable ( [Mac avec puce Apple](https://support.apple.com/fr-fr/116943) ou non).

Important : votre Mac doit être connecté à Internet pour que le programme d’installation puisse télécharger le programme interne et d’autres données spécifiques à ce modèle. Si la version de macOS que vous installez n’est pas compatible avec votre Mac, l’installation peut ne pas aboutir ou [un cercle barré peut s’afficher au démarrage](https://support.apple.com/fr-fr/101666) de votre Mac.

### Mac avec puce Apple

- Éteignez votre Mac.

- Connectez le support du programme d’installation amorçable directement à votre Mac.

- Appuyez sur le bouton d’alimentation de votre Mac et maintenez-le enfoncé. Pendant cette manipulation, votre Mac démarre et charge les [options de démarrage](https://support.apple.com/fr-fr/102342) . Cet écran affiche la liste des volumes de démarrage, y compris le programme d’installation amorçable.

- Sélectionnez le programme d’installation amorçable, puis cliquez sur Continuer.

- Lorsque le programme d’installation de macOS s’ouvre, suivez les instructions à l’écran.

### Autre Mac

- Éteignez votre Mac.

- Connectez le support du programme d’installation amorçable directement à votre Mac.

- Allumez votre Mac, puis maintenez immédiatement la touche Option (Alt) enfoncée.

- Relâchez la touche Option lorsqu’un écran s’affiche avec vos volumes de démarrage, dont le programme d’installation amorçable.

- Sélectionnez le programme d’installation amorçable, puis cliquez sur la flèche à l’écran ou appuyez sur Retour.

- Si vous utilisez un [Mac doté de la puce Apple T2 Security](https://support.apple.com/fr-fr/103265) et que vous ne parvenez pas à démarrer à partir du programme d’installation amorçable, assurez-vous que [l’utilitaire Sécurité au démarrage](https://support.apple.com/fr-fr/102522) est configuré pour autoriser le démarrage à partir d’un support externe ou amovible.

- Choisissez votre langue, si vous y êtes invité.

- Sélectionnez Installer macOS (ou Installer OS X) dans la fenêtre Utilitaires, puis cliquez sur Continuer et suivez les instructions à l’écran.
