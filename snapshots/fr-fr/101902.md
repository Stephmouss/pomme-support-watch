# Remplacer les modules Camel Audio par les versions de Logic Pro pour Mac

Alchemy, Phat FX et Step FX s’appuient sur des technologies précédemment utilisées dans Camel Audio Alchemy, CamelPhat, CamelCrusher et CamelSpace.

Si vous utilisez des modules Camel Audio, vous pouvez passer aux versions Logic Pro de ces modules :

- Utiliser Logic Pro Alchemy au lieu de Camel Audio Alchemy.

- Utiliser Phat FX au lieu de CamelPhat et CamelCrusher (les réglages de CamelPhat et de CamelCrusher sont transférés vers PhatFX).

- Utiliser Step FX au lieu de CamelSpace.

Lorsque vous passez des versions Camel Audio aux versions Logic Pro, les réglages sont conservés. Vous pouvez basculer automatiquement ou manuellement.

## Basculer automatiquement vers les versions de Logic Pro

Logic Pro peut remplacer automatiquement les modules Camel Audio par leur équivalent dans la version Logic Pro. Si vous ouvrez un projet contenant un module Camel Audio qui n’est pas installé sur votre Mac, cliquez sur Tout remplacer dans la boîte de dialogue qui apparaît. Les réglages existants sont également transférés vers la version Logic Pro du module.

## Basculer manuellement vers les versions de Logic Pro

- Dans Logic Pro, sélectionnez la piste contenant le module Camel Audio.

- Dans la tranche de console de la piste sélectionnée, placez le pointeur sur le slot Instrument ou Effet audio contenant le module, puis cliquez sur les flèches du menu contextuel qui apparaissent à droite.

- Choisissez la version Logic Pro appropriée du module :

- Choisissez Alchemy dans le niveau supérieur du menu.

- Choisissez Phat FX ou Step FX dans le menu Multi Effects.

## Accéder aux anciens préréglages de Camel Audio Alchemy

Si vous avez créé des préréglages avec la version Camel Audio d’Alchemy, vous pouvez y accéder dans le navigateur de la version de Logic Pro.

- Assurez-vous que vos anciens préréglages de Camel Audio Alchemy se trouvent à cet emplacement sur votre Mac : /Bibliothèque/Application Support/Camel Audio/Alchemy/Préréglages.

- Dans la fenêtre du module Alchemy de Logic Pro, cliquez sur Parcourir, puis sélectionnez Bibliothèque de sons dans le menu local situé au-dessus de l’une des deux dernières colonnes.

- Cochez la case Ancien contenu. Vous pouvez désormais accéder à vos anciens préréglages dans le navigateur Logic Pro Alchemy.
