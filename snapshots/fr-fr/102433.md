# Utiliser le mode Faibles données sur votre iPhone et iPad

Avec iOS 13 et versions ultérieures, vous pouvez activer le mode Faibles données pour limiter l’utilisation du réseau en arrière-plan et économiser vos données.

Si votre forfait mobile ou Internet limite votre utilisation des données, ou si vous vous trouvez dans une zone où la vitesse de transmission des données est faible, vous voudrez peut-être utiliser le mode Faible données.

## Activer le mode Faibles données

Vous pouvez activer le mode Faibles données séparément pour la connexion mobile et Wi-Fi. Les réglages du mode Faibles données peuvent varier en fonction de votre opérateur. Sélectionnez ci-dessous le type de forfait dont vous disposez et suivez les étapes correspondantes.

### Forfait mobile LTE/4G

- Accédez à Réglages et touchez Données cellulaires.

- Touchez Options, puis activez le mode Faibles données.

### Forfait mobile 5G

- Accédez à Réglages et touchez Données cellulaires.

- Touchez Options, sélectionnez Mode de données, puis activez le mode Faibles données.

### Double SIM

- Accédez à Réglages et touchez Données cellulaires ou Données mobiles.

- Touchez l’un de vos numéros.

- Activez le mode Faibles données.

### Wi-Fi

- Accédez à Réglages et touchez Wi-Fi.

- Touchez le bouton Infos en regard du réseau Wi-Fi auquel vous êtes connecté.

[Image: bouton Infos]

- Activez le mode Faibles données.

iCloud maintient à jour vos préférences Faibles données pour chaque réseau Wi-Fi sur tous vos appareils.

## À quoi faut-il s’attendre avec le mode Faibles données ?

En mode Faibles données, les apps réduisent chacune leur utilisation des données de manière différente. En général, voici ce à quoi vous pouvez vous attendre :

- Le mode Faibles données arrête d’utiliser les données réseau lorsque vous n’utilisez pas activement ces apps.

- Il désactive l’option Actualisation en arrière-plan.

- Il réduit la qualité du contenu diffusé en continu.

- Il désactive les téléchargements et les sauvegardes automatiques.

- Il met en pause les mises à jour pour les services tels qu’iCloud Photos.

Les apps et services iOS intégrés s’adaptent au mode Faibles données des manières suivantes :

- App Store : la lecture automatique des vidéos, les mises à jour automatiques et les téléchargements automatiques sont désactivés.

- Musique : les téléchargements automatiques et la diffusion en haute qualité sont désactivés.

- Podcasts : la fréquence de mise à jour des flux est limitée, et l’appareil ne télécharge les épisodes que lorsqu’il est connecté au Wi-Fi.

- News : le préchargement d’articles est désactivé.

- iCloud : les mises à jour et les sauvegardes automatiques sont suspendues, et les mises à jour iCloud Photos sont désactivées.

- FaceTime : le débit vidéo est optimisé pour une bande passante inférieure.
