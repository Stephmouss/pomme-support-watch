# À propos de la mise à jour 2.1.1 d’OS X Server

En savoir plus sur la mise à jour 2.1.1 d’OS X Server pour Mountain Lion.

Ce logiciel met à jour OS X Server 2.0 ou 2.1 vers la version 2.1.1. Cette mise à jour est recommandée pour tous les utilisateurs d’OS X Server (Mountain Lion).

### Installation de la mise à jour

OS X Server version 2.1.1 est disponible sur le Mac App Store. Il apparaîtra dans la sous-fenêtre Mises à jour si vous avez installé la version 2.0 ou 2.1 d’OS X Server (Mountain Lion). Cliquez sur le bouton Mettre à jour pour procéder à l’installation.

Si l’app Server est en cours d’exécution lorsque vous installez la mise à jour, vous serez invité à la quitter.

Lors de l’installation, le message « Suppression de l’app Server détectée » peut s’afficher. Ceci est normal. L’intégralité des réglages et des données de l’app Server est conservée lors de la mise à jour.

Une fois l’installation terminée, ouvrez l’app Server et sélectionnez votre serveur dans la liste des Mac disponibles. L’app Server terminera la configuration de tous les services précédemment configurés.

### Que comprend cette mise à jour ?

Voici certaines des améliorations incluses dans cette mise à jour :

### App Server

- L’app Server a maintenant la possibilité de gérer le service DHCP. Pour en savoir plus à ce sujet, consultez l’article dédié au service DHCP.

- Permet de gérer les réglages de la liste noire du service Mail.

- Empêche les faux messages d’alerte « Nom d’hôte modifié » après un redémarrage.

- Résout un problème où, dans certaines circonstances, les bornes d’accès AirPort ne pouvaient pas être gérées après une mise à niveau à partir d’une version précédente d’OS X Server.

- Permet de définir une image NetBoot par défaut dans l’app Server.

- Résout un problème où la migration à partir des versions précédentes de l’app Server pourrait ne pas fonctionner si certaines langues étaient utilisées.

- Permet aux utilisateurs d’Active Directory de s’authentifier auprès du service Calendrier après la migration à partir des versions précédentes d’OS X Server.

### Service Mail

- Résout plusieurs problèmes avec le service Mail après la migration à partir des versions précédentes d’OS X Server.

### Gestionnaire de profils

- Permet de gérer la possibilité de se connecter au Mac App Store uniquement pour les mises à jour logicielles.

- Permet la gestion des fonctionnalités d’iOS 6.

### Service de mises à jour logicielles

- Résout un problème où les fichiers de catalogue n’étaient pas correctement mis à jour après la migration à partir d’une version précédente d’OS X Server.

### Service Site Web

- Résout plusieurs problèmes liés à la migration à partir des versions précédentes d’OS X Server.

Pour en savoir plus sur les correctifs de sécurité de Lion Server 10.7.5, consultez [cet article](http://support.apple.com/HT1222) .

Remarque : si vous effectuez une mise à jour à partir de la version 2.0 ou 2.1 d’OS X Server (Mountain Lion), les services disponibles sur le Web tels que Wiki et Gestionnaire de profils qui s’exécutaient avant la mise à jour peuvent ne plus être accessibles après la mise à jour. Afin de les rendre accessibles, utilisez l’app Server pour arrêter et redémarrer les services concernés.

## Informations supplémentaires

Si le service Messages ne démarre pas après la mise à jour vers la version 2.1 d’OS X Server, procédez comme suit :

- Quittez l’app Server.

- Placez l’app Server dans la corbeille.

- Téléchargez et installez la version 2.1.1 d’OS X Server.

Si le service DNS ne fonctionne pas correctement suite à la mise à jour vers la version 2.1 d’OS X Server, procédez comme suit :

- Téléchargez et installez la version 2.1.1 d’OS X Server.

- Ouvrez l’app Server et suivez les instructions à l’écran pour terminer la configuration.

- Activez le service DNS.

- Ouvrez Préférences Système.

- Cliquez sur la sous-fenêtre Réseau des Préférences.

- Sélectionnez l’interface réseau principale du serveur.

- Cliquez sur le bouton Avancé.

- Cliquez sur l’onglet DNS.

- Supprimez toutes les adresses de serveur DNS hormis 127.0.0.1.

- Si nécessaire, ajoutez 127.0.0.1 à la liste des serveurs DNS.
