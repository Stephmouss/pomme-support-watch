# Réglages du serveur Mail iCloud pour les autres applications client de messagerie

Si vous ne disposez pas de la configuration système requise pour iCloud, utilisez ces réglages du serveur Mail iCloud pour configurer manuellement votre compte Mail iCloud dans une application client de messagerie.

## Dans quel cas définir ces réglages ?

Si vous disposez de la [configurtion système requise pour iCloud](https://support.apple.com/fr-fr/118308) , vous n’avez pas besoin de configurer manuellement votre compte Mail iCloud. Utilisez l’une de ces méthodes de configuration pour votre application de messagerie tierce :

- Sur votre iPhone ou iPad exécutant iOS 11 ou version ultérieure, ou votre Mac doté de macOS High Sierra 10.13 ou version ultérieure, [utilisez Réglages ou Préférences iCloud](https://support.apple.com/guide/icloud/mmfc0f1e2a/) .

- Sur votre PC sous Microsoft Windows avec Outlook 2021 ou version ultérieure, [autorisez l’application à l’aide de votre compte Apple](https://support.apple.com/fr-fr/121539) .

## Réglages du serveur Mail iCloud

Mail iCloud utilise les normes IMAP et SMTP, prises en charge par la plupart des applications client de messagerie modernes. Mail iCloud ne prend pas en charge le protocole POP. Consultez la documentation de votre application client de messagerie pour savoir comment définir ces réglages.

### Informations IMAP pour le serveur Mail iCloud entrant

- Nom du serveur : imap.mail.me.com

- Protocole SSL obligatoire : oui

- Si un message d’erreur s’affiche lors de l’utilisation du protocole SSL, utilisez le protocole TLS.

- Port : 993

- Nom d’utilisateur : il s’agit généralement du nom de votre adresse e-mail Mail iCloud (par exemple, johnappleseed, et non johnappleseed@icloud.com). Si votre application client de messagerie ne parvient pas à se connecter à Mail iCloud lorsque seule la partie de l’adresse incluant votre nom est indiquée, essayez de saisir l’adresse dans son intégralité.

- Mot de passe : [générez un mot de passe pour application](https://support.apple.com/fr-fr/102654) .

### Informations SMTP pour le serveur Mail iCloud sortant

- Nom du serveur : smtp.mail.me.com

- Protocole SSL obligatoire : oui

- Si un message d’erreur s’affiche lors de l’utilisation du protocole SSL, utilisez le protocole TLS ou STARTTLS.

- Port : 587

- Authentification SMTP obligatoire : oui

- Nom d’utilisateur : votre adresse e-mail Mail iCloud complète (par exemple, johnappleseed@icloud.com, et non johnappleseed).

- Mot de passe : utilisez le mot de passe pour application que vous avez généré lors de la configuration du serveur de messagerie entrant.
