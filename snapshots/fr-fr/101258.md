# OS X Server : mise à niveau et migration depuis Lion Server ou Snow Leopard Server

Découvrez comment effectuer une mise à niveau ou une migration vers OS X Server sous Mavericks ou Mountain Lion à partir de Lion Server ou de Mac OS X Server version 10.6.

Vous pouvez effectuer une mise à niveau vers OS X Server sous Mavericks ou Mountain Lion à partir de Lion Server ou de Mac OS X Server version 10.6 en commençant par installer OS X, puis l’app OS X Server.

Vous pouvez effectuer une migration vers OS X Server sous Mavericks ou Mountain Lion depuis Lion Server ou Mac OS X Server version 10.6 en migrant les données du serveur à partir de l’une des sources suivantes à l’aide de l’Assistant migration ou de l’Assistant réglages d’OS X :

- Un serveur connecté en mode disque cible

- Une partition locale ou un disque dur local sur lequel Lion Server ou Mac OS X Server version 10.6 est installé

- Une sauvegarde Time Machine locale de Lion Server ou de Mac OS X Server version 10.6

Important : avec OS X Server, il est impossible d’effectuer une migration via une connexion réseau à partir d’un serveur existant ou d’une sauvegarde Time Machine. Pour mettre à niveau ou migrer un serveur distant, vous devez être en mesure de contrôler le serveur à l’aide du partage d’écran ou d’Apple Remote Desktop.

Si vous effectuez une mise à niveau à partir d’OS X Server (Mountain Lion) vers OS X Server (Mavericks), consultez [cet article](http://support.apple.com/HT5996) .

## Données de services

Dans la plupart des cas, vos données et réglages de service sont conservés lors de la mise à niveau ou de la migration. Consultez les exceptions et les instructions spéciales ci-dessous avant de mettre à niveau ou de migrer votre serveur.

Les données de service stockées à l’emplacement par défaut sous Lion Server ou Snow Leopard Server sont déplacées vers le nouvel emplacement de données de service par défaut dans le répertoire /Bibliothèque/Server/. Les données de service stockées à un autre emplacement y restent.

Remarque : si vous avez sélectionné un autre emplacement de stockage de données sous Lion Server, seuls [les services qui utilisaient cet autre emplacement sous Lion](http://support.apple.com/HT4974) utilisent cet emplacement sous Mountain Lion. Les autres services utilisent l’emplacement par défaut et ne peuvent pas être déplacés vers l’autre emplacement.

## Planification de votre mise à niveau ou migration

Important : avant de lancer une mise à niveau ou une migration, vérifiez que vous disposez d’une sauvegarde ou d’un clone complet et fiable de l’installation et des données de votre serveur actuel.

Vérifiez que votre serveur cible dispose de la configuration système requise par OS X et OS X Server. Veillez à installer la dernière version d’OS X Server sur le serveur de destination. Les instructions suivantes concernent OS X Server versions 3 et ultérieures pour Mavericks ainsi qu’OS X Server versions 2.2.2 et ultérieures pour Mountain Lion. Si le serveur de destination est un nouveau Mac mini ou Mac Pro, vous devrez peut-être utiliser le Mac App Store pour mettre à jour votre copie d’OS X Server avant d’effectuer la migration.

Utilisez l’outil Mise à jour de logiciels de votre serveur source pour installer la dernière version de Lion Server ou de Mac OS X Server version 10.6 Snow Leopard.

Avant de lancer le processus, lisez dans son intégralité la section ci-dessous, qui s’applique au chemin de mise à niveau ou de migration. Exportez ou notez les réglages qui ne seront pas mis à niveau ou migrés.

Assurez-vous que tous les serveurs DNS ou DHCP dont votre serveur dépend restent disponibles tout au long de la mise à niveau ou de la migration.

Si vous disposez de répliques Open Directory, commencez par mettre à niveau ou migrer votre maître Open Directory. Assurez-vous qu’il est opérationnel avant de migrer les répliques. Pendant la mise à niveau du maître, les ordinateurs clients ne peuvent pas s’y connecter pour accéder aux services Open Directory. La localisation d’un serveur de répliques Open Directory par les clients peut prendre un certain temps. Pour éviter cela, vous pouvez rediriger temporairement les clients vers une réplique.

Les versions Lion et Snow Leopard n’étant pas prises en charge par Mountain Lion, l’app Server et les outils d’administration du serveur sont supprimés lors de la mise à niveau.

## Mise à niveau à partir de Lion Server ou de Mac OS X Server version 10.6 Snow Leopard

Pour effectuer une mise à niveau, commencez par télécharger et installer Mountain Lion depuis le Mac App Store. Une fois l’installation terminée, suivez les instructions du programme d’installation et de l’Assistant réglages. Lorsque vous avez installé et configuré Mountain Lion, téléchargez et installez Server à partir du Mac App Store. Ouvrez l’app Server et suivez les instructions à l’écran pour terminer la mise à niveau.

### Calendrier

Le service iCal s’appelle désormais Calendrier.

### Contacts

Le service Carnet d’adresses s’appelle désormais Contacts.

### DHCP

Si vous avez activé le protocole DHCP (uniquement) sous Lion Server ou que vous l’avez activé sous Mac OS X Server version 10.6, votre configuration est conservée et reste active après la mise à niveau.

Si vous avez activé le service NAT et le protocole DHCP dans Admin Serveur sous Lion Server, votre configuration n’est pas conservée lors de la mise à niveau. Pour plus d’informations, consultez cet article.

### Services de fichiers

Après la mise à niveau, il est possible que les clients AFP ne puissent plus s’authentifier à l’aide de Kerberos. Le service AFP peut référencer l’option LKDC, comme le décrit cet article.

### Coupe-feu

Le coupe-feu n’est plus géré par OS X Server. Les règles de coupe-feu existantes restent actives après la mise à niveau, mais les configurations ultérieures du coupe-feu doivent être effectuées à partir de la ligne de commande. Pour plus d’informations, consultez cet article.

### FTP

Les réglages FTP ne sont pas conservés lors de la mise à niveau à partir de Mac OS X Server version 10.6 Snow Leopard (uniquement), car les versions ultérieures de Server utilisent un logiciel FTP différent de celui de Snow Leopard. Vous pouvez configurer le protocole FTP dans l’app Server sous OS X Server.

### Mail

Webmail ne fait plus partie des fonctionnalités du service Mail sous OS X Server.

Les règles de messagerie côté serveur ne peuvent pas être activées ou désactivées dans l’app Server. Les règles existantes côté serveur seront conservées lors de la mise à niveau.

Une fois la migration terminée, il est possible que vous deviez à nouveau définir votre quota de stockage de messages par utilisateur.

### Messages

Le service iChat s’appelle désormais Messages.

Les réglages « Activer la fédération de serveur à serveur » et « Archiver tous les messages » peuvent être désactivés lorsque vous procédez à la mise à niveau vers OS X Server (Mavericks). Vérifiez ces réglages et, le cas échéant, réactivez-les.

### Service NAT

Le service NAT était fourni par le fichier binaire natpmpd sous Lion Server et natd sous Snow Leopard Server. Sous Mountain Lion et Mavericks, le fichier natd est obsolète et le fichier natpmpd est utilisé par la fonctionnalité Partage Internet, disponible dans la sous-fenêtre Partage des Préférences Système.

Si vous avez activé le service NAT dans Admin Serveur sous Lion Server, votre configuration ne sera pas conservée lors de la mise à niveau. Vous pouvez restaurer la configuration NAT par défaut en désactivant, puis en réactivant la fonctionnalité Partage Internet dans Préférences Système. Cette opération permet de s’assurer que les services NAT utilisent la plage d’adresses IP par défaut comprise entre 192.168.2.2 et 192.168.2.254. Important : vous ne pouvez pas utiliser la fonctionnalité Partage Internet et le service DHCP en même temps sous OS X Server. Pour plus d’informations, consultez cet article.

Si vous avez créé des règles NAT à l’aide de la commande pfctl sous Lion Server, elles seront conservées et resteront actives lors de la mise à niveau.

Si vous avez activé le service NAT sous Snow Leopard Server, votre configuration natd est désactivée après la mise à niveau. Vos fichiers de configuration sont conservés dans /Bibliothèque/Server/Migrated/private/etc/nat/.

### NetInstall

Le service NetBoot s’appelle désormais NetInstall.

### Open Directory

Lorsque vous mettez à niveau un maître Open Directory, suivez les instructions de [cet article](http://support.apple.com/HT5300) .

Après la mise à niveau vers OS X Server (Mavericks), il est possible que le message « Connexion existante non authentifiée : modification du mot de passe refusée » s’affiche. Consultez [cet article](http://support.apple.com/HT200018) pour en savoir plus.

### Podcast

Le service Podcast a été supprimé d’OS X Server. Le contenu existant du service Podcast est conservé lors de la mise à niveau, comme le décrit [cet article](http://support.apple.com/kb/TS4331) .

### Service RADIUS

Le service RADIUS n’est plus géré en tant que service distinct dans l’app Server. Les configurations RADIUS existantes restent actives après la mise à niveau, même si elles peuvent apparaître inactives dans l’app Server tant que vous n’actualisez pas le service (à partir du menu Présentation). Pour en savoir plus, consultez [cet article](http://support.apple.com/HT5415) .

### Sites web

Le service web s’appelle désormais Sites web. Différentes options de configuration sont disponibles après la mise à niveau. Pour en savoir plus sur l’impact de la mise à niveau sur les réglages existants, consultez [cet article](http://support.apple.com/HT5382) .

### Wiki

Les thèmes Wiki de Mac OS X Server version 10.6 Snow Leopard ne sont pas conservés lors de la mise à niveau. Après celle-ci, vous devrez sélectionner un nouveau thème pour chaque wiki.

### Autres services Mac OS X Server version 10.6 Snow Leopard

Les services suivants de Snow Leopard Server ont été supprimés sous Lion Server et ne sont plus disponibles sous OS X Server : Accès mobile, MySQL, Imprimer, Tomcat, Axis, QuickTime Streaming Server (QTSS) et les listes de diffusion et les archives basées sur Wiki.

## Migration à partir de Lion Server ou de Mac OS X Server version 10.6 Snow Leopard

Pour effectuer la migration, commencez par installer Mountain Lion sur un nouveau Mac ou un nouveau volume sur un serveur existant, ou commencez avec un nouveau Mac sur lequel Mountain Lion est préinstallé.

À l’aide de l’Assistant migration ou de l’Assistant réglages de Mountain Lion, sélectionnez la source de la migration :

- Un serveur connecté en mode disque cible

- Une partition locale ou un disque dur local sur lequel Lion Server ou Snow Leopard Server est installé

- Une sauvegarde Time machine locale de Lion Server ou de Snow Leopard Server

Une fois la migration terminée, téléchargez et installez Server à partir du Mac App Store (si l’app n’est pas préinstallée). Ouvrez l’app Server et suivez les instructions à l’écran pour terminer la configuration du serveur.

Remarque : si vous ouvrez l’app Server avant de migrer les données du serveur, vous devrez supprimer l’app Server avant la migration, puis la réinstaller après.

### Notifications d’alerte

Afin de pouvoir recevoir des notifications d’alerte, vous devez à nouveau saisir toutes les adresses e-mail applicables après la migration depuis un serveur qui exécute Snow Leopard.

Le service iCal s’appelle désormais Calendrier.

### Contacts

### DHCP

Si vous avez activé le service NAT et le protocole DHCP dans Admin Serveur sous Lion Server, votre configuration ne sera pas conservée lors de la migration. Pour plus d’informations, consultez cet article.

### Services d’annuaire

Si vous effectuez la migration depuis un serveur qui exécute Snow Leopard et qui est lié à Active Directory vers OS X (Mavericks), vous devez exécuter la commande Terminal suivante avant d’installer OS X Server :

sudo /System/Library/Frameworks/OpenDirectory.framework/odmigrationtool -source /path/to/source -target /

Où /path/to/source est remplacé par le chemin d’accès au volume à partir duquel vous effectuez la migration.

### Services de fichiers

Les points de partage ne sont pas conservés lors de la migration vers Mountain Lion (uniquement). Consultez [cet article](http://support.apple.com/HT5387) pour obtenir des instructions sur l’enregistrement des informations relatives aux points de partage avant la migration.
