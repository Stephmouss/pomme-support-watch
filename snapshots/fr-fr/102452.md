# Utilisez Face ID même en portant un masque avec l’iPhone 12 ou modèle ultérieur

Avec iOS 15.4 ou version ultérieure, vous pouvez déverrouiller votre iPhone avec Face ID même lorsque vous portez un masque.

Si vous portez un masque facial ou un autre accessoire qui couvre le visage, la fonction « Face ID avec un masque » peut analyser les traits uniques du contour de vos yeux. Même avec un masque, vous pouvez vous authentifier pour vous connecter à des apps, déverrouiller votre iPhone et utiliser Apple Pay [à l’aide de Face ID](https://support.apple.com/108411) .

Cette fonctionnalité est disponible sur l’iPhone 12 et les modèles ultérieurs dotés d’iOS 15.4 ou version ultérieure.

## Comment configurer Face ID pour qu’il soit compatible avec le port d’un masque facial

- Assurez-vous que votre iPhone est doté d’iOS 15.4 ou version ultérieure.

- Ouvrez Réglages, puis touchez Face ID et code.

- Faites défiler l’écran vers le bas et activez Face ID avec un masque.

[Image: La rubrique Face ID et Code des réglages comporte une option permettant d’activer Face ID avec un masque.]

- Lorsque vous y êtes invité, touchez Utiliser Face ID avec un masque. Suivez les instructions à l’écran pour [configurer Face ID en suivant le même processus d’analyse du visage](https://support.apple.com/108411) .

Vous pouvez également [déverrouiller votre iPhone à l’aide de votre Apple Watch tout en portant un masque](https://support.apple.com/102438) .

Si votre masque remonte trop haut sur votre visage ou se trouve trop près de vos yeux, il est possible que votre iPhone ne se déverrouille pas à l’aide de Face ID. Cette fonctionnalité exige que vos yeux soient bien visibles.

Vous ne pouvez pas utiliser Face ID en mode paysage lorsque vous portez un masque.

## Comment utiliser Face ID lorsque vous portez des lunettes et un masque facial

Si vous portez des lunettes et souhaitez améliorer la précision de Face ID avec un masque, vous pouvez configurer cette fonctionnalité tout en gardant vos lunettes, que ce soit la première fois que vous configurez Face ID ou ultérieurement. Vous pouvez configurer jusqu’à quatre paires de lunettes dans Face ID.

- Ouvrez l’app Réglages, puis touchez Face ID et code.

- Faites défiler l’écran vers le bas et touchez Ajouter des lunettes.

- Touchez Continuer lorsque vous y êtes invité, puis suivez les instructions à l’écran.

Pour utiliser la fonction Face ID avec un masque, il faut que Face ID puisse voir clairement vos yeux et leur contour. Face ID avec un masque n’est pas prévu pour fonctionner avec des lunettes de soleil.

Sur les modèles d’iPhone 18 Pro , vous devrez peut-être déplacer légèrement votre téléphone si vous ne parvenez pas à vous connecter avec Face ID au premier abord lorsque vous portez un masque et des lunettes. Vous pouvez également essayer de retirer vos lunettes ou votre masque si vous ne parvenez pas à utiliser Face ID dans des conditions de faible éclairage ou en cas de fort contre-jour. Lorsque vous saisissez votre code pour vous connecter, Face ID affine et met à jour vos données stockées lorsqu’il détecte une correspondance proche, mais un code est nécessaire pour déverrouiller l’appareil.
