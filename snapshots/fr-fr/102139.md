# Ajouter des emoji à votre vidéo dans Clips sur iPhone, iPad ou iPod touch

Vous pouvez ajouter des emoji à vos clips vidéo en cours d’enregistrement, ou les déposer sur les clips d’une vidéo existante.

## Ouvrir ou créer une vidéo

- Ouvrez Clips*. Si vous avez déjà utilisé cette app, la dernière vidéo sur laquelle vous avez travaillé s’ouvre automatiquement.

- Touchez le bouton Projets en haut à gauche.

[Image: Aucun texte de remplacement pour l’image]

- Pour créer une vidéo, touchez Nouveau projet . Pour ouvrir une vidéo enregistrée, effectuez un balayage pour afficher vos vidéos enregistrées, touchez celle qui vous intéresse, puis Ouvrir.

## Ajouter des emoji

Pour ajouter des emoji avant l’enregistrement d’une vidéo ou l’insertion d’une photo :

- Touchez le bouton Emoji .

[Image: Aucun texte de remplacement pour l’image]

- Touchez Emoji.

- Touchez un emoji pour l’ajouter au centre du clip dans le visualiseur. Vous pouvez aussi faire glisser l’emoji du navigateur vers le clip.

- Faites glisser l’emoji pour le placer à l’endroit souhaité.

- Effectuez un pincement pour redimensionner ou faire pivoter l’emoji.

- Touchez le bouton Fermer pour fermer le navigateur d’Emoji.

[Image: Aucun texte de remplacement pour l’image]

- Pour enregistrer votre vidéo, touchez de manière prolongée le bouton d’enregistrement .

- Pour prendre une photo, touchez le bouton de l’obturateur , puis touchez de manière prolongée le bouton d’enregistrement pour ajouter la photo à votre vidéo.

[Image: Aucun texte de remplacement pour l’image]

[Image: Emoji ajouté à l’intérieur d’une bulle de pensée dans un clip enregistré.]

Pour ajouter des emoji à un clip déjà enregistré, sélectionnez ce dernier dans la timeline affichée en bas de l’écran, puis ajoutez l’emoji.

## Supprimer un emoji

- Dans la timeline, sélectionnez le clip contenant l’emoji que vous souhaitez modifier.

- Touchez l’emoji, puis Supprimer.

[Image: Supprimez ou modifiez l’Emoji à partir du menu dans le clip sélectionné.]
