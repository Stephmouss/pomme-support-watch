# Passer un test d’audition avec les AirPods Pro 2 ou AirPods Pro 3

Effectuez un test d’audition avec un iPhone ou iPad pour faire le point sur votre audition.

## Éléments dont vous avez besoin

Pour effectuer le test d’audition, voici ce dont vous avez besoin :

- Des AirPods Pro 2 ou AirPods Pro 3 dotés de la dernière version du programme interne. Découvrez comment [mettre à jour le programme interne des AirPods](https://support.apple.com/fr-fr/106340) .

- Un iPhone ou iPad exécutant la dernière version du logiciel.

[Découvrez comment identifier votre modèle d’AirPods](https://support.apple.com/fr-fr/109525)

[Pays ou régions où le test d’audition est disponible](https://www.apple.com/airpods-pro/feature-availability/)

## Se préparer au test

La perte d’audition est courante et peut s’aggraver avec le temps. Le test d’audition avec les AirPods Pro 2 ou les AirPods Pro 3 peut déterminer si vous souffrez d’une perte auditive et montre votre capacité auditive à différentes fréquences sonores, mesurée en dBHL (niveau d’audition en décibels). À la fin du test d’audition, les résultats s’affichent, accompagnés de recommandations pour la suite.

Pour préparer un test dans les meilleures conditions, assurez-vous que vos AirPods sont parfaitement ajustés dans vos oreilles. Pour vous assurer que vos [AirPods sont bien ajustés](https://support.apple.com/guide/airpods/dev5c4d302d7/web) , vous pouvez [effectuer le test d’ajustement des embouts](https://support.apple.com/fr-fr/119849) (iPhone ou iPad uniquement). Le test d’audition teste également l’ajustement de vos AirPods.

Si le test suggère d’ajuster l’écouteur ou d’utiliser un autre embout :

- Essayez une autre taille d’embout pour AirPods Pro 2. Le lot d’embouts en silicone propose quatre paires d’embouts de tailles différentes. Vous pouvez ainsi choisir la taille la mieux ajustée à votre oreille. Ce lot est fourni avec vos AirPods Pro 2, mais [vous pouvez également en commander un](https://www.apple.com/fr/shop/product/MC4V4ZM/A/embouts-pour-airpods-pro-2-4-paires) .

- Essayez une autre taille d’embout pour AirPods Pro 3. Le lot d’embouts en mousse de silicone propose cinq paires d’embouts de tailles différentes. Vous pouvez ainsi choisir la taille la mieux ajustée à votre oreille. Ce lot est fourni avec vos AirPods Pro 3, mais [vous pouvez également en commander un](https://www.apple.com/fr/shop/product/MGYR4ZM/A/embouts-pour-airpods-pro-3-2-jeux-s) .

- [Nettoyez vos AirPods Pro](https://support.apple.com/fr-fr/120409) . Des débris peuvent empêcher le bon ajustement des AirPods dans vos oreilles. Vous devez également nettoyer régulièrement vos AirPods afin que les résultats du test soient aussi précis que possible.

Les résultats du test peuvent être faussés dans les cas suivants :

- Vous avez eu un rhume, une infection des sinus ou une infection de l’oreille au cours des dernières 24 heures.

- Vous souffrez actuellement d’allergies.

- Vous vous trouviez dans un environnement bruyant au cours des dernières 24 heures (si vous avez assisté à un concert par exemple).

## Trouver un endroit calme pour effectuer le test d’audition

Le test d’audition comprend un éventail complet de sons à des volumes différents et parfois très faibles, sur des fréquences allant de 250 Hz à 8 kHz. Pour garantir des résultats fiables, il est important de passer le test d’audition dans un environnement qui restera calme pendant toute la durée du test. Par exemple, installez-vous confortablement chez vous lorsque vous disposez d’environ cinq minutes de tranquillité sans bruits intermittents (personnes qui parlent ou système de climatisation ou de ventilation bruyant à proximité).

## Effectuer le test d’audition

La fonction Test d’audition est destinée aux personnes de 18 ans et plus et dure environ cinq minutes.

- Assurez-vous que vos AirPods sont suffisamment chargés* et que vous vous trouvez dans une pièce calme.

- Avec vos AirPods dans vos oreilles et connectés à votre iPhone ou iPad jumelé, accédez à Réglages > vos AirPods. Vous pouvez également lancer le test d’audition à partir de l’app Santé.

[Image: Réglages des AirPods Pro sur iPhone. Les options de santé auditive, y compris le bouton permettant de passer un test d’audition, se situent après les options de mode d’écoute.]

- Touchez Effectuer un test d’audition, puis suivez les instructions :

- Si l’app vous demande d’effectuer une vérification, remettez vos AirPods dans leur boîtier, fermez le couvercle, puis touchez OK. Touchez Effectuer le test d’audition lorsque la vérification est terminée.

- Si l’app vous invite à vous rendre dans un endroit plus calme, éteignez la climatisation ou la ventilation qui pourraient créer du bruit dans votre environnement, ou attendez la nuit lorsque les bruits ambiants, comme les bruits de circulation, sont moins nombreux. Le test analyse le bruit ambiant et vous prévient lorsque l’environnement est suffisamment silencieux.

- Si le test vous recommande de régler l’ajustement de vos AirPods, essayez une autre taille d’embout.

- Si le test recommande le nettoyage de vos AirPods Pro, [suivez les instructions de nettoyage des AirPods Pro](https://support.apple.com/fr-fr/120409) .

- Lorsque le test d’audition démarre, touchez l’écran lorsque vous entendez un son. Pendant le test, les sons sont joués trois fois pour vous donner le temps de répondre. Vous n’avez besoin de toucher l’écran qu’une seule fois lorsque vous entendez un son. Cela n’est pas grave si vous manquez un son.

- Si vous retirez ou ajustez vos AirPods (ou si le bruit ambiant autour de vous devient élevé), il est possible que le test d’audition se mette en pause. Le test reprend lorsque vous remettez les AirPods dans vos oreilles ou lorsque l’environnement est à nouveau silencieux.

À la fin du test, les résultats et des recommandations éventuelles s’affichent.

## Afficher vos résultats

Lorsque le test est terminé, les résultats s’affichent sur votre appareil. Les résultats montrent votre perte auditive globale en dBHL (niveau d’audition en décibels), la classification de votre perte auditive et les prochaines étapes recommandées.

Pour afficher un audiogramme détaillé, touchez Afficher les détails. Votre audiogramme est [stocké en toute sécurité dans l’app Santé sur votre appareil](https://support.apple.com/fr-fr/120991#manage) . Vous pouvez donc accéder à ces données à tout moment.

[Image: Résultats des tests d’écoute sur iPhone et audiogramme dans l’app Santé.]

## Interpréter les résultats

Les résultats affichent une valeur numérique unique pour chaque oreille. Cette valeur représente une moyenne de votre niveau d’audition dans les fréquences les plus importantes pour la compréhension de la parole. Plus la valeur est élevée, plus les sons doivent être forts pour que vous puissiez les entendre :

- 25 dBHL ou moins - Peu ou pas de perte auditive.

- 26 à 40 dBHL - Perte auditive légère. Vous pouvez entendre des mots prononcés d’une voix normale à un mètre de distance.

- 41 à 60 dBHL - Perte auditive modérée. Vous pouvez entendre des mots prononcés d’une voix forte à un mètre de distance.

- 61 à 80 dBHL - Perte auditive sévère. Vous pouvez entendre certains mots lorsqu’ils sont criés dans votre oreille.

Pour afficher un tableau détaillé de votre niveau d’audition dans les fréquences spécifiques testées, appuyez sur Afficher les détails.

## Étapes suivantes

Si les résultats révèlent une perte auditive légère à modérée, les [fonctionnalités d’aide auditive](https://support.apple.com/fr-fr/120992) comme Appareil auditif (la disponibilité des fonctionnalités varie selon les régions) et Aide multimédia peuvent vous aider. Si vous choisissez d’utiliser l’Aide auditive pour vos AirPods, vous pouvez utiliser les données de votre test d’audition pour personnaliser le son de vos AirPods. Vous pouvez également [utiliser les résultats de tests provenant de votre professionnel de la santé auditive](https://support.apple.com/guide/airpods/devd9aac5b42#devf2bf0d573) pour configurer l’Aide auditive.

Si vous souffrez d’une perte auditive sévère ou profonde, ou si vous avez des difficultés auditives ou remarquez un changement soudain de votre audition, parlez-en à votre médecin.

## Consulter et partager vos résultats de test dans l’app Santé

Vous pouvez consulter les résultats des tests d’audition dans l’app Santé et exporter ces résultats pour les partager avec d’autres personnes, comme votre médecin.

- Ouvrez l’app Santé sur votre iPhone ou iPad.

- Sur votre iPhone, touchez Parcourir. Sur votre iPad, touchez pour ouvrir la barre latérale.

- Touchez Audition. Vous pouvez voir la valeur numérique unique des résultats de votre test le plus récent dans la section Résultats du test d’audition.

- Pour afficher le dernier graphique de votre niveau d’audition sur le spectre de fréquences, touchez Résultats du test d’audition.

- Pour exporter un PDF de votre audiogramme, faites défiler l’écran vers le bas, puis touchez Exporter au format PDF. Touchez le bouton Partager, puis choisissez ce que vous souhaitez faire avec le PDF, par exemple le partager avec d’autres personnes par e-mail ou par message, ou l’enregistrer dans Fichiers sur votre appareil.

- Pour afficher l’historique de vos résultats de test d’audition, touchez Afficher plus de données.

* Vos AirPods doivent être chargés pour qu’Appareil auditif fonctionne correctement. [Découvrez comment charger vos AirPods et leur boîtier de charge, et comment optimiser l’autonomie de la batterie de vos AirPods](https://support.apple.com/fr-fr/119912) .
