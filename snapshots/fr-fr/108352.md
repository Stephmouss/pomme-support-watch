# Utiliser le mode Eau et évacuer l’eau de votre Apple Watch

Activez le mode Eau pour éviter de toucher accidentellement l’écran lorsque vous portez votre Apple Watch dans l’eau. Lorsque vous sortez, appuyez de manière prolongée sur la Digital Crown pour évacuer l’eau du haut-parleur de votre montre.

Lorsque le mode Eau est activé, l’écran de votre Apple Watch ne répond pas au toucher. Cela empêche les saisies accidentelles lorsque vous êtes dans l’eau. Lorsque vous désactivez le mode Eau, votre montre évacue l’eau présente dans le haut-parleur.

## Activer le mode Eau

- Appuyez sur le bouton latéral pour ouvrir le centre de contrôle.

- Appuyez sur le bouton Mode Eau . L’icône Mode Eau s’affiche en haut du cadran de la montre.

[Image: Centre de contrôle de l’Apple Watch montrant l’icône du mode Eau surlignée en bleu.]

Le mode Eau s’active automatiquement lorsque vous commencez un exercice dans l’eau, tel qu’une séance de [natation](https://support.apple.com/guide/watch/go-for-a-swim-apd09135915f/watchos) ou de surf. Il s’active également automatiquement lorsque vous [entamez une plongée sous-marine avec votre Apple Watch Ultra](https://support.apple.com/guide/watch/measure-underwater-temperature-duration-depth-apd9073c83d6/watchos) .

Les gestes de toucher et les mouvements du poignet ne sont pas disponibles lorsque le mode Eau est activé.

## Désactiver le mode Eau et évacuer l’eau

Lorsque le mode Eau est activé, maintenez la Digital Crown enfoncée* sur le côté de votre Apple Watch jusqu’à ce que l’écran indique Déverrouillé. Votre montre émet une série de tonalités pour évacuer l’eau présente dans le haut-parleur. Vous pouvez ensuite utiliser votre écran comme d’habitude.

[Image: L’écran de l’Apple Watch affiche une icône de goutte d’eau et le texte suivant : Maintenez la couronne enfoncée pour désactiver le mode Eau.]

* Si votre Apple Watch est dotée de watchOS 8 ou d’une version antérieure, tournez la Digital Crown au lieu d’appuyer dessus.
