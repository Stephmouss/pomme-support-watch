# Supprimer des apps de votre Apple Watch

Vous pouvez gérer vos apps Apple Watch directement sur votre montre ou à l’aide de l’app Watch sur votre iPhone.

## Comment supprimer des apps de votre Apple Watch

- [Appuyez sur la Digital Crown](https://support.apple.com/fr-fr/105063) pour afficher une sélection de vos apps récentes et fréquemment utilisées. Ensuite, balayez vers le haut pour afficher toutes vos apps.

- Maintenez votre doigt appuyé sur l’écran jusqu’à ce que les apps tremblent.

[Image: Un cadran d’Apple Watch est affiché. Certaines apps affichent le bouton Supprimer, qui vous permet de supprimer une app de votre Apple Watch.]

- Touchez le bouton Supprimer sur l’app que vous souhaitez supprimer, puis touchez Supprimer l’app pour confirmer. Certaines apps intégrées ne peuvent pas être supprimées. Les apps que vous ne pouvez pas supprimer n’affichent pas le bouton de suppression.

Si vous supprimez une app de votre iPhone, cette app est également supprimée de votre Apple Watch. Si vous souhaitez restaurer une app, y compris les apps Apple intégrées, vous pouvez la télécharger à partir de l’App Store sur votre iPhone ou Apple Watch.

## Comment gérer les apps de l’Apple Watch à l’aide d’un iPhone

- Ouvrez l’app Watch sur votre iPhone, puis touchez l’onglet Ma montre.

- Touchez Apps, puis touchez l’app que vous souhaitez supprimer.

- Désactivez l’option Afficher l’app sur l’Apple Watch. Pour les apps qui sont disponibles sous watchOS uniquement, touchez Supprimer l’app sur l’Apple Watch, puis touchez Supprimer pour confirmer.

[Image: Écran d’iPhone montrant les réglages de l’app Keynote dans l’app Watch, avec l’option Afficher l’app sur l’Apple Watch activée.]
