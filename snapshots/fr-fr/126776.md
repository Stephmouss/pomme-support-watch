# Mettre à jour iOS pour protéger votre iPhone contre les attaques sur Internet

Si votre iPhone ne dispose pas de la dernière version du logiciel, mettez à jour iOS pour protéger vos données.

Des chercheurs en sécurité ont récemment identifié des attaques en ligne qui ciblent les versions obsolètes d’iOS par le biais de contenus web malveillants. Par exemple, si vous utilisez une ancienne version d’iOS et que vous cliquez sur un lien malveillant ou que vous consultez un site web compromis, les données stockées sur votre iPhone risquent d’être volées.

Nous avons mené une enquête approfondie sur ces problèmes dès leur découverte et avons publié des mises à jour logicielles aussi rapidement que possible pour les versions les plus récentes du système d’exploitation afin de corriger ces vulnérabilités et de contrer ces attaques.

Si vous avez mis à jour le logiciel de votre iPhone, vous êtes déjà protégé(e). Maintenir vos logiciels [à jour](https://support.apple.com/fr-fr/guide/iphone/iph3e504502/ios) constitue la mesure la plus importante que vous puissiez prendre pour garantir la sécurité de vos produits Apple, et les appareils dont le logiciel était à jour n’étaient pas exposés aux risques liés à ces attaques signalées. Les appareils sur lesquels le mode Isolement est activé sont également protégés contre ces attaques spécifiques, même si leur logiciel n’est pas à jour, mais il est recommandé de les mettre à jour dès que possible vers la dernière version d’iOS.

Si votre iPhone exécute une ancienne version d’iOS, procédez à une mise à jour pour protéger vos données :

- Si possible, installez la dernière version d’iOS 26 qui contient les meilleures protections de sécurité.

- Les appareils équipés des dernières versions mises à jour d’iOS 15 à iOS 26 sont déjà protégés. Si vous n’avez pas mis à jour votre logiciel récemment, [mettez à jour iOS sur votre iPhone](https://support.apple.com/en-az/guide/iphone/iph3e504502/ios) .

- Le 11 mars 2026, nous avons publié une [mise à jour logicielle pour iOS 15 et iOS 16](https://support.apple.com/fr-fr/100100) afin d’étendre la protection aux appareils plus anciens qui ne peuvent pas être mis à jour vers la dernière version d’iOS.

- Les appareils exécutant iOS 13 ou iOS 14 doivent être mis à jour vers iOS 15 pour bénéficier de ces protections.

- Le 1er avril 2026, nous avons étendu la disponibilité d’iOS 18.7.7 à davantage d’appareils, afin que les personnes ayant activé les mises à jour automatiques puissent recevoir automatiquement d’importantes protections de sécurité.

- Les appareils exécutant des versions plus anciennes d’iOS 18 afficheront un message d’alerte supplémentaire indiquant qu’une mise à jour de sécurité importante est disponible.

- La fonctionnalité de navigation sécurisée d’Apple dans Safari est activée par défaut et bloque les domaines URL malveillants identifiés dans ces attaques.

Remarque : les utilisateurs et utilisatrices qui ne parviennent pas à mettre à jour leur appareil peuvent activer le [mode Isolement](https://support.apple.com/fr-fr/105120) (si disponible) afin de se protéger contre les contenus web malveillants et d’autres menaces.
