# Copier un ensemble Drum Machine Designer personnalisé sur un autre Mac

Si vous avez créé un ensemble Drum Machine Designer dans Logic Pro pour Mac à partir de vos propres échantillons, vous pouvez l’enregistrer et l’utiliser dans Logic Pro sur un autre Mac.

Un ensemble Drum Machine Designer est composé d’échantillons, ainsi que d’un fichier PATCH stockant les affectations des pads de l’ensemble et d’autres paramètres. Vous pouvez enregistrer ces composants, puis les copier sur un autre Mac pour les utiliser dans Logic Pro 10.5 ou version ultérieure. Vous pouvez utiliser un lecteur externe, iCloud Drive, AirDrop, un compte e-mail ou des services cloud tiers pour transférer ces composants vers l’autre Mac.

## Enregistrer les paramètres de votre ensemble en tant que fichier PATCH

- Ouvrez le projet Logic Pro avec l’ensemble personnalisé que vous souhaitez enregistrer.

- Pour ouvrir la fenêtre Drum Machine Designer, cliquez sur DMD dans le slot Instrument de la tranche de console.

- Sélectionnez le nom de l’ensemble du pad en haut de la fenêtre Drum Machine Designer, où le nom de la piste apparaît. Cela garantit que vous enregistrez l’ensemble complet sous forme de patch.

- ﻿Si vous avez sélectionné un seul pad de l’ensemble, seul l’élément associé de l’ensemble sera enregistré sous forme de patch.

- Si nécessaire, cliquez sur le bouton Bibliothèque.

- Cliquez sur Enregistrer en bas de la Bibliothèque, puis saisissez un nom pour votre ensemble personnalisé. Pour que votre ensemble personnalisé apparaisse dans le dossier Patchs utilisateur de la Bibliothèque, enregistrez-le à cet emplacement dans votre dossier de départ : ~/Music/Audio Music Apps/Patches/Instrument.

- Cliquez sur Enregistrer dans la boîte de dialogue Enregistrer.

- Accédez à ~/Music/Audio Music Apps/Patches/Instrument/, puis copiez le fichier PATCH sur l’autre Mac.

## Enregistrer les échantillons de votre ensemble

- Créez un projet vide avec une nouvelle piste Instrument logiciel.

- Sélectionnez la piste, puis choisissez votre ensemble personnalisé dans le dossier Patchs utilisateur de la Bibliothèque.

- Cliquez sur Fichier > Enregistrer.

- Dans la boîte de dialogue Enregistrer, sélectionnez Dossier pour enregistrer votre projet en tant que dossier. Sélectionnez « Données audio d’échantillonnage », saisissez un nom et choisissez un emplacement pour le projet, puis cliquez sur Enregistrer.

- Dans le Finder, ouvrez le dossier que vous venez de créer pour votre projet. Recherchez le sous-dossier appelé Quick Sampler, qui contient les échantillons utilisés dans votre ensemble.

- Copiez le dossier Quick Sampler sur l’autre Mac.

## Renommer et déplacer des dossiers sur l’autre Mac

- Sur l’autre Mac, recherchez le dossier Quick Sampler et le fichier PATCH.

- Renommez le dossier Quick Sampler en lui attribuant le même nom que celui que vous avez donné au fichier PATCH de votre ensemble personnalisé. Par exemple, si votre fichier PATCH se nomme MyDrumKit.patch, renommez le dossier Quick Sampler « MyDrumKit ».

- Dans le Finder, déplacez le fichier PATCH et le dossier renommé vers cet emplacement dans le dossier de départ : ~/Music/Audio Music Apps/Patches/Instrument/.

Vous pouvez désormais charger votre ensemble DMD personnalisé à partir de la Bibliothèque dans n’importe quel projet Logic Pro.
