# Si certaines notes ne sont pas reproduites dans Logic Pro pour Mac ou MainStage

Certains patchs d’instruments logiciels fonctionnent de manière monophonique lorsqu’ils sont reproduits à partir d’un contrôleur MIDI défini sur un canal MIDI supérieur à 1.

Par exemple, il se peut que vous n’entendiez qu’une seule note d’un accord de trois notes lorsque vous jouez un patch d’instrument logiciel particulier. Procédez comme décrit ci-dessous pour rendre les patchs entièrement polyphoniques sur tous les canaux MIDI :

- Cliquez au centre du slot d’insert de l’instrument logiciel pour ouvrir la fenêtre du module.

- Cliquez sur le triangle d’expansion situé en bas de la fenêtre du module pour afficher les paramètres supplémentaires.

- Cliquez sur le menu déroulant Mode mono MIDI et désactivez ce mode.

- Fermez la fenêtre du module.

- Placez le curseur à gauche du slot d’insert de l’instrument logiciel, puis cliquez sur le triangle gris qui s’affiche pour ouvrir la bibliothèque contenant le patch actuel.

- Cliquez sur Enregistrer, en bas à droite de la Bibliothèque.

- Dans la boîte de dialogue vous invitant à enregistrer les réglages, entrez un nouveau nom pour le patch.

- Cliquez sur Enregistrer. Lorsque vous utilisez un contrôleur MIDI externe avec le patch, choisissez la version polyphonique enregistrée du patch.

Lorsque vous utilisez Logic Remote pour contrôler le patch, choisissez la version d’usine du patch pour profiter de différents types de contrôles, comme le pitch bend polyphonique.
