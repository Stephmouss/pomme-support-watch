# OS X Server : des membres wiki peuvent ne pas recevoir les notifications Wiki par e-mail

Lorsque vous utilisez le service Wiki disponible sous OS X Server (Mountain Lion), il est possible que des membres wiki ne reçoivent pas les notifications par e-mail.

Assurez-vous d’avoir configuré le service Mail de manière à ce qu’il utilise le relais SMTP correct pour votre FAI.

- Dans l’application Serveur, cliquez sur Mail > Faire transiter le courrier sortant par le FAI.

- Saisissez l’adresse du serveur relais de messagerie de votre FAI dans le champ approprié. Si votre FAI requiert une authentification SMTP, vous pouvez également indiquer le nom d’utilisateur et le mot de passe.
