# Importation et partage de notes et de fichiers dans l’app Notes

Conservez toutes vos notes au même endroit sur Mac, iPhone et iPad.

## Avant de commencer

Mettez à jour votre [Mac vers la dernière version de macOS](https://support.apple.com/fr-fr/108382) et votre [iPhone ou iPad vers la dernière version d’iOS ou d’iPadOS](https://support.apple.com/fr-fr/118575) .

## Importer des fichiers texte dans Notes

Sur Mac, Notes peut importer les types de fichiers texte suivants :

- .txt

- .rtf

- .rtfd

- .html

- .enex

- .md

Chaque fichier texte est converti en une nouvelle note.

- Ouvrez Notes.

- Dans la barre latérale de Notes, choisissez un dossier dans iCloud* ou Sur mon Mac.

- Choisissez Importer dans Notes dans le menu Fichier de la barre des menus.

- Choisissez le(s) fichier(s) texte ou dossier(s) que vous souhaitez importer. Si les notes sont organisées en dossiers, cliquez sur Conserver la structure des dossiers lors de l’importation. Si vous ne trouvez pas ce réglage, cliquez sur Afficher les options.

- Cliquez sur Importer.

- Cliquez à nouveau sur Importer dans la fenêtre « Importer dans Notes ? ».

Si vous avez sélectionné iCloud, les notes importées sont placées dans un dossier Notes importées dans la section iCloud de Notes. Sinon, ce dossier apparaît dans la section Sur mon Mac de Notes.

Chaque fichier Evernote (.enex) peut inclure plusieurs notes, et Notes convertit chacune d’entre elles en une nouvelle note. Si un fichier Evernote contient une pièce jointe ou une fonctionnalité que Notes ne prend pas en charge, la pièce jointe ou la fonctionnalité n’est pas importée.

## Importer des fichiers Markdown (.md) dans Notes

Sous macOS Tahoe 26, iOS 26, iPadOS 26 et version ultérieure, Notes convertit la syntaxe Markdown en texte enrichi qui conserve le formatage.

Sur un Mac :

- Ouvrez Notes.

- Sélectionnez Importer le texte Markdown dans le menu Fichier de la barre des menus.

- Sélectionnez un ou plusieurs fichiers .md.

- Cliquez sur Importer.

- Cliquez à nouveau sur Importer dans la fenêtre « Importer dans Notes ? ».

Si vous utilisez iCloud*, les notes sont placées dans un dossier Notes importées dans la section iCloud de Notes. Sinon, ce dossier apparaît dans la section Sur mon Mac de Notes.

Sur iPhone et iPad, suivez les étapes de partage avec l’app Fichiers.

## Partager des fichiers dans Notes avec l’app Fichiers

Sur iPhone et iPad :

- Ouvrez l’app Fichiers.

- Touchez un fichier de manière prolongée.

- Touchez Partager.

[Image: Écran d’iPhone affichant le menu qui s’ouvre lorsque vous touchez un fichier de manière prolongée.]

- Touchez Notes.

- Enregistrez en tant que nouvelle note dans iCloud* ou Sur mon appareil, ou enregistrez sur une note existante dans iCloud ou Sur mon appareil.

## Partager des fichiers dans Notes avec le Finder

Sur un Mac :

- Ouvrez le Finder.

- Cliquez sur un fichier en maintenant la touche Contrôle enfoncée.

- Sélectionnez Partager.

- Sélectionnez Notes.

- Enregistrez en tant que nouvelle note dans iCloud* ou Sur mon Mac, ou enregistrez sur une note existante dans iCloud ou Sur mon Mac.

## Partager des fichiers dans Notes avec Mail

Sur un Mac, iPhone et iPad :

- Ouvrez Mail.

- Ouvrez un e-mail contenant une note ou un fichier.

- Sur Mac, cliquez sur la note ou le fichier en maintenant la touche Contrôle enfoncée, puis sélectionnez Partager. Sur iPhone et iPad, touchez la note ou le fichier de manière prolongée, puis touchez Partager.

[Image: Écran d’iPhone affichant un menu ouvert permettant de partager une note dans Notes.]

- Sélectionnez Notes.

- Enregistrez en tant que nouvelle note dans iCloud* ou Sur mon appareil, ou enregistrez sur une note existante dans iCloud ou Sur mon appareil.

* Les notes iCloud sont disponibles sur n’importe quel appareil connecté à votre compte Apple.
