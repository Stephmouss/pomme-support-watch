# Méthodes de sauvegarde pour les iPhone et iPad

Une sauvegarde vous permet de copier et d’enregistrer les informations de votre iPhone ou iPad. Si vous remplacez votre appareil, vous pourrez ainsi utiliser les sauvegardes réalisées pour transférer vos données vers un nouvel appareil.

[Choisir la meilleure méthode de sauvegarde](https://support.apple.com/fr-fr/108771#decide)

## Choisir la meilleure méthode de sauvegarde

Vous pouvez sauvegarder votre appareil à l’aide d’iCloud, de votre ordinateur, ou des deux. Si une méthode n’est pas disponible, vous pouvez toujours utiliser l’autre.

### Effectuer une sauvegarde dans iCloud

[Image: Icône de nuage pour la sauvegarde iCloud.]

- Les sauvegardes sont stockées sur iCloud.

- [Vous pouvez stocker jusqu’à 12 To](https://support.apple.com/fr-fr/108047) . Avec un abonnement Apple One Premier, cette limite passe à 14 To.

- Les sauvegardes sont toujours chiffrées.

- Possibilité de créer et d’utiliser des sauvegardes partout via une connexion Wi-Fi.

### Sauvegarder sur votre ordinateur

[Image: Icône d’ordinateur portable et de téléphone pour la sauvegarde sur ordinateur.]

- Vos sauvegardes sont stockées sur votre Mac ou PC.

- Le stockage dépend de l’espace disponible sur votre Mac ou PC

- Les sauvegardes peuvent être chiffrées (cette option est désactivée par défaut).

- Possibilité de créer et d’utiliser des sauvegardes à partir d’un Mac ou d’un PC.

## Gérer les sauvegardes iCloud

Vous pouvez sauvegarder le contenu de votre appareil avec iCloud, sous réserve de disposer d’une connexion Wi-Fi. Il n’est pas nécessaire de connecter l’appareil à un ordinateur pour effectuer une sauvegarde sur iCloud.

Les sauvegardes iCloud incluent les informations et les réglages stockés sur votre appareil qui ne sont pas déjà synchronisés avec iCloud. hormis :

- les notes que vous stockez et synchronisez déjà dans iCloud ;

- les photos, si vous avez activé Photos iCloud ;

- Messages (iMessage, SMS et MMS), si vous synchronisez les messages avec iCloud

- les données enregistrées via d’autres services dans le nuage, comme les messages Gmail ou Exchange ;

- les données d’Apple Mail ;

- les informations et réglages liés à Apple Pay ;

- les réglages de Face ID et Touch ID ;

- le contenu de la bibliothèque musicale iCloud et de l’App Store.

- les plans hors ligne.

[En savoir plus sur les éléments sauvegardés par iCloud](https://support.apple.com/fr-fr/108770)

## Sauvegarder à partir de votre ordinateur

Une sauvegarde sur ordinateur inclut presque toutes les données et tous les réglages de votre appareil, ce qui est [différent de la synchronisation](https://support.apple.com/fr-fr/108311) .

Une sauvegarde à partir d’un ordinateur ne comprend pas les éléments suivants :

- Contenu de l’iTunes Store, de l’App Store et d’Apple Books

- le contenu synchronisé à partir de votre Mac ou PC (vidéos, livres, photos, CD et MP3 importés, par exemple) ;

- Données déjà synchronisées et stockées dans iCloud, comme Photos iCloud, les iMessage, ainsi que les SMS et MMS

- les réglages de Face ID et Touch ID ;

- les informations et réglages liés à Apple Pay ;

- les données d’Apple Mail ;

- les données liées au trousseau et aux applications Santé et Activité (pour les sauvegarder, vous devez créer une sauvegarde chiffrée) ;

- les plans hors ligne.

## Utiliser une sauvegarde pour un autre appareil

Vous pouvez [restaurer un appareil à partir d’une sauvegarde](https://support.apple.com/fr-fr/118105) d’un autre type d’appareil. Par exemple, vous pouvez utiliser une sauvegarde d’iPad pour configurer un iPhone. Cependant, certains types de contenu ne seront pas transférés :

- les photos, sauf si vous utilisez Photos iCloud ;

- les messages et les pièces jointes dans Messages, sauf si vous synchronisez les messages avec iCloud ;

- l’app Dictaphone ;

- Les apps qui ne sont pas compatibles avec l’appareil que vous configurez (par exemple, les apps compatibles uniquement avec l’iPad ne seront pas transférées sur votre iPhone)
