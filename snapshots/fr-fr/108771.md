# Méthodes de sauvegarde pour les iPhone et iPad

Une sauvegarde vous permet de copier et d’enregistrer les informations de votre iPhone ou iPad. Si vous venez à remplacer votre appareil, vous pourrez ainsi utiliser les sauvegardes réalisées pour transférer vos données vers un nouvel appareil.

[Quelle méthode vous convient le mieux ?](https://support.apple.com/fr-fr/108771#decide)

[Sauvegardes iCloud](https://support.apple.com/fr-fr/108771#icloud)

## Quelle méthode vous convient le mieux ?

Si vous souhaitez un jour disposer de deux sauvegardes, vous avez la possibilité d’effectuer une sauvegarde de votre appareil dans iCloud et à l’aide de votre ordinateur. Découvrez [comment sauvegarder les données de votre appareil](https://support.apple.com/fr-fr/118426) ou [comment restaurer votre appareil à partir d’une sauvegarde](https://support.apple.com/fr-fr/118105) .

### iCloud

[Image: icloud-backup-cloud-topic-icon]

- Les sauvegardes sont stockées sur iCloud.

- intègrent jusqu’à [12 To d’espace de stockage](https://support.apple.com/fr-fr/108047) (combined with an Apple One Premier plan, you can get up to 14TB)

- Les sauvegardes sont toujours chiffrées.

- Possibilité de créer et d’utiliser des sauvegardes partout via une connexion Wi-Fi.

### Ordinateur

[Image: computer-backup-laptop-phone-topic-icon]

- Vos sauvegardes sont stockées sur votre Mac ou PC.

- La quantité d’espace disponible pour les sauvegardes dépend de l’espace libre sur votre Mac ou PC.

- Les sauvegardes peuvent être chiffrées (cette option est désactivée par défaut).

- Possibilité de créer et d’utiliser des sauvegardes à partir d’un Mac ou d’un PC.

## Sauvegardes iCloud

Vous pouvez sauvegarder le contenu de votre appareil avec iCloud, sous réserve de disposer d’une connexion Wi-Fi. Il n’est pas nécessaire de connecter l’appareil à un ordinateur pour effectuer une sauvegarde sur iCloud.

Les sauvegardes iCloud contiennent toutes les informations et tous les réglages stockés sur votre appareil qui ne sont pas déjà synchronisés avec iCloud, hormis :

- les notes que vous stockez et synchronisez déjà dans iCloud ;

- les photos, si vous avez activé Photos iCloud ;

- les iMessages, les messages texte (SMS) et multimédias (MMS), si vous synchronisez les messages avec iCloud ;

- les données enregistrées via d’autres services dans le nuage, comme les messages Gmail ou Exchange ;

- les données d’Apple Mail ;

- les informations et réglages liés à Apple Pay ;

- les réglages de Face ID et Touch ID ;

- le contenu de la bibliothèque musicale iCloud et de l’App Store.

- les plans hors ligne.

[En savoir plus sur les éléments sauvegardés par iCloud](https://support.apple.com/fr-fr/108770)

## Sauvegardes à partir de votre ordinateur

Une sauvegarde des données de votre appareil à partir d’un ordinateur, qui diffère d’une [synchronisation](https://support.apple.com/fr-fr/108311) , comprend quasi toutes les données et tous les réglages de votre appareil. Une sauvegarde à partir d’un ordinateur ne comprend pas les éléments suivants :

- le contenu provenant de l’iTunes Store et de l’App Store, ainsi que les PDF téléchargés directement dans Apple Books ;

- le contenu synchronisé à partir de votre Mac ou PC (vidéos, livres, photos, CD et MP3 importés, par exemple) ;

- les données déjà synchronisées et stockées dans iCloud, comme le contenu de Photos iCloud, les iMessages et les messages texte (SMS) et multimédias (MMS) ;

- les réglages de Face ID et Touch ID ;

- les informations et réglages liés à Apple Pay ;

- les données d’Apple Mail ;

- les données liées au trousseau et aux applications Santé et Activité (pour les sauvegarder, vous devez créer une sauvegarde chiffrée) ;

- les plans hors ligne.

[Découvrez comment effectuer et retrouver des sauvegardes et comment supprimer celles dont vous n’avez plus besoin sur votre Mac ou votre PC.](https://support.apple.com/fr-fr/108809)

## Puis-je utiliser la sauvegarde de mon appareil pour un autre type d’appareil, par exemple la sauvegarde d’un iPhone pour un iPad ?

Vous pouvez [restaurer un appareil à partir d’une sauvegarde](https://support.apple.com/fr-fr/118105) créée sur un autre type d’appareil, (par exemple, la sauvegarde des données d’un iPad pour un iPhone), toutefois certains types de contenu ne seront pas transférés :

- les photos, sauf si vous utilisez Photos iCloud ;

- les messages et les pièces jointes dans Messages, sauf si vous synchronisez les messages avec iCloud ;

- les mémos vocaux.

- les apps qui ne sont pas compatibles avec l’appareil que vous configurez. (Par exemple, les apps qui ne sont compatibles qu’avec l’iPad ne sont pas transférées sur un iPhone.)
