# Modifier le navigateur web ou l’app de messagerie par défaut sur un Mac

Le navigateur web par défaut sur votre Mac est Safari. C’est donc cette app qui s’ouvre lorsque vous cliquez sur un lien web. L’app de messagerie par défaut est Mail. Elle s’ouvre donc lorsque vous cliquez sur un lien de messagerie. Si vous souhaitez utiliser un autre navigateur web ou une autre app de messagerie pour ces actions, modifiez le réglage par défaut en procédant comme suit.

## Modifier le navigateur web par défaut

[Identifiez la version de macOS installée sur votre Mac](https://support.apple.com/fr-fr/109033) , puis suivez la procédure appropriée.

### Sous macOS Ventura 13 ou version ultérieure

- Installez le navigateur web que vous souhaitez utiliser par défaut.

- Dans le menu Pomme  situé dans l’angle de l’écran, choisissez Réglages Système.

- Cliquez sur Bureau et Dock dans la barre latérale.

- Faites défiler l’écran vers le bas à droite et choisissez un navigateur web dans le menu « Navigateur web par défaut ».

### Dans les versions antérieures de macOS

- Installez le navigateur web que vous souhaitez utiliser par défaut.

- Dans le menu Pomme  situé dans l’angle de l’écran, choisissez Préférences Système.

- Cliquez sur Général.

- Choisissez un navigateur web dans le menu « Navigateur web par défaut ».

## Modifier l’app de messagerie par défaut

- Installez l’app de messagerie que vous souhaitez utiliser par défaut.

- Ouvrez l’app Mail et assurez-vous qu’elle est [configurée pour utiliser un compte de messagerie](https://support.apple.com/guide/mail/mail35803/mac) .

- Vous pouvez supprimer ou désactiver ce compte dans les réglages de Mail après avoir effectué les étapes restantes.

- Si vous ne souhaitez pas ajouter temporairement un compte de messagerie, vérifiez les réglages de votre autre app de messagerie : vous pourrez peut-être la configurer comme app de messagerie par défaut.

- Dans le menu Mail de la barre des menus, sélectionnez Réglages (ou Préférences).

- Cliquez sur Général, puis choisissez une app de messagerie dans le menu contextuel « Application de messagerie par défaut ». Si vous ne voyez pas votre app de messagerie dans le menu, choisissez Sélectionner dans le menu, puis sélectionnez votre application de messagerie dans la boîte de dialogue du fichier qui s’ouvre.

Si vous utilisez une messagerie web (messagerie dans un navigateur web) plutôt qu’une app, vous pouvez choisir un navigateur web dans le menu « Application de messagerie par défaut » de Mail. Il se peut toutefois que le navigateur ne puisse pas ouvrir automatiquement la messagerie web lorsque vous cliquez sur les liens de messagerie. Certains navigateurs et services de messagerie web tiers peuvent avoir leurs propres paramètres pour modifier ce comportement.
