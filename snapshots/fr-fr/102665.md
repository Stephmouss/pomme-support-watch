# Effectuer une mise à jour vers la dernière version de Safari

Si une mise à jour Safari est disponible pour votre appareil, vous pouvez l’obtenir en mettant à jour ou à niveau le système d’exploitation de votre appareil.

## Mettre à jour Safari sur votre appareil Apple

Safari est inclus avec le système d’exploitation (OS) de votre appareil Apple. Si une version ultérieure de Safari est disponible pour votre appareil, vous pouvez l’obtenir en installant les dernières mises à jour ou mises à niveau du système d’exploitation pour votre appareil.

- Mac : [effectuez une mise à jour de macOS](https://support.apple.com/fr-fr/108382)

- iPhone : [effectuez une mise à jour d’iOS](https://support.apple.com/fr-fr/118575)

- iPad : [effectuez une mise à jour d’iPadOS](https://support.apple.com/fr-fr/118575)

- Apple Vision Pro : [effectuez une mise à jour de visionOS](https://support.apple.com/fr-fr/118481)

Apple ne propose plus de mises à jour de Safari pour Windows ou pour des systèmes d’exploitation autres qu’Apple. Safari 5.1.7 pour Windows était la dernière version conçue pour Windows. Sortie en 2010, cette version est désormais obsolète.

## Si un site web ne fonctionne pas comme prévu dans Safari

- Si un site web indique que Safari est obsolète alors que vous utilisez déjà la dernière version de macOS, d’iOS, d’iPadOS ou de visionOS, il se peut que le site web rencontre un problème. Si vous êtes sûr de vouloir utiliser ce site web, contactez son propriétaire ou son développeur pour savoir comment l’utiliser au mieux.

- Découvrez les autres [solutions possibles pour Mac](https://support.apple.com/fr-fr/102564) et les [solutions pour iPhone ou iPad](https://support.apple.com/fr-fr/102456) .
