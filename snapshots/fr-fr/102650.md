# Raccourcis clavier Mac

Les raccourcis clavier vous permettent d’effectuer des actions en recourant à des combinaisons de touches plutôt qu’à une souris ou à un trackpad. Certains raccourcis clavier peuvent être propres à une app. Les raccourcis qui fonctionnent dans une app donnée peuvent ne pas fonctionner dans une autre.

## Utilisation des raccourcis clavier

Les raccourcis clavier comprennent une ou plusieurs des touches de modification suivantes, qui sont [représentées par des symboles](https://support.apple.com/guide/mac-help/what-are-those-symbols-shown-in-menus-cpmh0011/mac) dans les menus :

- Fn (Fonction) ou Globe

- Contrôle (ou Ctrl) ⌃

- Option (ou Alt) ⌥

- Maj ⇧

- Verrouillage majuscule ⇪

- Commande (ou Cmd) ⌘

- Échap ⎋

- Tab ⇥

- Supprimer ⌫

- Retour ⏎

- Flèche vers le haut ▲

- Flèche vers le bas ▼

- Flèche vers la gauche ◀

- Flèche vers la droite ▶

Pour utiliser un raccourci, maintenez la ou les touches de modification enfoncées, puis appuyez sur la dernière touche du raccourci. Par exemple, pour utiliser le raccourci Commande + C, maintenez la touche Commande enfoncée, appuyez ensuite sur la touche C, puis relâchez les deux touches. (Sur un clavier conçu pour un PC Windows, appuyez sur la touche Alt au lieu de la touche Option, et sur la touche Ctrl ou la touche avec le logo Windows au lieu de la touche Commande.)

Les touches de la rangée supérieure de nombreux claviers Apple comportent des symboles et des fonctions spécifiques, comme le réglage de la luminosité , Mission Control , etc. Pour utiliser ces touches comme F1, F2, F3 ou d’autres touches de fonction standard, combinez-les avec la touche Fn (Fonction) ou Globe . Certaines d’entre elles peuvent être combinées avec la touche Option pour ouvrir rapidement certains réglages système.

## Couper, copier, coller et autres raccourcis courants

- Commande + X : couper l’élément sélectionné et en enregistrer une copie dans le presse-papiers.

- Commande + C : copier l’élément sélectionné dans le presse-papiers. Ce raccourci peut également être utilisé avec les fichiers du Finder.

- Commande + V : coller le contenu du presse-papiers dans le document ou l’app en cours. Ce raccourci peut également être utilisé avec les fichiers du Finder.

- Commande + Z : annuler la commande précédente. Vous pouvez ensuite appuyer sur Maj + Commande + Z pour rétablir la commande venant d’être annulée. Certaines apps permettent de réaliser plusieurs opérations de ce type (Annuler/Rétablir) à la suite.

- Commande + A : sélectionner tous les éléments.

- Commande + F : rechercher des éléments dans un document ou ouvrir une fenêtre Rechercher.

- Commande + G : trouver à nouveau, autrement dit trouver la prochaine occurrence de l’élément précédemment trouvé. Pour trouver l’occurrence précédente, appuyez sur Maj + Commande + G.

- Commande + H : masquer les fenêtres de l’app ouverte au premier plan. Pour masquer les fenêtres de toutes les apps ouvertes, hormis celles de l’app au premier plan, appuyez sur Commande + Option + H.

- Commande + M : minimiser, autrement dit placer la fenêtre active dans le Dock. Pour minimiser toutes les fenêtres de l’app ouverte au premier plan, appuyez sur Commande + Option + M.

- Commande + O : ouvrir l’élément sélectionné ou afficher une boîte de dialogue permettant de choisir un fichier à ouvrir.

- Commande + P : ouvrir une boîte de dialogue d’impression afin d’imprimer le document actif.

- Commande + Q : quitter l’app active.

- Commande + S : enregistrer le document actif.

- Commande + T : ouvrir un nouvel onglet.

- Commande + W : fermer la fenêtre ouverte au premier plan. Pour fermer toutes les fenêtres de l’app, appuyez sur Option + Commande + W.

- Option + Commande + Échap : [forcer la fermeture](https://support.apple.com/fr-fr/102586) d’une app.

- Commande + Barre d’espace : afficher ou masquer le champ de recherche [Spotlight](https://support.apple.com/guide/mac-help/mchlp1008/mac) . Pour lancer une recherche Spotlight depuis une fenêtre du Finder, appuyez sur Option + Commande + Barre d’espace . (Sous certaines versions de macOS, si vous [utilisez plusieurs méthodes de saisie](https://support.apple.com/guide/mac-help/mchlp1406/mac) pour écrire dans différentes langues, ces raccourcis modifient les méthodes de saisie. Découvrez comment [modifier un raccourci clavier présentant un conflit](https://support.apple.com/guide/mac-help/mchlp2864/mac) .)

- Contrôle + Commande + Barre d’espace ou Fn + E : afficher le visualiseur de caractères, à partir duquel vous pouvez choisir [des Emoji et d’autres symboles](https://support.apple.com/guide/mac-help/mchlp1560/mac) .

- Contrôle + Commande + F : utiliser ou arrêter d’utiliser l’app en plein écran, si celle-ci prend en charge ce mode d’affichage.

- Barre d’espace : utiliser la fonctionnalité [Coup d’œil](https://support.apple.com/guide/mac-help/mh14119/mac) pour obtenir un aperçu de l’élément sélectionné.

- Commande + Tab : passer à l’app ouverte suivante la plus récemment utilisée.

- Commande + Accent grave (`) : basculer entre les fenêtres de l’app en cours d’utilisation. (Le caractère sur la deuxième touche varie selon le clavier. Il s’agit en général de la touche située au-dessus de la touche de tabulation et à gauche du chiffre 1.)

- Maj + Commande + 5 : effectuer une capture d’écran ou procéder à l’enregistrement de l’écran sous [macOS Mojave ou version ultérieure](https://support.apple.com/fr-fr/109033) . Vous pouvez également appuyer sur les touches Maj + Commande + 3 ou Maj + Commande + 4 pour prendre des captures d’écran. [En savoir plus sur les captures d’écran](https://support.apple.com/fr-fr/102646) .

- Maj + Commande + N : créer un dossier vide dans le Finder.

- Contrôle + Commande + N : créer un dossier contenant les éléments actuellement sélectionnés.

- Commande + Virgule (,) : ouvrir les réglages (préférences) de l’app active.

- Fn + Q : créer une [note rapide](https://support.apple.com/guide/notes/apdf028f7034/mac) .

## Mise en veille, fermeture de session et arrêt de l’ordinateur

Vous pouvez avoir besoin d’appuyer et de garder les touches de certains de ces raccourcis enfoncées un peu plus longtemps que pour les autres. Cela vous évite de les utiliser involontairement.

- Bouton d’alimentation :

- Appuyer pour allumer votre Mac ou le sortir du mode veille

- Appuyer de manière prolongée pour forcer votre Mac à s’éteindre, par exemple s’il ne répond pas et que vous ne pouvez pas sélectionner Éteindre dans le menu Apple .

- Sur les claviers avec Touch ID, appuyer pour verrouiller l’écran.

- Sur les claviers intégrés sans Touch ID, appuyer de manière prolongée pendant 1,5 seconde pour mettre votre Mac en veille, ou appuyer sur Option + Commande + Bouton d’alimentation

- Contrôle + Maj + Bouton d’alimentation : sur les claviers intégrés sans Touch ID, mettre vos écrans en veille.

- Contrôle + Bouton d’alimentation : sur les claviers intégrés sans Touch ID, afficher une boîte de dialogue vous demandant si vous souhaitez redémarrer votre Mac, le mettre en veille ou l’éteindre.

- Contrôle + Commande + Bouton d’alimentation : sur les claviers intégrés sans Touch ID, forcer votre Mac à redémarrer, sans vous demander d’enregistrer les documents ouverts et non enregistrés.

- Contrôle + Option + Commande + Bouton d’alimentation : sur les claviers intégrés sans Touch ID, quitter toutes les apps, puis éteindre votre Mac. Si des modifications ont été apportées aux documents ouverts, on vous proposera de les enregistrer. Cela équivaut à choisir l’option Redémarrer dans le menu Apple .

- Contrôle + Commande + Q : verrouiller votre écran.

- Maj + Commande + Q : se déconnecter de votre compte utilisateur macOS. Vous serez invité à confirmer. Pour vous déconnecter immédiatement sans confirmer, appuyez sur Option + Maj + Commande + Q.

- Touche Option tout en sélectionnant la commande Fermer la session, Éteindre ou Redémarrer dans le menu Apple  : effectuer l’action sans afficher de boîte de dialogue de confirmation.

## Raccourcis d’accessibilité

### Raccourcis liés à la vision

Pour utiliser ces raccourcis liés à la vision, choisissez d’abord Réglages Système (ou Préférences Système) dans le menu Apple , puis cliquez sur Clavier. Cliquez sur Raccourcis clavier, sélectionnez Accessibilité à gauche, puis sélectionnez « Inverser les couleurs » et « Contraste » à droite.

- Contrôle + Option + Commande + 8 : inverser les couleurs.

- Contrôle + Option + Commande + virgule (,) et Contrôle + Option + Commande + point (.) : réduire et augmenter le contraste.

### Raccourcis liés au focus du clavier

Utilisez les raccourcis suivants pour changer le focus du clavier. Pour utiliser certains de ces raccourcis, choisissez d’abord Réglages Système (ou Préférences Système) dans le menu Apple , puis cliquez sur Clavier. Cliquez sur Raccourcis clavier, sélectionnez Clavier à gauche, puis sélectionnez le raccourci pour l’activer.

- Contrôle + F2 ou Fn + Contrôle + F2 : déplacer le focus vers la barre des menus. Vous pouvez ensuite utiliser les touches fléchées pour parcourir le menu, appuyer sur Retour pour ouvrir un menu sélectionné ou choisir un élément de menu sélectionné, ou taper le nom de l’élément de menu pour y accéder dans le menu sélectionné.

- Contrôle + F3 ou Fn + Contrôle + F3 : déplacer le focus vers le Dock.

- Contrôle + F4 ou Fn + Contrôle + F4 : déplacer le focus vers la fenêtre active ou la fenêtre suivante.

- Contrôle + F5 ou Fn + Contrôle + F5 : déplacer le focus vers la barre d’outils de la fenêtre.

- Contrôle + F6 ou Fn + Contrôle + F6 : déplacer le focus vers la fenêtre flottante.

- Contrôle + Maj + F6 : déplacer le focus vers la sous-fenêtre précédente.

- Contrôle + F7 ou Fn + Contrôle + F7 : changer le déplacement du focus de la touche Tab, entre la navigation entre toutes les commandes à l’écran et uniquement les zones de texte et les listes.

- Contrôle + F8 ou Fn + Contrôle + F8 : déplacer le focus vers le menu d’état dans la barre de menus.

- Commande + accent grave (`) : activer la fenêtre ouverte suivante dans l’app au premier plan.

- Maj + Commande + accent grave (`) : activer la fenêtre ouverte précédente dans l’app au premier plan.

- Option + Commande + accent grave (`) : déplacer le focus sur le volet de la fenêtre.

- Tab et Maj + Tab : passer à la commande suivante ou précédente.

- Contrôle + Tab : passer à la commande suivante lorsqu’un champ de texte est sélectionné.

- Contrôle + Maj + Tab : passer au groupe de commandes précédent.

- Touches fléchées : passer à l’élément adjacent dans une liste, un groupe d’onglets ou un menu, ou déplacer les curseurs et outils de réglage (flèche vers le haut pour augmenter les valeurs, flèche vers le bas pour diminuer les valeurs).

- Contrôle + touches fléchées : passer à une commande adjacente au champ de texte.
