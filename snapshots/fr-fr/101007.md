# OS X Server : mise à niveau et migration depuis Mavericks ou Mountain Lion

Consultez cet article pour savoir comment effectuer une mise à niveau ou une migration vers OS X Server sous Yosemite, et ce depuis OS X Server sous Mavericks ou Mountain Lion.

## Étapes préliminaires

Avant de lancer une mise à niveau ou une migration, assurez-vous de disposer d’une sauvegarde ou d’une copie complète et fiable de l’installation et des données de votre serveur actuel.

Si vous effectuez une mise à niveau ou une migration depuis Lion Server ou Mac OS X Server 10.6, consultez [cet article](http://support.apple.com/kb/HT5381?viewlocale=fr_FR) .

## Planification de la mise à niveau ou de la migration

Vérifiez que votre serveur cible dispose de la configuration requise par [OS X Yosemite](http://www.apple.com/fr/osx/specs/) et [OS X Server](http://www.apple.com/fr/osx/server/specs/) . Assurez-vous d’installer la dernière version d’OS X Server sur le serveur de destination.

Vérifiez que les serveurs DNS ou DHCP sur lesquels s’appuie votre serveur restent actifs pendant le processus. Si vous utilisez Xsan, assurez-vous de disposer de [noms d’hôte pleinement résolvables](http://support.apple.com/kb/HT6530?viewlocale=fr_FR) sur votre réseau de métadonnées.

Pour mettre à niveau ou migrer un serveur distant, vous devez être en mesure de contrôler le serveur à l’aide du partage d’écran ou d’Apple Remote Desktop.

Lorsque vous mettez à niveau un maître Open Directory, suivez les instructions de [cet article](http://support.apple.com/kb/HT5300?viewlocale=fr_FR) . Important : les règles générales relatives aux mots de passe, établies pour les comptes d’utilisateurs réseau, ne sont pas préservées lors de la mise à niveau ou de la migration vers OS X Server (Yosemite). Prenez note de ces règles avant la mise à niveau ou la migration, puis appliquez-les de nouveau dans l’application Serveur, une fois le processus terminé.

## Données de service

Vos réglages et données de service sont conservés lors d’une mise à niveau ou d’une migration. Les données de service sont conservées dans le répertoire /Bibliothèque/Serveur/ (emplacement par défaut des données de service). Les données stockées dans un autre emplacement sont conservées dans celui-ci.

## Mise à niveau du serveur

Vous pouvez effectuer une mise à niveau vers OS X Server sous Yosemite, depuis OS X Server sous Mavericks ou Mountain Lion, en installant tout d’abord OS X Yosemite, puis en installant l’application Serveur 4.0.

Procédez comme suit :

- Téléchargez et installez OS X Yosemite depuis le Mac App Store.

- Suivez les instructions du programme d’installation d’OS X.

- Une fois l’installation terminée, configurez votre ordinateur à l’aide de l’assistant Réglages.

- Si besoin, procédez à la migration des données à partir d’un autre ordinateur, tel qu’indiqué dans l’assistant.

- Une fois l’installation, la configuration et la migration terminées, achetez, téléchargez, puis installez l’application Serveur depuis le Mac App Store.

- Ouvrez l’application Serveur et suivez les instructions affichées à l’écran pour terminer la mise à niveau.

## Migration des données du serveur

Vous pouvez transférer les données d’OS X Server (Mavericks ou OS X Mountain Lion) vers un autre ordinateur doté d’OS X Yosemite. À l’aide de l’assistant Réglages ou de l’assistant Migration inclus sous Yosemite, transférez vos données avant d’ouvrir l’application Serveur.

Pour transférer les données de votre serveur, utilisez l’un des outils ci-dessous :

- Un serveur connecté en mode disque cible ;

- Un disque dur local ou une partition locale sur lequel/laquelle est installé OS X Server ;

- Une sauvegarde Time Machine locale d’OS X Server.

Avec OS X Server, il est impossible d’effectuer une migration via une connexion réseau, que ce soit à partir d’un serveur existant ou d’une sauvegarde Time Machine.

Pour transférer les données de votre serveur :

- Sur un nouvel ordinateur Mac, utilisez l’assistant Réglages. Sinon, ouvrez l’assistant Migration à partir du dossier Utilitaires.

- Suivez les instructions qui s’affichent à l’écran. Sélectionnez une méthode de connexion prise en charge lorsque vous y êtes invité.

- Une fois la migration terminée, téléchargez et installez l’application Serveur depuis le Mac App Store.

- Ouvrez l’application Serveur et suivez les instructions affichées à l’écran pour terminer la configuration du serveur.

Si vous ouvrez l’application Serveur avant la migration des données du serveur, supprimez-la avant de procéder à la migration, puis réinstallez-la une fois la migration terminée.
