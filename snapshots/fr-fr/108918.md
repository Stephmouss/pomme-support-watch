# Modes Réduction active du bruit et Transparence des AirPods

Vous pouvez basculer entre les modes d’écoute Réduction active du bruit et Transparence sur vos AirPods Pro ou AirPods Max, en fonction de ce que vous souhaitez entendre autour de vous. Vous pouvez également désactiver les modes d’écoute.

## En quoi consistent les modes Réduction active du bruit et Transparence ?

Lorsque vous activez le mode Réduction active du bruit, un ou plusieurs microphones orientés vers l’extérieur détectent les bruits ambiants. Vos AirPods 4 avec Réduction active du bruit (ANC), AirPods Pro 1, AirPods Pro 2, AirPods Pro 3, AirPods Max 1 et AirPods Max 2 génèrent alors un antibruit qui les annule avant que vous ne les entendiez. Par ailleurs, un microphone orienté vers l’intérieur détecte les bruits indésirables dans votre oreille, qui sont aussi neutralisés par un antibruit généré par vos AirPods.

Le mode Transparence laisse filtrer les sons extérieurs pour que vous puissiez rester attentif à votre environnement. Les modes Réduction active du bruit et Transparence fonctionnent de manière optimale lorsque [vos AirPods Pro sont parfaitement ajustés à vos oreilles](https://support.apple.com/fr-fr/119849) .

Si vous avez des AirPods 4 avec Réduction active du bruit, des AirPods Pro 2, des AirPods Pro 3 ou des AirPods Max 2 et la [dernière version d’iOS ou d’iPadOS](https://support.apple.com/fr-fr/118575) , vous pouvez également utiliser l’ [audio adaptatif](https://support.apple.com/fr-fr/104979) , qui ajuste la réduction du bruit en fonction de votre environnement.

Avec les AirPods Pro 2, les AirPods Pro 3 et les AirPods Max 2, les modes d’écoute peuvent aussi [réduire votre exposition aux sons bruyants de votre environnement](https://support.apple.com/fr-fr/120850) .

## Basculer entre les modes d’écoute

Vous pouvez passer d’un mode d’écoute à l’autre directement sur vos AirPods, ou sur votre iPhone, votre iPad, votre Apple Watch ou votre Mac. Lorsque vous passez d’un mode à un autre, vous entendez un son.

Lorsque vous choisissez un mode de contrôle du bruit sous iOS, iPadOS, watchOS ou macOS, le mode Réduction active du bruit correspond à l’option Réduction du bruit.

### Basculer d’un mode d’écoute à un autre sur vos AirPods Max 1 ou AirPods Max 2

Lorsque vous portez vos AirPods Max 1 ou vos AirPods Max 2, appuyez sur le bouton de mode d’écoute pour basculer entre les modes Réduction active du bruit et Transparence. Avec les AirPods Max 2, vous pouvez également passer à l’audio adaptatif. Vous pouvez [personnaliser les modes entre lesquels vous souhaitez basculer](https://support.apple.com/fr-fr/102663) dans les réglages Bluetooth de votre iPhone, votre iPad ou votre Mac.

[Image: Bouton de mode d’écoute sur les AirPods Max. Le bouton se trouve sur le dessus de l’oreillette droite, à l’opposé de la Digital Crown.]

### Basculer d’un mode d’écoute à un autre sur vos AirPods 4 (ANC) ou AirPods Pro

Appuyez de manière prolongée sur le capteur-pression situé sur la tige d’un AirPod jusqu’à ce qu’un son soit émis.

[Image: Capteur-pression des AirPods Pro.]

Pendant que vous portez les deux AirPods, appuyez de manière prolongée sur le capteur-pression de l’un ou l’autre des AirPods pour basculer entre les modes Réduction active du bruit, Transparence, ou aucun (Non). Avec les AirPods 4 (ANC), les AirPods Pro 2 et les AirPods Pro 3, vous pouvez également activer l’audio adaptatif. Vous pouvez personnaliser les modes entre lesquels vous souhaitez basculer dans les réglages AirPods de votre iPhone, iPad ou Mac.

Pour utiliser le mode Réduction active du bruit avec un seul AirPod, accédez à Réglages > Accessibilité > AirPods sur votre iPhone ou iPad, puis activez l’option « Réduction du bruit avec un AirPod ». Appuyez ensuite de façon prolongée sur le capteur-pression pour basculer d’un mode d’écoute à un autre.

### Basculer d’un mode d’écoute à l’autre sur votre iPhone ou iPad

- Effectuez un balayage vers le bas depuis l’angle supérieur droit de l’écran pour ouvrir le centre de contrôle [sur votre iPhone](https://support.apple.com/fr-fr/108330) ou [sur votre iPad](https://support.apple.com/fr-fr/111790) .

- Pendant que vous portez vos AirPods, appuyez de manière prolongée sur le curseur de volume, jusqu’à ce que des commandes supplémentaires s’affichent.

- Touchez le bouton Mode d’écoute dans l’angle inférieur gauche.

[Image: null]

[Image: Commande de volume dans le centre de contrôle d’un iPhone. Le bouton Mode d’écoute est le premier bouton situé après le curseur de volume.]

- Touchez le mode d’écoute souhaité.

[Image: Modes d’écoute Transparence, Adaptatif et Réduction du bruit dans le centre de contrôle d’un iPhone.]

Vous pouvez également personnaliser les modes d’écoute et passer de l’un à l’autre dans Réglages :

- Après avoir placé vos AirPods dans vos oreilles et les avoir connectés à votre iPhone ou iPad, accédez à Réglages.

- Touchez le nom de vos AirPods.

- Pour basculer d’un mode d’écoute à un autre, touchez Réduction du bruit ou Transparence. Pour choisir les modes d’écoute que vous pouvez activer avec le capteur-pression sur vos AirPods 4 (ANC) ou AirPods Pro, ou avec le bouton de mode d’écoute sur vos AirPods Max, sélectionnez deux ou trois modes sous « Cycles du bouton entre ».

[Image: Options du mode d’écoute dans les réglages des AirPods Pro sur iPhone. Les modes Transparence, Adaptatif et Réduction du bruit figurent après le champ Nom.]

### Basculer d’un mode d’écoute à l’autre sur votre Apple Watch

- Avec vos AirPods Pro ou AirPods Max connectés à votre Apple Watch, appuyez sur le bouton latéral pour accéder au Centre de contrôle.

- Lorsque vous écoutez un contenu audio, touchez l’icône de vos AirPods.

- Choisissez un mode d’écoute.

### Basculer entre les modes d’écoute sur votre Mac

- Avec vos AirPods Pro ou AirPods Max connectés à votre Mac, cliquez sur l’icône AirPods dans la barre des menus.

- Sélectionnez vos AirPods Pro ou AirPods Max, puis choisissez le mode d’écoute souhaité.

[Image: Menu Son dans la barre des menus sur Mac. Les modes de contrôle du bruit disponibles s’affichent lorsque les AirPods Pro ou AirPods Max sont sélectionnés comme appareil sortie audio.]

Vous pouvez également choisir les deux ou trois modes d’écoute que vous souhaitez pouvoir activer avec le capteur-pression sur vos AirPods (ANC) ou AirPods Pro, ou avec le bouton de mode d’écoute sur vos AirPods Max :

- Lorsque vos AirPods Pro ou AirPods Max sont connectés à votre Mac, sélectionnez le menu Pomme  > Réglages Système.

- Cliquez sur « Maintenir appuyé pour basculer entre » pour sélectionner les deux ou trois modes d’écoute entre lesquels vous souhaitez alterner.

[Image: Réglages des AirPods Pro dans Réglages Système sur un Mac.]

Découvrez comment procéder [si le mode Réduction active du bruit ne fonctionne pas comme prévu sur vos AirPods Pro](https://support.apple.com/fr-fr/111108) .

## Désactiver les modes d’écoute

- Vos AirPods connectés à votre appareil, accédez à Réglages > vos AirPods sur un iPhone ou iPad. Sur un Mac, choisissez le menu Pomme  > Réglages Système, puis sélectionnez vos AirPods.

- Pour des AirPods Pro 2 et des AirPods Pro 3 jumelés avec des appareils compatibles*, activez le réglage « Mode d’écoute Non », ce qui vous permet de désactiver toute la technologie des modes d’écoute.

- Sous Mode d’écoute, sélectionnez Non. La désactivation du mode d’écoute sur les AirPods Pro 2 et les AirPods Pro 3 désactive également les [fonctionnalités de protection auditive](https://support.apple.com/fr-fr/120850)

* Les appareils compatibles sont les iPhone dotés d’iOS 18.1 ou version ultérieure, les iPad dotés d’iPadOS 18.1 ou version ultérieure et les ordinateurs Mac dotés de macOS Sonoma 15.1 ou version ultérieure.
