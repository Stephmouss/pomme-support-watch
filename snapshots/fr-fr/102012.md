# Effectuer une capture d’écran sur un iPod touch

Enregistrez le contenu de votre écran.

## Effectuer une capture d’écran sur un iPod touch

- Appuyez simultanément sur le bouton supérieur et sur le bouton principal.

[Image: Appuyez simultanément sur le bouton supérieur et le bouton principal de l’iPod touch pour effectuer une capture d’écran.]

- Relâchez rapidement les deux boutons.

- Touchez la capture d’écran dans l’angle inférieur gauche.

- Touchez OK.

- Choisissez Enregistrer dans Photos, Enregistrer dans Fichiers ou Supprimer la capture d’écran.

## Trouver vos captures d’écran

Si vous choisissez Enregistrer dans Photos, vous pouvez accéder à l’élément enregistré dans l’album Captures d’écran de l’app Photos, ou dans l’album Toutes les photos si Photos iCloud est activé.
