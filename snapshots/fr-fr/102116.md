# Formater des périphériques de stockage pour Final Cut Pro, Motion et Compressor

Utilisez le format APFS pour les périphériques de stockage externes (comme les lecteurs USB) que vous souhaitez utiliser avec Final Cut Pro, Motion et Compressor sur Mac.

Certains périphériques de stockage sont vendus préformatés avec des formats de système de fichiers Windows tels que ExFAT ou FAT32. Ils pourraient ne pas fonctionner normalement avec Final Cut Pro, Motion ou Compressor.

Pour savoir quel est le format d’un périphérique de stockage, sélectionnez ce dernier dans le Finder, puis choisissez Lire les informations dans le menu Fichier. Le format est indiqué dans la section Format sous Informations générales.

Si vous avez besoin de reformater un périphérique de stockage, utilisez [le format APFS](https://support.apple.com/guide/disk-utility/erase-and-reformat-a-storage-device-dskutl14079/mac) pour de meilleures performances. Lorsque vous formatez un périphérique de stockage, toutes les données du volume sont supprimées. Vous devez donc créer une sauvegarde si vous souhaitez conserver ces données.

Vous ne pouvez pas stocker votre bibliothèque Final Cut Pro sur un périphérique de stockage utilisé pour [les sauvegardes Time Machine](https://support.apple.com/HT201250) .
