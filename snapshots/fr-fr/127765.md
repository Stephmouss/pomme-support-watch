# Compresser une vidéo sur iPhone

Pour réduire la taille d’une vidéo après l’avoir enregistrée, ouvrez-la dans iMovie, puis exportez-la depuis cette app dans une résolution plus basse.

## Éléments requis

- Un iPhone 12 ou modèle ultérieur doté d’iOS 26 ou version ultérieure*.

- La dernière version [d’iMovie pour iOS](https://apps.apple.com/fr/app/imovie/id377298193) . Téléchargez-la gratuitement sur votre iPhone depuis l’App Store.

- Une vidéo dans la [photothèque sur votre iPhone](https://support.apple.com/guide/iphone/browse-your-photo-library-iph7d24753a5/ios) . Si elle est stockée ailleurs ou si vous utilisez une app photo tierce pour gérer vos photos et vidéos, [découvrez comment importer des fichiers multimédias dans votre photothèque](https://support.apple.com/guide/imovie-iphone/import-video-clips-and-photos-kna18c32c373/ios) afin qu’ils apparaissent dans le navigateur multimédia iMovie.

* Vous pouvez compresser une vidéo avec iMovie sur iPhone sur des modèles plus anciens d’iPhone et des versions antérieures d’iOS et d’iMovie, mais la procédure de compression et les options disponibles peuvent varier.

## Compresser une vidéo avec iMovie

Ajoutez la vidéo à un projet iMovie, puis exportez-la dans une résolution inférieure. Vous pouvez [vérifier la taille de la vidéo](https://support.apple.com/fr-fr/127765#check_size) à tout moment.

### Ajouter votre vidéo à un projet iMovie

- Ouvrez iMovie.

- Dans le navigateur Projets, touchez Commencer un nouveau projet, puis Film.

- Touchez Données multimédias, puis Vidéo pour parcourir les vidéos stockées dans votre photothèque.

- Touchez la vidéo que vous souhaitez compresser. Une coche apparaît sur la vidéo pour confirmer votre sélection.

- Touchez Créer un film. Un nouveau projet s’ouvre avec votre vidéo dans la timeline d’iMovie. À partir de là, vous pouvez modifier votre vidéo ou passer directement à l’exportation si vous êtes prêt.

- Touchez OK.

### Exporter votre vidéo dans une résolution inférieure

Lorsque vous exportez un fichier dans une résolution inférieure, vous réduisez sa taille. Toutefois, la qualité vidéo peut être réduite, en fonction des réglages de votre iPhone au moment de l’enregistrement (la résolution HD 1080p est le réglage par défaut). La résolution 540p est adaptée aux médias sociaux, tandis que la résolution 360p est appropriée pour les SMS.

- Touchez le bouton Partager en bas de l’écran. Si vous êtes dans le navigateur Projets, touchez le projet iMovie, puis le bouton Partager.

- Touchez Enregistrer ou partager la vidéo.

- Touchez Options.

[Image: Après avoir touché le bouton Partager, touchez le bouton Options pour choisir une résolution inférieure pour la vidéo exportée.]

- Sélectionnez une résolution inférieure, comme 720, 540 ou 360. La taille approximative d’un fichier vidéo d’une minute aux résolutions disponibles est la suivante :

- 1080p (réglages d’exportation iMovie et de l’appareil photo de l’iPhone par défaut) : 70 à 105 Mo

- 720 : 19 à 27 Mo

- 540 : 12 à 16 Mo

- 360 : 6 à 9 Mo

- Touchez OK.

- Choisissez l’emplacement dans lequel vous souhaitez exporter votre film :

- Pour enregistrer la vidéo dans votre photothèque, touchez Enregistrer la vidéo. Si vous utilisez [Photos iCloud](https://support.apple.com/HT204264) , la vidéo apparaîtra sur vos autres appareils.

- Pour enregistrer dans iCloud, à un autre emplacement de votre appareil ou dans un autre [service de stockage tiers que vous avez activé dans l’app Fichiers](https://support.apple.com/fr-fr/102238) , touchez Enregistrer dans Fichiers, choisissez un emplacement, puis touchez Enregistrer.

- Pour partager la vidéo avec un appareil situé à proximité à l’aide d’AirDrop, touchez AirDrop, votre photo de profil en haut de l’écran, puis sélectionnez l’appareil destinataire.

- Pour vérifier la nouvelle taille de fichier, vous pouvez [vérifier la taille de la vidéo exportée](https://support.apple.com/fr-fr/127765#check_size) .

## Vérifier la taille d’une vidéo sur iPhone

Utilisez l’app Photos si votre vidéo se trouve dans votre photothèque. Utilisez l’app Fichiers si vous l’avez enregistrée ailleurs.

### Vérifier la taille d’une vidéo dans l’app Photos

Si vous avez enregistré la vidéo dans votre photothèque, vous pouvez voir la taille de la vidéo dans l’app Photos.

- Dans l’app Photos, recherchez la vidéo dans votre photothèque, puis sélectionnez-la.

- Touchez le bouton Informations en bas de l’écran. La taille du fichier apparaît sous le nom de l’appareil utilisé pour enregistrer la vidéo, avec d’autres détails techniques.

- Pour regarder la vidéo, touchez-la dans la photothèque.

### Vérifier la taille d’une vidéo dans l’app Fichiers

Si vous avez enregistré la vidéo à un autre emplacement que votre photothèque, vous pouvez vérifier sa taille dans l’app Fichiers. D’autres emplacements peuvent inclure différents endroits sur votre appareil, sur iCloud ou dans un service de stockage cloud tiers (si vous [l’avez ajouté à l’app Fichiers](https://support.apple.com/fr-fr/102238) ).

- Ouvrez l’app Fichiers sur votre iPhone.

- Pour trouver la vidéo exportée, touchez Explorer ou Récents en bas de l’écran, ou saisissez le nom de fichier de la vidéo dans le champ de recherche.

- Une fois que vous avez localisé la vidéo, la taille apparaît à côté du nom du fichier en présentation par liste ou sous la vignette en présentation par icônes.

- Pour regarder la vidéo, touchez-la dans l’app Fichiers.

## Si la vidéo est toujours trop volumineuse

Si le fichier est toujours trop volumineux, [élaguez la vidéo](https://support.apple.com/102353#ios) pour la raccourcir.

## Si vous souhaitez essayer une autre résolution

Si vous souhaitez essayer d’exporter dans une autre résolution, ouvrez à nouveau iMovie, ouvrez le projet contenant la vidéo, puis exportez la vidéo avec un réglage de résolution différent.

## Si vous souhaitez réduire de façon constante la taille de vos fichiers vidéo

Pour obtenir systématiquement des fichiers vidéo plus petits, vous pouvez [modifier les réglages de l’appareil photo](https://support.apple.com/guide/iphone/change-video-recording-settings-iphc1827d32f/ios) de votre iPhone. Choisissez une résolution inférieure à 1080p HD (le réglage de résolution par défaut), désactivez Vidéo HDR et assurez-vous que Haute efficacité est sélectionné.
