# Utiliser le mode Référence sur votre iPad Pro

Les écrans Liquid Retina XDR et Ultra Retina XDR de l’iPad Pro peuvent afficher des couleurs de référence correspondant aux normes de couleur répandues, ainsi qu’aux formats vidéo SDR et HDR.

## Qu’est-ce que le mode Référence ?

Le mode Référence est un mode d’affichage conçu pour les flux de travail professionnels de création de contenu, comme l’étalonnage des couleurs, le montage et la révision de contenu, pour lesquels la précision des couleurs et l’homogénéité de la qualité d’image sont essentielles.

Pour utiliser le mode Référence, vous avez besoin de :

- L’un des appareils suivants :

- iPad Pro 13 pouces (M4)

- iPad Pro 11 pouces (M4)

- iPad Pro 12,9 pouces (5e ou 6e génération)

- iPadOS 16 ou version ultérieure

Lorsque le mode Référence est activé, votre iPad Pro affiche les couleurs de référence pour ces normes de couleur et formats vidéo courants, jusqu’à 1 000 nits de luminosité maximale pour HDR et 100 nits de luminosité maximale pour SDR :

- BT.709

- BT.601 SMPTE-C

- BT.601 EBU

- sRGB

- HDR10 BT.2100 PQ

- BT.2100 HLG Dolby Vision Profile 8.4

- Dolby Vision Profile 5

Le mode Référence permet à votre iPad Pro de répondre aux exigences de couleur de votre flux de travail. Il cible un point blanc D65 et désactive tous les réglages d’affichage dynamiques pour le milieu ambiant, comme True Tone, Luminosité automatique et Night Shift. Vous pouvez également [ajuster le point blanc et la luminance manuellement](https://support.apple.com/fr-fr/111792#calibrate) . Pour les formats non pris en charge, les couleurs sont gérées comme elles le seraient en mode d’affichage par défaut.

Vous pouvez également [utiliser le mode Référence avec Sidecar](https://support.apple.com/fr-fr/111792#sidecar) pour créer un flux de travail de référence cohérent sur votre iPad et votre Mac.

Le mode Référence peut affecter l’autonomie de la batterie.

## Activer ou désactiver le mode Référence

- Ouvrez l’app Réglages, puis touchez Luminosité et affichage.

- Touchez Avancé.

[Image: Un iPad affichant les réglages Luminosité et affichage.]

- Activer ou désactiver le mode Référence.

## Utiliser Régler avec précision l’étalonnage

Utilisez Régler avec précision l’étalonnage pour maintenir la précision des couleurs de référence de votre écran en ajustant le point blanc et la luminance. Saisissez les valeurs que vous mesurez à l’aide d’un instrument externe et d’un motif de test. iPadOS ajuste automatiquement l’affichage en fonction des valeurs cibles de point blanc et de luminance.

- Ouvrez l’app Réglages, puis touchez Luminosité et affichage. Touchez ensuite Avancé, puis assurez-vous que le mode Référence est activé.

[Image: Un iPad affichant les réglages avancés d’affichage et de luminosité. Le mode Référence est actif.]

- [Mesurez un motif de test](https://support.apple.com/fr-fr/111792#test-patterns) à l’aide d’un instrument externe. Notez les valeurs mesurées.

- Revenez à l’app Réglages, puis touchez Affichage et luminosité. Touchez Avancé, puis Régler avec précision l’étalonnage.

[Image: Un iPad affichant les réglages Régler avec précision l’étalonnage, qui vous permettent de régler le point blanc et la luminance mesurés et cibles.]

- Touchez l’espace à côté de chaque réglage pour saisir une valeur. Saisissez les valeurs que vous avez mesurées dans les champs Mesure. Saisissez vos valeurs cibles pour le point blanc et la luminance dans les champs Cible.

- Lorsque vous avez fini, touchez OK. L’affichage de votre iPad Pro s’ajuste automatiquement en fonction des valeurs cibles de point blanc et de luminance.

Voici les descriptions de ce que vous devez saisir dans les champs Mesure et Cible :

- Point blanc mesuré (x) : coordonnée de chromaticité x (CIE 1931 xyY) lors de la mesure d’un motif de test de blanc ou de gris.

- Point blanc mesuré (y) : coordonnée de chromaticité y (CIE 1931 xyY) lors de la mesure d’un motif de test de blanc ou de gris.

- Luminance mesurée (cd/m 2 ) : valeur de luminance Y (CIE 1931 xyY) lors de la mesure d’un motif de test de blanc ou de gris.

- Point blanc cible (x) : coordonnée de chromaticité x (CIE 1931 xyY) de votre point blanc cible.

- Point blanc cible (y) : coordonnée de chromaticité y (CIE 1931 xyY) de votre point blanc cible.

- Luminance cible (cd/m 2 ) : valeur de luminance Y (CIE 1931 xyY) de votre luminance cible.

Pour supprimer tout réglage précis de l’étalonnage précédemment appliqué, touchez Rétablir les réglages par défaut.

### Téléchargement des motifs de test

Vous pouvez utiliser des motifs de test QuickTime, fournis par Apple, pour évaluer l’étalonnage de votre iPad Pro. Ces outils de référence adaptés aux formats couleur vous permettent d’utiliser votre propre instrument de mesure pour affiner l’étalonnage du point blanc et de la luminance de votre écran.

- Accédez à la [page AVFoundation dédiée aux développeurs](https://developer.apple.com/av-foundation/) .

- Dans la section Related Resources (Ressources connexes), cliquez sur Color Test Patterns (Motifs de test) pour télécharger les fichiers de test correspondants.

- Dans l’app Fichiers, décompressez l’archive QuickTime-Test-Pattern.zip. Chaque ensemble de motifs de test comprend un fichier Reference Values.txt qui répertorie la chromaticité et la luminance attendues pour chaque motif de test.

Seuls les ensembles de motifs de test QuickTime suivants sont recommandés pour l’iPad Pro :

- HDR10_ST2084

- SDR_BT601_NTSC_SMPTE_C

- SDR_BT601_PAL_EBU

- SDR_BT709_HDTV

### Vérifier votre configuration et votre environnement

Pour mesurer un motif de test et procéder à un réglage précis de votre écran :

- Pointez votre instrument de mesure au centre de l’écran.

- Vérifiez que votre instrument est perpendiculaire à la surface de l’écran.

- Assurez-vous que la pièce dans laquelle vous vous trouvez est sombre afin d’éviter que la lumière ou un reflet ne viennent fausser les mesures.

- Assurez-vous que l’écran est allumé depuis au moins 30 minutes et que sa température est stable.

- Procédez aux mesures et au réglage précis dans un environnement dont la température ambiante est de 25 °C maximum.

- Il n’est pas nécessaire de supprimer un étalonnage de précision existant avant d’effectuer des mesures et d’en appliquer un nouveau.

### Limites des plages pour l’étalonnage de précision

- Les champs de données des trois valeurs mesurées offrent des plages d’entrées statiques acceptables, ce qui vous permet de mesurer un large éventail de motifs de test.

- Les plages atteignables pour les champs de données x et y cibles sont calculées en fonction des valeurs x et y mesurées et de tout étalonnage de précision existant.

- La plage atteignable pour la luminance cible est calculée en fonction des valeurs x, y et de luminance mesurées, des valeurs x et y cibles et de tout étalonnage de précision existant.

- Les plages atteignables pour les champs de données cibles sont affichées à côté des champs.

- Si vous saisissez une valeur qui se situe en dehors de la plage atteignable, la plage est mise en surbrillance en rouge.

### Si votre valeur cible souhaitée se situe en dehors de la plage affichée

Cela peut être dû à une ou plusieurs des raisons suivantes :

- Les valeurs des mesures de votre instrument peuvent être incorrectes. Vérifiez que votre instrument est perpendiculaire à l’écran et pointé vers le centre de la séquence de test.

- Les valeurs que vous avez saisies dans les champs de mesures peuvent être incorrectes. Vérifiez que les valeurs mesurées saisies correspondent aux données de mesure que vous avez collectées avec votre instrument.

- Les valeurs que vous avez saisies dans les champs cibles peuvent être incorrectes. Vérifiez que vous utilisez le motif de test voulu et que les valeurs cibles saisies dans les champs de cibles correspondent à la chromaticité et à la luminance attendues du motif de test mesuré.

- La cible de luminance souhaitée peut ne pas être atteignable. Les écrans d’iPad sont conçus pour être les meilleurs de l’industrie. Tous les écrans peuvent être sujets à une réduction des niveaux de luminosité à mesure que l’écran prend de l’âge; de ce fait, votre cible de luminance peut ne plus être atteignable. Dans ce cas, la précision du point blanc de l’écran peut toujours être maintenue.

## Utiliser le mode Référence avec Sidecar

Nécessite un Mac avec puce Apple

Si vous utilisez Sidecar pour étendre ou recopier le bureau de votre Mac sur votre iPad Pro, vous pouvez activer le mode Référence pour utiliser votre iPad Pro comme moniteur de référence secondaire :

- Sur votre iPad, activez le mode Référence.

- Sur votre Mac, [choisissez un préréglage de référence](https://support.apple.com/108321#choose) . Vous pouvez utiliser l’un de ces préréglages (avec les normes de couleur et les formats vidéo correspondants qui sont pris en charge par le mode Référence entre parenthèses) :

- Vidéo HDTV (BT.709)

- Vidéo NTSC (BT.601 SMPTE-C)

- Vidéo PAL & SECAM (BT.601 EBU)

- Internet et Web (sRGB)

- Vidéo HDR (HDR10 BT.2100 PQ, BT.2100 HLG Dolby Vision Profile 8.4, Dolby Vision Profile 5)

- [Déplacer une fenêtre du Mac sur votre iPad](https://support.apple.com/fr-fr/102597) .
