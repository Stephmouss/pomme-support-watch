# Empêcher l’installation des logiciels bêta d’Apple sur des appareils supervisés

Utilisez Apple Configurator ou une solution de gestion des appareils mobiles (MDM) pour empêcher l’installation de logiciels bêta d’Apple sur des appareils supervisés.

Les logiciels bêta iOS sont accessibles aux utilisateurs inscrits au [programme de logiciels bêta d’Apple](https://support.apple.com/HT203282) .

Vous pouvez empêcher les utilisateurs d’installer des logiciels bêta sur des appareils supervisés via [Apple Configurator](https://support.apple.com/guide/apple-configurator-mac/welcome/mac)

- Dans Apple Configurator, ouvrez la fenêtre de charge utile Restrictions iOS.

- Désactivez l’option « Autoriser l’installation de profils de configuration (appareils supervisés uniquement) ».

Si vous utilisez une solution MDM tierce, recherchez la clé « allowUIConfigurationProfileInstallation ».

Lorsque vous définissez cette restriction, les utilisateurs ne peuvent pas installer de profils à partir de courriers électroniques ou de sites web. Cela inclut le profil permettant d’inscrire l’appareil dans le programme de logiciels bêta iOS. Cela empêche également les utilisateurs d’activer les mises à jour bêta dans les réglages. Vous pouvez toujours utiliser Apple Configurator ou une solution MDM pour installer des profils sur les appareils que vous gérez.
