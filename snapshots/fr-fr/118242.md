# Utilisez votre Apple Gift Card, votre App Store Card ou votre carte cadeau App Store et iTunes

Utilisez votre carte cadeau dans l’App Store ou l’app Musique pour acheter des apps, des abonnements et plus encore avec votre compte Apple.

## Utilisation d’une carte cadeau sur votre appareil

Vous pouvez utiliser une carte cadeau sur votre appareil pour ajouter des fonds au solde de votre compte Apple.

### Utilisation d’une carte cadeau dans l’App Store sur votre iPhone

- Recherchez le code à 16 chiffres qui figure au dos de la carte. Sur certaines cartes cadeaux, vous devrez peut-être décoller ou gratter délicatement l’étiquette pour voir le code.

- Dans l’App Store, touchez votre photo, vos initiales ou le bouton Mon compte . Il vous sera peut-être demandé de vous connecter à votre compte Apple.

- Touchez Utiliser un code.

[Image: Écran d’iPhone affichant la page du compte Apple dans l’App Store, avec le bouton Utiliser le code en surbrillance.]

- Touchez Utiliser la caméra et suivez les instructions à l’écran. Si vous rencontrez des difficultés pour utiliser la carte, touchez « Saisir le code manuellement », puis suivez les instructions à l’écran.

- Touchez Utiliser.

### Utilisez une carte cadeau dans l’app Cartes sur l’iPhone

Dans certains pays et certaines régions, vous pouvez utiliser votre carte cadeau dans Cartes. Pour ce faire, vous devez d’abord [ajouter la carte de votre compte Apple à Cartes](https://support.apple.com/guide/iphone/apple-account-iph5f869c0af/ios) .

- Recherchez le code à 16 chiffres qui figure au dos de la carte. Sur certaines cartes cadeaux, vous devrez peut-être décoller ou gratter délicatement l’étiquette pour voir le code.

- Dans l’app Cartes, touchez la carte de votre compte Apple.

- Touchez le bouton Plus , puis Utiliser.

- Touchez Utiliser la caméra et suivez les instructions à l’écran. Si vous rencontrez des difficultés pour utiliser la carte, touchez « Saisir le code manuellement », puis suivez les instructions à l’écran.

- Touchez Utiliser.

[Vous ne parvenez pas à utiliser votre carte cadeau ?](https://support.apple.com/fr-fr/108285)

### Utilisation d’une carte cadeau sur votre Mac

- Recherchez le code à 16 chiffres qui figure au dos de la carte. Sur certaines cartes cadeaux, vous devrez peut-être décoller ou gratter délicatement l’étiquette pour voir le code.

- Dans l’App Store, cliquez sur votre nom dans la barre latérale. Ou cliquez sur le bouton Connexion et connectez-vous à votre compte Apple.

- Cliquez sur Utiliser le code.

[Image: La page du compte Apple dans l’App Store sur Mac, avec le bouton Utiliser le code en surbrillance.]

- Cliquez sur Utiliser la caméra et suivez les instructions à l’écran. Si vous ne parvenez pas à utiliser la carte, cliquez sur Saisir le code manuellement, puis suivez les instructions qui s’affichent à l’écran.

[Vous ne parvenez pas à utiliser votre carte cadeau ?](https://support.apple.com/fr-fr/108285)

### Utilisation d’une carte cadeau sur un PC Windows

- Recherchez le code à 16 chiffres qui figure au dos de la carte. Sur certaines cartes cadeaux, vous devrez peut-être décoller ou gratter délicatement l’étiquette pour voir le code.

- Ouvrez l’app Musique ou l’app Apple TV.

- Cliquez sur votre nom en bas de la barre latérale, puis sur « Utiliser un code ». Il vous sera peut-être demandé de vous connecter d’abord à votre compte Apple.

- Suivez les instructions à l’écran, puis cliquez sur « Utiliser le code ».

[Image: L’app Apple Music sur un PC affichant l’option Utiliser sélectionnée dans la barre latérale pour utiliser une carte cadeau.]

[Vous ne parvenez pas à utiliser votre carte cadeau ?](https://support.apple.com/fr-fr/108285)

## En savoir plus sur les cartes cadeaux

- Découvrez ce que vous pouvez [acheter avec votre Apple Gift Card, votre App Store Card, votre carte cadeau App Store & iTunes ou le solde de votre compte Apple](https://support.apple.com/fr-fr/118245) .

- Découvrez comment [consulter le solde de votre carte cadeau](https://support.apple.com/fr-fr/108111) .

- Certains achats nécessitent qu’une carte de crédit soit associée à votre compte, même si vous utilisez le solde de votre compte Apple pour les régler.

- Les cartes cadeaux ne sont pas disponibles dans tous les pays et toutes les zones géographiques. [Déterminez si des cartes cadeaux sont disponibles dans votre pays ou votre région](https://support.apple.com/fr-fr/111741) .

Les fonctionnalités des services multimédias Apple peuvent varier selon le pays ou la région. [Découvrez quelles fonctionnalités sont disponibles dans votre pays ou votre région](https://support.apple.com/fr-fr/118205) .
