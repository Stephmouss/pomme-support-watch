# Utiliser votre Apple Gift Card, App Store Card ou carte cadeau App Store & iTunes

Utilisez votre carte cadeau dans l’App Store ou l’app Musique pour acheter des apps, des abonnements et plus encore avec votre compte Apple.

## Utilisation de votre carte cadeau

Découvrez ce que vous pouvez [acheter avec votre Apple Gift Card, votre App Store Card, votre carte cadeau App Store & iTunes ou le solde de votre compte Apple](https://support.apple.com/fr-fr/118245) .

## Utilisation d’une carte cadeau sur votre appareil

Vous pouvez utiliser une carte cadeau sur votre appareil pour ajouter des fonds au solde de votre compte Apple.

### Utilisation d’une carte cadeau dans l’App Store sur votre iPhone

- Recherchez le code à 16 chiffres qui figure au dos de la carte. Sur certaines cartes cadeaux, vous devrez peut-être décoller ou gratter délicatement l’étiquette pour voir le code.

- Ouvrez l’app App Store.

- En haut de l’écran, touchez le bouton de connexion ou votre photo.

[Image: Aucun texte de remplacement pour l’image]

- Touchez Utiliser une carte cadeau ou un code. Si le bouton Utiliser une carte cadeau ou un code n’apparaît pas, connectez-vous avec votre compte Apple.

- Touchez Utiliser la caméra et suivez les instructions à l’écran. Si vous rencontrez des difficultés pour utiliser la carte, touchez « Saisir le code manuellement », puis suivez les instructions à l’écran.

- Touchez Utiliser.

Si la carte de votre compte Apple figure dans l’app Cartes d’Apple, la valeur d’une carte cadeau apparaît sur le solde de votre compte Apple dans l’app Cartes une fois que vous avez utilisé la carte. [En savoir plus sur l’utilisation de l’app Cartes d’Apple](https://support.apple.com/fr-fr/111112#use) .

### Utilisation d’une carte cadeau sur votre Mac

- Recherchez le code à 16 chiffres qui figure au dos de la carte. Sur certaines cartes cadeaux, vous devrez peut-être décoller ou gratter délicatement l’étiquette pour voir le code.

- Cliquez sur votre nom en bas de la barre latérale, puis sur « Utiliser un code ». Vous devrez peut-être vous connecter avec votre compte Apple au préalable.

## Si vous avez reçu une carte cadeau par e-mail

Pour utiliser une carte cadeau que vous avez reçue par e-mail, ouvrez le message et touchez ou cliquez sur le bouton Utiliser maintenant.

## Ce que vous pouvez acheter avec ces cartes cadeaux

Lorsque vous utilisez une Apple Gift Card, une App Store Card ou une carte cadeau App Store & iTunes, les fonds sont ajoutés au solde de votre compte Apple. Le solde de votre compte Apple vous permet d’effectuer des achats, notamment :

- Des apps, des jeux ou des achats intégrés dans l’App Store.

- Des abonnements tels qu’Apple Music, iCloud+ et plus encore.

- Lorsque l’Apple Gift Card est disponible, vous pouvez utiliser le solde de votre compte Apple pour acheter des produits et des accessoires sur apple.com ou dans l’app Apple Store. [Vérifiez si l’Apple Gift Card est disponible dans votre pays ou votre région.](https://support.apple.com/fr-fr/118407)

Certains achats ne peuvent pas être effectuées en utilisant le solde de votre compte Apple. [Découvrez ce que vous pouvez acheter avec le solde de votre compte Apple](https://support.apple.com/fr-fr/118245) .

## En savoir plus sur les cartes cadeaux

- Découvrez comment [consulter le solde de votre carte cadeau](https://support.apple.com/fr-fr/108111) .

- Les cartes cadeaux ne sont pas disponibles dans tous les pays et toutes les zones géographiques. [Déterminez si des cartes cadeaux sont disponibles dans votre pays ou votre région](https://support.apple.com/fr-fr/111741) .

- Certains achats nécessitent qu’une carte de crédit soit associée à votre compte, même si vous utilisez le solde de votre compte Apple pour les régler.

Les fonctionnalités des services multimédias Apple peuvent varier selon le pays ou la région. [Découvrez quelles fonctionnalités sont disponibles dans votre pays ou votre région](https://support.apple.com/fr-fr/118205) .
