# Si vous ne parvenez pas à dicter du texte, saisir des caractères accentués ou sélectionner des emoji dans la Touch Bar de votre Mac

Ces fonctionnalités sont susceptibles de ne pas fonctionner si vous avez installé le produit tiers Webroot SecureAnywhere.

Webroot SecureAnywhere est développé par Webroot Inc. Lorsque ce logiciel est installé sur votre Mac avec les réglages par défaut, il est possible que vous remarquiez les symptômes suivants :

- Le texte que vous dictez ne s’affiche pas comme prévu.

- Vous ne voyez aucun caractère accentué lorsque vous maintenez une touche alphabétique enfoncée.

- Vous ne pouvez pas sélectionner d’éléments tels que les emoji dans la Touch Bar de votre MacBook Pro.

Procédez comme suit pour résoudre le problème :

- Cliquez sur l’icône Webroot SecureAnywhere dans la barre de menus.

- Choisissez Interrompre la saisie clavier sécurisée.

Un [article d’assistance du site Webroot](https://answers.webroot.com/Webroot/ukp.aspx?vw=1&solutionid=1369) fournit des informations supplémentaires sur cette solution.
