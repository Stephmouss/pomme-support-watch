# Utilisation du séquenceur de GarageBand sur iPhone ou iPad

Créez des grooves sur votre iPhone ou iPad à l’aide d’une interface inspirée des boîtes à rythmes traditionnelles, puis ajoutez-les à vos morceaux.

[Image: Écran du séquenceur]

Pour commencer à utiliser le séquenceur, ouvrez un morceau existant ou créez-en un. Lorsque vous créez un morceau, le navigateur de sons s’ouvre automatiquement.

Si vous souhaitez ajouter le séquenceur à un morceau existant, touchez le bouton Navigateur de sons , effectuez un balayage jusqu’à la catégorie Batterie, puis touchez Séquenceur.

[Image: le bouton Navigateur de sons]

## Ajouter rapidement un rythme à votre morceau

Dans le séquenceur, touchez le bouton Modèles , puis choisissez le modèle qui se rapproche le plus du style souhaité. Le modèle est lu au tempo défini pour votre morceau et se répète en boucle, sur toute sa durée. Chaque modèle dispose de réglages uniques, notamment une durée, [que vous pouvez modifier](https://support.apple.com/fr-fr/101954#settings) .

[Image: le bouton Modèles]

Pour arrêter et démarrer la lecture du modèle, touchez le bouton Jouer le rythme . Si vous souhaitez ajouter le modèle à votre morceau, [enregistrez-le](https://support.apple.com/fr-fr/101954#record) .

[Image: le bouton Jouer le rythme]

Vous pouvez modifier le modèle en activant ou en désactivant des étapes. Chaque rang correspond à un instrument individuel de la batterie, affiché à gauche de la grille. Pour désactiver une étape du modèle, touchez une case allumée dans la grille. Pour activer une étape, touchez une case éteinte.

Vous pouvez également modifier les sons du modèle. Pour modifier l’ensemble de batterie complet, touchez le bouton situé en bas de l’écran, indiquant le nom de l’ensemble actuel (Trap Door ou Hacienda, par exemple). Dans la fenêtre Batterie, sélectionnez un style de sons dans la colonne de gauche, puis un ensemble dans la colonne de droite. Pour télécharger d’autres sons, touchez « Plus d’ensembles de batterie », puis [sélectionnez les sons qui vous intéressent dans la bibliothèque de sons](https://support.apple.com/HT208195) . Une fois l’ensemble souhaité sélectionné, touchez OK.

## Créer votre propre rythme

Pour créer un rythme en partant de zéro, touchez le bouton Modèles , puis Nouveau motif. Touchez Étape oui/non pour ajouter et supprimer des étapes. Vous pouvez ajouter et supprimer des étapes en cours de lecture ou lorsque le séquenceur est inactif.

[Image: le bouton Modèles]

Après avoir ajouté des étapes, vous pouvez modifier chacune d’entre elles :

- Pour ajuster le volume d’une étape, touchez Vélocité. Faites glisser votre doigt vers le bas sur une étape pour baisser son volume, et vers le haut pour l’augmenter.

- Pour scinder une étape en plusieurs étapes, touchez Répétition de note. Faites glisser votre doigt vers le haut pour augmenter le nombre de notes, et vers le bas pour le réduire.

- Pour ajouter une variation humaine à une étape, touchez Chance. Ensuite, faites glisser votre doigt vers le bas pour augmenter la variation de l’étape.

Si vous souhaitez modifier les réglages d’un rang entier, touchez un instrument à gauche de la grille.

- Pour modifier un seul élément, touchez Élément dans la fenêtre Réglages du rang, puis touchez l’élément à assigner à ce rang. Le rang sera désormais lu avec le son de cet élément.

- Pour modifier la longueur de chaque étape d’un rang, touchez Longueur des étapes, puis sélectionnez une longueur.

- Pour changer le sens de lecture de cet instrument dans le modèle par le séquenceur, touchez Mode Lecture, puis choisissez une option.

Une fois votre rythme créé, vous pouvez l’enregistrer en tant que modèle. Touchez le bouton Modèles , puis touchez Enregistrer. Saisissez le nom du modèle, puis touchez OK. Vous pouvez charger ce modèle et l’ajouter à différents morceaux.

[Image: le bouton Modèles]

Lorsque votre modèle est prêt à être ajouté à un morceau, [enregistrez-le](https://support.apple.com/fr-fr/101954#record) .

## Enregistrer le modèle

Afin d’enregistrer le modèle pour l’utiliser dans votre morceau, touchez le bouton Enregistrer dans la barre des commandes. Le séquenceur démarre automatiquement. Le modèle est lu en boucle jusqu’à ce que vous arrêtiez l’enregistrement. Une fois l’enregistrement du modèle terminé, touchez le bouton Pistes pour afficher la piste enregistrée, puis touchez le bouton Lecture dans la barre des commandes pour écouter le modèle avec les autres pistes.

[Image: bouton Enregistrer]

[Image: le bouton Pistes]

[Image: le bouton Lecture]

Une fois le modèle enregistré, vous pouvez modifier et ajuster la piste comme vous le feriez avec n’importe quelle autre piste d’instrument.

## Afficher et modifier les réglages du modèle

La longueur d’un modèle du séquenceur est déterminée par son nombre d’étapes. Si votre morceau est en 4/4, la longueur du modèle peut aller de 16 à 64 étapes. Si votre morceau est en 3/4 ou en 6/8, elle peut varier de 12 à 48 étapes. Vous pouvez également modifier manuellement la longueur de la boucle de chaque élément en touchant le bouton Début/fin de boucle, puis en faisant glisser la poignée de chaque rang.

Pour afficher les informations du modèle actuel et modifier ses réglages, touchez le bouton Inspecteur .

[Image: le bouton Inspecteur]

- Définissez la longueur du modèle (16, 32, 48 ou 64 étapes en 4/4, et 12, 24 ou 48 étapes en 3/4 et en 6/8).

- Définissez la longueur des étapes (Croche, Triolet de croches, Double croche, Triolet de doubles croches, Triple croche).

- Définissez le mode de lecture (Suivant, Inverser, Ping Pong, Aléatoire).

- Définissez la quantité de swing du modèle.

- Réinitialisez le modèle : si vous avez commencé à partir d’un modèle vierge, touchez Réinitialiser pour effacer la grille.
