# OS X Server (Mountain Lion) : réception impossible d’e-mails après la migration

Il est possible que des clients utilisant un service de messagerie sous OS X Server ne puissent pas réceptionner d’e-mails. Ce problème peut se produire si vous avez configuré votre serveur de messagerie en procédant à une migration vers Mountain Lion, à partir d’une sauvegarde Time Machine créée avec Lion Server, puis avez installé OS X Server.

Procédez comme suit :

- Consultez l’historique SMTP dans la section Historiques de l’application Serveur. Passez à l’étape 2 si une ligne comportant le message suivant s’affiche : "FAILED: Can't call method "isa" on unblessed reference at /Applications/Server.app/Contents/ServerRoot/usr/bin/amavisd line 6062. (in reply to end of DATA command))"

- Dans l’application Serveur, sélectionnez le service de messagerie, puis cliquez sur le bouton Modifier les réglages des filtres. Modifiez la valeur minimale applicable au courrier indésirable en déplaçant le curseur vers la position souhaitée, puis cliquez sur le bouton OK pour enregistrer les modifications. Le client de messagerie devrait désormais être en mesure de réceptionner des e-mails.
