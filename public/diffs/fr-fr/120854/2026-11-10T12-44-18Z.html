1# Si une alerte de détection de liquide s’affiche sur votre ordinateur portable Mac

3Lorsque vous connectez un câble USB-C ou un accessoire à votre MacBook Neo, MacBook Air avec puce M3, M4 ou M5, ou MacBook Pro avec puce M3 Pro, M3 Max, M4, M4 Pro, M4 Max, M5, M5 Pro ou M5 Max doté de macOS Sequoia ou version ultérieure, une alerte peut vous indiquer que la présence d’un liquide a été détectée dans le port. Si vous voyez cette alerte, c’est que votre Mac a détecté du liquide dans le port USB-C, dans le câble ou dans l’accessoire.
3Sous macOS Sequoia ou ultérieur, lorsque vous connectez un câble ou un accessoire USB-C, certains modèles d’ordinateurs portables Mac peuvent vous avertir de la présence de liquide dans le port. Si vous voyez cette alerte, c’est que votre Mac a détecté du liquide dans le port USB-C, dans le câble ou dans l’accessoire.
