3Vous pouvez créer un code de Temps d’écran pour vous assurer que les réglages que vous choisissez pour l’appareil de votre enfant ou le vôtre restent en vigueur. Cela signifie que le code doit être saisi pour pouvoir modifier des réglages de Temps d’écran. Lorsqu’un code de Temps d’écran est activé sur l’appareil d’un enfant, vous recevez une notification chaque fois que ce code est saisi sur l’appareil en question.
3Vous pouvez créer un code de Temps d’écran afin que les réglages que vous choisissez pour l’appareil de votre enfant ou le vôtre restent en place. Cela signifie que le code doit être saisi pour pouvoir modifier des réglages de Temps d’écran. Lorsqu’un code de Temps d’écran est activé pour l’appareil d’un enfant, vous recevez une notification chaque fois qu’il utilise le code sur son appareil.
