5La majeure partie des données de notre vie numérique est stockée sur l’iPhone et l’iPad. Il est donc essentiel de protéger ces informations. De la même manière que Touch ID a révolutionné l’authentification à l’aide d’empreintes digitales, Face ID l’a radicalement changée avec la reconnaissance faciale. 5Une grande partie de notre vie numérique est stockée sur l’iPhone et l’iPad, et il est important de protéger ces informations. De la même manière que Touch ID a révolutionné l’authentification à l’aide d’empreintes digitales, Face ID l’a radicalement changée avec la reconnaissance faciale. 7D’un simple coup d’œil, Face ID déverrouille en toute sécurité votre iPhone ou iPad Pro. Vous pouvez l’utiliser pour autoriser les paiements avec Apple Pay, les achats effectués dans l’App Store, la Librairie et d’autres services Apple, et plus encore. De plus, les développeurs peuvent intégrer à leurs apps un système de connexion basé sur Face ID.

15Pour commencer à utiliser Face ID, vous devez d’abord enregistrer votre visage. Vous pouvez le faire lors du processus de configuration initiale ou ultérieurement en accédant à Réglages > Face ID et code. Pour déverrouiller votre appareil à l’aide de Face ID, il vous suffit d’y jeter un coup d’œil. Pour que Face ID fonctionne, la caméra TrueDepth doit voir votre visage ou vos yeux, que votre appareil soit posé sur une surface ou que vous le teniez dans une position naturelle. La caméra TrueDepth offre une profondeur de champ similaire à celle que vous obtenez lorsque vous prenez une photo ou passez un appel FaceTime à l’aide de la caméra avant. Le fonctionnement de Face ID est optimal lorsque l’appareil se trouve au maximum à une longueur de bras (25 à 50 cm) de votre visage. Pour utiliser Face ID tout en portant un masque, configurez la fonctionnalité et assurez-vous que l’appareil photo peut voir vos yeux.

23La probabilité qu’une personne choisie au hasard dans la population puisse regarder votre iPhone ou iPad Pro et le déverrouiller avec Face ID est inférieure à 1 pour 1 000 000 avec une seule apparence enregistrée, avec ou sans masque. Afin d’offrir un niveau de protection supplémentaire, Face ID autorise uniquement cinq tentatives infructueuses de reconnaissance avant de demander un code d’accès. La probabilité est plus élevée (encore davantage en cas d’utilisation de Face ID avec un masque) pour les jumeaux et les frères et sœurs qui se ressemblent, ainsi que chez les enfants de moins de 13 ans, car les traits de leur visage pourraient ne pas être encore totalement développés. Si vous êtes dans l’un de ces cas, nous vous recommandons de vous authentifier à l’aide d’un code d’accès. Vous pouvez également utiliser Face ID sans activer Face ID avec un masque.

25Face ID compare des informations de profondeur, absentes des photographies numériques en 2D ou imprimées. Cette fonctionnalité fait appel à des réseaux neuronaux sophistiqués pour empêcher tout individu portant un masque ou employant d’autres techniques d’usurper votre identité. Face ID est même sensible à l’attention. Face ID avec un masque vérifiera toujours l’attention de la personne. Face ID peut détecter si vos yeux sont ouverts et si vous portez votre attention sur l’appareil. Dès lors, un tiers éprouvera davantage de difficultés pour déverrouiller l’appareil à votre insu (comme lorsque vous dormez).

45Chez Apple, nous croyons que la vie privée est un droit humain fondamental et nous avons conçu Face ID pour protéger la vôtre. Les données de Face ID, y compris les représentations mathématiques de votre visage, sont chiffrées et protégées par la Secure Enclave. Ces données sont affinées et mises à jour au fil de votre utilisation de Face ID afin d’améliorer votre expérience, y compris lors d’une authentification réussie. Les données sont également mises à jour lorsque Face ID détecte une correspondance proche et qu’un code d’accès est ensuite saisi pour déverrouiller l’appareil. Les données de Face ID ne sortent jamais de votre appareil et ne sont jamais sauvegardées sur iCloud ni ailleurs.
45Chez Apple, nous croyons que la vie privée est un droit humain fondamental et nous avons conçu Face ID pour protéger la vôtre. Les données de Face ID, y compris les représentations mathématiques de votre visage, sont chiffrées et protégées par la Secure Enclave. Les données d’image supplémentaires utilisées pour Face ID sur certains appareils sont traitées par le Secure Exclave - un compartiment isolé au niveau matériel et intégré au processeur pour traiter les données des capteurs séparément du reste du système. Les données qui sont traitées et analysées dans le Secure Exclave ne sont accessibles ni par iOS, ni par les apps, ni par l’utilisateur, ni par Apple. Les données de Face ID sont affinées et mises à jour à mesure que vous utilisez Face ID pour améliorer votre expérience, y compris lorsque vous vous authentifiez. Les données sont également mises à jour lorsque Face ID détecte une correspondance proche et qu’un code d’accès est ensuite saisi pour déverrouiller l’appareil. Les données de Face ID ne quittent pas votre appareil, ne sont jamais mises à la disposition d’iOS, d’iPadOS, des apps ou d’Apple, et ne sont jamais sauvegardées sur iCloud ou ailleurs.

47Si vous choisissez d’enregistrer votre visage, vous pouvez à tout moment contrôler l’utilisation de Face ID ou désactiver cette fonctionnalité. Par exemple, si vous ne souhaitez pas que Face ID gère le déverrouillage de votre appareil, ouvrez Réglages > Face ID et code, puis désactivez l’option Déverrouiller l’iPhone ou Déverrouiller l’iPad. Vous pouvez également utiliser Face ID sans configurer l’utilisation avec un masque facial. Pour désactiver complètement Face ID, ouvrez Réglages > Face ID et code, puis touchez Réinitialiser Face ID. Cette opération supprime les données de Face ID de votre appareil, dont les représentations mathématiques de votre visage. Si vous choisissez d’effacer ou de réinitialiser votre appareil à l’aide de la fonction Localiser mon , ou d’effacer son contenu et ses réglages, toutes les données de Face ID seront également supprimées.
