29## Utiliser Terminal
30
31Vous pouvez utiliser Terminal pour télécharger le programme d’installation des versions de macOS compatibles, à condition qu’elles ne soient pas antérieures à la version fournie avec votre Mac, ou celui de la version la plus proche encore disponible.
32
33- Assurez-vous que votre Mac est doté de macOS Catalina 10.15 ou d’une version ultérieure.
34
35- Ouvrez Terminal, qui se trouve dans le sous-dossier Utilitaires du dossier Applications. Ou Utilisez Spotlight ou Siri AI dans la barre des menus pour rechercher et ouvrir Terminal.
36
37- Saisissez ou collez cette commande dans Terminal, en remplaçant « [number] » par le [numéro de la dernière version de macOS](https://support.apple.com/fr-fr/109033#latest) compatible que vous souhaitez télécharger : softwareupdate --fetch-full-installer --full-installer-version [number]
38
39- Exemple : softwareupdate --fetch-full-installer --full-installer-version 26.6.2
40
41- Appuyez sur la touche Retour pour valider la commande.
42
43- À mesure que macOS se télécharge dans le dossier Applications, Terminal indique la progression de l’installation (téléchargement) sous forme de pourcentage.
44
45- Si Terminal indique que la mise à jour est introuvable, cela signifie que cette version de macOS n’est pas disponible pour votre Mac. Vous pouvez saisir softwareupdate --list-full-installers pour obtenir la liste des versions de macOS actuellement disponibles pour votre modèle de Mac.
46
47- Lorsque Terminal indique que l’installation est terminée, le téléchargement est terminé. Ouvrez le dossier Applications et double-cliquez sur le programme d’installation de macOS, nommé Installer [nom de la version], puis suivez les instructions qui s’affichent à l’écran pour procéder à l’installation. Vous pouvez aussi conserver le programme d’installation dans le dossier Applications afin de l’utiliser ultérieurement.
